/*
 * SYSTEM OVERVIEW
 * ───────────────
 *
 * Full cave exploration system with production quality:
 *
 * 1. CAVE GENERATION (CaveGraphGenerator + HectonVoxelEngine + WorldCaveDirector)
 *    └─ Deterministic procedural cave topology (rooms, tunnels, entrances)
 *    └─ Biome-specific cave types (shallow/mid/deep)
 *    └─ Hazard and mood levels affect visual presentation
 *
 * 2. CAVE BIOLUMINESCENCE (CaveBioluminescenceSystem)
 *    └─ Automatic light spawning in caves
 *    └─ Spectral cues: warm (shallow), white (mid), blue (deep)
 *    └─ Intensity scales with mood level
 *    └─ Range scales inversely with hazard (danger = claustrophobic)
 *
 * 3. CAVE ENVIRONMENTS (CaveDressingConfig)
 *    └─ Shader overlays: mineral crust, wall growth
 *    └─ Simple meshes: sediment shelves
 *    └─ Particles: bioluminescent fungi, deep life glow
 *    └─ All cheap, no heavy geometry
 *
 * 4. CAVE FAUNA (CaveFaunaContext + FaunaDirector)
 *    └─ Fauna pressure based on cave type
 *    └─ Shallow: 1-3 peaceful fish
 *    └─ Mid: mixed territorial and passive
 *    └─ Deep: predatory, dangerous, rare large creatures
 *
 * 5. ENTRANCE QUALITY & READABILITY
 *    └─ Visual entrance markers (light + particles)
 *    └─ Seam cleanup and quality pass
 *    └─ Safe entrance zone (spherical trigger)
 *

 *
 * CONFIGURATION GUIDE
 * ═══════════════════
 *
 * BIOLUMINESCENCE SYSTEM (CaveBioluminescenceSystem)
 * ──────────────────────────────────────────────────
 *
 * shallowIntensity: 2.0f
 *   Controls how bright shallow cave lights are.
 *   Higher = more visibility, more arcade feel.
 *   Recommended: 1.5-2.5f for comfortable visibility.
 *
 * midIntensity: 1.5f
 *   Mid-depth cave brightness.
 *   Recommended: 1.0-2.0f.
 *
 * deepIntensity: 1.0f
 *   Deep cave brightness (should feel isolated and eerie).
 *   Recommended: 0.5-1.5f.
 *
 * hazardRangeScale: 1.5f
 *   How much hazard reduces light range.
 *   1.5 = dangerous caves have 33% narrower light range.
 *   This creates claustrophobic feeling in threat zones.
 *
 * updateInterval: 5
 *   How many frames between light updates.
 *   5 = update 12 times per second at 60 FPS.
 *   Higher = cheaper, but lighting changes lag.
 *   Safe range: 3-10.
 *
 *
 * CAVE PRESET SETTINGS (CavePreset)
 * ─────────────────────────────────
 *
 * moodLevel: 0f-1f
 *   0 = silent, empty cave
 *   0.5 = medium life activity
 *   1 = teeming with creatures and biolum
 *   Affects: biolum intensity, creature density, dressing layer richness
 *
 * hazardLevel: 0f-1f
 *   0 = safe to explore
 *   0.5 = moderate danger (territorial creatures)
 *   1 = maximum danger (predatory, aggressive fauna)
 *   Affects: light range (narrower = claustrophobic), fauna type, entrance color
 *
 * enableStructures: true/false
 *   Spawn interior structures (stalactites, boulders, columns, etc.)
 *   Recommended: always true for visual interest.
 *
 * maxStructures: 4-10 depending on cave size
 *   Shallow: 4-6 (sparse detail)
 *   Mid: 8-10 (moderate clutter)
 *   Deep: 10-15 (dense, complex)
 *
 * spawnContext: CaveShallow / CaveMid / CaveDeep
 *   Determines loot table (what resources spawn here).
 *   Shallow: titanium, copper, quartz
 *   Mid: uranium, mixed crystals
 *   Deep: rare uranium, exotic materials, anomalies
 *
 * isRuinLinked: true/false
 *   If true, adds old human-tech structures to cave (old modules, cables, etc.)
 *   Useful for story caves and canyon biomes.
 *
 *
 * FAUNA INTEGRATION (CaveFaunaContext)
 * ────────────────────────────────────
 *
 * The cave system outputs fauna presets to FaunaDirector:
 *
 * faunaDensity: 0f-1f
 *   Overall creature count and activity level.
 *
 * passivityLevel: 0f-1f
 *   0 = all predators (maximum threat)
 *   1 = all peaceful (swimming decoration)
 *
 * territoriality: 0f-1f
 *   How aggressively creatures defend their space.
 *   Used by nesting/spawning logic.
 *
 * smallPassiveRatio: 0f-1f
 *   Presence of small ambient fish (ambience, no threat).
 *
 * territorialRatio: 0f-1f
 *   Presence of medium creatures with nesting behavior.
 *
 * rareCreatureRatio: 0f-1f
 *   Presence of large/rare/epic creatures.
 *   Dangerous caves should have 0.1-0.5.
 *
 * floorSpawnBias, wallSpawnBias, openWaterBias
 *   Control where creatures spawn (floor shelter, wall nesting, open hunting).
 *   All three should sum to ≤1.0.
 *
 *
 * DRESSING LAYER SETTINGS (CaveDressingConfig)
 * ─────────────────────────────────────────────
 *
 * MineralCrust:
 *   Shader overlay for cave walls/ceiling.
 *   enabled: true/false
 *   intensity: 0.4 (shallow, sparse) to 0.8 (deep, heavy)
 *   tint: color stain (warm sand vs cold crystal)
 *   scale: 0.3-0.7 (finer = more detail)
 *
 * SedimentShelves:
 *   Simple floor meshes (cheap geometry).
 *   maxCount: 4-12 depending on cave size
 *   opacity: 0.5-0.8 (semi-transparent silt)
 *
 * DeepFungi:
 *   Bioluminescent particle glow.
 *   density: 0.2 (shallow) to 0.7 (deep)
 *   emissionRate: 5-25 particles/second
 *   particleSize: 0.05-0.15 meters
 *   lifetime: 2-3 seconds
 *
 * WallGrowth:
 *   Animated shader effect (sway + pulse).
 *   swayAmount: 0.1-0.4
 *   swayFrequency: 0.3-1.0 Hz (visual "breathing" effect)
 *   pulseAmount: 0.1-0.3 (brightness variation)
 *
 *
 * DEBUGGING
 * ═════════
 *
 * Console Output Codes:
 *   [CaveGraphGenerator]: Cave topology is sound
 *   [WorldCaveDirector]: Cave spawn successful
 *   [CaveBiolum]: Light creation (if debugLogLightSpawn=true)
 *
 * Common Issues:
 *
 * Q: No caves spawning
 * A: Check console for "voxelEngine == null" or entrance errors.
 *    Verify MapMagicBridge is working (test with terrain height sample).
 *    Verify biomeFamilyProfile is not null in current zone.
 *
 * Q: Caves spawn but no lights
 * A: Check if CaveBioluminescenceSystem is enabled.
 *    Verify reference is wired in WorldCaveDirector.
 *    Check console for "caveBiolumSystem == null" in ResolveReferences.
 *
 * Q: Lights but no interior structures
 * A: Verify preset.enableStructures == true.
 *    Check that maxStructures > 0 for the cave type.
 *    Verify allowed structure types list is not empty.
 *
 * Q: No dressing (minerals, fungi, shelves)
 * A: Check that dressing config has enabled=true.
 *    Verify shelf prefab is assigned if using sediment shelves.
 *    Check console for any particle system warnings.
 *
 *
 * PERFORMANCE TARGETS (MX350 Context)
 * ═══════════════════════════════════
 *
 * Per-cave cost budget:
 *   - Light component: 0.1ms (shadow setup is disabled)
 *   - Dressing shader overlay: 0.05ms (material property block only)
 *   - Fungi particles: 0.2ms (simple billboard, no gravity)
 *   - Interior structures (from voxel mesh): already in mesh cost (~0.5-2ms per cave for generation)
 *
 * Total: ~0.4ms per active cave (very cheap for rich visuals)
 *
 * GC Allocation:
 *   - Cave generation: one-time allocation during spawn
 *   - Per-frame in Tick: 0 bytes (no allocations in hot path)
 *   - On cave cleanup: minimal (destroy GameObjects, clear lists)
 *
 * Memory Estimates:
 *   - Per cave instance: ~5-50KB depending on voxel resolution
 *   - Cached light list: ~256 bytes
 *   - Dressing components: ~1KB
 *   - Total per cave: ~50KB (very lean)
 *
