Frequently Asked Questions

What is HECTON-8?

HECTON-8 is an in-development deep-sea Unity game project about pressure-rated machinery, salvage, instruments, and the cost of a bad return route. This page is a concept surface, not a playable build.

What technologies does HECTON-8 use?

The project configuration identifies Unity 6000.5 and the Universal Render Pipeline, with MapMagic and Crest integration symbols present in the repository. Runtime behavior, performance, and platform support require fresh build and profiler evidence.
