   13:     /// <summary>
   14:     /// Enters Play Mode from batchmode, lets the game boot, reports what the runtime actually
   15:     /// contains, and exits.
   16:     ///
   17:     /// This exists because nothing in the project could prove runtime behaviour. Every static
   18:     /// probe here answers "is it wired", never "does it run". The PlayMode test assembly is
   19:     /// disabled by a NEVER_COMPILE_TESTS define constraint, so no test can execute without
   20:     /// changing project-wide settings, and a headless machine has no other way in. The result was
   21:     /// a steady stream of changes verified by "0 CS errors" and nothing else.
   22:     ///
   23:     /// Usage - note there must be NO -quit, or the editor closes before Play Mode ever starts:
   24:     ///   Unity.exe -batchmode -nographics -projectPath . -logFile Logs/playprobe.log \
   25:     ///             -executeMethod Hecton8.EditorTools.Diagnostics.H8_HeadlessPlayModeProbe.Run \
   26:     ///             -h8Scene Assets/_Project/Scenes/02_HECTON_WORLD.unity -h8WarmupFrames 240
   27:     ///
   28:     /// The probe calls EditorApplication.Exit itself: 0 if every check passed, 1 otherwise.
   29:     ///
   30:     /// EVERY run leaves one machine-readable artifact, by default at
   31:     /// &lt;projectRoot&gt;/Logs/h8_playprobe_route.json, overridable with -h8RouteArtifact. It carries the
   32:     /// per-phase clock table, the save-directory diff, the determinism block described below, and a
   33:     /// verdict for all ten rows of the First 20 Minutes Required Route - rows with no producer report
   34:     /// NOT_EXERCISED rather than staying silent. Before that artifact existed, four runs on the same day
   35:     /// used four different argument sets, emitted only log text, and could not be compared with one
   36:     /// another.
   37:     ///
   38:     /// The determinism block (console tag <c>DETERMINISM</c>, artifact key <c>determinism</c>) is the
   39:     /// answer to "did two runs of one seed do the same thing": it publishes the master state hash that
   40:     /// LockstepStateValidator already computes, the post-simulation frame it was sampled at, and the
   41:     /// slow-tick time the dispatcher discarded. This probe computes no hash of its own, and the block's
   42:     /// <c>coverage</c> field states in the artifact exactly which four buffers the hash does and does not
   43:     /// cover - read it before quoting a match as proof that two worlds agreed.
   44:     ///
   45:     /// WHEN THERE IS NO HASH, the block says WHICH of three things was wrong, because they have three
   46:     /// different owners and one measured run reported all three identically. <c>OwnerAbsentNoBuffer</c> means
   47:     /// no <c>LockstepStateValidator</c> exists at all - a lifetime defect. <c>OwnerPresentBufferUnopened</c>
   48:     /// means one exists and its vault buffer open failed silently - a vault-timing defect.
   49:     /// <c>NeverSampled</c> means the buffer is open and the run simply ended before a hash frame - a budget
   50:     /// matter. Alongside them the <c>DETERMINISM OWNER TRACE</c> lines sample the owner's existence at the
   51:     /// boot warmup, at the first gameplay tick and at end of run, which brackets the window an owner
   52:     /// disappeared in WITHOUT a second editor run; before that trace existed, separating "never created"
   53:     /// from "created then destroyed by a scene load" cost one full run per hypothesis.
   54:     ///
   55:     /// The slow-tick discard is reported as a first-class COMPARABILITY caveat
   56:     /// (<c>DETERMINISM SLOWTICK DISCARD</c>, artifact <c>runComparable</c> / <c>comparabilityCaveat</c>), not
   57:     /// as one number among a dozen. Two runs of one seed that discarded different amounts of owed simulation
   58:     /// time did not simulate the same world, so a hash difference between them proves nothing. The clamp that
   59:     /// discards the time is CORRECT and stays - it is the anti-death-spiral guard.
   60:     ///
   61:     /// <c>-h8ReviveDeterminismOwner</c> is OPT-IN and off by default: it creates a validator in memory when
   62:     /// the session has none, to answer whether the hash path can produce a number at all. It is deliberately
   63:     /// not the default, because the owner's absence is the only evidence this harness has about it and a
   64:     /// silently manufactured owner would hide that defect behind a hash. See TryReviveDeterminismOwner.
   65:     ///
   66:     /// Save-leg arguments: -h8SaveSeconds (default 60, clamped so the leg cannot push the run past
   67:     /// -h8TimeoutSeconds), -h8SaveSlot (0..2), -h8SkipSaveLeg to disable it. The leg only runs after
   68:     /// a game was actually started and the world scene settled.
   69:     ///
   70:     /// Relies on the project having Enter Play Mode Options set to DisableDomainReload
   71:     /// (ProjectSettings/EditorSettings.asset, m_EnterPlayModeOptions: 1), which is why a plain
   72:     /// static state machine survives the transition. Should that ever change, the statics reset
   73:     /// mid-run and the probe stalls rather than lying - always run it under an external timeout.
   74:     /// </summary>
