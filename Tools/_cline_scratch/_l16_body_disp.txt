   78:         // Largest fixed step a step-bounded headless run can take without ANY lane discarding time.
   79:         //
   80:         // The binding lane is the FIXED-step lane, not the slow lane the discard counters made visible and
   81:         // not the fast lane either. Derivation, because guessing this wrong is the whole failure mode:
   82:         //
   83:         //   Fixed lane (AdvanceFixedStep): temporal compression trips when
   84:         //   residual + dt > FixedStepSeconds * MaxFixedSubstepsPerFrame = 0.02 * 3 = 0.06 s. The residual
   85:         //   carried in from the previous frame is anything under one FixedStepSeconds, so the bound must
   86:         //   leave a whole substep of headroom or a boundary frame compresses on a float hair:
   87:         //   0.02 * (3 - 1) = 0.04 s.
   88:         //
   89:         //   Fast/unscaled-fast lane: the clamp trips at (MaxCadenceSubstepsPerFrame + 1) intervals, and the
   90:         //   residual is under one interval, so the entire substep budget is usable: 4 * 1/60 = 0.0667 s.
   91:         //
   92:         //   Slow lane: 4 * 0.1 = 0.4 s. Cold lane: 4 * 1.0 = 4.0 s. Both far looser.
   93:         //
   94:         // So 0.04 s, and a caller who sized a step against the slow interval (0.4 s) or the fast one
   95:         // (0.0667 s) would silently drop physics/fixed-tick time while believing the run was clean. Both
   96:         // candidates are derived from the live constants and the minimum is taken, so re-tuning any cadence
   97:         // cannot leave this stale or silently invert which lane binds.
