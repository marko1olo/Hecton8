EXECUTIVE ANSWER
================================================================================

1) Does H8_HeadlessWorldDriver call SystemDispatcher fixed lanes / simulate FixedUpdate?
   NO. Driver only advances its own phase schedule counters and publishes input
   (SignalBus PLIN + CoreDeterminismSignals input-override). It may call
   HectonPlayerMovement.EnsureDispatcherRegistration() so HPM is ON the fixed
   lane, but it never calls DispatchFixedStep / FixedTick / RunDispatcherUpdate.

2) How should product path still get HPM FixedTick under headless?
   Only via the real product pump:
     PlayerLoop Update node
       -> SystemDispatcher.RunDispatcherUpdate
         -> RunFixedStepAccumulator(dilatedDeltaTime)
           -> DispatchFixedStep
             -> IFixedTickable.FixedTick (HPM on PriorityLayer.Player)
               -> SampleGameplayLocomotionInputForFixedStep
                 -> ProcessPlayerInputFrame -> GetState  (= hop2)

   HeadlessSimulationRunner already arms this with EnableStepBoundedTime +
   RequestHeadlessTimeDilation + unpause. H8_HeadlessPlayModeProbe does NOT.
   That is the missing product pump for the probe route.

3) Is the root that headless never advances dilatedDeltaTime/fixed steps so HPM
   never FixedTicks (hence never hop2)?
   YES for the playmode-probe path, as the primary root.
   LIVE L15: WORLDDRIVER ticks=258115 / inputOverrides=258115 while hop2 absent
   and intent=0 is exactly: input producer ran hot; fixed-step consumer did not.
   INPUTHOP lateFrameTick~22 / presimTick~300 proves SOME dispatcher frames ran,
   but not that fixed accumulator crossed 0.02s often enough (or at all with
   non-zero dilated dt) during Swim. Batchmode WallClock frequently yields
   unscaledDeltaTime==0; pause/dilation 0 forces dilatedDeltaTime=0; accumulator
   early-outs and never calls HPM.FixedTick.

4) Product-only fix (NOT mock hop2):
   When game is in play under batchmode probe, arm the SAME product clock path
   HeadlessSimulationRunner already uses:
     - unpause if SimulationPaused
     - RequestHeadlessTimeDilation(>0)
     - SystemDispatcher.EnableStepBoundedTime(dt <= MaxClampFreeStepSeconds)
   Ensure player loop actually runs (EnterPlaymode already does; do NOT replace
   with a fake FixedTick). Do NOT call HPM.GetState from the driver.
   Optional sustain: re-assert clock if pause/dilation/step-bound drops mid-window.

3. REAL FIXED-STEP PRODUCT PATH (SystemDispatcher)
================================================================================

File: Assets/_Project/Scripts/Core/SystemDispatcher.cs

Player loop install (EnsureDispatcherPlayerLoopInstalled):
  - DispatcherUpdatePlayerLoopNode before ScriptRunBehaviourUpdate
      -> RunDispatcherUpdateFromPlayerLoop -> RunDispatcherUpdate
  - DispatcherLateFramePlayerLoopNode before ScriptRunBehaviourLateUpdate
      -> RunDispatcherLateFrameFromPlayerLoop -> RunDispatcherLateFrame

RunDispatcherUpdate order for hop2:
  1. ResolveDispatcherUnscaledDeltaTime()
       WallClock: Time.unscaledDeltaTime (often 0 in batchmode stalls)
       StepBounded: AdvanceStepBoundedClock() => constant fixedDeltaSeconds
  2. EnsureInputDeterminismResolved + PreSimulationInputTick(unscaledDt)  // hop1
  3. frameDilationScalar = ConsumeFrameTimeDilationScalar()
       returns 0 if _simulationPaused OR _timeDilationScalar ~ 0
  4. deltaTime = unscaledDt * frameDilationScalar  // dilatedDeltaTime
  5. IUpdatable walk, RunFastTick, RunUnscaledFastTick
  6. RunFixedStepAccumulator(deltaTime, blockGameplayLanes)  // CRITICAL
  7. slow/cold/frost...

RunFixedStepAccumulator(dilatedDeltaTime):
  if dilatedDeltaTime <= 0f: RefreshFixedInterpolationAlpha(); return; // NO FixedTick
  accumulate; while >= FixedStepSeconds (0.02): DispatchFixedStep(0.02)
  MaxFixedSubstepsPerFrame = 3; temporal compression above 0.06s residual budget

DispatchFixedStep:
  RunMasterFixedSimulationBridge
  for each fixed lane (incl. PriorityLayer.Player): item.FixedTick(fixedDeltaTime)
  post-fixed walk

ShouldSkipLaneDuringBootstrap (L14 already landed): always returns false now.
Player lane bootstrap skip is NOT the remaining root if hop2 still absent LIVE.

EnableStepBoundedTime(fixedDeltaSeconds) [internal, QA headless uses it]:
  - switches ResolveDispatcherUnscaledDeltaTime off wall clock
  - docs: call before pumping player loop; node consumes fixedDeltaSeconds per pump
  - MaxClampFreeStepSeconds = 0.04 (fixed lane binding: 0.02*(3-1))

GameTickManager: also IFixedTickable on Core; only runs when DispatchFixedStep
walks it. NOT independent Unity FixedUpdate owner for HPM. HPM hop2 does not
go through GTM.
