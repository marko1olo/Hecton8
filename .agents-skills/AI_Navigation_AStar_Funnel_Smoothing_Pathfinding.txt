# PATHFINDING_FUNNEL.md
## Distilled Technical Mandate — Hecton-8 Navigation Engine

---

## §0 — CORE INVARIANTS

- Path smoothing: O(N) Funnel (Simple String Pulling). No Bezier. No iterative relaxation.
- All Nav Jobs: `[BurstCompile(FloatMode=FloatMode.Fast, FloatPrecision=FloatPrecision.Standard)]`
- Zero managed heap in hot path. All persistent buffers: `NativeList<float3>` / `NativeArray<T>`.
- No Physics.Raycast inside Jobs. LoS resolved via `ThreatGrid` voxel snapshot only.
- Edge costs: strictly non-negative. `multiplier >= 1.0f` enforced via `math.max(1.0f, m)`.

## §1 — DATA STRUCTURES

### 1.1 Portal Definition

struct NavPortal
{
    float3 Left;   // left vertex of portal edge (world-space)
    float3 Right;  // right vertex of portal edge (world-space)
}

- Store portal sequence as `NativeArray<NavPortal>` sized at worst-case corridor depth.
- Indexed sequentially. Portal[0] = first constraint after Apex. Portal[N-1] = goal portal.
- Winding invariant: Left always CCW relative to path forward vector. Enforce on grid build, not at runtime.

### 1.2 Funnel State

struct FunnelState
{
    float3 Apex;
    float3 LeftRay;    // direction from Apex to current left bound
    float3 RightRay;   // direction from Apex to current right bound
    int    ApexIndex;  // portal index where Apex was last set
    int    LeftIndex;
    int    RightIndex;
}

- Single struct. No class. Stack-allocated or member of Job struct.

### 1.3 Persistent Waypoint Buffer

NativeList<float3> WaypointBuffer  // Allocator.Persistent, cleared per-request
NativeList<float3> ApexHistory     // stores confirmed apex positions

- `WaypointBuffer.Clear()` at job entry. Never Dispose/Re-Alloc in hot path.
- Max capacity: `math.min(corridor_length * 2, 512)`. Pre-size at init.

### 1.4 Threat Grid Snapshot

NativeArray<byte> ThreatGrid   // [x + z*W + y*W*D], byte 0-255 = threat intensity
int3 GridDim                   // (W, H, D) voxel counts
float3 GridOrigin              // world-space origin of voxel[0,0,0]
float  VoxelSize               // uniform voxel edge length (e.g. 1.0m)

- Snapshot taken once per path-solve frame. Never read live physics during A* or Funnel.
- Updated async via `IJobParallelFor` over dynamic obstacle list, double-buffered.

### 1.5 Heightmap

NativeArray<ushort> Heightmap  // row-major [x + z*W], ushort in [0, 65535]
float HeightScale              // world_height = raw * HeightScale
float HeightOffset             // world_height += HeightOffset
int2  HeightmapDim             // (W, D) sample counts

## §2 — A* COST MODEL

### 2.1 Edge Cost Formula

g_cost(n) = g_cost(parent) + edge_base_cost(parent, n)

edge_base_cost(a, b):
    dist        = math.length(b.WorldPos - a.WorldPos)
    threat_byte = ThreatGrid[WorldToVoxelIndex(b.WorldPos)]
    threat_f    = (float)threat_byte * ThreatMultiplier      // ThreatMultiplier tunable [0.0, 8.0]
    return dist + threat_f

- `ThreatMultiplier` per-entity-type. Predator flees threat → multiplier negative-equivalent via inverse sampling. Herbivore avoids → positive. Never write negative weights; invert sampling logic instead.
- Admissibility: heuristic `h(n) = math.length(goal - n.WorldPos)` — Euclidean. Never overestimate. Admissible by definition in open 3D space.

### 2.2 Weighted A* Variant (Performance LOD)

f(n) = g(n) + W * h(n)

- Near entities (<50m): `W = 1.0` → optimal
- Mid entities (50–150m): `W = 1.5` → suboptimal, faster
- Distant entities (>150m): skip A*, use Flowfield vector only

### 2.3 Node Representation

struct NavNode
{
    int    Index;       // flat grid index
    float  G, F;
    int    ParentIdx;
    byte   Flags;       // bit0=Open, bit1=Closed, bit2=Blocked
}

- Flat `NativeArray<NavNode>` over grid. Index = x + z*W + y*W*D.
- Open set: `NativeMinHeap<int, float>` keyed by F. Custom Burst-compatible binary heap.

## §3 — FUNNEL ALGORITHM (O(N) STRING PULLING)

### 3.1 Prerequisites
- Input: `NativeArray<NavPortal>` (N portals) — ordered apex-to-goal.
- Input: `float3 StartPos`, `float3 GoalPos`.
- Output: appended into `NativeList<float3> WaypointBuffer`.

### 3.2 Cross Product Sign Test (2D projected onto XZ plane)

TriArea2D(a, b, c):
    return (b.x - a.x) * (c.z - a.z) - (b.z - a.z) * (c.x - a.x)
    // > 0 → c is left of (a→b)
    // < 0 → c is right of (a→b)
    // = 0 → collinear

- For 3D underwater (Y matters): project to dominant plane per corridor segment, or use full 3D cross for non-horizontal passages. Default: XZ for horizontal, XY for vertical shafts. Detect via `abs(corridor_up.y) < 0.3f`.

### 3.3 Step-By-Step Funnel Logic

INIT:
    state.Apex      = StartPos
    state.LeftRay   = Portal[0].Left  - Apex
    state.RightRay  = Portal[0].Right - Apex
    state.LeftIdx   = 0
    state.RightIdx  = 0
    WaypointBuffer.Add(StartPos)

FOR i = 1 TO N-1:
    newLeft  = Portal[i].Left
    newRight = Portal[i].Right

    // --- UPDATE RIGHT FUNNEL SIDE ---
    if TriArea2D(Apex, RightRay_endpoint, newRight) <= 0.0f:
        if SameOrCloser(Apex, RightRay_endpoint, newRight) OR TriArea2D(Apex, LeftRay_endpoint, newRight) > 0.0f:
            // newRight tightens right side
            state.RightRay = newRight - Apex
            state.RightIdx = i
        else:
            // newRight crosses LEFT ray → right apex step
            WaypointBuffer.Add(LeftRay_endpoint)
            state.Apex     = LeftRay_endpoint
            state.LeftRay  = Portal[state.LeftIdx + 1].Left  - Apex   // re-scan from apex's left index
            state.RightRay = Portal[state.LeftIdx + 1].Right - Apex
            i = state.LeftIdx  // restart scan from new apex portal
            CONTINUE

    // --- UPDATE LEFT FUNNEL SIDE ---
    if TriArea2D(Apex, LeftRay_endpoint, newLeft) >= 0.0f:
        if SameOrCloser(Apex, LeftRay_endpoint, newLeft) OR TriArea2D(Apex, RightRay_endpoint, newLeft) < 0.0f:
            state.LeftRay = newLeft - Apex
            state.LeftIdx = i
        else:
            // newLeft crosses RIGHT ray → left apex step
            WaypointBuffer.Add(RightRay_endpoint)
            state.Apex     = RightRay_endpoint
            state.RightRay = Portal[state.RightIdx + 1].Right - Apex
            state.LeftRay  = Portal[state.RightIdx + 1].Left  - Apex
            i = state.RightIdx
            CONTINUE

FINALIZE:
    WaypointBuffer.Add(GoalPos)

- `SameOrCloser`: `math.lengthsq(newPt - Apex) <= math.lengthsq(currentRayEndpoint - Apex)`
- Re-scan loop guard: never re-scan past current `i`. Track `scanStart` = apex portal index + 1.
- Degenerate wedge (LeftRay == RightRay): skip update, continue. Collinear portal = passthrough.

### 3.4 3D Vertical Correction
- After 2D funnel produces XZ waypoints, sample heightmap at each waypoint XZ.
- Set `wp.y = SampleHeightmapBilinear(wp.xz) + AgentHoverOffset`.
- Apply AFTER full funnel pass. Never during funnel iteration.

### 3.5 Fallback Condition

IF WaypointBuffer.Length <= 1 OR FunnelIterations > MaxPortals * 2:
    WaypointBuffer.Clear()
    CopyRawAStarChain(NodeParentArray, GoalIdx, StartIdx, WaypointBuffer)
    // reverse in-place: O(N) swap

## §4 — HEIGHTMAP BILINEAR SAMPLING (ZERO-GC, BURST)

### 4.1 Formula

SampleHeightmapBilinear(xz):
    u  = (xz.x - GridOrigin.x) / CellSize
    v  = (xz.y - GridOrigin.z) / CellSize   // xz.y = world Z

    x0 = (int)math.floor(u),  x1 = x0 + 1
    z0 = (int)math.floor(v),  z1 = z0 + 1

    // clamp to [0, Dim-1]
    x0 = math.clamp(x0, 0, W-1),  x1 = math.clamp(x1, 0, W-1)
    z0 = math.clamp(z0, 0, D-1),  z1 = math.clamp(z1, 0, D-1)

    fx = math.frac(u),  fz = math.frac(v)

    h00 = (float)Heightmap[x0 + z0*W]
    h10 = (float)Heightmap[x1 + z0*W]
    h01 = (float)Heightmap[x0 + z1*W]
    h11 = (float)Heightmap[x1 + z1*W]

    h = math.lerp(math.lerp(h00, h10, fx), math.lerp(h01, h11, fx), fz)
    return h * HeightScale + HeightOffset

- All ops: `Unity.Mathematics` intrinsics. No Mathf. No managed calls.
- `math.frac` = `u - math.floor(u)`. Compiler fuses to single FMA chain.

## §5 — LINE-OF-SIGHT (GRID-BASED, NO RAYCASTS)

### 5.1 Voxel LoS (Bresenham 3D)

VoxelLoS(a_world, b_world) → bool:
    a_vox = WorldToVoxel(a_world)
    b_vox = WorldToVoxel(b_world)

    dx = abs(b_vox.x - a_vox.x)
    dy = abs(b_vox.y - a_vox.y)
    dz = abs(b_vox.z - a_vox.z)
    sx = sign(b_vox.x - a_vox.x), sy = ..., sz = ...
    dominant = max(dx, dy, dz)

    FOR step = 0 TO dominant:
        t = step / (float)dominant
        sample_vox = round(lerp(a_vox, b_vox, t))
        IF ThreatGrid[FlatIdx(sample_vox)] >= SOLID_THRESHOLD:
            return false
    return true

- `SOLID_THRESHOLD = 255` (impassable geometry). Threat byte 0–254 = open with cost.
- Call only during waypoint post-validation, never inside A* inner loop.
- Funnel algorithm implicitly guarantees LoS through portal geometry — skip LoS revalidation for smoothed waypoints unless NavMesh is dynamic.

### 5.2 Dynamic Obstacle Integration
- Obstacle writes to ThreatGrid via `IJobParallelFor` each frame, double-buffered.
- Funnel re-solve triggered only if obstacle intersects active corridor AABB.
- Corridor AABB: `NativeArray<AABB>` per active path, updated O(1) on path assignment.

## §6 — PERFORMANCE & SCALABILITY

### 6.1 Time-Slicing

PathRequestQueue: NativeQueue<PathRequest>   // Allocator.Persistent
Solvebudget per frame: min(4, queue.Count)
Distribute: frame N → entities [0..budget-1], frame N+1 → [budget..2*budget-1]

- Heavy solve (>150 nodes): spread across 4–8 frames via coroutine-free state machine.
- State enum: `Idle | AStarSlice | FunnelPending | Complete | Failed`
- Store partial A* open/closed sets in persistent `NativeArray<NavNode>` per-agent slot.
- Max concurrent agents with full A*: 8 (MX350 constraint). Excess → Flowfield.

### 6.2 Path LOD Tiers

< 50m  → Full A* + Funnel smoothing         (precise, 1-frame or sliced)
50–150m → Weighted A* (W=1.5) + skip funnel  (raw node chain, cheaper)
> 150m  → Flowfield vector sample only        (precomputed, O(1) per agent)

- LOD tier evaluated at path-request time. Re-evaluated if entity crosses tier boundary.

### 6.3 Flowfield (Distant Tier)

FlowfieldGrid: NativeArray<float2>   // XZ direction vectors, goal-relative
Update frequency: every 4 frames for active goal clusters
Goal clustering: bin goals into 16m³ cells; shared flowfield per cell

- Entity samples `FlowfieldGrid[WorldToFlowfieldIdx(pos)]` → steer direction. O(1).
- Flowfield computed via Dijkstra flood-fill in `IJobParallelFor`, starting from goal.

### 6.4 Memory Budget (MX350 / 6-8GB RAM)

ThreatGrid (128³ voxels, byte):      2 MB
Heightmap (1024×1024, ushort):       2 MB
NavNode array (256³ grid):           ~50 MB  → REDUCE to 128³ (6.4 MB) for low-spec
WaypointBuffer × 16 agents:          16 × 512 × 12B = ~96 KB
FlowfieldGrid (512×512, float2):     2 MB
Total Nav budget:                    ≤ 12 MB

- On low-spec detect: halve grid resolution, double voxel size. Detect via `SystemInfo.graphicsMemorySize < 3000`.

## §7 — FLOATING ORIGIN INTEGRATION

### 7.1 Waypoint Translation on Origin Shift

OnOriginShift(float3 shift):
    FOR i = 0 TO WaypointBuffer.Length - 1:
        WaypointBuffer[i] -= shift
    Apex -= shift
    // ThreatGrid origin:
    GridOrigin -= shift
    // FlowfieldGrid: rebuild next frame (mark dirty flag)
    FlowfieldDirty = true

- Origin shift event: subscribe via `IFloatingOriginShiftListener` (custom interface, not Unity's managed event).
- Shift magnitude threshold: `math.length(shift) > 1000f` → trigger rebuild of NavNode world positions.
- NavNode world positions stored as `float3` local-to-origin. On shift: bulk subtract via `IJobParallelFor`.

### 7.2 Absolute Universe Position (AUP)

AUP = OriginAccumulator + LocalWorldPos
OriginAccumulator: double3   // accumulates all shifts, never reset

- Store AUP only for serialization/save. Runtime path ops: local float3 only.
- On load: `LocalWorldPos = (float3)(AUP - OriginAccumulator)`.

## §8 — BURST JOB TOPOLOGY

### 8.1 Job Dependency Chain (per frame)

[MainThread]
    SchedulePathRequests()

        ▼
[Job: UpdateThreatGridJob]          // IJobParallelFor, batch=32

        ▼
[Job: AStarSliceJob]                // IJob per agent slot, sequential per slot
          (depends on ThreatGrid complete)
        ▼
[Job: FunnelSmoothJob]              // IJob, reads NavPortals, writes WaypointBuffer
          (depends on AStarSlice complete)
        ▼
[Job: HeightmapLiftJob]             // IJobParallelFor, corrects Y per waypoint

        ▼
[MainThread]
    CompleteAndDispatch()           // JobHandle.Complete(), read results

- Never `.Complete()` mid-chain. Chain with `JobHandle` dependencies only.
- `AStarSliceJob` for 8 agents: use `NativeArray<JobHandle>` + `JobHandle.CombineDependencies`.

### 8.2 Forbidden Patterns

[FORBID] List<T>, Dictionary<T,K>, LINQ inside any Job
[FORBID] new NativeArray/NativeList inside Job Execute()
[FORBID] static mutable state accessed from Jobs
[FORBID] physics queries (Raycast, OverlapSphere) inside Jobs
[FORBID] math.sqrt in inner loops → use math.lengthsq for comparisons
[FORBID] branch-heavy switch in hot inner loop → bitmask + lookup table

## §9 — EDGE CASES & FAILURE MODES

### 9.1 Wedge Collapse

Detect: TriArea2D(Apex, LeftRayEnd, RightRayEnd) ≈ 0 (< EPSILON = 1e-5f)
Action: treat as zero-width portal → add midpoint to WaypointBuffer, advance Apex

### 9.2 Infinite Loop Guard

MaxFunnelIterations = PortalCount * 3
IF iterCount > MaxFunnelIterations: GOTO Fallback (§3.5)

### 9.3 Goal Unreachable

IF A* open set exhausted without reaching goal:
    Return nearest closed node to goal (by h-value)
    Set PathStatus = Partial
    Entity behavior: re-request after 2s, or switch to wander state

### 9.4 Portal Winding Violation

IF TriArea2D(Apex, Portal[i].Left, Portal[i].Right) < 0:
    SWAP Portal[i].Left, Portal[i].Right   // correct on-the-fly, log warning

### 9.5 Vertical Shaft Handling (Y-dominant corridors)

IF abs(Portal[i].Left.y - Portal[i].Right.y) > abs(Portal[i].Left.x - Portal[i].Right.x)
   AND abs(Portal[i].Left.y - Portal[i].Right.y) > abs(Portal[i].Left.z - Portal[i].Right.z):
    Project funnel onto XY plane for this portal
    Tag portal with PlaneFlag = XY
ELSE:
    PlaneFlag = XZ (default)

- Store `PlaneFlag` per `NavPortal`. Funnel step reads flag, selects TriArea2D projection.
