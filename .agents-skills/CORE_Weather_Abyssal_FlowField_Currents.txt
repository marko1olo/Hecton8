## SECTION 0 - CORE AXIOMS

AXIOM-01: Weather state IS source of truth. All flow vectors derive from `WeatherState` bitmask.
AXIOM-02: Flow Field is READ-ONLY at entity level. WRITE only from designated SlowTick Job.
AXIOM-03: Physics fidelity scales with depth. Abyssal layer: high viscosity, low turbulence freq. Surface: inverse.
AXIOM-04: Zero per-entity math on Main Thread. Zero current calc beyond 150m radius.
AXIOM-05: All distance ops use squared distance. Sqrt forbidden in inner loops.

## SECTION 1 - DATA ARCHITECTURE

### 1.1 Core Structs

FlowNode {
    float3 direction;    // normalized world-space vector
    float  velocity;     // m/s, capped [0..20]
    float  turbulence;   // [0..1] noise amplitude scalar
}

WeatherState : uint bitmask
    bit0 = CALM
    bit1 = STORM
    bit2 = UPDRAFT_ACTIVE
    bit3 = THERMOCLINE_ACTIVE
    bit4 = HALOCLINE_ACTIVE    // salinity gradient layer - buoyancy modifier
    bit5 = BIOLUME_SURGE       // bioluminescence pressure wave trigger

CurrentMeta {
    float3 globalBaseVector;   // pre-computed per weather tick
    float  globalScale;        // [0.1..1.0] storm intensity
    float  thermalIntensity;   // convection source strength
    float  timeAccumulator;    // drives noise evolution
}

### 1.2 Grid Layout

LAYER_SURFACE  : Y > -50m     | res: 32x8x32  cells | cell_size: 4m

## SECTION 2 - WEATHER -> FLOW DERIVATION

### 2.1 Base Vector Computation (SlowTick, max 5Hz)

GIVEN WeatherState bitmask W, timeT:

globalBaseVector = float3(0,0,0)

IF bit0(W) == 1 (CALM):
    globalBaseVector = float3(0.3, 0.0, 0.1) * 0.2
    globalScale      = lerp(0.05, 0.15, snoise(float2(T*0.01, 0)))

IF bit1(W) == 1 (STORM):
    stormAngle       = snoise(float2(T*0.02, 7.3)) * PI
    globalBaseVector = float3(cos(stormAngle), -0.05, sin(stormAngle))
    globalScale      = lerp(0.6, 1.0, snoise(float2(T*0.05, 3.1)))

// Bit blending: CALM+STORM illegal - resolve via priority: STORM > CALM
// UPDRAFT modifies Y component independently (see Section 3)
// Final: globalBaseVector *= globalScale

### 2.2 Depth Modulation Per Layer

Surface  layer multiplier: 1.0
Mid      layer multiplier: lerp(1.0, 0.55, depth_norm)  // depth_norm [0..1] in layer range
Abyssal  layer multiplier: lerp(0.55, 0.2, depth_norm)

// Viscosity model: abyssal water resists velocity change
// Apply as: effective_velocity = node.velocity * depth_multiplier

### 2.3 Thermocline / Halocline Barrier (bits 3,4)

IF bit3(W) == 1:
    thermocline_Y = -120m (configurable)
    // Nodes crossing thermocline boundary: attenuate vertical component
    IF abs(node_world_Y - thermocline_Y) < 8m:
        direction.y *= 0.1   // horizontal flow forced
        velocity    *= 0.7

IF bit4(W) == 1:
    halocline_Y = -180m
    // Buoyancy inversion: entities above halocline get upward bias
    // Nodes in zone: direction.y += 0.3 * (1 - dist_to_layer / 8m)

## SECTION 3 - CONVECTION & UPDRAFT LOGIC

### 3.0 Thermodynamics / Logistics Boundary

[RULE] Flow fields may consume thermodynamic heat-source summaries, but they do not own thermal authority.
[RULE] Heat sources are read-only packets: AUP/world position, intensity, radius, lifetime, and source id.
[RULE] Logistics `THERMAL_COOLANT` availability can damp heat-source intensity only through a thermodynamics-owned summary. Flow does not query Logistics directly.
[RULE] Visual updrafts, bubbles, shimmer, and turbulence are presentation approximations unless player-critical hazard/damage state is explicitly marked by the thermodynamics owner.

[FORBID] Flow-field jobs reading or writing `LogisticsNode`.
[FORBID] Flow-field jobs solving resource throughput.
[FORBID] Logistics solving thermal diffusion or convection visuals.

## Engineering Data

| Input | Owner | Flow Use | Rejection Rule |
|---|---|---|---|
| HeatSource intensity | Thermodynamics | scales updraft and bubble VFX | no gameplay heat mutation |
| Coolant availability | Logistics via Thermodynamics | damped heat-source summary | no direct graph read |
| Current vector | Weather/Flow | VFX, audio, limited physics hints | no resource transport |
| Hazard damage | Survival/Damage owner | event trigger only | no hidden damage in VFX flow |

### 3.1 Heat Source Detection

HeatSource {
    float3 worldPos
    float  intensity    // [0..1]
    float  radius       // meters
}

// Registered sources: hydrothermal vents, active geothermal cracks
// Max concurrent sources: 8 (NativeArray<HeatSource>[8])
// Dead sources intensity lerps to 0 over 5s - avoid sudden field discontinuity

### 3.2 Vertical Velocity from Heat (per FlowNode update)

FOR each HeatSource H:
    distSq = lengthsq(node.worldPos - H.worldPos)
    IF distSq > (H.radius * H.radius * 4.0): SKIP   // broad cull

    dist = sqrt(distSq) + EPSILON                    // sqrt allowed here - once per node per source
    vertical_velocity = H.intensity / (dist * dist)  // inverse-square falloff
    vertical_velocity = min(vertical_velocity, 8.0)  // per-source cap 8m/s upward

    node.direction.y  += vertical_velocity
    node.velocity     += vertical_velocity * 0.5

### 3.3 Radial Vortex Noise Around Heat Source

// Spiral induction: hot column draws surrounding water inward+upward

FOR node in radius of H:
    toSource_xz  = normalize(float2(H.worldPos.x - node.x, H.worldPos.z - node.z))
    tangent_xz   = float2(-toSource_xz.y, toSource_xz.x)   // 90deg rotate
    vortex_strength = H.intensity * (1.0 - dist / H.radius) * 0.4

    // Helical vortex: combine inward pull + tangential spin
    node.direction.xz += toSource_xz * vortex_strength * 0.5
        +  tangent_xz * vortex_strength * 0.5

    node.turbulence   += vortex_strength * 0.6
    node.turbulence    = saturate(node.turbulence)

### 3.4 Updraft Bitmask Trigger

bit2(WeatherState) = 1  WHEN:
    ANY HeatSource.intensity > 0.4 AND HeatSource.active

// Global updraft bias when bit2 set:
    surface_layer nodes: direction.y += 0.3 * globalScale
    mid_layer nodes:     direction.y += 0.15 * globalScale
    abyssal nodes:       direction.y += 0.05 * globalScale

## SECTION 4 - TURBULENCE FIELD

### 4.1 Noise-Modulated Velocity

// Per FlowNode, computed in Burst Job during SlowTick:

noisePos   = float4(node.worldPos * TURB_SCALE, timeAccumulator * TURB_FREQ)
noiseSample = snoise(noisePos)                     // [-1..1]
noiseAbs    = noiseSample * 0.5 + 0.5             // [0..1]

node.velocity   *= (1.0 + noiseSample * node.turbulence * 0.4)
node.direction  += snoise(float4(noisePos.xyz + float3(31.7, 17.3, 5.9), noisePos.w)) * node.turbulence * 0.15

// Re-normalize direction AFTER all additive passes:
node.direction = normalizesafe(node.direction, float3(0,0,1))

CONSTANTS:
    TURB_SCALE = 0.08   // low freq = large rolling eddies
    TURB_FREQ  = 0.25   // slow temporal evolution

### 4.2 Layer-Specific Turbulence Profiles

Surface  : turbulence base = 0.7 | TURB_SCALE = 0.12 | TURB_FREQ = 0.4
Mid      : turbulence base = 0.4 | TURB_SCALE = 0.08 | TURB_FREQ = 0.25
Abyssal  : turbulence base = 0.15| TURB_SCALE = 0.04 | TURB_FREQ = 0.1
// Abyssal: near-laminar flow - horror effect from stillness, not chaos

## SECTION 5 - WALL ATTENUATION (DISTANCE FIELD)

### 5.1 Voxel Wall Distance Sampling

// Pre-baked SDF volume: NativeArray<half> WallSDF [grid_total_nodes]
// half precision sufficient - dist encoded in meters, max ~50m

// During FlowNode update:
wallDist = WallSDF[nodeIndex]                      // meters to nearest solid
wallDist = max(wallDist, EPSILON)                  // zero-divide guard

// Attenuation curve: smooth near walls
attenFactor = saturate(wallDist / WALL_FADE_DIST)  // [0..1]
attenFactor = attenFactor * attenFactor            // quadratic - sharper boundary

node.velocity   *= attenFactor
node.turbulence *= lerp(1.2, 0.8, attenFactor)    // turbulence SPIKES at walls (boundary layer)

CONSTANT: WALL_FADE_DIST = 3.0m

### 5.2 No-Penetration Directional Correction

// Redirect flow parallel to wall when wallDist < 1.5m
IF wallDist < 1.5:
    wallNormal = SDF_Gradient(nodeIndex)           // pre-baked, normalized float3
    dotVal     = dot(node.direction, wallNormal)
    IF dotVal < 0:                                 // pointing INTO wall
        node.direction -= wallNormal * dotVal      // project onto wall plane
        node.direction  = normalizesafe(node.direction, wallNormal)

## SECTION 6 - JOB ARCHITECTURE & SCHEDULING

### 6.1 SlowTick Flow Update Job (5Hz max)

JOB: FlowFieldUpdateJob [IJobParallelFor]
    INPUT : MetaBuffer[0], WeatherStateBitmask, HeatSources[8], WallSDF
    OUTPUT: FlowField_Surface, FlowField_Mid, FlowField_Abyssal
    BATCH : innerLoopBatchCount = 64

    PER NODE EXECUTION ORDER:
        1. Compute layer depth_multiplier
        2. Apply globalBaseVector * globalScale * depth_multiplier -> direction, velocity
        3. FOR each HeatSource: compute vertical_velocity + vortex contribution
        4. Apply turbulence noise (Section 4.1)
        5. Apply wall attenuation (Section 5.1)
        6. Apply wall direction correction (Section 5.2)
        7. CLAMP velocity to [0..20]
        8. normalizesafe(direction)
        9. Write FlowNode

// Use double-buffering. 60Hz job reads FrontBuffer unblocked. 5Hz job writes BackBuffer.
// Fence: Complete before any entity sampling - use explicit JobHandle dependency chain

### 6.2 Entity Sampling Job (Per-Frame, ~60Hz)

JOB: EntityFlowSampleJob [IJobParallelFor]
    INPUT : FlowField arrays (ReadOnly), EntityPositions, PlayerPos
    OUTPUT: EntityFlowSamples NativeArray<float3>

    PER ENTITY:
        1. distSqToPlayer = lengthsq(entityPos - playerPos)
        IF distSqToPlayer > 22500:   // 150^2, no sqrt
            EntityFlowSamples[i] = float3.zero
            CONTINUE

        2. Determine layer from entityPos.y
        3. worldToGrid(entityPos) -> gridCoord (float3, fractional)
        4. Trilinear interpolation across 8 surrounding FlowNodes
        5. Write interpolated float3 (velocity * direction) to EntityFlowSamples[i]

// Trilinear: standard 8-corner lerp - do NOT use bilinear (2D only)
// Use pre-computed reciprocal cell_size to avoid division: cell_size_inv = 1.0/cell_size

### 6.3 Trilinear Interpolation Kernel

GIVEN fractional grid coord (fx, fy, fz) in [0..1] per axis:
    c000 = node(x0,y0,z0).direction * node.velocity
    c001 = node(x0,y0,z1) ...
    [all 8 corners]

    // Interpolate X axis:
    c00 = lerp(c000, c100, fx)
    c01 = lerp(c001, c101, fx)
    c10 = lerp(c010, c110, fx)
    c11 = lerp(c011, c111, fx)

    // Interpolate Y axis:
    c0  = lerp(c00, c10, fy)
    c1  = lerp(c01, c11, fy)

    // Interpolate Z axis:
    result = lerp(c0, c1, fz)

// result = world-space flow vector at entity position

### 6.4 Cross-Layer Boundary Sampling

// Entity at layer boundary: blend contribution from both layers
// Blend zone: 10m overlap at each boundary

IF entity_Y in [-60..-50]:   // Surface/Mid boundary
    t = (entity_Y + 60) / 10.0     // [0..1]
    result = lerp(Sample_Mid(pos), Sample_Surface(pos), t)

IF entity_Y in [-310..-300]: // Mid/Abyssal boundary
    t = (entity_Y + 310) / 10.0
    result = lerp(Sample_Abyssal(pos), Sample_Mid(pos), t)

## SECTION 8 - SAFETY & GUARD CONDITIONS

### 8.1 Velocity Cap

GLOBAL HARD CAP: node.velocity = min(node.velocity, 20.0)

### 8.2 Zero-Divide Guards

MANDATORY epsilon list - all distance-based denominators:
    HeatSource dist:          dist = max(dist, 0.01)
    Wall attenuation SDF:     wallDist = max(wallDist, 0.001)
    normalizesafe:            use Unity.Mathematics.normalizesafe - built-in epsilon
    Interpolation coords:     cell_size guaranteed > 0 at init - assert once, not per-frame
    Noise input:              no divide - snoise safe at all float3 inputs

### 8.3 NaN Propagation Guard

// After full node computation, before write:
IF any(isnan(node.direction)):  node.direction = float3(0,0,1)
IF isnan(node.velocity):        node.velocity  = 0.0
IF isnan(node.turbulence):      node.turbulence = 0.0

// math.isnan() is Burst-compatible - zero overhead in compiled form
// Alternative: use math.select with nan-check for branchless version:
    node.velocity = math.select(node.velocity, 0.0, math.isnan(node.velocity))

### 8.4 Job Dependency Fence

// FORBIDDEN: sampling EntityFlowSampleJob before FlowFieldUpdateJob.IsCompleted
// ENFORCE: store FlowUpdateHandle, pass as dependency to EntitySampleJob.Schedule
// On SlowTick miss (frame spike): use PREVIOUS frame FlowField - stale by 200ms max, acceptable

## SECTION 12 - COORDINATE CONVENTIONS

worldToGrid(worldPos, layer):
    localPos   = worldPos - layer.origin
    gridCoordF = localPos * layer.cell_size_inv    // multiply by reciprocal, no divide
    gridCoordI = int3(floor(gridCoordF))
    frac       = frac(gridCoordF)                  // fractional for trilinear
    gridCoordI = clamp(gridCoordI, 0, layer.dims - 1)
    // [FORBID] Lazy coordinate clamping. Clamp integers BEFORE 1D index flattening:
    int x1 = math.min((int)px + 1, layer.dims.x - 1);
    index      = gridCoordI.x + gridCoordI.y * layer.dims.x + gridCoordI.z * layer.dims.x * layer.dims.y
    RETURN (index, frac)

// Y-axis: world up. Depth increases as Y decreases (negative).
// All depth comparisons: use world Y directly - no coordinate flip.
// Grid origin per layer: defined at layer's shallowest corner, world-space.
