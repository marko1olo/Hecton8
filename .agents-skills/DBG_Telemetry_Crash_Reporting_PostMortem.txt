## §1 — CRASH TELEMETRY BUFFER [DATA]

### 1.1 Ring Buffer Architecture

Persistent `NativeArray<DebugLogEntry>` — capacity: 300 frames
Allocator: `Persistent` | Layout: `Sequential` | Access: `ReadWrite`

DebugLogEntry {
    uint  frameIndex        // 4B
    uint  systemMask        // 4B — which systems active this frame
    float deltaTime         // 4B
    float fixedDeltaTime    // 4B
    float gpuFrameTime      // 4B — FrameTimingManager sample
    float memoryUsedMB      // 4B
    float3 playerPos        // 12B
    uint  activeChunkCount  // 4B
    uint  boidAgentCount    // 4B
    uint  errorFlags        // 4B — NaN / physics violation / OOB flags
    uint  pad0              // 4B — align to 64B cache line
}
// Total: 64B per entry × 300 = 19.2KB — negligible

Write pattern (lockless, wrapping):

writeIndex = (frameCount % BUFFER_CAPACITY)  // no modulo branch needed
buffer[writeIndex] = BuildEntry(currentFrame)

Never allocate inside this path. Entry struct must be `blittable`.
`NativeArray` initialized in `Awake`, disposed in `OnApplicationQuit` with null-check.

### 1.2 Binary Export on Crash / Demand

Trigger conditions:
- `errorFlags != 0` on any entry
- Explicit hotkey: `Ctrl+Shift+D` (editor) / dev-build console command `dump_telemetry`
- `Application.logMessageReceived` catches `LogType.Exception` or `LogType.Error`

Export algorithm:

1. Determine export range: last min(writeIndex, 50) entries from ring
2. Open FileStream at: Application.persistentDataPath/crash_YYYYMMDD_HHMMSS.hbin
3. Write 8B magic header: 0x48454354_4F4E3800  ("HECTON8\0")
4. Write uint32 entryCount
5. Write uint32 structSizeBytes (64)
6. Unsafe.CopyBlock from NativeArray slice → byte* → FileStream
7. Flush + Close
8. Write companion .json manifest: timestamp, buildGUID, platform, systemFlags legend

Never use `JsonUtility` for binary section — raw `BinaryWriter` or `UnsafeUtility.MemCpy`.
Export runs on background thread via `Task.Run`. UI thread posts notification only.

### 1.3 State Snapshot: NaN / Error Recovery Flow

FLOW: ErrorDetected

├ [1] NaN Sweep (per FixedUpdate, Physics systems only)
       foreach component in tracked list:
           if IsNaN(pos.x | pos.y | pos.z | vel.magnitude):
               errorFlags |= ERR_NAN_PHYSICS
               Snap pos → lastValidPos[entityID]
               Zero velocity

├ [2] Buffer 50 Preceding States
       readCursor = (writeIndex - 50 + BUFFER_CAPACITY) % BUFFER_CAPACITY
       copy 50 entries to safetySnapshot NativeArray (pre-allocated, separate)

├ [3] Export Binary Log (§1.2)

 [4] Safe Recovery
        Invoke RecoveryState:
            Re-teleport entity to lastValidPos
            Broadcast SystemEvent.PHYSICS_RECOVERED
            Increment recoveryCounter (cap: 3 per session → escalate to scene reload)

NaN check math (SIMD-friendly):

nanMask = (x != x) | (y != y) | (z != z)
// IEEE 754: NaN is only float where self-comparison fails

## §3 — ZERO-GC GIZMO SYSTEM [RULE]

### 3.1 Pre-Allocated Geometry Pool

Forbidden: `new Mesh()` per frame. Forbidden: `Handles.DrawLine` loops without batching.

Pool architecture:

GizmoGeometryPool {
    Mesh[]       sphereLODs[3]      // r=0.1, 0.5, 2.0 — pre-built icospheres
    Mesh         wireCube
    Mesh         arrowMesh
    Mesh         frustumMesh
    ComputeBuffer instanceBuffer    // capacity: 1024 instances per type
    MaterialPropertyBlock mpb       // reused, never reallocated
    Matrix4x4[]  matrixScratch      // pre-alloc 1024 — reused per Draw call
}

Icosphere pre-generation (editor-time, baked to asset):

// Subdivision count s drives vertex count: V = 10·4^s + 2
// Use s=1 for debug spheres: 42 verts — negligible GPU cost

### 3.2 Instanced Gizmo Dispatch

Gizmo requests accumulate into `NativeList<GizmoRequest>` during frame.
Flush in `OnDrawGizmos` or custom debug camera CommandBuffer pass.

GizmoRequest {
    float4x4 matrix
    float4   color
    uint     meshType    // 0=sphere, 1=cube, 2=arrow, 3=frustum
    uint     lod         // 0=high, 1=mid, 2=low
}

Dispatch:

1. Group requests by (meshType, lod) — radix sort on uint key = (meshType<<2)|lod
2. Per group: extract Matrix4x4[] slice from matrixScratch
3. Graphics.DrawMeshInstanced(mesh, 0, material, matrices, count, mpb)
4. Clear NativeList (no dealloc — just set Length=0)

Silhouette markers (replaces `Instantiate` for debug objects):

// Debug entity marker = DrawMeshInstanced with depthWrite=OFF, wireframe material
// No GameObjects created. GPU instance cost only.

### 3.3 Camera-Distance LOD Scaling

Gizmo LOD selection:

dist = Vector3.Distance(sceneCamera.pos, gizmoWorldPos)

lod = dist < 10f  ? 0    // full icosphere
    : dist < 50f  ? 1    // medium
    :               2    // billboard quad — 4 verts only

scale = Mathf.Clamp(dist * 0.05f, 0.1f, 5.0f)
// Gizmo scales with distance — stays visible without occluding scene

Apply in matrix construction:

TRS(worldPos, rotation, Vector3.one * scale)

Frustum cull before adding to NativeList:

if GeometryUtility.TestPlanesAABB(frustumPlanes, gizmoBounds):
    Add to list
// frustumPlanes pre-extracted once per frame — Plane[6] stack alloc

## §4 — OVERDRAW HEATMAP [SCALE]

### 4.1 MX350 Fillrate Analysis Mode

MX350 peak fillrate: ~12 GB/s. Underwater post-processing is fillrate-dominant.
Overdraw mode exposes hotspots at runtime (dev build only).

Activation:

DebugFlags |= (1u << 7)  // HECTON_DEBUG_OVERDRAW bit

Implementation via replacement shader pass:

Shader "H8/Debug/Overdraw":
    Blend: One One (additive accumulation)
    ZWrite: Off
    ZTest: Always
    Color output: fixed4(0.05, 0.0, 0.0, 0.0)
    // Each overdraw layer adds +0.05 red
    // 1 layer = near-black, 20 layers = saturated red

Heat LUT remap (applied in blit pass):

t = saturate(accumulatedRed / MAX_OVERDRAW)  // MAX_OVERDRAW = 20
// Remap through heat gradient:
color = lerp(lerp(BLUE, GREEN, t*2), lerp(GREEN, RED, t*2-1), step(0.5, t))

Dispatch:

1. Camera.RenderWithShader(overdrawShader, "")  // replace all geometry
2. Blit result with heat LUT pass
3. Composite label overlay: "OVERDRAW | MX350 FILLRATE ANALYSIS"

Budget reference lines:

// Overlay horizontal bands showing overdraw budget thresholds:
// Green zone:  <4x  — acceptable
// Yellow zone: 4-8x — optimize
// Red zone:    >8x  — critical (MX350 fillrate cliff)

### 4.2 Fillrate Budget Math

MX350 fillrate at 1080p:

pixels_per_frame = 1920 × 1080 = 2,073,600
fillrate_budget_overdraw = GPU_FILLRATE_GB / (bpp × res_in_Gpx)
                         = 12e9 / (4 × 2.07e6) ≈ 1,449 overdraw passes/frame
// Realistic usable: ~8-12x accounting for bandwidth contention

Flag scenes exceeding 8x average overdraw for optimization pass.

## §5 — RUNTIME CONSOLE [SAFE]

### 5.1 Circular Status Buffer (Tick-Safe)

Forbidden: `Debug.Log` in `Update` / `FixedUpdate`. Status emitted to circular buffer only.

StatusBuffer {
    string[64] lines        // fixed ring — pre-allocated strings
    int        writeHead    // wraps with % 64
    float[]    timestamps   // parallel array
}

// Write (zero GC):
lines[writeHead] = ScratchFormat(formatString, args)  // stackalloc sprintf equivalent
timestamps[writeHead] = Time.unscaledTime
writeHead = (writeHead + 1) % 64

`ScratchFormat`: uses `Span<char>` + `MemoryMarshal` — never allocates.
Pre-bake format strings as `ReadOnlySpan<char>` literals.

### 5.2 Low-Overhead Text Overlay

Render path: `CommandBuffer` injected at `CameraEvent.AfterEverything`.
No Unity UI canvas. No LayoutGroup. No ContentSizeFitter.

Overlay render:
1. Blit background quad: 320×480px, bottom-left, alpha=0.6, one draw call
2. Font atlas: pre-baked monospace bitmap atlas (256×256, 1 texture bind)
3. Per visible line: pack glyph UVs into mesh vertex stream
   — Pre-allocated Mesh: 64 lines × 80 chars × 4 verts = 20,480 verts max
   — Update only dirty lines via SetVertices on NativeArray slice
4. DrawMesh: 1 draw call for all text
5. Composite over scene in CommandBuffer

Dirty-flag optimization:

lineDirty[i] = (newContent[i] != displayedContent[i])
// Only rebuild glyph geometry for changed lines
// Unchanged lines: zero CPU cost

### 5.3 Console Command Parser

Zero-allocation command dispatch:

Input: ReadOnlySpan<char> from input field (no string alloc)
Parse: SpanSplit on ' ' → commandToken + argTokens
Dispatch: CommandRegistry Dictionary<ReadOnlySpan<char>, Action<ReadOnlySpan<char>[]>>
// Use StringComparer.Ordinal for span keying

Built-in command registry:

"dump_telemetry"    → trigger §1.2 binary export
"toggle_overdraw"   → flip HECTON_DEBUG_OVERDRAW bit
"set_flags [hex]"   → set DebugFlags = ParseHex(arg)
"budget_report"     → flush ProfilerRecorder samples to overlay
"clear_log"         → reset StatusBuffer writeHead = 0
"recovery_status"   → print recoveryCounter + lastRecoveryReason
"voxel_stats"       → print chunk count, dirty queue depth, VRAM usage
"boid_stats"        → print agent count, spatial hash bucket fill rate
"mem_snapshot"      → GC.GetTotalMemory(false) + NativeMemory audit
"scene_reload"      → SceneManager.LoadScene(current, Single) after export

## §6 — LOG PROTECTION & DISK SAFETY [SAFE]

### 6.1 Hard Caps

MAX_BINARY_EXPORTS_PER_SESSION = 10
MAX_EXPORT_FILE_SIZE_MB        = 5
MAX_TOTAL_LOG_DIR_SIZE_MB      = 50
LOG_RETENTION_DAYS             = 7

Pre-session cleanup:

1. Enumerate Application.persistentDataPath/*.hbin
2. Delete files older than LOG_RETENTION_DAYS
3. If totalDirSizeMB > MAX_TOTAL_LOG_DIR_SIZE_MB:
       Delete oldest files (sort by LastWriteTime ascending) until under limit
4. exportCountThisSession = 0

Export gate:

if exportCountThisSession >= MAX_BINARY_EXPORTS_PER_SESSION:
    StatusBuffer.Write("EXPORT BLOCKED: session cap reached")
    return
if FileInfo(targetPath).Length > MAX_EXPORT_FILE_SIZE_MB * 1024 * 1024:
    StatusBuffer.Write("EXPORT BLOCKED: file size cap")
    return
exportCountThisSession++

### 6.2 Application.logMessageReceived Handler

Registered once in debug subsystem init. Captured on any thread.

Handler(string condition, string stackTrace, LogType type):
    if type == Exception || type == Error:
        entry = BuildErrorEntry(condition, stackTrace)
        errorQueue.Enqueue(entry)  // ConcurrentQueue — thread-safe
        // Main thread drains queue in LateUpdate → writes to telemetry + triggers export

Stack trace compression for binary log:

// Don't store raw string — store CRC32 of stackTrace + first 256 chars
// Full trace preserved in companion .txt sidecar file
// Binary log stays compact

## §7 — WATCHDOG BITFIELD REFERENCE

Complete `uint DebugFlags` bit allocation:

Bit  0  : PHYSICS        — NaN sweep, rigidbody state, joint stress
Bit  1  : VOXEL          — chunk rebuild times, dirty queue, mesh stats
Bit  2  : BOIDS          — agent count, spatial hash, separation force vectors
Bit  3  : AUDIO          — occlusion rays, hydrophone radius, reverb zones
Bit  4  : PRESSURE       — fluid sim convergence, pressure field visualization
Bit  5  : STREAMING      — chunk load/unload events, VRAM budget, streaming queue
Bit  6  : AI             — creature state machines, path nodes, perception cones
Bit  7  : OVERDRAW       — fillrate heatmap mode (§4)
Bit  8  : SHADOWS        — cascade splits, shadow caster count per cascade
Bit  9  : LIGHTING       — probe interpolation, light budget, emissive contributors
Bit 10  : MEMORY         — NativeArray audit, GC alloc tracking, texture memory
Bit 11  : NETWORK        — reserved for future co-op / telemetry transmission
Bit 12  : ANIMATION      — state machine transitions, IK solve cost, blend tree weights
Bit 13  : PARTICLES      — particle budget, GPU particle count, simulation cost
Bit 14  : POSTPROCESS    — underwater distortion cost, depth-of-field sample count
Bit 15  : MASTER_VERBOSE — enable all bits 0-14 simultaneously

Set/clear/query macros (logic only):

SET(flags, bit)    = flags |=  (1u << bit)
CLEAR(flags, bit)  = flags &= ~(1u << bit)
TOGGLE(flags, bit) = flags ^=  (1u << bit)
QUERY(flags, bit)  = (flags >> bit) & 1u

MASTER_VERBOSE shortcut:

if QUERY(DebugFlags, 15):
    DebugFlags |= 0x00007FFF  // set bits 0-14

## §8 — INTEGRATION CHECKLIST

Subsystem initialization order (critical — wrong order causes null-ref on early errors):

[1] Allocate NativeArray<DebugLogEntry> (Persistent)          // §1.1
[2] Allocate safetySnapshot NativeArray<DebugLogEntry> ×50   // §1.3
[3] Init GizmoGeometryPool — pre-build meshes                 // §3.1
[4] Allocate StatusBuffer string[64] + float[64]             // §5.1
[5] Pre-allocate Overlay Mesh (20,480 verts)                 // §5.2
[6] Register Application.logMessageReceived                   // §6.2
[7] Init ProfilerRecorder set (one per PM_* marker)          // §2.2
[8] Run pre-session log cleanup                               // §6.1
[9] Parse DebugFlags from PlayerPrefs or command-line args    // §7
[10] Write init entry to StatusBuffer: "DEBUG SUBSYSTEM READY | flags=0x{DebugFlags:X8}"

Shutdown order (reverse dependency):

[1] Trigger final binary export if errorFlags != 0
[2] Dispose all ProfilerRecorders
[3] Dispose GizmoGeometryPool ComputeBuffer
[4] Dispose safetySnapshot NativeArray
[5] Dispose main telemetry NativeArray
[6] Unregister Application.logMessageReceived
[7] Release Overlay Mesh

## §9 — PERFORMANCE ENVELOPE (MX350 / i3 BASELINE)

Debug subsystem overhead budget — must never exceed:

CPU overhead per frame (debug active):     < 0.3ms
CPU overhead per frame (debug inactive):   < 0.02ms  (compile-guard eliminates most paths)
GPU overhead per frame (debug active):     < 0.5ms
Memory footprint (all debug allocations):  < 4MB
Disk write latency (async export):         non-blocking — background thread only

Profiler self-measurement:

PM_GizmoFlush targets:     < 0.1ms
PM_TelemetryWrite targets: < 0.05ms
Overlay glyph rebuild:     < 0.1ms for 64 lines

If any debug subsystem cost exceeds 10% of frame budget → auto-disable that subsystem:

if debugSubsystemCostMs > (targetFrameMs * 0.10f):
    CLEAR(DebugFlags, offendingBit)
    StatusBuffer.Write("AUTO-DISABLED: {system} exceeded 10% frame budget")
