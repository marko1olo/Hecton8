# EQUIPMENT_INTERACTION.md

## 2026-05-11 VISUAL-FAKE / PHYSICS OWNERSHIP OVERRIDE

[RULE] Tool interaction may create gameplay state, decals, pooled VFX, audio, haptics, and structural graph edges. Tool modules do not create Unity Joint gameplay constraints as a production path.
[FORBID] `ConfigurableJoint`, `SpringJoint`, `HingeJoint`, or direct concrete physics ownership from tool modules.
[REQUIRE] Welds, anchors, hooks, and tethers publish deterministic structure/physics requests to the owning system. Presentation-only cable, seam, heat shimmer, slag, and recoil default to pooled visual/audio/haptic fakes.

## Section0 - CONTRACTS & IDENTITY

[CONTRACT] Every tool type satisfies dual interface binding: `IInteractable  AND  IToolModule`.
[CONTRACT] `IInteractable` exposes: `Interact(InteractionPacket p)`, `CanInteract(uint toolID) -> bool`, `QueryState() -> byte`.
[CONTRACT] `IToolModule` exposes: `Activate()`, `Deactivate()`, `CancelAction()`, `GetCapabilityMask() -> uint`.
[ENFORCE] No concrete tool class cross-references another concrete tool class. Coupling channel = `EventBus` only.
[ENFORCE] `ToolRegistry` is static, read-only after scene init. Population window = Awake phase only. O(1) via `NativeHashMap<uint, ToolCapabilityRecord>`.

## Section1 - DATA STRUCTURES

### 1.1 InteractionPacket

struct InteractionPacket {
  uint   ToolID;          // registry lookup key
  float3 Origin;          // AbsoluteAUPition (double-precision origin-shifted)
  float3 Direction;       // unit vector, pre-normalized caller-side
  float  Power;           // [0.0 - 1.0] normalized energy level
  float  Range;           // meters, world-space
  byte   Mode;            // 0=Primary, 1=Secondary, 2=Alt
  byte   ToolStateFlags;  // current state bitmask snapshot at dispatch time
  uint   FrameIndex;      // engine frame stamp for dedup/ordering
}

### 1.2 Tool State Bitmask

Bit 0 -> Idle        (0x01)
Bit 1 -> Active      (0x02)
Bit 2 -> Busy        (0x04)
Bit 3 -> Overheated  (0x08)
Bit 4 -> LowPower    (0x10)
Bit 5 -> TargetLock  (0x20)
Bit 6 -> Cooldown    (0x40)
Bit 7 -> RESERVED

[RULE] State transitions via bitwise OR/AND-NOT only. No enum cast. No string state.

Activate:   flags |= 0x02; flags &= ~0x01
Deactivate: flags |= 0x01; flags &= ~0x02
Overheat:   flags |= 0x08; flags &= ~0x02; flags &= ~0x04
Lock:       flags |= 0x20
CancelAll:  flags  = 0x01  // hard-reset to Idle, clears all

### 1.3 InteractionSignal (EventBus Payload)

struct InteractionSignal {
  InteractionPacket Source;
  uint     TargetInstanceID;
  float3   HitPoint;          // world-space, origin-shifted
  float3   HitNormal;
  float    PowerDelivered;    // post-attenuation
  byte     EffectType;        // 0=Drill, 1=Harpoon, 2=Weld, 3=PlasmaCut, 4=Torch
  bool     PenetrationOccurred;
}

### 1.4 ToolCapabilityRecord

struct ToolCapabilityRecord {
  uint  ToolID;
  float MaxRange;
  float BasePower;
  float HeatGenerationRate;
  float CooldownRate;
  uint  CompatibleTargetMask;   // bitfield matching TargetLayer flags
  byte  PenetrationTier;        // 0=surface, 1=thin, 2=medium, 3=deep
}

### 1.5 Pre-Allocated Query Buffers
[FORBID] `new RaycastHit[]` per frame. Allocate once at scene init:

RaycastHit[8]      _rayBuffer       // standard raycast results
SpatialQueryHit[16] _spatialBuffer  // overlap/sphere query results
NativeArray<RaycastCommand> _batchCmds(capacity=8, Persistent)
NativeArray<RaycastHit>     _batchResults(capacity=8, Persistent)

Ownership: single `ToolRaycastScheduler` MonoBehaviour. Tools request slots, never allocate.

## Section2 - RAYCAST ARCHITECTURE

### 2.1 Layered Query Pipeline

STEP 1 -> Screen-Space depth pre-cull (MX350 guard):
          Sample _CameraDepthTexture at projected tool-origin UV.
          If scene_depth < tool_near_plane: skip 3D query, emit OccludedSignal.

STEP 2 -> Broad-phase: OverlapSphere(Origin, Range * 0.5) -> _spatialBuffer[16]
          Filter: CompatibleTargetMask & target.LayerFlag != 0

STEP 3 -> Narrow-phase: BatchRaycast via Unity Jobs:
          Fill _batchCmds[N] from broad-phase survivors (N <= 8)
          Schedule RaycastCommand.ScheduleBatch(_batchCmds, _batchResults, minHits:1)
          Complete() before physics step boundary

STEP 4 -> Sort _batchResults by distance (insertion sort, N<=8, no alloc)

STEP 5 -> Select primary hit [0], secondary hits [1..3] if PenetrationTier >= 1

### 2.2 Origin Shift Safety
[RULE] All ray origins computed as:

float3 safeOrigin = (float3)(worldPosition - FloatingOrigin.CurrentOffset)

`FloatingOrigin.CurrentOffset` = double3, updated every origin-shift event.
[RULE] Subscribe to `FloatingOrigin.OnShift` -> re-project any active tether/logic-link endpoints.
[FORBID] Unity Transform.position as ray origin for any tool with range > 200m.

### 2.3 Hit Validation

IsValidHit(RaycastHit h):
  -> h.distance > 0.05f                      // skip self-intersection
  -> h.distance <= packet.Range               // within effective range
  -> CompatibleTargetMask & LayerMask(h) != 0 // target layer match
  -> dot(h.normal, packet.Direction) < 0     // surface facing tool
  -> return all true

## Section3 - MATH KERNELS

### 3.1 Voxel-Beam Attenuation

power_final = power_init * exp(-voxel_density * travel_distance)

- `voxel_density`: sampled from `VoxelSDF.DensityField[voxelCoord]` (float, [0..1] normalized)
- `travel_distance`: accumulated per voxel traversal step (DDA march, see Section5.2)
- Chain multiple voxels: `power_out = power_in * exp(-d_i * deltaDistance_i)` per step, multiplicative
- Early-exit if `power_final < 0.02f`: beam considered blocked, emit `BlockedSignal`

### 3.2 Tool Recoil Impulse

impulse_vector = packet.Direction * packet.Power * BasePower * (1.0 / max(rigidbody.mass, 0.1))
// [FORBID] Direct player-only recoil inside moving structures.
// If on a platform, apply the inverse impulse to the Submarine Rigidbody to ensure conservation of momentum.
- Scale by `underwater_drag_factor` (0.4 - 0.8 based on water viscosity zone)
- [RULE] Clamp impulse magnitude: `|impulse| <= 12.0` to prevent physics destabilization on MX350-tier simulation

### 3.3 Heat Accumulation & Cooldown

// Per FixedUpdate while Active:
heat += HeatGenerationRate * power * fixedDeltaTime

// Cooldown (Idle or Deactivated):
heat -= CooldownRate * fixedDeltaTime * (1 + passive_water_cooling_bonus)

// Overheat trigger:
if heat >= 1.0:
  flags = Overheat state (Section1.2)
  heat  = 1.0 (clamp)

// Recovery:
if heat <= 0.15 AND (flags & 0x08):
  flags &= ~0x08; flags |= 0x40  // exit Overheat, enter Cooldown
if heat <= 0.0:
  heat = 0.0; flags &= ~0x40     // exit Cooldown

`passive_water_cooling_bonus`  in  [0.0, 1.2]: higher in colder/deeper zones (query `OceanThermalMap`).

### 3.4 Power Draw from Energy System

// Per Active tick:
energy_cost = BasePower * packet.Power * ActiveDrainMultiplier * deltaTime
EnergySystem.Drain(ToolID, energy_cost)

// Low-power detection:
if EnergySystem.GetLevel() < 0.12f:
  flags |= 0x10  // LowPower set
  effective_power = packet.Power * 0.35f  // force-reduce output

if EnergySystem.GetLevel() <= 0.0f:
  CancelAction()

### 3.5 Cable Tether Tension (Harpoon)

// Verlet integration for visual cable proxy:
for each node i in cable[1..N-1]:
  velocity    = node[i].pos - node[i].prev_pos
  node[i].prev_pos = node[i].pos
  node[i].pos += velocity + gravity * dt^2

// Constraint solve (Jakobsen, 4 iterations):
for iter in 0..3:
  for each segment (i, i+1):
    delta     = node[i+1].pos - node[i].pos
    dist      = |delta|
// [FORBID] Naked division in distance constraints. Guard it:
float safe_dist = math.max(dist, 1e-5f);
error = (safe_dist - rest_length) / safe_dist * 0.5f;
    node[i].pos   += delta * error
    node[i+1].pos -= delta * error
// Anchor node[0] to harpoon tip (world), node[N] to target hit-point

## Section4 - TOOL-SPECIFIC FLOW KERNELS

### 4.1 Drill

TICK (FixedUpdate, Active state):
1. RaycastScheduler.RequestSlot() -> fill _batchCmds[0]
2. On hit: compute power_final (Section3.1)
3. Publish InteractionSignal{EffectType=0} to EventBus
4. EventBus->VoxelSystem: ApplyDrillStamp(hitPoint, radius, power_final)
   -> VoxelSDF: subtract density sphere, mark dirty chunks
5. Heat accumulate (Section3.3)
6. Recoil (Section3.2) every N=3 FixedUpdates (reduce physics spam)
7. Spawn spark ParticleSystem from pool at hitPoint (rate proportional_to power_final)

### 4.2 Harpoon

FIRE (one-shot, single FixedUpdate):
1. Instant ray-precheck: Physics.Raycast(_rayBuffer[0], packet.Range, layerMask)
2. If no hit: spawn projectile proxy, arc-simulate (no logic link)
3. If hit AND IsValidHit():
   a. Register LogicLink: HarpoonLinkRecord{OwnerID, TargetID, HitPoint, MaxTension}
   b. flags |= 0x20 (TargetLock) | 0x04 (Busy)
   c. Spawn visual cable proxy (N=12 nodes, Verlet Section3.5)
   d. EventBus->PhysicsSystem: CreateTetherConstraint(ownerRB, targetRB, restLength)

PHYSICS_INTEGRITY CHECK (every 4 FixedUpdates):
  tension = |ownerPos - targetHitPoint| - restLength
  if tension > MaxTension: BreakLink()
  if target destroyed: BreakLink()

BreakLink():
  EventBus->PhysicsSystem: RemoveTetherConstraint(linkID)
  Despawn cable proxy (return to pool)
  flags &= ~0x20; flags &= ~0x04

### 4.3 Welder

ACTIVE (sustained beam):
1. RaycastScheduler: continuous slot request, 1/FixedUpdate
2. Hit required on WeldableLayer mask
3. power_final via Section3.1 attenuation
4. WeldProgress += power_final * fixedDeltaTime
5. At WeldProgress >= WeldThreshold:
   EventBus->StructureSystem: RegisterWeldJoint(hitPoint, hitNormal, toolID)
   StructureSystem: create deterministic structure edge or owned anchor constraint between surfaces
6. Visual: lerp beam width (0.01->0.04m) over first 0.3s via AnimationCurve sample
7. Overheat accumulation rate * 1.4 multiplier (welder runs hot)

### 4.4 Plasma Cutter

ACTIVE (sustained cut):
1. DDA ray-march through VoxelSDF (Section5.2) along packet.Direction
2. Per voxel step:
   a. Sample density: d = VoxelSDF.SampleDensity(voxelCoord)
   b. d_new = d - CutStrength * power_final * marchStepSize
   c. VoxelSDF.WriteDensity(voxelCoord, clamp(d_new, -1, 1))
   d. Mark chunk dirty
3. After march completes: EventBus->VoxelSystem: ScheduleAsyncRebuild(affectedChunks[])
   -> Rebuild runs on worker thread, main thread continues
4. Emit plasma particle burst from pool (capped: 24 particles/frame on MX350 tier)
5. SDF geometry rebuild (Section5.3) triggered async, result uploaded next available frame

### 4.5 Torch (Thermal)

ACTIVE:
1. SphereCast (radius=0.15m) into _rayBuffer -> closest hit
2. power_final = Section3.1 (short range: <=3m, density effect minimal)
3. EventBus->MaterialSystem: ApplyHeatStamp(hitPoint, 0.15, power_final * dt)
   MaterialSystem: update HeatMap texture (R8 channel, GPU-side)
   Shader samples HeatMap -> drives thermal distortion + material state blend
4. If target material = Ice/Frozen: EventBus->VoxelSystem: MeltStamp(hitPoint, meltRate)
5. Particle: bubble stream upward (underwater), smoke horizontal (surface)
   Rate: lerp(4, 28, power_final), throttled by SlowTick frame-time (Section6.2)

## Section5 - SPATIAL MATH SUBSYSTEMS

### 5.1 SDF Query API (used by all tools)

VoxelSDF.SampleDensity(float3 worldPos) -> float
  -> Convert worldPos to voxel coords: vCoord = floor((worldPos  chunkOrigin) / voxelSize)
  -> Trilinear interpolation across 8 neighbors
  -> Returns signed float: negative=inside, positive=outside, 0=surface

VoxelSDF.ApplyStamp(float3 center, float radius, float strength, StampMode mode):
  StampMode: Subtract=drill/cut, Add=weld/deposit, Set=override
  -> Enumerate voxels in AABB(center, radius)
  -> Per voxel: d_new = SmoothUnion/Subtract(d_old, SDFSphere(voxelCenter, center, radius), strength)
  -> SmoothUnion kernel: h = clamp(0.5 + 0.5*(b-a)/k, 0,1); return lerp(b,a,h)  k*h*(1h)
    where k = blend_radius (0.05-0.2m)

### 5.2 DDA Voxel Ray March

// Digital Differential Analyzer - minimal branching, cache-coherent
Input: origin (float3), dir (float3), maxSteps (int)
Init:
  voxel    = floor(origin / voxelSize)
  step     = sign(dir)                          // int3: (-1,0,1) per axis
  tDelta   = abs(voxelSize / dir)               // distance per axis step
//[FORBID] Naked division by ray direction. You MUST guard against zero:
float3 safeDir = math.select(dir, 1e-7f, dir == 0.0f);
tMax = ((voxel + math.max(step,0)) * voxelSize - origin) / safeDir;

March loop (i = 0..maxSteps):
  axis = argmin(tMax)                           // cheapest axis select
  tMax[axis] += tDelta[axis]
  voxel[axis] += step[axis]
  -> Process voxel[voxelCoord] (sample, write, accumulate power)
  -> Early exit if power_final < 0.02f OR voxel out of chunk bounds

### 5.3 Async Voxel Mesh Rebuild

TRIGGER: VoxelSystem.ScheduleAsyncRebuild(NativeList<int3> dirtyChunks)
PIPELINE:
  Frame N:   Job scheduled - MarchingCubes on worker thread (Unity Job System)
             Input:  dirty chunk density NativeArrays (read-only)
             Output: NativeArray<Vector3> verts, NativeArray<int> tris
  Frame N+K: Job.Complete() checked in LateUpdate (non-blocking poll)
             On complete: write positions + indices + normals through MeshDataArray
             Normals computed analytically in Burst via SDF central differences
             Apply via Mesh.ApplyAndDisposeWritableMeshData(..., MeshUpdateFlags.DontValidateIndices)
             Upload to GPU: Mesh.UploadMeshData(markNoLongerReadable: true) // Unless procedurally deforming
PRIORITY: Cut operations = high priority job. Drill = normal. Weld deposit = low.
COALESCE: Accumulate dirty chunks for 3 frames before scheduling - batch merges adjacent chunks.

## Section6 - HARDWARE SCALABILITY

### 6.1 Quality Tier Definitions

TIER_LOW   -> MX350, 2GB VRAM, i3-10gen  (minimum baseline)
TIER_MED   -> GTX1060/RX580, 4GB VRAM
TIER_HIGH  -> RTX2060/RX6600, 6GB VRAM
TIER_ULTRA -> RTX3070+, 8GB+ VRAM

### 6.2 SlowTick Particle Throttle

// Computed in ToolParticleController (1/Update):
frameTime_ms    = Time.deltaTime * 1000f
budget_scalar   = clamp(16.67f / frameTime_ms, 0.1f, 1.0f)  // 60fps = 1.0
emission_rate   = base_emission * budget_scalar

// Per-tier emission caps (particles/frame):
TIER_LOW:   max 24   (sparks), 12 (bubbles), 8  (smoke)
TIER_MED:   max 64   (sparks), 32 (bubbles), 20 (smoke)
TIER_HIGH:  max 128  (sparks), 64 (bubbles), 48 (smoke)
TIER_ULTRA: max 256  (sparks), 96 (bubbles), 72 (smoke)

### 6.3 Beam Visual LOD

// CPU-side spatial pre-cull (execute before ANY beam draw call):
if VoxelSDF.SampleDensity(hitPoint) > 0.0f: skip all beam geometry -> exit

// Beam geometry complexity by tier:
TIER_LOW:   2D billboard sprite beam, no geometry shader
TIER_MED:   Tube mesh, 4-sided, single pass
TIER_HIGH:  Tube mesh, 8-sided + volumetric light contribution
TIER_ULTRA: Volumetric beam (ray-marched), caustic interaction

// Beam interpolation:
visual_origin = lerp(visual_origin, logic_origin, min(lerpSpeed * dt, 1.0))
visual_end    = lerp(visual_end,    logic_end,    min(lerpSpeed * dt, 1.0))
// lerpSpeed = 18.0 (snappy, lag < 55ms at 60fps)

### 6.4 VRAM Budget - Tool Visual Assets

TIER_LOW  -> Particle textures: 256x256 max. Atlas: 512x512. Tool meshes: <=800 tris. No realtime shadows.
TIER_MED  -> Particle textures: 512x512. Atlas: 1024x1024. Tool meshes: <=2400 tris. Shadow casting off by default.
TIER_HIGH -> 1024x1024 particles. Tool PBR textures: 1K. Realtime shadow optional.
TIER_ULTRA-> 2K particles. 2K tool textures. Full shadow + SSR interaction.

### 6.5 Raycast Budget Per Frame

TIER_LOW:   max 4 active batch slots/frame across ALL tools combined
TIER_MED:   max 8
TIER_HIGH:  max 12 (begin async overlap queries)
TIER_ULTRA: max 16 + GPU-side acceleration structure queries

ToolRaycastScheduler enforces slot budget via priority queue:
  Priority: Active(firing) > Busy(tether check) > Idle(proximity scan)
  Overflow: defer to next frame, preserve packet FrameIndex for ordering

## Section7 - EVENTBUS ARCHITECTURE

### 7.1 Bus Contract

EventBus<InteractionSignal>:
  Publish(InteractionSignal s)         -> O(1) enqueue to NativeQueue (Persistent)
  Subscribe(EffectType, handler)       -> handler registered in NativeHashMap<byte, FunctionPointer>
  FlushToSubscribers()                 -> called once per FixedUpdate, drain queue

Subscriber registration window: scene Awake only. No runtime subscribe/unsubscribe.

### 7.2 Signal Routing

EffectType 0 (Drill)     -> VoxelSystem.OnDrillSignal, AudioSystem.OnDrillSignal, VFXSystem.OnDrillSignal
EffectType 1 (Harpoon)   -> PhysicsSystem.OnHarpoonSignal, AudioSystem.OnHarpoonSignal
EffectType 2 (Weld)      -> StructureSystem.OnWeldSignal, MaterialSystem.OnWeldSignal, VFXSystem.OnWeldSignal
EffectType 3 (PlasmaCut) -> VoxelSystem.OnCutSignal, VFXSystem.OnCutSignal, AudioSystem.OnCutSignal
EffectType 4 (Torch)     -> MaterialSystem.OnTorchSignal, VoxelSystem.OnMeltSignal, VFXSystem.OnTorchSignal

### 7.3 Signal Deduplication

// Prevent duplicate signals same frame (tool held, continuous):
last_signal_frame[ToolID] stored in NativeHashMap<uint, uint>
On Publish: if current_frame - last_signal_frame[ToolID] < dedup_window: merge, don't enqueue new
dedup_window: 1 frame for instantaneous tools; 0 for sustained (accumulate all)

## Section8 - FAILURE MODES & SAFETY

### 8.1 CancelAction Protocol

CancelAction():
1. flags = 0x01                        // hard Idle, all bits cleared
2. heat  = clamp(heat, 0, heat)        // preserve heat (doesn't reset on cancel)
3. If TargetLock was set:
   EventBus.Publish(InteractionSignal{PowerDelivered=0, EffectType=cancelCode})
   HarpoonLinkRegistry.Release(ToolID)
4. ToolRaycastScheduler.ReleaseSlot(ToolID)
5. Active particle emitters: Stop(withChildren=true), return to pool next frame
6. LogicLink table: clear all entries keyed to ToolID
7. Tether constraints: EventBus->PhysicsSystem RemoveAll(ownerID=ToolID)

### 8.2 Deadlock Prevention

// Guard against stuck Busy state:
busy_watchdog[ToolID] = Time.fixedTime at Busy entry
Per FixedUpdate check:
  if (flags & 0x04) AND (Time.fixedTime - busy_watchdog > 8.0f):
    LogWarning("ToolID {id} Busy deadlock @ 8s - force CancelAction()")
    CancelAction()

### 8.3 Origin Shift Mid-Interaction

FloatingOrigin.OnShift subscription (all tool instances):
  delta = newOffset - oldOffset                 // double3
  packet.Origin   -= (float3)delta
  If HarpoonLinkRecord active:
    record.HitPoint     -= (float3)delta
    Re-project tether nodes: node[i].pos -= (float3)delta (all N nodes)
  If DDA march in progress (worker thread):
    Abort current march job, reschedule with corrected origin next frame

### 8.4 NaN / Degenerate Input Guards

Pre-dispatch validation:
  packet.Direction = normalize(packet.Direction)
  if isnan(packet.Direction) OR |packet.Direction| < 0.999:
    CancelAction(); return
  packet.Power = clamp(packet.Power, 0.0, 1.0)
  packet.Range = clamp(packet.Range, 0.1, MaxRange)
  voxel_density = clamp(voxel_density, 0.0, 1.0)   // before attenuation formula

### 8.5 Tether Integrity Edge Cases

BreakLink triggers on ANY of:
  -> target Rigidbody.isKinematic toggled true (structure locked)
  -> target GameObject layer changed (state invalidation)
  -> tension > MaxTension (Section4.2)
  -> target destroyed (OnDestroy event subscription)
  -> owning tool CancelAction() called
  -> origin-shift delta > 500m (extreme teleport - full reset)

## Section9 - AUDIO INTEGRATION HOOKS

[DATA] Audio driven by `InteractionSignal` only - no direct tool-to-audio calls.

AudioSystem.OnDrillSignal(s):
  pitch  = lerp(0.85, 1.15, s.PowerDelivered)
  volume = s.PowerDelivered * depthAttenuation   // deeper = more muffled
  Filter: LowpassCutoff = lerp(800, 4000, 1-(depth/maxDepth))

AudioSystem.OnHarpoonSignal(s):
  One-shot fire SFX on Publish
  Loop tension-creak SFX while TargetLock active, pitch proportional_to tension/MaxTension

AudioSystem.OnCutSignal(s):
  Loop plasma-hum, pitch proportional_to mean voxel_density along cut path

// All audio: spatialize at s.HitPoint, not tool origin
// Underwater muffle: apply convolution reverb IR switched by depth zone

## Section10 - LOGIC-VISUAL SPLIT ENFORCEMENT

[RULE] Hit detection = deterministic, frame-exact, mathematical. Runs FixedUpdate.
[RULE] Visual proxy = interpolated, lossy, frame-rate-dependent. Runs Update/LateUpdate.

LOGICAL LAYER (FixedUpdate):
  -> Raycast dispatch, hit resolve, attenuation math, state transitions
  -> EventBus flush, signal routing
  -> VoxelSDF stamp, physics constraint update
  -> Audio signal publish

VISUAL LAYER (LateUpdate, after physics):
  -> Beam origin/end interpolation (Section6.3)
  -> Cable Verlet step (Section3.5) - visual only, no physics write-back
  -> Particle emission rate compute (Section6.2)
  -> Heat shimmer intensity update (sample heat from logic layer, read-only)
  -> Tool mesh transform lerp for recoil animation

CROSS-LAYER DATA CHANNEL:
  NativeArray<ToolVisualState>[MaxTools] - written FixedUpdate, read LateUpdate
  struct ToolVisualState { float3 LogicHitPoint; float PowerLevel; float HeatLevel; bool IsActive; }
  Double-buffer: ping-pong index toggled each FixedUpdate to prevent read-write race
