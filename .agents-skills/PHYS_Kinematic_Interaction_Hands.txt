## II. DATA ARCHITECTURE

### [DATA] Core Grab State Struct (Blittable, 128-byte aligned)

```
GrabState {
    float3   targetPos          // world-space hand anchor this frame
    float3   targetPosPrev      // hand anchor last frame (velocity derive)
    float3   objectPos          // rb.worldCenterOfMass
    float3   objectVel          // rb.velocity snapshot
    float3   linearError        // targetPos - objectPos (cached, reused)
    float3   angularError       // delta rotation as axis-angle (cached)
    quaternion targetRot
    quaternion objectRot
    float    objectMass         // kg, cached at grab-init
    float    virtualHandMass    // derived, see SectionIII.C
    float    separationDist     // magnitude(linearError), updated each tick
    float    grabTimestamp      // Time.fixedTime at grab-init
    uint32   stateFlags         // bitmask (see below)
    uint8    _pad[12]           // align to 128 bytes
}
```

### [DATA] State Flags Bitmask (uint32)

```
BIT 0  : IS_GRABBED
BIT 1  : HEAVY_OBJECT (mass > 50kg, enables virtual hand lag)
BIT 2  : COLLISION_DISCONNECT_ARMED (separation > 0.4m, warning zone)
BIT 3  : GRIP_BROKEN (separation > 0.8m, disconnect triggered)
BIT 4  : FINGER_POSE_DIRTY (object moved, re-solve fingers next job)
BIT 5  : TWO_HAND_GRAB
BIT 6  : UNDERWATER_DRAG_ACTIVE
BIT 7  : PD_SATURATED (force clamp active this tick - telemetry)
BIT 8-15: RESERVED
BIT 16-31: OBJECT_TYPE_ID (lookup for mass/drag table, 16 bits)
```

### [DATA] NativeArray Layout - GrabStateBuffer

```
NativeArray<GrabState>[MAX_HANDS = 2]   // persistent, Allocator.Persistent
NativeArray<RaycastHit>[FINGER_COUNT * MAX_HANDS * 2]  // double-buffered finger cast results
NativeArray<SpherecastCommand>[FINGER_COUNT * MAX_HANDS]  // reused, no realloc

Ring-buffer:  GrabEventQueue - NativeQueue<GrabEvent>(Allocator.TempJob) per physics step
Double-buffer: FingerPoseBuffer[2] - ping-pong index (frame % 2)
              Each buffer = NativeArray<float3>[10] (5 fingers x 2 hands)
```

### [DATA] Spatial Locality Mandate

```
Pack per-hand data contiguous in memory.
GrabState[0] = LeftHand
GrabState[1] = RightHand
Access pattern: sequential. Never index by object. Hand is primary key.
Object Rigidbody ref: stored as int (rigidbody instanceID) -> NativeHashMap<int, RigidbodyAccessor>

## III. ALGORITHMIC & MATH TRUTH

### [MATH] A. PD Controller - Linear Force (dt-invariant, critically damped)

**Goal:** Move object from `currentPos` -> `targetPos` in minimum time without overshoot.

**Critical Damping Condition:**
```
_n = natural frequency (tuning param, rad/s). Tuning range: 12.0-20.0 for hand objects.
zeta   = damping ratio = 1.0 (critical). Never zeta < 0.8 (underdamped = oscillation).

Kp  = _n^2                          // proportional gain
Kd  = 2 * zeta * omega_n                   // derivative gain
```

**Per-FixedUpdate Force Solve:**
```
1. posError   = targetPos - objectPos
2. velError   = targetVel - objectVel
             where targetVel = (targetPos - targetPosPrev) / fixedDeltaTime
3. accel      = (Kp * posError) + (Kd * velError)
4. deltaVel   = accel * fixedDeltaTime
5. CLAMP:     magnitude(deltaVel) <= MAX_DELTA_VEL (e.g., 15.0 m/s per tick)
6. Apply:     publish velocity-change packet to PhysicsApplySystem
```

**Numerical Stability Guards:**
```
if magnitude(posError) < 1e-4f  -> skip force application (epsilon threshold)
if isNaN(accel) || isInf(accel) -> zero accel, set BIT 7 (PD_SATURATED), log telemetry
MAX_DELTA_VEL clamp prevents Torque Kraken initiation on fast hand sweeps
```

**dt-invariance proof:**
```
accel is in m/s^2. Multiply by fixedDeltaTime -> m/s (VelocityChange).
System responds identically at 50Hz or 120Hz physics rate.
Kp/Kd are frequency-domain params, not frame-count params. Invariant by construction.
```

### [MATH] B. PD Controller - Angular Torque (dt-invariant, critically damped)

**Delta Rotation Extraction (shortest path, NaN-safe):**
```
quaternion deltaRot = math.mul(targetRot, math.inverse(objectRot));
// Burst-compatible math intrinsics
float angle = math.angle(deltaRot);
float3 axis = math.axis(deltaRot);
3. GUARD:      if magnitude(axis) < 1e-6f -> axis = float3.up, angle = 0
4. GUARD:      if abs(angle) < 1e-4f -> skip torque
5. WRAP:       if angle >  -> angle -= 2   (always take shortest arc)
6. axisAngle   = axis * angle               (angular position error, radians)
```

**Torque Solve (same PD structure as linear):**
```
_n_angular = 10.0-16.0 rad/s (tune per object moment of inertia)
Kp_a = _n_angular^2
Kd_a = 2 * 1.0 * omega_n_angular

angularVelError = targetAngularVel - rb.angularVelocity
                  where targetAngularVel = (axisAngle_current - axisAngle_prev) / fixedDeltaTime

angularAccel  = (Kp_a * axisAngle) + (Kd_a * angularVelError)
deltaAngVel   = angularAccel * fixedDeltaTime
CLAMP:        magnitude(deltaAngVel) <= MAX_DELTA_ANGVEL (e.g., 25 rad/s per tick)
Apply:        publish angular velocity-change packet to PhysicsApplySystem
```

**Inertia Tensor Compensation (AAA pattern):**
```
// Scale torque input by inertia tensor to normalize response across object shapes
inertiaTensorWorld = rotation * inertiaTensorLocal (precomputed at grab-init, cached)
correctedAngVel    = inertiaTensorWorld * deltaAngVel  // element-wise, not matrix multiply
Apply correctedAngVel instead of raw deltaAngVel
```

### [MATH] C. Virtual Hand Mass - Heavy Object Lag (mass > 50kg)

**Concept:** Hand anchor position lags behind controller input. Controller drives "virtual hand target"; virtual hand has simulated inertia.

**Virtual Hand Mass Derivation:**
```
massRatio         = objectMass / HAND_MAX_CARRY_MASS     // HAND_MAX_CARRY_MASS = 50.0 kg
massRatio         = clamp(massRatio, 0.0, 1.0)
virtualHandMass   = lerp(0.0, VIRTUAL_HAND_MAX_MASS, massRatio)
                    // VIRTUAL_HAND_MAX_MASS = 8.0 kg (tune: affects lag feel)
```

**Virtual Hand Position Integration (symplectic Euler, stable for stiff springs):**
```
State:  virtualHandPos, virtualHandVel

Each FixedUpdate:
1. springForce    = (controllerPos - virtualHandPos) * VIRTUAL_SPRING_K
                    // VIRTUAL_SPRING_K = 300 N/m (tune)
2. dampForce      = -virtualHandVel * VIRTUAL_DAMPER_C
                    // VIRTUAL_DAMPER_C = 2 * sqrt(virtualHandMass * VIRTUAL_SPRING_K) * 0.9
                    // (90% critical damping - slight lag feel intentional)
3. netAccel       = (springForce + dampForce) / virtualHandMass
4. virtualHandVel += netAccel * fixedDeltaTime           // velocity update first (symplectic)
5. virtualHandPos += virtualHandVel * fixedDeltaTime     // then position

6. targetPos for PD controller = virtualHandPos (NOT controllerPos)
```

**Lag Magnitude Clamp:**
```
maxLag = 0.4m   // virtual hand never falls more than 0.4m behind controller
virtualHandPos = controllerPos + clamp(virtualHandPos - controllerPos, -maxLag, maxLag)
Apply clamp per-axis independently (allows asymmetric resistance).
```

### [MATH] D. Collision Disconnect - Anti-Torque-Kraken

**Separation Monitor (every FixedUpdate):**
```
1. separation = magnitude(objectPos - virtualHandPos)
2. if separation > 0.4m -> set BIT 2 (COLLISION_DISCONNECT_ARMED)
3. if separation > 0.8m -> EXECUTE DISCONNECT
```

**Disconnect Sequence (zero-alloc, deterministic):**
```
1. SET BIT 3 (GRIP_BROKEN)
2. CLEAR BIT 0 (IS_GRABBED)
3. rb.velocity    = clamp(rb.velocity, -8.0, 8.0) per axis    // de-energize
4. rb.angularVelocity = float3.zero                           // kill spin
5. virtualHandPos = objectPos                                  // reset virtual hand
6. virtualHandVel = float3.zero
7. Enqueue GrabEvent{type=GRIP_BROKEN, objectID, timestamp} to GrabEventQueue
8. Dispatch IGrabBreakListener.OnGripBroken(objectID) via cached interface ptr (no alloc)
9. Finger pose: mark BIT 4 dirty -> open-hand pose next frame
```

**Progressive Force Reduction (pre-disconnect, 0.4-0.8m zone):**
```
// Reduce PD gains linearly in warning zone - prevents violent snapping
zoneFraction = (separation - 0.4f) / 0.4f       // 0 at 0.4m -> 1 at 0.8m
gainMultiplier = lerp(1.0f, 0.0f, zoneFraction)
Kp_effective  = Kp * gainMultiplier
Kd_effective  = Kd * gainMultiplier
// Object feels like it's "slipping" - intentional UX signal before full break
```

### [MATH] E. Underwater Drag Compensation for PD Controller

**Problem:** Unity's Rigidbody.drag fights PD controller -> oscillation or sluggishness.

**Solution:** Zero rb.drag/rb.angularDrag during grab. Simulate fluid drag manually.

```
// Per FixedUpdate, AFTER PD packet publication:
fluidDensity   = lerp(SEA_DENSITY_SURFACE, SEA_DENSITY_DEEP, depthFraction)
                 // SEA_DENSITY_SURFACE = 1025 kg/m^3, DEEP = 1065 kg/m^3
dragForce      = -0.5 * fluidDensity * DRAG_COEFFICIENT * frontalArea * velocity^2 * normalize(velocity)
                 // frontalArea: precomputed at grab-init from object bounds
                 // DRAG_COEFFICIENT: 0.47 (sphere approx), overridable per object
publish drag packet to PhysicsApplySystem with owned acceleration/force semantics

// Apply drag to angular velocity:
angularDrag    = -rb.angularVelocity * ANGULAR_DRAG_COEFF * fluidDensity * 0.001f
publish angular velocity-change packet to PhysicsApplySystem
```

## IV. FINGER POSE - BURST SPHERECAST BATCH SYSTEM

### [DATA] Finger Pose Struct

```
FingerPoseData {
    float3 tipPos           // world-space result
    float3 tipNormal        // surface normal at contact
    float  bendAngle        // 0=straight, 1=fully curled
    uint8  fingerIndex      // 0-4
    uint8  contactFlags     // BIT0=surface_hit, BIT1=at_max_curl
    uint8  _pad[2]
}
// NativeArray<FingerPoseData>[10] per double-buffer slot
```

### [MATH] Finger Pose Solve - SpherecastCommand Batch

**Finger ray origin derivation:**
```
For each finger i (0-4):
  knuckleOffset[i] = precomputed local offsets on hand mesh (5 float3 values, const)
  rayOrigin[i]     = handAnchorPos + rotate(knuckleOffset[i], handAnchorRot)
  rayDir[i]        = rotate(fingerRestDir[i], handAnchorRot)
                     // fingerRestDir: default pointing direction per finger in hand-local space
  castRadius       = 0.012f   // ~fingertip radius
  castLength       = 0.09f    // max finger reach before full curl
```

**Job Pipeline (Burst-compiled):**
```
Step 1 - PREPARE (Main Thread, zero-alloc):
  WriteFingerCommandsJob {
    Input:  NativeArray<float3> knuckleWorldPos (derived from hand transform, IJobFor)
    Output: NativeArray<SpherecastCommand> commands
new SpherecastCommand(origin, radius, dir, new QueryParameters(layerMask, false, QueryTriggerInteraction.Ignore, false), length)
  }
  handle1 = WriteFingerCommandsJob.Schedule(FINGER_COUNT, 1)

Step 2 - CAST (Physics Thread):
  handle2 = SpherecastCommand.ScheduleBatch(commands, results, 1, handle1)

Step 3 - CONSUME (Burst IJobFor):
  ProcessFingerHitsJob {
    Input:  NativeArray<RaycastHit> results
    Output: NativeArray<FingerPoseData> poseBuffer[pingPong]
    Per finger i:
      if results[i].distance > 0:
        bendAngle[i]       = 1.0f - (results[i].distance / castLength)
        tipPos[i]          = results[i].point
        tipNormal[i]       = results[i].normal
        contactFlags[i]    |= BIT0
      else:
        bendAngle[i]       = 1.0f   // full curl, no surface
        tipPos[i]          = rayOrigin[i] + rayDir[i] * castLength
        tipNormal[i]       = -rayDir[i]
  }
  handle3 = ProcessFingerHitsJob.Schedule(FINGER_COUNT, 1, handle2)

Step 4 - APPLY POSE (Main Thread, after handle3.Complete()):
  Read poseBuffer[pingPong ^ 1]   // read completed buffer, write to other
  Drive finger bone rotations via precomputed bend-to-angle LUT (NativeArray<float>[64])
  LUT maps bendAngle[0-1] -> euler.x rotation per finger segment (3 segments per finger)
  Interpolate: boneRot = lerp(boneRot, targetRot, FINGER_INTERP_SPEED * fixedDeltaTime)
               FINGER_INTERP_SPEED = 18.0f
```

**Numerical Guards (inside ProcessFingerHitsJob):**
```
if results[i].normal == float3.zero -> normal = -rayDir[i]   (degenerate surface)
bendAngle = clamp(bendAngle, 0.0f, 1.0f)
if (math.any(math.isnan(results[i].point)))
```

### [SAFE] Failure Mode Table

```
CONDITION                              | RESPONSE                                        | FLAG SET
---------------------------------------|--------------------------------------------------|-------------------
separation > 0.8m                      | Grip break, de-energize rb, dispatch event       | BIT3, BIT7
objectMass > 500kg                     | Grab denied. OnGrabEnd(OVERWEIGHT)               | -
rb.velocity > 40m/s post-force         | Clamp velocity to 40m/s, SET BIT7               | BIT7
accel = NaN/Inf                        | Zero accel, log telemetry, continue              | BIT7
Spherecast returns NaN point           | Treat as no-hit, full finger curl                | -
fixedDeltaTime spike > 0.05s           | Clamp dt to 0.02s in all formulas (lagged sim)  | -
angularVelocity > 50 rad/s             | Clamp to 50 rad/s, kill excess energy            | BIT7
Two hands grab same object (BASE tier) | Deny second grab. Queue for HIGH/ULTRA only      | -
Object frozen/kinematic during grab    | Detect IsKinematic flag, break grip immediately  | BIT3
Depth > 4000m (pressure crush event)   | Override grab system, force grip break + object deform trigger | BIT3
```

### [SAFE] Grab Init Checklist (one-time, not per-tick)

```
1. Validate IGrabbable interface exists -> else deny
2. Cache rb reference (instanceID -> NativeHashMap lookup)
3. Cache objectMass, frontalArea, inertiaTensorLocal
4. Compute virtualHandMass (SectionIII.C)
5. Compute VIRTUAL_DAMPER_C = 2 * sqrt(virtualHandMass * VIRTUAL_SPRING_K) * 0.9
6. Set rb.drag = 0, rb.angularDrag = 0
7. Set rb.maxAngularVelocity = 50.0f
8. Set rb.interpolation = RigidbodyInterpolation.Interpolate (visual smoothness)
9. Set stateFlags = BIT0 | (mass > 50kg ? BIT1 : 0)
10. Invalidate finger pose: SET BIT4
11. Enqueue GrabEvent{GRAB_BEGIN}
```

### [SAFE] Grab Teardown Checklist

```
1. Restore rb.drag / rb.angularDrag to object's default (cached at init)
2. Clear stateFlags BIT0
3. Reset virtualHandPos/Vel
4. Complete any pending JobHandles before releasing NativeArrays
5. Enqueue GrabEvent{GRAB_END, reason}
6. Trigger finger open-hand pose (bendAngle -> 0 for all, interpolated)
```

### [SENIOR_HACK] PD Gain Auto-Tune Per Object Density

```

// Light objects (bio-samples, foam) need lower gains to feel "floaty"
