# LOGISTICS_ENERGY_NETWORKS.md
# Hecton-8 | Deep-Sea Logistics Substrate
---

## Section0 - AXIOMS

- All networks: directed weighted graphs. No exceptions.
- Flow is math. Visuals are decoupled proxies. Physics is irrelevant to throughput.
- Single authoritative `LogisticsTick` at 5Hz. No physics callbacks drive resource state.
- Max world nodes: 4096. Addressable by 12-bit ID. Fits uint16 with 4 reserved flag bits.

---

## Section1 - CANONICAL DATA STRUCTURES

### 1.1 Node Struct (pack to 32 bytes, cache-line aligned)

LogisticsNode {
    uint32  ID;           // bits[0..11] = index, bits[12..15] = NetworkID, bits[16..31] = reserved
    float32 Capacity;     // max throughput (watts or kPa)
    float32 Resistance;   // pipe/cable impedance (ohms or fluidic resistance)
    float32 CurrentLoad;  // real-time carried load
    float32 Potential;    // voltage (power) or pressure (oxygen/fluid)
    uint8   Priority;     // 0=critical(life-support), 1=essential, 2=operational, 3=ambient
    uint8   Flags;        // bitfield - see Section1.3
    uint8   NetworkID;    // island membership (DSU root compressed ID)
    uint8   _pad;         // alignment
}

Total: 32 bytes. 4096 nodes = 128KB. Fits L2 on MX350.

### 1.2 Graph Adjacency

NativeArray<int>                      EdgeOffsets;      // len = NodeCount + 1
NativeArray<int>                      EdgeDestinations; // contiguous neighbor list
NativeArray<float>                    EdgeResistance;   // same index space as EdgeDestinations
NativeArray<LogisticsNode>            NodeBuffer;       // flat, cache-linear
NativeList<int2>                      TopologyEdgeList; // authoring / mutation source
NativeArray<int>                      DSU_Parent;       // Union-Find parent array, len=4096
NativeArray<int>                      DSU_Rank;         // Union-Find rank array
NativeParallelHashMap<int,float>      ProducerMap;      // NodeID -> production rate
NativeParallelHashMap<int,float>      ConsumerMap;      // NodeID -> demand rate

CSR law:
  - Runtime traversal reads `EdgeOffsets/EdgeDestinations` only
  - Topology mutation edits `TopologyEdgeList`, then rebuilds CSR snapshot
  - No hash map iteration in BFS hot path

### 1.3 Flags Bitfield (uint8)

bit 0 - ACTIVE
bit 1 - RUPTURED
bit 2 - BROWNOUT        // set by distributor when starved
bit 3 - ISOLATED        // set by DSU when no path to producer
bit 4 - BRIDGE_NODE     // articulation point - see Section4.3
bit 5 - OVERLOADED      // CurrentLoad > Capacity
bit 6 - EMERGENCY_RSVD  // bypasses priority - hardcoded life-support
bit 7 - DIRTY           // recalc pending; cleared after LogisticsTick

## Section2 - MATHEMATICAL KERNEL

### 2.1 Flow Equation (Ohm / Hagen-Poiseuille unified form)

FlowRate(A->B) = (Potential[A] - Potential[B]) / Resistance(edge_AB)

Resistance(edge) = BaseResistance * Length * (1 + ThermalCoeff * Temperature)
                 + (RUPTURED flag ? RuptureResistanceMult : 1.0)

Apply iteratively per edge during Jacobi relaxation (Section3.2).

### 2.2 Potential Normalization (per LogisticsTick)

sum_Production  = sum of ProducerMap values within NetworkID
sum_Demand      = sum of ConsumerMap values within NetworkID

SupplyRatio   = _Production / max(_Demand, epsilon)    // epsilon=0.001, avoids div-zero

Potential[producer_node] = sum_Production             // source potential
Potential[consumer_node] = Potential[consumer_node] * SupplyRatio   // scaled sink

### 2.3 Brownout Threshold Logic

if SupplyRatio < 0.85:
    set BROWNOUT on all consumers where Priority >= 2
if SupplyRatio < 0.40:
    set BROWNOUT on all consumers where Priority >= 1
if SupplyRatio < 0.10:
    set BROWNOUT on all consumers where Priority >= 0
    trigger ALERT_CRITICAL_POWER

### 2.4 Overload Detection

if CurrentLoad[node] > Capacity[node] * 1.15:
    set OVERLOADED flag
    apply thermal damage accumulation: ThermalDamage[node] += OverloadRate * tickDelta
    if ThermalDamage[node] > BreakThreshold: trigger Rupture(node)

## Section3 - ALGORITHMIC KERNELS

### 3.1 BFS Traversal (NO recursion - NativeQueue mandatory)

INIT:
    enqueue all producer-nodes
// Pre-allocate 'visited' using Allocator.Persistent ONCE at subsystem boot.
// Inside loop: visited.Clear()

LOOP:
    node = queue.Dequeue()
    visited.Set(node, true)
    start = EdgeOffsets[node]
    end   = EdgeOffsets[node + 1]
    for i in start..end-1:
        neighbor = EdgeDestinations[i]
        if NOT visited.IsSet(neighbor):
            compute FlowRate(node->neighbor)          // Section2.1
            accumulate CurrentLoad[neighbor]
            enqueue neighbor

TERMINATE: queue empty

BFS completes in O(V+E). V<=4096, E<=~8192 (sparse base). Budget per tick: <0.3ms on i3-10gen.

### 3.2 Jacobi Relaxation (optional, for complex loops)

MAX_ITERATIONS = 8      // hard cap, prevents tick overrun
CONVERGENCE_DELTA = 0.01

for i in 0..MAX_ITERATIONS:
    max_delta = 0
    for edgeIndex = 0; edgeIndex < EdgeCount; edgeIndex++:
        edge = EdgeList[edgeIndex]
        A = edge.A
        B = edge.B
        old_flow = EdgeFlow[edge]
// [FORBID] Edge-based relaxation for closed loops.
// You MUST relax Node Potentials iteratively, then derive edge flow.
        max_delta = max(max_delta, abs(new_flow - old_flow))
    if max_delta < CONVERGENCE_DELTA: break

### 3.3 Priority-Sorted Greedy Distribution

Sort ConsumerList by Priority byte ASC (insertion-sort safe at <=512 consumers, stable)

remaining = sum_Production
for consumerIndex = 0; consumerIndex < SortedConsumerCount; consumerIndex++:
    consumer = SortedConsumers[consumerIndex]
    alloc = min(ConsumerMap[consumer.ID], remaining)
    CurrentLoad[consumer.ID] = alloc
    remaining -= alloc
    if alloc < ConsumerMap[consumer.ID] * 0.95:
        set BROWNOUT flag on consumer

### 3.4 Union-Find (DSU) - Island/Loop Detection

// Path-compressed Find
Find(x):
    while DSU_Parent[x] != x:
        DSU_Parent[x] = DSU_Parent[DSU_Parent[x]]   // path halving
        x = DSU_Parent[x]
    return x

// Union by rank
Union(a, b):
    ra = Find(a); rb = Find(b)
    if ra == rb: return false    // already same island -> LOOP detected
    if DSU_Rank[ra] < DSU_Rank[rb]: swap(ra, rb)
    DSU_Parent[rb] = ra
    if DSU_Rank[ra] == DSU_Rank[rb]: DSU_Rank[ra]++
    return true

// Full rebuild cost: O((N)*E) ~= O(E). Run on graph mutation only (not every tick).

Loop detection: Union returns false -> cycle exists -> flag both endpoints BRIDGE_NODE=0, log cycle for redundancy routing.

### 3.5 Articulation Point Detection (Bridge Nodes)

// Iterative Tarjan - no recursion
stack = NativeStack<(nodeID, parentID, edgeIndex)>
disc[] = NativeArray<int>   // discovery time
low[]  = NativeArray<int>   // low-link value
timer  = 0

push(startNode, -1, 0)
while stack not empty:
    (u, parent, ei) = stack.Peek()
    if ei == 0: disc[u] = low[u] = timer++
    neighbor = Adjacency[u][ei]
    stack.UpdateEdgeIndex(ei+1)
    if not visited[neighbor]:
        push(neighbor, u, 0)
    elif neighbor != parent:
        low[u] = min(low[u], disc[neighbor])
    if all edges of u processed:
        stack.Pop()
        low[parent] = min(low[parent], low[u])
        if low[u] >= disc[parent] AND parent != -1:
            set BRIDGE_NODE flag on parent    // removal splits network

Run articulation pass only on topology change events (cable placed/removed).

## Section4 - NETWORK TOPOLOGY OPERATIONS

### 4.1 Merge (O(1) amortized via DSU)

ON cable_placed(nodeA, nodeB):
    same_island = !Union(Find(nodeA), Find(nodeB))
    if same_island: log redundant loop, skip full rebuild
    else:
        TopologyEdgeList.Add(int2(nodeA, nodeB))
        RebuildCSRForNetwork(NetworkID(nodeA))
        mark DIRTY on both nodes
        schedule partial BFS from nodeA next LogisticsTick

### 4.2 Split (O(V+E) rebuild - amortize with dirty queue)

ON cable_removed(nodeA, nodeB):
    remove edge from TopologyEdgeList
    RebuildCSRForNetwork(NetworkID(nodeA))
    rebuild DSU from scratch for affected NetworkID only   // not full world
    re-run articulation pass
    nodes with new ISOLATED flag: set BROWNOUT, trigger VFX_POWER_LOSS emitter

Rebuild budget: 4096 nodes, sparse edges -> <0.5ms. Acceptable as one-shot event.

### 4.3 Bridge Node Handling

if player removes edge where both endpoints have BRIDGE_NODE:
    pre-warn: query articulation result BEFORE removal
    display "NETWORK SPLIT WARNING" in diegetic UI
    on confirm: execute Split (Section4.2)

## Section5 - RUPTURE & FAILURE SYSTEM

### 5.1 Rupture State Machine

States: NOMINAL -> STRESSED -> RUPTURED -> SEVERED

STRESSED  : ThermalDamage > BreakThreshold * 0.5
RUPTURED  : ThermalDamage >= BreakThreshold
SEVERED   : Capacity = 0, Resistance = infinity, ACTIVE flag cleared

### 5.2 Rupture Flow Drain

ON RUPTURED flag set on node N:
    each LogisticsTick:
        CurrentLoad[N] -= RuptureRate * tickDelta
        CurrentLoad[N] = max(0, CurrentLoad[N])
        emit VFX_FLUID_AESTHETICS at node world position (rate proportional to CurrentLoad)
        if CurrentLoad[N] == 0 AND Potential[N] < 0.01:
            transition -> SEVERED

### 5.3 Pressure Cascade (fluid networks only)

if node RUPTURED and NetworkType == FLUID_PRESSURE:
    backpropagate pressure drop:
        for upstreamIndex = 0; upstreamIndex < UpstreamCount[N]; upstreamIndex++:
            U = UpstreamNeighbors[N][upstreamIndex]
            Potential[U] -= RupturePressureLoss * (1 / Resistance(U->N))
            if Potential[U] < MinOperatingPressure:
                set BROWNOUT on U

## Section6 - TICK SCHEDULING & TIME-SLICING

### 6.1 LogisticsTick Architecture

FixedRate: 5Hz (200ms interval)
Graph solve: Burst-compiled IJob (NOT main thread)
Main-thread cadence may only schedule/consume jobs and touch Unity-owned objects/signals.

Tick N:   Networks 0,2,4,6... (even NetworkIDs)
Tick N+1: Networks 1,3,5,7... (odd NetworkIDs)
-> Effective per-network update: 2.5Hz. Imperceptible to player at this abstraction level.

### 6.2 Dirty-Flag Optimization

Only process nodes where DIRTY flag set OR neighbors changed last tick
DIRTY cleared at end of each LogisticsTick
Estimated active nodes in typical scene: 60-120 -> full 4096 budget rarely exercised

### 6.3 Frame Budget Targets

i3-10gen @ 5Hz tick:
    BFS traversal 4096 nodes:    <0.3ms
    Jacobi 8 iterations:         <0.4ms
    DSU full rebuild (on event): <0.5ms (event-only, not per-tick)
    Priority sort + distribution:<0.1ms
    Total LogisticsTick ceiling: <= 1.0ms per 200ms window -> <0.5% CPU budget

### 6.4 Current Source Alignment - Pipe Runtime Adapter Boundary

[RULE] `LogisticsTick` means the authoritative graph/math solve, not every Unity API touch around it.
[RULE] Graph/pressure solve runs in Burst jobs over NativeArray/NativeQueue/NativeParallel* buffers.
[RULE] Main-thread orchestration is allowed only for Unity object integration: pump drain/injection, service registration, job schedule/consume gates, signal publishing, and visual proxy dirty updates.
[RULE] `ISlowTickable` may be the cadence entrypoint; `ILateFrameTickable` may consume completed job outputs. Neither may contain per-frame `Update`, coroutine, physics callback, or allocation-driven simulation.
[RULE] Authoring endpoint MonoBehaviours such as pipe nodes and pump modules are adapters. They register into a shared scheduler and must not own per-segment simulation loops.
[RULE] Runtime state of record is NativeArray/CSR/queue data, not component fields, except debug mirrors and inspector authoring data.
[RULE] Pipe Black Box capacity is 300 frames. Current dump target: `Docs/AgentLogs/Dump_PIPE_LOGISTICS_ARCHITECT.bin`.

[FORBID] Treating the presence of `LogisticsPipeNode`, `WaterPumpModule`, or `FluidPipeGraphRuntime` MonoBehaviours as a mandate violation when they are cold adapters with shared scheduler ownership.
[FORBID] One MonoBehaviour `Update`/`FixedUpdate` per pipe/cable segment.
[FORBID] Pump/flood/logistics truth in physics callbacks.

## Section7 - GPU VISUAL PROXIES (MX350 COMPLIANT)

### 7.1 Flow Indicator Shader (zero CPU overhead)

// All animation via shader_time - no CPU scroll updates
UV_offset = frac(shader_time * FlowSpeed * FlowDirection)
// FlowSpeed and FlowDirection set ONCE when edge is created or load changes >10%
// Threshold prevents per-frame material property updates

### 7.2 Load-Driven Color Mapping (material property block, not new material)

LoadNorm = CurrentLoad / Capacity    // computed CPU-side in LogisticsTick
color = lerp(COLOR_IDLE, COLOR_ACTIVE, LoadNorm)
if OVERLOADED: color = lerp(COLOR_ACTIVE, COLOR_DANGER, sin(time*8)*0.5+0.5)  // flicker GPU-side
if RUPTURED:   color = COLOR_RUPTURE, enable particle emitter flag

Property block update: batch all changed edges post-tick. Max ~50 dirty edges per tick -> trivial draw call cost.

### 7.3 VRAM Budget (MX350 <= 1800MB constraint)

Flow textures: 1 tileable 256x256 per network type (power / fluid / oxygen) = 3 textures = ~768KB
Node indicator sprites: 1 atlas 512x512 = ~1MB
Total logistics visual budget: <2MB VRAM

## Section8 - RESOURCE TYPE EXTENSIONS

### 8.0 Logistics / Thermodynamics Boundary

[RULE] Logistics owns transport capacity, graph connectivity, pressure/load/potential, brownout, rupture flags, and resource availability.
[RULE] Thermodynamics owns heat storage, ambient exchange, cooling/heating rates, tissue/suit/compartment temperature, and visual heat cues.
[RULE] Logistics may carry a `THERMAL_COOLANT` channel, but it transports heat capacity as a resource; it does not solve temperature diffusion or physiology.
[RULE] Thermodynamics may read logistics `THERMAL_COOLANT` availability through a read-only contract or queued event, then solve heat locally.
[RULE] Cross-domain exchange is a fixed-rate summary: node id, coolant availability ratio, temperature delta request, and flags. No per-frame polling.

[FORBID] Logistics directly mutating temperature fields.
[FORBID] Thermodynamics mutating `LogisticsNode`, graph edges, DSU/CSR topology, or resource potential.
[FORBID] Using `GlobalRegistry.Get<T>()` for continuous thermal state updates.

## Engineering Data

| Quantity | Owning Domain | Shared As | Cadence |
|---|---|---|---|
| Node potential/load | Logistics | read-only summary | LogisticsTick |
| Coolant availability | Logistics | ratio + flags | 5 Hz / dirty only |
| Temperature delta | Thermodynamics | event/request packet | SlowTick |
| Heat damage | Thermodynamics / Damage owner | event packet | threshold only |
| Visual pipe glow | Presentation | shader proxy | dirty change only |

### 8.1 Supported Network Types (NetworkType enum, uint8)

0x00 - POWER_DC          // voltage model, Ohm's law
0x01 - OXYGEN_PRESSURE   // Hagen-Poiseuille, viscosity factor
0x02 - THERMAL_COOLANT   // pressure + heat capacity coefficient
0x03 - DATA_SIGNAL       // binary: connected or not, no flow math needed
0x04 - FUEL_LIQUID       // pressure + density, gravity-affected potential

### 8.2 Type-Specific Resistance Modifiers

POWER_DC:          Resistance *= (1 + 0.004 * (Temperature - 20))   // copper temp coeff
OXYGEN_PRESSURE:   Resistance *= (PipeRadius^-4) * 8 * Viscosity * Length /
THERMAL_COOLANT:   Resistance *= (1 / FlowVelocity) * ThermalConductivity^-1
DATA_SIGNAL:       Resistance = 0 if ACTIVE, infinity if not (binary only)
FUEL_LIQUID:       Resistance += Density * g * HeightDelta           // hydrostatic head

## Section9 - INTEGRATION CONTRACTS

### 9.1 External System Interfaces

SubmarineHullSystem   -> writes RUPTURED flags on hull breach events
OxygenSystem          -> reads CurrentLoad from OXYGEN_PRESSURE nodes
PowerConsumerSystem   -> reads BROWNOUT flags, adjusts device behavior
PhysicsSystem         -> NO ACCESS to LogisticsNode data. Zero coupling.
VFXSystem             -> reads: node world position, Flags, CurrentLoad. Read-only.
SaveSystem            -> serialize: NodeBuffer, Adjacency, DSU_Parent, EdgeWeight

### 9.2 Event Bus (no polling)

LogisticsEvents (NativeQueue<LogisticsEvent>, consumed main thread post-tick):
    BROWNOUT_STARTED  (NetworkID, AffectedNodeIDs)
    BROWNOUT_CLEARED  (NetworkID)
    NODE_RUPTURED     (NodeID, WorldPosition)
    NODE_SEVERED      (NodeID)
    NETWORK_SPLIT     (NetworkID_A, NetworkID_B)
    NETWORK_MERGED    (NetworkID_surviving)
    OVERLOAD_WARNING  (NodeID, LoadPercent)

### 9.3 Save/Load Contract

Serialize NodeBuffer as raw bytes (4096 * 32 bytes = 128KB flat binary)
Serialize Adjacency as edge-list: (uint16 A, uint16 B, float weight) * EdgeCount
DSU rebuilt from edge-list on load (do not serialize DSU_Parent - recompute)
Total logistics save footprint: <200KB per world instance

## Section10 - FAILURE GUARDS & ASSERTIONS

ASSERT: Resistance[edge] > 0 before division. Clamp min: 0.0001.
ASSERT: Capacity[node] > 0 at node creation.
ASSERT: NetworkID < 16 (4-bit field constraint).
ASSERT: BFS visited count <= 4096 (overflow = graph corruption).
GUARD:  Logistics graph solve never runs on main thread. Main-thread cadence may only schedule/consume jobs and touch Unity-owned objects/signals.
GUARD:  TopologyEdgeList writes locked behind topology-change mutex. CSR snapshot is read-only during tick.
GUARD:  If DSU_Parent rebuild exceeds 2ms wall clock -> log warning, skip tick, force next-frame.
