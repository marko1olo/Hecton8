struct DestructibleChunkData  // 32 bytes

### 2.5 State Bit Masks

```
// DestructibleParent stateFlags
MASK_INTACT      = 0b00000001
MASK_DAMAGED     = 0b00000010  // HP < 50%
MASK_DESTROYED   = 0b00000100
MASK_DECAL_LIVE  = 0b00001000
MASK_MESH_HIDDEN = 0b00010000

// Transition rules (bitwise, no branching where possible):
// On damage:   flags |= MASK_DAMAGED   when hp < hpMax * 0.5f
// On destroy:  flags = (flags & ~MASK_INTACT) | MASK_DESTROYED | MASK_MESH_HIDDEN
// Decal spawn: flags |= MASK_DECAL_LIVE when (flags & MASK_DAMAGED) && !(flags & MASK_DECAL_LIVE)

// DestructibleChunkData stateFlags
CHUNK_ACTIVE     = 0b00000001
CHUNK_SINKING    = 0b00000010
CHUNK_POOLED     = 0b00000100
CHUNK_NOCOLLIDE  = 0b00001000
```

### 2.6 Double-Buffer for Debris Transform Updates

```
// Two NativeArrays<float4x4> of size 256 (instanced renderer input)

## III. ALGORITHMIC & MATH TRUTH

### 3.1 Damage Application & HP Depletion

```
// Called from DrillSystem job. Input: toolPower, impactPoint, parentEntityID
Step 1: Fetch DestructibleParentData by entityID (direct NativeArray index lookup)
Step 2: hpNew = hpCurrent - toolPower * dt * DRILL_RATE_SCALAR
        DRILL_RATE_SCALAR = materialHardnessTable[materialClass] // precomputed LUT, 8 entries
Step 3: Guard: hpNew = max(hpNew, 0.0f)
Step 4: damageAccumulator += (hpCurrent - hpNew)
Step 5: Write hpNew back. Set hpCurrent = hpNew.
Step 6: Branch-free state update:
        isDamaged  = (hpNew < hpMax * 0.5f)        → 1 or 0
        isDestroyed = (hpNew <= 0.0f)               → 1 or 0
        flags |= (isDamaged << 1)    // sets MASK_DAMAGED bit
        flags |= (isDestroyed << 2)  // sets MASK_DESTROYED bit
Step 7: If isDestroyed: enqueue entityID into DestructionEventQueue (NativeQueue, lock-free SPSC)
```

### 3.2 Conservation of Mass / Loot Yield

```
// Executed by EntropyYieldJob (Burst, single-threaded against event queue)
// Inputs: parentMassKg, materialClass, drillPower, depthMeters, toolEfficiency ∈ [0,1]

// Base yield volume (m³):
yieldVolume = (drillPower * toolEfficiency * dt) / densityLUT[materialClass]
// densityLUT[kg/m³]: Porous=800, Sediment=1400, Basalt=2900, Coral=1100

// Mass extracted this frame:
massExtracted = yieldVolume * densityLUT[materialClass]
// Clamp: massExtracted = min(massExtracted, parentMassKg_remaining)

// Item count (discrete):
rawCount = massExtracted / UNIT_ITEM_MASS[itemTypeForMaterial]
// UNIT_ITEM_MASS: lookup by materialClass → itemType mapping (8-entry LUT)
itemCount = (ushort)floor(rawCount)  // floor: conservation — never over-yield

// Quality factor (depth-driven rarity):
qualityFactor = saturate(depthMeters / MAX_DEPTH_RARITY_THRESHOLD)
// MAX_DEPTH_RARITY_THRESHOLD = 3000.0f (meters)
// qualityFactor drives rarity tier: 0.0–0.33=Common, 0.33–0.66=Uncommon, 0.66–1.0=Rare

// Remainder accumulation (no float waste):
yieldRemainder += (rawCount - floor(rawCount))
bonusItem = (ushort)floor(yieldRemainder)   // carry fractional mass across frames
yieldRemainder -= bonusItem
itemCount += bonusItem

// Write to DropBuffer:
For i in [0, itemCount):
    dropEntry.itemID      = materialToItemID[materialClass]
    dropEntry.quantity    = 1
    dropEntry.qualityFactor = (half)qualityFactor
    dropEntry.worldSpawnPos = parentWorldPos + RandomOnUnitSphere() * 0.3f
    // RandomOnUnitSphere: use deterministic hash(entityID ^ frameCount ^ i) → spherical coords
    DropBuffer.Enqueue(dropEntry)
```

### 3.3 Destruction Swap — Mesh Disable + Debris Spawn

```
// DestructionSwapJob — runs on DestructionEventQueue drain, main-thread-adjacent (requires Transform access)
// Per destroyed entity:
Step 1: parentRenderer.enabled = false  // O(1) flag flip, no alloc
Step 2: parentCollider.enabled = false
Step 3: chunkCount = parentData.chunkCount  // 5–15 (baked)
Step 4: For i in [0, chunkCount):
    Step 4a: poolIdx = freeIndices.Dequeue()   // O(1)
             Guard: if freeIndices.IsEmpty → log warning, skip chunk (graceful degrade)
    Step 4b: rb = pooledRigidbodies[poolIdx]
    Step 4c: rb.position = parentWorldPos + chunkData[chunkStartIndex + i].localPositionOffset
    Step 4d: rb.rotation = parentWorldRot  // inherit parent orientation
    Step 4e: impulseDir = normalize(chunkData[i].localPositionOffset) + Random3D(seed=entityID^i)*0.3f
             impulseDir = normalize(impulseDir)  // re-normalize after noise
             impulseMag = sqrt(2.0f * parentData.hpMax) * DEBRIS_IMPULSE_SCALAR
             // DEBRIS_IMPULSE_SCALAR = 0.04f (tuned: avoid MX350 physics overload)
    Step 4f: rb.AddImpulse(impulseDir * impulseMag)  // single-frame impulse
    Step 4g: poolState[poolIdx] = 1  // mark active
    Step 4h: chunkData[chunkStartIndex+i].stateFlags |= CHUNK_ACTIVE
             chunkData[chunkStartIndex+i].despawnTimer = 0.0f
             chunkData[chunkStartIndex+i].poolIndex = poolIdx
Step 5: Mark parent stateFlags |= MASK_MESH_HIDDEN
Step 6: Push debris handle batch into instanced renderer batch list
```

### 3.4 Debris Despawn Hysteresis (5-Second Lifecycle)

```
// DebrisDespawnJob — Burst, runs every FixedUpdate
// Iterates active chunk entries only (filtered by CHUNK_ACTIVE bit)
// Phase table:
//   t ∈ [0.0, 3.0):  normal physics, full collision
//   t ∈ [3.0, 5.0):  disable collision, begin kinematic sink
//   t ∈ [5.0, ∞):    pool return

For each active chunkData c:
    c.despawnTimer += dt

    Phase 0→1 transition (t >= 3.0f):
        if !(c.stateFlags & CHUNK_NOCOLLIDE):
// Burst job writes to NativeArray<DebrisStateResult>.
// Main thread applies to Rigidbody components post-JobHandle.Complete()
            pooledRigidbodies[c.poolIndex].detectCollisions = false
            c.stateFlags |= CHUNK_NOCOLLIDE | CHUNK_SINKING
            // Record sinkStartY = rb.position.y at this moment (stored in scratch NativeArray)

    Phase 1 — kinematic sink lerp (t ∈ [3.0, 5.0)):
        if c.stateFlags & CHUNK_SINKING:
            t_norm = (c.despawnTimer - 3.0f) / 2.0f          // [0,1]
            t_smooth = t_norm * t_norm * (3.0f - 2.0f*t_norm) // smoothstep
            sinkDelta = SINK_DEPTH * t_smooth                  // SINK_DEPTH = -0.25f (meters)
            rb.position.y = sinkStartY[poolIdx] + sinkDelta
            // Also drive alpha fade via MaterialPropertyBlock: _Opacity = 1.0 - t_smooth

    Phase 2 — pool return (t >= 5.0f):
        rb.position = POOL_GRAVEYARD_POS   // float3(0,-9999,0) — off-screen
        rb.velocity = float3.zero
        rb.isKinematic = true
        rb.detectCollisions = false
        c.stateFlags = CHUNK_POOLED        // clear all other bits
        poolState[c.poolIndex] = 0         // mark free
        freeIndices.Enqueue(c.poolIndex)   // return to pool O(1)
```

### 3.5 Decal Projection — Damage Crack System

```
// Trigger: (hpCurrent < hpMax * 0.5f) AND !(flags & MASK_DECAL_LIVE)
// Execution: DecalSpawnJob — runs on damage event, NOT every frame

// World-space projector approach (no screen-space dependency, MX350 safe):

Step 1: Compute decalOrigin = impactPoint  // from DrillSystem hit data
Step 2: Compute decalNormal = surfaceNormal at impactPoint (baked per-chunk — stored as byte3 in ChunkData, octahedral encoding)
        Decode: n.xy = (byte3.xy / 127.5f) - 1.0f
                n.z  = sqrt(saturate(1 - dot(n.xy, n.xy)))  // reconstruct Z, guaranteed unit length

Step 3: Compute decalTangent via Gram-Schmidt:
        up = float3(0,1,0)
        tangent = normalize(up - decalNormal * dot(up, decalNormal))
        bitangent = cross(decalNormal, tangent)

Step 4: Build decal OBB matrix (3x3 rotation, no scale branch):
        decalBasis = float3x3(tangent, bitangent, decalNormal)
        // Stored in DecalData struct (NativeArray, 64-entry max concurrent)

Step 5: Assign decal size:
        hpRatio = hpCurrent / hpMax                        // [0, 0.5] at this point
        crackScale = lerp(CRACK_MAX, CRACK_MIN, hpRatio * 2.0f)  
        // CRACK_MAX = 0.8f, CRACK_MIN = 0.2f
        // Full damage (HP=0) = largest crack; 50% HP = smallest crack

Step 6: Select crack atlas tile:
        tileIndex = hash(entityID) & 0x07  // 8 tiles in atlas (3-bit mask). Zero branch.

Step 7: Write DecalData struct:
        decalData.worldPos     = decalOrigin
        decalData.basisMatrix  = decalBasis
        decalData.scale        = crackScale
        decalData.atlasIndex   = tileIndex
        decalData.entityID     = parentEntityID
        decalData.opacity      = 1.0f

Step 8: Shader receives decalBasis + worldPos → reconstructs local UV:
        // In surface shader (or URP decal pass):
        localPos  = transpose(decalBasis) * (fragWorldPos - decalOrigin)
        uv        = localPos.xy / crackScale + 0.5f          // [0,1]
        discard   if any(abs(localPos) > crackScale * 0.5f)  // OBB clip: no geometry needed
        sampleUV  = uv / 8.0f + float2((tileIndex & 3), (tileIndex >> 2)) / 8.0f  // atlas offset

// On full destruction (HP=0): clear MASK_DECAL_LIVE, release DecalData slot back to pool.
// DecalData pool: 64 slots. NativeQueue<byte> freeDecalSlots. Same ring pattern as debris.
```

### 3.6 Frame-Rate Independent Stabilization

```
// All lerps use exponential decay (dt-invariant):
lerpedValue = target + (current - target) * exp(-lambda * dt)
// lambda tuning:
//   Sink lerp (cosmetic):  lambda = 3.0f  → 95% complete in ~1s
//   Decal fade:            lambda = 1.0f  → gradual 3s fade post-destroy

// NaN/Inf guards (applied at Burst job boundaries):
Guard_Float(x):
    isValid = (x == x) & (x != INFINITY) & (x != -INFINITY)
    return isValid ? x : 0.0f
    // Branchless: return x * (float)isValid  [valid=1, invalid=0]

// Impulse magnitude clamp (prevents tunneling on MX350 physics):

// MAX_SAFE_IMPULSE = 15.0f N·s (empirical for chunk mass range 2–30kg)

// Velocity clamp post-impulse (prevents physics explosion):

// MAX_CHUNK_SPEED = 12.0f m/s. length() guard: add 1e-6f before divide.

### 5.2 Failure Mode Catalog

```
FAILURE: Pool exhausted (freeIndices.IsEmpty)
RESPONSE: Skip chunk spawn for that index. Log once per second (time-gated log, no alloc).
          Parent destruction still completes. Visual degrades gracefully (fewer chunks).
          Never throw. Never stall.

FAILURE: Simultaneous destructions > 2/frame (queue overflow)
RESPONSE: DestructionEventQueue capped at 8. If full, new events dropped with warning.
          Player cannot trigger >8 destructions in 16ms — physical constraint enforced upstream.

FAILURE: impactNormal = float3.zero (bad geometry / degenerate mesh)
RESPONSE: Replace with float3(0,1,0) default. Guard before normalize:
          normal = (lengthSq(n) < 1e-6f) ? float3(0,1,0) : normalize(n)

FAILURE: depthMeters > 4000.0f (beyond rarity curve)
RESPONSE: qualityFactor = 1.0f (clamp). No overflow. Rarity tier stays at Rare max.
          No special-case branching. saturate() handles automatically.

FAILURE: rb.velocity NaN post-impulse (degenerate physics state)
RESPONSE: Each DebrisDespawnJob frame start: 
          if isnan(rb.velocity.x) → rb.velocity = float3.zero; rb.isKinematic = true; force-pool.

FAILURE: drillPower = 0 or negative (bad tool state)
RESPONSE: Guard at IDrillTarget boundary: power = max(power, 0.0f). Zero power = zero damage = no-op.

FAILURE: Decal pool full (64 slots exhausted)
RESPONSE: Evict oldest decal (lowest despawnTimer headroom). Reuse slot. No new alloc.
          Ring eviction: evictIdx = (lastEvicted + 1) & 63

FAILURE: chunkCount out of range [5,15] (bad bake data)
RESPONSE: chunkCount = clamp(chunkCount, 1, 16) at Init validation pass.
          Flag asset as WARN_BAD_BAKE in editor-only validation tool. Runtime clamp = safe.

FAILURE: Double-buffer swap while GPU still reading (rare on MX350 single queue)
RESPONSE: Insert Graphics.ExecuteCommandBuffer fence before swap.
          If CommandBuffer unavailable (platform): skip swap that frame, write next frame instead.
          Double-buffer write side always safe — only readIdx exposed to GPU.
```

### 5.3 Initialization Sequence (Scene Load)

```
Order:
1. Allocate NativeArrays (Persistent allocator). Register in DisposableRegistry for scene unload.
2. Populate freeIndices queue: for i in [0,255] → freeIndices.Enqueue((ushort)i)
3. Pre-position all pooled rigidbodies at POOL_GRAVEYARD_POS. isKinematic=true. detectCollisions=false.
4. Load densityLUT, materialToItemID, UNIT_ITEM_MASS tables into NativeArray<float/uint> (Persistent).
5. Validate all DestructibleParentData baked assets: chunkCount, chunkStartIndex, densityClass in range.
6. Initialize DropBuffer NativeQueue (capacity=256, Persistent).
7. Initialize DecalData NativeArray[64]. freeDecalSlots filled 0..63.
8. Set Physics.autoSyncTransforms = false. Manage manually per job completion.
9. Register double-buffer arrays. Initialize writeIdx=0, readIdx=1.
10. Signal: EntropySystemReady = true. No system processes events before this flag.
```

### 5.4 Scene Unload / Disposal

```
// Reverse init order. All NativeArrays: .Dispose() in OnDestroy.
// DisposableRegistry pattern: List<IDisposable> — single loop, no missed leaks.
// Complete all scheduled jobs before Dispose: JobHandle.ScheduleBatchedJobs(); masterHandle.Complete();
// Never dispose NativeArray with active job handle — deadlock or native crash.

### 6.5 Entropy Accumulation for Progressive Weakening

```
// damageAccumulator (in ParentData) tracks total damage received across sessions (persistent save).
// On load: if damageAccumulator > hpMax * 0.3f → spawn object pre-damaged (crack decal active, HP=70%)
// Simulates underwater entropy / natural degradation without scripted events.
// Formula: savedAccumulator decays between sessions: acc *= exp(-DECAY_RATE * hoursSinceSave)
// DECAY_RATE = 0.01f (slow geological time). Prevents save-scumming fully-healed resources.
```
