# REND_Instanced_Flora_Physics.md
## Mandated Technical Specification - Underwater Flora Instancing, Physics & Culling

---

## I. EXECUTION POLICY

[RULE] All flora tick logic executes inside `IJobParallelFor` with `[BurstCompile]` attribute. No exceptions.
[RULE] Zero managed heap allocations per frame. All persistent buffers pre-allocated at chunk load.
[RULE] Struct-of-Arrays (SoA) layout mandatory. No Array-of-Structs for GPU-bound data.
[RULE] `NativeArray<T>` with `Allocator.Persistent` for CPU-side. `GraphicsBuffer` with `GraphicsBuffer.Target.Structured` for GPU-side.
[REQ] Player-visible flora, coral, kelp, and instanced biome detail acceptance inherits the Visual Reference Parity Gate. Captures must beat mandatory references plus best-known internal baseline/current rejection matrix before density, sway, culling, or LOD work is credited.
[FORBID] `GetComponent`, `FindObjectOfType`, `SendMessage`, `Invoke`, `UnityEvent` in any per-frame path.
[FORBID] `Graphics.DrawMeshInstanced` and manual `Graphics.DrawMeshInstancedIndirect` dispatch. BatchRendererGroup / GPU Resident Drawer mandatory.
[FORBID] `new T[]` or `List<T>` during chunk streaming. Use pre-warmed `NativeArray` pools.
[FORBID] `GraphicsBuffer.GetData` per frame (CPU stall). Read-back only for debug builds behind `#if UNITY_EDITOR`.
[FORBID] Crediting flora optimization, culling, sway, or density when silhouettes, material truth, contact with terrain/water, route readability, or compact-tier composition remain below April/previously-in-development baseline. Declare `VISUAL_ROUTE_INVALID` and replace flora/material/placement owners first.

## I.A Unity 6000 GPU Resident Drawer Selection

[RULE] Flora that exists as authored GameObjects with `MeshRenderer` components uses Unity 6 GPU Resident Drawer first.
[RULE] Procedural flora emitted as pure data uses manual BRG only when there is no stable MeshRenderer ownership.
[RULE] GPU occlusion is enabled only with RenderGraph enabled, Forward+ active, compute shader support confirmed, and profiler proof that culling setup cost is lower than saved draw/vertex cost.

[FORBID] Maintaining a custom HiZ append-buffer culler for MeshRenderer-owned flora.
[FORBID] Uploading instance data for unchanged flora pages; page dirty flags are mandatory.
[FORBID] Static Batching on objects intended for GPU Resident Drawer batching.

## Engineering Data

| Ownership | Draw Path | Culling Owner | MX350 Rule |
|---|---|---|---|
| Authored MeshRenderer flora | GPU Resident Drawer | Unity GPU occlusion when proven | Use only for repeated meshes and occlusion-heavy zones |
| Procedural SoA flora | Manual BRG + custom compute cull | Flora system | Keep group size 64 until target capture proves otherwise |
| HLOD cards | GPU Resident Drawer where MeshRenderer-owned | Unity GPU occlusion | Prefer silhouette card over shader-heavy distant flora |

## II. DATA ARCHITECTURE

### II.A - CPU-Side Memory Layout (SoA, Cache-Aligned)

```
// Stride target: 64-byte cache-line aligned blocks per chunk
// Max instances per chunk: 4096 (configurable per biome tier)

NativeArray<float3>  flora_positions   // world XYZ root pivots
NativeArray<float>   flora_radii       // bounding sphere radius (scalar, not float3)
NativeArray<half2>   flora_uv_scale    // packed UV tiling per species (half = 2B each)
NativeArray<byte>    flora_species_id  // 0-255 species index -> shader variant LUT
NativeArray<byte>    flora_state_mask  // bitfield: see II.B
NativeArray<float>   flora_phase_seed  // per-instance random phase offset [0,2*pi]
```

**Interleaved GPU Instance Struct (written once at chunk load, read-only on GPU):**
```
struct FloraInstance  // 48 bytes, 16-byte aligned
{
    float3 worldPos;    // 12B - root pivot
    float  boundRadius; //  4B
    float4 rotation;    // 16B - quaternion (identity at spawn, updated by physics job)
    uint   packedData;  // 4B - bits[0:7]=speciesID, bits[8:11]=LODhint, bits[12:15]=stateMask, bits[16:31]=reserved
    float  phaseOffset; // 4B
    float  pad;         //  4B - explicit pad, no compiler surprise
}
// Total: 48B. Fits 1365 instances per 64KB L1 cache block.
```

### II.B - State Bitmask Layout (`flora_state_mask`, 8-bit)

```
Bit 0 (0x01): VISIBLE          - set by FloraCull.compute output
Bit 1 (0x02): PLAYER_CONTACT   - set by collision job when dist < playerRadius + floraRadius
Bit 2 (0x04): FLOW_ACTIVE      - FlowField magnitude at position > epsilon threshold
Bit 3 (0x08): ANCHORED         - rooted to terrain (vs. floating debris variant)
Bit 4 (0x10): HIGH_LOD         - distance < LOD_HIGH_THRESH
Bit 5 (0x20): ULTRA_LOD        - distance < LOD_ULTRA_THRESH
Bit 6 (0x40): DEAD             - culled permanently (eaten by creature, etc.)
Bit 7 (0x80): DIRTY            - GPU buffer needs re-upload this frame
```

### II.C - GPU Buffer Set (Per Active Chunk)

```
GraphicsBuffer instanceBuffer      // FloraInstance[], Structured - source of truth
GraphicsBuffer visibleIDBuffer     // uint[], Append/Structured - FloraCull output
GraphicsBuffer indirectArgsBuffer;
// Delegate culling and draw submission to Unity 6 BatchRendererGroup / GPU Resident Drawer
GraphicsBuffer flowFieldBuffer     // float4[], 3D linearized grid - shared global singleton
GraphicsBuffer playerDataBuffer    // float4[MAX_PLAYERS=4] - pos.xyz + radius.w
```

### II.D - Ring Buffer for Chunk Stream Data (Zero-GC Handoff)

```
// Pre-allocated at boot. Chunk loader writes into slots; GPU consumer reads.
// Never reallocated. No managed array ever created.

PRE_ALLOC: RingBuffer<NativeArray<FloraInstance>> chunkRing[RING_SIZE=8]
           int writeHead = 0, readHead = 0  // atomic int, Interlocked ops

ON_CHUNK_LOAD (worker thread):
  slot = Interlocked.Increment(writeHead) % RING_SIZE
  ASSERT chunkRing[slot].IsCreated == false OR slot != readHead  // overrun guard
  chunkRing[slot] = new NativeArray<FloraInstance>(count, Allocator.Persistent, NativeArrayOptions.UninitializedMemory)
  // Fill via Burst job - no managed intermediary
  Interlocked.Increment(writeHead)

ON_RENDER_TICK (main thread):
  if writeHead != readHead:
    Upload chunkRing[readHead] to instanceBuffer via SetData (one-time, not per-frame)
    Interlocked.Increment(readHead)
```

### II.E - MapMagic Zero-GC Position Handoff

**Problem:** MapMagic outputs `TransformData[]` (managed) per chunk. Bridging to GPU without GC pressure.

**Solution - UnsafeUtility Pin Pattern:**
```
ALGORITHM:
1. Hook MapMagic chunk callback (IMapMagicObject.Apply or custom ITileObject)
2. Receive managed TransformData[] once - unavoidable at boundary
3. Pin managed array: GCHandle handle = GCHandle.Alloc(managedArray, GCHandleType.Pinned)
4. IntPtr ptr = handle.AddrOfPinnedObject()
5. UnsafeUtility.MemCpy(nativeArray.GetUnsafePtr(), ptr.ToPointer(), byteCount)
6. handle.Free() - pin released immediately, no long-lived GC root
7. Managed array eligible for GC. Native copy now owns data.
8. Schedule Burst job on NativeArray - zero further managed access
```

**Constraint:** Step 2-6 happens ONCE per chunk load event, not per frame. Acceptable boundary cost.

## III. ALGORITHMIC & MATH TRUTH

### III.A - FloraCull.compute: Frustum Culling Logic

**Input:** `StructuredBuffer<FloraInstance> _Instances`, `float4 _FrustumPlanes[6]`, `uint _InstanceCount`

**Frustum Plane Encoding:**
```
// Each plane: float4(normal.x, normal.y, normal.z, d)
// Convention: d = -dot(normal, pointOnPlane)
// Inside condition: dot(normal, center) + d > -radius
// i.e., signed distance from plane to sphere center > -radius
```

**Cull Kernel Logic (1 thread per instance, group 64):**
```
threadID = SV_DispatchThreadID.x
if threadID >= _InstanceCount: return

inst = _Instances[threadID]
center = inst.worldPos
r = inst.boundRadius

visible = true
for p in 0..5:
    dist = dot(_FrustumPlanes[p].xyz, center) + _FrustumPlanes[p].w
    if dist < -r:
        visible = false
        break  // early exit - hemisphere test optimization

if visible:
    _VisibleIDs.Append(threadID)
```

**Dispatch formula:**
```
dispatchX = ceil(instanceCount / 64.0)  // ThreadGroupSize = (64,1,1)
```

**SENIOR_HACK - Hierarchical Cull (MX350 ALU budget):**
```
// Pre-sort instanceBuffer by morton code (z-order) at chunk load.
// Run coarse 4x4x4 grid cull first (1 thread per grid cell).
// Only dispatch fine cull for cells that pass coarse test.
// Reduces fine cull thread count by ~70% in typical dense flora scenes.
// Morton code generation (offline, at chunk spawn):

mortonEncode3D(x,y,z):  // x,y,z are 10-bit integers (0-1023)
    x = (x | x<<16) & 0x030000FF
    x = (x | x<<8)  & 0x0300F00F
    x = (x | x<<4)  & 0x030C30C3
    x = (x | x<<2)  & 0x09249249
    // repeat for y, z with 1-bit and 2-bit shifts respectively
    return x | (y<<1) | (z<<2)
```

### III.C - FlowField Bending: HLSL Vertex Shader Math

**FlowField Data:**
```
// _MarineSnowFlowField: Texture3D<float4> OR StructuredBuffer<float4>
// Convention: rgb = flow direction (world space, normalized), a = magnitude [0,1]
// Resolution: 32x32x32 per chunk (32KB as R16G16B16A16_Float)
```

**Vertex Shader Bending Logic:**
```
// Input: vertex worldPos, uv.y = [0=root, 1=tip], phaseOffset, time

// 1. Compute root pivot (stationary point)
rootPivot = float3(instanceData.worldPos.x, instanceData.worldPos.y, instanceData.worldPos.z)

// 2. Sample FlowField at root pivot (trilinear, no aniso needed)
float3 gridUVW = (rootPivot - _FlowFieldOrigin) / _FlowFieldExtents  // normalize to [0,1]
float4 flow = _MarineSnowFlowField.SampleLevel(sampler_linear_clamp, gridUVW, 0)
float3 flowDir = flow.rgb  // already normalized in buffer
float  flowMag = flow.a    // [0,1]

// 3. Influence factor - root is pinned, tip bends fully
float influence = uv.y * uv.y  // quadratic falloff: tip bends ~4x more than mid

// 4. Temporal oscillation (cheap sinusoidal sway)
float wave = sin(_Time.y * _FloraSwayFreq + phaseOffset) * _FloraSwayAmplitude
float totalMag = flowMag * _FlowBendScale + wave

// 5. Rodrigues rotation around up-axis perpendicular to flow
// Rotate vertex around root pivot by angle theta in flow direction plane
// theta = totalMag (radians, clamped)
float theta = clamp(totalMag * influence, -_MaxBendAngle, _MaxBendAngle)

// Rodrigues formula: v_rot = v*cos(theta) + (kxv)*sin(theta) + k*(k-v)*(1-cos(theta))
// k = rotation axis = normalize(cross(float3(0,1,0), flowDir))
// If flowDir == (0,1,0): k = float3(1,0,0) fallback

float3 k = normalize(cross(float3(0,1,0), flowDir) + float3(1e-5,0,0))  // NaN guard
float3 relV = vertex.xyz - rootPivot
float sinT = sin(theta);
float cosT = cos(theta);
float3 bent = relV*cosT + cross(k,relV)*sinT + k*dot(k,relV)*(1-cosT)
vertex.xyz = bent + rootPivot
```

**Numerical Guards:**
```
// Pre-check before Rodrigues:
if dot(flowDir, flowDir) < 1e-6: flowDir = float3(0,0,1)  // zero flow fallback
theta = isnan(theta) || isinf(theta) ? 0.0 : theta         // NaN/Inf kill
```

### III.D - Player Collision Displacement: HLSL Logic

**Player buffer:**
```
// float4 _PlayerData[4]: xyz = world position, w = interaction radius
// Upload via GraphicsBuffer.LockBufferForWrite + UnsafeUtility.MemCpy - zero-copy, zero GC
```

**Vertex shader displacement (runs after FlowField bending):**
```
// Accumulate displacement from all active players
float3 totalDisplace = float3(0,0,0)

for i in 0..3:  // unrolled by compiler - static count
    float3 playerPos = _PlayerData[i].xyz
    float  playerRad = _PlayerData[i].w
    if playerRad < 0.001: continue  // inactive slot

    float3 delta = vertex.xyz - playerPos
    delta.y = 0  // horizontal push only - prevent lifting flora off terrain
    float dist = length(delta) + 1e-5  // epsilon prevents /0

    // Smooth step decay: full push at dist=0, zero at dist=playerRad*2
    float influence = 1.0 - smoothstep(playerRad * 0.5, playerRad * 2.0, dist)
    influence *= uv.y  // root stays pinned

    // Push radially outward, magnitude proportional to proximity
    float pushMag = influence * _PlayerPushStrength / dist
    totalDisplace += delta * pushMag

// Clamp total displacement - prevent degenerate geometry at zero dist
float dispLen = length(totalDisplace)
if dispLen > _MaxDisplacement:
    totalDisplace = totalDisplace / dispLen * _MaxDisplacement

vertex.xyz += totalDisplace
```

**SENIOR_HACK - Fast `length` approximation for MX350 ALU:**
```
float3 delta = vertex - playerPos
float dist = math.length(delta); // Let Burst use RSQRTPS intrinsic
float3 dir = delta / max(dist, 1e-5)
// [FORBID] Manual rsqrt cargo cult. Use the hardware path.
```

### III.E - LOD Distance Math (CPU-Side Burst Job)

```
// Run once per frame, time-sliced (see IV.B)
// Per instance:

float3 toCam = cameraPos - flora_positions[i]
float distSq = dot(toCam, toCam)  // avoid sqrt - compare squared thresholds

const float LOD_HIGH_SQ  = LOD_HIGH_DIST  * LOD_HIGH_DIST   // e.g. 15^2 = 225
const float LOD_ULTRA_SQ = LOD_ULTRA_DIST * LOD_ULTRA_DIST  // e.g. 8^2  = 64

byte mask = flora_state_mask[i]
mask &= ~(0x10 | 0x20)  // clear LOD bits
if distSq < LOD_ULTRA_SQ: mask |= 0x30   // ULTRA implies HIGH
else if distSq < LOD_HIGH_SQ: mask |= 0x10
flora_state_mask[i] = mask
```

### III.F - Numerical Stability Contracts

```
// FlowField magnitude clamp:
flowMag = clamp(flow.a, 0.0, 1.0)

// Bend angle clamp (prevent gimbal/degenerate geometry):
_MaxBendAngle default = 0.52 rad (~30 deg). Hard cap in shader: min(|theta|, 0.78) -> 45 deg absolute

// Phase offset: generated at spawn via seed:
phaseOffset = frac(sin(instanceID * 127.1 + chunkSeed * 311.7) * 43758.5) * TWO_PI
// Goldbacher-style hash - uniform distribution, no clustering

// Player dist guard: if distSq < 0.0001 (player inside pivot):
// override delta = float3(1,0,0) * 0.01 - deterministic push direction
```

## IV. HARDWARE & SCALABILITY

### IV.A - MX350 VRAM Budget (2GB Hard Limit)

```
Budget allocation for flora system:
  FloraInstance buffer (4096 * 48B * 16 active chunks) = ~3MB      [OK]
  VisibleID buffer     (4096 * 4B  * 16 chunks)        = ~256KB    [OK]
  IndirectArgs buffer  (5 * 4B     * 16 chunks)        = ~320B     [OK]
  FlowField Texture3D  (32^3 * 8B R16G16B16A16)         = ~512KB    [OK] (global singleton)
  Total flora VRAM: ~4MB

  Enforce: If VRAM_Available < 256MB (emergency threshold):
    Reduce max active chunks: 16 -> 8
    Reduce max instances/chunk: 4096 -> 2048
    Downscale FlowField: 32^3 -> 16^3 (halves to 64KB)
```

### IV.B - Time-Slicing CPU Budget

```
// Spread per-chunk updates across N frames to flatten CPU spike

frameBudget_ms = 1.5  // max flora CPU time per frame on i3-10gen
chunkUpdateBudgetPerFrame = floor(frameBudget_ms / avgChunkUpdateCost_ms)

// Frame scheduling:
frame 0: Cull dispatch + IndirectArgs copy (always, every frame)
frame 1: LOD update job (Burst, time-sliced)
frame 2: State mask propagation (dirty flag resolution)
frame 3: Player data buffer upload (LockBufferForWrite + MemCpy)
frame 0: [cycle repeats]

// Player buffer upload: only if player moved > 0.05m since last upload
// Dirty check: if dot(posDelta, posDelta) < 0.0025: skip buffer map
// Zero-copy async write mapping
var ptr = buffer.LockBufferForWrite<FloraInstance>(0, count);
UnsafeUtility.MemCpy(ptr.GetUnsafePtr(), nativeArray.GetUnsafePtr(), byteCount);
buffer.UnlockBufferAfterWrite<FloraInstance>(count);
```

### IV.C - LOD Tier Definitions

```
BASE (< MX350 min, software fallback):
  - No vertex bending. Static instances.
  - Cull only. IndirectDraw active.
  - No player interaction.
  - FlowField disabled.

HIGH (MX350 standard):
  - Frustum cull + FlowField bending active.
  - Player displacement: 1 player slot only.
  - FlowField sample: trilinear, 32^3.
  - Sway oscillation: 1 frequency term.

ULTRA (RTX-class):
  - All 4 player slots active.
  - FlowField: 64^3, bicubic sample.
  - Sway: 3 frequency terms (wind harmonics).
  - LOD_ULTRA_DIST = 12m (vs HIGH: 20m).
  - Vertex bending applies to sub-geometry (individual frond segments).
```

### IV.D - Dispatch & Draw Call Budget

```
Per active chunk per frame:
  1x Compute dispatch: FloraCull.compute
  1x GraphicsBuffer.CopyCount
  1x BatchRendererGroup / GPU Resident Drawer submission

Total for 16 chunks: native GPU culling, native draw submission
CPU driver overhead target: remove manual DrawMeshInstancedIndirect dispatch entirely
Group by species/material so GPU Resident Drawer keeps total submissions < 8
```

### V.B - Failure Mode Catalog

```
FAILURE: speed > 40 m/s (submarine boost / debug noclip)
  SYMPTOM: Player displacement delta exceeds shader _MaxDisplacement in single frame
  GUARD: In IFloraPlayerInterface.GetPlayerData - clamp playerPos velocity contribution.
         Previous frame pos stored. delta clamped: if |posDelta| > 2.0m: lerp toward newPos at rate 2m/frame
  RESULT: Flora bends catch up smoothly, no geometry explosion

FAILURE: depth > 4km (depth value exceeds FlowField Z extent)
  SYMPTOM: gridUVW.z > 1.0 -> sampler_clamp returns boundary value. Flow artifacts.
  GUARD: clamp(gridUVW, 0.001, 0.999) in shader - explicit, not relying on sampler state
  RESULT: Constant boundary flow value. Acceptable deep-ocean stillness. Intentional fallback.

FAILURE: instanceCount = 0 (empty chunk / all culled)
  SYMPTOM: GPU Resident Drawer submission with 0 visible instances
  GUARD: No guard needed - indirectArgs[1] = 0 after GraphicsBuffer.CopyCount. Valid API behavior.

FAILURE: GraphicsBuffer not initialized (chunk still loading)
  GUARD: IFloraChunkProvider.TryGetChunkInstanceBuffer returns false
         Dispatcher skips dispatch for that chunk. No null deref, no exception.
         Frame skip budget: max 4 frames before chunk considered failed -> log warning only.

FAILURE: FlowField GPU buffer null (first frame / biome without flow)
  GUARD: Shader-side: if _FlowFieldExtents.x < 0.001: flowMag = 0.0, skip bending.
         CPU-side: _FlowFieldExtents set to float3(1,1,1) as sentinel -> shader detects.

FAILURE: NativeArray disposed mid-frame (race condition, worker teardown)
  GUARD: All NativeArray usage behind AtomicSafetyHandle (Unity enforces in editor).
         In release: ChunkID validity mask (NativeHashSet<ChunkID> activeChunks).
         Unload only after IsDispatchComplete confirmed via GPUFence / AsyncGPUReadback dummy.

FAILURE: VRAM OOM (> 1.8GB used, MX350 swaps to system RAM)
  DETECT: SystemInfo.graphicsMemorySize runtime check at boot.
          Threshold: if freeVRAM < 128MB: reduce to BASE tier immediately.
  ACTION: IFloraCullDispatcher.SetQualityTier(FloraQuality.Base) - zero-alloc state change.
          Existing buffers not released mid-frame. Take effect next chunk load cycle.

FAILURE: Rodrigues rotation with flowDir = (0,1,0) exactly (vertical flow)
  SYMPTOM: cross(float3(0,1,0), float3(0,1,0)) = float3(0,0,0) -> normalize -> NaN
  GUARD: k = normalize(cross(up, flowDir) + float3(1e-5, 0, 0))
         Epsilon bias guaranteed non-zero cross product. Bias magnitude < visual threshold.
```
