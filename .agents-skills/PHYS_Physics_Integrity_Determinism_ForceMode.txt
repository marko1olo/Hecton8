## 0. FIXED TIMESTEP CONTRACT
- [RULE] `Time.fixedDeltaTime = 0.02f` (50Hz). Immutable. No runtime modification permitted.
- [RULE] `Time.maximumDeltaTime = 0.05f`. Caps spiral-of-death. Physics never processes >2.5 steps per visual frame.
- [RULE] `Time.timeScale` changes route through `PhysicsTimeScaleGate`. Gate validates: clamp [0.05, 2.0], flush velocity accumulators, reset drag integrals.
- [FORBID] `FixedUpdate` logic dependent on `Time.deltaTime`. Use `Time.fixedDeltaTime` constant reference only.
- [FORBID] Coroutines driving physics state. Physics state = FixedUpdate-only domain.
- [SENIOR_INJECT] Implement `PhysicsAccumulator` pattern: track `_accumulator += unscaledDelta`, consume in discrete 0.02s chunks. Prevents sub-step aliasing on variable-framerate hosts.
csharp
// PhysicsAccumulator — zero-alloc, deterministic sub-step guard
private const float FIXED_STEP = 0.02f;
private float _accumulator;
void Update() {
    _accumulator += Time.unscaledDeltaTime;
    _accumulator = math.min(_accumulator, FIXED_STEP * 3f); // spiral clamp
}

## 1. EXECUTION POLICY
### 1.1 ForceMode Doctrine
| Context | Mode | Rationale |
|---|---|---|
| Ocean current, water drag | `Force` | Mass-dependent, sustained, per-fixedDelta |
| Thruster, gravity override | `Acceleration` | Mass-independent, uniform response |
| Explosion, impact, sonar pulse recoil | `Impulse` | Instantaneous, mass-scaled |
| Kinematic weld-snap correction | `VelocityChange` | Direct velocity override, bypass mass |
- [FORBID] `ForceMode.Force` for instantaneous effects. Timestep-dependent = unstable at hitches.
- [FORBID] `ForceMode.Impulse` for sustained thrust. Accumulates incorrectly across variable step counts.
### 1.2 Transform Mutation Policy
- [FORBID] `transform.position = ...` on any object with active `Rigidbody`. Physics broadphase corruption.
- [FORBID] `transform.rotation = ...` on active Rigidbody. Use `rb.MoveRotation`.
- [RULE] Position changes: `rb.MovePosition` gated by sweep (see §4.1).
- [RULE] Kinematic wrecks / set-dressing: allowed `transform` mutation only while `rb.isKinematic == true` AND `rb.detectCollisions == false`.
- [SENIOR_INJECT] Teleport protocol for respawns/checkpoints:
csharp
void TeleportBody(Rigidbody rb, Vector3 target, Quaternion rot) {
    rb.isKinematic = true;
    rb.detectCollisions = false;
    rb.transform.SetPositionAndRotation(target, rot);
    rb.linearVelocity = Vector3.zero;
    rb.angularVelocity = Vector3.zero;
    rb.isKinematic = false;
    rb.detectCollisions = true;
}
### 1.3 GC-Zero Hot Path Contract
- [FORBID] `new` keyword inside `FixedUpdate`, `OnCollisionStay`, `OnTriggerStay`.
- [FORBID] LINQ operators anywhere in physics execution chain.
- [FORBID] String operations, `Debug.Log`, boxing of value types in hot path.
- [FORBID] `GetComponent<T>()` in FixedUpdate. Cache all references `Awake`.
- [RULE] Collections: `NativeArray`, `NativeList`, or pre-allocated managed arrays only.
- [RULE] Event dispatch from physics: queue `PhysicsEvent` structs into pre-allocated `FixedCircularBuffer<PhysicsEvent>`. Process in `LateUpdate`. Zero cross-thread allocation.
csharp
// FixedCircularBuffer — stack-allocated ring, zero GC
public struct FixedCircularBuffer<T> where T : struct {
    private T[] _buffer;
    private int _head, _tail, _count;
    private readonly int _capacity;
    public FixedCircularBuffer(int capacity) {
        _capacity = capacity;
        _buffer = new T[capacity]; // ONE alloc at init
        _head = _tail = _count = 0;
    }
    public void Enqueue(T item) {
        _buffer[_tail] = item;
        _tail = (_tail + 1) % _capacity;
        _count = math.min(_count + 1, _capacity);
    }
    public bool TryDequeue(out T item) {
        if (_count == 0) { item = default; return false; }
        item = _buffer[_head];
        _head = (_head + 1) % _capacity;
        _count--;
        return true;
    }
}

## 3. ALGORITHMIC & MATH TRUTH
### 3.1 Quadratic Drag — Analytical Solution
- [FORBID] Euler-step drag: `v -= k * v * v * dt`. Unstable below 20 FPS. Produces velocity reversal.
- [RULE] Analytical solution mandatory:
csharp
// Quadratic drag — analytical, timestep-stable, no reversal
// v(t) = v0 / (1 + k * |v0| * dt)
// Applied per-axis independently for directional drag coefficients
[MethodImpl(MethodImplOptions.AggressiveInlining)]
private static float3 AnalyticalDrag(float3 v0, float3 k, float dt) {
    float3 speed = new float3(math.abs(v0.x), math.abs(v0.y), math.abs(v0.z));
    float3 denom = 1f + k * speed * dt;
    return v0 / math.max(denom, 0.001f); // guard zero-divide
}
- [SENIOR_INJECT] Separate drag coefficients per-axis. Underwater: high lateral drag (vehicle feels planted), lower vertical (allows sinking). Expose as `DragProfile` ScriptableObject per vehicle class.
### 3.2 Anti-NaN Protocol
- [RULE] Every `rb.linearVelocity` assignment preceded by finite check.
- [RULE] Every `rb.AddForce` call validates force vector finite.
csharp
[MethodImpl(MethodImplOptions.AggressiveInlining)]
private static bool IsVelocitySafe(float3 v) =>
    math.isfinite(v.x) & math.isfinite(v.y) & math.isfinite(v.z);
[MethodImpl(MethodImplOptions.AggressiveInlining)]
private static float3 SafeVelocity(float3 v, float3 fallback = default) =>
    IsVelocitySafe(v) ? v : fallback;
// Usage pattern — mandatory before every velocity write:
float3 candidate = ComputeNewVelocity();
if (!IsVelocitySafe(candidate)) {
    _stateFlags |= PhysicsStateMask.NaNDetected;

rb.linearVelocity = candidate;
- [SAFE] NaN Recovery Protocol:
  - Zero all velocities.
  - Teleport to last-known-good position (ring buffer of 3 positions, updated every 30 fixed frames).
  - Log `PhysicsEvent { type=NaNRecovery, entityID, frame }` to circular buffer.
  - Emit debug metric. Never crash. Never freeze.

### 3.4 Neutral Buoyancy Deadzone
csharp
// Kill micro-jitter when net force approaches zero
// Applied in FixedUpdate after all force accumulation
private const float BUOYANCY_DEADZONE_N = 2f;       // N
private const float BUOYANCY_DEADZONE_VEL = 0.05f;  // m/s
void ApplyNeutralBuoyancyDeadzone(Rigidbody rb, float3 netForce) {
    float netMag = math.length(netForce);
    float velMag = math.length((float3)rb.linearVelocity);
    if (netMag < BUOYANCY_DEADZONE_N && velMag < BUOYANCY_DEADZONE_VEL) {
        rb.linearVelocity = Vector3.zero;
        rb.angularVelocity = Vector3.zero;
        // Do NOT use Sleep() — prevents buoyancy re-activation on current change
    }
}
- [SENIOR_INJECT] Hysteresis band: deadzone activates at <2N, deactivates at >4N. Prevents rapid toggle (flickering) at threshold boundary.
### 3.5 Water Entry / Exit Transition Math
- [RULE] Buoyancy force: `F_b = ρ_water * V_submerged * g`. Compute `V_submerged` via discrete vertical sample points (4–8 points per object), not per-frame mesh intersection.
- [SENIOR_INJECT] Smooth buoyancy transition using signed distance to water surface. Remap [-0.5m, +0.5m] → [0, 1] submersion factor. Apply `math.smoothstep`. Eliminates pop on entry.
csharp
[MethodImpl(MethodImplOptions.AggressiveInlining)]
private static float SubmersionFactor(float distToSurface) =>
    math.smoothstep(0.5f, -0.5f, distToSurface); // 1 = fully submerged
- [RULE] `AddedMassTerm`: fluid adds effective inertia to submerged body. Multiply angular damping by `(1f + 0.3f * submersionFactor)`. Submerged turns feel heavier.
### 3.6 Pressure-Depth Physics
- [RULE] Compute pressure as `P = P_atm + ρ * g * depth`. Expose as `float PhysicsEnvironment.GetPressure(float depth)`.
- [RULE] Crush threshold per-object defined in `StructuralIntegrity` component. Crossing threshold triggers `OnCrushEvent`. No inline calculation.
- [SENIOR_INJECT] Pressure affects drag coefficient. Deep water = higher effective viscosity. Scale `k_drag` by `math.log(1f + depth / 100f)` (diminishing returns, asymptotic).

## 4. HARDWARE & SCALABILITY
### 4.1 Sweep Gating — Mandatory MovePosition Protocol
csharp
private const float SKIN_WIDTH = 0.02f;
bool TrySweepGatedMove(Rigidbody rb, CapsuleCollider cap, Vector3 delta) {
    Vector3 p1, p2;
    GetCapsulePoints(rb.transform, cap, out p1, out p2);
    float dist = delta.magnitude;
    Vector3 dir = delta / math.max(dist, 0.0001f);

    PhysicsBuffers.SweepCommands[0] =
        new CapsulecastCommand(p1, p2, cap.radius, dir, dist + SKIN_WIDTH,
            PhysicsLayers.Static | PhysicsLayers.Terrain, QueryTriggerInteraction.Ignore);

    JobHandle handle = CapsulecastCommand.ScheduleBatch(
        PhysicsBuffers.SweepCommands,
        PhysicsBuffers.SweepResults,
        1,
        default);

    // Interleave other fixed-step systems here. Block only when movement resolution is required.
    handle.Complete();

    if (PhysicsBuffers.SweepResults[0].distance > 0f) {
        float safeDistance = PhysicsBuffers.SweepResults[0].distance - SKIN_WIDTH;
        if (safeDistance > 0.001f)
            rb.MovePosition(rb.position + dir * safeDistance);
        return false;
    }

    rb.MovePosition(rb.position + delta);
    return true;
}
- [FORBID] `MovePosition` without preceding sweep on dynamic bodies in motion >0.5 m/s.
- [RULE] Kinematic wrecks exempt from sweep (static by definition, already in broadphase).

## 6. WEIGHTINESS DOCTRINE
### 6.1 Perceived Mass Principles
- [RULE] Mass ≠ perceived weight. Mass is physics parameter. Weight = mass + drag + response latency.
- [RULE] Player vehicle minimum mass: 800kg. Heavy feel mandatory. Adjust thruster force to compensate, not mass downward.
- [RULE] Rotation response: angular drag 3.5–5.0 for submarine class. Sluggish turn = weight perception.
- [SENIOR_INJECT] "Inertial Ghost" pattern: cache velocity 3 frames prior. Blend actual velocity with ghost velocity at 15%. Adds perceptual momentum without increasing mass.
csharp
// Inertial Ghost — perceived momentum enhancement
private float3[] _velHistory = new float3[4];
private int _velHistIdx = 0;
void FixedUpdate() {
    _velHistory[_velHistIdx % 4] = (float3)rb.linearVelocity;
    _velHistIdx++;
    float3 ghost = _velHistory[(_velHistIdx + 1) % 4]; // 3-frame-old vel
    float3 perceived = math.lerp((float3)rb.linearVelocity, ghost, 0.15f);
    // Feed perceived velocity to audio/haptic/VFX systems — NOT to physics
    PhysicsEventBus.Post(new PhysicsEvent {
        type = PhysicsEventType.Impact,
        magnitude = math.length(perceived)
    });
}
### 6.2 Thruster Force Scaling
- [RULE] Thruster force = `mass * targetAcceleration`. Compute from desired 0→max_speed time.
- [RULE] Desired: 0 → 8 m/s in 4 seconds = 2 m/s² × 800kg = 1600N per thruster axis.
- [RULE] Thruster ForceMode: `Acceleration`. Mass-independent scaling. Simplifies tuning.
- [SENIOR_INJECT] Thruster response curve: map input [0,1] → force via `AnimationCurve`. Non-linear feel. Exponential ramp for immersion. Expose per vehicle profile.
### 6.3 Impact Weight Feedback
- [RULE] Impact sound/haptic intensity = `math.log10(1f + impactForce / 100f)`. Log scale prevents tiny taps and catastrophic hits both mapping to max output.
- [RULE] Camera shake on impact: drive `ShakeIntensity = impactForce / (rb.mass * 50f)`. Heavier vehicles shake less. Weight-consistent.
- [FORBID] Linear impact → feedback mapping. Perceptually wrong. Log or sqrt scale only.

     PhysicsApplySystem.Flush() ← drains ALL ForcePacket queues
         SafeVelocity() validation
         NeutralBuoyancyDeadzone()
         SweepGate (if MovePosition needed)
         PhysicsEventBus.Post() (impact, NaN, state changes)
         Native contact job / overlap polling handles collisions
LateUpdate:
     PhysicsEventBus.Poll() → AudioSystem, VFXSystem, HapticSystem, UISystem
- [RULE] Dependency direction: one-way. Audio/VFX/UI never writes to physics. Physics never reads from render systems.
- [FORBID] Circular dependencies across physics subsystem boundaries.
