## [Section2] IBootstrapStep CONTRACT

INTERFACE IBootstrapStep:
  int     Priority          -> sort key (ascending = earlier)
  string  StepID            -> unique string token (e.g. "TICK_MANAGER")
  bool    IsCritical        -> true = failure halts boot
  float   TimeoutSeconds    -> per-step watchdog limit

  ExecuteAsync() -> Awaitable   -> Unity 6 allocation-free async execution
  Validate()    -> bool         -> post-execute integrity check

REGISTRATION FLOW:
  BootstrapOrchestrator.Register(IBootstrapStep step)
    -> insert into SortedList<int, IBootstrapStep> by Priority
    -> duplicate Priority = ASSERT_FAIL("PRIORITY_COLLISION: {StepID}")

EXECUTION LOOP (pseudo):
  FOREACH step IN sorted_queue:
    START watchdog_timer(step.TimeoutSeconds)
    await step.ExecuteAsync()
    CANCEL watchdog
    IF NOT step.Validate():
      IF step.IsCritical: INJECT_FATAL(0xB007_0002, step.StepID)
      ELSE: LOG_WARN + SKIP

## [Section3] LAZY SINGLETON GUARD - LOGIC KERNEL

PATTERN: Double-Checked Locking + Frame-Safe EnsureInitialized

ACCESS RULE:
  T Instance:
    IF _instance == null:
      EnsureInitialized()           -> scene-safe search + create
    RETURN _instance

EnsureInitialized() LOGIC:
  LOCK(_lock_object):
    IF _instance != null: RETURN     -> second check inside lock
    _instance = FindObjectOfType<T>()
    IF _instance == null:
      IF !BootstrapOrchestrator.HasCompleted(StepID):
        THROW InvalidOperationException("PREMATURE_ACCESS: {T.Name}")
      _instance = new GameObject($"[{T.Name}]").AddComponent<T>()
      DontDestroyOnLoad(_instance.gameObject)

FORBID:
  Awake() -> NO dependency calls to other managers
  Awake() -> NO third-party SDK init
  Awake() -> ONLY self-state allocation (arrays, pools, local fields)

## [Section5] SHADER WARMUP EXECUTOR - LOGIC KERNEL

TIMING: Execute during SPLASH SCREEN (P4 window, min 2.5s guaranteed display)

WARMUP SEQUENCE:
  1. Load ShaderVariantCollection asset (addressable, preloaded):
       handle = Addressables.LoadAssetAsync<ShaderVariantCollection>("SVC_Core")
       await handle.Task.AsAwaitable()

  2. Validate integrity:
       IF handle.Result == null: INJECT_FATAL(0xB007_0010, "SVC_NULL")
       hash_check = ValidateSVCHash(handle.Result, BuildManifest.SVCHash)
       IF NOT hash_check: LOG_WARN("SVC_HASH_MISMATCH") + USE_FALLBACK_SVC

  3. Execute warmup (non-blocking via frame spread):
       svc = handle.Result
       // [FORBID] Synchronous Shader Warmup.
       // You MUST use Unity 6's background shader prewarming APIs or render a dummy camera over several frames.
       for frame in 0..2:
           RenderWarmupDummyCamera()
           await Awaitable.NextFrameAsync()

  4. Post-warmup stall guard:
       await Awaitable.NextFrameAsync()
       await Awaitable.NextFrameAsync()

  5. Dispose handle reference; retain svc ref for runtime lookup

VRAM GUARD (MX350 <= 1800MB):
  IF TIER == TIER_MX350:
    BEFORE WarmUp(): force Texture2D budget to 512MB
    AFTER  WarmUp(): restore TextureStreamingBudget = 768MB
    CALL   BootstrapEvictQueue.DrainSynchronously()
    GC.Collect(0, GCCollectionMode.Optimized)

## [Section6] VERSION AUDIT & SAVE MIGRATION

BUILD_ID VALIDATION (executes at P0):
  stored_id  = PlayerPrefs.GetString("BUILD_ID", "NONE")
  current_id = Application.version + "_" + BuildManifest.CommitHash[..8]

  IF stored_id != current_id:
    FLAG: build_changed = true
    PlayerPrefs.SetString("BUILD_ID", current_id)

SAVE VERSION MIGRATION (executes at P2 / SaveManager):
  save_header = DeserializeHeader(save_path)    -> read first 64 bytes only

  MIGRATION_MATRIX:
    save_header.version == current_save_version -> LOAD_DIRECT
    save_header.version <  current_save_version -> PROMPT_MIGRATE
    save_header.version >  current_save_version -> BLOCK + ERROR_UI("FUTURE_SAVE")

  PROMPT_MIGRATE FLOW:
    Show modal: "Save format v{old} -> v{new}. Backup created. Continue?"
    ON_CONFIRM:
      backup_path = save_path + ".bak." + DateTime.UtcNow.Ticks
      File.Copy(save_path, backup_path)
      RunMigrationChain(save_header.version, current_save_version, save_data)
    ON_DENY:
      Load clean new-game state; archive old save

  MIGRATION_CHAIN PATTERN (version-step pipeline):
    FOREACH migrator IN MigrationRegistry WHERE version IN [old..new]:
      data = migrator.Transform(data)    -> pure data transform, no MonoBehaviour
    Serialize(data) -> overwrite save_path

  CORRUPTION GUARD:
    checksum_stored  = save_header.CRC32
    checksum_computed = CRC32(save_body_bytes)
    IF mismatch: BLOCK_LOAD + ERROR_UI("SAVE_CORRUPT") + OFFER_BACKUP_RESTORE

## [Section7] SCENE TRANSITION LOGIC - ATOMIC SEQUENCE

TRANSITION_STATE_MACHINE:
  States: IDLE | FADING | LOCKED | LOADING | UNLOADING | FINALIZING

STEP SEQUENCE (blocking per step):
  1. FADING:
       await ScreenFader.FadeOutAsync(duration: 0.35s, curve: EaseIn)

  2. LOCKED:
       InputManager.LockAll()
       EventSystem.enabled = false

  3. LOADING:
       op = SceneManager.LoadSceneAsync(target, LoadSceneMode.Single)
       await op
       // For local streamed content: use `UnityEngine.Object.InstantiateAsync(prefab)`.
       // Let Unity timeslice Awake/OnEnable work instead of manual load gating.

  4. UNLOADING:
       StreamLeaseRegistry.ReleaseSceneLeases(target)
       EvictQueue.DrainSynchronously()
       GC.Collect(1, GCCollectionMode.Forced)
       await Awaitable.NextFrameAsync()
       await Awaitable.NextFrameAsync()

  5. FINALIZING:
       InputManager.UnlockAll()
       EventSystem.enabled = true
       await ScreenFader.FadeInAsync(duration: 0.25s, curve: EaseOut)
       state = IDLE

VRAM FLUSH (MX350 critical path, between steps 3->4):
  IF TIER == TIER_MX350 OR TIER_LOW:
    TextureStreamingManager.SetBudget(256MB)   -> force eviction
    await Awaitable.NextFrameAsync()
    TextureStreamingManager.SetBudget(preset.TextureStreamingBudget)

## [Section8] FATAL HALT - "BIOS ERROR" UI PROTOCOL

FATAL_HALT TRIGGER CONDITIONS:
  - IsCritical step Validate() == false
  - Step timeout exceeded (watchdog fires)
  - VRAM < 1800MB (cannot meet minimum)
  - Save CRC32 mismatch with no backup
  - ShaderVariantCollection null

HALT SEQUENCE:
  1. FREEZE: Time.timeScale = 0; Physics.autoSimulation = false
  2. INPUT_KILL: InputManager.HardKillAll() (bypass lock queue)
  3. BIOS_UI:
       Activate HardwareErrorCanvas (always loaded, never unloaded, DontDestroyOnLoad)
       Display:
         ERROR_CODE: 0x{code:X8}
         SUBSYSTEM:  {step_id}
         DETAIL:     {msg}
         RAM_FREE:   {SystemInfo.systemMemorySize}MB
         VRAM_FREE:  {SystemInfo.graphicsMemorySize}MB
         BUILD:      {Application.version}_{CommitHash[..8]}
         ACTION:     "Restart Application / Report"
  4. LOG_FLUSH:
       Debug.LogError -> write to Application.persistentDataPath/crash_{timestamp}.log
       Include: full step execution timeline, hardware profile, exception stack
  5. HALT:
       WHILE true: await Awaitable.NextFrameAsync()   -> preserve UI, block all game logic
       ON_QUIT_BUTTON: Application.Quit(-1)

RECOVERY_OPTION (non-critical subsystems only):
  IF !step.IsCritical AND halt_not_triggered:
    FallbackRegistry.Activate(step.StepID)   -> inject stub/null-object
    LOG_WARN("FALLBACK_ACTIVE: {step.StepID}")
    CONTINUE boot sequence

## [Section9] TICK MANAGER - CORE TEMPORAL CONTRACT

DUAL TICK ARCHITECTURE:
  FixedTick  (physics/simulation): 50Hz default -> 20Hz on CPU_LIGHT
  VariableTick (rendering/input):  uncapped -> capped 60fps on TIER_MX350

REGISTRATION KERNEL:
  ITickable.OnFixedTick(float fixedDt)
  ITickable.OnVariableTick(float dt, float alpha)   -> alpha = physics interpolation

ALPHA FORMULA (render interpolation):
  alpha = (Time.time - Time.fixedTime) / Time.fixedDeltaTime
  -> clamp(alpha, 0.0, 1.0)
  -> apply to transform lerp: pos = Vector3.LerpUnclamped(prev_pos, curr_pos, alpha)

BUDGET ENFORCEMENT (CPU_LIGHT):
  fixedHz_actual = 1.0 / Time.fixedDeltaTime
  IF fixedHz_actual > 20.0 AND CPU_TIER == CPU_LIGHT:
    Time.fixedDeltaTime = 0.05f   -> force 20Hz
    LOG_WARN("TICK_THROTTLE: CPU_LIGHT 20Hz enforced")

PRIORITY TIERS (execution order within tick):
  [T0] Ocean simulation (FFT advance)
  [T1] Physics pre-step (buoyancy, pressure)
  [T2] AI perception + pathing
  [T3] Player controller
  [T4] Camera
  [T5] Audio spatial update
  [T6] UI world-space sync

## [Section10] OCEAN + TERRAIN BRIDGE INIT CONTRACT

OCEAN BRIDGE (P4):
  PREREQ: ShaderWarmupExecutor.Status == COMPLETE

  INIT STEPS:
    1. Detect ocean system type: [CREST | CUSTOM_FFT | FALLBACK_PLANE]
    2. IF TIER_MX350:
         FFT_Resolution = 128
         SimLayers      = 1       -> single cascade
         GerstnerWaves  = 8
         Foam_ON        = false
         SSR_ON         = false   -> no screen-space reflections
         CubemapRefresh = 0       -> static skybox reflection only
    3. IF TIER_HIGH+:
         FFT_Resolution = 512
         SimLayers      = 4
         GerstnerWaves  = 32
         Foam_ON        = true
         SSR_ON         = true
    4. Bind BuoyancyManager -> ocean height query API
    5. Validate query: ocean.GetHeight(Vector3.zero) -> IF NaN: FATAL(0xB007_0020)

TERRAIN BRIDGE (P5 / MapMagic):
  PREREQ: OceanBridge.Status == COMPLETE

  INIT STEPS:
    1. Set chunk_size by tier:
         CPU_LIGHT: 128m chunks, 1 thread
         CPU_MID:   256m chunks, 2 threads
         CPU_HEAVY: 512m chunks, 4 threads
    2. Preload radius: 1 chunk on CPU_LIGHT, 2 on CPU_MID, 3+ on CPU_HEAVY
    3. LOD bias:
         TIER_MX350: QualitySettings.lodBias = 0.4f
         TIER_HIGH:  QualitySettings.lodBias = 1.0f
         TIER_ULTRA: QualitySettings.lodBias = 2.0f
    4. Collision bake: Physics.BakeMesh async on worker thread, NOT main thread
    5. Validate: IF first_chunk.bounds.size == Vector3.zero: FATAL(0xB007_0030)
