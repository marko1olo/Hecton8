[REQ] Player-visible HUD, menu, terminal, panel, and streamed UI data acceptance inherits the Visual Reference Parity Gate. Captures must beat mandatory references plus best-known internal baseline/current rejection matrix before UI performance or binding work is credited.
[FORBID] Faster UI data flow, zero-GC binding, glow, glitch, animation, or layout churn as acceptance when legibility, physical instrument feel, route decision value, material anchoring, and compact-tier composition remain below April/previously-in-development baseline. Declare `VISUAL_ROUTE_INVALID` and recover UI owner stack first.

## REGISTRY_ARCHITECTURE

### TMP_TextRegistry
- Static `Dictionary<int, TMP_Text>` keyed by serialized deterministic hierarchy hash
- Registration: OnEnable auto-registers via `_bakedHierarchyHash` generated at edit/build time
- Deregistration: OnDisable removes entry; null-check before removal
- Batch Lookup: `GetTextBatch(int[] hashes, TMP_Text[] outBuffer)` fills pre-allocated array
- Forbidden: LINQ, `FindObjectsOfType`, string-keyed dictionaries

### HierarchyPath_BakePipeline

Editor/build step only:
  canonicalPath = "Canvas/HUD/HealthBar/ValueText"
  hash = FNV1a(canonicalPath)
  serialize hash into `TMP_TextRegistryNode._bakedHierarchyHash`

Runtime law:
  - never build hierarchy paths from `Transform` names
  - never hash strings during `OnEnable`
  - registry identity exists as baked integer only

### Registry_Lifecycle
- Init: Empty constructor, capacity = 256
- Update Check: If `_isDirty` flag set, rebuild internal sorted array for batch ops
- Concurrent Safety: Mark dirty on add/remove; rebuild only during safe tick window

## ZERO_GC_TEXT_SYSTEMS

### CharBuffer_Pool
- `static char[16][64]` pre-allocated buffers (16 slots, 64 chars each)
- Bitmask allocation: `ushort _slotMask` tracks free slots via bitwise ops
//[FORBID] Unchecked bit-math. You MUST guard the tzcnt:
if (_slotMask == 0) return ERROR_POOL_FULL;
slot = math.tzcnt(_slotMask);
_slotMask &= ~(1u << slot);
- Release: `_slotMask |= (1u << slot)`

### Numeric_Formatters_SpanBased_ZeroGC

Input: int/float value, char[] buffer, int startIndex
Output: int charsWritten

Required path:
  span = new Span<char>(buffer, startIndex, buffer.Length - startIndex)
  if value.TryFormat(span, out charsWritten):
      return charsWritten
  else:
      trigger Overflow_Guard

Rules:
  - Use `TryFormat` for `int`, `uint`, `float`, `double`, and `TimeSpan`
  - `format` token allowed only as compile-time literal (`"F1"`, `"F0"`, `"000"`)
  - No manual `% 10`, `/= 10`, reverse loops, or temporary string creation
  - `charsWritten` is authoritative; never scan for null terminator
  - `ReadOnlySpan<char>` is the only approved runtime formatting/template input
  - `Span<char>` may wrap a preallocated `char[]`, pooled `FixedCharBuffer`, or arena-backed scratch span
  - `stackalloc` in gameplay UI paths is capped at 256 bytes and must not cross async/iterator boundaries

### TMP_SetTextZeroGC

Step 1: Format numeric payload into pooled `Span<char>` via `TryFormat`
Step 2: Push text with `TMP_Text.SetCharArray(char[] sourceText, int start, int length)`.
Step 3: If visual geometry must be refreshed, call TMP vertex update APIs only after the char array write and only for dirty elements.

[FORBID] `TMP_Text.SetText(string)`.
[FORBID] `text =`.
[FORBID] interpolated strings, `string.Format`, `new string(span)`, `string.Create`, enum `.ToString()`, or numeric `.ToString()` in HUD/update paths.
[FORBID] Capturing `Span<T>` in lambdas, storing it in fields, using it in async methods, or using it in iterator methods.
[FORBID] uGUI text mutation for 60Hz readouts without nested canvas isolation and profiler proof.

## Engineering Data

| Operation | Approved | Forbidden | Gate |
|---|---|---|---|
| Number format | `TryFormat(Span<char>, out written, literalFormat)` | `.ToString()` / interpolation | 0 B GC over 300 frames |
| Text submit | `TMP_Text.SetCharArray(buffer, 0, len)` | `text =` / `SetText(string)` | Memory Profiler / GC column |
| Localization token input | `ReadOnlySpan<char>` + baked hash | runtime string path build | static scan |
| Overflow | clamp + ellipsis in same buffer | allocating fallback string | UI stress test |
| Debug UI | fixed ring + preallocated chars | `Debug.Log` spam or string concat | dev-build only |

## HUD_UPDATE_CADENCE

### TickBudget_Scheduler
- `SlowTick`: 500ms interval (2Hz) for FPS counter, memory stats
- `MediumTick`: 100ms interval (10Hz) for oxygen, depth meters
- `FastTick`: 16ms interval (60Hz) for crosshair, critical warnings
- Per-tick budget: 0.3ms for all UI text updates combined

### Staggered_Update_Pattern

Frame N % 30 == 0: Update FPS/Memory
Frame N % 6 == 0: Update Oxygen/Depth
Frame N: Update Critical Warnings

Store last update values; skip if delta < threshold:
  FPS: Skip if abs(newFPS - oldFPS) < 2
  Oxygen: Skip if abs(newO2 - oldO2) < 0.5%

### Hysteresis_Damping

displayValue = lerp(displayValue, targetValue, dampFactor * deltaTime)

dampFactor tuning:
  Health: 8.0 (smooth decay)
  Oxygen: 12.0 (responsive)
  Battery: 6.0 (slow drain feel)

Apply only when abs(display - target) > 0.01

## CANVAS_OPTIMIZATION

### Layer_Separation
- Canvas_Static: Icons, borders, background panels (never rebuild)
- Canvas_LowCadence: 2Hz/10Hz text only
- Canvas_WorldSpace: Hologram displays, 3D UI panels
- High-frequency text (60Hz): each critical TMP_Text lives on its own nested Canvas
- Nested Canvas rule: `OverrideSorting = true`, own GraphicRaycaster disabled unless interactive
- Sorting Order: Static=10, LowCadence=20, HighCadenceSubCanvas=30, WorldSpace=5

### HighFrequency_SubCanvas_Isolation

Mandatory for:
  - FPS
  - Depth
  - Crosshair diagnostics
  - Any warning text updated faster than 10Hz

Contract:
  - Parent HUD canvas remains static
  - Child object carries dedicated `Canvas`
  - Rebuild cost confined to that TMP quad only
  - Do not group multiple 60Hz texts into one shared dynamic canvas

### Visibility_Control

Hide: canvasGroup.alpha = 0; canvasGroup.blocksRaycasts = false
Show: canvasGroup.alpha = 1; canvasGroup.blocksRaycasts = true
Forbidden: SetActive(false) on Canvas GameObjects

### Overdraw_Reduction
- Disable raycastTarget on all non-interactive TMP_Text
- Use `PixelPerfect = false` on CanvasScaler
- Static batching: Group all static images under single Canvas with `additionalShaderChannels = None`

## MATRIX_SCALING_SYSTEM

### Resolution_Adaptation

Reference: 1920x1080
Current: screenWidth x screenHeight

scaleX = screenWidth / 1920.0
scaleY = screenHeight / 1080.0
uniformScale = min(scaleX, scaleY)

canvasRootTransform.localScale = Vector3.one * uniformScale

### Anchor_Presets
- Corners: Use `AnchorMin/Max = (0,1)` style anchors, not CanvasScaler stretch
- Safe Area: Apply `Screen.safeArea` rect to root RectTransform on mobile
- Forbidden: RectTransform size delta changes during runtime (layout thrash)

### DPI_Scaling (Desktop)

baseDPI = 96.0
actualDPI = Screen.dpi
dpiScale = clamp(actualDPI / baseDPI, 0.75, 2.0)

fontSize = baseFontSize * dpiScale
iconSize = baseIconSize * dpiScale

Store base sizes in ScriptableObject; apply scale on init only

## FONT_ATLAS_STREAMING

### SDF_Settings_LOD
- Distance < 5m: Full quality (Dilate=0, Softness=0)
- Distance 5-15m: Medium (Dilate=0.1, Softness=0.15)
- Distance > 15m: Low (Dilate=0.2, Softness=0.3)
- Check distance per world-space canvas every MediumTick

### Staged_Font_Swap

State Machine:
1. COLLECT: Build list of all TMP_Text via Registry (1 frame)
2. SWAP_BATCH: Process 18 references per frame
   - tmpText.font = newFontAsset
   - Increment counter
3. WAIT_ATLAS: Check font.atlasPopulationMode completion
4. FINALIZE: Rebuild all canvases, set _swapComplete = true

Display "REBOOTING INTERFACE..." overlay during states 1-3
Progress bar: (processedCount / totalCount) * 100

### Fallback_BIOS_Font
- If font.material == null after 2 frames: bind a monospace fallback font asset. Resources/Fonts/Fallback_Mono.asset (unbackticked: dead path) does not exist and the route is wrong twice over (verified 2026-07-27): no such asset, and `Resources.Load` is banned by `AGENTS.md` Runtime Hot-Path Law. Reference the fallback as a serialized field on the UI owner, or load it through the approved Addressables/streaming route with a tracked handle. If no fallback asset exists yet, creating one is an `ASSET_CHANGE` — do it explicitly, do not fake the path.
- BIOS style: Monospace, no SDF, 12pt fixed size
- Auto-revert when primary font loads

## INTERACTION_SYSTEMS

### Raycast_Optimization
- UI Camera: Separate camera for UI layer only
- Event Mask: Bitwise filter for interactive elements only
- Blocked Raycast Budget: Max 8 raycast checks per frame
- Cache: Store last hovered element; skip raycast if mouse unmoved

### Button_Pooling

Pool size: 32 button instances
On menu open: Activate N buttons from pool
On menu close: Deactivate all, return to pool
Reset state: image.color = default, text.text = ""

## FAILURE_MODES

### Overflow_Guard

if bufferLength > 63:
  Array.Copy(buffer, 0, buffer, 0, 60)
  buffer[60] = '.'
  buffer[61] = '.'
  buffer[62] = '.'
  length = 63

### Null_Reference_Chain

Before Registry access:
if (_registry == null) InitRegistry()
if (!_registry.TryGetValue(key, out var tmp)) return
if (tmp == null) { _registry.Remove(key); return }
