## Section0 - FOUNDATIONAL AXIOMS

[AXIOM-001] All resource data lives in contiguous memory. No heap-scattered objects.
[AXIOM-002] CPU-side truth. GPU receives only render-relevant subsets.
[AXIOM-003] Zero string operations in hot paths. All lookups via numeric keys.
[AXIOM-004] WorldItems = data records + dumb proxy meshes. Never smart objects.
[AXIOM-005] ScriptableObjects = compile-time constants. Runtime = struct copies only.

## Section1 - CORE DATA STRUCTURES

### 1.1 ItemData (Primary Record - 24 bytes, ARM64-safe)

struct ItemData {
    ulong instanceUID;   // [EntityID:24bit | Timestamp:40bit] - collision-free
    uint  hashID;        // FNV-1a of canonical item name - computed offline
    float quality;       // [0.0, 1.0] - saturate-clamped always
    ushort stackCount;   // max 65535 - sufficient for all resource types
    ushort flags;        // bitfield - see Section1.4
    uint  _pad0;         // explicit tail padding -> total size multiple of 8
}

Size: 8+4+4+2+2+4 = 24B. Runtime layout follows `DATA_Runtime_Struct_Layout_ARM64.txt`: 8-byte field first, then 4-byte fields, then 2-byte fields, explicit padding, total size multiple of 8.

[FORBID] `[StructLayout(Pack=1)]` or `[StructLayout(Pack=4)]` for this runtime record. Packed file records must be copied into this aligned runtime shape before NativeArray, Burst, SignalBus, save staging, telemetry, or GPU upload use.

### 1.2 ItemState (Per-Instance Mutable Runtime - 16 bytes)

struct ItemState {
    uint   instanceUID;   // FK -> ItemData.instanceUID
    float  durability;    // [0.0, 1.0]
    float  temperature;   // Celsius - affects chemistry/biology items
    uint   containerUID;  // owner: player/chest/world - 0 = unowned
}

### 1.3 WorldItemProxy (Render-Side Record - 12 bytes)

struct WorldItemProxy {
    uint   instanceUID;   // links to ItemData
    uint   chunkID;       // spatial partition key
    float3 position;      // world-space - NO rotation stored (billboards/LOD-silhouettes)
}

Proxies never store mesh refs. Mesh resolved via `ItemTemplateRegistry[hashID].ProxyMeshIndex`.

### 1.4 Flags Bitfield (ushort - 16 bits)

Bit 0:    IS_STACKABLE
Bit 1:    IS_EQUIPPABLE
Bit 2:    IS_CONSUMABLE
Bit 3:    IS_QUEST_LOCKED       // prevents drop/destroy
Bit 4:    IS_RADIOACTIVE        // triggers hazard system
Bit 5:    IS_PRESSURIZED        // hull-breach interaction
Bit 6:    IS_BIOLOGICAL         // decay timer active
Bit 7:    IS_TOOL
Bit 8:    IS_DEGRADED           // quality < 0.25 threshold
Bit 9:    IS_WORLD_ACTIVE       // proxy mesh enabled in scene
Bit 10:   IS_CRAFTING_LOCKED    // mid-craft reservation
Bit 11:   RESERVED_NETWORK      // future co-op sync
Bit 12-15: RARITY [0-15]        // 4-bit rarity tier

Flag test: `bool stackable = (item.flags & 0x0001) != 0;`
Rarity extract: `byte rarity = (byte)((item.flags >> 12) & 0xF);`

## Section2 - REGISTRY & TEMPLATE SYSTEM

### 2.1 ItemTemplateRegistry

static class ItemTemplateRegistry {
    NativeHashMap<uint, int>  hashToIndex;    // hashID -> template array index
    ItemTemplate[]            templates;       // SO-baked structs - READ ONLY
}

struct ItemTemplate {
    uint    hashID;
    uint    categoryMask;     // bitfield: MINERAL|BIO|TOOL|CRAFT|FOOD|TECH
    float   baseDurability;
    float   wearMultiplier;
    ushort  maxStackSize;
    ushort  proxyMeshIndex;   // index into MeshRegistry
    ushort  iconAtlasIndex;   // UV tile in texture atlas
    ushort  hlodSilhouetteIdx;
}

// ----------------------------------------------------------------
// REVISION 2026-08-04 (Architecture Audit): PRODUCTION ItemTemplate is 64 B, not
// the 24 B baseline above. The layout was reorganized and extended with gameplay
// data required by carry-mass and audio/physics propagation. The PRODUCTION layout
// (ItemTemplateRegistry.cs, LayoutKind.Explicit, verified) is:
//   uint   hashID               @0
//   uint   categoryMask         @4
//   float  baseDurability       @8
//   float  wearMultiplier       @12
//   uint   vulnerabilityMask    @16
//   uint   blueprintQuestFlagId @20
//   float  massKg               @24
//   float  volumeM3             @28
//   ushort maxStackSize         @32
//   ushort proxyMeshIndex       @34
//   ushort iconAtlasIndex       @36
//   ushort hlodSilhouetteIndex  @38
//   byte   audioMaterialId      @40
//   byte   physicsMaterialTag   @41
//   ushort _reserved0           @42
//   byte   _pad00 .. _pad19     @44..63
//   ---- total = 64 B (multiple of 8, explicit-layout, largest->smallest) ----
// Notes:
//   - Fields moved vs 24 B baseline: maxStackSize @16->@32, proxyMeshIndex
//     @18->@34, iconAtlasIndex @20->@36, hlodSilhouetteIdx @22->@38.
//   - Additive fields: vulnerabilityMask@16, blueprintQuestFlagId@20, massKg@24,
//     volumeM3@28, audioMaterialId@40 (byte), physicsMaterialTag@41 (byte),
//     _reserved0@42 (ushort). The mandate's "baseStrength" baseline field does NOT
//     exist in production (superseded by the vulnerabilityMask/blueprint fields).
// Registered in the SHINOBU_204 ARM64 self-audit CriticalTypeNames so the 64 B
// size and alignment are enforced at editor self-audit time.
// ----------------------------------------------------------------

Lookup: O(1) - `templates[hashToIndex[hashID]]`
Population: Bake at AssetPostprocessor stage. No runtime SO reads.

### 2.2 UID Generation Algorithm

instanceUID generation:
  entityCounter: static uint64 - atomic increment per session
// [FORBID] Millisecond-based UIDs for high-speed physics objects.
// You MUST use a monotonic atomic counter:
uid = Interlocked.Increment(ref globalCounter);
  entityID:  uint64 = Interlocked.Increment(ref entityCounter) & 0xFFFFFF  // 24-bit mask
  uid = (entityID << 40) | timestamp
  collapse to uint32 via FNV-1a fold:
// [FORBID] 32-bit collapse. Retain full 64-bit integrity.
instanceUID : ulong = (entityID << 40) | timestamp;

Collision probability at 10K items/session: < 2^-18. Acceptable. Use uint32 form as instanceUID.

### 2.3 HashID Generation (Offline - Build Tool)

FNV-1a 32-bit:
  hash = 2166136261u
  foreach byte b in canonicalName.ToLowerInvariant():
    hash ^= b
    hash *= 16777619u
  return hash

Bake into ScriptableObject field at import. Never compute at runtime.

### 3.1 Container Types

enum ContainerType : byte {
    PlayerHotbar   = 0,   // 8 slots - NativeArray fixed
    PlayerBackpack = 1,   // 32 slots - NativeArray fixed
    WorldChest     = 2,   // variable - NativeArray<ItemData> pooled

### 3.2 PlayerInventoryBuffer (Burst-Compatible)

struct PlayerInventoryBuffer {
    NativeArray<ItemData>   hotbar;        // [8]
    NativeArray<ItemData>   backpack;      // [32]
    NativeArray<ItemState>  states;        // [40] - parallel indexed to above
    NativeArray<uint>       sortKeys;      // [40] - category|rarity|hashID packed
    int                     hotbarCount;
    int                     backpackCount;
}

Sort key pack: `sortKey = (categoryMask << 20) | (rarity << 16) | (hashID & 0xFFFF)`
Enables radix sort by category -> rarity -> type in single pass.

### 3.3 WorldStateManager (Spatial Partition)

struct ChunkItemRegistry {
    uint                              chunkID;
    NativeArray<ItemData>             items;        // max 128 per chunk [SCALE-MX350]
    NativeArray<WorldItemProxy>       proxies;      // parallel to items

}

WorldStateManager owns:

UID->Chunk lookup: O(1). Required for scavenging protocol step 2.

## Section4 - ALGORITHMIC KERNELS

### 4.1 Stack Merge Logic

STACK_MERGE(ref ItemData dest, ref ItemData src, ushort maxStack):
  template = ItemTemplateRegistry.Get(dest.hashID)
  capacity = template.maxStackSize - dest.stackCount
  delta    = min(capacity, src.stackCount)
  dest.stackCount += delta
  src.stackCount  -= delta
  remainder = src.stackCount
  if remainder == 0: invalidate src (set hashID = 0, instanceUID = 0)
  return remainder

### 4.2 Durability Decay (Per-Tick - Burst Job)

DURABILITY_DECAY(ref ItemState state, float deltaTime, uint hashID):
  template     = ItemTemplateRegistry.Get(hashID)
  wearFactor   = template.wearMultiplier
  decay        = deltaTime * wearFactor
  state.durability = saturate(state.durability - decay)
  // Flag update:
  if state.durability < 0.25f:
    items[idx].flags |= 0x0100   // IS_DEGRADED
  if state.durability <= 0.0f:
    TRIGGER_ITEM_BREAK_EVENT(state.instanceUID)

Saturate: `saturate(x) = clamp(x, 0.0, 1.0)` - maps to single SIMD instruction in Burst.

### 4.3 Biological Decay (Secondary Overlay)

BIO_DECAY(ref ItemState state, float ambientTemp, float deltaTime):
  if (flags & IS_BIOLOGICAL) == 0: return
  tempFactor = exp((ambientTemp - 4.0f) * 0.05f)   // Arrhenius-simplified
  qualityDelta = deltaTime * 0.001f * tempFactor
  items[idx].quality = saturate(items[idx].quality - qualityDelta)
  if items[idx].quality < 0.1f:
    TRIGGER_SPOILAGE(state.instanceUID)

Cold storage (4 degC) = near-zero decay. Deep-sea temps (2 degC) actually preserve bio-items. Design leverage.

### 4.4 Pressure-Temperature State Check (NASA-Punk integration)

PRESSURE_CHECK(ItemData item, float ambientPressure, float ambientTemp):
  if (item.flags & IS_PRESSURIZED) == 0: return
  critPressure = 60.0f   // ATM - configure per item via template
  if ambientPressure > critPressure:
    TRIGGER_CONTAINER_BREACH(item.instanceUID)
    // Spawns particle event + destroys item
  if ambientTemp > 300.0f && (item.flags & IS_RADIOACTIVE):
    TRIGGER_MELTDOWN_HAZARD(item.instanceUID)

### 4.5 Inventory Sort (Radix - Burst Job)

INVENTORY_SORT(NativeArray<ItemData> items, NativeArray<uint> sortKeys, int count):
  // Rebuild sortKeys pass:
  for i in [0, count):
// [FORBID] Bitmasks in sort keys.
// Define a mutually exclusive sequential 'byte CategoryID' and pack that into the sort key.
    id     = items[i].hashID & 0xFFFF
    sortKeys[i] = (cat << 20) | (rar << 16) | id

  // Native Burst sort on contiguous key/value buffers:

struct SortEntry { public uint key; public ItemData item; }

Schedule as Burst job over contiguous key/value buffers. Off main-thread. No GC.

### 4.6 Scavenging Protocol (Full Flow)

SCAVENGE_ATTEMPT(Ray cameraRay, PlayerInventoryBuffer* playerBuf):
  Step 1 - RAYCAST:
    hit = PhysicsScene.Raycast(cameraRay, maxDist=3.5f, layerMask=LOOT_LAYER)
    if !hit: return FAIL

  Step 2 - RESOLVE UID:
    proxyGO   = hit.collider.gameObject
    proxyUID  = ProxyUIDComponent[proxyGO]   // single-field struct on proxy GO
    chunkID   = WorldStateManager.uidToChunk[proxyUID]
    registry  = WorldStateManager.chunkMap[chunkID]
    itemIdx   = FindIndexByUID(registry.items, proxyUID)
    if itemIdx < 0: return FAIL_STALE

  Step 3 - TRANSFER TO PLAYER:
    itemData  = registry.items[itemIdx]
    result    = ATTEMPT_ADD_TO_INVENTORY(playerBuf, itemData)
    if result == INVENTORY_FULL:
      DROP_BUFFER_ENQUEUE(itemData, playerBuf->position)
      return FAIL_FULL

  Step 4 - WORLD CLEANUP:
    registry.proxyActive[itemIdx] = false
    registry.items[itemIdx]       = default   // zero-fill
    registry.count--
    WorldStateManager.uidToChunk.Remove(proxyUID)
    DisableProxyMesh(proxyGO)                 // SetActive(false) deferred to end-of-frame batch

  return SUCCESS

### 4.7 Add-To-Inventory Logic

ATTEMPT_ADD_TO_INVENTORY(PlayerInventoryBuffer* buf, ItemData incoming):
  // Phase 1 - Stack merge attempt:
  if (incoming.flags & IS_STACKABLE):
    for slot in buf.backpack[0..backpackCount]:
      if slot.hashID == incoming.hashID && slot.stackCount < maxStack:
        remainder = STACK_MERGE(ref slot, ref incoming, maxStack)
        if remainder == 0: return SUCCESS

  // Phase 2 - Empty slot:
  if backpackCount < 32:
    buf.backpack[backpackCount] = incoming
    buf.states[8 + backpackCount] = NEW_ITEM_STATE(incoming.instanceUID)
    backpackCount++
    return SUCCESS

  return INVENTORY_FULL

### 4.8 Drop-On-Full Protocol

DROP_OVERFLOW(ItemData item, float3 playerPos, WorldStateManager* wsm):
  chunkID  = WORLD_POS_TO_CHUNK(playerPos)
  registry = wsm.chunkMap[chunkID]
  if registry.count >= 128: EVICT_OLDEST(registry)   // LRU eviction, oldest itemIdx
  idx = registry.count
  registry.items[idx]       = item
  registry.proxies[idx]     = { item.instanceUID, chunkID, playerPos + SCATTER_OFFSET() }
  registry.proxyActive[idx] = true
  registry.count++
  wsm.uidToChunk[item.instanceUID] = chunkID
  SPAWN_PROXY_MESH(item.hashID, registry.proxies[idx].position)

SCATTER_OFFSET():
  // Deterministic random offset from instanceUID:
// [FORBID] Implicit size casting in Burst. Use 64-bit literal suffixes (UL):
ulong seed = item.instanceUID ^ 0xDEADBEEFUL;
seed = (seed ^ (seed >> 16)) * 0x45D9F3BUL;
  x     = ((seed & 0xFF) / 255.0f - 0.5f) * 0.8f
  z     = (((seed >> 8) & 0xFF) / 255.0f - 0.5f) * 0.8f
  return float3(x, 0.05f, z)

## Section5 - HARDWARE SCALABILITY [MX350 MANDATE]

### 5.1 Proxy Budget Enforcement

CHUNK_VISIBILITY_CULL(ChunkItemRegistry registry, float3 cameraPos):
  visibleCount = 0
  for i in [0, registry.count):
    dist = length(registry.proxies[i].position - cameraPos)
    if dist < PROXY_FULL_DIST (30m):
      registry.proxyActive[i] = true
      visibleCount++
      if visibleCount >= 128: break   // hard cap [MX350 SCALE]
    elif dist < HLOD_DIST (80m):
      RENDER_HLOD_SILHOUETTE(registry.proxies[i])
    // beyond 80m: invisible, data retained

### 5.2 VRAM Footprint - Loot Proxies

Proxy mesh budget:
  Max unique proxy meshes:  32 types (shared via GPU instancing)
  Per-mesh avg VRAM:        ~48KB (low-poly, 200-500 tri)
  Total mesh VRAM:          32 x 48KB = 1.5MB
  Instance data (128/chunk x 4 active chunks):
    512 instances x 64B transform = 32KB
  Icon atlas:               512x512 RGBA8 = 1MB
  HLOD silhouettes:         16 types x 8KB = 128KB
  TOTAL PROXY VRAM:         ~2.7MB - within MX350 2GB ceiling alongside main render

### 5.3 Job Scheduling Policy

Frame N:
  MainThread:   Scavenge raycasts, UI reads, input
  JobThread A:  DurabilityDecayJob (all active ItemStates)
  JobThread B:  BiologicalDecayJob (IS_BIOLOGICAL subset)
  JobThread C:  InventorySortJob (dirty flag triggers only)

Frame N+1 fence:
  Complete all jobs before save-serialize or UI-refresh reads

Job dependencies:
  DurabilityDecayJob -> completes before CraftingValidationJob
  SortJob -> completes before UIRenderJob

### 5.4 Memory Budget (6GB RAM Target)

PlayerInventoryBuffers:    40 x 20B (ItemData) + 40 x 16B (ItemState) = 1.44KB
WorldStateManager total:
  32 active chunks x 128 items x 36B (ItemData+Proxy) = 147KB
ItemTemplateRegistry:      512 templates x 24B = 12KB
NativeHashMaps overhead:   ~2MB (worst case, pre-allocated)
TOTAL INVENTORY SYSTEM:    ~2.2MB - negligible vs. 6GB ceiling

## Section6 - PERSISTENCE & SERIALIZATION [ZERO-GC]

### 6.1 Save Blit Protocol

SAVE_INVENTORY(PlayerInventoryBuffer buf, FileStream stream):
  // Direct memory blit - no serializer, no JSON, no GC
  headerSize = sizeof(int) x 2   // hotbarCount + backpackCount
  dataSize   = (buf.hotbarCount + buf.backpackCount) x sizeof(ItemData)
  stateSize  = (buf.hotbarCount + buf.backpackCount) x sizeof(ItemState)

  WRITE_RAW(stream, &buf.hotbarCount,   headerSize)
  WRITE_RAW(stream, buf.hotbar.ptr,     buf.hotbarCount x 20)
  WRITE_RAW(stream, buf.backpack.ptr,   buf.backpackCount x 20)
  WRITE_RAW(stream, buf.states.ptr,     stateSize)
  CRC32_APPEND(stream)   // validation on load

### 6.2 World State Save (Chunk-Selective)

SAVE_CHUNK(ChunkItemRegistry registry, FileStream stream):
  WRITE_RAW(stream, &registry.chunkID,  4)
  WRITE_RAW(stream, &registry.count,    4)
  for i in [0, registry.count):
    if registry.proxyActive[i] || ITEM_HAS_VALUE(registry.items[i]):
      WRITE_RAW(stream, &registry.items[i],   20)
      WRITE_RAW(stream, &registry.proxies[i], 12)
  // Skip zeroed/invalid records - reduces save file bloat

### 6.3 Load & Validation

LOAD_INVENTORY(FileStream stream, PlayerInventoryBuffer* buf):
  READ_RAW(stream, &hotbarCount, &backpackCount)
  VALIDATE(hotbarCount <= 8, backpackCount <= 32)
  READ_RAW(stream, buf.hotbar.ptr,   hotbarCount x 20)
  READ_RAW(stream, buf.backpack.ptr, backpackCount x 20)
  READ_RAW(stream, buf.states.ptr,   (hotbarCount+backpackCount) x 16)
  storedCRC = READ_UINT32(stream)
  computedCRC = CRC32(buf.hotbar.ptr, totalBytes)
  if storedCRC != computedCRC: LOAD_BACKUP_SAVE()
  // Rehydrate: verify all hashIDs against ItemTemplateRegistry
  for item in buf: if !ItemTemplateRegistry.Contains(item.hashID): item = default

## Section7 - FAILURE MODES & GUARDS

### 7.1 Stale UID Handling

UID_VALIDATE(uint instanceUID):
  if !WorldStateManager.uidToChunk.ContainsKey(instanceUID): return STALE
  if !PlayerInventoryBuffer.ContainsUID(instanceUID): return STALE
  return VALID

// Call before any operation that resolves UID to data
// Stale UIDs arise from: save corruption, async job race, duplicate UID (see Section2.2 collision note)

### 7.2 Chunk Overflow Guard

EVICT_OLDEST(ChunkItemRegistry registry):
  // Find oldest by lowest instanceUID (encodes timestamp in low 40 bits)
  minUID = uint.MaxValue; evictIdx = -1
  for i in [0, registry.count):
    if registry.items[i].instanceUID < minUID:
      minUID = registry.items[i].instanceUID
      evictIdx = i
  // Despawn without drop - world clutter cap enforcement
  registry.items[evictIdx]       = default
  registry.proxyActive[evictIdx] = false
  DisableProxyMesh(evictIdx)
  registry.count--
  SWAP_WITH_LAST(registry.items, evictIdx)    // maintain dense array
  SWAP_WITH_LAST(registry.proxies, evictIdx)

### 7.3 Quest-Lock Guard

ITEM_DESTROY_GUARD(ItemData item):
  if (item.flags & IS_QUEST_LOCKED) != 0:
    REJECT_OPERATION("QUEST_LOCKED: " + item.hashID)
    return BLOCKED
  return ALLOW

// Apply at: drop, craft-consume, discard, world-evict
// Quest flags set/cleared by QuestStateManager only

### 7.4 Crafting Reservation Lock

CRAFT_RESERVE(ItemData[] inputs):
  for item in inputs:
    item.flags |= IS_CRAFTING_LOCKED    // prevents concurrent scavenge/drop ops
  SCHEDULE_CRAFT_JOB(inputs)

CRAFT_COMPLETE(ItemData[] inputs, ItemData output):
  for item in inputs:
    item.flags &= ~IS_CRAFTING_LOCKED
    CONSUME_ITEM(item)
  ATTEMPT_ADD_TO_INVENTORY(output)

CRAFT_FAIL(ItemData[] inputs):
  for item in inputs: item.flags &= ~IS_CRAFTING_LOCKED
  // No items lost on craft failure

## Section8 - RENDER INTEGRATION NOTES

### 8.1 Proxy Mesh Instantiation Strategy

GPU/BRG groups by proxyMeshIndex:
  Build InstancedRenderData[32] arrays each frame
  Per-instance data: float4x4 TRS (computed from proxy.position + identity rotation)
  Submit via BatchRendererGroup / GPU Resident Drawer compatible path where possible.
  Raw Graphics.DrawMeshInstanced requires a route exception and profiler proof.
  Batch threshold: submit when count >= 1 (no minimum - underwater scenes sparse)

### 8.2 Icon Atlas Sampling

UV tile calculation (512x512 atlas, 32x32 icon tiles = 16x16 grid):
  col = iconAtlasIndex % 16
  row = iconAtlasIndex / 16
  uvMin = float2(col / 16.0f, row / 16.0f)
  uvMax = uvMin + float2(1/16.0f, 1/16.0f)

### 8.3 Highlight Shader Integration (Scavenge Target)

On raycast hit proxy:
  Pass highlighted instanceUID through GraphicsBuffer instance data, a renderer-feature highlight buffer, or a material CBUFFER owned by the highlight route.
  Shader reads: _HighlightUID (uint) - compares against per-instance ID
  If match: rim light + depth-outline pass active
  No material duplication. No MaterialPropertyBlock on standard SRP-batched geometry.
