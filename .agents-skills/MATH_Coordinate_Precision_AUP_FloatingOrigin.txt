## II. DATA ARCHITECTURE

### [DATA] Coordinate Representation

AUPition (CPU-side):

struct AUP {
    int64 gridX, gridY, gridZ;     // 5000m cells
    float32 localX, localY, localZ; // offset within cell [-2500, +2500]
}

Conversion Logic:

AUP -> WorldPos:
    worldPos = (gridXYZ * CELL_SIZE) + localXYZ - _GlobalFloatingOffset
WorldPos -> AUP:
    gridXYZ = floor(absPos / CELL_SIZE)
    localXYZ = absPos - (gridXYZ * CELL_SIZE)

Bitmask State Flags (8-bit):

0x01: SHIFT_PENDING
0x02: PHYSICS_FROZEN
0x04: NAVIGATION_STALE
0x08: SHADER_OFFSET_DIRTY
0x10: INTEGRATOR_RESET_REQ

[RULE] For 300 frames after a shift, systems must tag telemetry with `_ShiftFrameID`, shift vector, pre/post camera AUP, and high-level position hashes for physics/render/navigation.
[RULE] Shift-sensitive systems must reject stale cached world positions if their cached shift id does not match the current `_ShiftFrameID`.
[RULE] During the snap-fence window, visual interpolation may hide the snap; gameplay authority may not interpolate across pre/post-shift coordinates.
[RULE] At frame 300, the fence resolves only after drift probes report finite positions and max camera-relative error is below the tier threshold.

### [MATH] Atomic World Shift Protocol

Step-by-step (Single Frame):

1. Set SHIFT_PENDING flag globally.
2. Freeze gameplay-side physics integration.
3. Cache all Rigidbody linear/angular velocities once.
4. Compute shift vector:
   shiftVec = -playerWorldPos
   shiftVec = round(shiftVec / SNAP_GRID) * SNAP_GRID
5. Update CPU-side universe origin accumulators.
6. // Group all physics objects under a root GameObject. Shift the Root Transform ONCE.
7. Rebuild renderer / collider transforms from rebased AUP data on the CPU.
8. Reapply cached velocities unchanged.
9. Clear SHIFT_PENDING and resume simulation.
10. Increment _ShiftFrameID.

Numerical Stability Guards:

shiftVec = clamp(shiftVec, -10000m, +10000m)
if dot(shiftVec, shiftVec) < 1.0:
    abort_shift()

### [SAFE] Failure Modes & Guards

Mode 1: Physics "Kraken" (Velocity Spike)

Cause: Rigidbody velocity not cached before shift
Detect: if velocity.magnitude > 1000 m/s after shift
Recovery:
    rb.velocity = Vector3.ClampMagnitude(rb.velocity, maxSpeed)
    rb.angularVelocity = Vector3.zero
    Log warning + entity ID

Mode 2: Shader Offset Desync

Cause: Constant buffer upload skipped or stale frame data bound
Detect: `_ShiftFrameID` mismatch against shared global uniform block
Recovery:
    Re-upload `Hecton8GlobalUniforms` once
    Rebind constant buffer handle
    Flag SHADER_OFFSET_DIRTY cleared

Mode 3: Navigation Path Corruption

Cause: Waypoint world position queried during shift frame
Detect: SHIFT_PENDING flag set during path query
Recovery:
    Stall path query until shift complete (max 1 frame)
    Return cached last-valid waypoint

Mode 4: Float Precision Exhaustion (>100km travel)

Cause: _TotalUniverseOffset exceeds float32 mantissa
Detect: if _TotalUniverseOffset.magnitude > 16777216
Recovery:
    Enable high/low component splitting (see [MATH])
    Fallback: Quantize to 1m grid permanently

Mode 5: Noise Discontinuity

Cause: UV3 not baked or precision loss
Detect: Visual texture "sliding" during shift
Recovery:
    Validate mesh.uv3 != null in asset validator
    Re-bake UV3 for affected meshes
    Emergency fallback: Use world-space UVs with 10m quantization
