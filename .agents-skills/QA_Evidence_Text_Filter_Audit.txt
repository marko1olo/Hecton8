## Law

[RULE] Static text search is evidence of text presence only. It is not compile proof, runtime proof, profiler proof, RenderGraph proof, GC proof, or scene wiring proof.
[RULE] Reports must label each claim by evidence class:
- STATIC_SOURCE
- STATIC_DOC
- PACKAGE_LOCK
- CLI_COMPILE
- UNITY_CONSOLE
- PLAYMODE
- PROFILER
- FRAME_DEBUGGER
- PLAYER_BUILD

[RULE] Any claim above its evidence class must be downgraded to `PENDING VERIFICATION`.
[RULE] "Verified", "complete", "master grade", "0 GC", "0 errors", and timing claims require artifact paths, command lines, timestamps, and target hardware.

[FORBID] Using `rg`/`Select-String` hits as proof that a system is integrated or runtime-clean.
[FORBID] Claiming Unity Editor status from generated project compile alone.
[FORBID] Reporting microseconds saved without profiler sample context.
[FORBID] Reporting "all agents audited" without listing scanned files and unresolved files.
[FORBID] Claiming data sovereignty while DTOs, signal payloads, or contract structs crossing native/binary/platform boundaries lack explicit layout proof.
[FORBID] Claiming IL2CPP, Quest, Android, console, or platform readiness from `link.xml`, package text, or preservation attributes without a platform build artifact.
[FORBID] Claiming compile health when another log or current console reports duplicate signals, duplicate structs, missing methods, or unresolved generated-project errors.
[FORBID] Reporting a task as done while `Status_[ID].md` remains unchecked or `LOG_[ID].md` is missing.
[FORBID] Reporting hot-path purity while source still contains a private `Update()` fallback outside the dispatcher exception list.

## Batch 007 Inquisition Rules

[RULE] Duplicate signal names across first-party assemblies are Critical contract drift until reconciled by the Integrator.
[RULE] Contract expansion during an active batch requires a legacy wrapper and a rationale entry. Mutating an existing public signature is rejected.
[RULE] Any binary/native DTO or signal payload used across save, Burst, native collections, telemetry, or platform boundaries must declare explicit layout or documented unmanaged field order.
[RULE] `GlobalDataVault` is a memory/data owner. Reports claiming DataVault integration must list BufferID, SystemID, generation handling, and disposal/relocation behavior.
[RULE] Microsecond savings and `0 B GC` claims are static estimates unless backed by profiler or GCMonitor artifact paths.
[RULE] Platform hardening claims require the platform build command, artifact path, timestamp, and unresolved error list.
