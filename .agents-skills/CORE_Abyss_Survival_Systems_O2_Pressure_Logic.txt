/// <summary>
/// Pure value-type survival state. NO heap allocations.
/// Passed by ref across all survival subsystems.
/// </summary>
[System.Serializable]
public struct SurvivalState
{
    // --- Hull / Pressure ---
    public float hullStress;          // [0.0 ... 1.0+sentinel]
    public float hullIntegrity;       // Base structural rating. Degrades via fatigue. [0.0 ... 1.0]
    public float depthPressure;       // Current ambient pressure in MPa. Derived from depth.
    public bool  isFatalSequenceArmed;// Guards single-fire implosion event.

    // --- Life Support ---
    public float oxygenLevel;         // [0.0 ... 1.0]  1.0 = full tank
    public float batteryLevel;        // [0.0 ... 1.0]  1.0 = full charge
    public bool  isConscious;         // False = player has fainted

    // --- Thermal ---
    public float internalTemp;        // Celsius, suit interior
    public float externalTemp;        // Celsius, ambient water
    public float insulationFactor;    // [0.0 ... 1.0]  1.0 = perfect insulation

    // --- Glitch State ---
    public float glitchIntensity;     // [0.0 ... 1.0] derived from hullStress
    public bool  isGlitchActive;

    // --- Recovery ---
    public Vector3 lastSafeZonePosition;
    public float   lastSafeZoneDepth;
}

### 3.1 Depth -> Pressure Mapping

depthPressure (MPa) = (depth_meters / 100.0) * 1.0 MPa

At 4,000 m:  `depthPressure = 40.0 MPa`

    => depthMeters * 0.01f; // 1 MPa per 100 m (simplified ocean model)

### 3.2 Hull Stress Accumulation - Asymptotic Fatigue Model

Formula:

Deltastress = (depthPressure / hullIntegrity) * pressureStressMultiplier * dt
stress   = stress + Deltastress

Structural Fatigue - Integrity Degradation:

Integrity does NOT recover. It decays via fatigue exponent whenever stress is non-zero:

hullIntegrity_new = hullIntegrity * (1 - (stress^fatigueDecayExponent) * dt * 0.001)
hullIntegrity_new = clamp(hullIntegrity_new, 0.01, 1.0)

The exponent `fatigueDecayExponent < 1.0` creates sub-linear early degradation
that accelerates as stress accumulates - matching real material fatigue curves.

> Design Intent: At low stress (0.0-0.3) integrity erodes slowly. Above 0.6,
> feedback loop (lower integrity -> higher stress -> lower integrity) becomes
> self-reinforcing. system has no natural equilibrium at 4 km depth.
> Survival requires active ascent or structural repair items.

Stress does NOT decrease passively. Stress reduction is ONLY possible via:
- `RepairKitConsumable` (reduces stress by fixed delta, defined in item config)
- Ascending above `config.safeDepthThreshold` (stress frozen, not reduced)

Implementation:

public static void TickHullStress(
    ref SurvivalState  state,
    SurvivalConfig     cfg,
    float              dt)
{
    // Guard: already imploded
    if (state.isFatalSequenceArmed) return;

    // 1. Compute pressure-driven stress increment
    float integrityGuard = Mathf.Max(state.hullIntegrity, 0.001f); // avoid /0
    float delta = (state.depthPressure / integrityGuard)
                * cfg.pressureStressMultiplier
                * dt;

    state.hullStress += delta;

    // 2. Apply structural fatigue to integrity (non-linear, sub-linear exponent)
    float fatigueDelta = Mathf.Pow(state.hullStress, cfg.fatigueDecayExponent)
                       * dt
                       * 0.001f;
    state.hullIntegrity = Mathf.Clamp(state.hullIntegrity - fatigueDelta, 0.01f, 1.0f);

    // 3. Arm fatal sequence - do NOT clamp yet; sentinel value propagates to event check
    if (state.hullStress >= cfg.fatalStressThreshold && !state.isFatalSequenceArmed)
    {
        state.isFatalSequenceArmed = true;
        // Event firing handled in ImplosionSequencer (Section 3.3)
    }

    // 4. Hard clamp AFTER event check
    state.hullStress = Mathf.Clamp(state.hullStress, 0f, 1.05f); // 1.05 sentinel ceiling
}

### 3.3 Implosion Sequence - Fatal Pressure Loop

State machine:

[Normal]  (stress > 0.70)-> [GlitchOnset]
[GlitchOnset] (stress > 0.95)-> [CriticalWarning]
[CriticalWarning] (stress >= 1.00)-> [FatalImplosion]

CriticalWarning Phase (stress 0.95 -> 1.00):
- Visual: chromatic aberration ramp, screen crack overlay alpha = `(stress - 0.95) / 0.05`
- Audio: hull groan pitch-shifted up by `stress * 2.0` semitones, loop interval shortened
- HUD: stress display blinks at `4 Hz`

FatalImplosion Phase (stress >= 1.00):

public sealed class ImplosionSequencer
{
    private bool _fired = false;

    public void Evaluate(in SurvivalState state, IEventBus eventBus)
    {
        if (_fired) return;
        if (!state.isFatalSequenceArmed) return;

        _fired = true;

        // Fire exactly once - no repeat, no async
        eventBus.Publish(new FatalPressureImplosionEvent
        {
            Position    = state.lastSafeZonePosition, // for VFX spawn
            StressValue = state.hullStress,
            Timestamp   = Time.time
        });
    }
}

// Event data - value type, zero heap cost on publish
public readonly struct FatalPressureImplosionEvent
{
    public readonly Vector3 Position;
    public readonly float   StressValue;
    public readonly float   Timestamp;
}

- `GameStateManager` -> transition to `DeathState`

### 3.4 Life Support Depletion - Zero-GC Resource Logic

Oxygen:

oxygenLevel -= oxygenDepletionRate * stressModifier * dt

Where:

stressModifier = 1.0 + (hullStress * 0.5)
// Higher stress = micro-leaks increase O2 loss rate by up to 50%

Battery:

batteryLevel -= batteryDepletionRate * thermalLoadModifier * dt

Where:

thermalLoadModifier = 1.0 + max(0, (dangerousInternalTemp - internalTemp) / dangerousInternalTemp)
// Heating elements draw extra power in cold conditions

Faint Trigger:

if (oxygenLevel <= faintOxygenThreshold && isConscious):
    isConscious = false
    -> Initiate FaintRecoverySequence (Section 3.6)

Implementation:

public static void TickLifeSupport(
    ref SurvivalState  state,
    SurvivalConfig     cfg,
    float              dt)
{
    //  Oxygen
    float stressModifier = 1.0f + (state.hullStress * 0.5f);
    state.oxygenLevel -= cfg.oxygenDepletionRate * stressModifier * dt;
    state.oxygenLevel  = Mathf.Max(state.oxygenLevel, 0f);

    //  Battery
    float tempDelta         = Mathf.Max(0f, cfg.dangerousInternalTemp - state.internalTemp);
    float thermalLoadMod    = 1.0f + (tempDelta / Mathf.Max(cfg.dangerousInternalTemp, 0.001f));
    state.batteryLevel     -= cfg.batteryDepletionRate * thermalLoadMod * dt;
    state.batteryLevel      = Mathf.Max(state.batteryLevel, 0f);

    //  Faint Check
    if (state.oxygenLevel <= cfg.faintOxygenThreshold && state.isConscious)
    {
        state.isConscious = false;
        // Caller responsible for routing to FaintRecoverySequence
    }
}

### 3.5 Temperature Pockets - Cold Current Thermal Model

Exponential Decay Formula:

The suit's internal temperature converges toward external temperature following
Newton's Law of Cooling with exponential decay:

DeltaT = (externalTemp - internalTemp) * (1 - e^(-dt / )) * (1 - insulationFactor)
internalTemp_new = internalTemp + DeltaT

Where:
- `` = `thermalTimeConstant` (seconds) - insulation time constant
- `insulationFactor`  `[0, 1]` - 1.0 = perfect insulation (no heat exchange)
- At `insulationFactor = 0.0`, suit reaches external temp in ~3tau seconds

Cold Current Detection:

A "cold current" zone is tagged trigger volume with `externalTemp` override.

| Current Class | External Temp | tau Override | Notes |
|---------------|--------------|------------|-------|
| `Mild`        | 4 degC          | 60s        | Marginal heat drain |
| `Deep`        | 1 degC          | 30s        | Significant - player warned |
| `Abyss`       | -0.5 degC       | 15s        | Critical - emergency ascent advised |

> Seawater at 4 km can reach -0.5 degC due to pressure effects on freezing point.

Implementation:

public static void TickThermal(
    ref SurvivalState  state,
    SurvivalConfig     cfg,
    float              dt)
{
    // Exponential decay toward external temperature
    // Uses 1 - e^(-dt/tau) approximated accurately for small dt values
    float tau           = cfg.thermalTimeConstant;
    // Use Unity.Mathematics
    float decayFactor   = 1.0f - math.exp(-dt / tau);
    float tempDelta     = (state.externalTemp - state.internalTemp)
                        * decayFactor
                        * (1.0f - state.insulationFactor);

    state.internalTemp += tempDelta;
}

Insulation Damage:

Insulation degrades with stress (micro-fractures in thermal lining):

insulationFactor_new = insulationFactor * (1 - stress * 0.0001 * dt)
insulationFactor_new = clamp(insulationFactor_new, 0.0, 1.0)

InputManager Noise Injection:

public static Vector2 ApplyInputNoise(Vector2 rawLookDelta, float glitchIntensity, ref uint rngState)
{
    if (glitchIntensity <= 0f) return rawLookDelta;

    // Deterministic noise via xorshift32 - zero GC, no Random.Range
    float noise    = NextFloat(ref rngState) * 2f - 1f; // [-1, +1]
    float maxDrift = glitchIntensity * 20f;             // degrees

    return new Vector2(
        rawLookDelta.x + noise * maxDrift,
        rawLookDelta.y + noise * maxDrift * 0.5f
    );
}

// xorshift32 - deterministic, zero-alloc PRNG
[MethodImpl(MethodImplOptions.AggressiveInlining)]
private static float NextFloat(ref uint state)
{
    state ^= state << 13;
    state ^= state >> 17;
    state ^= state << 5;
    return (state & 0x7FFFFF) / (float)0x800000; // [0, 1)
}

HUDRenderer Noise:

HUDRenderer receives `GlitchPayload` struct (value type) each frame:

public readonly struct GlitchPayload
{
    public readonly float Intensity;     // [0...1]
    public readonly float FlickerPhase;  // Time.time * flickerHz * 2*pi
    public readonly bool  CrackOverlay;  // stress > 0.95
}

HUDRenderer applies `Intensity` to material property block - no string ops,
no new allocations. Shader reads `_GlitchIntensity` float uniform.

### 3.7 Failure Recovery - Faint & Safe-Zone Restoration

Faint State Rules:

When `isConscious = false`:
1. Player loses locomotion input (movement set to zero)
2. Camera begins slow drift downward (simulated loss of control)
3. `FaintRecoveryTimer` starts: `t = 8.0 seconds`
4. During timer: oxygen auto-refills at `emergencyO2Rate = 0.02/sec` (emergency reserve canister)
5. At timer expiry: trigger `RestoreToSafeZone()`

Safe-Zone Registration:

A safe zone is any trigger volume tagged `SafeZone` with recorded depth <= 1000 m.
Updated continuously while player is conscious and within volume.

// Called while player is alive and inside SafeZone trigger
public static void RegisterSafeZone(ref SurvivalState state, Vector3 position, float depth)
{
    state.lastSafeZonePosition = position;
    state.lastSafeZoneDepth    = depth;
}

`RestoreToSafeZone()` - Zero-GC Teleport Path:

public static void RestoreToSafeZone(
    ref SurvivalState state,
    CharacterController characterController,
    SurvivalConfig cfg)
{
    // 1. Disable CharacterController to allow position write (Unity requirement)
    characterController.enabled = false;

    // 2. Teleport - single frame, no async, no coroutine
    characterController.transform.position = state.lastSafeZonePosition;

    // 3. Re-enable
    characterController.enabled = true;

    // 4. Restore minimum viable life support
    state.oxygenLevel   = Mathf.Max(state.oxygenLevel, 0.15f);  // Emergency O2 floor
    state.batteryLevel  = Mathf.Max(state.batteryLevel, 0.10f); // Emergency power floor
    state.isConscious   = true;

    // 5. Recalculate pressure for new depth
    state.depthPressure = DepthToMPa(state.lastSafeZoneDepth);

    // 6. Stress is PRESERVED - structural damage does not heal on revival
    //    (Stress reduction requires RepairKit consumable)

    // 7. Thermal reset to safe-zone ambient (safe zones are heated)
    state.internalTemp  = 18.0f; // Heated safe-zone baseline

    // 8. Disarm glitch state
    state.glitchIntensity = 0f;
    state.isGlitchActive  = false;
}

> RULE: Safe-zone restoration preserves `hullStress` and `hullIntegrity`.
> player returns damaged. This is intentional - revival is not reset.
> If stress >= 0.95 at revival, critical warning loop immediately resumes.

Stress Preservation Rationale:

Resetting stress on revival would negate asymptotic fatigue model and allow
exploit loops. structural damage hull sustained is physical fact. Players
must manage stress proactively or carry repair consumables.

## SECTION 5: SAFE - FALLBACKS & EDGE CASES

| Scenario | Handling |
|----------|----------|
| `hullIntegrity` reaches `0.01` floor | Stress accumulation rate reaches ~40x baseline. Implosion is seconds away. Intentional design. |
| Player has no registered safe zone (spawn case) | `lastSafeZonePosition` defaults to spawn point, depth = 0. `RestoreToSafeZone()` sends player to surface. |
| `dt` spike (>0.2s, e.g., loading stall) | All tick functions clamp `dt = min(dt, 0.05f)` to prevent single-frame stress spikes from instant death. |
| Battery reaches 0.0 | Suit heating disabled. `insulationFactor` set to `0.0`. Thermal decay accelerates to uninsulated rate. |
| Both O2 and battery at 0.0 | O2 depletion continues (no pump = no circulation). Faint trigger fires normally. Revival still possible if safe zone exists. |
| `externalTemp > internalTemp` (geothermal vent) | Exponential decay formula works identically - convergence direction reverses. No special case required. |
| Repair kit used at stress > 0.95 | Stress delta applied: `stress -= repairKit.stressReduction`. Fatal sequence re-checked. If stress drops below 0.95, `isFatalSequenceArmed` remains true but `ImplosionSequencer._fired` is false - implosion does NOT re-trigger unless stress returns to 1.0. |
| Multiple cold current volumes overlapping | Take `externalTemp` from volume with lowest temperature (worst case). Evaluated by `ThermalZoneManager`. |
