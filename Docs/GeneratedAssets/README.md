# Generated Assets Corpus

Status: `STATIC_SOURCE / STATIC_DOC`.

`Docs/GeneratedAssets` is an authoring support corpus only. It stores generated/source image candidates, prompt packs, source-bake experiments, QA notes, manifests, and contact sheets for later review.

This directory is not a Unity import location and is not production asset proof. File presence here does not prove:

- Unity import into `Assets/**`.
- Material, shader, terrain, water, sky, or Addressables binding.
- Runtime texture readiness, mip streaming, residency, VRAM, memory, frame-time, GC, or platform proof.
- Surface, photic, terrain, ocean, Aegir, cloud, moon, coastline, or route visual acceptance.

Promotion to production must go through the relevant authority docs and Unity evidence gates:

- `PROCEDURAL_ASSET_PIPELINE.md`
- `3DMODEL_TEXTURE_GENERATION_PLAYBOOK.md`
- `3DMODEL_TEXTURES_MATERIALS.md`
- `rendering.md`
- `water.md`
- `terrain.md`
- `Docs/ARCHITECTURE/ARM_TEXTURE_PACKING_PIPELINE.md`
- `Docs/ARCHITECTURE/PROJECT_RUNTIME_TOPOLOGY.md`

Allowed use: static source selection, prompt history, source QA, and intake planning. Rejected use: citing this corpus as imported asset readiness, material binding proof, runtime proof, visual proof, or platform readiness.
