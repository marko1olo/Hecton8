# AG3D-A Patch Plan Round 1

## Patch Items

### Patch 1: Enforce Sharp Normal Splitting on Geology Edges
- **Target File**: `Assets/_Project/Scripts/WorldGenerativeGeologyMeshBuilder.cs`
- **Target Symbol**: `PFB_family_rock_small_floor__group`
- **Change Shape**: Introduce a dot product check iterating through adjacent face normals. If the dot product indicates an angle greater than 45 degrees, split the shared vertex to create a hard edge seam, ensuring the normal does not average across the corner.
- **Validation**: Vertex count will increase by the number of split vertices. Normals exported must exhibit discontinuous vector values at steep boundaries.
- **Risk**: Increased vertex budget could push the mesh slightly over the LOD0 limit, requiring more aggressive decimation on flat areas.
- **Fallback**: Retain smooth normals but apply a baked normal map to simulate the hard edge offline.
