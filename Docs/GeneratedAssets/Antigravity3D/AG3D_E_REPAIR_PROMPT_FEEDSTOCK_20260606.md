# AG3D-E REPAIR PROMPT FEEDSTOCK FOR GENERATIVE MESH AGENTS

## 1. PURPOSE AND GROUND RULES
This document provides exact, non-hallucinated strings, file paths, and architectural rules for any future Antigravity 3D mesh generation or procedural asset refinement agents. The previous iteration (`AG3D_C`) failed catastrophically due to generative models inventing non-existent reference images (e.g., `ref_1_1.jpg`), hallucinating prefab names (e.g., `PFB_coral_tube_neon.prefab`), and relying on generic, repetitive language ("too clean", "add dirt", `random.choice`). 

**ALL GENERATIVE PROMPTS MUST BE SOURCED EXCLUSIVELY FROM THIS FEEDSTOCK.**

## 2. BAD PROMPT PATTERNS TO HARD REJECT
If an agent or a generation script outputs any of the following patterns, the execution must be aborted, and the prompt must be rewritten using the approved language in Section 3.

### 2.1 Hallucinated Reference Names
*   **REJECT:** "Based on `ref_2_deep.jpg`, the coral should..."
*   **REJECT:** "Looking at `image_01.png`..."
*   **REASON:** These files do not exist. Any reference must exactly match the `AG3D_E_REFERENCE_IMAGE_LEDGER_20260606.csv` list.

### 2.2 Hallucinated Prefab Names
*   **REJECT:** "Modify `PFB_Alien_Wreckage_Large.prefab`..."
*   **REJECT:** "Spawn `PFB_Seaweed_01`..."
*   **REASON:** The Hecton-8 procedural engine only recognizes the 88 prefabs located in `Assets/_Project/Prefabs/WorldProceduralProxy/`. Prefixing "PFB_" to a random noun does not create a valid asset.

### 2.3 Python/Algorithmic Clichés
*   **REJECT:** "Use `random.choice([mesh1, mesh2])` to add variety."
*   **REJECT:** "Iterate through a random loop to place barnacles."
*   **REASON:** The Hecton-8 scattering pipeline (`WorldProceduralScatterDirector.cs`) relies on deterministic, mathematically seeded noise algorithms (e.g., Voronoi, Perlin) and specific placement rules (`WorldProceduralPlacementRule.cs`). `random.choice` is a banned string because it implies non-deterministic, uncontrollable generation that breaks multiplayer sync and LOD bounds.

### 2.4 Generic Visual Critique
*   **REJECT:** "The mesh looks too clean. Add more dirt to make it realistic."
*   **REJECT:** "Break up the symmetry."
*   **REASON:** "Dirt" is not a shader property. "Break up symmetry" is an unactionable instruction for a mesh builder. Prompts must specify *how* to break symmetry (e.g., "Apply a boolean fracture to the X-axis edge and displace vertices using a high-frequency noise map with an amplitude of 0.15").
