# AG3D-C Asset Blueprint Atlas

This Atlas contains the definitive, rigorously defined architectural blueprints for the 15 targeted asset families in the Hecton-8 procedural generation pipeline. Every entry is backed by verifiable source prefabs, explicitly mapped reference imagery, and detailed constraints to prevent the catastrophic integration failures observed in previous generation passes.

## Family 1: Cave Entrance (`family_cave_entrance`)

### Asset 1: BP_CAVE_ENT_01
- **Source Reference:** `PFB_family_cave_entrance.prefab`
- **Image Mapping:** `UNDERWATER PREVIOUSLY IN DEVELOPMENT (MAPMAGIC + TEXTURES + CREST OCEAN).jpg`
- **Dimensions:** Width: 15.0m, Height: 10.0m, Depth: 8.0m. Represents a standard, vehicle-passable threshold.
- **Silhouette:** Jagged, arching semi-circle. The top edge must be heavily distressed to avoid reading as a manufactured tunnel.
- **Topology:** Extrude base opening matching local terrain slope constraint. The vertex density must be highest at the lip where it intersects the voxel terrain.
- **UV/Material:** Uses tri-planar mapping with `MAT_Rock_Limestone_Base` to prevent texture stretching on the extreme vertical faces of the entrance shaft.
- **LOD/Collider:** LOD0: 15,000 tris. Collision relies on a simplified custom mesh to prevent submersible snagging on the complex lip geometry.
- **Placement:** Anchored to sloped terrain. Must align its local Z-axis perfectly with the inverse normal of the cliff face.
- **Fail Cases:** If the entrance spawns on flat ground, the inner shaft will clip upwards through the terrain, creating an impossible floating ring.
