## Hot Path

1. Density owner or mock job writes SDF samples into `Density`.

2. `SurfaceNetExtractionJob` scans sign-crossing cells, computes one centroid vertex per cell, samples tetrahedral SDF gradients, packs normals/tangents/material blend, and writes indices.

3. Quad emission is edge-gated.
4. Index quad emits only when corresponding X/Y/Z grid-edge crosses the iso-surface.
5. Edge signs drive winding.
6. Raw debug triangles mirror exact final index order.

4. `SurfaceNetExtractionJob` writes indirect draw args into vault memory.

5. Caller owns the returned `JobHandle`; this module does not call `Complete()`.

7. Boot-prewarmed `VoxelSurfaceNetsGpuUploadDispatcher` starts upload with `TryBeginUpload`.
8. It locks vertex/index/indirect `GraphicsBuffer` objects with `LockBufferForWrite`.
9. It schedules `VoxelSurfaceGpuUploadCopyJob`.
10. Job copies vault vertices, indices, and indirect args directly into mapped buffer views.

7. Caller chains the upload `JobHandle` through the frame graph.
8. `TryFinalizeUpload` unlocks/publishes only after the caller dependency is complete.
9. Dispatcher performs no caller-thread bulk copy.
10. Dispatcher does not call `JobHandle.Complete()`.
