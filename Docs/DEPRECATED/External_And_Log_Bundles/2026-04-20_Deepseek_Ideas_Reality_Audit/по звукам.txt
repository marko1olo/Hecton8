Приветствую. Как ведущий аудио-инженер проекта HECTON-8, я прекрасно понимаю задачу. Звук не должен быть просто «шумным» — он должен вызывать физический дискомфорт, клаустрофобию и чувство неизбежности.

Мы не будем использовать готовые сэмплы. Только чистая математика и процедурная генерация. 400 атмосфер давления мы сымитируем через агрессивный FM-синтез (частотную модуляцию), добавив эффект прерывистого трения (stick-slip friction) металла.

Для саб-баса мы сгенерируем честный Brown Noise через FFT-фильтрацию (быстрое преобразование Фурье), а микротрещины реализуем через стохастические импульсы белого шума, пропущенные через каскад математических производных (что даст нам жесткий High-Pass фильтр).

Вот оптимизированный Python-скрипт, использующий только разрешенные numpy и scipy.io.wavfile.

import numpy as np
from scipy.io import wavfile

# --- [ КОНФИГУРАЦИЯ ] ---
SAMPLE_RATE = 44100
DURATION = 4.5  # секунд. Идеально для нарастающего саспенса.
t = np.linspace(0, DURATION, int(SAMPLE_RATE * DURATION), endpoint=False)
NUM_SAMPLES = len(t)

print("[1/6] Инициализация генератора давления...")

# --- [ LAYER 1: SUB-BASS PRESSURE (Дыхание бездны) ] ---
# Генерируем Белый шум и превращаем его в Коричневый шум (Brown Noise) через FFT-фильтр (1/f^2)
white_noise = np.random.normal(0, 1, NUM_SAMPLES)
W_freq = np.fft.rfft(white_noise)
freqs = np.fft.rfftfreq(NUM_SAMPLES, 1.0 / SAMPLE_RATE)
freqs[0] = 1.0  # Избегаем деления на ноль

# Фильтр: затухание высоких частот. Отрезаем всё, что ниже 20 Hz, чтобы не спалить сабвуферы игроков.
filter_curve = 1.0 / (freqs ** 1.2)
filter_curve[freqs < 20.0] = 0.0 
W_freq *= filter_curve

brown_noise = np.fft.irfft(W_freq, n=NUM_SAMPLES)
brown_noise /= np.max(np.abs(brown_noise))  # Нормализация

# LFO: медленное, удушающее пульсирование (0.3 Гц)
lfo_pressure = 0.6 + 0.4 * np.sin(2 * np.pi * 0.3 * t)
layer1_sub = brown_noise * lfo_pressure

print("[2/6] Синтез металлического скрежета (FM-Synthesis)...")

# ---[ LAYER 2: METALLIC FRICTION (Скрежет корпуса) ] ---
# Аддитивный FM-синтез: негармонические частоты, имитирующие толстые титановые плиты
f_carriers =[120.0, 315.0, 542.0, 830.0]
f_modulators =[45.0, 87.0, 133.0, 311.0]

# Огибающая основного стона: два нарастания давления за 4.5 секунды
groan_env = np.sin(2 * np.pi * 0.22 * t) ** 4 

# Эффект "Stick-Slip": прерывистое трение металла
chatter_noise = np.random.uniform(0.5, 1.0, NUM_SAMPLES)
stick_slip = 0.7 + 0.3 * np.sin(2 * np.pi * 35.0 * t) * chatter_noise

layer2_metal = np.zeros(NUM_SAMPLES)

for fc, fm in zip(f_carriers, f_modulators):
    # Металл гнется: частота медленно ползет вниз под давлением
    pitch_slide = 1.0 - 0.15 * np.linspace(0, 1, NUM_SAMPLES)
    
    # Интегрируем фазу для корректного изменения питча (Pitch Bend)
    phase_c = np.cumsum(fc * pitch_slide) / SAMPLE_RATE * 2 * np.pi
    phase_m = np.cumsum(fm * pitch_slide) / SAMPLE_RATE * 2 * np.pi
    
    # Индекс модуляции: чем сильнее давление (groan_env), тем агрессивнее гармоники
    mod_index = 6.0 * groan_env * stick_slip
    
    modulator = np.sin(phase_m)
    carrier = np.sin(phase_c + mod_index * modulator)
    
    layer2_metal += carrier * groan_env

# Нормализуем слой скрежета
layer2_metal /= np.max(np.abs(layer2_metal))

print("[3/6] Просчет микротрещин и лопающихся заклепок...")

# --- [ LAYER 3: MICRO-FRACTURES (Транзиенты) ] ---
# Генерируем 30 случайных точек "треска"
layer3_cracks = np.zeros(NUM_SAMPLES)
num_pops = 30
pop_times = np.random.randint(0, NUM_SAMPLES - 1000, num_pops)

# Создаем резкие экспансивные всплески шума
crack_noise = np.random.normal(0, 1, NUM_SAMPLES)
crack_env = np.zeros(NUM_SAMPLES)

for p in pop_times:
    # Острый экспоненциальный спад
    decay = np.exp(-np.linspace(0, 15, 1000))
    crack_env[p:p+1000] += decay * np.random.uniform(0.5, 1.0)

layer3_cracks = crack_noise * crack_env

# High-Pass фильтр (математическая производная от сигнала 2-го порядка)
# Отсекаем все низы, оставляем только острый "хруст" песка/металла
layer3_cracks = np.diff(layer3_cracks, prepend=0)
layer3_cracks = np.diff(layer3_cracks, prepend=0)
layer3_cracks /= (np.max(np.abs(layer3_cracks)) + 1e-9)

print("[4/6] Микширование и Soft Clipping (Искажение)...")

# --- [ СВЕДЕНИЕ И SOFT CLIPPING ] ---
# Пропорции микса
MIX_SUB = 0.85
MIX_METAL = 0.70
MIX_CRACKS = 0.35

mixed = (layer1_sub * MIX_SUB) + (layer2_metal * MIX_METAL) + (layer3_cracks * MIX_CRACKS)

# Имитируем перегруз акустической среды (Soft Clipping) через гиперболический тангенс.
# Drive = 2.5 сплющивает пики, делает звук грязным и монолитным.
DRIVE = 2.5
distorted = np.tanh(mixed * DRIVE)

print("[5/6] Обработка реверберацией кабины скутера...")

# ---[ ЭФФЕКТЫ: SMALL CABIN DELAY / REVERB ] ---
# Примитивная линия задержки. Используем простые числа миллисекунд для избежания резонансов.
delays_ms =[17, 23, 37, 43]
decays =[0.4, 0.3, 0.2, 0.15]

reverbed = np.copy(distorted)
for ms, decay in zip(delays_ms, decays):
    shift_samples = int((ms / 1000.0) * SAMPLE_RATE)
    shifted_signal = np.zeros(NUM_SAMPLES)
    shifted_signal[shift_samples:] = distorted[:-shift_samples] * decay
    reverbed += shifted_signal

print("[6/6] Мастеринг и экспорт...")

# ---[ МАСТЕРИНГ И ЭКСПОРТ ] ---
# Защита от клиппинга и приведение к 16-бит
final_audio = reverbed / np.max(np.abs(reverbed)) * 0.95 
audio_16bit = np.int16(final_audio * 32767)

wavfile.write("abyssal_hull_groan.wav", SAMPLE_RATE, audio_16bit)
print("Готово! Файл 'abyssal_hull_groan.wav' сгенерирован успешно.")
Разбор DSP-архитектуры для аудио-команды:

Brown Noise через FFT: Вместо стандартного np.cumsum для белого шума, который может вызывать дикое блуждание смещения по постоянному току (DC offset) и щелчки на краях, я применил быструю свертку в частотной области: кривую

Phase Accumulation (Интегрирование фазы): В блоке FM-синтеза частота (Pitch Slide) интегрируется через np.cumsum. Это дает физически-реалистичное и гладкое «сползание» питча металла под нагрузкой без артефактов (в отличие от умножения времени на изменяемую частоту напрямую).

Stick-Slip Effect: Низкочастотная шумовая модуляция (chatter_noise) заставляет FM-индекс дергаться. Из-за этого скрежет звучит не как ровный синт, а как металл, который с трудом ползет рывками друг по другу.

High-Pass (Производные): Использование двукратного np.diff() дает спад 12 дБ/октаву снизу вверх. Это мгновенный способ в чистом NumPy срезать весь низ из импульсов заклепок, оставив только пугающий, высокочастотный "песок".

Soft Clipping (tanh): np.tanh — классика цифрового овердрайва. Сжимает динамический диапазон как ламповый усилитель, "склеивая" гул, скрежет и щелчки в одно акустическое событие.

import numpy as np
from scipy.io import wavfile

def generate_sonar_ping():
    # Базовые параметры
    sample_rate = 44100
    duration = 4.0  # Общая длительность звука с учетом затухания эха
    t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)

    print("Инициализация акустических подсистем HECTON-8...")

    # ==========================================
    # СЛОЙ 1: THE ATTACK (Пьезо-удар)
    # ==========================================
    # Очень резкий щелчок. Мы генерируем высокочастотный синус и белый шум,
    # а затем "душим" их сверхбыстрой экспоненциальной огибающей (~5мс).
    attack_duration = 0.1
    t_attack = t[:int(sample_rate * attack_duration)]
    
    # Огибающая: np.exp(-t * 1000) падает почти до нуля как раз к 5-й миллисекунде
    env_attack = np.exp(-t_attack * 1000) 
    
    attack_sine = np.sin(2 * np.pi * 4500 * t_attack) # Резкий резонанс пьезокристалла
    attack_noise = np.random.randn(len(t_attack))     # Металлический лязг/искра
    
    attack_signal = env_attack * (attack_sine + 1.2 * attack_noise)
    attack_full = np.pad(attack_signal, (0, len(t) - len(attack_signal)))

    # ==========================================
    # СЛОЙ 2: THE CHIRP (Основной пробивающий импульс)
    # ==========================================
    # Линейная частотная модуляция (LFM) от 2000 Гц до 400 Гц за 0.5с.
    chirp_duration = 0.5
    t_chirp = t[:int(sample_rate * chirp_duration)]
    f_start = 2000
    f_end = 400
    
    # Интеграл от линейного изменения частоты дает квадратичную фазу
    phase_chirp = 2 * np.pi * (f_start * t_chirp + ((f_end - f_start) / (2 * chirp_duration)) * t_chirp**2)
    
    # Огибающая чирпа: мощный старт с плавным затуханием к концу 0.5с
    env_chirp = np.exp(-t_chirp * 5)
    chirp_signal = env_chirp * np.sin(phase_chirp)
    chirp_full = np.pad(chirp_signal, (0, len(t) - len(chirp_signal)))

    # ==========================================
    # СЛОЙ 3: THE ABYSSAL TAIL (Глубинное эхо)
    # ==========================================
    # Грязный низкочастотный рокот с "эффектом биений" (разница частот 150 и 147 Гц)
    tail_carrier = (
        np.sin(2 * np.pi * 150 * t) + 
        0.6 * np.sin(2 * np.pi * 147 * t) +  # Расстройка создает пульсацию толщи воды
        0.4 * np.sin(2 * np.pi * 300 * t)
    )

    # Генерация низкочастотного модулирующего шума (LFO)
    # Создаем 15 случайных точек и плавно интерполируем их на всю длину (создает мутные "волны")
    num_lfo_points = int(duration * 4) 
    lfo_noise = np.interp(
        np.linspace(0, 1, len(t)), 
        np.linspace(0, 1, num_lfo_points), 
        np.random.uniform(0.1, 1.0, num_lfo_points)
    )

    # Добавляем высокочастотный "песок/ил" — сглаженный белый шум
    mud_noise = np.convolve(np.random.randn(len(t)), np.ones(40)/40, mode='same')

    # Огибающая хвоста: эхо начинает нарастать с 0.1с (сразу после удара), 
    # достигает пика и долго затухает в бездне (4 км)
    env_tail = np.clip((t - 0.1) / 0.3, 0, 1) * np.exp(-(t - 0.1) * 0.9)

    tail_full = env_tail * lfo_noise * (tail_carrier + 0.3 * mud_noise)

    # ==========================================
    # МИКСИНГ И МАСТЕРИНГ
    # ==========================================
    print("Компиляция звуковых слоев и сатурация...")
    
    # Смешиваем слои с нужными пропорциями
    mixed_signal = 0.9 * attack_full + 1.0 * chirp_full + 0.7 * tail_full

    # Сатурация (Soft-clipping через гиперболический тангенс)
    # Это "сплющивает" пики сигнала, добавляя ему характерную электромагнитную теплоту и мощь
    driven_signal = np.tanh(mixed_signal * 1.8) / 1.8

    # Нормализация в 16-битный PCM
    final_signal = driven_signal / np.max(np.abs(driven_signal))
    audio_data = np.int16(final_signal * 32767)

    # Экспорт
    output_filename = "sonar_active.wav"
    wavfile.write(output_filename, sample_rate, audio_data)
    print(f"Готово! Акустический профиль сохранен как: {output_filename}")

if __name__ == "__main__":
    generate_sonar_ping()
Разбор механики звука (почему он звучит именно так):

Сатурация (np.tanh): Это секретный ингредиент. Вместо чистого математического сложения, гиперболический тангенс имитирует перегрузку аналоговых цепей. Удар и начало LFM-чирпа "сминаются", создавая эффект колоссального расхода энергии генератором скутера.

Phase Calculation: Чирп написан не через встроенные функции scipy.signal, а чисто математически через интеграл частоты. Это дает идеальный, непрерывный спад от 2000 Гц до 400 Гц без "щелчков" по фазе.

Beating Effect (Биения): В глубине хвоста звучат синусоиды на 150 Гц и 147 Гц. Разница в 3 Гц заставляет звук пульсировать (3 раза в секунду), что психоакустически воспринимается как огромное, замкнутое водное пространство или отражение от неровных стен каньона.

LFO Интерполяция: Мы генерируем случайный массив данных очень низкой частоты и натягиваем его (np.interp) на всю длину аудио. Это заставляет реверберацию (хвост) "дышать" и перекатываться, имитируя неровности рельефа (те самые воксельные скалы).


Этот скрипт — настоящая акустическая инженерия. Чтобы звук двигателя был идеально бесшовным (loopable), мы не можем просто сгенерировать случайный шум, так как на стыке начала и конца 5-секундного файла появится заметный щелчок.

Вместо этого мы используем генерацию шума в частотной области (через обратное преобразование Фурье - IFFT). Это математически гарантирует, что начало и конец волны идеально сойдутся друг с другом. А чтобы имитировать «нагрузку», мы завяжем интенсивность пузырьков на вращение винта скутера (LFO).

import numpy as np
from scipy.io import wavfile

def generate_thruster_loop(duration=5.0, load=0.85):
    """
    Генерирует бесшовный звук двигателя Manta.
    :param duration: Длительность лупа (строго 5.0 для совпадения фаз).
    :param load: Нагрузка на двигатель (0.0 - 1.0). Чем выше, тем жестче кавитация.
    """
    sample_rate = 44100
    # endpoint=False важен для бесшовного зацикливания, чтобы последний сэмпл не дублировал первый
    t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)
    N = len(t)

    print(f"Запуск реактора Manta... Нагрузка: {load*100}%")

    # ==========================================
    # СЛОЙ 1: THE HUM (Электромотор)
    # ==========================================
    # Базовая частота 80 Гц (идеально кратна 5 секундам: 80 * 5 = 400 полных циклов)
    # Гармоники создают "напряженное" жужжание обмоток статора
    hum = (
        1.00 * np.sin(2 * np.pi * 80 * t) + 
        0.60 * np.sin(2 * np.pi * 160 * t) + 
        0.35 * np.sin(2 * np.pi * 240 * t) + 
        0.15 * np.sin(2 * np.pi * 320 * t)
    )

    # ==========================================
    # ПОДГОТОВКА ИДЕАЛЬНОГО ШУМА (FFT-метод)
    # ==========================================
    # Генерируем массив частот. Использование IFFT гарантирует, 
    # что сгенерированный шум будет бесшовным при зацикливании.
    freqs = np.fft.rfftfreq(N, 1 / sample_rate)
    
    # ==========================================
    # СЛОЙ 2: THE FLOW (Турбулентность воды)
    # ==========================================
    # Создаем Розовый шум (спад энергии 1/sqrt(f))
    pink_mag = np.zeros_like(freqs)
    pink_mag[1:] = 1.0 / np.sqrt(freqs[1:]) 
    
    # Low-pass фильтр: пропускаем все до 600 Гц, затем плавный спад
    lp_filter = np.where(freqs <= 600, 1.0, np.exp(-(freqs - 600) / 150))
    
    # Генерируем случайные фазы и собираем спектр
    phases_flow = np.random.uniform(0, 2 * np.pi, len(freqs))
    flow_spectrum = pink_mag * lp_filter * np.exp(1j * phases_flow)
    
    # Переводим обратно во время
    flow = np.fft.irfft(flow_spectrum, n=N)
    flow /= np.max(np.abs(flow))  # Нормализация

    # ==========================================
    # СЛОЙ 3: THE CAVITATION (Пузырьки / Вскипание)
    # ==========================================
    # Band-pass фильтр: оставляем только высокие частоты (8-12 кГц)
    bp_filter = np.where((freqs >= 8000) & (freqs <= 12000), 1.0, 0.0)
    phases_cav = np.random.uniform(0, 2 * np.pi, len(freqs))
    cav_spectrum = bp_filter * np.exp(1j * phases_cav)
    
    cav_base = np.fft.irfft(cav_spectrum, n=N)
    
    # Возведение в 3-ю степень делает из сплошного "шипения" острые импульсы (треск лопающихся пузырьков)
    cav_crackle = cav_base ** 3
    cav_crackle /= np.max(np.abs(cav_crackle))

    # Динамика кавитации: привязываем к вращению лопастей винта (например, 20 оборотов в секунду)
    prop_rpm = 20 # 20 * 5 сек = 100 циклов (бесшовно)
    prop_lfo = (np.sin(2 * np.pi * prop_rpm * t) + 1) / 2  # От 0 до 1

    # Влияние переменной LOAD:
    # При load=1.0 (полный газ) пузырьки кипят почти постоянно (prop_lfo ** 0.5 - широкие пики)
    # При load=0.2 (холостой ход) пузырьки лишь слегка похрустывают на пиках оборотов (prop_lfo ** 4 - узкие пики)
    envelope_sharpness = 5.0 * (1.0 - load) + 0.5 
    dynamic_envelope = prop_lfo ** envelope_sharpness

    cavitation = cav_crackle * dynamic_envelope * (load * 1.5)

    # ==========================================
    # МИКСИНГ И МАСТЕРИНГ
    # ==========================================
    print("Синхронизация магнитных потоков...")
    
    # Сводим всё в единый массив (Flow дает "тело", Hum - "мотор", Cavitation - "агрессию")
    mix = 0.9 * hum + 1.2 * flow + 2.0 * cavitation
    
    # Сатурация/Искажения (NASA-punk стиль). Приближаем к прямоугольной волне для плотности
    driven = np.tanh(mix * 2.0) / 2.0
    
    # Нормализация в 16-битный PCM для WAV
    final_signal = driven / np.max(np.abs(driven))
    audio_data = np.int16(final_signal * 32767)

    # Сохраняем в файл
    filename = "manta_idle_loop.wav"
    wavfile.write(filename, sample_rate, audio_data)
    print(f"Аудио-луп успешно сгенерирован: {filename} (Бесшовность гарантирована)")

if __name__ == "__main__":
    # Попробуй поменять load от 0.1 до 1.0, чтобы услышать разницу в поведении турбины
    generate_thruster_loop(duration=5.0, load=0.85)
Главные фишки синтеза:

The FFT Loop Trick: В слоях Flow и Cavitation вместо встроенных генераторов numpy.random в прямом времени, мы берем спектр, вырезаем из него нужные частоты и конвертируем во время (np.fft.irfft). Это на 100% гарантирует, что начало файла сойдется с его концом с точностью до сэмпла.

Экспоненциальная огибающая load: Выражение prop_lfo ** envelope_sharpness. Эта математическая уловка меняет не просто громкость пузырьков, а их характер. При высокой нагрузке вода вокруг винта постоянно вскипает. При низкой — кавитация возникает только в самых пиковых точках вращения ротора (короткими, редкими всплесками).

Возведение шума в куб (cav_base ** 3): Простой фильтрованный шум на 8-12 кГц звучит как обычное шипение змеи. Но если возвести волну в третью степень, тихие звуки станут микроскопическими, а громкие пики сохранятся. В результате шипение превращается в высокочастотный треск/песок, который идеально описывает схлопывающиеся под водой вакуумные пузырьки.


Этот скрипт продолжает концепцию математической генерации бесшовных индустриальных звуков. Чтобы передать агрессию плазменного резака, пробивающего броню под давлением ледяной воды, мы используем хард-клиппинг (Hard Clipping) для имитации скрежета металла и FM-синтез для непредсказуемых «прострелов» электрической дуги.

Всё генерируется с учетом идеальной зацикленности (5 секунд), поэтому звук можно бесконечно проигрывать в игре без щелчков.

import numpy as np
from scipy.io import wavfile

def generate_cutter_loop(duration=5.0):
    sample_rate = 44100
    # endpoint=False гарантирует, что последний сэмпл не совпадает с первым (важно для лупа)
    t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)
    N = len(t)

    print("Активация термального резака. Внимание: зафиксировано внешнее давление воды...")

    # ==========================================
    # ВСПОМОГАТЕЛЬНАЯ ФУНКЦИЯ ДЛЯ БЕСШОВНОГО ШУМА
    # ==========================================
    freqs = np.fft.rfftfreq(N, 1 / sample_rate)
    
    def seamless_noise(filter_mask):
        """Генерирует идеально зацикленный шум заданной частотной формы через IFFT"""
        phases = np.random.uniform(0, 2 * np.pi, len(freqs))
        spectrum = filter_mask * np.exp(1j * phases)
        noise = np.fft.irfft(spectrum, n=N)
        return noise / np.max(np.abs(noise))

    # ==========================================
    # СЛОЙ 1: THE THERMAL SIZZLE (Кипение/Испарение)
    # ==========================================
    # High-pass фильтр: оставляем только "шипящие" частоты от 3 кГц и выше
    sizzle_mask = np.where(freqs > 3000, 1.0, 0.0) * np.exp(-(np.maximum(0, freqs-3000))/5000)
    raw_sizzle = seamless_noise(sizzle_mask)
    
    # Хаотичная амплитудная модуляция (AM) для имитации неравномерного кипения воды
    # Генерируем низкочастотный "управляющий" шум (до 30 Гц)
    am_mask = np.where(freqs < 30, 1.0, 0.0)
    am_mod = seamless_noise(am_mask)
    
    # Смещаем модулятор в диапазон [0.2, 1.0] и возводим в квадрат для агрессивности пульсаций
    am_env = (0.6 + 0.4 * am_mod) ** 2
    thermal_sizzle = raw_sizzle * am_env

    # ==========================================
    # СЛОЙ 2: THE STRUCTURAL RESONANCE (Вибрация корпуса)
    # ==========================================
    # Гудящие частоты. 120, 144 и 196 Гц идеально кратны 5 секундам (целое число циклов).
    base_res = (
        1.0 * np.sin(2 * np.pi * 120 * t) +
        0.6 * np.sin(2 * np.pi * 144 * t) +
        0.4 * np.sin(2 * np.pi * 196 * t)
    )
    
    # HARD CLIPPING (Жесткое ограничение). 
    # Умножаем синусоиды на 4 (перегруз), а затем жестко срезаем верхушки.
    # Это превращает мягкий гул в пронзительный металлический скрежет/сопротивление.
    resonance = np.clip(base_res * 4.0, -0.6, 0.6)
    
    # Легкое дрожание руки оператора (модуляция громкости резонанса)
    res_mod_mask = np.where(freqs < 5, 1.0, 0.0)
    res_mod = seamless_noise(res_mod_mask)
    resonance *= (0.8 + 0.2 * res_mod)

    # ==========================================
    # СЛОЙ 3: THE IONIZED ARC (Электрическая дуга / Плазма)
    # ==========================================
    # Частоты для FM-модуляции. Несущая (1500 Гц) модулируется низкочастотным треском (80 Гц)
    fm_carrier_freq = 1500
    fm_mod_freq = 80
    
    # Создаем редкие, острые "вспышки" плазмы, когда резак натыкается на тугоплавкий сплав.
    # Перемножение синусоид и возведение в 8-ю степень дает резкие импульсы.
    # 0.4 Гц и 1.8 Гц дают ровно 2 и 9 циклов за 5 секунд (бесшовно).
    arc_burst_env = (np.sin(2 * np.pi * 0.4 * t) * np.sin(2 * np.pi * 1.8 * t)) ** 8
    
    # Добавляем хаоса в огибающую вспышек
    arc_rnd_mask = np.where(freqs < 10, 1.0, 0.0)
    arc_rnd = seamless_noise(arc_rnd_mask)
    combined_arc_env = arc_burst_env * (0.8 + 0.5 * arc_rnd)
    
    # Индекс модуляции завязан на вспышки (когда вспышка - звук разрывается)
    mod_index = 18.0 * combined_arc_env
    
    fm_phase = 2 * np.pi * fm_carrier_freq * t + mod_index * np.sin(2 * np.pi * fm_mod_freq * t)
    ionized_arc = np.sin(fm_phase) * combined_arc_env

    # ==========================================
    # МИКСИНГ И МАСТЕРИНГ (Асимметричный дисторшн)
    # ==========================================
    print("Прожиг брони. Калибровка искажений...")
    
    # Сводим слои: кипение дает фактуру, резонанс - "тело", арка - пронзительные акценты
    mix = 1.0 * thermal_sizzle + 0.7 * resonance + 1.4 * ionized_arc
    
    # Асимметричный перегруз (Ламповый эффект)
    # Положительные полуволны скругляем (soft-clipping), отрицательные - жестко срезаем.
    # Это создает очень "рваный", индустриальный характер звука.
    mix_driven = mix * 1.8
    mix_driven = np.where(mix_driven > 0, np.tanh(mix_driven), np.clip(mix_driven, -0.8, 0.8))
    
    # Финальная нормализация
    final_signal = mix_driven / np.max(np.abs(mix_driven))
    audio_data = np.int16(final_signal * 32767)

    # Экспорт
    filename = "plasma_cut_loop.wav"
    wavfile.write(filename, sample_rate, audio_data)
    print(f"Запись термального повреждения сохранена: {filename} (5 сек, Бесшовно)")

if __name__ == "__main__":
    generate_cutter_loop()
Разбор механики звука:

Жесткий клиппинг металла (np.clip(base_res * 4.0, ...)): Изначально резонанс корпуса представляет собой мягкий аккорд из низких частот. Умножая его амплитуду в 4 раза и "отрезая" всё, что выходит за рамки [-0.6, 0.6], мы математически превращаем синусоиды в почти прямоугольные волны (Square wave). Это звучит как напряженная, скрипящая под огромным давлением сталь.

Экстремальный FM-синтез дуги: Индекс модуляции здесь плавающий (зависит от combined_arc_env и достигает значения 18.0). При нулевом индексе это был бы скучный писк на 1500 Гц. Но в моменты "вспышек" индекс резко возрастает, и звук буквально "разваливается" на агрессивный электромагнитный треск — именно так звучат пробои изоляции под высоким напряжением.

Асимметричный дисторшн в мастере: Конструкция np.where обрабатывает верхнюю и нижнюю часть звуковой волны по-разному. Положительные пики мягко сплющиваются тангенсом, а отрицательные безжалостно обрубаются. Это имитирует перегруженный транзистор (или сломанный микрофон скутера), который не справляется с экстремальной громкостью резака.

Математическое кипение: Использование возведения в квадрат для амплитудной огибающей кипения (am_env = (0.6 + 0.4 * am_mod) ** 2) делает перепады громкости шипения резкими и неравномерными, создавая иллюзию крупных пузырей пара, мгновенно коллапсирующих в холодной воде.

Этот скрипт погружает нас в область цифрового хоррора. В отличие от генерации двигателей или сонаров, здесь мы имитируем сломанный алгоритм синтеза речи. Hecton-OS пытается воссоздать человеческий голос, но из-за поврежденных кластеров памяти он проваливается в зловещую «долину сверхъестественного» (uncanny valley).

Для создания этого эффекта мы используем кастомный гранулярный синтезатор и частотный вокодер на основе фазового интегрирования.

import numpy as np
from scipy.io import wavfile

def generate_madness_whisper(duration=7.0):
    sample_rate = 44100
    t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)
    N = len(t)

    print("КРИТИЧЕСКАЯ ОШИБКА: Обнаружено несанкционированное обращение к голосовому модулю Hecton-OS...")
    print("Расшифровка битых секторов...")

    # ==========================================
    # СЛОЙ 1: THE UNCANNY PITCH (Ломаная речь / Вокодер)
    # ==========================================
    # Генерируем "фонемы" — случайные частоты, прыгающие по октавам.
    # Октавы (110, 220, 440, 880, 1760, 3520 Гц) дают зловещий, нечеловеческий строй.
    control_points = int(duration * 12)  # Скорость "разговора" (~12 фонем в секунду)
    octaves = np.array([110, 220, 440, 880, 1760, 3520])
    random_freqs = np.random.choice(octaves, control_points)
    
    # Интерполируем частоты на всю длину аудио
    freq_interp = np.interp(t, np.linspace(0, duration, control_points), random_freqs)
    
    # Сглаживаем скачки частот скользящим окном, чтобы получить быстрые Chirp-скольжения (глиссандо), 
    # а не мгновенные переключения. Это звучит как синтезатор, пытающийся "выговорить" буквы.
    window = np.ones(1500) / 1500
    smooth_freq = np.convolve(freq_interp, window, mode='same')
    
    # Интегрируем частоту (cumsum) для получения непрерывной фазы без щелчков
    phase = 2 * np.pi * np.cumsum(smooth_freq) / sample_rate
    voice_sine = np.sin(phase)
    
    # Добавляем "Дыхание/Шепот" — умножаем белый шум на нашу синусоиду.
    # Это переносит спектр шума на текущую частоту голоса (эффект примитивного вокодера).
    whisper_noise = np.random.randn(N)
    voice_core = 0.5 * voice_sine + 1.2 * (voice_sine * whisper_noise)

    # ==========================================
    # СЛОЙ 2: THE GRANULAR STUTTER (Заикание и микро-разрывы)
    # ==========================================
    stutter_mask = np.zeros(N)
    i = 0
    
    # Алгоритм гранулярной нарезки. Мы случайным образом включаем и выключаем звук
    while i < N:
        # Длина "зерна" (grain) звука: 10 - 30 мс
        grain_samples = int(sample_rate * np.random.uniform(0.01, 0.03))
        # Длина микро-паузы: 5 - 30 мс
        pause_samples = int(sample_rate * np.random.uniform(0.005, 0.03))
        
        # 15% шанс на длинную паузу (имитация разделения на "слова")
        if np.random.rand() > 0.85:
            pause_samples += int(sample_rate * np.random.uniform(0.1, 0.4))
            
        end_idx = min(i + grain_samples, N)
        grain_length = end_idx - i
        
        if grain_length > 0:
            # Случайная громкость для каждой гранулы (эффект рваной ленты)
            env = np.ones(grain_length) * np.random.uniform(0.2, 1.0)
            
            # Добавляем крошечный fade-in/fade-out (1 мс) по краям гранулы,
            # чтобы избежать DC-щелчков, оставляя только "цифровой" ритм.
            f_len = min(int(sample_rate * 0.001), grain_length // 2)
            if f_len > 0:
                fade = np.linspace(0, 1, f_len)
                env[:f_len] *= fade
                env[-f_len:] *= fade[::-1]
                
            stutter_mask[i:end_idx] = env
            
        i += grain_samples + pause_samples
        
    stuttered_voice = voice_core * stutter_mask

    # ==========================================
    # СЛОЙ 3: THE RING MODULATION (Металлический тембр)
    # ==========================================
    # Генерируем сверх-низкочастотный шум (около 25 Гц) с помощью интерполяции
    lf_points = int(duration * 25)
    lf_noise = np.interp(t, np.linspace(0, duration, lf_points), np.random.uniform(-1, 1, lf_points))
    
    # Смешиваем низкочастотный шум с чистым синусом на 55 Гц (даёт классический SCI-FI металл)
    rm_modulator = lf_noise + 0.6 * np.sin(2 * np.pi * 55 * t)
    
    # Ring Modulation: перемножаем гранулярный голос на модулятор
    alien_whisper = stuttered_voice * rm_modulator

    # ==========================================
    # МИКСИНГ И МАСТЕРИНГ (Уничтожение сигнала)
    # ==========================================
    print("Формирование аудио-галлюцинации...")
    
    # Экстремальный Hard-clipping. Разгоняем сигнал в 6 раз и жестко обрубаем.
    # Это превращает шепот в агрессивный цифровой "скрежет".
    driven_signal = np.clip(alien_whisper * 6.0, -0.9, 0.9)
    
    # Финальная нормализация
    final_signal = driven_signal / np.max(np.abs(driven_signal))
    audio_data = np.int16(final_signal * 32767)

    # Экспорт
    filename = "ai_whisper_glitch.wav"
    wavfile.write(filename, sample_rate, audio_data)
    print(f"Дамп памяти сохранен. Прослушайте {filename} (На свой страх и риск)")

if __name__ == "__main__":
    generate_madness_whisper()
Разбор механики звука (Психоакустика безумия):

Фазовое интегрирование (Слой 1): Самая частая ошибка при синтезе меняющихся частот (Chirp) — это просто передать массив частот в np.sin(2 * np.pi * freq * t). Это вызовет жуткие щелчки при каждом перепаде, потому что фаза сбрасывается. Мы используем метод np.cumsum(smooth_freq), который математически накапливает угол. Это заставляет ИИ плавно «тянуть» (скользить) гласные звуки, даже когда он прыгает на 3 октавы вверх.

Амплитудный Вокодер: ИИ не может «дышать». Чтобы сделать голос похожим на шепот, мы умножаем синусоиду на белый шум. Это концентрирует спектр шума ровно на частоте синусоиды. В результате мы слышим не писк, а скрежещущее шипение, меняющее свою тональность.

While-loop для Гранулярного Синтеза: Мы не используем стандартные LFO (синусоиды) для эффекта заикания, потому что они предсказуемы. Цикл while нарезает звук асимметричными кусками. Ваш мозг безуспешно пытается найти ритм в этих 10-30 мс обрывках, что вызывает чувство тревоги.

Ring Modulation (Кольцевая модуляция): При умножении звука на 55 Гц + НЧ-шум, появляются так называемые боковые полосы (sidebands) частот, которые математически не кратны основному тону. Именно эта некратность убивает человечность в голосе, придавая ему знаменитый металлический окрас (вспомни голоса Далеков из Доктора Кто, они были сделаны по точно такой же технологии, только аналоговой).

Этот скрипт — квинтэссенция саунд-дизайна для хоррора и клаустрофобии. Чтобы заставить игрока задыхаться, мы используем три независимых временных линии (LFO), которые ускоряются к концу аудиофайла, нагнетая панику.

Для генерации самого дыхания используется формантный синтез: белый шум пропускается через математические «трафареты», имитирующие акустику открытого горла на вдохе и замкнутого объема маски шлема на выдохе.

import numpy as np
from scipy.io import wavfile

def generate_exertion_breath(duration=5.0):
    sample_rate = 44100
    t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)
    N = len(t)

    print("КРИТИЧЕСКИЙ СБОЙ: Давление в контуре жизнеобеспечения падает...")
    print("Генерация акустического профиля гипоксии...")

    # ==========================================
    # СЛОЙ 1: THE INHALE/EXHALE (Форманты и поток воздуха)
    # ==========================================
    # Ускоряем дыхание к концу (от 0.35 Гц до 0.7 Гц)
    breath_rate = np.linspace(0.35, 0.7, N)
    breath_phase = 2 * np.pi * np.cumsum(breath_rate) / sample_rate
    
    # Создаем огибающие вдоха и выдоха. Смещение -0.15 создает мертвую зону (паузу в дыхании)
    inhale_env = np.maximum(0, np.sin(breath_phase) - 0.15)
    exhale_env = np.maximum(0, -np.sin(breath_phase) - 0.15)
    
    # Искажаем кривую: вдох резкий и обрывистый (паника), выдох тяжелый
    inhale_env = (inhale_env / np.max(inhale_env)) ** 1.5
    exhale_env = (exhale_env / np.max(exhale_env)) ** 2.0

    # Генерация формант (резонансов) через частотные маски (FFT)
    freqs = np.fft.rfftfreq(N, 1 / sample_rate)
    
    # Маска вдоха: Узкое горло, спазм. Резонанс на 1200 Гц и шипение зубов на 2800 Гц
    inhale_mask = 1.5 * np.exp(-((freqs - 1200) / 300)**2) + 0.8 * np.exp(-((freqs - 2800) / 600)**2)
    
    # Маска выдоха: Внутри шлема. Глухой "бочкообразный" резонанс 500 Гц и 1400 Гц
    exhale_mask = 2.0 * np.exp(-((freqs - 500) / 200)**2) + 0.6 * np.exp(-((freqs - 1400) / 400)**2)
    
    def generate_formant_noise(mask):
        phases = np.random.uniform(0, 2 * np.pi, len(freqs))
        return np.fft.irfft(mask * np.exp(1j * phases), n=N)

    inhale_noise = generate_formant_noise(inhale_mask)
    exhale_noise = generate_formant_noise(exhale_mask)
    
    # Добавляем "дрожь/хрип" на вдохе — амплитудная модуляция на 12 Гц (спазм диафрагмы)
    tremolo = 1.0 + 0.4 * np.sin(2 * np.pi * 12 * t) * inhale_env
    
    airflow = (inhale_noise * inhale_env + exhale_noise * exhale_env) * tremolo
    airflow /= np.max(np.abs(airflow))

    # ==========================================
    # СЛОЙ 2: THE VALVE CLICK (Механика клапанов маски)
    # ==========================================
    valves = np.zeros(N)
    
    # Ищем моменты, когда дыхание пересекает порог, чтобы спустить пружину клапана
    def get_triggers(env, threshold=0.05):
        is_active = (env > threshold).astype(int)
        crossings = np.where(np.diff(is_active) == 1)[0]
        return crossings

    all_starts = np.sort(np.concatenate([get_triggers(inhale_env), get_triggers(exhale_env)]))

    for idx in all_starts:
        click_len = int(sample_rate * 0.02) # 20 миллисекунд
        if idx + click_len < N:
            t_click = np.linspace(0, 0.02, click_len, endpoint=False)
            # Резкий механический щелчок: спад громкости + резонанс пружины клапана (1200 Гц) + шум
            env_click = np.exp(-t_click * 400)
            click_sig = env_click * (np.sin(2 * np.pi * 1200 * t_click) + 0.6 * np.random.randn(click_len))
            valves[idx:idx+click_len] += click_sig
            
    valves /= (np.max(np.abs(valves)) + 1e-9)

    # ==========================================
    # СЛОЙ 3: THE HEARTBEAT (Суб-бас)
    # ==========================================
    # Пульс ускоряется с 90 до 168 ударов в минуту (от 1.5 до 2.8 Гц)
    heart_bpm_hz = np.linspace(1.5, 2.8, N)
    heart_phase = 2 * np.pi * np.cumsum(heart_bpm_hz) / sample_rate
    
    # Формируем двойной удар (lub-dub). 
    # Возведение в 30-ю степень сужает широкую синусоиду до острых коротких пиков.
    lub = np.maximum(0, np.sin(heart_phase)) ** 30
    dub = np.maximum(0, np.sin(heart_phase - 1.2)) ** 30 * 0.6 # Смещение фазы дает второй удар
    heart_env = lub + dub
    
    # Несущая частота сердца (40 Гц) дает ощутимый толчок в сабвуфер.
    heart_carrier = np.sin(2 * np.pi * 40 * t)
    
    # Сглаженный НЧ-шум добавляет глухой "удар в грудную клетку"
    heart_noise = np.convolve(np.random.randn(N), np.ones(100)/100, mode='same') 
    
    heartbeat = heart_env * (heart_carrier + 0.4 * heart_noise)
    heartbeat /= np.max(np.abs(heartbeat))

    # ==========================================
    # МИКСИНГ И МАСТЕРИНГ (Внутренности скафандра)
    # ==========================================
    print("Компиляция биометрических данных...")
    
    # Клапаны и дыхание звучат громко, а сердце пульсирует "под" ними
    mix = 1.0 * airflow + 0.4 * valves + 1.2 * heartbeat
    
    # Сатурация для клаустрофобного эффекта
    # Сплющивание синусоиды (tanh) имитирует перегруз дешевого микрофона внутри шлема,
    # который не справляется с агрессивным давлением воздуха.
    driven = np.tanh(mix * 1.5) / 1.5
    
    final_signal = driven / np.max(np.abs(driven))
    audio_data = np.int16(final_signal * 32767)

    filename = "player_breath_stress.wav"
    wavfile.write(filename, sample_rate, audio_data)
    print(f"Готово. Уровень паники сохранен: {filename}")

if __name__ == "__main__":
    generate_exertion_breath()
Разбор механики звука (Акустическая психология):

Интеграция частоты (np.cumsum): Чтобы сердце и дыхание ускорялись бесшовно, мы не можем просто использовать формулу sin(f * t), так как при изменении f фаза разорвется. Вместо этого мы интегрируем частоту кадр за кадром (накопление фазы). Сердце плавно срывается с 90 ударов в минуту до почти критических 168.

Формантные кривые (np.exp в частотной области): Вместо сложных каскадов IIR-фильтров, мы строим в спектре Гауссовы «колокола» на частотах 1200 и 2800 Гц. Пропуская через них белый шум с помощью обратного преобразования Фурье (irfft), мы физически моделируем прохождение воздуха через узкую щель гортани, не используя сэмплы реального голоса.

Хрип диафрагмы (tremolo): При сильной панике мышцы сводит судорогой. Амплитудная модуляция в 12 Гц, наложенная только на фазу inhale_env, заставляет воздух прерываться («запинаться»), что мгновенно считывается нашим мозгом как крайняя степень стресса.

Алгоритм триггеров (get_triggers): Чтобы клапаны щелкали строго в тот момент, когда подается воздух, скрипт анализирует огибающую дыхания, находит пересечения нулевой отметки с помощью функции разницы массива np.diff и математически "стреляет" 20-миллисекундным кликом пружины редуктора.

Этот скрипт завершает нашу картину тяжелой индустриальной акустики HECTON-8. Звук удара многотонного меха под водой кардинально отличается от удара на суше. Здесь нет резкого эха, зато есть мощное распространение низких частот через плотную среду и шуршание поднятого со дна ила.

Мы используем Pitch Drop (свип частоты вниз) для создания эффекта колоссальной массы, Ring Modulation (кольцевую модуляцию) для имитации звона полых металлических ног экзокостюма и кастомный розовый шум, чтобы нарисовать облако подводной пыли.

import numpy as np
from scipy.io import wavfile

def generate_mech_impact(duration=3.0):
    sample_rate = 44100
    t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)
    N = len(t)

    print("Регистрация сейсмического толчка. Расчет массы объекта...")

    # ==========================================
    # СЛОЙ 1: THE LOW THUD (Масса и Удар)
    # ==========================================
    # Имитация массы через быстрое падение частоты (Pitch Envelope).
    # Частота стартует с 200 Гц и за долю секунды падает до саб-баса в 40 Гц.
    freq_drop = 40 + 160 * np.exp(-t * 40)
    
    # Интегрируем частоту для получения непрерывной фазы
    phase = 2 * np.pi * np.cumsum(freq_drop) / sample_rate
    
    # Огибающая удара: мгновенная атака и плотное, но короткое затухание
    thud_env = np.exp(-t * 6)
    
    # Добавляем жесткую сатурацию уже на этапе генерации, чтобы "расплющить" синус
    # и получить плотный прямоугольно-подобный панч.
    raw_thud = np.sin(phase) * thud_env
    heavy_thud = np.tanh(raw_thud * 5.0) / 2.0

    # ==========================================
    # СЛОЙ 2: THE MECHANICAL RING (Лязг и звон конструкций)
    # ==========================================
    # Звон металла не бывает гармоничным. Мы берем некратные частоты в диапазоне 400-800 Гц.
    metal_carrier = (
        1.0 * np.sin(2 * np.pi * 412 * t) +
        0.7 * np.sin(2 * np.pi * 538 * t) +
        0.4 * np.sin(2 * np.pi * 781 * t)
    )
    
    # Ring Modulation: умножаем на низкую частоту (140 Гц). 
    # Это создает интермодуляционные искажения — знаменитый "ведерный" или "роботизированный" тембр.
    ring_modulator = np.sin(2 * np.pi * 140 * t)
    
    # Резкая атака для лязга. Звон металла затухает быстрее, чем низкочастотный гул.
    ring_env = np.exp(-t * 12)
    mechanical_ring = metal_carrier * ring_modulator * ring_env

    # ==========================================
    # СЛОЙ 3: THE SILT DISPLACEMENT (Всплеск ила и песка)
    # ==========================================
    # Генерируем Розовый шум (спад 3 дБ на октаву) через FFT, 
    # он звучит более массивно и "темно" по сравнению с белым.
    freqs = np.fft.rfftfreq(N, 1 / sample_rate)
    
    # Защита от деления на ноль для первой частоты (DC)
    pink_mag = np.zeros_like(freqs)
    pink_mag[1:] = 1.0 / np.sqrt(freqs[1:])
    
    # Low-pass фильтр: ил тяжелый, поэтому срезаем все выше 400 Гц, оставляя только низкий гул потока
    lp_filter = np.where(freqs <= 400, 1.0, np.exp(-(freqs - 400) / 200))
    
    phases = np.random.uniform(0, 2 * np.pi, len(freqs))
    spectrum = pink_mag * lp_filter * np.exp(1j * phases)
    silt_noise = np.fft.irfft(spectrum, n=N)
    
    # Нормализация шума перед наложением огибающей
    silt_noise /= np.max(np.abs(silt_noise))
    
    # Огибающая ила: нарастает за 50мс (пока песок поднимается со дна) 
    # и очень медленно оседает.
    silt_env = np.clip(t / 0.05, 0, 1) * np.exp(-t * 2.5)
    silt_displacement = silt_noise * silt_env

    # ==========================================
    # МИКСИНГ И МАСТЕРИНГ (Акустика толщи воды)
    # ==========================================
    print("Компиляция звуковых слоев и физики среды...")
    
    # Смешиваем. Тhud дает удар в грудь, Ring дает металл, Silt дает реализм окружения.
    mix = 1.5 * heavy_thud + 0.9 * mechanical_ring + 1.2 * silt_displacement
    
    # Экстремальная компрессия (Soft-Clipping).
    # Умножаем на 3.0, чтобы "впечатать" звук в потолок, а tanh сгладит углы, 
    # создавая ощущение чудовищного перепада давления в воде при ударе.
    driven_impact = np.tanh(mix * 3.0) / 1.5
    
    # Финальная нормализация
    final_signal = driven_impact / np.max(np.abs(driven_impact))
    audio_data = np.int16(final_signal * 32767)

    # Экспорт
    filename = "heavy_mech_thud.wav"
    wavfile.write(filename, sample_rate, audio_data)
    print(f"Анализ завершен. Акустический след записан: {filename}")

if __name__ == "__main__":
    generate_mech_impact()
Разбор механики звука (Физика удара):

Эффект Инерции (freq_drop): Синус, который просто играет на 40 Гц, звучит как гул трансформатора. Но если заставить частоту экспоненциально упасть с 200 Гц до 40 Гц за первые миллисекунды, наше ухо воспринимает это как "удар", физический толчок массивного объекта. Этот прием (Pitch Envelope) используется для синтеза всех барабанов (Kicks) в электронной музыке.

Динамический перегруз (np.tanh(raw_thud * 5.0)): Мы сплющиваем чистый синус основного удара еще до сведения со всем остальным миксом. Это делает «тело» удара толстым, квадратным (по форме волны) и невероятно плотным, имитируя гидродинамический удар в воде.

Некратный металл: Полые металлические предметы (как броня меха) никогда не резонируют чистыми аккордами. Мы используем частоты 412, 538, 781 Гц — они математически не соотносятся друг с другом (диссонанс). А перемножение их на 140 Гц (Ring Mod) дробит эти частоты еще сильнее, генерируя грязный индустриальный звон.

Смещение ила (Атака огибающей): Функция np.clip(t / 0.05, 0, 1) создает линейное нарастание громкости ровно за 50 миллисекунд (fade-in), после чего вступает в силу спадающая экспонента. В отличие от металла и удара (которые происходят мгновенно в нулевую секунду), ил имеет микро-задержку в раскрытии звука. Эта крошечная разница во времени атаки дает мозгу понять, что звук имеет масштаб и физику: Сначала удар -> потом поднимается облако.

Этот скрипт моделирует смерть электроники. Звук электромагнитного импульса (ЭМИ) — это не просто взрыв. Это звук того, как энергия мгновенно выжигает цепи, процессоры теряют тактовую частоту, а трансформаторы захлебываются.

Для этого мы применим цифровую деградацию (с помощью векторизованного Sample-and-Hold), генерацию квадратных волн (для жесткого гула) и экспоненциальный спад частоты (Pitch Drop).

import numpy as np
from scipy.io import wavfile

def generate_emp_surge(duration=4.0):
    sample_rate = 44100
    t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)
    N = len(t)

    print("ВНИМАНИЕ: Зафиксирован пробой экранирования. Выброс ЭМИ...")

    # ==========================================
    # СЛОЙ 1: THE STATIC BURST (Разряд и цифровой треск)
    # ==========================================
    # Для создания эффекта "умирающего процессора" мы используем эффект Sample-and-Hold (S&H).
    # Частота дискретизации (квантования) шума начинается с 15000 Гц и стремительно падает до 50 Гц.
    sh_freq = 50 + 15000 * np.exp(-t * 5)
    
    # Интегрируем частоту, чтобы получить фазу сэмплирования
    sh_phase = np.cumsum(sh_freq) / sample_rate
    
    # Превращаем фазу в целые индексы. Это векторизованный математический трюк:
    # массив indices будет выглядеть как[0,0,1,1,1,2,2, ...], создавая "ступеньки" во времени.
    indices = np.floor(sh_phase).astype(int)
    
    # Генерируем случайный белый шум и "растягиваем" его по индексам S&H
    random_values = np.random.randn(indices[-1] + 2)
    sh_noise = random_values[indices]
    
    # Огибающая: мощнейшая атака в начале, затухающая за 1.5 секунды
    burst_env = np.exp(-t * 4)
    static_burst = sh_noise * burst_env

    # ==========================================
    # СЛОЙ 2: THE POWER DOWN (Затухание турбин / конденсаторов)
    # ==========================================
    # Глиссандо: стремительное падение частоты от 1000 Гц до 50 Гц.
    freq_drop = 50 + 950 * np.exp(-t * 3.5)
    
    # Накопление фазы (cumsum) для плавного спада без щелчков
    phase_drop = 2 * np.pi * np.cumsum(freq_drop) / sample_rate
    
    # Создаем синусоиду, но слегка перегружаем ее, чтобы звук был более синтетическим
    power_down_raw = np.sin(phase_drop)
    power_down_env = np.exp(-t * 2)
    power_down = power_down_raw * power_down_env

    # ==========================================
    # СЛОЙ 3: THE HIGH-VOLTAGE HUM (Отключение питания)
    # ==========================================
    # Используем функцию np.sign, чтобы превратить синус в КВАДРАТНУЮ волну (Square Wave).
    # Квадратная волна содержит бесконечное количество нечетных гармоник, создавая "жужжание" тока.
    # Смешиваем 60 Гц и 50 Гц для диссонанса (неисправный трансформатор).
    hum_60 = np.sign(np.sin(2 * np.pi * 60 * t))
    hum_50 = np.sign(np.sin(2 * np.pi * 50 * t))
    voltage_hum_base = 0.6 * hum_60 + 0.4 * hum_50
    
    # Создаем "агонию" трансформатора перед отключением.
    # До 0.4 секунды гул ровный, затем начинает запинаться (модулируется 15 Гц),
    # а после 0.8 сек - мгновенно умирает (жесткая экспонента).
    stutter = np.maximum(0, np.sign(np.sin(2 * np.pi * 15 * t))) # Вкл/Выкл 15 раз в секунду
    
    hum_env = np.ones(N)
    cutoff_point = int(sample_rate * 0.8)
    hum_env[:cutoff_point] = 0.7 + 0.3 * stutter[:cutoff_point]
    hum_env[cutoff_point:] = np.exp(-(np.linspace(0, duration - 0.8, N - cutoff_point)) * 40)
    
    voltage_hum = voltage_hum_base * hum_env

    # ==========================================
    # СЛОЙ 4: THE SUB-PUNCH (Сам удар волны ЭМИ)
    # ==========================================
    # Крошечный, но сверхмощный суб-басовый хлопок в самом начале (0-50мс)
    pop_phase = 2 * np.pi * np.cumsum(80 * np.exp(-t * 60)) / sample_rate
    emp_pop = np.sin(pop_phase) * np.exp(-t * 40) * 2.0

    # ==========================================
    # МИКСИНГ И МАСТЕРИНГ (Уничтожение динамики)
    # ==========================================
    print("Выжигание микросхем...")
    
    # Собираем все слои
    mix = 1.2 * static_burst + 1.0 * power_down + 0.5 * voltage_hum + emp_pop
    
    # Жесткий лимитер и сатурация.
    # Умножение на 4 перед tanh загоняет сигнал в экстремальный перегруз,
    # что имитирует физическое перегорание аудио-тракта от высокого напряжения.
    driven_mix = np.tanh(mix * 4.0) / 2.0
    
    # Финальная нормализация
    final_signal = driven_mix / np.max(np.abs(driven_mix))
    audio_data = np.int16(final_signal * 32767)

    filename = "emp_blast.wav"
    wavfile.write(filename, sample_rate, audio_data)
    print(f"Цепи обесточены. Аудио-отчет сохранен: {filename}")

if __name__ == "__main__":
    generate_emp_surge()
Разбор механики звука (Акустика смерти электроники):

Векторизованный Sample-and-Hold (indices = np.floor(sh_phase)): Это невероятно мощный математический прием. Вместо того чтобы фильтровать белый шум эквалайзерами, мы обманываем время. В начале скрипта шум сэмплируется на частоте 15 кГц (звучит как обычное шипение). Но к концу секунды частота сэмплирования падает до 50 Гц. Звук разбивается на огромные цифровые "пиксели" (ступеньки), превращаясь в жесткий роботизированный скрежет (Bitcrush/Decimation). Это звук того, как процессору не хватает тактовой частоты.

Квадратные волны трансформатора (np.sign): Обычная электросеть гудит синусоидально. Но когда цепь пробивает, напряжение прыгает рывками. Функция np.sign берет плавную синусоиду и превращает её в жесткие прямоугольники из 1 и -1. Математически, квадратная волна несет в себе гигантское количество нечетных гармоник (слышимое "зузжание"), которое идеально ложится в индустриальный NASA-punk.

Голосовое заикание сети (stutter): Гул отрубается не сразу. Между 0.0 и 0.8 секунды мы умножаем гул трансформатора на другую квадратную волну (15 Гц), значения которой колеблются между 0 и 1 (np.maximum). Это создает короткие микро-разрывы питания — словно автоматика отчаянно щелкает реле, пытаясь перезапустить систему, прежде чем окончательно умереть.

Сверхбыстрый Pitch Drop (emp_pop): ЭМИ — это волна невидимой энергии, но она бьет физически. Секретный 4-й слой создает хлопок (Punch), частота которого падает

Этот скрипт генерирует атмосферу первобытного ужаса. Инфразвук и низкие частоты (25-37 Гц) в реальной жизни вызывают у человека необъяснимое чувство тревоги, так как находятся на границе восприятия.

Чтобы не использовать медленные for-циклы для имитации резонансного фильтра, я применил изящный DSP-трюк: Синтез узкополосного шума через амплитудную модуляцию. Мы генерируем сверхнизкий гул (до 5 Гц) и математически "сдвигаем" его на плавающую частоту (150-300 Гц) с помощью перемножения на синусоиду. Это дает 100% точный эффект завывания ветра в трубах или гуляющего резонанса подводных пещер.

import numpy as np
from scipy.io import wavfile

def generate_abyss_drone(duration=10.0):
    sample_rate = 44100
    t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)
    N = len(t)
    freqs = np.fft.rfftfreq(N, 1 / sample_rate)

    print("Погружение на 4000 метров. Кавернозные резонансы активны...")

    # ==========================================
    # ВСПОМОГАТЕЛЬНАЯ ФУНКЦИЯ: FFT-Генератор LFO (Perlin-like)
    # ==========================================
    def make_smooth_lfo(cutoff_hz, min_val, max_val):
        """Генерирует идеально гладкий, медленный случайный сигнал (похожий на Perlin Noise)"""
        noise_spec = np.fft.rfft(np.random.randn(N))
        # Жесткий срез всего, что выше cutoff_hz (оставляем только медленные колебания)
        mask = np.where(freqs < cutoff_hz, 1.0, 0.0)
        lfo = np.fft.irfft(noise_spec * mask, n=N)
        # Нормализация в диапазон [min_val, max_val]
        lfo = (lfo - np.min(lfo)) / (np.max(lfo) - np.min(lfo))
        return min_val + lfo * (max_val - min_val)

    # ==========================================
    # СЛОЙ 1: THE DEEP LOOM (Инфразвуковой Гул и Биения)
    # ==========================================
    # Базовые частоты: 25, 31, 37 Гц (Они создают темный, мистический аккорд)
    # Добавляем к каждой частоте микро-смещение (detune), чтобы они "переливались" (Phasing)
    f_bases = [25.0, 31.0, 37.0]
    detunes =[0.15, -0.12, 0.18]
    
    loom_raw = np.zeros(N)
    for f, df in zip(f_bases, detunes):
        # Основной инфразвук
        loom_raw += np.sin(2 * np.pi * f * t) + np.sin(2 * np.pi * (f + df) * t)
        # Добавляем вторую гармонику (октаву выше), чтобы гул был слышен даже на ноутбуках
        loom_raw += 0.4 * np.sin(2 * np.pi * (f * 2) * t)
        
    # Легкий перегруз (сатурация) добавляет гулу физической плотности
    deep_loom = np.tanh(loom_raw * 1.5) / 1.5

    # ==========================================
    # СЛОЙ 2: THE DISTANT MOAN (Стон Бездны)
    # ==========================================
    # 1. Генерируем плавающую частоту фильтра (от 150 до 300 Гц), меняется каждые 2-3 секунды
    wandering_freq = make_smooth_lfo(0.4, 150, 300)
    phase_moan = 2 * np.pi * np.cumsum(wandering_freq) / sample_rate
    
    # 2. Генерируем "воздух" для фильтра (очень низкочастотный шум с плавным спадом)
    noise_spec = np.fft.rfft(np.random.randn(N))
    bandpass_width = np.exp(-freqs / 8.0) # Мягкий спад к 15-20 Гц
    breathy_noise = np.fft.irfft(noise_spec * bandpass_width, n=N)
    breathy_noise /= np.max(np.abs(breathy_noise))
    
    # 3. МАГИЯ DSP: Перемножаем плавающую синусоиду на НЧ-шум. 
    # Это переносит спектр шума на частоту синусоиды, создавая идеальную иллюзию 
    # блуждающего резонансного фильтра с высоким Q (эффект воющей трубы)
    moan_resonant = breathy_noise * np.sin(phase_moan)
    
    # 4. Фоновый Коричневый шум (Brownian Noise) — массивное движение водной толщи
    brown_mask = 1.0 / (np.maximum(freqs, 1.0) ** 1.5)
    brown_noise = np.fft.irfft(noise_spec * brown_mask, n=N)
    brown_noise /= np.max(np.abs(brown_noise))

    distant_moan = 2.0 * moan_resonant + 0.8 * brown_noise

    # ==========================================
    # СЛОЙ 3: THE WATER WEIGHT (Давление Среды)
    # ==========================================
    # Очень медленная амплитудная модуляция (цикл ~4-5 секунд),
    # которая заставляет весь звук "накатывать" и "отступать", имитируя течения
    pressure_lfo = make_smooth_lfo(0.2, 0.4, 1.0)

    # ==========================================
    # МИКСИНГ И МАСТЕРИНГ (Погружение во тьму)
    # ==========================================
    print("Синтез давления толщи воды...")
    
    # Смешиваем Гул и Стон, пропуская их через модулятор Давления
    mix = (1.2 * deep_loom + 1.0 * distant_moan) * pressure_lfo
    
    # Пленка (Soft-clipping). Не дает пикам пробить 0 дБ и "склеивает" инфразвук с шумом
    driven_mix = np.tanh(mix * 2.0) / 2.0
    
    # Убираем DC-offset (смещение константы), которое могло возникнуть при сатурации
    driven_mix -= np.mean(driven_mix)
    
    # Финальная нормализация
    final_signal = driven_mix / np.max(np.abs(driven_mix))
    audio_data = np.int16(final_signal * 32767)

    filename = "deep_void_drone.wav"
    wavfile.write(filename, sample_rate, audio_data)
    print(f"Атмосфера Бездны сгенерирована: {filename} (Наденьте наушники)")

if __name__ == "__main__":
    generate_abyss_drone()
Разбор механики звука (Акустика ужаса):

Phasing (Биения): Инфразвук в скрипте звучит не ровно. Перемножение и сложение частот (например, 25 Гц и 25.15 Гц) заставляет их то математически складываться (громко), то взаимоуничтожаться (тихо). Этот цикл занимает несколько секунд. Мозг считывает эту пульсацию как "дыхание" чего-то гигантского во тьме.

SSB Синтез вместо фильтров: Функция distant_moan. Вместо того, чтобы создавать шум и "резать" его медленными эквалайзерами, мы создаем частоту (wandering_freq), на которой должен звучать стон, и обволакиваем ее микроскопическим шумом (breathy_noise). Это дает кристально чистое, пугающее "пение" воды.

FFT Перилин-шум (make_smooth_lfo): Классическая функция np.random дает песок (белый шум). Чтобы заставить давление и стон плавно и непредсказуемо меняться (как Perlin Noise), мы генерируем шум в спектральной области (rfft), отрубаем всё, что выше 0.4 Гц, и конвертируем обратно во время (irfft). Получается идеальная, органическая кривая, по которой движется вся атмосферная жизнь трека.
