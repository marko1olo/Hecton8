## Purpose

This playbook defines the exact runtime evidence required before the mod API status can move from `PENDING RUNTIME VERIFICATION` to `VERIFIED`. It does not grant new API rights. It verifies that the static contract survives Unity runtime execution.

The current authority is envelope-only. The old managed callback playbook remains below as legacy source-audit context; it is not the active runtime acceptance path while managed mod entry, managed event bridges, resource proxy registration, content filesystem discovery, and legacy command lanes are quarantined.

## Current Envelope-Only Test Mod

The required test package is not a gameplay `.dll`. It is a package generated by the SDK or a fixture that emits deterministic `FutureCommandEnvelope` streams.

Required package contents:

```text
EnvelopeOnlyFixture.h8mod
  manifest.h8json
  commands.h8bin
  assets.h8manifest
  sdk_validation_report.txt
```

Required manifest fields:

- stable mod id;
- required API version;
- mod priority;

- declared command budget;
- declared asset byte ceiling;
- deterministic package hash.

No `EntryAssembly`, `EntryType`, `.dll`, `.bundle`, or `lang_*.json` runtime ingress is allowed in this fixture.

## Current Envelope-Only Runtime Steps

### Step E1 - Static Package Gate

Run the modding static validator and the SDK/package validator when available.

Required evidence:

- `Validate_Mod_API_Static.ps1` reports `PASS` or records a precise static failure.
- Package manifest includes `RequiredAPIVersion` and `ModPriority`.
- Package `mod.json` is non-empty and `<=32768` bytes; oversized manifests are skipped before JSON read.
- Package discovery enumerates `mod.json` lazily and caps discovery at 64 manifests before candidate allocation.
- Package manifest uses canonical mod id and dependency ids: lowercase letter/digit segments separated by single `.`, `_`, or `-`; no whitespace, separator-only ids, path-ish ids, or reserved filesystem device names.
- Explicit `EntryAssembly`, when present for legacy-source audit fixtures, is a package-local `.dll` file name only.
- Blank or anonymous execution scope cannot satisfy public facade owner guards; active scope requires a non-empty mod id and non-zero owner hash.
- Package declares capabilities that match emitted opcode families.
- No managed entry path is declared.
- Package DLL file names and assembly metadata identities do not use reserved engine/runtime names: `Hecton8.*`, `Unity*`, `Assembly-CSharp`, `System`, `mscorlib`, or `netstandard`; the cold gate scans every accepted top-level package DLL up to the 32-DLL cap, over-cap packages are disabled, and the SDK builder caps selected DLLs at `32`, rejects duplicate output names, and removes stale output DLLs through bounded cleanup.
- No loose runtime asset/content file is discovered as a runtime ingress path.
- Public `HectonAPI.Events` subscribe/publish calls outside active `ModExecutionScope` throw `IllegalContractException` before reporting envelope-only quarantine status.
- `SubscribeNative` native byte payload sources have explicit schema-checked layouts: `InteractionEventPayload = 32` bytes and `CraftingEventPayload = 64` bytes.
- Public `RequestFuture` calls outside active `ModExecutionScope` or with mismatched `ModderSignature` throw `IllegalContractException`.
- Public legacy command facade calls (`Request`, `RequestAup`, `RequestRenderInstance`) outside active `ModExecutionScope` throw `IllegalContractException`; inside active scope they return quarantine `false`.
- Resource hash registration rejects any `modId` that does not match the active `ModExecutionScope`.
- Public `HectonAPI.Events.Publish<TPayload>` rejects engine-owned payload types when managed event bridges are exercised by a first-party harness.

### Step E2 - Unity Load Gate

Start Unity and load:

```text
00_BOOTSTRAP -> 01_MAIN_MENU -> 01_ORBIT -> 02_HECTON_WORLD
```

Required evidence:

- Unity Console has no compile errors.
- Package is discovered without executing managed mod callbacks.
- Managed factory registration remains rejected in envelope-only mode.
- Direct filesystem content discovery remains disabled.
- `FutureCommandSandboxValidator` initializes before any legacy command dispatcher allocation.

### Step E3 - Valid Envelope Gate

Submit a small deterministic stream of valid envelopes through public `HectonAPI.Commands.RequestFuture` and, in a separate first-party harness only, through internal loader bulk-ingress routes.

Required evidence:

- accepted envelope count matches the fixture expectation;
- opcode allowlist accepts only declared/approved opcodes;
- integrity hash is checked over bytes `0..47`;
- valid asset reference envelopes pass CRC32 and declared byte count checks;
- downstream engine-facing output is unmanaged signal or DevNull, not a managed callback.

### Step E4 - Rejection Gate

Submit invalid fixtures:

- bad opcode hash;
- bad integrity hash;
- non-finite `TargetAUP`;
- AUP outside +/-50 km;
- non-finite numeric payload for fauna/spawn numeric lanes;
- CRC mismatch;
- asset byte count mismatch;
- packet flood above per-mod frame budget.

Required evidence:

- each fixture produces deterministic rejection counters;
- no exception is thrown to gameplay;
- no first-party object handle is exposed;
- telemetry ring records the failure class;
- NaN payloads do not enter downstream signals.

### Step E5 - Thermal Shed Gate

Drive effective quality below `0.3` through `GlobalQualityWeight` and `CpuThermalPressure01`.

Required evidence:

- accepted command budget collapses continuously, not by binary low/high branch;
- backlog above the safe window is dropped;
- frame remains responsive;
- thermal shed count is visible to telemetry/editor monitor.

### Step E6 - Rollback Freeze Gate

Set the local rollback flag view at buffer `70752`, bit `1 << 4`, or use the explicit test override if present.

Required evidence:

- validation freezes or drops runtime-mutating packets during rollback resimulation;
- no direct `Hecton8.Networking` assembly reference is required by the sandbox validator;
- queued stale packets do not replay later into an inconsistent frame.

### Step E7 - Legacy Surface Quarantine Gate

Try the old surfaces from a controlled fixture:

- `HectonAPI.Commands.Request`;
- `RequestAup`;
- `RequestRenderInstance`;
- managed event subscribe/publish;
- resource registry/proxy registration;
- bundle/localization filesystem registration.

Required evidence:

- old command methods return `false`;
- managed event bridges no-op, throw the documented contract exception, or remain uninstalled according to source;
- resource/content paths do not allocate legacy registries in envelope-only mode;
- no managed callback is invoked.

### Step E8 - GC/Profiler Gate

Capture runtime metrics during valid, invalid, flood, thermal, and rollback tests.

Required evidence format:

```text
BEFORE: <measured KB/frame>
AFTER: <measured KB/frame>
STATUS: 0 B hot-path envelope validation / PENDING if nonzero
Profiler markers: FutureCommandSandboxValidator validation/drain markers when available
```

Required result:

- hot-path envelope validation: 0 B/frame;
- no single mod sandbox frame path exceeds 0.1 ms without a documented quality/thermal gate;
- no unbounded queue growth;
- no private persistent native container allocation by the validator.

## Pass Criteria

The mod API can be marked `VERIFIED` only when all conditions below are true:

- Static validator passes.
- Unity Console is clean after loading the test mod.
- Only `CombatDamageSignal` and `WeatherChangedSignal` reach `SubscribeProjected`.
- Native byte events expose no native container handles.
- Command rejection and quota payloads are delivered.
- Loader/save contracts match `Loader_Save_Audit_Matrix.md`.
- Event subscription contracts match `Event_Subscription_Audit_Matrix.md`.
- Resource/content contracts match `Resource_Content_Audit_Matrix.md`.
- Change control requirements match `Change_Control_Checklist.md`.
- SaveState stores only mod-owned text under the scoped mod boundary.
- `OnUnload` prevents later callbacks.
- GC hot-path projection dispatch is 0 B/frame.
- Profiler captures show no unbounded callback fanout.
