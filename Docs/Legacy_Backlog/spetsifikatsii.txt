1. Sozday prefab kollaydera

Na prefabe ne nuzhen MeshRenderer, MeshFilter, Rigidbody. Tolko BoxCollider (ili SphereCollider). Maksimalno legkovesnyy.

text

200 kollayderov — eto maksimum, kotoryy mozhet byt aktiven odnovremenno v radiuse 40m. Dlya plotnyh skopleniy uvelich do 300-500.

4. Initsializiruy pozitsii iz generatora mira
csharp

// V tvoem WorldGenerator ili GPUInstancerManager:
public class RockGenerator : MonoBehaviour
{
    [SerializeField] private ProximityColliderSystem proximitySystem;
    
    private void Start()
    {
        // Generiruem pozitsii kamney (oni zhe idut v GPU Instancer)
        Vector3[] rockPositions = GenerateRockPositions(10000);
        
        // Peredaem GPU Instancer...
        gpuInstancer.SetPositions(rockPositions);
        
        // ...i sisteme kollayderov
        proximitySystem.Initialize(rockPositions);
    }
}

Klyuchevye resheniya
TempJob dlya _prevStatusNative: allotsiruetsya kazhdyy kadr, no eto NativeArray — ne GC heap. Allokator TempJob pereispolzuet memory pool vnutri Unity. Alternativa — derzhat persistent, no togda nuzhen dopolnitelnyy Dispose tracking

maxOperationsPerTick = 64: pri teleportatsii igroka na 500m mozhet potrebovatsya 200+ Spawn i 200+ Despawn. Bez limita — spayk 5-10ms. S limitom — rastyanetsya na 6-7 kadrov, nezametno dlya igroka

Gisterezis 40/45m: bez nego kollaydery na rasstoyanii rovno 40m budut kazhdyy kadr Spawn→Despawn→Spawn→Despawn. S gisterezisom — odin Spawn, stabilnost do 45m
