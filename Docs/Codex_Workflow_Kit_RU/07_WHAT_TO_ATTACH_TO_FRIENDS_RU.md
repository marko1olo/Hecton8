# Что Скидывать Друзьям

Если у друзей свои проекты, не надо скидывать им все HECTON-8 файлы. Им нужна схема.

## Скинуть Им Эту Папку

Скиньте целиком:

```text
Codex_Workflow_Kit_RU/
```

Этого достаточно, чтобы они поняли:

- как писать `AGENTS.md`;
- как давать Codex operator prompt;
- как оркестрировать агентов;
- как использовать Gemini для генерации картинок/текстур;
- как требовать proof;
- как не принимать фейковые отчеты.

## Что Им Нужно Создать У Себя

В своем проекте они должны создать свои файлы:

- `AGENTS.md`
- `TASTE.md` или `PRODUCT_TASTE.md`
- `VISION_LOCKS.md` или `PRODUCT_LOCKS.md`
- `PROJECT_BIBLES.md` или `DOCS_INDEX.md`
- доменные docs по своему проекту

Не надо копировать чужие игровые правила, если проект другой.

## Сообщение Для Друзей

```text
Я скидываю тебе не документацию моего проекта, а workflow kit для Codex.

Открой README_START_HERE_RU.md.
Сначала сделай в своем проекте AGENTS.md по шаблону.
Потом дай Codex prompt из 02_CODEX_OPERATOR_PROMPT_RU.md.
Если хочешь, чтобы Codex управлял несколькими агентами, используй 03_MANUAL_ORCHESTRATION_PROMPT_RU.md.
Если надо генерировать картинки/текстуры через Gemini, используй 04_GEMINI_IMAGE_ASSET_WORKFLOW_RU.md и английские prompts из 05_IMAGE_PROMPT_TEMPLATES_EN.md.

Главная идея: Codex должен работать руками - читать релевантные документы, править файлы, запускать проверки, управлять GUI, делать screenshots, скачивать assets и честно отделять proof от планов.
```
