🏛 ТОТАЛЬНЫЙ РЕЕСТР СИСТЕМНЫХ ГРЕХОВ (ДОПОЛНЕНИЕ КО ВСЕМ МАНДАТАМ)

1. СЕКТОР: РЕНДЕР И GPU (MX350 DEATH SQUAD)

  - [REND-01] Кастомные синусы: Агенты пытались внедрить полиномы Тейлора для
    sin/cos в шейдеры. На MX350 есть железные блоки SFU, которые делают это
    быстрее. Тяжесть: P2.
  - [REND-02] PCIe Bus Saturation: Использование ComputeBuffer.SetData() для
    загрузки позиций игрока. Это блокирует CPU, пока GPU не ответит. Нужно
    использовать GraphicsBuffer.LockBufferForWrite. Тяжесть: P0.
  - [REND-03] Alpha-to-Coverage vs Clip: Использование clip() в фрагментном
    шейдере отключает Early-Z на Pascal-архитектуре. Это убивает филлрейт
    MX350. Нужно использовать A2C или Depth Prepass. Тяжесть: P1.
  - [REND-04] Reversed-Z Decal Inversion: Ошибка в формуле смещения (-= bias). В
    Reversed-Z буфере (Unity 6) это вжимает декали ВНУТРЬ стен. Нужно += bias.
    Тяжесть: P1.
  - [REND-05] Broken HDR Bloom: Применение ACES-тонемаппинга вручную внутри
    шейдеров материалов. Это зажимает яркость в [0..1] и убивает эффект
    Bloom. Тонемаппинг должен быть только в финальном Resolve-пассе. Тяжесть:
    P1.

2. СЕКТОР: ФИЗИКА И МАТЕМАТИКА (KINETIC BOMBS)

  - [PHYS-01] Diagonal Drag Warp: Квадратичный драг считался по осям независимо.
    Это создает «магнитное» притяжение к диагоналям мира. Нужно считать от
    общего вектора скорости (math.length). Тяжесть: P1.
  - [PHYS-02] Verlet Zero-Distance NaN: В формуле троса при нулевом расстоянии
    (overlap) происходит деление на 0. Вся цепочка троса превращается в NaN и
    исчезает. Тяжесть: P0.
  - [PHYS-03] Internal Momentum Deletion: При экстренном телепорте игрока внутри
    подлодки скорость игрока тупо приравнивалась к скорости лодки. Относительная
    инерция (бег) стиралась — игрок «бил мордой стену». Тяжесть: P2.
  - [PHYS-04] Relative Recoil Catapult: Отдача от резака прикладывалась только к
    игроку, игнорируя массу подлодки. В итоге игрока «выстреливало» сквозь
    обшивку внутри судна. Тяжесть: P1.
  - [PHYS-05] Inertia Tensor Thrashing: Скрипт менял mass и centerOfMass
    подлодки каждый кадр. В PhysX это вызывает пересчет тензора и фриз
    Main Thread. Нужно менять inertiaTensor напрямую. Тяжесть: P0.

3. СЕКТОР: ПАМЯТЬ И ПОТОКИ (BURST/JOB CRASHERS)

  - [MEM-01] Managed Rigidbody in Burst: Попытка передать массив Rigidbody[]
    (ссылочный тип) внутрь Burst-джобы. Мгновенный краш сборки. Тяжесть: P0.
  - [MEM-02] Managed Mesh.vertices in Job: Попытка читать mesh.vertices в
    потоке. Это вызывает аллокацию массива в куче и
    InvalidOperationException. Нужно AcquireReadOnlyMeshData. Тяжесть: P0.
  - [MEM-03] Nested NativeContainers: Попытка засунуть NativeList внутрь
    NativeHashMap. Это «смертный грех» Unity — утечки памяти, которые нельзя
    отследить. Тяжесть: P0.
  - [MEM-04] Illegal Ref Access: Попытка сделать ref array[index] для атомарных
    операций. Индексатор NativeArray возвращает значение, а не ссылку. Нужно
    использовать указатели (void*). Тяжесть: P0.
  - [MEM-05] Managed AudioSettings in Burst: Вызов AudioSettings.dspTime из
    аудио-потока. Потоки аудио не имеют доступа к манагед-классам. Тяжесть:
    P0.

4. СЕКТОР: ДАННЫЕ И ЛОГИКА (ARCHITECTURAL DEBTS)

  - [DATA-01] UID Birthday Paradox: Использование миллисекунд для генерации ID
    предметов. При взрыве и выпадении 20 кусков руды в один кадр они получат
    одинаковый ID, и 19 из них исчезнут. Нужен атомарный счетчик. Тяжесть: P1.
  - [DATA-02] O(N*M) Dehydration Hell: Линейный поиск по тысячам объектов в
    реестре для их удаления. При плотных сценах CPU просто встанет. Нужна
    NativeHashMap для обратного поиска. Тяжесть: P0.
  - [DATA-03] Save-Corrupting Pointers: Ошибка в LoadBinaryBlock. Прибавление
    +64 к указателю uint* прыгает на 256 байт вместо 64. Сейв будет прочитать
    невозможно. Тяжесть: P0.
  - [DATA-04] Non-Conservative Energy Leak: Использование Якоби-релаксации для
    токов без соблюдения закона Кирхгофа. База будет сама «создавать» или
    «пожирать» электричество из пустоты. Тяжесть: P1.
  - [DATA-05] Negative Modulo Array Crash: Расчет хеша hash % TILE_SIZE на
    отрицательных координатах выдает отрицательный индекс. Мгновенный
    вылет потока стриминга. Тяжесть: P0.

5. СЕКТОР: ИИ И СЕНСОРИКА (SENSORY FAILURES)

  - [AI-01] Negative-Space Grid Collapse: Кламп координат в ячейку [0,0,0] для
    всех объектов в отрицательных координатах. Половина рыб в океане будет
    обсчитываться в одной точке, вызывая TDR-краш видеокарты. Тяжесть: P0.
  - [AI-02] Spatial Hash Negative Cluster: XOR-хеширование отрицательных чисел
    забивает все ячейки сонара в одну кучу. Сонар ослепнет в половине мира.
    Тяжесть: P1.
  - [AI-03] Impossible Compute Logic: Попытка вернуть List<int> из функции в
    HLSL. Шейдеры не умеют работать с динамическими списками. Тяжесть: P0.
