🧬 ДОПЗАДАНИЕ: ПРОЦЕДУРНЫЙ ГЕНЕРАТОР «SAR_GASSUM_ULTRA»

Концепция:
Саргассовы водоросли — это не трава на воде. Это массивные, запутанные плавучие «острова», имеющие объем, внутреннюю структуру и сложную физику. Они должны выглядеть как золотисто-коричневые кружевные маты, которые дышат вместе с океаном.

1. Структурная Магия (Алгоритм ветвления)

Забудь про один меш. Мы будем использовать Стохастическую L-систему (Stochastic L-System) для создания каждого «куста»:

Главный стебель: Имеет кривизну, зависящую от «возраста» куста.

Пневматоцисты (Air Bladders): Генератор должен расставлять маленькие золотистые пузырьки-поплавки в узлах ветвления. В шейдере они должны иметь Subsurface Scattering (SSS), чтобы солнце просвечивало их насквозь, как маленькие фонарики.

Микро-листья: Зубчатые, полупрозрачные края, создающие «шумный» силуэт.

2. Физика «Живого Ковра» (Island Clustering)

Саргассы должны формировать колонии. Мы применим алгоритм метаболов (Metaballs logic) или клеточных автоматов для распределения:

Водоросли притягиваются друг к другу, формируя плотные центры и изрезанные, «рваные» края.

Collision Avoidance: Когда игрок или скутер влетает в остров, кусты не просто «прогибаются», они должны расталкиваться в стороны (разрыв ковра), а после прохождения — медленно дрейфовать обратно под действием фиктивного притяжения.

3. Визуальные Эффекты «Wow-уровня»

Вертексная анимация 2.0: Каждый куст имеет свою фазу качания, но они все подчиняются глобальному вектору волны Crest.

Подводная часть: Остров имеет «бороду» — свисающие вниз на 1.5–2 метра тонкие нити. При взгляде снизу они должны создавать потрясающую игру света («лучи бога», пробивающиеся сквозь путаницу стеблей).

Экологический след: Генератор должен спавнить вокруг островов «морской снег» (частицы детрита) и мелких полупрозрачных креветок/рыбок, которые живут только в этих зарослях.

ДЕТАЛИЗАЦИЯ МЕША «SAR_GASSUM_MONSTER»
Мы создаем не «плоскую заплатку», а многоуровневый объемный спрут. Каждый процедурный экземпляр — это сложная иерархия элементов:
1. «Скелетная» структура (Fractal Backbone)
Главный Хребет: Центральный гибкий стебель с переменной толщиной (толще у основания, почти нитевидный на концах). Он не прямой, а имеет «память изгиба» — закручивается в спирали, создавая объемный каркас.
Вторичное Ветвление: От главного стебля под углом 45–60 градусов отходят боковые побеги. Они переплетаются между собой, формируя структурную сетку. Это ключевой момент: ветки должны физически пересекаться в пространстве, создавая эффект запутанного «вороньего гнезда».
2. «Лиственная» масса (Serrated Foliage)
Морфология листа: Листья — это узкие, длинные ланцетные формы с зубчатыми (пильчатыми) краями. В процедурном меше края должны иметь микро-изломы, чтобы при освещении создавались тысячи мелких бликов (спекл-эффект).
Плотность заполнения: Мы используем алгоритм «облака точек». Листья растут пучками по 3–5 штук из каждого узла ветвления. В центре «острова» меш максимально плотный (нулевая видимость сквозь него), к краям — разреженный, распадающийся на отдельные усики.
Текстурные вариации: Часть листьев должна быть «увядшей» — скрученной и темной, часть — молодой, почти прозрачной на солнце.
3. Пневматоцисты (Buoyancy Berries)
Янтарные пузырьки: Это сотни мелких сферических поплавков, закрепленных у оснований листьев.
Визуальный акцент: Они — главные «ловцы света». В меше это отдельные мелкие лоу-поли сферы. В шейдере они получают мощный Backlighting (просвет сзади). Когда игрок ныряет под водоросль и смотрит на солнце, он должен видеть тысячи светящихся янтарных «ягод».
4. «Подводная Борода» (Abyssal Roots)
Нижняя часть острова генерирует длинные (до 3–5 метров), свисающие вертикально вниз нити.
Динамика: У этих нитей в шейдере прописана другая физика качания — они инертны, медленно колышутся под действием глубинных течений, в то время как верхушка острова повторяет ритм поверхности Crest.
5. Параметры «Наполненности» (Fullness Logic)
Multi-Layering: Меш строится в 3–4 слоя.
Слой 1 (Топ): Золотистый, подсохший на солнце.
Слой 2 (Ватерлиния): Самый густой и сочный.
Слой 3 (Погружной): Полупрозрачный, темно-коричневый.
Ambient Occlusion: Процедурный генератор должен запекать в Vertex Color данные о плотности — чем глубже внутрь куста, тем темнее цвет (Self-Shadowing), это создаст ощущение «глубины» внутри растительного мата.

Представь: ты плывешь на скутере. Впереди — гигантское золотистое поле, занимающее сотни метров. Оно не плоское.
Сверху: Ты видишь рельефную, «пушистую» массу, которая вздымается и опадает на 2-метровых волнах. Трава раздвигается перед твоим носом, обнажая темную воду внутри.
Сбоку: Виден «пирог» из стеблей, пузырьков и листьев толщиной в полтора метра.
Снизу: Это инопланетный потолок. Сквозь сплетения нитей и янтарные пузырьки пробиваются «God Rays», а в корнях прячутся мелкие рыбки.

🌑 1. Оптическая тень и «Световой фильтр» (Light Occlusion)
Саргассовы острова огромны и плотны. Они не могут просто пропускать свет насквозь.
Задача для шейдера: Реализуй Shadow Mask. Под плавающим островом на морском дне должна появляться мягкая динамическая тень (Shadow Blob).
Эффект «God Rays»: Когда игрок находится под водорослями, лучи солнца должны «разбиваться» об структуру меша. В толще воды должны быть видны четкие световые столбы, пробивающиеся сквозь «дырки» в растительном ковре. Это создаст невероятную атмосферу «подводного леса».
🌊 2. Физическое сопротивление и вязкость (Drag & Friction)
Саргассы — это путаница стеблей. Плыть сквозь них должно быть трудно.
Логика для Агента 1 (Физика): Внедрите зону Localized Drag. Когда игрок заплывает внутрь меша саргассовых водорослей (детектируй это по позиции относительно «островов»), его скорость должна плавно снижаться на 30–50%.
Инерция: Скутер должен «вязнуть» в траве, заставляя игрока искать обходные пути или прорубаться сквозь них. Это превратит водоросли из декорации в геймплейное препятствие.
🔊 3. Аудио-резонанс (Tactile Soundscape)
Вход в саргассовый лес должен ощущаться ушами.
Задача: Когда камера игрока пересекает границы «острова», аудио-микшер должен переключаться.
Звуки: Добавь приглушенный шорох, треск пузырьков (пневматоцист) и глухое «хлюпанье» стеблей о скафандр. Звук открытого океана должен сменяться «уютным», но тревожным шумом живой массы.
🦐 4. Микро-биота (Procedural Micro-Life)
Остров — это дом. Без жителей он будет казаться мертвым.
Задача для генератора: В коде спавна меша предусмотрите «точки интереса».
Детали: Пускай вокруг веток генерируются частицы «морского снега» (детрит) и редкие, привязанные к мешу мелкие спрайты инопланетных креветок или планктона. Они не должны иметь сложного ИИ, просто лениво плавать в радиусе 1 метра от веток, создавая эффект кишащей жизни.

1. ГЕНЕРАТОР МЕША: Стохастическая L-Система и Запекание Данных

Класс: SargassumGrowth
Отвечает за процедурную генерацию единичного "супер-куста". Меш собирается динамически через NativeArray для молниеносной скорости. Данные пакуются в Vertex Color и UV:

Color.r = Ambient Occlusion (чем глубже/ближе к центру, тем темнее).

Color.g = Subsurface Scattering (SSS) Mask (1.0 для пузырьков-пневматоцист, 0.5 для листьев, 0.0 для толстых стеблей).

Color.b = Фаза качания (Vertex Animation Phase) для десинхронизации волн Crest.

Color.a = Идентификатор слоя/жесткости (0.0 = инертная «борода», 1.0 = жесткий плавучий центр).

using UnityEngine;

    [Header("Структура L-Системы (Fractal Backbone)")]
    public int maxGenerations = 5;
    public float baseLength = 2.0f;
    public float lengthDecay = 0.75f;
    public float baseThickness = 0.1f;
    public float thicknessDecay = 0.6f;

    public float curlAmplitude = 45f; // Градусы изгиба

    public GameObject bladderPrefab;[Range(0,1)] public float bladderSpawnChance = 0.3f;
    public float rootLength = 5.0f;

    // Структура «Черепахи» для L-Системы
    private struct TurtleState
    {
        public float3 position;
        public quaternion rotation;
        public float length;
        public float thickness;
        public int generation;
        public float depth; // Глубина внутри ковра для AO
    }

    private Mesh generatedMesh;
    private List<Vector3> vertices = new List<Vector3>();
    private List<int> triangles = new List<int>();
    private List<Color> vertexColors = new List<Color>();
    private List<Vector4> uv2_data = new List<Vector4>(); // Для физики Crest и Ветра

    public void GenerateSargassumMonster(int seed)
    {
        UnityEngine.Random.InitState(seed);
        vertices.Clear(); triangles.Clear(); vertexColors.Clear(); uv2_data.Clear();
        
        TurtleState rootState = new TurtleState 
        {
            position = float3.zero,
            rotation = quaternion.identity,
            length = baseLength,
            thickness = baseThickness,
            generation = 0,
            depth = 1.0f // Топ слой
        };

        // Запуск рекурсивной L-системы для верхушки (Топ и Ватерлиния)
        GenerateBranch(rootState);

        // Генерация «Абиссальной Бороды» (Abyssal Roots)
        GenerateRoots(rootState);

        // Финализация меша
        generatedMesh = new Mesh();
        generatedMesh.indexFormat = UnityEngine.Rendering.IndexFormat.UInt32; // Меш будет огромным
        generatedMesh.SetVertices(vertices);
        generatedMesh.SetTriangles(triangles, 0);
        generatedMesh.SetColors(vertexColors);
        generatedMesh.SetUVs(1, uv2_data); // UV2 хранит вектора для качания
        generatedMesh.RecalculateNormals();
        generatedMesh.RecalculateBounds();
        
        GetComponent<MeshFilter>().sharedMesh = generatedMesh;
    }

    private void GenerateBranch(TurtleState state)
    {
        if (state.generation >= maxGenerations) return;

        // 1. Изгиб стебля (Perlin Memory)
        // Генерируем 3D шум для плавного закручивания стебля в спирали
        float noiseX = noise.snoise(state.position * curlFrequency) * curlAmplitude;
        float noiseY = noise.snoise(state.position * curlFrequency + new float3(100,0,0)) * curlAmplitude;
        float noiseZ = noise.snoise(state.position * curlFrequency + new float3(0,100,0)) * curlAmplitude;
        
        quaternion curlRot = quaternion.Euler(math.radians(noiseX), math.radians(noiseY), math.radians(noiseZ));
        state.rotation = math.mul(state.rotation, curlRot);

        // 2. Вычисление конечной точки сегмента
        float3 forward = math.mul(state.rotation, new float3(0, 1, 0));
        float3 endPos = state.position + (forward * state.length);

        // 3. Генерация геометрии сегмента (Цилиндр с переменным радиусом)
        BuildStemCylinder(state.position, endPos, state.thickness, state.thickness * thicknessDecay, state.depth);

        // 4. Ветвление (Stochastic Branching) - 3 боковых побега
        int branchCount = UnityEngine.Random.Range(2, 4);
        for (int i = 0; i < branchCount; i++)
        {
            float branchAngle = UnityEngine.Random.Range(45f, 75f);
            float azimuthAngle = (360f / branchCount) * i + UnityEngine.Random.Range(-15f, 15f);
            
            quaternion branchRot = math.mul(state.rotation, quaternion.Euler(math.radians(branchAngle), math.radians(azimuthAngle), 0));
            
            TurtleState nextState = new TurtleState
            {
                position = endPos,
                rotation = branchRot,
                length = state.length * lengthDecay,
                thickness = state.thickness * thicknessDecay,
                generation = state.generation + 1,
                depth = state.depth - 0.2f // Чем дальше поколение, тем ближе к краям/глубже -> меняется AO
            };

            GenerateBranch(nextState);
        }

        // 5. Размещение пневматоцист и микро-листьев в узлах
        SpawnFoliageAndBladders(endPos, state.rotation, state.generation, state.depth);
    }

    private void GenerateRoots(TurtleState rootState)
    {
        // Подводная борода генерируется вниз от центра
        int rootStrands = 15;
        for (int i = 0; i < rootStrands; i++)
        {
            float3 rootPos = rootState.position + (float3)UnityEngine.Random.insideUnitCircle * 2.0f;
            // Нити идут строго вниз с легким шумом
            // Vertex Color A = 0.0f (Инертная физика, не качается от волн, качается от течений)
            BuildStemCylinder(rootPos, rootPos - new float3(0, rootLength, 0), 0.02f, 0.005f, 0.0f);
        }
    }

    // Вспомогательные функции BuildStemCylinder и BuildBladderMesh 
    // добавляют вершины, треугольники и цвета в соответствующие списки.

🌊 6. СИСТЕМА «ПЛЕНЕНИЯ» (Dynamic Entanglement)
Саргассы — это не просто вода с повышенным трением. Это сеть. Если игрок остановится внутри острова, он не должен просто «стоять».
Логика «Захвата»:
Sticky Constraint: Если скорость игрока/скутера падает ниже порогового значения (например, 1 м/с) внутри меша, активируется «захват». К физическому телу игрока программно привязывается невидимая пружина (SpringJoint), соединяющая его с центром маста.
Вырывание: Чтобы выйти из захвата, игроку нужно нажать «газ» и накопить определенный импульс, имитируя разрыв стеблей.
Визуал: В этот момент шейдер должен усиливать амплитуду качания ближайших веток в сторону игрока (эффект натяжения).
🫧 7. АЛГОРИТМ «ГРЯЗНОЙ ПЕНЫ» (Foam Trapping & Scum)
В реальном океане саргассовы острова работают как гигантские фильтры. Они ловят мусор, пластик и, самое главное, океаническую пену.
Дополнение для Шейдера (Surface Logic):
Foam Accumulation Mask: Мы используем данные из RT-текстуры взаимодействия. Там, где меш водорослей пересекается с поверхностью воды Crest, шейдер должен генерировать «грязную», желтоватую пену.
Scum Layer: Это не пушистая белая пена прибоя. Это вязкая, пузырчатая субстанция (Sea Foam).
Математика: Используй шум Вороного (Voronoi) со смещением по времени, наложенный поверх меша саргассов в зоне ватерлинии. Это создаст ощущение, что острова «задыхаются» в собственной органике.
Floating Debris: Генератор должен с шансом 5% спавнить внутри меша инородные объекты: обломки дерева, старые буи или куски пластика, застрявшие в «кружеве» стеблей.
✂️ 8. ПРОЦЕДУРНОЕ РАЗРУШЕНИЕ (Slicing & Harvesting)
Если у игрока есть нож, винт скутера или лазер, он должен иметь возможность прорезать проход.
Реализация через Vertex Alpha Mask:
Вместо того чтобы реально резать меш (это слишком дорого для производительности), мы используем Masking Buffer.
Логика: Когда винт скутера касается меша, он «рисует» в специальную маску прозрачности (Alpha Mask) черные пятна.
Shader Result: Шейдер считывает эту маску и через discard или Opacity = 0 просто перестает отрисовывать куски веток.
VFX: В месте «разреза» спавнятся частицы — ошметки листьев и коричневый сок (хлорофилл), замутняющий воду на несколько секунд.
9. СЕНСОРНЫЙ ФИДБЕК (Camera & Post-Processing)
Чтобы игрок почувствовал плотность биомассы «кожей».
Seaweed Lens Dirt: Если камера игрока проходит сквозь меш саргассов, на экран (через Post-Processing) накладывается временная маска «грязи» — капли воды с коричневыми частицами и слизью. Она медленно стекает и исчезает за 3-5 секунд.
Chromatic Aberration (Underwater): Внутри острова эффект хроматической аберрации должен усиливаться, создавая ощущение искажения света через тысячи мелких пузырьков-пневматоцист




Твоя дорожная карта реализации:
Mesh Stage: Напиши скрипт SargassumGenerator.cs, который на основе L-System строит иерархию (Стебель -> Лист -> Пузырек). Запеки это в Static Batching или используй GPU Instancing для массивов.
Shader Stage: Создай HDRP/URP шейдер.
Входные данные: Vertex Color для AO и SSS.
Логика: World Position Offset для качания.
Интеграция: Чтение из _GlobalInteractionTrail для физического отклика.
Physics Stage: Реализуй Culling System. Острова, которые дальше 500 метров — это плоские LOD-меши. Острова ближе 50 метров — это честные процедурные «монстры» с коллизией.
Audio Stage: Напиши простенький AudioTrigger, который при входе в зону саргассов делает Low-Pass фильтр на глобальный эмбиент океана и добавляет слой «хруста» (Bubble Pop).

public class SargassumEntangler : MonoBehaviour 
{
    [Header("Настройки захвата")]
    public float snagVelocityThreshold = 1.2f; // Скорость, ниже которой кусты «хватают» игрока
    public float breakForceRequired = 500f;    // Сила (импульс), нужная для разрыва «пружины»
    public float entanglementElasticity = 0.5f; // Насколько сильно тянет обратно

    private ConfigurableJoint entanglementJoint;
    private bool isSnagged = false;

    void OnTriggerStay(Collider other) 
    {
        if (!other.CompareTag("Player") && !other.CompareTag("Scooter")) return;

        Rigidbody playerRb = other.GetComponent<Rigidbody>();
        float currentSpeed = playerRb.velocity.magnitude;

        // 1. ПРОВЕРКА НА ЗАХВАТ
        if (!isSnagged && currentSpeed < snagVelocityThreshold) 
        {
            StartSnagging(playerRb);
        }

        // 2. ЛОГИКА ВЫРЫВАНИЯ
        if (isSnagged) 
        {
            // Считаем приложенную игроком силу (нажатие газа)

            // Шейдер будет гнуть ветки по вектору (PlayerPos - ClusterCenter)
            UpdateShaderTension(other.transform.position, escapeEffort / breakForceRequired);

            if (escapeEffort > breakForceRequired) 
            {
                BreakFree();
            }
        }
    }

    private void StartSnagging(Rigidbody rb) 
    {
        isSnagged = true;
        // Создаем динамическое соединение между игроком и центром острова
        entanglementJoint = rb.gameObject.AddComponent<ConfigurableJoint>();
        entanglementJoint.connectedAnchor = this.transform.position;
        entanglementJoint.xMotion = ConfigurableJointMotion.Limited;
        entanglementJoint.yMotion = ConfigurableJointMotion.Limited;
        entanglementJoint.zMotion = ConfigurableJointMotion.Limited;
        
        SoftJointLimit limit = new SoftJointLimit();
        limit.limit = 0.5f; // Даем немного «хода» перед натяжением
        entanglementJoint.linearLimit = limit;

        // Звук: глухой щелчок и натяжение стеблей
        AudioManager.Instance.PlaySfx("Sargassum_Snag", transform.position);
    }

    private void BreakFree()

        isSnagged = false;
        Destroy(entanglementJoint);

// Фрагмент шейдера саргассовых водорослей
float4 ApplySargassumScum(float3 worldPos, float3 normal, float2 uv) 
{
    // 1. Определяем зону ватерлинии (Crest Interaction)
    float waveHeight = GetCrestWaveHeight(worldPos.xz);
    float waterLineMask = smoothstep(0.1, -0.1, worldPos.y - waveHeight);

    // 2. Генерация шума Вороного для «пузырчатой» структуры пены
    // Мы смешиваем два слоя шума с разной частотой для эффекта вязкости
    float2 voronoiUV = worldPos.xz * _ScumScale + (_Time.y * _ScumDriftSpeed);
    float scumNoise = VoronoiNoise(voronoiUV);
    float scumNoise2 = VoronoiNoise(voronoiUV * 2.5 + 0.5);
    float finalScumMap = saturate(scumNoise * scumNoise2);

    // 3. Цвет «грязной» пены: болотно-желтый с высокой прозрачностью
    float3 scumColor = lerp(_FoamColor, _OrganicScumColor, finalScumMap);
    
    // 4. Накладываем на основной цвет водоросли только сверху (Normal.y > 0)
    float surfaceMask = saturate(normal.y) * waterLineMask;
    
    return float4(scumColor, finalScumMap * surfaceMask * _ScumOpacity);
}

Почему? Потому что водоросли — органика. Они качаются на волнах. Если мы попытаемся математически сшивать вертексы (сделать идеальные швы), то при вертексной анимации (Crest-волны) эти швы неминуемо «порвутся», образуя дырки. К тому же расчет сшивки в реальном времени убьет CPU.

Мы пойдем путем ААА-индустрии (Horizon Forbidden West, Subnautica). Мы вообще не будем делать один меш острова.

Вот как мы решим проблему титанического поликаунта и сделаем так, чтобы это выглядело как единый монолитный ковер.

1. ОТМЕНА ЕДИНОГО МЕША. ПЕРЕХОД НА GPU INSTANCING

Мы создаем в редакторе (через наш SargassumGrowth) всего 3-5 вариаций базового куста-префаба (размером примерно 2х2х2 метра). Это наши «кирпичики». Полигонаж одного куста — средний (допустим, 3000-5000 трисов).

Далее мы не спавним их как GameObjects. Это убьет иерархию Unity.
Мы используем метод Graphics.DrawMeshInstancedIndirect.
Вместо того чтобы рисовать 10 000 кустов отдельными командами, мы отправляем на видеокарту один меш и массив из 10 000 матриц (позиция, поворот, масштаб). Видеокарта отрисует гигантский остров за ОДИН Draw Call.

2. СЕКРЕТ «СЛИПАНИЯ» БЕЗ ШВОВ (Intersection Blending)

Нам не нужно стыковать их "вертекс в вертекс". Кусты будут проникать друг в друга (Overlapping). Но чтобы это не выглядело как тупая каша из пересекающихся полигонов, мы сделаем магию в шейдере:

Depth Fade (Soft Intersections): Там, где геометрия одного куста входит в геометрию другого, шейдер делает плавный переход (как у мягких частиц).

Global Color Noise: Чтобы кусты не выглядели как повторяющиеся клоны, шейдер накладывает поверх всего острова глобальную текстуру шума Перлина (Global World-Space Noise). Один край куста может быть темно-зеленым, а другой, пересекающийся с соседним кустом — ярко-желтым. Визуально мозг будет воспринимать это как единый гигантский биом.

3. ЖЕСТОЧАЙШАЯ СИСТЕМА LOD (Levels of Detail)

Ты абсолютно прав, без ЛОДов это смерть. Мы строим 4-уровневую систему:

LOD 0 (0 – 15 метров от камеры): ХИЩНИК

Тут рисуется тот самый супер-меш: с янтарными пузырьками, физикой расталкивания, микро-листьями. Здесь работает DrawMeshInstancedIndirect.

LOD 1 (15 – 50 метров): ГЕОМЕТРИЯ

Пузырьки удаляются (они становятся текстурой). Листья схлопываются в более крупные плашки. Вертексная анимация работает, но физика расталкивания отключается.

LOD 2 (50 – 150 метров): OCTAHEDRON IMPOSTORS (Импосторы)

Это ключевая фича. Мы заменяем 3D-модели на Импосторы. Это хитрая плоская карточка (спрайт), которая запекает 3D-модель со всех углов. Когда игрок плывет вокруг острова, карточка поворачивается и подменяет текстуру. Выглядит как 3D, но стоит 2 полигона.

LOD 3 (150+ метров): OCEAN SURFACE MASK

На горизонте острова вообще не имеют геометрии! Мы передаем координаты кластеров в шейдер самой воды (Crest), и она просто красит поверхность волн в коричневый цвет и убирает пену барашков.

4. ГРИД-СИСТЕМА И ПРОСТРАНСТВЕННОЕ ХЭШИРОВАНИЕ (Chunking)

Да, мы разобьем карту на логические чанки (Grid Cells), скажем, 50х50 метров.

Мы не грузим в память весь остров размером 2 километра.

Наш LogicClusterer держит в памяти только математические точки (X, Y, Z, Радиус).

Когда игрок заплывает в Чанк А, система собирает координаты всех кустов в этом чанке и в соседних, кладет их в ComputeBuffer и шлет на GPU.

Чанки позади игрока (дальше 200 метров) мгновенно выгружаются из GPU-буфера.

ДОПОЛНЕНИЕ К ПРОТОКОЛУ: ГЕНЕРАЦИЯ «САРГАССОВОГО ЛАБИРИНТА» (LANGMUIR WEB LOGIC)

Мы отказываемся от равномерного заполнения кругов. Теперь генератор использует Шум Ворли (Worley Noise) или алгоритм поиска краев Вороного (Voronoi Edges), чтобы строить «ячеистую сетку».

1. МАТЕМАТИКА ЛАБИРИНТА: Как это работает

Вместо того чтобы расставлять кусты где попало, алгоритм делает следующее:

Генерирует на плоскости океана невидимые клетки (Voronoi Cells) размером примерно 15х15 или 20х20 метров.

Сами центры клеток остаются пустыми (это те самые «окна» для игрока).

Кусты водорослей спавнятся только на границах (стыках) этих клеток.

В точках, где сходятся 3-4 клетки (Узлы), водоросли образуют плотные, толстые комки. Здесь спавнятся креветки, светящиеся пневматоцисты и лут.

В линиях между узлами водоросли образуют тонкие «мосты» (шириной 1-2 метра).

Местами линии алгоритмически «рвутся», создавая проходы для скутера.

    [Range(0, 1)] public float breakChance = 0.2f; // Шанс разрыва стенки (ворота для игрока)

    // Возвращает список точек для GPU Instancing
    public List<Matrix4x4> GenerateSargassumLabyrinth()
    {
        List<Matrix4x4> instanceData = new List<Matrix4x4>();

        // Проходим по всей зоне с шагом bushSpacing
        for (float x = -mapSize / 2; x < mapSize / 2; x += bushSpacing)
        {
            for (float z = -mapSize / 2; z < mapSize / 2; z += bushSpacing)
            {
                float2 pos = new float2(x, z);

                // 1. Вычисляем Шум Ворли (Расстояние до ближайших двух точек)
                // Функция вернет distanceToF1 (до ближайшего центра) и distanceToF2 (до второго)
                CalculateVoronoi(pos, cellSize, out float distF1, out float distF2);

                // 2. Ищем ГРАНИЦУ (Edge). Граница там, где расстояние до двух центров почти одинаковое
                float edgeDistance = distF2 - distF1;

                // 3. Формируем "стенки" лабиринта
                if (edgeDistance < webThickness)
                {
                    // 4. Добавляем органический Шум Перлина, чтобы стенки не были идеально ровными
                    float organicNoise = noise.snoise(pos * 0.1f);
                    
                    // 5. Делаем случайные «дыры» (проходы) в стенках
                    // Если низкочастотный шум меньше порога — тут стена рвется, игрок может проплыть
                    if (organicNoise > breakChance)
                    {
                        // 6. Дополнительная кучность в "Узлах" (где сходятся несколько ячеек)
                        // Чем меньше distF1, тем ближе мы к перекрестку

                    }
                }
            }
        }
