## Phase 0 API Notes
- Allocation/grow: `EnsureGenerationHandle<T>()`, private `TryEnsureVaultBuffer<T>()`, private arena growth via `TryGrowArenaForBytes()` and `H8Memory.ReallocateRaw()`.
- Resolve/read: `TryResolveHandle<T>()`, `TryReadHandle<T>()`, `TryReadOnlyHandle<T>()`, `TryResolveSlice<T>()`.
- Writer fence: `TryAcquireWriteLock<T>()` sets `ActiveWriterSystemID`, `BlockFlagLocked`, `Reserved1`, and `_activeLocks`; `ReleaseWriteLock<T>()` reverses them.
- Job pin: `TryLockBuffer(BufferID,SystemID)` sets `BlockFlagLocked`, increments `Reserved1`, stores `LastAliasRequester`, and sets `_activeLocks`; `TryUnlockBuffer()` clears when count reaches zero.
- Defrag: public `FrostTickDefrag(elapsed,stress,PreSimulation,mask)` is legal path; private `TryRunLiveCompactionSlice(uint)` performs `MemMove` only after fence/gate/lock checks.
- Reflection required: private `TryRunLiveCompactionSlice(uint)` and private `_defragLockedSkipCount` are not public; editor fuzzer will access them only under `#if UNITY_EDITOR`.
