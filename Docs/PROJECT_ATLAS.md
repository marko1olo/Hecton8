## H-Phi Metric

`H-Phi` is a static architecture pressure metric. It scores whether a domain behaves like a sovereign data system connected through typed lanes, or like a concrete-reference knot.

It is not runtime proof. It is a triage number.

### Data Sovereignty

Data Sovereignty measures how much runtime state lives in owned data buffers rather than scattered Unity objects or local native allocations.

Calculation:

```text
DataSovereignty =
    VaultOwnedBuffers /
    max(1, VaultOwnedBuffers + LocalNativeBuffers + ManagedMutableStores + UnityObjectTruthStores)
```

Rules:

- A NativeArray counts as sovereign only when requested from GlobalDataVault or an explicitly documented vault-owned allocator.
- A local persistent NativeArray counts against sovereignty.
- A GameObject/Transform/MonoBehaviour field used as simulation truth counts against sovereignty.
- A DTO or signal payload crossing native/binary boundaries without layout proof caps sovereignty at `0.5`.
- False "verified data sovereignty" language sets the report evidence multiplier to `0`.

### Synaptic Density

Synaptic Density measures whether systems communicate through typed, cache-safe links instead of concrete references, singleton accessors, or broad polling.

Calculation:

```text
SynapticDensity =
    TypedSignalLanes + CachedInterfaceContracts + DataVaultHandles
    ------------------------------------------------------------
    max(1, DirectConcreteRefs + SingletonRefs + HotRegistryPolls + MonolithicEventTraffic + StringEvents)
```

Rules:

- A typed `SignalBus<T>` lane with bounded payload counts positive.
- A cached interface injected through `OnDependencyInject()` counts positive.
- A `GlobalRegistry.Get<T>()` call inside Tick/Update paths counts negative.
- Duplicate signal names across assemblies count negative twice: one for contract drift, one for compile risk.
- String event names count as monolithic traffic.

### Phase Discipline

Phase Discipline is `1.0` only when the domain names PRE_SIMULATION, SIMULATION, POST_SIMULATION, or VISUAL_SYNC ownership and avoids private runtime schedulers.

```text
PhaseDiscipline = phase_owned_work / max(1, phase_owned_work + private_update_work)
```
