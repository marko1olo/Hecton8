## Proof Labels

Use these labels in reports:

- `STATIC_DOC`: document text was read or edited.
- `STATIC_SOURCE`: source text was scanned.
- `FILESYSTEM`: file presence or absence was checked.
- `CLI_COMPILE`: local command-line build compiled a target.
- `UNITY_CONSOLE`: Unity Console was read fresh.
- `PLAYMODE`: Unity Play Mode executed the route.
- `PROFILER`: Unity Profiler, Memory Profiler, Frame Debugger, or RenderDoc captured data.
- `PLAYER_BUILD`: platform player build artifact exists and ran.

Any claim above its evidence class is rejected.
