## Executive Cut

Right now we cannot market a game that has no stable public gameplay surface. We can prepare the machinery that turns first screenshots and clips into wishlists.

The useful work now:

1. lock positioning;
2. build Steam funnel;
3. build creator/press lead base;
4. build pitch bank;
5. build content shotlists;
6. build community critique loops;
7. build metrics dashboard;
8. build regional outreach;
9. build key/press hygiene;
10. build agent workflows.

## Direction 01 - Positioning Lock

Goal: prevent scope drift and derivative messaging.

Current approved position:

> HECTON-8 is a single-player-first NASA-punk / deep-sea noir survival game about pressure, salvage, machinery, and the cost of staying alive below the light.

Public enemies:

- "Subnautica killer";
- co-op promise;
- generic underwater survival;
- unsupported realism;
- unsupported performance.

Immediate prep:

- keep a forbidden-claims checklist;
- run every Steam, post, press, and creator pitch through the checklist;
- require one concrete differentiator in every public copy block: pressure, machinery, salvage, corrosion, black water, Seed Ship, acoustic dread, heavy traversal.

Done files:

- `Docs/Marketing/NO_COOP_PUBLIC_POSITIONING.md`
- `Docs/Marketing/CreatorOutreach/PITCH_BANK.md`

Next documents to expand later:

## Direction 02 - Steam Funnel Preparation

Goal: make Steam the primary conversion point once assets exist.

Why it matters:

- Steam wishlists begin once the public store page exists.
- Per Steamworks Wishlists, users may receive launch/Early Access/full-release, qualifying-discount, and one-time public-demo notifications, subject to Steam email eligibility, cooldowns, user settings, and current Steamworks rules; recheck before campaign planning.
- Next Fest requires a public base game page and playable demo.

Immediate prep:

- short description A/B bank;
- long description skeleton;
- tag strategy;
- capsule brief;
- screenshot order;
- trailer structure;
- UTM naming convention;
- page conversion dashboard.

Do not:

- launch a weak page just to say it exists;
- use concept art as proof of gameplay;
- put co-op tags anywhere;
- mention performance without capture.

Done file:

- `Docs/Marketing/Steam/STEAM_WISHLIST_AND_NEXT_FEST_PLAN.md`

Needed next:

- `STORE_PAGE_COPY_MATRIX.md`
- `STEAM_CAPSULE_BRIEF.md`
- `STEAM_UTM_NAMING.md`

## Direction 03 - Visual Proof Pipeline

Goal: create screenshots that sell identity without explanation.

The first image set must prove:

- this is not bright plastic alien wonder;
- this is not just dark water;
- the base is a machine;
- pressure is visible;
- salvage is readable;
- the Seed Ship/anomaly is a systemic hook.

Immediate prep:

- exact screenshot shotlist;
- clip shotlist;
- thumbnail/crop requirements;
- low-tier proof requirement;
- first-5-seconds trailer rule.

Success test:

Give one screenshot to a cold viewer for five seconds. If they cannot say "industrial underwater survival / pressure / machinery / danger", recapture.

## Direction 04 - Short-Form Content Engine

Goal: turn each proof clip into 5-10 platform variants.

Formats:

- 9:16 vertical 15-20s;
- 1:1 square for broader feed reuse;
- 16:9 YouTube/X/Steam;
- static screenshot + caption;
- GIF/WebM from the same source.

Clip pattern:

- 0-2s: failure/threat/hook;
- 3-12s: player action;
- 13-18s: consequence;
- 19-20s: title + wishlist.

Immediate prep:

- caption bank;
- hook bank;
- sound/caption standards;
- per-platform export settings;
- asset naming convention.

## Direction 05 - Creator Outreach Machine

Goal: have hundreds of verified creator leads ready when proof assets exist.

Database states:

- `RAW_SEED`;
- `VERIFY_BEFORE_CONTACT`;
- `READY_FOR_HUMAN_REVIEW`;
- `APPROVED_TO_CONTACT`;
- `CONTACTED`;
- `REPLIED`;
- `COVERED`;
- `DO_NOT_CONTACT`.

Immediate prep:

- expand raw leads from Subnautica, survival, horror, engineering, indie demo, regional language, Steam curator sources;
- verify recent activity;
- find safe contact route;
- assign exactly one pitch angle;
- write 2-line personalized reason.

Do not:

- scrape/purchase private lists;
- infer email;
- mass-mail unverified leads;
- send keys before key policy exists.

## Direction 07 - Community Critique Loops

Goal: get useful feedback without acting like spam.

Useful communities:

- survival crafting;
- indie development critique;
- underwater/thalassophobia adjacent spaces;
- horror game players;
- base-building players;
- Unity/technical communities only for proof/process, not player marketing.

Post stance:

- ask one question;
- show one asset;
- do not beg for wishlists;
- do not attack Subnautica;
- do not argue with feedback.

Done file:

- `Community/COMMUNITY_POST_TEMPLATES.md`

## Direction 09 - KPI Dashboard

Goal: avoid vibes-based marketing.

Track by phase:

- Steam visits;
- wishlists;
- visit-to-wishlist rate;
- source/UTM;
- creator replies;
- coverage;
- short-form 3s hold;
- clip completion;
- demo downloads;
- demo completion;
- negative feedback themes;
- "Subnautica clone" comment ratio.

Kill criteria:

- Steam conversion under 5%;
- clip completion under 25%;
- repeated "clone" comments;
- creator reply under 2% after personalized outreach;
- demo feedback dominated by confusion.

## Direction 10 - Agent Operations

Goal: convert agent labor into repeatable work, not hallucinated plans.

Agents can do:

- verify recent activity;
- draft pitches;
- monitor competitors;
- summarize feedback;
- create copy variants;
- check compliance;
- build source ledgers.

Agents cannot do:

- approve final copy;
- promise features;
- decide spend;
- contact creators unsupervised;
- infer private data;
- claim metrics.

Done file:

- `AgentOps/AGENT_MARKETING_WORKFLOWS.md`

## Minimum Ready State Before Public Push

Do not start real outreach until:

- 6-10 game screenshots exist;
- one 15-20s gameplay clip exists;
- Steam page draft exists;
- no-coop/no-fake-proof compliance passes;
- creator top-50 leads are verified;
- press kit has at least factsheet, screenshots, trailer/clip, logo, contact;
- KPI sheet is ready;
- first post batch has been reviewed by a human.
