# Campaign 00 - Pre-Screenshot Setup

Status: active now / no public hype push
Window: before first real gameplay screenshots
Public stance: single-player-first scope / proof-first campaign copy
Runtime impact: none

## Objective

Prepare the machinery of marketing before assets exist. This campaign does not ask the public for wishlists. It builds the page, lists, copy, tracking, verification queue, and visual requirements so the first screenshot drop is not improvised.

## Why This Matters

With a few thousand dollars, the project cannot buy attention twice. The first public assets must already know:

- who they are for;
- what they are proving;
- which creators they unlock;
- what Steam page they support;
- which comments would mean the direction is failing.

## Public Posting Rule

Do not post broad public hype yet.

Allowed:

- private/internal cold-read tests;
- asking trusted reviewers which screenshot concept is clearest;
- non-promotional dev notes if they do not ask for wishlists;
- creator verification with no outreach.

Forbidden:

- "wishlist now";
- "Subnautica killer";
- unsupported multiplayer-scope hints;
- "runs great";
- AI/worldgen claims without proof;
- paid traffic.

Stop and revise positioning if internal readers say:

- "looks like Subnautica but darker";
- "I cannot tell what the player does";
- "too dark to parse";
- "the machinery looks decorative";
- "why is this not just a horror walking sim?"
