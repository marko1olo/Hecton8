# HECTON-8 Public FAQ And Objection Handling

Status: public-response draft bank
Owner lane: Marketing / community and press response
Runtime impact: none

## Purpose

This file gives short, safe answers to predictable questions. Use these in Steam forums, Discord, Reddit, creator replies, press emails, and social responses.

## Core Rule

Answer the question. Do not debate. Do not overpromise. Do not attack competitors.

## FAQ

### Is HECTON-8 co-op or multiplayer?

No. HECTON-8 is single-player-first. Co-op is not part of the current public plan, and we are not selling the game on a feature that is not in the build.

### Is this just Subnautica?

The underwater survival comparison is understandable, but HECTON-8 is aiming at a different lane: pressure, machinery, salvage, corrosion, base risk, and deep-sea noir.

### Will there be a demo?

A demo/playtest is planned only when the first route is strong enough to represent the game honestly. We will not release a public demo just to create noise.

### What platforms?

PC/Steam is the current planning focus unless official pages say otherwise.

### Will it run on low-end PCs?

The project is designed with scalable quality in mind, but we will publish performance claims only with build, hardware, settings, and frame-time context.

### Is it horror?

HECTON-8 uses dread, pressure, black water, and hostile systems. It is not being built as a jumpscare-first horror game.

### Is there combat?

Do not answer with a promise until combat/defense systems are public and proven. Safe answer:

```text
We are not ready to describe combat/defense systems publicly. The current public focus is survival pressure, salvage, machinery, and base risk.
```

### How big is the world?

Do not give size claims without proof. Safe answer:

```text
We are not using raw map size as the selling point. The priority is route density, pressure, and meaningful survival decisions.
```

### Is it Early Access?

```text
No final public launch model has been locked. If we use Early Access, the Steam page will describe the current build honestly rather than selling future promises.
```

## Objection Responses

### "Looks too dark."

```text
Fair point. The target is hostile visibility, not unreadable darkness. We are tuning silhouettes, instrument light, and contrast so pressure and machinery read clearly.
```

### "Looks like AI/concept art."

```text
We only want public gameplay assets to be clear about source/build. If an asset reads as concept art, it needs to be replaced or labeled better.
```

### "Looks slow."

```text
HECTON-8 is deliberately heavier and more mechanical than clean sci-fi movement, but slow cannot mean tedious. We are testing that distinction hard.
```

### "Resource gathering looks tedious."

```text
That is a valid risk for survival games. The loop we are targeting is pressure and recovery routes, not blind repetition.
```

### "Why no co-op?"

```text
Because we do not want to promise a network feature before it is real. The current game is single-player-first.
```

### "Will you beat Subnautica?"

```text
That is not useful public framing. HECTON-8 has to stand on its own identity: pressure, machinery, salvage, and deep-sea noir.
```

- the same objection has been answered once;
- replies become mostly identity/politics/AI-war/engine-war;
- users request keys, private files, Discord, or personal contact;
- people are quote-mining the developer instead of discussing the asset;
- the thread produces no new asset-specific signal.
