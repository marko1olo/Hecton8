# HECTON-8 Trailer Script, Capture, And Editing Brief

Status: pre-footage production brief
Owner lane: SHINOBU_81 / trailer planning
Runtime impact: none

## Trailer Goal

The first trailer must make a cold player understand:

- this is single-player deep-sea survival;
- the identity is pressure/machinery/noir;
- the player does things, not just watches scenery;
- there is a base/salvage loop;
- the Seed Ship creates mystery;
- Steam CTA is clear.

## Trailer Lengths

| Version | Length | Use |
|---|---:|---|
| Teaser | 20-30s | first social/creator hook |
| Steam trailer | 55-75s | Steam page primary trailer |
| Showcase trailer | 45-60s | events/showcases |
| Vertical cut | 15-25s | TikTok/Shorts/Reels |
| Press clip reel | 90-120s | presskit B-roll |

## First Steam Trailer Beat Sheet

| Time | Beat | Visual |
|---:|---|---|
| 0-3s | Hook | black water, machinery light, pressure sound |
| 3-8s | Player action | hand/tool/repair/salvage interaction |
| 8-15s | Survival pressure | leak, oxygen, route hazard, warning |
| 15-25s | Base/machine loop | module, pump, hatch, repair consequence |
| 25-35s | Exploration | salvage route, wreck, visibility control |
| 35-45s | Threat/failure | environmental danger or hostile ecology |
| 45-55s | Seed Ship | anomaly signal, impossible silhouette, instrument corruption |
| 55-65s | Feature proof | fast cuts of real systems |
| 65-75s | CTA | title, Steam wishlist/demo |

## Opening Rules

Do:

- show actual game by second 3;
- show player action by second 8;
- use audio as identity;
- make the first shot readable at mobile size.

Do not:

- start with long logo;
- start with lore text;
- start with empty ocean;
- hide gameplay behind darkness;
- use concept art as gameplay.

## Shot Requirements

Required shots:

- pressure hatch or warning;
- salvage pickup/route;
- base or machine interaction;
- hostile visibility/dark water;
- Seed Ship/anomaly clue;
- one failure state;
- one wide scale shot;
- one close tactile machinery shot.

Optional shots:

- vehicle/heavy tool if real;
- UI if polished;
- creature/ecology if behavior is convincing.

## Capture Rules

- capture at target Steam trailer resolution;
- use stable camera unless motion is player-authentic;
- no debug UI unless deliberate tech clip;
- no placeholder icons/text;
- no inconsistent color grade;
- no footage from systems not in current public build unless labeled.

## Audio Direction

Use:

- hull groan;
- compressor/pump rhythm;
- distant metal stress;
- muffled sonar;
- low-frequency pressure;
- short silence before anomaly.

Avoid:

- generic trailer boom spam;
- heroic orchestral swell;
- cozy ocean music;
- horror sting every 5 seconds.

## Text Cards

Use no more than 4 text cards.

Possible cards:

- PRESSURE IS A SYSTEM
- SALVAGE BELOW THE LIGHT
- KEEP THE MACHINES ALIVE
- THE SEED SHIP IS NOT DEAD

Avoid:

- feature laundry list;
- "massive world";
- "zero stutter";
- "co-op";
- "Subnautica killer".

## Trailer QA

Trailer fails if:

- first 10 seconds have no player verb;
- viewers ask if it is pre-rendered;
- the CTA is missing;
- feature cards exceed footage proof;
- UI/text unreadable;
- audio mix hides action;
- trailer could be any underwater game.
