## Phase Gates

| Phase | Trigger | Main Asset | Outreach Scope |
|---|---|---|---|
| P0 Prep | Now | docs, lead base, pitch bank | No external outreach except private critique. |
| P1 Screenshot Proof | 6-10 real screenshots | Steam draft + screenshot pack | 10-20 high-fit creators for feedback. |
| P2 Clip Proof | 3-5 20s clips | vertical/16:9 clips | 20-40 creators + community critique. |
| P3 Steam Page Live | public Coming Soon page | Steam link + page assets | 50-100 leads, mostly feedback/wishlist funnel. |
| P4 Demo Locked | stable public demo | demo + press kit | 100-200 leads, keys only with tracking. |
| P5 Next Fest | after current Steamworks eligibility recheck, registered/demo-approved state, and page/demo proof assets | demo + trailer + livestream assets | 200+ segmented contacts. |
| P6 EA Launch | current-state EA build | launch trailer + key policy | press/creators, no future promises. |

## P0 - Prep Only

Allowed:

- lead mining;
- verification;
- pitch drafting;
- screenshot planning;
- Steam copy tests with private readers;
- community rules research;
- press kit shell.

Forbidden:

- broad creator contact;
- Steam public page with no proof assets;
- ads;
- co-op hints;
- launch promises.

## P1 - Screenshot Proof Batch

Batch size:

- 10-20 A-priority leads.

Targets:

- Subnautica specialists;
- indie showcase;
- horror atmosphere;
- one or two regional high-fit reviewers.

Ask:

> Does this visual direction read as industrial deep-sea survival, or still too close to existing underwater survival games?

No key. No demo promise unless true.

## P2 - Clip Proof Batch

Batch size:

- 20-40 leads.

Targets:

- horror streamers;
- short-form clippers;
- survival creators;
- engineering/system creators if clip shows machinery.

Ask:

> Would this 15-20 second format fit your audience when a demo exists?

Measure:

- replies;
- specific critique;
- "send demo later" responses;
- "Subnautica clone" objections.

## P3 - Steam Page Live Batch

Batch size:

- 50-100 leads.

Targets:

- A/B creators;
- indie press;
- Steam demo list channels;
- regional outlets with localized one-pager.

Ask:

> Steam page is live. I am collecting blunt feedback on whether the page communicates pressure/machinery/survival clearly.

Optional CTA:

- Wishlist only if they already show interest. Do not beg.

## P4 - Demo Locked Batch

Batch size:

- 100-200 leads.

Targets:

- survival/horror creators;
- demo showcase sites;
- indie press;
- Steam curators;
- regional leads.

Required:

- tracked key list;
- embargo if needed;
- known demo length;
- known demo content;
- known no-coop public answer;
- known performance answer.

Ask:

> Demo is ready for coverage. Would you like a key/press kit for [date/window]?

## P5 - Next Fest Batch

Batch size:

- verified database only.

Daily actions:

- send no more than one update per target unless requested;
- track coverage;
- clip best moments;
- answer Steam discussions;
- fix only critical demo blockers;
- do not chase balance noise.

## P6 - Early Access Launch

Rules:

- sell current state;
- no future feature promises;
- no co-op promise;
- no fake performance claim;
- launch discount only if pricing strategy supports it;
- review keys in small batches.

## Weekly Agent Cadence

Monday:

- verify 20 raw leads;
- update competitor/sentiment watch.

Tuesday:

- produce 10 pitch variants;
- check forbidden language.

Wednesday:

- community rule refresh for target forums/subreddits.

Thursday:

- Steam copy/capsule critique variants.

Friday:

- KPI report and kill-criteria check.

Weekend:

- no outreach unless scheduled; process replies only.

## Human Approval Check

Before any batch:

- user approves asset;
- user approves exact copy;
- user approves target list;
- user approves spend/key count;
- compliance pass done.
