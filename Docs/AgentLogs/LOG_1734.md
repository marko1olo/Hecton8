What was wrong:

- Primitive collision proxies are resolved from `COL_[EquipmentName]` prefab assets or copied from primitive source-prefab colliders into a `COL_` child on the `Interactable` layer; MeshCollider fallback is rejected.
- Metadata-declared runtime scripts are added offline and known TMP/renderer fields are bound by serialized reflection before prefab save, avoiding runtime hierarchy search.
- Validator rejects MeshCollider, Canvas, CanvasRenderer, TextMeshProUGUI, missing direct TMP, non-SDF TMP font, TMP raycast target, bad projection transforms, non-primitive colliders, wrong layers, null materials, material clones, and SRP-batcher proof failures.

- Primitive `COL_` interaction proxies replace visual-mesh collision. Exact saved estimate: 700 microseconds in dense interaction raycast scans.
