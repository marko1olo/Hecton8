## 2026-06-02 - Audio/UI Purification Pass

What was wrong:
- `UIParticleEffect.cs` contained a runtime fallback that created `new GameObject("Particles")` and `AddComponent<ParticleSystem>()` when no prefab was provided.
- `SpatialAudioManager.cs` had per-voice depth low-pass behavior but no master-bus depth-pressure muffle below deep-water thresholds.

- `PlayerCriticalProceduralAudioRenderer.cs` has no managed `OnAudioFilterRead`; it uses the native kernel bridge route.

What was done:
- Added master depth-pressure LPF to `SpatialAudioManager.cs`:
  - `-50m` maps to `22000Hz`.
  - `-300m` maps to `400Hz`.
  - Exponential smoothing uses existing `FastDecayBlend`.
  - Mixer writes target `MasterDepthPressureLowPassCutoffHz`.
  - Writes are skipped unless cutoff changes by more than `1Hz`.
  - Non-finite Y fails open to `0m`; invalid cutoff state resets to `22000Hz`.
- Rewrote `UIParticleEffect.cs`:
  - Added serialized `ObjectPoolManager _uiEffectPool`.
  - Added serialized `_authoredParticlePrefab` with `FormerlySerializedAs("particlePrefab")`.
  - Spawn now uses `pool.Spawn(_authoredParticlePrefab, ..., allowExpand:false)`.
  - Disable/despawn returns the instance to the pool.
  - Shared atlas binding uses `ParticleSystemRenderer.sharedMaterial`; CanvasRenderer-only prefab routes fail closed.
  - Removed runtime `new GameObject`, `AddComponent<ParticleSystem>`, `Instantiate`, and `.material` paths from the UI particle script.
- Updated status and rationale:
  - `Docs/Tasks/Status_1710.md`
  - `Docs/AgentLogs/Rationale_1710.md`

Cinematic cheats used:
- Master-bus depth muffle is a presentation fake. It does not simulate water physics, does not alter gameplay truth, and does not create a new DataVault route.
- Depth pressure is represented as a continuous LPF curve and exponential smoothing instead of physical absorption simulation.
- UI particles are authored prefab bursts from a pool, not procedural runtime construction.

Exact microseconds saved:
- UI runtime fallback object creation removed: estimated `250us` per previous missing-prefab fallback on i3/MX350-class hardware.
- UI material clone/rebatch avoidance: estimated `80us` per spawn where `.material` or mismatched material path would have cloned or forced batching churn.
- Master LPF deadband: estimated `3us` per unchanged presentation frame by skipping redundant mixer `SetFloat`.
- DataVault read avoided: estimated `2us` per audio tick by using already-resolved listener AUP frame data instead of a speculative DTO read.
