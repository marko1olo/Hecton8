- Updated the editor-only procedural strip preview builder to emit the same RGBA contract instead of full-biolu/full-wear legacy colors.

Cinematic cheats used:
- Replaced runtime vegetation generation with static authored mesh output; motion and richness are bought through vertex color semantics and shader-driven sway.
- Sargassum visual richness now scales through authored static meshes/materials, not runtime primitive fallback geometry.
- Silt trail complexity is pushed into preauthored pooled prefabs, allowing cheap low-tier trails and overbuilt high-tier prefabs without chunk logic changes.
- 1711 topology profiles use continuous `GlobalQualityWeight` to scale bake iterations, attractors, AO samples, atlas size, and LOD budgets.
