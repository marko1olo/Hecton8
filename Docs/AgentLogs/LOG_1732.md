# LOG 1732 - Flora & Coral Scatter Prefab Assembler

## 2026-06-03 - RB-110 Flora Prefab Factory Pass

What was wrong:
- `ImpostorSystem` allowed non-geology impostors to retain source renderer materials. That preserved per-species material routes and made RB-110 impossible to enforce at scale.
- No dedicated offline flora prefab factory existed for the requested LOD0/LOD1/LOD2-impostor hierarchy, shared material binding, pivot correction, harvest trigger authoring, and validation deletion gate.
- Small flora and impostor renderers could still carry shadow-casting cost even when the underwater read is negligible.

What was done:
- Added `Assets/_Project/Editor/Assembly/FloraPrefabFactory.cs`.
- Added `Assets/_Project/Scripts/World/ScavengeTarget.cs` as scalar serialized harvest data, not a ticking runtime system.
- Added authored shared impostor material `Assets/_Project/Art/Materials/WorldProceduralProxy/MAT_Flora_ImpostorAtlas.mat`.
- Updated `Assets/_Project/Scripts/World/ImpostorSystem.cs` so flora/geology impostors require authored atlas metadata and the single `_authoredImpostorAtlasMaterial`; source-material fallback is removed.
- Updated `Assets/_Project/Scripts/World/HectonIndirectVegetationRenderer.cs` so BRG LOD distances and material parameters consume continuous quality weight, 0.3x to 1.0x, without changing gameplay truth.
- Updated `Assets/_Project/Art/Shaders/Hecton_ProceduralBio.shader` with SRP-Batcher-safe vertex sway properties `_SwayAmplitude` and `_BiolumPhase`.
- Factory output route is `Assets/Prefabs/Environment/Flora/PFB_[FloraName].prefab`.
- Factory validation rejects missing 3-LOD sets, root `MeshFilter`, any `MeshCollider`, non-impostor LOD2 material, and incomplete harvest triggers.

Cinematic cheats used:
- Vertex sway is a shader-space sinusoidal fake driven by vertex color red, instance seed, `_SwayAmplitude`, `_BiolumPhase`, and continuous `_H8GlobalQualityWeight`; no physics simulation.
- Far-field flora collapses to one impostor atlas material with UV/tint instance data instead of per-species materials.
- Small flora under 1 m3 and all LOD2 impostors cast no shadows; silhouette density and biolum detail buy the immersion instead.
- Low/Middle/High/Ultra scaling is distance/cadence/fidelity only; ecosystem truth, DTO layout, and authority route are unchanged.

- Expected low-end runtime gain remains profiler-pending: fewer material state routes, no runtime material clone fallback, earlier atlas impostors at 0.3 quality weight, and fewer shadow casters.

## 2026-06-03 - Loop 6 Atlas And Authoring Polish

What was wrong:
- Authored impostor atlas entries used first-match material-or-albedo lookup. A broad albedo record could override a later exact material record.
- The indirect atlas C# capability gate did not include the shader-level requirement implied by the `target 4.5` StructuredBuffer shader path.
- Flora material scoring penalized placeholder/debug materials but still allowed them if no better candidate existed.
- A failed pooled billboard tracking insert could return a renderer to the pool with atlas property-block state still attached.

What was done:
- `ImpostorSystem.TryResolveAuthoredAtlasEntry()` now resolves exact `SourceMaterial` records before `AlbedoTexture` fallback records.

- `FloraPrefabFactory.ValidateFloraMaterial()` now rejects placeholder/debug materials outright.
- `ActivateImpostor()` clears billboard atlas properties before despawning a billboard on tracking failure.

Cinematic cheats used:
- Low hardware keeps the cheap property-block billboard atlas path instead of attempting unsupported indirect StructuredBuffer rendering.
- Authoring validation fails closed; it does not create visual filler prefabs from debug/placeholder materials.
