## Follow-up Texture Completeness Audit

What was wrong: The original texture/material standard was correct for UVs, atlas packing, PBR channel contracts, imports, and runtime bans, but it was too thin on source texture generation. It did not fully prevent AI-assisted flat noise, baked-light material samples, bad roughness logic, or semantically random emission masks.

What was done: Added `3DMODEL_TEXTURE_GENERATION_PLAYBOOK.md` and routed it from `3dmodel.md`, `3DMODEL_TEXTURES_MATERIALS.md`, and `AGENTS.md`. The new file defines source generation contracts, material family recipes, mandatory albedo/normal/MRAO/emission/detail/height roles, AI prompt rules, procedural bake algorithms, continuous quality lanes, and texture acceptance gates.

Cinematic Cheats used: Texture richness is pushed into offline curvature, AO, height, roughness, emission, drip, grime, sediment, and detail masks instead of runtime simulation. Runtime shaders consume static masks and shared materials.

Exact Microseconds saved: PENDING PROFILER. Estimated prevention value is 20-250 us in material-heavy scenes from avoiding material proliferation and corrective overlay/effect paths; larger savings occur when bad source textures would otherwise force runtime mask generation or duplicated materials.

## Follow-up Hero Realism Upgrade

What was wrong: The standards could prevent low-quality technical failures, but maximum-realism assets also need reference contracts, high-poly source meshes, deliberate retopology, layered detail hierarchy, render proof, and anti-primitive rejection. Without that, a generator can pass mesh validation and still look like a clean procedural toy.

What was done: Added `3DMODEL_HERO_REALISM_OVERKILL.md` and routed it from `3dmodel.md` and `AGENTS.md`. The file defines hero entry conditions, realism stack, reference contracts, high-poly source rule, retopology rule, silhouette budgets, anti-low-poly rejection, hard-surface/organic/geology hero rules, bake requirements, trim/decal strategy, render proof gates, continuous overkill scaling, and implementation order.

Cinematic Cheats used: Hero detail is bought with offline high-poly bakes, curvature/AO/cavity/thickness masks, trims, decals, and detail maps rather than runtime mesh mutation or brute-force physics/rendering.

Exact Microseconds saved: PENDING PROFILER. Expected savings are indirect: better detail per triangle, fewer runtime corrective effects, preserved material batching, and no collision/render brute force. Estimated prevention value remains 20-250 us in material-heavy scenes, with larger avoided spikes if a future agent would otherwise generate or mutate hero detail during gameplay.
