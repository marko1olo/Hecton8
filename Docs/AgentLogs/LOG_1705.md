# LOG 1705 - Sonar Ghost & Acoustic Decryption

2026-06-02

What was wrong:
Topographical sonar fabricated procedural mock SDF data when no real voxel SDF was published. Ground radar allocated a runtime material clone from a shader fallback. Acoustic echo runtime had no integrated phantom blip route tied to player stress, SHINOBU_273 tuning, or flashlight cone suppression.

What was done:
Removed GenerateMockSdfJob and mock SDF flags from TopographicalSonarSynthesizer.cs. Missing published SDF now enters zero-draw SdfUnavailable|Fault state and mirrors zero counters.
Removed runtime new Material fallback from GroundPenetratingRadarRuntime.cs. Radar now requires the serialized authored material, with FormerlySerializedAs preserving existing scene references.
Extended EchoTap to 144 bytes and added GenerateAcousticPingsJob in AcousticEchoLocationRuntime.cs. Ghost taps are generated in the existing NativeArray frame-tap lane, filtered by stress, SHINOBU current/target frequency delta, and flashlight cone dot product.
Corrected flashlight culling to use PlayerFlashlight.PresentationAnchor.forward, fixed first haptic pulse cooldown underflow, and throttled missing SHINOBU external handle refresh to a 30-frame cadence.
Flattened topographical telemetry writes into two sequential write-lock sections with finally release and removed the obsolete mutation-guard helper.
Sanitized ghost job stress/time/frequency inputs inside Burst and made blackbox recovery fail closed instead of force-completing active tracking work.
Deferred acoustic DataVault hot-swap until the active tracking fence finalizes normally, and wrapped shutdown force-complete with mutation guard release in finally.
Cold-initialized the haptic pulse lane for acoustic ghost feedback, rejected unchanged stress SignalBus sequences older than 8 acoustic frames, and made ghost LCG seed multiplication unsigned.

Cinematic cheats used:
Deterministic LCG rear-arc placement instead of scene probes or spawned emitters.
Seventh-order sine approximation instead of trigonometric placement inside the job.
Branchless amplitude masks via saturate/select/step for fear, frequency suppression, and flashlight suppression.

Exact microseconds saved:
Mock SDF fabrication removed: estimated up to 1700 us on missing-payload scans, plus 262144 byte staging write avoided.
Runtime radar material clone removed: one unmanaged allocation path and shader lookup removed at enable.
Frame-path registry fallback removed: per-acoustic-frame GlobalRegistry.Player fallback avoided under stress spikes.
Absent SHINOBU handle refresh throttled: avoids two DataVault handle lookup attempts per stressed frame while TerminalOS is not present.
Telemetry lock flattening: removes a broad two-buffer mutation guard and guarantees one write lock at a time for topographical sonar telemetry.
Blackbox recovery stall removal: skips one optional telemetry write instead of synchronously waiting on an active acoustic tracking job.
DataVault rebind stall removal: service replacement queues one pointer and switches ownership after normal job finalization instead of blocking the frame.
Stress freshness gate: stops old stress telemetry from keeping ghost blip generation active after the owner stops publishing, without depending on heterogeneous stress DTO frame counters.
Acoustic math de-duplication: removes the duplicate job-local sine polynomial and routes ghost placement through the shared acoustic approximation.
SHINOBU FrequencyDelta NaN gate: finite-sanitizes knob delta before preview-frequency construction, preventing malformed UI input from contaminating branchless frequency masking.
Partial cold init cleanup: acoustic Dispose now releases partial DataVault handles and resets initialization state even if the runtime never reached _initialized = 1.
Phantom truth isolation: ghost EchoTap entries are retained as presentation data but branchlessly masked out of EchoTrackingJob's authoritative predator hunt result.
