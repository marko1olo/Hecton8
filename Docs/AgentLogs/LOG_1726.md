# LOG_1726 - Visor Glass Dirt, Scratch, Salt Mask Baker

## 2026-06-03 - Offline Packed Visor Mask Baker

What was wrong:
- SuitVisor.shader depended on separate scratch/fingerprint/droplet/procedural paths and had no single packed visor wear contract for dirt, scratches, salt, and 64-frame condensation.
- Runtime UI audit found no glass-wear `SetPixels` route in SuitHUDV4CanvasOverlay.cs, but the visor presentation path still lacked a static baked texture contract. The only `new Texture2D`/`Apply` in the audited overlay is acoustic radar payload, not visor glass wear.
- Default unassigned texture risk: Unity black texture alpha can be nonzero, so condensation alpha needed an RGB presence gate to avoid accidental fog if `_VisorMaskTex` is not assigned.

What was done:
- Added `Assets/_Project/Editor/Bakers/VisorMaskBaker.cs`.
  - EditorWindow with MenuItems: open, default bake, dry-run kernel.
  - Uses RenderTexture random-write output, GraphicsBuffer structured params, ComputeShader.HasKernel, GetKernelThreadGroupSizes, ceil dispatch groups, try/finally cleanup, OnDisable/OnDestroy release routes.
  - Writes `Assets/_Project/Art/Textures/UI/TX_Visor_{assetName}_Masks.png`.
  - Configures TextureImporter: sRGB false, Clamp, Bilinear, mipmaps false, CompressedHQ, Standalone BC7, Android/iPhone ASTC_6x6.
  - Validates finite normalized pixels, exact pixel count, non-empty RGBA channels, and frame 0 to frame 63 alpha loop delta before success.
- Added `Assets/_Project/Art/Shaders/Include/VisorMaskBaker.compute`.
  - R channel: dirt/fingerprint/edge smudge.
  - G channel: long scratches and micro scratches.
  - B channel: salt crust, edge accumulation, lower-lip residue, crystalline flecks.
  - A channel: 8x8/64 condensation flipbook.
- Updated `Assets/_Project/Art/Shaders/SuitVisor.shader`.
  - Added `_VisorMaskTex`, `_VisorMaskStrengths`, `_VisorMaskUvShift`, `_VisorCondensationFlipbook`.
  - Added GPU-only flipbook alpha sampler using `_Time`, drift speed, optional manual frame/blend, and RGB presence gate.
  - Integrated baked dirt/scratch/salt/condensation into existing scratch normal, smudge opacity, condensation mask, refraction dirt, and glare tint.
- Added pre-bake proof artifact `Docs/Reports/VISOR_BAKER_REPORT_1726.json`.
  - State is `PENDING_UNITY_BAKE_CPU_GATE`; editor bake overwrites it with pixel metrics after dispatch.

Cinematic Cheats used:
- Replaced real condensation simulation with periodic unit-circle time sampling in a static alpha atlas.
- Replaced real glass wear physics with edge masks, smudge ellipses, scratch lines, and salt/brine noise baked offline.
- Runtime variation is shader-only: UV shift, threshold/strength, and time-driven flipbook interpolation.

Exact microseconds saved:
- Runtime CPU texture update eliminated for new visor wear path: target steady-state cost 0 B GC and 0 us CPU pixel update.
- Avoided CPU `Texture2D.Apply` fog upload target: estimated 50-300 us per avoided dynamic update on i3/MX350-class hardware; exact profiler capture pending Unity bake/playmode.
- Texture fetch consolidation target: four authored mask sources collapsed into one packed texture binding; fragment cost not profiler-confirmed.
- Static audit/implementation estimates recorded in `Docs/Tasks/Status_1726.md`; exact runtime microseconds remain `PENDING_UNITY_BAKE_CPU_GATE`.

Verification:

- `Docs/Reports/VISOR_BAKER_REPORT_1726.json`: JSON parse PASS.
- New files ASCII scan: PASS.
- Runtime mutation scan: new `Texture2D`/`Apply` exists only inside `UNITY_EDITOR` VisorMaskBaker readback. Existing SuitHUDV4CanvasOverlay acoustic radar texture path remains unrelated to visor glass wear.
