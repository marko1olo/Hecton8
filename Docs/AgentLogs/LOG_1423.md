# LOG_1423

## 2026-05-28 - ZERO_GC_SUBTITLES_AND_BABEL_LOCALIZATION_COMPILER

What was wrong:
- Runtime UI/Audio/Babel target scan found no real hot `string.Format`, `TMP_Text.text =`, `.ToString()`, or interpolation hits in the assigned path set; two hits were glyph literal false positives.
- Existing span route had weaker correctness: numeric formatting depended on current culture, recognized Babel placeholder overflow could fall back to literal token output, and no UI-specific numeric failure ring existed for missing localization hashes or text buffer overflow.
- Build verification is blocked by out-of-domain Visor/XR errors: `Assets/_Project/Scripts/Visor/HectonVRBrownoutFeature.cs(437,64)` and `(476,74)` missing `XRPass`.

What was done:
- Added `IBabelLocalization.TryWriteLocalized(uint, Span<char>, out int, bool)` and implemented it in `LocalizationManager`.
- Hardened `ZeroGCFormatter` int/float span formatting with `CultureInfo.InvariantCulture`.
- Added `ZeroGCFormatter.AppendToSpanTruncated` and `AppendAsciiEllipsis` for explicit bounded text writes.
- Routed `LocNumericArg.Float` through `ZeroGCFormatter` instead of direct culture-default `float.TryFormat`.
- Hardened `LocRegistry.DecodeUtf8VisualSpan` so recognized caret/brace placeholder overflow clamps to max glyph capacity, records truncation, and renders ellipsis instead of literal placeholder leakage.
- Added `TmpTextNoAlloc.SetLocalized` to decode a Babel hash directly into `CharBufferPool.BabelLease` and push to TMP via `SetCharArray`.
- Added `UIOptimizationFailureCode` and 64-byte `UIOptimizationTelemetryEntry` ring in `BabelSubtitleSyncRuntime`, capacity 300, DataVault buffer id 15070552, dump path `Docs/AgentLogs/Dump_1423.bin`.
- Injected numeric failure telemetry writes for missing localization hash, text buffer overflow, and formatter overflow.
- Added `Assets/_Project/Tests/Editor/ZeroGCSubtitleFormatter1423EditTests.cs` with invariant numeric, 500-warning mock formatter, and truncation cursor tests.
- Emitted reports:
  - `Docs/Reports/UI_STRING_ALLOCATION_HITLIST_1423.json`
  - `Docs/Reports/UI_ZERO_GC_ARCHAEOLOGY_1423.json`
  - `Docs/Reports/UI_STRING_ALLOCATION_AST_AUDIT_1423.json`
  - `Docs/Reports/UI_ZERO_GC_OPTIMIZATION_REPORT_1423.json`
