- Added PlayerEcosystemTelemetryDTO as explicit 32 bytes with required first 16 bytes: EmptyScansStreak, TotalOresMined, DistanceSinceLastFind, PityTriggerActive.
- Added runtime/editor SizeOf/offset validation for the telemetry DTO.
- Added deterministic pity spawn path inside GenerateResourceNodesJob: threshold >= 5, LCG seed from sector/streak/AUP, forward placement 42-60m ahead with bounded grounding probes, copper baseline and titanium bonus after longer streak.
- Added IWorldResourceSpawnerCommandModel.ReportScannerSweepResult and wired GPR scan completion to the spawner command lane after job completion.
- Added existing-handle-only telemetry write helper; scan report and mining reset acquire exactly one write lock and release in finally.
- Moved pity haptic feedback after telemetry lock release through SignalBus<HapticRequest>.
- Removed GPR runtime material fallback; render material is authored-only.

Cinematic cheats used:
- Pity ore is not a physical simulation. It is a deterministic authored reward placement biased into the player's forward cone.
- Low/Middle/High/Ultra all share the same ore truth; GlobalQualityWeight only affects existing presentation density/cluster visuals.
- Forward placement uses bounded surface sampling instead of raycast-heavy physical searching.
- Missing authored prefabs fail closed instead of generating ugly primitive placeholders.
