# LOG_1415

## 2026-05-28 - Circular Telemetry Ring Hardening

What was wrong:
- Telemetry DTO inventory found non-uniform ring element sizes and implicit/partial layout contracts across crash telemetry domains.
- 76 telemetry/black-box candidates were non-64-byte; 40 were field-preserving convertible, 36 were oversize and cannot be safely shrunk without deleting diagnostics.
- After the first 64-byte rewrite, stale dump/validator contracts still advertised old 32/48-byte rows in FluidPipe, DRS, Scalability, Biolum, and Salinity corrosion paths.
- DRS dump serialization wrote `UpscalerComputeTimeMsBits` at the old offset; Salinity corrosion dump wrote only 32 payload bytes for a now-64-byte record.

What was done:
- Materialized 38 telemetry structs to explicit 64-byte layouts with concrete `[FieldOffset]` maps and padding to byte 63.
- Left 36 oversize entries untouched and tracked as owner-domain split work; no diagnostics were dropped.
- Repaired dump/validator contracts:
  - `FluidPipeTelemetryEntry`: runtime size sentinel 32 -> 64.
  - `DrsTelemetryEntry`: `DrsTelemetryEntryBytes` 48 -> 64 and little-endian writer realigned to offsets 36/40/42/44-47.
  - `ScalabilityTelemetryEntry`: validator/header/stackalloc row size 32 -> 64.
  - `BiolumPulseTelemetryEntry`: black-box stride and layout sentinel 32 -> 64.
  - `SalinityCorrosionTelemetryEntry`: dump stride 32 -> 64 and per-row writer changed from `BinaryWriter` fields to stackalloc 64-byte row + `FileStream.Write`.
- Generated `Assets/_Project/Scripts/Editor/TelemetryLayoutValidator1415.cs`, with 38 spec rows, reflected `UnsafeUtility.SizeOf<T>()`, and `UnsafeUtility.GetFieldOffset` checks for every field including padding.
- Produced final proof artifact `Docs/Reports/TELEMETRY_LAYOUT_OPTIMIZATION_REPORT_1415.json`.

Cinematic cheats used:
- No physical simulation was added. The pass is data-layout only.
- DTO stride remains invariant across weak, middle, high, and ultra devices; quality scaling remains a consumer policy via continuous `GlobalQualityWeight`, never a binary DTO shape switch.
- Mock corruption was done in-memory instead of mutating source, avoiding cross-agent damage while proving the validator catches offset drift.
