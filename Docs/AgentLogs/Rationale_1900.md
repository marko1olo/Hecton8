# Rationale 1900

Evidence class: STATIC_DOC / STATIC_SOURCE
Runtime proof: PENDING UNITY

## Decisions

- Preserve the nine WorldSupport family concepts. The blocker is visible primitive carrier art, not the support route itself.
- Keep hidden truth under `ProceduralFamily_*.asset` and WorldSupport marker/trigger ownership: family id, final variant id, heatmap, placement, spacing, radius, count, spawn/zone/pocket role.
- Treat visible carrier as replaceable presentation only. It may signal route, ecology, hazard, resource, or shelter meaning, but it must not own gameplay truth.
- Allow current flora/geology/BioForge sources only as ingredients after manifests and proof. Static existence is not production readiness.
- Forbid `WorldProceduralProxy`, `WorldRuntime/ProceduralPlaceholders`, visible built-in primitive meshes, AI proxies, and current primitive finals as production visible carriers.
- Require future editor/offline authoring, manifests, material/texture/vertex-color contracts, separate hidden triggers, collider proxies, screenshots, profiler, and Frame Debugger proof before relink.
- Use `PENDING UNITY` status for all runtime, import, screenshot, profiler, and Frame Debugger claims.

## Scaling Consequence

- Compact preserves route silhouette, hidden truth, shared material use, simple proxies, and no alpha-blended flora fields.
- Middle adds normal LOD/material density.
- High adds richer material response and longer LOD residency.
- Ultra adds visual overkill only. It does not change gameplay truth, DTO layout, save identity, family ids, or authority route.
