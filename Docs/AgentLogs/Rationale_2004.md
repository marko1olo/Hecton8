# Rationale 2004

## Decisions

- Treated 2004 as a source package task only because the prompt forbids Unity, MCP, imports, builds, and active `Assets` edits.
- Produced docs, manifests, checklist, prompt packs, and explicit batch logs only.
- Separated intertidal shoreline flora from underwater kelp. Underwater kelp on dry land is a reject condition.
- Kept BioForge as a source/topology route, not a final proof route. Static code shows BioForge vertex colors currently encode only height in red, while final flora/coral requires semantic RGBA.
- Documented the BioForge shallow atlas as ORMA (`R=AO`, `G=Roughness`, `B=0/metallic unused`, `A=Emission`) because the code writes that order. It must not be silently treated as MRAO.
- Required imported managed texture stacks for authored finals because the final variant validator rejects unmanaged or mixed texture sources and warns on generated starter stacks.
- Required placement fixes before scene proof because the dry-land audit shows min-depth 0 underwater rules, dry depth 0 mapping, missing required substrate serialization, `preferSeafloor:0`, and proxy fallbacks.
- Used fauna report only to reserve passive-fauna view lanes, predator separation, and navigation biolum coordination.

## Low Middle High Ultra Consequences

- Low: reduce density, map size, and optional cadence; keep authored silhouettes, seafloor placement, and route cues.
- Middle: use full family coverage at moderate density with stable imported stacks.
- High: add richer detail, more variants, and stronger ecology masks inside validator budgets.
- Ultra: spend extra budget on hero variants only through explicit route cards; do not alter gameplay truth, DTO layout, save identity, or placement ownership.
