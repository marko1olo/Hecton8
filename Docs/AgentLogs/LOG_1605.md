# LOG 1605 - SUBSTANCE_SHADER_AND_TEXTURE_BAKER

What was wrong: The offline texture/atlas pipeline still had transaction escape points: raw compute kernel resolution, broad mesh UV catch filters, throwing packed-rect lookup, false success on empty rectangle packs, APEX missing transaction guard coverage, fatal short-buffer mesh copy, and per-mesh asset saves.
What was done: Added controlled compute kernel resolution, recoverable exception fence, rollback-aware packed rect lookup, empty pack rejection, APEX transaction safety token verification, recoverable short-buffer route, and single-save mesh UV transaction behavior.
Cinematic Cheats used: Static generated PBR textures and BRG-friendly atlases remain the draw-call/VRAM cheat; the pass prevents corrupted source data from leaving partial texture/material/UV proof artifacts.
Exact Microseconds saved: Runtime 0 us. Editor I/O saves estimated 200-5000 us per extra mesh by removing per-mesh `AssetDatabase.SaveAssets()`; other changes avoid wasted allocation or false proof states. No `dotnet build`, Unity build, Unity test, or player build launched by 1605.

## 2026-06-02 - Atlas Transaction Polish Pass

What was wrong: Atlas PNG rollback did not include the `.mat` output file, and the readable texture bridge could report success even if `isReadable` restoration failed.
What was done: Added four-asset rollback capture for albedo/normal/M.R.A.O./material outputs; renamed atlas rollback flow to `assetRollback`; made readable-state restoration fail-closed through `TryRestoreTextureReadableState`; extended APEX token gates and source probes.
Cinematic Cheats used: Offline atlas bake remains the BRG material-family cheat: one compressed atlas family buys fewer material routes and stable UV remaps instead of runtime material mutation.
Exact Microseconds saved: Runtime 0 us. Failed atlas recovery avoids estimated 100-3000 us manual asset repair/reimport per failed pack; readable restore hardening prevents persistent imported CPU texture copies. No `dotnet build`, Unity build, Unity test, or player build launched by 1605.

What was done: Added `iPhone` ASTC_6x6 import override and audit path in `ProceduralTextureBaker`; extended source probes.
Cinematic Cheats used: Mobile/handheld lanes keep the offline atlas cheat compressed instead of paying runtime memory for platform fallback.

Cinematic Cheats used: Low/mid lanes can bake smaller atlases while high/ultra retains 4K atlas overkill from the same material-family path.
