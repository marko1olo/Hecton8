## 1. Deep Reachの企業構造

Aegirシステムへようこそ。諸君は現在、Deep Reach地球外開発コンバインの管轄下で活動する、認可された独立請負業者である。スムーズな統合を確実にするため、以下の部門権限を記憶すること：

*   **Aegir Continuity Holdings:** HECTON-8のすべての惑星リース権を保有するフロンティア部門。彼らが諸君の最終的な雇用主である。
*   **Atlas Continuity Office:** Atlas-6 AIコアを管理する法務およびソフトウェア部門。許可なくAtlas-6にアクセスしようとしてはならない。
*   **Keelmark Loss Desk:** 引受部門。壊滅的な機器の故障が発生した場合、Keelmarkが諸君の損失の財務リスクを評価する。
*   **Recovery Compliance Office:** 我々は軌道補給船*Black Keel*における諸君の直接の管理者である。我々は潜水座標を発行し、キセノン・オメガの存在証明を要求し、請負業者沈黙プロトコルを執行する。

## 2. 「マローダー」の区別

諸君は公式には「独立サルベージ請負業者」として分類されている。自らを「マローダー（略奪者）」と呼ぶことは、企業の行動規範に対する違反である。この用語は元々、Keelmarkの検査官が到着する前に放棄されたモジュールをこじ開けたクルーに対する、軽蔑的な法的分類に由来する。

*[欄外のメモ: 俺たちがこの名前を使い続けているのは、スーツ連中をビビらせるためだ。企業契約の救助条項なんて、奴らがお前の死体を所有するための別の手段にすぎない。俺たちは破産したパイロット、はぐれ者の溶接工、そして契約破りの集まりだ。]*

## 3. 3つの元帳

独立請負業者として、諸君の報酬は回収されたキセノン・オメガ基質の質量に基づいて厳密に計算される。諸君の初期の先取特権は、4.8トン（軌道打ち上げ質量）相当である。*Black Keel*での恒久的な居住区が許可される前に、この負債を働いて返済しなければならない。

*[欄外のメモ: 企業の元帳はデタラメだ。本物のマローダーの経済は、「空気」、「借金」、そして「死者」で回っている。*
*空気: 分数、分圧、CO2スクラバーの熱、そしてバルブが壊れた後の醜い沈黙で数えられる。*
*借金: ツールの摩耗、バッテリーのサイクル、貸し借り、そしてKeelmarkのリストから消された名前で数えられる。*
*死者: 行方不明の労働者は奴らにとって悲劇ではない。「未解決のシステム負荷」だ。俺たちが死者の目録を作るのは、企業に彼らが最初から存在しなかったふりをさせないためだ。]*

## 4. 運用用語

インシデントを記録する際は、標準的な企業用語を遵守すること。圧力変動には「一時的な大気変動」を使用すること。「資産の封じ込め優先」とは、緊急時にキセノン保管庫を密閉する必要性を指す。
