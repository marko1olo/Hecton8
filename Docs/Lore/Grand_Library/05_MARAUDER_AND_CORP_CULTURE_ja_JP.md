# 企業官僚主義と略奪者文化
**大図書館セクション:** 05
**言語:** ja_JP
**カノン:** 厳格 (Lore Bible 2190)

---

## 1. Deep Reach：敵の構造
*Deep Reach Extraterrestrial Development Combine* は黒いマントを羽織った段ボールの悪役ではない。それはスプレッドシートで人を殺す官僚的機械だ。エーギルでの汚れ仕事は、死体の個人的責任を誰も負わなくて済むように、ペーパーカンパニーと部門のシステムを通じて分割されている：

*   **Aegir Continuity Holdings：** HECTON-8惑星の書類を保有するフロンティアのペーパーカンパニー。
*   **Atlas Continuity Office：** Atlas-6 AIコードの文言を擁護し、同位体抽出の継続性を保証する法務部門。
*   **Keelmark Loss Desk：** 保険部門。彼らの仕事は、死んだ労働者の名前を「負荷カテゴリーと財務リスク」に変換することだ。
*   **Recovery Compliance Office：** 2190年に我々略奪者を雇うのは彼らだ。軌道補給船*Black Keel*を調整し、キセノンの存在証明を要求し、請負業者の沈黙を確保する。

Deep Reachの恐怖は、秘密の玉座の間にあるのではない。恐怖は、彼らが作成するすべての文書が技術的に完璧で法的に正当化可能であることにある——人々がロックされたドアの向こうで窒息している最中でさえ。

## 2. 略奪者文化
我々は冒険小説に出てくるロマンチックな宇宙海賊ではない。「略奪者（マローダーズ）」という言葉はもともと、保険検査官が到着する前に放棄されたモジュールをこじ開ける独立した乗組員に対する企業の侮蔑語だった。乗組員たちはその言葉を残した。それが正しい人間を怯えさせたからだ。

略奪者とは、サルベージャー、契約破棄者、破産したパイロット、あるいは追放された溶接工であり、「企業契約の救助条項は、あなたの死体を所有するもう一つの方法にすぎない」と学んだ者だ。

## 3. 三つの主要な台帳
略奪者の乗組員の経済は三つの概念の上に成り立っている：**空気、借金、そして死者**。

*   **空気：** 分単位、分圧、CO2スクラバーの熱、そして壊れたバルブの後に続く醜い沈黙で数えられる。
*   **借金：** 工具の摩耗、バッテリーサイクル、恩義、そしてDeep Reachの保険リストから消された名前で数えられる。略奪者の初期留置権は4.8トン相当（軌道リフト質量）であり、Black Keelに乗ることを許可される前にこれを働いて返さなければならない。
*   **死者：** 行方不明の労働者は、その人が放棄されたのか、配置転換されたのか、「バイオマス会計に溶解」されたのか、あるいは単に企業がまだ「安全」と呼んでいるドアの後ろに閉じ込められたのかを誰かが証明するまで、トロフィーではない。略奪者たちはこの仕事をロマンチックにしない。彼らはそれを棚卸しする。

## 4. 生存の言語
浸水した施設の内部では、階級は能力に属する。カッターは、スカウトが帰還ルートにマーキングした後にのみドアを切る。計器が嘘をついているとき、技術者はパイロットを却下できる。新米の略奪者は英雄的行為ではなく、小さな故障が大惨事になる前に報告することで信頼を獲得する：ハッチ周りの霜、死んだチャンネルに響く声、流れに逆らって圧縮する魚の群れ。

企業人は書く：「一時的な大気変動」。略奪者は書く：「CO2が最初に判断力を食う。」
企業人は書く：「資産封じ込め優先」。略奪者は書く：「彼らはキセノンタンクを救い、居住区の空気を抜いた。」

略奪者の名誉は清潔な道徳ではない。それは致命的な圧力下での、再現可能でフェイルセーフな手順である。我々は企業から盗み、死者から借金を取り立てる。それが略奪者が安い宇宙服を着た企業人に成り下がることを防ぐ唯一の境界線である。
