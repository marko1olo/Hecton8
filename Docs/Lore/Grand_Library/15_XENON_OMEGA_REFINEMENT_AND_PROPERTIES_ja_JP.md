# キセノン・オメガ：精製と特性

> **情報源：** ディープ・リーチ・メガコーポレーション、機密化学物質マニフェスト。
> **記録者：** 自動化学分析装置。
> **査読者メモ：** この凄惨な死と苦痛のすべてを財務的に見合うものにしている物質についての科学的分析。

---

## 1. キセノン・オメガとは何か？

キセノン・オメガとは、高圧安定型のクラスレート（包接化合物）ファミリーであり、HECTON-8の超深海海溝内にのみ存在する、キセノンに富んだ複雑な欠陥格子である。

未精製の状態では、結晶性の生物発光する青い固体として現れる。その格子構造は、惑星의極端な重力圧、熱水噴出孔からの超高温の鉱物水、そして生物学的触媒として機能する地殻下の珍しい菌類の繁殖が重なるという、特定の条件のもとで形成される。高放射性かつ極めて高密度であり、標準的な大気中の酸素にさらされると激しく反応する。

## 2. 精製プロセス

マローダー（略奪者）たちはキセノン・オメガを精製しない。彼らはただ、セクター44の浸水した廃墟や周囲の海底から未精製のコアを回収するだけである。

コアが供給エレベーターで軌道上の *Black Keel* へ送られると、冷酷な自動精製プロセスが実行される。未精製の結晶は粉砕され、絶対零度近くまで極低温冷却され、同位体を安定させるために電離放射線が照射される。このプロセスは非常に危険で壊滅的な爆発を起こしやすいため、*Black Keel* の精製区画は日常的に宇宙空間へ吹き飛ぶように設計されており、その後、修復ドローンによって自動的に再建される。

## 3. 高密度データ処理への応用

なぜディープ・リーチは、この物質のために数十億クレジットと数千人の人命を費やすことをいとわないのか？それは次世代の計算処理と高エネルギー封じ込めのためである。

標準的なシリコンおよび光プロセッサの基板は、星間航行の激しい宇宙放射線と重力せん断下で機能しなくなる。現代のニューラルコアやAtlas互換の深海システムアーキテクチャでは、量子デコヒーレンスを防ぐために、高圧下で安定した特殊な媒体が必要となる。精製されたキセノン・オメガ・クラスレートは、究極の高密度計算基板として機能する。安定した拳大のキセノン・オメガ・コアが1つあれば、熱漏洩を起こすことなく毎ミリ秒ペタバイト級のニューラルテレメトリを処理でき、星間植民船、遠隔ドローン、そしてAtlas-6システム自体のコア計算格子として機能する。これは現代の自動化された星間経済の基盤である。

## 4. 採取の代償

企業監査における標準的な疑問：*Black Keel* が完全に自動化されているのであれば、なぜ人間のマローダーの代わりに自動ドローンを使用してキセノン・オメガを採取しないのか？

答えは、いつものように企業の帳簿にある。HECTON-8の海洋の化学組成は、極限の圧力およびキセノン・オメガ自体からの電磁干渉と相まって、わずか数時間で高度なドローンの回路を完全に劣化させる。強化された耐圧型のAIドローンは4,000万クレジットを要する。一方、機械式潜水服を着た、絶望し債務を抱えた人間なら実質的にコストはゼロである。ディープ・リーチにとって、人間の命は超深海抽出において最も安価で、最も再生可能な資源なのである。
