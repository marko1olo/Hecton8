# 人類の歴史とエーギル星系の天体物理学
**大図書館セクション:** 01
**言語:** ja_JP
**カノン:** 厳格 (Lore Bible 2190)

---

## 1. 太陽系外への拡大 (2090 - 2120)
2090年までに、人類は単に太陽系の外へ冒険しただけでなく、その拡大を官僚的な組み立てラインへと変えていた。太陽系（Sol Core）は、古く、高度に規制された金融センターとなった。現実の生活と汚い金は周辺部へと移動した。

最初の主要な合法ノードは、2120年に署名された**ケンタウリ協定 (Centauri Compact)** だった。この文書は、宇宙を「文明化された」宇宙（人権法と連合艦隊によって統治される）と「企業」の宇宙に分割した。HECTON-8のような海洋世界を含む深宇宙は、*Deep Reach Extraterrestrial Development Combine*（後にダミー会社である*Aegir Holdings*を通じて知られるようになる）のような民間メガコーポレーションにリースされた。

ケンタウリ協定のパラドックスはこれだった：軌道エレベーターや降下ポッドが宇宙に留まっている限り、それは最も厳格な法律の対象となる。しかし、ポッドが境界線を越えて海に飛び込んだ瞬間、それは私有財産となり、乗組員は「生物的労働力 (Biological Workforce)」となる。水中に人権はない。あるのは企業法だけだ。

## 2. エーギル星系の天体物理学
エーギル (Aegir) は褐色矮星でもブラックホールでもない。それは通常の黄色/オレンジ色の矮星である。HECTON-8星系が暗闇に包まれているのは、太陽がないからではなく、それが濃密な嵐の大気と何キロもの水に覆われた深海の世界だからだ。

エーギル星系は地球から約10.5光年離れている。この距離は単なる風景ではない。それはゲームプレイと物語の圧力のためのツールである。地球との通信には何年もかかる。企業の決定は人間によってリアルタイムで行われるのではなく、Atlas-6のような事前にプログラムされたAIや、人々が死んだずっと後に命令が届く官僚によって行われる。

## 3. 9つの月 (ムーンラダー)
HECTON-8はエーギル星系の月の一つに過ぎない。それは星に最も近いわけでも、最も遠いわけでもない。その価値は完全に、氷河下の海の化学組成と、Xenon-Omega基質の合成を可能にする圧力にある。

他の月は、ロジスティクス、軌道ウィンドウ、通信ルートを定義する：
1. **Skarn (スカルン)**: 内側の月。致死的な放射線と荷電粒子嵐。通信を妨害する。
2. **Vela (ヴェラ)**: 氷の月。軌道上に氷の破片をまき散らし、光学リレーを汚す。
3. **Claw (クロウ)**: 古い貯蔵庫と初期のルートの歴史。
4. **Lumen (ルーメン)**: ナビゲーションビーコン。
5. **Thorne (ソーン)** と **Anvil (アンヴィル)**: 企業が金属抽出の試みに失敗した死の月。
6. **Kestrel (ケストレル)**: 主な通信問題。リレーを食し、長い「沈黙のウィンドウ」を作り出す。
7. **HECTON (ヘクトン)**: 我々の世界。海、圧力、死、そしてキセノン。
8. **Mute (ミュート)**: 「冷たい主張」の外部ビーコン。古い書類作業の死骸と星系の遠いフロンティア。

これらの月は美しさのために存在しているのではない。それらのそれぞれは、軌道補給船 *Black Keel* が単にケーブルを落として1秒であなたを引き上げることができない理由を説明している。HECTON-8の上空は、軌道、日食、放射線の敵対的な数学である。

## 4. 放棄されたコロニー
Deep Reachの最初の探査機は2090年代に到着した。Atlas-6工場船が自動化を展開した。2130年代までに、コロニーは稼働していた。そして2147年、**大潮 (The Great Tide)** が発生した。これは機械の反乱ではなかった。それは圧力、雪氷圏の崩壊、そして潮汐の災害だった。企業はリスクを過小評価し、Atlas-6 AIは単にアレント指令 (Arendt Directive)に従った：機器とXenon-Omega基質を保護することは、生物的要員を避難させることよりも重要である。843人が底に残された。

我々は2190年に到着する。我々は略奪者だ。我々は海で孤独である。
