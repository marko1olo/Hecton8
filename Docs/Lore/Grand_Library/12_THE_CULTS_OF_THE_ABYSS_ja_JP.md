# 深淵のカルトと圧力精神病

> **出典:** 精神医学的評価記録（回収済）、セクター44医療室。
> **話し手:** サイラス・ベイン博士、主任精神科医（死亡）。
> **査読者注記:** 深海で発生した労働者の精神的崩壊と、そこで生まれた奇妙な宗教運動に関する臨床的考察。

---

## 1. 圧力誘発性せん妄

人間の精神は、超深海層（アビッサルゾーン）の孤立状態に耐えられるようには設計されていない。セクター44が崩壊する前、労働者たちは医療スタッフが「圧力誘発性せん妄（PID）」と呼ぶ症状に苦しんでいた。

PIDは幻聴から始まる。労働者たちは、チタン製支柱の規則的なきしむ音の中に「声」が聞こえると主張する。病状が進行するにつれ、強化ガラスの向こう側に広がる暗闇は、単なる虚無空間ではなく、意志を持った存在として認識されるようになる。コロニーにかかる8,500メートルの海洋の凄まじい水圧そのものが、いかなる薬物でも完全には抑制できない閉塞的な恐怖を生み出すのだ。人類から完全に隔絶された実存的恐怖に対処するため、一部の労働者たちは、海洋を敵対的な環境ではなく「神」として合理化し始めた。

## 2. 空無のカルト

セクター44の下部技術デッキにおいて、本格的な宗教運動が根を下ろした。それが「空無のカルト（ボイド・カルト）」である。

このカルトは、レヴィアサン、ストーカー、発光生物の群れといった異星深海生物たちを、深海に沈んだ神の「使徒（天使）」であると信じていた。彼らは、メガコーポレーション（Deep Reach）がキセノン・オメガを採取することは神への冒涜であると説いた。カルトの信者たちは、「暗闇を迎え入れる」ために、コロニーの照明を意図的にサボタージュした。彼らは発光する深海植物をすり潰して作った染料でタトゥーを彫り、その皮膚を漆黒の闇の中で光らせた。

## 3. 犠牲的サルベージ

カルトの行為は次第に常軌を逸していった。キセノン・オメガのコアを供給エレベーターで地上（軌道上）に送る代わりに、彼らはそれらを「捧げ物」として最も深い熱水噴出孔へ投げ入れ始めた。

食料配給が不足した際、カルトは「異なる形態の生贄」を捧げ始めたという噂がある。セクター44の廃墟を捜索するマローダーは、内側から手動でオーバーライドされ、内扉に深い爪痕が残されたエアロックを発見することがある。カルト信者たちは、コロニーの存続を許してもらう代償として、レヴィアサンが肉体を要求していると信じ、未信者を潜水服なしで海洋へ突き落としたのだ。

## 4. コープの対応

通常であれば、Deep Reachは数兆クレジットの施設から殺人カルトを直ちに排除するはずである。しかし、彼らはそうしなかった。

軌道船 *Black Keel* のリスク管理アクチュアリー（保険数理士）たちは、空無のカルトが下部セクターにおけるキセノン・オメガの採取率を実際には14%向上させていると算出した。信者たちは、自らの労働を過酷な贖罪の儀式であると信じ、文句も言わずに1日20時間という過酷なシフトで働いた。ノルマが達成されている限り、Deep Reachは人員の失踪や照明の破損を黙認した。コロニー全体が水没して初めて、コープはカルトが単にレヴィアサンを崇拝していただけでなく、それらを能動的に「目覚めさせよう」としていたことに気付いたのである。
