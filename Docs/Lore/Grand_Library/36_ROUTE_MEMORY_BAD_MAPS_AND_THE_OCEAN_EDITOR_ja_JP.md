# ルート記憶、悪い地図、編集する海

> **出典:** Black Keel ルート受入付録、Deep Reach 測量断片、Marauder 経路メモ。  
> **話者:** ナビゲーション教官。後年のサルベージ注釈を含む。  
> **レビュアー注:** HECTON-8 において、地図は誰かが一度その道を生き延びた証明である。その道が今も存在するという約束ではない。

---

## 1. 海は編集する

乾いた地図は人間を甘やかす。距離が従順であるかのように見せる。

HECTON-8 はそのようには従わない。圧力は廊下を座屈させる。塩水は忍耐強い動物のように下へ滑る。シルトは、どの警報も崩落と呼ばないほどゆっくり扉口を埋める。サービストンネルは物理的には開いているまま、ひとつの受信機が死に、ひとつのガスケットが膨らみ、ひとつの生物巣が吸入口を横切って育っただけで使えなくなる。道はまだある。ルートは消えている。

古い測量図は役に立つ。意図を記録しているからだ。Deep Reach が人々にどこを移動させるつもりだったか、緊急チームがどこに集まる想定だったか、機械がどこで熱を水へ吐くはずだったか、安全室がどこで電力を持って待つはずだったかを示している。だが海は許可を求めずに意図を編集する。すべてを消すわけではない。十分なだけ変える。

だから良いルートメモは決して「安全」とは言わない。いつ、誰が、どのスーツで、どの荷重で、どの嵐の後に、どのドアが壊れる前に通ったのかを書く。

## 2. ルート記憶

HECTON-8 のルートは層で記憶する。

公式層は清潔だ。測量線、アクセス番号、保守予定、圧力分類、音響アンカー、ドローンのウェイポイント。これはもっともアーカイブされやすく、もっとも現状と合いにくい層である。作業者の層はもっと汚い。近道の切れ込み、繰り返しの手袋で磨かれた手掛かり、低い配管の結束バンド、鉱物皮膜の下に封じられた古いチョーク。Marauder の層はさらに荒い。擦過痕、tether の結び目、私的な警告、もう応答しないクルーにだけ点滅するよう調整された受信機。

どの層も単独では足りない。公式データは、そのルートが何のためにあったかをプレイヤーに教える。作業者の記憶は、生きた人々が実際にどう使ったかを教える。Marauder の記憶は、コロニーの保守が止まった後で何が変わったかを教える。三つが食い違うとき、その食い違いはノイズではない。手がかりである。

地図上の行き止まりは、生きた近道かもしれない。きれいな廊下は、誰も印を残していないから罠かもしれない。警告が多すぎるルートは、少なくとも最近読まれたという理由で、地区でもっとも安全な道かもしれない。

## 3. 悪い地図

悪い地図は、いつも間違っているとは限らない。もっと悪いことに、ほとんど正しい場合がある。

ほとんど正しい地図はプロを殺す。疲れたダイバーを正しい隔壁へ連れていくが、間違った圧力ポケットを通らせる。まだ存在する梯子を示すが、その梯子はシルトの下で終わっている。もう浸水していない区画を迂回し、今では塩水だまりになった乾いたロッカーを通らせる。事実が動いた後も、古い確信だけを保存する。

地図詐欺は存在するが、多くの場合、嘘は年齢である。売り手はルートを捏造しなくても、古くなっていると認める前に売ればよい。クルーは悪意がなくても悪いデータを残す。ただ急いで生き延びればいい。Deep Reach が悪である必要はなかった。緊急オーバーレイが危険になるには、去り、更新を止め、水に残りを任せるだけでよかった。

Black Keel は地図を疑いながら評価する。新しいスキャンは重要だ。添付メタデータは重要だ。欠けたメモのパターンは重要だ。訂正のない地図は、新しいか、役に立たないか、販売用に掃除されたかのどれかである。

## 4. ルートの読み方

経験ある Marauder は、ルートを身体のように読む。

同じ曲がり角で肩が擦れた、磨かれた角を探す。敷居の片側に積もったシルトを見て、流れがどちらへ息をしていたかを読む。低電力のドローンが帰還のために引きずったケーブル痕を探す。悪いフィルター越しに熱い断熱材の匂いを嗅ぐ。死んだ受信機より、その取り付け部の錆を信じる。完全に開いた通路を生物が避けていることに気づく。

これは神秘主義ではない。圧力下の注意である。HECTON-8 は、移動の小さな文法を学ぶプレイヤーに報いる。繰り返しの接触が塗料に何をするか。パニックが手すりに何をするか。スーツが警告で沈黙を埋めるのをやめたとき、長く放棄されたルートがどう聞こえるか。

最良の道は、めったに最短ではない。プレイヤーがその嘘を理解している道である。

## 5. プレイヤーが学ぶこと

プレイヤーは、ナビゲーションを移動ではなく保管として扱うことを学ぶ。

使われたすべてのルートは記録の一部になる。更新することも、売ることも、隠すことも、汚染することも、掃除することも、警告として残すこともできる。修正された地図は別の作業者を救うか、地区の価値を上げる。隠された近道はクレームを生かし続けるか、プレイヤーがもう説明したくない部屋へ別の誰かを導く。悪いメモは書いた者より長く生き、害を与え続ける。

Black Keel がルートに金を払うのは、ルートが未来の労働だからだ。Marauder がルートを守るのは、ルートが私的な呼吸だからだ。Deep Reach がルートを残したのは、コロニーが、ストレスの下でも人が移動しなければならないという前提なしには存在できないからだ。

HECTON-8 において、地図は決してただの地図ではない。昨日をまだ信じられるかどうかについての、海との議論である。プレイヤーがその議論に勝つには、線をたどるべき時、疑うべき時、そして暗闇の中を呼吸しながら進む次の人のためにより良い印を残すべき時を学ぶしかない。
