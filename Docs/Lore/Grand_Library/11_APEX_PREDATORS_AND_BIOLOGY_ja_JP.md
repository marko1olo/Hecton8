# エイペックス・プレデターと深海生物学

> **情報源:** 第44セクター研究ラボより回収された地球外生物学報告書の断片。
> **報告者:** 主任地球外生物学者 アリス・ソーン博士（死亡）。
> **査読者メモ:** 第44セクターのテレメトリーにより、バイオ脅威密度94%が確認された。ソーン博士の記録は、水没した生物封じ込めリングから回収された。

---

## 1. 化学合成食物網

HECTON-8の第44セクターの運用深度においては、日光が届かない。生態系全体が熱水噴出孔（ブラックスモーカー）によって維持されている。巨大な熱水噴出孔が、周囲の1.8℃の海洋水柱に向けて、超高温でミネラル豊富な水を噴出している。

これらの噴出孔の周囲には、細胞壁内に硫化鉄を蓄積する生体鉱物化された植物相である *Siderophycus ferreus*（「アイアン・ケルプ」）の広大な藻場が形成されている。このケルプは食物網の基盤となり、盲目で発光能力を持つ巨大なアミの群れを維持している。熱量の極端な不足は、捕食者に非常に攻撃的な狩猟パターンを強いる。深海帯の生物は、極端な適応を示している。極厚のシリカ・チタン甲殻、高濃度の神経毒、あるいは緩慢な代謝率によって生じる巨大化などである。

## 2. トレンチ・ストーカー

運用ログは、船外回収作業における主要な危険として *Bathysqualus caecus*（「トレンチ・ストーカー」）を挙げている。これらは群れで狩りをする体長6〜8メートルの捕食者であり、視覚器官は完全に退化している。

目の代わりに、頭部の甲殻プレートにはマイクロボルト単位の変動を検出できる電磁受容器（頭部ロレンチーニ膨大部様受容器）が密集している。クラスIV大気圧潜水服が発する稼働時の電磁シグナルは、最大2.8キロメートル離れた場所からでも検知可能である。マグネシウム・テルミット熱ランスの着火を含む、システム内の電気的な出力スパイクは、すべて捕食者を直接発信源へと誘導するトリガーとなる。

## 3. キチン質の装甲

深海においては、流体抵抗と現地の生物甲殻の超高密度により、運動エネルギーを利用した銃火器は一切役に立たない。

400気圧の極限環境において、有機構造は強化された骨格を必要とする。ストーカーの外殻は、生体鉱物化されたシリカ・チタンマトリクスで構成されている。標準的な高引張強度のハープーンは、構造的貫通を伴わずに甲殻プレートに弾かれる。戦術マニュアルは、高圧下で鍛造されたキチン質を溶解させるために、4000℃で稼働するマグネシウム・テルミット熱ランスの使用を義務付けている。

## 4. レヴィアサン

Deep Reach社は、第44セクターからの退避前に、大質量生物の音響特性に関するデータをすべて機密に指定した。

受動ソナーアレイは、当初は地殻変動として分類されていた180デシベルを超える低周波音響シグナルを定期的に記録している。これらの生物は、大陸棚の下にある超深海海溝に生息している。音響モデリングによると、5〜15 Hz帯の至近距離での発声は、ダイバーの内部組織に致命的なキャビテーションを引き起こす可能性がある。生き残ったエンジニアチームは、第44セクターの主要構造支柱の壊滅的な崩壊が、断層の剪断ではなく、付近を通過した大質量生物の流体力学的航跡によって引き起こされた可能性を示唆している。
