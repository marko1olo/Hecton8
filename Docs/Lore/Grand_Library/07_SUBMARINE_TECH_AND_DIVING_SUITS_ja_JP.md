# 潜水艦技術とマローダーの潜水服

> **出典:** Keelmark損失処理デスク、独立サルベージ作業に関するアクチュアリー（保険数理士）的リスク評価。
> **話し手:** 保険引受人 H・トス。
> **査読者注記:** Deep Reachは、独立請負業者への高級耐圧装甲の支給を拒否している。マローダーは改造された産業用装備に頼らざるを得ない。

---

## 1. Styx級降下ポッド

我々はマローダーにAtlas級の輸送シャトルを提供しない。彼らは余剰品のStyx級軌道降下ポッドを介して投入される。これらのユニットは元々、自動採掘ドリルをHECTON-8の大気圏に投下するために設計されたものだ。

大気圏ブレーキ用のスラスターは搭載されていない。高度にアブレーション（融除）される熱シールドと、終端速度での水面への衝突を利用して、惑星の表面張力を打ち破る。Styx投下の生存率は88.4%である。Keelmarkは、これを請負業者に対する許容可能なリスク・マージンと見なしている。ポッドが海に衝突すると、石のように運用深度まで沈み、一時的な拠点として機能する。

## 2. ネオジム音響テザー

電波は深海には届かない。マローダーは、水面に到達した瞬間、軌道補給船*Black Keel*から完全に切り離される。彼らの唯一の命綱はネオジム音響テザーである。これは、Styxポッドから繰り出される物理的に編み込まれた光ファイバーケーブルだ。

このテザーには3つの目的がある：
1. 低周波ソナー・バーストをポッドに送り返す。
2. 高圧縮された酸素・ヘリウムの混合呼吸ガスを送る。
3. 機能停止した潜水服をエアロックまで引き戻すための、物理的なウィンチとして機能する。

もしテザーが破片、現地の動物相、あるいは急な海流によって切断された場合、マローダーに残された緊急脱出用の空気は正確に4.5分間である。テザー切断事故の99%において、Keelmarkは「資産の完全な喪失」としてファイルを閉じる。

## 3. 深海兵器と水抵抗

標準的な実体弾を発射する火器は、400気圧の下では役に立たない。水の摩擦により、銃弾は2メートル以内で停止する。

請負業者は、空気圧駆動式のスピアガンとサーマル・ランス（熱槍）を装備している。サーマル・ランスは、防衛用に転用された産業用切断工具である。マグネシウム・テルミット反応を点火し、水中で4000℃の熱を発する。現地の捕食者の装甲に対しては非常に効果的だが、密閉空間で不用意に振り回せば、水は瞬時に蒸発し、潜水士を自らの潜水服の中で茹で上げる致命的な水蒸気爆発を引き起こす。

## 4. 「ラザロ」スーツ

マローダーは、再利用されたクラスIVの重工業用潜水服を着用している。これらは戦闘用に作られたものではなく、押し潰すような暗闇に耐えるために作られたものだ。スーツは、合成ネオプレンの気袋（ブラダー）で覆われた、炭化チタン製の関節式外骨格で構成されている。

請負業者の主な死因は捕食者ではない。スーツのパンク（貫通）である。運用深度において、防圧シールの破損部から侵入する水は、穏やかな浸水などではない。それは極超音速のウォータージェットと化し、レーザーカッターのごとく骨や組織をたやすく両断する。Keelmarkのアクチュアリーは、高圧注入による死はほぼ瞬間的であると記録している。
