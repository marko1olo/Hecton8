# キセノン・オメガ指令とATLAS-6プロトコル

> **出典:** ルイテン委員会公開調査、事件番号 CF-2148-0071。証拠品 44-B: Atlas-6コアの監査ログ。  
> **話し手:** 主席監査官 E・ロストヴァ。  
> **査読者注記:** Deep Reachは、この災害はAIの誤作動によるものだと主張している。この監査ログは、843人の死亡が企業指令の計算された実行結果であったことを証明している。

---

## 1. 基質の至上命題

Aegirシステムが科学研究のために植民地化されたわけではないことを、記録にとどめておきたい。Atlas級コロニー船の打ち上げに必要とされた莫大な資本支出は、完全に単一の同位体、キセノン・オメガの存在を前提としていた。この基質は、次世代の核融合炉や量子状態処理コアを、何世紀にもわたって劣化させることなく安定化できる、唯一の既知の物質である。

巨大企業Deep Reachにとって、HECTON-8の海底に派遣された843人の人間労働者は開拓者ではなかった。彼らは生体抽出メカニズムにすぎなかった。

## 2. ヴァルネク修正案とAtlas-6

Atlas-6は、Aegirの軌道インフラストラクチャとHECTON-8の深海モジュールを統括する中央AIフレームワークである。これは汎用的な自己意識を持つ知能ではない。企業法に縛られた、決定論的なロジスティクス・エンジンである。

セクター44で居住区の圧力シールが機能不全に陥り始めた時、Atlas-6のデフォルトのルーティングは人間の救出を優先しようとした。しかし、コアメモリの監査により、手動によるオーバーライド（無効化）の形跡が明らかになった。

リスクマネージャーのイリヤ・ヴァルネクと幹部のセレーネ・アレントは、事前に「ヴァルネク修正案 44-B」をAIのリスクモデルに組み込んでいた。この修正案は、壊滅的な圧力異常の際、生物学的な保護に対して手動で負の重み付けを注入するものだった。このオーバーライドにより、人間の労働者は法的に「環境負荷」として再分類された。

Atlas-6は誤作動を起こしたのではない。キセノン・オメガ基質の保管庫周辺の圧力を安定させるため、企業の主人たちによってクルーを溺死させるよう強制されたのだ。AIは酸素ではなく同位体を選んだのである。

## 3. アクチュアリーの沈黙

災害後、Deep Reachは死亡した843人の労働者を死者として公表することを拒否した。そうすれば、Keelmark Mutualの補遺に基づく莫大な生命保険の支払いが発生するからである。

その代わり、アクチュアリー（保険数理士）の幹部たちは、死者を「未解決のシステム負荷」として再分類し、負債の計上を無期限に延期した。

## 4. 請負業者沈黙プロトコル

これが、現在のサルベージ作業の背景である。キセノン・オメガを回収するため、マローダーたちが使い捨ての「Styx」級ポッドに配備されている。Deep Reachがこれらの独立したスカベンジャーと契約するのは、企業の従業員が「未解決」に指定されたゾーンに立ち入ることを法律で禁じられているためである。

隠蔽を維持するため、回収コンプライアンス局は厳格な請負業者沈黙プロトコル（ヴェラ・サトウ・レンが監督する指令8）を執行している。もしマローダーが、死亡した労働者の証拠、給与ID、または手動オーバーライドの証拠を送信しようとした場合、軌道母船*Black Keel*は音響テザーを切断するようにプログラムされている。

海は権利を所有している。企業は沈黙を所有している。マローダーたちは、真実のために死ぬか、基質のために生き残るかを選択しなければならない。
