# ステュクス降下ポッド

> **出典:** Deep Reach メガコーポレーション、軌道ロジスティクス部門。  
> **話し手:** 自動ロジスティクスAI。  
> **査読者注記:** Black Keelと海底の間の恐ろしい通勤経路の詳細な調査。

---

## 1. 片道エレベーター

*Black Keel*は、HECTON-8の嵐が吹き荒れる大気圏の遥か上空を周回している。安全な軌道上から、押し潰されるような深海へとマローダーを展開する唯一の手段が、ステュクス級大気圏降下ポッドである。

マローダーたちから「棺桶の乗り心地」と親しみを込めて呼ばれるステュクス・ポッドは、クラスIV潜水服を着たマローダーが一人入るだけの広さしかない、窮屈で、断熱材もなく、動力を持たないチタン製の円柱である。窓も、パイロットも、手動コントロールもない。これは快適さではなく、最大限の費用対効果を目的として設計された、完全自動化された弾道輸送システムである。

## 2. 降下プロファイル

展開は、*Black Keel*の軌道ベイから磁力で加速された激しい発射から始まる。

ポッドはHECTON-8の猛烈な上層大気を突き抜けて落下する。搭乗者が焼却されるのを防ぐため、加工された鉄の昆布（Iron Kelp）で編まれたアブレーション熱シールドに依存している。骨が砕けるような衝撃を伴う大気圏突入の後、ポッドは終端速度で荒れ狂う海面に激突する。その衝撃は、分厚いパッドの入ったクラスIVスーツの内部でさえ脳震盪を引き起こすほど激しいものである。そこから先は、ポッドはただ沈んでいくだけだ。続く3時間の苦痛に満ちた時間、マローダーは完全な暗闇の中に座り、圧力が高まるにつれてきしむチタン製の船体の音を聞きながら、8,500メートルの深淵へと沈んでいく。

## 3. 構造的完全性と故障

ステュクス・ポッドは安価で再利用可能であるように設計されている。多くの場合、十分に安価ではなく、そして過剰に再利用されている。

コアとなる船体は高密度のチタン合金で作られているが、度重なる大気圏再突入と400気圧の圧力への暴露により、微細な応力亀裂が生じる。Deep Reachのメンテナンス・ドローンが速乾性の樹脂でこれらの亀裂を修復するが、故障は許容された統計的確率となっている。大気圏突入時にポッドの強度が失われた場合、マローダーは一瞬で沸騰する。深海への降下中に強度が失われた場合、船体は一瞬で内側に圧壊し、搭乗者は何が起こったのか理解する前に血まみれのペースト状に粉砕される。

## 4. 回収シーケンス

降りるのも恐ろしいが、戻るのはロジスティクスの悪夢である。

マローダーのシフトが終わると、彼らは指定された回収ゾーンを見つけなければならない。ステュクス・ポッドは高張力の単分子テザーを展開して上方に発射し、残存して機能している廃墟のセントラル・ピラー（中央の柱）の貨物エレベーター、または水面近くを漂う自動ドローン・バージに引っ掛けようとする。ラッチが掛かると、巨大なウインチが何マイルもの水中をゆっくりとポッドを巻き上げる。それは遅く、苦痛を伴う上昇であり、ポッドは捕食性の動物に対して完全に無防備な状態のままとなる。もしリヴァイアサンがテザーに噛み付くことを決めた場合、あるいはトレンチ・ストーカー（海溝のストーカー）がウインチのメカニズムを汚損した場合、ポッドは海底へと落ちていく。中にいるマローダーは、完全な損失として企業の帳簿から消去されるだけである。
