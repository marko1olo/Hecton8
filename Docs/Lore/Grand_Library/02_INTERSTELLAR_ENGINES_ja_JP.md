# エンジン設計と恒星間ロジスティクス
**大図書館セクション:** 02
**言語:** ja_JP
**カノン:** 厳格 (Lore Bible 2190)

---

## 1. 魔法はない、物理学だけだ
HECTON-8の宇宙には、**超光速（FTL）ドライブは存在しない**。ジャンプゲート、超空間、アンシブル（瞬間通信）、あるいは運動量保存の法則に違反する反作用のないドライブは存在しない。

人類の拡大は遅く、困難で、莫大な費用がかかる。これがまさに「深宇宙」がメガコーポレーションに属している理由である。投資の見返りを得るために何十年も待つことができるのは彼らだけなのだ。

## 2. 船とエンジンの種類
恒星間ロジスティクスは、3つの主要なトランジットタイプに依存している：

### A. ビーム支援探査機と自律型パケット
エーギル星系（HECTON-8）に最初に到着したのは自動探査機だった。それらは、太陽系またはルイテン・ジャンクションのような中間ノードに設置された巨大な軌道ペレットビームレーザーを使用して加速された。探査機は小型で、速く、無人で、誰かが安全を確認する前にルート上に「投げる」ことができるほど安価である。Xenon-Omega同位体に関する最初のデータを持ち帰ったのはこれらの探査機だった。

### B. 核融合パルス / 核融合電気貨物船
工場、インフラ、そして休眠状態（トーパー）で眠る乗組員を運ぶ「アトラス」クラスの重植民船は、核融合電気またはパルスエンジンを使用する。エーギル星系への飛行には何年もかかる。
そのような船は文字通り「エンジン付きの住宅ローン」である。企業は、一人か二人の略奪者を救出するためだけに重輸送船を運航することはない。ルートが利益を生む場合にのみ、船は派遣される。

### C. マグセイルと空力ブレーキ
光速に近い速度での飛行における主な問題は、加速することではなく、停止することである。Deep Reachの重宇宙船は、エーギル星系に近づくにつれて、何百キロメートルにも広がる巨大な磁気帆（マグセイル）を展開し、星間物質に対してブレーキをかける。最終段階では、巨大ガス惑星の大気、またはHECTON-8自体の濃密な嵐のエンベロープを利用した空力ブレーキ（エアロブレーキ）を使用する。

## 3. トランジットと救助のドクトリン
FTL旅行が存在しないため、人類の世界の中心部からの救助は**不可能**である。HECTON-8で災害が発生した場合、地球またはタウ・ケティからの応答は10〜15年後に到着する。

これがまさに、Deep ReachがAtlas-6 AIを「工場総督」として配備した理由である。それはコロニーの自治を維持することになっていた。
略奪者が海面に降下するとき、彼らは軌道補給船（Black Keel）から「ステュクス」クラスのポッドで投下される。このポッドは片道降下用に設計されている。そのフレームは圧力で変形し、アビオニクスは浸水する。軌道に戻るためには、略奪者は死んだコロニーから熱化学上昇爆薬を見つけるか、修理するか、あるいは盗まなければならない。

あなたは乗客ではない。あなたは船を所有していない。あなたは、虚空を横切って張られた非常に長くて非常に遅いロープの端にある消耗品にすぎない。
