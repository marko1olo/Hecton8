# エーギル衛星系と軌道ハザード

> **データソース：** エーギル航行局、天体航海日誌
> **記録主：** 自動天体レジストリ
> **監査官メモ：** エーギル系の軌道力学と環境ハザードの分析。我々の孤立を決定づけるパラメータ群。

---

## 1. 衛星の梯子と重力共鳴

ガス巨大惑星エーギルはHECTON-8 ofの空に君臨し、9つの主要な月と数十の微小な小衛星からなる複雑なシステムを繋ぎ止めている。HECTON-8はこの軌道シーケンスの8番目の位置を占め、激しい地熱活動と過酷な潮汐サージを引き起こす安定した共鳴状態に固定されている。

これらの月（スカルン、ヴェラ、クロウ、ルーメン、ソーン、アンビル、ケストレル、ヘクトン、ミュート）がこの惑星環境を構成している。それぞれの天体は、その下のオペレーションに個別の物理的影響を及ぼしている。最も内側の月であるスカルンは激しい磁気圏加熱を経験し、内軌道を一掃する強い放射線を生成する。ヴェラは氷의結晶と微細なケイ酸塩の塵を継続的に放出し、通信リレーの光学センサーを汚す軌道デブリ雲を作り出す。ソーンとアンビルは低温で高密度であり、放棄された企業採掘調査の遺物として残っており、その重力井戸は航行チェックポイントとして機能している。

## 2. 蝕とルートシャドウ・ウィンドウ

軌道アライメント中、内側の月がエーギルとHECTON-8の真間を通過し、一時的な信号と光の遮断を引き起こす。これらはルートシャドウ・ウィンドウとして知られ、地表施設と高軌道上の*Black Keel*との間のあらゆる高周波通信を遮断する。

これらの特定の軌道イベント以外では、空は明るく視認可能である。ルートシャドウは予測可能な軌道遷移であり、永続的な環境の暗闇ではない。マローダーは、これらのウィンドウを考慮して降下とサルベージの計画をプログラムしなければならない。シャドウ・ウィンドウ中にサルベージ現場に到着すると、完全にテレメトリが途絶し、回収システムが機能しなくなり、ダイビングチームが取り残されることになる。

## 3. 電磁サージと粒子散乱

内側の月からの放射線の掃引は、激しい電磁干渉を引き起こす。スカルンの通過は、シールドされていない地表アンテナに過負荷をかける荷電粒子サージを引き起こす。

ヴェラのケイ酸塩の塵は搬送波信号を散乱させ、高周波チャネルを汚染する。これらの信号減衰の期間はシャッター・イベントと呼ばれる。これらは、HECTON-8の地表ステーションと軌道リレーの間の自動ハンドシェイクを中断させ、深刻なデータパケット損失を引き起こす。シャッター・イベント中は、緊急トランスポンダが機能しなくなり、誘導システムは深刻な遅延に見舞われる。

## 4. リレー中断とハンドシェイク制約

ディープ・リーチのオペレーションは、HECTON-8とロイテン・ジャンクションの間を移動する自動パケット・リレーに依存している。瞬時の通信は存在しないため、データパケットは自動貨物ランナーによって物理的に運ばれなければならない。

*Black Keel*はシステム内の主要なデポとして機能し、転移軌道に入る前にテレメトリと貨物を収集する。マローダーが*Black Keel*が転移ウィンドウから脱出する前にペイロードハッシュを認証できない場合、貨物は法的に「放棄されたもの」として分類される。ソル・コアの金融データベースとエーギルのオペレーションとの間の遅延により、マローダーの負債台帳は取引の数週間後に更新されるため、乗組員は古い金融データと絶え間ない契約圧力の下で活動することを強いられる。
