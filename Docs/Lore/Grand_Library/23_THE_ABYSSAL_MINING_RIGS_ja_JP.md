# 深淵採掘リグ

> **出典:** Deep Reach メガコーポレーション、重機械およびサルベージ部門。  
> **話し手:** 自動資産トラッカー。  
> **査読者注記:** 海底に散らばる死んだ巨大な獣たち。我々はもう彼らを建造することはない。ただ死骸を剥ぎ取るだけだ。

---

## 1. モバイル抽出クローラー

セクター44の壊滅的な崩壊以前、Deep Reachはキセノン・オメーガを収穫するために、原子力駆動の巨大な「モバイル抽出クローラー」を利用していた。

都市の区画ほどの大きさがあるこの巨大なリグは、強化されたスパイク付きの無限軌道で海底を這い進んだ。それらは深淵の押し潰されるような圧力に耐え、最大級のものを除くすべてのリヴァイアサンからの攻撃をしのぐように設計されていた。200人以上の乗組員を収容するこのクローラーは移動式の精製所として機能し、海底を浚渫して生のキセノン・オメーガをその場で処理した後、自動貨物魚雷を介して水面へと発射した。

## 2. 這い回る墓場

クローラーの黄金時代は、地元の動物群が適応し始めたときに終わった。

今日、海底には放棄されたこれらのリグの腐りゆく残骸が数十も散らばっている。何十年もメンテナンスされずに放置された巨大な原子炉はゆっくりと破れ、強烈な局所的放射線を水中に漏出させている。この放射線は周囲の生態系を攻撃的に突然変異させ、金属の鉄の昆布（Iron Kelp）の森の成長を加速させ、クローラーの放射線を浴びた外殻を巣として利用する超攻撃的なトレンチ・ストーカー（海溝のストーカー）の変種を生み出した。これらの死んだリグが最も集中しているエリアは、マローダーたちの間で単に「這い回る墓場（Crawling Graveyard）」として知られている。

## 3. ハイリスク・サルベージ

Deep Reachが価値ある資産を完全に見捨てることは決してない。

生のキセノン・オメーガがほとんどの降下の主な目的である一方で、経験豊富なマローダーには時折、ハイリスクな「資産回収」の契約が与えられる。彼らの目的は、放棄されたクローラーの放射線を浴び、怪物がはびこる廃墟をナビゲートし、ブラストドアを切断して、崩壊しつつある原子炉のコアから非常に価値の高い兵器級核分裂性物質を手作業で抽出することである。これらのミッションの死亡率は驚異的な85%に達するが、マローダーの「債務元帳」に適用される企業からの報酬は、コア・ワールド（中心世界）にいる家族のためにさらに10年分の食料配給を買うのに十分な額であることが多い。

## 4. 「空っぽのリグ」

すべてのクローラーがリヴァイアサンや構造的欠陥によって破壊されたわけではない。

企業のサルベージ・ログには、クローラーが単に送信を停止した事例が少なくとも3件記録されている。サルベージ・チームが最終的にリグを発見したとき、外部のチタン製船体は完全に無傷であり、外部からの突破や戦闘の兆候はまったく見られなかった。内部のブラストドアは内側から密閉されていた。しかし、200人の乗組員全員が単に消え失せていたのだ。死体も、血も、争った形跡もなかった——ただ、頑丈に強化されたエアロック・ドアの**内側**に、深くて説明のつかない爪痕が削り取られており、乗組員を連れ去った「何か」が、すでに彼らと一緒にリグの内部にいたことを示唆していた。
