# 企业合规与掠夺者亚文化

> **来源：** 回收合规办公室，分包商入职指南（表格 88-C）。  
> **讲话人：** 自动接收系统 / 主管 K. 伦。  
> **审阅者说明：** 从“冥河”级吊舱“拉撒路”内部回收了未经授权的涂鸦（以 *[页边笔记：... ]* 表示）。这些笔记概述了非法的“掠夺者”亚文化。

## 1. Deep Reach 企业结构

欢迎来到埃吉尔星系。您现在是在 Deep Reach 地外开发联合体管辖下运营的持牌独立承包商。为确保无缝整合，请牢记以下部门职权：

*   **Aegir 连续性控股公司：** 拥有 HECTON-8 所有行星租赁权的前沿部门。他们是您的最终雇主。
*   **Atlas 连续性办公室：** 管理 Atlas-6 AI 核心的法律和软件部门。未经授权，请勿尝试与 Atlas-6 进行交互。
*   **Keelmark 损失理赔处：** 承保部门。在发生灾难性设备故障时，Keelmark 会评估您损失的财务风险。
*   **回收合规办公室：** 我们是您在轨道补给船 *Black Keel* 上的直接处理人员。我们发布您的潜水坐标，要求您提供存在氙-欧米伽的证明，并执行《承包商沉默协议》。

*[页边笔记：他们不是什么邪恶的幕后黑手。他们只是电子表格。当你死的时候没人承担责任，因为他们的文书工作在技术上完美无瑕。]*

## 2. “掠夺者”的区别

您的官方分类是“独立打捞承包商”。任何自称为“掠夺者”的行为均违反企业行为准则。该术语最初是一种贬义的法律分类，指的是在 Keelmark 检查员到达之前强行进入废弃舱室的船员。

*[页边笔记：我们保留这个名字是因为它能吓到那些穿西装的。企业合同里的救援条款不过是他们占有你尸体的另一种方式。我们是破产的飞行员、流氓焊工和合同违约者。]*

## 3. 三大账本

作为独立承包商，您的报酬严格根据回收的氙-欧米伽基质质量计算。您的初始留置权相当于 4.8 吨（轨道提升质量）。在获准获得 *Black Keel* 上的永久住所之前，您必须偿还这笔债务。

*[页边笔记：公司的账本是假的。真正的掠夺者经济靠的是：空气、债务和死人。*
*空气：以分钟、分压、二氧化碳净化器的热量，以及阀门破裂后那令人作呕的寂静来计算。*
*债务：以工具的磨损、电池循环次数、人情，以及从 Keelmark 名单上划掉的名字来计算。*
*死人：失踪的工人对他们来说不是悲剧；那是“未解决的系统负载”。我们清点死者，这样公司就不能假装他们从未存在过。]*

## 4. 操作术语

记录事件时，请遵守标准的公企业术语。应使用“临时大气压变化”来描述压力波动。“资产遏制优先级”指的是在紧急情况下必须密封氙气金库。

*[页边笔记：在被水淹没的建筑群里，唯一的等级就是能力。只有在侦察员标记了返回路线后，切割工才会切开舱门。当仪表撒谎时，技术人员的决定可以凌驾于飞行员之上。一个菜鸟掠夺者通过报告小故障来赢得信任：舱口周围结霜、死寂的频道里回荡的声音、逆流挤在一起的鱼群。公司的人说“资产遏制”。我们说“他们保住了氙气罐，却把生活区排气了”。我们偷公司的东西来向死人讨债。这是唯一让我们不至于变成他们那种人的东西。]*
