# 通信のブラックアウトと軌道上の沈黙

> **出典:** *Black Keel* 軌道補給船運用マニュアル、第4節。
> **話し手:** 通信士官 J・ヴァンス。
> **査読者注記:** マローダーが水面からほぼ完全に孤立した状態で活動する理由についての、冷酷な説明。

---

## 1. ブラックアウトの物理学

HECTON-8の海は純粋なH2Oで構成されているわけではない。溶解した重金属、イオン塩、そして微粒子状のキセノン・オメガの塵が大量に含まれている。この特殊な化学のスープは、絶対的なファラデーケージとして機能する。

電磁波（すべての標準的な無線、マイクロ波、レーザー通信を含む）は、水深200メートルを超えて透過することはできない。放棄されたコロニー、セクター44は水深8,500メートルに位置している。軌道補給船*Black Keel*の視点から見れば、海底は完全にブラックボックスなのである。

## 2. 音響テレメトリー

電波が使い物にならないため、水面と通信する唯一の手段は音響テレメトリーである。Styx降下ポッドには、デジタルデータを低周波の音響パルスに変換する巨大なソナー・アレイが装備されている。

その伝送速度は絶望的に遅く、およそ300ビット/秒である。マローダーは動画をストリーミングしたり、複雑なテレメトリーを送信したりすることはできない。基本的なテキスト文字列、スーツの圧力警告、そして暗号化された給与署名を送信することしかできない。海底から遭難のピングを送信し、軌道から応答を受け取るまでの遅延は、およそ8分間である。浸水した区画において、8分間とは永遠に等しい。

## 3. 「サイレント・オービット（静かな軌道）」プロトコル

Deep Reachの幹部たちは、音響送信がライバル企業の偵察衛星に傍受される可能性があることを認識していた。キセノン・オメガ抽出方法の知的財産を保護するため、*Black Keel*は厳格な「サイレント・オービット」プロトコルの下で運用されている。

軌道補給船から通信を開始することは決してない。マローダーが完了したサルベージ目録をアップロードした際に、自動化された受領確認を「打ち返す」だけである。向こう側には、励ましや戦術的な助言、救助の調整を行ってくれる人間のオペレーターは存在しない。マローダーが自身の通信チャンネルに話しかける時、彼らは自動化された虚無に向かって話しかけているのだ。

## 4. 切断

音響テザーは書類上、命綱だ。実際には、企業の「首輪」である。

もしマローダーが請負業者沈黙プロトコルに違反する何かを発見した場合（例えば、843人の死亡した労働者の証拠や、Atlas-6が意図的にコロニーを溺死させた証拠など）、*Black Keel*の自動システムは、音響ストリーム内のフラグが立てられたキーワードを検出する。

それが発生した場合、軌道補給船は議論をしない。脅迫もしない。ただ単にStyxポッドへ爆発ボルトのコマンドを発行する。音響テザーは切断される。酸素供給は断たれる。マローダーは帳簿から永久に抹消され、深海の沈黙に飲み込まれるのだ。
