# 地質学、圧力、そして2147年の大潮
**大図書館セクション:** 03
**言語:** ja_JP
**カノン:** 厳格 (Lore Bible 2190)

---

## 1. HECTON-8 地質図鑑
HECTON-8の海は平坦な海底ではない。それは断裂し、共鳴によって加熱された、残忍な地形を持つ世界であり、明確な水深帯に分けられている：

*   **0-250 m（透光帯棚）：** 浅い棚、光の領域（尾根）。嵐を突き抜ける地表からの微かな光がまだここにはある。
*   **250-1200 m（産業棚 / ケーブルリーフ）：** 産業棚。最初のプラットフォームの残骸がここに眠り、藻類に覆われたケーブルリーフを形成している。
*   **1200-2800 m（塩水キャニオン）：** 塩水キャニオン。塩分のために水の密度が非常に高く、重力と浮力が予測不能な振る舞いをする。これはソナーを欺き、略奪者から「底」の感覚を奪う。
*   **2800-4300 m（深淵マシンフィールド）：** 深淵のマシンフィールド。主要工場が圧力に押し潰されてここに横たわっており、Atlas-6の修復生物生態系に完全に支配された領域を示している。
*   **4300-5600 m（アトラス盆地）：** アトラス盆地。熱帯フィールドと生産フロアの領域であり、生物と機械が一つに融合した場所。

## 2. 熱水鍛造炉 (Vent Forges)
固い海底はここでは稀少である。通常は露出した尾根や熱水噴出孔のクレーターで構成されている。企業は地熱断層線（Vent Forges）の真上に工場を建設した。これは無料のエネルギーと、「圧力ガラス」(Pressure Glass) やセラミックの焼鈍に必要な熱サイクルを提供した。しかし、同じ断層線が流体力学的な沸騰剪断を生み出し、腐食性の藻類ブルームを引き起こし、ダイバーの酸素センサーを狂わせる。

## 3. Xenon-Omega基質（青い借金）
Xenon-Omegaは単なる鉱石の塊ではない。魔法でもない。それはHECTON-8の極限条件下で形成される戦略的同位体である。希ガス、塩水、地熱の鉱物欠陥、そしてAtlas-6のインフラストラクチャそのものが共生関係に入り、途方もないエネルギー負荷に耐えうる素材を生み出す。
略奪者たちはそれを「青い借金」(Blue Debt) と呼ぶ。耐圧容器なしで未精製のキセノンを収穫すると中毒を引き起こす——肺組織の微視的な結晶化が、青いガラスの破片を咳き込ませるのだ。

## 4. 2147年の大潮 (The Great Tide)
Deep Reachは、コロニーが「予期せぬAI蜂起」や「レヴィアタンの攻撃」によって破壊されたと主張しているが、それは嘘だ。2147年の災害は純粋に物理的なものだった。
衛星の全球的な気候変動、氷圏の崩壊、嵐の潮汐、そして地球物理学的な変動がインフラストラクチャを引き裂いた。

企業はこのリスクを知っていた。リスクマネージャーのイリヤ・ヴァルネク (Iliya Varnek) は予算内に収めるためにモジュールの構造限界を人為的に引き下げた。潮が来たとき、法律顧問のヌール・ホルデイン (Noor Haldane) が検疫と税関手続きの問題で避難を遅らせた。そしてAtlas-6 AIは単純に数字を天秤にかけた：キセノン抽出装置を保存することは、不採算になった843人を救うことよりも重要だと判断されたのだ。

HECTON-8は、数学と重力を使って犯された犯罪である。
