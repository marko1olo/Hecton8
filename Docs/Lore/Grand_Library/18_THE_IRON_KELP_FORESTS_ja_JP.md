# アイアン・ケルプ（鉄の昆布）の森

> **出典:** Deep Reach 異星生物学部門、危険ログ。
> **話し手:** 自動植物分析器。
> **査読者注記:** HECTON-8の一見無害に見えるが、信じられないほど致命的な深海の植物群の分析。

---

## 1. アイアン・ケルプとは何か？

アイアン・ケルプ（鉄の昆布）は、地球の伝統的な意味での植物ではない。それは、深海の海溝の押しつぶされるような圧力の中で繁殖する、金属質の化学合成独立栄養生物である。

光合成のために太陽光に依存することはない。その代わり、水中に浮遊する高放射性のキセノン・オメーガ微粒子を代謝し、それを高密度の金属製の生体繊維に変換するのだ。アイアン・ケルプの葉状体は1本で長さ30メートルにまで成長し、編み込まれた鋼鉄ケーブルのような引張強度を持つ。錆色をしており、信じられないほど重く、深海の海流の中で絶えずうねっている。

## 2. 絡みつきの危険性

マローダーにとって、アイアン・ケルプの森は死の罠である。

ケルプは信じられないほど早く成長する。特に、キセノン・オメーガの濃度が最も高い、活動中の熱水噴出孔の周辺では顕著である。それがもたらす主な危険は「絡みつき」だ。クラスIV潜水服のモーター駆動サーボは強力だが、金属製のケルプの葉状体が関節やハイドロジェット・スラスターに巻き付くと、簡単に動けなくなってしまう。一度マローダーが絡まると、もがけばもがくほどケルプはよりきつく巻き付く。多くのマローダーが、重い金属のツルに絶望的に縛り付けられたまま、酸素スクラバーがゆっくりと尽きていく中で、海底でゆっくりと窒息死していった。

## 3. 深海の狩り場

アイアン・ケルプの森は単なる航行上の危険物ではない。それは地域のエコシステムの基盤なのだ。

この密集した金属の茂みは、HECTON-8の頂点捕食者たちに完璧なカモフラージュを提供する。トレンチ・ストーカー（海溝のストーカー）はしばしばケルプの森を待ち伏せのポイントとして利用し、葉状体の間にキチン質の体を縫うように這わせ、不用意なマローダーを襲う。さらに、水流の中で金属の葉状体がこすれ合う絶え間ないきしみ音は、接近するリヴァイアサン（巨大海獣）のソナー・シグネチャをかき消してしまうため、早期発見をほぼ不可能にしている。

## 4. 企業による収穫

極めて危険であるにもかかわらず、Deep Reachは時折アイアン・ケルプの収穫に関する副次的な契約を発行する。

ケルプの金属生体繊維は、放射線や極度の熱に対する自然の耐性があるため、航空宇宙製造において高く評価されている。事実、ステュクス降下ポッドで使用されているアブレーション熱シールドは、加工されたアイアン・ケルプから織られたものである。もしマローダーがサーマル・ランスを使ってケルプの束を収穫する時間を割いたなら、その試みを生き延び、その過程でストーカーを引き寄せなかった場合に限り、自分の帳簿に多額のボーナスを獲得することができるだろう。
