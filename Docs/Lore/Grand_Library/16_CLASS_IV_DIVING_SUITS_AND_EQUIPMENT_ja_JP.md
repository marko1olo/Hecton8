# クラスIV潜水服と深海装備

> **出典:** Deep Reach メガコーポレーション、装備品補給将校マニュアル。
> **話し手:** 補給将校AIユニット。
> **査読者注記:** マローダーと、400気圧の圧力による即座の粉砕との間に立ちはだかる唯一の防具についての技術的分析。

---

## 1. クラスIV「鉄の棺桶」

HECTON-8の深海の海溝へ降下するすべてのマローダーに標準支給される装備が、クラスIV・機械式潜水服である。

マローダーたちの間では通称「鉄の棺桶」と呼ばれており、このスーツは本質的には着用可能な潜水艦である。放射線を浴びたタングステンとポリマー化チタン合金の重なり合ったプレートで構築されており、海底での400気圧という押しつぶされるような圧力に耐えられるように設計されている。スーツはかさばり、動作が遅く、強化石英製の単一のビューポートを使用しているため、周辺視野が著しく制限される。

## 2. 生命維持装置と化学ヒーター

HECTON-8の海は漆黒の闇に包まれており、水温は氷点よりわずかに高い程度である。スーツの生命維持システムは原始的だが効果的である。

酸素は、吐き出された二酸化炭素をリサイクルする自動化学スクラバー（浄化）システムによって供給される。しかし、これらのスクラバーは時間の経過とともに劣化するため、定期的に交換する必要があり、その費用はマローダーが自腹で支払わなければならない。氷点下の海中でダイバーが凍死するのを防ぐため、スーツの内側には化学的なサーマル・メッシュが張り巡らされている。スーツのメインバッテリーが低下すると、生命維持スクラバーのための電力を節約するために、このサーマル・メッシュが最初に自動的に無効化されるシステムとなっている。

## 3. 機動性と推進力

これほど巨大な圧力環境下で海底を歩くことは、遅く、過酷なプロセスである。

クラスIVスーツは、関節部にあるモーター駆動のサーボに依存して動きを補助しており、マローダーの歩き方は不自然によろめくような足取りになる。ブーツには、ダイバーを海底にしっかりと固定し、突然の深海流に流されるのを防ぐために、固体のタングステン製バラスト（重り）が仕込まれている。垂直方向の機動性を確保するため、スーツの背面にはツイン・ハイドロジェット・スラスターが搭載されている。これらのスラスターは持続的な飛行のために設計されたものではない。マローダーが峡谷を飛び越えたり、セクター44の崩壊した建造物をよじ登ったりできるように、短時間で強力な推力を提供するものである。

## 4. 深海での武装

伝統的な運動エネルギー式の銃器は、極端な水の密度と、重装甲の甲殻を持つ現地の動物相のため、HECTON-8では全く役に立たない。

マローダーの主な武器はサーマル・ランス（熱槍）である。これは実質的に水中火炎放射器として機能し、4000℃で燃焼するマグネシウム・テルミットの集中した流れを点火する。これは、トレンチ・ストーカーのキチン質の装甲を溶かしたり、詰まったチタン製の隔壁を切り裂いたりできる唯一の武器である。長距離での交戦には、マローダーは空気圧駆動式のキネティック・ハープーン（運動エネルギー銛）を使用する。この銛は、攻撃的な動物を海底に釘付けにするために設計された固体のタングステン製スパイクを発射し、マローダーが逃げるのに十分な時間を稼ぐことができる。
