# Terugkeervectorvenster

Terugkeervensters maken ontsnapping hard-sf: geometrie, weer, signaal en hardware.

## Scanner

Baangeometrie is geen reddingsknop. De Black Keel hoort je alleen in smalle Aegir-vensters.
