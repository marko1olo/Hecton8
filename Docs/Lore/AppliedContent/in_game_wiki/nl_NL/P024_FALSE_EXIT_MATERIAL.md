# Materiële exit

De materiële exit is een geldig gedeeltelijk einde. Het betaalt uit maar laat de grote waarheid open.

## Scanner

Carrier-aanbod geldig: payloadmassa betaalt schuld. Bewijsverlies open. Atlas-coördinatenverzoek wacht.

## Terminal

Exitcontract: verzegeld monster indienen, diep bewijs opgeven, claim-audit en schuldcontrole accepteren.

## Audio

Je kunt met waarde vertrekken. Niet schoon.

## Field Note

Een echt einde kan nog steeds een slecht antwoord zijn.
