# Mara Venn-getijdenmodel

Mara Venn geeft de Great Tide een wetenschappelijke getuige. Haar model verbond Aegir-maanstand, cryosphere shear en evacuatiecapaciteit tot één lelijke marge. Deep Reach wiste het model niet; het veranderde het actielabel tot de waarschuwing goedkoop genoeg was om te negeren.

## Scanner
