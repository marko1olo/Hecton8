# Kestrel-relaisschaduwkaart

Een geborgen relaisschaduwkaart maakt van Aegirs manen werkende routemachines. Kestrel blokkeert niet alleen licht; hij snijdt de bruikbare dragerbaan in ruisende tanden. Tijdens schaduw kan Black Keel fragmenten, verlopen tijdstempels of helemaal niets ontvangen.

## Scanner

RELAISSCHADUW // Kestrel kruist de Aegir-baan. Uplinkkwaliteit valt in tanden, niet in een vloeiende fade. Bewaar burstpakketten tot de geladen rand opent.

## Terminal

AEGIR RELAISVOORSPELLING // Kestrel-occultatie plus Aegirs magnetische ruis vormt een schaduwkam. Laagbandig akoestisch relais kan opstijgdata in de wachtrij zetten, maar verificatie wacht op een schone dragerrand.

## Audio

Black Keel-relais: je hemel is niet leeg; hij is geblokkeerd. Houd pakketten vast voor de heldere rand nadat Kestrel vrij komt.

## Field Note

Vervloek het relais niet wanneer de schaduw valt. Vervloek de maan. Een pakket dat in het midden sterft, kan aan de rand doorkomen.
