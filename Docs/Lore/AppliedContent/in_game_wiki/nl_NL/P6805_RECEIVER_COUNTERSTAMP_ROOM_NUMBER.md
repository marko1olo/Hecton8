# Kamernummer van de receiver counterstamp

Een receiver counterstamp is het moment waarop een blank berth een named door wordt. Het kan recovery moeilijker te negeren maken, maar noemt ook wie het lichaam na lift bezit. Controleer room class, medical owner en receiver strip voordat je de stamp vertrouwt.

## Scanner

COUNTERSTAMP-LEZING // Quarantine room number aanwezig. Controleer body custody class; sample-only rooms klaren geen living recovery.

## Terminal

RECEIVER ROOM COUNTERSEAL // Blank berth overschreven door owned custody. Lift allocation alleen met named room, owner en body class.

## Audio

Room number geschreven. Receiver bezit de deur. Bevestig body custody voor ascent burn.

## Field Note

Een room number is een handgreep. Trek voorzichtig; sommige deuren zijn kooien.
