# Bevolkings- En Autoriteitsschaal

Bevolkingscijfers blijven bij benadering omdat de speler geen census opera nodig heeft. De nuttige vraag is eenvoudiger: wie kan van veraf op je inwerken? Een druk kerndomein raakt HECTON-8 misschien alleen als certificeringsregel. Een klein depot kan belangrijker zijn omdat het pakket-custody controleert. Een dode frontier-shell kan het belangrijkst zijn omdat die de hardware in de kamer bezit.

Dit is de schaal die de speler voelt. Sol kan beslissen dat een object van iemand is. Centauri kan oude Deep Reach-taal respectabel laten klinken. Barnard normaliseert het werk dat Marauders vastzet. Tau Ceti kan bewijs in publieke druk veranderen, te laat voor zuurstof maar niet te laat voor gevolgen. Luyten kan de berichtketen bewijzen. Aegir is waar handtekeningen druk, water, vergrendelde luiken en factureerbare massa worden.
