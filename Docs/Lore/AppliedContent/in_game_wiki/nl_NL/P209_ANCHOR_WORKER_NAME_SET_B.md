# Ankerarbeidersnamenset B

Ankerarbeidersnamenset B draagt het rooster naar donkerdere bewijslagen. Nadiya Rook, Tomas Eline, Keiko Madsen, Harun Vale, Estel Nwosu, Dima Korr, Sofia Leung en Bram Kessel moeten verschijnen nadat de speler begrijpt dat storingen zich door ontwerp herhalen. Hun records horen bij pekelkloofwerk, abyssale machinevelden, triage-uitzonderingen, Atlas-reparatietegenspraken en salvageschuld. Set B moet voelen als het moment waarop een vertrouwd werkplaatsverhaal verandert in een aanklacht waar de namen nog aan vastzitten.

## Scanner

Diepere namen moeten aankomen nadat de speler het schadepatroon al kent. Ze kosten meer omdat het water de misdaad is gaan bewijzen.
