# Ankerarbeidersnamenset A

Ankerarbeidersnamenset A is de eerste menselijke laag die de speler moet gaan herkennen. Mara Venn, Juno Kade, Ren Okoye, Sahana Iqbal, Lian Torres, Oskar Neumann, Aya Morita en Pavel Sorn horen bij bewijs uit ondiepten en industriële shelf. Hun namen moeten niet als biografieën aankomen. Ze moeten verschijnen op een lockerlabel, pomptag, routevergunning, bevlekt maaltijdbonnetje, gebarsten gereedschapskoffer, en later terugkeren in een record dat de betekenis verandert. Set A laat de kolonie bewoond voelen voordat de diepere samenzwering duidelijk is.

## Scanner

Vroege namen moeten via werk terugkeren, niet via toespraken. De ondiepe route leert geheugen door herhaling.

## Terminal

ANCHOR SET A: herhaling in ondiepten en industriële shelf. Elke naam moet binden aan één gereedschap, één routevergunning, één beschadigd werkobject en één latere tegenspraak. Deze namen zijn het eerste bewijs van de speler dat de kolonie een werkplek was voordat ze salvage werd.

## Audio

Rouw niet om de naam tot het gereedschap vertelt waarom.
