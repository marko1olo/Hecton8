# Aegir Sky Window Machine

Aegirs zichtbare hemel is route machinery, geen decor. Maanschaduwen kunnen relay confidence breken, stormen kunnen body beschermen terwijl ze upload doden, en een heldere carrier line kan nog falen op radiation, tide, quarantaine of mass checks. Lees sky windows als gestapelde poorten: packet, body, proof en salvage delen niet noodzakelijk dezelfde pass.

## Scanner

SKY-WINDOW-LEZING // Visueel heldere hemel is geen rescue clearance. Kestrel-schaduw, stormplafond, radiation count, tide load en carrier phase spreken elkaar tegen.

## Terminal

AEGIR ROUTE PLATE // Vensterstatus is gedeeltelijk. Packet line kan open zijn terwijl ascent body, quarantaine en tonne-window mass gesloten blijven.

## Audio

Relaisnotitie: hemel helder, route vuil. Stuur alleen packet; houd ascent vast tot moon tag, storm ceiling en mass line akkoord zijn.

## Field Note

De hemel kan open zijn voor packet en gesloten voor je body. Controleer de hele machine voordat je viert.
