# Seed-role-naamgrammatica

Seed-role-naamgrammatica is de regel die voorkomt dat replayvariatie ruis wordt. Een seed-role-arbeider mag van run tot run in een andere locker verschijnen, naast ander beschadigd gereedschap of onder een andere routevergunning. De identiteit heeft nog steeds grammatica nodig: een stabiele persoonlijke naam, crewfamilie, vergunningcontext, laatste taak en een inspecteerbare objectvariant. Als een deel ontbreekt, voelt de naam niet meer als een persoon maar als gegenereerde vulling. Het systeem mag de bewijsvolgorde schudden; het mag verantwoordelijkheid niet wegschudden.

## Scanner

Een seed kan de bewijsvolgorde verplaatsen. Hij kan een arbeider niet in wegwerptekst veranderen.

## Terminal

SEED GRAMMAR: personal_name + crew_family + route_permission + last_task + object_variant. Lokalisatie mag crewtermen toelichten voor leesbaarheid, maar mag identiteit niet herschrijven, werk niet wissen en de naam niet losmaken van een concreet object.

## Audio

Willekeur is geen auteurschap. Bind de naam aan een taak.

## Field Note

Elke seed-role-identiteit combineert persoonlijke naam, crewfamilie, routevergunning, laatste taak en objectvariant.
