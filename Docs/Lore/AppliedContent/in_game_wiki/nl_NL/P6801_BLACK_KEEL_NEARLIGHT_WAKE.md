# Black Keel Nearlight Wake

Black Keel is een claim-tender in het Aegir-systeem, geen reddingsschip uit Sol. Een datapakket kan door een vuile relay pass passen terwijl een levend lichaam nog faalt op ascent seal, stormplafond, Kestrel-schaduw, quarantaine en tonne-window-controles. Behandel carrier contact als routebewijs: noteer het venster, houd bewijs getagd en gebruik geen ascent hardware voordat de massalijn de payload accepteert.

## Scanner

CARRIER-WAKE-LEZING // Pakketroute open. Lichaamsberging gesloten door ascent seal, Kestrel-schaduw, stormplafond, quarantaine en tonne-window-massa.

## Terminal

BLACK KEEL TRANSFERLEDGER // Pakketontvangst wijst geen lift toe. Berging vereist gerate ascent sleeve, seal-integriteit, lage Aegir-ruis, vrijgave uit Kestrel-schaduw, quarantine handshake en geaccepteerde tonne-window-massa.

## Field Note

Als het schip je kan horen, goed. Als het je kan liften, zegt de ledger dat met koudere woorden.
