# Log van drukpak-reparatiepatches

Reparatiepatches op drukpakken zijn menselijk handschrift op levensonderhoud. Fabriekspanelen spreken in schone bochten. Veldpatches spreken in krom draad, verkeerde stofkleur, zout onder tape en de eerlijkheid van iemand die een lek sluit voor de volgende drukcyclus.

Patchvolgorde telt. Naadband onder kruissteek betekent dat de eerste reparatie niet vertrouwd werd. Zout onder draad betekent dat het pak al blootgesteld was. Slijtage op de patch betekent dat de drager terug werkte. Schone tape op oude schade betekent late inspectie. Twee stofkleuren betekenen donor-pak.

Voor een marauder is een patch geen kostuumdetail. Het kan noodroute, laatste taak, triage, gestolen kit of een pakklasse tonen die niet bij de drager hoorde.

## Scanner

PAKPATCH // Donkere neopreenachtige huid, gestikt reparatie-eiland, versterkte naadband, zoutschuur, lichte technische textielstrook. Ongelijke klasse: veldreparatie, geen fabriek.

## Terminal

PATCH LEZEN // Kruissteek over naadband: noodsluiting. Zout onder draad: patch na blootstelling. Schone tape over versleten stof: late inspectie. Twee kleuren: materiaal uit ander pak.

## Field Note

Lees de patch nooit alleen. Lees knie, manchet en gereedschapstas mee.
