# 鉄モロコ

読むのは群れの形で、魚ではない。開けた水域に散っているうちは何の意味もない。厚さ二、三メートルの平らな帯に圧縮されているときは、酸素ポケットの縁を押さえている。

平らな帯はあと一交代か二交代もつ。ほどけ始めれば、食う側はどれも移動する。

既知の鉱脈の上に帯が無いのは逆の読みだ。ポケットは反転し、水は緑に変わり、そこでは数週間なにも食っていない。

鱗の鉄質の粒は走査での反射が強すぎて、背後にあるものを消してしまう。群れ越しに壁を読むなら、先に利得を落とせ。

その粒を分析すれば、出るのは鉱脈の鉱石ではなく船体板だ。

評価：帯の上縁を泳ぐ。帯の中は決して通らない。空気は自分の分を持っていく。

## Scanner

密集する群れ採餌種、体表に鉄質微粒子。信頼度91パーセント。危険：なし。限界：遠距離では群れの反射が構造を隠す。壁を読む前に利得を下げること。

## Terminal

試料ロット 44-XO-0091。区分：微量分析、付随。方法：群れ密度、シェルフ格子 0〜100 M。品位：微量、限界で採算可。トン数根拠：請求明細へ繰越。

## Field Note

あんたの担保が測られているトン数は、2146年にこの魚をシェルフ格子で数えて見積もったもので、分析はその後一度も取り直されていない。帯からは、良い水がどこで終わるかを読め。空気は請求書付きのボトルから出るままだ。鉱石については、この数は何の役にも立たない。
