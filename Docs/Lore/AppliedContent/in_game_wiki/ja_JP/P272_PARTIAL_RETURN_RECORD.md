# 部分帰還記録

部分帰還記録は、脱出ではなく一時の安堵を記録する。Black Keelはスーツ修理、空気、除染、台帳同期のためにオペレーターを引き上げられるが、同一seedへの帰還命令は先取特権、隔離期間、スキャン記憶、未解決証拠パケット、未処理ペイロードを同じ海に結び付けたままにする。

## Scanner

部分帰還記録 // Black Keelの一時回収を受理。同一seedへの帰還は延長先取特権下で承認。スキャン記憶と未解決証拠パケットは残存。

## Terminal

エンディング記録 / 部分帰還
回収: Black Keelによる一時抽出。
目的: スーツ修理、空気補充、除染、台帳同期。
保管状態: 先取特権延長、隔離期間添付。
帰還権限: 同じseed、同じ海、経路警告を保持。
残存データ: スキャン記憶、未解決証拠パケット、未処理ペイロード。
既知の損失: 安堵は自由になる前に請求される。

## Audio

圧力は離れた。契約は席を取っておいた。

## Field Note

清潔なスーツと睡眠一回では契約は閉じない。下の経路は古い警告を保持している。
