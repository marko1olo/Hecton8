# フォティックマット標本カード

フォティックマットは浅い棚を生きているように見せるが、安全にはしない。光、鉱物の皮膚、弱いガス滲出、圧力化学が交わる場所に育つ層状バイオフィルムシートだ。健康なマットはポケットに酸素を加え、glass grazersを養い、石灰岩に緑金の縁を付け、本来なら水中へ舞う薄い沈殿物を安定させる。その有用性こそ、プレイヤーが装飾や無料の食料として扱ってはいけない理由だ。小さな浮いた縁のサンプルならスキャン作業には十分安全である。裂け目、ガスケットシーム、ケーブルの傷、淡いガス膨れの上に張ったマットは、すでに経路の一部だ。そこで裂けば棚は変わる。閉じ込められたガスが抜け、grazersが散り、沈殿物が濁り、明るい斑点が視界問題になる。規則は単純だ。縁を採る。包帯を盗むな。

## Scanner

フォティックマット。鉱物の皮膚上にある酸素正味のバイオフィルムシート。明るく、有用で、圧力に脆い。封じた裂け目から剥がすな。
