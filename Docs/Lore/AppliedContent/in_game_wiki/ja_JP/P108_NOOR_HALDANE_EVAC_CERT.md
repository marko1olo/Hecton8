# ヌール・ハルデーンの退避証明

ヌール・ハルデーンは、退避保留の背後にあるDeep Reachの法務および認証の声である。彼女の署名はパニックとして書かれていない。統制として書かれている。ルートは認証可能でなければならない。輸送体は管理を受け入れなければならない。生物学的状態は審査可能でなければならない。ルートの中の人間が災害を生き残れなくても、法的連鎖は災害を生き残らなければならない。

だからハルデーンのファイルは痛い。言葉は自分を弁護できる。隔離違反は汚染を広げるかもしれない。未認証抽出は輸送体を孤立させるかもしれない。港湾拒否は救助を別の災害に変えるかもしれない。清潔な会議室では、すべての条項が責任ある封じ込めに聞こえる。水が上がる圧力廊下では、同じ条項が鍵になる。

プレイヤーにとって、この記録はコロニーのルート保留、医療遅延、Deep Reachの責任をつなぐ。ハルデーンは誰かを憎む必要がない。退避が安全だと証明する条件を待たせるだけでいい。圧力は待たない。酸素は待たない。証明書は待った。
