# 熱水チューブワーム

熱い流体が床から出る所にしか育たない。そこは安価な酸素セルが上向きに読む唯一の場所だ。

噴出口の化学がセルに負荷をかける。群体域の内側ではClass-IVの予備計が四から九パーセント、滑らかに上がり、その間に水は悪くなる。その数字に合わせて補充すれば、浮上時に足りない。

群体は警告を一度だけ出す。域全体が同時に管へ引っ込んだときは、二、三秒後にこちらへ届く流れの変化をすでに検知している。

産出：長さ一メートルを超える管の基部に座ったマイクロノード。こじり出せば、4,830 mで約60 Cの中身が手に噴き出す。

1,100 m離れた二つの域から回収されたノードが、同じ刻印の部品番号を持っている。評価：域の内側では酸素値の上昇を故障として扱い、二つ目のセルで確認する。

## Scanner

噴出口に付随する管群体、密。信頼度66パーセント。溶存酸素21パーセント、上昇中。危険：熱接触。限界：セルは硫化物干渉に対応していない。

## Terminal

試料ロット 44-T-4830。深度 4,830 M。区分：センサー宿主、使用可。回収：ノードのみ、宿主は不要。大気記録 22-B：校正ドリフト、記載抑制。提出先：回収適合室。

## Field Note

「校正ドリフト」は、噴出水の中で上がる計器に窓口が付けた言葉で、手順書を直す代わりに警告を消したという意味だ。どの域にも二つ目のセルを持ち込み、低い側を信じろ。
