# ペレットレーン航跡台帳

回収された航跡台帳は、FTLなしの近光速貨物を説明する。ビームセイルが航路を開き、ペレット供給式核融合と段階制動がseed payload、重貨物、後の人間契約をAegirへ運んだ。燃焼ごとに記録が残る。使ったペレット、遮蔽損失、巡航質量、制動権、トーパー寝台、請求優先だ。

## Scanner

航跡プレート // ペレットレーン貨物船の孔食した台帳片。衝突痕の一つ一つが、暗闇を越えて質量を押す金を誰が払ったかを記録する。

## Terminal

LUYTEN貨物受領書 // ビームセイル加速完了。ペレット核融合ハンドオフ承認。巡航質量、遮蔽摩耗、制動割当、トーパー席、請求貨物はAegir捕獲まで固定。

## Audio
