# ブラインベーン標本カード

ブラインベーンは、安心できる意味での植物ではない。塩と鉱物の平たい膜で、ブライン、圧力、温度が境界を壁のように振る舞うほど鋭くする場所で生き残る。峡谷では、見えない水の構造をMarauderが目、sonar、浮力トリムで読めるものに変える。完全なベーン膜は、向こう側がより高密度で、pingを曲げたりスーツの浮力予測を外したりすることが多い。裂けた口は、最近の動物の通過、流れによる損傷、または層を抜ける唯一の弱い窓を示すことがある。丸まった先端はせん断が緩んでいる印だ。死んだ帯から落ちた淡いリブは有用素材になり得るが、生きた膜を切ると峡谷を読める状態にしていた経路標識を消す。垂直に見えるからといって開いた発光を渡るな。ベーンの縁を一つ視界に入れ、トリムを控えめに保ち、見えるベーン境界のない床反射は別の読みが確認するまで嘘として扱え。

## Scanner

ブラインベーン膜。密度せん断に固定された塩鉱物膜。完全な縁は壁、裂けた口は通路。ベーン縁のない黒い水は偽床リスク。
