# 降下カプセル損傷部位

降下カプセルは一つの派手な事故として壊れたのではない。まだ仕事をほとんど果たした部品の連鎖として壊れた。Ascent sleeveは歪み、上昇圧に対して再密閉できない。Guidance gimbalは傷つき、きれいな上昇でもBlack Keelが受け入れる前に姿勢を失う。Relay mastは切れ、compressorは塩混じりの砂で詰まり、割れたheat tileは想像上のburnを破片雲に変える。

HECTON-8には清潔な救助ボタンがない。空気を一時間保てるカプセルと、海を離れられるカプセルは別の機械だ。壊れた部位はそれぞれルートを示す。圧力対応sleeve stock、gimbal軸受、リレー背骨、compressor経路、またはBlack Keelに別窓を値付けさせる損傷証明だ。

残骸は背景ではない。最初の工学地図だ。カプセルがFAILと表示した時点で、海は着水を部品リストに変えている。

## Scanner

Ascent sleeve変形、guidance gimbal損傷、relay mast切断、compressor汚損、heat tile亀裂。

## Terminal

DROP DAMAGE: ascent sleeve FAIL, gimbal DEGRADED, relay mast SHEARED, compressor FOUL, heat tile CRACK.

## Audio

きちんと閉じ込めるには十分うまく着水した。

## Field Note

カプセルは最初の一時間、Marauderを生かせる。だが深度対応の交換部品なしでは上がれない。
