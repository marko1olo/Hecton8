# 沈没圧力コンクリート台帳

HECTON-8 の沈没コンクリートは背景ではない。ガスケット跡、錆の影、セラミック骨材、貝砂の詰まった割れ目が、消えた部屋の形を残す。石として掘る前に、何を支えていたかを読む。

緑に染まった下端は崩落前の水たまりを示す。きれいなせん断面は最近の salvage、地震、圧力破壊のどれかだ。見える鉄筋がなくても錆影があれば、金属はすでに剥がされたか腐食した。縁のガスケット粉はハッチや圧力扉の位置を示す。

Marauder は rubble を loot だけとして見ない。錆影をたどって配管 spine を探し、最後の圧縮片を切らず、砂に埋もれた route board を見つける。海は部屋を消したが、壊れ方は消していない。

## Scanner

沈没コンクリート // 自然石ではなく、植民地の耐圧骨材。鉄筋は消え、錆の影だけが残る。割れ目の貝砂は長い浸水、白い新しい面は最近の崩落か salvage cut を示す。

## Terminal

古い植民地スラブ // 普通の石として掘るな。コンクリート片は部屋、配管溝、荷重線を示す。白いセラミック骨材は圧縮壁。橙の影はかつての補強。下の緑黒い染みは崩落前の滞留水。
