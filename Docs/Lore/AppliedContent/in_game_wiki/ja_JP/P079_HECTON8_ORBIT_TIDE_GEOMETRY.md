# HECTON-8軌道 / 潮汐幾何

HECTON-8の軌道は、Great Tideを政治になる前に信じられるものにする。共鳴が海を引き、氷応力と高潮が棚を載荷し、産業熱と塞がれた排水が植民地の仕組みを悪い時刻に押し返させた。

罪はDeep Reachが物理を発明したことではない。Atlas continuity、保険貨物、労働階級を中心に避難計算を組み、死者を許容予測誤差と呼んだことだ。

## Scanner
