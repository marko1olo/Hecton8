# 最終問い：壊れた守護者

壊れた守護者は保存/隔離の軸だ。Atlasはまだ圧力室を支え、亀裂にbiofiber sealantを送り込み、居住モジュールから熱を逃がし、vent micronodeに局所損傷を修復させることができる。人間の指揮が失敗した後も一部の生物とサービス室が残った理由は、この機能にあるかもしれない。同じ連続性は損傷した分類も動かし続ける。作業員、工具、バイオマス、経路タグ、修復在庫が一つの保守目録へ落ちることがある。隔離保持は盆地崩壊を防ぐ機能を残すが、作業員名、Deep Reach責任、手動オーバーライド保管権は未解決のままになる。
