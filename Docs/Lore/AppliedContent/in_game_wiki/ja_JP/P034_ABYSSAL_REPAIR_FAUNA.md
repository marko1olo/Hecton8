# 深淵修復動物

深淵修復動物は、Atlas-6が固定インフラで不適切な修復材料を受け入れるのをプレイヤーが見た後に現れる。ここでは同じ判定が生きた動物に届いている。スキャンは筋反応、鰓の動き、追跡行動、傷口の縁をまだ読み取る。同時にセラミック支柱、ケーブル繊維、ドローン外殻板、移植部を通る稼働中の保守ピングも読む。

標本は遠隔ドローンではなく、機械を載せた死体でもない。Atlasは圧力傷を閉じ、動ける状態を残し、動物に狩りを続けさせた。遭遇は二方向に危険だ。動物は自分の捕食ルートを進み、移植部は近くの修復ドローンを呼ぶか、その動物をサービス経路の一部として示すことがある。対象を単なる野生生物として扱う前に、移植材料、ピング間隔、巣の電力を読むこと。

## Scanner

標本は古い咬傷を貫くセラミック肋骨パッチを持つ。ケーブル繊維が左鰓扇とドローン外殻板を接続。移動: 狩猟パターン維持。危険: 移植部が稼働中の保守ピングを発信。
