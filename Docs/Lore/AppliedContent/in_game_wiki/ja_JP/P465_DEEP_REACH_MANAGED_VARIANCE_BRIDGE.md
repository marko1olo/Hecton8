# Deep Reach管理偏差

Deep Reachは浸水した修理限界を管理偏差と呼ぶ。水位線、消えた経路印、歪んだP-63カラー、ブラックボックス片のほうが「公称」より強い。 通知は公称許容範囲と言う。部屋には塩、膝までの水、変形したカラー、届かなかった経路印が残る。 Deep Reachが公称と書いたら、先に金属を読む。紙は監査に残り、圧力は傷を残す。
