# Nearlight駆動スタック断面

近光速船は船体に付けた魔法のトーチではない。駆動スタックとは物理化した経路全体だ。Beam arrayは出発前に電力を使い、pellet laneは捕獲質量を船が飲める場所へ置き、fusion-electric throatは燃料を電力と熱へ変え、シールドは塵の損失を受け、放熱器は何年も廃熱を捨て、制動装備は加速と同じ重さを持つ。

## Scanner

DRIVE STACK断面 // Barnard Yards整備板: beam-sail yoke、pellet catcher、fusion-electric throat、shadow shield、放熱リブ、magsail spool、aerobrake skin、custody meterが同じ経路番号を共有。

## Terminal

ATLAS TRANSIT STACK // 出発推進: 外部beam array。巡航供給: pellet lane捕獲。変換: fusion-electric throat。損失制御: シールド氷、炭素、放熱リブ。到着権限: magsail spool、aerobrake skin、受信スロット、custody台帳。

## Audio
