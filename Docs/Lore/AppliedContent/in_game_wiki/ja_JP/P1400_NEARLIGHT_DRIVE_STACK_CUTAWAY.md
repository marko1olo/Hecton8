# 近光速ドライブスタック断面図

Barnard Yardsの断面図がぶっきらぼうなのは、乗客ではなく請負作業員向けだからだ。Atlas級の船体は、船内エンジンが点火した瞬間に旅を始めるわけではない。ビームアレイが帆へ電力を使い、ペレット航路が開かれ、捕獲質量が核融合電気スロートへ届き、シールド台帳が高価な防護材を何年も塵に削られると認めた時点で、もう始まっている。

航海の中間部は、眠った人間を内部に抱えた熱問題だ。放熱リブ、冷凍睡眠区画、機械工房、掘削架台、耐圧貨物が同じ余裕を奪い合う。到着は勝利の噴射ではない。別の契約機械だ。磁気帆スプール、空力制動スキン、受領窓、保管ソフトが、誰に現地の制動枠を使う権利があるかを決める。だからBlack KeelはAegir上空でサルベージ通過料を計算できても、救助船にはならない。近光速輸送船は、航路インフラ、熱予算、制動権、所有権がそろった時だけ動く。閉じ込められたMarauderは、航路に数えさせない限り一つの明細にすぎない。

## Scanner
