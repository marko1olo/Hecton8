# 静かな軌道の受領台帳

静かな軌道の受領台帳は、Black KeelがMarauderに渡す最初の正直なものだ。助けではなく、受領だけ。上層海を過ぎると無線は死ぬ。レーザーもマイクロ波も散るか消える。深度では、契約者は低速の音響パルスで話す。運べるのは文字、ハッシュ、圧力警告、支払い対象の質量記録だけだ。Black Keelが応答するのは契約上の保管に受領が必要だからで、救助盤を見ている人間がいるからではない。

Kestrel、嵐の窓、HECTON-8の鉱物を含む海は、軌道が空く前にメッセージを古い証拠へ変える。受領は、テンダーが作業に値段を付けるだけの情報を聞いた証明でしかない。抽出、慈悲、ライブ指令の証明ではない。だから最初の本物の返答は沈黙より冷たい。システムは救う前に、まずあなたを数えられる。

## Scanner

音響受領 // パケットを312 bpsで受理。船殻質量、酸素リース、請求ハッシュ、サルベージ検査値を受信。抽出ベクトルなし。

## Terminal

BLACK KEEL軌道受領 BKH8-RC-2190-0041 // アップリンク種別: 音響。送信者: 債務拘束契約者。内容: マニフェスト予告、圧力テレメトリ、スーツ残存推定。状態: 受領、エスクロー済み、未回収。Kestrel影窓は11時間40分後に閉鎖。回収には認証済み上昇質量、隔離ハンドシェイク、支払い対象請求物が必要。

## Audio

受領記録。マニフェスト確認。抽出ベクトル保留。質量、シール証明、より清浄な検査値を送れ。

## Field Note

受領は救助ではない。Keelがパケットに請求できるという意味だ。帰り道を請求できるまで息を残せ。
