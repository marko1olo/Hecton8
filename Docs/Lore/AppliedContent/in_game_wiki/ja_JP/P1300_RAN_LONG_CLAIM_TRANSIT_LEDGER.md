# Ran長期請求輸送台帳

Ran長期請求台帳とは、文明が遭難信号を聞いたあと、物理が変わったふりを拒んだ結果だ。パケットは答えに感じられるほど速くルートを渡る。だが答えは船体を連れてこない。記録されるのは請求者、位置、ペイロード、保管連鎖、そしてオフワールドの誰かが質量を払う理由だ。

            台帳は硬い輸送に巻き付いた古い辺境法である。Ranの中継は光速の証人パケットを受け入れる。Luyten事務所は受領をハッシュ化する。Black Keelは鏡とキャリア窓を通して清潔なバーストを流す。どの仕組みも無料の救助船を持たない。テンダーには今もレーン、制動割当、受信スロット、隔離許可、監査に耐える支払者が必要だ。

            だから最初のキャリア窓は痛い。Marauderは「生きている」と叫びたい。台帳にはその欄がすでにある。良いパケットは、どこか、どれほど確かか、何を上げられるか、誰が触れたか、Deep Reachが何を壊したか、上昇パッケージが密封できるか、誰も来なければどの証拠が失われるかを伝える。身体は重要だ。身体だけでは間違った欄で安い。

            Black Keelの残酷さの大半は、人間の声を抜かれた算術だ。生きた人間は責任。認められる証拠を持つ生きた人間は梃子。代替不能なルートデータに縛られた生きた人間は歯のある貨物。台帳は恐怖を項目に変える。項目なら、信号がHECTON-8を離れた後でも、値付けされ、証言され、争われる。
