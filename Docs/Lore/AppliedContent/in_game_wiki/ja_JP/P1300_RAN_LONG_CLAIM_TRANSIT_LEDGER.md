# Ran長期請求輸送台帳

取り残されたMarauderが最初に信じたがる嘘は、通信が救助を意味するというものだ。Ran周辺での通信は、パケットがキャリア窓を見つけたという意味でしかない。運べるのは位置、証人ハッシュ、法的要求、見積もり、脅しだ。圧力船体、医療員、貨物テンダー、制動スタックは運べない。

だからRan長期請求台帳は救難信号ではなく会計書類のように読める。生存者は一つの欄でしかない。座標信頼度、ペイロード種別、保管等級、上昇質量、隔離リスク、ルート保険、回収前に死んだ場合の支払先も欄になる。Black Keelがパケットを動かすのは安いからであり、契約権限が遅延の中に宿るからだ。

大事なのは誰かが聞いたかではない。おそらく聞いている。問題は最初に何を聞いたかだ。清潔な生存状態は列を買う。検証済みのルート受領は交渉力を買う。Deep Reachの責任を示す証拠は、列の価格を決める権限を変える。HECTON-8の外で価値を持つペイロードなら、ただの身体なら海底に置かれるリスクを船に引き受けさせることがある。
