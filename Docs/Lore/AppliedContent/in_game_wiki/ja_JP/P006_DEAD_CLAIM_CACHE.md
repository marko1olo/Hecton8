# 死んだクレームのキャッシュ

死んだクレームのキャッシュは、プレイヤー以前にもHECTON-8の金を追った専門家がいた証拠だ。工具、悪い地図、切られたテザー、私的な印、そして十分に学んだが清く脱出できなかった者たちの警告が入っている。

## Scanner

隠された現場キャッシュ。戻るつもりだった誰かが詰めたものだ。

## Terminal

北パイプ下のルートはランプが起きるまで静かだ。青い容器に触れるな。峡谷内でキャリアの ping に答えるな。

## Audio

これはDeep Reachの装備ではない。別の誰かがカッターと不運を持ってここへ降りた。

## Field Note

地図が安全と二度言うなら、書いた奴は自分を納得させたかっただけだ。
