# 死んだクレームのキャッシュ

死んだクレームのキャッシュは、プレイヤー以前にもHECTON-8の金を追った専門家がいた証拠だ。工具、悪い地図、切られたテザー、私的な印、そして十分に学んだが清く脱出できなかった者たちの警告が入っている。

## Terminal
