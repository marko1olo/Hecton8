# 死んだ請求権のキャッシュ

死んだ請求権のキャッシュは、プレイヤーがHECTON-8の金を追った最初の略奪者ではないことを示す。キャッシュは通常の調査経路より下にある。保守配管の下へ押し込まれたドライバッグ、バラストに削られた私的な請求印、油紙に包まれた酸素錠、震える手で修正された地図。価値があるのは装備ではない。価値があるのは時系列だ。2147年の喪失の後、プレイヤーの降下の前に、独立クルーが下へ来て、沈んだインフラを抜ける部分的な道を見つけ、植民地を沈黙させていた同じ暗闇へ消えた。

## Scanner

隠された現場キャッシュ。乾いたまま低く結ばれ、切られたテザーと、安全と書きすぎた地図で印を付けられている。

## Terminal

キャッシュ記録: 北パイプ下の経路はランプ格子が目覚めるまで静か。青い箱は封印のまま。峡谷の影の中ではcarrier pingに応答するな。テザーが切れているなら、このキャッシュは引き継いだ厄介事として数えろ。

## Audio
