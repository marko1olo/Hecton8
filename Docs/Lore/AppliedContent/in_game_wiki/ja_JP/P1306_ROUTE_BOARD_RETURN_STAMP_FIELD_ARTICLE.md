# 経路板と帰還スタンプのフィールド記事

圧力コロニーは記憶だけでは動かない。役に立つ扉の横には、いつか必ず板が生える。目的地、ハッチ番号、窓、工具タグ、空気見積もり、ピンガーのチャンネル、帰還スタンプ。一見ただの事務だが、それは部屋が外に出た人間を数える方法だった。

経路板を発明したのは Deep Reach ではない。濡れた廊下が口約束を食い潰すから、現場のクルーが作った。会社はそれを責任逃れの言語に変えて毒にした。行方不明は遅延になり、遅延は保留になり、保留は未解除になった。次の窓までに欄を書き換えられれば、失敗は死ではなく予定の問題になる。

印刷された見出しより、手の跡のほうが重要だ。塩の上のグリースペンは、誰かが手袋のまま真実を書き直した証拠だ。乾いたスタンプ台は、部屋がもう支えられない帰還をまだ待っていた証拠だ。名前のない工具タグは、装備だけが別の手で戻った証拠だ。きれいな欄へ移された名前は、消された名前より悪いことがある。誰かが板を管理済みに見せたかったからだ。

Marauder にとって、板は航法器具であり告発でもある。最後に開いたハッチ、まだピンガーが届くサービス幹、隠されたキャッシュの場所、廊下が作り物ではなく使われていた理由を示す。普通の作業員がまだ実務の問題を解いていた時点で、企業はすでに記録を編集していたことも教えてくれる。

帰還スタンプは小さく、醜く、人間的だ。人が圧力をくぐって戻り、工具を返し、部屋をもう一行だけ完全にしたという印だ。HECTON-8 で最も怖い板は、血や標語に覆われた板ではない。最後の日がまだ明日を待つシフトに見える板だ。
