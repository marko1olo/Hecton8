# 音声転写ダメージ帯

転写ダメージ帯は、壊れた音声に残る目に見える傷だ。レコーダーが失ったもの、パケット公証が抑えたもの、粗い翻訳が解けなかったもの、後のオペレーターが切り取ったかもしれないものを示す。帯は飾りではない。転写をどれだけ信じてよいかをプレイヤーに伝える。

よい破損転写は、生存に関わる場所では読める。名前、座標、貨物番号、債務条項、叫びの最後の一秒は隠してよい。だが扉の警告、経路反転、圧力変化、話者の職務、証拠を理解するための行動は隠せない。破損が手掛かりをただのノイズに変えるなら、その手掛かりはまだ未完成だ。

HECTON-8ではダメージ帯を誠実さの規則として扱う。潰れた音声にきれいな字幕が乗っていたら怪しい。無傷のレコーダーの横に黒塗り行があれば、誰が消したのかを問う。同じ一秒が複数のログで欠けていれば、自動スクラバーの痕跡かもしれない。プレイヤーは欠落の形を読むことになる。切れた語、時刻の跳び、信頼度の括弧、話者のずれ、翻訳の傷、公証印。

これはアクセシビリティも守る。世界内の破損は、字幕を必要とするプレイヤーを罰してはならない。帯は不確かさを示してよいが、警告は読めるまま残す。コロニーは暗闇で失敗したかもしれない。インターフェースまで暗くする必要はない。

## Scanner

転写ダメージ帯 // 録音に物理的または手続き上の欠落がある。黒塗りは名前、貨物ID、時刻を隠してよい。ただし中核警告、話者の役割、経路上重要な行動を隠してはならない。
