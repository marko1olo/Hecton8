# Kestrelリレー影図

回収されたリレー影図は、Aegirの月を稼働する機械として見せる。Kestrelは光を遮るだけではない。有用な母船レーンをノイズの歯に刻む。影の間、Black Keelは断片、古いタイムスタンプ、あるいは何も受け取れないことがある。

## Scanner

リレー影 // KestrelがAegirレーンを横切っている。アップリンク品質は滑らかに落ちず、歯のように欠ける。荷電した縁が開くまでバーストパケットを保持。

## Terminal
