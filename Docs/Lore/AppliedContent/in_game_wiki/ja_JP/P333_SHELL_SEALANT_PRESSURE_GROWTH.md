# 貝殻シーラント圧力成長

貝殻シーラントは緊急化学から始まる。補修フォーム、鉱物スラリー、そして圧力が材料を破口へ押し込む。HECTON-8の水では、局所成長がパッチに定着し、層状の殻へ硬化する。

圧力損失が下がればAtlasは成功と判定する。Marauderが気にするのは戻り幅、工具の通り、殻が向こう側に閉じ込めたものだ。良い密封は経路を孤立させ、悪い水を隠し、死んだ部屋を機械が返答するまで保存する。
