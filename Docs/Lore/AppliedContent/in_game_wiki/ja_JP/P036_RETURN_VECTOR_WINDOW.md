# 帰還ベクトル窓

帰還ベクトル窓は、Black Keel が応答できても即時救助はできないことを示す最初の証拠だ。キャリアは Aegir 上方の自動遷移トラックで動いているが、HECTON-8 から出る経路は天候、荷電粒子ノイズ、中継損傷、未完成の上昇装備を越えなければならない。

有効な帰還窓には、キャリア幾何、表層嵐の切れ目、清浄な中継経路、打ち上げに耐えるカプセル連鎖の四つが同時に要る。ひとつでも失敗すれば、ping は回収ではなく時刻印になる。同じ仕組みは後の部分回収にも使われるが、債務、証拠保全、損傷した経路は消えない。上昇クレードル、誘導コア、熱シールド、帰還ハンドシェイクが再建されるまで、軌道からの応答はすべて時刻制約として扱う。

## Scanner

帰還ベクトル読取 // Black Keel ping を Aegir 嵐間隙で受信。キャリア距離: 高位遷移トラック。中継線は雲電荷下で汚い。誘導コア、熱シールド、帰還ハンドシェイクが全て緑になるまでカプセル上昇拒否。

## Terminal

帰還窓予測器
Carrier: BLACK KEEL / 自動遷移トラック

中継: 空側ラインノイズ / シェルターマストは一度だけ反復可
上昇装備: 誘導コア欠落、熱シールド未認証、バッテリー予備低
処置: carrier ping を回収扱いにする前に上昇連鎖を再建
