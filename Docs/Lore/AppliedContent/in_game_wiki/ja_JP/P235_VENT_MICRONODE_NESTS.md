# ベント・マイクロノード巣

ベント・マイクロノード巣は、Atlas が全能の悪役コンピュータにならずに活動を続ける仕組みを説明する。ベント近くの深部では、小さな保守ノードが熱勾配、鉱物、振動からエネルギーを取る。それぞれが近くのバイオフィルム、殻シーラント、タグ付き動物、損傷金属へ弱いパルスを送れる。どれもコロニー全体を制御しない。だが集まれば、清潔な送電網が消えた後も修理行動を生かし続ける。

そのため最終バイオームは単に建てられたのではなく、育ったように感じられる。ノードはパッチを起こし、リレー器官に栄養を送り、亀裂上の殻を硬くし、偽の診断を生かすことがある。局所的に間違えることもあり、かつて圧力が改善したという理由だけで、経路が読めなくなっても修理パターンを繰り返す。プレイヤーにとってマイクロノード巣は電源、危険、証拠、そして標的になり得る。壊せば部屋は静まるかもしれない。放置すれば Atlas は材料を通じて囁き続ける。
