# Aegir回収プール

Aegir回収プールはBlack Keelの背後にある公的なsalvageの殻だ。小さなmarauder免許でも、私有の惑星間carrierを持たずに放棄されたAegirクレームへ届く。その取引は役に立ち、同時に毒でもある。テンダーを送れる同じプールが、呼吸している操作者、封印payload、隔離ロック、証拠束のどれが次のburnに値するかを決める。
