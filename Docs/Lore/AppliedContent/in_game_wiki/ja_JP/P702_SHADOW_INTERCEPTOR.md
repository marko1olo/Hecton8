# 影迎撃

追ってはこない。こちらが向かっていた場所に先に着く。

開けた横断では、接触は広い方位を保ち、こちらの針路には合わせずに速度だけを合わせ、それから表示から消える。その空白が攻撃だ。音を返さなくなったのは、いまこちらの方位上にいるからで、表示を読む潜水士は空の画面を見て気を緩める。

速度は効かない。こちらの速度はすでに解かれている。効くのは目的地の変更だ。解は古い目的地に対して計算されている。

D交代のスーツ発信機三つが、遮蔽になる構造のない開けた横断で、互いに四十メートル以内で停止した。回収待ち一覧は座標を記載し、その項目を閉じた。

評価：横断中に接触が消えたら、着く速さではなく、向かう先を変える。

## Scanner

接触は断続。信頼度は低下中。危険：現在位置ではなく予測位置へ寄せる。限界：接触喪失は離脱を意味しない。

## Terminal

標本 現場照会 2147-D-09。区分：回収可能バイオマス。事案関連：D交代 移動中喪失、3名。喪失原因：経路選択。回収：座標記載、項目終了。

## Field Note

喪失原因、経路選択。三人が開けた水域を同じ直線で渡り、書式はその直線のせいにした。画面がきれいになったら針路を折れ。
