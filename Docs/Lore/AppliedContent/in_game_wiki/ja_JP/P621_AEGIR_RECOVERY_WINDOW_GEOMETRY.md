# Aegir回収ウィンドウの幾何

回収されたAegirウィンドウ図は、Black Keelとの接触が救助ではない理由を示す。信号は一つの通過に収まっても、身体、上昇カプセル、検疫請求、証拠パケット、ペイロード質量が同じ幾何に収まらないことがある。最初の修理で得られるのは時計に載る権利だけだ。

## Scanner

ウィンドウ時計 // この通過でBlack Keelはパケットを受信できる。身体回収にはまだ上昇装備、検疫ハンドシェイク、Kestrelリレー影の解除、承認済みtonne-window質量行が要る。

## Terminal

KEELMARK回収通知 // 信号受信はリフト承認ではない。回収要求の前に、母船位相、嵐の天井、リレー影、検疫許可、上昇パッケージ状態、承認済みペイロード質量を合わせること。

## Audio

Black Keel中継: パケット受信。身体はこのウィンドウに入らない。上昇パッケージを封印したまま、証拠タグを維持し、数字ひとつで空気を使って喜ぶな。

## Field Note

母船が応答しても、空気を祝いに使うな。返答は幾何と会計だ。救助は、ウィンドウ、封印、ペイロード、身体が同じ線に入った時に始まる。
