# payload公開台帳受領プロトコル

公開台帳プロトコルは、Deep Reachが静かに所有できない場所へ証拠を送る。座標を編集し、attestation hashesを封印し、航路保管とAtlas重み付けdigestを付け、遅延リレーへ入る。送信者は受理時に制御を失う。パケットは買いにくく、埋めにくく、使うには遅くなる。

## Scanner
