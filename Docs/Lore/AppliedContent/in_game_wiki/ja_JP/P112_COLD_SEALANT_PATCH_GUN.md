# 低温シーラントパッチガン

低温シーラントパッチガンは、ポンプ作業の後で最初に得る正直な修理手段だ。ピンホール漏れを止めたり、ガスケットの縁を小部屋の復旧まで保たせたりできるが、損傷した構造を安全にはしない。役に立つ教訓は定格ラベルにある。HECTON-8では、圧力クラス外の修理が罰を受ける。

## Scanner

低温シール用パッチガン。カートリッジはピンホール漏れと静かな継ぎ目のみ対応。動くせん断には剥がされる。

## Terminal

パッチ限界 / 低温シーラント: 表面を拭いた後、低深度の濡れた外板に接着。ピンホール、ガスケット縁、静かな継ぎ目漏れのみ承認。せん断亀裂、温かいblue debtブルーム、動くケーブル継ぎ目は拒否。

## Audio

密閉とは呼ぶな。時間と呼べ。

## Field Note

パッチが買うのは数分だ。亀裂がまだ動くなら、その数分で離れろ。
