# Atlas切断記録

Atlas切断記録は停止の受領書ではない。Atlasの損傷した修復層を横切る連続性切断を記録し、噴出口マイクロノード応答、殻質シーラントパルス消失、タグ付き動物経路の断絶、Deep Reach経路拒否を追跡する。同じ切断が、閉じ込められた作業者の痕跡を解放し、圧力生態を傷つけ、生きたインフラを受領者の所有問題に変えることがある。

## Scanner

Atlas切断記録 // 損傷した修復層で連続性を切断。マイクロノード応答は低下中。盆地安定性と保管効果は未解決。
