# 有光マット基準

有光マットは、プレイヤーの呼吸を助けながら雑な採取を罰する最初の浅瀬生命だ。光、鉱物流出、遅い水が出会う場所で膜が育ち、岩を酸素に富む色で覆う。健康な中心は柔らかく明るい。塩で硬い縁は、圧力化学または古いインフラがそのポケットを痛めている印だ。マットは音も変える。良い成長は小さな衝撃を鈍らせ、汚染された継ぎ目はスクレーパーの下でクリック音と泡立ちを返す。繊維や酸素化学が必要な時は、浮いた縁だけを切ること。ハッチ、配管、密封パネルの近くで明るい中心を裂くと、局所酸素が落ち、マットが押さえていたものを露出させる。
