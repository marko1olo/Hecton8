# 青い負債

青い負債とは、圧力保持されたXenon-Omega残渣と、その周囲で育った汚染基質を指すマローダーの俗語だ。単一の鉱物ではない。冷たい格子、クラスレートの檻、計算灰、失敗した封じ込めゲル、Deep Reach装置が残した深部処理スクラップの総称である。HECTON-8の水柱の下では、動かせる程度には静かでいる。キャビン空気では反応性ガス、ガラス質の粉塵、法的な厄介事を放出しかねない。この物質が重要なのは、高エネルギー封じ込め、Atlas互換メモリ、サルベージ経済という三つの系を同時につなぐからだ。封印されたサンプルは電力セル、工具ライセンス、借金から出る道を買える。同じサンプルがcarrierを標識し、留置権を起動し、シェルターを汚染し、Deep Reachが捨てたと言ったものを取りに戻った証拠にもなる。

## Scanner

圧力保持されたXenon-Omega残渣。冷たく暗い圧潰水中では安定。暖かい空気と低圧では危険。

## Terminal

XO CONTINUITY SUBSTRATE. 圧力ロック必須。ベント禁止。保管フラグ: 請求 / 汚染 / 留置権。

## Audio

コンテナがソナーで歌っている。低く規則的だ。あれは生命ではなく処理残渣だ。生命より悪いものとして扱え。

## Field Note
