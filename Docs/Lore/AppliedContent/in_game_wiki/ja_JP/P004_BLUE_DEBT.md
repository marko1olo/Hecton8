# Blue Debt

Blue debtは、圧力保持されたXenon-Omega材料と関連プロセス残渣を指すマローダーの俗称だ。単一の鉱物ではない。圧力成長格子、クラスレート構造、汚染基質、Deep Reachが高エネルギー封じ込め、極限計算、Atlas互換インフラに使った産業残渣の集合である。

## Scanner

圧力保持されたXenon-Omega残渣。敵対的条件内でのみ安定。暖かい居住区空気へ放出するな。

## Terminal

XO連続性基質。減圧禁止。未濾過の居住区大気に曝露禁止。

## Audio

容器がソナーで歌っている。低く、規則的だ。生物ではない。もっと悪い。

## Field Note

Blue debtは二度噛むから金になる。運ぶ時に一度。持っていると知られた時にもう一度。
