# グラスグレイザーの群れ

グラスグレイザーは、浅瀬の美しさを役に立たせながらも安全にはしない最初の動物である。透明な殻と硬い口稜で、pressure glass、緩いフォティックマット、古いケーブル外装から鉱物膜を削り取る。採餌中の群れは淡いレーンを残し、そこから直近の流れ、新しい成長、汚染された継ぎ目を避ける一番穏やかな線が読める。群れの中心ではなく縁を見ること。彼らは温かいシーラント、酸っぱい塩水漏れ、Atlas 互換の信号ドリフトを帯びた表面を避ける。餌が残っているのに刻み音が止まったら、水を変えた大きな何かがいる。清掃されたレーンは証拠であって、全速で進む許可ではない。

## Scanner

グラスグレイザー群 // 透明な殻を持つ採餌生物が pressure glass とフォティックマットの縁から鉱物膜を削る。殻の刻む音は明るい経路痕を開き、急な沈黙は捕食者のデータになる。

## Terminal

基礎ファウナ: 非敵対性のグレイザー集団。pressure glass 膜、新しい鉱物ブルーム、流れの乱れ、捕食者による退避を追跡する。活発な採餌後の不在は経路警告であり、空の出現地点ではない。

## Field Note

群れを追うな。群れが露出させるものを読め。新しい膜、古い削痕、温かいシーラントの回避、そして彼らが渡ろうとしない空白のレーン。
