# ペレット航跡制動台帳

ペレット航跡制動台帳は、星間航行をプレイヤーが手に取れる物に変える。焦げたアブレーター片、経路学校の断片、墜落より古い質量勘定だ。Aegirへ最初に届いたのは、Luyten Junctionから撃ち出された小型のペレットビーム探査機だった。失っても帳消しにできるほど安かった。人間を載せた重貨物は後から来た。Atlas級輸送船は核融合電気パルスを燃やし、乗員を昏睡状態で眠らせ、全てのキログラムを負債として扱った。

残酷なのは到着だ。光速近傍の航行へ向けて何年も速度を積んだ船は、その速度を捨てなければならない。磁気帆が星間物質を噛む。大気制動がガス巨星と嵐の外層をかすめる。余裕値の小さな誤差が貨物をプラズマにする。だからHECTON-8は人間の法で所有され、請求され、索引化されていながら、救助の場としては届かない。企業は船体が闇を越える前に請求権を継承できる。
