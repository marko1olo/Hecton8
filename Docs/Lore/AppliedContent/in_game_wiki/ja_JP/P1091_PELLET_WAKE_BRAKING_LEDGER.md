# ペレット航跡制動台帳

一見すると台帳はただのスクラップだ。手のひらほどの焼けたアブレーター箔、割れた経路学校のスレート、墜落より古い質量勘定。合わせると、星間航行そのものがMarauderの手に乗る。Aegirは闇を突き破る英雄船で開かれたのではない。Luyten Junctionから撃ち出された小型ペレットビーム偵察機が地図を作った。証跡パケットを持ち、帰還を期待されない安い機械だ。経路は安全になる前に合法になった。

人間の質量は後から来た。Atlas級輸送船はジャンプしない。何年も押され、供給され、守られ、請求された。核融合電気パルススタックは光速近傍の航行へ速度を積み、乗員は冷たく眠り、債権者は全てのキログラムを将来の担保として測った。追加装甲、食料、推進剤、救助寝台、交換工具。全てに質量価格がある。HECTON-8では、その質量価格が生存者を見る前にblue debtへ変わる。

航跡サンプルは公開教材が丸める部分を記録している。到着とは、逆向きの難しい燃焼だ。磁気帆は帯電した塵と薄いプラズマを引きずる。ペレット流は帆の縁を食う。大気制動の通過はガス巨星と嵐外層を道具にするが、その道具は船も殺せる。慎重すぎれば輸送船は窓を逃す。足りなければ貨物は明るい汚れになる。

だからDeep Reachは救助より速く請求を出せる。パケットは情報として経路を渡る。債務は契約で動く。Black KeelはすでにAegir現地空間にいるから回収窓に値を付けられる。内側の世界から来る救助船体は、まだ速度、制動、乗員リスク、保険質量を払わなければならない。文明はHECTON-8へまず署名として、次に警告として、ずっと後に機械として届く。
