# 深淵機械場修復ゲート

深淵場は、請求を傷つけたシステムをオペレーターに使わせる。Atlas成長は電力を橋渡しし、ルートハードウェアをパッチし、生体材料を通じて信号を運べる。成功した修復は同時に分類を変える。工具、生物、資産、汚染、証拠がフィールドを行き来し続ける。
