# アルファ・リヴァイアサン：統合ファイル

二十二件の事象のうち九件が一つの呼称にまとめられた。九隻が船体応力警報を出しており、損失報告の書式に原因欄が一行しかない。

第2項 形態、第4項 質量および全幅 - 非開示（RCO/hv）
第6項 音響 - 搬送波 40 Hz 以下、1340 m。上限は非開示
第7項 航路影響 - 針路のみ、ライン214
第9項 接触事象 - 付録K、同封なし、抜き取りの押印なし
第11項 生存者供述 - 保持、計上せず（低酸素症、窒素酔い）
第12項 種の一致 - 判定不能、22件中22件

残るのは機器の挙動だ。ソナーに何も出ていない状態で鳴る船体応力警報、距離の付かない方位、流れを曲げるものが何もない通路で横に曲がる流れ。

多くの事象では、先に水が静まる。小型の摂食種が一斉に止まってそのまま戻らず、通路の片方の端が先に沈黙する。

評価：先に静まった側の端が、それが来た端だ。退避は別の方位で。

## Scanner

接触未解決。材質不明。信頼度：9秒で94パーセントから12パーセント。危険：船体応力上昇、接触の記録なし。限界：方位のみ返り、距離なし。

## Terminal

文書 7734-C。呼称：ALPHA LEVIATHAN、統合。区分：通航注意、反復。報告事象：22件。呼称へ統合：9件、統合根拠は船体応力警報の提出。残り13件：方位を記録、請求なし、呼称は付与せず。第2・4・6・7項は資産非開示委員会 改訂11により非開示。第11項は保持：該当する抜き取りコードなし。損失計上：圧力変動。

## Field Note

方位は二十二件あの部署に入って、名前が付いて出てきたのは九件だ。九隻が船体応力警報を出していて、提出には原因が要る。質量と全幅は削っておいて、生存者の供述は一つも落とさず残している。書式に恐怖を削る欄がない。第9項は信用しない。距離のない方位は、船体警報を読んでいる怯えた班のことだ。ただし静けさは本物だから、人の出入りがある通路の音を覚えておけ。
