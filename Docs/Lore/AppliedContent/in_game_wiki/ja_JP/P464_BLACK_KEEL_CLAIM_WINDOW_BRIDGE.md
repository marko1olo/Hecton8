# Black Keel請求ウィンドウ

Black Keel請求窓通知を回収。carrier接触は信号がAegir中継レーンに届いたことを示すだけで、回収可能を意味しない。抽出には上昇ハード、検疫、受理済みペイロード、tonne-window割当が要る。

## Scanner

請求ウィンドウ // Aegir中継は受信窓のみ予測。回収には上昇パッケージ、検疫ハンドシェイク、tonne-window割当が必要。

## Terminal

KEELMARK保管通知 // 作業者信号受信。回収優先度未解決。信号や証拠パケットの受領は作業者回収を保証しない。

## Audio

Black Keel中継: 作業者信号を価格登録。回収窓は保留。受信を引き上げと混同するな。

## Field Note

Black Keelが返答したら、救助ではなく請求を数えろ。受信済みパケットは、質量、封印、検疫、天候が揃うまで待ち行列の席でしかない。
