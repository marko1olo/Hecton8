# 耐圧スーツパッチ・フィールド記事

耐圧スーツのパッチは中立の布ではない。空気が減り、経路がまだ終わらず、誰かが所有権を論じる前に身体をハッチへ戻さねばならなかった時の決定だ。素材は単純に見える。暗色の技術布、補強シームテープ、縫われた修理島、くすんだ白いパネル、グラファイト帯、塩擦れ、摩耗の弧。形よりも痕跡の順序が重要だ。

工場縫製は均一なテープ、規則的な縫い目、縁下に塩なし。現場パッチは違う。袖が腕にあるまま貼られたため傾いていることがある。正式な工房なら通さない関節を横切ることもある。糸が二色なら、スーツ用と工具ポーチ用の糸を混ぜた可能性が高い。縫い目周囲の鈍い白は圧力サイクル後の塩だ。光る暗い三日月は梯子、ハッチ、ケーブルとの反復接触を示す。

プレイヤーにとって、補修布は小さな生存記録である。袖口ガスケット近くのパッチは、以前の手袋シール不良を示す。胸部袋の上のパッチは、廃棄判定のスーツが再使用されたことを示す。工具ポーチのシームテープは Marauder の癖を示す。ポーチは残す。工具は信じる。スーツは疑う。

このパッチは人間の応急処置と自動修理を分ける。Atlas 繊維は所有を理解せず傷を閉じることがある。スーツパッチは醜く、明確だ。誰かが損傷を見て、素材を見つけ、押さえ、縫い、縫い目が十分長く持つことを願った。
