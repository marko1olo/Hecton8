# ドメイン距離尺度

ドメイン尺度は観光地図ではなく圧力図だ。Sol Core は遠くからでも所有を認証できる。Centauri は古い憲章を清潔に見せる。Barnard はカッターと借金を背負った Marauder を汚れ仕事へ出せる。Tau Ceti は遅延の後で証拠を公にできる。Luyten はパケットの custody を証明できる。Ran/Aegir は、その遠い力がヘルメットの上の水になる場所だ。

だから HECTON-8 は、宇宙を空っぽにしなくても孤独に感じる。メッセージは航路を渡れる。それでも酸素、潮汐、船殻温度、Black Keel の recovery window が先に決めてしまった後で届く。距離は法を消さない。救助より冷たくする。
