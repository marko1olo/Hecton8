# Seed Ship制動アーキテクチャ

Seed shipは探検巡洋艦のようには到着しない。減速質量、遮蔽損失、自動建設、何年もの低温ステージングを前提にした産業ペイロードだった。機械の方が制動予算に耐えたため、Aegirには安定した人間社会より先にハードウェアがあった。
