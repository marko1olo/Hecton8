# Aegir空模様サバイバル台帳

Aegirは描かれた背景ではない。生存者がどの部品も所有しないまま見ることのできる最大の機械だ。ガス巨星、その磁気圏、月の階段、嵐帯、リレー角度、Black Keelの航行は、スーツの密閉を保とうとしている小さな海に同時に圧力をかけている。

水面上の晴れ間は慈悲に見えることがある。光が戻り、carrierの声が少しだけ壊れていないように聞こえるからだ。だがそれは読みの半分でしかない。澄んだ空は荷電粒子カウントの上昇を意味することもある。嵐はAegirを隠し、パケット窓を潰す一方で、肉体を最悪のノイズから少し守る。月影は潮汐カードを数分だけ嘘にする。その数分で浅瀬のハッチ、塩水層の縁、上昇推定は悪い助言に変わる。

古いステーションは空を景色ではなく計器として扱うから生き残る。エフェメリス板は生の天体力学を解かない。証拠を送るリレー帯が十分に澄む時、潮汐モデルが疑わしい時、Black Keelが応答できる時、そしてascent stackが間違った空の下で高価な金属にすぎない時を、作られた反復可能な窓表として保持している。Aegirが美しく見えたら、無線を確認しろ。美しさはたいてい、何かが君を通過しているという意味だ。
