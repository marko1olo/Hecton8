# 公開証拠の悪用警告

公開台帳は救助信号ではない。価格を変える装置だ。Tau Cetiのパケットが編集ヘッダー、キャプション連鎖、証人ハッシュ、Luyten公証印を保ったまま公開ミラーへ届けば、Deep Reachはその部屋が存在しなかったと安く言い張れない。Aegirの殻会社も、付属する矛盾を買い集めなければ清潔な時系列を売れない。

危険なのは、同じパケットが名簿にもなることだ。ブローカーは名前と身体痕で賞金を計算する。保険業者は時刻印で支払いを遅らせる。請求部門は支援者より先に家族へ向かう。整理班はキャプション順を読み、どの証人を脅し、買い、消せるか選ぶ。公開は交渉力を変えるが、記録内の人間を安全にはしない。
