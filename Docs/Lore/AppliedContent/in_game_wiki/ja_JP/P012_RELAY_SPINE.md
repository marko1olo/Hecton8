# リレースパイン

リレースパインは人類圏の遅い通信骨格だ。ビーム枠、パケットバッファ、保管印、再試行予定を運ぶ。証拠、請求、命令は動くが、浸水区画へ酸素は動かない。

HECTON-8では、メッセージが正しく目撃済みでも間に合わない。真実と救助は別の物流問題だ。

## Scanner
