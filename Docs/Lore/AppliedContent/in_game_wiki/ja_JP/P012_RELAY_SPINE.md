# リレー・スパイン

リレー・スパインは、人類圏が距離を消したふりをせずにつながる方法だ。ビーム枠、パケットバッファ、保管ハッシュ、再送予定、公証スプール、ローカル天候許可の鎖でできている。命令、証拠、債務通知、生命証明バーストを星間距離の向こうへ運べる。だが水没した部屋へ酸素は運べない。

HECTON-8では、リレーは背景ではなく圧力だ。読めるが役に立たないメッセージがある。Deep Reachのパケットは、最初の版を書いた人々が死んだ後で浄化されて届くことがある。Tau Cetiの公開台帳受領は何年も後に証拠を政治的に危険にする。Luytenは保管を証明し、それでもプレイヤーを水中に残す。リレーは真実を長持ちさせる。速くはしない。
