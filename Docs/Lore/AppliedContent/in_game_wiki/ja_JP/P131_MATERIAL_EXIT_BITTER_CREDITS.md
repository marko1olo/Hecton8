# 物資回収出口: 苦いクレジット

これはHECTON-8からの最も冷たい合法的出口だ。MarauderはBlack Keelが量り、請求し、上昇窓に通せる圧力素材を戻す。負債は下がり、輸送台帳は整い、作業ファイルは数字を偽らずに閉じられる。受領書に直接の嘘はない。サンプルは本物で、custodyも十分に清い。失敗は省かれた欄に残る。照合されない作業員名、起訴には薄すぎる証拠連鎖、請求価値に変えられた沈んだ植民地、そしてDeep Reachに戻る理由を与える経路データ。ここでは職業的成功が生き残るが、その味は金属と古い空気だ。

## Scanner

圧力素材受領。退出窓販売済み。名前は未払いのまま。

## Terminal

物資退出受領書: custody-grade圧力素材受領。lien減額。上昇質量承認。証拠payload不完全。行方不明作業員台帳未解決。Deep Reach回収関心上昇。

## Audio

請求書は名前より先に空気へ届く。

## Field Note

Black Keelは記憶より先に質量を清算する。契約はそれを成功と呼ぶ。
