# ロッカー小道具変種マトリクス

ロッカー小道具変種マトリクスは、作業員の証拠を物理的に保つ。良いロッカーは、その作業員が何をし、どこへ行く許可を持ち、コロニーや後のサルベージャーが何を消そうとしたかを語る。工具摩耗はクルー系統を示す。ルートタグは扉、リフト、スーツ、クローラー湾を示す。圧力テープとシフトステッカーは、異常な危険の中にある普通の保守を示す。給与消去痕とマローダー保存印は、Deep Reach が人間を費用行に変えようとした後の証拠の第二の人生を示す。親密でありつつ、装飾的な散らかりにはならないべきだ。

## Scanner

ロッカーは仕事、ルートアクセス、誰かが消そうとしたものを示すべきだ。思い出の品は、仕事が読めた後でだけ許される。

## Terminal

LOCKER MATRIX: 作者付きロッカーには三つの読める手がかりが必要だ。仕事、ルート、損傷。装飾的な記憶は二次的なものだ。家族の印や内輪の冗談を入れてもよいが、工具、許可痕、消去痕がこの人物とコロニーの接点を先に語る必要がある。

## Audio

ロッカーは祭壇ではない。失敗した作業命令だ。

## Field Note

変種: 工具摩耗、ルート許可タグ、圧力テープ、シフトステッカー、給与消去痕、マローダー保存印。
