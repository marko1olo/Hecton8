# 広域濾過体の痕跡

広域濾過体は、目印と目印の間にある開けた深淵が空ではないことを最初に証明する存在だ。小型の別棟フレームより広い体で、深層水の中をゆっくり進み、プランクトン雲を収穫する。生物は Marauder を狩っているのではない。Marauder の周囲の地図を書き換えている。通過後、浮遊生物は薄くなり、ソナー反応は体の縁でにじみ、埋もれた工業輪郭が数分だけシルトの下から現れる。

だからこの生物は危険であり道具でもある。影は整備フレームを隠すことも、実際には動く組織で満ちた水域を開けたルートに見せることもある。正しい行動は航跡を読むことだ。口の後ろの澄んだ水、縁の汚れた崩れ、体の陰の音響的な静けさ。生物を見るためだけに影の下へ泳ぐな。残された隙間を進むのは、電力、ライン、帰路がある時だけにしろ。
