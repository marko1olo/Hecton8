# Pump Room Valve Handshake

pump handshakeとは、溺れた機械が再びlocal handを受け入れる瞬間である。floorが晴れ、lampが泳ぐのをやめ、routeが開いたように見えるため、controlを取り戻した感覚がある。だがHECTON-8ではwaterは消えない。別のcompromiseへ移されるだけだ。intake basketsはcapsule foam、古いgloves、shell grit、torn labelsを捕まえる。outletsは、理由があって静かだったcorridorsを起こす。正しい習慣はpumpをtradeとして読むことだ。一つのroomが呼吸し、別のroomがknockし始める。

## Scanner

local sumpがhandwheel inputを受理。capsule foamがintake basketを詰まらせ、outlet pulseはReturn Corridor Bへ上昇中。

## Terminal
