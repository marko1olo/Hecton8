# 圧力クルー原型表

圧力クルー原型表は、コロニーの証拠を感傷より先に機能へ結びつける。Pump 作業員は水、弁、圧力急変、保守記録の嘘へプレイヤーを導くべきだ。Seal 作業員は扉、船体パッチ、ロックの儀式、長すぎるほど乾いていた部屋に属する。Relay、Brine Map、Vent Forge、Triage、Pressure Botany、Payload Witness も同じように、信号、経路、製造、医療遅延、食料生存、Deep Reach が名づけたくなかったものを担う。この表は、悲しみをプレイヤーが触れられるシステムにつなぎ留める。

## Scanner

クルーは背景設定である前に動詞だ。汲む、封じる、中継する、測る、鍛える、選別する、育てる、証言する。

## Terminal

CREW FAMILIES: Pump、Seal、Relay、Brine Map、Vent Forge、Triage、Pressure Botany、Payload Witness。すべての作業員IDは、個人情報の前にクルー系統へ結びつく。これにより証拠は機械、ルート、圧力障害、食料文化、サルベージ法、最終 payload 連鎖に結びついたままになる。

## Audio

仕事が先。記憶は後。それが紙の上でコロニーを生き残らせる方法だ。

## Field Note

その人が知っていた仕事を部屋がまだ必要としている時、死んだ作業員はより明瞭に読める。
