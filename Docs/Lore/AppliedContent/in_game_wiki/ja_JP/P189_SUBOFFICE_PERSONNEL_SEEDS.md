# 下位オフィス人員シード

下位オフィス人員シードは、Deep Reach に人間の書類層を与えるが、会社をきれいなボス表に変えない。これらの名前は新しい支配集団を作るためにあるのではない。署名、ドアログ、メモ断片を、優先度を失っていく警報の中で午前三時に誰かが触れたものとして感じさせるためにある。リスク受付のクラークは潮汐余裕を誤って分類できる。避難法務は解放を保留できる。パケット公証人は、なぜ部屋が浸水しているのかを問わず証人ハッシュを認証できる。システムはどの労働者より大きいままだが、証拠には指紋がつく。

## Scanner
