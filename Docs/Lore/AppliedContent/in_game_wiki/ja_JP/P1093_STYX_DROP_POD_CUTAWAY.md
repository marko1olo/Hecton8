# Styx降下ポッド断面

Styxポッドはシャトルではなく、使い捨ての耐圧殻である。Black Keelから合法作業地へ、保険質量を最小にしてスーツ作業員一人を運ぶために作られた。大気、嵐の剪断、水面衝突を越え、避難場所、弱い電力、端末、証拠物を残せるだけの強度を持つ。

故障は具体的だ。耐熱タイル消耗、uplinkマスト剪断、圧縮機浸水、回収スリーブno-lock、回収閾値未満のclaim handshake。ポッドは作業員を生かし、配送と救助が別の契約事象だと証明した。
