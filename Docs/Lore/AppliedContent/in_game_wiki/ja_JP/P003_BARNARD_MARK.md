# Barnardの印

HECTON-8で最初に見つかるBarnardの印は、見逃せるほど小さい。工具刻印、ロッカー札、補給の癖、安いヤード鋼の傷跡。だから重要だ。見慣れた作業痕が、避難保留、作業員名、失敗したルート許可の横に現れ始めると、この月は遠い契約ではなくなる。
