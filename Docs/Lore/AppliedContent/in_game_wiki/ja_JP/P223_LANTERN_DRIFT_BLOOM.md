# ランタン漂流ブルーム

ランタン漂流ブルームは、フォティックシェルフで起きるプランクトンの視界イベントである。ランプが見つける前に、流線、浮遊デブリ、ケーブル弧、歯のある小さな危険を描き出す。そのため航法には役立つが、これは安心の照明ではない。攪乱された細胞は脈打ち、振動を食物網へ渡す。カッター、ポンプ、pinger、雑なスラスター操作は、プレイヤーの背後に明るい音響の痕跡を残す。光はコントラストも平らにし、小さな棘や壊れたシェルクランプを美しすぎる水の中に隠す。bloom は経路判断として扱え。輪郭が必要なら一緒に漂い、静けさが必要なら横切り、同行者が欲しくないなら中央で大きな作業をするな。

視界イベント: bloom は輪郭読みと流れの追跡を改善するが、隠密性を下げる。カッター、ポンプ、pinger、スラスター、船体衝撃による攪乱は、フィルター摂食者、グレイザー、浅瀬の捕食者を発光航跡へ引き寄せうる。
