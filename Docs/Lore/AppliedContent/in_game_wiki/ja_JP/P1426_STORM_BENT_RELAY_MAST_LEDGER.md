# 嵐曲がりリレーマスト台帳

HECTON-8で最初に役立つアンテナは、たいてい哀れに見える。嵐で曲がったマスト、塩づいたヒンジ、割れたセラミック、間違ったテープで巻かれたケーブル外皮、それでもAegirを指す方向印。誰かが嵐のたびに締め直していたからだ。だから重要なのだ。英雄的な技術ではない。空の向きを忘れていない疲れたインフラだ。

マストを直すとゲームは変わるが、遭難者が望むほど単純ではない。よりきれいなuplinkはpacket信頼度を上げ、壊れたhandshakeを戻し、Black Keelにオペレーターが生存していると認めさせるかもしれない。同時にcarrierは救助らしい言葉の前に、claim state、sample state、座標、証拠を要求することもある。マストは文章を良くする。聞き手を良くするわけではない。

これが軌道サバイバルの最初の教訓だ。通信は回収ではない。よい支柱、清掃した接点、修正された方位は、嵐帯がリレーを覆う前に一つのpacketを買う。プレイヤーはそのpacketに何を乗せるか選ばなければならない。医療状態、証拠hash、試料テレメトリ、位置、あるいは嘘。Black Keelはそれぞれを違うものとして聞く。マストが保証するのは、議論が海を離れることだけだ。
