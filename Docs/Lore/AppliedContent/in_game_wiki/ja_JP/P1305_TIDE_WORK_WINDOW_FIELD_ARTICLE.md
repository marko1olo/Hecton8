# 潮汐作業窓フィールド記事

HECTON-8 の海には勤務時間がある。冗談のように聞こえるが、ハッチが均圧を拒み、傾いた塩水層でピンガーが死に、十分前には開いていた経路が粉砕機に変われば笑えない。潮汐位相はこの月の背景天候ではない。扉の荷重、シルト量、音響距離、塩水層の漂流、スーツのバラスト、ポンプ負荷、そして Aegir ノイズ越しにキャリアが聞けるわずかな角度を変える。

Deep Reach はそれらを丁寧な言葉に圧縮した。窓。静水窓、ポンプ窓、揚収窓、中継窓、通信断窓。言葉は効率的で、毒がある。物理的な猶予を予定表の枠のように聞かせ、戻らない作業員を遅延処理のように見せる。板の上では、名前がグリースペンの一線で許可から遅延、保留へ滑る。

Marauder は窓を現場文法として読む。ハッチ縁の白い弧は荷重方向を示す。ピンガー間隔は経路が悪くなる前に伸びる。塩水の幕は底流が変わる前に傾く。静かな中継器はいつも故障ではない。月が間違った影に入り、法的キューだけが声なしで進んでいる場合もある。

Great Tide はおとぎ話の波ではなかった。交渉できるものとして扱われた作業窓が積み重なった最後の結果だった。負荷の中へ遅らされた避難、閉じた排水に逆らう熱排出、退避より上に置かれた Atlas 継続性、そして物理がもう守らない予定表の中に残された作業員たち。
