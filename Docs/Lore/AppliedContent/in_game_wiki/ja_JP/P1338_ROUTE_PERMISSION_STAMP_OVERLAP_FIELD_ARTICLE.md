# 経路許可スタンプの重なり

経路許可スタンプは飾りではない。作業者、ハッチ、作業系統、アクセス等級、時間枠、予定帰還印を結ぶ、コロニーの移動許可だった。転写媒体にそのスタンプが残るなら、誰かが記録を私的なものに見せる前に、媒体が経路デスクを通ったことを示す。

重要なのは重なりだ。きれいなスタンプだけなら、ただの事務痕跡で終わる。packet notaryマスクの下に一部埋まったスタンプは別物だ。経路デスクのインク、部屋由来の塩、黒塗りの顔料が別々の層で交差する。スタンプがマスクの下で、ハッチ塩の上なら、許可は曝露後、編集前に記録された。転写は現場でただ壊れたのではない。回収され、経路に載せられ、押印され、それから選んで覆われた。

帰還印も見る。通常の経路は帰還印、取消線、回収例外のどれかで閉じる。遅いマスクの横に帰還印がないなら、その紙は移動記録から請求文書に変わっている。Deep Reachはなお承認だと言えるが、重なりは承認の種類を示す。部屋に入る許可ではなく、部屋から出た証拠を処理する許可だ。

現場では単純に扱う。スタンプを切らない。マスク縁とスタンプ縁を同じフレームで撮る。ハッチ塗装、スーツタグ、トリアージ台帳、転写損傷帯と照合する。問題は誰がアクセスできたかだけではない。誰がその媒体を机上に置き、行を覆うだけの時間を持っていたかだ。
