# 圧力職務名テーブル

職務名テーブルはコロニーの労働骨格である。作業員の証拠を汎用的な悲劇にせず、各人をポンプ、シール、リレー、medlock、ファブリケータ、経路板、vent-kiln、Atlas 安全コンソールへ結びつける。

職名は物理証拠を期待させるべきだ。シールリガーならガスケットのチョーク、クランプ痕、ハッチログ。brine ダイバーなら密度メモ、重り付きラインの切断、スーツ洗浄染み。リレー管理者ならタイミング票とアクセス拒否。medlock 補助員なら、ステーションが回復より人員維持を選んだことを示す書式が残る。

JOB BOARD // 職名は人事用の飾りではない。作業員が応答しなくなった時、どのシステムが失敗したかを示す。
