# ルート許可スタンプセット

ルート許可スタンプセットは、移動に視覚言語を与える。PUMP、SEAL、RELAY、BRINE、FORGE、TRIAGE、BOTANY、WITNESS スタンプは階級章ではない。これは圧力許可だ。コロニーが壊れつつあった時、誰がハッチを越え、スーツを請求し、crawler を解放し、保守ロックへ入れたかを示す。スタンプは常に物理状態と組み合わせるべきだ。開放、封鎖、拒否、上書き、浸水、または後のマローダー修正。これによりプレイヤーは、説明役なしでコロニーの移動を再構築できる。

## Scanner

ルートスタンプは日記の一文より強い。誰が圧力境界を通る許可を持っていたかを証明するからだ。

## Terminal

STAMP RULE: ルート許可は、一人の作業員、一つの扉または車両、一つのクルー系統、一つの後の矛盾を結ぶ必要がある。物理境界のないスタンプは装飾だ。ハッチ、スーツラック、crawler レール、リフトタグ上のスタンプは移動証拠になる。

## Audio

アクセスとは圧力下の伝記だ。

## Field Note

スタンプ: PUMP, SEAL, RELAY, BRINE, FORGE, TRIAGE, BOTANY, WITNESS。ハッチ状態と作業物に組み合わせる。
