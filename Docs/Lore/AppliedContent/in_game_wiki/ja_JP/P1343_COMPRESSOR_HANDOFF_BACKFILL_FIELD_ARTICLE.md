# コンプレッサー引き渡しの後追い記入

コンプレッサーの引き渡し行は、機械としての空気移動と部屋の台帳の間に置かれる。コンプレッサーは圧力を動かす。リレーは供給状態が変わると刻む。ポンプカウンターはサイクルを数える。逆止弁は、片側の系統がもう片側へ塩水を引き戻すのを止める。この四つが揃っていれば、引き渡し行は退屈な記録だ。部屋が負荷を次の勘定へ渡したというだけでいい。

後追い記入の問題は、機械が荒れた後も行だけが滑らかに残るところから始まる。水没したコンプレッサーは、事務員の文章のようには故障しない。失速し、リレーの間隔で咳き込み、逆止弁の片側だけに塩を残し、きれいなサイクルを数えなくなる。後の机上行は、それでも完成して見えることがある。transfer accepted、compressor handoff pending、support load carried forward。どの文言も、止まったポンプに空気を通さない。

このパケットは、酸素台帳の遮断、スーツ予備デルタ、スクラバー番号不一致の後で読むものだ。台帳は部屋の限界を示す。スーツは身体に残った数を示す。スクラバーの銘板は空気列にいたカートリッジを示す。コンプレッサー引き渡しは、その負荷を部屋が本当に先へ押したかを示す。ポンプカウンターが先に死に、引き渡し行が後で来たなら、鎖は機械から離れて管理言語へ入った。

現場ではコンプレッサーの汚さを残す。清掃前にカウンター面を撮る。リレー刻みの位置、逆止弁の塩輪、ドレンカップ内部の塩水染み、転送を主張するhandoff行を記録する。機械側の印と合わない滑らかな行を受け入れない。その行は、誰が責任を先へ運んだかを説明できる。部屋をもう一度呼吸させることはできない。
