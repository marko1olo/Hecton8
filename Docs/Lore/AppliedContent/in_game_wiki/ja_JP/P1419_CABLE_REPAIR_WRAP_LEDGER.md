# ケーブル外装補修巻き台帳

HECTON-8のケーブルは背景の紐ではない。圧力ケーブルは二つの場所がまだ互いを必要としていた証拠だ。電力、信号、ポンプ制御、センサー、ハッチ駆動、非常灯。外装が傷むと、補修巻きはその接続を死なせまいとした人間の短い履歴になる。

跡の順序が重要だ。縁の下に塩を含む灰色テープは古い修理。きれいなゴムに強いクランプ跡があれば後日の介入だ。浅い傷の下に斜め繊維が見えれば最近引きずった。片側だけの摩耗は、保管ではなく張力下で働いた線を示す。

プレイヤーは補修ケーブルを経路証拠として扱える。動くポンプ、隠れ端末、まだ電気のあるハッチ、残留電流の罠、または生かそうとした死室へ導く。すべて切るのは早い。最後に巻かれた線を読むのが、コロニーが最後まで気にしたものを探す方法だ。

## Scanner

補修巻き // 黒いゴム外装、灰色テープ帯、斜めの繊維下地、継ぎ目の塩、クランプ圧痕。片側だけ強く擦れている。保管ではなく通電中に引きずられた線だ。

## Terminal

ケーブル読取 // 切る前に補修帯を数える。縁の下に塩がある幅広テープは古い。塩のない強いクランプ跡は遅い介入。きれいな傷の下に繊維が見えるなら最近の摩耗。高く結ばれ低く擦れた線は、部屋が動く間も荷重を持った。

## Audio

死んだケーブルは簡単だ。補修されたケーブルは、誰かがまだ向こう側を必要としていた印だ。

## Field Note

一番新しい巻きを最初に切るな。最後に救ったものを指していることが多い。
