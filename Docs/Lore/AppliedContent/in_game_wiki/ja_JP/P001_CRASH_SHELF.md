# 墜落棚

バシー・ドロップは降下用の道具であって、救助艇ではない。Aegirの気象へ突入し、HECTON-8の海へ叩き込まれ、熱を捨て、最初のシェルターが動くまで作業員一人を呼吸させるために造られた。衝突は上昇パッケージを奪った。残った殻は粗く、うるさく、価値がある。耐圧フレーム、セラミック片、バッテリーのリブ、乾いた空洞、半死のアップリンク。周囲の棚は穏やかに見えるほど明るいが、役に立つ物はすべて証拠でもある。Black Keelは生きた請求対象がいることを知っている。その請求にどれだけの価値があるかは、まだ決めていない。

## Scanner

バシー・ドロップの残骸。耐圧フレームは無事。上昇パッケージは失われた。殻は圧力と熱を保てる。あなたを持ち上げることはできない。

## Terminal

BATHY-DROP BD-K8-113: 衝突を生存。上昇パッケージ: 喪失。アップリンク・コア: 破断。BLACK KEEL: ハンドシェイクのみ。

## Audio

Black Keelのハンドシェイクを受信。オペレーター生存。回収権限は未解決。シェルターを維持し、使用可能な窓を待て。

## Field Note

ドロップ殻を骨組みだけにするな。HECTON-8で最初の基地とは、雨を外に、圧力を中に、工具を乾いたままにしてくれるものだ。
