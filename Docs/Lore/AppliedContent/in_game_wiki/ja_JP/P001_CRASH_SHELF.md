# 墜落棚

降下カプセルは一つの乱暴な仕事のために作られた。大気に入り、嵐の剪断を耐え、海へ落ち、熱を捨て、作業開始まで一人のオペレーターを生かす。それは船ではない。物理法則への使い捨ての反論だった。Black KeelはAegir圏のどこか、月の上方にいるが、カプセルの通信コアは割れ、上昇機構は失われている。救助には電力、タイミング、軌道窓、そして天候と水とAegirの磁気ノイズを抜ける送信機が必要だ。

## Scanner

降下カプセルの残骸。耐圧フレームは無事だが、上昇パッケージは破壊されている。生き延びる場所にはなるが、帰る船にはならない。

## Terminal

上昇パッケージ: 消失。通信コア: 亀裂検出。キャリア接触: 遅延。

## Audio

Black Keelのハンドシェイクを受信。パケット完全性は回収しきい値未満。繰り返す、しきい値未達。

## Field Note

殻がまだ圧を保っているなら、全部はぎ取るな。粗末な避難所は、きれいな在庫より価値がある。
