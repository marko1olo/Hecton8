# 濡れた滑り止め作業床台帳

HECTON-8の作業床はただの床ではない。滑り止めの山は通常作業では足を止め、崩壊後は記録係になった。塩は山の上に残り、油は溝に沈み、黄塗装は工具やボンベを持って曲がった場所で半月に消える。錆は誰も通らなくなった継ぎ目に残る。

プレイヤーは部屋に入る前に床を読める。暗い板を横切る明るい線は浸水後の反復通行だ。ハッチ横のきれいな半円は、そこで何度も旋回した証拠になる。下り方向の油筋は漏れの道筋で、ただの汚れではない。継ぎ目を横切る錆が削れていれば、後日の通行や解体があった。

この床は標識にならずに役に立つ。安全な廊下、引きずられた荷物、滑る足場、避難記録の後に動いたエアロックを示す。良い床は説明しない。プレイヤーに判断できるだけの物理を渡す。

## Scanner

作業床 // 暗い滑り止め金属、削れた白と黄の塗装、山の上の塩擦れ、溝の油じみ。錆は継ぎ目に残る。通行線はエアロックへ曲がる。

## Terminal
