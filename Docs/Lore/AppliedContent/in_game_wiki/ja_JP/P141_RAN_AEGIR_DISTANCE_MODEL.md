# Ran-Aegir距離モデル

Ran-Aegirモデルは、HECTON-8の尺度をスーツの中で感じられるものにする。Aegirは2190年までに探査機、貨物、航路法、債務付き入植、企業の欲望が届くほど近い。それでも、浸水した区画が内圏の善意を待てるほど近くはない。距離はリレー遅延、発進窓、制動推進剤、輸送者の管理、保険除外、そして質量は命令より遅く届くという事実で圧力になる。

## Scanner

航路プレートは、Aegirがインフラの射程内であり、緊急救助の射程内ではないことを示す。

## Terminal

航路モデル: Ran/AegirはSolから十光年級の目的地として扱われる。公開面ではAegir、乾いた航法カタログではRAN-B:H8を使う。精密暦は表で封鎖される。運用上の真実は遅延、制動質量、リレー管理、所有権リスクである。

## Audio

信号は闇を渡れる。船はその全距離を支払わなければならない。

## Field Note

十光年はカタログでは小さく、救助には残酷な距離だ。
