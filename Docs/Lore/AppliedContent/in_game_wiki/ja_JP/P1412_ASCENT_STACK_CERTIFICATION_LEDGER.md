# 上昇スタック認証台帳

上昇スタックは、脱出が祈りではなく工学に見え始める最初の部品だ。魔法の救助ポッドでも英雄的ロケットでもない。醜い約束を積んだものだ。身体は密閉されたまま、チャージは船体を割らず、誘導pingは聞こえ、温度ジャンプはスリーブを割らず、上では誰かがその結果を受け取ることに同意している。

HECTON-8は悪い上昇を罰する。浅い発射は自分の航跡に溺れることがある。深い発射では、キャリアが見る前にシール欠陥が刃の線になる。圧力はチャンネルが開いているかどうかを気にしない。海が問うのは、クランプリングが座ったか、上昇燃焼が計測されたか、誘導クレードルが行き先を言えるほど腐食に耐えたかだけだ。

認証によってsalvageは進捗になる。Marauderは植民地ハードからリング対を組み、見つけたチャージ質量で燃焼カートリッジを詰め、拾ったコイルで古いpingerを起こせる。それでも十分ではない。スタックは来歴を証明しなければならない。シールの出所、耐えた圧力痕、誰がチャージを測ったか、どのrelayがpingを聞くか、receiver tagが隔離ハンドシェイクと一致するか。Black Keelは美しさを求めない。保険にかけられることを求める。

台帳は曖昧な希望をルートチェックリストに変える。シール。チャージ。ping。衝撃余裕。受領者。各語はプレイヤーが探し、修理し、盗み、証明できる場所を指す。証明が完成するとclaim windowの形が変わる。それはまだ優しさではない。生きた身体が有効な質量予約になったと機械が認めるだけだ。
