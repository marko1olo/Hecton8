# Marauder修正マーク

Marauder修正マークは、公式ラベルの上書きではなく、その横に残される小さな現場注記である。油性鉛筆、刻まれた矢印、テープ片、ワッシャー周りの傷、結び目コード、サルベージチョーク、ガスケットの切り込み、スキャンパケットの短い音声タグなどの形を取る。よいマークはMarauderが全て正しいことを示さない。訓練されたclaim作業者がラベルを疑い、次の者が物体を読めるようにしたことを示す。

公式文は見えるまま残す。これも証拠だからだ。Deep Reachがrelease pendingと書いたなら、その語句は閉ざされた医療ドアを一時的な問題に見せようとした者を示す。Keelmarkがpayout exposureと書いたなら、部屋のどの部分が金額に変えられていたかを示す。Marauderの修正は嘘の横に置くべきであり、よりきれいな反対の嘘で置き換えてはいけない。

最良のマークは不格好で正確だ。ドア保持、半分の名前、救助前に空気請求、帰還印なし、翻訳が滑らかすぎる、body chainここで切断。これは宣言文ではない。悪い光と悪い酸素の中で読む誰かのための作業メモだ。マークは、プレイヤーの物体、経路リスク、保管連鎖の読み方を変えなければならない。態度だけを足すなら、それは落書きだ。

修正はclaimを汚すこともある。Marauderは記録の嘘に気づくために支払われるが、それでも支払われている。マークは名前を保存し、経路を警告し、標本に値をつけ、証人を隠し、次の回収者を利益の出る失敗へ押すこともある。蝶番、水位線、傷の方向、出所印と一緒に読め。修正は最終真実ではない。公式文が早すぎる終止符を打つことへの拒否である。
