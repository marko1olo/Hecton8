# Aegir Sky Window Machine

Aegir の見える空は route machinery であり、背景ではない。月影は relay confidence を壊し、嵐は body を守りながら upload を殺し、きれいな carrier line でも radiation、tide、quarantine、mass checks に失敗することがある。sky window は積み重なった gate として読む。packet、body、proof、salvage が同じ pass を共有するとは限らない。
