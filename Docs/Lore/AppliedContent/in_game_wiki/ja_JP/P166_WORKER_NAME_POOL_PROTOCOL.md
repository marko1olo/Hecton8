# 作業員名簿記録

HECTON-8 の作業員名は、小さな証拠の鎖である。どのドメインがその体を海へ送り、どの仕事がその体を有用にし、どの経路へ合法的に入れたのか、そしてどのバッジ片がロッカーやマニフェストクリップやシフト板に残ったのかを示す。

名前プールは、リプレイ時の施設を人のいた場所に感じさせるためにある。canon を書き換えるためではない。ポンプ技師がある seed ではガスケット台帳の横に、別の seed では medlock 拒否票の横に現れても、Great Tide、Deep Reach の責任、ステーションの地理は変わらない。変わるのは発見順であり、罪ではない。

良い名前は地に足がついている。冗談でも収集品でも安い悲劇のフックでもない。賃金、圧力手当、食事クレジット、次のシフトを待っていた人間に聞こえるべきだ。Marauder が工具を取る前に名前を読む時、その部屋は一瞬コンテナではなく職場になる。

## Scanner
