# 近光速船級

近光速船は物理を破らず人類圏を作った。失ってよい安価な探査機が先に着き、次にシード船、そして工場、睡眠者、契約、遮蔽を運ぶAtlas級貨物船が来た。

船級表は所有と救助を分ける。Aegirは人類法で請求されても、身体を運んで届くには遠い。

## Scanner

輸送マニフェストにニードルプローブ、シード船、Atlas貨物船、睡眠者輸送、系内テンダー、請求プール船を記載。

## Terminal

輸送級表 // FTL航路登録なし。全級に発射インフラ、遮蔽質量、制動計画、経路保管、債務権限が必要。恒星間所有は現地救助能力を意味しない。

## Audio

星を渡れる船でも、浸水した部屋には役に立たないことがある。

## Field Note

船は自由ではない。エンジン付きの予定表だ。
