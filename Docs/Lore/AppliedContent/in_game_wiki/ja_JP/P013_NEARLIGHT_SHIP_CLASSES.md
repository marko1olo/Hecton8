# 近光速船級

近光速船は、物理法則が魅了されないことを受け入れて人類圏を作った。needleprobeが先に行ったのは、細く、守られ、失ってもよいほど安かったからだ。seed shipは機械、ゲノム、航路指示、冷たいステージングを何年も耐える建設習慣を運んだ。Atlas級貨物船は高価な質量を動かした。工場中核、sleeperベイ、シールド氷、放熱器、掘削系、乗員が目覚める時にはすでに古い契約だ。

船級が重要なのは、失敗の仕方が違うからだ。probeは役に立って死ねる。seed shipは証人なしで到着できる。sleeper輸送は身体を保存し、労働を保管へ変える。system tenderはAegir内で働けても中核空間から命令一つで来られない。Black Keelはエンジン付き自由ではない。質量、検疫、保険、証拠を同じ台帳に数える回収機械だ。

どの級も光を破らない。ビーム帆、ペレットレーン、fusion-electric喉、シールド氷、magsail、受信窓は旅を可能にするだけで、気軽にはしない。到着は残酷な半分だ。制動の所有者がいなければ、有用な質量としては何も到着しない。
