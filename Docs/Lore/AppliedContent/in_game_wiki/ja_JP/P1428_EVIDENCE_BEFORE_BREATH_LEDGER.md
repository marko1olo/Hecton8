# 呼吸より先に届く証拠台帳

distress hashはプレイヤーより先にHECTON-8を離れられる。証拠は小さく作られているからだ。checksum、custody、witness time、そして何が存在したかについての狭い主張。relay windowを分割して通過できる。保存、値付け、異議、複写ができ、誰かに温めてもらう必要がない。

人間はその種類のpayloadではない。呼吸する身体には温度、圧力、医療、汚染処理、route authority、法的custody、そして停止を所有するreceiverが必要だ。航路は君の証拠を受け入れても、君の質量を拒める。HECTON-8では矛盾ではない。人間を部品ごとに値付けできる制度の残酷さだ。

だから最初の返信パケットは救助に聞こえてはいけない。Black Keelはhashを認める。brokerはsampleを順位づける。return deskは座標、substrate、proof integrityを求める。その間にも空気計は進む。プレイヤーは文明に気づかせようとしているのではない。文明はもう気づいている。仕事は、生きた身体を、それが生んだデータより無視しにくくすることだ。
