# ケーブル礁共生

ケーブル礁は中深度の警告だ。底の工場ではないが、生命が産業を骨、影、流れ止め、栄養線として扱う証拠だ。

## Scanner

植物相が電力幹線と信号線に育つ。礁はコロニー配線を骨格として使っている。

## Terminal
