# ケーブル礁共生

ケーブル礁は、中層のサービス溝が生きた成長に安定した形を与える場所で形成される。電力幹線、リレー対、クランプリング、古いケーブルトレイだ。一部のマットは摩耗を減らし、線路周辺の流れを落ち着かせる。一部の摂食生物は露出導体からぬめりを取る。同じスリーブが割れた絶縁を隠し、熱を閉じ込め、プレイヤーが静かだと思ったルートへドローン交通を呼ぶこともある。

スキャンが否定するまで、ケーブル礁は稼働中のインフラとして扱う。緑のスリーブはリレーを乾いたまま保つ唯一のものかもしれないし、負荷で落ちる故障を覆っているだけかもしれない。切断前に信号連続性、絶縁材の色、クランプ順序、ドローンの動きを確認する。これは最初の修復痕と後の修復動物をつなぐ橋だ。Atlasが生体に修復を通す前に、生きた成長が電流を追う。

## Scanner

ケーブル根マットがP63電力幹線を3つのクランプリングでつかんでいる。信号は緑のスリーブ下をまだ通過。下縁に絶縁不良あり。危険: ドローンと摂食生物の往来が活電流を追跡。
