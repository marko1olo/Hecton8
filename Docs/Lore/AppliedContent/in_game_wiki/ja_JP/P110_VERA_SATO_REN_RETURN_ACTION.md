# ヴェラ・サトウ＝レンの返還行動

ヴェラ・サトウ＝レンは2190年のRecovery Compliance Office署名者であり、現在のDeep Reachに顔を与えるが、物理的にどこにでもいる存在にはしない。彼女はパケット、管理窓、輸送体条項、遅延指示を通じて行動する。圧力は手続き的だ。座標を回収する。XO連鎖を証明する。Atlasアクセス状態を報告する。ペイロードがまだ制御可能なら契約者の沈黙を保つ。

返還行動の言葉が危険なのは、助けのように聞こえるからだ。救助は可能なままだが、ペイロード管理の後でのみ。支援は提示されるかもしれないが、証拠露出が管理可能な間だけだ。パケットを読むMarauderは、悪役に怒鳴られているわけではない。答えても答えなくても閉じる窓に測られている。

プレイヤーにとって、サトウ＝レンはDeep Reachを歴史的責任から現在の圧力へ変える。古いコロニーは墓だけではない。アクティブな請求現場だ。回収された記録は、誰が先に受け取るかによって、証拠、身代金、沈黙条項、交渉材料になる。現代のDeep Reachの脅威は、きれいな敵艦隊ではない。真実が水から出る前に返還を所有しようとする、法的圧力セルである。
