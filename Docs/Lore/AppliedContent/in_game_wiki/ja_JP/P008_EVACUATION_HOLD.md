# 退避保留

退避保留記録は、植民地の最も直接的な告発だ。災害が圧力障害、嵐の時刻、またはパニックだけではなかったことを示している。人々がまだ中にいる間に、経路は評価され、遅延され、再分類された。医療搬送は承認を待った。上昇廊下は基質保護に優先度を奪われた。Atlas連続性の請求は、現地救助権限より上に置かれた。人員数は経路オブジェクトに添付され、システムは中の身体が空気を使い果たす間、紙の上で廊下を保存できた。保留に各扉の悪人は不要だった。人を貨物と呼び、廊下を資産と呼び、次のレビュー周期までの遅延を許容と呼べる規則が必要だった。

## Scanner

緊急輸送ゲート。圧力障害中にロック爪が閉鎖状態で融着。手動ホイールは承認保留後に撤去された。
