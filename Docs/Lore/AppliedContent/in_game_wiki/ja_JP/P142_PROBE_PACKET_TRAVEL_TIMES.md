# 探査パケット航行時間

探査パケットの時間が、Deep Reachが人を守れる前にHECTON-8の価値を知れた理由だ。最初の記録は狭く、到着時には古く、すでに金融化されていた。パケットは、人間の計画がまだ推測でも、請求を成熟して見せることができる。
