# ハッシュベルト軌道沈黙図

マローダーはこの重なりをハッシュベルトと呼ぶ。地図上の場所ではない。Aegirが帯域を磁気ノイズで満たし、Kestrelが見通し線を切り、HECTON-8の鉱物海洋が電磁信号を食い、Black Keelが保管タグ付きの音響パケットだけを受ける時間帯のことだ。

だから空の連絡先は存在していても役に立たない。船は嵐を知っているかもしれない。リレーブイの応答も知っているかもしれない。サルベージ目録の受領だけなら返すかもしれない。それでも人間の通信士が聞いたとは限らない。上層水より下では、通信は圧力、塩、ブイ、契約フィルターを通る遅い法的物体になる。遭難信号は叫びではない。信じてもらう許可を求めるパケットだ。

## Scanner

ハッシュベルト図 // Black Keelの返信窓が劣化。Aegirの磁気ノイズ、Kestrelの掩蔽、鉱物海洋での減衰、リレー保管権が重なっている。軌道は嵐の上面を見る。あなたは見えない。

## Terminal

軌道沈黙通知 // 無線は上層水で死ぬ。レーザー線は噴出氷、嵐雲、Ranの眩光で途切れる。音響パケットは遅いブイと所有権フィルターを通って上がる。沈黙は状態であり、不在の証明ではない。

## Audio

軌道が頭上にあっても届かないことはある。鍵は距離ではなく、時刻と水と保管権だ。

## Field Note

Black Keelの返事が遅いなら、慈悲だと思うな。会計があなたのパケットを見つけただけだ。
