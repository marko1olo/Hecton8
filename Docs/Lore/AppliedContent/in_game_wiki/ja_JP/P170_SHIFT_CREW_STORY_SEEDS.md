# シフトクルー・ストーリー seed

シフトクルー seed は、HECTON-8 にリプレイの質感を与えつつ矛盾機械にしないための層である。同じコロニーが別の作業員ペア、別のロッカー順、別の欄外注記を示しても、Deep Reach が無罪になることも Great Tide の理由が変わることもない。

変化は局所的である。経路事務員がある run では brine ダイバーと結びつき、別の run ではシールリガーと結びつく。拒否票の位置も変えられる。これらはプレイヤーの証明の組み立て方を変えるが、証明そのものは変えない。

## Scanner

SHIFT SEED // 名簿は変わってよい。罪は変わらない。

## Terminal

SHIFT CREW SEEDS // run ごとに名簿順、作業員ペア、ロッカー内容、拒否票、経路チョーク、バッジ片、後の Marauder 修正を変えられる。seed が変えてよいのは証拠との出会い方であり、証拠が証明する内容ではない。

## Audio

別のロッカーは同じ真実を別の側から切り込む。

## Field Note

seed の多様性は物の順序、仕事の組み合わせ、Marauder 注記を変える。Great Tide や Deep Reach の責任は変えない。
