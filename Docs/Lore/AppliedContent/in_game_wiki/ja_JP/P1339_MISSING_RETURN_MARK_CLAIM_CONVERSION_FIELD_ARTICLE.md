# 欠落した帰還印と請求変換

帰還印は経路を閉じた。作業者の安全を証明する印ではなく、経路デスクがその作業者を移動中として数えるのをやめた印だった。帰還チェック、取消線、医療移送、回収例外、損失コードのいずれかが必要だった。それがなければ、経路は事務上開いたまま残る。

開いた経路は危険な証拠になる。Deep Reachはそこを指して、作業者はまだ割当中、まだ到達可能、まだ作戦中だと言える。部屋は別のことを示せる。冷えたスーツタグ、切れたテザー、酸素停止を持つトリアージ行、時間窓後のハッチ擦過が、空欄の帰還欄を保管経路の失敗に変える。

請求変換は、後のデスクが開いた経路で媒体を再分類した時に起きる。転写は遭難記録ではなく、回収可能質量、汚染装備、請求可能遅延、サルベージ財産になる。欠落した帰還印は死を解くものではない。紙がその死を閉じなかった場所を示す。

現場では塩を落とす前にスタンプを保全する。開いた経路を酸素停止、スーツタグ、トリアージ行、packet notaryマスクと照合する。身体の証拠が閉じているのに経路だけが開いたままなら、デスクが守ったのは作業者ではなく請求だ。
