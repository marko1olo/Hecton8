# 開始claimバリアント

開始claimとは、作業命令の一番上に書かれた嘘だ。債務salvage、証拠賞金、失われた航路機材、危険試料の保管、ブラックリスト緩和。各バリアントは、なぜ掲示板がMarauderを水中へ下ろすのかを変える。動機と最初の圧力に色を付けるべきで、主人公を別の仮面に置き換えてはいけない。
