# 耐圧寝台の勤務手順

圧力寝台は、地表の古い意味での寝室ではない。借りた暖かさ、拘束ウェビング、ポンプが機嫌よく動く日の乾いたフォーム、そして作業者が圧力から戻ったことを示す小さな証明鎖だ。C-12 スレートは起床トーン 03:40、スーツシール確認、圧力メモ、食事水トークン、工具保管、下降割当を記録する。朝日はこのモジュールに届かなかった。朝の役目はポンプトーンが果たした。

手順は冷たく見えるが、鎖を追うと意味が変わる。シール確認の欠落は寝台主任へ届く。遅れたポンプキーは工具庫と食堂台帳へ届く。圧力メモは、悪い判断が浸水廊下になる前に作業者をルートから医療ロックへ移せる。寝台はベッドであり、住所であり、予定表であり、保管点であり、静かな警報だった。

ここでは小さな証拠が重要だ。レールに貼られた湿った靴下テープ、省略された名前、圧力メモの横に留めた食事トークン、トーン2までに返す鍵。どれも記念のために書かれたものではない。疲れた身体を次のトーンまで生かすための、普通のステーション生活だった。
