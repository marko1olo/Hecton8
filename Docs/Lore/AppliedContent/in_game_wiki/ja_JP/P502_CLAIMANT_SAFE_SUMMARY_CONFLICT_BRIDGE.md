# 請求者保護要約の不一致

請求者保護要約は中立な短縮版ではなく、保護された書換だ。名前を消し、座標を丸め、負傷詳細を分類へ置き換え、経路動詞を弱め、公開返信用の部署へ差し替えることがある。人を守る編集もあるが、Deep Reachは同じ安全語で交渉材料を埋める。要約と生の物体の不一致は継続性ミスではない。何が消え、誰が得をし、どの物体が文脈を戻せるかを示す証拠だ。
