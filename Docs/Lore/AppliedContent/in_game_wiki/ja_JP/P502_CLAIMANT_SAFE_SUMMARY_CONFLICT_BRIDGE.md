# 請求安全要約の競合

請求安全要約は短くした真実ではない。請求経路のために許可された伏せ字だ。作業員名を消し、座標をぼかし、負傷の詳細を支払い区分に置き換え、保留を待機中に変え、公開郵便に返答できる事務所だけを載せることがある。削除の一部は生存している作業員、医療情報、未完了の回収経路を守る。別の削除はDeep Reachを保管問題から守る。要約と生の物証の競合は証拠だ。切り取り自体に所有者、時刻印、受益者があるからだ。

要約は、それを強制した物証の横で読む。タグスリーブ、音声カセット、試料袋、圧力扉ログ、スーツリング、トレイ写真。省略リストを表示したままにする。何が削られたか、どの法的リスクマーカーに対応するか、誰が伏せ字を求めたか、物証が名前や座標を捏造せず文脈を戻せるかを確認する。生の物証が要約以上を示すなら、その差分を保存する。きれいな一文で埋めるな。
