# サルベージ切断断面台帳

サルベージ切断は、物質に残された議論だ。圧力船体は美しさのために切られない。道が塞がれた、壁の向こうに人がいた、ケーブルを奪う必要があった、あるいは地図が金属と一致しなくなった後も区画に価値があったから切る。

層が重要だ。塗装は元の外側を示す。暗い金属芯は荷重の道を示す。セラミック断熱は熱が制御されたかを語る。ゴムガスケットの断面は、封止が切られたのか裂かれたのかを示す。ケーブル束は、信号を守ったのか、銅を取ったのか、意図的に系統を殺したのかを語る。

マローダーにとって、問いは「持ち去れるか」だけではない。「誰が、いつ、何を失わないために切ったか」だ。公式救助の切断と飢えたブラックキールの切断は同じ縁を残さない。一方は扉を作る。もう一方はアリバイを作る。

## Scanner

切断縁 // 塗装された船体皮膜、暗い金属芯、セラミック断熱層、ゴムガスケット断面、ケーブル束、焼けたカッター線、裂け目の塩。無作為ではない。熱は外側から入り、二度止まっている。

## Terminal

断面読み // 滑らかな熱ビードは制御されたカッター。裂けたセラミックは焦りか工具の震え。金属芯の中の塩は回収前に開口が濡れていた証拠。きれいなケーブル端は浸水後の切断。

## Audio

切断縁は、故障後に誰が来て、何を壊す覚悟があったかを語る。

## Field Note

金属より先にセラミック粉を見ろ。焦りはいつも柔らかい層を先に震わせる。
