# ケーブルの森の導電性生物相

回収されたケーブルの森の試料は、サルベージ班が導電ケルプを採る前に工具を接地する理由を示している。この成長は、古い中継ジャケット、鉱物ブライン、光に飢えたマットが重なる場所で生まれる。弱い配線をつなぎ、死んだセルへ電荷を誘導し、リレーにもう一度だけ応答させることもできるが、同時に信号ゴーストを投げ、いまだにその生きた橋を経路の一部と数える修理ドローンを起こすことがある。

## Scanner

導電ケルプ // 死んだ中継ケーブルに編み込まれた生きた束。弱い電荷を蓄え、偽のピングを返し、接地してから切ればきれいな電流を渡す。

## Terminal

ケーブルの森の生態 // 静電の藪、ランタングラス、ケーブルケルプが裂けた絶縁材に住み着く。濡れた組織は通電線として扱うこと。振動を読み、損傷した経路を橋渡しし、修理ドローンにはインフラとして記録される場合がある。

## Audio

Marauderのスプール記録: ケルプが唸り返したら切るな。植物が歌っているわけじゃない。経路が圧力を覚えている。

## Field Note

良い線は震えない。震えたなら接地し、タグを付け、それでも電力が欲しいか決めろ。
