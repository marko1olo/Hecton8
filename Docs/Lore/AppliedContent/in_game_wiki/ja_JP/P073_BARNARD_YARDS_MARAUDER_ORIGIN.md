# バーナード造船場のマローダー起源

Barnard Yards は HECTON-8 のマローダーを支える現在の労働出身文化だ。工業サルベージ、船体解体、圧力機器、死んだ請求権の仕事。サルベージ労働者を地球観光客や救助神話にせず、能力の理由を与える。
