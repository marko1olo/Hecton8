# 資源スタック

HECTON-8は一資源の月ではない。初期材料は呼吸と修理を可能にする。サルベージは封じられた経路を開く。塩水と噴出口化学は圧力を教える。青い債務とpressure glassは請求連鎖の上位にあるが、その価値は小さな材料が作業者をそこまで生かすから成立する。

## Scanner

スタック読取: リーフ繊維、塩水塩、リレーコア、圧力弁、噴出口触媒、青い債務、pressure glass、Atlas格子。

## Terminal

価値モデル: 生存生物資材、人間サルベージ、経路ハード、圧力化学、青い債務、pressure glass、連続性基質。スタックを単一の奇跡素材へ縮めるな。
