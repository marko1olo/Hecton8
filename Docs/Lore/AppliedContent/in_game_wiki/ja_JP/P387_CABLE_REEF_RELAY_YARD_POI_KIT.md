# ケーブルリーフ中継ヤード証拠キット

ケーブルリーフ中継ヤードは、修理場が自分自身の故障様式まで育った場所である。導電膜、ケーブルジャケット、音響ソケットは信号を戻せるが、同じ橋はオペレーターが無走査で切れば古いサービス脚へルートを送る。

## Scanner

POI証拠キット: 中継ヤードは生きた橋膜で導通し、損傷したケーブル記憶で誤配線する。

## Terminal

中継ヤードキット: 音響スパインソケット、バイオフィルム橋、切断警告、ピンガー応答、Atlasサービス痕、剥離絶縁、リレーフォーク、死脚マップ。
