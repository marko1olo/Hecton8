# グラスグレイザー標本カード

グラスグレイザーはペットでも戦利品でも飾りでもない。透明な小型殻食動物で、pressure glass、緩いフォティックマットの縁、古いケーブル外皮、石灰岩の唇から鉱物膜を削り、フォティックシェルフを読める場所にする。摂食中の群れは成長面に淡い道を残す。その道は直近の流れ、手を掛けられる清浄面、熱すぎない継ぎ目、数分以内に捕食者が通っていない場所を示すことがある。重要なのは動きだけではない。中断だ。餌が残り、殻の ticking が止まったなら、群れは圧力変化、影の動き、cutter振動、あるいは scanner 円錐外を通る大型動物を聞いた。削り道は証拠であって許可証ではない。縁を追え。縁が内側へ畳まれたら離れろ。

## Scanner

グラスグレイザーの群れ。敵対しない殻食性の削り手。鉱物膜を食べる。規則的な殻音は作業できる水、突然の沈黙は広場を大きなものが変えた合図。
