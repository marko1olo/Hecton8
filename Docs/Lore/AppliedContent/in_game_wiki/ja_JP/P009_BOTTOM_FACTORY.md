# 海底工場

海底工場はAtlas盆地の下部リターンにある。Deep Reachの配管は今もそこでブラインと熱を動かしているが、炭酸塩のスリーブと濾過生物の成長が多くのサービス経路を塞いでいる。古い鋼材、ケーブルトレイ、圧力成長したシールが同じ保守経路を共有する継ぎ目には、blue debtの残留物が染みている。

有用さそのものが危険になる。そこは漏れを塞ぎ、ポンプを回路内に保ち、人間用に承認されていない経路で信号を運ぶ。扉はガスケットが失われても、圧力成長物が荷重を受けて閉じたままになる。ケーブルトレイは、カバーがフィルターとして働きながらデータを中継できる。スーツリング、サンプル容器、工具は、管理タグが読まれる前に埋まれば同じ補修スリーブ内に消える。淡い継ぎ目は、流れの痕跡とタグの引き出しを確認するまで、すべて稼働中のインフラとして扱うこと。

## Scanner

圧力成長した炭酸塩がサービス壁を覆っている。同じスリーブ内にブライン管、熱戻り、信号ケーブルが入っている。信頼度: 64%。危険: 淡色の殻の下の管理タグは、切断前に読めなくなる可能性がある。

## Audio
