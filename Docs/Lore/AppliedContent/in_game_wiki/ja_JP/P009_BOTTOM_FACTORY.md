# 底部工場

底部工場は、HECTON-8がインフラと居住域を分けるのをやめる地点だ。Deep Reachの機械、Atlas経路、blue debt残渣、作業員の残骸、圧力成長した膜、海洋生物学が一つの稼働体になっている。同じ組織の中で熱、流体、信号、サンプル、損傷を動かす。壁は弁になり得る。廊下は腸になり得る。ケーブルはフィルターへ咲き得る。修復には珊瑚、ドローン殻、工具鋼、骨が含まれても、システムは矛盾を見ない。危険はランダムな変異ではない。人間的カテゴリを持たない機能だ。工場は連続性を保ち、経路を保存し、漏れを閉じ、新しい圧力皮膚を育て、損失を有用な場所へ送れる材料として扱う。
