# 圧力スーツ補修パッチ台帳

圧力スーツの補修パッチは、生命維持具に残った人間の筆跡だ。工場パネルは清潔な曲線と認証で語る。現場パッチは曲がった糸、違う色の布、テープ下の塩、次の圧力周期の前に漏れを塞ぐしかなかった人間の正直さで語る。

順序が重要だ。十字縫いの下にシームテープがあるなら、最初の修理は信用されなかった。糸の下の塩は、スーツがすでに水に触れていた証拠だ。パッチ上の摩耗は着用者が仕事に戻った印だ。古い損傷上のきれいなテープは遅い検査。二色の布は、死んだスーツや再開予定のないロッカーから取った材料を示す。

マローダーにとって、パッチは衣装の飾りではない。緊急ルート、作業者の最後の任務、医療判断、盗まれたキット、または着用者に本来ない等級のスーツを示す。HECTON-8での生存は、もう一回の潜行だけ耐えた醜い縫い目に見える。
