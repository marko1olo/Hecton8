# 捕食者の影エンカウンター文法

捕食者の影の遭遇は、動物が見える前に海が占有されていると感じさせるべきだ。有用な警告連鎖は環境にある。餌が残ったままグラスグレイザーが止まり、lantern bloomが片側で薄くなり、pressureweedがうねりなしに畳まれ、sonarは瓦礫にしては広すぎる空白を返し、プレイヤーの光がきれいな輪郭にならない広い形を横切る。動物はarenaで待つbossではない。経路圧だ。酸素消費、return-line discipline、修理タイミング、scan信頼を変える。良い影の遭遇は、不在を読んだプレイヤーを生かす。音を足すな。ランプを絞れ。きれいな道を追うな。印のある水を直線で戻らず、角度をつけて離脱しろ。
