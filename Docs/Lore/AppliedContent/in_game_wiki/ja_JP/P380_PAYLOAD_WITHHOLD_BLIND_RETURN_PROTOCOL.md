# payload blind return保持プロトコル

blind returnプロトコルはすべての受領者を拒否する。企業、台帳、検疫レーン、切断対象のどれも最終payloadを受け取らない。運搬者は地図と証拠をローカルに保持し、Deep Reachのきれいな帰路を拒む。同時に、債務は有効のまま、公開証拠は未提出のまま、パケットは水、死、不良保管に弱くなる。
