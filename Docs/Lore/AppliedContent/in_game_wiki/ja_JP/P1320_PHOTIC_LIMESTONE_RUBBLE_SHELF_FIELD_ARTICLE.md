# 有光層石灰岩瓦礫棚

有光層石灰岩瓦礫棚は、乗員が視界と安全を最初に取り違える場所だ。HECTON-8の浅水では、カルシウム板がAegirで濾された光を反射し、遠くからでも底が読める。だがそれだけでは足りない。貝殻砂は小さな流れがまだ働く場所に集まる。オリーブ色の染みは保護された孔に残る。白い割れは新しい破断、古い採石、最近の回収を示す。上から滑らかに見える棚も、削られた縁や緩い瓦礫袋を隠す。

## Scanner

有光層石灰岩棚 // 淡いカルシウム板、貝殻砂、壊れた群体瓦礫片。明るい水は単純に見せる。地図は割れ目にある。流れ、採石痕、崩落縁、安全な足場は、それぞれ別の堆積物を集める。

## Terminal
