# レン・オコエ、塩水層地図師

レン・オコエはHECTON-8の塩水層を景色ではなく作業道路として地図化した。残ったスレート、染まった密度ビーズ、ピンボードの痕、圧力印付きの経路票は、水そのものを証人にして公式回廊を訂正した地図師を示す。彼の地図は、コロニーで最も安全な道がしばしば許可板の外にあった理由を説明する。塩水は承認より速く動き、工具を運ぶ人々は最新の署名より最新の測深を信じる必要があった。

## Scanner

記録: レン・オコエ。密度ビーズ、スレートの切り傷、糸ピンの痕が一晩で動いた経路を示す。

## Terminal

塩水地図卓 / OKOYE, REN: 密度反転後、安全流は東へ3.2m移動。許可板はまだ昨日の回廊を表示。次の測深まで、作業者の経路印が管理経路に優先する。

## Audio

オコエは、図面を保ちたがらない水に道を描いた。

## Field Note

オコエは塩水経路の発見、密度層ナビゲーション、許可板との矛盾に使う。彼の証拠は古い地図を疑う具体的理由を与えるべき。
