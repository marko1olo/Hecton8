# グラスグレイザー清地エンカウンター文法

グラスグレイザー清地は、期限つきの信頼を教える。生きた群れは鉱物膜に淡い削り道を開き、酸素の多いマット縁を露出させ、流れが最近きれいに動いた場所を泳ぎ手に見せる。それは寛大に感じてよい。HECTON-8には、美しさが助けになる場所が必要だ。罠は永続性である。グレイザーの回廊はsafe roomではない。そこは、まだその場で食べる意思のある動物が作った現在状態だ。殻音が対で続き、群れが縁沿いに働いているなら、レーンはscan、低騒音修理、慎重なreturn-lineの折り返しを支えられる。餌が残り、群れが凍り、内側へ畳まれ、あるいはリーフの片側へ消えたなら、清地は変わった。三十秒前に水が友好的に見えたからといってtask barを押し切るな。

## Scanner

グラスグレイザー清地。新しい削り道、酸素膜、安定した殻音は近い圧が低いことを示す。餌だけ残る空き場は警告状態。

## Terminal

遭遇文法 / グラスグレイザー清地 / 役割: 浅層の対比、読める暫定安全レーン、捕食者不在テスト / 安全な読み: 活発な摂食、対になる戻り音、削れた鉱物縁、見える離脱線 / 拒否: グレイザーを安全保証にする、静かな清地、残された餌、塞がれたreturn-line / 経路注記: その回廊が有用なのは動物が今使っているからで、海が約束したからではない。
