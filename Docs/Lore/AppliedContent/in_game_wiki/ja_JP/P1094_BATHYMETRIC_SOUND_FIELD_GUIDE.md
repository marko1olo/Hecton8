# 水深音響フィールドガイド

HECTON-8の深度は数字ではなく作業条件である。有光棚、ケーブル礁、塩水峡谷、機械野、Atlas盆地はそれぞれ浮力、信号距離、酸素作業、捕食者の隠れ場、機械挙動を変える。

鉱物水で無線が死ぬため、音が主な地平線になる。音響ダクトはpingerを何キロも運ぶ。塩水鏡は反射だけの部屋を描く。影帯は隣の信号すら消す。ソナーは判決ではなく証人として扱え。

## Scanner

音響場 // 棚下では無線死亡。帯域、ダクト、鏡、影帯を確認。きれいなping一つは証人一人でしかない。

## Terminal

水中音響メモ // HECTON-8は圧力、塩、熱で音を曲げる。切断、溶接、反応追跡の前に別角度から再pingせよ。

## Audio

HECTON-8が静かなことはない。何が鳴らし、どの層が曲げ、他に誰が聞いたかを問え。

## Field Note

一度鳴らして気づけ。二度鳴らして疑え。海が明瞭すぎる返事をする前に動け。
