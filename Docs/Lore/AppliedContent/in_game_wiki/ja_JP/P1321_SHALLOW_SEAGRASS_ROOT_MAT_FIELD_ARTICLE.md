# 浅瀬の根マット基質

浅瀬の根マットは、光、炭酸塩砂、穏やかな流れ、古い植民地流出物が重なる場所に育つ。遠くからは海草に似ているが、重要なのは葉の下だ。暗い根繊維が貝殻砂、サンゴ類似体の粉、石灰岩片を縫い合わせ、弾む皮を作る。その皮は沈殿物を支えることも、柔らかいシルトを隠すこともある。根の結び目はピンガー、工具コード、シェルクランプ、古い配管縁を捕らえる。

## Scanner

浅瀬の根マット基質 // 貝殻砂と淡い瓦礫の上に広がる海草状の有光成長。根は上層を縛るが、その下の柔らかいシルトを隠すことがある。マット端にピンガー線の絡まりを検出。

## Terminal

P-63メモ: 根マットは単なる植物ではない。棚に酸素を与え、貝殻砂を捕らえ、古いケーブルを隠し、流れの向きを示す。暗緑の結び目は探針なしに踏むな。

## Audio

マットは靴を捕まえるまで柔らかく見える。すると生きているように見える。そこに経路線が編み込まれているのを見て、誰かが何度も通ったとわかる。

## Field Note

マットが靴を捕まえるなら、他のものも捕まえている。切る前に読め。
