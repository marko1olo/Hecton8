# 天然硫化塩スタック

天然硫化塩スタックは、HECTON-8が単なる企業犯罪現場ではないことを最初に示す証拠のひとつだ。噴出孔の熱、塩水の染み出し、金属を多く含む地殻が圧力下でこすれ合う場所に育ち、棚、肋骨状の岩、脆い煙突に黒緑の塩を残す。導体を洗い、非常用セルを起こし、セラミックのフラックスを調整するが、普通の鉱石のように扱えば工具を殺す。プレイヤーにはブルー・デットより先に見せるべき資源だ。この月には、Deep Reachが請求印を押す前から固有の化学、価値、危険がある。
