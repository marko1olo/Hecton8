# 請求継続損失変換

連鎖は台帳で終わる。台帳は他のすべてを生き延びられるからだ。作業者は回収不能損失になり、損傷モジュールは物資保管になり、証拠は請求に付いたまま残る。この文書を運ぶ者は感傷を運んでいない。遺体なしで請求を欲しがるすべての受領者にとっての問題を運んでいる。

## Scanner

損失デスク印を回収。証拠保管が有効請求から離れる前に、作業者状態は回収不能へ変換される。
