# 重貨物ステージング時間

重貨物はHECTON-8を調査対象から債務対象へ変えた。大型貨物は変化する真実を追えない。準備され、担保化され、保険を掛けられ、待機し、制動され、権限ある誰かに受領されなければならない。モジュール列が航路を越えた時、その背後の契約は植民地の抗議より大きな慣性を持っていた。

## Scanner

積荷マニフェスト: 受け取り地点の生存確認より先に貨物が拘束された。

## Terminal

貨物ステージング: 圧力船殻、セラミック遮蔽、炉心質量、seed備蓄、クローラー枠、居住リングには年単位に離れた発射窓が必要である。拘束後の貨物は、移動する法的主張になる。

## Audio

出荷はすでに支払われていた。だから止めることは人を救うより難しくなった。

## Field Note

貨物は急がない。急ぎを他者に高くつける。
