# 支援負荷繰り越し例外

支援負荷繰り越し例外は、機械が仕事をやめた後も、失敗した部屋をルートへ結びつける机上の印だ。たいていは細いストリップにある。部屋コード、負荷クラス、maintenance override、carry-forward刻み、claim hold参照。平常なら会計だ。生命維持が切れた後では、蝶番になる。

そのストリップは、物として読める。サービスベイのグリースは行の前半を横切り、override stampの前で止まることがある。湿った紙を親指で押した場所ではインクが溜まる。折り返しの下に塩が残る。carry-forward刻みがグリースの切れ目よりきれいで、コンプレッサー引き渡しがすでにポンプカウンターやリレー刻みと食い違っているなら、その例外は空気を動かしていない。責任を動かした。

これは自白の行ではない。Deep Reachには不要だった。支援負荷が繰り越されたから、ルートはアクティブのままでいられる。部屋がまだ保守管理下にあるから、claimは開いたままでいられる。酸素台帳、スーツ予備、スクラバー番号がすでに別方向を示していても、失敗した作業者は請求可能または回収可能として残る。

現場ではストリップを濡れた機械部品のように扱う。平らにする前に両面を撮る。グリースの切れ目、折り目の下の塩、スタンプの重なり、正確なcarry-forward刻みを記録する。それからコンプレッサー引き渡し後追いと並べて読む。例外がポンプ停止の後に来たなら、負荷は呼吸としてではなく責任として部屋を出た。
