# ブライン階段

ブライン層は単なる危険ではない。保存し、隠し、運び、分ける。開水域では不可能な経路も、密度、熱、バラストのタイミングを読めば生存可能になる。

## Scanner

高密度ブライン層。境界でソナー反射が曲がる。浮力モデルは信頼できない。

## Terminal

熱タップ整列完了。基質成長が予測を超過。Atlas保守要求は運用側で延期。

## Audio

水を一つのもの扱いするのをやめれば、ここには階段がある。

## Field Note

船殻等級は金属が諦める時を教える。ブラインはお前の傲慢さを教える。
