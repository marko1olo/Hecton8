# ブライン階段

ブライン階段は、濃い塩水、噴出口の熱、遅い盆地流が鋭い境界として重なった場所にできる。不注意な操縦者には見えない壁だ。浮力の変化は遅れ、ソナーは曲がり、光はにじみ、降下は滑落になる。注意深い操縦者には経路になる。潜水艇は一つの層に乗り、別の層を抜け、カーテンの下に隠れ、熱上昇を使って開水域では不可能な隙間を渡れる。層は残骸と生物痕跡も残酷な忍耐で保存する。遺体、工具箱、試料カスケット、古いドローンが、何年も混ざらない同じ段に座り続けることがある。ブライン階段はHECTON-8の中心規則を教える。深度は海の構造と交渉するもので、船殻の強さだけで征服するものではない。

## Scanner

高密度ブライン層。境界でソナーが曲がる。バラスト応答が遅延。段状せん断を通って熱プルームが上昇している。

## Terminal

熱タップ整列。密度段マッピング完了。基質成長は予測超過。Atlas経路要求は運用側で延期。

## Audio

ここには階段がある。塩と熱と忍耐でできた階段だ。

## Field Note

船殻等級は金属がいつ諦めるかを教える。ブラインは、あなたが海を平面として扱った時を教える。
