# 湿った断熱ブランケット熱記憶台帳

湿った断熱ブランケットは柔らかい背景ではない。HECTON-8では、秘密を下手に隠した壁だ。熱、息、結露、圧力は布を均一に通らない。縫い目を暗くし、縫製線に塩を残し、キルトの袋を潰し、どちら側が長く生きていたかを示す。

順序が重要だ。縫い目の内側の暗い湿りは、暖かい空気がまだあった時の遅い結露を示す。その上の塩は、後で乾燥または圧力呼吸があった証拠だ。乾いた塩を含む裂け目は、布が古くなった後に開いた。腐ったキルトの上のきれいな補修テープは、修理ではなく次のシフトを買う行為だ。

マローダーにとって断熱材は避難の証拠だ。空気ポケット、隠れたサービス空洞、死にかけた機械で暖められた部屋、正規寝台に戻れず作業者が眠った廊下を示す。地味な素材だが、快適さを技術的緊急事態として覚えている。

## Scanner
