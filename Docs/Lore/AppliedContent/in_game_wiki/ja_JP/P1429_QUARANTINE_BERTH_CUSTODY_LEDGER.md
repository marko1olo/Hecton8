# 隔離バース custody 台帳

隔離バースは感傷的な意味でのベッドではない。空気、フィルター、廃棄物処理、医療ロック、custody カメラ、証拠連鎖シール、そして liability 行の名前を持つ法的な部屋だ。封鎖された海洋 claim から生存者が出る時、受信側は最初から救助された人間を受け入れるわけではない。負傷し、感染し、汚染され、負債を抱え、法的に危険で、さらに誰かが埋めたい証拠を運ぶ生物学的対象を受け入れる。

だから Black Keel からの最初の明瞭な返答は痛い。リレーは distress hash を承認できる。Luyten は packet custody を保存できる。ブローカーは、プレイヤーが空を見る前にサンプルに値を付けられる。だがそのどれもバースを予約しない。生きた身体はパケットより重いだけではない。責任の所有者を変える。誰が同じ空気を吸うのか。誰が減圧傷を診るのか。誰が Deep Reach に生存者を claim property と呼ばせないのか。バースが一か月閉じた時、誰が払うのか。

古い航路労働者はこの台帳を、料金欄のある慈悲と呼んだ。不公平で、正確でもある。初期の救助は汚染を道徳の些事として扱い、ステーションを殺した。だからバースは必要になった。同時に企業はここで、言葉が自分たちに有利になるまで助けを遅らせる術を覚えた。プレイヤーにとって台帳は読める圧力だ。バース欄が空なら救助語は芝居であり、custodian と liability が埋まっていれば誰かが紙ではなく生存に実力を使い始めたことになる。
