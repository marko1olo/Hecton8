# 偽エンディング分類

HECTON-8の偽エンディングと部分エンディングは、ただの肩透かしではなく実際の結果として扱われる。物資報酬だけでクレジットに到達することもある。部分脱出では、ドシエの知識を持ったまま同じシードへ戻される。企業拘束と隔離保留は、悪いペイロードや危険な証拠経路への罰になる。より深い結末には、公的証拠、Atlas状態の解決、そしてプレイヤーがどんな救助の代金を支払うのかという選択が必要になる。

## Scanner

結末ボード。成立するほど本物で、傷つくほど間違った出口がある。

## Terminal

結末系統: 物資報酬、部分脱出と同一シード帰還、企業拘束、隔離保留、公開台帳の放出、Atlas盆地解決。結果記録ではペイロード、証拠、債務状態を分けて保持すること。

## Audio

水から出ることは、仕事を終えることではない。

## Field Note

偽エンディングは手品ではない。真実を欠いた有効な取引だ。
