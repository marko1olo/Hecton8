# 最終問い: 公開台帳、失われた制御

公開台帳ルートは保管を受領書に交換する。パケットは証人ハッシュ、責任連鎖、Atlas状態要約、墨消し済みブルーデット座標、ペイロード経路証明を持って盆地を離れ、Deep Reachが単独でアーカイブを閉じる前に出る。それは名前を単純削除から守るが、規制機関、債権者、生存者ネットワーク、ドメイン裁判所、競合相手、最初に提出できる受領者すべてにファイルを渡す。
