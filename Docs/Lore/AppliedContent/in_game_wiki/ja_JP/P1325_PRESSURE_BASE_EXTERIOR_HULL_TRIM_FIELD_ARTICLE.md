# 圧力基地外装ハルトリム

HECTON-8の圧力基地外装は飾りの殻ではない。トリム帯は、水中で整備されるために作られたモジュールの読める文法だ。淡色のセラミック被膜は耐圧外皮を示す。暗い黒鉛リブは荷重の流れを示す。細いガスケット溝は、二つの容積が海を共有せずに接するはずだった場所を示す。沈んだパネルリップは多くの場合、装飾ではなく人間のアクセスを意味する。

切る前にトリムを読む。モジュールを途切れず横切る長いリブは、その壁が一体として圧力を受けていることを示す。きれいな塩筋のそばで折れたリブは、漏れが局所に留まり、ポケットを残した可能性を示す。古い鉱物粉で詰まったガスケット溝は、接合部がゆっくり呼吸していたことを意味する。新しい傷のあるパネルリップは、部屋がすでに濡れた後、あるいは公式作業命令が終わった後に開けられたことを示す。

よいトリムシートは、基地を塗られた背景ではなく建てられた構造に見せる。サルベージも盲目ではなくなる。プレイヤーはリブの方向を追って危険な切断を避け、繰り返すガスケット形状から整備ハッチを見つけ、帰還を前提に修理されたモジュールと証拠として捨てられたモジュールを読み分けられる。海は最初にラベルを消す。縁は残す。

## Scanner

外装ハルトリム // 淡色の耐圧外皮、黒鉛色のリブ帯、沈み込んだガスケット溝。塩の筋は主板の下ではなく整備リップの下を走っている。これは整備されたモジュール縁で、ただの残骸板ではない。

## Terminal
