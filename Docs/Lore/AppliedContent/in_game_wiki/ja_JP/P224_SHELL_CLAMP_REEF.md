# シェルクランプ礁

シェルクランプ礁は、浅い棚が在来生物と人間の残骸を分けておかなくなる最初の場所である。クランプ殻は知性を持たず、Atlas 組織でもない。鉱物流出、熱、振動、流れの圧力に従うだけだ。それだけで、玄武岩、古いケーブル外装、カプセル外板、pressure glass の継ぎ目を恐ろしい忍耐でつかむ。プレイヤーにとって礁は、経路標識、採取源、構造警告を同時に兼ねる。死んだ外殻はシーラントやセラミック充填材の粒として使える。生きた芯は仕事をしているかもしれない。ケーブルを静かに保持し、割れたブラケットを硬くし、scanner がまだ名付けていない漏れを遅らせている。間違った集団を切っても、礁は攻撃しない。環境が支えを一つ失うだけだ。

## Scanner

シェルクランプ礁 // 在来のクランプ殻が岩、ケーブル外装、カプセル外板、pressure glass の継ぎ目に固着する。礁は機械を基質として受け入れている。

## Terminal

礁ベースライン: 摩耗したケーブル外装、温かい継ぎ目の金属、鉱物流出を伴う pressure glass 縁で固着が増える。採取は死んだ外殻だけ。サービスライン近くの生きたクランプを切ると、漏れを開いたり修理ファウナの注意を引いたりする。

## Audio

礁はボルトの形を覚えた。

## Field Note

手の届く最初のクランプをこじるな。生きた集団は、ケーブルを静止させ、細い漏れを塞ぎ、経路アンカーを示しているかもしれない。
