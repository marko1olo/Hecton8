# Aegir主星

Aegirは通常のK型主星を回る。HECTON-8が暗いのは星が失敗したからではない。水柱の深さ、嵐の濁り、食の時刻、シルト、圧力、壊れた産業が闇を作る。表層の光は棚の生命を育てるが、深淵は法的にも物理的にも盲点のままだ。

## Scanner

K型主星を確認。系には光がある。闇を作るのは深度、嵐、食、そして負債だ。

## Terminal

RAN/AEGIR暦表: K矮星主星、安定した光球出力、遅延する星間パケット級、FTL救助ベクトルなし。質量が到着するまでは支援を局所扱い。

## Audio

星光は棚に届く。問題には届かない。

## Field Note

恐怖は星ではない。海が光を噂に変える場所にある。
