# ブラインベーン林

ブラインベーン林は、見えない物理を見えるものにする最初の中深度生態である。塩水、温度、圧力の境界に沿って張られた平たい塩鉱物膜だ。遠くからは沈んだ峡谷の淡い葉に見えるが、近くでは経路計器である。無傷のシートは、その向こうの水が単に違うだけではなく、入りにくいことを意味する。密度せん断はソナーを曲げ、身体をトリムから外すほど強い。裂けた縁は最近の通過を示す。巻いた先端は境界がせん断窓へ弱っている場所を示す。淡い鉱物リブは剥がれた帯から採取できるが、生きたシートを切ると峡谷壁を抜ける唯一読めるレーンを閉じることがある。経路が必要なら裂けたベーンを追え。縁を消す黒い層状水は避けろ。
