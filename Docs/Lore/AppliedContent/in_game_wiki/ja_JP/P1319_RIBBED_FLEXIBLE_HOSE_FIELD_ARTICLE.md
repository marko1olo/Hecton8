# リブ付き柔軟ホース

リブ付き柔軟ホースは、加圧基地の柔らかい系統をつなぐ。酸素、冷却、ポンプ始動、工具電力、スーツ整備、緊急バイパス。リブは潰れを防ぎ、表面を読めるものにする。乾燥周期はリブの頂点に塩を残す。谷は水、油膜、細かいシルトを保持する。平たい輪はクランプ、扉の圧迫、急ごしらえの固定点を示す。片側だけの摩耗は設置ではなく引きずりを示す。小さなシアンの塗料片は、ラベルが消えても冷却ラインを示すことがある。

## Scanner

リブ付き柔軟ホース // 圧力対応のゴムライン。リブ上の塩、濡れた谷、平たいクランプ跡は最近の流れを示す。切る前に両端を追え。死んだように見えるホースが空気、冷却、証拠を運んでいることがある。

## Terminal

バイパスメモ: 避難命令後に引かれたホースは整っていない。片側のリブが磨かれていれば、荷重下で引きずられた。谷が濡れたままなら、浸水後にも圧力が通った。

## Audio

手袋をホースに置くと、ゴム越しに部屋が聞こえる。空気は鋭く、冷却液は疲れて聞こえる。切られたラインは、到着した負債の音がする。

## Field Note

頂点は乾いたものを語る。谷は動き続けたものを語る。平たい輪は即席仕事を語る。
