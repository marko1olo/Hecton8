# 音声断片小道具規則

音声断片小道具規則は、音声ログを希少で有用で地に足のついたものに保つ。HECTON-8 は最期の演説の博物館ではない。音声断片は、部屋がすでに真実の一部を示しているからこそ、プレイヤーを近づかせるべきだ。ハイドロフォン片は圧力ノイズとルート時刻を運べる。スーツ記録器は、許可拒否後に誰がハッチを越えたかを証明できる。端末キャッシュは、きれいな台帳と食い違う損傷転写を保持できる。ブラックボックス断片は、機械優先度が人間の要求を上書きした瞬間を保存できる。物体が支えられないことを声が語るなら、それは安い説明になる。物体と声が食い違うなら、プレイヤーには調査が生まれる。

## Scanner

声は高価だ。金属、水、時刻、損傷で部屋も証明できる何かを証明しなければならない。

## Terminal

AUDIO RULE: 宙に浮いた独白は禁止。声はハイドロフォン片、スーツ記録器、端末キャッシュ、保守受話器、またはブラックボックス断片に属する。再生可能なすべての行には、発信元、損傷した転写状態、ルート時刻、プレイヤーが調べられる矛盾が一つ必要だ。

## Audio

部屋が私を証明できないなら、その行を切れ。

## Field Note

音声断片には、発信元小道具、転写損傷、ルート時刻、物理的矛盾が一つ必要だ。
