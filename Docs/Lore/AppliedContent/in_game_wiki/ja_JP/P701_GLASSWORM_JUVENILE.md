# ガラス虫、幼体

群落が最も厚い所では、その背後の板が割れている。

群落は亀裂の近くではなく亀裂の上に育ち、そこを通る流れが強い所で厚くなる。つまり最も健康な区画が最悪の漏れを示す。管の口はどれも流れの上流を向く。口を読めば、亀裂を横切らずに漏れの軸が分かる。

群落は柔らかい。その背後では22.9 MPaが乾いた空洞に向かって働いていて、亀裂の流入は手首でグローブの縫い目を持っていく。荷を受けている区画を切れば、管は順に破れ、板に沿って連続した音が走る。その連続音は、亀裂が自分の荷を取り戻しているところだ。

セクター44で記録された個体はすべて幼体だ。2147年の調査も同じ段階を記録している。

評価：採取は下流側の面から。板が鳴った瞬間に板から離れる。

## Scanner

群体性の幼体、亀裂の縁に微量級ガラスを積層。信頼度82パーセント。危険：隠れた流入。限界：成体の記録がなく、段階は未確認。

## Terminal

## Field Note

「緩和済」とは、虫が押さえているという意味で、だれかが直したという意味ではない。区画を薄くしたら、モジュール9を開けたのはあんただ。
