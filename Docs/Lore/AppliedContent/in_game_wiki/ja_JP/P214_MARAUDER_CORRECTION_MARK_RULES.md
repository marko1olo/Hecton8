# マローダー修正印規則

マローダー修正印規則は、コロニー証拠に触れた第二の人間の手を定義する。Deep Reach は作業員を埋めるために分類を書いた。後の請求クルーは、生き残り、交渉し、互いに警告するために、その分類の上へ書いた。修正印はプレイヤーの推測を変える時だけ有用だ。丸で囲まれた名前は、人を損失分類から救える。消されたルートスタンプは、安全な扉を怪しく見せられる。価格印は生物サンプルを債務物に変えられる。隠された証人印は、正しい文脈が来るまで音声断片を守れる。印は素早く、実用的で、疲れているべきだ。芝居がかっていてはいけない。これは雰囲気用の落書きではない。記録が汚いと知りながら、それでも食べる必要があった人々の仕事だ。

## Scanner

修正印は名前を救い、請求を汚し、次の潜水者に公式分類が嘘だと警告できる。

## Terminal

CORRECTION RULE: マローダー印は証拠解釈、ルートリスク、支払い圧力を変えなければならない。有効な印は作業員名を保存し、保険分類に異議を唱え、ルートを警告し、サンプルに値を付け、証人を隠し、または債務を記す。空の落書きは証拠連鎖を壊す。

## Audio

あなたより前に誰かが来て、それでもきれいには去れなかった。

## Field Note

印: 名前保存、分類異議、ルート警告、サンプル値付け、証人隠し、債務印。筆跡は読みを変えるべきで、物を飾るためではない。
