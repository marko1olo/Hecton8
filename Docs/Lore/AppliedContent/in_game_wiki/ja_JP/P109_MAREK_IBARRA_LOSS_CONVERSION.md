# マレク・イバラの損失変換

マレク・イバラはKeelmark Mutualの査定記録であり、行方不明作業員を未解決の会計状態へ変える。表は悲嘆のためではなく、閉鎖コストのために書かれている。遺体未回収、圧力状態未認証、汚染保留、給与上の身元停止。

だからHECTON-8では名前が重要になる。ロッカープレート、スーツタグ、遺体台帳の行、回収されたルート時計は、作業員を未解決荷重から誰かが答えるべき請求へ戻すことができる。曖昧さは救助より安く、補償より安く、輸送体の争いに埋めやすい。

Marauderにとって、回収された身元は飾りではない。その人を二度消した会計上の仕掛けを傷つける。一度目は水の中で、二度目は台帳の中で。

## Scanner

査定表 // M. イバラは、圧力状態、汚染状態、または給与状態が認証されるまで、行方不明作業員を未解決荷重クラスへ変換した。
