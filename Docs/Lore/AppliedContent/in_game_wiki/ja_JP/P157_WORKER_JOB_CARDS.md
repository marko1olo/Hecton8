# 作業員ジョブカード

ジョブカードはコロニーで最も小さな伝記だ。重みを持つために幼少期や恋愛や演説はいらない。必要なのは役割、許可印、最後の作業、そして次の音のあとに終えるはずだったものだ。プレイヤーがカードを見つけると、人々は背景の犠牲者ではなく経路証拠になる。誰かがポンプキーを持ち、ハッチを遅らせ、班の食事を作り、カッターを持ち出し、シールを認証し、あるいはシステムが救助を待たせたせいで戻れなかった。

## Scanner

JOB CARD // 名前、役割、最後の作業、経路許可、工具認証。予算が読める顔。

## Terminal

証拠規則: 回収された名前は、実行された何かに結びつくべきだ。ポンプ経路、厨房台帳、医療呼び出し、カッター保管、圧力確認、製造バッチ。作業が名前を証拠にする。

## Audio

作業のない名前は祭壇になる。作業はそれを証拠にする。

## Field Note

名前を悲劇にする前に、役に立つものにする。
