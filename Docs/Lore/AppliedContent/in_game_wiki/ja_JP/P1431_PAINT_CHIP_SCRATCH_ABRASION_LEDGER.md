# 塗装剥離・擦傷・摩耗台帳

HECTON-8の塗装剥離はただの汚れではない。Deep Reachは耐圧モジュールを作業で読める色に塗った。白は外殻、暗い下地と黒鉛色はレールや接触面、橙色は手袋の手がラッチやレバー、点検縁を探す場所だった。海中の数十年でロゴとラベルは弱るが、失われた塗装は記録を残す。

順序が重要だ。剥離の中の塩は、露出縁が長く湿った室内で呼吸していたことを示す。縁に清潔な暗い下地があれば、最近の工具か手袋が古い鉱物膜を切った。ラッチ周りの弧は偶然の擦れではなく、圧力下で何度も開けた軌跡だ。直線の黒鉛傷はカッターの案内、引かれた機材ケース、または支えに使われたパネルを示すことがある。サービス角の橙片はたいてい天候ではなく人の動作を示す。

マローダーにとって塗装欠損は経路の道具になる。耐圧扉の安全なラッチ側を教え、公式停止後にパネルが開かれたことを証明し、通常整備と後のサルベージ干渉を分けられる。先に剥がせば証拠はただのスクラップになる。先に読め。それから板を資材、遮蔽、入口、証拠のどれとして扱うか決める。

## Scanner

表面摩耗 // 白い塗装の剥離から暗い下地、黒鉛色の傷群、ラッチ弧の近くの橙色安全塗装片が見える。古い剥離には塩が入り、明るい露出縁は引かれた側にだけ残る。最初の浸水後に扱われた痕跡。

## Terminal

摩耗読取 // 塗装欠損は層で読む。剥離の下の塩は古い露出。縁の清潔な下地は最近の工具接触。ラッチ周りの曲線傷は反復アクセス、直線の黒鉛傷はガイド切断か引きずられたケースを示す。剥がす前に模様を記録すること。

## Audio

## Field Note
