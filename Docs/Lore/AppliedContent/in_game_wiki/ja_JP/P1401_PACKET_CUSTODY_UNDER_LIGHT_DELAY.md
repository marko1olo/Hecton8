# 光遅延下のパケット保管

HECTON-8で真実を見つけることは、簡単な失敗だ。端末はまだ起動し、タグはまだ名前を持ち、濡れたカメラスプールは圧力扉の向こうに閉じ込められた人物を映すかもしれない。それだけでは証拠にならない。パケットにソース時計、ハッシュ、第二の証人、そして請求者の手を離れた保管経路がそろうまで、Black Keelはそれをサルベージ質量として扱え、Deep Reachは汚染されたプロジェクト資材と呼べる。

古い人類フロンティアは遅延を法律にした。FTL返信はなく、海の上に生きた法廷もない。有効なパケットはローカル中継窓、Black Keelのキュー、Luyten Packet Ladderの受領、そしてDeep Reachを傷つける必要があるならTau Public Ledger Laneのような受取人まで生き残らなければならない。鎖はわざと地味だ。時計、複製、封印、キュー、受領。一つ切れれば、同じ真実はサンプル、噂、責任ファイルになる。

Deep Reachはそれを知っている。Recovery Complianceはすべての文書を消す必要がない。経路を毒すだけでよい。積荷を隔離物と標識し、時計に異議を出し、原保管を要求し、質量窓を高値にし、公共受取人が見る前にパケットをKeelmark経由にする。Marauderは博物館用の資料を集めているのではない。水没したコロニーを、請求システムが資材として数える前に、人間として数えさせようとしている。

優れたMarauderは醜い証拠を二つの形で持つ。公証に出せるほど清潔なものと、どこで見つけたかを証明できるほど汚れたものだ。前者は案件を動かす。後者は、真実が場所も圧力状態も背後の身体もなく届いたと会社に言わせない。

## Scanner

パケット保管 // 濡れた中継封印。読めるファイル一つでは証拠ではない。サルベージ圧縮前に時計、ハッシュ、重複証人、保管印、受取経路を保存しろ。
