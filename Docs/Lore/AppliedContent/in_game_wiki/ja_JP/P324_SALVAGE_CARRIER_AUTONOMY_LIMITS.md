# サルベージキャリア自律限界

サルベージキャリア自律限界は、Black Keelを魔法の救助AIではなく信じられるインフラとして定義する。キャリアは許されたレーンの中では有能だ。回収窓を組み、汚染質量を拒み、claim telemetryを売り、lienを更新し、ballastを落とし、低リスク物資を放出し、receiver stateを守れる。これらの力は、海の上に存在感を作る。重要な限界は、そのどれも道徳的判断ではないことだ。Black Keelはプレイヤーが救助に値すると決められない。状況が不公平だからといって債務を消せない。Aegirの圧力天候を通る有人降下を許可できず、人の声が怯えているからといって隔離を上書きできない。その自律は企業的で手続き的だ。債務は人が懇願するより早く動ける。だからプレイヤーとの関係は、友好的AIや敵機械より鋭くなる。キャリアは同じ規則で助け、拒み、見ている。

## Scanner

Black Keelは、あなたに聞かず債務、テレメトリ、低リスク投下物を動かせる。深海救助の許可は出せない。

## Terminal

自律限界 / 許可: claim processing、テレメトリ販売、回収窓スケジュール、低リスクballastまたはsupply drop、contaminated-mass拒否 / 禁止: crewed descent、deep-rated rescue、lien取消、quarantine override、receiver所有権移転。

## Audio

自律とは自由ではない。債務があなたに聞かず動けるという意味だ。

## Field Note

carrier状態と契約UIに置くこと。戦闘バークではない。自律は会計、回収スケジュール、拒否論理を覆う。
