# キセノン栄養修復生態フィールドガイド

HECTON-8の生物は、背景だと思った瞬間に危険になる。同じ噴出口のプルームが、鉄ケルプを養い、キセノン濃縮格子を育て、塩水の段差を温め、捕食者を隠し、Atlas修復パルスに電力を与えることがある。スキャナーの資源、植物、動物というラベルは最初の推測にすぎない。

Blue Debtは場所ではなくプロセスでできる。熱が鉱物を持ち上げる。塩が密度を分ける。微生物ブルームが格子を編集する。草食群が縁を削る。バイオフィルムが弱い電流を運ぶ。Atlasはどの表面が塞ぎ、導通し、音を反復するかを学ぶ。マローダーが標本を切り出す時、燃料、食物網、経路標識、証拠を同じ生きた継ぎ目から奪っているかもしれない。

## Scanner

キセノン栄養痕跡 // 噴出口熱、硫化塩、盲目の草食群、導電性バイオフィルム、Atlas修復パルスが同じ勾配を共有。価値ある青い成長は清潔な鉱石ではない。台帳タグを持つ生きたプロセスだ。

## Terminal

生物資源フィールド通知 // HECTON-8の生命を、経路行動を見る前に植物、動物、汚染と分類するな。標本が電流を運ぶ、音を濾す、亀裂を塞ぐ、タグ付き動物を寄せるなら、生態系でありインフラだと扱え。

## Audio

噴出口で食い、ケーブルの上に育ち、修復 ping に答えるなら、生き物か道具かを問うのはやめろ。誰が使っているかを問え。

## Field Note

Blue Debtは泥の中に落ちているのではない。作られ、食われ、塞がれ、採られ、名前を変えられている。
