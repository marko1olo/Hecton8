# 中継保管の債務鎖

中継保管は宇宙物流を圧力に変える。助けは届き得るが、助けを運ぶ経路は債務、優先フック、企業権限も運ぶ。

## Scanner

債務鎖は経路パケット、carrierアクセス、claim保険を一つの首輪にする。

## Terminal

Custody note: Luyten packet buffer、Aegir claim pool、Black Keel carrier権が同じ債務鎖を参照。
