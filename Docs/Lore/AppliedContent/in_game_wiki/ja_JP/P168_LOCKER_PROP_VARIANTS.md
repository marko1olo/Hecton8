# ロッカー証拠バリエーション

HECTON-8のロッカーは感傷的な小物置きではない。小さな圧力室の記録だ。作業員が何に触れ、何を持つ許可を得て、何を班長から隠し、後から来たMarauderが何を訂正すべきだと見たかを残す。

よいロッカーは組み合わせで語る。手袋の横の圧力テープは漏れ作業を示す。私物工具の中の摩耗ガスケットは、扉を何度も扱い、予備部品を信用しなくなった人間を示す。食事クレジットと経路チョークが並ぶなら、次の勤務がまだ来ると思っていた。medlock却下票は、部屋を背景から証拠に変える。身体がすでにコスト問題になっても、働けと言われたのだ。

ゲーム上、ロッカーはシード可能な人間の痕跡になる。中身はランごとに変わっても大きなカノンは変わらない。安定する規則は読むことだ。トークン、ガスケット、メモをただのスクラップとして剥ぐと、部屋から作業員を現前させる文法が消える。
