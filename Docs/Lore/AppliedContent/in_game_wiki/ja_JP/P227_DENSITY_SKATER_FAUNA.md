# 密度スケーター・ファウナ

密度スケーターは、ブライン峡谷を空の体積ではなく層状機械に感じさせる中深度動物である。脚、鰭、または鉤状のパッドが、小さな体を数秒支えるほど強い密度界面を押す。目には開いた水を滑っているように見えるが、scanner には面がないはずの場所に波紋が残る。その矛盾が手掛かりだ。スケーターの跡は、せん断窓、ブライン段、ソナーの盲縁、あるいは大型生物の狩猟レーンを示すことがある。動物は魔法ではなく、安全の約束でもない。スーツは重く、うるさく、この技には形が悪い。スケーターの航跡で層を読め。追えると思うな。

## Scanner

密度スケーター // 細い脚を持つファウナがブライン界面を面として滑り、ソナーが開水を予想する場所に波紋を残す。

## Terminal

基礎ファウナ: スケーター接触は、裂けた brine vane、温かいブライン段、ソナー死角の縁で増える。その航跡は密度棚を示すが、安全な足場ではない。不透明層を追って渡るな。
