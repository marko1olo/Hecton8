# ペレット核融合貨物

ペレット核融合貨物はFTLなしでAegirを到達可能にした。ビーム局が押し、ペレット流が核融合燃焼を養い、遮蔽質量が塵を受け、磁気帆と現地制動系が時間をかけて速度を返済した。同じ構造が救助を遅くする。すべてのキログラムには予定、熱予算、所有者がある。

## Scanner

駆動板: 加速、ペレット供給、遮蔽、惰行、制動、そして損失請求。

## Terminal

貨物教義: seed payloadと植民質量は、ビーム加速、ペレット供給核融合、遮蔽質量、磁気帆制動、長い惰行期間を用いた。生体貨物はインフラの後に続いた。

## Audio
