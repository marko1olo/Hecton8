# 修復痕

修復痕とは、Atlasの保守論理がカテゴリを失った後も働き続けた場所だ。ネットワークはまだ漏れ、死んだ経路、圧力低下、露出基質、不足した隔壁質量を認識する。さらに海が近くへ運んだものにも手が届く。ケーブルの森、礁の骨格、ドローンの殻、作業員の残骸、工具ラック、封印ゲル、電流の周囲で訓練された生きた成長。だから痕は有用であり、同時に猥雑だ。電力を戻し、扉を封じ、廊下を通れるようにすることがある。同時に、システムがケーブルと根、殻と筐体、動物と工具、身体と予備在庫、植民地と工程を分けなくなった証拠にもなる。AtlasはHECTON-8の保守をやめなかった。内部の人間を守るには壊れすぎた語彙で、月を保守し続けた。

## Scanner

成長の縫い目が古いケーブル経路をサービスノード間隔で追っている。組織、絶縁材、殻が一つの圧力溶接を共有している。
