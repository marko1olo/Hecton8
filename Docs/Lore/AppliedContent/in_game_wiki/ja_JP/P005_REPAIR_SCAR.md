# 修復痕

修復痕は、ケーブル森林の成長とドローンの通行が入り込んだ後に漏れたサービスノードで見つかるAtlas-6の保守閉鎖だ。Atlasは今も圧力低下、信号経路の断線、隔壁質量の不足、ルート連続性を認識する。壊れているのは材料判定である。荷重を受ける、水を止める、信号を通す、または故障箇所を通ってすでに成長しているものは、修復に受け入れられることがある。

そのため修復痕は、証拠になる前に役に立つ。継ぎ当てられた隔壁はルートを救い、生きたスリーブはケーブルを乾いたまま保つ。同じ閉鎖が、新しい礁炭酸塩の下に作業員タグ、工具番号、スーツリング、骨片を埋めることもある。切断前に継ぎ目の順序をスキャンし、見えるタグを読み、ドローン巣の電力を確認する。最初のカテゴリエラーは、AtlasがHECTON-8を修理することではない。修理が、どの材料を人として残すべきか分からなくなったことだ。

## Scanner

サービスノードの継ぎ目が古いケーブル溝と亀裂入り隔壁リブをつないでいる。材料: 生体サンゴ層、ドローン外殻、オレンジ色の絶縁材、骨片2点。圧力保持: 78%。タグ読取前の切断禁止。
