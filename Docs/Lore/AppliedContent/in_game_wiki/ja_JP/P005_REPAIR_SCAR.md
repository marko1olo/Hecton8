# 修復痕

Atlasの修復痕は、保守論理が本来混ぜてはならない分類を横断した場所を示す。システムは漏洩、壊れた経路、圧力低下、露出基質、壊れかけの居住壁、欠損材料をまだ識別する。しかしケーブルと根、殻と筐体、動物と工具、死体と予備材、植民地とプロセスを安定して区別できない。

## Scanner

生物成長がケーブル形状を非ランダムな間隔で追っている。エネルギー漏れだけでは説明できない。

## Terminal

漏洩: 閉鎖。経路: 復旧。材料: 互換。生命状態: 未解決。連続性: 改善。
