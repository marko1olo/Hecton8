# 受信側制動債務台帳

Nearlight航行は距離を無害にしなかった。距離を会計可能にした。人間の船が星の間を渡れるのは、古い航路が部品ごとに所有されているからだ。beam arraysが押し、pellet lanesが供給し、fusion stagesが消費し、シールドが質量を失い、ラジエータが熱を捨て、magsailsが場に噛みつき、receiver stationsが航路の送るものを捕まえることに同意する。

最後の動詞が醜い。身体を捕まえるには、受信側が身体の到着前に制動債務を受け入れなければならない。熱余裕、隔離容積、医療custody、法的露出、停止が失敗した時に誰が払うかを予約する必要がある。signal packetはその大半を求めない。封印されたevidence hashはrelayに乗れる。貨物箱は何年も前に書かれた予定に乗れる。壊れた海洋claim内の生きたoperatorは別種の質量だ。

だからHECTON-8はつながっていて、同時に見捨てられている。Black Keelはrelay window越しに君を聞ける。brokerはsampleに価格を付けられる。public ledgerは君のdistress hashが存在したと記録できる。だがそのどれも君の身体のbraking rightsを作らない。救助が可能になるのは、signal、custody、receiver liability、隔離、空のタイミング、lift mass、実際のhardwareが揃った時だけだ。それまではシステムは沈黙していない。もっと悪い。読み取れる。
