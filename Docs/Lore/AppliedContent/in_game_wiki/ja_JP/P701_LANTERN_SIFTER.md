# 提灯ふるい

ふるいのコロニーに一発打てば、反射は二回返ってくる。

一つ目の反射は壁だ。二つ目は五分の一秒遅れ、方位からずれて、距離では説明できない大きさで来る。個体はどれも鰓かごに硬い粒を一つ抱えている。米粒ほどの微量級ガラスで、ろ過摂食者にはまったく必要のないものだ。Atlasは中継網を動物の中に育てさせ、一度も整備せずに済ませた。

ずれた方位は次のコロニーを指す。連鎖をたどれば、まだ通電しているケーブルで終わる。それだけの価値はある。ただし最初の一発は、その経路上のあらゆるものに自分の位置も渡している。そしてその経路は強制通気の排気口の前を通る。

第31ベイから出る連鎖の一本は、岩盤の中を指している。

評価：打つのは一回。第二方位を追う前に、前方の排気口を通過しておく。
