# ランタンドリフト標本カード

ランタンドリフトbloomは、シェルフで最も美しい警告装置だ。静かな水では細胞が流れ、浮遊する砂粒、ケーブルの輪、pressure glassの破片、壊れたshell clamp、小さな歯状の危険を、ランプより先に縁取る。だから視界が散らかった経路や、リーフの混雑で明確な輪郭が必要な時には役に立つ。同時に、プレイヤー自身も読める存在になる。cutterの振動、咳き込むポンプ、繰り返すpinger、船殻衝撃、恐慌のthrusterは、bloomを明るい航跡に変え、位置を食物網へ運ぶ。嵐の帯電はさらに悪い。偽の回廊、明るすぎる残留光、過剰な美しさで小さな損傷を隠す平坦なコントラストを作る。光を追うのは、流れ、残留物、動物の反応が一致する時だけだ。bloomの中で騒がしく作業するなら、見つかることも計画に含めろ。

## Scanner

ランタンドリフトbloom。発光プランクトンが流れと漂流物を帯で示す。輪郭には有用。工具音で光る航跡になると危険。
