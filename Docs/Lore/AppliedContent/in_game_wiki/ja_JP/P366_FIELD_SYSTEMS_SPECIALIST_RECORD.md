# フィールドシステム専門員記録

フィールドシステム記録は、オペレーターを秘密の司令官にせず能力を説明する。Deep Reachはこの職種を、ポンプ、シール等級、バイパスカード、リレー室、避難待ち列、route-safe認証の周辺で訓練した。埋められたルートがどう見えるか分かる程度のアクセスを持つ、インフラ労働だった。

権限剥奪後、資格は安全扉を開けない。訓練は消えない。排水命令、clamp等級、封じられた手動人数欄、洗浄されたhold文句は、かつて信じた仕事としてまだ読める。だから沈んだ機械は背景ではなく証拠になる。オペレーターは、安全手順が見捨てを完了済みに見せるまで曲げられた場所を読める。

記録は背景を狭く保つ。指揮権限なし。清潔な自白なし。英雄的な乗客の地位なし。いるのは、人数表から人を消した機械を読める元Deep Reachシステム作業員だ。
