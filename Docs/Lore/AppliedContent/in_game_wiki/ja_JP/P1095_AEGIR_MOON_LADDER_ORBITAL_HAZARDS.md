# Aegirの月梯子

Aegirの月梯子は空の飾りではない。Ranは恒星、Aegirは巨星、HECTON-8は月、リレー、嵐、保管確認、保険付き質量窓の連鎖に入った海洋月である。

Skarnはアンテナを荷電ノイズであふれさせる。Velaは氷塵でリレーを閉じる。Kestrelは最悪の瞬間に視線を遮る。HECTONは清浄な上昇回廊へ嵐プルームを投げ込む。Black Keelはパケットを受け取っても、窓、隔離ハンドシェイク、質量クラスが落ちれば引き上げを拒む。

## Scanner

軌道危険 // 窓は不安定。Skarnサージ、Velaシャッター、Kestrel遮蔽、HECTON嵐プルームが回収幾何を壊す可能性がある。

## Terminal
