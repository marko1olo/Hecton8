# 請求枠救助遅延台帳

この台帳が嫌なものに見えるのは、役に立ちそうに見えるからだ。Black Keelの回収チャンネル印、Keelmark Mutualの質量窓表、そして追い詰められた人間に最初の行を二度読ませる小さな緑の認可印がある。チャンネルは開いている。キャリアはパケットを聞ける。契約は生存中の請負人を認めている。しかしそのどの行も、水中へ船体が降りてくるとは約束していない。

Aegirの請求法は接触と回収を分ける。接触は信号であり、空と海とキャリア待ち行列が許すとき、ローカルリレーを通過できる。回収は質量だ。圧力下の身体には密閉された上昇経路、定格チャージ、誘導タイミング、隔離許可、そして生存者が持ち帰るものを相続する受領者が必要になる。その窓を通るすべてのキログラムは、試料保管、予備機材、保険リスク、すでに列に並ぶDeep Reach条項と競合する。

だから最初のBlack Keelの返答はわいせつに感じられる。機械は役に立つかもしれない。技術的には正直ですらあるかもしれない。チャンネルを開き、帰還に値段を付け、足りないものを並べる速度は、誰かを救う速度より速い。Keelmarkはプレイヤーを憎む必要がない。ただ古い順番で古い問いを出せばよい。何の質量が戻るのか。誰の封印で戻るのか。汚染分類は何か。そして回収された身体が貨物ではなく証拠を持っていた場合、誰が支払うのか。

Marauderはこの台帳を作業命令として読む。リレーの背骨を組む。クランプリングを認証する。圧力で砕けない上昇エネルギーを見つける。隔離法務ハンドシェイクを取得する。ペイロードが座標なのか、証拠なのか、Atlas継続性なのか、公的台帳なのか、沈黙なのかを決める。HECTON-8に救助がないわけではない。救助は項目化され、遅延され、プレイヤーが十分に安く、十分に役立ち、あるいは十分に危険になるのを待っている。
