# 音響リレースパイン組立

音響リレースパインは、カプセルが存在することを示す最初の証明だ。衝撃、マスト喪失、嵐のノイズの後では音声チャンネルは脆すぎる。スパインは水中に低帯域 pressure-code を送る。セラミックリブ、ケーブル外皮、pinger floats、そしてランダムな残骸音ではなく位置を繰り返せる時計が必要になる。

重要なのは、軌道がすべての音を救助しないことだ。Black Keel は HECTON-8 からの圧力イベントを聞けるが、claim custody、ルート形状、受信タイミングで濾過する。route proof のない破損 tap は背景になる。時計の合わない清い tap は evidence loss になる。組立は音を回収可能な対象へ変える。位置、生存状態、時計、checksum。

スパインの salvage は狭く、許容が少ない。Marauder はケーブルジャケットを替え、割れたリブを座らせ、pinger floats をバラストし、パケット cadence を合わせられる。だが海は multipath delay、brine distortion、船体ノックを足し続ける。直したスパインは哀れみを求めない。受信機が recovery window を危険にさらすだけの反復事実を渡す。

## Scanner

破損音響スパイン // セラミックリブ束、裂けたケーブル外皮、二つの pinger floats。低帯域 tap は可能。タイミングと route proof が合わなければ軌道受信機は無視する。

## Terminal

ASCENT RELAY: recovery window 前に low-band acoustic spine を復旧。High-gain mast 喪失。Emergency buoy 不安定。Black Keel 受信機は route proof、clock match、custody checksum 付き pressure-code のみ受理。

## Audio

Keel が聞くなら、悪い水越しに座標を叩くセラミック音を聞く。

## Field Note

カプセルから出る最初の呼びかけは声ではない。リブ、ケーブルジャケット、バラスト float、そして水に同じ事実を二度繰り返させるだけの時計精度だ。
