# 債務ブラックリスト契約圧

債務圧は契約を醜くするが、芝居にはしない。オペレーターは鎖でHECTON-8へ引きずられたわけではない。しかし拒否の道は周囲で閉じるよう設計されている。Black Keelがclaimを出せるのは、債務窓、oxygen credit、berthアクセス、ルート時刻、custody proofが同じ辺境台帳にあるからだ。

拒否は合法だ。同時にMarauderをblacklistに残し、地上に縛り、次のAegirルート窓から価格で締め出す。受諾は移動を与えるが、慈悲ではない。recoverable massを届け、custodyを保ち、receiver complianceがclaimの価値を決める。carrierに悪役の顔は要らない。契約自体がリスクを紙へ変える。
