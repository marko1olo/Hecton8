# 血ケルプ

作業ランプでは見えない。色素はランプが合わせている青緑帯を吸収するので、12 mでは開けた水として読み、3 mでは壁として読む。

琥珀色の非常用レンズなら塊として浮かび上がる。根を張るのは硬い構造の上だけだ。1,900 mの開けた水にある群落は、海図が何と言っていても屋根スラブの上に座っている。

接触は発光器を作動させる。縁から始まり内側へ進み、触れた点から外へは決して広がらない。約九十秒続き、入ってきた縁にいるものを見せるには十分な長さだ。

茎は潜水士の体重を支える。絡んだハーネスは引きちぎれない。切るのは縁から内側へ。第17ベイでの四件の絡まりは、いずれも内側から切ったことで終わった。

産出：生物発光化合物、放電していない葉状部に最も多い。縁は必ず使い切られている。切るときは琥珀色レンズで。

## Scanner

固着する葉状生長、暗色色素。信頼度49パーセント。反射は疎。危険：記録なし。限界：色素が調査ランプの帯域を吸収し、範囲が過小に出る。

## Terminal

採取ロット 44-K-0774。区分：照明用原料、等級B。場所：第17ベイ 屋根、1,900 M。絡まり事案：4件。分類変更なし：非危険、植生。審査：資産沈黙委員会、終了。

## Field Note

絡まりが四件あって、分類はいまも非危険、植生だ。あの書式には、掴んで離さない植物のための欄がない。接近するときは琥珀色レンズを入れておけ。白い光は、もう中に入るまで何も見せない。
