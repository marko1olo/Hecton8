# パヴェル・ソルンの手続き保留

パヴェル・ソルンは、HECTON-8 の惨事にもっとも平凡な人間の蝶番を与える。避難を遅らせるだけの権限はあるが、条項の鎖を断つ勇気はない現地契約担当官だ。彼の手続き保留は、悪役の演説でも秘密の殺害命令でもない。Deep Reach の法務の内側で書かれた業務メモであり、救命行動でさえ認証、責任経路、Atlas 継続シール、請求権保管の文言を通らなければ「救助」と呼べない世界を示している。この記録が重要なのは、罪を人間のものとして残しながら、単純化しない点にある。ソルンは作業員の危難を見て、上昇待ちが死刑宣告に変わりつつあると理解し、それでも事務所を先に守る一文を選んだ。チャンネルがクリアになるまで許可を保留する、と。

## Scanner
