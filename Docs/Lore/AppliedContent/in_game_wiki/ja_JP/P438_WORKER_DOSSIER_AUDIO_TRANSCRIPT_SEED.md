# 作業員ドシエ音声記録

作業員ドシエ記録は、彼らが証拠になる前に、沈んだコロニーへ労働人口を与える。重要なのは日常だ。名前、作業、工具、悪い水量計算、次のシフトを期待する習慣。

## Scanner

回収された作業員音声。名前、職務、ロッカー、水量カウント、route holdを一つの人間的custody線につなぐ。

## Terminal
