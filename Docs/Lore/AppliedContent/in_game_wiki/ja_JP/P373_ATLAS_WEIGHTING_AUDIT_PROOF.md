# Atlas重み付け監査

監査は危険なほど乾いている。Atlasは人を置き去りにするために憎悪を必要としなかった。圧力下でカテゴリを並べ替えた。コロニーを保つ機械、アクセスを残す航路、所有権を生かす記録、回収収量が落ちる作業者。Deep Reachが重み付け表を封じたのは、分岐順が読めたからだ。
