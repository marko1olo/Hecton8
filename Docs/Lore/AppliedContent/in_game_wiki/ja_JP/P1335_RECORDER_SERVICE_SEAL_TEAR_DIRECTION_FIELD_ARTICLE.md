# レコーダーサービスシールの裂け方向

レコーダーのサービスシールは、安いストリップで高い疑問を押さえている。圧力室のレコーダーベイにあるサービスラッチを横切っており、技師はラッチ経路を開く時だけこれを破る。Deep Reach はこうしたシールを好んだ。保管記録が整って見えるからだ。Marauder が好む理由は別にある。安いシールは人間ほど器用に嘘をつかない。

        室内から引かれたシールは、繊維金属の縁を乾いた側へ持ち上げ、裂け目の下へ手袋の汚れを引き込む。廊下側から工具を入れた場合は外側の塗装が先に切れ、フックの下に古い塩が残る。交換されたシールは傷だらけのラッチの上で不自然に清潔だ。新しい接着剤、古い酸化、そして本来なら接着剤が金属に触れる場所の鉱物粉。方向は小さな手掛かりだが、閉じ込められた作業員の手と、あとから記録を整えた手を分けられる。

        シールはラッチガラス、カセット歯、圧力インクホイールと一緒に読む。ガラスは力の向き。歯はテープの引き。ホイールは記録時の湿り方。サービスシールは、ベイが正式に閉じていたのか、室内から開いたのか、廊下から開いたのか、回収後に再封印されたのかを示す。一つの部品だけなら曖昧なこともある。四つが清潔な転写記録に逆らうなら、それは保管上の問題だ。

        プレイヤーの手順は単純だ。切る前にスキャンする。カッターはきれいなアクセスを作るが、裂けた縁を壊す。裂け目が室内を向くなら、その部屋を最初のアクセス側として記録する。外側フックが古い塩の上に乗っているなら、音声は後で扱われたものとして印を付ける。接着剤がラッチより清潔なら、誰かが最後の正直なストリップを見栄えのよいものに替えた。

## Scanner

サービスシール裂け // レコーダーベイのサービスラッチ上にある繊維金属ストリップ。裂けた縁、接着痕、タグ下の塩、手袋の汚れから、どちら側がシールを引き、いつラッチに触れたかを読む。

## Terminal

整備メモ // 切断前にシールを撮影。内側からの引きは繊維を乾いた区画側へ起こす。古い塩の上にある外側フックは後日のアクセス。汚れたラッチ上の清潔な接着剤は交換を示す。
