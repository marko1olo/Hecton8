# HECTON-8公開入門

HECTON-8は単なる犯罪現場ではなく、生き残る価値のある場所として紹介される。この月はAegir系に属する。冷たく、潮汐に縛られ、価値があり、迅速な救助には不便なほど遠い。フォティックシェルフは透明で生きていて、明るい水越しにコロニーの機材が見えることもある。その美しさの下で、古いDeep Reachの経路はポンプ室、耐圧通路、塩水の切れ目、壊れた中継ヤード、人々が返事をやめた後も動き続けた機械へ降りていく。公開入門はネタバレ安全のままだ。プレイヤーが債務に縛られたMarauderとして戻ることは言える。コロニーが失敗したこと、サルベージ契約が強制的であること、海が証拠を抱えていることも言える。最終payloadの選択やAtlasの問いの全体は明かさない。目的は、世界の牙を丸めずにプレイヤーを招き入れることだ。
