# 圧力封じ込め失敗

圧力封じ込め失敗は、blue debtに読める物質挙動を与える。深部圧力がそれを整合させたから価値があり、浅い扱いがその整合を壊すから危険だ。段階0は密封。段階1はドリフトし、噴出口再加圧で救える場合がある。段階2で格子が割れる。段階3で塩水と生物が入る。段階4では価値の死んだサンプルが装備、水、ルートを汚染する。

## Scanner

容器段階図。blue debtは圧力記憶、信号せん断、bloomで失敗する。迷信は酸素の無駄だ。

## Terminal

封じ込め段階: 0 密封格子; 1 信号ドリフト; 2 格子破断; 3 塩水/生物bloom; 4 死んだサンプルと生きた汚染。噴出口再加圧で回復可能なのは段階1のみ。

## Audio

サンプルは君を憎んでいない。形成された場所へ戻ろうとしている。

## Field Note

ある深度で財産だったサンプルが、十メートル後には負債になる。
