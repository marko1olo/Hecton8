# 経路許可スタンプ

経路許可スタンプは、コロニーの小さな移動言語だった。勤務板、ハッチタグ、スーツチップ、車両スレート、工具棚、封印された経路カードに残る。良いスタンプは物語を語らない。一人の作業者を、一つの場所、一つの任務、一つの予定された帰還印に結びつける。

浸水後に重要なのはそのためだ。ロッカーの名前は、その人が存在したことを示す。経路スタンプは、システムがその人をどこへ送ったかを示す。PUMP、SEAL、RELAY、BRINE、FORGE、TRIAGE、BOTANY、WITNESS は飾りではない。誰がロックを越え、サービス通路に入り、ポンプ幹線に触れ、塩水カートに乗り、リレーパケットへ署名し、医療扉の前に立つかを決めていた。スタンプがない、遅い、取り消されている、周囲の金属より清潔すぎる場合、部屋は記録に反論し始める。

スタンプは物と一緒に読む。スタンプ済みで一度も開かなかったハッチは拒否だ。期限後に開いたハッチは遅い命令か、無許可の救助だ。削れた床塗装の横に空白の帰還欄があるなら、誰かが出て、権限を持つ誰も戻って閉じなかった。古い塩の上の新しい管理ステッカーは、後から物語を直した印だ。Deep Reach はスタンプを好んだ。人を手続きに変えられるからだ。Marauder は逆の理由で好むべきだ。手続きは指紋を残す。

経路タグだけを剥がすな。パネル全体より運びやすいからという理由では足りない。パネルには圧力状態、水位線、工具痕、扉の方向がある。タグだけでは収集品の雑音になる。部屋と一緒なら、誰が送られ、誰が止められ、誰がきれいな損失カテゴリへ変換されたかをまだ知っている。
