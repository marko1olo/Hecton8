# Return Action Queue の署名

Return Action Queue の署名は、古い HECTON-8 事件を2190年の現在の圧力につなげる。この queue は歴史アーカイブではない。Aegir の live window 中に遅延パケットを処理し、Black Keel または relay owner が何を先に行うかを順位付けする。回収された strip では、payload custody、coordinate receipt、quarantine handshake が contractor recovery より上位にある。これにより、部屋に司令官がいなくても Deep Reach は危険なままだ。下位オフィスは、どの action が実行可能なほど clean かを決めるだけで、rescue window を曲げられる。
