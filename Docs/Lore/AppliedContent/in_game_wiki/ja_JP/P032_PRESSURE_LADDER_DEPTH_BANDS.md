# 圧力ラダー

圧力ラダーは、HECTON-8 の深度進行を支える経路ロジックだ。レベル名の一覧ではない。深い帯域に進むたびに、同じ実務上の問いがさらに厳しくなる。スーツのシール、バッテリー、酸素ループ、断熱、信号、帰還 ping は、次の降下を同時に生き残れるのか。

最初の棚では、帰還ラインをまだ見つけられるため、損傷装備での短時間作業が通る。サービス棚では、各深度ゲートがスーツ等級とバッテリーラッチを確認する。ブライン峡谷では断熱と浮力調整が必要になる。塩分、熱、密度差が、降下中に良好な読取を悪化させるからだ。深淵機械場では硬化信号と船殻運用の規律が要る。遅れた ping は、経路がすでに背後に消えた合図かもしれない。Atlas 盆地では同じ連鎖にバスノイズと圧力損失が加わる。

ゲートを許可と見なす前に、保守盤を読め。ひとつでも赤い読取があれば、次の降下は劇的ではなく、手順違反だ。最も弱いシール、パック、ループ、ラップ、リレーを先に直す。
