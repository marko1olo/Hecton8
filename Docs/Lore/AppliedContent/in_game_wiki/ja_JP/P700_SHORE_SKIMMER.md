# 岸すくい

八メートルより下には行かない。だから在ることより、無いことのほうが使える。

群れは水面を切れ目のない一本の線になって進み、うねりが寄せたものを食う。その線が途切れて四十メートル先で再開しているとき、切れ目の水は緑色で、食い尽くされている。すくいは一匹も入らない。取水中の潜水士も入る必要はない。

ちらつくものはすべて叩かれる。水面近くでランプを構えれば、線ごと二秒間フェイスプレートに来る。スリングを満載していれば、それだけで水平が分からなくなる。

スコールの四十秒ほど前に隊列が崩れる。Class-IVの気圧計より早い。Annexが船体板を失った朝、水面は平らなまま線がばらけた。

評価：線をたどり、線が終わる切れ目は閉鎖水域として扱う。
