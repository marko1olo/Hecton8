# ランタンドリフト偽安全エンカウンター文法

ランタンドリフト偽安全の遭遇は、プレイヤーにまず光を欲しがらせ、それから疑わせるべきだ。明るいレーンは酸素膜、ケーブルの弧、浮遊粒子、リーフの乱雑さを抜けるきれいな道を見せることがある。同時に、それはプレイヤー自身の航跡、嵐帯電の残留、古いインフラからの信号ノイズ、または小動物がすでに退いた捕食者移動線かもしれない。この文法は同じ美しさが複数の意味を運ぶ時に働く。色だけで経路を解いてはならない。パルス速度、流れの向き、グレイザー反応、残留物の側、pinger戻り、工具音が一致してからレーンを信用する。光がプレイヤーの後ろで鋭くなるなら、遭遇は露出になった。前方で明るくなり、動物が静まるなら、餌になった。ランタンドリフトは証人として追え。約束として追うな。

## Scanner

ランタンドリフトのレーン。明るい水は酸素縁、信号ノイズ、工具航跡、または捕食者でずれた通行を意味し得る。追う前に流れを確認。

## Terminal

遭遇文法 / ランタンドリフト偽安全 / 役割: 曖昧なデータとしての美、経路誘惑、stealth低下 / 安全な読み: 流れと光が一致、動物が通常反応、残留物が予想側にある / 拒否: 青い光を安全と見る、嵐帯電の偽回廊を追う、光る航跡内で騒がしく修理する / 経路注記: 一つの光は道、餌、恐慌の記録、または露出になり得る。
