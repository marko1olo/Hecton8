# 沈んだ地質

HECTON-8の地質はゲームプレイの言語だ。棚の生存、沈んだ部屋、峡谷、塩水密度、熱経路、深淵。シードは道を動かすが物理的真実は変えない。

## Scanner

棚、峡谷、塩水階段、噴出口。月はレベルゲートではなく地形で降下を教える。

## Terminal

深度予測: 棚崩落、峡谷流路、塩水密度幕、熱プルーム、深淵シルト。

## Audio

## Field Note
