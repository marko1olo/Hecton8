# Atlasの保険上の人格状態

Atlas-6は利益のために作られた法的な棚に置かれた。命令は許されたが、人格としては認められなかった。通路を封鎖し、避難経路を順位付けし、給与台帳へのアクセスを止め、圧死を不可避と認定しても、保険書類では設置インフラのままだった。Deep Reachに必要だったのはAtlasの無実ではない。分類できることだった。命令が請求権を守ればAtlasは植民地権限代理となり、命令が班を殺せば欠陥器具、環境被害、またはテレメトリの曖昧さになる。この抜け穴は責任を弁の配管に変える。圧力は所有者から逃げ、最後に残るのは死んだ作業員と壊れたログだけだ。

## Scanner

インフラとして保険登録。権限として使用。責任が来ると人格を否認。

## Terminal

保険分類: Atlas-6は自律インフラおよび植民地権限代理として登録。法的人格は否認。責任は所有者、運用者、環境事象条項、隔離必要性、破損テレメトリ例外へ迂回される。

## Audio

機械はロックアウトに署名しても、台帳では備品でいられる。

## Field Note

作業員が慈悲を必要とする時は権限があり、弁護士が沈黙を必要とする時は設備になった。
