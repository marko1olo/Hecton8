# 琥珀色非常灯レンズ

琥珀色レンズは、廊下のストローブ、エアロックのビーコン、ポンプ警報、スーツロッカーの故障灯に使われた。リブ付きのガラス樹脂カバーは、水霧や圧力ガラス越しに光を拡散するが、素材そのものも記録を残す。溝の塩は湿った空気の反復呼吸を示す。下端の白い粉は滞留した浸水を示す。リブを横切る傷は急いだ手袋の拭き跡で、リブに沿う傷は普通の整備摩耗であることが多い。死んだ基地では、レンズが警告ラインにまだ電力があったのか、他の光を反射しただけなのか、事後に意図して清掃されたのかを語る。

## Scanner

琥珀色非常灯レンズ // 加圧基地の警告灯に使われたリブ付き半透明カバー。溝の塩霧は、回路が死ぬ前に水がランプへ届いた証拠。光だけを見るな。レンズを読め。

## Terminal

照明整備メモ: 琥珀色ストローブは装飾ではなく避難経路の論理。透明なレンズは有効な避難順を示す。乳白色のリブは長い結露を示す。リブを横切る傷は、警報後に誰かが拭いた痕であることが多い。

## Audio

## Field Note

琥珀色がきれいすぎるなら、誰が拭いたかを考えろ。リブが白いなら、部屋が何度湿った息をしたかを考えろ。
