# Deep Reach圧力セラミック

Deep Reach圧力セラミックは、HECTON-8の現地鉱物を窯、触媒槽、噴出炉サイクルに通し、金属ならクリープや固着を起こす圧力を保持できるようにした素材である。クランプリング、シール座、カッター接点、上昇クレードル断熱に使われ、修理と脱出チェーン製作に不可欠だ。危険なのは素材が邪悪だからではない。悪い管理下で有能すぎるからだ。リングは何年も保持し、その後、熱衝撃や誤った減圧順序で刃のような破片を咲かせる。
