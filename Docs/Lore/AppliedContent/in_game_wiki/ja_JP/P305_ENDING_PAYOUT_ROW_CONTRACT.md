# エンディング支払データ境界

境界はエンディングを勝利点ではなく取引記録として保つ。支払は重要だが、保管、公開証拠、隔離、債務、プレイヤーが去った後の受信者の行動権も同じく重要だ。

## Scanner

エンディング行は受信者、保管、証拠状態、支払、未解決結果を結びつける。

## Terminal

ENDING PAYOUT CONTRACT: 行には payload ルート、受信者、証拠状態、物質支払、法的結果、隔離遅延、未解決コストが必要。クレジットは犯罪現場を閉じない。
