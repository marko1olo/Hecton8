# 証拠関係グラフ調書

関係オーバーレイは裁判官のためではなく、疲れた調査員と怯えたサルベージャーのために作られた。共通のソース物体、航路プレート、請求語句、証人ハッシュ、キャプション系統、負傷痕、編集状態、可視の結果がある記録を同じ机に載せる。圧力下で模様が見えるようになる。だが、偽の確信も簡単に作る。

ハッシュ一致は証言の真実を証明しない。キャプション一致はソース回収を証明しない。同じ編集状態は、同じ事務員が同じテンプレートで切っただけかもしれない。オーバーレイが有用なのは、保管履歴、ソース物体、請求文言、証人ハッシュ、航路結果、編集理由、キャプション順に注意を配る場所を示すからだ。線を評決として扱った瞬間、それは危険になる。

## Scanner

関係オーバーレイ // エッジは共通の物体、語句、ハッシュ、結果、キャプション、編集状態を示す。確認用の合図であって、告発でも免罪でもない。

## Terminal

調書グラフ凡例
緑: ソース物体または航路プレート一致。
琥珀: 請求語句またはキャプション系統一致。
赤: 証人ハッシュ、負傷痕、抑圧結果一致。
灰: 編集状態のみ共有。
すべてのエッジは保管履歴と照合すること。美しいグラフも、直線で描いた嘘であり得る。

## Audio

記録同士の線は、次に見る場所を示すだけだ。誰が有罪か、安全か、沈黙を買ったかは示さない。

## Field Note

きれいなグラフに考えさせるな。線は安い。キャプションと編集状態こそ、嘘が出荷できるほど安くなる場所だ。
