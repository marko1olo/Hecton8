# 質量保管トン窓台帳

tonne-windowはメートル法の服を着た通貨ではない。身体、試料、電池、圧力スリーブ、証拠パケットが同じ上昇burnを求める時、Black Keelが使う単位だ。金の議論は後でできる。質量は今運ばなければならない。

だからcarrierは、計算が正直でも残酷に感じる。海は重要な物を渡す。封印substrate、作業員バッジ、ブラックボックスのスプール、予備酸素、割れたpressure glass。Keelmarkはそれぞれを保管クラスに変える。Black Keelはそのクラスを質量、体積、隔離リスク、熱、バラスト、受信者責任に変える。そして台帳は汚い問いを出す。次の揚収窓を占めてよいのはどれか。

プレイヤーは答えを変えられる。ただし無線に叫んでも変わらない。認証済みの上昇スタックは一つの異議を消す。隔離handshakeは別の異議を消す。公開証拠hashはパケットを埋めにくくする。汚染試料を捨てれば身体の余白を買える。残せば真実と債務軽減を買えるが、救助は難しくなる。tonne-window圧力はメニュー税ではない。salvageの選択を物理にする物語ルールだ。
