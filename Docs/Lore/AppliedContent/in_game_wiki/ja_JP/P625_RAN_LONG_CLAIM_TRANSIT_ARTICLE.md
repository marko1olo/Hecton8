# Ran Long Claim航路通過

古い中継殻の下で見つかった航路プレートは、多くのMarauderが遅すぎる時点で問う疑問に答える。人類はAegirに届く。だが到達は救助ではない。Ran Long Claimは、播種貨物、パケット梯子、燃料デポ、検疫法、そして信号が一季節で越える距離に何年もかけるキャリアの鈍い鎖に乗っている。生存証明のバーストはSol、Luyten、Barnardを通過しても、それを送った身体はまだ局地天候、質量制限、債務権限の下に押さえられていることがある。Black Keelは君を聞ける。先取特権を記帳し、保管案件を開き、tonne-windowを予約できる。だが水中で怯えるダイバーのためだけに、キャリア船体を真空越しに動かすことはできない。

## Scanner

航路プレート // Ran Long Claim、Aegir交通帯。パケットは窓で通る。船体は質量、曳航時間、検疫、引き受けられた責任で通る。

## Field Note

一枚のプレートにSol、Luyten、Barnard、Aegirが一行で並んでいたら、順番を読め。Solは法を持つ。Luytenはパケットを持つ。Barnardは手を持つ。Aegirは天候を持つ。次の一息を持つ者はいない。
