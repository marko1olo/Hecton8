# Aegir 月群役割台帳

Aegir の月リストは稼働中の交通図だ。ガス巨星の周囲にある各天体は、交通、サルベージ請求法、通信タイミング、または HECTON-8 からの離脱計画を変える。

## Scanner

公開名はチャートの間で揺れる。軌道の仕事は変わらない。

## Terminal

ATLAS LEDGER: 公開ラベルは保険者と航路チャートごとに変動する。機能役割は固定: 放射線シア、リレーマスク、潮汐強制、氷散乱、公開航路、検疫噂、工業 salvage、高窓交通、深部請求、死ビーコン経済。

## Audio

月の名は変えられる。軌道の請求書は残る。

## Field Note

Skarn は粒子を裂く。Vela はリレーを隠す。Claw は氷を投げる。Lumen は航路を印刷する。Thorne は検疫の噂を運ぶ。Anvil は salvage を供給する。Kestrel は高窓を押さえる。HECTON は深部請求を抱える。Mute は死んだビーコンを売る。
