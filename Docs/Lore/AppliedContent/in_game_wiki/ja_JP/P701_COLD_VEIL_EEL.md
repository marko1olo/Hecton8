# 冷幕ウナギ

断熱材と間違われることで狩る。そして1,900メートルの水は、外れた断熱材で満ちている。

裂けた制振マットはたるんで垂れ、流れに従って漂う。冷幕ウナギはその横で片方の縁をまっすぐ保つ。違いはそれだけで、素材ではなく縁を見ていればランプの距離で読める。

冷えが必要なので、2147年の周期で四十分ごとにまだ噴出しているスクラバー・ベイ7で働く。ウナギは、始動の打撃音が甲板を伝わってから四秒後に壁を離れる。接触は切らない。スーツの循環が戻すより速く熱を抜き、冷えたシールは硬いシールだ。

六回に一回の周期は出てこない。

評価：ベイは噴出の合間に扱い、縁が固定されている板状のものはすべて動物として扱う。

## Scanner

冷水性の板状形態、片縁を固定保持。信頼度55パーセント。危険：接触時の熱損失。限界：九メートルを超えると制振マットと分離できない。

## Terminal

標本 44-E-503。区分：温度計測器、計画外。場所：スクラバー・ベイ7 排出、1,900 M。タグ 7742-C：送信中。ベイ周期：維持。人員：2147年以降不要。

## Field Note

計測器と呼ばれているのは、保守経路がタグを前縁に育て込み、排出ループが今もそのタグの送信を記録しているからだ。水ではなく、始動の打撃音を見ておけ。
