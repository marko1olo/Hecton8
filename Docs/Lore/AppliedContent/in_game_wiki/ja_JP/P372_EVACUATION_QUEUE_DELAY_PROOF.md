# 避難キュー遅延記録

この記録は避難を不明な結果ではなく、順序ある遅延に変える。警報、審査、シール等級超過、遅すぎる解放の順だ。Deep Reachは避難が未完了だったと言える。だがキュー時計は、通路圧が安全線を越えた後も手続きで閉じられたゲートを示す。
