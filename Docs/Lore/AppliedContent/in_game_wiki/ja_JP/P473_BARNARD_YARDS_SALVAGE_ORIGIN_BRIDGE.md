# Barnard Yards サルベージ起源

Barnard Yards は、作業者が HECTON-8 の最初の修理順を知る理由だ。抜水、隔離、等級内のパッチ、サービス金属だけ切断、証拠保全、それから移動。この能力は自由ではない。同じヤードの論理が工具、訓練、死んだ請求を Black Keel が値付けできる債務に変える。

## Scanner

BARNARD YARDS 工具タグ // レンタルカッター柄。圧力クランプ証明有効。債務窓は Black Keel 受入と接続。作業者は死んだ請求サルベージ訓練済み、無料救助ではない。

## Terminal

BARNARD YARDS レンタルカウンター // 支給: 誘導カッター、クランプセット、封印ゲージ、証人スリーブ。リエン注記: 工具紛失、汚染、未認証切断、payload 証人失敗は契約作業を回収可能債務に変える。切る前に抜水。上げる前に等級確認。売る前にタグ付け。

## Audio

借りたのはカッターで、請求権ではない。柄、クランプ数、清潔な証人タグを戻せ。

## Field Note

Barnard は静かに切り、債務を大きく読むことを教える。カッタータグは製造番号付きの綱だ。
