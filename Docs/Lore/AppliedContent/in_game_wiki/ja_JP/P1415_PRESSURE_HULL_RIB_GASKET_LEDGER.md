# 耐圧リブとガスケット台帳

HECTON-8の耐圧外殻は、ただの金属板ではない。白い外板は皮膚にすぎず、黒いリブが圧力を逃がす骨格になる。ガスケット溝は水を止める境界で、塩筋は長い漏れの低い道筋を残す。橙の塗装は飾りではなく、手が入る場所を示す。

まっすぐなボルト列は、部屋が一体のまま動いた印だ。裂けたガスケットと白い塩は、ゆっくり水が入った記録になる。内側へ曲がったリブは外圧の勝利、外側へ膨らんだリブは内部の排気や破裂を語る。平らな板だけを見て切ると、静かな残骸が動く鉄屑に変わる。

Deep Reachの図面はきれいだった。海底の外殻はもっと正直だ。過負荷のリブ、規格違いの補修材、避難後に開いたハッチ、戻るつもりで貼られた応急パッチまで残している。略奪者にとって外殻読取は知識ではなく、生存手順だ。

## Scanner

耐圧外殻 // 白い外板、黒鉛色のリブ、押し潰された黒いガスケット。塩筋は低い継ぎ目から落ちる。ボルト列が直線なら、モジュールは一体で動いたが開いてはいない。

## Terminal

外殻読取 // リブ間隔は飾りではなく耐圧モジュールを示す。ガスケット溝が生きていれば、奥に乾いた空間が残ることがある。リブ角の橙塗装は保守口の合図だ。切断前にラッチ側を確認する。
