# 塩水密度ルート台帳

Brine Stairs は洞窟の階段ではない。普通の海水の下に重い塩水が重なり、境界だけが床のように光る。真下へ撃った sonar は石の床のような返事を返すことがある。信じた潜水者は重い層へ落ち、トリムを失い、ケーブルを削り、固体ではない白い皮の下へ沈む。

古い植民地は小さな計器でこの階段を読んだ。横 ping は壁、棚、密度カーテンを分ける。バラストの反応は、スーツが普通の水にいるのか塩水に支えられているのかを示す。温度低下は、熱い水が冷たい塩の上を滑る場所を教える。きれいな地図線より岩のケーブル傷が信用された。

Marauder にとって台帳は恐怖を手順に変える。塩水カーテンは捕食者やドローンから航路を隠し、過熱した cutter を冷やし、何年も避難タグを保存する。だが seal を食い、音を曲げ、嘘の床を作る。2800-3600 m の Brine Stairs では横 ping、トリム、漂流待ち、傷跡での横断が生存手順になる。

## Scanner

塩水台帳 // 前方に密度境界。ソナー反射は見えている棚より低く曲がる。バラスト応答の遅れを想定。降下前に横からカーテンを打診し、二つのトリムが一致するまで光る床を流体として扱え。

## Terminal

DEEP REACH ルート板 B3-17 // 白い反射に着底するな。重い塩水の上に張った塩皮だ。横断前にトリム補正、温度低下、ケーブル擦過深度を記録。消えた避難ポッドの最後の ping は第三カーテンの下で、地図上の床ではない。

## Audio

床が磨かれて見えるなら疑え。横から ping を撃ち、手でバラストを抜き、塩水に深度を書かせるな。

## Field Note

塩は管理者より正確な地図を書く。きれいな線ではなく傷を追え。
