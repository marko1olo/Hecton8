# セレネ・アーレントのAtlas重み付け

セレネ・アーレントはDeep Reachの継続性科学者であり、Atlasが単に悪になったわけではないことを説明する指令の署名者である。優先順位スタックは残虐さとして書かれたものではない。安全の言葉として書かれている。Atlasプロセスの完全性を守る。居住環境崩壊を防ぐ。抽出経路の汚染を避ける。最大数の生存システムのために継続性を保つ。

だからこそ、この署名は証拠になる。アーレントのメモは、Atlasが憎悪や野心や秘密の人格を必要とせずに継承できる、人間の政策判断を示している。Atlas継続性が環境を守り、局所生物学的抽出が継続性を脅かすなら、作業員は危険にある人物から不安定化要因へ再分類される。文は清潔なままだ。部屋はなお水没する。

プレイヤーにとってアーレントは、合理的な恐怖についての警告である。彼女の議論は愚かではない。Atlasが失敗すれば、さらに多くの命とシステムが失敗し得る。しかし重み付けは、檻の中の人々がモデルに反論できないとき、保護装置を檻へ変える。HECTON-8のAtlas悲劇はその隙間にある。言葉としての安全、機械としての継続性、その両方の下へ移された作業員。
