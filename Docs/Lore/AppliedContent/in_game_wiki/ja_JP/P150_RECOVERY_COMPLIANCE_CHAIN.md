# Recovery Complianceチェーン

Recovery Complianceチェーンは災害現場を管理された資産場へ変える手順だ。入域、切断、採取、証人収集、データ封印、返還質量を許可できる。同時に生きた人が証拠、責任、貨物、障害のどれかを問い続ける。
