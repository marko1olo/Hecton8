# receiver counterstamp の部屋番号

receiver counterstamp は blank berth が named door になる瞬間だ。recovery を無視しにくくするが、lift 後に body を所有する者の名前も書く。stamp を信じる前に room class、medical owner、receiver strip を確認する。

## Scanner

COUNTERSTAMP READ // quarantine room number あり。body custody class 確認。sample-only rooms は living recovery を clear しない。

## Terminal

RECEIVER ROOM COUNTERSEAL // blank berth は owned custody で上書き。lift allocation は named room、owner、body class がある時だけ進む。

## Audio

room number 記入済み。receiver が扉を所有。ascent burn 前に body custody を確認せよ。

## Field Note

room number は取っ手だ。慎重に引け。一部の扉は檻だ。
