# ブラインベーン航法エンカウンター文法

ブラインベーン航法の遭遇は、中深度の水が空ではなく構築物だと教える。プレイヤーはベーン場を壊れた階段のように読むべきだ。完全な膜は壁、裂けた口は可能な開口、丸まった先端は弱まるせん断、見えるベーン縁のない黒い隙間はsonarが床を発明する場所だ。この遭遇は、最も美しい光へ直進するのではなく、遅い移動、控えめな浮力トリム、角度変更を求める。Atlasが同じ密度境界を修理経路に使うことはあっても、流れは物理のままだ。この区別が重要だ。海は話していない。過程を可視化している。良いブラインベーン経路は、一つの縁を追い、二つ目の角度からpingし、driftを試し、開いた近道を拒んだことで賢く感じさせる。

## Scanner

ブラインベーン場。そろった膜は密度の曲がりを示し、丸まった先端は弱い窓を示す。開いた発光近くではsonarが歪む。縁を一つ視界に保て。

## Terminal

遭遇文法 / ブラインベーン航法 / 役割: 中深度経路読解、密度壁の手すり、偽床補正 / 安全な読み: 完全なベーン縁、裂けた口、浮力 drift と一致するsonar屈曲 / 拒否: 黒い開水を横切る、案内膜を切る、ベーン境界なしの床反射を信用する / 経路注記: ベーンは意図で導かない。追えるほど大きな声で水に従っている。

## Audio

ベーンは標識ではない。水が壁を作り、継ぎ目を残している。

## Field Note

ベーン縁を手すりとして扱え。線が変に曲がるなら、浮力の読みはもう遅れている。
