# Aegir系公開入門

AegirはHECTON-8の実用的な形を決める。この系は物語の周囲に描かれた空ではない。経路が開き、閉じ、遅れ、高くつく理由そのものだ。HECTON-8は月の梯子、潮汐、放射線窓、運搬船の遷移軌道、中継角の中を動いている。メッセージは救助艇が入るより先に出られる。請求は人間抽出スタックが準備されるより先に値付けされる。Black Keelが答えられるのは、信号が遮蔽質量の移動より安いからだ。それはAegirを空虚で到達不能にしない。むしろ産業的にする。スケジュール、燃料余裕、検疫文言、月影、海洋潮汐、軌道保管が一人の潜水者にのしかかる。公開Aegir文は、科学を硬く、ドラマを実務的に保つべきだ。この系は機能している。だからこそ、置き去りは沈黙ではなく手続きになれる。

## Scanner
