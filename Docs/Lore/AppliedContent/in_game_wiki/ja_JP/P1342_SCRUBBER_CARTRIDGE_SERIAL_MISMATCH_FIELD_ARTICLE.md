# スクラバー・カートリッジのシリアル不一致

スクラバー・カートリッジのシリアル不一致は、机で替えられるスリーブではなく、本体に固定された小さなプレートから始まる。水没したサービスベイでは、そのプレートが塩の縁、ラッチの傷、充填喉部の染みの下に残ることがある。プレートが酸素台帳や補充スリーブと食い違うなら、まず本体を読む。

カートリッジは空気と書類の間にある。部屋の負荷を処理し、台帳は稼働窓を数え、スロットラッチはどの本体が枠に入っていたかを示し、補充スリーブは倉庫が出したと主張する物を示す。本来それらは一緒に動く。ラッチ下の塩水線が清潔なスリーブより古い場合、その順序が読みを変える。

Deep Reachは問題を作るために化学を偽る必要はなかった。遅れて来たスリーブだけで、ベイを補充済みに見せ、claim deskメモを開いたままにし、故障した部屋から遮断行を遠ざけることができる。シリアルプレートは触った人物を名指ししない。だが空気勘定が支援として機能しなくなった後、誰かがカートリッジを扱った時間幅を狭める。

現場処理は遅くなる。証拠が低く濡れているからだ。プレート、ラッチ塩、スリーブ継ぎ目、喉部の塩水、台帳行を記録する前にカートリッジを抜かない。スリーブは別袋にする。ラッチのどちら側に塩が残っていたかを印す。清潔な包みは悪い部屋を直さない。シリアル不一致は、交換という言葉が物理的な支援を越えた場所を示す。
