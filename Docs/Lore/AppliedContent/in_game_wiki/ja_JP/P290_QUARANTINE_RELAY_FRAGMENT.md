# 隔離リレー断片

隔離リレー断片は、小さいが牙のある終わりだ。HECTON-8は圧力から誰かを救い出しても、その人を人間として返すことを拒める。このパケットは同じ事務的な息の中で二つの事実を運ぶ。搬出承認、解放拒否。身体は回収された。本人は保持された。空気審査の行は救助受領より古く、つまり隔離判定は誰かがハッチを開ける前から待っていた。ゲームプレイとロアにおいて、この断片は救助を道徳的に不完全なものにする。乾いた床は自由ではない。医療封印は解放ではない。植民地は必要なものを証拠、試料、請求者財産、証人目録として保存し、人間だけを傷つけたシステムの中に残せる。

## Scanner

同じリレーパケットが搬出を承認し、解放を拒否する。海は身体を放すが、植民地は人間を放さない。

## Terminal
