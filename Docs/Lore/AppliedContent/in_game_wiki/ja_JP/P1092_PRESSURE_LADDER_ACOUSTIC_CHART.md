# 圧力階梯音響図

圧力階梯音響図は、調査データに見せかけた生存地図だ。HECTON-8は一つの海ではない。有光棚にはわずかなRanの光と嵐の生物圏が残る。ケーブル礁は古いDeep Reach設備に工具とピングを絡め取る。塩水峡谷は浮力を曲げ、ソナーを芝居にする。機械原は圧力で潰れた工場で、今もAtlas修復論理に応答する。Atlas Basinは暗く、熱く、金属的で、悪い分類で生きている。

上層海洋の下では、音が唯一の実用的な視線だ。ただし音は無料で正直にならない。塩の層は音を閉じ込める。熱水孔は音を裂く。ケーブルの床は音を返す。きれいな反射は壁、捕食者の航跡、管の記憶、または自分の恐怖を返すリレーかもしれない。規則は単純だ。下降はシール、酸素、電池、戻りピング、疑いで許可される。
