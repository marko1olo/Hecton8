# 穴待ち

狩りはしない。穴を借りて、通路が届けるのを待つ。

使われている窪みは、危険に見えるより先に不自然に見える。冠水した翼区で、空いている縁にはどれも柔らかいシルトの襟がある。使われている縁は拭ったようにきれいだ。動物が数百回そこを出入りしているからだ。読むのは縁で、暗がりではない。

打撃はまず窪みから水を押し出すことで始まる。Class-IVでは、接触の約0.5秒前に胸板への圧の一突きとして届く。その一突きを信じる潜水士は生き残る。ランプの光円錐を見ている潜水士は残らない。

自然の開口よりも切り抜き開口を好む。その好みを説明した者はいない。評価：きれいな縁へは上方から、その喉の外側を通って接近する。あるいは翼区ごと迂回する。

## Scanner

大型の待ち伏せ摂食種、切り抜き開口を占有。信頼度71パーセント。危険：打撃距離が可視体長を超える。限界：第二の角度がなければ体長を測定できない。

## Terminal

標本 44-B-207。区分：入退管理資産、付随。位置：東側下層 作業用喉部。備考：翼区閉鎖は所定の閘門修理を行わずに維持。再審査：不要。

## Field Note

会社がこれを入退管理として記録したのは、動くドアより安く東翼区から人を遠ざけたからだ。ホリスも入れなかった。手を入れる前に、縁の拭き跡を確かめろ。
