# Black Keel請求プール憲章

Black Keel請求プール憲章は、プレイヤーに船という言葉を疑わせる最初の文書である。Black Keelは有用で、近くにいて、実在する。しかし頭上で待つ忠実な船ではない。Aegir Reclamation Pool内の賃貸回収資産であり、請求、遺体、貨物、テレメトリ、債務を法的チャンネルに通すために作られている。契約者に船体所有権を渡すためではない。この違いが重要なのは、HECTON-8の中心的な罠を魔法抜きで説明するからだ。キャリアはpingを聞き、テレメトリを売り、窓を組み、低リスク物資を落とせる。それでも、プレイヤーが経路の所有者ではないため、清い救助を拒否できる。輸送は許可される。救助優先度は条件付き。lienは残る。憲章は軌道を自由ではなく圧力に変える。あなたの上には何かがいるが、それは人間より先に請求へ答える。
