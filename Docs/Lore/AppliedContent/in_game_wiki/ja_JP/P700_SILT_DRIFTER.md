# 泥漂い

泥漂いの掘り跡は開けた底では直線に走り、まだ水を引いているものがある場所で曲がる。

流れが運んでくるものを食うので、曲がりは五十から九十メートルの生きた取水口であり、四十三年たってなお通電している設備ということになる。それが同時に危険でもある。堆積物を選り分けられる強さの格子は命綱を引き込むし、そこは当時から一度も点検されていない。

驚かせれば底ごと水中に吐き出す。広い光束はその濁りを切らない、満たすだけだ。弱い光に落とし、方位を保ち、上ではなく横へ、通路の外へ抜けろ。

掘り跡は6番から11番までどの格子でも反時計回りに曲がる。逆向きに引いている二基でも同じだ。

評価：まず曲がりを読み、格子は通路の外側から扱う。

## Scanner

底層の堆積物食者、40〜90メートル。信頼度66パーセント。危険：接触時に視界喪失。限界：巻き上がった堆積物越しでは反射が返らない。接触は失われ、回復しない。

## Terminal

文書 44-M-1180。区分：堆積物管理、受動。範囲：取水格子6〜11、40〜90 M。予定浚渫：廃止。格子点検：現行とみなす。

## Field Note

「格子点検は現行とみなす」とは、2147年以降だれも見ていないという意味だ。泥漂いが曲がりを保っているなら、その取水口はまだ引いている。命綱は通路の外に置き、格子は横から取れ。
