# 工場神殿の閾値

工場神殿の閾値は、海底工場の先にある最後の下部ゲート集合体だ。これは神話的な合体ではない。稼働中の荷重分担である。Deep Reachのトラスは古い船体応力を受け、戻り配管はブラインと熱を動かし、炭酸塩の成長が壊れたガスケットを塞ぎ、Atlas-6はまだ応答する接点を通して継続性を経路化する。読む手掛かりはクランプ順、流れ跡、ケーブルバスのノイズ、タグの位置だ。

## Scanner

下部ゲート読取: 工場トラス、戻り配管、圧力シール、Atlas経路バスが同じ荷重を受けている。壁と扉のきれいな境界は残っていない。

## Field Note

地図のラベルは閾値と言う。言葉ではなくクランプを見ろ。ゲートが保っているのは、四つの系が同じ荷重を受けているからだ。
