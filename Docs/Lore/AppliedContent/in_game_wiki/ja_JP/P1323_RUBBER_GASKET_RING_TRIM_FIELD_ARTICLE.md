# ゴム製圧力シールリング

圧力ガスケットはHECTON-8工学の静かな部分だ。プレートとリブは見える荷重を受けるが、最後の一ミリを海が越えるかどうかは黒いゴムが決める。良いガスケットは飾りではない。部屋と海との間で圧縮された議論だ。

素材は記憶を持つ。ラッチ側リップが一方向に潰れていれば、そのハッチは荷重下で何度も閉じられた。溝の奥の塩は一度の崩壊ではなく、長い滲みを示す。裂けた外縁の下のきれいなゴムは、浸水後の強制開放を示すことがある。光沢のある膨れたリングは化学損傷、乾いた灰色の中心は、その奥の部屋が壁に見合わないほど長く空気ポケットを保った可能性を示す。

Marauderにとって、ガスケットを読むことは作業順序を変える。切る前にスキャンする。リングがまだ圧力を受けているか確かめる。公式避難時刻の後に扉が開いた証拠になるなら、シール痕を残す。ポケットが死に、ラインが安全で、証拠を読んだ後でのみ回収する。
