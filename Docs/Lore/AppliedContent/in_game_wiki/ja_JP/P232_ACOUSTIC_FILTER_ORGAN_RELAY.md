# 音響フィルター器官リレー

音響フィルター器官リレーは、HECTON-8 のソナー言語を科学的な調子を壊さずに身体的恐怖へ変える。古いリレー管の周囲で、鰓壁状の組織がバッフル、折り目、湿った室へ育つ。組織は話さない。インピーダンスを変える。広いポンプ騒音はそこで死ぬ。細いピンガーパルスは通る。戻りエコーはずれて返るが、そのずれは Atlas が使え、注意深い Marauder が学べるほど反復する。

重要なのは、反復する嘘はランダムではないということだ。器官の下流にある廊下は、プレイヤーがどの周波数が生きたフィルターを抜けるか学ぶまで、短く、広く、あるいは塞がって見えることがある。Atlas は、壊れた機械だけより圧力下で信号を保てるからこのリレーを使う。プレイヤーは証拠として使う。同じパルス幅で同じソナー誤差が現れるなら、部屋は呪われていない。フィルターしている。だからこのリレーは有用で、不快で、公平だ。

## Scanner

音響フィルター器官 // 鰓壁状の組織がリレー管の周囲に育っている。ポンプの轟音を弱め、細いピンガー信号を通し、ソナーを反復可能な嘘へ折り曲げる。
