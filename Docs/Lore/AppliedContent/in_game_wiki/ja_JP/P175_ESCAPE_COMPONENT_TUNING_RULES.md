# 脱出部品調整規則

脱出部品調整規則は、HECTON-8の終盤を発射ボタン付きの買い物リストにしないためのものだ。信じられる脱出路には部品が必要だが、各部品は素材コスト以上の何かを証明しなければならない。Relay spineは、プレイヤーが水と磁気ノイズを越えて通信できることを証明する。Clamp ringsは、カプセルまたは上昇物体が圧力下で形を保てることを証明する。Guidance coreは目的地の夢ではなくタイミングを証明する。軌道を願うのではなく、窓に入らなければならない。Ascent chargeはエネルギーとリスクを証明する。Legal handshakeは誰が応答し、誰が回収チャンネルを所有し、隔離がペイロードを受け入れるかを決める。Evidence payloadは結果を変える。プレイヤーは通貨、告発、試料保管、交渉力を持って離脱できる。証明が一つ欠けた時、それは単なる無効ボタンに見えるべきではない。部分回収、保管拘束、悪い受信者、請求失敗、沈黙で買った脱出という別の結末に見えるべきだ。

## Scanner

脱出部品はグラインドではなく、深度と証拠を要求するべきだ。HECTON-8を離れることは、高価なクラフト一回ではなく証明の連鎖だ。

## Terminal

脱出部品 / relay spine は通信を証明 / clamp rings は圧力定格を証明 / guidance core はタイミングを証明 / ascent charge はエネルギーを証明 / legal handshake は誰が応答するかを決める / evidence payload は結果と保管を変える。

## Audio

離脱は一つのクラフトではない。証明の連鎖だ。

## Field Note

各上昇部品には物理的理由と法的理由が必要だ。通信、定格、タイミング、エネルギー、受信者、ペイロード。一つ欠ければボタンを止めるだけでなく、結末が変わるべきだ。
