# 粘土シルト濁流斜面の野外記事

粘土シルト濁流斜面は、HECTON-8 が海底を証人に変える場所だ。最初は空白に見える。灰ベージュの堆積物、低いコントラスト、目立つ鉱石も劇的な洞窟口もない。だが光が当たると、圧縮リップル、線状に押し込まれた貝粒、ゆっくりした滑りが通った暗い湿った筋、上縁で斜面が裂けた新しい傷が見える。表面は空白ではない。浮遊粘土で書かれた文字だ。

この物質は古い濁流のあと、細かな堆積物が水中から落ちることで作られる。峡谷が咳をする。棚が崩れる。上の嵐や遠い潮汐パルスが汚れたシートを斜面へ送る。重い粒が先に止まり、粘土はさらに遠くまで行く。層ごとに、斜面は動きの静かな記録になる。

移動では、その柔らかさが危険になる。ブーツ、ドローンの滑走、カッターの噴き、雑な推進はただの泥煙ではない。読める表層を壊し、水を壁に変える。プレイヤーは視界、古い足跡、安全な堆積物と弱い張り出しの境界を失う。航法は音、手綱、忍耐になる。

斜面は証拠でもある。新しい滑落痕は、コロニーが振動制限を維持しなくなった後にどこが壊れたかを示す。圧縮リップルは埋もれた構造物の方を指すことがある。工具の引きずり跡は、自分の航跡で消す前なら、別の回収者の道を示す。

Deep Reach はこうした斜面を嫌った。きれいな地図を嘘にするからだ。シルトの上に描いた通路は、荷重に耐えるまで通路ではない。調査班は、承認が欲しい時には不安定面を季節濁りと呼び、誰かを責めたい時には作業者の乱れと呼ぶことを覚えた。

略奪者の規則は単純だ。床が証言できるように動け。渡る前に上縁をスキャンする。リップルが戻っていない暗い筋を見る。水が澄んでいるうちにピンガーを置く。斜面が粒でなく板として浮くなら、退いて待て。
