# 溶接シームとリベット列台帳

溶接シームとリベット列は、植民地の清潔な幾何が告白を始める場所だ。工場の船殻線は辛抱強く反復する。間隔、面取り、ガスケット、検査帯。現場修理はそう話さない。つまずき、膨れ、古い塗装に重なり、発射図面が熱を想定しなかった場所に熱痕を残す。

順番が物語を決める。後の溶接の下にリベット列があるなら、元の固定はもう信じられていなかった。ビード下の塩は、接合部が何度も水を呼吸した印だ。半分金属で埋まったガスケット溝は、整備性より強度を選んだ証拠だ。きれいなビード横の裂けた板縁は、多くの場合、封じる時間はあったが正直な修理にする時間はなかったことを示す。

マローダーにとって、補修シームは地図より役に立つことがある。漏れた部屋、圧力で撓んだ隔壁、工具はあったが部品はなかった乗員、あるいは後の回収者が同じ傷を修理ではなく採取として開いた場所へ導く。

## Scanner

船殻接合部 // 水中で盛り上がった溶接ビード、酸化したリベット列、裂けた補修板の縁、シーム下の塩筋。ガスケット線は後の金属で半分埋まっている。工場接合ではない。

## Terminal

接合読取 // ガスケット上の溶接は、シール圧縮後の修理。リベット下の錆は一度の浸水ではなく、湿った呼吸の反復。ビード頂部の明るい擦り傷は、圧力周期後に工具で試された跡。
