# 音響フィルター器官リレー

音響フィルター器官は、水と圧力と音が無線の代わりをする古いリレー喉部に育つ。組織は話していない。インピーダンスを変え、ポンプの轟音を弱め、細いピンガー音を本来より遠くへ運ぶ。Atlasはその反復反響を安いリレーとして使い、注意深いプレイヤーは経路の手掛かりとして使える。

## Scanner

リレー管内の柔らかい隔壁組織がピンガー音を通し、ポンプ騒音を殺している。

## Terminal

リレー記録: 生きたひだは広帯域の機械音を拒み、細いピンガーパルスを通し、戻り反響の位相をずらす。下流マップの信頼度低下。

## Audio

装置みたいに返事をしても、装置は血を流さない。

## Field Note

ソナーが助けになる前半から、疑わしくなる後半への橋に使う。
