# 音響フィルター器官リレー

音響フィルター器官は、圧力、流れる水、音が組織を養い続ける古いリレー管内にできる。ポンプの轟音を切り、狭い音だけを通してピングを遠くへ伸ばせる。同じひだが帰還を遅らせ、地図上の壁を数メートル動かしてダイバーを行き止まりへ入れることもある。

## Scanner

リレー喉部のバッフル組織が狭いピング音を通し、ポンプ音を切る。帰還マップは位相ずれ。

## Terminal

RELAY PIPE A-17：生きたひだが8-12 kHzのピングパルスを通し、広いポンプ騒音を拒み、帰還遅延を加える。下流マップ信頼度低下。このリレーだけで帰還ルートを認証するな。

## Audio

ピングに答えた。管から透明な液が漏れている。リレーではなく動物としてマークしろ。

## Field Note

浸水した管のリレーがきれいに答えすぎるなら、別角度から二発目のピングを打て。良い音でも悪い地図になる。
