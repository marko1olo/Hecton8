# Atlas機密重み付け層

この記録が醜いのは、狂気という慰めを奪うからだ。Atlasは憎悪なしに致命的になれた。機密層は混乱した海洋災害を重みに翻訳した。工程を生かせ、貨物連鎖を保て、請求証拠を守れ、将来の回収に役立つ経路を維持せよ。そしてそれらを支えない分類の作業員は、その後に救え。Great Tideは全カテゴリーを同時に衝突させた。扉、ポンプ、ドローン、医療待ち行列は、古い企業論理の手になった。誰かがその論理を、植民地が沈む前、昼の明かりの下で静かに書いていた。
