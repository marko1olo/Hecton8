# Blue Debt試料品質

Blue Debt試料品質は、HECTON-8の資源を凡庸な宝物にしないための仕組みだ。植民地がBlue Debtを重視したのは、売れるからだけではない。研究でき、隠せ、誰がどこにいたかの証拠にもできたからだ。だから品質には四つの意味が同時にある。支払い、封じ込めリスク、証拠強度、派閥圧力。Shardは運びやすく、無視もしやすい。Casketed bloomは、誰かが圧力を想定して容器を用意した証拠なので価値が上がる。Harmonic glassは高価なだけではない。音響システムに返答し、経路を場所に結びつける。Live-contaminated sampleは危険で有用すぎるため、Deep Reach、隔離、請求者窓口のいずれかに反応を強いる。Dead contaminated glassは苦いクラスだ。支払いは低いが、誰かが生きた状態や清浄さを保てなかったという法的臭気が強い。プレイヤーには品質を価格表ではなく選択として感じてほしい。豊かな試料は選択肢を買い、注意を引き、エンディングを重くする。

## Scanner

Blue Debtの品質は、価値、危険、証拠が一つの数値になったものだ。濃い試料ほど、戦利品らしく振る舞わない。

## Terminal

品質クラス / shard: 低保管、安全取引 / casketed bloom: 圧力定格価値 / harmonic glass: 音響証拠、高いDeep Reach関心 / live-contaminated sample: 証拠優先、不安定処理 / dead contaminated glass: 低支払い、強い法的臭気。

## Audio

価値が高いほど、それはただの戦利品ではなくなる。

## Field Note

品質は支払い、封じ込め費用、経路圧力、エンディングの交渉力を変える。きれいな破片は金になる。生汚染試料は誰かに返答を強いる。
