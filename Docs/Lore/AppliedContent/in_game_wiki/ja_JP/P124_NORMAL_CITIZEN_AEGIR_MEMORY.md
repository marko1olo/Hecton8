# 一般市民のエーギル記憶

普通の市民にとって、Aegir は禁じられた秘密ではない。もっと悪い。学校読本、保険警告、航路料金表に残る古い項目だ。人々は海の惑星、失われた植民地、隔離という語を覚えている。しかし交代勤務の班、子供、料理人、圧力技師、死亡名簿の名前は覚えていない。その距離が Deep Reach を公共生活の中で生き残らせる。知られた災害も、誰も遺体を見なくてよいなら背景になる。
