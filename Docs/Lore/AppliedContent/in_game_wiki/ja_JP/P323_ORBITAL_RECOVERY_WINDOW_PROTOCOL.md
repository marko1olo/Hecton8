# 軌道回収窓プロトコル

軌道回収窓プロトコルは、救助を希望ではなく工学に変える硬い制限である。Black KeelはHECTON-8上空を意味がある頻度で通過できるが、carrierは月規模の嵐の場から濡れた未検証物体をただすくい上げることはできない。Aegirの上層大気は悪い上昇角を裂き、磁気ノイズは弱い誘導を食い、受信機は隔離handshakeに失敗した質量を受け入れない。だからプロトコルは同時に複数の証明を要求する。rated ascent object、窓に入れるguidance core、受信機が信じる圧力履歴、carrierに何を捕まえてよいかを教える法的保管状態。ほとんど動く脱出がまだ危険なのはそのためだ。早すぎれば嵐が物体を奪う。遅すぎればBlack Keelは雲頂の上を遠ざかる声になる。隔離同期なしで打ち上げれば、carrierはあなたを聞き、記録し、それでも質量を拒める。窓は空を本物にする。見え、届き、時刻で縛られ、慈悲はない。

## Scanner

Black Keelはあなたを聞けるほど近いが、頼めばいつでも捕まえられるほど自由ではない。Aegirは狭い回収窓しか開かない。
