# FTLなしの航路経済

2190年の人類圏は、低速船、リレー保管権、制動窓、負債で動いている。HECTON-8は即時救助の外側にある。法はパケットで届くが、船が来るには質量、遮蔽、燃料、制動設備、そして費用を払う誰かが必要だ。

## Scanner

輸送刻印: 遅延、質量、遮蔽、制動負債が、コロニーが水に触れる前からこの物体を形作っていた。

## Terminal

航路通知: アンシブルなし。次のリレーパケットまで現地保管権は有効。サルベージ権限はソルの応答を待てない。

## Audio

内圏から誰もこの海には間に合わない。君の先取特権はそれを織り込み済みだ。

## Field Note

救助が遅すぎると感じるなら、領収書を見ろ。遭難信号より先に距離は請求されていた。
