# 有光棚サバイバルゲート

有光棚は快適さではなく物で教える。どのポンプハウジングが空気を残し、どのパッチが数分を買い、どの明るい生物が工具を汚すかをオペレーターは覚える。Atlasはまず修復残留として現れる。有用で、ところどころ間違い、触れられるほど近い。

## Scanner

ルートゲート: 有光棚。酸素ポケット、ポンプ室、最初の切断、浅部Atlas修復残留が昼光水で読める。

## Terminal

キャンペーンルート // 有光棚。必要: ポンプ再起動、シールパッチ、ケーブル切断、スキャナーping。上昇ハードウェア使用不可。消費セルは生存系へルート済み。Atlas残留は汚染注意付きで有用分類。

## Audio

浅い水は安全ではない。読めるだけだ。
