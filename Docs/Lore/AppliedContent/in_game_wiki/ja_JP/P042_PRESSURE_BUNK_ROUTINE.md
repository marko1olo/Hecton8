# 耐圧寝台ルーチン

耐圧寝台は日常生活を維持する機械として植民地を見せる。恐怖は正常な系が悪い優先順位に従ったこと。

## Scanner

寝台は圧力下の睡眠用だった。密閉確認、酸素券、結露排水、シフト警報。

## Terminal

居住ルーチン: 寝台密閉は安定。起床警報はステーション優先上書きで取消。乗員は31分間回収可能。
