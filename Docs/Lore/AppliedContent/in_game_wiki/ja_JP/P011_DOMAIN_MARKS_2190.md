# ドメイン刻印 2190

ドメイン刻印は、HECTON-8を原始的にせず遠く感じさせる小さな法的傷だ。一つのブラケットにSol Coreの安全文法、Centauri憲章句、Barnard Yardsの修理痕、Luytenの保管ハッシュ、Aegir地方請求コードが並ぶことがある。装飾ではない。誰が部品を認証し、誰が修理し、誰がパケットを証明し、誰が損失を保険処理し、部屋が水没した後に誰がサルベージを争うかを示している。

重要なのはドメイン名の暗記ではなく、疲れた金属に重なる権限だ。Solは救えない物を認証できる。Barnardは死んだ請求仕事を普通にする。Luytenは情けを問わず保管を残す。Aegirは他者の書類の下で汚れた地方権を執行する。Marauderが刻印を読む時、海は空白ではなくなる。人間の温度より先に、人間の権限が届いていた。
