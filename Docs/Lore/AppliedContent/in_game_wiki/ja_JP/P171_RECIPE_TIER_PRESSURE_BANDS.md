# レシピ階層の圧力帯

レシピ階層の圧力帯は、HECTON-8のクラフト文法である。植民地は便利さでレシピを分けたのではない。プレイヤーが作業台を離れた後、圧力が部品に何をするかで分けた。Tier 0は浅場でプレイヤーを生かす。パッチ、手封止、そして正直に壊れるサルベージ品。Tier 1は定格修理の領域で、ポンプ室部品、古い工業在庫、負荷下で動くための認証印が必要になる。Tier 2では圧力ハードウェアに入る。ブライン洗浄、噴出孔硬化、音響証明が、その部品が安全なのか部品の形をした危険物なのかを決める。Tier 3は上昇、Atlas接続、深淵権限の領域だ。材料だけでなく、受信者状態、法的保管、封じ込め証明が必要になる。だからクラフトは経路論理と結びつく。問いは、何を持っているかだけではない。それはどこにあったのか、どの圧力に耐えられるのか、誰が結果を受け入れるのかだ。

## Scanner

HECTON-8のレシピは買い物リストではなく深度の主張だ。部品は、名乗った圧力帯を生き残って初めて部品になる。

## Terminal

レシピ帯 / T0 生存パッチ: 浅場サルベージ、手封止、保管責任なし / T1 定格修理: 棚上工業部品、ポンプ室認証 / T2 圧力ハードウェア: ブライン洗浄、噴出孔硬化、音響証明 / T3 上昇またはAtlas作業: 深淵由来、法的受信者、封じ込め受領。

## Audio

レシピとは、ボルト付きの深度許可証だ。

## Field Note

レシピ階層は圧力等級、経路コスト、保管リスクと一致させる。間違った帯域の安いボルトは安くない。未来の漏水だ。
