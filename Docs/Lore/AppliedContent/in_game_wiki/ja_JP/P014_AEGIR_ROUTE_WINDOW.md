# Aegir航路窓

Aegir航路窓は、敵対する時計が一瞬だけ合う時刻だ。ガス巨星放射線、月影、嵐ノイズ、潮汐、リンク品質、上昇質量、Black Keel幾何。

だから空は生存ループに入る。データは上がれても身体は上がるべきでないことがある。上昇に良い窓でもノイズが証拠を壊すことがある。

## Scanner

局所エフェメリス表。通信、潮汐、放射線、月影、キャリア幾何が一つの狭い上昇窓を共有。

## Terminal
