# 塩分・鉱物沈着記憶台帳

塩分と鉱物の沈着は、HECTON-8の静かな筆跡だ。きれいな亀裂は嘘をつける。磨かれたパネルも嘘をつける。だが鉱物の縁は偽りにくい。水の移動、乾燥、圧力の呼吸、化学反応を別々の層で残すからだ。

継ぎ目の白い花は水が移動し、荷を置いていった印だ。ボルト下の石灰垂れは遅い排水を示す。緑灰色の輪は一度の飛沫ではなく、何度も戻った湿った境界だ。ガスケット溝の粉は、空気か濃塩水が何周期も通った証拠になる。新しい黒い流れが塩を横切るなら、機械漏れは鉱物殻より後だ。

マローダーにとって、沈着は汚れではない。水の記憶だ。隠れた浸み、弱いハッチ、圧力変動で乾く洞窟ポケット、停止後も呼吸していた密閉区画を示す。良い沈着は叫ばない。時計なしで潮を数えていた壁に気づく者を待つ。

## Scanner

鉱物沈着 // 継ぎ目の縁に白い塩、古いボルト下に石灰の垂れ、圧力染みの周囲に緑灰色の輪。泡でも雪でもない。水はここを通り、止まり、呼吸し、鉱物を残した。

## Terminal

塩の読み方 // 錆の上の乾いた塩は古い湿潤故障。新しい黒い流れの下の塩は、その後に封止が漏れた証拠。下向きの石灰指は低圧排水、ボルト周囲の輪は圧力周期を示す。

## Audio

塩は領収書だ。海は遅く署名するが、すべてに署名する。

## Field Note

読む前に塩を拭くな。最初の一拭きで潮の数が消える。
