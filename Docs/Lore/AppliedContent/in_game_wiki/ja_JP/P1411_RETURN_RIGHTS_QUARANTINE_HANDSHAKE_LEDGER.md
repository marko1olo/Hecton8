# 帰還権限と隔離ハンドシェイク台帳

帰還権限タグは、上へ行くことが自由と同じではない理由を説明する。小さな物で、コンソールに配線されていたり宅配ケースに封印されていたりするが、人々が自動的に起こると思っている救助の部分を背負っている。誰かが生存者を受け入れることに同意しなければならない。誰かが試料、スーツ、汚染された道具、パケットアーカイブ、保険リーエン、そこに付随する法的熱を受け入れなければならない。

Aegir空間での隔離は、医療だけの言葉ではない。生物、証拠、所有権を整理してから、誰かが帰還を清浄と呼ぶことを許すための停止だ。スーツの縫い目には、ブライン胞子、ベント化学、ブラックボックス記憶、Atlas痕跡、労働者名、航路座標、企業責任が同時に残りうる。ハンドシェイクは各権限に異なる恐れへの署名を求める。病気、圧力破損、保管違反、債務移転、公的露出、継続性汚染だ。

受領者は命を救いながら証人を埋めることもできる。Keelmark Mutualは請求価値を保つ帰還を好む。Deep Reachは記録を封じ込める帰還を好む。public ledger公証人は静かに再分類できない証拠を好む。Atlas継続性オフィスは、死んだ機械が人間に見えるようなペイロードを嫌う。彼らは最初から嘘をつく必要がない。プレイヤーが到着する前に、プレイヤーが何であるかを定義すればよい。

Marauderにとって、ハンドシェイクはレバーだ。私的受領者は速いが、身体とパケットを保管に閉じ込めるかもしれない。公的受領者は記録を守るが、座標、名前、生存者を清掃予算を持つ全員に晒す。隔離受領者はプレイヤーを生かしながらガラスの向こうに閉じ込める。きれいな答えはない。重要な答えは上昇燃焼の前、まだ海が外にあり、キャリアが生存者の分類を決めていないうちに選ばれる。
