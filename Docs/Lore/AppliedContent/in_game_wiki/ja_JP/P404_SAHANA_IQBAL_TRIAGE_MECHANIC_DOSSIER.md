# サハナ・イクバル、トリアージ整備士

サハナ・イクバルは、負傷した作業者の名前がレールを上がるのを待つ部屋で機械を修理していた。彼女の記録は、トルクメモを寝台タグ、スクラバーカートリッジ、酸素予備票、オレンジの隔離テープに結びつける。これらの物はDeep Reachの遅延を物理化する。同じ板がボルト張力を制限し、次の圧力低下前にどの身体、弁、フィルターが注意を受けるかを決めた。イクバルの仕事は大きな慈悲ではない。公式順序が変わり続ける中で、最も死ににくい順番を選ぶ手だった。

## Scanner

記録: サハナ・イクバル。トルク板、寝台タグ、隔離テープが同じ待機順序を共有する。

## Terminal

トリアージ区画C-2 / IQBAL, SAHANA: トルク上限は酸素予備タグの横に掲示。工具、寝台、スクラバーカートリッジは同じレールに並ぶ。隔離用語がまた到達線を動かした。

## Audio

イクバルは届くものを直した。何が届くものかは、板が決め続けた。

## Field Note

イクバルは隔離修理ループ、医療区画通路、酸素待ち列、機械選択が人間の時間を奪うUIで使う。
