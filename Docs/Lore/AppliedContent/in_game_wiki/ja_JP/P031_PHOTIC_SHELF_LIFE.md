# 有光棚の生命

有光棚は、損傷した投下の後に現れる最初の生きた基準線だ。Ran-Aegir の光は上層 0-250 m に届き、棚は潜水者が読める物で応答する。玄武岩上の酸素マット、藻を切るグラスグレイザーの筋、うねりの前に曲がる pressureweed、シェルターラインへ戻る流れを示すルート藻だ。

それらの兆候は許可ではない。明るい酸素マットは汚染された継ぎ目を隠すことがある。新しいグレイザー筋は安全な通路かもしれないし、浅場の捕食者の前に群れが散った跡かもしれない。Pressureweed は天候、捕食者の移動、下のサービス設備から来る圧力パルスを警告する。ルート藻は、嵐の泥や緩いラインで流れが変わるまでは帰路を示す。ケーブル礁と Atlas 修復組織の前にある土着の比較点だ。機械が生命を保守材料として使う前から、この月は生きていて、読めて、危険だった。
