# 有光棚の生命

有光棚は、破損した降下の後に最初に出会う生きた基準線だ。Ran-Aegirの光が上層水に届き、棚は鉱物で育つマット、透明なグレイザー、pressureweed、ルート藻で応える。マットは岩を明るくし小さな酸素ポケットを保つ。グラス・グレイザーは藻を削って読める通路を作る。Pressureweedはうねりや捕食者の動きがプレイヤーへ届く前に曲がる。ルート藻は泳者をラインへ戻す流れ、または遠ざける流れを示す。この区域は美しくなければならない。HECTON-8は欲しがられる価値があったからだ。同時に危険でなければならない。嵐、視界不良、浅瀬の捕食者、切れた帰還ラインは、深いケーブル礁やAtlas修復組織が現れる前に、明るい水を罠に変える。

## Scanner
