# ハイドロフォン・ログストリップ

ハイドロフォン・ログストリップは音声日記ではない。幽霊のように鳴ることを覚えた保守領収書だ。

        古いコロニーモジュールでは、各圧力室のハイドロフォンレコーダー脇に細いセラミック繊維ストリップがあった。安く、単純で、改ざんしにくい。壁越しにポンプの律動、扉の歯、ブーツの衝撃、工具音、船殻のうなり、ヘルメット内の呼吸、密閉を保つか迷う部屋の低い震えを聞いていた。ネットワークが落ちてもストリップは動いた。だから公式パケットより多く残った。

        ストリップは層で読む。まず圧力インク。傾斜、落ち込み、ロックが枠に噛んだ鋭い歯。次に音響の櫛。繰り返す機械音、抜けたポンプ拍、言葉にならないほど滲んだ声の形。最後に公証の縁。番号、区画スタンプ、時間梯子、継ぎ目。復元音だけを真実にしてはいけない。ストリップは部屋と一致しなければならない。

        よいハイドロフォン証拠は経路を変える。許可スタンプより前に扉が開いたこと、死亡時刻の後もポンプが動いていたこと、black-box断片が洗浄されたこと、公式ログが遠隔操作だと言う間に誰かが部屋にいたことを示せる。ストリップは劇的に告発しない。誰かが読めるまで圧力跡を持ち続ける。
