# 鉄サンゴ

金属の上にしか育たない。開けたシルトの中の群落は、その下に埋まっているものを示す。

色が基材を読む。構造用鋼の上では赤錆色、機械用合金の上では灰黒色、下の板が微量のXOを含む所では鈍い青。

骨格はClass-IVの手のひら板より硬い。群落の上を二交代引き回せばグローブの縫い目が開き、それは手を曲げるまで漏れとして表示されない。

亀裂の上の外殻は、200 mm離れた健全な板の外殻より三倍厚くなる。溶接継ぎ目を橋渡ししている所では、その継ぎ目は二度と点検できない。

産出は外殻そのもので、厚い所が最も多い。外殻付きで切った板は総量で計上され、4.8トンの枠は内訳を出さないので、削るのは沈没物のところでやれ。Keelの上ではやるな。

## Scanner

鉄質基材上の鉱化した群体生長。金属反射強。信頼度77パーセント。危険：グローブの縫い目を削る。限界：外殻と基材が一つの塊として返る。

## Terminal

分析ロット 44-N-118。区分：回収可能鉱物、品位未定。基材：構造用鋼、由来未確定。継ぎ目12〜19：被覆、点検終了。質量は総量で計上。窓口：KEELMARK 損失デスク。

## Field Note

「質量は総量で計上」とは、外殻もあんたの枠に乗り、差額は窓口が取るという意味だ。破面が青く出たら、それは品位ではない。青い負債だ。触る前に記録に上げろ。
