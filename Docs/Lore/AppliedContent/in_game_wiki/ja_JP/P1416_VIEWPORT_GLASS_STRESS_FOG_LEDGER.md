# 観察窓の応力霧台帳

HECTON-8の観察窓は、圧力下で交わされた約束だ。部屋に外を見せるが、海を入れない。そのため汚れの一つ一つが意味を持つ。透明な中心は人間が清掃した部分であり、縁が真実を話す。乳白の剥離、塩霧、清掃アームの半月傷、ガスケットの黒ずみ、閉じ込められた水滴、曇った応力弧。

プレイヤーは窓を計器として読む。応力弧があってもガスケットがきれいなら古いが安定しているかもしれない。ガスケット下の霧は層間に水が入った印だ。ラミネート内の水滴は乾いた側がゆっくり死んだ証拠になる。半月傷は整備された部屋を示し、乱れた切り傷は崩落や後日の解体を示す。

観察窓は経路にも危険にもなる。乾いた空間を教え、空気の残る部屋を見せ、日々海を見ながら働いた場所を残し、公表された「瞬時破断」が実は遅い失敗だったことを証明する。きれいな中心を叩くと、静かな壁が刃になる。

## Scanner

観察窓ガラス // 厚い縁、乳白の剥離弧、ガスケット下の塩霧。三日月傷は清掃アーム由来で、生物ではない。濁った縁は圧力履歴を示し、透明な中心は安全を意味しない。
