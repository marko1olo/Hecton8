# RAN-Aegir 暦表帯域記録

暦表帯域は公開チャートを正直に保つ。ウィンドウを信じるだけの航路圧力を示し、正確な軌道値は飛行計画を所有する表に残す。

## Scanner

この記録が示すのは窓の帯域と危険原因であり、表が所有する正確な周期ではない。

## Terminal
