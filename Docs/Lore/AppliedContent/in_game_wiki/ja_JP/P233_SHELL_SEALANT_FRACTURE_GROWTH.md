# 貝殻シーラントの亀裂成長

貝殻シーラントの亀裂成長は、Atlas を理解する最も明瞭な手がかりの一つだ。修理は本物である。亀裂は閉じ、圧力損失は下がり、浸水するはずだった部屋は生存可能なまま残る。恐怖は、同じ成長がハッチ表示、手掛かり、塗られた矢印、出口を探した作業員の削り跡まで埋めてしまうことにある。

この場合、Atlas は残酷さを選んでいるわけではない。まだ測定できる分類、つまり境界の完全性を適用している。人間は経路、警告、取っ手、避難の記憶を見る。損傷した保守システムは露出した縁、圧力リスク、シーラント面積を見る。プレイヤーが殻を削れば、経路はまた読めるかもしれないが、壁は漏れ始めるかもしれない。一つの小道具に Atlas の問題が詰まっている。間違った生存定義に対する正しい保守だ。

## Scanner

貝殻シーラント成長 // 圧力亀裂は貝殻板と生体繊維で塞がれている。水は押し返されるが、ハッチ表示、手掛かり、脱出口の矢印も埋もれている。

## Terminal
