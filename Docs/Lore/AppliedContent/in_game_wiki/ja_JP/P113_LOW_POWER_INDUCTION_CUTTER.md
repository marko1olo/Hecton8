# 低出力誘導カッター

低出力誘導カッターは最初のアクセス工具であり、万能鍵ではない。固着したサービスハッチ、パネルボルト、サルベージ箱を開けるが、その部品が何を支えているかを読ませる。pressure glass、稼働フレーム、Atlasが成長させた継ぎ目は、後の工具かより確かな証拠の領域だ。

## Scanner

低出力誘導カッター。対象はサービス金属のみ。荷重フレームとpressure glassは定格外。

## Terminal

工具警告 / 誘導カッター: 承認対象はサービスハッチ、パネルボルト、軽量ブラケット、クレート錠。後期クラス認証なしで稼働フレーム、pressure-glass格子、Atlas成長継ぎ目を切断しないこと。

## Audio

ボルトを切れ。リブは残せ。

## Field Note

いいカッターでも信仰には向かない。パネルは開くが、部屋を保つリブを切れば許してくれない。
