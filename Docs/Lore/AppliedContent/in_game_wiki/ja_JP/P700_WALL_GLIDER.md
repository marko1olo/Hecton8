# 壁滑り

移動するのは加工された面の上だけだ。板、ケーブル路、配管、手すり。裸岩の上は通らず、開いた亀裂も越えない。

この拒否がそのまま検査になる。跡が途切れず走っていれば、その下の板は健全だ。跡が折り返していれば、板は開きかけている。

残す膜は導電性がある。通電している板の上では膜も通電し、工場ガバナーの導通確認はその膜をそのまま通るので、壁滑りの跡の下にある髪筋の亀裂は健全と測定される。新しい膜の上に工具を平らに置くと一秒張り付き、計器は十秒落ちる。

Annexのデッキにある黄色い作業帯の塗装は越えない。塗装の大半は四十三年前に消えているが、それでも越えない。

評価：導通の値ではなく跡を信じ、跡が終わる所で止まる。

## Scanner

加工面に付着して食む種。信頼度77パーセント。危険：導電性の付着物、微弱電流。限界：跡の新旧を判別できない。死んだ跡も生きた跡と同じに読める。

## Terminal

文書 44-H-0742。区分：構造監視、生物、代替として受理。対象：ANNEX P-63 船体板、0〜100 M。所見：調査済みの跡に圧力偏差なし。未調査の跡：報告なし。

## Field Note

署名された船体点検は、動物がたまたま這った場所のことだ。這わなかった板は報告から落ちていて、抜けたのはその板だった。跡が終わる所で止まれ。
