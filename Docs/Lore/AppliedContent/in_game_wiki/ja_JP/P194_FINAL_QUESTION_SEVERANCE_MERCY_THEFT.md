# 最終問い：切断、慈悲、窃盗

切断はAtlas-海洋修復層を切るのであり、一つのスイッチを押すのではない。損傷した分類ロジックを止め、Deep Reachの生きた回収経路を断つことができる。同時にvent micronodesを黙らせ、shell sealantパルスを壊し、タグ付き動物経路を切り、作業員記録バッファを傷つけ、圧力室を密閉していたシステムなしで残すこともある。切断ペイロードにはproof-hash保存が必要だ。部屋が暗くなった後、その行為は争われる。

## Scanner

切断軸 // 連続性の切断はAtlas修復層を横切る。圧力扉、導電膜、作業員記録バッファ、タグ付き動物経路、vent micronode、ペイロード経路。証拠状態が保管ラベルを変える。

## Terminal

最終軸 / Atlas切断
行動: Atlas-海洋修復層を通る連続性切断。
影響: 圧力扉、生きた導電膜、vent micronodes、shell sealantパルス、タグ付き動物経路、作業員記録バッファ、ペイロード経路。
受信者効果: 別ペイロード経路が残らない限り、Deep Reach経路を拒否。
リスク: 盆地不安定化、修復経路喪失、生態損傷、保管権争い。
既知損失: 同じ切断が、証拠状態によって救助、損傷、妨害、窃盗になり得る。
