# Xenon-Omega 公開材料

Xenon-Omega は危険材料カテゴリとしてだけ公開される。噂、調達痕跡、封印ケース、取扱規則だ。名前を最終説明として読んではならない。役に立つ問いは、試料が圧力下に残り、タグを保ち、Black Keel や Deep Reach が静かに改名できない経路につながっているかどうかだ。
