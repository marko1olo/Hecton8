# 塩水吸い

これが定位している所では、その背後の板が開いている。

塩水吸いは塩水層を泳ぐのではなく汲み上げ、引き込む二つの密度の差を食う。鋭い境界は手放さない。ここで最も鋭いのは我々が作ったものだ。2,185メートルで真水を塩水へ漏らしている裂けた冷却配管、死んだポンプを通してまだ引いている取水格子。

格子沿いに個体を数えれば、その背後の破口を測ったことになる。乱されると一匹が濃い側を一塊で吐き出し、その塊はClass-IVの脇を沈みながら、深度チャンネルを四秒から十秒持っていく。

東ギャラリーの漏れ一箇所だけは避ける。そこの水は分析上まったく同じだ。

評価：先に格子を数え、それから開いた船体として扱う。

## Scanner

浸透圧特化種、密度境界に定位。信頼度64パーセント。危険：吐き出された塩水が深度チャンネルを乱す。限界：計器の復帰時間は未特定。

## Terminal

標本 44-D-118。区分：漏水検知業務、契約外。場所：冷却ギャラリー3 取水格子、2,185 M。所見：塩水偏差は観察により作図。センサー交換項目 22-B：終了、校正ドリフト。

## Field Note

漏水センサーの項目を閉じたのは、動物が無償で調べてくれたからで、そのあと調査が見つけたものを直すのをやめた。カッターを近づける前に格子を数えろ。
