# パケット保管

パケット封印を回収。Black Keelは貨物を受け取れるが、証拠には出所、封印、witness hash、中継印、受信レーン、損傷状態が必要だ。機材を剥がす前に保管タグを守れ。

## Scanner

パケット封印 // witness hash帯は損傷しているが読める。サルベージ切断前に保全。未封印の証拠は請求材料になる。
