# 請求者言語監査

請求者言語は、植民地でもっとも静かな武器の一つだ。ポンプ室、閉ざされたトリアージ扉、サービス格子の奥に残された作業員の質量を否認する必要はない。権限を持つ者が読む前に名前を変えればいい。列は解放時刻差になる。閉じた扉は隔離審査ゲートになる。戻らない身体は支払露出になる。損傷したサルベージ帰還は部分資格になる。

この監査は、手続き語を行動として読むためにある。変換された語句は、必ず人、部屋、工具、航路時計、圧力事象へ戻して読む。Deep Reachは証人を残したまま、棚札を変えて証言を埋められる。分類が残り身体が消えたなら、証拠はすでに一度洗浄されている。
