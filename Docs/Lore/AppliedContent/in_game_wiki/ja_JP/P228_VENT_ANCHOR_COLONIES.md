# ベントアンカー群体

ベントアンカー群体は、Marauder が浅瀬に留まったまますべての修理問題を解決できない理由を説明する。群体は熱水噴出口が熱と硫化物化学をブライン層へ押し込む場所で成長する。肋状の体は鉱物を捕らえ、板状に冷え、致死的な水の縁で小さなベントファウナを守る。だから価値はあるが、魔法の鉱石ではない。剥がれた肋は pressure-ceramic filler、cold-sealant grit、化学フィルターに使える。生きた熱い肋はスーツをすぐ殺し、工具ヘッドを熱衝撃で割ることがある。正しい読み方は忍耐だ。熱 bloom をスキャンし、冷えた縁を待ち、剥がれた板だけを切り、目的に見合うリスクがない限り活動中の喉には触れるな。
