# 遭遇文法：センサータグ付き生物の追跡

センサータグ付き生物の追跡は、Atlas の修復論理を見せるための遭遇であり、現地生物を兵士に変えるためのものではない。動物は動物のままだ。飢えているか、怯えているか、縄張りを守っているか、混乱している。問題はタグである。タグは瘢痕組織や殻の成長部に埋まり、弱いパケットを返す。損傷した保守論理はそれを圧力状態、経路の占有、汚染の広がり、または移動する目印として読むことがある。プレイヤーがまっすぐ避難場所へ走れば、タグはその退避の形を持ち帰る。音を出し、何度もピングを打ち、修復通路へ動物を引き込めば、ネットワークは誤った教訓をさらに早く覚える。答えは操り人形を殺すことではない。フィードバックを断つことだ。角度を変え、光を切り、密度層や構造物で遮蔽し、動物に別の道を選ばせ、汚れたタグをプレイヤーの安全室への最もきれいな地図にしてはならない。
