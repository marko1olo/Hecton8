# 誘導タイミングコア組立品

誘導タイミングコアは、上昇をどこにも届かない綺麗な燃焼にしないための部品だ。HECTON-8の上には開けた空はない。Aegirは回収ジオメトリを動かし、リレーシャッターは開閉し、嵐のプルームは音響と無線の受け渡しを曲げ、Black Keelは特定の時刻の特定レーンだけを見る。

コアはカプセルを海より賢くしない。時計、暦スライス、受信レーン表、そして水面を出る事象を分類可能にするだけのドリフト補正を与える。早すぎるパケットはcarrierスタックで捕獲ノイズになる。遅すぎるパケットはレーンが過ぎた後に届く。良いエンジンでも悪いコアなら、設計通りに飛んでなお有効な回収請求を残さない。

修理できるコアには四つ必要だ。深海遅延に耐える時計、現在のAegir窓、正しいBlack Keelレーン、嵐の上のリレー鎖と一致するシャッターキャッシュ。だからこの組立品は小さく、容赦がない。推力は増やさない。推力が到着になるかを決める。
