# 手動ビルジポンプキット

手動ビルジポンプは、投下後に最初に役立つ工具だ。カプセルの電装が危険でも動く。小さな浸水区画しか空にできないが、緑ランプではなく吸入口、排出口、弁の抵抗を読むようプレイヤーに教える。HECTON-8の最初の規則は、水と圧力と手作業から修理が始まることだ。

## Scanner

手動ビルジキットを検出。吸入口スクリーンにカプセルフォームが詰まっている。パネルに通電する前に除去すること。

## Terminal

P-63 現場支給 / ビルジキット: 手動ポンプ、ホースクランプ、吸入口スクリーン、逆止弁。通電パネル試験の前に滞留水を排出。密閉ケーブルトラフへ排水しないこと。

## Audio

水が先。電源は後。ハンドルが返すなら、部屋が返事をしている。

## Field Note

ポンプは計器よりましに正直だ。ハンドルが押し返すなら、止めて水の逃げ先を確認しろ。
