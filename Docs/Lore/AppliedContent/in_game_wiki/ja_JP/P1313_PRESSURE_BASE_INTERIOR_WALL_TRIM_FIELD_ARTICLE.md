# 圧力基地内壁トリムの野外記事

圧力基地の内壁は、HECTON-8 がただの残骸ではなく、溺れた職場に見え始める場所だ。パネルは清潔な宇宙船プラスチックではない。圧力用の背面材に暖かいオフホワイトのセラミック被覆、台車と手で削られた暗いグラファイトレール、振動を抑えるゴム帯、何百回も急いで開けられて磨かれた小さなサービスハッチ縁でできている。

よい壁は横向きに時間を語る。結露汚れは暖かい息が冷たい構造に触れた所に集まる。下壁の湿り染みは、ポンプ停止後に水が立ち、下がり、また上がった場所を示す。琥珀色の安全塗料は本当に使われた角で剥げる。ねじ列は、メンテナンスで開けられたパネルと、廊下を完成して見せるためだけのパネルを分ける。

移動では、内壁トリムは実用的だ。下の染みは壁裏の浸水ポケットを示すことがある。膨らんだパネルは反対側の圧力を隠すことがある。明るく磨かれたハッチ縁は、バイパス弁、ケーブル経路、古い食料隠しにつながることがある。すべての壁を背景扱いすると、扉と呼ばれなかった扉を見逃す。

壁は人間の尺度も持つ。Deep Reach は基地をモジュール、出力ノルマ、安全図として売った。壁は肩、台車、濡れた手袋、貼り紙、袖で拭かれた結露を覚えている。基地は、人々が圧力を日常にしようとした場所だった。

大潮の後、壁は公式ログよりよい証人になった。端末は消せる。壁は塩の線を残す。報告書は避難済みと言える。その日付の後に磨耗したハッチ縁は、誰かが戻ったと言う。

略奪者の規則は、箱を切る前に壁を読むことだ。床線の染みをスキャンする。ガスケットのどちら側に砂があるか見る。手で削れた琥珀色塗装を探す。廊下がまだ快適に感じるなら、その快適さが何を隠したかを問え。
