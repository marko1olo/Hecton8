# Ran / Aegir名称権限台帳

HECTON-8に名前が多すぎるのは、汚れた水をきれいに所有したい事務所が多すぎたからだ。Ranは恒星。光、航路、キャリア遅延、航法を扱う文書で使う。Aegirはガス巨星。月をより大きな請求システム、空、親天体、資産群の中に消したい話者が使う。RAN-B:H8は保険対象月のキーであり、そこに誰が住んだかを覚えずに台帳が並べられる名だ。HECTON-8は現場名で、濡れた梯子、ハッチ縁、ルート板、古い圧力扉に張り付いている。

            名前は交換可能ではない。指紋だ。Ranと言うルート事務所はおそらく航法をしている。Aegirと言うDeep Reachメモは、たいていシステム規模の所有権を守っている。RAN-B:H8と言うBlack Keel受領は場所を請求可能な物体に変える。HECTON-8と言う労働者メモは俗語でも感傷でもない。海が区画ごとに人を殺した高さからの証言だ。

            良い証拠は見つけた名前を保つ。早すぎる正規化は動機を壊す。Aegir資産と書かれた隔離命令は、枠を広げて局所的な失敗を隠しているかもしれない。RAN-B:H8と書かれたサルベージ見積もりは、月を悲しみなしで保険に通すため記憶を剥がしているかもしれない。

            だからPDAは名前の衝突をならさず保存する。衝突は、誰が話し、何を数えたがり、何を埋めたがったかをプレイヤーに教える。
