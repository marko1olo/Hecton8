# Ran / Aegir名称権限台帳

HECTON-8に複数の名前があるのは、複数の権限が同じ水を所有しようとしているからだ。Ranは恒星であり、天文上の基準、ルート物理の名前である。Aegirはガス巨大惑星で、空の親であり、請求オフィスが好む系全体の略称だ。RAN-B:H8はカタログキーで、冷たく、保険可能で、並べ替えられる。HECTON-8はプレイヤーが血を流す現場名だ。

違いは重要だ。Ranと書かれたルート板は光、距離、輸送を語る。Aegirと書くDeep Reachメモは所有と請求継続を語ることが多い。RAN-B:H8のBlack Keel受領は特定の月記録に値を付ける。HECTON-8と書くMarauderのメモは部屋、身体、圧力扉、弁護士名を気にしない海を語る。
