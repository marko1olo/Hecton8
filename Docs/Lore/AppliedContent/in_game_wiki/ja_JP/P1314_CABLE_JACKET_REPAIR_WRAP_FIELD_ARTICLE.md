# ケーブルジャケット補修巻き現地記事

ケーブルジャケットの補修巻きは、沈んだ施設に残る小さな人間の告白である。生物ではなく、Atlasのシール材でもなく、飾りの警告線でもない。黒い防水ゴム、灰色の耐圧テープ、破れ端から見える斜め繊維、継ぎ目に詰まった塩、濡れて傷ついたリブ、そして作業を続けるために締め付けられたクランプ痕だ。

巻かれたケーブルは、公式図面が語れないことを語る。重ね方向は技術者が信じた端を示す。白い結晶が重ね口の下にあれば、水はジャケットを伝っていた。テープを横切るクランプ痕は、補修後もその線が固定され使われた証拠。塩のない滑らかなテープは新しいかもしれない。暗い濡れ溝を持つしわのあるテープは、漏れを止めたのではなく抱えているだけかもしれない。

ゲーム上、補修巻きは読める表面になる。迂回盤、酸素ホース、通電リレー、死んだピンガー、隠し通路へ導くことがある。感電経路や安全に見える誤診断を警告することもある。線がまだ負荷を持つなら、濡れたリブはわずかに温まり、違う成長を集める。死んだ線なら継ぎ目は塩のひげになる。

重要なのは順序だ。人間の補修巻きは、生きた修復網より前にある。導電性バイオフィルムは後から割れ目に住む。Atlasのバイオファイバーは後から閉じようとする。灰色のテープは最初の判断を残す。替え部品がない。清潔な予定もない。それでももう一勤務だけ持たせる。
