# 最後の平常日の証拠セット

最後の平常日は日付ではない。仕事が中断されたときに部屋が保つ形だ。ロッカー札は戻らなかった手を待つ。訂正票に署名がないのは、誰かが下降後に戻ってくるつもりだったからだ。ポンプ作業は開いたまま。昼食トークンはテープの下に留まる。ルート時計は帰還印を待ち続ける。時計には沈黙という分類がない。

これらの物は演説より信頼できる。記憶のために並べられたものではない。掲示はまだシフトを回し、クルーを食べさせ、サンプを空け、工具を数え、ルートを正直に保とうとしていた。だから証拠が痛い。植民地はまだ災害になりきっていなかった。故障が壁に入った後でも、まだカップ、鍵、遅れた署名について争えるほど平常だった。

Marauder にとって、このセットは雑な salvage への警告でもある。価値ある札は数秒で剥がせるが、未署名の訂正は公式原因欄が空だった理由を説明するかもしれない。留められた食事トークンは、ドア時計が止まる前に作業者が帰るつもりだった証拠になる。遺体分類は、ポンプ証明とシフト数が食い違うまではきれいに見える。

物を取る前に、中断を読め。HECTON-8 の沈んだ部屋には完璧な最終メッセージはいらない。もっと小さい証言のほうが強い。開いた仕事、渡されなかった義務、すでに海に取り除かれた人を待つ時計。
