# 内側月リレー危険

内側月のリレー危険は通信失敗を物理にする。Skarn整列サージはアンテナを殺さずに壊す。Velaの塵と氷は、航路が存在を主張したまま光学を閉じる。

ClawとLumenは古い航路論理を運ぶためさらに悪い。handshakeは形式上有効で、作業上は無価値になり得る。だからBlack Keelはパケットを記録し、custodyを保ち、体を水中に残せる。
