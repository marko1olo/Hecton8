# 漏水・錆・生膜の時系列台帳

HECTON-8の漏水痕は汚れではなく、層になった時計だ。錆、塩、生膜、油、ガスケットから流れた黒い筋は、同じ速度でも同じ理由でも現れない。重ねて読むと、壁は背景ではなく失敗の記録になる。

ボルト下の錆は水が長く留まった証拠だ。緑褐色の生膜は、温かい機械、廃液、冷却液、または有機材を通った遅い流れを示す。白い塩は水が移動し、乾き、または圧力で呼吸した痕跡だ。塩の上に油があれば機械漏れは後だ。油の上に塩があれば水が後から来た。

略奪者にとって、この順序は道具になる。層のある部屋は、壊れ始めたあともしばらく生きていた。誰かがポンプを動かし、拭き、ロックを回し、負けかけた場所へ電力を通していた。染みは隠れた保守路、遅い修理、避難後の移動、または公式報告が数週間を一文に縮めた証拠を示す。

## Scanner

漏水痕 // ボルト列の下の錆、緑褐色の生膜、ガスケット縁の白い塩花。油水の染みが鉱物縁を横切る。これは一撃ではなく、初回浸水後も漏れが周期化した印だ。

## Terminal

漏水時系列 // 層を順番に読む。錆は濡れた金属に酸素が届いた場所で育つ。生膜は遅い栄養流に従う。塩花は蒸発か圧力呼吸を示す。きれいな塗装の下に黒いガスケット流れがあれば、パネル破断前に封止が死んでいた。
