# 塩層追い

塩水境界に沿って狩る。境界がこの動物のために嘘をつくからだ。

密度境界では音が曲がる。その線に乗った追い手はソナー上で二つの深度に同時に返り、きれいな反射のほうがたいてい偽物だ。第88ステーションが二重に記録されたのも同じ理由だ。Marauderが沈船を使うのと同じように、この層を使う。

踏み込む前に試す。最初の一回は距離を取って肩の外側を通り、こちらが振り向くかを確かめる。振り向いて正面を向けば、その通過は終わる。泳ぎ続ければ、二度目の接近は通過ではない。

塩水は皮膚に残る。擦れたスーツのシールは正常と表示され、一交代あとに破れる。

セクター44から出る標示済みの避難通路を巡回している。評価：正面を向き、それから相手が知るはずのない経路で離脱する。
