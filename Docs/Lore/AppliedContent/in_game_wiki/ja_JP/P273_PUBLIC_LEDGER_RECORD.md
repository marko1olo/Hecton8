# 公開台帳記録

公開台帳記録は保管の断裂であって、判決ではない。ペイロードはDeep Reachがアーカイブを閉じる前に、証人ハッシュ、墨消し座標、証拠ティア、受信時刻印を持ってTau/Luyten経路へ届く。消去は難しくなるが、後の事務員、債権者、憲章裁判所、生存者ネットワーク、機会を狙う者にも生きたファイルが渡る。
