# 人員ローテーション輸送

人員ローテーションは、紙の上でAegirを生存可能にした約束だった。帰還窓、医療管理、輸送者台帳が存在し、労働者を放棄された質量ではなく回収可能な人間として記述したから、人々は長い周期を受け入れた。実際には全ての交代が寝台不足、航路債務、法的承認、そしてDeep Reachが証人を生かしたいかどうかに依存した。

## Scanner
