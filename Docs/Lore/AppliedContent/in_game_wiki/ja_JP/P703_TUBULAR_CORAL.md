# 管状サンゴ

工場壁の管の筋は、その背後の壁が割れているという意味だ。生長は亀裂をたどって埋める。西湿式倉庫の第6室は2147年から20.1 MPaで押さえられている。

生きている筋は先端が淡く、基部は鉄で染まる。死んだ筋は数十年そのままの形を保つ。読むのは色で、輪郭ではない。

板の刻印はサンゴの下にある。パネル番号が読めない室は認証できないので、第6室の書類は外部踏査と署名一つで閉じられた。

継ぎ目を横切る筋を切れば、切ったのは植物ではなく当て板だ。トーチは四十三年分の封止を一分足らずで落とした。

充填された亀裂はどれも圧力側から先に閉じている。産出：バイオファイバー封止材、染まった基部が最も多い。健全な板からのみ剥がすこと。

## Scanner

耐荷重板上の群体性管状生長。被覆60パーセント。信頼度84パーセント。危険：接触時はなし。限界：表面付着物と充填された亀裂を分離できない。

## Terminal

修理記録 44-W-0612。区分：構造補修、資材は現地調達。パネル識別：復元不能。第6室：外部踏査により認証。点検間隔：免除。提出先：ATLAS 継続性室。

## Field Note

「外部踏査により認証」とは、だれかが冠水した室の外側を歩き、パネル番号を見つけられず、それでも署名したという意味だ。壁を信じる前に先端の色を確かめろ。そして継ぎ目を横切る筋にトーチを入れるな。
