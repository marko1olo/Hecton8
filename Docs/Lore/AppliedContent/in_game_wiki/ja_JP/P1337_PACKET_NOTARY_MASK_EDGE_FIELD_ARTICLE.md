# packet notaryマスクの縁

packet notaryマスクは、レコーダーが忘れたふりをせず、非公開の転写データを示すためのものだ。正しいマスクには理由がある。法的hold中の名前、隔離下の座標、sealed table扱いのpayloadシリアル。マスクは文書層にあり、媒体の損傷を変えない。縁が重要なのは、手続きが物質に触れる場所だからだ。

ハイドロフォン帯やレコーダーカセットでは、遅いマスクは癖を出す。顔料が塩の粉の下ではなく上に乗る。浅い傷をまたぎ、傷の底に落ちない。印字されたroute stampを覆るのに、同じ黒塗りを要求するはずの擦過を外す。拡大すると、媒体とnotary層が別の順序を語る。部屋が先に帯を傷つけ、事務側が後で行を隠した。

Deep Reachはマスクを「承認済み編集」と呼べるが、時刻についてはまだ嘘をつける。承認は順序を決めない。順序は顔料の縁、鉱物の重なり、クロックラダーの括弧、工具が媒体を引いた最初の場所に残る。マスクの縁が塩より古いなら、転写は露出前に保護された。塩よりきれいでカセット傷の上に浮くなら、回収後に清掃された。

扱いは厳密にする。拭く前に縁を撮影する。媒体をコピーする前に、隠れた行を読む目的で顔料を削らない。マスクを転写損傷帯とroute permission stampに照合する。遅いマスクの横でスタンプが読めるなら、きれいな救助転写は処理済みclaim documentに変わる。
