# Cable Skin Pulse Knot

The pulse knot in cable skin swells when old relay current passes underneath. It can point toward live infrastructure or toward a short. The knot is useful only with timing: steady pulse means route, twitching pulse means bite.

## Scanner

PULSE KNOT // Cable skin swelling over relay current. Pulse irregularity noted.

## Terminal

RELAY ROUTE // Track steady pulse. Avoid twitching knot until circuit isolated.

## Audio

Technician note: count the pulse before you trust the direction.
