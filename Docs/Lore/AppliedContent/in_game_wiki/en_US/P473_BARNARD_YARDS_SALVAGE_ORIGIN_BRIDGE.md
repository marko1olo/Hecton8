# Barnard Yards Salvage Origin

Barnard Yards explains why the operator knows the first repair order on HECTON-8: drain, isolate, patch within rating, cut only service metal, preserve evidence, then move. That competence is not freedom. The same yard logic turns tools, training, and dead claims into debt Black Keel can price.

## Scanner

BARNARD YARDS TOOL TAG // Rented cutter handle. Pressure-clamp certificate valid. Debt window linked to Black Keel intake. Operator trained for dead-claim salvage, not free rescue.

## Terminal

BARNARD YARDS RENTAL COUNTER // Issued: induction cutter, clamp set, seal gauge, witness sleeves. Lien note: tool loss, contamination, uncertified cut, or failed payload witness may convert contract work into recoverable debt. Drain before cut. Rate before lift. Tag before sale.

## Audio

You rented the cutter, not the claim. Bring back the handle, the clamp count, and a clean witness tag.

## Field Note

Barnard teaches you to cut quiet and read debt loud. The cutter tag is a leash with a serial number.
