# Key Cabinet Empty Hook

The empty hook swings longer than the others when the cabinet opens. A missing key can still move air.

## Scanner

Hook paint is worn through to brass. The label below it was peeled and replaced with a shorter word.

## Terminal

Key custody shows the item retired. Door records tied to that key continue after retirement under emergency override.

## Audio

Cabinet glass rattles. One hook ticks alone after the door closes, counting the absence.

## Field Note

Retired keys are dangerous when locks remain old. Empty hooks deserve the same attention as open doors.
