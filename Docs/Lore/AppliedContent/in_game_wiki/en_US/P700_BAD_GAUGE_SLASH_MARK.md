# Bad Gauge Slash Mark

A recovered slash mark warns that a gauge survived the flood but lost the truth. Marauders cut the slash across displays that lag, stick or flatter pressure after pump cycling. The analog face still helps if the player treats it as suspect.

## Scanner

BAD GAUGE // Slash mark across pressure face. Compare with hatch sound and pinger waterline.

## Terminal

GAUGE WARNING // Manual readout flagged for lag after pump restart. Use secondary pressure cue before opening route.

## Audio

Marauder note: bad gauge can still tell you when it lies the same way twice.

## Field Note

Broken instruments are tools after you learn their failure.
