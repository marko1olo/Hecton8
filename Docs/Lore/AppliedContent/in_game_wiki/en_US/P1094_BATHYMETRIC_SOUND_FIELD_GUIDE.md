# Bathymetric Sound Field Guide

Depth on HECTON-8 is a working condition, not a number. The Photic Shelf, Cable Reef, Brine Canyons, Machine Fields and Atlas Basin each change buoyancy, signal range, oxygen work, predator cover and machine behavior.

Sound is the main horizon because radio dies in mineral water. Acoustic ducts can carry a pinger for kilometers. Brine mirrors can draw rooms that are only reflections. Shadow zones can erase a signal beside you. Treat sonar as a witness, not a verdict.

## Scanner

ACOUSTIC FIELD // Radio dead below shelf. Check band, duct, mirror and shadow zone. One clean ping is only one witness.

## Terminal

HYDROACOUSTIC NOTE // HECTON-8 bends sound by pressure, salt and heat. Re-ping from another angle before cutting, welding or following a return.

## Audio

HECTON-8 is never silent. Ask what made the sound, what layer bent it, and who else heard it.

## Field Note

Ping once to notice. Ping twice to doubt. Move before the ocean answers too clearly.
