# Seed Role Name Grammar

Seed Role Name Grammar is the rule that keeps replay variation from becoming noise. A seed-role worker may appear in a different locker, beside a different damaged tool, or under a different route permission from run to run. The identity still needs grammar: a stable personal name, a crew family, a permission context, a last task, and an object variant that can be inspected. If any part is missing, the name stops feeling like a person and starts feeling like generated filler. The system may shuffle evidence order; it must not shuffle away responsibility.

## Scanner

A seed can move evidence order. It cannot turn a worker into disposable text.

## Terminal

SEED GRAMMAR: personal_name + crew_family + route_permission + last_task + object_variant. Localization may annotate crew terms for readability, but it must not rewrite identity, erase the job, or detach the name from a concrete object.

## Audio

Random is not authorship. Bind the name to a job.

## Field Note

Each seed-role identity combines personal name, crew family, route permission, last task, and object variant.
