# Marauder Tool Pledge Mark

The pledge mark is scratched into a cutter handle, tying the tool to a debt pool rather than a single owner. It means repair first, payment later, argument always. The mark keeps crews honest enough to keep moving.

## Scanner

PLEDGE MARK // Cutter pledged to shared debt pool.

## Terminal

TOOL CUSTODY // Return pledged cutter to marked cache after route use.

## Audio

Marauder rule: borrowed steel comes back dull or paid for.

## Field Note

Trust is easier when scratched into metal.
