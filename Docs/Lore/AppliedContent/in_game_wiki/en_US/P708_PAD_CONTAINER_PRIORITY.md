# Evacuation Load Priority Notice

Notice ELP-7 is a numbered loading order for Berth 3. Personnel are line four.

The basis line is not a lie. Sealed substrate genuinely cannot be reconstituted off-site, and the office that wrote this had a defensible engineering argument for every line above four. Nobody had to decide that workers mattered less. They only had to decide what was irreplaceable, and then let the list sort itself.

Berth 3 still holds the racks. They are latched, rated, and intact, which means they were never loaded either. Whatever window this notice was written for did not open.

The muster bench opposite is empty except for one boot, left upright. Assessment: the racks are salvageable and heavy, and the tonne-window will make you re-read line four.

## Scanner

Priority tag, polymer, still latched. Confidence 94 percent. Hazard: rack contents pressure-rated, seal intact. Limit: cannot read the reverse face without cutting the tie.

## Field Note

Four. They wrote it down as four and then never came for one through three either. Take the rack if the window allows it, and read the number out loud before you decide that is fine.
