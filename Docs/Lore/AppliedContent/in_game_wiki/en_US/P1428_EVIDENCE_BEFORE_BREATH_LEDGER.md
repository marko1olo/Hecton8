# Distress Hash Notary Ledger

A distress hash leaves fast because it is small: identity, sample mark, witness time, pressure telemetry and a checksum. It can cross a relay window in pieces. It can be copied, challenged, priced and stored without cabin volume or medical risk.

A living body uses a different ledger. It needs temperature, pressure, contamination handling, route authority, quarantine, braking margin and somebody willing to own the stop. Black Keel can accept the hash while refusing the mass. That makes the first answer useful but not safe. The operator has made the event harder to deny, not easier to survive.

## Scanner

Salt-pitted notary cradle. Witness seal intact. Accepted: identity hash, sample hash, time window, pressure telemetry. Life-support allocation absent.

## Terminal

RETURN ACTION QUEUE RAQ-08
Evidence chain: verified
Extraction language: suspended
Missing fields: route owner; breathing-mass custody; quarantine berth; lift reservation; braking margin
Instruction: acknowledgement is not extraction.

## Audio

Hash accepted. Seat not assigned. Air still counts down.

## Field Note

When the terminal says accepted, read the next noun. Evidence accepted is not person accepted.
