# Aegir Relay Window

Aegir can let a packet climb while leaving the operator underwater. The relay window is a temporary geometry between weather, magnetics, queue, Black Keel carrier position, and legal clearance. It proves a message may leave HECTON-8; it does not prove anyone can lift a body through the same opening.

## Scanner

RELAY WINDOW // Signal receive lane opening. Storm plume and Aegir magnetic noise remain high. Recovery blocked until ascent package, quarantine handshake, and tonne-window allocation clear.

## Terminal

AEGIR RELAY NOTICE // Contact may pass before help can move. Preserve packet route, timing mark, antenna state, storm plume reading, carrier lane, and custody seal. Window acceptance does not allocate oxygen, lift mass, or operator extraction.

## Audio

Signal lane opens first. Help comes only if the rest of the machinery agrees.

## Field Note

A received ping is not a rescue ship. Mark the window, save the route, and keep cutting.
