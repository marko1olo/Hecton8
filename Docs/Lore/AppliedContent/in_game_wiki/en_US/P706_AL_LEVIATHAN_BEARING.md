# Six Returns, No Range

A bearing with an empty range field is a reading, not a broken set.

Mark 9 active sets carry an upper limit on target extent. A return above that limit fails the range solution, so the gate discards the range field while the bearing channel, indifferent to extent, keeps working. Six returns inside an arc second of each other is not noise. It is six good measurements of direction and a refusal to state distance.

Bearing drift under your own motion is the only ranging left. Four degrees in eleven minutes while swimming means station-keeping.

Two sets on different hulls, run the same hour, both refused range and disagreed on bearing by eleven degrees.

Assessment: kill the active set, change depth rather than heading, and log the full bearing series. The gate limit has not been raised since 2147.
