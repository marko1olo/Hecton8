# Thermal Vent Pulse Count

The vent pulse count repeats in groups of four before a hotter fifth burst. Old chalk marks on the pipe record the same rhythm. Workers counted pulses because the heat had a beat long before it had a warning panel.

## Scanner

PULSE COUNT // Four warm bursts before hotter fifth vent pulse.

## Terminal

VENT CROSSING // Move after second pulse only if exit is clear before fifth.

## Audio

Pipe mic: one, two, three, four, bite.

## Field Note

Rhythm can be a survival interface.
