# Atlas Biometal Scrap Grade

A recovered scrap tag makes Atlas-altered metal valuable and suspect. Biometal can carry signal memory, repair affinity and contamination grade in the same shard. It may fit a relay, improve a pinger or invite a maintenance system to classify the player's route as unfinished repair inventory.

## Scanner

BIOMETAL SCRAP // Signal memory detected. Keep away from clean evidence packets and shelter relay.

## Terminal

SCRAP GRADE // Atlas-altered biometal requires contamination tag, signal bleed test and isolated storage before use in repair path.

## Audio

Marauder note: if the metal remembers, make sure it remembers from a bag.

## Field Note

Smart scrap is still scrap. Dangerous scrap gets its own pouch.
