# Worker Roster Ledger Limit

The worker roster ledger keeps HECTON-8's human evidence small enough to follow. Seventy-two active identities is enough for crews, lockers and shift boards without turning every wall into disposable names. Twenty-four anchor workers recur across pump tags, route permits, meal chits, damaged tools and audio fragments. Forty-eight seed-role workers widen the run while still carrying a job, a place and a last task.

The ledger's job is evidence control. A name without a room is decoration. A name with a job card, a water count and a damaged tool can return later as proof that somebody changed the record.
