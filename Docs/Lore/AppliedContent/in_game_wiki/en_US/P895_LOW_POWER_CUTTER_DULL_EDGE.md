# Low-Power Cutter Dull Edge

The cutter edge is dull from work on ceramic, not metal. It will still open foil, tape and soft hose, but it wastes charge on hard panels. The edge tells the player when a tool is still useful and when pride is burning battery.

## Scanner

DULL EDGE // Ceramic wear. Soft material cuts remain viable.

## Terminal

TOOL USE // Save cutter charge for hose, foil and tape until edge is dressed.

## Audio

Marauder note: dull steel still has small jobs.

## Field Note

Knowing what a bad tool can still do is survival.
