# Missing Return Mark Claim Conversion

A return mark closed a route. It did not prove a worker was safe; it proved the route desk had stopped counting the worker as moving. The mark could be a return tick, a cancellation slash, a medical transfer, a recovery exception or a loss code. Without one of those marks, a route stayed administratively open.

An open route is dangerous evidence. Deep Reach could point to it and say the worker was still assigned, still reachable, still part of an active operation. The room can prove otherwise. A cold suit tag, a cut tether, a triage ledger with oxygen stopped, or a hatch scrape after the time window can turn the missing mark into a custody failure.

The claim conversion happens when a later desk uses the open route to reclassify the carrier. A transcript stops being a distress record and becomes recoverable mass, contaminated equipment, billable delay or salvage property. The missing return mark does not solve the death. It shows where the paperwork refused to close it.

Field handling is simple. Preserve the stamp before cleaning salt. Compare the open route to oxygen cutoff, suit tag, triage line and packet notary mask. If the route stays open after the body evidence closes, the desk was protecting a claim, not a worker.

## Scanner

MISSING RETURN MARK // Route stamp has worker, hatch and task, but no return closure. Later claim desk exception uses the open route as recoverable mass.

## Terminal

RETURN MARK QA // Check return tick, cancellation slash, recovery exception, claim desk handoff and oxygen ledger cutoff. Open route is not proof of survival.

## Field Note
