# Metal-Ion Battery Brine

A recovered power tray shows emergency chemistry at worker scale. Metal-ion brine can wake a low cell long enough for a pump cycle, latch release or pinger burst. It also fouls contacts and makes future repair harder if the player treats it like clean charge.

## Terminal

POWER NOTE // Use battery brine only for low-duration circuit recovery. Rinse contacts before returning cell to tool pool.
