# Emergency Buoy Dead Loop

A recovered buoy signal repeats an ascent request the hardware can no longer satisfy. The buoy is useful as a clock, surface hint and warning marker, but it has no authority to prove the capsule can launch.

## Scanner

BUOY LOOP // Emergency ascent request repeating without fresh capsule state. Treat as stale signal.

## Terminal

BUOY STATUS // Distress loop active. Recovery confidence invalid until capsule ring, ascent bus and window geometry update.

## Audio

Buoy loop: ascent request pending. Ascent request pending.

## Field Note

Dead loops comfort nobody. They only prove the system learned one last sentence.
