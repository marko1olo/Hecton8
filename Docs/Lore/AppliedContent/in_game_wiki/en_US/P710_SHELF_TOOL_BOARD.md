# Tool Board, Shelf Camp 186

Every hook on this board carries a printed label, and every tool sits on the hook its label names. The strip was dusted before the crew left.

The four-dot hook is empty. Four centre-punch dots instead of a name is the rigger's mark, and the out-log reads CUTTER HEAD 4 DOT, SHIFT S-14, with the return column blank.

A descent card pinned at the left edge is in another hand: bearings as three digits and a depth, 214/1,190. Below it, printed, HOISTS STOP AT CROWN 1,880.

The shelf reads 1.86 MPa and a Class-IV works it all shift. Following the card gets you to the factory face in one descent, which is where the card stops being correct. Assessment: strip the rated cutting gear, and copy the out-log before you copy the card.

## Scanner

Printed tool board, shelf camp, 1.86 MPa ambient. Confidence 92 percent. Hazard: none. Limit: one hook logged out, no return entry on the strip.

Cutting gear goes out against the window, so an unreturned head is money, not carelessness. Whoever kept this board did it properly right up to the hook that stayed empty.
