# Scanner Cache Red Rescan

The red rescan mark appears when cached scanner data conflicts with a fresh material read. It is not an error to dismiss. It means the object changed, moved or was misunderstood the first time.

## Scanner

RED RESCAN // Cached data conflicts with fresh material read.

## Terminal

SCANNER CACHE // Keep both reads until route state explains the conflict.

## Audio

Suit note: second scan made the first one nervous.

## Field Note

Contradiction can be new evidence arriving.
