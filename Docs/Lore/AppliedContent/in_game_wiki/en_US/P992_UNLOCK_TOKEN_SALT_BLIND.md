# Unlock Token Salt Blind

The unlock token is salt-blind across its contact strip, so it opens by proximity only when pressed hard. The token works badly enough to be misread as revoked. Cleaning it changes access before authority does.

## Scanner

SALT BLIND // Contact strip obscured. Hard-press proximity open possible.

## Terminal

ACCESS TOKEN // Clean contact strip before requesting override.

## Audio

Worker note: press until it remembers you.

## Field Note

Access can fail from dirt, not decision.
