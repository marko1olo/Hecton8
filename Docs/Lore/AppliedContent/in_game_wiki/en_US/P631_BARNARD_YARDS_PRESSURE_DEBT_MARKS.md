# Barnard Yards Pressure Debt Marks

A recovered yard stamp ties Marauder tools to the breaker culture that built them. Barnard Yards crews mark pressure clamps, rented cutters and dead-claim cases with service debt, not family crests or flags. The mark says the tool survived hull work, bad contracts and people who measured trust by whether a gauge was reported before it killed somebody.

## Scanner

BARNARD YARD MARK // Scratched pressure stamp on a rented cutter case. Debt notch, service cycle and dead-claim tag are still readable under salt.

## Terminal

MARAUDER CACHE TAG // Barnard tool pool asset. Return credit void after dead-claim breach. Report gauge drift, clamp scar, battery swell and cutter-contact loss before next route.

## Audio

Marauder cache: yard rule still stands. Bad readings kill the next diver. Log the fault or wear it.

## Field Note

Barnard marks do not make a tool noble. They make it accountable.
