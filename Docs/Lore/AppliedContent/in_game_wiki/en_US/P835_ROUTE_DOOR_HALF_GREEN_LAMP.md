# Route Door Half Green Lamp

The route door lamp glows green on the hinge side and dark on the latch side. The panel reads passable because the old circuit averages both halves. The body must trust the latch side, not the arithmetic.

## Scanner

HALF GREEN // Hinge-side lamp active, latch-side lamp dead. Passable average false.

## Terminal

ROUTE DOOR // Inspect latch voltage before treating green state as safe.
