# Predator Shadow Encounter Grammar

Predator-shadow encounters should make the ocean feel occupied before the animal becomes visible. The useful warning chain is environmental: glass grazers stop with food still exposed, lantern bloom thins along one side, pressureweed folds without surge, sonar returns show a gap too wide for debris, and the player light crosses a broad shape that never resolves into a clean silhouette. The animal is not a boss waiting in an arena. It is route pressure. It changes oxygen spending, return-line discipline, repair timing and scan confidence. A good shadow encounter lets the player survive by reading absence: stop adding noise, keep the lamp narrow, do not chase the clean lane, and leave on an angle instead of sprinting straight back through the marked water.

## Scanner

Predator shadow trace. Sonar gap, cut prey path, sudden grazer silence, broad light occlusion. Body unconfirmed; keep light discipline and exit angle.

## Terminal

ENCOUNTER GRAMMAR / PREDATOR SHADOW / role: route pressure before body reveal, oxygen-spend spike, scan-confidence break / safe read: prey path stops, bloom noise collapses, sonar returns split around empty water / reject: scripted full-body reveal as first warning, harmless jump scare, clean boss arena / route note: if every small animal stops before the scanner names a target, the route has already changed.

## Audio

The safe sign is not seeing it. The safe sign is noticing everything else choose silence first.

## Field Note

Name the animal late. Let prey, light and sonar fail first. If the route goes quiet, the shadow already owns it.
