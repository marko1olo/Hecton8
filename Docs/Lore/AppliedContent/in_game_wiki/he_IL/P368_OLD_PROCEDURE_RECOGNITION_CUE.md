# רמז זיהוי נוהל ישן

זיהוי נוהל ישן הופך את עברו של הפרוטגוניסט לכלי משחקי. השחקן אינו עוקב אחרי רמז מיסטי או נבואה אישית. הוא קורא טופס בטיחות שפעם היה עליו לסמוך עליו. חותמת מסלול בטוח אומרת שהקו אושר. הראיות בחדר אומרות שספירת העובדים שונתה. שדה העד הידני, החלק שנועד לכפות בדיקה אנושית שנייה, נאטם בידי משרד רציפות. הסתירה הזאת היא הקרס. Deep Reach לא רק הסתירה מסלול. היא השתמשה בשפת הגנת עובדים כדי לגרום לנטישה להיראות מושלמת מבחינה מנהלית. העניין האישי של הפרוטגוניסט מתחיל כהכרה מקצועית: הטופס הזה נועד למנוע בדיוק את הכשל הזה.

## Scanner

חותמת מסלול בטוח קיימת. ספירת העובדים נדרסה בשני סוגי דיו. שדה העד הידני נאטם. הטופס נבנה כדי לתפוס שקר כזה לפני שמישהו הפך אותו למדיניות.
