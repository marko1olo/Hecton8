# חתך קפסולת Styx

קפסולת Styx היא מעטפת לחץ חד-פעמית, לא שאטל. היא מעבירה מפעיל בחליפה מ-Black Keel לאתר עבודה חוקי עם מינימום מסה מבוטחת. היא מסוגלת לשרוד אטמוספרה, גזירת סופה ופגיעת מים מספיק כדי להשאיר מחסה, זרם חלש, מסוף וחפץ ראייה.

הכשל שלה מסוים: אריחי חום נוצלו, תורן uplink נגזר, מדחס הוצף, שרוול שחזור no-lock, handshake תביעה מתחת לסף שחזור. הקפסולה השאירה את המפעיל חי והוכיחה שמסירה וחילוץ הם אירועי חוזה שונים.
