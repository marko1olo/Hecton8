# מגבלת ספוילרים של אינדקס ציבורי

האינדקס הציבורי קיים כדי שהארכיון יהיה שימושי בלי לשרוף את המסלול. כותרת יכולה לקרוא למשפחת ראיות: מסלול משמורת, מחלקת ראיה, מצב השחרה, שפת תביעה, שער סורק. זה מספיק כדי שהשחקן יבין איזה סוג אמת הוא רודף ולמה חבילה אחרת חשובה.
