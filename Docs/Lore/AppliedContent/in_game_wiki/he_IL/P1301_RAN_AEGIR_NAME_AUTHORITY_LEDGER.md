# יומן סמכות שמות Ran / Aegir

HECTON-8 משתמש בכמה שמות כי כמה רשויות מנסות להחזיק באותם מים. Ran הוא הכוכב, עוגן אסטרונומי ושם לפיזיקת נתיבים. Aegir הוא ענק הגז, הגוף הזוהר בשמיים וקיצור של משרדי התביעה. RAN-B:H8 הוא מפתח קטלוג: קר, מבוטח וניתן למיון. HECTON-8 הוא שם השטח שבו השחקן מדמם.
