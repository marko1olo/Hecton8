# לולאת משוב של פאונה מתויגת חיישן

Deep Reach תייגה פאונה מקומית כדי למפות זרמים, כימיה ונדידה. תגים רבים שרדו יותר מהצוותים. Atlas עדיין קורא אותם כקלטי סקר, כך שמסלול של חיה יכול להעלות עדיפות תיקון או לפתוח אריח מפה ישן.

זה לא עושה את החיה צייתנית. היא יכולה להיות פצועה, טריטוריאלית, נגועה בחומרה ישנה או מחפשת מזון. המכונה רואה רק תנועה ונתונים. בוזז רואה אמת גרועה יותר: האוקיינוס יכול לדווח עליך בטעות.

## Scanner

תג חיישן קולוניאלי ישן מתחת לרקמת צלקת חדשה. פרופיל תנועה נכנס לערוץ סקר Atlas. החיה נסערת מפינג פעיל.
