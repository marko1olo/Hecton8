# חתך מערום הנעה Nearlight

ספינת nearlight אינה לפיד קסום שמוברג לגוף. מערום ההנעה הוא נתיב שלם שהפך לחומרה: beam arrays מוציאים כוח לפני יציאה, pellet lanes מניחים מסה ללכידה במקום שהספינה יכולה לשתות אותה, fusion-electric throats הופכים דלק לחשמל וחום, מגנים מקבלים אובדן אבק, רדיאטורים זורקים חום במשך שנים, וחומרת בלימה חשובה כמו האצה.
