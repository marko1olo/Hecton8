# דקדוק שמות seed-role

דקדוק שמות seed-role הוא הכלל שמונע משונות replay להפוך לרעש. עובד seed-role יכול להופיע בלוקר אחר, ליד כלי פגום אחר, או תחת הרשאת נתיב אחרת מריצה לריצה. לזהות עדיין דרוש דקדוק: שם אישי יציב, משפחת צוות, הקשר הרשאה, משימה אחרונה ווריאנט חפץ שאפשר לבדוק. אם חלק חסר, השם מפסיק להרגיש כמו אדם ומתחיל להרגיש כמו מילוי שנוצר. המערכת יכולה לערבב את סדר הראיות; אסור לה לערבב את האחריות עד שהיא נעלמת.

## Scanner
