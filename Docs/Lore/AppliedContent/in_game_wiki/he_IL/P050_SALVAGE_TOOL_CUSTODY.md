# Salvage Tool Custody

Salvage tools ב-HECTON-8 הם survival gear, אבל הם אינם innocent. Cutter פותח panel. Patcher seals a line. Fabricator dock prints a clamp שמחזיק air moving. אותה action יכולה גם write custody: מי used the tool, מה opened, האם sample pouch היה attached, ואיזה claim token owns the next argument. ה-record הזה יכול protect evidence או tighten debt. החלק האכזרי הוא ש-refusing the tool יכול kill faster מאשר accepting its witness.
