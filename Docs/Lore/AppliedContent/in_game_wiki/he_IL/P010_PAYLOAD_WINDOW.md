# חלון מטען

חלון המטען הוא המקום שבו בחירות אחרונות הופכות לפיזיות. השחקן יכול להזיז רק מסה מוגבלת דרך לחץ, כיסוי סערה, תזמון קרינה של אגיר וגאומטריית חילוץ של Black Keel. כסף, ראיות, שמות עובדים, קואורדינטות, דגימות חיות, אות Atlas או שתיקה אינם יכולים לצאת יחד.
