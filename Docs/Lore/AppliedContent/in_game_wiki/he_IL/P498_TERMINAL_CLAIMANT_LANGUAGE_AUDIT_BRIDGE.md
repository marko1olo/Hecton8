# ביקורת שפת תובעים

שפת התובעים היא אחד הנשקים השקטים ביותר של המושבה. היא לא צריכה להכחיש את חדר המשאבות, את דלת המיון הנעולה או את מסת העובד מאחורי סבכת השירות. מספיק לשנות להם שם לפני שמישהו בעל כוח קורא את הקובץ. תור הופך לסטיית זמן שחרור. דלת נעולה הופכת לשער ביקורת בידוד. גוף שלא חזר הופך לחשיפת תשלום. חזרת חילוץ פגומה הופכת לזכאות חלקית.

הביקורת קיימת כדי שהשחקן יקרא שפת נוהל כפעולה. כל ביטוי שהומר צריך להיקשר מחדש לאדם, חדר, כלי, שעון מסלול או אירוע לחץ. Deep Reach יכולה להשאיר עד ועדיין לקבור את העדות באמצעות החלפת תווית המדף. אם הקטגוריה שרדה והגוף נעלם, הראיה כבר כובסה פעם אחת.
