# ביקורת שפת תביעות

הניירת של Deep Reach יכולה לקבור רשומה בלי למחוק אותה. היא משאירה את החדר, התג, חותמת הזמן ומספר הגופות, ואז מחליפה את שם העצם שלצדם. במטמון המראה Tau, חדר משאבות B שסומן כתפוס אחרי זמן ההצפה 03:18 מתויק כסטיית חלון שחרור. דלת טריאז' 2 שננעלה מצד הבקרה מתויקת כסקירת הסגר. תג עובד R-17 חסר, בעוד טבעת החליפה נמצאת במסת החילוץ, מתויק כחשיפת Keelmark. מגש החזרה עם ארבעה ווי ערכה ריקים מתויק ככשירות מטען חלקית.
