# ביוטה מוליכה ביער הכבלים

דגימה שנמצאה ביער הכבלים מסבירה מדוע צוותי חילוץ מאריקים את הכלים לפני קציר קלפ מוליך. הצמיחה נוצרת במקום שבו מעטפות ממסר ישנות, תמלחת מינרלית ומרבדים רעבי אור חופפים. היא יכולה לטלא חיווט חלש, למשוך מטען לתא מת או לגרום לממסר לענות בעוד פעימה אחת, אבל היא גם משליכה רוחות אות ועלולה להעיר רחפני תיקון שעדיין סופרים את הגשר החי כחלק מהנתיב.
