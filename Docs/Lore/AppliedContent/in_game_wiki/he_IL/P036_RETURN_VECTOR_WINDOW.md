# חלון וקטור חזרה

חלון וקטור החזרה הוא ההוכחה הראשונה לכך ש-Black Keel יכול לענות בלי להיות מסוגל לחלץ מיד. ה-carrier נע במסלול העברה אוטומטי מעל Aegir, אבל הדרך החוצה מ-HECTON-8 חייבת לעבור מזג אוויר, רעש חלקיקים טעונים, נזק ממסר וחומרת עלייה לא גמורה.

חלון חזרה תקף צריך ארבע קריאות יחד: גאומטריית carrier, פער סערה בפני השטח, נתיב ממסר נקי ושרשרת קפסולה שיכולה לשרוד שיגור. אם אחת נכשלת, ה-ping הופך לחותמת זמן במקום איסוף. אותה מערכת תומכת בהמשך בחילוץ חלקי, אבל היא לא סוגרת חוב, משמורת ראיות או נתיב פגום. כל תשובה מהמסלול היא מגבלת לוח זמנים עד שמיטת העלייה, ליבת ההנחיה, מגן החום ולחיצת יד החזרה נבנים מחדש.
