# מפעל הקרקעית

מפעל הקרקעית נמצא בהחזרה התחתונה של אגן Atlas. צנרת Deep Reach עדיין מזיזה שם brine וחום, אבל שרוולי פחמת וצמיחת סינון סגרו מסלולי שירות רבים. שאריות blue debt מכתימות את התפרים שבהם פלדה ישנה, מגשי כבלים ואטמים שגדלו בלחץ חולקים עכשיו את אותו נתיב תחזוקה.

השימושיות היא הסיכון. המקום מטלא דליפות, שומר משאבות במעגל ומעביר אות דרך נתיבים שמעולם לא אושרו לבני אדם. דלת יכולה להישאר סגורה כי האטם נעלם וצמיחת הלחץ נושאת את העומס. מגש כבלים יכול עדיין להעביר נתונים בזמן שהכיסוי שלו פועל כמסנן. טבעת חליפה, מכל דגימה או כלי עלולים להיעלם באותו שרוול תיקון אם תג המשמורת שלהם נקבר לפני שמישהו קורא אותו. התייחס לכל תפר בהיר כתשתית פעילה עד שנבדקו סימני הזרימה ומגירות התגים.
