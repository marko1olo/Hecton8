# 黑匣姓名堆栈

黑匣姓名堆栈把后期真相变成实物载荷。证据、广播和结局档案取决于玩家带上去的内容。

## Scanner

堆栈保存姓名、班次哈希和最终压力状态。这不是设定。这是证据。

## Terminal

档案堆栈可读。船员身份与疏散搁置、Atlas修复状态和Deep Reach删改请求交叉链接。
