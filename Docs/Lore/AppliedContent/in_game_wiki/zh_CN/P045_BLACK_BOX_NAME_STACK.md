# 黑匣姓名堆栈

黑匣子姓名栈让最终真相可以被携带。证据、广播包和公共档案取决于哪些姓名、哈希和收据离开水下。

## Scanner

堆栈保存姓名、班次哈希和最终压力状态。这不是设定。这是证据。

## Terminal

档案堆栈可读。船员身份与疏散搁置、Atlas修复状态和Deep Reach删改请求交叉链接。

## Audio

## Field Note

姓名是载荷。带走它们会改变结局。
