# Aegir月梯

Aegir月梯不是天空装饰。Ran是恒星，Aegir是巨行星，HECTON-8是在卫星、 relay、风暴、保管检查和承保质量窗口链条中的一颗海洋月球。

Skarn会用带电噪声淹没天线。Vela会用冰尘遮住relay。Kestrel会在最糟的分钟挡住视线。HECTON会把风暴羽流甩进干净的上升走廊。Black Keel能收到你的数据包，但如果窗口、隔离握手或质量等级失败，它仍会拒绝吊起。

## Scanner

轨道危险 // 窗口不稳定。Skarn涌动、Vela遮帘、Kestrel遮挡和HECTON风暴羽流都可能破坏回收几何。

## Terminal

回收窗口记录 // Black Keel在吊起人体前需要信号保管、干净payload hash、隔离握手和可回收吨位窗口。明亮天空不是救援许可。

## Audio
