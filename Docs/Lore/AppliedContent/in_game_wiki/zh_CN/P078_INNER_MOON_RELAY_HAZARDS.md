# 内侧卫星relay危险

内侧卫星relay危险让失联变得物理化。Skarn对齐的涌动会破坏天线而不杀死它。Vela尘埃和冰会遮住光学，同时航线仍声称自己存在。

Claw和Lumen更糟，因为它们携带旧航线逻辑。handshake可以形式有效、操作无用。因此Black Keel能记录数据包、保存custody，却仍把人体留在水里。
