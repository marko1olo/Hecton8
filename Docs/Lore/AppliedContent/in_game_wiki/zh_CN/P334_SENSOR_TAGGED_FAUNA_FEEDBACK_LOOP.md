# 传感标记动物反馈回路

Deep Reach 给本地动物打标签，用来绘制洋流、化学和迁徙。许多标签比船员活得更久。Atlas 仍把它们当作勘测输入，所以动物路线可能提高维修优先级，或打开过期地图块。

这不会让动物服从。它可能受伤、护地盘、感染旧硬件，或只是跟着食物。机器只看见运动和数据。Marauder 看见更糟的真相：海洋可能无意中举报你。

## Scanner

新疤痕组织下有旧殖民地传感标签。运动曲线进入 Atlas 勘测通道。动物受主动 ping 刺激。

## Terminal

动物回路 // 遗留标签 7F 通过受损勘测通道报告温度、运动和盐度。迁徙事件后 Atlas 维修优先级上升。带标签动物是遥测源，不是指挥资产。

## Audio

它不是替 Atlas 狩猎。它只是带着仍钉在皮下的徽章游泳。

## Field Note

带标签动物会无意改变地图。只有知道还有什么跟着它时，才跟它走。
