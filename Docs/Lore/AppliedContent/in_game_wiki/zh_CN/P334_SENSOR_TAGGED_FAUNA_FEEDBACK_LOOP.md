# 传感标记动物反馈环

传感标记动物把旧殖民地带在伤疤里。Deep Reach曾给动物打标，用于迁徙、压力和污染研究；后来Atlas把这些标签读成廉价环境遥测。生物不是傀儡。它的移动仍可改变维修优先级，唤醒无人机路线，或让安全通道看起来被占用。

## Scanner

壳层生长下有旧Deep Reach标签。迁徙轨迹匹配一次维护巡扫。

## Terminal

动物环：嵌入标签返回微弱的压力、运动和污染数据包。Atlas把移动读作环境状态，而不是动物意图。

## Audio

它不是在猎你。但它仍然可能汇报你。

## Field Note

适合动物无辜但仍会威胁路线的遭遇。
