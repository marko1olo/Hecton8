# 漂泥者

漂泥者的犁沟在开阔底面上是直的，在还有东西在抽水的地方会弯。

它吃水流带来的东西，所以弯折处就是五十到九十米之间一个仍在工作的取水口，也就是一个四十三年后仍然带电的舱段。它同时也是危险：能筛分沉积物的格栅会把安全绳吸进去，而那下面从那时起没有一处受过检查。

惊动它，它会把底面倒进水里。宽光束切不开这团浑浊，只会把它填满。降到弱光，守住方位，横向退出通道，不要向上。

从6号到11号，每一副格栅外的犁沟都逆时针弯，包括那两副往反方向抽的。

评估：先读弯折，再从通道外侧处理格栅。

## Scanner

底栖沉积物摄食种，40至90米。置信度66%。危险：接触即失去可见度。限制：悬浮沉积物中没有回波。接触会丢失，不会恢复。

## Terminal

文件 44-M-1180。类别：沉积物管理，被动。范围：取水格栅6至11，40至90 M。计划疏浚：已废止。格栅检查：视为现行。

## Field Note

“格栅检查视为现行”的意思是2147年之后没人看过任何一处。如果漂泥者守着一个弯折，那个取水口就还在抽水，所以把安全绳留在通道外面，从侧面上格栅。
