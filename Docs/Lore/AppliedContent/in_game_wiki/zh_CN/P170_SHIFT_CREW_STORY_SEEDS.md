# 班组故事种子

班组故事 seed 给 HECTON-8 重玩质感，同时避免把设定变成矛盾机器。同一个殖民地可以呈现不同工人配对、不同储物柜物品顺序和不同边注，但不能突然让 Deep Reach 变无辜，也不能让 Great Tide 有新原因。

变化范围必须局部。路线文员可以在一次 run 中关联 brine 潜员，在另一次关联密封索具员。拒绝单可以在储物柜里、岗位板磁铁下或 medlock 湿托盘旁。这些变化改变玩家组织证据的方式，不改变证据本身。

## Scanner

班次 seed // 名单可以变，罪责不能变。

## Terminal

班组 seed // 一次 run 可以改变名单顺序、工人配对、储物柜内容、拒绝单、路线粉笔、工牌碎片和后来的 Marauder 修正。seed 只能改变玩家如何遇见证据，不能改变证据证明什么。

## Audio

另一个储物柜可以从另一侧切入同一个真相。

## Field Note

seed 变化可以改变物品顺序、岗位配对和 Marauder 批注，但不能改变 Great Tide 或 Deep Reach 的责任。
