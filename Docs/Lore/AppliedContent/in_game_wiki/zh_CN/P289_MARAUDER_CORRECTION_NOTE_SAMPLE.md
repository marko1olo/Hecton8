# 掠夺者更正便条样本

掠夺者更正便条样本不是供词，也正因为如此才更有用。它是一张官方事故表上的脏污批注，出自一个已经学会不相信干净理由的人。便条没有说明谁杀了谁。它列出的是在事故这个词被允许留在档案里之前必须核对的东西：泵证、班次人数、尸体类别、舱门时钟错位，以及那条把救援拖到房间变成证据的授权队列。在 HECTON-8 中，这件物品把环境证据和派系声音接在一起。殖民地记录想用天气结束故事。掠夺者的笔迹把玩家推回现场。

## Scanner

事故表上用油脂笔改出的结论：不是天气，不是恐慌，而是一段带着尸体数字的授权延误。

## Terminal

掠夺者便条 / 官方原因：驳回 / 立案前必须核对：泵证、班次人数、尸体类别、舱门时钟错位、救援授权队列。
