# 努尔·哈尔丹的撤离证书

努尔·哈尔丹是Deep Reach撤离保留背后的法律与认证声音。她的签名不是以恐慌写成的，而是以控制写成的。路线必须仍然可认证。承运方必须接受监管。生物状态必须可复核。即使路线里的人活不过灾难，法律链也必须活过灾难。

这就是哈尔丹文件刺痛人的原因。语言能为自己辩护。隔离破坏可能传播污染。未认证撤离可能让承运方陷入困境。港口拒收可能把救援变成另一场灾难。在干净的会议室里，每个条款都像负责任的控制。在水位上升的耐压走廊里，同样的条款就成了锁。

对玩家来说，这篇文章把殖民地路线保留、医疗延迟和Deep Reach责任连接起来。哈尔丹不需要恨任何人。她只需要让撤离等待那些证明撤离安全的条件。压力不会等待。氧气不会等待。证书会等。

## Scanner

认证保留 // N. 哈尔丹让路线在法律上保持干净，而路线在物理上已经失败。
