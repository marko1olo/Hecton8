# 电缆森林导电生物群

一份回收的电缆森林样本说明了为什么打捞队在采集导电海带前必须给工具接地。这种生长出现在旧中继护套、矿物盐水和缺光菌藻垫重叠的地方。它能修补微弱线路，把电荷引入死电池，或让中继再回答一次；但它也会投出信号幽影，并可能唤醒仍把活体桥接视为通道一部分的维修无人机。

## Scanner

导电海带 // 活体丝束编进死去的中继电缆。储存微弱电荷，复述假脉冲；接地后切割，可以输出干净电流。

## Terminal

电缆森林生态 // 静电灌丛、灯草和电缆海带占据破裂绝缘层。湿润组织按带电线路处理：它读取振动，桥接受损通道，也可能被维修无人机登记为基础设施。

## Audio

掠夺者线轴记录：如果海带对你嗡鸣回应，停止切割。那不是植物在唱歌。那是通道还记得压力。

## Field Note

好线缆不会抽动。会抽动就接地、标记，然后决定你是否真的那么需要电力。
