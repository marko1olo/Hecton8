# 证据市场清理出价

清理出价是付费改变证据碎片流向的尝试: 清理、改名、压制、附到打捞批次，或移入更安全的类别。它证明有人认为纸面痕迹值得干预，但不证明碎片真假，也不证明买方有罪。在HECTON-8记录里，清理出价是动机压力: 追踪付款路线、原始标签、清理标签、索赔改写和保管转移。

## Scanner

清理出价 // 付费要求清理、重分类、压制或改道证据碎片。只是压力信号。

## Terminal

证据清理出价
不要把付款行当作裁决。
下一证据: 出价来源、付款扣留、保管转移、索赔安全改写、物体路线。
把原始标签保存在清理标签旁边。
