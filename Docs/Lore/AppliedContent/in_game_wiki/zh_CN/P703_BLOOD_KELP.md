# 血藻

你的工作灯看不见它。色素吸收了灯具所配的蓝绿波段，所以在12米处一丛读作开阔水，在3米处读作墙。

琥珀色应急镜片能把它整片提出来。它只在硬结构上扎根：1,900米开阔水里的一丛，不管海图怎么写，都坐在一块屋顶板上。

接触会触发发光器，从边缘开始向内推进，从不从触点向外扩散。它维持接近九十秒，足够把你进入的那道边缘上的任何东西照出来。

茎能承住一名潜水员的体重；缠住的背带拽不断。要从边缘往里切；17号舱那四起缠绕，都是从里面开始切的结果。

产出：生物发光化合物，未放过电的叶片含量最高。边缘总是已经放完的。切的时候用琥珀镜片。

## Scanner

固着叶状生长，深色色素。置信度49%。回波稀疏。危险：无记录。限制：色素吸收勘测灯波段，范围被低估。

## Terminal

采收批次 44-K-0774。类别：照明原料，B级。地点：17号舱屋顶，1,900 M。缠绕事件：4起。分类未变：非危险，植被。复审：资产沉默委员会，已结案。

## Field Note

四起缠绕，分类还是写着非危险、植被，因为那张表上没有一栏是给会抓住人的植物用的。接近时就把琥珀镜片挂上；白光在你已经进到里面之前什么都不会给你看。
