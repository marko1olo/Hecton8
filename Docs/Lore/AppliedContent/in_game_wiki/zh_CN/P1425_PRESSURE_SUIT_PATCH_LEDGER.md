# 压力服维修补丁账

压力服维修补丁是生命维持物上的人类笔迹。工厂面板用干净曲线和认证说话。现场补丁用歪针脚、异色织物、胶带下的盐，以及在下一次压力循环前堵住漏点的那种直白诚实说话。

补丁顺序很重要。十字针下面有缝带，说明第一次修理不被信任。线下有盐，说明压力服已经接触过水。补丁上方有磨损，说明穿戴者又回去工作。旧伤上的干净胶带意味着后期检查。两种布色说明材料来自另一套压力服，往往来自死掉的套装或没人打算再打开的柜子。

对拾荒者来说，补丁不是服装细节。它能指出紧急路线、工人的最后任务、医疗取舍、被偷的维修包，或一套本不属于穿戴者等级的压力服。在HECTON-8，生存常常是一道丑陋针脚，只撑过了下一次下潜。
