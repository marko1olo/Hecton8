# 近光速驱动堆剖面图

Barnard Yards的剖面图很直白，因为它是给承包工看的，不是给乘客看的。Atlas级船体的航程并不是从船上发动机点火开始。它开始于束阵列把功率花在帆上，开始于弹丸航道被清空，开始于捕获质量抵达聚变电喉管，也开始于护盾账册承认：尘埃会用多年时间磨掉昂贵的防护。

航程中段是一个把睡眠中的人装在里面的热问题。散热肋、冷冻舱、机工间、钻机托架和耐压货物争夺同一份余量。抵达不是胜利点火，而是另一台合同机器。磁帆卷筒、气动制动蒙皮、接收窗口和托管软件决定谁可以花掉本地制动时隙。所以Black Keel可以在Aegir上方给打捞通行定价，却不会变成救援。近光速运输船只有在航路基础设施、热预算、制动权和所有权对齐时才会移动。被困的Marauder只是账上的一行，除非有人迫使航路把他们算进去。
