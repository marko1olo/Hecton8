# 近光速驱动栈剖面

近光速飞船不是螺在船壳上的魔法火炬。驱动栈是一整条被做成实物的路线：beam array在出发前消耗功率，pellet lane把可捕获质量放到飞船能吞入的位置，fusion-electric throat把燃料变成电和热，护盾承受尘埃损耗，散热器用多年时间丢弃废热，而制动硬件和加速同样重要。

## Scanner

DRIVE STACK剖面 // Barnard Yards维护板：beam-sail yoke、pellet catcher、fusion-electric throat、shadow shield、散热肋、magsail spool、aerobrake skin和custody meter共用同一路线号。

## Terminal

ATLAS TRANSIT STACK // 出发推力：外部beam array。巡航供给：pellet lane捕获。转换：fusion-electric throat。损耗控制：护盾冰、碳层、散热肋。抵达权限：magsail spool、aerobrake skin、接收槽、custody账本。

这块板把热量放在推力前面。好板。廉价船组会先死在散热余量上，还没机会吹嘘速度。
