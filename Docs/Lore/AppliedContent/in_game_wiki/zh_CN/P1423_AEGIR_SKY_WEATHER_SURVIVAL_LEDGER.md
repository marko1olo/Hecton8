# Aegir天空天气生存账册

Aegir不是画上去的背景。它是幸存者能看见、却不拥有任何部件的最大机器。气态巨星、磁层、月梯、风暴带、中继角度和Black Keel航线，一起压在同一片小海上，而你只是在努力让潜服保持密封。

海面上的晴朗缺口会像慈悲，因为光回来了，carrier的声音也不再那么破碎。但这只是读数的一半。晴空也可能意味着带电粒子计数正在上升。风暴会遮住Aegir并毁掉数据包窗口，却也可能让身体避开最糟的噪声。月影会让潮汐卡片错上几分钟，而几分钟足够让浅水舱门、盐水层边缘或升空估算变成坏建议。

旧站点能活下来，是因为它们把天空当仪表，而不是风景。星历板不计算实时天体力学。它们保存被编写、可重复、可信的窗口表：什么时候中继通道足够干净可以发送证据，什么时候潮汐模型不可信，什么时候Black Keel能回答，以及什么时候ascent stack只是错误天空下的一堆昂贵金属。如果Aegir看起来很美，先检查无线电。美通常意味着有什么东西正穿过你。
