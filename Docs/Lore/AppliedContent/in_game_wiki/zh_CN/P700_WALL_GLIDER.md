# 壁滑者

它只在人造表面上行走。板材、电缆走线、管路、扶手，从不上裸岩，也从不跨过开口的裂缝。

这种拒绝本身就是一次勘验。痕迹连续不断的地方，下面的板材完好。痕迹折回自身的地方，板材正在开裂。

它留下的膜是导电的。在带电板材上这层膜也带电，工厂总控的导通检查会直接从膜上过去，所以壁滑者痕迹下面的发丝裂缝测出来是完好的。工具平放在新鲜的膜上会粘住一秒，仪表会空白十秒。

它们不越过Annex甲板上黄色的班次通道漆线。那些漆已经消失四十三年，它们仍然不越过。

评估：信痕迹，不信导通读数；痕迹停在哪里，你就停在哪里。

## Scanner

附面啃食种，只在人造板材上活动。置信度77%。危险：导电残留物，微弱电流。限制：无法判定痕迹的新旧。死痕与活痕读数相同。

## Terminal

文件 44-H-0742。类别：结构监测，生物，替代受理。覆盖：ANNEX P-63 船体板，0至100 M。结论：已勘验痕迹上无压力偏差。未勘验痕迹：未报告。

## Field Note

他们签掉的船体检查，就是动物碰巧爬过的地方；它们没爬过的板材没进报告，而松脱的正是那块板。痕迹停在哪里，你就停在哪里。
