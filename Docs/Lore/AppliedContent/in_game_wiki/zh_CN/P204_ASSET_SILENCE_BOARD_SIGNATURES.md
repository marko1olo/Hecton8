# Asset Silence Board 签名

Asset Silence Board 记录位于工人台账和公开报告之间。它们不制造损失；它们决定损失的哪些部分可以上路。redaction vote 可以让 load class、locker count 和 claim value 继续可见，同时静音见证人姓名和路线附件。所以这些签名应当与储物柜、redaction cards 和 packet mute flags 放在一起。Brigit Senn 的签名不让她变成隐藏指挥者。它标识的是下层办公室：该办公室在 relay review 后把可恢复的人类事实转换成 asset-risk categories。
