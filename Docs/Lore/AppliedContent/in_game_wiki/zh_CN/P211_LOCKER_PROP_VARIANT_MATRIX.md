# 储物柜道具变体矩阵

储物柜道具变体矩阵让工人证据保持物理性。一个好的储物柜会告诉玩家工人做什么、被允许去哪里，以及殖民地或后来的打捞者试图移除什么。工具磨损指向班组家族。航线标签指向门、升降机、潜服或爬行车舱。压力胶带和班次贴纸显示异常风险下的普通维护。薪资擦除疤和掠夺者保存标记显示证据的第二次生命，在 Deep Reach 试图把人变成成本行之后。结果应当亲密，但不能变成装饰杂物。

## Scanner

储物柜应显示工作、航线权限，以及某人试图擦除的东西。纪念物只有在工作可读之后才允许存在。

## Terminal

LOCKER MATRIX: 每个作者化储物柜需要三条可读线索：工作、路线和损坏。装饰性记忆是次要的。储物柜可以放家庭物件或私人玩笑，但必须先由工具、许可痕迹或擦除疤告诉玩家这个人如何接触过殖民地。

## Audio

储物柜不是神龛。它是一张失败的工作单。

## Field Note

变体：工具磨损、航线许可标签、压力胶带、班次贴纸、薪资擦除疤、掠夺者保存标记。
