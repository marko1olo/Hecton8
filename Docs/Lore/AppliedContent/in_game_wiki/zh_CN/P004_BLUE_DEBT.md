# Blue Debt

Blue debt是Marauder对压力保存的Xenon-Omega材料及相关工艺残留的俗称。它不是单一矿物，而是一类压力生长晶格、包合结构、污染基质和工业残余。Deep Reach曾将其用于高能约束、极端计算和Atlas兼容基础设施。
