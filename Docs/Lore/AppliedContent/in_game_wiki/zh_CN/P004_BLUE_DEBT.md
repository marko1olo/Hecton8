# 蓝债

蓝债是掠夺者对压力保存Xenon-Omega残留物及其周围污染基质的俗称。它不是单一矿物，而是一族冷晶格、笼形包合物、计算灰、失败的约束凝胶，以及Deep Reach设备留下的深层工艺废料。在HECTON-8的水柱下，它安静到足以移动。进入舱内空气后，它可能释放反应性气体、玻璃状粉尘和法律麻烦。它重要，是因为它同时连接三套系统：高能约束、Atlas兼容记忆，以及salvage经济。密封样本可以买到能源电池、工具许可或脱离债务的路。同一份样本也可能标记carrier，触发留置权，毒害庇护所，或证明Deep Reach回来寻找它声称已经放弃的东西。

## Scanner

压力保存的Xenon-Omega残留物。在寒冷、黑暗、碾压般的水中稳定；在温暖空气和低压中危险。

## Terminal

XO CONTINUITY SUBSTRATE。需要压力锁。不得排放。保管标记：索赔 / 污染 / 留置权。

## Audio

容器在声呐上歌唱。低沉而规律。那是工艺残留，不是生命。把它当成比生命更糟的东西处理。

## Field Note

他们叫它蓝债，因为每一克都向未来借款。它先付款，然后派收债人来。
