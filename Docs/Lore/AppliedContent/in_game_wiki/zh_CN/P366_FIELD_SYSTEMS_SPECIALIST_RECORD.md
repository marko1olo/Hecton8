# 现场系统专员记录

现场系统记录解释了操作员的能力，却不把操作员变成秘密指挥官。Deep Reach围绕泵、密封等级、旁路卡、中继室、疏散队列和route-safe认证训练这种工种。这是基础设施劳动，拥有足够权限去看懂一条被埋掉的路线。

权限撤销后，凭证不再打开安全门。训练不会消失。排水指令、clamp等级、被封住的人工计数字段，或经过清洗的hold措辞，仍会读作曾经被信任的工作。所以淹没的机器会变成证据，而不是背景：操作员能看出安全流程在哪里被弯折，直到遗弃看起来像已经完成。

记录把背景收窄。没有指挥权。没有干净供认。没有英雄乘客身份。只有一名前Deep Reach系统工，能读懂那台把人从名单里归档出去的机器。
