# 种子船制动架构

Seed ships不是像探索巡洋舰那样抵达。它们是围绕减速质量、护盾损耗、自动建造和多年冷阶段规划的工业载荷。Aegir先有硬件，后有稳定人类社区，因为机器比人更能承受制动预算。
