# 真因知情层级

真因知情层级定义了 Deep Reach 的罪责形状，同时不把公司里的每个人都压平成同一种怪物。没有一个办公室掌握整场灾难。现场观察员看见异常潮汐行为和传感余量崩塌。风险办公室把它翻译成可接受的尾部暴露。Atlas Safety 保护连续性分数。撤离法律顾问延迟放行权限。Keelmark 和回收部门准备索赔语言，把死亡、货物和沉默转成可管理损失。每一层都可以说自己不知道足以单独阻止灾难的全部信息。合在一起，他们知道的已经足够让 HECTON-8 缓慢而合法地下沉。
