# Mute 外侧死 beacon 角色

Mute 是 Aegir 阶梯外侧的死 beacon 卫星。它的 relay 不可靠、冰冷，并且部分缺失于当前公开地图。它们仍出现在旧 solver、保险条款和 recovery 表里。这让 HECTON-8 的通信显得稀少而丑陋，不是魔法。消息可能因物理、坏数据，或把二者伪装成同一件事的保管规则而延迟。

## Scanner

死 beacon ping。Mute 不再干净回答，但旧 route solver 仍在花费它的幽灵。

## Terminal

BEACON 记录 H9 MUTE：归档星历与当前 relay 回波不一致。救援 solver 标记可用歧义。合同台授权延迟消息保管，直到窗口确认。

## Audio

如果账单知道在哪里找到它，死 beacon 仍是 beacon。

## Field Note

死基础设施不会离开 Aegir。它会变成某人可收费的误差项。
