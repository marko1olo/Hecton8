# 2190 域标记

域标记是小小的法律伤痕，让 HECTON-8 显得遥远，却不是原始。一个支架上可能同时有 Sol Core 的安全语法、Centauri 宪章短语、Barnard Yards 的维修痕、Luyten 托管哈希和 Aegir 本地索赔代码。它们不是装饰。每个标记都说明谁认证了零件，谁维修过它，谁能证明数据包，谁承保损失，以及房间进水后谁会争夺打捞权。

关键不是域名清单，而是它们如何叠在疲惫的金属上。Sol 可以认证自己无法拯救的物体。Barnard 把死索赔工作变成常态。Luyten 保留托管链，却不关心仁慈。Aegir 在别人的文件下面执行肮脏的本地法。Marauder 读懂这些标记时，海洋就不再空。人类的权力比人类的温度先抵达。
