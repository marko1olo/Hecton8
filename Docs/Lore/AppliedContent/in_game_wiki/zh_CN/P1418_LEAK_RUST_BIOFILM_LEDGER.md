# 渗漏、锈蚀与生物膜时间账本

HECTON-8的渗漏痕不是装饰性污垢，而是分层时钟。锈、盐、生物膜、油和密封流痕不会以同一速度、同一原因出现。把它们一起读，墙面就不再是背景，而是一次失败的记录。

螺栓下的锈说明水在那里停留了足够久。绿褐色生物膜说明有缓慢供养：温热设备、废液痕迹、冷却液残留，或穿过有机填料的渗流。白色盐花说明水迁移、干燥或随压力周期呼吸。盐上有油，机器漏油更晚；油上有盐，水更晚到来。

对拾荒者来说，顺序很重要。只有一道暴力刮痕的房间危险但简单。拥有多层渗漏的房间在开始失败后仍活了一段时间。有人继续抽水、擦拭、循环气闸或把电力送过已经输给海的地方。这些层能指向隐藏服务路线、后期维修、撤离后的移动，或官方报告把几周压成一句话的证据。

## Scanner

渗漏痕 // 螺栓排下方的锈、绿褐色生物膜、密封唇边的白色盐花。油水污迹跨过矿物边缘：这不是一次撞击，而是第一次进水后仍在循环渗漏。

## Terminal

渗漏时间线 // 按层读取。锈出现在金属长期潮湿且仍有氧气的地方。生物膜跟随缓慢营养流。盐花标记蒸发或压力呼吸。干净油漆下方有黑色密封流痕，说明密封先死，面板后撕裂。
