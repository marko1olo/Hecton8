# 透光生物膜基线

透光生物膜是第一种既能帮玩家呼吸、又会惩罚粗暴采集的浅层生命。它生长在光、矿物流和缓水交汇处，用富氧颜色给岩石覆皮。健康中心柔软明亮；盐化硬边意味着压力化学或旧基础设施正在压迫这个水囊。生物膜也会改变声音：良好生长会钝化小撞击，而受污染接缝会在刮刀下发出咔哒和嘶泡声。需要纤维或氧气化学时，只切松散边缘。若在舱口、管道或密封面板旁撕开明亮中心，本地氧气会下降，并暴露出生物膜一直压住的东西。

## Scanner

透光生物膜 // 覆在浅层岩石上的矿物供养活膜。明亮条带给水增氧；盐化硬边标出受压化学和隐藏接缝漏点。

## Terminal

生态基线：记录氧气皮层、矿物流、声学阻尼和盐边压力。只采松散边缘。在接缝或密封设备附近撕开生物膜，会让氧气囊塌成污染。
