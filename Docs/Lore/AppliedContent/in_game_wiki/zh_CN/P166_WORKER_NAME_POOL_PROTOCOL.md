# 工人姓名池记录

HECTON-8 里的工人姓名是一条很短的证据链。它告诉玩家哪个域把这具身体送进海里，哪份工作让这具身体继续有用，这个人合法进入过哪条路线，以及后来哪块工牌碎片留在储物柜、名单夹或班次板上。

姓名池让重复游玩时的殖民地仍像有人住过，同时不改写正史。泵房技师在一个 seed 里可能出现在密封垫账本旁，在另一个 seed 里可能出现在 medlock 拒绝单旁，但 Great Tide、Deep Reach 的责任和空间站地理都不变。变化的是发现顺序，不是罪行。

好名字必须落地。它不是笑话、收藏卡或廉价情绪钩子。它应该像一个还在等工资、压力补贴、餐券和下一班的人。当 Marauder 在拿走下面的工具前先读名字时，房间会短暂地不再是容器，而是一处工作场所。

## Scanner

姓名条 // 来源域、路线许可、班次职责和破损工牌指向同一名工人。把储物柜当废料拆走之前，先读名字。

## Terminal

姓名池协议 // 工人身份由稳定个人名、域来源带、压力岗位、班次字母、工牌碎片和路线许可组成。系统可以按 seed 改变顺序和配对，但不能把人变成随机战利品标签。个人名按语言预制；岗位、路线和权限词汇承载机制含义。

## Audio

名字是殖民地第一个想拆成零件的东西。

## Field Note

名字不是点缀。名字说明空间站开始撒谎时，谁被允许进入那个潮湿舱室。
