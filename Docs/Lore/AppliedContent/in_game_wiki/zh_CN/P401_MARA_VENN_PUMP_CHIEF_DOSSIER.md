# 玛拉·文，泵房主管

玛拉·文是泵房主管，在进水表开始撒谎后仍让下层附属区活了下来。她的档案由工作物件组成：被盐蚀的徽章、手工刻点的节拍板、用压力墨水修正的用水账本，以及因反复使用而磨光的旁通手柄。它们共同说明，有个工人迫使殖民地承认水损不是背景噪声。那是能被计算的机器故障，连在人类肺上。

## Scanner

档案：玛拉·文。徽章边缘、节拍板和修正过的用水账本都指向P-63泵房。

## Terminal

P-63泵房 / VENN, MARA：旁通手柄被隔着手套层磨亮；节拍板钉在进水损失标记旁。账本修正把失踪的水从背景漏水改写成机器负载。

## Audio

文没有留下告别词。她在泵板上留下节拍，让害怕的人能数到下一口气。

## Field Note

把文的证据放在泵节拍谜题、用水账本和旁通手柄附近。她的物件应让玩家把基础设施听成呼吸。
