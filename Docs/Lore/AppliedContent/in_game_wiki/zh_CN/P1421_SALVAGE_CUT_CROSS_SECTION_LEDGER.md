# 打捞切割断面账

打捞切口是留在材料里的争论。没人为了好看去切压力船壳。切开它，是因为路线被堵、墙后有人、线缆必须被拿走，或地图不再对应金属之后，某个舱室仍然有价值。

层次很重要。油漆告诉原来的外侧。深色金属芯告诉承力路径。陶瓷绝热层说明切割热量是否受控。橡胶密封切片说明密封件是被切开还是被撕开。线束说明当时是保护信号、收割铜，还是故意切断一个系统。断面里的盐说明开口在封闭前湿了很久。

对拾荒者来说，问题不只是能不能拿走。问题是谁切的、什么时候切的、他们在试图不失去什么。干净的官方救援切口和饥饿的黑龙骨切口不会留下同一种边。一个制造门，另一个制造不在场证明。

## Scanner

切割边 // 涂漆船壳、深色金属芯、陶瓷绝热层、橡胶密封切片、线束、烧灼切割线、撕裂处的盐。这个切口不是随机的：热从外面进入，中途停了两次。

## Terminal

断面读取 // 平滑热珠表示受控切割。撕裂陶瓷表示恐慌或工具抖动。金属芯里的盐说明回收前开口曾长期湿着。干净线头表示淹水后切断；绿黑胶泥表示切前已有泄漏。

## Audio

切割边会告诉你故障后谁来了，以及他们愿意毁掉什么。

## Field Note

先看陶瓷粉，再看金属。恐慌总是先震碎软层。
