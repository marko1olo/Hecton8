# 岸掠鱼

它不下八米，所以它不在的地方比它在的地方更有用。

鱼群沿水面拉成一条不断的线，吃涌浪聚起来的东西。线在某处断掉、四十米之后重新开始，断口里的水就是发绿的、被吃空的。没有一条岸掠鱼会进去，正在取水的潜水员也不必进去。

任何闪动的东西都会被撞击，靠近水面举灯会把整条线拉到你的面罩上两秒。挂满吊索的时候，这两秒足够让你丢掉水平线。

起风前大约四十秒它们散队，比Class-IV的气压计更早。Annex那块船体板松脱的那个早上，水面是平的，线也散了。

评估：沿线走，线终止的断口按封闭水域处理。
