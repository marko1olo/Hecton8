# 灯漂 bloom

灯漂 bloom 是光照大陆架上的浮游物能见度事件。它会在灯光发现之前，画出水流线、悬浮碎屑、缆线弧线和带齿的小型危险。因此 bloom 对导航有用，但它不是令人安心的照明。受扰动的细胞会脉冲，并把振动传入食物网；切割器、泵、pinger 或粗暴推进器会在玩家身后留下明亮的声学痕迹。光还会压平对比度，把小刺和破裂的贝壳夹藏进过度美丽的水里。把 bloom 当作路线决策：需要轮廓时顺着它漂，必须安静时横切过去，不想招来同伴时不要在正中间大声作业。

## Scanner

灯漂 bloom // 生物发光浮游物把水流分成光带。它勾出安全水域和小型危险，但工具噪声会把 bloom 变成发光尾迹。

## Terminal

能见度事件：bloom 改善轮廓读取和水流追踪，但降低隐蔽。切割器、泵、pinger、推进器或船壳撞击造成的扰动，可能让滤食者、啃食者和浅水捕食者沿发光尾迹聚拢。

## Audio

漂亮的水也还是水。它会带走你的噪声。

## Field Note

这里的光不是安慰。在 bloom 水体里，切割器脉冲、泵的咳声和 pinger 回波都比你的灯传得更远。
