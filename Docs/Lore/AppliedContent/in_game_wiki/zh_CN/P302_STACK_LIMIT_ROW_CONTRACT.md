# 堆叠限制数据边界

堆叠限制数据边界让背包保持物理性。只有当容器、压力等级、质量和污染状态能在同一路线中存活且不欺骗存档时，物品才可以堆叠。

## Scanner

堆叠行拒绝图标堆：容器类别、压力等级、污染和质量决定数量。

## Terminal

STACK CONTRACT：堆叠数量需要容器类型、压力等级、污染阶段、质量类别、警告层级和 save-stable identity。箱子不是压力容器。
