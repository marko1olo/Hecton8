# 手动舱底泵套件

手动舱底泵是投放后第一个真正有用的工具，因为它能在投放舱电气系统不安全时工作。它只能清理小型积水空间，却会迫使玩家观察进水、出水和阀门阻力，而不是相信一盏绿灯。这个套件教会HECTON-8开局规则：修理从水、压力和双手开始。

## Scanner

检测到手动舱底泵套件。进水滤网被投放舱泡沫堵塞；给面板通电前先清理。

## Terminal

P-63 现场发放 / 舱底泵套件：手动泵、软管夹、进水滤网、止回阀。任何带电面板测试前先清除积水。禁止将出水排入密封电缆槽。

## Audio

先处理水。再处理电。手柄回弹，就是房间在回应。

## Field Note

泵比仪表少撒谎。手柄回弹时，先停下，查清水被推到哪里去了。
