# 静默带轨道静默图

掠夺者把这种重叠叫作静默带。它不是地图上的地点，而是四把锁同时合上的时段：Aegir用磁噪淹没频段，Kestrel切断视线，HECTON-8的矿物海洋吞掉电磁信号，Black Keel只接收带托管标签的声学数据包。

所以天空中的联系人可以存在，却完全没用。航母也许知道风暴。也许知道中继浮标答复过。甚至可能给打捞清单开出回执。那不代表有人听见了你。在上层水体以下，通信变成一个缓慢的法律物件，穿过压力、盐、浮标和合同过滤器。求救信号不是尖叫。它是一个请求被相信的数据包。

## Scanner

静默带图 // Black Keel返回窗口恶化。Aegir磁噪、Kestrel掩星、矿物海洋衰减和中继托管同时重叠。轨道能看见风暴顶层。它看不见你。

## Terminal

轨道静默通知 // 无线电死在上层水体。激光线会被喷流冰、风暴云和Ran眩光切断。声学数据包只能通过迟缓浮标和所有权过滤器上行。静默是一种条件，不是不在场的证据。

## Audio

轨道可以就在你头顶，却依旧不可抵达。锁住你的不是距离，是时机、水和托管权。

## Field Note

如果Black Keel迟迟才回复，别把那叫仁慈。只是会计找到了你的数据包。
