# 接收端制动债务账册

Nearlight航行没有让距离变得无害。它让距离变得可记账。人类船只能在恒星之间航行，是因为旧航路被分件拥有：beam arrays负责推动，pellet lanes负责供料，fusion stages负责消耗，护盾损失质量，散热器丢弃热量，magsails咬住场线，而receiver stations同意捕获航路送来的东西。

最后一个动词最难看。要捕获一具身体，接收端必须在身体抵达前接受制动债务。它必须预留热余量、隔离体积、医疗custody、法律暴露，以及停止出错时由谁付款的权利。signal packet几乎不需要这些。密封的evidence hash可以搭乘relay。货箱可以搭乘多年前写好的时刻表。破碎海洋claim里的活operator是另一种质量。

所以HECTON-8可以同时显得已连接又被抛弃。Black Keel能通过relay window听见你。broker能给你的sample定价。public ledger能记录你的distress hash曾经存在。但这些事实都不会为你的身体创造braking rights。只有signal、custody、receiver liability、隔离、天空时机、lift mass和真实hardware排到一起时，救援才可能发生。在那之前，系统并不沉默。更糟的是，它清晰可读。
