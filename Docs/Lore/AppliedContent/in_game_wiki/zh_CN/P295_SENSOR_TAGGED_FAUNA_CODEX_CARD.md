# 传感器标记动物图鉴卡

传感器标记动物是观察HECTON-8机器生态的最清晰方式之一，同时不会把海洋写成一个意志。Deep Reach曾为迁徙、耐压和污染研究给动物、shell colonies与路线物种打tag。多年后，一些tag已经埋进疤痕组织、壳窝、矿物帽或生长环。Atlas仍能听到微弱返回，并可能把移动身体当成诊断地标：压力packet、污染提示、路线occupancy、drone sweep锚点、陈旧维护见证。这不代表动物在服从。它可能因为普通原因取食、逃跑、捕猎或恐慌，而tag让它的路径对破损基础设施产生意义。不要把tag移动读成意图。除非路线代价足以承担残酷和脏数据，否则不要从活体切出tag。有用的问题不是“它想要什么？”而是“哪个系统仍然相信这道伤疤是sensor？”

## Scanner

传感器标记动物。旧Deep Reach生物金属tag嵌在伤疤、壳或生长环里。弱Atlas路线回声；动物意图未确认。

## Terminal

样本 / 传感器标记动物 / 作用: 活体遥测载体、陈旧调查地标、修复路线污染源 / 安全读取: 旧tag脉冲、疤痕组织生长、非命令移动 / 拒绝: 把行为当作服从、从活体切出tag、信任occupancy echo / 路线备注: tag可以报告动物穿过的房间，不能报告它为什么穿过。

## Audio

它没有服从Atlas。它只是带着一个Atlas仍在追问的旧问题。

## Field Note

tag是伤疤，不是缰绳。它可能报告你、错放你，或唤醒从未看见那只动物的东西。
