# 盐水阶梯

盐水阶梯形成于高密度盐水、喷口热量和缓慢盆地流叠成清晰边界的地方。对粗心驾驶员来说，它们是看不见的墙：浮力反应滞后，声呐弯折，灯光涂抹，下降可能变成滑落。对谨慎驾驶员来说，它们是路线。潜航器可以骑在一层上，刺穿另一层，藏在帘幕下，或利用热升力跨过开放水域不可能跨过的缺口。这些层还以残酷的耐心保存残骸和生物痕迹。尸体、工具箱、样本匣和旧无人机可以多年停在同一个未混合阶层中。盐水阶梯教会HECTON-8的一条核心规则：深度要与海洋结构协商，而不是只靠船壳强度征服。

## Scanner
