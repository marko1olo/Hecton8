# Carrier 窗口音频提示

Carrier 窗口音不是救援承诺。两声高提示表示 Black Keel 听到了一个数据包。第三声低音表示回收通道仍因硬件、隔离、几何或 tonne-window 分配而关闭。触碰上升硬件前，把声音当作时间戳和路线标记。

## Scanner

CARRIER WINDOW TONE // 两声高提示只表示数据包已收到。第三声低音表示回收通道关闭；移动前记录窗口。

## Terminal

BLACK KEEL 音频状态 // 两声高提示确认数据包已接收。一声低沉关闭音表示回收通道仍因上升包、隔离握手、carrier 几何或 tonne-window 分配而关闭。音频确认不会分配起吊质量。

## Audio

Black Keel 中继：数据包已接收。回收通道关闭。记录窗口。不要凭音调上升。

## Field Note

两声明亮的音是收据。难听的那一声是账单，说明你的身体仍装不进窗口。
