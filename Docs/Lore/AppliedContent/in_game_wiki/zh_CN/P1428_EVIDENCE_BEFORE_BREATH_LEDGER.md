# 证据先于呼吸账册

distress hash 可以比玩家更早离开 HECTON-8，因为证据被设计得很小。它是 checksum、custody、witness time，以及关于某物曾经存在的窄声明。它能分段穿过 relay window。它能被保存、定价、质疑和复制，而不需要任何人让它保持温暖。

人不是这种 payload。会呼吸的身体需要温度、压力、医疗、污染处理、route authority、法律 custody，以及愿意拥有这次停止的 receiver。航路可以接收你的证据，同时拒绝你的质量。在 HECTON-8 这不是矛盾。这是一个能把人按部件估价的系统的残酷。

所以第一条得到回应的 packet 不该像救援。Black Keel 可以确认 hash。broker 可以给 sample 排序。return desk 可以索取坐标、substrate 和 proof integrity，而你的空气计时仍在继续。玩家不是在让文明知道。文明已经知道。真正的工作，是让活着的身体比它产生的数据更难被忽略。

## Scanner

DISTRESS HASH 公证器 // 盐蚀 cradle，witness seal 完整。已接收：identity hash、sample hash、time window、pressure telemetry。人员未接收。生命维持另行计费。

## Terminal

RETURN ACTION QUEUE // 证据链已验证。救援措辞暂停，直到 route ownership、breathing-mass custody、隔离床位和 lift 预留被分配。不要把 acknowledgement 当成 extraction。
