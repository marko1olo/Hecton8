# Marauder 修正层

Marauder 修正层是旧企业语言失去权威的地方。Deep Reach 写 variance、custody、hold、asset、exposure。Marauder 写潜水员下一口气前需要知道的东西：CO2 先让手变慢；brine 会藏住台阶；seal tape 在弯折处失效；别信干净舱门。这些备注应该像一种文化在重建自身，由那些被系统训练过、又学会憎恨它词汇的人写成。
