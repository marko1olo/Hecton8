# 热泉锻炉地热引擎

热泉锻炉把地质和制造、生存、恐怖连在一起。它们提供陶瓷、密封件和压力玻璃需要的热压循环，但同样的循环也制造沸腾空穴、假氧读数、腐蚀云和动物迁移。

## Scanner

## Terminal

地热引擎：热泉脉冲适合陶瓷固化、压力玻璃退火和紧急上升充能预热。暴露风险：沸腾剪切、氧气传感器假阳性、腐蚀云。
