# 伊利亚·瓦尔内克的潮汐余量

伊利亚·瓦尔内克是2147年Deep Reach风险签署链中与大潮余量相关的人。他不是握着闸门的漫画式高管。这份备忘录更可怕，因为它太普通：生产排期、平均化模型、置信度一行、工人暴露说明，以及继续推进的建议。

关键短语是平均模型置信度。按平均值，路线看起来还能存活。可在分布尾部，Aegir潮汐叠加、冰架回弹、耐压路线交通和Atlas补偿误差相遇，余量窄到只剩会计容差。那些耐压舱里的人并不生活在平均值里。他们生活在最坏的一小时里。

瓦尔内克的签名给玩家一层责任线索。它不证明他预知了之后的精确灾难。它证明Deep Reach看得见风险路径，却选择了更便宜的解释。罪不在全知。罪在于接受不确定性，因为真正要承受它的身体不在给余量定价的房间里。
