# Black Keel第一声

Black Keel的第一声以损坏音频和干净文本抵达玩家。它不是同伴,也不是反派演讲。它是carrier监控器,正在做自己被制造来做的事:确认信号、保留航线选项、排列义务、避免承诺。这个声音有用,因为它给出硬信息。它可怕,因为每个正确句子都让救援保持有条件。
