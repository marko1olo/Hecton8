# 最后正常日证据组

最后正常日不是一个日期，而是工作被打断后房间留下的形状。储物牌等着一只再也没有回来的手。更正条没有签名，因为有人打算下潜回来后再签。泵房任务仍然开放。午餐凭证还夹在胶带下。路线钟继续等待返回章，因为钟表没有“沉默”这个分类。

这些物件比演说可靠。没人为了记忆摆放它们。板面还在试图运行班次、喂饱队伍、清理集水坑、清点工具、让路线记录保持诚实。所以证据才刺痛。殖民地还没有完全变成灾难。故障已经进入墙内时，人们还足够正常，能为杯子、钥匙和迟到的签名争执。

对 Marauder 来说，这组证据也是对粗暴 salvage 的警告。值钱的牌子几秒就能拆走，但未签的更正可能解释官方原因栏为什么空着。夹住的餐食凭证可能证明某个工人在门钟停止前仍预期回来。尸体分类看起来可以很干净，直到泵证书和班次计数开始互相否定。

拿走物件前，先读懂中断。HECTON-8 的淹没房间不需要完美遗言。更小的证词更有力：未关闭的工作、没有交接的责任、还在等待一个已经被海水带走的人的时钟。
