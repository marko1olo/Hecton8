# 隔离法律握手组件

隔离法律握手是最后的逃离部件，因为HECTON-8不把抵达当作纯机械事件。胶囊可以有密封环、充能托架、工作中继和正确定时，却仍抵达错误权力之下。

握手携带接收器身份、隔离状态、载荷custody等级、lien披露和公共账本延迟。Keelmark可能先接受质量和债务，再接受一个人。Recovery Compliance可以接受坐标，同时把舱门置于医疗锁下。公共账本只能在数据包经过延迟和审查后接受证据。

这个组件让最后选择变得具体。快速密钥可能把舱门打开到企业申索。Compliance密钥可能把生存变成隔离扣留。公共路线可以保护证据，同时让身体等待。发动机抬起胶囊；握手决定对接时recovered这个词是什么意思。

## Scanner

握手插座 // 接收器密钥缺失。机械可以认证发射路径；custody栈仍会决定谁有权把抵达称作recovered。

## Terminal

RECOVERY HANDSHAKE: 载入接收器密钥组、隔离状态、载荷custody等级、公共账本延迟和lien披露。无密钥发射即使上升干净，也会进入争议队列。

## Audio

发动机能把你升上去。插座决定谁能打开舱门。

## Field Note

最后一道锁不是金属，而是名字、隔离状态和账本签名。钢铁无法决定谁来回应。
