# 逃离组件调校规则

逃离组件调校规则让 HECTON-8 的终局不会变成带发射按钮的购物清单。可信的逃离路线需要零件，但每个零件都必须证明材料成本之外的东西。Relay spine 证明玩家能穿过水体和磁噪通信。Clamp rings 证明胶囊或上升物能在压力下保持形状。Guidance core 证明的是时机，而不是幻想中的目的地：它必须命中窗口，而不是许愿到轨道。Ascent charge 证明能量和风险。Legal handshake 决定谁会回应、谁拥有回收频道，以及隔离是否接受载荷。Evidence payload 改变后果：玩家可能带着货币、控诉、样本保管链或谈判筹码离开。如果缺少一个证明，结果不应该像一个灰掉的按钮。它应该像另一种结局：部分回收、羁押扣留、错误接收端、申领失败，或用沉默买来的逃离。

## Scanner

逃离组件应当要求深度和证据，而不是刷材料。离开 HECTON-8 是一条证明链，不是一件昂贵制作物。

## Terminal

逃离组件 / relay spine 证明联络 / clamp rings 证明压力评级 / guidance core 证明时机 / ascent charge 证明能量 / legal handshake 决定谁回应 / evidence payload 改变后果和保管。

## Audio

离开不是一次制作，而是一条证明链。

## Field Note

每个上升组件都需要物理理由和法律理由：联络、评级、时机、能量、接收端、载荷。缺一个不该只是锁按钮，而应该改变结局。
