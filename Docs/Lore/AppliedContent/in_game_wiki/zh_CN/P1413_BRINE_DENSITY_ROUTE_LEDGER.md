# 盐水密度航路账本

Brine Stairs 不是洞穴楼梯。它是重到会伪装成地面的水层：上方清，下面厚，边界锋利。向正下方发出的 sonar 可能像撞到地板一样返回。相信它的人会落入更重的层，失去配平，刮断缆线，或者沉到从来不是固体的白色盐壳下。

旧殖民地靠小仪器和坏记忆学会读这些台阶。侧向 ping 区分墙、台地和密度帘。压载配平说明潜服是在普通海水里，还是被盐水托着。温降标出热水从冷盐上滑过的位置。岩壁上的缆线刮痕比干净地图线更可靠，因为缆线撞到水层时不会自我安慰。

对 Marauder 来说，账本把恐惧变成流程。盐水帘能遮蔽路线、冷却过热切割器、保存撤离标签和尸体记录；也会腐蚀密封、弯曲声音，把谎言做成安全地板。进入 2800-3600 m 的 Brine Stairs 时，规则是侧向 ping、配平、等待漂移、沿刮痕穿越。

## Scanner

盐水账本 // 前方存在密度边界。声呐回波会弯到可见台地之下；压载响应延迟属正常。下降前从侧面 ping 穿帘幕。直到两次配平一致前，把发亮的地面当作流动液体。

## Terminal
