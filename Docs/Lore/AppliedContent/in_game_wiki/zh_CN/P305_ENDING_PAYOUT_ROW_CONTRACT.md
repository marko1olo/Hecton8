# 结局支付数据边界

结局支付数据边界把结局保持为取舍记录，而不是胜利分数。支付很重要，但监管、公开证据、隔离、债务，以及玩家离开后接收器的行动权同样重要。

## Scanner

结局行绑定接收器、监管、证据状态、支付和未解决后果。

## Terminal

ENDING PAYOUT CONTRACT：行需要 payload 路线、接收器、证据状态、物资支付、法律后果、隔离延迟和未解决成本。信用点不能关闭犯罪现场。
