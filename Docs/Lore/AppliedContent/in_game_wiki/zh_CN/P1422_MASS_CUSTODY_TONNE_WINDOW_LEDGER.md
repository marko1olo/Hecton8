# 质量监管吨窗账

tonne-window不是披着公制外衣的货币。它是Black Keel在身体、样本、电池、耐压套筒和证据包都想占用同一次上升burn时使用的单位。钱可以之后争。质量必须现在运。

这就是carrier即使算得诚实也显得残酷的原因。海会给你真正重要的东西：封存substrate、工人牌、黑匣子线轴、备用氧瓶、开裂的pressure glass。Keelmark把每件东西变成监管类别。Black Keel再把类别变成质量、体积、隔离风险、热、压载和接收方责任。然后账本问一个脏问题：下一个升力窗口允许谁占用？

玩家能改变答案，但不能靠对着无线电喊。认证过的上升堆消除一个拒绝点。隔离handshake消除另一个。公开证据hash让packet更难被埋掉。丢掉污染样本可能换来身体余量。保留它可能换来真相和减债，却让救援更难。tonne-window压力不是菜单税，而是让salvage选择变成物理事实的叙事规则。
