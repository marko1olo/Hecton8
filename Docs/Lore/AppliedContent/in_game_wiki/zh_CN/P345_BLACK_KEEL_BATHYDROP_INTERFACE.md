# Black Keel Bathydrop接口

第一个逃脱阻碍是工程问题。Black Keel仍在水面上方，但损坏的bathydrop接口不能只靠意图重新连接水面、轨道和时序。修理需要深度级salvage、干净密封、可用中继几何，以及载体会接受的发射窗口。

## Scanner

Bathydrop接口损坏：没有耐压部件、中继时序和干净的上升锁，水面返回链无法闭合。

## Terminal
