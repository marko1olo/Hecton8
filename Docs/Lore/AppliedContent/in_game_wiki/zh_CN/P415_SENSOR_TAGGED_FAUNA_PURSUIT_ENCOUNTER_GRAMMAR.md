# 遭遇语法：带传感器标记动物的追逐

带传感器标记动物的追逐遭遇，用来让玩家看见 Atlas 的修复逻辑，而不是把本地生物写成士兵。动物仍然是动物：饥饿、受惊、护地盘，或只是混乱。问题在标记。它埋在瘢痕组织或壳质增生里，回传微弱数据包；受损的维护逻辑可能把这些数据读成压力状态、路线占用、污染扩散，或一个正在移动的地标。如果玩家直奔避难点，标记会把这次撤退的形状带回去。如果玩家制造噪声、频繁发 ping，或把动物拖过修复走廊，网络会更快学到错误结论。正确反应不是杀掉“傀儡”。正确反应是切断反馈：换角度，关灯，用密度层或结构遮挡，让动物选择别的路，绝不能让一枚脏标记变成通往玩家安全室的最清晰地图。

## Scanner

带传感器标记动物追逐。旧生物金属标记正在回传修复网络回声。动物的移动是局部的；网络的解释不是。

## Terminal

遭遇语法 / 传感器标记追逐 / 作用：损坏的维护反馈、避难点污染风险、非反派式压力 / 安全解读：标记脉冲滞后于动作，动物会避痛，Atlas 路线回声跟随最后已知路径 / 拒绝：精神控制框架、干净的敌对AI行为、把带标记动物引向基地避难点 / 路线备注：用角度、静默和遮挡打断回声；不要教网络哪里是家。

## Audio

它跟着你，是因为某个旧东西以为“跟随”是修复步骤。

## Field Note

别把标记带回家。断开视线，断开声音，断开解释。动物不是网络。
