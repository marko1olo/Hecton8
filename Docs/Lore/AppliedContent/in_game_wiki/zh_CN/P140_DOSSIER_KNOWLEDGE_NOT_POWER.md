# 档案是知识，不是力量

如果档案携带力量，HECTON-8 就不再关于压力。海会变成已经做完的作业。正确的持久化更奇怪，也更残酷：玩家更早识别谎言，知道哪条合约该刺痛，看懂为什么干净报酬并不干净，然后仍以脆弱身体下潜进新的 seed。智慧可以存活。安全不该。

## Scanner

META RULE // 不继承氧气、船壳等级、武器、库存、路线权限或魔法捷径。档案保存警告，不保存肌肉。
