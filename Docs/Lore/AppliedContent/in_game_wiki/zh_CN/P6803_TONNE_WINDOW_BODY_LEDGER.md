# Tonne-Window Body Ledger

tonne-window body ledger 解释为什么活着的 Marauder 不会自动优先于所有 payload。Black Keel 可以听见 signal、给 body line 定价，却仍能在 proof、samples、salvage 与 quarantine 争夺同一份 lift mass 时暂停 recovery。把 ledger 当作 evidence 阅读：receiver、contamination、proof priority 与 lift allocation 对齐之前，rescue 不会成真。

## Scanner

## Terminal

KEELMARK BODY LEDGER // 4.8 tonne-window active。Body、proof core、sample canister、salvage crate 与 witness tag 共享 recovery mass pressure。
