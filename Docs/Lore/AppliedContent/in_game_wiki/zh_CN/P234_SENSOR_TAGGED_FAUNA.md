# 带传感器标签的动物群

带传感器标签的动物群让 Atlas 改变过的生命保持可信。Deep Reach 曾给动物、贝壳群体和路线物种打标签，用来监测移动、耐压和污染。多年后，那些生物金属标签已经不再是干净设备。它们嵌在生长环、贝壳窝、旧伤疤和矿物盖层中，成为身体绕过它们生存后留下的一部分。

这个区别很重要。带标签的生物不是傀儡。Atlas 可能 ping 标签，误读回波，或把它当作弱诊断地标，但指令响应不可靠，而且常常不存在。玩家应把标签读成工业历史：微弱信号、旧伤、责任链，有时也是 Deep Reach 在殖民地失败前监视位置的线索。
