# P-63 泵房工作单

P-63 泵房工作单让第一次维修像继承下来的殖民地流程，而不是教程文字。它湿透、实用，并在细节里带着恐惧。工作单要求清空 sump、修补 cold seam、等待 return pinger，并且只有在压力保持后才切开 fused latch。这个顺序教玩家 HECTON-8 工人的思维：先处理水，再密封；先听声音，再用力；最后才信任路线。缺失的主管缩写和切割行外的双重圈让这张纸像被真正用过，而不是为玩家编写。它是小物件，却浓缩了整个游戏循环：读懂房间，恢复系统，怀疑轻易的切割。

## Scanner

第一次维修读起来像殖民地习惯：先抽水，后密封，先听，再在房间停止撒谎时切割。
