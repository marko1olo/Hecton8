# 撤离扣留

撤离扣留记录是殖民地最直接的控诉。它们表明，灾难并不只是压力故障、风暴时机或恐慌。人们还在路线内部时，路线就被评估、延迟并重新分类。医疗转运等待授权。上升走廊的优先级输给了substrate保护。Atlas连续性主张高于本地救援权限。人员计数被附加到路线对象上，这让系统能在纸面上保留一条走廊，同时让里面的身体耗尽空气。扣留不需要每扇门前都有恶人。它只需要一些规则，能够把人叫作货物，把走廊叫作资产，把延迟叫作下一个审查周期前可以接受。

## Scanner

紧急转运门。压力故障期间锁爪熔合关闭；授权扣留后手轮被拆除。
