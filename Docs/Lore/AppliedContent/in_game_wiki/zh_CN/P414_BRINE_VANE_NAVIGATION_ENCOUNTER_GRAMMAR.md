# 盐水叶片导航遭遇语法

盐水叶片导航遭遇教玩家：中深层水域是被建成的，不是空的。玩家应像读损坏楼梯一样读叶片场：完整膜片是墙，撕裂口是可能开口，卷曲尖端是减弱的剪切，没有可见叶片边缘的黑色缺口是sonar会发明地面的地方。遭遇应要求缓慢移动、保守浮力配平和改变角度，而不是直冲最漂亮的亮光。Atlas可能利用同一密度边界进行repair routing，但水流仍然是物理过程。这个区别很重要。海洋没有说话。它只是让过程可见。好的叶片路线让玩家沿一个边缘走，从第二个角度ping，测试漂移，并因为拒绝开放捷径而感到聪明。

## Scanner

盐水叶片场。对齐膜片标记密度转弯；卷曲尖端标记弱窗口；开放亮光附近sonar扭曲。保持一个边缘在视野内。

## Terminal

遭遇语法 / 盐水叶片导航 / 作用: 中深层路线读写、密度墙扶手、假地面校正 / 安全读取: 完整叶片边缘、撕裂口、sonar弯折与浮力漂移一致 / 拒绝: 横穿黑色开放水域、切割引导膜、信任没有叶片边界的地面回波 / 路线备注: 叶片不是有意引导你；它只是足够明显地服从水，值得跟随。

## Audio

叶片不是路牌。是水正在造墙，并留下了一道缝。

## Field Note

把叶片边缘当扶手。线条弯得不对时，你的浮力读数已经晚了。
