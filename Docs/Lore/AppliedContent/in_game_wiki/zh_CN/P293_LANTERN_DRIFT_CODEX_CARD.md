# 灯漂图鉴卡

灯漂bloom是浅架最美的警告系统。安静水域里，发光细胞会在灯照到之前勾出水流、悬浮砂屑、缆线环、pressure glass碎片、破裂的shell clamp和小型齿状危险。这让它在路线视觉杂乱、玩家需要从礁体垃圾里读出清晰轮廓时很有用。但它也会让玩家变得可读。cutter振动、咳嗽的泵、反复pinger、船体撞击或慌乱thruster都可能把bloom搅成发光尾迹，把你的位置传进食物网。风暴充电还会带来另一层问题：假走廊、过亮残留，以及把小损伤藏进漂亮光里的平坦对比。只有当水流、残留和动物反应一致时才跟随光。若要在bloom里大声作业，就把“被找到”也算进计划。

## Scanner

灯漂bloom。生物发光浮游体用带状光标出水流和碎屑。适合读轮廓；当工具噪声把它变成发光尾迹时就危险。
