# 热泉管虫

它只长在热流体离开底面的地方，而那里正是廉价氧电池唯一会往上读的地方。

喷口化学给电池加了负荷。在群落场内，Class-IV的储备表会平滑地上升四到九个百分点，而水在同时变差。照那个数字补气，你上浮时就是不够。

群落只给一次警告。整片一起缩回管里的时候，它已经检测到一个流量变化，那个变化会在两三秒后到你这里。

产出：坐在长度超过一米的管基部的微节点。撬出来一个，管子就会在4,830米、接近60 C的条件下把内容物排到你手上。

从相距1,100米的两片群落中回收的节点，带着同一个钢印零件号。评估：在群落场内，把上升的氧气数值当作故障，并用第二块氧电池确认。

## Scanner

与喷口相关的密集管状群落。置信度66%。溶解氧21%，仍在上升。危险：热接触。限制：氧电池未按硫化物干扰定级。

## Terminal

样品批次 44-T-4830。深度 4,830 M。类别：传感器宿主，可用。回收：仅节点，宿主不需要。大气记录 22-B：校准漂移，条目已压制。归档：回收合规办公室。

## Field Note

“校准漂移”是窗口给在喷口水里往上爬的仪表起的名字，意思是把警告删掉，而不是把手册改对。每片群落都带第二块氧电池进去，信读数低的那块。
