# 压力阶梯

压力阶梯是 HECTON-8 深度推进背后的路线逻辑，不是关卡名称列表。每进入更深的区段，同一个实际问题都会变得更严苛：潜服密封、电池、氧气回路、绝缘、信号和回程 ping，能不能同时撑过下一次下潜？

第一段陆架允许受损装备短时作业，因为回程线还找得到。服务陆架开始在每个深度闸检查潜服等级和电池锁扣。盐水峡谷需要绝缘和浮力配平，因为盐、热和密度变化会在下潜中把好读数变坏。深渊机器场要求强化信号和严格的壳体操作；延迟的 ping 可能说明路线已经落在身后。Atlas 盆地则把总线噪声和失压加入同一条链。

把闸门当成许可前，先读维护板。只要一个读数为红，下一次下潜就不是英勇，而是错误流程。先修最弱的密封、模块、回路、包覆层或继电器。

## Scanner

深度闸读数 // 区段：250-1200 m 服务下潜。密封余量 11%。电池组 B2 锁定后，潜服铭牌才接受 Grade C。第三个夹环以下回程 ping 变弱。不要靠胆量打开下层闸。
