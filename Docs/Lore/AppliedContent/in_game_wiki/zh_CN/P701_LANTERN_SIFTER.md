# 灯笼滤食者

对滤食者群落打一次声，回波会回来两次。

第一个回波是墙。第二个晚五分之一秒到，偏离方位，而且比距离所能解释的更响。每一只的鳃篮里都带着一颗硬粒，米粒大小的微量级玻璃，滤食动物完全不需要它。Atlas把一套中继网养进了动物体内，从来不必维护。

偏掉的方位指向下一个群落。顺着这条链走下去，尽头是仍然带载的电缆，这一趟值得。但第一次发声也把你的位置交给了那条路线上的一切，而那条路线要经过强制通风的排气口。

从31号舱出去的一条链指进实心岩体。

评估：只打一次；跟第二个方位之前，先过掉前方的排气口。

## Scanner

群体滤食种。鳃篮内有高密度非生物包体。置信度47%。危险：无直接危险。限制：仪器无法把动物与安装硬件分开。

## Terminal

标本 44-D-402。库存项：声学中继器，培育。地点：电缆走线12，2,120 M。数量：估计41,000。维护间隔：无，单元自行替换。来源：总控维护路由，未核实。

## Audio

——又回来两次了，科兰，第二个在我左舷后方，而我左舷后方什么都没有，整个方位我都看得见。不。我不去追。我记录下来，坐着不动。你那边回来几次？科兰说三次。

## Field Note

四万一千个单元，没有维护间隔，因为有人把活的动物填成了安装硬件，把省下来的钱拿走了。对你来说的意思是：你的声音传得比你的灯远。
