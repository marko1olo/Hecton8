# 宽幅滤食体痕迹

宽幅滤食体首先证明，地标之间的开放深渊并不空。它们像缓慢的浮游云收割机一样穿过深水，身体比小型附属结构还宽。它并不猎杀 Marauder；它改变 Marauder 周围的地图。它经过后，悬浮生命变稀，声呐回波沿着身体边缘被抹开，被掩埋的工业轮廓会在淤泥重新合拢前显露几分钟。

因此，这种生物既是危险，也是工具。它的影子可能遮住一座维护框架，也可能让一条其实充满运动组织的水域看起来像开放路线。正确做法是阅读尾流：口器后方的清水，边缘处脏污的回落，身体背后的声学安静。不要为了看清生物而游到影子下。只有在有电力、有线缆、有返回路径时，才沿着它留下的空隙前进。
