# Aegir 天空窗口机器

Aegir 的可见天空是 route machinery，不是布景。月影会破坏 relay confidence，风暴能保护 body 同时杀死 upload，干净的 carrier line 仍可能在 radiation、tide、quarantine 或 mass checks 上失败。把 sky windows 读成叠在一起的 gate：packet、body、proof 和 salvage 不一定共享同一次 pass。

## Scanner

SKY WINDOW 读数 // 肉眼晴空不等于 rescue clearance。Kestrel 阴影、storm ceiling、radiation count、tide load 和 carrier phase 彼此不一致。

## Terminal

AEGIR ROUTE PLATE // 窗口状态是部分的。packet line 可以开启，而 ascent body、quarantine 和 tonne-window mass 仍然关闭。

## Audio

Relay note：天空明亮，route 很脏。只发送 packet；等 moon tag、storm ceiling 和 mass line 同意后再考虑 ascent。

## Field Note

天空可以向 packet 打开，却对你的 body 关闭。庆祝前先检查整台机器。
