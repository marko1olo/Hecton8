# 责任备忘碎片链

责任备忘碎片链教玩家阅读 Deep Reach 证据的方式。没有一份备忘包含整场罪行；每个办公室都保留了能让自己的行为看起来像程序的一句话。风险表承认潮汐余量正在失效。撤离备注把延误写成通道纪律。Atlas 覆盖让连续性听起来比逃生更安全。Keelmark 碎片把失踪工人转换成可回收损失。玩家必须把纸面与被淹的房间、损坏的路线钟和工人姓名交叉核对。只有当碎片不再保护各自办公室，而开始互相矛盾时，这条链才真正可读。

## Scanner

责任备忘以碎片形式存活下来，因为每个办公室只保存了能保护自己的那一段。

## Terminal

FRAGMENT CHAIN：风险余量表 / 撤离放行备注 / Atlas 连续性覆盖 / Keelmark 损失转换 / 回收保管请求。接受公开摘要前，交叉核对路线时间、房间损伤和工人姓名。

## Audio

他们没有把真相藏进保险柜。他们把真相拆开归档。

## Field Note

被撕开的备忘，会在它本不想诚实的地方变得诚实。
