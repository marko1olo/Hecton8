# 颗粒尾迹制动账本

颗粒尾迹制动账本把星际航行变成玩家能拿在手里的东西：一条烧焦的烧蚀带，一块航线教材碎片，一份比坠毁更老的质量账户。最先抵达Aegir的是从Luyten Junction射出的微型颗粒束探测器。它们便宜到可以损失。重型载人货运后来才到，靠Atlas级运载船燃烧聚变电力脉冲，让船员休眠，并把每一公斤都当成债务。

残酷之处在抵达。飞船花几年把速度推向近光航渡，仍然必须把速度卸掉。磁帆咬住星际介质。气动制动掠过气态巨行星和风暴包层。余量里一个错误小数就能把货物变成等离子体。因此HECTON-8可以被人类法律拥有、计费和索引，却仍无法成为救援现场。公司能在船体穿过黑暗前继承索赔权。
