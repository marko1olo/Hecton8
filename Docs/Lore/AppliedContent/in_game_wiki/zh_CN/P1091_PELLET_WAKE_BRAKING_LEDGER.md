# 颗粒尾迹制动账本

乍看这本账像废料：一条掌长的烧焦烧蚀箔，一块裂开的航线学校板，一份比坠毁更老的质量账户。合在一起，它们把星际航渡放进Marauder手里。Aegir并不是由英雄船只撞开黑暗而打开的。它由从Luyten Junction射出的小型颗粒束侦察器测绘，那些廉价机器带着见证数据包，也不期待返航。航线先变成合法，再变成安全。

人类质量后来才到。Atlas级运载船不会跳跃。它们被推动、供给、防护和计费，持续多年。聚变电力脉冲堆把速度推向近光航渡，船员在冷眠中睡去，债权人把每一公斤都量成未来留置权。额外护盾、食物、推进剂、救援铺位、替换工具：全都有质量价格。在HECTON-8，质量价格会在任何人见到幸存者前变成blue debt。

尾迹样本记录了公开入门资料会淡化的部分。抵达是反向的艰难燃烧。磁帆拖曳带电尘埃和稀薄等离子体。颗粒流啃咬帆缘。气动制动通道把气态巨行星和风暴包层当成工具，而这些工具也能杀死飞船。过度谨慎，运载船会错过窗口。谨慎不足，货物就会变成一道亮痕。

这就是Deep Reach能比救你更快提交索赔的原因。数据包以信息形式跨过航线。债务通过合同移动。Black Keel可以给回收窗口定价，因为它已经在Aegir本地空间。来自内侧世界的救援船体仍然必须支付速度、制动、船员风险和保险质量。文明抵达HECTON-8的顺序是：先签名，再警告，最后很久以后才是机器。
