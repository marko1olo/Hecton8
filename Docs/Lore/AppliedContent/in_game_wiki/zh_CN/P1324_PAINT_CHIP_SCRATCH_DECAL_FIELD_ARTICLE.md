# 漆面剥落与划痕证据

HECTON-8 的漆面磨损不是装饰噪声。殖民地使用灰白压力涂层、深色石墨底漆和短橙色安全漆条，因为工人需要在浑水中读懂表面。当这些层破裂时，使用痕迹就会露出来。

方向最重要。锁扣周围的月牙弧表示手或工具反复运动。甲板边缘上的直线亮痕表示货物拖拽。随机星状切口可能来自坍塌碎片，但一道干净划痕若穿过旧盐，就说明浸水后有人触碰过表面。如果暴露底漆又黑又干，剥落可能很新。如果盐沉在破边内部，损伤已经在水中呼吸很久。

玩家应先读漆，再把它当材料剥走。剥落面板可能指向真正被使用的门、警报后被打开的柜子，或被擦干净以隐藏警告的表面。漆作为材料很廉价，作为上下文很昂贵。盲目拆走它，墙就会沉默。

## Scanner

漆面剥落划痕 // 灰白涂层破至石墨底漆。锁扣弧线附近有橙色安全漆碎片。盐只抛亮了下缘。磨损方向像后期工具接触，不像坍塌碎片。

## Terminal

表面磨损读取 // 扫描前不得重漆或打磨。剥落深度、底漆颜色和划痕方向，比房间日志更能保存通行、强行开启和撤离后清理的证据。
