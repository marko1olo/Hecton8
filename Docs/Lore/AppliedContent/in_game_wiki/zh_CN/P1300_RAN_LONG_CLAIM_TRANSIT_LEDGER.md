# Ran长程索赔运输账册

Ran长程索赔运输账册，是求救信号被文明听见之后，文明拒绝假装物理已经改变时形成的东西。数据包穿过航线的速度足以让它像一个回答。回答不会带来船体。它记录索赔人、位置、载荷、托管链，以及让离世界很远的某个机构愿意花费质量的理由。

            账册是旧边境法包裹在硬运输外面。Ran中继接收光速见证包。Luyten办公室给回执打哈希。Black Keel把干净突发推过镜面和载波窗口。这些系统没有一艘免费的救援船。救援艇仍需要航道、制动分配、接收槽、隔离许可，以及一个能经受审计的付款方。

            所以第一个载波窗口会让人难受。Marauder想喊自己还活着。账册已经有这个格子。更好的数据包会说明在哪里、有多确定、什么能升上去、谁碰过它、Deep Reach损坏了什么、上升包是否密封、如果没人来会失去哪份证据。身体重要。只有身体时，它在错误的栏里很便宜。

            Black Keel的残酷多半是去掉人声的算术。活人是责任。带着可采信证据的活人是杠杆。绑着不可替代航线数据的活人，是长了牙的货物。账册把恐惧变成字段，因为字段可以在信号离开HECTON-8之后被定价、被见证、被争夺。

## Scanner

长程索赔账册 // Luyten见证编链完整。可用载波窗口一个。字段：存活状态、坐标置信度、上升质量、托管等级、Deep Reach异议、载荷价值。求救不是救援艇命令。

## Terminal

BLACK KEEL / RAN长程索赔回执7C // 数据包已作为活体索赔接收，并非回收授权。请在窗口衰减前提交位置证明、打捞类别、医疗责任、隔离暴露和首返偏好。空白字段默认处理为货物负值、身体低优先级。

## Audio

Black Keel中继：你到达账册了。很好。这代表你成为记录，不代表你获救。趁载波滑脱前，把这次突发用于证据、位置或价值。
