# Ran长程索赔运输账册

被困Marauder最想相信的第一个谎言，是联系就等于救援。在Ran周围，联系只说明一个数据包找到了载波窗口。它能移动位置、见证哈希、法律要求、报价或威胁。它不能移动压力船体、医护、货运艇或制动堆。

所以Ran长程索赔账册读起来不像求救信标，而像会计。幸存者活着只是一个字段。旁边还有坐标置信度、载荷类别、托管等级、上升质量、隔离风险、路线保险，以及如果人在接走前死亡由谁收款。Black Keel移动数据包，因为数据包便宜，也因为合同权力活在延迟里。

有用的问题不是有没有人听见你。很可能有人听见了。问题是他们先听见了什么。干净的存活状态买到队列位置。已验证的路线回执买到杠杆。Deep Reach责任证据可以改变谁有权给队列定价。一个在HECTON-8之外也有价值的载荷，可能让船接受本会为单独一具身体留在海底的风险。
