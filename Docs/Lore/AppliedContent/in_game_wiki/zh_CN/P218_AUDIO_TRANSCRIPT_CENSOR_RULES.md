# 音频转写损伤带

转写损伤带是受损音频的可见伤痕。它标出记录器丢失了什么，包件公证器压下了什么，糟糕翻译没能解析什么，以及后来的操作员可能剪掉了什么。损伤带不是装饰。它告诉玩家这份转写值得多少信任。

好的受损转写在关乎生存的地方仍然可读。它可以隐藏姓名、坐标、货物编号、债务条款，或尖叫的最后一秒。它不能隐藏舱门警告、路线反转、压力变化、说话者职责，或理解证据所必需的行动。如果损伤把线索变成噪声，这条线索还没准备好。

HECTON-8把损伤带当作诚实规则。破碎音频上出现干净字幕，很可疑。完好记录器旁边有一行黑块，会让人问是谁删了它。多个日志里同一秒同时消失，可能指向自动清洗器。玩家应学会阅读缺席的形状：截断词、时间跳变、置信括号、说话者漂移、翻译伤痕和公证标记。

这也保护无障碍。叙事内损伤不应惩罚需要字幕的玩家。损伤带可以显示不确定性，但警告必须保持可读。殖民地可能死在黑暗里；界面不该如此。

## Scanner

转写损伤带 // 录音存在物理或流程缺口。删改可以隐藏姓名、货物ID或时间戳。它不能隐藏核心警告、说话者职责或路线关键动作。

## Terminal

无障碍闸口 // 受损音频可以不完整。如果剩余转写不能说明发生了什么、改变了什么、哪里不安全，就不要把它发布为线索。

## Audio

静噪可以吃掉名字。它不能吃掉警报。

## Field Note

必须的话，藏起名字。把警报留在活人能读到的地方。
