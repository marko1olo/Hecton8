# 电缆礁中继场证据套件

电缆礁中继场是一座修理场，已经长出自己的故障模式。导电膜、电缆护套和声学插座可以恢复信号，但如果操作员不扫描就切割，同一座桥也会把航路送进旧服务支路。

## Scanner

POI证据套件：中继场通过活体桥膜导通，又通过受损电缆记忆误导航路。

## Terminal

中继场套件：声学脊柱插座、生物膜桥、切割警告、信标响应、Atlas服务标记、剥落绝缘层、中继叉、死支路地图。

## Audio

## Field Note
