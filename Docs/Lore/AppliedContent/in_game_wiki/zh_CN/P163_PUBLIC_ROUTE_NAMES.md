# 公共航路名称

公共航路名称不是穿越黑暗的诗，而是能在合同、船体铭牌、中继队列和法庭展品中存活的工作标签。Sol-Centauri Charter Spine 携带合法性语言，Barnard Breaker Run 带着拆船场和债务劳工的味道。Luyten Packet Ladder 是让证据有效或作废的 custody 链，Tau Public Ledger Lane 是缓慢的公共压力。Ran Long Claim 是最靠近 HECTON-8 的肮脏边缘，说明海洋收费之前，工作已经昂贵。
