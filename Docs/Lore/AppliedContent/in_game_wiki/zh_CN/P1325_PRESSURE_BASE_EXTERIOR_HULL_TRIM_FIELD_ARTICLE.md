# 压力基地外部船壳饰条

HECTON-8压力基地的外部不是装饰外壳。它的饰条是模块的可读语法，而这些模块原本就是为了在水下维护而建造的。浅色陶瓷涂层标记耐压外皮。深色石墨肋显示载荷流向。狭窄的密封槽显示两个体积本该相接而不让海水共享的位置。下沉的面板唇通常意味着人的入口，不是装饰。

切割前先读饰条。一条不断穿过模块的长肋说明这面墙作为整体承压。干净盐痕旁的断肋说明漏水保持在局部，可能留下了口袋。被旧矿物粉填满的密封槽说明接缝曾缓慢呼吸。带有新划痕的面板唇说明有人在房间已经潮湿之后，或在官方工单结束之后打开过它。

好的trim sheet会让基地像被建造出来，而不是被画上去。它也让打捞不再盲目。玩家可以顺着肋的方向避开糟糕切口，通过重复的密封几何找到维修舱口，并读出哪些模块是为了返回而修补，哪些模块是作为证据被丢下。海水最先抹掉标签。它会留下边缘。

## Scanner

外部船壳饰条 // 浅色耐压外皮，石墨色肋带，下沉式密封槽。盐痕从维修唇下方流出，不在主板下方。这是维护过的模块边缘，不是随机残骸板。

## Terminal

船壳外皮读数 // 在标出载荷路径前不要切穿饰条。长暗色肋承担压力，浅色面板封闭体积，密封槽标记模块接缝，维修唇常藏着最后的手动入口。
