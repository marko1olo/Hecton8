# 洞口伏击者

它不捕猎。它租一个洞，等走廊把东西送来。

被占用的凹口先显得不对，才显得危险。在淹没的翼区里，每一个空着的口沿都有一圈松软的淤泥。被占用的那个是擦干净的，因为动物已经进出过几百次。读口沿，别读黑暗。

它出手时先把水从凹口里推出来。在Class-IV上，这会在接触前约0.5秒变成胸板上的一次压力轻击。相信这一击的潜水员活下来。盯着自己灯锥的潜水员活不下来。

它偏好切割开口，不偏好天然开口。这个偏好没人解释过。评估：从上方、从它喉口的外侧接近干净的口沿，或者干脆绕开整个翼区。

## Scanner

大型伏击摄食种，占据切割开口。置信度71%。危险：打击距离超过可见体长。限制：没有第二个角度无法判定个体尺寸。

## Terminal

标本 44-B-207。类别：出入管制资产，附带。位置：东侧下层检修喉道。备注：翼区封闭在未进行计划闸门维修的情况下维持。复审：不需要。

## Field Note

公司把它记成出入管制，因为它把人挡在东翼区外面比一扇能用的门更便宜。它也把霍利斯挡在了外面。伸手之前，先做口沿擦拭检查。
