# 实物付款记录

实物付款记录是付费结局的收据。Keelmark/Recovery Compliance接受盆地坐标、蓝债样本和运输方托管哈希，然后降低或关闭操作员留置债务。同一张收据把见证材料、工人姓名和救援质量审计留在公证托管之外，给Deep Reach一条比被埋班组更干净的HECTON-8返回路。
