# 最终问题：出售犯罪现场

出售犯罪现场是物质成功轴。Keelmark/Recovery Compliance承认坐标、样本价值、XO证明和运输方托管哈希，因此操作员可以活下来、结清债务并带钱离开。缺失附件很关键：没有单独见证包，工人姓名、救援质量核算和Deep Reach责任就留在付费收据之外。

## Scanner

犯罪现场出售轴 // Keelmark可以用Atlas盆地坐标、蓝债样本、XO见证证明和运输方托管哈希结清留置债务。工人证据除非另行公证，否则不会进入收据。

## Terminal

最终轴 / 出售犯罪现场
接收方：Keelmark/Recovery Compliance。
已接受：Atlas盆地坐标、可用蓝债样本、XO见证证明、运输方托管哈希。
留置影响：按合同表关闭或降低操作员债务。
默认遗漏：工人姓名账本、救援质量审计、公共见证包。
Deep Reach优势：接近几何和样本估值在没有敌对托管链的情况下到达。
已知损失：墓地图可能先成为财产，后成为证词。

## Audio

你可以卖掉墓地图。收据仍会把它叫作工作。

## Field Note

这是带收据的付费出口。危险的是空白行：没有附上工人姓名账本。
