# 路线板与返回戳现场文章

压力殖民地不能靠记忆运转。每一扇有用的门旁边，最终都会长出一块板：目的地、舱门编号、窗口、工具标签、空气估算、脉冲器频道、返回戳。它看起来很普通，直到玩家明白：这是房间计算自己外壳之外人员的方式。

路线板不是 Deep Reach 发明的。它是班组发明的，因为潮湿走廊会吞掉口头承诺。公司把它变成责任语言，于是它有了毒。失踪的人变成延误。延误变成扣留。扣留变成未清。只要能在下一个窗口前改掉栏目，失败就变成排程，而不是死亡。

痕迹比印刷标题更重要。盐层上的油笔说明有人戴着手套改写真相。干掉的印台说明房间已经无法支持返回，却仍在等待返回。没有姓名的工具标签说明装备经由另一只手回来了。被移到干净栏目的名字可能比划掉的名字更糟，因为有人需要让那块板看起来仍被管理。

对 Marauder 来说，路线板既是导航仪，也是控诉。它能说明哪扇舱门最后打开，哪条服务脊仍有脉冲覆盖，哪里可能藏有补给，为什么一条走廊像有人生活过，而不是被布置出来。它也告诉玩家：当普通工人仍在解决实际问题时，公司已经开始编辑记录。

返回戳很小、难看、而且有人味。它说明一个人穿过压力返回，交还工具，让房间在下一行里重新完整。在 HECTON-8，最吓人的板不是沾满血或口号的板。最吓人的是那些最后一天仍像一个期待明天的班次的板。
