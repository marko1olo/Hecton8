# 氙营养修复生态野外指南

当HECTON-8生物被当成布景时，它就变得危险。同一股喷口羽流可以喂养铁藻，生长富氙晶格，加热盐水台阶，掩护捕食者，并为Atlas修复脉冲供能。扫描器标出的资源、植物或动物，只是第一猜测。

Blue Debt由过程形成，不由地点决定。热量抬升矿物。盐分整理密度。微生物爆发改写晶格。牧食者修剪边缘。生物膜传导微弱电流。Atlas学习哪些表面能封闭、导电或重复声音。当掠夺者切下样本时，可能同时从同一个活接缝中拿走燃料、食物网、路线标记和证据。

## Scanner

氙营养痕迹 // 喷口热、硫化盐、盲眼牧食者、导电生物膜和Atlas修复脉冲共享同一梯度。值钱的蓝色生长从来不是干净矿石；它是带账簿标签的活过程。

## Terminal

生物资源现场通知 // 在观察路线行为之前，不要把HECTON-8生命归类为植物、动物或污染。如果样本导电、滤声、封住裂缝或吸引带标签动物，就把它当作生态和基础设施。

## Audio

如果它靠喷口进食，长过电缆，还回应修复 ping，就别再问它是活物还是工具。问是谁在使用它。

## Field Note

Blue Debt不是躺在泥里。它正在被制造、吃掉、封存、采走并改名。
