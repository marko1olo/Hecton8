# 隔离舱位 custody 账册

隔离舱位不是温情意义上的床。它是一间法律房间，拥有空气、过滤器、废物处理、医疗闸锁、custody 摄像头、证据链封条，以及 liability 栏里的名字。当幸存者离开一个封闭海洋 claim 时，接收方首先接收的不是被拯救的人，而是一个可能受伤、感染、污染、负债、具有法律危险，并仍携带某些势力想埋掉的证据的生物对象。

这就是为什么 Black Keel 的第一个清晰回应会让人难受。中继可以确认 distress hash。Luyten 可以保存 packet custody。经纪人可以在玩家看见天空之前给样本定价。但这些收据都不会预留舱位。活体身体不只是比数据包更重；它会改变责任归属。谁和它呼吸同一份空气？谁治疗减压伤？谁阻止 Deep Reach 把幸存者归类为 claim property？如果舱位被锁一个月，谁付款？

老航路工人把这种账册叫作带有收费栏的仁慈。这既不公平，也很准确。早期救援把污染当成道德细节，结果杀死了空间站，所以舱位必须存在。但企业也在这里学会了拖延帮助，直到语言对自己有利。对玩家来说，这本账册是一种可读压力：舱位栏空着，救援措辞就是表演；custodian 和 liability 字段填上，说明有人已经开始把真实能源花在生存上，而不是花在纸面上。

## Scanner

隔离舱位收据 // 陶瓷 custody 卡，一角被热弯曲。字段：身体质量、压力暴露、病原 hold、医疗负责人、接收舱位、lift exception。数据包已接受。人员待定。

## Terminal

RETURN CUSTODY HOLD // 证据包已确认。活体质量转移暂停，直到隔离舱位、医疗 custodian、接收方 liability 和上升升力被分配。不得把确认转换为撤离命令。
