# 静默轨道收据账本

静默轨道收据账本是Black Keel给Marauder的第一件诚实物：确认收到，但不提供帮助。上层海洋以下，无线电死亡。激光和微波会散射或消失。在深处，承包人只能用缓慢的声学脉冲说话，携带文本、哈希、压力警告和可计费质量记录。Black Keel回复这些数据包，是因为合同托管需要收据，不是因为有人拿着救援板在听。

Kestrel、风暴窗口和HECTON-8的矿物海洋，会在轨道放晴前把信息变成过期证据。收据只能证明运载平台听见了足够内容，可以给这趟活定价。它不能证明撤离、怜悯或实时指令。因此第一次真正回复比沉默更冷：系统能先数清你，然后才可能救你。
