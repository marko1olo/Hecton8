# 断联窗口信号衰减

信号衰减让通信稀缺拥有物理形状。玩家得到的是稀有窗口、截断的数据包碎片和水下声学后备，而不是来自轨道的持续引导。

## Scanner

通信窗口正在塌缩：浸水中继脊柱、Aegir 阴影、过期载舰几何，法务队列仍在重试。

## Terminal

BLACKOUT WINDOW：上行链路损耗超过容限。语音频道暂停。文本碎片可能通过修复后的声学脊柱节点抵达。轨道载舰几何将在 Aegir 磁影清除后刷新。自动留置和监管计时器在没有操作员接触的情况下继续运行。

## Audio

天空先安静下来。债务通知还在敲门。

## Field Note

把 blackout window 绑定到路线节奏：更少语音、更多碎片阅读，让修复中继和本地信标更有价值。
