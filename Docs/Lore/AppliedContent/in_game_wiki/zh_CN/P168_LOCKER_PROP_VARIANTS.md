# 储物柜证据变体

HECTON-8 的储物柜不该是一堆煽情杂物。它是一个小型压力舱档案：工人摸过什么，被允许携带什么，向班组长藏了什么，以及后来某个 Marauder 认为哪里需要修正。

有效的储物柜靠组合说话。手套旁的压力胶带指向漏水作业。个人工具里的磨损密封圈说明这个人经常处理舱门，已经不再相信备用件。餐食额度条和路线粉笔放在一起，说明他还以为会有下一班。medlock 拒绝单会把房间从背景变成证据：身体已经成了成本问题，人却仍被要求继续排班。

在玩法上，储物柜是可种子的人的痕迹。内容可以随周目变化，而不改变大设定。稳定规则是先读后拿。如果玩家把代币、密封圈和便条当普通废料拿走，房间就失去那套让工人在无过场动画中出现的语法。
