# 玻璃啃食者图鉴卡

玻璃啃食者不是宠物，不是掉落物，也不是装饰。它们是小型透明带壳取食者，从pressure glass、松散透光垫层边缘、旧缆线护套和石灰岩边唇上刮走矿物膜，让透光浅架变得可读。正在取食的群会在生长层里留下浅色通道。这些通道能显示最近水流、干净抓点、没有过热的接缝，或者几分钟内捕食者没有穿过的区域。有用的线索不只是移动，而是中断。食物还在、壳声却停止时，群可能听到了压力变化、影子移动、cutter振动，或scanner锥外经过的大型动物。刮出的通道是证据，不是许可。沿边走。边缘向内收起时就离开。

## Scanner

玻璃啃食者群。非敌对的带壳取食者，刮食矿物膜。稳定咔嗒声表示水域仍在工作；突然安静表示有更大的东西改变了空场。

## Terminal

样本 / 玻璃啃食者群 / 作用: 浅层膜刮食者、水流见证、捕食者位移线索 / 安全读取: 取食边缘、新鲜浅色刮痕道、稳定壳音 / 拒绝: 食物仍在的废弃取食区、紧缩静止的群、pinger后没有回音 / 路线备注: 取食后的缺席就是危险数据。

## Audio

小嘴停止咔嗒而食物还在时，不要成为下一个留下来等待的东西。

## Field Note

取食群：读通道。静止群：读水。食物还在的空通道：离开。
