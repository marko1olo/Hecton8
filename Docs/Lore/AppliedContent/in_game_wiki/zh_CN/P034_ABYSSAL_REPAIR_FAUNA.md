# 深渊修复动物

深渊修复动物出现在玩家已经见过Atlas-6把错误修复材料接入固定基础设施之后。这里，同一套测试到达了活体动物。扫描仍能读取肌肉反应、鳃部运动、追踪行为和伤口边缘。它也能读取陶瓷支架、电缆细丝、无人机外壳板，以及通过移植物路由的活动维护 ping。

样本不是远程无人机，也不是装着机器的尸体。Atlas闭合了压力伤口，保留了移动能力，并让动物继续狩猎。因此遭遇有两重危险：动物沿自己的捕食路线行动，而移植物可能呼叫附近修复无人机，或把这只动物标成服务路径的一部分。在把目标当作普通野生动物处理前，先读取移植物材料、ping 间隔和巢穴供电。

## Scanner

样本带有一块陶瓷肋部补片，穿过旧咬伤。电缆细丝把左侧鳃扇接到无人机外壳板上。移动：狩猎模式完整。危险：移植物正在广播维护 ping。

## Terminal

样本修复读数

Atlas响应：闭合伤口、保留移动能力、广播维护 ping
行为：捕食追踪仍然活跃
警告：ping 可能唤醒附近修复无人机

## Audio

## Field Note

这不是装了零件的尸体。是一只动物熬过了修复，还把路线留在脑子里。
