# 工厂神殿阈限

工厂神殿阈限是海底工厂之后的最终下部闸门组件。这不是神话式融合，而是仍在工作的载荷分担：Deep Reach桁架承受旧船壳应力，回流管仍移动盐水和热量，碳酸盐生长封住失效垫圈，Atlas-6通过仍会响应的触点维持连续性。玩家要读夹具顺序、流痕、电缆总线噪声和标签位置。

## Scanner

下部闸门读数：工厂桁架、回流管、压力密封和Atlas路由总线共同承载。墙和门之间已经没有干净边界。
