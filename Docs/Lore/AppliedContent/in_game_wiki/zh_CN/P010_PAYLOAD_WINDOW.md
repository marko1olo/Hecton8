# 载荷窗口

载荷窗口是最终选择变成物理问题的地方。玩家只能把有限质量带过压力、风暴遮蔽、埃吉尔辐射时序和Black Keel回收几何。金钱、证据、工人姓名、坐标、活体样本、Atlas信号或沉默，不可能全部一起离开。

## Scanner

临时上升包。如果质量、天气、剂量时序和Black Keel几何一致，它就能离开海洋。

## Terminal

PAYLOAD SLOT：有限。WINDOW：开启。ROUTE：争议中。RECEIVER：未确认。CLAIM VALUE：可变。EVIDENCE STATE：不足以进行干净争端。

## Audio
