# 暗影拦截者

它不跟着你走。它到你原本要去的地方等你。

在开阔横渡上，接触保持一个大方位，跟上你的速度但不跟你的航向，然后从显示上消失。那段空白就是攻击。它不再返回声音，是因为它此刻已在你的方位线上，而读着图的潜水员看到一块空屏，就放松了。

加速没用。你的速度它已经解出来了。有用的是换目的地，因为那个解是照着旧目的地算的。

D班的三个服装信标在一段没有任何结构可掩护的开阔横渡上停止，彼此相距不到四十米。回收队列登记了坐标，然后把条目关掉。

评估：横渡中接触消失时，改你要去的地方，不是改你多快到。

## Scanner

接触间断。置信度下降中。危险：向推算位置合拢，不是向当前位置。限制：接触丢失并不表示它已离开。

## Terminal

标本现场编号 2147-D-09。类别：可回收生物质。事件关联：D班转移损失，3人。损失原因：路线选择。回收：坐标已录，条目已关闭。

## Field Note

损失原因，路线选择。三个人挑了同一条穿过开阔水域的直线，表格怪那条直线。屏幕变干净的时候，把航向折掉。
