# 热口锚群落

热口锚群落解释了为什么 Marauder 不能留在浅处解决所有维修问题。群落生长在热液喷口把热量和硫化物化学推入盐水层的地方。它们的肋状身体捕获矿物，冷却成板，并在致命水体边缘庇护小型热口动物。这让它们有价值，却不把它们变成魔法矿石。脱落肋条可用于 pressure-ceramic filler、cold-sealant grit 和化学过滤器。活的热肋条会快速杀死潜水服，或用热冲击裂开工具头。正确读法是耐心：扫描热 bloom，等待冷却边缘，只切脱落板，除非目标值得风险，否则不要碰活跃喉口。

## Scanner

热口锚群落 // 肋状群落锁在热液喷口周围，捕获硫化物，并生长出深度级维修所需的化学。

## Terminal

资源基线：群落提高 cold-sealant grit、pressure-ceramic precursor 和 sulfide salt 概率。热 bloom 仍致命；只从冷却肋条和脱落板采样。
