# Aegir 中继窗口

Aegir 可以让数据包上升，同时把操作员留在水下。中继窗口是天气、磁场、队列、Black Keel carrier 位置和法律清除之间的临时几何。它证明消息可以离开 HECTON-8；不证明人体能从同一个开口升上去。

## Scanner

中继窗口 // 信号接收通道正在开启。风暴羽流和 Aegir 磁噪仍然很高。上升包、隔离握手和 tonne-window 分配清除前，回收被阻断。

## Terminal

AEGIR 中继通知 // 联系可能先于援助通过。保留数据包路线、时间标记、天线状态、风暴羽流读数、carrier 通道和保管封印。窗口接受不分配氧气、升举质量或操作员撤离。

## Audio

## Field Note
