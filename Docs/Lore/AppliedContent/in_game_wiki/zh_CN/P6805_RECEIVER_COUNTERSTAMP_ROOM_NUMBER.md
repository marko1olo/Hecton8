# receiver counterstamp 房间编号

receiver counterstamp 是 blank berth 变成 named door 的瞬间。它能让 recovery 更难被忽视，但也会写明 lift 后谁拥有 body。相信 stamp 之前，先检查 room class、medical owner 与 receiver strip。

## Scanner

COUNTERSTAMP 读数 // quarantine room number 存在。确认 body custody class；sample-only rooms 不能清除 living recovery。

## Terminal

RECEIVER ROOM COUNTERSEAL // blank berth 被 owned custody 覆写。只有 named room、owner 与 body class 存在时，lift allocation 才能推进。

## Audio

room number 已写入。receiver 拥有这扇门。ascent burn 前确认 body custody。

## Field Note

room number 是把手。小心拉动；有些门是笼子。
