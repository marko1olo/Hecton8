# 路线许可戳

路线许可戳是殖民地的小型移动语言。它们出现在班次板、舱门标签、潜服芯片、车辆板、工具柜和封存的路线卡上。好的戳记不讲故事。它把一个工人与一个地点、一项任务和一个预期返程标记绑定在一起。

洪水之后，它们才变得重要。储物柜上的名字证明一个人存在过。路线许可证明系统把这个人送去了哪里。PUMP、SEAL、RELAY、BRINE、FORGE、TRIAGE、BOTANY和WITNESS不是装饰标签。它们决定谁能通过气闸、进入维修通道、触碰泵脊、乘坐盐水车、签署relay包，或站在医疗门前。戳记缺失、迟到、被划掉，或比周围金属更干净时，房间就开始和记录争辩。

读戳记时要连同物体一起读。有戳但从未开启的舱门是拒绝。许可过期后打开的舱门是迟来的命令，或未经授权的救援。刮花地面旁边空白的返程格说明有人出去了，但有权限关闭循环的人没有回来。旧盐层上的新管理贴纸说明故事后来被修补过。Deep Reach喜欢戳记，因为戳记把人变成流程。Marauder应该因为相反的原因喜欢它们：流程会留下指纹。

不要因为路线标签比整块面板容易带走就把它剥下来。面板保存压力状态、水线、工具痕和门的方向。单独的标签会变成收藏噪声。标签和房间在一起，才知道谁被派出、谁被扣住、谁被转换成干净的损失类别。

## Scanner

ROUTE STAMP // 工人姓名、工作类别、访问等级仍可读。返程标记缺失。舱门涂层显示许可过期后曾被开启。切割框架前保留标签。

## Terminal

路线台规则 // 有效许可必须绑定工人、路线、任务和返程状态。接受路线为真前，对照舱门损伤、班次板、潜服标签和分诊账本。

## Field Note

戳记不是仁慈。它是系统放置身体的位置。
