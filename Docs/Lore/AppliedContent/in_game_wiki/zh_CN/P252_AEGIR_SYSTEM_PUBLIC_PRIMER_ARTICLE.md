# Aegir系统公开入门

Aegir给HECTON-8提供了实际形状。这个系统不是围绕故事画出来的天空盒；它是路线打开、关闭、延迟并变得过于昂贵的原因。HECTON-8在月球阶梯、潮汐、辐射窗口、承运方转移轨道和中继角度中运行。信息可以先于救援艇离开。索赔可以先于人类撤离堆栈被定价。Black Keel能够回应，是因为信号比移动有屏蔽的质量便宜。这不会让Aegir空旷或不可抵达。它让Aegir变得工业化：日程、燃料余量、隔离语言、月影、海洋潮汐和轨道监管一起压在一个潜水者身上。公开Aegir文本应该保持科学坚硬、戏剧实用。系统在运转。正因为如此，遗弃可以成为程序，而不是沉默。
