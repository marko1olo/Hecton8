# 轨道回收窗口协议

轨道回收窗口协议是把救援变成工程而不是希望的硬限制。Black Keel 足够频繁地经过 HECTON-8 上方，因此它重要；但 carrier 不能直接从月球级风暴场里捞出一个潮湿、未经验证的物体。Aegir 的高层大气会撕碎糟糕的上升角，磁噪会吞掉薄弱制导，接收器也不会接受隔离 handshake 失败的质量。因此协议同时要求几项证明：rated ascent object、能命中窗口的 guidance core、接收器信任的压力历史，以及告诉 carrier 它被允许接住什么的法律保管状态。这就是为什么几乎可用的逃离仍然危险。发射太早，风暴拿走物体。发射太晚，Black Keel 变成云顶上方远去的声音。没有隔离同步就发射，carrier 可能听见你、标记你，却仍然拒绝质量。窗口让天空变得真实：看得见、够得着、按时间打开，而且没有仁慈。

## Scanner

Black Keel 近到能听见你，却受限到不能随叫随接。Aegir 只会打开狭窄的回收窗口。

## Terminal

回收窗口 / Black Keel 接收器仅在低 storm-top shear、Aegir 磁噪降低、guidance core 已验证、quarantine handshake 匹配且 receiver custody state 合法时接受 rated ascent object。窗口漂移会使手动 launch 失效。

## Audio

船近到足够重要，又远到不能迅速救你。

## Field Note

用于路线计时器、carrier UI 和假出口解释：风暴剪切、磁噪、上升几何、隔离 handshake。
