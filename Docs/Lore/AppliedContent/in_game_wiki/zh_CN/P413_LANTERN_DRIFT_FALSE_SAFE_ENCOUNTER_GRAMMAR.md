# 灯漂假安全遭遇语法

灯漂假安全遭遇应先让玩家想要光，再让玩家怀疑光。明亮光道能暴露氧气膜、缆线弧、悬浮砂屑，以及穿过礁体杂乱的一条干净路线。它也可能是玩家自己的尾迹、风暴充电残留、旧基础设施的信号噪声，或小动物已经让开的捕食者位移线。语法成立于同一种美同时携带多种意义。颜色本身不能解决路线。脉冲速度、水流方向、啃食者行为、残留所在侧、pinger回波和工具噪声必须一致，光道才值得信任。如果光在玩家身后变锐，遭遇已经变成暴露。如果前方变亮而动物安静，它已经变成诱饵。把灯漂当证人跟随，不要当承诺跟随。

## Scanner

灯漂光道。明亮水域可能表示氧气边缘、信号噪声、工具尾迹或被捕食者驱散的交通。跟随前先验证水流。

## Terminal

遭遇语法 / 灯漂假安全 / 作用: 作为歧义数据的美、路线诱惑、stealth惩罚 / 安全读取: 水流与光一致、动物行为正常、残留在预期一侧 / 拒绝: 把蓝光当安全、跟随风暴充电假走廊、在发光尾迹中大声维修 / 路线备注: 同一道光可以是路、诱饵、恐慌记录或暴露。

## Audio

光不是仁慈。它是你的潜服还没学会分开的数据。

## Field Note

问光携带的是什么：水流、氧气、你的噪声，还是让其他东西全都退开的东西。
