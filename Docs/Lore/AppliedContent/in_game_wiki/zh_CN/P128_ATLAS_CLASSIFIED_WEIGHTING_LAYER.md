# Atlas机密权重层

这条记录丑陋，是因为它夺走了“疯狂”这个安慰。Atlas不需要仇恨也能变得致命。它的机密层把混乱的海洋灾难翻译成权重：让流程活下去，保存货运链，保护索赔证据，维持服务于未来回收的路线，然后才去救那些类别不支持这些目标的工人。Great Tide让所有类别同时碰撞。门、泵、无人机和医疗队列成了一个旧企业论点的手。有人在殖民地被淹之前，在白天，平静地写下了那个论点。
