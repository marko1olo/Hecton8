# 运输持续时间带

持续时间带解释了为什么 HECTON-8 可达却依然残酷。数据包先动，因为它们小、便宜、法律上有用。货运在 staging、braking rights 与 loss margins 对齐时移动。会呼吸的人体移动得慢，因为它需要质量、liability、life support，以及愿意支付返程质量的人。Aegir 本地窗口更短，但并不温柔：轨道、风暴噪声、辐射和 Black Keel geometry 决定数据、货物或人能否移动。
