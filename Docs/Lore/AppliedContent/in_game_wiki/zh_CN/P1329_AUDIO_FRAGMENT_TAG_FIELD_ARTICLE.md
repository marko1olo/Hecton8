# 音频碎片标签

音频碎片标签用来防止声音变成廉价说明。在 HECTON-8，一个声音应该来自真正可能记录它的东西：水听器条、潜服记录卷、终端缓存、black-box 碎片、数据包公证页脚、受损转录带，或 Marauder scan tag。物体必须回答为什么这个声音能存活。

有用的碎片很短，因为硬件正在失效。它可能携带工作命令、被切断的警告、呼吸计数、泵节奏、失败翻译、修正标记，或检查表最后一行。它不应该从虚空解释剧情。如果玩家不能指出设备、保管印章和塑造转录的损伤，那么这段音频还不是证据。

音频要和物体一起读。压碎的记录器上出现干净转录，很可疑。缺失的时间带可以隐藏是谁切断线路。字幕损伤带可以同时是叙事内损伤和无障碍文本，但不能让场景不可读。最好的 voice logs 不会把殖民者变成煽情角色。它们展示系统失败时，人们正被困在工作中。

## Field Note
