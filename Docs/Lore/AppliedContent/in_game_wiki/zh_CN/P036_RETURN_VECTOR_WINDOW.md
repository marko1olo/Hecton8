# 回程矢量窗口

回程矢量窗口第一次证明 Black Keel 能回应，但不能立刻救援。Carrier 在 Aegir 上方的自动转移轨道上仍然运行，但离开 HECTON-8 的路径必须穿过天气、带电粒子噪声、中继损伤和未完成的上升硬件。

有效回程窗口需要四个读数同时成立：carrier 几何、表面风暴间隙、干净中继路径，以及能承受发射的胶囊链。只要一个失败，ping 就只是时间戳，而不是接送。同一系统之后会支持部分撤离，但不会清掉债务、证据保管或受损路线。上升托架、制导核心、隔热盾和回程握手重建前，任何来自轨道的回应都只能当成时间约束。
