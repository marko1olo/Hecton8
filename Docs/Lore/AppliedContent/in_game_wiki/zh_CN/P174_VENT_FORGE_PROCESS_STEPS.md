# 热泉锻造流程

热泉锻造流程把 HECTON-8 的制作变成仍然有物理感的工业仪式。玩家并不是把幻想炉子装在口袋里。锻造点是海洋、地热热泉和殖民地残破设备短暂达成一致的地方。首先排出坯件里的旧盐水，避免它在内部沸腾。然后在热泉脉冲升起前夹紧，借压力上升预热，在短暂低谷中封口，再用冷回流淬冷。最后的声学响环不是装饰，它证明零件是一个完整的干净整体，而不是把裂纹藏在里面。这给制作带来一种世界可以用 VFX、音频和 UI 支撑的节奏。热量重要，但时机更重要。错过窗口不会得到神秘失败状态，而会得到扭曲废料、盐 bloom 或压力裂纹组件，明确告诉玩家哪里出了错。

## Scanner

热泉锻造不是魔法金工，而是在不让行星吞掉零件的前提下，借用它的热、压力和时机。

## Terminal

热泉锻造步骤 / 01 从坯件排出盐水 / 02 脉冲前夹紧 / 03 随热泉上升预热 / 04 在压力低谷封口 / 05 用冷回流淬冷 / 06 以声学响环认证 / 失败：扭曲废料、盐 bloom 或压力裂纹件。

## Audio

这颗月亮就是炉子。你只是被允许借用它。

## Field Note

流程必须能读成排盐、夹紧、预热、封口、淬冷、响环测试。风险不是火焰，而是错过压力低谷。
