# 疏散队列终端证据套件

疏散队列终端有价值，不是因为它说有人等待，而是因为门状态、时钟漂移、工人计数和航路容量以可现场核查的方式互相矛盾。

## Scanner

POI证据套件：队列终端通过门状态、时钟漂移、工人数量错位和航路容量证明延迟。

## Terminal

队列终端套件：航路保持清单、隔离解除延迟、Atlas权重记录、工人计数不符、salvage冲突标签、舱门状态条、徽章残留。

## Audio

队列是格式更干净的尸体计数。

## Field Note

掠夺者备注：扫描徽章残留前不要撬下舱门条。金属不如时间戳值钱。
