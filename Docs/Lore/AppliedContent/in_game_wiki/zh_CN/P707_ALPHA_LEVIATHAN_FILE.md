# 阿尔法利维坦：合并档案

二十二次事件里有九次被并到一个代号下：九条船体报了应力警报，而损失表格上原因只有一行。

第2节 形态、第4节 质量与展长 - 不予披露（RCO/hv）
第6节 声学 - 载波低于 40 Hz，1340 m；上限不予披露
第7节 航路影响 - 只有航向，214线
第9节 接触事件 - 附录K，未随件，无抽出印章
第11节 生存者陈述 - 留档，不计入（缺氧、氮麻醉）
第12节 物种比对 - 无法判定，22次中22次

留下来的是仪器的表现：声呐上什么都没有时响起的船体应力报警、只有方位没有距离的记录、走廊里没有任何能改变水流的东西却横着转向的水流。

多数事件里，水先静下来：小型摄食种一起停住而且不再恢复，走廊的一端先于另一端安静。

评估：先静下来的那一端，就是它来的那一端。撤离走别的方位。
