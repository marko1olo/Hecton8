# Aegir主恒星

Aegir围绕一颗普通K型主星运行。HECTON-8并非因为恒星失败而黑暗；水柱深度、风暴浑浊、食影时间、淤泥、压力和破损工业制造了黑暗。表层光可以养活陆架生命，而深渊仍是法律和物理上的盲点。

## Scanner

K型主星确认。系统里有光；制造黑暗的是深度、风暴、食影和债务。

## Terminal

RAN/AEGIR星历：K矮星主星，光球输出稳定，星际包延迟级，无FTL救援矢量。质量抵达前，一切援助按本地处理。

## Audio

星光能抵达陆架。抵达不了问题。

## Field Note

恐怖不在恒星。恐怖在海洋把光变成传闻的地方。
