# 公司响应账本

账本是Black Keel在无人即兴处理时的语言。它能承认危险、打开队列、保留索赔，同时仍把操作员留在资产规则之后。玩家应该把响应账本当作有用信号，也当作已变成可执行代码的敌意文书。

## Scanner

每个回复都以合同语言到达：资产托管、责任锁、样本路线、船体风险，然后才是操作员回收。

## Terminal

响应等级：资产保存。操作员回收附加在样本托管、责任封印、船体审计和付款路线之后。

## Audio

回复是自动的。救援是有条件的。

## Field Note

立即响应不是立即救援。
