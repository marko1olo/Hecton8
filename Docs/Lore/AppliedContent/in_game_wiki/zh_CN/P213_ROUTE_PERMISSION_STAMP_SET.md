# 航线许可印章集

航线许可印章集给移动一种视觉语言。PUMP、SEAL、RELAY、BRINE、FORGE、TRIAGE、BOTANY 和 WITNESS 印章不是等级徽章，而是压力许可：在殖民地失效时，谁能穿过舱门、领取潜服、放行 crawler，或进入维修气闸。印章应始终与物理状态配对：打开、密封、拒绝、覆盖、淹没，或后来被掠夺者手写修正。这样玩家无需角色解释，也能重建殖民地的移动。

## Scanner

航线印章比日记句子更强，因为它证明谁被允许穿过压力边界。

## Terminal

STAMP RULE: 航线许可必须连接一个工人、一扇门或一台载具、一个班组家族，以及一个后来的矛盾。没有物理边界的印章只是装饰。舱门、潜服架、crawler 轨道或升降机标签上的印章会成为移动证据。

## Audio

访问权限就是压力下的传记。

## Field Note

印章：PUMP、SEAL、RELAY、BRINE、FORGE、TRIAGE、BOTANY、WITNESS。与舱门状态和工作物件配对。
