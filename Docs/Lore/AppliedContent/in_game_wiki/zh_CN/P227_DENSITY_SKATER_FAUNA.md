# 密度滑行者动物群

密度滑行者是中深度动物，它们让盐水峡谷像层状机器，而不是空旷体积。它们的足、鳍或钩状垫会压在密度界面上；这种界面足以让小型身体保持数秒。肉眼看似在开放水域中滑行；scanner 却在本不该有表面的地方看到波纹。矛盾就是线索。滑行者轨迹可以标记剪切窗口、盐水台阶、声纳盲边，或大型生物使用的狩猎路线。它不是魔法，也不是安全承诺。潜水服更重、更吵，形状也不适合这种技巧。用滑行者尾迹读取层面。不要以为你能跟上。

## Scanner

密度滑行者 // 细肢动物把盐水界面当作表面滑行，在声纳预期为开放水域的地方留下波纹。

## Terminal

基础动物群：滑行者接触在撕裂 brine vane、温热盐水台阶和声纳死边附近增加。它们的尾迹标记密度台地，不是安全落脚点。不要追着穿过不透明层。

## Audio

有什么东西正在水里的水面上行走。

## Field Note

它们不是悬浮。它们在一条你的潜水服可能会跌穿的边界上行走。
