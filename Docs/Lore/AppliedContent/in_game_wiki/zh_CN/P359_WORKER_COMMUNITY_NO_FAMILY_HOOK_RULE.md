# 工人联络公告

工人联络公告不是冰冷的官僚表格。它是海底殖民地承认一个事实的办法：隔着光时延的爱，不能在六分钟内打开舱门。母亲、配偶或旧友可以非常重要，却在压力警报中完全来不及。公告要求铺位排、路线负责人、医锁见证人、泵房搭档和工具库联系人，因为这些人才近到能听见漏掉的提示音。

这种实用的亲近让站点真正像一个共同体。D. Rivas 不只是铺位牌上的名字；他还是饭前必须归还的泵钥匙。Mara Venn 不只是水账边上的更正；她知道哪道滤芯已经发酸，也知道哪个主管还在装作那不是污染。路线负责人敢签联系人调换，是因为一个工人信任另一个工人会先发现手抖、呼吸乱掉，或者手套密封已经开始用声音报警。

私人通话只是被中继流量延后，并不是被抹掉。差别很重要。公告没有否认人们在 HECTON-8 之外的人生；它记录的是下一次隔舱循环前能救命的人。在这里，共同体等于距离、能力和反复归来的习惯。有人没有回应提示音时，公告知道谁该先动。

这张公告不需要秘密血缘也能让殖民地有人的重量。潮湿的靴子、共用的工具、欠下的水、糟糕的睡眠、下潜前互相检查的习惯把他们绑在一起。海洋让距离变贵。名册把靠近变成责任。
