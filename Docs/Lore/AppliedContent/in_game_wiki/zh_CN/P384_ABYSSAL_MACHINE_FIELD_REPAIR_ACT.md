# 深渊机器场修复门

深渊场迫使操作员使用损害索赔的系统。Atlas 生长可以桥接电力、修补路线硬件，并通过活材料传输信号。每次成功修复也会改变分类：工具、生物、资产、污染和证据不断跨过字段。

## Scanner

路线门：深渊机器场。Atlas 修复生态变成可用路线硬件，并附带保管风险。

## Terminal

战役路线 // 深渊机器场。需要：导电膜、声学器官、服务盆地、pressure-safe reroute。修复输出可在同一遍中恢复硬件，并污染所有权类别。
