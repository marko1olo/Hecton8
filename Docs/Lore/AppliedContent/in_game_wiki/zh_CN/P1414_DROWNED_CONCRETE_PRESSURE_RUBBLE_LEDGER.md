# 沉没压力混凝土账本

沉没混凝土不是背景。垫圈痕、锈影、陶瓷骨料和塞满贝砂的裂缝，都保留着已经消失的房间形状。开采前先问：它原来挡住了什么。

绿色下缘表示坍塌前长期积水。干净剪切面可能是新 salvage、震裂或压力失效。没有钢筋但有锈影，说明金属已被拆走、腐蚀或撕出。边缘的垫圈尘能指出舱门或压力门的位置。

Marauder 不只把碎块当 loot。玩家可以沿锈影找到维护脊线，避免切掉最后受压板，或在贝砂下找出航路板。海抹掉了房间，却没抹掉房间失败的方式。

## Scanner

沉没混凝土 // 殖民地耐压骨料，不是天然石灰岩。钢筋已无，只剩锈影。裂缝里的贝砂代表长期进水；干净断面代表近期坍塌或 salvage 切割。

## Terminal

旧殖民地板块 // 不要当普通石头开采。混凝土碎块标出房间、管线槽或承重路径。白色陶瓷骨料是受压墙，橙色锈影是旧加固，下缘绿黑污迹说明坍塌前曾泡水。
