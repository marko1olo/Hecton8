# Styx降下舱剖面

Styx舱不是穿梭机，而是一次性耐压壳体。它用最小承保质量，把一名穿作业服的操作员从Black Keel送到合法工作地点。它足以熬过大气、风暴剪切和水面冲击，留下庇护所、微弱电力、终端和证据物。

它的失败很具体：热瓦耗尽、uplink桅杆剪断、压缩机进水、回收套筒no-lock、claim handshake低于回收阈值。降下舱让操作员活着，同时证明投送和救援是不同的合同事件。
