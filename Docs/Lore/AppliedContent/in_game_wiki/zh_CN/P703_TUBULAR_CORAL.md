# 管状珊瑚

工厂墙面上的一条管迹，意思是它后面的墙裂了。这种生长沿裂缝走并把裂缝填满；西湿式库房6号房间自2147年起就是它以20.1 MPa撑着的。

活的管迹尖端发白、基部带铁锈色；死的能保持形状几十年。读颜色，不要读轮廓。

板材钢印在珊瑚下面。面板编号读不出来的房间无法认证，所以6号房间的档案是靠一次外部踏勘和一个签字结掉的。

切一条横跨焊缝的管迹，你切掉的是补片，不是植物。一把焊枪不到一分钟就削掉了四十三年的密封。

每一条被填满的裂缝都是先从压力侧封住的。产出：生物纤维密封剂，染色的基部最多。只从完好的板材上取。

## Scanner

承载板上的群体管状生长。覆盖60%。置信度84%。危险：接触无危险。限制：无法把表面附着物与已填充裂缝分开。

## Terminal

维修记录 44-W-0612。类别：结构修补，材料就地取得。面板识别：无法复原。6号房间：以外部踏勘认证。检查间隔：免除。归档：ATLAS 连续性办公室。

## Field Note

“以外部踏勘认证”的意思是，有人绕着一个淹没的房间外面走了一圈，找不到面板编号，还是签了字。信一面墙之前先查尖端颜色，而且绝不要把焊枪伸进横跨焊缝的管迹。
