# Aegir回收池

Aegir回收池是Black Keel背后的公共salvage外壳。它让小型marauder执照无需拥有私人行星际carrier,也能抵达Aegir废弃索取点。这笔交易既有用又有毒:同一个能派出补给艇的池,也决定活着的操作员、封存payload、隔离锁或证据包,哪一个值得下一次burn。
