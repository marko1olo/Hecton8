# 索赔语言审计

索赔语言是殖民地最安静的武器之一。它不必否认泵房、被锁住的分诊门或留在维修格栅后的工人质量。它只需要在有权者读到文件前替它们改名。队列变成释放时间差。锁门变成隔离复核门。没有返回的身体变成赔付暴露。受损的打捞返程变成部分资格。

审计存在，是为了让玩家把程序语言读成行动。每个被转换的短语都要追回到一个人、一间房、一个工具、一只路线钟或一次压力事件。Deep Reach可以保留证人，同时通过更换货架标签埋掉证词。如果类别还活着，身体却消失了，证据已经被清洗过一次。
