# 观察窗应力雾账本

HECTON-8的观察窗是在压力下做出的承诺。它允许房间看向外面，却不让海进来。因此每一处污迹都有意义。清晰中心只是被人清理过的部分；边缘才说真话：乳白分层、盐雾、清洁臂留下的月牙划痕、密封污垢、夹层冷凝和浑浊应力弧。

玩家应该像读仪表一样读窗。边缘有应力弧但密封干净的玻璃可能很老，却仍稳定。密封圈下有雾，说明水进入了层间。夹层里有水珠，说明干燥侧是慢慢失败的。月牙划痕通常属于被维护过的房间；随机切痕更像坍塌碎片或后期拆解。

观察窗既是路线标记，也是风险。它能显示墙后干燥口袋、仍有空气的房间、曾经每天看海工作的岗位，也能证明所谓“瞬间破裂”其实是缓慢失效。沿疲劳边缘切割可能温和释放房间；敲击清晰中心会把安静的墙变成刀。
