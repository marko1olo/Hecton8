# 系统载体拖船栈

Black Keel是系统载体和salvage平台，不是私人星船。它能保持轨道、处理货物、运行托管锁、发射胶囊并协调拖船。它不能抹掉光延迟、路线窗口、损坏的bathydrop硬件，或决定帮助何时移动的成本规则。
