# 工人名册规模规则

工人名册规模规则让废弃殖民地保持可读。HECTON-8 必须像一个由班组运转过的地方，而不是随机铭牌堆成的场景，所以名册被故意控制在足以让重复有意义的规模。锚点工人会在储物柜、泵标签、分诊表、航线许可和损坏工作物件中再次出现。Seed-role 工人为每次运行提供更宽的变化，但他们仍然带着工作、地点和最后任务。这个规则同时防止两种失败：没有人味的匿名废墟，以及让每一次死亡都显得廉价程序化的姓名泛滥。

## Scanner

七十二个名字不是氛围文本。它是殖民地的记忆预算：足够多，让这里像曾经有人工作；又足够少，让储物柜、维修标签和最后班次指回同一个人。

## Terminal

ROSTER RULE: 运行名册包含72个工人身份。24个是锚点姓名，可在储物柜、账簿、损坏工具、通行许可章和音频碎片中反复出现。48个是用于重玩变化的 seed-role 姓名。生成姓名可以移动证据顺序；它不能变成一次性填充物。

## Audio

当房间能证明那份工作时，名字才成为证据。

## Field Note

如果一个名字之后不能带着工作再次出现，就从名册里删掉它。
