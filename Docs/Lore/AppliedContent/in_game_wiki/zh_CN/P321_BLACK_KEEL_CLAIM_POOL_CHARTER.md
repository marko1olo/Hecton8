# Black Keel 申索池章程

Black Keel 申索池章程是第一个应该让玩家怀疑船这个词的文件。Black Keel 有用、接近、真实，但它不是在头顶忠诚等待的私人船只。它是 Aegir Reclamation Pool 内的一项租用回收资产，负责把申索、尸体、货物、遥测和债务通过法律通道移动，而不是把船体所有权交给承包人。这个区别重要，因为它不用魔法就解释了 HECTON-8 的核心陷阱。Carrier 可以听到 ping、出售遥测、安排窗口、投放低风险物资，却仍能拒绝干净救援，因为玩家并不拥有这条路线。运输被允许。救援优先级有条件。Lien 仍然有效。章程把轨道变成压力，而不是自由：你上方确实有东西，但它先回应申索，再回应人。

## Scanner

Black Keel 不是你的船。它是申索池的回收资产，你的名字写在它的债务账里。

## Terminal

章程摘录 / BLACK KEEL：自主打捞 carrier / 保管方：Aegir Reclamation Pool / 承包人运输：允许 / 船体所有权：拒绝 / 救援优先级：从属于 insured receiver 状态、隔离 handshake 与 claim value。
