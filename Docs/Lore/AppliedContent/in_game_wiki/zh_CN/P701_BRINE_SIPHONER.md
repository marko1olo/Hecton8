# 卤水吸食者

它们定位的地方，后面的板材是开的。

卤水吸食者是抽卤水层，不是在里面游，靠它抽进的两种密度之差进食。锋利的界面它不会放弃，而这里最锋利的界面是我们造的：2,185米处一条裂开的冷却管把淡水漏进卤水，一副取水格栅隔着一台死泵还在抽。

沿格栅把它们数一遍，你就量出了后面的破口。受扰时，一只会把浓的一侧整团排出，这团东西沿Class-IV旁边下沉，并把深度通道带走四到十秒。

东廊道有一处渗漏它们避开。那里的水化验结果完全相同。

评估：先数格栅，再按开口船体处理。

## Scanner

渗透压特化种，定位于密度界面。置信度64%。危险：喷出的卤水污染深度通道。限制：仪表恢复间隔未标定。

## Terminal

标本 44-D-118。类别：检漏服务，无合同。地点：冷却廊道3 取水格栅，2,185 M。结论：卤水偏差由观察绘制。传感器更换项 22-B：已关闭，校准漂移。

## Field Note

他们关掉检漏传感器项，是因为这些动物白干了勘查，然后就不再修勘查查出来的东西。把切割器凑近格栅之前，先把格栅数一遍。
