# 压力阶梯声学图

压力阶梯声学图是一张伪装成测绘数据的生存地图。HECTON-8不是一片均匀海洋。透光陆棚保留少量Ran光和风暴生命。电缆礁把工具和声标挂进Deep Reach旧基础设施。盐水峡谷弯曲浮力，把声呐变成舞台。机器场是被压力压碎的工厂，仍在回应Atlas修复逻辑。Atlas盆地黑暗、炽热、金属化，并靠错误分类活着。

上层海洋以下，声音是唯一实用视线，但声音不会免费诚实。盐层会困住它。热液喷口会撕裂它。电缆毯会回放它。干净回波可能是墙、捕食者尾迹、管道记忆，或把你的恐慌复制回来的中继。规则是：下潜由密封、氧气、电池、回程 ping 和怀疑共同许可。
