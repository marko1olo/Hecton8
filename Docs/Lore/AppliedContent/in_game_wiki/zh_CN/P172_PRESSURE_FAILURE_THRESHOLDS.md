# 压力失效阈值

压力失效阈值让 HECTON-8 的打捞变成物理问题，而不是抽象库存数学。容器安全，不是因为它在背包里的名字是绿色的，而是因为外壳、垫圈、夹具、证明标记和路线历史仍然与周围深度一致。这些阈值同时也是玩家公平规则。失效变成损失之前，世界应该先开口：密封件发出滴答，垫圈开始漂移，夹具颤响，发丝裂反光，盐 bloom 生长，声学回波变成幽影，或死样本雾开始把玻璃弄浑。每个信号在不同层级里含义相同：材料已经从有用物件跨入局部危险。这样制作、UI和环境音可以共用同一套警告语言。玩家受到惩罚，是因为忽视压力，而不是因为没读到隐藏数学。

## Scanner

好样本跨过错误的压力线后也会变成危险物。海洋不在乎标签只差一点就对了。

## Field Note

失效阈值必须在惩罚之前可读：滴答、漂移、发丝裂、盐 bloom、死样本雾。如果玩家只能在损失后学习，世界就是作弊。
