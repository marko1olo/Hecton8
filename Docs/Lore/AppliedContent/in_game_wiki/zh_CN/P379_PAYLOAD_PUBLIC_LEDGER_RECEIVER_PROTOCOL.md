# payload 公共总账接收协议

公共总账协议把证据送到 Deep Reach 无法安静占有的地方。它编辑坐标，封存 attestation hashes，附加路线保管和 Atlas 权重摘要，然后进入延迟中继。发送者在接收时失去控制。包裹变得更难购买、更难埋葬，也更慢才能使用。

## Scanner

公共总账路线已武装。坐标在延迟中继前被编辑；attestation hash 栈和责任链在接收时封存。

## Terminal

PAYLOAD 接收方 // 公共总账通道。接收方：分布式公共总账，延迟 Tau 通道。接收坐标编辑后的事故包、attestation hashes、路线保管、Atlas 权重摘要、接收方时间戳。拒绝私人付款和直接回收索赔。中继接收时撤回结束。

## Audio
