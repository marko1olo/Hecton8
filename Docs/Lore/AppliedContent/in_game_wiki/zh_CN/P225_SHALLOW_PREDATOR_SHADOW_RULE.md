# 浅水捕食者阴影规则

浅水捕食者阴影规则防止第一个捕食者变成简单的怪物亮相。HECTON-8 应该通过一分钟前还在帮玩家的生态来引入危险。矿物膜还在，玻璃啃食者却停止滴答。灯漂仍在发光，但细小噪声被撕开。壳夹礁收紧在缆线路径上。然后一片宽阔阴影穿过明亮路线，安全线不再感觉安全。捕食者最开始不需要名字。它需要后果：被封住的水道、耗氧昂贵的绕路、突然显得过于吵闹的工具任务，或一次证明水体已经改变的擦身而过。战斗可以之后再发生。第一次接触应是可读的压力，而不是镜头前的一张脸。

## Scanner

浅水捕食者阴影 // 啃食者滴答消失、bloom 噪声撕裂、宽阔移动阴影，就是第一次接触。路线压力先于战斗接触。

## Terminal

接触规则：捕食者证据应先改变路线选择，再强制伤害。按不在场、沉默、轮廓和尾迹分阶段；只有玩家忽视或误读至少两个提示后，才进入直接攻击。

## Audio

当那些小嘴停止滴答时，停止移动。

## Field Note

不要先给捕食者一张脸。让大陆架先变得不对：食物还在，水更亮，小生命离开，然后阴影横过任务。
