# 卤层追猎者

它沿着卤水界面捕猎，因为这个界面替它撒谎。

声音在密度界面上会弯折。骑在这条线上的追猎者会在声呐上同时出现在两个深度，而更干净的那个回波通常是假的。88号站被记成两条记录，原因相同。它用这一层的方式，就像Marauder用沉船。

它先试，再下手。第一次经过是在距离外、从你肩侧掠过，为了弄清你会不会转身。转身正面对它，这次经过就结束。继续往前游，第二次靠近就不是经过了。

卤水会留在皮肤上。被刮过的服装密封件读数正常，一个班之后失效。

它在从44区出去的标记疏散通道上巡游。评估：正面对它，然后走一条它没有理由知道的路线离开。

## Scanner

追击型捕食者，保持在密度界面上。置信度58%。危险：跨盐跃层的接触深度不可信。限制：回波可能是镜像，不是动物本体。

## Terminal

标本 44-B-311。类别：可回收生物质，暂缓。路线重叠：疏散通道6（2147年退役）。密封件接触：卤水，2级。索赔用语：设备劣化，非人员暴露。
