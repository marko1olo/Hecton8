# 盐与矿物沉积记忆账

盐与矿物沉积是HECTON-8安静的笔迹。干净裂缝会撒谎，抛光面板也会撒谎。矿物边缘更难伪造，因为它把水的移动、干燥、压力呼吸和化学反应分成不同层。

接缝上的白花说明水迁移并留下负载。螺栓下的钙质滴痕说明缓慢排水，通常发生在房间不再被擦洗之后。污迹周围的绿灰色环说明反复湿边，而不是一次飞溅。垫圈槽里的粉末说明空气或盐水经过了许多压力循环。新黑色流痕越过盐壳，机器泄漏就晚于矿物外壳。

对拾荒者来说，沉积不是脏东西，而是水的记忆。它能标出隐藏渗流、脆弱舱门、压力摆动时会变干的洞穴口袋，或一个停机后仍在呼吸的所谓密封隔间。好的沉积不会大喊。它等人发现：这面墙没有时钟，也一直在数潮。

## Scanner

矿物沉积 // 接缝边缘有白色盐花，旧螺栓下有钙质滴痕，压力污迹周围有绿灰色环。不是泡沫，不是雪。水从这里走过、停下、呼吸，把矿物留下。
