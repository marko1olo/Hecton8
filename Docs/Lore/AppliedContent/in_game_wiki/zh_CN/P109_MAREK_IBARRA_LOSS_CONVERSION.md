# 马雷克·伊瓦拉的损失转换

马雷克·伊瓦拉是Keelmark Mutual理赔痕迹，把失踪工人变成未解决会计状态。表格不是写给悲伤的，而是写给结案成本的：尸体未回收，压力状态未认证，污染待定，薪资身份暂停。

因此名字在HECTON-8中很重要。储物柜铭牌、潜服标签、尸体账本行或找回的路线钟，都能把工人从未解决负载带回某人必须回应的索赔。模糊比救援便宜，比赔偿便宜，也更容易埋进承运方争议。

对Marauder来说，找回的身份不是装饰。它破坏了让一个人消失两次的会计把戏：一次在水里，一次在账本里。

## Scanner

理赔表 // M. 伊瓦拉把失踪工人转换为未解决负载类别，直到压力状态、污染状态或薪资状态可以认证。
