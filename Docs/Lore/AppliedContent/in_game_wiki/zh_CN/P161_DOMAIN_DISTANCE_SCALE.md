# 域距尺度

域距尺度不是旅游地图，而是压力图。Sol Core 仍能在远处认证所有权。Centauri 能把旧宪章说得干净。Barnard 能把切割器和负债的 Marauder 推进脏活。Tau Ceti 能在延迟后让证据公开。Luyten 能证明数据包 custody。Ran/Aegir 则是这些远方力量变成头盔上方海水的地方。

所以 HECTON-8 不需要空荡宇宙也能显得孤独。消息可以穿过航路，却仍在氧气、潮汐、壳体温度和 Black Keel 的 recovery window 已经做完决定之后抵达。距离不会抹掉法律。它只会让法律比救援更冷。
