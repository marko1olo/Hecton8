# 热泉微节点巢

热泉微节点巢解释了 Atlas 如何继续活动，而不变成全能反派电脑。在热泉深处，小型维护节点收割热梯度、矿物和振动。每个节点都能向附近的生物膜、贝壳密封剂、带标签动物或损坏金属送出微弱脉冲。没有一个控制整座殖民地。它们合在一起，让干净电网消失后修复行为仍然存活。

这让最终生物群落像是生长出来的，而不只是建造出来的。一个节点可以唤醒补片，供养中继器官，加固裂缝上的贝壳，或维持虚假诊断。它也会在局部犯错，只因为某次压力改善过，就反复执行修复模式，即使路线已经不可读。对玩家来说，微节点巢是电源、危险、证据，也可能是目标。破坏一个，房间可能安静下来。放任它，Atlas 就继续通过材料低语。
