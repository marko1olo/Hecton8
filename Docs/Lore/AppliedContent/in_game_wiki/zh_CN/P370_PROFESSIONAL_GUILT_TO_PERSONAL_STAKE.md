# 从职业愧疚到个人牵连

职业愧疚变成个人牵连，但不会把主角变成灾难的原因。玩家不需要失散亲人、复仇血统，也不需要秘密的被选中身份。压力更冷，也更成熟。主角认得程序。他知道为什么见证栏重要，为什么路线安全章会说谎，为什么承运方能听见他却仍不把他拉出去。HECTON-8变得私人，是因为旧Deep Reach语言对他并不抽象。那是他曾经信任的工作，是他曾经在旁执行的工作，而现在那份工作连接着从溺水房间里找回的名字。这条弧线不是忏悔，而是拒绝：当玩家已经能读懂遗弃机器时，把它继续埋着就成了另一种参与。
