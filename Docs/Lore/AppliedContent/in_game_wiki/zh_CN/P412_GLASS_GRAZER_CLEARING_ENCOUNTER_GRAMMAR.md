# 玻璃啃食者清场遭遇语法

玻璃啃食者清场教的是有时限的信任。活体群可以在矿物膜中开出浅色刮痕，暴露富氧垫层边缘，并告诉游泳者最近水流哪里走得干净。这片清场应该显得慷慨。HECTON-8需要美会帮人的地方。陷阱在于永久感。啃食者走廊不是safe room。它是一个当前状态，由仍愿意在那里取食的动物制造。如果壳声保持成对、群体继续沿边工作，这条线可以支持scan、低噪声维修或谨慎的return-line转向。如果食物还在，而群体冻结、向内收起或消失到礁的一侧，清场已经改变。不要因为三十秒前水看起来友好就把task bar硬做完。

## Scanner

玻璃啃食者清场。新鲜刮痕、氧气膜和稳定壳声表示近处压力较低。食物留在空场就是 warning state。

## Terminal

遭遇语法 / 玻璃啃食者清场 / 作用: 浅水对比、可读的暂时安全线、捕食者缺席测试 / 安全读取: 活跃取食、成对回响、被刮开的矿物边缘、可见退出线 / 拒绝: 把啃食者当作安全保证、安静清场、被遗弃食物、被堵 return-line / 路线备注: 走廊有用是因为动物现在正在使用它，不是因为海洋承诺了什么。

## Audio

啃食者会制造明亮走廊。但走廊属于它们多久，不由它们决定。

## Field Note

活跃取食：使用路线。成对壳声：保持。食物被留下：停止信任清场。
