# Aegir 月群航路账簿

Aegir 月群账簿给附近月亮明确的航路功能，同时保留 HECTON-8 作为深层索赔被争夺的海洋月。天空显得有人活动，却不会把每颗月亮都变成承诺目的地。

## Scanner

Aegir 的月亮靠它们破坏、隐藏、散射、中继或出售的东西赢得名字。
