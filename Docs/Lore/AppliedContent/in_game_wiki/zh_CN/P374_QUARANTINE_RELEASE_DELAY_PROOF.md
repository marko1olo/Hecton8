# 检疫释放保留

HECTON-8 上的污染是真实的。压力暴露、卤水化学和 Atlas 兼容生长，都可能让草率救援变得致命。保留板显示，这种真实危险如何变成掩护。Deep Reach 在出口路线锁定后调用检疫，接受可回收资产质量，并把工人释放压在线下。

## Scanner
