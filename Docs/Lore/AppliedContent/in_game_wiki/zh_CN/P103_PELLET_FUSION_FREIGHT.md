# 弹丸聚变货运

弹丸聚变货运让Aegir在无FTL条件下可达。光束站推动；弹丸流喂给聚变燃烧；屏蔽质量吸收尘埃；磁帆和本地制动系统用时间偿还速度。同一套架构也让救援变慢。每一公斤都有时间表、热预算和所有者。
