# Ran / Aegir名称权限账册

HECTON-8名字太多，是因为太多办公室想用干净办法拥有肮脏的水。Ran是恒星。文件谈光、航线、载波延迟或导航时使用它。Aegir是气态巨行星。说话者想让月球消失进更大的索赔系统、天空、母体或资产组时使用它。RAN-B:H8是投保月球键，是账册可以排序却不必记得谁曾住在那里的名字。HECTON-8是现场名，粘在湿梯、舱口边、路线板和旧压力门上。

            这些名字不可互换。它们是指纹。说Ran的路线办公室大概率在做导航。说Aegir的Deep Reach备忘录常在保护系统尺度的所有权。写RAN-B:H8的Black Keel回执把这个地方变成可收费对象。写HECTON-8的工人笔记不是俚语也不是感伤。它是来自海洋逐舱杀人的高度的证言。

            好证据会保留发现时的名字。过早规范化会毁掉动机。写Aegir资产的隔离命令，可能通过扩大框架来隐藏本地失败。写RAN-B:H8的打捞报价，可能是在剥掉记忆，好让月球不带哀悼地穿过保险。

            所以PDA保存名称冲突，而不是抹平它。冲突会告诉玩家是谁在说话、他们想计算什么、又想埋掉什么。
