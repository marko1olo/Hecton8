# Ran / Aegir名称权限账册

HECTON-8有多个名字，因为多个权力都想拥有同一片水。Ran是恒星，是天文锚点，也是路线物理使用的名字。Aegir是气态巨行星，是天空中的明亮母体，也是索赔办公室偏爱的系统简称。RAN-B:H8是目录键：冰冷、可投保、可排序。HECTON-8是玩家真正流血的现场名称。

差异很重要。写着Ran的路线牌在谈光、距离和运输。Deep Reach备忘录写Aegir，往往在谈所有权和索赔连续性。Black Keel回执写RAN-B:H8，是在给某个具体月球记录定价。Marauder笔记写HECTON-8，是在谈房间、身体、压力门，以及不在乎律师名字的海洋。
