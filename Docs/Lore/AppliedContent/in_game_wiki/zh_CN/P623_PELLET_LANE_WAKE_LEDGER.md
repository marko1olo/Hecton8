# 弹丸航道尾迹账本

回收的尾迹账本解释了没有 FTL 的近光速货运。光束帆打开航线；弹丸供料聚变和分阶段制动把 seed 载荷、重货物以及后来的人员合同送向 Aegir。每次燃烧都留下账目：消耗弹丸、护盾损失、巡航质量、制动权、冬眠床位和索赔优先级。
