# 电缆礁共生

电缆礁是中层警告。它还不是底部工厂，但显示海洋生命能把工业当作骨、阴影、挡流物和营养线。

## Scanner

植物群在电力主干和信号线上生长。礁体把殖民地布线当骨架。

## Terminal

维护记录：电缆根席减少磨损并保持信号连续，但会吸引无人机和取食动物。

## Audio

一片活礁学会了服务走廊的形状。

## Field Note
