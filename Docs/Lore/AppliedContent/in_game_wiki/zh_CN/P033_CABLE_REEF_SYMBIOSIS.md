# 电缆礁共生

电缆礁形成于中层服务沟，在那里，活体生长物被旧设施固定成稳定形状：供电主干、继电对、夹环和旧电缆托盘。有些垫层会降低磨损，平缓线路周围的水流。有些食草生物会清理裸露导体上的黏液。同一层套也可能隐藏开裂绝缘、困住热量，或把无人机活动带到玩家以为安静的路线。

在扫描证明相反之前，把电缆礁当作仍在工作的基础设施。绿色套层可能是让继电器保持干燥的唯一东西；它也可能盖住将在负载下失效的故障。切割前先检查信号连续性、绝缘层颜色、夹环顺序和无人机移动。这是第一道修复疤痕和后续修复动物之间的桥：活体生长先跟随电流，随后Atlas才开始通过活体路由修复。

## Scanner

电缆根垫在三个夹环处抓住P63供电主干。信号仍从绿色套层下通过。下缘可见绝缘故障。危险：无人机和食草生物的活动跟随带电电流。

## Audio

那片礁不是装饰。它在让那个继电器保持干燥，而无人机知道电流还活着。

## Field Note

不要因为绿色生长物看起来不对就剥掉它。如果它让护套保持干燥，先标出故障并绕路。
