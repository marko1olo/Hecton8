# 捕食者阴影遭遇语法

捕食者阴影遭遇应让海洋在动物可见前就显得已被占据。有效警告链来自环境：玻璃啃食者在食物仍暴露时停下，lantern bloom在一侧变薄，pressureweed没有涌浪却折起，sonar回波出现大得不像碎屑的空洞，玩家灯光扫过一个始终无法解析成清晰轮廓的宽大形体。动物不是arena里等待的boss。它是路线压力。它改变氧气消耗、return-line纪律、维修时机和scan信任。好的阴影遭遇让会读取缺席的玩家活下来：停止制造噪声，收窄灯束，不要追逐那条干净路线，沿角度离开，而不是直线冲回被标记的水域。

## Scanner

捕食者阴影痕迹。sonar空洞、被截断的猎物路径、啃食者突然沉默、宽幅遮光。实体未确认；保持灯光纪律和退出角。

## Terminal

遭遇语法 / 捕食者阴影 / 作用: 实体出现前的路线压力、氧气消耗峰值、scan置信断裂 / 安全读取: 猎物路径停止、bloom噪声塌陷、sonar回波绕开空水分裂 / 拒绝: 把scripted全身显形当作第一警告、无害jump scare、干净boss arena / 路线备注: 如果小动物在scanner命名前全停下，路线已经改变。

## Field Note

晚点命名动物。先让猎物、光和sonar失效。路线一安静，阴影就已经拥有它。
