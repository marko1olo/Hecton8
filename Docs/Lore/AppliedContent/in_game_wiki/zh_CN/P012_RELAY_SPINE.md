# 中继脊柱

中继脊柱让人类空间保持连接，却不假装距离已经消失。它由光束时隙、数据包缓冲、托管哈希、重试计划、公证卷轴和本地天气许可组成。它可以把命令、证据、债务通知和生命证明脉冲送过星际距离。它不能把氧气送进进水的房间。

在 HECTON-8，中继是压力，不是背景。消息可能可读却无用。Deep Reach 数据包可能被清洗后抵达，因为写第一版的人早已死亡。Tau Ceti 公共账本回执可能在多年后让证据具有政治危险。Luyten 可以证明托管，却仍把玩家单独留在水里。中继让真相耐久，却不让真相变快。
