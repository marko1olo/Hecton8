# 生态登记

生态登记把生命和损伤分开。明亮陆架菌毯和摄食者显示基线。缆线植物和滤食体显示生命适应人类硬件。带传感标记的动物、导电膜和shell-seal生长指向Atlas修复路线。正确问题不是它是否活着，而是它在压力系统中承担什么工作。

## Scanner

登记分层确认：原生陆架生命、缆线适应生物群、Atlas路线修复生物。切割前先识别。

## Terminal

登记分层：原生压力生态；殖民地适应缆线生物群；Atlas改变的修复生物。误标可能毁掉工作密封，或抹除路线证据。

## Audio

如果一切都是怪物，你会切断正在维持压力的东西。

## Field Note

世界在受伤之前就已经活着。
