# 湿滑防滑服务甲板账本

HECTON-8的服务甲板不是普通地面纹理。它是殖民地最后的笔迹。防滑凸纹在正常工作时防止打滑，在正常工作结束后变成记录器。盐卡在凸脊上，油沉进槽里，黄色安全漆在携带工具或气瓶转身的地方磨成月牙，锈留在交通不再触碰的接缝。

玩家进入房间前就能读湿甲板。深色金属上的亮线表示洪水后仍有人反复通过。舱门旁的干净半圆表示频繁转身。服务车下坡方向的油迹是泄漏路径，不是随机污垢。整条锈线跨过接缝说明很久没人开过；被磨断的锈线说明后期移动、拆解或返回。

这样的材料不用箭头也能有用。它能给出更安全的走廊、拖拽货物的路线、湿滑平台的警告，或证明所谓封闭的气闸在官方撤离后仍然运转。好的甲板不解释自己，它给玩家足够的物理证据去聪明地判断。

## Scanner

服务甲板 // 深色凸纹防滑金属、磨损的白色和黄色油漆、凸脊上的盐痕、槽里的油湿条纹。锈停在接缝里。通行线弯向气闸。

## Terminal

甲板读取 // 凸纹是移动记录。发亮的凸脊是脚步；暗槽是油或冷却液漂移。黄色油漆磨成弧形，说明有人带货转身，不是装饰。跨缝前先看锈线是否被踩断。
