# 蓝债压力匣处理

蓝债是依赖状态的 salvage。在决定把它当工具材料、索赔价值、诱饵或证据之前，必须保持密封、低温和压力稳定。

## Scanner

压力匣 // 冷却并密封时稳定。不要放气。若接缝升温，运输前先夹紧。

## Terminal

XO 连续性基质 // 保持压力状态。禁止民用储存。样本遥测只能走索赔级保管。

## Audio

如果匣子开始在声呐里计数，它就不再只属于你。

## Field Note

蓝债会付款，因为它带着三个主人到来：找到它的人，想要它的人，以及注意到它移动的东西。
