# 壳质密封剂压力生长

壳质密封剂起初是应急化学：补丁泡沫、矿物浆和把材料压进破口的压力。在 HECTON-8 的水里，本地生长会占据补丁并硬化成分层外壳。

Atlas 只要看到压力损失下降，就把事件判定成功。Marauder 关心的是返回宽度、工具净空，以及外壳把什么困在另一侧。好密封可能搁浅路线、藏住坏水袋，或把死房间保存到里面的机器还能回应。
