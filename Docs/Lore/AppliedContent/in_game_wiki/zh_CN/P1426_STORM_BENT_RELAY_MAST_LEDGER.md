# 风暴折弯中继桅杆账册

HECTON-8上第一根有用天线通常很寒酸：被风暴折弯的桅杆、结盐的铰链、开裂的陶瓷、用错胶带修补的电缆外皮，以及仍指向Aegir的方向刻线。有人每次风暴后都把它重新拧紧，所以它才重要。它不是英雄科技。它是疲惫的基础设施，还记得天空在哪边。

修理桅杆会改变游戏，但不是被困者想要的那种简单改变。更干净的uplink可以提高packet可信度，恢复破损的握手，或者让Black Keel承认操作员还活着。它也可能让carrier在任何像救援的话之前，先询问claim state、sample state、坐标和证据。桅杆改善句子。它不会改善听话的人。

这是轨道生存的第一课：通信不是撤离。一个好支撑、干净触点和校正方位，可以在风暴带压过中继前买到一个packet。玩家仍要选择这个packet承载什么：医疗状态、证据hash、样本遥测、位置，或者谎言。Black Keel会以不同方式听见这些。桅杆只保证争论离开海洋。
