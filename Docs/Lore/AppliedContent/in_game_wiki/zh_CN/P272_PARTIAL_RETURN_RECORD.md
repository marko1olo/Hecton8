# 部分返回记录

部分返回记录登记的是喘息，不是逃离。Black Keel可以把操作员带上去维修潜服、补气、去污并同步账本，但同一seed返回令会把留置、隔离期限、扫描记忆、开放证据包和未解决载荷继续绑在同一片海上。
