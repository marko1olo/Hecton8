# 压力壳肋条与密封圈账本

HECTON-8的压力壳从外侧就能读懂，只要不把它当成普通铁皮。白色外板只是皮肤，深色肋条才是压力载荷的路径。密封槽说明模块在哪里接合，水本应在哪里停住。盐痕指向长期渗漏的最低点。橙色安全漆通常靠近一个可操作的位置。

这会改变拆解方式。螺栓排笔直，说明模块作为一个整体移动；后面的房间也许被压坏，但结构还连贯。撕裂的密封圈和白色盐花说明水进入得很慢，里面可能还保存着标签、工具和纸张。向内弯的肋条说明外压赢了，向外鼓的肋条说明内部曾经排气或爆开。

Deep Reach喜欢干净的模块图。海水留下的修订更可靠：哪根肋条过载，哪处用了错误规格的密封材料，哪些舱门在官方撤离窗口之后又被打开。对拾荒者来说，读壳不是背景知识，而是决定入口、切割线和证据价值的动作。

## Scanner

压力壳 // 白色外板、石墨色肋条、被压缩的黑色密封圈。盐痕从低缝流下。螺栓排仍然笔直：模块整体移动，但没有剥开。

## Terminal

外壳读取 // 肋距说明这是耐压模块，不是装饰残骸。完整密封槽意味着内部可能仍有干燥口袋。肋角的橙色漆标记服务入口；切割前先确认锁扣侧。

## Field Note

先读肋条，再读外板。外板更会骗人。
