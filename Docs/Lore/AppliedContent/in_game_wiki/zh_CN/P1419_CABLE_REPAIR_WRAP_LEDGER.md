# 电缆外护套维修缠绕账本

HECTON-8的电缆不是背景绳子。耐压电缆承诺两个地点仍然彼此重要：电力、信号、泵控制、传感器、舱门驱动、应急灯。当外护套失败，维修缠绕就变成了人们拒绝让连接死亡的短历史。

痕迹顺序很重要。边缘下有盐的灰色胶带是老维修，已经随海水呼吸。干净橡胶上的紧夹痕是后期干预。划痕下露出斜向纤维说明近期切割或拖拽。只有一侧磨损说明线路在张力下工作，而不是储存。高处固定、低处磨损的电缆说明维修后房间还移动过。

玩家应把包扎电缆当作路线证据。它可能指向仍工作的泵、隐藏终端、带电舱门、残余电流陷阱，或一间有人试图维持生命的死房间。把所有电缆切成废料很快。读出最后维修的是哪条，才是找到殖民地最后在意之物的方法。

## Scanner

维修缠绕 // 黑色橡胶电缆外护套、灰色胶带带、斜向纤维底层、缝里的盐、夹具压力痕。磨损集中在一侧：这条线是在供电时被拖动，不是库存。

## Terminal

电缆读取 // 切割前先数维修带。边缘下有盐的宽胶带是旧维修。没有盐的紧夹痕是后期干预。干净划痕下露出纤维，说明近期磨损。高处绑住、低处磨损的电缆说明房间移动时它仍在承载。

## Audio

死电缆很简单。维修过的电缆说明还有人需要另一端。

## Field Note

不要先切最新的缠绕。它通常指向最后被拯救的东西。
