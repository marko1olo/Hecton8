# 第一小时脊柱

第一小时不是从黑暗开始。它从合同声音、受损下降、呼吸管理、明亮浅水，以及重启水泵的实际需求开始。美丽是陷阱的一部分：HECTON-8 必须先显得值得渴望，然后它的 paperwork 才变得致命。开场路线把生存变成证据。第一个庇护房间有用但被污染；消毒过的事故包听起来太干净；第一道 Atlas 维修疤显示电缆、工具金属和活体残留被压成一道仍在工作的密封。

## Scanner

合同、受损投放、空气、明亮浅水、泵房庇护、消毒过的谎言，然后是第一道把生命当垫圈的维修疤。

## Terminal

## Audio
