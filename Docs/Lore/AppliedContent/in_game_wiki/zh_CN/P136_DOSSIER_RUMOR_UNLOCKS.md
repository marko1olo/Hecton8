# 档案传闻记忆

Marauder 档案不是储物箱。它是失败 claim 之后仍会留下的工作部分：中继里听到一半的名字，闻起来不对的合约条款，已经暴露的结局类别，用别人最后几分钟买来的警告。新的开局应该带来更敏锐的怀疑，而不是更好的潜艇。

## Scanner

档案记忆 // 传闻、警告、合约背景和结局记录会保留。船壳、氧气、工具、货物和地图不会。

## Terminal

持久化规则：档案可以跨战役保留传闻族、证据类别、结局标记和路线警告。它不得保留装备、资源、seed 地形或对真相的所有权。
