# 连·托雷斯，热口锻炉操作员

连·托雷斯操作热口锻炉，把HECTON-8的热变成小到能携带、危险到必须挂名的零件。他的档案由烧焦手套、循环计时器、废品托盘、压力玻璃试片和划有批次标记的密封环组成。托盘最重要：它证明坏件在教会下一道压力边界如何保持之前还不是废物。托雷斯把资源设定变成劳动设定。拾荒分类从这里开始：烧伤、延迟、带标签的失败，以及保存裂纹证据的决定。

## Scanner

档案：连·托雷斯。隔热手套、循环计时器和废品托盘对应同一批压力玻璃。

## Terminal

V-9热口锻炉 / TORRES, LIAN：废品托盘保留了裂开的密封环、浑浊压力玻璃和三块标记过热试片。批次备注：失败只有在保留标签时，才能教会下一道密封。

## Audio

托雷斯保留坏件。在锻炉里，干净地面意味着有人把教训扔掉了。

## Field Note

在热口锻炉道具、压力玻璃配方、废弃密封环，以及需要可见失败历史的升级台附近使用托雷斯。
