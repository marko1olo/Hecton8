# 净化事故回复窗口

净化事故回复窗口让 Deep Reach 在当下发声，却不会把公司变成全知者。它的第一个实时回答不是威胁，而是更安静也更糟的东西：一份旧公开解释，在新压力下被推入新频道。消息仍然说风暴增水、地质坍塌和自主撤离失败，因为这套脚本曾经保护过 Deep Reach，系统现在又伸手去抓它。玩家应该在发现物理矛盾之后才听到它：错误的舱门时间、坏掉的泵证、从 payroll 抹除中幸存的名字、损伤和天气不相符的房间。时机很重要。如果脚本先到，它只是说明。如果它在潮湿证据之后到来，它就是侮辱。Deep Reach 不是在和玩家所在的房间说话，而是在和它需要这个房间变成的那份干燥报告说话。

## Scanner

回复窗口开启。Deep Reach 重复风暴坍塌、地质失效和自主撤离失败，好像房间仍然干燥。

## Terminal

DR-LIVE WINDOW / PUBLIC LOSS LINE：风暴增水、地质坍塌、自主撤离失败 / RESTRICTED ADVICE：不要传输未验证 Atlas continuity、body-category disputes 或 basin-coordinate claims。

## Audio

他们回答的是你本该找到的房间，不是你正站着的房间。

## Field Note

放在第一个物理矛盾之后：玩家应先拥有潮湿证据，再听到陈旧公开脚本。
