# 玻璃虫，幼体

群落最厚的地方，后面的板材是裂的。

群落长在裂缝上，不是长在裂缝旁边，并在穿过裂缝的流量最强处变厚，所以最健康的一片标记着最严重的渗漏。每个管口都朝上游。读管口，你就能在不穿过裂缝的前提下拿到渗漏轴线。

群落是软的。它后面有22.9 MPa正对着一个干燥空腔工作，裂缝处的流入会在腕部把手套接缝撕掉。切开一片受载的群落，管子会依次破裂，沿板材跑出一串脆响。那一串就是裂缝在把自己的载荷拿回去。

44区登记的每一个个体都是幼体。2147年的勘测记下的也是同一阶段。

评估：从下游面采集；板材一响就离开板材。

## Scanner

## Field Note

“已缓解”的意思是虫在撑着它，不是有人修过它。你把一片削薄，打开9号舱段的人就是你。
