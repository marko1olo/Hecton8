# 资源栈

HECTON-8不是单一资源月球。早期材料让呼吸和修理成为可能。打捞物打开封闭路线。盐水和喷口化学教会压力。蓝债和压力玻璃在claim链条中更高，但它们的价值之所以成立，是因为较小材料让操作者活得够久，能抵达那里。

## Scanner

栈读取：礁纤维、盐水盐类、中继核心、压力阀、喷口催化剂、蓝债、压力玻璃、Atlas晶格。

## Terminal

价值模型：生存生物材料、人类打捞、路线硬件、压力化学、蓝债、压力玻璃、连续性基质。不要把资源栈压缩成单一奇迹材料。
