# 锚点工人姓名集 A

锚点工人姓名集 A 是玩家应该开始认出的第一层人类痕迹。Mara Venn、Juno Kade、Ren Okoye、Sahana Iqbal、Lian Torres、Oskar Neumann、Aya Morita 和 Pavel Sorn 属于浅层与工业陆架证据。他们的名字不应以传记出现，而应出现在储物柜标签、泵牌、航线许可、染污餐券、开裂工具箱上，然后在后来一份改变意义的记录里返回。Set A 在深层阴谋清晰之前，让殖民地先像有人住过和工作过。

## Scanner

早期姓名必须通过工作回来，而不是通过演讲回来。浅层路线用重复教会记忆。

## Terminal

ANCHOR SET A: 浅层和工业陆架的重复。每个名字应绑定一个工具、一个航线许可、一个损坏工作物件，以及一个后来的矛盾。这些名字是玩家第一次证明殖民地在成为可打捞物之前曾是工作场所。

## Audio

在工具告诉你原因之前，不要哀悼那个名字。

## Field Note

Set A 锚点: Mara Venn, Juno Kade, Ren Okoye, Sahana Iqbal, Lian Torres, Oskar Neumann, Aya Morita, Pavel Sorn.
