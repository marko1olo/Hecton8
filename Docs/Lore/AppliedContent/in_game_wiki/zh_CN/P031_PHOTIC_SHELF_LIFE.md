# 透光陆架生命

透光陆架是受损投放后遇到的第一条活体基线。Ran-Aegir的光抵达上层海水，陆架以矿物供养的生物膜、透明啃食者、pressureweed和路线藻回应。生物膜照亮岩石并维持小型氧气囊；玻璃啃食者把藻类刮成可读通道；pressureweed会在涌浪或捕食者运动抵达玩家前弯折；路线藻标出能把游泳者带回线缆或带离线缆的水流。这个区域必须美丽，因为HECTON-8确实值得被渴望。但它也必须危险：风暴、低能见度、浅水捕食者和断掉的回路线，都能在更深的电缆礁或Atlas修复组织出现之前，把明亮水域变成陷阱。

## Scanner

透光陆架生物群 // 已确认活体生物膜、玻璃啃食者、pressureweed和路线藻。明亮的水提供氧气和路线线索；它不会原谅坏天气、捕食者或丢失的回路线。

## Terminal

陆架调查：Atlas修复支配之外的原生透光生态。基线样本：氧气膜、透明啃食者轨迹、pressureweed弯折线、路线藻尾流。采集前与电缆礁生长和修复疤组织对比。
