# 焊缝与铆钉列账本

焊缝和铆钉列，是殖民地干净几何开始招供的地方。工厂船体线耐心重复：间距、倒角、密封垫、检查条。现场维修不是这种语气。它结巴、膨胀、压过旧漆，在发射图里不该有热的地方留下热痕。

顺序讲故事。后期焊道下面压着铆钉列，说明原来的固定已经不被信任。焊道下悬盐说明接缝不止一次呼吸过水。密封垫槽被金属半埋，说明有人选择强度而不是可维护性。干净焊道旁的撕裂板边通常说明很急：有时间封住泄漏，没有时间让船体诚实。

对打捞者来说，修补接缝有时比地图更有用。它指向漏过水的房间、被压力扭弯的隔壁、有工具却没有替换件的船员，或后来的回收队把同一处伤口重新打开，只是那时已经不叫维修。

## Scanner

船体接缝 // 水下鼓起的焊道、氧化铆钉列、撕裂维修板边、缝下盐痕。密封垫线被后加金属半埋。这不是工厂接缝。

## Terminal

读接缝 // 焊在密封垫上，说明密封受压后才维修。铆钉下锈蚀说明反复潮湿呼吸，不是一次进水。焊道顶端亮擦痕说明压力循环后有人用工具试过。
