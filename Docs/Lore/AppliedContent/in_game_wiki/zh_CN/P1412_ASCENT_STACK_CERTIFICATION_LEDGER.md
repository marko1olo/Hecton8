# 上升栈认证账本

上升栈是逃离过程中第一个像工程而不是祈求的东西。它不是魔法救援舱，也不是英雄火箭。它是一叠丑陋承诺：身体会保持密封，装药不会劈开壳体，制导ping会被听见，温度跃迁不会裂开套筒，上面有人同意接收结果。

HECTON-8会惩罚糟糕的向上运动。浅层发射可能淹死在自己的尾流里。深层发射能在载体看见之前，把密封缺陷变成刀线。压力并不在乎频道是否打开。海洋只问夹环是否坐稳，上升燃烧是否计量，制导托架是否在足够腐蚀后仍能说出胶囊去向。

认证让salvage变成进度。Marauder可以用殖民地硬件拼出一对环，用找到的装药质量填充燃烧弹匣，用捡来的线圈唤醒旧pinger。但这还不够，除非栈证明来源：密封来自哪里，承受过什么压力伤痕，谁测量了装药，哪个relay听见ping，receiver tag是否匹配检疫握手。Black Keel不需要它漂亮。它需要它可保险。

账本把模糊希望变成路线清单。密封。装药。Ping。热冲击裕度。接收方。每个词都指向玩家可以搜索、修理、偷取或证明的地方。证书完成时，claim window改变形状。它仍然不是善意。它只是机器承认，一个活体已经成为有效的质量预留。

## Scanner

ASCENT STACK认证 // 带燃烧污痕的压力套筒，一半纸质，一半陶瓷标签。认证字段：密封环对、上升装药、制导ping、热冲击裕度、接收方标签。缺两个戳。有人想用salvage做一架梯子，却在海洋评分前停下了。
