# 返还权利检疫握手账本

返还权利标签说明了为什么向上并不等于自由。它只是个小物件，常被绑在控制台上，或封在快递箱上，却承载了人们以为会自动发生的那部分救援。必须有人同意接收幸存者。必须有人接收样本、潜服、污染工具、数据包档案、保险留置权，以及随之而来的法律热量。

Aegir空间里的检疫不只是医学词。它是一个暂停点，用来在任何人能称返还为清洁之前，分拣生物、证据和所有权。一套压力服的缝里可能同时带着盐水孢子、热液化学、黑匣子记忆、Atlas痕迹、工人姓名、航线坐标和公司责任。握手要求每个权力机关签署不同的恐惧：疾病、压力失效、保管破裂、债务转移、公开暴露，或连续性污染。

接收方可以救命，也可以埋掉证人。Keelmark Mutual喜欢保住索赔价值的返还。Deep Reach喜欢能把记录关住的返还。public ledger公证人喜欢不能被安静改名的证据。Atlas连续性办公室喜欢不会让一台死机器看起来像人的载荷。它们不需要一开始就说谎。它们只需要在玩家抵达之前定义玩家是什么。

对Marauder来说，握手是杠杆。私人接收方可能更快，但会把身体和数据包锁进保管。公共接收方可能保护记录，却把坐标、姓名和幸存者暴露给每个有清理预算的人。检疫接收方可能让玩家活着，同时把人困在玻璃后面。没有干净答案。重要的答案在上升燃烧前选择，那时海还在外面，载体还没决定幸存者算什么。
