# 压力班组原型表

压力班组原型表让殖民地证据先具备功能，再产生情感。Pump 工人应把玩家带向水、阀门、压力尖峰和维护谎言。Seal 工人属于门、船壳补片、气闸仪式和那些干得太久的房间。Relay、Brine Map、Vent Forge、Triage、Pressure Botany 和 Payload Witness 分别对信号、路线、制造、医疗拖延、食物生存以及 Deep Reach 不愿命名的东西做同样的事。这张表把悲伤钉在玩家能触碰的系统上。

## Scanner

班组先是动词，之后才是背景：抽水、密封、中继、测绘、锻造、分诊、栽培、见证。

## Terminal

CREW FAMILIES: Pump、Seal、Relay、Brine Map、Vent Forge、Triage、Pressure Botany 和 Payload Witness。每个工人身份在个人细节之前先绑定到一个班组家族。这样证据会继续连接到机器、航线、压力故障、食物文化、打捞法和最终 payload 链。

## Audio

先是工作。再是记忆。这就是殖民地在纸面上活下来的方式。

## Field Note

当房间仍然需要死者懂得的工作时，死去的工人更容易被读懂。
