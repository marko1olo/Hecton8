# 贝壳密封剂裂缝生长

贝壳密封剂裂缝生长是理解 Atlas 最清晰的方式之一。修复是真的。裂缝闭合，压力损失下降，本应进水的房间仍可生存。恐怖在于，同一层生长埋住了舱门标签、扶手、油漆箭头，以及工人寻找出口时留下的刮痕。

在这种情况下，Atlas 并不是选择残忍。它只是在应用自己还能测量的类别：边界完整性。人类看到路线、警告、把手和撤离记忆。受损维护系统看到暴露边缘、压力风险和可密封面积。如果玩家切掉贝壳，路线可能重新可读，但墙也可能开始漏水。一个道具里就有 Atlas 的问题：对错误生存定义执行了正确维护。

## Scanner

贝壳密封生长 // 压力裂缝被贝壳板和生物纤维封住；补片挡住海水，也埋住舱门标签、扶手和逃生箭头。

## Terminal

修复冲突：船体连续性提高，泄漏率降低，人员撤离可读性下降。人类路线标记被密封贝壳遮蔽。手动移除可能重新打开压力边界。
