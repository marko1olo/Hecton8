# 测深声学现场指南

HECTON-8的深度不是数字，而是作业条件。透光陆架、电缆礁、盐水峡谷、机械原野和Atlas盆地都会改变浮力、信号距离、氧气负担、掠食者掩护和机器行为。

矿物水会杀死无线电，所以声音成为主要地平线。声学导管能把pinger送出数公里。盐水镜面会画出只是倒影的房间。阴影区能抹掉身边的信号。把声呐当证人，不要当判决。

## Scanner

声学场 // 陆架下无线电死亡。检查水层、导管、镜面和阴影区。一次干净ping只是一个证人。

## Terminal

水声说明 // HECTON-8用压力、盐和热弯折声音。切割、焊接或追随回波前，从另一个角度再ping。

## Audio

HECTON-8从不安静。问是什么发声，哪一层弯折了它，还有谁听见了它。

## Field Note

ping一次用于发现。ping两次用于怀疑。在海洋回答得过于清楚前移动。
