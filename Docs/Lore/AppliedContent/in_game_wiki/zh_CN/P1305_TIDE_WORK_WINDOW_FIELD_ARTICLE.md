# 潮汐工作窗口现场文章

HECTON-8 的海洋有工作时间。这句话听起来像笑话，直到舱门拒绝均压，脉冲器死在倾斜的盐水层里，或者十分钟前还开放的路线变成绞磨机。潮汐相位在这颗月球上不是背景天气。它会改变门的应力、泥沙负荷、声学距离、盐水层漂移、潜服压载、泵的值守负荷，以及母船能穿过 Aegir 噪声听见信号的少数干净角度。

Deep Reach 把这些条件压缩成一个礼貌的词：窗口。缓水窗口。泵窗口。提升窗口。中继窗口。通信黑窗。这种语言高效，而且有毒。它让物理上的怜悯听起来像日历格子，让失踪工人听起来像延迟执行。在板面上，一个名字可以被一笔油笔从放行划到延误，再划到扣留。

Marauder 学会把窗口读成现场语法。舱门边缘的白弧标记应力方向。脉冲器间隔会在路线变坏前拉长。盐水帘会在底流改变前倾斜。安静的中继器不一定坏了；有时只是月球站在错误阴影里，而法律队列仍在无声运行。

Great Tide 不是童话里的巨浪。它是太多工作窗口被当成可谈判事项后的最后堆叠：撤离被拖进负荷里，热排放顶着封闭排水，Atlas 连续性压过撤退，工人被留在物理学已经不再尊重的时间表里。

## Scanner

潮汐工作窗口 // 三只钟同意十二分钟：缓水、泵降、母船阴影。路线板说安全。墙壁说只是暂时。
