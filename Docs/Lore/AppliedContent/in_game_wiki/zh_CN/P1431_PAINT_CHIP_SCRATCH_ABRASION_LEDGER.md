# 漆面剥落、划痕与磨损账本

HECTON-8上的漆面剥落不是背景噪声。Deep Reach把压力模块涂成可读的维修颜色：白色外壳，深色底漆和石墨色导轨，橙色安全标记放在戴手套的人应该找到锁扣、拉杆或检查边的位置。几十年水下会磨掉标志、软化铭牌，但缺失的油漆会留下记录。

顺序很重要。缺口里有盐，说明裸露边缘长期和房间一起潮湿呼吸。边缘露出干净的深色底漆，说明近期工具或手套切开了旧矿物壳。锁扣周围的曲线弧不是随机擦伤，而是压力下反复开启的路径。直线石墨划痕可能是切割导线、被拖动的设备箱，或被当成支撑的面板。服务角附近的橙色碎片通常表示人的动作，不是天气。

对掠夺者来说，漆面缺失是一种路线工具。它能指出压力门安全的锁扣侧，证明某块面板在官方停机后仍被打开，或区分正常维修和后来的打捞干扰。太早剥掉油漆，证据就会变成废料。先读它，再决定这块板是材料、掩护、入口还是证据。

## Scanner

表面磨损 // 白色漆片脱落，露出深色底漆、石墨色划痕簇，以及锁扣弧线附近的橙色安全漆碎片。盐留在旧缺口里；明亮裸边只出现在受拉一侧。首次进水后有人处理过这里。

## Terminal

磨损读取 // 漆面缺失要按层读取。漆片下有盐，说明旧暴露。边缘干净底漆，说明近期工具接触。锁扣弧线表示反复开启；直线石墨划痕表示导向切割或拖过的工具箱。剥取材料前先记录图案。
