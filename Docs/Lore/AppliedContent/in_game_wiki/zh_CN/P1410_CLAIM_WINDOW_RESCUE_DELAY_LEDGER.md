# 索赔窗口救援延迟账本

这本账本恶心，是因为它看起来像在帮忙。它带有Black Keel的回收频道戳、Keelmark Mutual的质量窗口表，还有一枚小小的绿色授权标记，足以让绝望的人把第一行读两遍。频道是开的。载体能听见数据包。合同承认活着的承包人。可这些文字没有一行承诺会有船壳穿过海水下来。

Aegir索赔法把接触和回收分开。接触是信号；当天空、海洋和载体队列允许时，它能通过本地中继。回收是质量。一个承压身体需要密封上升路径、额定装药、制导时机、检疫许可，以及一个愿意继承幸存者带回之物的接收方。穿过这个窗口的每一公斤，都要和样本保管、备用硬件、保险暴露，以及已经在队列中的Deep Reach条款竞争。

所以Black Keel的第一个回答听起来如此下流。机器可能有用，甚至可能在技术上诚实。它可以开通频道、给返还定价、列出缺项，而且速度比救任何人都快。Keelmark不需要憎恨玩家。它只需要按旧顺序问旧问题：返回的是什么质量，盖谁的封印，污染等级是什么，如果回收的身体携带的是证据而不是货物，谁来付钱？

Marauder会把这本账当成工单读。建起中继脊柱。认证夹环。找到不会在压力下碎裂的上升能量。拿到检疫法律握手。决定载荷是坐标、证据、Atlas连续性、公共账本材料，还是沉默。HECTON-8不是没有救援。救援被逐项列出，被推迟，等待玩家变得足够便宜、足够有用，或足够危险，值得移动。
