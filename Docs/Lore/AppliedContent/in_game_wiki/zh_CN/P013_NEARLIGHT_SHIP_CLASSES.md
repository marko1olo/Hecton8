# 近光速船级

近光速船在不打破物理的情况下建立了人类空间。探针先到，然后是seed ship、mass carrier、sleeper transport、本地system carrier、拖船和维护母船。这个尺度解释了Black Keel为什么是本地基础设施，而不是个人逃生游艇。

## Scanner

转运清单列出needleprobe、seed ship、mass carrier、sleeper transport、system carrier。

## Terminal

No FTL lane registered. Transit class requires launch infrastructure, braking plan, shielding mass, and route custody.

## Audio

一艘船可以跨越恒星，却仍对被淹房间毫无用处。

## Field Note

船不是自由。船是带发动机的时间表。
