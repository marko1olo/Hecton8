# Atlas访问边界

早期可以把Atlas讨论为受损的工业连续性。它试图让压力路线、记录、机器和开采硬件不掉出链条。令人不安的部分开始于修复路径穿过活体或半活体材料时：跨过电缆断口的导电生物膜、中继管里的声学组织、覆盖裂缝的壳质密封、把路线状态反馈进传感器的带标记动物。最终接收者层保持封锁，因为它会改变动词。密封、保存、切断、隔离和释放在保管证据恢复后不再中立。
