# 轮班队，不是英雄

HECTON-8 应先通过工作而非悲剧让殖民地具有人性。压力技师更换阀门垫圈，厨工记录水代币，路线文员盖错返回戳，潜水员签出切割器后再也没有签回：这些细节让人可读，不需要强行塞入家庭复仇线。沉没殖民地最有力的时候，是它像一个在日常中被打断的地方，而不是死后修建的博物馆。
