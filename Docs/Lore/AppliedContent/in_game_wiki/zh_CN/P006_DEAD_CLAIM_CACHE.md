# 死亡索取缓存

死亡索取缓存证明玩家不是第一个追着钱来到HECTON-8的掠夺者。这些缓存位于常规测绘路线以下：塞在服务管线下的干袋，刻在压载物上的私人索取标记，包在油纸里的氧片，还有被颤抖的手修改过的地图。它们的价值不在装备。它们的价值在时间顺序。2147年的失事之后、玩家下潜之前，独立船组已经下到这里，找到穿过淹没基础设施的部分路线，然后消失在让殖民地保持沉默的同一片黑暗里。

## Scanner

隐藏的现场缓存。干燥封装，低位绑牢，用一根切断的系绳和一张把安全写得太多次的地图标记。

## Terminal

缓存备注：北管下方路线安静，直到灯栅醒来。蓝色箱体保持封存。不要在峡谷阴影内回应carrier ping。如果系绳被切断，把这份缓存算作继承来的麻烦。

## Audio

这不是Deep Reach装备。另一个专业人士带着切割器、烂地图和不该拥有的希望下到了这里。

## Field Note

有人在你之前抵达这条峡谷，学会了足够多来藏装备，却没有学会足够多来干净离开。
