# 铁珊瑚

它只长在金属上。开阔淤泥里的一丛，能标出下面埋着什么。

颜色读基材：结构钢上是铁锈红，机用合金上是灰黑，下面板材含微量XO的地方是暗蓝。

骨架比Class-IV的掌板硬。在一丛上拖两个班就会磨开手套接缝，而在你弯手之前，它不会读成泄漏。

裂缝上的结壳比200 mm外完好板材上的结壳厚三倍。它桥住焊缝的地方，那道焊缝就再也没法检查。

产出就是结壳本身，最厚处最富。带着结壳切下来的板材按毛重计费，而4.8吨的额度不列明细，所以在残骸边上敲，不要在Keel上敲。

## Scanner

铁质基材上的矿化群体生长。金属回波强。置信度77%。危险：磨蚀手套接缝。限制：结壳与基材作为同一质量返回。

## Terminal

化验批次 44-N-118。类别：可回收矿物，品位待定。基材：结构钢，来源未确定。焊缝12至19：被覆盖，检查已关闭。质量按毛重计入。窗口：KEELMARK 损失台。

## Field Note

“质量按毛重计入”的意思是结壳算在你的额度里，差额归窗口。断口出来是蓝的，那不是品位，那是蓝色债务，你要在动手之前先上报。
