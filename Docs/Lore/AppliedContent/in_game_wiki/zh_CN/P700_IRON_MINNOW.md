# 铁鲦鱼

读的是鱼群的形状，不是鱼。散在开阔水里的时候它们没有意义。压成两到三米厚的一条平带时，它们守着一个氧气囊的边缘。

一条平整的带还剩一两个班次；一旦散开，在那里吃东西的都会跟着走。

已知矿脉上方出现空带是相反的读数：囊已经翻了，水会发绿，那里已经几周没有东西进食。

鳞上的铁质砂粒在扫描上回波强到能把身后的一切抹掉。要透过鱼群读墙，先把增益调下来。

这些砂粒的化验结果是船体板，不是矿脉里的矿石。

评估：沿带的上缘走，绝不穿过带里，空气自己带。

## Scanner

密集集群觅食种，体表附铁质微粒。置信度91%。危险：无。限制：远距离上鱼群回波遮蔽结构。读墙之前先降增益。

## Terminal

样品批次 44-XO-0091。类别：微量化验，附带。方法：鱼群密度，陆架网格 0至100 M。品位：微量，临界可采。吨数依据：结转至索赔清单。

## Field Note

衡量你留置权的那个吨数，是2146年在陆架网格上数这些鱼估出来的，化验此后一次也没重做。带只告诉你好水在哪里到头。空气还是从你付过账的气瓶里来，而这个数字对矿石毫无用处。
