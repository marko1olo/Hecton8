# 缺失返程标记与索赔转换

返程标记用来关闭路线。它不证明工人安全，只证明路线台不再把那名工人计为移动中。标记可以是返程勾、取消斜线、医疗转移、回收例外或损失代码。没有这些，路线在行政上保持开放。

开放路线是危险证据。Deep Reach可以指着它说：工人仍在分配中，仍可联系，仍属于活动作业。房间可以证明相反。冷掉的潜服标签、割断的系缆、氧气停止的分诊行、路线窗口后的舱门刮痕，都能把空返程栏变成保管链失败。

后来的台面利用开放路线重新分类载体时，索赔转换就发生了。转录不再是求救记录，而变成可回收质量、污染设备、可计费延迟或打捞财产。缺失返程标记不解决死亡。它显示文书拒绝关闭死亡的位置。

现场处理很直接。清盐前保留戳记。把开放路线同氧气截断、潜服标签、分诊行和packet notary遮盖对照。如果身体证据已经关闭，路线仍保持开放，台面保护的是索赔，不是工人。
