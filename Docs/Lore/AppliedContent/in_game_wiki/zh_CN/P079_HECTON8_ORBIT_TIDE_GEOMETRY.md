# HECTON-8轨道 / 潮汐几何

HECTON-8的轨道让Great Tide在成为政治事件前就可信。共振拉动海洋。冰应力和风暴增水压住陆架。工业热与堵塞排水让殖民地系统在错误时刻反推。
