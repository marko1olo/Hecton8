# 光延迟下的包托管

在HECTON-8找到真相，是最容易失败的一步。终端还能启动，徽牌还能带着名字，潮湿的摄像卷轴还能显示谁被锁在压力门后面。但这些本身不是证据。直到数据包拥有源时钟、哈希、第二见证，以及不在索赔方手中的托管路径之前，Black Keel都可以把它当成打捞质量，Deep Reach也可以称它为受污染的项目材料。

旧人类边疆把延迟做成法律。没有FTL回复，海面上方也没有活法庭。一个有用的数据包必须熬过本地中继窗口、Black Keel队列、一张Luyten Packet Ladder收据，以及如果需要伤到Deep Reach，还要熬到Tau Public Ledger Lane这样的接收方。链条故意枯燥：时钟、副本、封印、队列、收据。断掉一环，同一个真相就会变成样本、传闻或责任文件。

Deep Reach知道这一点。Recovery Compliance不需要删除每份文件。它只要污染路径：把载荷标成隔离材料，质疑时钟，要求原始托管，把质量窗口定价过高，或在公共接收方看到之前把数据包转进Keelmark。Marauder不是在收集博物馆材料。Marauder是在努力让淹没的殖民地先被算作人，再被索赔系统算作材料。

优秀的Marauder会把丑陋证据保存成两种形态：一份足够干净，可以交给公证；一份足够脏，可以证明它在哪里被找到。前者推动案件。后者阻止公司声称真相到达时没有地点、没有压力状态、背后也没有身体。
