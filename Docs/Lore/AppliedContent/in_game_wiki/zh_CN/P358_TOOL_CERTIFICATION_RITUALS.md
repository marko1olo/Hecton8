# 工具认证板

如果误读殖民地，工具认证板看起来会像某种仪式。这里没有神秘主义。重复的印章、油性铅笔缩写和红色保留标记，是工人在下潜前把恐惧变成流程的方法。切割头不是因为看起来锋利就被信任。密封剂筒不是因为标签写着满就被信任。压力手套必须由两个人签名，其中一个还要穿下一只手套，才算可信。

这形成了一种文化。泵技师、密封索具工、盐水潜工、制造机操作员和路线文员都依赖工具，而这些工具只要差一点点正确，就可能悄无声息地杀人。他们的“仪式”是重复：称重、检查、签名、归还、复检。它也是社会压力。迟还的泵钥匙不会变成道德演讲。它会变成板上的标记、被保留的下潜套件、被拉回复检的工人；如果延误消耗了水，之后还会变成食堂争执。

对掠夺者来说，这块板先是实用信息，然后才是美。它说明哪些工具被信任，哪些路线被推迟，哪些警告在房间淹没前没有被擦掉。不要把签名当装饰。双签名压力手套可以把工人与路线连起来。迟还钥匙的标记可以把铺位板连到泵房工单。被扣留的切割器可以解释为什么某扇密封门仍然存在。认证，就是殖民地让信任可见的方式。
