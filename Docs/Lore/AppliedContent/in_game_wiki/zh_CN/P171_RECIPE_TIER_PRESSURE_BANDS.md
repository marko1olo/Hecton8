# 配方层级压力带

配方层级压力带是 HECTON-8 制作系统背后的语法。殖民地不是按方便程度划分配方，而是按玩家离开工作台后压力会对零件做什么来划分。Tier 0 让玩家在浅层活下来，靠补片、手工密封，以及会诚实坏掉的打捞件。Tier 1 属于额定维修，需要泵房部件、旧工业库存和证明物件能承载工作的认证标记。Tier 2 进入压力硬件领域，盐水清洗、热泉固化和声学证明决定一个组件是安全的，还是只是长得像组件。Tier 3 属于上升、Atlas接口和深渊权限：配方需要材料，也需要接收端状态、法律保管和封存证明。这样制作就被绑在路线逻辑上。问题从来不只是你拥有什么，而是它去过哪里、能承受什么压力、谁会接受结果。

## Scanner

HECTON-8 的配方不是购物清单，而是一段关于深度的论证。零件必须撑过它声称的压力带，才算零件。

## Terminal

配方压力带 / T0 生存补片：浅层打捞、手工密封、无保管链 / T1 额定维修：货架工业件、泵房认证 / T2 压力硬件：盐水清洗、热泉固化、声学证明 / T3 上升或Atlas作业：深渊来源、合法接收端、封存收据。

## Audio

配方就是一张带螺栓的深度许可证。

## Field Note

配方层级必须匹配压力评级、路线成本和保管风险。错误压力带里的廉价螺栓并不廉价；那只是未来的漏点。
