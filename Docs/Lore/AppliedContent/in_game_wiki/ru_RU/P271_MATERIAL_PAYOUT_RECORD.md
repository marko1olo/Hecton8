# Запись материальной выплаты

Запись материальной выплаты — это квитанция платного финала. Keelmark/Recovery Compliance принимает координаты бассейна, образец синего долга и хэш хранения перевозчика, после чего снижает или закрывает залог оператора. В той же квитанции свидетельские материалы, имена рабочих и учет спасательной массы остаются вне нотариального хранения, а Deep Reach получает более чистый путь обратно к HECTON-8, чем похороненная смена.

## Scanner

ЗАПИСЬ МАТЕРИАЛЬНОЙ ВЫПЛАТЫ // Keelmark/Recovery Compliance приняла координаты бассейна и образец синего долга. Залог оператора снижен; доказательства по рабочим остались вне нотариальной цепочки.

## Terminal

ЗАПИСЬ ФИНАЛА / МАТЕРИАЛЬНАЯ ВЫПЛАТА
Получатель: Keelmark/Recovery Compliance.
Принято: координаты бассейна Atlas, образец синего долга, хэш хранения перевозчика.
Не приложено: нотариальный свидетельский пакет, реестр имен рабочих, аудит спасательной массы.
Эффект по залогу: снижен или закрыт по контрактной таблице.
Эффект для Deep Reach: более чистый обратный путь к HECTON-8.
Известная потеря: доказательство можно оценить в деньгах и не выслушать.

## Field Note

Квитанция закрывает графу залога, а не помещение. Имена, не попавшие в хранение, после выплаты не появляются.
