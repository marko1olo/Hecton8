# Вера Сато-Рен: возвратное действие

Вера Сато-Рен — подпись Офиса восстановительного соответствия от 2190 года, которая дает современному Deep Reach лицо, не делая компанию физически вездесущей. Она действует через пакеты, окна опеки, оговорки перевозчиков и задержанные инструкции. Давление процедурное: восстановить координаты, подтвердить XO-цепочку, сообщить состояние доступа к Atlas, сохранить молчание подрядчика, если payload все еще можно контролировать.

Язык возвратного действия опасен тем, что может звучать как помощь. Спасение остается возможным, но только после опеки payload. Помощь может быть предложена, но только пока риск раскрытия доказательств управляем. Marauder, читающий пакет, не слушает крик злодея. Его сверяют с окном, которое закрывается независимо от ответа.

Для игрока Сато-Рен превращает Deep Reach из исторической вины в настоящее давление. Старая колония — не только могила. Это активная площадка претензий. Каждая восстановленная запись может стать доказательством, выкупом, пунктом молчания или весом сделки в зависимости от того, кто получит ее первым. Вот современная угроза Deep Reach: не чистый вражеский флот, а юридическая ячейка давления, пытающаяся завладеть возвратом до того, как правда выйдет из воды.
