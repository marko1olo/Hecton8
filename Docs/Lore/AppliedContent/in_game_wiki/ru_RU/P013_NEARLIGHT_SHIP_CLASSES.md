# Классы околосветовых кораблей

Околосветовые корабли построили человеческую сферу, приняв, что физику нельзя уговорить. Первыми шли needleprobes: узкие, экранированные, достаточно дешевые для потери. За ними шли seed ships с машинами, геномами, маршрутными инструкциями и строительными привычками, переживающими годы холодного ожидания. Грузовые Atlas перевозили дорогую массу: заводские ядра, sleeper-отсеки, ледовую защиту, радиаторы, буровые системы и контракты, которые к пробуждению части экипажей уже стали старыми.

Класс важен, потому что каждый ломается по-своему. Зонд может погибнуть с пользой. Seed ship может прийти без свидетелей. Sleeper transport может сохранить тела, превращая труд в хранение. Системный tender может работать внутри Aegir и все равно не быть вызванным из ядра по приказу. Black Keel — не свобода с двигателями; это машина возврата, где масса, карантин, страховка и доказательство считаются в одном реестре.

Ни один класс не ломает свет. Лучевые паруса, pellet lanes, fusion-electric горловины, защитный лед, magsails и приемные окна делают перелет возможным, а не легким. Прибытие — жестокая половина. Без владельца торможения ничто не приходит полезной массой.
