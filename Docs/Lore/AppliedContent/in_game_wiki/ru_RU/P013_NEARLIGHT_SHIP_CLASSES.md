# Классы околосветовых кораблей

Околосветовые корабли построили человеческую сферу, не ломая физику. Первыми пришли дешевые игольчатые зонды, потом корабли-засеватели и носители Atlas с фабриками, спящими, контрактами и защитной массой.

Таблица классов отделяет владение от спасения. Aegir может быть заявлен человеческим правом и все равно оставаться труднодостижимым для живых тел.
