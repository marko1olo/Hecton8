# Классы околосветовых кораблей

Околосветовые корабли построили человеческое пространство, не ломая физику. Сначала пришли probes, потом seed ships, mass carriers, sleeper transports, локальные system carriers, tugs и tenders. Их масштаб объясняет, почему Black Keel - локальная инфраструктура, а не личная яхта для побега.

## Scanner
