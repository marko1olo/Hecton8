# Финальный вопрос: продажа места преступления

Продажа места преступления — материальная ось успеха. Оператор может выжить, закрыть долг и уйти с деньгами, потому что Keelmark/Recovery Compliance признает координаты, ценность образца, доказательство XO и хэш хранения перевозчика. Важна отсутствующая строка: без отдельного свидетельского пакета имена рабочих, учет спасательной массы и ответственность Deep Reach не попадают в платную квитанцию.

## Scanner

ОСЬ ПРОДАЖИ МЕСТА ПРЕСТУПЛЕНИЯ // Keelmark может закрыть залог за координаты бассейна Atlas, образец синего долга, свидетельское доказательство XO и хэш хранения перевозчика. Доказательства по рабочим не попадают в квитанцию без отдельного нотариата.

## Terminal

ФИНАЛЬНАЯ ОСЬ / ПРОДАЖА МЕСТА ПРЕСТУПЛЕНИЯ
Получатель: Keelmark/Recovery Compliance.
Принято: координаты бассейна Atlas, пригодный образец синего долга, свидетельское доказательство XO, хэш хранения перевозчика.
Эффект по залогу: долг оператора закрыт или снижен по контрактной таблице.
По умолчанию отсутствует: реестр имен рабочих, аудит спасательной массы, публичный свидетельский пакет.
Преимущество Deep Reach: геометрия возврата и оценка образца приходят без враждебной цепочки хранения.
Известная потеря: карта могилы может стать имуществом раньше, чем станет свидетельством.
