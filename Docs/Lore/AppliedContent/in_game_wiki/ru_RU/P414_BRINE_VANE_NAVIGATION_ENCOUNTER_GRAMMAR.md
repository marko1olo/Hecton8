# Грамматика встречи: навигация по рассольным лопастям

Навигация по рассольным лопастям учит, что вода средних глубин построена, а не пуста. Игрок должен читать поле лопастей как поврежденную лестницу: целые листы — стены, рваные устья — возможные проходы, завитые концы — ослабевающий сдвиг, а черные провалы без видимого края лопасти — места, где sonar может выдумать пол. Встреча должна требовать медленного движения, осторожного трима плавучести и смены угла, а не прямого рывка к самому красивому свечению. Atlas может использовать ту же границу плотности для repair routing, но течение остается физикой. Это различие важно. Океан не говорит. Он делает процесс видимым. Хороший маршрут по лопастям позволяет игроку вести один край, ping со второго угла, проверять дрейф и чувствовать себя умным за отказ от открытого shortcut.

## Scanner

Поле рассольных лопастей. Совпадающие листы отмечают повороты плотности; завитые концы — слабые окна; sonar коробится возле открытого свечения. Держи один край в поле зрения.

## Terminal

ГРАММАТИКА ВСТРЕЧИ / НАВИГАЦИЯ ПО РАССОЛЬНЫМ ЛОПАСТЯМ / роль: грамотность маршрута на средних глубинах, поручень плотностной стены, исправление ложного пола / безопасное чтение: целый край лопасти, рваное устье, изгиб sonar совпадает с дрейфом плавучести / отказ: пересекать черную открытую воду, резать лист-проводник, доверять возврату пола без границы лопасти / маршрутная заметка: лопасть ведет не намерением; она достаточно громко подчиняется воде, чтобы за ней идти.

## Audio

Лопасть не указатель. Это вода делает стену и оставляет шов.

## Field Note

Считай край лопасти поручнем. Если линия гнётся неправильно, показание плавучести уже опоздало.
