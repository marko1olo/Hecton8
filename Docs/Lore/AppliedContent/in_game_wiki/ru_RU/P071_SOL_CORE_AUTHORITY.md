# Полномочия Sol Core

Sol Core - юридический и финансовый корень человеческой экспансии, но не личная родина и не служба спасения. На HECTON-8 его стандарты уцелели как печати, формы ответственности, таблички безопасности и страховой язык, переживший людей, которых эти системы должны были защищать.
