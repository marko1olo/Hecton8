# Конверсия потерь при сохранении претензии

Цепочка заканчивается на реестре, потому что реестр способен пережить все остальное. Работники становятся невосстанавливаемой потерей, поврежденные модули - хранением материала, а доказательства остаются привязаны к претензии. Носитель этих документов несет не сентимент. Он несет проблему для каждого получателя, который хочет претензию без тел.
