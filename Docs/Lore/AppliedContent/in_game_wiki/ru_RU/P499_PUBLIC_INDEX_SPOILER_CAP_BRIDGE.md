# Правило редактуры публичного индекса

Строка публичного индекса — это запись контроля доступа, а не краткое содержание. Она может показать семейство досье, линию хранения, тип доказательства, флаг редактуры, шлюз сканера и следующий предмет, который нужен для открытия пакета. Этого хватает, чтобы вести поиск и не раскрывать получателя.

Скрытые поля важнее заголовка. Цепь получателей, финальные координаты, состояние груза, ответ Atlas, давление на финал и юридический результат остаются за печатью редактуры, пока маршрут их не заработает. Если индекс слишком рано печатает адрес получателя, он не объясняет дело; он сливает маршрут всем, кто смотрит в зеркало.

## Scanner

РЕДАКТУРА ПУБЛИЧНОГО ИНДЕКСА // Видно: семейство досье, линия хранения, тип доказательства, флаг редактуры, шлюз сканера, следующий предмет. Скрыто: цепь получателей, координаты, состояние груза, ответ Atlas, юридический результат.

## Terminal

ШТАМП РЕДАКТУРЫ ПУБЛИЧНОГО ИНДЕКСА
Показывать: заголовок, семейство досье, линию хранения, тип доказательства, флаг редактуры, шлюз сканера, следующий предмет доказательства.
Скрывать: цепь получателей, финальные координаты, состояние груза, ответ Atlas, давление финала, юридический результат.
Сбой: адрес получателя виден до порога хранения.
Действие: держать поля маршрута запечатанными, пока хэш пакета и предметная улика не совпадут.

## Audio

Строка индекса открыта. Строка получателя — нет. Если видны обе, кто-то уже сжег маршрут.

## Field Note

Используй индекс, чтобы выбрать следующий предмет-улику. Видимая категория — еще не хранение, не приговор и не пункт назначения.
