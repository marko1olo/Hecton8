# Ограничитель спойлеров публичного индекса

Публичный индекс нужен, чтобы архивом можно было пользоваться, не сжигая маршрут. Заголовок может назвать семейство доказательства: маршрут хранения, класс доказательства, состояние редактуры, язык истца, шлюз сканера. Этого достаточно, чтобы игрок понял, за каким типом правды идет и почему соседний пакет важен.

Индекс не должен раскрывать, кто получит груз, где закончится маршрут, в каком состоянии груз, что с ним сделает Atlas, какую ветку финала он давит и какой юридический результат последует. Эти смыслы принадлежат заработанному пути доказательств. Если заголовок раскрывает строку получателя, индекс перестает быть архивом и становится машиной спойлеров. Правильное публичное обещание простое: эта полка существует, последняя страница закрыта.

## Scanner

ОГРАНИЧИТЕЛЬ СПОЙЛЕРОВ // Видно: маршрут хранения, класс доказательства, состояние редактуры, язык истца. Скрыто: цепь получателей, координаты, состояние груза, последствие Atlas, ветка финала, юридический результат.

## Terminal

ШТАМП ОГРАНИЧЕНИЯ ПУБЛИЧНОГО ИНДЕКСА
Показывать: название категории, маршрут хранения, класс доказательства, состояние редактуры, шлюз сканера, следующую цель доказательства.
Скрывать: цепь получателей, финальные координаты, состояние груза, последствие Atlas, ветку финала, юридический результат.
Правило: показать полку, замаскировать последнюю страницу. Публичный индекс говорит, какое доказательство существует, а не что оно сделает в конце маршрута.

## Audio

Название категории - это ярлык полки. Не получатель, не приговор и не последняя дверь.

## Field Note

Названия категорий путешествуют дальше тел. Читай полку, но не делай вид, что полка - последняя страница. Если последняя страница бесплатна, маршрут уже кто-то продал.
