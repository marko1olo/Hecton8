# Цепочка фрагментов служебки об ответственности

Цепочка фрагментов служебки об ответственности учит игрока читать доказательства Deep Reach. Ни одна служебка не содержит преступление целиком; каждый офис сохранил предложение, которое делало его действие процедурным. Таблица риска признает, что приливный запас проваливался. Заметка об эвакуации превращает задержку в дисциплину канала. Override Atlas заставляет непрерывность звучать безопаснее побега. Фрагмент Keelmark превращает пропавших рабочих в возмещаемый убыток. Игрок должен сверять бумагу с затопленными комнатами, сломанными маршрутными часами и именами рабочих. Цепочка становится читаемой только тогда, когда фрагменты перестают защищать свои офисы и начинают противоречить друг другу.

## Scanner

Служебка об ответственности выжила фрагментами, потому что каждый офис сохранил абзац, защищавший именно его.
