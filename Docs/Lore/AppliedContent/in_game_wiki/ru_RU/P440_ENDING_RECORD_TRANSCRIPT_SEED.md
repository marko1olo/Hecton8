# Транскрипт финальной записи

Транскрипты финальных записей делают исходы логируемыми и сравнимыми при replay, не превращая знание в наследуемую силу.

## Scanner

Фрагмент финальной записи перечисляет приемника, hash payload, состояние долга и нерешенную цену.

## Terminal

AFTER-ACTION RECORD: receiver accepted; payload hash retained; claim closed for accounting; truth state unresolved; suppression flag unknown.

## Audio

Послеоперационная запись. Приемник принял hash payload. Claim закрыт для учета. Флаг подавления нечитаем. Custody правды не решена.

## Field Note

Финальная запись dossier. Должна называть receiver, custody и нерешенную цену, а не чистое моральное закрытие.
