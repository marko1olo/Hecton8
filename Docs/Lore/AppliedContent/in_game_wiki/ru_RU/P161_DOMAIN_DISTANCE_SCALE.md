# Шкала дистанций доменов

Шкала доменов - это карта давления, а не туристическая карта. Sol Core все еще может сертифицировать собственность издалека. Centauri может сделать старую хартию чистой на вид. Barnard может дать резак и долгового Marauder для грязной работы. Tau Ceti может вынести доказательства в публичный контур после задержки. Luyten может доказать цепочку custody. Ran/Aegir - место, где все эти далекие силы становятся водой над шлемом.

Поэтому HECTON-8 ощущается одиноким без пустой вселенной. Сообщение может пройти маршрут и все равно прийти после того, как кислород, прилив, температура корпуса и окно recovery у Black Keel уже приняли свои решения. Дистанция не стирает закон. Она делает закон холоднее спасения.

## Scanner

ПЛИТА ДОМЕННЫХ ДИСТАНЦИЙ // Sol, Centauri, Barnard, Tau Ceti, Luyten и Ran/Aegir здесь не декорация. Это задержка, custody, масса, доказательства и цена спасения.

## Terminal

DOMAIN SCALE // Ran/Aegir считается целью класса примерно 10,5 светового года от Sol, пока финальные эфемериды не заменят диапазон. Нет FTL-вектора помощи. Нет мгновенного ответа. Маршрутное право приходит раньше живых людей.
