# Запись сохранения карантина

Запись сохранения карантина — приказ удержания для лучшего из поврежденных финалов. Полезная нагрузка не попадает в прямое хранение Deep Reach, координаты остаются закрытыми, а частичная квитанция держит внешнее давление живым. Atlas продолжает дышать через поврежденную ремонтную логику: это защищает экологию давления и выжившую ремонтную жизнь, но оставляет имена рабочих, ответственность бассейна и будущие salvage-подачи нерешенными.
