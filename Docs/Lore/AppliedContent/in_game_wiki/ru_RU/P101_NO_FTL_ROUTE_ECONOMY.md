# Экономика маршрутов без FTL

К 2190 году человеческое пространство держится на медленных кораблях, релейной опеке, окнах торможения и долге. HECTON-8 находится за пределом немедленного спасения. Закон может прийти пакетами; корабли приходят только с массой, защитой, топливом, тормозной архитектурой и тем, кто готов оплатить рейс.
