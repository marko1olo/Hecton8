# UI-копия маршрутных предупреждений

UI-копия маршрутных предупреждений задает короткую грамматику PDA, scanner и terminal surfaces.

## Scanner

Предупреждение, которое не меняет поведение, является декором.

## Terminal

ROUTE WARNING: назови что сломалось, что ухудшится и что игрок еще может сделать.

## Audio

Плохая новость полезна только если пришла до поворота.

## Field Note

Pattern: [failure] + [route cost]. Example: Relay shutter: return call may miss carrier window.
