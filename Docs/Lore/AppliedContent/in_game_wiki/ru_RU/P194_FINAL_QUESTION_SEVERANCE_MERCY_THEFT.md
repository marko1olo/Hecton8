# Финальный вопрос: отсечение, милость, кража

Отсечение режет ремонтный слой Atlas-океан, а не один выключатель. Оно может остановить поврежденную логику категорий и закрыть Deep Reach живой путь возврата. Оно же может заставить vent micronodes замолчать, оборвать импульсы shell sealant, бросить маршруты помеченной фауны, повредить буферы записей рабочих и оставить напорные комнаты без системы, которая держала их герметичными. Груз отсечения должен сохранить proof-hash, потому что после темноты в комнате этот поступок будут оспаривать.

## Scanner

ОСЬ ОТСЕЧЕНИЯ // Разрыв непрерывности проходит через ремонтный слой Atlas: двери давления, проводящую пленку, буферы записей рабочих, маршруты помеченной фауны, vent micronodes и пути груза. Состояние доказательств меняет ярлык хранения.

Эффект для получателя: маршрут Deep Reach закрыт, если не выжил отдельный путь груза.

Известная потеря: один и тот же разрез может быть спасением, ущербом, саботажем или кражей в зависимости от состояния доказательств.
