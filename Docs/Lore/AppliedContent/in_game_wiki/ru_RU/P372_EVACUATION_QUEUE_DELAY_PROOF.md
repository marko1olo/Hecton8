# Запись задержки эвакуационной очереди

Эта запись превращает эвакуацию из пропавшего результата в упорядоченную задержку. Сначала тревога, затем рассмотрение, затем превышение класса уплотнения, затем слишком поздний выпуск. Deep Reach может назвать эвакуацию неполной; часы очереди показывают шлюз, удержанный процедурой после перехода давления за безопасную линию.
