# Шкала Населения И Власти

Числа населения остаются приблизительными, потому что справочная перепись не решает, кто выживет. Полезный вопрос проще: кто может действовать на тело издалека? Переполненный внутренний домен может касаться HECTON-8 только строкой сертификации. Малый depot может быть важнее, потому что держит опеку пакетов. Мертвая frontier-оболочка может оказаться важнее всех, потому что владеет железом в комнате.

Это ощутимая шкала власти. Sol может решить, что объект кому-то принадлежит. Centauri может сделать старый язык Deep Reach приличным. Barnard нормализует работу, которая ловит мародеров. Tau Ceti может превратить доказательство в публичное давление - слишком поздно для кислорода, но не слишком поздно для последствий. Luyten может доказать цепочку сообщений. Aegir - место, где подписи становятся давлением, водой, запертыми люками и оплачиваемой массой.
