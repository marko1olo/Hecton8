# Окно полезной нагрузки

Окно полезной нагрузки — место, где финальные выборы становятся физическими. Игрок может провести через давление, штормовое прикрытие, радиационное время Аегира и геометрию восстановления Black Keel только ограниченную массу. Деньги, доказательства, имена работников, координаты, живые образцы, сигнал Atlas или молчание не могут уйти вместе.

## Scanner

Импровизированный пакет подъёма. Он может покинуть океан, если совпадут масса, погода, дозовое время и геометрия Black Keel.
