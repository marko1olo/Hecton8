# Окно полезной нагрузки

Окно полезной нагрузки - место, где концовки становятся физическими. Игрок может провести через давление, погоду, радиационное окно и геометрию Black Keel только ограниченную массу. Деньги, доказательства, имена, координаты, живые образцы, сигнал Atlas или молчание не могут уйти вместе.

## Scanner

Импровизированный пакет подъема. Он может выйти из океана, если совпадут масса, погода и геометрия carrier.

## Terminal

PAYLOAD SLOT: ограничен. WINDOW: открыто. ROUTE: оспаривается. CLAIM VALUE: переменная. EVIDENCE STATE: недостаточна для чистого спора.

## Audio

Окно открыто. Оно не останется открытым для всего.

## Field Note

Выбраться - это маршрут. Выбраться чисто - миф.
