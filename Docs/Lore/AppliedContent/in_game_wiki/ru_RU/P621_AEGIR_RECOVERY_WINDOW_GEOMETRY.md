# Геометрия окна эвакуации в Aegir

Найденная карта окна Aegir объясняет, почему контакт с Black Keel не равен спасению. Сигнал может пройти в один проход, а тело, подъёмная капсула, карантинная претензия, пакет доказательств и масса груза не попадут в ту же геометрию. Первый ремонт только ставит тебя на часы.

## Scanner

ЧАСЫ ОКНА // Black Keel может принять пакет на этом проходе. Для эвакуации тела всё ещё нужны подъёмное железо, карантинное согласование, выход из тени реле Kestrel и принятая строка массы tonne-window.

## Terminal

УВЕДОМЛЕНИЕ KEELMARK ОБ ЭВАКУАЦИИ // Приём сигнала не является разрешением на подъём. Перед запросом эвакуации сведи фазу носителя, потолок шторма, тень реле, карантинный допуск, состояние подъёмного пакета и принятую массу груза.

## Audio

Ретранслятор Black Keel: пакет принят. Тело не попадает в это окно. Держи подъёмный пакет запечатанным, доказательства помеченными, и не трать воздух на радость из-за числа.

## Field Note

Если носитель ответил, не трать воздух на праздник. Ответ это геометрия плюс бухгалтерия. Спасение начинается, когда окно, пломба, груз и тело помещаются в одну строку.
