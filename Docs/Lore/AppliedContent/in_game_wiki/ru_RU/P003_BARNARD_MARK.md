# Метка Barnard

Первая метка Barnard на HECTON-8 достаточно мала, чтобы её пропустить: штамп инструмента, бирка шкафчика, привычка снабжения, шрам от дешёвой верфевой стали. Поэтому она важна. Луна перестаёт быть дальним контрактом, когда знакомые рабочие следы появляются рядом с удержанными эвакуациями, именами работников и проваленными разрешениями маршрута.

## Scanner

Штамп Barnard Yards. Не имущество Deep Reach. Кто-то дотащил верфевое железо до дна этой луны.
