# Журнал тормозного долга приемника

Nearlight-переходы не сделали расстояние безвредным. Они сделали расстояние подотчетным. Человеческие корабли ходят между звездами потому, что старые маршруты принадлежат по частям: beam arrays толкают, pellet lanes кормят, fusion stages тратят, щиты теряют массу, радиаторы сбрасывают тепло, magsails вгрызаются в поля, а receiver stations соглашаются поймать то, что присылает маршрут.

Последний глагол самый грязный. Чтобы поймать тело, приемник должен принять тормозной долг до прибытия тела. Он должен зарезервировать тепловой запас, карантинный объем, медицинскую опеку, юридическую экспозицию и право решить, кто платит, если остановка пойдет плохо. Signal packet почти ничего из этого не требует. Запечатанный evidence hash может ехать через relay. Грузовой ящик может ехать по расписанию, написанному за годы. Живой оператор в сломанной океанской претензии это другая масса.

Поэтому HECTON-8 одновременно связан и брошен. Black Keel может слышать тебя через relay window. Брокер может назначить цену образцу. Публичный ledger может записать, что distress hash существовал. Ни один из этих фактов не создает braking rights для твоего тела. Спасение становится возможным только когда signal, custody, receiver liability, карантин, небесный тайминг, lift mass и реальное железо сходятся. До этого система не молчит. Хуже: она читаема.
