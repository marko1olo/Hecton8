# Петля обратной связи сенсорно-меченой фауны

Сенсорно-меченая фауна несет старую колонию внутри своих шрамов. Deep Reach метила животных для исследований миграции, давления и загрязнения; позже Atlas прочитал эти теги как дешевую экологическую телеметрию. Существо не марионетка. Его движение все равно может изменить приоритет ремонта, разбудить маршрут дрона или сделать безопасный проход занятым.

## Scanner

Старый тег Deep Reach под ростом раковины. След миграции совпадает с ремонтным обзорным проходом.

## Terminal

ПЕТЛЯ ФАУНЫ: встроенный тег возвращает слабые пакеты давления, движения и загрязнения. Atlas читает движение как состояние среды, а не намерение животного.

## Audio

Оно не охотится на тебя. Но все равно может о тебе доложить.

## Field Note

Для встреч, где животное невиновно, но все равно опасно для маршрута.
