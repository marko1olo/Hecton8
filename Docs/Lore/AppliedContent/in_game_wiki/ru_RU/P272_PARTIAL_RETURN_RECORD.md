# Запись частичного возврата

Запись частичного возврата фиксирует передышку без побега. Black Keel может поднять оператора для ремонта костюма, воздуха, декона и синхронизации реестра, но приказ возврата в тот же seed оставляет залог, карантинный срок, память сканов, открытые доказательные пакеты и нерешенную полезную нагрузку привязанными к тому же океану.
