# Кузня давления Оскара Нойманна

Оскар Нойманн связывает ремесло колонии с цепочкой побега. Его заметки о кузне давления объясняют глубокую фабрикацию, зажимные кольца, испытания уплотнений и необходимость спускаться за компонентами вместо ожидания спасения с поверхности.

## Scanner

Оскар Нойманн оставил кузнечный рецепт зажимных колец, достаточно прочных, чтобы подъемная колыбель стала больше чем гробом.

## Terminal

НОЙМАНН, О. Кузнечная заметка: пыль баростекла портит первый уплотнитель, если вмешать ее холодной. Нагреть кольцо под тягой вентшахты, закалить в соляной рубашке, затем испытать двойной нагрузкой подъема.

## Audio

Запуск - это просто гермодверь, которая уходит вверх. Строй его как дверь.
