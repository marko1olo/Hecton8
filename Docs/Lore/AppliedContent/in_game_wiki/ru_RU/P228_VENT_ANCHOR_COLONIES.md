# Колонии вент-якорей

Колонии вент-якорей связывают экологию HECTON-8 с маршрутами крафта, не превращая ресурсы в магическую руду.

## Scanner

Колониальные ребра цепляются за thermal vents, ловят сульфиды и питают материалы для глубинного ремонта.
