# Задержка релейных сообщений

Релейная задержка позволяет HECTON-8 получать власть без заботы. Пакет может нести предупреждение, долг, собственность, опеку или признание через расстояние, но не может принести руки в затопленную комнату. Этот разрыв делает связь страшной: удаленные системы остаются сильными, потому что их написали рано, поставили в очередь рано, оценили под дистанцию и доверили машинам, которые не знают, что отправитель мертв.
