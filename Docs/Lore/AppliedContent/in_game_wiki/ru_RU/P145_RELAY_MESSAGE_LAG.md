# Задержка релейных сообщений

Релейная задержка позволяет Deep Reach угрожать игроку без живого голоса в комнате. Контрактные машины, нотариусы, окна претензий и условия носителя могут прибыть раньше сострадания, потому что их написали раньше, поставили в очередь раньше и оценили так, чтобы пережить расстояние.
