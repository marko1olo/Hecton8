# Ресурсный стек биометалла

Ресурсный стек не дает HECTON-8 схлопнуться в один магический материал. Синий долг важен, но луна платит еще сульфидными металлами, солями, благородными газами, керамикой, катализаторами, биоволокнами, фотопротеинами, salvage-железом и биометаллом, измененным Atlas. Насилие становится понятным потому, что ценность распределена: много мелких причин резать, метить, прятать, возвращаться и лгать.
