# Модель расстояния Ran-Aegir

Модель Ran-Aegir дает HECTON-8 масштаб, который чувствуется прямо в костюме. Aegir достаточно близок для зондов, фрахта, маршрутного права, долгового заселения и корпоративного аппетита к 2190 году. Но он все еще слишком далек, чтобы затопленный отсек дождался доброты внутренних миров. Расстояние превращается в давление через задержку реле, окна запуска, тормозное топливо, опеку перевозчика, страховые исключения и простую правду: масса приходит медленнее приказов.
