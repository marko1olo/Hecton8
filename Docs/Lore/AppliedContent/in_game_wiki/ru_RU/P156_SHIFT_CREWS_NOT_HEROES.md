# Сменные бригады, не герои

HECTON-8 должен очеловечивать колонию через работу раньше, чем через трагедию. Техник давления меняет прокладку клапана, повар считает водные жетоны, маршрутный клерк ставит не тот штамп возврата, водолаз берет резак и уже не возвращает его в журнал: такие детали делают людей читаемыми без обязательной семейной мести. Утонувшая колония сильнее всего, когда кажется местом, прерванным посреди рутины, а не музеем, построенным после смерти.

## Scanner

ЧЕЛОВЕЧЕСКИЙ СЛОЙ // Колония становится настоящей через графики, стертые инструменты, пропущенные возвраты и имена на досках смен. Не через речи.

## Terminal
