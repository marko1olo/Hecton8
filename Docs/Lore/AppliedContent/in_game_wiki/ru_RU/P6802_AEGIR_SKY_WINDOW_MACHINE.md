# Машина небесного окна Aegir

Видимое небо Aegir это маршрутная машина, а не декорация. Лунные тени ломают relay confidence, штормы могут прикрыть тело и убить upload, а чистая carrier line все еще может провалить radiation, tide, quarantine или mass checks. Читай sky windows как сложенные ворота: packet, body, proof и salvage не обязаны делить один проход.

## Scanner

ЧТЕНИЕ SKY WINDOW // Чистое видимое небо не является rescue clearance. Тень Kestrel, storm ceiling, radiation count, tide load и carrier phase расходятся.

## Terminal

ROUTE PLATE AEGIR // Состояние окна частичное. Packet line может быть открыт, пока ascent body, quarantine и tonne-window mass закрыты.

## Audio

Заметка relay: небо яркое, маршрут грязный. Отправляй только packet; держи ascent, пока moon tag, storm ceiling и mass line не согласятся.

## Field Note

Небо может быть открыто для packet и закрыто для твоего тела. Проверь всю машину, прежде чем радоваться.
