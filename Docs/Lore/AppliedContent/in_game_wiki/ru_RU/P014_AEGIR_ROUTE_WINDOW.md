# Маршрутное окно Aegir

Маршрутное окно Aegir - момент, когда несколько враждебных часов ненадолго совпадают: радиация газового гиганта, лунная тень, штормовой шум, приливный сдвиг, качество связи, масса подъема и геометрия Black Keel.

Поэтому небо входит в цикл выживания. Данные могут пройти тогда, когда телам нельзя подниматься. Хорошее окно подъема может одновременно испортить улики шумом.

## Scanner

Местная эфемеридная таблица. Связь, прилив, радиация, тень луны и геометрия носителя делят одно узкое окно подъема.
