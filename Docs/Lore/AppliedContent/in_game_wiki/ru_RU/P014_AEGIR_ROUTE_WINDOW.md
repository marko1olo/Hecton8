# Окно маршрута Aegir

Окно маршрута Aegir — не красивый прогноз погоды. Это короткий период, когда враждебные часы достаточно совпадают: радиация, лунная тень, storm plume, приливный сдвиг, акустический канал, геометрия Black Keel и хранение tonne-window. Окно может быть открыто для данных и закрыто для тела. Ядро доказательства может пройти карантин, а образец blue-debt застрять. Спасение — это пересечение выживания, закона и массы.

## Scanner

Локальная таблица эфемерид. Радиация Aegir, лунная тень, storm plume, приливный сдвиг, качество акустического канала, геометрия Black Keel и хранение tonne-window ненадолго совпадают.
