# Леса соляных лопастей

Леса соляных лопастей - первая среднеглубинная экология, которая делает невидимую физику видимой. Это плоские соле-минеральные мембраны, натянутые вдоль границ между рассолом, температурой и давлением. Издалека они похожи на бледные листья в утонувшем каньоне; вблизи это маршрутные приборы. Целый лист означает, что вода по другую сторону не просто иная, а трудная для входа: сдвиг плотности достаточно силен, чтобы согнуть сонар и сбить тело с trim. Рваные края отмечают недавний проход. Свернутые кончики показывают, где граница слабеет в окно сдвига. Бледные минеральные ребра можно брать со сброшенных полос, но срез живого листа может закрыть единственную читаемую полосу через стену каньона. Иди вдоль рваных лопастей, когда нужен маршрут. Обходи черную слоистую воду, которая стирает их края.

Это не деревья. Это листья давления: мембраны, питающиеся химическими градиентами и рвущиеся только там, где маршрут недавно продавился насквозь.
