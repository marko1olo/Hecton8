# Приливная модель Мары Венн

Мара Венн дает Великому приливу научного свидетеля. Ее модель связала геометрию лун Aegir, сдвиг криосферы и эвакуационную емкость в один неприятный запас. Deep Reach не стер модель; он менял метку действия, пока предупреждение не стало достаточно дешевым, чтобы его игнорировать.
