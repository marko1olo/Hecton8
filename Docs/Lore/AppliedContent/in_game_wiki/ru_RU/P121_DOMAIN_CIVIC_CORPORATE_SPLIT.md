# Гражданско-корпоративный раскол доменов

Человеческое пространство к 2190 году разреженное, но зрелое. Sol Core важен для собственности, финансов и сертификации. Centauri дает Deep Reach язык старых хартий. Barnard Yards объясняет salvage-культуру игрока. Tau Ceti может сделать доказательства публичными после relay-задержки. Luyten контролирует custody маршруты. Aegir - место, где все эти системы становятся уязвимыми.
