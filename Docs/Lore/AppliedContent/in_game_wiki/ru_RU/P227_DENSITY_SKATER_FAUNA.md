# Фауна плотностных скользунов

Фауна плотностных скользунов строится вокруг реального поведения слоев плотности, а не вокруг фантазийной левитации.

## Scanner

Скользуны идут по brine interface как по твердой поверхности, оставляя рябь там, где сонар ожидает открытую воду.

## Terminal

FAUNA: контакт skater вероятнее у разрывов vane, теплых brine steps и мертвых краев сонара.

## Audio

Что-то идет по воде внутри воды.

## Field Note

Плотностные скользуны доказывают, что каньон является слоистой машиной. Их маршруты идут по химии, а не по пустоте.
