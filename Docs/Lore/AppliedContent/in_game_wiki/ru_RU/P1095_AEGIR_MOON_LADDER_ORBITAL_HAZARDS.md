# Лунная лестница Aegir

Лунная лестница Aegir - не украшение неба. Ran - звезда, Aegir - гигант, а HECTON-8 - одна океаническая луна внутри движущейся цепи лун, ретрансляторов, штормов, проверок опеки и застрахованных окон массы.

Skarn может залить антенны заряженным шумом. Vela может закрыть ретрансляторы ледяной пылью. Kestrel может перекрыть линию видимости в худшую минуту. HECTON может бросить штормовой плюм через чистый коридор подъема. Black Keel может принять пакет и все равно отказать в подъеме, если окно, карантинное рукопожатие или класс массы провалены.

## Scanner

ОРБИТАЛЬНАЯ ОПАСНОСТЬ // Окно нестабильно. Всплеск Skarn, шторка Vela, перекрытие Kestrel и штормовой плюм HECTON могут сломать геометрию возврата.

## Terminal

ЗАМЕТКА ОКНА ВОЗВРАТА // Black Keel требует опеку сигнала, чистый payload hash, карантинное рукопожатие и поднимаемое тоннажное окно перед подъемом тела. Светлое небо не является разрешением на спасение.

## Audio

Небо отказало не пустотой. Оно отказало по расписанию: луна, шторка, всплеск, реестр, масса.

## Field Note

Если возврат сорвался, сначала прочитай предупреждение неба, потом обвиняй pinger.
