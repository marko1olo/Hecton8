# Цепочка сохранности пакета

Найдена пломба пакета. Black Keel принимает груз, но доказательству нужны источник, пломба, witness hash, метка ретранслятора, линия получателя и состояние повреждений. Не снимай теги сохранности перед разбором железа.

## Scanner

ПЛОМБА ПАКЕТА // Полоса witness hash повреждена, но читается. Сохрани до спасательного реза. Незапечатанное доказательство станет материалом претензии.

## Terminal

ПАКЕТНЫЙ НОТАРИЙ KEELMARK // До передачи сохранить пластину пломбы, witness hash, маршрутный штамп и тег разъема. Материал без штампа может уйти как претензионная потеря.

## Audio

Ретранслятор Black Keel: груз - это масса. Доказательство - это сохранность. Принеси оба, иначе окно выставит счет за разницу.

## Field Note

Сначала пломба, потом рез. Чистый образец со сломанным тегом принадлежит тому, у кого реестр.
