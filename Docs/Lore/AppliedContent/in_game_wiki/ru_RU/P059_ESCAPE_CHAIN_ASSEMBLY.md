# Сборка цепи побега

Побег — это сборочная цепь, а не один отремонтированный аппарат. Повреждённый drop-пакет может удержать игрока в живых, но не может сам создать доверенный подъём. Пути домой нужен акустический релейный хребет, чтобы сигнал проходил через воду и шум шторма; уплотнение давления, которое не превратит подъём в разрыв; ядро наведения, способное пережить местные угрозы HECTON-8; заряд подъёма; карантинно-юридическое рукопожатие и, если игрок хочет власть над записью возврата, доказательный груз, который Black Keel не сможет обесценить. Каждая часть лежит глубже комфорта, потому что исходная система строилась для движения активов, а не для ухода брошенных рабочих на своих условиях.

## Scanner

Для выхода нужны шесть твёрдых доказательств: релейная связь, уплотнение, наведение, заряд подъёма, юридическое рукопожатие и груз, который носитель не сможет проигнорировать.
