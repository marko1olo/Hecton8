# Сборка цепочки побега

Сборка цепочки побега превращает уход в длинную инженерную ветку. Поврежденный drop package не может стартовать сам. Игрок должен собрать relay, pressure sealing, guidance, ascent energy, legal access и опциональную evidence capacity на разных глубинах.

## Scanner

Для ухода нужны шесть жестких доказательств: relay, seal, guidance, ascent charge, legal handshake и payload, который carrier не сможет проигнорировать.

## Terminal

ПАКЕТ ПОДЪЕМА: акустический relay spine отсутствует. Рейтинг clamp ring недостаточен. Guidance core отсутствует. Charge cradle пуст. Quarantine handshake не решен. Evidence payload опционален, но меняет authority восстановления.

## Audio

Ты не ремонтируешь капсулу. Ты строишь первый честный выход, которого у колонии никогда не было.

## Field Note

Маршрут вверх собирается из деталей, которые никогда не должны были дать рабочим уйти самостоятельно.
