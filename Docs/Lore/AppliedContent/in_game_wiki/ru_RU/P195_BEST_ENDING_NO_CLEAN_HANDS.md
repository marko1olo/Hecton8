# Лучший маршрут: видимый остаток

Видимый остаток - стандарт самого сильного маршрута. Финал должен спасать что-то конкретное, не превращая HECTON-8 в экран награды: публичную запись, закрытый маршрут Deep Reach, сохраненный бассейн, освобожденного оператора, имена рабочих или Atlas proof hash. Запись также должна оставить открытые поля для хранения получателя, ответственности, пропавших имен, ущерба бассейна, состояния Atlas и остатка долга.
