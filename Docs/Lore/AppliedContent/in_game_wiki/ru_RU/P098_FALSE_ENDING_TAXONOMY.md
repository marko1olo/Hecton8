# False Ending Taxonomy

HECTON-8 поддерживает false и partial endings, не делая их фейковыми. Material payout может дать титры. Partial exit может вернуть в тот же seed. Corporate capture и quarantine hold наказывают плохие payloads. Public ledger release и Atlas resolution требуют более глубокой правды.

## Scanner
