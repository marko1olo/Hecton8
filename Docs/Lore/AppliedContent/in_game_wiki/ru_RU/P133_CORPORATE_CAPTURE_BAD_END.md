# Корпоративный захват: чистое спасение

Корпоративный захват начинается ровно так, как должна начинаться помощь. Сигнал чистый, вектор pickup профессиональный, в комнате есть пригодный воздух. Потом порядок вопросов выдает спасение: сначала координаты, потом custody, потом доступ к Atlas, welfare после проверки. Подрядчик выходит из океана живым, но ответившая власть обращается со свидетелем как с загрязнением, а с payload как с пациентом. Показания запечатывают раньше, чем они могут стать публичной записью. Тело переживает давление только для того, чтобы войти в более тихую машину контроля доказательств.

## Scanner

Источник recovery подтвержден: прокси Deep Reach. Payload запрошен до проверки пульса.

## Terminal

PICKUP DEEP REACH: команда recovery запрашивает координаты, custody XO, ключ доступа Atlas и печать payload Seed до проверки состояния подрядчика. Показания свидетеля запечатаны по протоколу загрязнения.

## Audio

Чистая комната построена не для свидетеля.

## Field Note

Чистое спасение, которое сперва просит координаты, - это custody с теплым воздухом.
