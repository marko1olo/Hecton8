# Правило фиксации имен лун

Список лун можно переименовать лучше, но лестница ролей зафиксирована для геймплея и маршрутной логики.

## Scanner

Названия лун можно заменить, но их орбитальные роли нельзя.

## Terminal

ATLAS NOTE: имена лун - публикационные ярлыки. Опасности маршрута, реле, приливы, ледяное рассеяние, salvage и quarantine - канонические функции маршрута.

## Audio
