# Режим напорных коек

Напорные койки показывают колонию как обслуживаемую машину быта. Ужас в том, что нормальные системы выполняли плохие приоритеты.

Койки сделаны для сна под давлением: проверки герметика, кислородные карточки, дренаж конденсата, сменные будильники.
