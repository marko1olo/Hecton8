# Звезда системы Aegir

Aegir обращается вокруг нормальной оранжево-желтой звезды K-типа. HECTON-8 темен не из-за нехватки света; его затемняют глубина, штормовая вода, затмения, ил, давление и сломанная индустрия.

## Scanner

Подтвержден свет K-типа. Освещение поверхности есть; темноту создают глубина, штормы и затмения.
