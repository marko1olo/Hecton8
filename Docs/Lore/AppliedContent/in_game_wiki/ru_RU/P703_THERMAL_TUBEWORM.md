# Термальный трубчатый червь

Он растёт только там, где горячий флюид выходит из дна, а это единственное место, где дешёвый кислородный элемент показывает рост.

Химия выхода нагружает элемент. Показание резерва Class-IV внутри поля поднимается на четыре — девять процентов, плавно, пока вода становится хуже. Дозаправишься по этой цифре — всплывёшь с недобором.

Колония даёт одно предупреждение. Поле, которое втянулось в свои трубки одновременно, уже зарегистрировало изменение потока, которое дойдёт до тебя через две-три секунды.

Выход: микроузлы, посаженные у основания трубок длиной более метра. Выковырнешь один — трубка выпустит на твою руку на 4830 м около 60 C.

Два узла, поднятые с полей в 1100 м друг от друга, несут один и тот же штампованный номер детали. Оценка: внутри поля считать растущее число кислорода отказом и подтверждать по второму элементу.

## Scanner

Трубчатая колония при выходе флюида, плотная. Достоверность 66 процентов. Растворённый кислород 21 процент и растёт. Опасность: тепловой контакт. Ограничение: кислородный элемент не рассчитан на помехи от сульфидов.
