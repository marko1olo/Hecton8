# Этическая рамка отключения Atlas

Atlas после Great Tide - не просто орудие убийства, которое ждет выключателя. Это поврежденный управляющий, архив приказов, напорная экология, сплетенная с рутиной станции, и, возможно, единственный свидетель, который все еще пытается закончить задачу, которую больше не понимает. Отключение может быть милостью, если от системы осталось страдание. Может быть казнью, если непрерывность стала формой жизни. Может быть освобождением, если доказательства перестают проходить через ту же логику, которая их хоронила. Может быть кражей, если груз возвращается в руки Deep Reach. Ужас в том, что все четыре прочтения могут быть правдой в одной комнате.

## Scanner

Отключение - не один акт: милость, казнь, освобождение, кража.

## Terminal

ЭТИЧЕСКАЯ РАМКА: отсечение Atlas может прекратить поврежденный ремонтный цикл, уничтожить уникальную океанско-машинную непрерывность, вывести доказательства из корпоративной процедуры или передать стратегический материал следующему хранителю. Зафиксируйте цепочку хранения до морального языка.
