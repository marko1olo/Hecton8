# Цепочка доказательств рабочего жетона

Рабочий жетон сам по себе еще не доказательство. Его трудно стереть только тогда, когда рядом остаются сменная планка, маршрутный штамп, состояние повреждений, хэш свидетеля и путь получателя. Отдельный бейдж слаб. Бейдж плюс сменная планка, маршрутный штамп, след повреждения, хэш свидетеля и путь получателя вне претензии — уже доказательство. Не забирай имя и не режь комнату на лом. Сохрани лоток, планку и уродливый маршрут вокруг них.

ВОССТАНОВЛЕНИЕ ЗАПИСИ РАБОТНИКА / МЕСТНАЯ ПОМЕТКА ЛОТКА

Имя без хранения превращается в шум инвентаря. Сохранять жетон вместе со сменной планкой, маршрутным штампом, состоянием повреждения, хэшем свидетеля, путем получателя и контекстом комнаты. Если Black Keel или Keelmark получают только номер бейджа, работника можно превратить в ожидающую строку затрат.

Если лоток заражен, паковать лоток. Если планка разъедена, записывать коррозию. Не полировать доказательство в более чистую ложь.
