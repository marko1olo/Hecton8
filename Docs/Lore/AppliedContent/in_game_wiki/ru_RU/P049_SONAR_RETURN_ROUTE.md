# Sonar return route

Return beacon записывает, как route звучал, когда был last safe. Он не обещает, что route stayed safe. На HECTON-8 у safety есть звук: clear edges, clean delay, no loose metal singing in the low band, no silt swallowing the tail. Storm surge, cut cable, moving fauna, fresh salvage mass и door, который flexed under pressure, могут bend the return, не erased corridor. Return route - это work. Ping it before loading, и cache the load, если echo возвращается другой формы.
