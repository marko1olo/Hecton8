# Окно возвратного вектора

Окна возврата делают побег hard sci-fi цепочкой, а не пунктом меню. Для подъема нужны геометрия, погода, сигнал и железо.

## Scanner

Орбитальная геометрия не кнопка спасения. Black Keel слышит тебя только в узкие окна Aegir.

## Terminal

Прогноз связи: carrier высоко над Aegir. Для подъема капсулы нужны разрыв шторма, спад заряженных частиц и чистая релейная линия.

## Audio

Black Keel достаточно жив, чтобы ответить. Недостаточно близко, чтобы спасти.

## Field Note
