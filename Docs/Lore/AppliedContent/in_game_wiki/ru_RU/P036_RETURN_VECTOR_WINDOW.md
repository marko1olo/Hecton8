# Окно возвратного вектора

Окно возвратного вектора впервые доказывает, что Black Keel может ответить, но не может сразу забрать. Carrier живет на автоматической переходной траектории над Aegir, а выход с HECTON-8 должен пройти через погоду, шум заряженных частиц, поврежденное реле и недособранное подъемное железо.

Рабочее окно возврата требует четыре показания одновременно: геометрию carrier, разрыв поверхностного шторма, чистый релейный путь и цепь капсулы, которая переживет запуск. Если одно показание падает, пинг становится отметкой времени, а не подбором. Позже эта же система поддерживает частичную эвакуацию, но она не закрывает долг, цепочку доказательств и поврежденный маршрут. Любой ответ с орбиты считайте ограничением расписания, пока подъемная люлька, ядро наведения, теплозащита и возвратное рукопожатие не восстановлены.
