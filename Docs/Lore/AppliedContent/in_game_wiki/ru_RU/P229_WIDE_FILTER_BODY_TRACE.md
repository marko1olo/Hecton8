# След широкого фильтрующего тела

Широкие фильтрующие тела впервые доказывают, что открытая бездна между ориентирами не пуста. Они идут через глубинную воду как медленные сборщики планктонных облаков, шире малых пристроек колонии. Существо не охотится на Marauder; оно меняет карту вокруг Marauder. После его прохода взвешенная жизнь редеет, сонарные возвраты смазываются по краю тела, а погребенные промышленные контуры на несколько минут проступают из ила.

Поэтому организм одновременно опасность и инструмент. Его тень может скрыть сервисную раму или сделать маршрут открытым там, где вода на самом деле заполнена движущейся тканью. Правильное действие - читать след: чистая вода за пастью, грязный спад по краю, акустическая тишина в подветрии тела. Не плыви под тень просто чтобы увидеть существо. Иди по оставленному просвету только если есть заряд, линия и путь назад.
