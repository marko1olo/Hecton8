# Журнал доказательства до дыхания

Distress hash может покинуть HECTON-8 раньше игрока, потому что доказательство специально сделано маленьким. Это checksum, custody, witness time и узкое утверждение о том, что существовало. Оно может пройти relay window частями. Его можно хранить, оценивать, оспаривать и копировать, не спрашивая никого, кто будет держать его в тепле.

Человек не такой payload. Дышащему телу нужны температура, давление, медицина, обработка заражения, маршрутное право, юридическая custody и приемник, готовый владеть остановкой. Маршрут может принять твое доказательство и все еще отказать твоей массе. В HECTON-8 это не противоречие. Это жестокость системы, которая точно знает, сколько человек стоит по частям.

Поэтому первый отвеченный пакет не должен звучать как спасение. Black Keel может подтвердить hash. Broker может ранжировать sample. Return desk может запросить координаты, substrate и proof integrity, пока твой запас воздуха продолжает тикать. Игрок не пытается сделать цивилизацию осведомленной. Цивилизация уже осведомлена. Задача в том, чтобы живое тело стало труднее игнорировать, чем данные, которые оно произвело.

## Scanner

НОТАРИУС DISTRESS HASH // Соляная cradle с целой witness seal. Пакет принят: identity hash, sample hash, time window, pressure telemetry. Человек не принят. Жизнеобеспечение идет отдельным счетом.

## Terminal

ОЧЕРЕДЬ RETURN ACTION // Цепочка доказательств проверена. Формулировка спасения остановлена до назначения владельца маршрута, custody живой массы, карантинной койки и резерва lift. Не путай подтверждение с извлечением.

## Audio

Доказательство путешествует потому, что оно не кашляет, не паникует, не мерзнет и не требует места.
