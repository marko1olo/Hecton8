# Registro de reclamación de expedientes

El registro de reclamación de expedientes es un formulario de entrada de Black Keel para pruebas anteriores, no una taquilla de equipo. Un expediente seleccionado puede llevar finales antiguos, familias de rumores, presión de gravamen, términos de custodia y avisos de ruta a un contrato nuevo. Esos registros cambian lo que sospecha el operador y lo que cobra el carrier. No alteran la reserva de oxígeno, la clase del casco, las armas, el inventario ni la identidad laboral escrita en la reclamación.

## Scanner
