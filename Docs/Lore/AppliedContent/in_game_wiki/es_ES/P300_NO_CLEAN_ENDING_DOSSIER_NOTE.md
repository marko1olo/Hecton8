# Nota de dossier sin final limpio

La nota define el tono de memoria posterior al final. Incluso el final más fuerte deja un archivo vivo: algo salvado, algo dañado y un coste que se niega a quedar ordenado.

## Scanner

Nota de dossier: cierre denegado; consecuencia retenida.

## Terminal

DOSSIER RECORD: resultado almacenado. Cierre limpio no disponible con el estado actual de pruebas. Deuda, ecología, responsabilidad y custodia del testigo siguen como registros activos.

## Audio

Salvaste algo. Eso no es lo mismo que limpiarlo.

## Field Note

El dossier posterior mantiene el puente abierto: resultado registrado, deuda y pruebas sin resolver, ninguna victoria perfecta concedida.
