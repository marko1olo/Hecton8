# División de mensajes de Deep Reach

La división mantiene a Deep Reach como institución, no como villano caricaturesco y unificado. Una corporación puede emitir órdenes de rescate, órdenes de encubrimiento y advertencias técnicas honestas a la vez porque cada oficina defiende un libro contable distinto.
