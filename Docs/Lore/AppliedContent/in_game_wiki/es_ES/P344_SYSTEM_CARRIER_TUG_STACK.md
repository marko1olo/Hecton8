# Pila de portador y remolcadores de sistema

Black Keel es portador de sistema y plataforma de salvamento, no nave personal. Puede sostener órbita, manejar carga, operar bloqueos de custodia, lanzar cápsulas y coordinar remolcadores. No puede borrar retardo lumínico, ventanas de ruta, hardware bathydrop dañado ni reglas de coste.
