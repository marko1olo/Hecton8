# Escala De Población Y Autoridad

Las cifras de población quedan aproximadas porque el jugador no necesita census opera. La pregunta útil es más simple: ¿quién puede actuar sobre ti desde lejos? Un dominio interior abarrotado quizá toque HECTON-8 solo como una línea de certificación. Un depósito pequeño puede importar más porque controla custody de paquetes. Una shell de frontera muerta puede importar más que todos porque posee el hardware de la sala.

Esa es la escala que siente el jugador. Sol puede decidir que un objeto pertenece a alguien. Centauri puede hacer respetable el viejo lenguaje de Deep Reach. Barnard normaliza el trabajo que atrapa Marauders. Tau Ceti puede convertir una prueba en presión pública, tarde para el oxígeno pero no tarde para las consecuencias. Luyten puede probar la cadena de mensajes. Aegir es donde las firmas se vuelven presión, agua, escotillas cerradas y masa facturable.
