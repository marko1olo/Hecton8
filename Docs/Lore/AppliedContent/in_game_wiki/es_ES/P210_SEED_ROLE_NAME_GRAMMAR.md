# Gramática de nombres seed-role

La Gramática de nombres seed-role es la regla que impide que la variación de rejugada se vuelva ruido. Un trabajador seed-role puede aparecer en otra taquilla, junto a otra herramienta dañada o bajo otro permiso de ruta entre partidas. La identidad aún necesita gramática: un nombre personal estable, una familia de cuadrilla, un contexto de permiso, una última tarea y una variante de objeto inspeccionable. Si falta alguna parte, el nombre deja de sentirse como persona y empieza a sentirse como relleno generado. El sistema puede barajar el orden de la evidencia; no debe barajar la responsabilidad hasta hacerla desaparecer.

## Scanner

Un seed puede mover el orden de la evidencia. No puede convertir a un trabajador en texto desechable.

## Terminal

SEED GRAMMAR: personal_name + crew_family + route_permission + last_task + object_variant. La localización puede anotar términos de cuadrilla para legibilidad, pero no debe reescribir la identidad, borrar el oficio ni separar el nombre de un objeto concreto.

## Audio

Azar no es autoría. Ata el nombre a un trabajo.

## Field Note

Cada identidad seed-role combina nombre personal, familia de cuadrilla, permiso de ruta, última tarea y variante de objeto.
