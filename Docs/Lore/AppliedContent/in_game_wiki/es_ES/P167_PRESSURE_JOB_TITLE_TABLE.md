# Tabla de oficios de presión

La tabla de oficios es el esqueleto laboral de la colonia. Ata a cada persona a bombas, sellos, relés, medlocks, fabricadores, tableros de ruta, vent-kilns y consolas Atlas.

Un cargo debe prometer evidencia física. Un aparejador de sellos deja tiza de juntas, marcas de abrazadera y registros de escotilla. Un buzo brine deja notas de densidad, cortes de línea lastrada y manchas de enjuague del traje. Un custodio de relé deja hojas de tiempo y rechazos de acceso. Un auxiliar medlock deja formularios que prueban que la estación eligió dotación antes que recuperación.

## Scanner

TABLERO DE PUESTOS // El cargo no es adorno de recursos humanos. Indica qué sistema falló cuando el trabajador dejó de responder.

## Terminal

OFICIOS DE PRESIÓN // Técnica de bombas, aparejador de sellos, escribiente de ruta, buzo brine, operadora de fabricador, auxiliar medlock, custodio de relé, peón vent-kiln, lector de seguridad Atlas y supervisora de turno no son color social. Son lógica de acceso. El cargo define qué sabía el trabajador, qué panel aceptaba su placa, qué sala debía tener sus herramientas y qué fallo se le culparía después del Great Tide.
