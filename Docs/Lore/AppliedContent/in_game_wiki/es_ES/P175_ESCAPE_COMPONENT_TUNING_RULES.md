# Reglas de ajuste de componentes de escape

Las Reglas de ajuste de componentes de escape evitan que el final de HECTON-8 se convierta en una lista de compras con botón de lanzamiento. Una ruta de escape creíble necesita piezas, pero cada pieza debe probar algo más que su coste material. El relay spine demuestra que el jugador puede hablar a través del agua y el ruido magnético. Los clamp rings demuestran que la cápsula o el objeto de ascenso mantendrá forma bajo presión. El guidance core demuestra timing, no fantasía de destino: debe acertar una ventana, no desear órbita. La ascent charge demuestra energía y riesgo. El legal handshake decide quién responde, quién posee el canal de recuperación y si cuarentena acepta la carga. El evidence payload cambia la consecuencia: el jugador puede salir con moneda, acusación, custodia de muestra o palanca. Si falta una prueba, el resultado no debe sentirse como un botón desactivado. Debe sentirse como otro final: recuperación parcial, retención de custodia, receptor malo, reclamación fallida o escape comprado con silencio.

## Scanner
