# Firmas de la cola de acción de retorno

Las firmas Return Action Queue conectan el caso antiguo de HECTON-8 con presión presente en 2190. La cola no es un archivo histórico. Maneja paquetes retrasados durante ventanas Aegir activas y ordena qué debe hacer primero Black Keel o un propietario de relé. En la tira recuperada, payload custody, coordinate receipt y quarantine handshake van por delante de contractor recovery. Eso mantiene peligroso a Deep Reach sin poner un comandante en la sala: una oficina baja todavía puede dirigir una ventana de rescate al decidir qué acción queda lo bastante limpia para ejecutarse.
