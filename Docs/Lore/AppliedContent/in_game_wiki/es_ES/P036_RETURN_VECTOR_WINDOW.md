# Ventana de vector de retorno

La ventana de vector de retorno es la primera prueba de que Black Keel puede responder sin poder rescatar de inmediato. El carrier sigue una pista de transferencia automatizada sobre Aegir, pero la ruta de salida de HECTON-8 debe cruzar clima, ruido de partículas cargadas, daño de relé y hardware de ascenso incompleto.

Una ventana de retorno válida necesita cuatro lecturas a la vez: geometría del carrier, hueco de tormenta superficial, ruta de relé limpia y una cadena de cápsula capaz de sobrevivir al lanzamiento. Si una falla, el ping se vuelve marca de tiempo en vez de recogida. El mismo sistema sostiene más tarde la extracción parcial, pero no limpia deuda, custodia de pruebas ni ruta dañada. Trata cada respuesta orbital como restricción de horario hasta reconstruir cuna de ascenso, núcleo de guiado, escudo térmico y handshake de retorno.

## Scanner

LECTURA DE VECTOR DE RETORNO // Ping de Black Keel recibido por hueco de tormenta de Aegir. Alcance del carrier: pista alta de transferencia. Línea de relé sucia bajo carga de nubes. Ascenso de cápsula rechazado hasta que núcleo de guiado, escudo térmico y handshake de retorno den verde.
