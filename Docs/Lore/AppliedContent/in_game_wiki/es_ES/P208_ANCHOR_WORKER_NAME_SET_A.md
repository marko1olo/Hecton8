# Conjunto A de nombres laborales ancla

El Conjunto A de nombres laborales ancla es la primera capa humana que el jugador debería empezar a reconocer. Mara Venn, Juno Kade, Ren Okoye, Sahana Iqbal, Lian Torres, Oskar Neumann, Aya Morita y Pavel Sorn pertenecen a la evidencia somera y de plataforma industrial. Sus nombres no deben llegar como biografías. Deben llegar en una etiqueta de taquilla, un tag de bomba, un permiso de ruta, un vale de comida manchado, una caja de herramienta rajada, y luego volver en un registro que cambie el sentido. Set A hace que la colonia parezca vivida antes de que la conspiración profunda sea clara.

## Scanner

Los nombres tempranos deben volver mediante trabajo, no discursos. La ruta somera enseña memoria por repetición.

## Terminal

ANCHOR SET A: recurrencia en someros y plataforma industrial. Cada nombre debe unirse a una herramienta, un permiso de ruta, un objeto de trabajo dañado y una contradicción posterior. Estos nombres son la primera prueba del jugador de que la colonia fue un lugar de trabajo antes de volverse salvamento.

## Audio

No llores el nombre hasta que la herramienta te diga por qué.

## Field Note

Anclas Set A: Mara Venn, Juno Kade, Ren Okoye, Sahana Iqbal, Lian Torres, Oskar Neumann, Aya Morita, Pavel Sorn.
