# Paquete de falso informe público

Paquete de falso informe público es la versión de HECTON-8 que Deep Reach podía mostrar con seguridad a los mundos. No inventa un océano falso. La Gran Marea fue real, la demora de relé fue real, la incertidumbre de cuarentena fue real, y por eso el informe sobrevive a una lectura casual. La mentira vive en las omisiones. Retira márgenes de riesgo aceptados, autoridad de evacuación demorada, ponderación de continuidad Atlas, conversión de seguros y presión de custodia de recuperación. El jugador debe leerlo como el movimiento corporativo final: dejar suficiente física para sonar sobrio, cortar suficientes decisiones para borrar la culpa.
