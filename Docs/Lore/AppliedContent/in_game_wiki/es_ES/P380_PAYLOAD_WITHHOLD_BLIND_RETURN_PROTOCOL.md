# Protocolo blind return con retención de payload

El protocolo blind return rechaza todos los receptores. Ni corporación, ni libro, ni carril de cuarentena, ni objetivo de corte reciben el payload final. El portador mantiene mapa y pruebas en local, negando a Deep Reach una ruta limpia de regreso. También deja deuda activa, pruebas públicas sin registrar y el paquete vulnerable al agua, muerte o mal almacenamiento.

## Scanner

Ruta blind return armada. Ningún receptor asignado. Vector de cuenca, hashes de prueba y clase de acceso quedan locales; gravamen y ventana de recuperación siguen sin resolver.

## Terminal

RECEPTOR PAYLOAD // BLIND RETURN WITHHOLD. Receptor: ninguno. Retener vector de cuenca, hashes de prueba, clase salvage, paquete local de pruebas. Negar a Deep Reach mapa de acceso, recibo de pago y custodia receptora. Coste conocido: gravamen sin resolver, riesgo total de pérdida del paquete.

## Audio

Sin receptor, sin recibo. Si la bolsa se inunda, la prueba se va con ella.

## Field Note

Nota de saqueador: quedarse el mapa es una decisión. Solo te deja sin receptor al que culpar si la bolsa se rompe.
