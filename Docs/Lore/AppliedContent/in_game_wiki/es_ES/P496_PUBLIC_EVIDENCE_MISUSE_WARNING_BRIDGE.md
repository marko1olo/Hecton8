# Advertencia de abuso de pruebas publicas

El registro publico no es una bengala de rescate. Es un mecanismo de precio. Cuando un paquete Tau Ceti llega a un espejo publico con encabezado de redaccion, cadena de pies, hash de testigo y marca notarial Luyten, Deep Reach ya no puede fingir barato que la sala nunca existio. Las oficinas pantalla de Aegir tampoco pueden vender una cronologia limpia sin comprar cada contradiccion adjunta.

El peligro es que el mismo paquete se convierte en directorio. Los corredores tasan recompensas con nombres y marcas corporales. Las aseguradoras usan marcas de tiempo para retrasar pagos. Las oficinas de reclamacion llegan a las familias antes que los defensores. Los equipos de limpieza leen el orden de pies y deciden que testigo aun puede ser asustado, comprado o borrado. La publicacion cambia la palanca; no hace seguras a las personas del registro.
