# Tonne-window de Keelmark

Un tonne-window es la masa recuperable que Black Keel puede elevar en una oportunidad orbital después de tasar combustible, tormenta, cuarentena, seguro y prioridad. Keelmark Mutual vuelve legible al jugador como masa antes de verlo como persona. Cada muestra guardada, paquete de prueba, deuda de oxígeno y cláusula de bienestar puede mover el número.
