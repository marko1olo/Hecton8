# Programa precursor Needleprobe

Las needleprobes llevaron la primera reclamación humana a Aegir. Eran cargas de estudio estrechas y blindadas enviadas antes de las tripulaciones para leer gravedad, radiación, espectros oceánicos, órbitas lunares y líneas de relé. Sus paquetes demorados hicieron legible HECTON-8 para inversores antes de volverlo habitable para trabajadores.

## Scanner

Archivo needleprobe: Aegir fue un objetivo contable mucho antes de ser lugar de trabajo. Los ojos de máquina llegaron primero a las lunas.

## Terminal

ARCHIVO RAN: la cadena de sondas devolvió paralaje, radiación, firmas oceánicas, geometría de relé y confianza de carril de pellets. Clasificación para tripulación retenida hasta estabilizar el tercer modelo de riesgo.

## Audio

La primera cosa humana en Aegir no fue una persona. Fue una máquina preguntando si la gente sería rentable aquí.

## Field Note

Los archivos de sondas son evidencia de ruta. La telemetría vieja puede ser anterior a la colonia y aun así decidir quién posee el agua.
