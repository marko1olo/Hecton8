# Regeln für Marauder-Korrekturmarken

Regeln für Marauder-Korrekturmarken definieren die zweite menschliche Hand auf Koloniebeweisen. Deep Reach schrieb Kategorien, um Arbeiter zu begraben; spätere Anspruchscrews schrieben darüber, um zu überleben, zu handeln oder einander zu warnen. Eine Korrekturmarke ist nur nützlich, wenn sie verändert, was der Spieler folgern kann. Ein eingekreister Name kann eine Person aus einer Verlustkategorie retten. Ein durchgestrichener Routenstempel kann eine sichere Tür verdächtig machen. Eine Preismarke kann eine biologische Probe in ein Schuldobjekt verwandeln. Eine versteckte Zeugenmarke kann ein Sprachfragment schützen, bis der Spieler den richtigen Kontext hat. Die Marken sollen schnell, praktisch und müde wirken, nicht theatralisch. Sie sind kein Stimmungsgraffiti. Sie sind Arbeit von Menschen, die wussten, dass der Datensatz schmutzig war und trotzdem essen mussten.

## Scanner

Eine Korrekturmarke kann einen Namen retten, einen Anspruch vergiften oder den nächsten Taucher warnen, dass die offizielle Kategorie lügt.

## Terminal

CORRECTION RULE: Marauder-Marken müssen Beweisinterpretation, Routenrisiko oder Auszahlungsdruck verändern. Gültige Marken bewahren einen Arbeiternamen, fechten eine Versicherungskategorie an, warnen vor einer Route, bepreisen eine Probe, verstecken einen Zeugen oder markieren Schuld. Leeres Graffiti bricht die Beweiskette.

## Field Note

Marken: Namen bewahren, Kategorie anfechten, Route warnen, Probe bepreisen, Zeuge verstecken, Schuld markieren. Handschrift muss die Lesart ändern, nicht die Requisite dekorieren.
