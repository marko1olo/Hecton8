# Feldartikel zu Routentafel und Rückkehrstempel

Eine Druckkolonie kann nicht aus Erinnerung arbeiten. Jede nützliche Tür bekommt irgendwann eine Tafel: Ziel, Lukennummer, Fenster, Werkzeugmarke, Luftschätzung, Pingerkanal, Rückkehrstempel. Es wirkt banal, bis man versteht, dass der Raum damit die Menschen außerhalb seiner Haut zählt.

Deep Reach erfand die Routentafel nicht. Die Crews taten es, weil ein nasser Korridor mündliche Zusagen frisst. Die Firma vergiftete sie, indem sie daraus Haftungssprache machte. Eine vermisste Person wurde verzögert. Verzögert wurde gehalten. Gehalten wurde nicht freigegeben. Wenn die Spalte vor dem nächsten Fenster geändert werden konnte, wurde Versagen zu Planung statt Tod.

Die Spuren zählen mehr als die Überschriften. Fettstift über Salz bedeutet, dass jemand die Wahrheit mit Handschuhen umschrieb. Ein trockenes Stempelkissen heißt, dass Rückkehr erwartet wurde, nachdem der Raum sie nicht mehr tragen konnte. Eine Werkzeugmarke ohne Namen heißt, dass Ausrüstung durch eine andere Hand zurückkam. Ein Name in einer sauberen Spalte kann schlimmer sein als ein gestrichener Name, weil jemand die Tafel ordentlich aussehen lassen musste.

Für einen Marauder ist die Tafel Navigationsinstrument und Anklage zugleich. Sie verrät, welche Luke zuletzt offen war, welche Service-Spine noch Pingerabdeckung hat, wo ein Cache liegen könnte und warum ein Korridor bewohnt statt inszeniert wirkt. Sie zeigt auch, wann normale Arbeiter noch praktische Probleme lösten, während die Firma die Akte schon bearbeitete.

Ein Rückkehrstempel ist klein, hässlich und menschlich. Er sagt, dass jemand durch den Druck zurückkam, das Werkzeug abgab und den Raum für eine weitere Zeile ganz machte. Auf HECTON-8 sind die erschreckendsten Tafeln nicht blutig oder voller Parolen. Es sind die Tafeln, auf denen der letzte Tag noch wie eine Schicht aussieht, die Morgen erwartete.

## Scanner

ROUTENTAFEL-NARBE // Name, Luke, Arbeitsfenster, Werkzeugobhut, Luftzählung, Rückkehrstempel. Ein leeres Stempelfeld ist keine Abwesenheit. Dort schuldet der Raum noch jemanden.

## Terminal

SCHICHTTAFEL-VERFAHREN // Namen erst löschen, wenn Rückkehrstempel, Pinger-Eingang, Werkzeugsiegel und Luftzählung übereinstimmen. Tidealarm erlaubt keine Tilgung.

## Audio

Die Tafel war nie eine Karte. Sie war eine Liste von Menschen, denen der Raum noch etwas schuldete.

## Field Note

Wenn eine Tafel zu sauber ist, misstraue ihr. Salz sammelt sich unter ehrlichem Tape. Lügen werden glatt gewischt.
