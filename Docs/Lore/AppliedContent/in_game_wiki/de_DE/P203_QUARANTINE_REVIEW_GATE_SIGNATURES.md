# Signaturen des Quarantine Review Gate

Quarantine-Review-Gate-Datensätze zeigen, wie Sicherheitssprache zu Verzögerung wird. Das Gate braucht keinen Satz, der jemanden zum Sterben bestimmt. Es hält Extraktion aus, solange pressure-biology risk, externe Prüfung und Custody Owner ungeklärt bleiben. In HECTON-8s Beweiskette ist das harte Detail, dass manche Evakuierungshardware noch Strom hatte, als der Hold gesetzt wurde. Ikenna Sors Signatur markiert das Gate, das eine offene Route bis zur Zertifizierung als unsicher behandelte. Das Zertifikat konnte durch Aegirs Relaisverzögerung nicht schnell genug eintreffen, und Deep Reach hatte nicht genug unabhängigen Lift reserviert, um die Verzögerung auszuhalten.

## Scanner

Prüfkarte geborgen: extraction state HELD, Gefahrenfeld BIO/PRESSURE-UNCERTAIN, externes Zertifikat fehlt. Routenfreigabe durch gate code blockiert.

## Terminal

SIGNATURE SEED: Ikenna Sor, Quarantine Review Gate. Queue: Evacuation release. Aktion: Extraktion bis pressure-biology certificate und externer Prüfung halten. Ausnahme: keine unabhängige Shuttle-Kapazität zugewiesen. Human tags bleiben lokal in Custody, bis das Gate frei ist.

## Audio

Die Tür hatte noch Strom. Das Gate sagt review pending, und die Luke blieb rot.

## Field Note

Leg das neben verriegelte Überlebendenrouten und Evakuierungshardware mit Reststrom. Das Hold-Feld machte eine funktionierende Tür rechtlich geschlossen.
