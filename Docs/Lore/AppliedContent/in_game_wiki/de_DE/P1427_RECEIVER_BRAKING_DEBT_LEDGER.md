# Empfänger-Bremsschuld-Ledger

Nearlight-Reisen machten Entfernung nicht harmlos. Sie machten Entfernung abrechenbar. Menschliche Schiffe kreuzen zwischen Sternen, weil alte Routen in Teilen besessen werden: beam arrays drücken, pellet lanes füttern, fusion stages verbrauchen, Schilde verlieren Masse, Radiatoren werfen Hitze ab, magsails beißen in Felder, und receiver stations stimmen zu, das zu fangen, was die Route schickt.

Dieses letzte Verb ist das hässliche. Um einen Körper zu fangen, muss ein Empfänger Bremsschuld akzeptieren, bevor der Körper ankommt. Er muss Hitzemarge, Quarantänevolumen, medizinische custody, rechtliche Exposition und das Recht reservieren, zu sagen, wer zahlt, wenn der Stopp misslingt. Ein signal packet braucht das meiste davon nicht. Ein versiegelter evidence hash kann über ein relay reisen. Eine Frachtkiste kann einem Jahre vorher geschriebenen Plan folgen. Ein lebender Operator in einem gebrochenen Ozean-claim ist eine andere Art Masse.

Darum kann HECTON-8 verbunden und verlassen zugleich wirken. Black Keel kann dich durch ein relay window hören. Ein broker kann dein sample bepreisen. Ein public ledger kann festhalten, dass dein distress hash existierte. Keiner dieser Fakten erzeugt braking rights für deinen Körper. Rettung wird erst möglich, wenn signal, custody, receiver liability, Quarantäne, Himmelstiming, lift mass und echte hardware zusammenpassen. Bis dahin schweigt das System nicht. Schlimmer: Es ist lesbar.
