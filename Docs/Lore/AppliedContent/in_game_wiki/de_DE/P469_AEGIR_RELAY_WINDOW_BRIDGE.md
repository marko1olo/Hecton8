# Aegir-Relaisfenster

Aegir kann ein Paket steigen lassen und den Operator unter Wasser lassen. Das Relaisfenster ist zeitweilige Geometrie aus Wetter, Magnetik, Queue, Black-Keel-Carrierposition und Rechtsfreigabe. Es beweist, dass eine Nachricht HECTON-8 verlassen kann; es beweist nicht, dass ein Körper durch dieselbe Öffnung gehoben wird.

## Scanner

RELAISFENSTER // Signalempfangsbahn öffnet. Sturmplume und Aegir-Magnetrauschen bleiben hoch. Bergung blockiert bis Aufstiegspaket, Quarantäne-Handshake und Tonnefenster-Zuteilung frei sind.

## Terminal

AEGIR-RELAISHINWEIS // Kontakt kann durchkommen, bevor Hilfe sich bewegen kann. Paketroute, Zeitmarke, Antennenzustand, Sturmplume, Carrier-Bahn und Verwahrungssiegel sichern. Fensterannahme weist keinen Sauerstoff, keine Hebemasse und keine Operator-Extraktion zu.

## Audio

Signallane öffnet zuerst. Hilfe kommt nur, wenn der Rest der Maschine zustimmt.

## Field Note

Ein empfangener Ping ist kein Rettungsschiff. Markiere das Fenster, sichere die Route und schneide weiter.
