# Schlotschmiede-Prozessschritte

Schlotschmiede-Prozessschritte machen Crafting in HECTON-8 zu einem industriellen Ritual, das physisch bleibt. Der Spieler trägt keinen Fantasieofen in der Tasche. Die Schmiede ist ein Ort, an dem Ozean, geothermischer Schlot und ruinierte Koloniehardware kurz übereinstimmen. Zuerst wird der Rohling gespült, damit alte Salzlake nicht darin kocht. Dann wird er vor dem Schlotpuls geklemmt, beim Druckanstieg vorgeheizt, im kurzen Drucktief versiegelt und im kalten Rückstrom abgeschreckt. Der abschließende akustische Ring ist keine Verzierung; er beweist, dass das Teil einen sauberen Körper trägt statt versteckter Risse. So erhält Crafting einen Rhythmus, den die Welt mit VFX, Audio und UI unterstützen kann. Hitze zählt, aber Timing zählt mehr. Ein verpasstes Fenster erzeugt keinen mysteriösen Fehlzustand. Es erzeugt verzogenen Schrott, Salzblüte oder ein druckgerissenes Bauteil, das dem Spieler genau sagt, was schiefging.

## Scanner

Schlotschmieden ist keine magische Metallarbeit. Es leiht Hitze, Druck und Timing des Planeten, ohne dem Planeten das Teil zu überlassen.

## Terminal

SCHLOTSCHMIEDE / 01 Salzlake aus Rohling spülen / 02 vor Puls klemmen / 03 bei Schlotanstieg vorheizen / 04 im Drucktief versiegeln / 05 in Kaltstrom abschrecken / 06 per akustischem Ring zertifizieren / Fehler: verzogener Schrott, Salzblüte oder druckgerissenes Teil.

## Audio

Der Mond ist der Ofen. Du darfst ihn nur ausleihen.

## Field Note

Der Prozess muss als Spülen, Klemmen, Vorheizen, Versiegeln, Abschrecken, Ringtest lesbar sein. Das Risiko ist nicht Flamme, sondern das verpasste Drucktief.
