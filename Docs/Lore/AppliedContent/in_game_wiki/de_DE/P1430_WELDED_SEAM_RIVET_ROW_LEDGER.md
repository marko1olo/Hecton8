# Protokoll für Schweißnähte und Nietreihen

Schweißnähte und Nietreihen sind die Stellen, an denen die saubere Geometrie der Kolonie gesteht. Werkslinien wiederholen geduldig: Abstand, Fase, Dichtung, Prüfstreifen. Feldreparaturen sprechen anders. Sie stolpern, schwellen, überdecken alte Farbe und hinterlassen Hitze dort, wo kein Startplan Hitze erwartete.

Die Reihenfolge erzählt. Eine Nietreihe unter späterer Schweißung bedeutet, dass der ursprünglichen Befestigung nicht mehr vertraut wurde. Salz unter der Raupe zeigt, dass die Fuge mehrmals Wasser atmete. Ein halb begrabener Dichtungskanal bedeutet Stärke statt Wartbarkeit. Gerissene Plattenkanten neben sauberer Raupe sprechen meist von Eile: genug Zeit zum Schließen, nicht genug für Ehrlichkeit.

Für einen Marodeur kann eine reparierte Naht besser sein als eine Karte. Sie führt zu einem Raum, der leckte, einem Schott, das bog, einer Crew mit Werkzeug aber ohne Ersatzteil, oder Bergungstrupps, die dieselbe Wunde später nicht als Reparatur, sondern als Beute öffneten.

## Scanner

## Terminal

NAHTLESUNG // Schweißung über Dichtung: Reparatur nach Kompression. Rost unter Nieten: wiederholtes feuchtes Atmen, keine Einzelflut. Heller Kratzer auf Raupe: Werkzeugtest nach Druckzyklen.

## Audio

Eine Schweißnaht ist eine Signatur aus Hitze. Eine Nietreihe kann über Rhythmus nicht lügen.
