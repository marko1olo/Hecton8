# Noor Haldane: Evakuierungszertifikat

Noor Haldane ist die rechtliche und zertifizierende Deep-Reach-Stimme hinter Evakuierungssperren. Ihre Signatur ist nicht als Panik geschrieben. Sie ist als Kontrolle geschrieben. Die Route muss zertifizierbar bleiben. Der Träger muss Verwahrung akzeptieren. Der biologische Zustand muss prüfbar bleiben. Die Rechtskette muss die Katastrophe überleben, selbst wenn die Menschen in der Route es nicht tun.

Darum schmerzt Haldanes Akte. Die Sprache kann sich verteidigen. Quarantänebruch kann Kontamination verbreiten. Unzertifizierte Extraktion kann Träger stranden lassen. Hafenverweigerung kann Rettung in eine weitere Katastrophe verwandeln. In einem sauberen Sitzungsraum klingt jede Klausel wie verantwortliche Eindämmung. In einem Druckkorridor mit steigendem Wasser werden dieselben Klauseln zum Schloss.

Für den Spieler verbindet dieser Artikel Kolonie-Routensperren, medizinische Verzögerungen und Deep-Reach-Haftung. Haldane muss niemanden hassen. Sie muss Evakuierung nur auf die Bedingungen warten lassen, die beweisen, dass Evakuierung sicher ist. Druck wartet nicht. Sauerstoff wartet nicht. Das Zertifikat wartete.

## Scanner

ZERTIFIZIERUNGSSPERRE // N. Haldane hielt die Route rechtlich sauber, während die Route physisch versagte.

## Terminal

HALDANE, N. // Rechtsberatung Evakuierungszertifizierung // Freigabe verweigert, bis Druck-Bio-Quarantäne, Trägerverwahrung und externe Routenprüfung erfüllt sind. Unautorisierte Extraktion kann Anspruchskette, Habitat-Haftung und nachgelagerte Hafenannahme gefährden.
