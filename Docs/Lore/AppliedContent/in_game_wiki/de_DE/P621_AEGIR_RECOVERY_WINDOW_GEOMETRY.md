# Aegir-Bergungsfenster-Geometrie

Eine geborgene Aegir-Fensterkarte erklärt, warum Black-Keel-Kontakt keine Rettung ist. Ein Signal kann durch einen Pass passen, während Körper, Aufstiegskapsel, Quarantäneanspruch, Beweispaket und Nutzlastmasse an derselben Geometrie scheitern. Die erste Reparatur bringt nur einen Platz auf der Uhr.

## Scanner

FENSTERUHR // Black Keel kann in diesem Pass ein Paket empfangen. Körperbergung braucht weiter Aufstiegshardware, Quarantäne-Handshake, Freigabe aus Kestrels Relaisschatten und eine akzeptierte tonne-window-Massenzeile.

## Terminal

KEELMARK BERGUNGSHINWEIS // Signalempfang ist keine Hebegenehmigung. Trägerphase, Sturmdecke, Relaisschatten, Quarantänefreigabe, Zustand des Aufstiegspakets und akzeptierte Nutzlastmasse vor der Bergungsanfrage abgleichen.

## Audio

Black-Keel-Relais: Paket empfangen. Körper nicht in diesem Fenster. Aufstiegspaket versiegelt halten, Beweise getaggt halten und keine Luft für die Freude über eine Zahl verbrauchen.

## Field Note

Wenn der Träger antwortet, verbrauche keine Luft zum Feiern. Eine Antwort ist Geometrie plus Buchhaltung. Rettung beginnt, wenn Fenster, Siegel, Nutzlast und Körper in dieselbe Zeile passen.
