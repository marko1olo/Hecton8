# Arbeitskarten der Arbeiter

Eine Arbeitskarte ist die kleinste Biografie der Kolonie. Sie braucht keine Kindheit, Romanze oder Rede, um zu zählen. Sie braucht Rolle, Erlaubnisstempel, letzte Aufgabe und das, was der Arbeiter nach dem nächsten Ton beenden wollte. Wenn der Spieler diese Karten findet, hören Menschen auf, Hintergrundopfer zu sein, und werden Routenbeweise: Jemand hielt den Pumpenschlüssel, verzögerte eine Luke, kochte für eine Crew, trug einen Cutter aus, zertifizierte eine Dichtung oder verpasste die Rückkehr, weil das System Hilfe warten ließ.

## Scanner

JOB CARD // Name, Rolle, letzte Aufgabe, Routenerlaubnis, Werkzeugzertifikat. Ein Gesicht, das das Budget lesen konnte.

## Terminal

BEWEISREGEL: Jeder geborgene Name soll an eine Handlung gebunden sein: Pumpenroute, Küchenledger, Med-Bay-Ruf, Cutterverwahrung, Druckcheck, Fabrikationscharge. Eine Aufgabe macht einen Namen zum Beweis.

## Audio

Ein Name ohne Aufgabe wird zum Schrein. Eine Aufgabe macht ihn zum Beweis.

## Field Note

Mach Namen nützlich, bevor du sie tragisch machst.
