# Kodexkarte: sensorgetaggte Fauna

Sensorgetaggte Fauna ist eine der klarsten Arten, HECTON-8s Maschinenökologie zu sehen, ohne den Ozean in einen Geist zu verwandeln. Deep Reach markierte Tiere, shell colonies und Routenarten für Studien zu Migration, Drucktoleranz und Kontamination. Jahre später liegen manche Tags in Narbengewebe, Schalensockeln, Mineralcaps oder Wachstumsringen. Atlas kann noch immer eine schwache Rückkehr hören und den bewegten Körper als Diagnoselandmarke behandeln: Druck-packet, Kontaminationshinweis, Routen-occupancy, Anker für drone sweep, veralteter Wartungszeuge. Das macht das Tier nicht gehorsam. Es kann aus normalen Gründen grasen, fliehen, jagen oder panisch werden, während der Tag seinen Weg für kaputte Infrastruktur bedeutsam macht. Lies Tagbewegung nicht als Absicht. Schneide keinen lebenden Tag heraus, wenn der Routenpreis Grausamkeit und schmutzige Daten nicht rechtfertigt. Die nützliche Frage lautet nicht „was will es?“, sondern „welches System glaubt noch, dass diese Narbe ein sensor ist?“

## Scanner

Sensorgetaggte Fauna. Alter Deep-Reach-Biometalltag in Narbe, Schale oder Wachstumsring. Schwaches Atlas-Routenecho; Tierabsicht nicht bestätigt.

## Terminal

PROBE / SENSORGETAGGTE FAUNA / Rolle: lebender Telemetrieträger, veralteter Vermessungsmarker, Störung der Reparaturroute / sichere Lesung: alter Tag-Puls, Narbenwachstum, Bewegung ohne Befehl / verwerfen: Verhalten als Gehorsam lesen, Tag aus lebendem Körper schneiden, occupancy echo vertrauen / Routennotiz: Der Tag kann melden, welchen Raum das Tier kreuzte, nicht warum.

## Audio

Es gehorcht Atlas nicht. Es trägt eine alte Frage, die Atlas noch immer stellt.

## Field Note

Der Tag ist eine Narbe, keine Leine. Er kann dich melden, falsch platzieren oder etwas wecken, das das Tier nie gesehen hat.
