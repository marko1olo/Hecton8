# Finale Frage: Öffentliches Register, verlorene Kontrolle

Die öffentliche Registerroute tauscht Verwahrung gegen Quittung. Das Paket verlässt das Becken mit Zeugenhash, Haftungskette, Atlas-Zustandsauszug, redigierten Blau-Schuld-Koordinaten und Nutzlast-Routenbeleg, bevor Deep Reach das Archiv allein schließen kann. Das schützt Namen vor einfacher Löschung, gibt die Datei aber auch Regulierern, Gläubigern, Überlebendennetzen, Domaingerichten, Wettbewerbern und jedem Empfänger, der zuerst einreicht.

## Scanner

ÖFFENTLICHE-REGISTER-ACHSE // Tau/Luyten-Paketnotariat akzeptiert Zeugenhash vor vollständiger Verwahrung. Deep Reach verliert alleinigen Archivabschluss; Sender verliert Empfängerreihenfolge.

FINALE ACHSE / ÖFFENTLICHES REGISTER

Verloren: Empfängerreihenfolge, Marktauslegung, Kontrolle der ersten Ankunft.

## Audio

Der Stempel rettet die Datei. Er wählt nicht, wer sie liest.

## Field Note

Eine öffentliche Quittung macht Löschen teuer. Sie startet auch Sanktionstische, Routensperren, Rettungsstreit, Kopieeinreichungen und Koordinatenjagd, bevor ein Schiff Aegir erreicht.
