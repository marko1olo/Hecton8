# Aegir Sky Window Machine

Aegirs sichtbarer Himmel ist route machinery, keine Kulisse. Mondschatten können relay confidence brechen, Stürme können den body schützen und upload töten, und eine klare carrier line kann noch an radiation, tide, Quarantäne oder mass checks scheitern. Lies sky windows als gestapelte Tore: packet, body, proof und salvage teilen nicht zwingend denselben pass.

## Scanner

SKY-WINDOW-READ // Sichtbar klarer Himmel ist keine rescue clearance. Kestrel-Schatten, storm ceiling, radiation count, tide load und carrier phase widersprechen sich.

## Terminal

AEGIR ROUTE PLATE // Fensterstatus ist teilweise. Packet line kann offen sein, während ascent body, Quarantäne und tonne-window mass geschlossen bleiben.

## Audio

## Field Note

Der Himmel kann für ein packet offen und für deinen body geschlossen sein. Prüfe die ganze Maschine, bevor du feierst.
