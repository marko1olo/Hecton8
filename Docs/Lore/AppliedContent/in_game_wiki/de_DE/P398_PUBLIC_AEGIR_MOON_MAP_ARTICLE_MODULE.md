# Aegir-Mondroutenkarte

Aegirs Monde gehören zum Routensystem. HECTON-8 ist der Ozeanmond unter dem Spieler, doch der Rest der Leiter verändert, was gehört, bepreist, verborgen oder bewegt werden kann. Ein kleiner Körper kann eine Relaislinie schneiden. Ein Eisstreupfad kann ein Paket beschädigen. Eine Gezeitenphase kann einen Bathydrop-Aufstieg billig und danach tödlich machen. Öffentliche Karten zählen, weil der Himmel über dem Wasser keine Dekoration ist; er ist eine der Maschinen, die entscheiden, ob ein Anspruch abgehen kann.

## Scanner

Systemkartendatensatz. Mondlabel setzen Relaisalter, Gezeitenlast, Strahlenschutz, Eisstreuung, Bedeckungsbänder, tote Baken und Bergungsgeometrie.

## Terminal

ÖFFENTLICHER ARCHIVKNOTEN // AEGIR-MONDLEITER. Mondname ist Routendatum. Pflichtfelder: Signalalter, Gezeitenphase, Sturmschutz, Anspruchsfenster, Bakenstatus, Aufstiegsrisiko.

## Audio

Ein Mond auf der Karte ist keine Kulisse. Er ist ein Grund, warum die Antwort spät kam.

## Field Note

Marauder-Notiz: Markiere den Mond, dann notiere, was er mit Signal, Gezeiten, Masse und Verwahrung macht.
