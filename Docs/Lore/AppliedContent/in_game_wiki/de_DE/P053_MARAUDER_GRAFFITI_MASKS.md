# Marauder-Graffiti-Masken

Marauder graffiti ist keine Dekoration. Es ist field navigation, social warning und anti-surveillance language, eingeritzt an Orten, wo radios verraten, maps ablaufen und official signage lugt, weil sie zu alt ist. Die marks wirken roh, weil sie water, bad lamps, glove tremor und cameras uberleben mussten, die readable intent bestrafen konnten. Ein slash kann silence bedeuten. Ein black ring kann Black Keel ping bedeuten. Ein broken arrow kann zeigen, dass pressure changed seit dem letzten route survey. Die colony hinterliess labels; marauders hinterliessen weather.

## Scanner

Paint code. Slash count markiert noise discipline; black rings markieren carrier-ping danger; broken arrows markieren pressure drift.

## Terminal

ROUTE MASK INDEX: three slashes: hand signals only. Black ring: carrier sweep. Broken arrow: pressure changed since last mark. Salt bloom: cache compromised. Double hook: official route no longer honest.
