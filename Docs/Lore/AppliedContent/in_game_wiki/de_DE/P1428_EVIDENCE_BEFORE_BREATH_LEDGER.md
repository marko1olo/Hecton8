# Beweis-vor-Atem-Ledger

Ein distress hash kann HECTON-8 vor dem Spieler verlassen, weil Beweis klein gebaut ist. Er ist checksum, custody, witness time und eine enge Behauptung darüber, was existierte. Er kann eine relay window in Stücken queren. Er kann gespeichert, bepreist, angefochten und kopiert werden, ohne dass jemand ihn warm halten muss.

Eine Person ist keine solche payload. Ein atmender Körper braucht Temperatur, Druck, Medizin, Kontaminationsbehandlung, route authority, rechtliche custody und einen receiver, der den Stopp besitzen will. Die Route kann deinen Beweis akzeptieren und deine Masse trotzdem verweigern. In HECTON-8 ist das kein Widerspruch. Es ist die Härte eines Systems, das genau weiß, was ein Mensch in Teilen wert ist.

Darum darf das erste beantwortete Paket nicht wie Rettung wirken. Black Keel kann den hash anerkennen. Ein broker kann das sample bewerten. Ein return desk kann Koordinaten, substrate und proof integrity verlangen, während dein Lufttimer weiterläuft. Der Spieler versucht nicht, Zivilisation aufmerksam zu machen. Zivilisation weiß es bereits. Die Arbeit ist, den lebenden Körper schwerer ignorierbar zu machen als die Daten, die er erzeugt hat.

## Scanner

DISTRESS-HASH-NOTAR // Salzzerfressene Cradle mit intaktem witness seal. Paket akzeptiert: identity hash, sample hash, time window, pressure telemetry. Person nicht akzeptiert. Lebenserhaltung bleibt eine eigene Rechnung.

## Terminal

RETURN ACTION QUEUE // Beweiskette verifiziert. Rettungssprache ausgesetzt, bis route ownership, breathing-mass custody, Quarantänekoje und lift reservation zugewiesen sind. Acknowledgement nicht mit extraction verwechseln.

## Audio

Beweis reist, weil er nicht hustet, nicht panisch wird, nicht friert und keinen Sitz braucht.
