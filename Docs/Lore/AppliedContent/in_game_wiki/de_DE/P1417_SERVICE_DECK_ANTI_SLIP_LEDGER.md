# Protokoll für nasses rutschhemmendes Servicedeck

Ein HECTON-8-Servicedeck ist kein generischer Boden. Es ist die letzte Handschrift der Kolonie. Das rutschhemmende Profil hielt Stiefel im Normalbetrieb fest und wurde danach zum Schreiber. Salz bleibt auf Rippen, Öl in Rinnen, gelbe Farbe verschwindet in Halbmonden dort, wo Menschen mit Werkzeug oder Flaschen drehten.

Der Spieler kann ein nasses Deck vor dem Eintritt lesen. Eine helle Linie über dunklem Metall bedeutet wiederholten Durchgang nach der Flutung. Ein sauberer Halbkreis an einer Luke zeigt häufige Drehung. Ölige Spuren bergab von einem Wagen zeigen einen Leckpfad. Rost über eine ganze Naht bedeutet lange keine Öffnung; unterbrochener Rost bedeutet spätere Bewegung.

So hilft Material ohne Wegweiser. Es zeigt sicherere Korridore, gezogene Last, glatte Plattformen oder beweist, dass eine angeblich geschlossene Schleuse nach der Evakuierung noch lief.

## Scanner

SERVICEDECK // Dunkles rutschhemmendes Metall, abgenutzte weiße und gelbe Farbe, Salzabrieb auf Rippen, ölige Nassspuren in Rinnen. Rost bleibt in Nähten. Die Verkehrslinie biegt zum Luftschleusentor.

## Terminal

DECKLESUNG // Das Profil zeichnet Bewegung auf. Helle Rippen bedeuten Stiefelverkehr; dunkle Rinnen Öl- oder Kühlmitteldrift. Gelbe Farbe in Bögen bedeutet Drehen mit Last. Eine Naht erst kreuzen, wenn die Rostlinie geprüft ist.

## Audio

Ein Boden erinnert Panik besser als eine Wand. Menschen lügen nach oben; Stiefel geben die Route.

## Field Note

Frag nicht zuerst, wohin sie gingen. Frag, wo die Farbe aufhörte zu überleben.
