# Domänen-Distanzskala

Die Domänenskala ist eine Druckkarte, keine Reisekarte. Sol Core kann Eigentum aus der Ferne zertifizieren. Centauri kann eine alte Charta sauber klingen lassen. Barnard kann einen Cutter und einen verschuldeten Marauder in Drecksarbeit schicken. Tau Ceti kann Beweise nach Verzögerung öffentlich machen. Luyten kann eine custody-Kette beweisen. Ran/Aegir ist der Ort, an dem diese fernen Kräfte zu Wasser über dem Helm werden.

Darum wirkt HECTON-8 allein, ohne dass das All leer sein muss. Eine Nachricht kann die Route überqueren und doch eintreffen, nachdem Sauerstoff, Gezeit, Hüllentemperatur und Black Keels recovery window bereits entschieden haben. Entfernung löscht Recht nicht aus. Sie macht Recht kälter als Rettung.
