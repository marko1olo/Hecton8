# Spind-Beweisvarianten

Ein Spind auf HECTON-8 ist kein sentimentaler Stapel. Er ist ein kleines Archiv eines Druckraums: was ein Arbeiter berührte, was er tragen durfte, was er vor der Schichtleitung versteckte und was ein späterer Marauder korrigieren wollte.

Gute Varianten sprechen durch Kombinationen. Druckband neben einem Handschuh weist auf Leckarbeit. Eine abgenutzte Dichtung bei persönlichen Werkzeugen sagt, dass diese Person Türen oft genug handhabte, um Ersatzteilen zu misstrauen. Essensgutschrift neben Routen-Kreide heißt, dass noch mit einer nächsten Schicht gerechnet wurde. Eine Medlock-Ablehnung macht aus Kulisse Beweis: Jemand sollte weiterarbeiten, obwohl der Körper schon als Kostenproblem galt.

Für das Spiel ist der Spind eine seedbare menschliche Spur. Inhalte können wechseln, ohne den großen Kanon zu ändern. Stabil bleibt die Regel: lesen vor plündern. Wer Marke, Dichtung und Notiz als Schrott nimmt, löscht die Grammatik, die einen Arbeiter ohne Zwischensequenz anwesend machte.

## Scanner

SPIND // Druckband, abgenutzte Dichtung, Essensgutschrift, Werkzeugmarke, Routen-Kreide und Medlock-Ablehnung liegen auf einem Fach. Letzter praktischer Bestand eines Arbeiters, keine Dekoration.

## Terminal

SPINDVARIANTEN // Reihenfolge vor Bergung lesen: Druckband bei Handschuhen = Leckarbeit; abgenutzte Dichtung = wiederholte Luken; Essensstreifen = Schichtschuld; Kreide = improvisierte Route; Medlock-Ablehnung = krank weiterarbeiten; Marauder-Notiz = späterer Beweisstreit.

## Audio

Das beste Denkmal ist keine Plakette. Es ist ein Werkzeug, das noch weiß, welche Hand müde war.

## Field Note

Dekoriere keine Spinde. Baue sie aus Dingen, die eine müde Hand wirklich berühren musste.
