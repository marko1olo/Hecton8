# Pista de Reconhecimento de Procedimento Antigo

O reconhecimento de um procedimento antigo transforma o passado do protagonista em uma ferramenta jogável. O jogador não segue uma pista mística nem uma profecia pessoal. Ele lê um formulário de segurança no qual já precisou confiar. Um selo de rota segura diz que a linha foi certificada. As evidências na sala dizem que a contagem de trabalhadores foi alterada. O campo de testemunha manual, a parte feita para exigir uma segunda checagem humana, foi selado por um escritório de continuidade. Essa contradição é o gancho. A Deep Reach não apenas escondeu uma rota. Ela usou linguagem de proteção ao trabalhador para fazer o abandono parecer administrativamente concluído. O interesse do protagonista começa como reconhecimento profissional: este formulário foi criado para impedir exatamente essa falha.

## Scanner

Selo de rota segura presente. Contagem de trabalhadores sobrescrita em duas tintas. Campo de testemunha manual selado. O formulário foi criado para pegar esse tipo de mentira antes que alguém a transformasse em política.

## Terminal

FORMULÁRIO DE CONTINUIDADE DE EVACUAÇÃO / CERTIFICAÇÃO DE ROTA SEGURA
rota: linha auxiliar de saída
ocupantes declarados: contagem degradada aceita
testemunha manual: selada pelo Escritório de Continuidade
correção de campo: contagem de trabalhadores inconsistente com etiquetas da sala de bombas
status: preservação de reivindicação, sem liberação para extração.

## Audio

Você conhece este formulário. Ele deveria impedir que uma sala fosse contada como vazia enquanto ainda havia pessoas respirando nela.

## Field Note

O formulário deveria forçar outra contagem. Aqui, forçou silêncio.
