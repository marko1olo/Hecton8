# Rastro de Linguagem de Acesso Revogado

A linguagem de acesso revogado é uma das travas mais quietas da Deep Reach. Um ex-trabalhador pode ser recusado na porta enquanto o texto de negação ainda expõe o procedimento por trás da rota selada. A trava não precisa confessar. Só precisa usar as palavras antigas erradas.

Maintenance reclassification significa que uma rota humana foi feita parecer material de serviço. Degraded-count significa que uma contagem de trabalhadores foi aceita depois do ponto em que deveria ser conferida de novo. Claim-preservation routing significa que a empresa protegeu a propriedade da linha antes dos corpos na linha. Cada frase é pequena o bastante para passar como linguagem de escritório e específica o bastante para apontar para o corredor enterrado.

Isso torna a credencial morta útil de forma limitada. Ela não abre a escotilha. Pode forçar o arquivo a falar em seu antigo dialeto de responsabilidade, e esse dialeto é um mapa.

## Scanner

RASTRO LOCKOUT // Texto de negação cita maintenance reclassification, continuity hold e route materials. A porta rejeita o crachá, mas vaza a rota enterrada.

## Field Note
