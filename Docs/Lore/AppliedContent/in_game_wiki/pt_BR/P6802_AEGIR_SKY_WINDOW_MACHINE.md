# Máquina de janela do céu de Aegir

O céu visível de Aegir é route machinery, não cenário. Sombras lunares podem quebrar relay confidence, tempestades podem proteger body enquanto matam upload, e uma carrier line limpa ainda pode falhar em radiation, tide, quarentena ou mass checks. Leia sky windows como portões empilhados: packet, body, proof e salvage talvez não compartilhem o mesmo pass.

## Scanner

LEITURA SKY WINDOW // Céu visualmente limpo não é rescue clearance. Sombra Kestrel, storm ceiling, radiation count, tide load e carrier phase discordam.

## Terminal

ROUTE PLATE AEGIR // Estado de janela é parcial. Packet line pode estar aberta enquanto ascent body, quarentena e tonne-window mass seguem fechadas.

## Audio
