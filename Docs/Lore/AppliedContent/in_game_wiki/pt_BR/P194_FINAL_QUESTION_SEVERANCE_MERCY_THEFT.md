# Pergunta final: corte, misericórdia, roubo

O corte força o jogador a decidir o que a continuidade Atlas-oceano virou. Se é só ferramenta quebrada, cortar é reparar. Se é sistema vivo, cortar é matar. Se é testemunho, cortar pode destruir prova.

## Scanner

Cortar Atlas não é apertar um botão de desligar. É cirurgia sem anatomia limpa.

## Terminal

EIXO DE CORTE: cortar continuidade de Atlas, isolar ecologia de pressão, negar roteamento de payload para Deep Reach, arriscar colapso da bacia ou preservar só memória parcial de reparo. O sentido depende das provas levadas à sala final.

## Audio

Um interruptor limpo seria misericordioso. Você não recebe um.

## Field Note

O mesmo ato pode libertar trabalhadores presos, matar vida oceano-máquina, negar Deep Reach e roubar uma infraestrutura viva de si mesma.
