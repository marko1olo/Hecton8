# Cartão Inicial de Contrato com Lien do Jogador

O Cartão Inicial de Contrato com Lien do Jogador fixa o protagonista de HECTON-8 como profissional comprometido, não turista inocente. O jogador começa com um motivo prático: salvage contract, lien de dívida, conhecimento de acesso antigo e confiança suficiente para acreditar que isso é trabalho. Isso importa porque o jogo não precisa de lost-relative hook para tornar a descida pessoal. A pressão pessoal vem das evidências. Uma antiga Deep Reach field key ainda ser reconhecida pela Black Keel não é conveniência; é aviso de que o sistema antigo nunca esqueceu totalmente o operador. O contrato dá ao jogador uma razão para entrar no oceano e uma razão para interpretar mal o primeiro perigo. Ele acha que está lendo um job file. O arquivo também lê ele: clearance anterior, familiaridade de rota, liability history e beneficiary conflict. Quando o jogador entende que o antigo empregador não é só pano de fundo, o lien já transformou curiosidade profissional em custódia.

## Scanner

O cartão inicial não transforma você em vítima escolhida. Transforma você em ex-profissional da Deep Reach com um lien, uma chave e um motivo para mentir para si.

## Terminal

INÍCIO DO CONTRATO / operador: salvage contractor independente / acesso antigo: Deep Reach field key, inativa mas reconhecida / lien: ativo / motivo declarado: claim value / pressão não declarada: prior exposure, familiaridade de rota, beneficiary conflict.

## Field Note

Sem lost-relative hook. O motivo começa como trabalho: salvage value, field access antigo, exposição profissional, pressão pessoal mascarada.
