# Conflito de Resumo Seguro para Reclamante

Um resumo seguro para reclamante nao e versao curta neutra, mas reescrita protegida. Pode remover nomes, arredondar coordenadas, trocar lesao por categoria, suavizar verbo de rota ou substituir o escritorio autorizado a responder. Pode proteger pessoas; a Deep Reach tambem pode usar essa linguagem para enterrar alavanca. O conflito com o objeto bruto e prova do que foi omitido.

## Scanner

CONFLITO DE RESUMO // Texto publico omite ou suaviza fatos que a evidencia bruta ainda implica. Omissao e trilha de prova.

## Terminal

CONFLITO DE RESUMO SEGURO
Resumo seguro para publico. Objeto bruto talvez nao.
Nao restaure nomes ou coordenadas por palpite.
Preserve lista de omissoes, prova de rota e marcador de risco.
