# Conjunto A de Nomes Âncora de Trabalhadores

O Conjunto A de Nomes Âncora de Trabalhadores é a primeira camada humana que o jogador deve começar a reconhecer. Mara Venn, Juno Kade, Ren Okoye, Sahana Iqbal, Lian Torres, Oskar Neumann, Aya Morita e Pavel Sorn pertencem às evidências dos rasos e da plataforma industrial. Seus nomes não devem chegar como biografias. Devem chegar numa etiqueta de armário, tag de bomba, permissão de rota, vale-refeição manchado, caixa de ferramenta rachada, e depois voltar num registro que muda o significado. Set A faz a colônia parecer vivida antes que a conspiração profunda fique clara.

## Scanner

Nomes iniciais devem voltar por meio do trabalho, não de discursos. A rota rasa ensina memória pela repetição.

## Terminal

ANCHOR SET A: recorrência nos rasos e na plataforma industrial. Cada nome deve se ligar a uma ferramenta, uma permissão de rota, um objeto de trabalho danificado e uma contradição posterior. Esses nomes são a primeira prova do jogador de que a colônia era um local de trabalho antes de virar salvage.

## Audio

Não lamente o nome até a ferramenta dizer por quê.

## Field Note
