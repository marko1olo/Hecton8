# Protocolo blind return com retenção do payload

O protocolo blind return recusa todos os receptores. Nenhuma corporação, livro, lane de quarentena ou alvo de corte recebe o payload final. O portador mantém mapa e provas locais, negando à Deep Reach uma rota limpa de volta. Também deixa dívida ativa, prova pública não protocolada e o pacote vulnerável a água, morte ou armazenamento ruim.

## Scanner

Rota blind return armada. Nenhum receptor designado. Vetor da bacia, proof hashes e classe de acesso permanecem locais; lien e janela de recuperação seguem sem resolução.

## Terminal

RECEPTOR PAYLOAD // BLIND RETURN WITHHOLD. Receptor: nenhum. Reter vetor da bacia, proof hashes, classe salvage, pacote local de provas. Negar à Deep Reach mapa de acesso, recibo de pagamento e custódia receptora. Custo conhecido: lien sem resolução, risco total de perda do pacote.

## Audio

Sem receptor, sem recibo. Se a bolsa alagar, a prova vai junto.

## Field Note

Nota de saqueador: guardar o mapa é uma escolha. Só não dá nenhum receptor para culpar se a bolsa rasgar.
