# Gramática de Nomes Seed-role

A Gramática de Nomes Seed-role é a regra que impede a variação de replay de virar ruído. Um trabalhador seed-role pode aparecer em outro armário, ao lado de outra ferramenta danificada ou sob outra permissão de rota de uma run para outra. A identidade ainda precisa de gramática: nome pessoal estável, família de equipe, contexto de permissão, última tarefa e variante de objeto que possa ser inspecionada. Se uma parte falta, o nome deixa de parecer pessoa e começa a parecer preenchimento gerado. O sistema pode embaralhar a ordem das evidências; ele não deve embaralhar a responsabilidade até ela sumir.

## Scanner

Um seed pode mover a ordem das evidências. Ele não pode transformar um trabalhador em texto descartável.

## Terminal

SEED GRAMMAR: personal_name + crew_family + route_permission + last_task + object_variant. A localização pode anotar termos de equipe para legibilidade, mas não deve reescrever identidade, apagar o trabalho nem separar o nome de um objeto concreto.

## Audio

Aleatório não é autoria. Prenda o nome a um trabalho.

## Field Note

Cada identidade seed-role combina nome pessoal, família de equipe, permissão de rota, última tarefa e variante de objeto.
