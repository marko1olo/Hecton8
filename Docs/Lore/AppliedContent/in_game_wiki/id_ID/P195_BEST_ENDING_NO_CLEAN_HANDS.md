# Rute Terbaik: Sisa Tetap Terlihat

Sisa Tetap Terlihat adalah standar untuk rute terkuat. Ending harus menyelamatkan sesuatu yang konkret tanpa mengubah HECTON-8 menjadi layar hadiah: catatan publik, rute Deep Reach yang ditolak, cekungan yang dipertahankan, operator yang bebas, nama pekerja, atau Atlas proof hash. Catatan juga harus menjaga bidang terbuka untuk kustodi penerima, tanggung jawab, nama hilang, kerusakan cekungan, keadaan Atlas, dan sisa utang.

## Scanner

ATURAN RUTE TERBAIK // Selamatkan hasil konkret: kustodi operator, catatan publik, muatan ditolak, cekungan hidup, paket nama pekerja, atau Atlas proof hash. Biarkan bidang kerusakan terbuka.

## Terminal

STANDAR CATATAN ENDING

Bidang yang wajib terbuka: kustodi penerima, rantai tanggung jawab, nama hilang, kerusakan cekungan, keadaan Atlas, sisa utang.
