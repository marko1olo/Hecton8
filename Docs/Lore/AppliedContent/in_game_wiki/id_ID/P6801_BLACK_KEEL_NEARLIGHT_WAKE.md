# Wake nearlight Black Keel

Black Keel adalah tender klaim sistem Aegir, bukan kapal penyelamat dari Sol. Paket data bisa masuk melalui relay pass kotor sementara tubuh hidup masih gagal pada ascent seal, batas badai, bayangan Kestrel, karantina, dan pemeriksaan tonne-window. Perlakukan kontak carrier sebagai bukti rute: catat jendela, jaga bukti tetap bertag, dan jangan gunakan hardware ascent sampai garis massa menerima payload.
