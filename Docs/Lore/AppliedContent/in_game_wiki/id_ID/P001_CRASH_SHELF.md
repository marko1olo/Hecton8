# Paparan Jatuh

Bathy-drop dibuat untuk satu pekerjaan kasar: masuk atmosfer, bertahan dari geseran badai, menghantam laut, membuang panas, dan menjaga satu operator tetap hidup cukup lama untuk mulai bekerja. Itu bukan kapal. Itu adalah perdebatan sekali pakai dengan fisika. Black Keel masih berada di atas bulan, di suatu tempat dalam lalu lintas Aegir, tetapi inti uplink kapsul retak dan perangkat naik hilang. Penyelamatan bersih membutuhkan daya, waktu, jendela orbit, dan pemancar yang mampu menembus cuaca, air, serta derau magnetik Aegir.

## Scanner

Rongsokan kapsul bathy-drop. Rangka tekanan utuh, paket naik hancur. Ini bisa membuatmu hidup, bukan membawamu pulang.

## Terminal

PAKET NAIK: hilang. INTI UPLINK: retak terdeteksi. KONTAK CARRIER: tertunda.

## Audio

Handshake Black Keel diterima. Integritas paket di bawah ambang pemulihan. Ulangi: ambang belum tercapai.

## Field Note

Kalau cangkang kapsul masih menahan tekanan, jangan lucuti habis. Tempat berlindung buruk lebih berharga daripada inventaris rapi.
