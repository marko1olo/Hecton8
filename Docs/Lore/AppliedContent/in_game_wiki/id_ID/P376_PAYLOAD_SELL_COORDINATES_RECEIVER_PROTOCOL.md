# Protokol Penerima Jual Koordinat Payload

Protokol jual koordinat memperlakukan HECTON-8 sebagai properti yang dapat dipulihkan. Ia mengubah payload akhir menjadi paket penerima untuk Deep Reach: vektor cekungan, grid keyakinan, digest bukti, dan kelas akses salvage. Pengirim menerima uang dan keringanan utang. Deep Reach menerima peta pendekatan dan jalan lebih bersih kembali ke klaim.

## Scanner

Rute penjualan koordinat dipersenjatai. Vektor cekungan, peta keyakinan, dan digest bukti menuju Deep Reach Recovery Compliance.

## Terminal

PENERIMA PAYLOAD // JUAL KOORDINAT. Penerima: Deep Reach Recovery Compliance. Kirim vektor cekungan, grid keyakinan, XO proof digest, kelas akses salvage. Kembali: tanda terima bayar, pengurangan lien, stempel prioritas pemulihan. Peta akses ditransfer saat tanda terima terkunci.

## Audio

Pembayaran beres. Peta ditransfer. Buku pekerja masih terbuka.

## Field Note

Catatan perompak: jika baris pertama adalah jumlah, baca baris kedua. Baris kedua adalah access map transferred.
