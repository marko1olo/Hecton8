# Nomor ruang receiver counterstamp

Receiver counterstamp adalah saat blank berth menjadi named door. Itu dapat membuat recovery lebih sulit diabaikan, tetapi juga menamai siapa yang memiliki tubuh setelah lift. Periksa room class, medical owner, dan receiver strip sebelum mempercayai stamp.

## Scanner

BACAAN COUNTERSTAMP // Quarantine room number ada. Periksa body custody class; sample-only rooms tidak membersihkan living recovery.

## Terminal

RECEIVER ROOM COUNTERSEAL // Blank berth ditimpa owned custody. Lift allocation hanya dengan named room, owner, dan body class.

## Audio

Room number ditulis. Receiver memiliki pintu. Konfirmasi body custody sebelum ascent burn.

## Field Note

Room number adalah pegangan. Tarik hati-hati; beberapa pintu adalah kandang.
