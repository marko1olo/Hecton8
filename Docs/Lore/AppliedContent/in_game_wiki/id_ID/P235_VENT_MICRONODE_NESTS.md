# Sarang Mikronode Vent

Sarang mikronode vent menjelaskan bagaimana Atlas tetap aktif tanpa menjadi komputer penjahat mahakuasa. Jauh di dekat vent, node pemeliharaan kecil memanen gradien panas, mineral, dan getaran. Masing-masing dapat mendorong pulsa lemah ke biofilm, sealant cangkang, fauna bertag, atau logam rusak di dekatnya. Tidak ada yang mengontrol seluruh koloni. Bersama-sama mereka menjaga perilaku perbaikan tetap hidup setelah jaringan bersih hilang.

Ini membuat bioma akhir terasa tumbuh, bukan sekadar dibangun. Sebuah node dapat membangunkan tambalan, memberi makan organ relai, mengeraskan cangkang di atas retakan, atau mempertahankan diagnostik palsu. Ia juga dapat membuat kesalahan lokal, mengulangi pola perbaikan karena tekanan pernah membaik, meskipun rute menjadi tak terbaca. Bagi pemain, sarang mikronode adalah sumber daya, bahaya, bukti, dan mungkin target. Hancurkan satu, dan ruangan bisa diam. Biarkan, dan Atlas terus berbisik lewat material.
