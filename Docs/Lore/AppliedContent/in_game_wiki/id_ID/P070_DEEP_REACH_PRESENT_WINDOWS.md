# Jendela Deep Reach Saat Ini

Jendela Deep Reach Saat Ini menjelaskan bagaimana korporasi yang absen masih bisa menjadi antagonis aktif pada tahun 2190. Tidak ada meja penyelamatan lebih cepat dari cahaya dan tidak ada eksekutif hidup yang mengendalikan HECTON-8 dari kursi dunia inti. Jaraknya nyata: jendela jarang, terlambat, dan disaring melalui tulang punggung relai, proxy lokal, pemberitahuan hukum otomatis, serta bahasa klaim Black Keel. Itu tidak membuat Deep Reach tidak berbahaya. Ketika sinyal menyeberangi jurang, koloni sudah dibentuk oleh kontrak lama, default karantina, ambang pembayaran, dan aturan kustodi. Saat pemain memegang bukti, suara perusahaan terdengar sebagai tawaran: serahkan kunci otoritas Atlas, terima kustodi muatan, tunduk pada tinjauan, dan mungkin dapat pemulihan alih-alih ditinggalkan.

## Scanner

Deep Reach tidak bisa mengemudikan HECTON-8 lewat radio, tetapi jendela tertunda, pemberitahuan proxy, dan klausul Black Keel masih menentukan harga bantuan.

## Terminal

LIVE WINDOW / PROXY DEEP REACH: pemulihan operator bisa dinegosiasikan setelah tinjauan bukti, kustodi muatan, kepatuhan karantina, dan transfer kunci otoritas Atlas. Penolakan mempertahankan status pengklaim tetapi membatalkan prioritas ekstraksi segera.

## Audio
