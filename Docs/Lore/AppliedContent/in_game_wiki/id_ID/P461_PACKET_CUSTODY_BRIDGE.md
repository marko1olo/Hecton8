# Kustodi Paket

Segel paket ditemukan. Black Keel dapat menerima kargo, tetapi bukti perlu sumber, segel, hash saksi, tanda relay, jalur penerima, dan status kerusakan. Simpan tag kustodi sebelum membongkar perangkat.

## Scanner

SEGEL PAKET // Strip hash saksi rusak tetapi masih terbaca. Simpan sebelum potong salvase. Bukti tanpa segel berubah jadi material klaim.

## Terminal

NOTARIS PAKET KEELMARK // Simpan pelat segel, hash saksi, cap rute, dan tag konektor sebelum transfer. Material tanpa cap bisa diproses sebagai rugi klaim.

## Audio

Relay Black Keel: kargo adalah massa. Bukti adalah kustodi. Bawa keduanya, atau jendela menagih selisihnya.

## Field Note

Segel dulu, potong kemudian. Sampel bersih dengan tag patah menjadi milik siapa pun yang memegang ledger.
