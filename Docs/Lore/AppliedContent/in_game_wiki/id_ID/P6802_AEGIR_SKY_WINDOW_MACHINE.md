# Mesin Jendela Langit Aegir

Langit Aegir yang terlihat adalah route machinery, bukan pemandangan. Bayangan bulan bisa merusak relay confidence, badai bisa melindungi body sambil membunuh upload, dan carrier line yang bersih masih bisa gagal pada radiation, tide, karantina, atau mass checks. Baca sky windows sebagai gerbang bertumpuk: packet, body, proof, dan salvage tidak selalu berbagi pass yang sama.

## Scanner

BACAAN SKY WINDOW // Langit yang tampak cerah bukan rescue clearance. Bayangan Kestrel, storm ceiling, radiation count, tide load, dan carrier phase tidak sepakat.

## Terminal

ROUTE PLATE AEGIR // Status jendela parsial. Packet line bisa terbuka sementara ascent body, karantina, dan tonne-window mass tetap tertutup.

## Field Note

Langit bisa terbuka bagi packet dan tertutup bagi body-mu. Periksa seluruh mesin sebelum merayakan.
