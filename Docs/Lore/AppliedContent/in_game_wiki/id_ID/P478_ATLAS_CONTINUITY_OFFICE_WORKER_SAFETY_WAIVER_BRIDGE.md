# Waiver Keselamatan Pekerja Atlas

Waiver tidak menghapus keselamatan pekerja. Ia membiarkan janji terlihat sambil mengalihkan evakuasi lewat kontinuitas, paparan, aset, dan risiko proses. Klausul keselamatan ada. Jalur rilis dialihkan lewat bobot Atlas, risiko Great Tide, dan gerbang tahan evakuasi. Klausul bersih bisa tetap pintu terkunci. Ikuti cap rute, bukan janji.
