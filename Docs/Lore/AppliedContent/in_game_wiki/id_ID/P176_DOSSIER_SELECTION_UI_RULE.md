# Registri Klaim Dosier

Registri klaim dosier adalah formulir intake Black Keel untuk bukti lama, bukan loker peralatan. Dosier yang dipilih dapat membawa catatan akhir lama, keluarga rumor, tekanan lien, syarat kustodi, dan peringatan rute ke kontrak baru. Catatan itu mengubah apa yang dicurigai operator dan apa yang ditagih carrier. Catatan itu tidak mengubah cadangan oksigen, rating hull, senjata, inventaris, atau identitas pekerja yang tertulis dalam klaim.

## Scanner

Registri klaim DR-902. Dosier aktif membuka keluarga rumor, catatan akhir, tekanan lien, syarat kustodi, klausul orbit/cuaca, dan petunjuk urutan bukti. Tidak ada warisan peralatan.
