# Tonne-Window Keelmark

Tonne-window adalah massa yang dapat dipulihkan yang mungkin diangkat Black Keel lewat satu kesempatan orbit setelah bahan bakar, badai, karantina, asuransi, dan prioritas dihitung. Keelmark Mutual membuat pemain terbaca sebagai massa sebelum terlihat sebagai orang. Setiap sampel, paket bukti, utang oksigen, dan rider welfare dapat menggeser angka.

## Scanner

LIEN TONNE-WINDOW // Ekuivalen 4,8 tercatat. Oksigen, adendum welfare, kustodi sampel, dan payload bukti dapat mengubah prioritas massa pemulihan.

LEDGER JENDELA KEELMARK MUTUAL // Lien dasar: ekuivalen 4,8 tonne-window. Penyesuaian dapat mencakup risiko oksigen, adendum welfare, kustodi sampel, payload bukti, tahanan karantina, dan alokasi angkat carrier. Ledger ini memberi harga pemulihan; bukan janji penyelamatan.

## Audio
