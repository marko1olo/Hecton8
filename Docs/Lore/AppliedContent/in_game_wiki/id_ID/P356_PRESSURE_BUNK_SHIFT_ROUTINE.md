# Pressure Bunk Shift Routine

The colony should feel populated by workers, not plot relatives. Shift routines make the loss concrete without turning the player into a family-revenge archetype.

## Scanner

Shift bunk slate. Workers slept by pressure schedule, not by day/night comfort.

## Terminal

BUNK RULE: wake by pump tone, suit check, pressure note, meal token, tool custody, descent assignment. The colony was human because it was repetitive.
