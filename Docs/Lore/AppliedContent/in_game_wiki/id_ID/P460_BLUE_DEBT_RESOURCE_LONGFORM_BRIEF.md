# Blue Debt: Riwayat Tekanan dalam Custody

Blue debt berguna, mahal, dan kotor secara moral. Ini bukan bijih ajaib, melainkan pressure-grown substrate yang nilainya bergantung pada handling, contamination, custody, Atlas compatibility, dan pemilik bukti.
