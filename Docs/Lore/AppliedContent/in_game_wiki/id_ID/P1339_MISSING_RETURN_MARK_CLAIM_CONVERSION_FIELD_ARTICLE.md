# Tanda Kembali Hilang dan Konversi Klaim

Tanda kembali menutup rute. Ia tidak membuktikan pekerja aman; ia membuktikan meja rute berhenti menghitung pekerja itu sebagai bergerak. Tanda itu bisa berupa kembali, batal, transfer medis, pengecualian pemulihan, atau kode hilang. Tanpa itu, rute tetap terbuka secara administratif.

Rute terbuka adalah bukti berbahaya. Deep Reach bisa menunjuknya dan berkata pekerja masih ditugaskan, masih dapat dicapai, masih bagian operasi aktif. Ruangan bisa membuktikan sebaliknya. Tag setelan dingin, tether terpotong, baris triase dengan oksigen berhenti, atau gores palka setelah jendela rute mengubah kolom kembali kosong menjadi kegagalan custody.

Konversi klaim terjadi saat meja belakangan memakai rute terbuka untuk mengklasifikasi ulang media. Transkrip berhenti menjadi catatan darurat dan menjadi massa pulih, peralatan tercemar, keterlambatan tertagih, atau properti salvage. Tanda hilang tidak menyelesaikan kematian. Ia menunjukkan tempat dokumen menolak menutupnya.

Di lapangan, simpan cap sebelum membersihkan garam. Bandingkan rute terbuka dengan potong oksigen, tag setelan, baris triase, dan masker packet notary. Jika rute tetap terbuka setelah bukti tubuh menutupnya, meja itu melindungi klaim, bukan pekerja.
