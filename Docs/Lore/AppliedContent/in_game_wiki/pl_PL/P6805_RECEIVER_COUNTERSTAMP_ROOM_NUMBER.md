# Numer sali z receiver counterstamp

Receiver counterstamp to chwila, w której blank berth staje się named door. Może utrudnić ignorowanie recovery, ale także nazywa tego, kto posiada ciało po lift. Sprawdź room class, medical owner i receiver strip, zanim zaufasz stamp.

## Scanner

ODCZYT COUNTERSTAMP // Quarantine room number obecny. Sprawdź body custody class; sample-only rooms nie czyszczą living recovery.

## Terminal

RECEIVER ROOM COUNTERSEAL // Blank berth nadpisany przez owned custody. Lift allocation tylko przy named room, owner i body class.

## Audio

Room number wpisany. Receiver posiada drzwi. Potwierdź body custody przed ascent burn.

## Field Note

Room number to uchwyt. Ciągnij ostrożnie; niektóre drzwi są klatkami.
