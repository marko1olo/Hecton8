# Dryf kolejki przekaźnika

Opóźniona łączność jest groźna, bo może pozostać dokładna w złym czasie. Ostrzeżenie przewoźnika może opisywać prawdziwy zawór, prawdziwy wyciek i prawdziwą trasę, która już zmieniła się pod ciśnieniem. Gracz porównuje wiek pakietu z lokalnym dowodem.

## Scanner
