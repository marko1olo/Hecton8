# Medyczny ledger triage

Medyczny ledger nie powinien robić z HECTON-8 widowiskowego gore. Jego siła jest chłodniejsza. Pacjent staje się pressure-state, potem długiem tlenu, opóźnieniem śluzy, holdem certyfikacji. Medycy mogą znać właściwe leczenie i nadal stracić pacjenta, bo właz, zegar trasy albo signoff Deep Reach opóźnia pomoc. Ledger jest ludzki, bo pokazuje ludzi próbujących być precyzyjnymi, gdy system czyni precyzję bezużyteczną.

## Scanner

TRIAGE LEDGER // Uraz ciśnieniowy, hipoksja, opóźnienie śluzy, brak trasy, hold certyfikacji. Groza tkwi w tym, jak schludnie pomoc czekała.

## Terminal

REGUŁA MEDYCZNA: liczyć ciała bez gore. Używaj pressure-state, długu tlenu, opóźnienia trasy, priorytetu triage i signoff hold, by pokazać, jak procedura tworzyła pacjentów szybciej, niż medycy leczyli.
