# Przyjęcie roszczenia Black Keel

Odzyskany tekst kontraktu pokazuje, że praca zaczyna się od nacisku długu, nie od ratunku. Black Keel daje zejście, ulgę długu i wąskie okno trasy, ale zatrzymuje payload custody.

Konsola kontraktu. Aegir Reclamation Pool pokazuje zastaw 4.8 tonne-window, zanim pokaże tlen.
