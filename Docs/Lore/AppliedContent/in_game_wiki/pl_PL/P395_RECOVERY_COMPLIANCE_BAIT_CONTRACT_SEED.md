# Ziarno kontraktu-przynęty zgodności odzysku

Kontrakty-przynęty zgodności odzysku wyglądają jak hojne zlecenia ratunkowe, ale łańcuch odbiorcy jest już wygięty ku Deep Reach. Wypłata jest prawdziwa. Kosztem jest ukryty obowiązek ujawnienia miejsca znalezienia wraku, znacznika zwłok, skrzyni próbek albo zaplombowanej maszyny.

## Scanner

Ziarno kontraktu: przynęta zgodności odzysku. Wysoka wypłata, skażony łańcuch odbiorcy, ukryte żądanie współrzędnych.
