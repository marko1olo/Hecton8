# Pętla sprzężenia fauny z tagiem sensorowym

Deep Reach tagował lokalną faunę, by mapować prądy, chemię i migracje. Wiele tagów przetrwało załogi. Atlas nadal czyta je jako dane pomiarowe, więc trasa zwierzęcia może podnieść priorytet napraw lub otworzyć starą płytkę mapy.

To nie czyni zwierzęcia posłusznym. Może być ranne, terytorialne, zainfekowane starym sprzętem albo podążać za jedzeniem. Maszyna widzi tylko ruch i dane. Marauder widzi gorszą prawdę: ocean może zgłosić cię przypadkiem.

## Scanner

Stary kolonijny tag czujnikowy pod nową blizną. Profil ruchu trafia do kanału pomiarowego Atlas. Zwierzę pobudzone aktywnym pingiem.

## Terminal

PĘTLA FAUNY // Dziedziczny tag 7F zgłasza temperaturę, ruch i zasolenie przez uszkodzony kanał pomiarowy. Priorytet napraw Atlas wzrósł po migracji. Oznakowane zwierzę jest źródłem telemetrii, nie zasobem dowodzenia.

## Audio

Ono nie poluje dla Atlas. Pływa z odznaką wciąż przybitą pod skórą.

## Field Note

Otagowane zwierzęta zmieniają mapę bez zamiaru. Idź za jednym tylko, jeśli wiesz, co idzie za nim.
