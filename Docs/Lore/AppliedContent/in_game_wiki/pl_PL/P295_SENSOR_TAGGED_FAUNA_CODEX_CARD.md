# Karta kodeksu: fauna z tagiem sensorowym

Fauna z tagiem sensorowym to jeden z najczystszych sposobów zobaczenia maszynowej ekologii HECTON-8 bez robienia z oceanu umysłu. Deep Reach tagował zwierzęta, shell colonies i gatunki trasowe do badań migracji, odporności na ciśnienie i skażenia. Po latach część tagów tkwi w tkance blizn, gniazdach skorup, mineralnych czapach lub pierścieniach wzrostu. Atlas nadal może słyszeć słaby powrót i traktować poruszające się ciało jak znacznik diagnostyczny: pressure packet, ślad skażenia, occupancy trasy, kotwicę drone sweep, starego świadka obsługi. To nie czyni zwierzęcia posłusznym. Może żerować, uciekać, polować lub panikować z normalnych powodów, podczas gdy tag nadaje jego ścieżce znaczenie dla zepsutej infrastruktury. Nie czytaj ruchu tagu jako intencji. Nie wycinaj żywego tagu, jeśli koszt trasy nie jest wart okrucieństwa i brudnych danych. Użyteczne pytanie nie brzmi „czego ono chce?”, tylko „który system wciąż wierzy, że ta blizna jest sensorem?”

## Scanner

Fauna z tagiem sensorowym. Stary biometaliczny tag Deep Reach tkwi w bliźnie, skorupie lub pierścieniu wzrostu. Słabe echo trasy Atlas; intencja zwierzęcia niepotwierdzona.

## Terminal

OKAZ / FAUNA Z TAGIEM SENSOROWYM / rola: żywy nośnik telemetrii, przestarzały punkt survey, zanieczyszczenie trasy naprawczej / bezpieczny odczyt: stary puls tagu, wzrost blizny, ruch bez komendy / odrzuć: traktowanie zachowania jak posłuszeństwa, wycinanie tagu z żywego ciała, ufanie occupancy echo / notatka trasy: tag może zgłosić pokój, który zwierzę przeszło, ale nie powód przejścia.

## Audio

Ono nie słucha Atlasa. Niesie stare pytanie, które Atlas wciąż zadaje.

## Field Note

Tag to blizna, nie smycz. Może cię zgłosić, źle umieścić albo obudzić coś, co nigdy nie widziało zwierzęcia.
