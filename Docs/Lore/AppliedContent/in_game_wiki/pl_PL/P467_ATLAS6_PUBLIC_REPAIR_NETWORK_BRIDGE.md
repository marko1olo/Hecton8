# Publiczna sieć napraw Atlas-6

Publiczny język Atlas-6 to termin trasy przemysłowej. Oznacza priorytet naprawy, prowadzenie awaryjne, zapisy ciągłości i harmonogram fabrykatora. Idź za tagami, potem porównaj je z fizyczną naprawą: linią zalania, kołnierzem ciśnienia, trasą pracownika, stanem powiernictwa Black Keel i późniejszymi fragmentami czarnej skrzynki.

## Scanner

## Terminal

BIURO CIĄGŁOŚCI ATLAS // Eksport publiczny może zachować etykietę serwisu, znak trasy, klasę ciśnienia, stan uszkodzeń i priorytet naprawy. Nie dołączać analizy basenu, kontroli Xenon-Omega ani nierozstrzygniętej władzy odbiorcy.

Trasa naprawy Atlas-6 przyjęta. Priorytet oznacza serwis, nie ratunek.

## Field Note
