# Rejestr zatopionego betonu ciśnieniowego

Zatopiony beton nie jest tłem. Ślady uszczelek, cienie rdzy, ceramiczne kruszywo i piasek w szczelinach trzymają kształt znikłych pomieszczeń. Przed cięciem pytaj, co płyta powstrzymywała.

Zielony dolny brzeg oznacza wodę przed zawalem. Czysta płaszczyzna to świeże salvage, wstrząs albo awaria ciśnienia. Rdza bez pręta znaczy metal wyrwany lub rozpuszczony. Pył uszczelki wskazuje starą krawędź drzwi.

Marauder idzie po cieniu rdzy do serwisowego kręgosłupa, nie tnie ostatniej płyty ściskanej i znajduje tablicę trasy pod piaskiem. Ocean skasował pokój, nie sposób jego śmierci.

## Scanner

ZATOPIONY BETON // Kolonialne kruszywo ciśnieniowe, nie wapień. Zbrojenia nie ma; został cień rdzy. Muszlowy piasek w pęknięciach: długie zalanie. Czysta twarz: świeży zawal lub cięcie salvage.

## Terminal

STARA PŁYTA KOLONII // Nie wydobywać jak kamień. Beton znaczy pokój, kanał rur albo linię obciążenia. Białe kruszywo ceramiczne: ściana ściskana. Pomarańczowy cień: dawne zbrojenie. Zielono-czarny dół: stojąca woda.

## Audio

Naturalna skała pęka jak pogoda. Beton kolonii pęka jak kształt opłacony, a potem odebrany przez ocean.

## Field Note

Pod wodą prosta krawędź zawsze ma powód.
