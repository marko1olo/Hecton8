# Rozłam komunikatów Deep Reach

Rozłam sprawia, że Deep Reach pozostaje instytucją, a nie kreskówkowo jednolitym złoczyńcą. Korporacja może jednocześnie wydawać rozkazy ratunku, rozkazy tuszowania i szczere ostrzeżenia techniczne, bo każde biuro broni innej księgi strat.
