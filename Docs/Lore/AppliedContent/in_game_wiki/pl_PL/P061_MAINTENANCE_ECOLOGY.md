# Ekologia utrzymania

Ekologia utrzymania sprawia, że HECTON-8 jest użyteczny i chory zarazem. Atlas nauczył się, że biofilm przenosi słaby sygnał, kolonie filtrujące powtarzają pingi, narosty muszlowe zamykają pęknięcia, a znakowana fauna zwraca uszkodzone sensor packets. Ocean nie jest osobą. Sieć naprawcza żyje jednak dość mocno, by każdy cable reef stał się narzędziem, zagrożeniem i tropem dowodowym.

## Scanner

Przewodzący biofilm, narosty muszlowe, znakowana fauna i ciepło kominów niosą ruch naprawczy.
