# Pusty kwit berth kwarantanny

Pusty quarantine berth receipt pokazuje różnicę między tym, że ktoś cię usłyszał, a tym, że ktoś cię przyjął. Black Keel ma żywą body line i wycenione tonne-window, ale żaden receiver nie wskazał sali kwarantanny, medical owner ani custody door. Czytaj receipt jako evidence: trasa działa, odmowa jest proceduralna, a brakująca sala jest blokadą.

## Scanner

ODCZYT BERTH FIELD // Body line przyjęta. Quarantine berth pusty. Brak receiver custody; lift allocation pozostaje zablokowane.

## Terminal

NULL BERTH RECEIPT // Packet przyjęty, body wycenione, quarantine volume bez nazwy. Carrier acknowledgement nie oznacza rescue.
