# Pytanie finałowe: publiczny rejestr, utracona kontrola

Trasa publicznego rejestru zamienia pieczę na pokwitowanie. Pakiet opuszcza basen z hashem świadka, łańcuchem odpowiedzialności, streszczeniem stanu Atlas, ukrytymi współrzędnymi niebieskiego długu i dowodem trasy ładunku, zanim Deep Reach zdąży zamknąć archiwum samodzielnie. Chroni to nazwiska przed prostym usunięciem, ale oddaje plik regulatorom, wierzycielom, sieciom ocalałych, sądom domenowym, konkurentom i każdemu odbiorcy dość szybkiemu, by złożyć pierwszy.

## Scanner

OŚ PUBLICZNEGO REJESTRU // Notariat pakietów Tau/Luyten przyjmuje hash świadka przed pełną pieczą. Deep Reach traci wyłączne zamknięcie archiwum; nadawca traci kolejność odbiorców.
