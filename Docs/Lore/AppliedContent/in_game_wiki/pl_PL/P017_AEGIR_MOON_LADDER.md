# Drabina księżyców Aegir

Drabina Aegir obejmuje znaczniki promieniowania, przekaźniki, wyczerpane claimy, zagrożenia rezonansowe, HECTON-8, chłodne magazyny i obiekty zewnętrzne. HECTON-8 jest cenny, bo leży między żywym oceanem a presją orbitalną.

## Scanner
