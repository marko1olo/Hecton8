# Maszyna okna nieba Aegir

Widzialne niebo Aegir jest route machinery, nie dekoracją. Cienie księżyców mogą łamać relay confidence, sztormy mogą chronić body i zabijać upload, a czysta carrier line nadal może zawieść przez radiation, tide, kwarantannę lub mass checks. Czytaj sky windows jak ułożone bramy: packet, body, proof i salvage nie muszą dzielić tego samego pass.

## Scanner

ODCZYT SKY WINDOW // Wizualnie czyste niebo nie jest rescue clearance. Cień Kestrel, storm ceiling, radiation count, tide load i carrier phase nie zgadzają się.

## Terminal

ROUTE PLATE AEGIR // Stan okna jest częściowy. Packet line może być otwarta, gdy ascent body, kwarantanna i tonne-window mass pozostają zamknięte.

## Audio

Notatka relaya: niebo jasne, route brudna. Wyślij tylko packet; wstrzymaj ascent, aż moon tag, storm ceiling i mass line się zgodzą.

## Field Note

Niebo może być otwarte dla packetu i zamknięte dla twojego body. Sprawdź całą maszynę, zanim zaczniesz świętować.
