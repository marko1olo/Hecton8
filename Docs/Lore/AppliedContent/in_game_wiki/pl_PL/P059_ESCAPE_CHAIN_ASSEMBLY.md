# Montaż łańcucha ucieczki

Ucieczka jest łańcuchem montażowym, nie jednym naprawionym pojazdem. Uszkodzony pakiet zrzutowy może utrzymać ciało przy życiu, ale sam nie stworzy zaufanego wznoszenia. Droga do domu wymaga acoustic relay spine słyszalnej przez wodę i szum burzy, pressure seal, który nie zmieni wznoszenia w rozerwanie, guidance core zdolnego przetrwać lokalne zagrożenia HECTON-8, ascent-energy charge, quarantine/legal handshake i evidence payload dość silnego, by zmienić recovery authority Black Keel. Każdy komponent jest jednocześnie fizyczny, prawny i moralny.

## Scanner

Odlot wymaga sześciu twardych dowodów: przekaźnika, uszczelnienia, naprowadzania, ładunku wznoszenia, prawnego handshake i payloadu, którego carrier nie zignoruje.
