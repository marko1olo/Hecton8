# Okno tonowe Keelmark

tonne-window to odzyskiwalna masa, którą Black Keel może podnieść przez jedną okazję orbitalną po wycenie paliwa, burzy, kwarantanny, ubezpieczenia i priorytetu. Keelmark Mutual czyni gracza czytelnym jako masa, zanim zobaczy w nim osobę. Każda próbka, pakiet dowodowy, dług tlenu i rider welfare mogą przesunąć liczbę.

## Scanner

ZASTAW TONNE-WINDOW // Ekwiwalent 4,8 zapisany. Tlen, dodatki welfare, powiernictwo próbek i ładunek dowodowy mogą zmienić priorytet masy odzysku.

## Terminal

REJESTR OKNA KEELMARK MUTUAL // Zastaw bazowy: ekwiwalent 4,8 tonne-window. Korekty mogą obejmować ryzyko tlenu, dodatek welfare, powiernictwo próbki, ładunek dowodowy, blokadę kwarantanny i przydział podnoszenia carriera. Ten rejestr wycenia odzysk; nie obiecuje ratunku.

## Audio

Okno liczy masę, zanim policzy litość.
