# Okno trasy Aegir

Okno trasy Aegir nie jest ładną prognozą pogody. To krótki moment, gdy wrogie zegary zgadzają się: promieniowanie, cień księżyca, plume burzy, ścinanie pływu, link akustyczny, geometria Black Keel i opieka tonne-window. Może być otwarte dla danych, zamknięte dla ciała. Rdzeń dowodowy może przejść kwarantannę, a próbka blue-debt ugrzęznąć. Ratunek to przecięcie przetrwania, prawa i masy.

## Scanner
