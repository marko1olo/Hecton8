# Fauna łyżwiarzy gęstości

Łyżwiarze gęstości to zwierzęta średnich głębin, które sprawiają, że kanion solanki czuje się jak warstwowa maszyna, nie pusty wolumen. Ich stopy, płetwy lub haczykowate poduszki naciskają na interfejsy gęstości dość silne, by przez kilka sekund utrzymać małe ciała. Dla oka ślizgają się po otwartej wodzie; dla scannera zostawiają fale tam, gdzie otwarta woda nie powinna mieć powierzchni. Ta sprzeczność jest wskazówką. Ślad łyżwiarza może znaczyć okno ścinania, stopień solanki, ślepą krawędź sonaru albo linię łowów większych istot. Zwierzę nie jest magią ani obietnicą bezpieczeństwa. Kombinezon jest cięższy, głośniejszy i źle ukształtowany do tej samej sztuczki. Użyj śladów, by czytać warstwę. Nie zakładaj, że możesz podążyć.

## Scanner

ŁYŻWIARZ GĘSTOŚCI // Cienkokończysta fauna jedzie po interfejsie solanki jak po powierzchni, zostawiając fale tam, gdzie sonar oczekuje otwartej wody.

## Terminal

BAZA FAUNY: kontakt z łyżwiarzami rośnie przy rozdartych brine vanes, ciepłych stopniach solanki i martwych krawędziach sonaru. Ich ślad oznacza półkę gęstości, nie bezpieczne oparcie. Nie goń przez nieprzezroczyste warstwy.

## Audio

Coś chodzi po wodzie wewnątrz wody.

## Field Note

Oni nie lewitują. Chodzą po granicy, przez którą twój kombinezon może spaść.
