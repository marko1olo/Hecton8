# Registre des patchs de combinaison pressurisée

Les patchs de combinaison pressurisée sont l'écriture humaine sur un objet de survie. Les panneaux d'usine parlent en courbes propres. Les patchs de terrain parlent en fil tordu, tissu de mauvaise couleur, sel sous bande et honnêteté brutale d'une fuite fermée avant le prochain cycle.

L'ordre compte. Bande sous point croisé : première réparation non fiable. Sel sous fil : combinaison déjà exposée. Abrasion sur patch : porteur retourné travailler. Bande propre sur vieux dégât : inspection tardive. Deux tissus : matière prise sur une autre combinaison.

Pour un maraudeur, ce n'est pas costume. C'est route d'urgence, dernière tâche, triage, kit volé ou grade de combinaison qui n'appartenait pas à son porteur.

LECTURE PATCH // Point croisé sur bande : fermeture d'urgence. Sel sous fil : patch après exposition. Bande propre sur tissu usé : inspection tardive. Deux couleurs : combinaison cannibalisée.

## Audio

Un patch de combinaison est un petit vote contre la noyade.

## Field Note

Ne lis jamais le patch seul. Lis genou, manchette et poche d'outil avec lui.
