# Ensemble de preuves du dernier jour normal

Le dernier jour normal n'est pas une date. C'est la forme qu'une pièce garde quand le travail est interrompu. Une plaque de casier attend une main qui n'est jamais revenue. Une correction n'a pas de signature parce que quelqu'un comptait revenir après la descente. Une tâche de pompe reste ouverte. Un jeton de déjeuner demeure sous le ruban. L'horloge de route attend un tampon de retour parce qu'une horloge n'a pas de catégorie pour le silence.

Ces objets sont plus fiables que les discours. Personne ne les a arrangés pour la mémoire. Le tableau essayait encore de faire tourner un quart, nourrir une équipe, vider un puisard, compter un outil et garder une route honnête. C'est pour cela que la preuve blesse. La colonie n'avait pas encore fini de devenir une catastrophe. Elle était encore assez normale pour se disputer sur des gobelets, des clés et des signatures tardives alors que la panne était déjà dans les murs.

Pour un Marauder, l'ensemble prévient aussi contre le salvage paresseux. Une plaque de valeur se retire en secondes, mais une correction non signée peut expliquer pourquoi la cause officielle est restée vide. Un jeton de repas pincé peut prouver qu'un travailleur devait revenir avant l'arrêt de l'horloge de porte. Une catégorie de corps peut paraître propre jusqu'à ce que le certificat de pompe et le compte de quart se contredisent.

Lis l'interruption avant de prendre l'objet. Les salles noyées de HECTON-8 n'ont pas besoin de messages finaux parfaits. Leur témoignage le plus fort est plus petit: travail ouvert, devoir non transmis, horloge attendant une personne que l'océan a déjà retirée.
