# Tuyau flexible nervuré

Les tuyaux flexibles nervurés relient les systèmes souples d'une base pressurisée : oxygène, refroidissement, amorçage de pompe, alimentation d'outil, service de combinaison et dérivations d'urgence. Les nervures protègent l'écrasement et rendent la surface lisible. Le sel sec reste sur les crêtes. Les creux gardent eau, huile et limon. Les anneaux plats marquent colliers, portes ou ancres hâtives. Une abrasion d'un seul côté indique un traînage. Une tache cyan peut révéler une ligne de refroidissement quand l'étiquette a disparu.

## Scanner

TUYAU FLEXIBLE NERVURÉ // Ligne de caoutchouc certifiée pression. Sel sur les crêtes, creux humides et bandes de collier aplaties suggèrent un flux récent. Suis les deux bouts avant de couper; un tuyau mort peut encore porter air, refroidissement ou preuve.

## Terminal

Note de dérivation : les tuyaux posés après l'ordre d'évacuation ne sont pas propres. Des nervures polies d'un côté indiquent une ligne tirée en charge. Des creux humides indiquent un flux sous pression après l'inondation.

## Audio

Pose ton gant sur le tuyau et tu entends la pièce dans le caoutchouc. L'air sonne net. Le refroidissement sonne fatigué. Une ligne coupée sonne comme une dette qui arrive.

## Field Note

Les crêtes disent ce qui a séché. Les creux disent ce qui bougeait encore. Les plats de collier disent qui a improvisé.
