# Machine de fenêtre céleste d'Aegir

Le ciel visible d'Aegir est une route machinery, pas un décor. Les ombres lunaires peuvent casser la relay confidence, les tempêtes peuvent protéger le body tout en tuant l'upload, et une carrier line claire peut encore échouer aux contrôles radiation, tide, quarantaine ou mass. Lis les sky windows comme des portes empilées: packet, body, proof et salvage ne partagent pas forcément le même pass.
