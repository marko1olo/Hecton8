# Registre thermique des couvertures isolantes humides

Une couverture isolante humide n'est pas un fond doux. Dans HECTON-8, c'est un mur qui garde mal son secret. Chaleur, souffle, condensation et pression ne traversent pas le tissu pareillement. Ils noircissent les coutures, salent les points, écrasent les poches et montrent quel côté a survécu le plus longtemps.

L'ordre compte. Humidité sombre dans une couture : condensation lente avec air encore chaud. Sel au-dessus : séchage ou respiration de pression plus tardive. Déchirure avec sel sec : brèche ouverte après vieillissement. Ruban propre sur matelassage pourri : on n'a plus réparé la colonie, on a acheté un quart de plus.

Pour un maraudeur, l'isolant est preuve d'abri : poche d'air, vide de service, pièce chauffée par une machine mourante, couloir où l'on dormait quand les couchettes étaient inaccessibles.

## Scanner

COUVERTURE ISOLANTE // Tissu technique gris beige matelassé, couture comprimée, ligne d'humidité sombre, sel dans le canal de couture, petite déchirure montrant une couche interne sombre. Ce mur a gardé chaleur ou air plus longtemps que la pièce.

## Terminal

LECTURE ISOLANT // Couture sombre d'abord, sel ensuite : condensation lente avant respiration sèche. Sel sous tissu déchiré : brèche ouverte après séchage. Tache chaude sur mauvaise face : panneau retourné lors d'une réparation tardive.

## Audio

L'isolant se souvient des pièces que l'on a tenté de garder vivantes.

## Field Note

Si la couverture est humide au-dessus de l'épaule, demande ce qui respirait encore là.
