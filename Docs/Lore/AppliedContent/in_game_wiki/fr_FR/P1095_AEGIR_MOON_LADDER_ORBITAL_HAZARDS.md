# Échelle lunaire d'Aegir

L'échelle lunaire d'Aegir n'est pas une décoration du ciel. Ran est l'étoile, Aegir le géant, et HECTON-8 une lune océanique dans une chaîne mouvante de lunes, relais, tempêtes, contrôles de garde et fenêtres de masse assurée.

Skarn peut noyer les antennes de bruit chargé. Vela peut fermer les relais avec de la poussière de glace. Kestrel peut couper la ligne de vue au pire instant. HECTON peut jeter un panache de tempête dans un couloir d'ascension propre. Black Keel peut recevoir votre paquet et refuser quand même le levage si la fenêtre, le handshake de quarantaine ou la classe de masse échoue.

## Scanner

DANGER ORBITAL // Fenêtre instable. Sursaut Skarn, volet Vela, occultation Kestrel et panache de tempête HECTON peuvent briser la géométrie de récupération.

## Terminal

NOTE DE FENÊTRE DE RÉCUPÉRATION // Black Keel exige garde du signal, payload hash propre, handshake de quarantaine et fenêtre de tonnage récupérable avant levage du corps. Un ciel clair n'est pas une autorisation de secours.

## Audio

Le ciel n'a pas échoué par vide. Il a échoué selon l'horaire : lune, volet, sursaut, registre, masse.

## Field Note

Quand la récupération échoue, lis l'alerte du ciel avant d'accuser le pinger.
