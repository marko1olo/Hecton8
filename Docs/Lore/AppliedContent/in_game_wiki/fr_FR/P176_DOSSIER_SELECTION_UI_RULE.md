# Registre de réclamation de dossier

Le registre de réclamation de dossier est un formulaire d'entrée Black Keel pour preuves antérieures, pas une armoire d'équipement. Un dossier sélectionné peut porter anciennes fins, familles de rumeurs, pression de privilège, termes de garde et avertissements de route dans un nouveau contrat. Ces enregistrements changent ce que l'opérateur soupçonne et ce que le carrier facture. Ils ne changent pas la réserve d'oxygène, la classe de coque, les armes, l'inventaire ni l'identité du travailleur inscrite dans la réclamation.

## Scanner

Registre DR-902. Les dossiers actifs exposent familles de rumeurs, fins enregistrées, pression de privilège, termes de garde, clauses orbite/météo et indices d'ordre des preuves. Aucun héritage d'équipement.

Champs refusés : réserve d'oxygène, classe de coque, état d'arme, report d'inventaire
Statut : dossier de connaissance uniquement ; équipement de survie réinitialisé par contrat

## Audio

Les dossiers gardent les noms et les mauvaises clauses. Ils ne donnent pas une combinaison plus solide.

## Field Note

Ouvre un dossier et Black Keel le chiffre. Garde l'ancien soupçon ; poumons, coque et outils restent hors du fichier.
