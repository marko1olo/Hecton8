# Fiche codex de la dérive-lanterne

Le bloom de dérive-lanterne est le plus beau système d’alerte du plateau. En eau calme, les cellules dessinent le courant, la poussière suspendue, les boucles de câble, les éclats de pressure glass, les shell clamps brisés et les petites menaces dentées avant qu’une lampe les trouve. Il devient donc utile quand la route est visuellement sale ou quand le joueur a besoin d’une silhouette nette dans le fouillis du récif. Il rend aussi le joueur lisible. Vibration de cutter, pompe qui tousse, pinger répété, impact de coque ou thruster paniqué peuvent agiter le bloom en sillage lumineux qui porte la position dans le réseau alimentaire. La charge d’orage ajoute de faux corridors, des résidus trop brillants et un contraste aplati qui cache de petits dégâts dans trop de beauté. Suis la lueur seulement quand courant, résidu et faune concordent. Travailler fort dans un bloom n’a de sens que si être trouvé fait partie du plan.

## Scanner

Bloom de dérive-lanterne. Le plancton bioluminescent bande le courant et les débris. Utile pour les contours; dangereux quand le bruit d’outil en fait un sillage éclairé.

## Terminal

SPÉCIMEN / BLOOM DE DÉRIVE-LANTERNE / rôle: événement de visibilité peu profonde, croquis de courant, enregistreur de perturbation / lecture sûre: lueur de bord stable, halos de débris, courant et résidu concordants / rejet: faux corridor chargé par l’orage, bloom qui écrase les petits dangers, sillage d’outil qui s’éclaire derrière l’opérateur / note de route: la lumière est une donnée, pas un abri.

## Audio

La lueur ne t’aide pas. Elle rapporte ce que l’eau a entendu.

## Field Note

Utilise le bloom pour les silhouettes. Ne répare pas bruyamment dedans. Si la lueur te suit, autre chose peut la suivre aussi.
