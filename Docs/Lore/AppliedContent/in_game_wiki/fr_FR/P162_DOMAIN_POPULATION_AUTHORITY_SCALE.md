# Échelle De Population Et D'Autorité

Les chiffres de population restent approximatifs parce que le joueur n'a pas besoin de census opera. La question utile est plus simple : qui peut agir sur vous depuis loin ? Un domaine intérieur bondé ne touche peut-être HECTON-8 que par une ligne de certification. Un petit dépôt peut compter davantage parce qu'il contrôle la custody des paquets. Une coquille de frontière morte peut compter le plus parce qu'elle possède le matériel dans la pièce.

C'est l'échelle que le joueur ressent. Sol peut décider qu'un objet appartient à quelqu'un. Centauri peut rendre respectable l'ancien langage de Deep Reach. Barnard normalise le travail qui piège les Marauders. Tau Ceti peut transformer une preuve en pression publique, trop tard pour l'oxygène mais pas trop tard pour les conséquences. Luyten peut prouver la chaîne de messages. Aegir est le lieu où les signatures deviennent pression, eau, sas verrouillés et masse facturable.
