# Ordre de travail salle des pompes P-63

L'Ordre de travail salle des pompes P-63 fait de la première réparation une procédure héritée de la colonie plutôt qu'un texte de tutoriel. Il est trempé, pratique et légèrement effrayé. L'ordre demande de vider le sump, colmater le cold seam, attendre le return pinger et couper le fused latch seulement après maintien de pression. Cette séquence enseigne comment pensaient les ouvriers de HECTON-8 : l'eau d'abord, le scellement ensuite, le son avant la force, la confiance de route en dernier. Les initiales du superviseur manquantes et le double cercle autour de la ligne de coupe rendent le papier utilisé, pas écrit pour le joueur. C'est un petit artefact, mais il porte toute la boucle du jeu en miniature : lire la pièce, restaurer un système, se méfier de la coupe facile.

## Scanner

La première réparation se lit comme une habitude de colonie : pomper, sceller, écouter, couper seulement quand la pièce cesse de mentir.

## Terminal

WORK ORDER P-63 : vider le sump ; colmater le cold seam ; vérifier le return pinger ; couper le fused latch seulement après maintien de pression ; imprimer le gasket depuis stock local ; marquer route safe après trois retours acoustic return. Initiales du superviseur absentes sous tache d'eau.

## Audio

Pompe d'abord. Scelle ensuite. Si ça chante, arrête de couper.

## Field Note

Le bas du clipboard est trempé. La ligne de coupe reste lisible parce que quelqu'un l'a entourée deux fois et a écrit si ça chante, stop.
