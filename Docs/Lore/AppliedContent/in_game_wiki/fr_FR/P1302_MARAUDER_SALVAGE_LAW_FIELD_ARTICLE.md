# Article de Terrain sur le Droit de Salvage Marauder

Marauder est un mot juridique sale avant d'être un métier. Un pirate vole hors du registre. Un sauveteur arrive avec devoir, équipage, autorité publique et assez de carburant pour admettre qu'une personne compte. Un Marauder entre dans l'espace entre les deux. La licence dit que vous pouvez toucher une propriété abandonnée ou disputée, marquer une masse récupérable, préserver une matière témoin et déposer un privilège. Elle dit aussi, plus bas, que si vous mourez dans la réclamation, le système peut appeler cela perte de contractuel plutôt qu'échec de sauvetage.

            C'est pourquoi le travail Marauder semble mauvais même quand il sert. Vous coupez des panneaux d'une porte pressurisée morte parce que le métal vaut quelque chose. Vous gardez aussi le bord coupé parce qu'il prouve que la porte a été soudée après la disparition des gens. Vous prenez une plaque de nom parce qu'elle se vend en alliage. Vous gardez aussi le hash mouillé parce que la plaque rend une catégorie de corps à une personne.

            Les marques de terrain sont nées parce que la loi formelle est trop lente pour les salles noyées. Un anneau noir signifie propriétaire hostile ou menteur. Une flèche fendue signifie chemin de pression faux. Un tampon corporatif barré signifie ne pas croire la cause imprimée. Un nom ouvrier près d'une marque de route signifie préserver la personne avec le lieu.

            Sur HECTON-8, refuser le salvage ne rend pas le joueur pur. Le refus laisse debout les étiquettes propres. La discipline difficile est de prendre avec contexte : objet, lieu, hash, marque, nom, trajet des dégâts. Salvage sans mémoire est pillage. Salvage avec témoin reste laid, mais il peut forcer une pièce morte à parler dans un registre qui préférerait compter seulement la masse.

Si vous le prenez, gardez son origine. Un butin propre achète du carburant. Un butin sale avec témoin peut racheter un nom.
