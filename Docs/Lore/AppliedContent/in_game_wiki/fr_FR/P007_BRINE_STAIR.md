# Escalier de saumure

Les escaliers de saumure se forment quand l'eau salée dense, la chaleur des évents et les flux lents de bassin s'empilent en limites nettes. Pour un pilote négligent, ce sont des murs invisibles : la flottabilité répond tard, le sonar se courbe, les lumières bavent, et une descente peut devenir une glissade. Pour un pilote attentif, ce sont des routes. Un submersible peut longer une couche, percer une autre, se cacher sous un rideau ou utiliser la portance thermique pour franchir un vide que l'eau ouverte rendrait impossible. Les couches préservent aussi les épaves et traces biologiques avec une patience cruelle. Corps, caisses d'outils, coffres d'échantillons et vieux drones peuvent rester des années dans la même marche non mélangée. L'Escalier de saumure enseigne une règle centrale de HECTON-8 : la profondeur se négocie avec la structure de l'océan, elle ne se conquiert pas par la seule résistance de coque.
