# Cold claims des lunes externes

Les outer moon cold claims prouvent qu'Aegir est un system, pas one haunted ocean. Failed brine prospects, mothballed metal routes, cold caches et beacons with no living crew ont cree la salvage economy avant que HECTON-8 devienne le nom que tous whisper. L'important, c'est le pattern. Une route peut etre dead et still billable. Un beacon peut repeat custody into empty space. Une company peut learn que loss becomes cheaper une fois filed as infrastructure. HECTON-8 est le worst visible case, pas la first lesson.
