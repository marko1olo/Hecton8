# Coupe du drive stack quasi-luminique

Un vaisseau quasi-luminique n'est pas une torche magique boulonnée à une coque. Le drive stack est une route entière rendue matérielle : les beam arrays dépensent l'énergie avant le départ, les pellet lanes placent de la masse capturable, les fusion-electric throats changent le carburant en électricité et chaleur, les boucliers acceptent la perte de poussière, les radiateurs jettent la chaleur pendant des années, et le freinage compte autant que l'accélération.

## Scanner

COUPE DRIVE STACK // plaque Barnard Yards : beam-sail yoke, pellet catcher, fusion-electric throat, shadow shield, nervures radiateur, magsail spool, aerobrake skin et compteur custody partagent un numéro de route.

## Terminal

ATLAS TRANSIT STACK // Poussée de départ : beam array externe. Alimentation de croisière : capture pellet lane. Conversion : fusion-electric throat. Contrôle pertes : glace de bouclier, carbone, nervures radiateur. Autorité d'arrivée : magsail spool, aerobrake skin, slot récepteur, registre custody.

## Audio

Arrête d'appeler le cône moteur. Le moteur, c'est la route, la chaleur perdue et celui qui possède le slot de freinage.

## Field Note

La plaque met la chaleur avant la poussée. Bonne plaque. Les équipages bon marché meurent sur la marge radiateur avant de se vanter de vitesse.
