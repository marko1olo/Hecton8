# Dérive de file relais

La communication retardée est dangereuse parce qu'elle peut rester exacte au mauvais moment. Un avertissement du transporteur peut décrire une vraie vanne, une vraie fuite et une vraie route déjà changée par la pression. Le joueur compare l'âge du paquet aux preuves locales.

## Scanner

Le tampon relais est plus vieux que la fuite qu'il nomme ; l'instruction était vraie pour une pièce qui n'existe plus ainsi.

## Terminal

DÉRIVE DE FILE : âge du paquet au-delà de la validité de route. La preuve locale dépasse l'ordre du transporteur jusqu'à une fenêtre relais fraîche.

## Audio

Le message est correct. C'est le problème.

## Field Note

Une vérité tardive peut encore tuer.
