# Bordures extérieures de coque de base pressurisée

L'extérieur d'une base pressurisée HECTON-8 n'est pas une coque décorative. Ses bandes de bordure sont la grammaire lisible d'un module conçu pour être entretenu sous l'eau. Le revêtement céramique clair marque la peau de pression. Les nervures graphite sombres montrent où voyage la charge. Les canaux de joint étroits montrent où deux volumes devaient se rejoindre sans partager l'océan. Les lèvres de panneaux encastrées signifient généralement accès humain, pas ornement.

Lis la bordure avant de couper. Une longue nervure qui traverse un module sans rupture indique que le mur porte la pression comme un seul corps. Une nervure cassée près de traces de sel nettes signifie que la fuite est restée locale et a peut-être laissé une poche. Un canal de joint rempli de vieille poussière minérale signifie que la jonction respirait lentement. Une lèvre de panneau avec des rayures fraîches signifie que quelqu'un l'a ouverte après que la pièce fut déjà mouillée ou après la fin de l'ordre officiel.

De bons trim sheets font sentir qu'une base est construite, pas peinte. Ils rendent aussi le salvage moins aveugle. Le joueur peut suivre la direction des nervures pour éviter les mauvaises coupes, trouver les trappes de service par la géométrie répétée des joints, et lire quels modules furent réparés pour un retour plutôt qu'abandonnés comme preuve. L'océan efface d'abord les étiquettes. Il laisse les bords.

## Scanner

BORDURE DE COQUE EXTÉRIEURE // Peau de pression claire, bande de nervure graphite, canal de joint encastré. Les traces de sel descendent sous la lèvre de service, pas sous la plaque principale. C'est un bord de module entretenu, pas une plaque d'épave au hasard.

## Terminal

LECTURE DE PEAU DE COQUE // Ne pas couper les bandes de bordure avant d'avoir cartographié le chemin de charge. Les longues nervures sombres portent la pression, les panneaux clairs ferment le volume, les canaux de joint marquent les jonctions, et les lèvres de service cachent souvent le dernier accès manuel.

## Audio

Le panneau semblait plat jusqu'à ce que la lumière touche la bordure. Ensuite le mur n'était plus un mur. Il avait une colonne, une bouche, et un endroit que quelqu'un avait scellé deux fois.

## Field Note

Les plaques plates sont pour les bureaux. Dans l'eau, lis les bords d'abord.
