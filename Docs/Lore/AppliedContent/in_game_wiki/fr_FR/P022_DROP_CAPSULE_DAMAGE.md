# Dégâts de capsule

La capsule de largage amène le Maraudeur sur HECTON-8. Le crash laisse assez de systèmes vivants pour abri, énergie et journaux, mais détruit le matériel d'ascension. La sortie précoce devient une chaîne d'ingénierie, pas un bouton.

## Scanner

Siège intact. Trajet d'ascension détruit. La capsule est un abri, pas un véhicule retour.

## Terminal

Boîte noire: parachute brûlé, ballast percé, mât com cisaillé, joint d'ascension ruiné. Retour orbital via chaîne externe.

## Audio

La capsule ne remonte pas. Ce n'est pas un vaisseau.

## Field Note

La première prison est mécanique.
