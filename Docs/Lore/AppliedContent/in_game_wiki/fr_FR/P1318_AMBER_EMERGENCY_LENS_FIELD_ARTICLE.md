# Lentille d'urgence ambre

Les lentilles ambre équipaient les strobes de couloir, balises de sas, alarmes de pompe et voyants de défaut des casiers de combinaison. Leur capot nervuré en verre-plastique diffusait la lumière dans la brume et à travers le verre de pression, mais il gardait aussi des traces. Le sel dans les nervures indique une respiration répétée d'air humide. La poudre blanche sur la lèvre basse indique une infiltration stagnante. Les rayures qui coupent les nervures viennent souvent d'une main gantée pressée; celles qui suivent les nervures relèvent de l'entretien normal. Dans une base morte, la lentille peut dire si une ligne d'alerte était encore alimentée, si elle ne faisait que réfléchir une lumière étrangère, ou si elle a été nettoyée après l'événement.

## Scanner

LENTILLE D'URGENCE AMBRE // Capot translucide nervuré d'une lampe d'alerte de base pressurisée. Le voile salin dans les rainures signifie que l'eau a atteint la lampe avant la mort du circuit. Ne lis pas seulement la lueur; lis la lentille.

## Terminal

Note maintenance éclairage : les strobes ambre sont une logique de route, pas un décor. Une lentille claire marque un ordre d'évacuation encore actif. Des nervures laiteuses marquent une longue condensation. Les rayures en travers viennent souvent d'un essuyage après l'alarme.

## Audio

La lampe clignotait encore quand le couloir s'est tu. Pas assez forte pour sauver quelqu'un. Assez forte pour montrer qui est passé.

## Field Note

Si l'ambre est trop propre, demande qui l'a nettoyé. Si les nervures sont laiteuses, compte les respirations humides de la pièce.
