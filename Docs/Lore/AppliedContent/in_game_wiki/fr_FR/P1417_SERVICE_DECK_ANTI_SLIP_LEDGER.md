# Registre de pont de service antidérapant humide

Un pont de service HECTON-8 n'est pas une texture de sol banale. C'est la dernière écriture de la colonie. Le relief antidérapant gardait les bottes en place pendant le travail normal, puis il est devenu enregistreur. Le sel accroche les crêtes, l'huile dort dans les creux, la peinture jaune disparaît en croissants là où l'on tournait avec outils ou bouteilles.

Le joueur peut lire un pont humide avant d'entrer. Une ligne claire sur plaque sombre signifie passage répété après inondation. Un demi-cercle propre près d'une trappe signifie rotation fréquente. Une traînée huileuse qui descend d'un chariot est un chemin de fuite, pas de la saleté décorative. Une rouille brisée sur le joint signale mouvement tardif ou retour.

Ce matériau aide sans devenir panneau. Il montre la route plus sûre, une charge traînée, une plateforme glissante, ou prouve qu'un sas supposé scellé a encore cyclé après l'évacuation officielle.

## Scanner

PONT DE SERVICE // Métal sombre à relief antidérapant, peinture blanche et jaune usée, sel sur les crêtes, traînées huileuses dans les creux. La rouille reste dans les joints. La ligne de passage courbe vers le sas.

## Terminal

LECTURE DU PONT // Le relief enregistre le mouvement. Les crêtes claires marquent les bottes ; les creux sombres marquent huile ou liquide de refroidissement. La peinture jaune usée en arc indique un virage avec charge. Avant de franchir un joint, vérifier si la ligne de rouille est brisée.

## Audio

Un sol se souvient mieux de la panique qu'un mur. Les yeux mentent vers le haut ; les bottes donnent la route.

## Field Note

Ne demande pas d'abord où ils sont allés. Demande où la peinture a cessé de survivre.
