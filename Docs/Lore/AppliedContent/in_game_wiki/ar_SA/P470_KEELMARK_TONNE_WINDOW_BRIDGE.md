# نافذة الطن لدى Keelmark

tonne-window هي الكتلة القابلة للرفع التي قد ترفعها Black Keel خلال فرصة مدارية واحدة بعد تسعير الوقود والعاصفة والحجر والتأمين والأولوية. تجعل Keelmark Mutual اللاعب مقروءا ككتلة قبل أن تراه كشخص. كل عينة محفوظة وحزمة دليل ودين أكسجين وملحق رعاية يمكن أن يحرك الرقم.

## Scanner

رهن TONNE-WINDOW // سجل مكافئ 4.8. يمكن للأكسجين وملاحق الرعاية وحفظ العينات وحمولة الدليل تعديل أولوية كتلة الاسترداد.

## Terminal

دفتر نافذة KEELMARK MUTUAL // الرهن الأساسي: مكافئ 4.8 tonne-window. قد تشمل التعديلات خطر الأكسجين وملحق الرعاية وحفظ العينة وحمولة الدليل وحجر quarantine وتخصيص رفع carrier. هذا الدفتر يسعر الاسترداد ولا يعد بالإنقاذ.
