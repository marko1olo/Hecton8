# ملف مخطط علاقات الأدلة

طبقة العلاقات صنعت للمحققين المتعبين والناهبين الخائفين، لا للقضاة. إنها تضع السجلات على الطاولة نفسها عندما تشترك في جسم مصدر أو لوحة مسار أو عبارة مطالبة أو بصمة شاهد أو عائلة تعليق أو علامة إصابة أو حالة تنقيح أو نتيجة مرئية. هكذا تظهر الأنماط تحت الضغط، وتظهر معها الثقة الزائفة.

تطابق البصمة لا يثبت صدق الشاهد. تطابق التعليق لا يثبت استعادة المصدر. حالة التنقيح المشتركة قد تعني فقط أن الموظف نفسه قص ملفين بالقالب نفسه. الأداة مفيدة لأنها تقول أين تصرف انتباهك: حيازة الحزمة، جسم المصدر، لغة المطالبة، بصمة الشاهد، نتيجة المسار، سبب التنقيح، وترتيب التعليقات. تصبح خطيرة حين تقرأ الحافة كحكم.

## Scanner

طبقة العلاقات // الحافة تعني جسما مشتركا أو عبارة أو بصمة أو نتيجة أو تعليقا أو حالة تنقيح. إنها إشارة مراجعة، لا اتهام ولا تبرئة.

## Terminal

مفتاح مخطط الملف
أخضر: تطابق جسم المصدر أو لوحة المسار.
كهرماني: تطابق عبارة مطالبة أو عائلة تعليق.
أحمر: تطابق بصمة شاهد أو علامة إصابة أو نتيجة قمع.
رمادي: حالة تنقيح مشتركة فقط.
كل حافة يجب فحصها مع الحيازة. المخطط الجميل قد يظل كذبة بخطوط مستقيمة.

## Audio

الخط بين السجلات يخبرك فقط أين تنظر بعد ذلك. لا يخبرك من المذنب أو الآمن أو من دفع ثمن الصمت.

## Field Note

لا تدع المخطط النظيف يفكر بدلا منك. الخطوط رخيصة. التعليق وحالة التنقيح هما المكان الذي تصبح فيه الكذبة رخيصة بما يكفي للشحن.
