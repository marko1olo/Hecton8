# بروتوكول حفظ الحجر payload

بروتوكول الحفظ يبقي الحوض خارج الاسترجاع المؤسسي المباشر، لكنه لا يحرره. يختم payload الإحداثيات، ويحفظ بيئة Atlas تحت escrow حجر، ويدفع المراجعة إلى مسار عام مؤجل. قد يحمي الأنظمة الحية من استخراج فوري. وقد يبني قفصا أنظف.

## Scanner

مسار الحفظ مسلح. يخصص payload حيازة المستقبل لمراجعة حجر مؤجلة ويمنع النقل المباشر إلى Deep Reach.

مستقبل PAYLOAD // حفظ الحجر. المستقبل: مسار escrow حجر. إبقاء متجه الحوض مختوما، حفظ استمرارية بيئة Atlas، رفض الاسترجاع المؤسسي المباشر. المراجعة العامة مؤجلة. سلطة الخروج غير محسومة.
