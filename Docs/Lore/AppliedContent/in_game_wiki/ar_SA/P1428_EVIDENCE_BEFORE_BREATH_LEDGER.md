# سجل الدليل قبل النفس

يمكن أن يغادر distress hash من HECTON-8 قبل اللاعب لأن الدليل مصمم ليكون صغيرا. إنه checksum وcustody وwitness time وادعاء ضيق حول ما كان موجودا. يمكنه عبور relay window على أجزاء. يمكن تخزينه وتسعيره والطعن فيه ونسخه من دون أن يطلب من أحد أن يبقيه دافئا.

الشخص ليس هذا النوع من payload. الجسد الذي يتنفس يحتاج حرارة وضغطا وطبابة ومعالجة تلوث وroute authority وcustody قانونية وreceiver يقبل امتلاك التوقف. يمكن للطريق قبول دليلك ورفض كتلتك. في HECTON-8 هذا ليس تناقضا. إنها قسوة نظام يعرف بالضبط قيمة الإنسان كأجزاء.

لذلك يجب ألا يبدو أول packet مجاب كإنقاذ. يمكن لـ Black Keel أن يعترف بالـ hash. يمكن لـ broker أن يرتب sample. يمكن لـ return desk طلب الإحداثيات وsubstrate وproof integrity بينما عداد الهواء يستمر. اللاعب لا يحاول إبلاغ الحضارة. الحضارة تعرف بالفعل. العمل هو جعل الجسد الحي أصعب تجاهلا من البيانات التي أنتجها.

## Scanner

موثق DISTRESS HASH // cradle متآكلة بالملح مع witness seal سليم. الحزمة مقبولة: identity hash وsample hash وtime window وpressure telemetry. الشخص غير مقبول. دعم الحياة فاتورة منفصلة.

## Terminal

RETURN ACTION QUEUE // سلسلة الدليل موثقة. لغة الإنقاذ معلقة حتى تعيين route ownership وbreathing-mass custody وسرير حجر وحجز lift. لا تخلط acknowledgement مع extraction.
