# نافذة الحمولة

نافذة الحمولة تجعل النهايات مادية. يستطيع اللاعب نقل كتلة محدودة فقط عبر الضغط والطقس وتوقيت الإشعاع وهندسة Black Keel. المال والأدلة والأسماء والإحداثيات والعينات الحية وإشارة Atlas أو الصمت لا يمكن أن تغادر كلها معا.

## Scanner

حزمة صعود مرتجلة. يمكنها مغادرة المحيط إذا اتفقت الكتلة والطقس وهندسة الحاملة.

## Terminal

PAYLOAD SLOT: محدود. WINDOW: مفتوحة. ROUTE: متنازع. CLAIM VALUE: متغير. EVIDENCE STATE: غير كاف لنزاع نظيف.

## Audio

النافذة مفتوحة. لن تبقى مفتوحة لكل شيء.

## Field Note

الخروج مسار. الخروج نظيفا أسطورة.
