# سجل تسلسل التسرب والصدأ والغشاء الحيوي

بقع التسرب في HECTON-8 ليست وسخا للزينة. إنها ساعات ذات طبقات. الصدأ والملح والغشاء الحيوي والزيت وسيلان الحشية لا تظهر بالسرعة نفسها ولا للسبب نفسه. إذا قرئت معا، صار الجدار سجلا للفشل.

الصدأ تحت البراغي يعني أن الماء بقي هناك طويلا. الغشاء الأخضر البني يعني تغذية بطيئة: آلة دافئة، أثر نفايات، مبرد، أو رشح عبر حشو عضوي. الملح الأبيض يعني انتقال ماء أو جفافا أو دورات ضغط. الزيت فوق الملح جاء لاحقا؛ الملح فوق الزيت جاء بعده الماء.

بالنسبة للمغير، الترتيب مهم. غرفة فيها خدش عنيف واحد خطرة لكنها بسيطة. غرفة ذات طبقات عاشت بعد بداية فشلها. شخص ما ضخ ومسح وشغل غرف الضغط أو مرر الطاقة عبر مكان كان يخسر أمام البحر.

## Scanner

أثر تسرب // صدأ تحت صف البراغي، غشاء حيوي أخضر بني، ازهرار ملحي عند شفة الحشية. بقعة زيت وماء تعبر حافة معدنية: التسرب تكرر بعد الغمر الأول لا بسبب ضربة واحدة.

## Terminal

تسلسل التسرب // اقرأ الطبقات بالترتيب. الصدأ ينمو حيث بقي المعدن رطبا ومعه أكسجين. الغشاء الحيوي يتبع تغذية بطيئة. الملح يدل على جفاف أو تنفس ضغط. سيلان أسود من الحشية تحت طلاء نظيف يعني أن الحشية فشلت قبل اللوح.

## Audio

التسرب غير الممسوح ساعة. المستعمرة قاست الزمن بالبقع.

## Field Note

الصدأ الجديد يصرخ. الملح القديم يشهد.
