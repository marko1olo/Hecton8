# حيازة الحزمة

تم العثور على ختم حزمة. يستطيع Black Keel استقبال الشحنة، لكن الدليل يحتاج مصدرا وختما و witness hash وعلامة ترحيل ومسار مستقبل وحالة ضرر. احفظ وسوم الحيازة قبل تفكيك العتاد.

## Scanner

ختم الحزمة // شريط witness hash متضرر لكنه مقروء. احفظه قبل قطع الخردة. الدليل غير المختوم يتحول إلى مادة مطالبة.

## Terminal

موثق حزم KEELMARK // احفظ لوحة الختم و witness hash وختم المسار ووسم الموصل قبل النقل. المادة بلا ختم قد تعالج كخسارة مطالبة.

## Audio

ترحيل Black Keel: الشحنة كتلة. الدليل حيازة. أحضر الاثنين، وإلا ستحاسبك النافذة على الفرق.

## Field Note

الختم أولا، القطع ثانيا. العينة النظيفة ذات الوسم المكسور تخص من يملك الدفتر.
