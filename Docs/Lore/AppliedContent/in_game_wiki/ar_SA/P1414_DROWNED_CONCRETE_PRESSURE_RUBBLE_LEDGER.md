# سجل الخرسانة المضغوطة الغارقة

الخرسانة الغارقة ليست خلفية. آثار الحشيات وظلال الصدأ والركام الخزفي ورمل الأصداف في الشقوق تحفظ شكل غرف اختفت. قبل القطع، اسأل: ماذا كانت هذه البلاطة تمنع؟

الحافة الخضراء السفلية تعني ماء راكدا قبل الانهيار. الوجه النظيف قد يكون salvage حديثا أو زلزالا أو فشل ضغط. الصدأ بلا قضيب يعني معدنا أزيل أو ذاب. غبار الحشية يكشف موضع باب ضغط.

يتبع Marauder ظل الصدأ إلى عصب صيانة، ويتجنب قطع آخر قطعة ضغط، ويجد لوحة مسار تحت الرمل. محا المحيط الغرفة، لا طريقة موتها.
