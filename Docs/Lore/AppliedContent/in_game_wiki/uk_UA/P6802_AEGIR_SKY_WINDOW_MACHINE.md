# Машина небесного вікна Aegir

Видиме небо Aegir це route machinery, а не декорація. Місячні тіні можуть ламати relay confidence, шторми можуть захистити body і вбити upload, а чиста carrier line все ще може провалити radiation, tide, quarantine або mass checks. Читай sky windows як складені ворота: packet, body, proof і salvage не мусять ділити один pass.

## Scanner

ЧИТАННЯ SKY WINDOW // Видиме ясне небо не є rescue clearance. Тінь Kestrel, storm ceiling, radiation count, tide load і carrier phase не сходяться.

## Terminal

ROUTE PLATE AEGIR // Стан вікна частковий. Packet line може бути відкритою, поки ascent body, quarantine і tonne-window mass залишаються закритими.

## Audio

Нотатка relay: небо яскраве, route брудний. Надсилай тільки packet; тримай ascent, доки moon tag, storm ceiling і mass line не погодяться.

## Field Note

Небо може бути відкритим для packet і закритим для твого body. Перевір усю машину, перш ніж радіти.
