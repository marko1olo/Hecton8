# Журнал хронології течі, іржі та біоплівки

Плями течі в HECTON-8 - не декоративний бруд. Це шаруваті годинники. Іржа, сіль, біоплівка, олія й стік із прокладки з'являються з різною швидкістю. Разом вони перетворюють стіну на запис відмови.

Іржа під болтами означає довгу присутність води. Зелено-бура біоплівка говорить про повільне живлення: тепле обладнання, відходи, охолоджувач або просочування через органічну набивку. Біла сіль означає міграцію, висихання чи цикли тиску. Олія поверх солі прийшла пізніше; сіль поверх олії прийшла після машини.

Для мародера порядок важливий. Кімната з одним грубим ударом небезпечна, але проста. Кімната з шарами жила після початку відмови. Хтось качав, витирав, ганяв шлюзи або вів живлення через місце, яке вже програвало океану.
