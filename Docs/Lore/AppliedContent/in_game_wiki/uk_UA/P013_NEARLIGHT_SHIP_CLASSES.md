# Класи навколосвітлових кораблів

Навколосвітлові кораблі збудували людську сферу без зламу фізики. Першими прийшли дешеві голчасті зонди, потім кораблі-засівачі й носії Atlas із фабриками, сплячими, контрактами й захистом.

Таблиця класів відділяє володіння від порятунку. Aegir може бути заявлений людським правом і все одно лишатися важкодоступним для тіл.

## Scanner

Транзитний маніфест: голчастий зонд, корабель-засівач, вантажний носій Atlas, транспорт сплячих, системний тендер і носій claim-pool.

## Terminal

ТАБЛИЦЯ ТРАНЗИТНИХ КЛАСІВ // FTL-лінію не зареєстровано. Усім класам потрібні пускова інфраструктура, маса захисту, план гальмування, маршрутне зберігання й боргова влада. Міжзоряне володіння не означає місцевий порятунок.

## Audio
