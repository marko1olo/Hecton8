# Слід мови відкликаного доступу

Мова відкликаного доступу - один із тихих замків Deep Reach. Колишнього працівника можна зупинити біля дверей, але текст відмови все одно відкриває процедуру за запечатаним маршрутом. Замку не треба зізнаватися. Досить ужити старі неправильні слова.

Maintenance reclassification означає, що людський маршрут змусили виглядати як сервісний матеріал. Degraded-count означає, що підрахунок працівників прийняли після моменту, коли його треба було перевірити знову. Claim-preservation routing означає, що компанія захищала власність лінії раніше за тіла в лінії. Кожна фраза достатньо мала, щоб пройти як офісна мова, і достатньо точна, щоб вказати на похований коридор.

Так мертве посвідчення лишається корисним у вузький спосіб. Воно не відкриє люк. Воно може змусити архів говорити старим діалектом відповідальності, а цей діалект стає картою.
