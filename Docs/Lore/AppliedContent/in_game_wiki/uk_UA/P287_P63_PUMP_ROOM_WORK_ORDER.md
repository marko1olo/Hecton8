# Робочий наказ насосної P-63

Робочий наказ насосної P-63 робить перший ремонт успадкованою процедурою колонії, а не текстом навчання. Він мокрий, практичний і трохи наляканий у дрібницях. Наказ велить очистити sump, залатати cold seam, дочекатися return pinger і різати fused latch лише після утримання тиску. Ця послідовність навчає гравця, як думали працівники HECTON-8: спершу вода, потім герметизація, звук перед силою, довіра до маршруту наприкінці. Відсутні ініціали старшого й подвійне коло навколо рядка різання роблять папір використаним, а не написаним для гравця. Це малий артефакт, але він тримає весь ігровий цикл у мініатюрі: прочитай кімнату, віднови систему, не довіряй легкому розрізу.

## Scanner

Перший ремонт читається як звичка колонії: качай, герметизуй, слухай, ріж лише якщо кімната перестала брехати.

## Terminal

WORK ORDER P-63: очистити sump; залатати cold seam; перевірити return pinger; різати fused latch лише після утримання тиску; друкувати gasket з місцевого запасу; позначати route safe після трьох повторів acoustic return. Ініціали старшого зникли під водяною плямою.

## Audio

Спочатку насос. Потім герметизація. Якщо співає, припини різати.

## Field Note

Нижня половина планшета промокла наскрізь. Рядок про різання все ще читається, бо хтось обвів його двічі й написав якщо співає, зупинись.
