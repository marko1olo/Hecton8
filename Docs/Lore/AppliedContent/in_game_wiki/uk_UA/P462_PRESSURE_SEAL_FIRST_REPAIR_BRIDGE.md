# Перший ремонт PressureSeal

Знайдено ремонтну нотатку P-63. FiberKelp можна переробити на FiberMesh і використати як несучий шар тимчасового PressureSeal. Пломба сповільнює локальний витік, але не сертифікує підйом.

## Scanner

ЦІЛЬ PRESSURESEAL // Витік воротника P-63. Носій FiberMesh сумісний. Лише локальна стабілізація; сертифікацію підйому відхилено.

## Terminal

ДОПУСК P-63 DEEP REACH // Заміну воротника відкласти. Застосувати затверджений м'який носій там, де витік лишається в локальному сервісному порозі.

## Audio

Ретранслятор Black Keel: латка P-63 локально безпечна, але не підйомна. Забери пломбу, збережи серійник.

## Field Note

Зовні світла вода. Усередині мокрий воротник. Deep Reach назвала це штатним, бо слово дешевше за затискне кільце.
