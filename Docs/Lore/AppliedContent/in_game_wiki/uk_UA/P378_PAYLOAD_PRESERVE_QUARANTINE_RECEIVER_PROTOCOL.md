# Протокол карантинного збереження payload

Протокол збереження тримає басейн поза прямим корпоративним відновленням, але не звільняє його. Payload запечатує координати, тримає екологію Atlas під карантинним escrow і виштовхує розгляд у відкладену публічну лінію. Це може захистити живі системи від негайного видобутку. Це також може збудувати чистішу клітку.

## Scanner

Маршрут збереження зведено. Payload призначає custody отримувача відкладеному карантинному розгляду й блокує пряму передачу Deep Reach.

## Terminal

ОТРИМУВАЧ PAYLOAD // ЗБЕРЕГТИ КАРАНТИН. Отримувач: карантинний escrow lane. Утримувати вектор басейну запечатаним, зберегти безперервність екології Atlas, відмовити прямому корпоративному відновленню. Публічний розгляд відкладено. Влада випуску не вирішена.

## Audio

Збережено живим - не те саме, що випущено.
