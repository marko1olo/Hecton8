# Картка кодексу: фауна із сенсорною міткою

Фауна із сенсорними мітками — один із найчистіших способів побачити машинну екологію HECTON-8, не перетворюючи океан на розум. Deep Reach мітила тварин, shell colonies і маршрутні види для досліджень міграції, переносимості тиску й забруднення. Через роки частина tag опинилася в рубцевій тканині, гніздах панцира, мінеральних ковпачках або кільцях росту. Atlas усе ще може чути слабке повернення й вважати рухоме тіло діагностичним орієнтиром: pressure packet, натяк на забруднення, occupancy маршруту, якір drone sweep, застарілий свідок обслуговування. Це не робить тварину слухняною. Вона може пастися, тікати, полювати чи панікувати зі звичайних причин, поки tag робить її шлях значущим для зламаної інфраструктури. Не читай рух tag як намір. Не вирізай живий tag, якщо ціна маршруту не варта жорстокості й брудних даних. Корисне питання не “чого вона хоче?” Корисне питання: “яка система досі вірить, що цей шрам — sensor?”

## Scanner

Фауна із сенсорною міткою. Старий біометалевий tag Deep Reach у шрамі, панцирі чи кільці росту. Слабке ехо маршруту Atlas; намір тварини не підтверджено.

## Terminal

ЗРАЗОК / ФАУНА ІЗ СЕНСОРНОЮ МІТКОЮ / роль: живий носій telemetry, застарілий survey landmark, забруднювач repair-route / безпечне читання: старий імпульс tag, ріст рубцевої тканини, рух без команди / відмова: трактувати поведінку як послух, вирізати tag із живого тіла, довіряти occupancy echo / примітка маршруту: tag може повідомити кімнату, через яку пройшла тварина, але не причину проходу.

## Audio

Вона не підкоряється Atlas. Вона несе старе питання, яке Atlas досі ставить.

## Field Note

Мітка — шрам, не повідець. Вона може видати тебе, поставити не туди або розбудити те, що тварини навіть не бачило.
