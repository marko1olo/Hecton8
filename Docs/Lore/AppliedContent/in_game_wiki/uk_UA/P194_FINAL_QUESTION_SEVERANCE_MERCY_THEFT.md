# Фінальне питання: відсікання, милість, крадіжка

Відсікання ріже ремонтний шар Atlas-океан, а не один вимикач. Воно може зупинити пошкоджену логіку категорій і закрити Deep Reach живий шлях повернення. Воно ж може змусити vent micronodes замовкнути, обірвати імпульси shell sealant, кинути маршрути позначеної фауни, пошкодити буфери записів працівників і лишити відсіки тиску без системи, що тримала їх герметичними. Вантаж відсікання має зберегти proof-hash, бо після темряви в кімнаті цей вчинок оскаржуватимуть.

## Scanner

ВІСЬ ВІДСІКАННЯ // Розрив неперервності проходить крізь ремонтний шар Atlas: двері тиску, провідну плівку, буфери записів працівників, маршрути позначеної фауни, vent micronodes і шляхи вантажу. Стан доказів змінює ярлик зберігання.
