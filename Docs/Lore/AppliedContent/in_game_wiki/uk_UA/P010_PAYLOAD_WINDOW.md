# Вікно корисного вантажу

Вікно корисного вантажу робить фінали фізичними. Гравець може провести крізь тиск, погоду, радіаційний час і геометрію Black Keel лише обмежену масу. Гроші, докази, імена, координати, живі зразки, сигнал Atlas або мовчання не можуть піти разом.

## Scanner
