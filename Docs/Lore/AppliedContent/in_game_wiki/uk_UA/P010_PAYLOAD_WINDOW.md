# Вікно корисного вантажу

Вікно корисного вантажу — місце, де фінальні вибори стають фізичними. Гравець може провести крізь тиск, штормове прикриття, радіаційний час Аегіра й геометрію відновлення Black Keel лише обмежену масу. Гроші, докази, імена працівників, координати, живі зразки, сигнал Atlas або мовчання не можуть піти разом.
