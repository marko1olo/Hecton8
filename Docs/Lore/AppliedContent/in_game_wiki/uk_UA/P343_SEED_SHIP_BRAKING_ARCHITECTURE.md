# Гальмівна архітектура seed ships

Seed ships не прибували як дослідницькі крейсери. Це були промислові вантажі, сплановані навколо маси сповільнення, втрати захисту, автоматичного будівництва і років холодного staging. Aegir мав залізо до стабільної людської спільноти, бо машини краще переживали гальмівний бюджет.

## Scanner

Архів гальмування: прибуття залежало від жертовної маси, захоплення магнітним вітрилом, термоядерних допалів захоплення і екранного льоду, витраченого за розкладом.

## Terminal

ЖУРНАЛ SEED-ГАЛЬМУВАННЯ: основний magsail розкрито. Захоплення пелет часткове. Запас екранного льоду витрачено. Вантаж прийнято лише для автоматичної вставки інфраструктури.

## Audio

Дістатися було не найважче. Зупинитися з достатньою машиною для будівництва — ось що було важке.

## Field Note

Гальмівні записи — передісторія колонії. Кожен ранній habitat починався з рішення, яку масу можна витратити.
