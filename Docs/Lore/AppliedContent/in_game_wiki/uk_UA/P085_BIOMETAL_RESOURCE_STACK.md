# Ресурсний стек біометалу

Ресурсний стек не дає HECTON-8 схлопнутися в один магічний матеріал. Синій борг важливий, але місяць платить також сульфідними металами, солями, благородними газами, керамікою, каталізаторами, біоволокнами, фотопротеїнами, salvage-залізом і біометалом, зміненим Atlas. Насильство має сенс, бо цінність розподілена: багато малих причин різати, мітити, ховати, повертатися й брехати.
