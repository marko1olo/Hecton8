# Найкращий маршрут: видимий залишок

Видимий залишок - стандарт найсильнішого маршруту. Фінал має рятувати щось конкретне, не перетворюючи HECTON-8 на екран винагороди: публічний запис, закритий маршрут Deep Reach, збережений басейн, звільненого оператора, імена працівників або Atlas proof hash.
