# Фінальне питання: публічний реєстр, втрачений контроль

Маршрут публічного реєстру міняє зберігання на квитанцію. Пакет виходить із басейну зі свідчим хешем, ланцюгом відповідальності, зведенням стану Atlas, закритими координатами синього боргу й доказом маршруту вантажу до того, як Deep Reach встигає закрити архів самостійно. Це захищає імена від простого видалення, але віддає файл регуляторам, кредиторам, мережам уцілілих, доменним судам, конкурентам і кожному одержувачу, який устигне подати першим.

## Scanner

ВІСЬ ПУБЛІЧНОГО РЕЄСТРУ // Пакетний нотаріат Tau/Luyten приймає свідчий хеш до повного зберігання. Deep Reach втрачає одноосібне закриття архіву; відправник втрачає порядок одержувачів.

## Terminal

ФІНАЛЬНА ВІСЬ / ПУБЛІЧНИЙ РЕЄСТР
Тригер: свідчий хеш виходить зі зберігання HECTON-8 через нотаріальний burst Tau/Luyten.
Передано: ланцюг відповідальності, зведення стану Atlas, закриті координати синього боргу, доказ маршруту вантажу.
Заблоковано: одноосібне закриття архіву Deep Reach.
Втрачено: порядок одержувачів, ринкове тлумачення, контроль першого прибуття.
Черга ризику: санкції, замороження маршрутів, тиск порятунку, копії подань, зустрічні пакети фальшивого звіту.
