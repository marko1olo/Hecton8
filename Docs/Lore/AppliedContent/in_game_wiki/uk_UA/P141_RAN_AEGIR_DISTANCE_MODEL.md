# Модель відстані Ran-Aegir

Модель Ran-Aegir дає HECTON-8 масштаб, який відчувається в скафандрі. До 2190 року Aegir досить близький для зондів, фрахту, маршрутного права, боргового заселення й корпоративного апетиту. Але він усе ще надто далекий, щоб затоплений відсік дочекався доброти внутрішніх світів. Відстань стає тиском через релейну затримку, стартові вікна, гальмівне паливо, опіку перевізника, страхові винятки й простий факт: маса приходить повільніше за накази.

## Scanner

Маршрутна пластина підтверджує: Aegir доступний для інфраструктури, але не для аварійного порятунку.
