# Затримка релейних повідомлень

Релейна затримка дозволяє HECTON-8 отримувати владу без турботи. Пакет може нести попередження, борг, власність, опіку чи зізнання через відстань, але не може принести руки в затоплену кімнату. Цей розрив робить зв'язок страшним: віддалені системи лишаються сильними, бо їх написали рано, поставили в чергу рано, оцінили під дистанцію й довірили машинам, які не знають, що відправник мертвий.
