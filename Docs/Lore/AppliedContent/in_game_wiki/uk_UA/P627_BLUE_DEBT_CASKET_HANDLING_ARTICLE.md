# Поводження з касетою синього боргу

Синій борг - salvage, залежний від стану. Тримай його запечатаним, холодним і стабільним за тиском, перш ніж вирішувати: матеріал, цінність претензії, приманка чи доказ.

## Scanner

КАСЕТА ТИСКУ // Стабільна, доки холодна й запечатана. Не стравлювати. Закріпити перед транспортуванням, якщо шов теплішає.

## Terminal

СУБСТРАТ БЕЗПЕРЕРВНОСТІ XO // Зберегти стан тиску. Цивільне зберігання заборонено. Телеметрію зразка вести лише через claim-grade custody.

## Audio

Якщо касета починає рахувати в сонарі, вона вже не тільки твоя.

## Field Note

Синій борг платить, бо приходить із трьома власниками: тим, хто знайшов, тим, хто хоче, і тим, що помітило рух.
