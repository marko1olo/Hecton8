# Вікно маршруту Aegir

Вікно маршруту Aegir — не красивий прогноз погоди. Це короткий час, коли ворожі годинники збігаються: радіація, місячна тінь, storm plume, припливний зсув, акустичний канал, геометрія Black Keel і зберігання tonne-window. Воно може бути відкрите для даних і закрите для тіла. Ядро доказу може пройти карантин, а blue-debt застрягти. Порятунок — перетин виживання, права й маси.

## Scanner
