# Петля зворотного зв'язку сенсорно-міченої фауни

Сенсорно-мічена фауна несе стару колонію у своїх шрамах. Deep Reach мітило тварин для досліджень міграції, тиску й забруднення; пізніше Atlas прочитав ці теги як дешеву екологічну телеметрію. Істота не маріонетка. Її рух однаково може змінити пріоритет ремонту, розбудити маршрут дрона або зробити безпечний прохід зайнятим.

## Scanner

Старий тег Deep Reach під мушлевим ростом. Слід міграції збігається з ремонтним оглядовим проходом.

## Terminal

ПЕТЛЯ ФАУНИ: вбудований тег повертає слабкі пакети тиску, руху й забруднення. Atlas читає рух як стан середовища, а не намір тварини.

## Audio

Воно не полює на тебе. Але все одно може про тебе повідомити.

## Field Note

Для зустрічей, де тварина невинна, але все одно небезпечна для маршруту.
