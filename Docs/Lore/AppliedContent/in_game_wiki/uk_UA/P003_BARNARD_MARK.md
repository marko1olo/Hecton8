# Мітка Barnard

Перша мітка Barnard на HECTON-8 така мала, що її можна пропустити: штамп інструмента, ремонтна звичка, ярлик поставки. Тому вона важлива. HECTON-8 перестає бути далеким контрактом, коли ті самі мітки з'являються біля імен, маршрутів евакуації й провалених дозволів.
