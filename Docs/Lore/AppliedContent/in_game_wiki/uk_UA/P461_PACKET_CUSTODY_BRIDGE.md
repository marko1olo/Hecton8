# Ланцюг збереження пакета

Знайдено пломбу пакета. Black Keel приймає вантаж, але доказу потрібні джерело, пломба, witness hash, позначка ретранслятора, лінія отримувача і стан пошкоджень. Збережи теги перед розбором заліза.

## Scanner

ПЛОМБА ПАКЕТА // Смуга witness hash пошкоджена, але читається. Зберегти до рятувального різу. Доказ без пломби стане матеріалом претензії.

## Terminal

ПАКЕТНИЙ НОТАРІЙ KEELMARK // До передачі зберегти пластину пломби, witness hash, маршрутний штамп і тег роз'єму. Матеріал без штампа може піти як претензійна втрата.

## Audio

Ретранслятор Black Keel: вантаж - це маса. Доказ - це збереження. Принеси обидва, інакше вікно виставить рахунок за різницю.

## Field Note

Спершу пломба, потім різ. Чистий зразок зі зламаним тегом належить тому, хто тримає реєстр.
