# Журнал доказу перед диханням

distress hash може покинути HECTON-8 раніше за гравця, бо доказ створений малим. Це checksum, custody, witness time і вузьке твердження про те, що існувало. Він може пройти relay window частинами. Його можна зберігати, оцінювати, оскаржувати й копіювати, не питаючи, хто триматиме його в теплі.

Людина не такий payload. Тілу, що дихає, потрібні температура, тиск, медицина, обробка зараження, route authority, юридична custody і receiver, готовий володіти зупинкою. Маршрут може прийняти твій доказ і все ще відмовити твоїй масі. У HECTON-8 це не суперечність. Це жорстокість системи, яка точно знає, скільки людина варта по частинах.

Тому перший відповідний пакет не має звучати як порятунок. Black Keel може підтвердити hash. Broker може ранжувати sample. Return desk може просити координати, substrate і proof integrity, поки твій лічильник повітря йде далі. Гравець не намагається повідомити цивілізацію. Цивілізація вже знає. Завдання — зробити живе тіло важчим для ігнорування, ніж дані, які воно створило.

## Scanner

НОТАРІУС DISTRESS HASH // Соляна cradle з цілою witness seal. Пакет прийнято: identity hash, sample hash, time window, pressure telemetry. Людину не прийнято. Життєзабезпечення окремим рахунком.

## Terminal

RETURN ACTION QUEUE // Ланцюг доказів перевірено. Мова порятунку зупинена до призначення route ownership, breathing-mass custody, карантинної койки й резерву lift. Не плутай acknowledgement з extraction.

## Audio

Доказ подорожує, бо він не кашляє, не панікує, не мерзне й не потребує місця.

## Field Note

Якщо термінал пише accepted, читай наступний іменник. Evidence accepted не означає person accepted.
