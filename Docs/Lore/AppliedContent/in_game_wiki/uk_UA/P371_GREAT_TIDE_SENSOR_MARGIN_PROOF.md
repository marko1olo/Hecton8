# Слід припливного допуску

Цей датчик не робить Великий приплив підробкою. Він фіксує час. Проєктний запас колонії зник раніше, ніж Deep Reach визнала ризик у публічному звіті. Маршрутна влада лишила вікно відкритим за комерційним винятком, а потім опублікувала ланцюг каскаду без цього винятку.

## Scanner

Відновлено припливний датчик. Зсувний пік реальний; пробій допуску з'являється за шістнадцять хвилин до публічного часу каскаду Deep Reach.

## Terminal

ПРИПЛИВНИЙ МАСИВ // ПІВНІЧНИЙ ХРЕБЕТ P-63. Хвостовий допуск нижче підлоги зупинки. Вікно маршруту утримано за комерційним винятком. Публічний ланцюг інциденту пропускає примітку про виняток. Контрольна сума brine-buffer ціла.

## Audio

Приплив зламав коридор. Брехня починається з годинника.

## Field Note

Нотатка мародера: збережи сирий слід. Видалений рядок допуску сильніший за будь-яку промову.
