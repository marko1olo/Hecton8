# Зберігання tonne-window Black Keel

Квитанція Keelmark пояснює, чому Black Keel говорить про масу раніше, ніж про порятунок. Носій працює через зберігання tonne-window: юридичний слот, зіставлений фізичному payload, страховій експозиції і фазі маршрутного годинника. Живе тіло, запечатане ядро доказів, зріз технологічного матеріалу Xenon-Omega і ящик відновлюваної обшивки змагаються за те саме вікно, якщо контракт ставить їх в один рядок. Система холодна, але не випадкова. Вона показує гравцю, що цінує фронтир і який вибір першим поїде додому.
