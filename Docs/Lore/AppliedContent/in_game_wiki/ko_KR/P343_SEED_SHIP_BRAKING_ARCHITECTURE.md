# Seed Ship 제동 구조

Seed ship은 탐사 순양함처럼 도착하지 않았다. 감속 질량, 차폐 손실, 자동 건설, 수년의 냉간 스테이징을 중심으로 계획된 산업 페이로드였다. 기계가 사람보다 제동 예산을 더 잘 견뎠기 때문에 Aegir에는 안정된 인간 공동체보다 하드웨어가 먼저 있었다.

## Scanner

제동 기록: 도착은 희생 질량, 자기 세일 포획, 핵융합 포획 연소, 일정에 맞춰 소비된 차폐 얼음에 달려 있었다.

## Terminal

SEED 제동 로그: 1차 magsail 전개. 펠릿 포획 부분 성공. 차폐 얼음 여유분 소모. 화물은 자동 인프라 삽입 전용으로 승인.

## Audio

도착이 어려운 부분은 아니었다. 건설할 만큼의 기계를 남기고 멈추는 것이 어려웠다.

## Field Note

제동 기록은 식민지 이전 역사다. 모든 초기 거주지는 어떤 질량을 소비할 수 있는지에 대한 결정으로 시작됐다.
