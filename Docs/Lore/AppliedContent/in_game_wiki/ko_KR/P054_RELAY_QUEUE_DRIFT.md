# 릴레이 대기열 표류

지연된 통신은 잘못된 시간에도 정확할 수 있어서 위험하다. 운반선 경고는 실제 밸브, 실제 누수, 압력 아래 이미 변한 실제 경로를 설명할 수 있다. 플레이어는 원격 권한을 믿기 전에 패킷 나이와 현지 증거를 비교해야 한다.

## Scanner

릴레이 스탬프는 그것이 부르는 누수보다 오래되었다. 그 지시는 이제 존재하지 않는 방에는 맞았다.

## Terminal

대기열 표류: 패킷 나이가 경로 유효성을 초과. 새 릴레이 창이 열릴 때까지 현지 증거가 운반선 지시보다 우선.
