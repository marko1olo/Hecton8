# Return Action Queue 서명

Return Action Queue 서명은 오래된 HECTON-8 사건을 2190년의 현재 압력과 연결한다. 이 queue는 역사 아카이브가 아니다. Aegir live window 동안 delayed packets를 처리하고 Black Keel이나 relay owner가 무엇을 먼저 해야 하는지 순서를 매긴다. 회수된 strip에서는 payload custody, coordinate receipt, quarantine handshake가 contractor recovery보다 위에 있다. 그래서 방 안에 지휘관이 없어도 Deep Reach는 위험하다. 하위 사무소는 어떤 action이 실행할 만큼 clean한지 결정하는 것만으로 구조 창을 조종할 수 있다.

## Scanner

live return strip 수신: payload custody priority HIGH, contractor recovery BELOW-CLEARANCE, Aegir window 04는 12분간 열림.
