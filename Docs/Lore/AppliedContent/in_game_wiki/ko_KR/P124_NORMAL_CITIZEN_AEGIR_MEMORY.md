# 일반 시민의 에기르 기억

일반 시민에게 Aegir는 금지된 비밀이 아니다. 더 나쁘다. 학교 독본, 보험 경고, 항로 요금표에 남은 낡은 항목이다. 사람들은 바다 행성, 잃어버린 식민지, 격리라는 단어는 기억하지만 교대 근무자, 아이들, 조리사, 압력 기술자, 사망 명단의 이름은 기억하지 않는다. 그 거리가 Deep Reach를 공적 생활 속에서 살아남게 한다. 알려진 재난도 누구도 시신을 보지 않아도 된다면 배경이 된다.
