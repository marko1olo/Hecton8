# 거짓 엔딩 수 사다리

HECTON-8에는 여러 탈출 방식이 있을 수 있지만 진실이 소음이 되어서는 안 된다. 도시어는 거짓 또는 부분 결과를 읽히는 소수 계열로 정리해야 한다. material을 챙기고 떠난다. 빠져나왔지만 다시 끌려간다. 기업 보관이나 격리에 떨어진다. 기계를 끝내지는 못하지만 상처낼 만큼 ledger 진실을 유출한다. 모든 출구는 진짜다. 그러나 어느 것도 바닥은 아니다.

## Scanner

엔딩 사다리 // material 지급, 부분 귀환, 기업 포획 또는 격리, 공개 ledger 유출. 깊은 Atlas 답변 전 네 거짓 계열.
