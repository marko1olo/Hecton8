# 강하 캡슐 손상

## Scanner

좌석은 멀쩡하다. 상승 경로는 파괴됐다. 캡슐은 피난처지 귀환선이 아니다.

## Terminal

## Audio

캡슐은 올라가지 못한다. 배가 아니다.

## Field Note
