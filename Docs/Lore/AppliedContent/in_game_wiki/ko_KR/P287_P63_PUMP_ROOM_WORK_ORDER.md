# P-63 펌프실 작업 지시서

P-63 펌프실 작업 지시서는 첫 수리를 튜토리얼 문구가 아니라 계승된 식민지 절차처럼 느끼게 한다. 젖어 있고, 실용적이며, 작은 방식으로 겁먹어 있다. 지시서는 sump를 비우고, cold seam을 패치하고, return pinger를 기다리고, 압력이 유지된 뒤에만 fused latch를 자르라고 한다. 이 순서는 HECTON-8 작업자들이 어떻게 생각했는지 가르친다. 물이 먼저, 봉합이 둘째, 힘보다 소리, 항로 신뢰는 마지막. 사라진 감독자 이니셜과 절단 줄의 이중 원은 종이가 플레이어를 위해 작성된 것이 아니라 사용된 것처럼 보이게 한다. 작은 아티팩트지만 게임 루프 전체를 축소해 담고 있다. 방을 읽고, 시스템을 복구하고, 쉬운 절단을 의심하라.

## Scanner

첫 수리는 식민지 습관처럼 읽힌다. 펌프질하고, 봉합하고, 듣고, 방이 거짓말을 멈출 때만 자른다.

## Terminal

WORK ORDER P-63: sump 제거; cold seam 패치; return pinger 확인; 압력이 유지된 뒤에만 fused latch 절단; local stock에서 gasket 출력; acoustic return이 세 번 반복된 뒤 route safe 표시. 감독자 이니셜은 물 얼룩 아래 사라짐.

## Audio

펌프가 먼저다. 봉합은 두 번째. 노래하면 자르지 마라.

## Field Note

클립보드 아래쪽 절반은 흠뻑 젖었다. 절단 줄은 누군가 두 번 동그라미 치고 노래하면 멈추라고 썼기 때문에 아직 읽힌다.
