# 케이블 외피 보수 감김 장부

HECTON-8의 케이블은 배경 줄이 아니다. 압력 케이블은 두 장소가 아직 서로를 필요로 했다는 약속이다. 전력, 신호, 펌프 제어, 센서, 해치 구동, 비상등. 외피가 실패하면 보수 감김은 연결을 죽이지 않으려 한 사람들의 짧은 역사가 된다.

흔적의 순서가 중요하다. 가장자리 아래 소금이 있는 회색 테이프는 오래된 수리다. 깨끗한 고무의 클램프 자국은 늦은 개입이다. 긁힘 아래 사선 섬유는 최근 끌림이다. 한쪽 마모는 보관이 아니라 장력 아래 작동한 선을 뜻한다.

마라우더는 감긴 케이블을 경로 증거로 읽어야 한다. 작동 중인 펌프, 숨은 터미널, 전원이 남은 해치, 잔류 전류 함정, 또는 누군가 살려 두려 한 죽은 방으로 이어질 수 있다.

## Scanner

보수 감김 // 검은 고무 케이블 외피, 회색 테이프 띠, 사선 섬유층, 이음의 소금, 클램프 압흔. 한쪽 마모가 가장 강하다. 보관된 것이 아니라 전원이 있거나 하중을 받을 때 끌린 선이다.

## Terminal

케이블 판독 // 자르기 전에 보수 띠를 세어라. 가장자리 아래 소금이 있는 넓은 테이프는 오래됐다. 소금 없는 조인 클램프 자국은 늦다. 깨끗한 긁힘 아래 섬유는 최근 마모다. 높게 묶이고 아래가 닳은 케이블은 방이 움직일 때 하중을 가졌다.

## Audio

죽은 케이블은 쉽다. 보수된 케이블은 누군가 아직 다른 끝을 필요로 했다는 뜻이다.

## Field Note

가장 새 감김을 먼저 자르지 마라. 보통 마지막으로 구하려던 것을 가리킨다.
