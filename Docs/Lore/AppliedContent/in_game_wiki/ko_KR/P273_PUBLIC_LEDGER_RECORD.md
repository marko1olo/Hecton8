# 공개 장부 기록

공개 장부 기록은 보관의 단절이지 판결이 아니다. 페이로드는 Deep Reach가 기록고를 닫기 전에 증인 해시, 가려진 좌표, 증거 등급, 수신 시각표지를 가지고 Tau/Luyten 경로에 도달한다. 삭제는 어려워지지만 이후의 서기, 채권자, 헌장 법정, 생존자 네트워크, 기회주의자도 살아 있는 파일을 받는다.

## Scanner

공개 장부 기록 // 증인 해시가 Tau/Luyten 패킷 경로로 사적 보관을 벗어남. 공개 증거 등급 설정, Deep Reach 응답 지연 첨부.

## Terminal

엔딩 기록 / 공개 장부
경로: 지연 Tau/Luyten 패킷.
페이로드: 증인 해시, 보관 스트립, 좌표가 가려진 증거 등급, 수신자 시각표지.
중계 이후 제어권: 포기됨.
Deep Reach 응답: 공개 영수증 때문에 반대 패킷 지연.
확인된 손실: 송신자는 첫 독자나 이후 제출 사슬을 선택하지 못한다.

## Audio

장부가 도장을 찍었다. 첫 독자는 더 이상 선택할 수 없다.

## Field Note

영수증이 공개라면 파일은 손을 떠나 살아남는다. 도장을 기뻐하기 전에 좌표 가림을 확인하라.
