# 귀환 벡터 창

귀환 창은 탈출을 메뉴가 아닌 하드 SF 공학 사슬로 만든다: 기하, 날씨, 신호, 장비.

## Scanner

궤도 기하학은 구조 버튼이 아니다. Black Keel은 Aegir의 좁은 창에서만 신호를 듣는다.

## Terminal

통신 예측: 운반선은 Aegir 고궤도. 캡슐 상승에는 폭풍 틈, 입자 정지, 깨끗한 중계선이 필요하다.

## Audio

Black Keel은 대답할 만큼은 살아 있다. 구할 만큼 가깝지는 않다.

## Field Note

응답은 자비가 아니라 타이밍이다.
