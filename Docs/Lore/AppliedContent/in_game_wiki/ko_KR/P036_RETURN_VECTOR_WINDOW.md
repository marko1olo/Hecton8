# 귀환 벡터 창

귀환 벡터 창은 Black Keel이 응답할 수 있지만 즉시 구조할 수는 없다는 첫 증거다. carrier는 Aegir 위 자동 전이 궤도를 따라 움직이지만, HECTON-8을 벗어나는 경로는 기상, 하전 입자 잡음, 중계 손상, 미완성 상승 하드웨어를 통과해야 한다.

유효한 귀환 창에는 네 판독이 동시에 필요하다. carrier 기하, 표면 폭풍 틈, 깨끗한 중계 경로, 발사를 견딜 캡슐 사슬이다. 하나라도 실패하면 ping은 회수가 아니라 시간표가 된다. 같은 시스템은 나중에 부분 추출을 지원하지만, 부채와 증거 보관, 손상된 경로를 지우지 않는다. 상승 크래들, 유도 코어, 열 차폐, 귀환 핸드셰이크가 재건될 때까지 궤도 응답은 모두 일정 제약으로 취급해야 한다.

## Scanner
