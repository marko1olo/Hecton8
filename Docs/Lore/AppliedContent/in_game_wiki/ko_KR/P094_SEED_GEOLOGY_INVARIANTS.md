# 시드 지질 불변값

시드 지질 불변값은 긴 반복 플레이에서도 HECTON-8을 일관되게 지킨다. 협곡은 다른 순서로 열리고, 증거는 이동하고, 안전 주머니는 바뀌고, 종 압력도 달라질 수 있다. 별은 Aegir로 남고, 달은 HECTON-8로 남고, 심도대는 순서를 지키고, Great Tide는 간격을 지키며, Atlas 분지는 가장 깊은 진실과의 관계를 유지한다.

## Scanner

루트 생성 노트. 인양 지도는 바뀌지만 달은 같은 뼈를 유지한다.

## Terminal

불변: Aegir 주성, HECTON-8 궤도 사다리, Great Tide 간격, 심도대 순서, Atlas 분지 관계, blue debt 압력 행동. 가변: 협곡 접근, POI 순서, 안전 주머니, bloom 밀도, 인양 노출.
