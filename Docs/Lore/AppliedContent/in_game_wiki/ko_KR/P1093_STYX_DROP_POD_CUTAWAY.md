# Styx 강하 포드 절개도

Styx 포드는 셔틀이 아니라 일회용 압력 껍질이다. Black Keel에서 합법 작업지까지, 가능한 최소 보험 질량으로 슈트 작업자 한 명을 옮긴다. 대기, 폭풍 전단, 수면 충돌을 견뎌 피난처, 약한 전력, 터미널, 증거물을 남길 수 있다.

실패는 구체적이다. 열 타일 소모, uplink 마스트 절단, 압축기 침수, 회수 슬리브 no-lock, claim handshake 회수 임계값 미만. 포드는 작업자를 살려 두면서, 인도와 구조가 서로 다른 계약 사건임을 증명했다.
