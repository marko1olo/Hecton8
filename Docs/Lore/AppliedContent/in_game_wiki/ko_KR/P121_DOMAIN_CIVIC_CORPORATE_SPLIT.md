# 도메인의 시민-기업 법 분열

2190년의 인간권은 희박하고 오래되었으며 구획이 심하다. Sol Core는 여전히 어떤 서류가 소유권으로 인정되는지 결정한다. Centauri는 Deep Reach에 초기 정통성의 언어를 준다. Barnard Yards는 marauder 일이 해적질이 아니라 직업처럼 보일 수 있는 이유를 만든다. Tau Ceti는 증거를 공개할 수 있지만, 릴레이 지연과 정치 심사를 통과해야 한다. Luyten은 패킷을 옮기고 어떤 custody chain이 여정을 견디는지 결정한다. Aegir는 모든 관할이 쓸모 있어지고 아무도 충분히 빨리 도착하지 못하는 곳이다.
