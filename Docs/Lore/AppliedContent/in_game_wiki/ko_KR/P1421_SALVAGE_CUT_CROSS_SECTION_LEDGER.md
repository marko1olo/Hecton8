# 인양 절단 단면 장부

인양 절단은 재료에 남은 논쟁이다. 아무도 아름다움 때문에 압력 선체를 자르지 않는다. 길이 막혔거나, 벽 뒤에 사람이 있었거나, 케이블을 가져가야 했거나, 도면이 금속과 맞지 않게 된 뒤에도 구획에 가치가 있었기 때문에 자른다.

층이 중요하다. 도장은 원래 면을 말한다. 어두운 코어는 하중 경로를 말한다. 세라믹은 열 제어를 말한다. 고무는 밀봉이 잘렸는지 찢겼는지 말한다. 케이블 묶음은 신호 보존, 구리 수확, 또는 시스템 절단 의도를 말한다.

마라우더에게 질문은 전리품뿐이 아니다. 누가, 언제, 무엇을 잃지 않으려고 잘랐는가. 공식 구조 절단과 굶주린 블랙 킬 절단은 같은 가장자리를 남기지 않는다.

## Scanner

절단 가장자리 // 칠해진 선체 피부, 어두운 금속 코어, 세라믹 단열층, 고무 가스켓 단면, 케이블 묶음, 탄 절단선, 찢긴 파면의 소금. 무작위 절단이 아니다.

## Terminal

단면 읽기 // 매끈한 열 비드는 제어된 커터다. 찢긴 세라믹은 공포나 공구 떨림이다. 금속 코어 속 소금은 회수 전 열린 채 젖어 있었다는 뜻이다. 깨끗한 케이블 끝은 침수 후 절단이다.

## Audio

절단 가장자리는 고장 뒤 누가 왔고 무엇을 부술 각오가 있었는지 말한다.

## Field Note

금속보다 세라믹 먼지를 먼저 봐라. 공포는 언제나 부드러운 층을 먼저 흔든다.
