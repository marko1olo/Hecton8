# 압력복 수리 패치 장부

압력복 수리 패치는 생명 유지 물건 위의 인간 필적이다. 공장 패널은 깨끗한 곡선과 인증으로 말한다. 현장 패치는 삐뚠 실, 다른 색 천, 테이프 아래 소금, 다음 압력 주기 전에 누수를 막는 사람의 솔직함으로 말한다.

패치 순서가 중요하다. 십자 바느질 아래 이음 테이프는 첫 수리가 믿기지 않았다는 뜻이다. 실 아래 소금은 이미 물에 노출된 수트다. 패치 위 마모는 착용자가 다시 일했다는 뜻이다. 오래된 손상 위 깨끗한 테이프는 늦은 검사다. 두 색 천은 기증 수트다.

마라우더에게 패치는 의상 장식이 아니다. 비상 경로, 노동자의 마지막 임무, 의료 판단, 훔친 키트, 또는 착용자에게 맞지 않는 수트 등급을 보여 준다.

## Scanner

수트 패치 // 어두운 네오프렌 같은 외피, 꿰맨 수리 섬, 보강 이음 테이프, 소금 마모, 밝은 기술 섬유 띠. 등급이 고르지 않다. 공장 서비스가 아니라 현장 수리다.

## Terminal

패치 읽기 // 테이프 위 십자 바느질은 비상 봉합이다. 실 아래 소금은 노출 후 패치다. 마모 천 위 깨끗한 테이프는 늦은 검사다. 두 색 천은 다른 수트를 뜯었다는 뜻이다.

## Audio

수트 패치는 익사에 반대하는 작은 표다.

## Field Note

패치만 읽지 마라. 무릎, 소매, 도구 주머니와 함께 읽어라.
