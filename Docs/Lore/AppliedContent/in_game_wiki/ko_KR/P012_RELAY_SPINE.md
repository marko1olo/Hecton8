# 릴레이 척추

릴레이 척추는 느린 통신 골격이다. 빔 슬롯, 패킷 버퍼, 보관 도장, 재시도 일정을 운반한다. 증거, 청구, 명령은 움직이지만 침수된 방으로 산소는 가지 않는다.
