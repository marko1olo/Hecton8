# 사물함 이름 프로토콜

사물함은 한 삶 전체를 설명해서가 아니라 사용되었기 때문에 개인적이다. 가장 좋은 증거는 실용적이다. 한쪽이 닳아 반짝이는 배지, 갈라진 씰 위 테이프, 경로 스티커, 노동자식 약어로 쓴 수정 메모, payroll이 나중에 지운 이름판. 이런 물건들은 Marauder가 사용 흔적과 미완 작업으로 사람을 되찾게 한다. 식민지가 인간적으로 느껴지려면 멜로드라마가 필요하지 않다. 기업 청소가 긁어내지 못한 작은 흔적이 필요하다.

## Scanner

사물함 흔적 // 이름판, 도구 마모, pressure tape, 수정 메모, 경로 스티커. 가족 서사 없는 개인 증거.

## Terminal

사물함 규칙: Deep Reach가 payroll에서 지운 이름을 보존한다. 사물함은 배지, 역할, 경로 허가, 수리 습관, 안에 남은 미완의 것을 묶어야 한다.

## Audio

## Field Note
