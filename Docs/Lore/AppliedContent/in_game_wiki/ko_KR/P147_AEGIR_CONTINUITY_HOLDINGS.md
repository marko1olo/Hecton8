# Aegir Continuity Holdings

Aegir Continuity Holdings는 Deep Reach가 아무것도 인정하지 않고 가치를 유지하게 하는 껍데기다. 휴면 항로 임대, 압력 거주지 옵션, 광물 청구, 손상 장비 소유권, recovery 권리를 보유하고 공공 컴바인은 서비스를 말하게 둔다.
