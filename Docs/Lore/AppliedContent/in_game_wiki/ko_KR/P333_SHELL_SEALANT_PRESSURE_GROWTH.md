# 압력성 껍질 밀봉 성장

압력성 껍질 밀봉 성장은 Atlas의 가장 깨끗한 실수다. 수리는 작동한다. 칼슘-규산층과 바이오폴리머 수지가 균열을 닫고 정압을 버티며 물에 잠겼어야 할 방을 구한다. 같은 성장은 표지, 손잡이, 분필 화살표, 긁힌 자국, 스테이션을 통과하는 마지막 인간 경로를 묻을 수 있다.

## Scanner

층진 밀봉재가 균열을 닫고 작업자 경로 표시를 흰 껍질 아래 묻었다.

## Terminal

수리 충돌: 누출률 감소, 압력 경계 개선, 탈출 표시 폐쇄. 껍질 절단 시 침수 경로 재개 가능.

## Audio

방은 살아남았다. 출구는 그렇지 못했다.

## Field Note

문, 기어가는 경로, 압력 선택에서 수리와 피해가 같은 물체일 때 사용.
