# 취소된 접근 언어 흔적

취소된 접근 언어는 Deep Reach의 조용한 잠금장치 중 하나다. 전직 작업자는 문에서 거부될 수 있지만, 거부 문구는 여전히 봉인된 경로 뒤의 절차를 드러낸다. 잠금장치가 고백할 필요는 없다. 잘못된 옛 단어를 쓰기만 하면 된다.

Maintenance reclassification은 사람의 경로가 서비스 자재처럼 보이게 만들어졌다는 뜻이다. Degraded-count는 다시 확인해야 할 작업자 수가 받아들여졌다는 뜻이다. Claim-preservation routing은 회사가 경로 안의 몸보다 경로의 소유권을 먼저 보호했다는 뜻이다. 각 문구는 사무실 언어로 통과할 만큼 작고, 묻힌 복도를 가리킬 만큼 구체적이다.

그래서 죽은 credential은 제한적으로 유용하다. 해치를 열 수는 없다. 하지만 아카이브가 오래된 책임 방언으로 말하게 만들 수 있고, 그 방언은 지도다.

## Scanner

LOCKOUT 흔적 // 거부 문구가 maintenance reclassification, continuity hold, route materials를 명명한다. 문은 배지를 거부하지만 묻힌 경로를 흘린다.
