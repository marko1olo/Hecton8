# 포식자 그림자 인카운터 문법

포식자 그림자 인카운터는 동물이 보이기 전에 바다가 점유되어 있다는 느낌을 줘야 한다. 유용한 경고 사슬은 환경에서 온다. 먹이가 드러난 채 glass grazer가 멈추고, lantern bloom이 한쪽에서 얇아지며, pressureweed가 파도 없이 접히고, sonar는 잔해라기엔 너무 넓은 공백을 보여 주며, 플레이어의 빛은 끝내 선명한 실루엣이 되지 않는 넓은 형체를 가로지른다. 그 동물은 arena에서 기다리는 boss가 아니다. 경로 압박이다. 산소 소비, return-line discipline, 수리 타이밍, scan 신뢰를 바꾼다. 좋은 그림자 인카운터는 부재를 읽는 플레이어를 살린다. 소음을 더하지 말고, 램프를 좁히고, 깨끗한 길을 쫓지 말고, 표시된 물을 직선으로 되돌아가지 말고 각도를 잡아 빠져나가라.

## Scanner

포식자 그림자 흔적. sonar 공백, 끊긴 먹이 경로, 갑작스러운 그레이저 침묵, 넓은 빛 가림. 몸체 미확인. 빛 discipline과 이탈 각도 유지.

## Terminal

인카운터 문법 / 포식자 그림자 / 역할: 몸체 공개 전 경로 압박, 산소 소비 급증, scan 신뢰 붕괴 / 안전 판독: 먹이 경로 정지, bloom 소음 붕괴, 빈 물 주변으로 갈라지는 sonar 반환 / 거부: 첫 경고로 scripted 전신 공개, 무해한 jump scare, 깨끗한 boss arena / 경로 메모: scanner가 목표 이름을 붙이기 전에 작은 동물이 모두 멈추면, 경로는 이미 바뀐 것이다.
