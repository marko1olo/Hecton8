# 시작 claim 변형

시작 claim은 작업 명령 맨 위에 적힌 거짓말이다. 부채 salvage, 증거 bounty, 사라진 경로 장비, 위험 샘플 보관, blacklist 경감. 각 변형은 게시판이 왜 Marauder를 물속으로 내려보내는지 바꾼다. 동기와 첫 압력에 색을 입혀야지, 주인공을 새 가면으로 바꾸면 안 된다.

## Scanner

CLAIM 변형 // 같은 전 Deep Reach Marauder. 다른 첫 부채, bounty, 경로 장비, 샘플 보관 또는 blacklist 경감.
