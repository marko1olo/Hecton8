# 대피 대기열 지연 기록

이 기록은 대피를 빠진 결과가 아니라 순서 있는 지연으로 바꾼다. 먼저 경보, 다음 검토, 그다음 실 등급 초과, 그리고 너무 늦은 해제. Deep Reach는 대피가 미완료였다고 말할 수 있다. 대기열 시계는 복도 압력이 안전선을 넘은 뒤에도 절차가 게이트를 닫아 두었음을 보여 준다.

## Scanner

대기열 시계 회수. 압력 경보가 점유된 복도 구역에 도달한 뒤에도 해제 게이트는 수동 검토 상태로 남아 있었다.

## Terminal

대피 대기열 // 도크 E-7. 수동 확인 비어 있음. 격리 위원회 대기. 해제 승인 전에 실 등급 초과. 게이트 잠금은 침수 손상이 아니라 대기열 상태에 반응.

## Audio

경로가 공기를 잃는 동안 그들은 승인을 기다렸다.

## Field Note

약탈자 메모: 확인 칸이 빈 닫힌 게이트는 이름을 기다리는 결정이다.
