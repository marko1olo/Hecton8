# Vela 내부 릴레이 교통 역할

Vela는 Aegir의 내측 작업 달이다. 나쁜 차폐를 벌할 만큼 빠르게 하전 항로를 지나지만, 오래된 relay 마스크와 반사는 아직도 경로표를 만든다. Black Keel 접근은 Vela의 그림자로 몇 분 동안 링크 잡음을 숨길 수 있다. 같은 그림자는 구조 ping을 늦춰 계약 시계가 이미 다른 손으로 넘어간 뒤 돌아오게 만들 수 있다.

## Scanner

달 장부. Vela는 relay 교통을 가리고 반사한다. 선박은 그것을 움직이는 통행료 문처럼 다룬다.
