# 수심 음향 현장 안내서

HECTON-8에서 깊이는 숫자가 아니라 작업 조건이다. 유광 대륙붕, 케이블 리프, 염수 협곡, 기계 지대, Atlas 분지는 부력, 신호 거리, 산소 작업, 포식자 엄폐, 기계 행동을 각각 바꾼다.

무전이 광물수에서 죽기 때문에 소리가 주된 지평선이다. 음향 덕트는 pinger를 수 킬로미터 운반한다. 염수 거울은 반사뿐인 방을 그린다. 그림자 지대는 옆의 신호도 지운다. 소나는 판결이 아니라 증인으로 대하라.

## Scanner

음향장 // 대륙붕 아래 무전 사망. 수심대, 덕트, 거울, 그림자 지대 확인. 깨끗한 핑 하나는 증인 하나일 뿐.

## Terminal

수중음향 메모 // HECTON-8은 압력, 염분, 열로 소리를 휜다. 절단, 용접, 반향 추적 전에 다른 각도에서 다시 핑하라.

## Audio

HECTON-8은 결코 조용하지 않다. 무엇이 소리를 냈는지, 어떤 층이 휘게 했는지, 누가 더 들었는지 물어라.

## Field Note

한 번 핑해서 알아차려라. 두 번 핑해서 의심하라. 바다가 너무 깨끗하게 답하기 전에 움직여라.
