# Keelmark 톤 창

tonne-window는 연료, 폭풍, 격리, 보험, 우선순위가 계산된 뒤 Black Keel이 하나의 궤도 기회로 들어 올릴 수 있는 회수 질량이다. Keelmark Mutual은 플레이어를 사람으로 보기 전에 질량으로 읽히게 만든다. 보존된 시료, 증거 패킷, 산소 빚, 복지 rider가 숫자를 움직인다.
