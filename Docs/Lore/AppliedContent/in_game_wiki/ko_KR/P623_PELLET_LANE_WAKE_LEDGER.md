# 펠릿 항로 항적 장부

회수된 항적 장부는 FTL 없는 근광속 화물을 설명한다. 빔 세일이 항로를 열었고, 펠릿 공급 핵융합과 단계 제동이 seed 적재물, 중화물, 이후 인간 계약을 Aegir로 실어 보냈다. 모든 연소는 회계를 남겼다. 소모된 펠릿, 차폐 손실, 순항 질량, 제동권, 토퍼 침상, 청구 우선순위다.

## Scanner

추진 항적판 // 펠릿 항로 화물선에서 나온 패인 장부 띠. 각각의 충돌 자국은 누가 어둠 너머로 질량을 밀 돈을 냈는지 기록한다.

## Terminal

LUYTEN 화물 영수증 // 빔 세일 가속 완료. 펠릿 핵융합 인계 승인. 순항 질량, 차폐 침식, 제동 배정, 토퍼 좌석, 청구 화물은 Aegir 포획까지 잠금.

## Audio

## Field Note

깨끗한 연소 자국은 낭만이 아니다. 누군가 밀어내는 값을 냈고, 다른 누군가에게 멈추는 값을 물렸다는 뜻이다.
