# Ran / Aegir 명칭 권한 장부

HECTON-8에 여러 이름이 있는 것은 여러 권한이 같은 물을 소유하려 하기 때문이다. Ran은 별, 천문 기준점, 항로 물리의 이름이다. Aegir는 가스 거인, 하늘의 부모, 청구 사무실이 선호하는 시스템 약칭이다. RAN-B:H8은 카탈로그 키로, 차갑고 보험 가능하며 정렬 가능하다. HECTON-8은 플레이어가 피 흘리는 현장 이름이다.

차이는 중요하다. Ran이라고 쓰인 항로 플레이트는 빛, 거리, 운송을 말한다. Aegir라고 쓰는 Deep Reach 메모는 소유와 청구 연속성을 말할 때가 많다. RAN-B:H8이 적힌 Black Keel 영수증은 특정 위성 기록의 가격을 매긴다. HECTON-8이라고 쓰는 Marauder 메모는 방, 몸, 압력문, 변호사의 이름을 신경 쓰지 않는 바다를 말한다.
