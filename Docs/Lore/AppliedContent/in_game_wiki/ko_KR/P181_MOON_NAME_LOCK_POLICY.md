# Aegir 달 역할 원장

Aegir의 달 목록은 실제로 돌아가는 교통도다. 가스 거성 주변의 각 천체는 교통, salvage 청구법, 통신 타이밍 또는 HECTON-8 탈출 계획을 바꾼다.

## Scanner

공개 명칭은 차트마다 흔들리지만, 궤도는 제 일을 계속한다.

## Terminal

ATLAS LEDGER: 공개 라벨은 보험자와 항로 차트에 따라 달라진다. 기능 역할은 고정된다: 방사선 전단, 중계 마스크, 조석 강제, 얼음 산란, 공개 항로, 격리 소문, 산업 salvage, 높은 창 교통, 깊은 청구, 죽은 비콘 경제.
