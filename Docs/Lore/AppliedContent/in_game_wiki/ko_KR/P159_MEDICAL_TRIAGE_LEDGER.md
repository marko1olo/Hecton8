# 의료 분류 ledger

의료 ledger는 HECTON-8을 구경거리 gore로 만들면 안 된다. 힘은 더 차갑다. 환자는 pressure-state가 되고, 산소 부채가 되고, 락 지연이 되고, 인증 hold가 된다. 의료진은 올바른 처치를 알아도 해치, 경로 시계, Deep Reach signoff가 도움을 늦게 도착하게 해서 환자를 잃을 수 있다. ledger가 인간적인 이유는 시스템이 정확성을 무의미하게 만드는 동안 사람들이 정확하려 애쓰는 모습을 보여주기 때문이다.

## Scanner

TRIAGE LEDGER // 압력 손상, 저산소, 락 지연, 사라진 경로, 인증 hold. 공포는 도움이 얼마나 깔끔하게 기다렸는가다.
