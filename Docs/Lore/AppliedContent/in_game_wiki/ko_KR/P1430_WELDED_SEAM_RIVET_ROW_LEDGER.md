# 용접 이음과 리벳 열 장부

용접 이음과 리벳 열은 식민지의 깨끗한 기하가 자백하기 시작하는 자리다. 공장 선체선은 간격, 베벨, 가스켓, 검사 띠를 참을성 있게 반복한다. 현장 보수는 그렇게 말하지 않는다. 더듬고, 부풀고, 낡은 페인트를 덮으며, 발사 도면이 열을 예상하지 않은 곳에 열 흉터를 남긴다.

순서가 이야기다. 나중 용접 아래 리벳 열이 있으면 원래 고정은 더는 믿지 않았다는 뜻이다. 비드 아래 소금은 이음이 물을 여러 번 들이쉬었다는 뜻이다. 금속에 반쯤 묻힌 가스켓 홈은 정비성보다 강도를 골랐다는 증거다. 깨끗한 비드 옆 찢긴 판 가장자리는 대개 서두름을 말한다. 막을 시간은 있었지만 선체를 정직하게 만들 시간은 없었다.

마라우더에게 보수된 이음은 지도보다 나을 때가 있다. 새던 방, 압력에 휜 격벽, 도구는 있었지만 부품은 없던 승무원, 또는 나중 회수팀이 같은 상처를 보수가 아니라 채취로 다시 연 곳을 가리킨다.
