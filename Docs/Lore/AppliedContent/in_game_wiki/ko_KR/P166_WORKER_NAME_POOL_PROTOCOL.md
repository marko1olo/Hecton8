# 작업자 이름 풀 기록

HECTON-8의 작업자 이름은 작은 증거 사슬이다. 어느 도메인이 그 몸을 바다로 보냈는지, 어떤 일이 그 몸을 유용하게 만들었는지, 어떤 경로에 합법적으로 들어갈 수 있었는지, 어떤 배지 조각이 사물함이나 명단 클립이나 교대판에 남았는지 알려 준다.

이름 풀은 반복 플레이의 식민지가 사람이 살던 곳처럼 느껴지게 하되 canon을 다시 쓰지 않기 위해 존재한다. 펌프 기술자가 한 seed에서는 개스킷 장부 옆에, 다른 seed에서는 medlock 거부표 옆에 나타날 수 있지만, Great Tide와 Deep Reach의 책임과 정거장 지리는 변하지 않는다. 바뀌는 것은 발견 순서이지 범죄가 아니다.

좋은 이름은 땅에 붙어 있어야 한다. 농담도 수집품도 값싼 멜로드라마도 아니다. 임금, 압력 수당, 식사 크레딧, 다음 교대를 기다리던 사람처럼 들려야 한다. Marauder가 아래의 도구를 집기 전에 이름을 읽는 순간, 방은 잠시 컨테이너가 아니라 일터가 된다.

## Scanner

이름 띠 // 출신 대역, 경로 허가, 교대 역할, 긁힌 배지 조각이 한 작업자를 가리킨다. 사물함을 salvage로 만들기 전에 이름을 읽어라.

## Terminal

이름 풀 프로토콜 // 작업자 신원은 안정된 개인명, 도메인 출신 대역, 압력 직무, 교대 문자, 배지 조각, 경로 허가로 구성된다. 시스템은 seed마다 순서와 짝을 바꿀 수 있지만, 사람을 무작위 전리품 라벨로 바꾸면 안 된다. 개인명은 locale별로 작성하고, 역할과 경로와 접근 어휘가 기계적 의미를 맡는다.

## Audio

이름은 식민지가 처음으로 부품처럼 뜯어내려 한 물건이었다.

## Field Note

이름은 장식이 아니다. 정거장이 거짓말을 시작했을 때 누가 젖은 구역에 들어갈 허가를 받았는지 알려 주는 증거다.
