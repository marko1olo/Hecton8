# 케이블 암초 공생

케이블 암초는 중층 경고다. 생명은 산업을 뼈, 그늘, 흐름막, 영양선으로 사용한다.

## Scanner

식물이 전력 줄기와 신호선 위에서 자란다. 암초는 식민지 배선을 골격으로 쓴다.

## Terminal

정비 기록: 케이블 뿌리 매트는 마모를 줄이고 신호를 보존하지만 드론과 초식 동물을 끌어들인다.

## Audio

살아 있는 암초가 서비스 복도의 형상을 배웠다.

## Field Note

첫 결합은 끔찍해지기 전에 유용하다.
