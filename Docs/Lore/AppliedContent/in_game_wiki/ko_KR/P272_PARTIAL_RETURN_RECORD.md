# 부분 귀환 기록

부분 귀환 기록은 탈출이 아닌 안도감을 기록한다. Black Keel은 운용자를 슈트 수리, 공기, 제염, 장부 동기화를 위해 끌어올릴 수 있지만, 같은 seed 귀환 명령은 유치권, 검역 기간, 스캔 기억, 열린 증거 패킷, 미해결 페이로드를 같은 바다에 묶어 둔다.

## Scanner
