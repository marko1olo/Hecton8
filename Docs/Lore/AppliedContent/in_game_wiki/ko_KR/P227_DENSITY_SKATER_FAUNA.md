# 밀도 스케이터 동물상

밀도 스케이터는 브라인 협곡을 빈 부피가 아니라 층상 기계처럼 느끼게 하는 중간 깊이 동물이다. 발, 지느러미, 갈고리 패드가 작은 몸을 몇 초 동안 지탱할 만큼 강한 밀도 경계를 누른다. 눈에는 열린 물을 미끄러지는 것처럼 보이지만, scanner 에는 열린 물에 없어야 할 표면의 잔물결이 남는다. 그 모순이 단서다. 스케이터 흔적은 전단 창, 브라인 계단, 소나 사각 가장자리, 더 큰 생물이 쓰는 사냥 레인을 표시할 수 있다. 동물은 마법도 안전의 약속도 아니다. 수트는 더 무겁고, 더 시끄럽고, 같은 속임수에 맞지 않는 형태다. 스케이터 항적으로 층을 읽어라. 따라갈 수 있다고 가정하지 마라.

## Scanner

밀도 스케이터 // 가느다란 팔다리의 동물이 브라인 경계를 표면처럼 타며, 소나가 열린 물을 예상하는 곳에 잔물결을 남긴다.

## Terminal

기초 동물상: 스케이터 접촉은 찢어진 brine vane, 따뜻한 브라인 계단, 소나 사각 가장자리 근처에서 증가한다. 그들의 항적은 밀도 선반을 표시하지 안전한 발판이 아니다. 불투명 층을 가로질러 쫓지 말 것.
