# Ran/Aegir 거리 대역

Ran/Aegir 거리 대역은 현재 산문을 최종 simulation data처럼 꾸미지 않고 설정을 읽기 쉽게 만든다. Aegir는 probe, freight, debt-backed settlement로 닿을 수 있지만 방이 침수되기 시작한 뒤의 가벼운 구조로는 닿지 않는다.

## Scanner

공개 대역: Ran/Aegir는 Sol에서 온 10광년급 no-FTL 항로다.

## Terminal

EPHEMERIS BAND: 천체 상수가 테이블에서 고정될 때까지 공개 문장에는 10광년급을 사용한다. 이 항로에는 FTL rescue가 없다.

## Audio

10광년은 지도에서는 가깝고 계약에서는 잔혹하다.

## Field Note

공개 천문 기록: 거리 대역과 항로 지도는 설명 범위이며 최종 ephemeris constants가 아니다.
