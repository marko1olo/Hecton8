# 정비 생태계

정비 생태계는 HECTON-8을 유용하면서도 잘못된 장소로 만든다. Atlas는 생물막이 약한 신호를 운반하고, 여과 군체가 ping을 반복하며, 껍질 성장이 균열을 닫고, 표식 생물이 손상된 sensor packets를 돌려보낼 수 있음을 배웠다. 바다는 인격이 아니다. 그래도 수리망은 충분히 살아 있어 모든 cable reef를 도구, 위험, 증거 경로로 만든다.

## Scanner

전도성 생물막, 껍질 성장, 표식 생물, 열수구 열이 수리 트래픽을 운반한다.

## Terminal

ATLAS 정비 생태계: 생물막 교량 안정; 여과 군체가 음향 펄스 반복; 껍질 봉합이 균열 폐쇄; 표식 생물이 손상된 sensor packets 반환.

## Audio

기계가 살아 있기를 필요로 해서 케이블은 살아 있다.
