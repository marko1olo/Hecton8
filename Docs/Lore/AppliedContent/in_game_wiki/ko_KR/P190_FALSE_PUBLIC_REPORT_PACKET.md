# 거짓 공개 보고 패킷

거짓 공개 보고 패킷은 Deep Reach가 세계들에 안전하게 보여 줄 수 있었던 HECTON-8의 버전이다. 가짜 바다를 만들어 내지 않는다. Great Tide는 실제였고, 중계 지연도 실제였으며, 격리 불확실성도 실제였다. 그래서 보고서는 대충 읽으면 버틴다. 거짓말은 누락 속에 있다. 수용된 위험 여유, 지연된 대피 권한, Atlas 연속성 가중치, 보험 전환, 회수 보관 압력을 제거한다. 플레이어는 이것을 마지막 기업적 수로 읽어야 한다. 냉정하게 들릴 만큼 물리를 남기고, 죄책을 지울 만큼 결정을 잘라 내는 것이다.

## Scanner

공개 보고서가 통했던 이유는 실제 바다는 남기고 그 안의 인간 선택을 제거했기 때문이다.

## Terminal

PUBLIC PACKET: HECTON-8 손실은 예외적 조석 연쇄, 중계 지연, 격리 불확실성 탓으로 귀속. 누락: 수용된 위험 여유, 대피 해제 보류, Atlas 연속성 오버라이드, 청구 전환, 화물 우선 회수 요청.

## Audio

그들은 물에 대해서는 진실을 말했고, 손에 대해서는 거짓말했다.

## Field Note

최고의 거짓말은 조석을 부정하지 않았다. 조석을 엄폐물로 삼았다.
