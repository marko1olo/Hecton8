# 앵커 작업자 이름 세트 A

앵커 작업자 이름 세트 A는 플레이어가 처음 알아보기 시작해야 할 인간 층이다. Mara Venn, Juno Kade, Ren Okoye, Sahana Iqbal, Lian Torres, Oskar Neumann, Aya Morita, Pavel Sorn은 얕은 수역과 산업 선반의 증거에 속한다. 이 이름들은 전기로 도착해서는 안 된다. 사물함 라벨, 펌프 태그, 항로 허가, 얼룩진 식사 표, 금 간 도구 케이스에 나타나고, 나중에 의미를 바꾸는 기록으로 돌아와야 한다. Set A는 더 깊은 음모가 분명해지기 전에 식민지를 사람이 살던 곳처럼 만든다.

## Scanner

초기 이름은 연설이 아니라 일을 통해 돌아와야 한다. 얕은 경로는 반복으로 기억을 가르친다.

## Terminal

ANCHOR SET A: 얕은 수역과 산업 선반에서 반복된다. 각 이름은 하나의 도구, 하나의 항로 허가, 하나의 손상된 작업 물건, 하나의 후반 모순에 묶여야 한다. 이 이름들은 식민지가 회수물이 되기 전에 일터였다는 플레이어의 첫 증거다.
