# 물적 지급 기록

물적 지급 기록은 돈을 받은 결말의 영수증이다. Keelmark/Recovery Compliance는 분지 좌표, 블루-부채 샘플, 운반체 보관 해시를 받고 운용자의 유치권을 줄이거나 닫는다. 같은 영수증은 증인 자료, 작업자 이름, 구조 질량 감사를 공증 보관 밖에 두며, Deep Reach에게 묻힌 작업조보다 더 깨끗한 HECTON-8 복귀 경로를 준다.

## Scanner

물적 지급 기록 // Keelmark/Recovery Compliance가 분지 좌표와 블루-부채 샘플을 수락. 작업자 증거는 공증 보관 밖에 남고 운용자 유치권은 감액됨.
