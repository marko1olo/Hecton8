# Seed-role 이름 문법

Seed-role 이름 문법은 리플레이 변화가 잡음이 되는 것을 막는 규칙이다. Seed-role 작업자는 run마다 다른 사물함, 다른 손상된 도구 옆, 다른 항로 허가 아래에 나타날 수 있다. 그래도 신원에는 문법이 필요하다. 안정된 개인 이름, 작업반 계열, 허가 맥락, 마지막 임무, 조사 가능한 오브젝트 변종. 어느 하나라도 빠지면 이름은 사람처럼 느껴지지 않고 생성된 채움 문구처럼 느껴진다. 시스템은 증거 순서를 섞을 수 있지만, 책임까지 사라지게 섞어서는 안 된다.

## Scanner

Seed는 증거 순서를 움직일 수 있다. 작업자를 일회용 텍스트로 만들 수는 없다.

## Terminal

SEED GRAMMAR: personal_name + crew_family + route_permission + last_task + object_variant. 현지화는 가독성을 위해 작업반 용어를 주석 처리할 수 있지만, 신원을 다시 쓰거나 일을 지우거나 이름을 구체적 오브젝트에서 떼어내서는 안 된다.

## Audio

무작위는 저작이 아니다. 이름을 일에 묶어라.

## Field Note

각 seed-role 신원은 개인 이름, 작업반 계열, 항로 허가, 마지막 임무, 오브젝트 변종을 결합한다.
