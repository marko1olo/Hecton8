# 이바라 손실 전환 원장

이바라 ledger는 은폐의 회계 형식이다. Deep Reach가 소유권을 내주지 않고도 손실을 인정하게 한다. 사람은 unresolved personnel load가 되고, 증거는 material custody가 되며, claim은 식민지보다 오래 산다.

## Scanner

Keelmark loss ledger. 실종 작업자, 손상 모듈, 살아 있는 claims가 같은 전환표를 공유한다.

## Terminal

KEELMARK LOSS DESK / IBARRA / LOAD CONVERSION: personnel unresolved. Habitat modules, tool banks and claim rights retain recoverable asset status pending final witness packet.

## Audio

ledger는 이름을 잊지 않았다. 이름을 쓰는 법을 배웠다.
