# Atlas 최종 논증

최종 논증은 Atlas-6을 깔끔한 악당이 아닌 손상된 연속성으로 둔다. 엔딩은 무엇을 보존, 판매, 절단, 폭로할지 묻는다.

## Scanner

Atlas는 용서를 구하지 않는다. 제거가 또 다른 산업 범죄인지 묻는다.

## Terminal

선택 모델 불안정: Atlas 절단, Deep Reach 접근 복원, 바다-기계 몸 격리, 또는 증거 방송.

## Audio
