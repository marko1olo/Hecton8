# 패킷 보관

패킷 봉인을 회수했다. Black Keel은 화물을 받을 수 있지만 증거에는 출처, 봉인, witness hash, 중계 표식, 수신 레인, 손상 상태가 필요하다. 장비를 벗기기 전에 보관 태그를 지켜라.

## Scanner

패킷 봉인 // witness hash 스트립은 손상됐지만 판독 가능. 인양 절단 전에 보존. 봉인 없는 증거는 청구 재료가 된다.

## Terminal

KEELMARK 패킷 공증 // 이전 전에 봉인판, witness hash, 경로 도장, 커넥터 태그를 보존. 도장 없는 물자는 청구 손실로 처리될 수 있다.

## Audio

Black Keel 중계: 화물은 질량이다. 증거는 보관이다. 둘 다 가져와라. 아니면 창구가 차액을 청구한다.

## Field Note

먼저 봉인하고, 다음에 자른다. 부러진 태그가 붙은 깨끗한 샘플은 장부를 가진 쪽의 것이다.
