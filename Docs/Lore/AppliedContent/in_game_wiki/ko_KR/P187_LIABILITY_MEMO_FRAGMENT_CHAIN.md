# 책임 메모 조각 사슬

책임 메모 조각 사슬은 Deep Reach 증거를 읽는 법을 플레이어에게 가르친다. 하나의 메모에 범죄 전체가 들어 있지 않다. 각 사무실은 자기 행동을 절차처럼 보이게 만드는 문장만 보존했다. 위험 표는 조석 여유가 실패하고 있음을 인정한다. 대피 메모는 지연을 채널 규율로 바꾼다. Atlas 오버라이드는 연속성을 탈출보다 안전하게 들리게 한다. Keelmark 조각은 실종 작업자를 회수 가능한 손실로 전환한다. 플레이어는 서류를 침수된 방, 고장 난 경로 시계, 작업자 이름과 교차 확인해야 한다. 조각들이 자기 사무실을 방어하기를 멈추고 서로 모순되기 시작할 때에야 사슬은 읽힌다.

## Scanner

책임 메모는 조각으로 살아남았다. 각 사무실이 자신을 보호하는 문단만 보관했기 때문이다.

## Terminal

FRAGMENT CHAIN: 위험 여유 표 / 대피 해제 메모 / Atlas 연속성 오버라이드 / Keelmark 손실 전환 / 회수 보관 요청. 공개 요약을 받아들이기 전에 경로 시간, 방 손상, 작업자 이름을 교차 확인할 것.

## Audio

그들은 진실을 금고에 숨기지 않았다. 조각으로 파일했다.

## Field Note

찢어진 메모는 솔직할 생각이 없던 부분에서 솔직해진다.
