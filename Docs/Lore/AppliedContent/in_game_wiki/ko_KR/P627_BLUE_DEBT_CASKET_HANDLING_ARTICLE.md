# 푸른 빚 캐스킷 취급

푸른 빚은 상태 의존 salvage다. 도구 재료, 클레임 가치, 미끼, 증거 중 무엇인지 결정하기 전에 봉인, 저온, 압력 안정 상태를 유지해야 한다.

## Scanner
