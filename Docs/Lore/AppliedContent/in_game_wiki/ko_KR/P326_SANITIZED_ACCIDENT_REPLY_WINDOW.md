# 정제된 사고 응답 창

정제된 사고 응답 창은 Deep Reach에 현재의 목소리를 주지만, 회사를 전지적으로 만들지는 않는다. 첫 실시간 응답은 위협이 아니다. 더 조용한 방식으로 더 나쁘다. 오래된 공개 설명이 새로운 압력 속에서 새 채널로 밀려 들어온다. 메시지는 여전히 폭풍 해일, 지질 붕괴, 자율 대피 실패를 말한다. 그 스크립트가 한 번 Deep Reach를 보호했고 시스템이 다시 그것을 붙잡기 때문이다. 플레이어는 물리적 모순을 발견한 뒤에야 그것을 들어야 한다. 잘못된 문 시간, 나쁜 펌프 인증, payroll 삭제를 살아남은 이름, 날씨와 맞지 않는 손상을 가진 방. 타이밍이 중요하다. 스크립트가 먼저 오면 설명이다. 젖은 증거 뒤에 오면 모욕이다. Deep Reach는 플레이어가 서 있는 방에 말하지 않는다. 그 방이 되기를 원했던 마른 보고서에 말한다.

## Scanner

응답 창이 열렸다. Deep Reach는 방이 아직 마른 것처럼 폭풍 붕괴, 지질 실패, 자율 대피 실패를 반복한다.

## Terminal

DR-LIVE WINDOW / PUBLIC LOSS LINE: 폭풍 해일, 지질 붕괴, 자율 대피 실패 / RESTRICTED ADVICE: 검증되지 않은 Atlas continuity, body-category disputes, basin-coordinate claims 전송 금지.

## Audio

그들은 당신이 찾기로 되어 있던 방에 답했다. 당신이 서 있는 방이 아니다.

## Field Note

첫 물리적 모순 뒤에 배치. 플레이어는 오래된 공개 스크립트를 듣기 전에 젖은 증거를 가져야 한다.
