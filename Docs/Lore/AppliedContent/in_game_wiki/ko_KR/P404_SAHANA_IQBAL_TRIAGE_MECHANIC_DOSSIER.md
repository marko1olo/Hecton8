# 사하나 이크발, 분류 정비사

사하나 이크발은 다친 작업자들의 이름이 레일 위로 올라가기를 기다리는 방에서 기계를 수리했다. 그녀의 기록은 토크 메모, 침상 태그, 스크러버 카트리지, 산소 예비표, 주황색 격리 테이프를 묶는다. 이 물건들은 Deep Reach의 지연을 물리적으로 만든다. 볼트 장력을 제한하던 같은 판이 다음 압력 저하 전에 어느 몸, 밸브, 필터가 먼저 주목받을지 결정했다. 이크발의 일은 크게 쓰인 자비가 아니다. 공식 순서가 계속 바뀌는 동안 가장 덜 치명적인 순서를 고르는 손이다.

## Scanner

기록: 사하나 이크발. 토크판, 침상 태그, 격리 테이프가 하나의 대기 순서를 공유한다.

## Terminal

분류 구역 C-2 / IQBAL, SAHANA: 산소 예비 태그 옆에 토크 한계 게시. 도구, 침상, 스크러버 카트리지가 같은 레일에 줄을 선다. 격리 용어가 도달선을 다시 옮겼다.

## Audio

이크발은 닿을 수 있는 것을 고쳤다. 무엇이 닿을 수 있는지는 판이 계속 결정했다.

## Field Note

이크발은 격리 수리 루프, 의료 구역 복도, 산소 대기열, 기계 선택이 인간 시간을 눈에 보이게 소모하는 인터페이스에서 사용한다.
