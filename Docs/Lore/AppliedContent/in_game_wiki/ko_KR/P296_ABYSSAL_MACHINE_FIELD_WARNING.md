# 심연 기계장 경고

이 경고는 심해 생태를 마지막 Atlas 접근로와 연결한다. 플레이어는 더 이상 생명이 우연히 들어 있는 폐허를 건너는 것이 아니라, 기계를 운반하는 법을 배운 생명을 건넌다.

## Scanner

실트가 조류를 거슬러 움직인다. 필터 몸체들이 불빛 아래에서 위치를 바꾸고 있다.

## Terminal

ROUTE WARNING: 심연 기계장의 실트 이동이 조류 모델을 초과. 필터 몸체와 묻힌 액추에이터 갈비가 이동 인프라로 등록됨. 이격 유지. 부드러운 바닥에 앵커 금지.

## Audio

바닥은 멈춰 있지 않다.

## Field Note

후반 경고: 조용하고 객관적인 공포. 최종 필드는 보스 준비가 아니라 깨어나는 인프라다.
