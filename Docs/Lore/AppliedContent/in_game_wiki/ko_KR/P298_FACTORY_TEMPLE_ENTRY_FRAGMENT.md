# 공장-사원 입구 파편

이 파편은 최종 구역의 시각 문법을 정의한다. 성스러운 느낌은 우연이다. 수천 번의 수리가 반복되어 기계, 생물, 인간의 손상이 하나의 패턴이 되었다.

## Scanner

합금, 껍질 밀봉재, 손도구, 활성 수리 펄스가 하나의 표면으로 등록된다.

## Terminal

ENTRY MARKER: 유지보수 범주 붕괴. 도구 흉터, 밀봉 껍질, 케이블 뿌리, 필터 조직, 액추에이터 갈비가 하나의 수리 표면으로 등록됨. 인간 경로 표식은 더 이상 우선되지 않는다.

## Audio

이건 방이 아니다. 습관이다.

## Field Note

시각 규칙: 산업, 조직, 반복이 의식이 되었기 때문에 사원처럼 보일 뿐이다.
