# Barnard Yards 인양 기원

Barnard Yards는 조작자가 HECTON-8의 첫 수리 순서를 아는 이유다. 배수, 격리, 등급 내 패치, 서비스 금속만 절단, 증거 보존, 이동. 이 능력은 자유가 아니다. 같은 야드 논리가 공구, 훈련, 죽은 청구를 Black Keel이 가격 매길 수 있는 부채로 바꾼다.

## Scanner

BARNARD YARDS 공구 태그 // 임대 cutter 손잡이. 압력 클램프 인증 유효. 부채 창은 Black Keel 접수와 연결. 조작자는 죽은 청구 인양 훈련을 받았고, 무료 구조가 아니다.

## Terminal

BARNARD YARDS 대여 카운터 // 지급: 유도 cutter, 클램프 세트, 봉인 게이지, 증인 슬리브. 유치권 주석: 공구 분실, 오염, 미인증 절단, payload 증인 실패는 계약 작업을 회수 가능한 부채로 바꿀 수 있다. 자르기 전 배수. 들어 올리기 전 등급 확인. 판매 전 태그.

## Audio

네가 빌린 것은 cutter지 청구권이 아니다. 손잡이, 클램프 수, 깨끗한 증인 태그를 돌려와라.

## Field Note

Barnard는 조용히 자르고 빚을 크게 읽는 법을 가르친다. cutter 태그는 일련번호가 붙은 줄이다.
