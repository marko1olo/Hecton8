# HECTON-8 중궤도 조석 역할

HECTON-8은 Aegir의 궤도 수학이 개인의 문제가 되는 달이다. 최악의 내부 방사선에서는 긴 작전에 충분히 멀고, 바다를 계속 움직이게 할 조석에는 충분히 가깝고, Deep Reach가 압력 아래 건설할 만큼 가치가 있다. 같은 위치가 구조를 더럽힌다. 조석 위상, 캐리어 질량, 폭풍 노이즈, 법적 보관이 수트 위에서 움직이는 천장처럼 만난다.
