# 릴레이 메시지 지연

릴레이 지연은 방 안의 살아 있는 목소리 없이도 Deep Reach가 플레이어를 위협하게 한다. 계약 기계, 공증인, 청구 창, 캐리어 조항은 연민보다 먼저 도착할 수 있다. 더 일찍 쓰였고, 더 일찍 대기열에 들어갔으며, 거리를 견디도록 가격이 매겨졌기 때문이다.
