# 더 위험한 계약 seed

위험한 계약은 survival을 망가뜨리지 않고 숙련된 Marauder를 유혹하는 방식이다. 게시판은 나쁜 창, 편한 깊도 아래의 이른 하강, 봉인 유지 샘플, 모든 지름길을 비싸게 만드는 증거 보관 조건과 맞바꿔 더 큰 lien 경감을 제시한다. 플레이어가 고르는 것은 계승된 힘이 아니라 압력이다.

## Scanner

계약 SEED // 더 나쁜 창, 더 깊은 첫 목표, 더 엄격한 보관, 더 희귀한 샘플, 더 큰 lien 경감. 계승 힘 없음.
