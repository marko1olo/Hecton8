# 베라 사토-렌 반환 조치

베라 사토-렌은 2190년 회수 준수 사무소 서명자로, 현재의 Deep Reach에 얼굴을 주되 물리적으로 어디에나 있게 만들지는 않는다. 그녀는 패킷, 보관 창, 운송체 조항, 지연 지시를 통해 행동한다. 압박은 절차적이다. 좌표를 회수하고, XO 체인을 증명하고, Atlas 접근 상태를 보고하고, payload가 아직 통제 가능하면 계약자 침묵을 유지한다.

반환 조치 언어가 위험한 이유는 도움처럼 들릴 수 있기 때문이다. 구조는 여전히 가능하지만 payload 보관 이후에만 가능하다. 지원은 제안될 수 있지만 증거 노출 위험이 관리 가능한 동안뿐이다. 패킷을 읽는 Marauder는 악당에게 고함을 듣는 것이 아니다. 답하든 답하지 않든 닫히는 창에 대해 측정되고 있다.

플레이어에게 사토-렌은 Deep Reach를 역사적 책임에서 현재의 압박으로 바꾼다. 오래된 식민지는 무덤만이 아니다. 활성 청구 현장이다. 회수된 모든 기록은 누가 먼저 받느냐에 따라 증거, 몸값, 침묵 조항, 협상 무게가 될 수 있다. 그것이 현대 Deep Reach의 위협이다. 깨끗한 적 함대가 아니라, 진실이 물 밖으로 나오기 전에 반환을 소유하려는 법적 압박 세포.

## Scanner

반환 조치 패킷 // V. 사토-렌은 좁은 보관 창 안에서 회수 가능한 payload, Atlas 접근 상태, 계약자 침묵을 우선시한다.

## Terminal

SATO-REN, V. // 회수 준수 사무소 // 우선순위: 좌표, XO 증거, Atlas 접근 상태, 창 안에서 회수 가능할 경우 계약자 침묵. 구조 지원은 payload 보관과 증거 노출 위험에 조건부로 유지.

## Audio

그녀는 너를 협박할 필요가 없다. 창이 이미 하고 있다.

## Field Note

현재의 Deep Reach는 악당 독백이 아니라 압박으로 도착해야 한다. 그 창이 위협이다.
