# 최종 질문: 공개 장부, 잃어버린 통제

공개 장부 경로는 보관을 영수증과 맞바꾼다. 패킷은 증인 해시, 책임 사슬, Atlas 상태 요약, 가려진 블루-부채 좌표, 페이로드 경로 증명을 싣고 분지를 떠나며, Deep Reach가 혼자 아카이브를 닫기 전에 빠져나간다. 이는 이름을 단순 삭제에서 보호하지만, 규제기관, 채권자, 생존자 네트워크, 도메인 법원, 경쟁자, 먼저 제출할 만큼 빠른 모든 수신자에게 파일을 넘긴다.

## Scanner
