# 자연 황화염 적층

자연 황화염 적층은 HECTON-8이 단순한 기업 범죄 현장이 아님을 보여 주는 첫 증거 중 하나다. 분출구 열, 염수 누출, 금속이 풍부한 지각이 압력 아래 서로 갈리며 선반, 늑골 같은 암벽, 부서지기 쉬운 굴뚝에 흑록색 염을 남긴다. 이것은 도체를 씻고, 비상 전지를 깨우고, 세라믹 플럭스를 맞추며, 승무원이 평범한 광석처럼 다루면 공구를 망가뜨린다. 블루 데트보다 먼저 보여야 한다. 플레이어는 Deep Reach가 도장을 찍기 전부터 이 달에 고유한 화학, 가치, 위험이 있었다는 것을 배워야 한다.
