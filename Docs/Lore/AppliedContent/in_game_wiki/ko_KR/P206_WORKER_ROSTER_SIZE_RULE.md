# 작업자 명부 규모 규칙

작업자 명부 규모 규칙은 버려진 식민지를 읽을 수 있게 유지한다. HECTON-8은 무작위 명패가 널린 장소가 아니라, 여러 작업반이 살고 일했던 곳처럼 느껴져야 한다. 그래서 명부는 반복이 의미를 가질 만큼 작게 설계된다. 앵커 작업자는 사물함, 펌프 태그, 분류표, 항로 허가, 손상된 작업 물건에서 다시 돌아온다. Seed-role 작업자는 각 run에 폭을 주지만, 여전히 직무, 장소, 마지막 임무를 가진다. 이 규칙은 두 실패를 막는다. 인간적 무게 없는 익명의 폐허, 그리고 모든 죽음을 절차적으로 싸게 만드는 이름 난사다.

## Scanner

일흔두 개의 이름은 분위기용 문구가 아니다. 그것은 식민지의 기억 예산이다. 이곳이 실제로 일하던 장소처럼 느껴질 만큼의 손이 있고, 사물함과 수리 태그와 마지막 교대가 같은 사람을 가리킬 만큼 적다.

## Terminal

ROSTER RULE: 실제 명부는 72명의 작업자 신원을 담는다. 24명은 사물함, 장부, 손상된 도구, 허가 도장, 오디오 조각에 반복 등장하는 앵커 이름이다. 48명은 리플레이 변화를 위한 seed-role 이름이다. 생성 이름은 증거 순서를 움직일 수 있지만, 버려지는 채움 문구가 되어서는 안 된다.
