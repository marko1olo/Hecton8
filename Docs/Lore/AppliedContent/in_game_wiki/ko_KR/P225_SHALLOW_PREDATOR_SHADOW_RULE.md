# 얕은 포식자 그림자 규칙

얕은 포식자 그림자 규칙은 첫 포식자가 단순한 괴물 공개가 되지 않게 한다. HECTON-8 은 1분 전까지 유용했던 생태를 통해 위험을 소개해야 한다. 광물막은 남아 있는데 글래스 그레이저가 딸깍임을 멈춘다. 랜턴 드리프트는 여전히 빛나지만 작은 소리가 찢어진다. 셸 클램프는 케이블 라인에서 단단히 조인다. 그다음 넓은 그림자가 밝은 항로를 가로지르고, 안전한 선이 더 이상 안전하게 느껴지지 않는다. 포식자에게 처음부터 이름은 필요 없다. 필요한 것은 결과다. 막힌 수로, 산소가 비싼 우회, 갑자기 너무 시끄럽게 들리는 도구 작업, 물이 바뀌었다는 것을 증명하는 스침. 전투는 나중에 와도 된다. 첫 접촉은 카메라 속 얼굴이 아니라 읽을 수 있는 압박이어야 한다.

## Scanner

얕은 포식자 그림자 // 사라진 그레이저 딸깍임, 찢긴 bloom 소음, 넓게 움직이는 그림자가 첫 접촉이다. 전투 접촉보다 항로 압박이 먼저 온다.

## Terminal

접촉 규칙: 포식자 증거는 피해를 강제하기 전에 항로 선택을 바꿔야 한다. 부재, 침묵, 실루엣, 항적으로 단계화하라. 직접 공격은 플레이어가 최소 두 단서를 무시하거나 오독한 뒤에만.

## Audio

작은 입들이 딸깍임을 멈추면, 움직임을 멈춰라.

## Field Note

포식자에게 먼저 얼굴을 주지 마라. 선반이 어긋나게 하라. 먹이는 남고, 물은 더 밝아지고, 작은 생명은 떠나며, 그다음 그림자가 작업을 가로지른다.
