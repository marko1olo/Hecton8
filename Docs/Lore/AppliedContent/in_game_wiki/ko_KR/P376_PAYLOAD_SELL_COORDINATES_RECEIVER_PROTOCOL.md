# payload 좌표 판매 수신 프로토콜

좌표 판매 프로토콜은 HECTON-8을 회수 가능한 재산으로 취급한다. 최종 payload를 Deep Reach가 사용할 수 있는 수신자 패킷으로 바꾼다. 분지 벡터, 신뢰 격자, 증거 digest, salvage 접근 등급이다. 발신자는 돈과 부채 완화를 받는다. Deep Reach는 접근 지도와 청구로 돌아가는 더 깨끗한 경로를 받는다.

## Scanner

좌표 판매 경로 무장. 분지 벡터, 신뢰 지도, 증거 digest가 Deep Reach Recovery Compliance로 라우팅된다.

## Terminal

PAYLOAD 수신자 // 좌표 판매. 수신자: Deep Reach Recovery Compliance. 전송: 분지 벡터, 신뢰 격자, XO proof digest, salvage 접근 등급. 반환: 지급 영수, 유치권 감면, 회수 우선 도장. 영수 잠금 시 접근 지도 전송.

## Audio

지급 완료. 지도 전송. 노동자 원장은 아직 열려 있다.
