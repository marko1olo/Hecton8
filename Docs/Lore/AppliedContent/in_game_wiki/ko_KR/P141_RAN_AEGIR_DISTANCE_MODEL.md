# Ran-Aegir 거리 모델

Ran-Aegir 모델은 HECTON-8의 규모를 압력복 안에서 느끼게 만든다. 2190년의 Aegir는 탐사체, 화물, 항로법, 부채 기반 정착, 기업의 욕망이 닿을 만큼 가깝다. 그러나 침수된 구획이 내세계의 선의를 기다릴 만큼 가깝지는 않다. 거리는 릴레이 지연, 발사 창, 감속 추진제, 운송자 보관, 보험 제외 조항, 그리고 질량은 명령보다 늦게 온다는 단순한 사실을 통해 압력이 된다.

## Scanner

항로판은 Aegir가 기반 시설의 도달권 안에 있지만 긴급 구조의 도달권 안에는 없다고 확인한다.

## Terminal

항로 모델: Ran/Aegir는 Sol에서 십 광년급 목적지로 취급된다. 공개 표면은 Aegir라고 부른다. 건식 항법 목록은 RAN-B:H8을 유지한다. 정밀 천체력은 표에 잠겨 있다. 운용상의 진실은 지연, 감속 질량, 릴레이 보관, 소유권 위험이다.

## Audio

## Field Note

십 광년은 목록에서는 작고 구조에는 잔혹한 거리다.
