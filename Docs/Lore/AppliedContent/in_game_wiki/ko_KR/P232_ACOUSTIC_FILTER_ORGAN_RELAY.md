# 음향 필터 기관 릴레이

음향 필터 기관 릴레이는 HECTON-8 의 소나 언어를 과학적 톤을 깨지 않고 신체 공포로 바꾼다. 오래된 릴레이 파이프 주위에서 아가미벽 조직이 배플, 주름, 젖은 방으로 자란다. 조직은 말하지 않는다. 임피던스를 바꾼다. 넓은 펌프 소음은 그 안에서 죽는다. 좁은 핑어 펄스는 지나간다. 복귀 반향은 이동되어 돌아오지만, Atlas 가 이용하고 주의 깊은 Marauder 가 배울 만큼 반복된다.

중요한 점은 반복되는 거짓말은 무작위가 아니라는 것이다. 기관 하류의 복도는 플레이어가 어떤 주파수가 살아 있는 필터를 통과하는지 배우기 전까지 더 짧거나 넓거나 막힌 것처럼 보일 수 있다. Atlas 는 망가진 하드웨어만으로는 압력 아래 신호를 보존하기 어렵기 때문에 이 릴레이를 사용한다. 플레이어는 그것을 증거로 쓴다. 같은 펄스 폭에서 같은 소나 오류가 나타난다면, 방은 유령 들린 것이 아니다. 필터링하고 있는 것이다. 그래서 릴레이는 유용하고, 역겹고, 공정하다.

## Scanner

음향 필터 기관 // 아가미벽 같은 조직이 릴레이 파이프 주위에 자랐다. 펌프 굉음을 낮추고, 좁은 핑어 펄스를 통과시키며, 소나를 반복 가능한 거짓말로 접는다.

## Terminal

릴레이 기록: 살아 있는 배플은 핑어급 펄스를 통과시키고, 넓은 펌프 소음을 거부하며, 복귀 반향의 위상을 이동시킨다. 하류 지도는 조건부 참으로 표시할 것.

## Audio

이 방은 살과 파이프로 듣고 있다.

## Field Note

여기서 Atlas 에게 필요한 것은 목소리가 아니다. 올바른 소리만 살아남게 하는 기관이다.
