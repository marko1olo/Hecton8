# 근광속 추진 스택 절개도

Barnard Yards 절개도는 승객이 아니라 계약 작업자를 위해 만들어졌기 때문에 무뚝뚝하다. Atlas급 선체의 여행은 선내 엔진이 점화될 때 시작되지 않는다. 빔 배열이 세일에 전력을 쓰고, 펠릿 항로가 열리고, 포획 질량이 핵융합 전기 목에 도달하고, 차폐 장부가 값비싼 보호층이 수년 동안 먼지에 갈린다는 사실을 받아들일 때 이미 시작된다.

항해 중간은 잠든 사람들을 품은 열 문제다. 방열 리브, 냉동 수면실, 기계 작업장, 시추 크래들, 압력 등급 화물이 같은 여유를 두고 경쟁한다. 도착은 승리의 분사가 아니라 또 하나의 계약 기계다. 자기돛 스풀, 대기제동 외피, 수신 창, 보관 소프트웨어가 누가 현지 제동 슬롯을 쓸 수 있는지 결정한다. 그래서 Black Keel은 Aegir 위에서 salvage 통과권 가격을 매길 수 있어도 구조선이 되지 않는다. 근광속 운반선은 항로 인프라, 열 예산, 제동권, 소유권이 맞아야 움직인다. 갇힌 Marauder는 항로가 강제로 세기 전까지 하나의 항목일 뿐이다.

## Scanner

추진 스택 절개 // Barnard Yards 정비판. 빔 세일 요크, 펠릿 포획기, 핵융합 전기 목, 그림자 차폐, 방열 리브, 자기돛 스풀, 대기제동 외피, 보관 계량기가 같은 항로 번호로 찍혀 있다.

## Terminal

ATLAS 통과 스택 // 외부 빔 배열이 출발 밀기를 제공한다. 펠릿 항로는 포획 질량을 핵융합 전기 목으로 보낸다. 차폐 얼음과 탄소가 먼지 손실을 받는다. 방열 리브는 수년 동안 열값을 치른다. 자기돛, 대기제동 외피, 수신자 권리가 화물이 멈출 수 있는지 결정한다.
