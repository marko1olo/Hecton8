# Nearlight 드라이브 스택 절개도

근광속 선박은 선체에 붙인 마법 횃불이 아니다. 드라이브 스택은 물리화된 전체 경로다. beam array는 출발 전에 전력을 쓰고, pellet lane은 선박이 마실 수 있는 곳에 포획 질량을 놓고, fusion-electric throat는 연료를 전기와 열로 바꾸며, 차폐는 먼지 손실을 받고, 라디에이터는 수년 동안 폐열을 버리고, 제동 장비는 가속만큼 중요하다.

DRIVE STACK 절개 // Barnard Yards 서비스 플레이트: beam-sail yoke, pellet catcher, fusion-electric throat, shadow shield, radiator ribs, magsail spool, aerobrake skin, custody meter가 하나의 경로 번호를 공유.

ATLAS TRANSIT STACK // 출발 추진: 외부 beam array. 순항 공급: pellet lane 포획. 변환: fusion-electric throat. 손실 제어: 차폐 얼음, 탄소, 라디에이터 리브. 도착 권한: magsail spool, aerobrake skin, 수신 슬롯, custody ledger.

## Field Note
