# 공장-사원 문턱

공장-사원 문턱은 최종 공간 문법이다. Deep Reach, 식민지, Atlas-6, HECTON-8의 바다가 하나의 물리 시스템이 된다.

## Scanner

바닥 구조물은 기지가 아니다. 공장 선체, 사원 논리, 살아 있는 압력 조직이 하나의 하중 경로를 공유한다.

## Terminal

문턱 경고: 산업 트러스, 생체 봉합, xenon lattice 열, Atlas 라우팅이 구조 권한을 공유한다.

## Audio

바다는 공장을 묻지 않았다. 공장을 몸으로 만들었다.

## Field Note

여기서 지도는 식민지 폐허인 척을 멈춘다.
