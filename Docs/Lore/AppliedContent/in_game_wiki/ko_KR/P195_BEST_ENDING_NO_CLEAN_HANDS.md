# 최선 경로: 잔여를 보이게 남김

잔여를 보이게 남기는 것이 가장 강한 경로의 기준이다. 엔딩은 HECTON-8을 보상 화면으로 바꾸지 않고 구체적인 것을 구해야 한다. 공개 기록, 차단된 Deep Reach 경로, 보존된 분지, 해방된 운영자, 노동자 이름, Atlas proof hash 같은 것들이다. 기록은 수신자 보관권, 책임, 누락 이름, 분지 손상, Atlas 상태, 채무 잔여의 열린 필드도 유지해야 한다.

## Scanner

최선 경로 규칙 // 구체적 결과를 구한다. 운영자 보관권, 공개 기록, 거부된 페이로드, 살아 있는 분지, 노동자 이름 패킷, Atlas proof hash. 손상 필드는 열어 둔다.
