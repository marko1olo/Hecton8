# 근광속 선박 등급

근광속 선박은 물리를 깨지 않고 인간권을 만들었다. 잃어도 되는 탐사기가 먼저 왔고, 시드선과 공장, 수면자, 계약, 차폐를 실은 Atlas급 화물선이 뒤따랐다.

등급표는 소유와 구조를 분리한다. Aegir는 인간 법으로 청구되어도 몸을 실어 도달하기 어렵다.

## Scanner

수송 명세서에 니들프로브, 시드선, Atlas 화물선, 수면자 수송선, 시스템 텐더, 청구 풀 캐리어 기재.

## Terminal

수송 등급표 // FTL 항로 등록 없음. 모든 등급은 발사 인프라, 차폐 질량, 감속 계획, 경로 보관, 부채 권한 필요. 성간 소유권은 지역 구조 능력을 뜻하지 않음.

## Audio

배는 별을 건너도 침수된 방에는 쓸모없을 수 있다.

## Field Note

배는 자유가 아니다. 엔진 달린 일정표다.
