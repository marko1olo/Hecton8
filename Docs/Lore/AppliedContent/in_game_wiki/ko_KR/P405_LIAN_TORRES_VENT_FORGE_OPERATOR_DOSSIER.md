# 리안 토레스, 열수구 단조 작업자

리안 토레스는 HECTON-8의 열을 들고 다닐 만큼 작고 이름을 빚질 만큼 위험한 부품으로 바꾸는 열수구 단조를 운영했다. 그의 기록은 그을린 장갑, 주기 타이머, 폐기 트레이, 압력 유리 쿠폰, 배치 표식이 긁힌 밀봉 링으로 이루어진다. 가장 중요한 것은 트레이다. 깨진 부품은 다음 압력 경계가 버티는 법을 배우기 전까지는 폐기물이 아니었음을 증명한다. 토레스는 자원 설정을 노동 설정으로 바꾼다. salvage 분류는 여기서 화상, 지연, 라벨 붙은 실패, 갈라진 것의 증거를 남기려는 결정으로 시작한다.

## Scanner

기록: 리안 토레스. 열 장갑, 주기 타이머, 폐기 트레이가 같은 압력 유리 배치와 맞는다.

## Terminal

열수구 단조 V-9 / TORRES, LIAN: 폐기 트레이에는 갈라진 밀봉 링, 흐린 압력 유리, 표시된 과열 쿠폰 셋이 남아 있다. 배치 메모: 실패는 라벨이 남아 있을 때만 다음 밀봉을 가르친다.

## Audio

토레스는 나쁜 부품을 보관했다. 단조장에서 깨끗한 바닥은 누군가 교훈을 버렸다는 뜻이었다.

## Field Note

토레스는 열수구 단조 소품, 압력 유리 제조법, 폐기 밀봉 링, 실패한 부품의 역사를 보여야 하는 업그레이드 작업대 근처에서 사용한다.
