The source knows pitting makes the cutter less reliable on dirty targets. It does not define cutter mechanics. The article should tie tool care to target discipline.

### Codex

The tip still works if the target is honest. Pitting makes dirty cuts worse and shortens the margin on a tool that already has little spool to spare. The cutter should open access, not solve anger.

Clean the target before spending the edge.
