## Source Brief

The source knows the ceramic shard has insulation value and one safe edge for handling. It does not claim every shard is usable. The article should make salvage selective and careful.

Player use: supports first debris stock reading and caution near sharp wreckage.

Forbidden facts: no universal ceramic stock, no safe-handling guarantee, no armor crafting claim, no runtime readiness.

The shard came from heat-shield material, but breakage changed it. One edge is smooth enough to handle. The other is sharp enough to punish speed. It can become insulation stock if the player reads the edge before pocketing the lesson.
