## Source Brief

The source knows the collar can be reused only if the bite teeth are intact and the hinge is not cracked through. It does not claim cable systems are implemented. The article should teach inspection before reuse.

Player use: supports repair-stock restraint and cable safety language.

Forbidden facts: no cable-system proof, no universal reusable fastener, no full electrical safety, no runtime readiness.

## Surface Texts

### Scanner

CABLE COLLAR // Bite teeth intact, hinge salt-cracked. Reuse only on low-load line.

### Codex

The collar survived because it was cheap and stubborn. Its bite teeth still hold, but the hinge carries a salt crack. It can restrain a low-load line. It should not pretend to be new hardware.

Reuse starts with admitting what the part cannot do.
