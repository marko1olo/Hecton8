## Surface Texts

**Website article seed:**

A relation edge suppression reason is the scanner admitting that it saw a possible connection and refused to draw it. The reason may be low field confidence, source voice mismatch, claimant-safe hold, proof escalation, or a route alias conflict. That is different from no relation.

The scanner should name the visible cause and the safe next action. It should not draw a line that turns a cautious hint into a final relation. It should not silently erase the edge either.

**Wiki article seed:**

Relation edge suppression reason: a scanner/PDA graph state used when a possible relation is hidden. It should name visible cause, hidden relation class, confidence state, and safe next action. It must not reveal exact hidden relation or final outcome.

**PDA / codex entry:**

PDA graph note: relation edge suppressed. The scanner has a possible connection, but the field confidence, source voice, claimant hold, route alias, or proof escalation state blocks display. Follow the safe next action.

**Scanner entry:**

Scanner graph tag: relation edge suppressed. Visible cause available; exact relation held.

**Terminal note:**

Terminal suppression note: edge not drawn because showing it would outrun proof order. Compare the safe field before accepting relation.

**Evidence caption:**

Relation edge suppressed: possible connection held by proof boundary.

**Spoiler policy:**

Safe to show visible cause and safe next action. Hold exact hidden relation, final receiver, protected claimant, Atlas consequence, legal verdict, and rescue conclusion behind later proof gates.
