## Surface Texts

**Website article seed:**

A public archive review queue stamp tells the reader that an entry is visible but not settled. It can wait for source voice review, confidence ladder review, claimant-safe review, route alias review, or relation-edge review. The stamp keeps the page from looking broken and keeps the evidence from looking final.

The stamp is useful only when it names the safe next action. A plain waiting label is bureaucracy. A useful stamp tells the player what proof class is still pending without printing the hidden answer.

**Wiki article seed:**

Review queue stamp: a visible page or relation state used when evidence is present but not settled. It should name visible review state, held reason class, source voice, and safe next action. It must not expose final relation or final outcome.

**PDA / codex entry:**

PDA review stamp: entry queued. Read the visible review state and safe next action. The hidden reason class is held until proof order clears it.

**Scanner entry:**

Scanner queue tag: evidence visible, review pending. Safe action available.

**Terminal note:**

Terminal review note: this entry is queued by proof class. Do not treat queue state as final approval.

**Evidence caption:**

Review queue stamp: visible entry, pending proof class.

**Spoiler policy:**

Safe to show visible review state and safe next action. Hold exact relation, final receiver, protected claimant, Atlas consequence, legal verdict, and rescue conclusion behind later proof gates.
