## Surface Texts

**Website article seed:**

A PDA review prompt is not a conclusion. It appears when one evidence family has too many clean labels and too many damaged edges: an object mark that survived handling, a custody line that diverges from the public category, a scanner downgrade, a terminal receipt rewritten after the packet moved, a relation edge to another record, or a claimant-safe phrase that removes a name without removing the wound.

Public archive editors treat the prompt as a hold. Marauder notes treat it as a warning. The PDA can ask the reader to review the family, but it cannot name the final receiver or decide who the language protected. The object still has to be read first.

**Wiki article seed:**

PDA evidence-family review prompt: a neutral prompt shown when related records carry unresolved conflict. Common triggers include object mark, custody divergence, scanner downgrade, terminal receipt rewrite, relation edge, and claimant-safe language. The prompt asks for review only. It is not a verdict, source admission, final receiver label, protected-claimant label, route branch, or legal result.

**PDA / codex entry:**

Evidence family needs review. Object mark, custody divergence, scanner downgrade, receipt rewrite, relation edge, and claimant-safe wording are present in the same family. Keep all records open. No conclusion recorded.

**Scanner entry:**

Evidence-family review suggested. Scanner confidence downgraded by custody divergence and rewritten terminal receipt. Relation edge active. Required next evidence: object mark, witness hash, or original receipt body.

**Terminal note:**

Action: ask for review. Do not write conclusion.

**Evidence caption:**
