## Surface Texts

**Website article seed:**

A dispute reason code is not a verdict. It is the public archive's way of saying why a clean label cannot carry the evidence alone. HECTON-8 packets use reason codes when the object mark conflicts with a category, when custody splits between offices, when a witness hash repeats in the wrong place, when a terminal receipt has been rewritten, or when a legal hold hides the route that the body of the file still remembers.

The code matters because vague suspicion is useless to a reader. A packet marked "disputed" without a reason only teaches distrust. A packet marked "receipt rewrite" tells the reader to compare header and body. A packet marked "custody divergence" tells the reader to separate object custody from office custody. A packet marked "witness mismatch" tells the reader to find the second hash before believing the first.

**Wiki article seed:**

Dispute reason code: a short archive label attached to an evidence packet when confidence is reduced by a specific conflict. Common reason families include object-label conflict, custody divergence, witness mismatch, receipt rewrite, route alias conflict, claimant-safe omission, quarantine/legal double hold, and spoiler-held relation. Reason codes point to the next proof target; they do not resolve the route.

**PDA / codex entry:**

PDA prompt: read the reason, not just the word "disputed." If the code says custody divergence, split object custody from office custody. If it says receipt rewrite, keep the old body fields. If it says witness mismatch, look for the second hash. A dispute code is a route instruction, not a conclusion.

**Scanner entry:**

Dispute reason code detected. Confidence lowered by named evidence conflict. Required next proof: object mark, custody sequence, witness hash, receipt body, or route alias.

**Terminal note:**

PUBLIC ARCHIVE DISPUTE CODE

Dispute is not enough.

Reason required.

Record code, affected field, missing proof, and next target.

Do not replace a missing proof with a cleaner label.

**Evidence caption:**

Dispute-reason card. The archive names why confidence dropped so the reader can test the next proof instead of treating disagreement as a verdict.

**Spoiler policy:**

Dispute reason codes may appear early. Exact route branch, final receiver, protected claimant, Atlas consequence, rewrite authority, and legal result stay masked until later proof gates.

**String-pool key plan:**
