## Surface Texts

**Website article seed:**

A PDA evidence link audit trail records when a relation link changes state. A link can become visible, partial, locked, downgraded, or suppressed. The trail names the visible cause: source voice match, confidence change, receipt-body support, route alias conflict, claimant-safe hold, or proof escalation.

The audit trail is not a confession log. It does not print the exact hidden relation. It tells the player that proof order changed the graph and gives one safe next action.

**Wiki article seed:**

Evidence link audit trail: a record of relation-link state changes. It should name previous state, new state, visible cause, held relation class, and safe next action. It must not reveal exact hidden relation or final outcome.

**PDA / codex entry:**

PDA link audit: evidence link changed state. Read previous state, new state, visible cause, and safe next action. The exact hidden relation remains protected.

**Scanner entry:**

Scanner link audit tag: relation link state changed. Visible cause available; exact relation held.

**Terminal note:**

Terminal audit note: link state changed by proof order. Do not infer final relation from the state change alone.

**Evidence caption:**

Link audit trail: relation state changed, hidden relation protected.

**Spoiler policy:**

Safe to show previous state, new state, visible cause, and safe next action. Hold exact hidden relation, final receiver, protected claimant, Atlas consequence, legal verdict, and rescue conclusion behind later proof gates.
