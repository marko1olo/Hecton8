## Surface Texts

**Terminal audit**

PACKET NOTARY INTERFACE / CLAIMANT LANGUAGE AUDIT

Article: TERMINAL_CLAIMANT_LANGUAGE_AUDIT_BRIDGE

Loc namespace: LORE_EVIDENCE_TERMINAL_CLAIMANT_LANGUAGE_AUDIT_BRIDGE

Claimant desk: Deep Reach Recovery Compliance Office, contested.

Audit trigger: worker testimony or physical evidence has been converted into a procedure category.

Native localization hold: active. Source line, claimant clause, and Marauder correction must remain separate until language review and layout proof can test meaning.

Relation-graph stub: source witness line -> physical object -> claimant clause -> consequence category.

Observed conversion:

- "pump room queue still occupied" becomes "release timing variance."
- "triage door held shut" becomes "quarantine review gate."
- "unrecovered worker mass" becomes "Keelmark payout exposure."
- "return without full payload" becomes "partial return eligibility."

Instruction: do not collapse worker testimony into claimant category labels. Preserve the source line, witness hash, LocID, object carrier, and claimant clause before any archive summary is written.

**Codex audit**

Deep Reach claimant language does not need to delete a witness. It can keep the witness and change the shelf they are filed on.

When a terminal turns a worker into a quarantine hold, a payout exposure, or a partial-return class, read the relation first. Who spoke? What object carried the line? Who held the packet? Which clause softened it? Was the translation still on native hold? A clean category may be useful for sorting evidence, but it is not the evidence itself.

This audit marks language that tries to make physical proof behave like procedure. The claimant category stays visible because it can prove the lie. The worker line stays visible because it proves what the category tried to survive.

**Public archive caution**

Some HECTON-8 records arrive with claimant wording already attached. The archive may show those words, but it must not treat them as neutral labels.

Quarantine, payout, partial return, and recovery action are not only administrative categories. In Deep Reach files they can be replacement language for people, doors, bodies, tools, route clocks, and pressure evidence. Read the custody strip and the witness line before reading the summary. If the native localization hold is still present, the claimant clause is even easier to polish into something it did not earn.

**Marauder annotation**

Categories are how they make a dead worker quiet without losing the invoice.

If Keelmark says payout, ask what got priced. If Recovery Compliance says partial return, ask what they wanted left behind. If the quarantine line sounds careful, find the door it kept closed.

Do not clean the sentence. Pin it to the worker line and let both stay ugly.
