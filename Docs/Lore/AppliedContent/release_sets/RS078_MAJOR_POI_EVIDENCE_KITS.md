# Major POI Evidence Kits

Status: production-facing AppliedLore source.
Runtime rule: source/export only; runtime consumes baked static data and string-pool offsets.

Define reusable major POI kits so first-hour, mid-depth, abyssal and final evidence can be placed as physical objects instead of exposition.

## Packets

- `P386_SHALLOW_ANNEX_P63_POI_KIT` - Shallow Annex P-63 POI Kit: P-63 is the first safe module: pump, seal, cut, ping and a controlled Deep Reach contradiction.
- `P387_CABLE_REEF_RELAY_YARD_POI_KIT` - Cable Reef Relay Yard POI Kit: The cable reef is where living repair and broken relay hardware first become the same route problem.
- `P388_BRINE_CANYON_PUMP_CATHEDRAL_POI_KIT` - Brine Canyon Pump Cathedral POI Kit: The pump cathedral is where density geology, evacuation delay and Great Tide proof intersect.
- `P389_EVACUATION_QUEUE_TERMINAL_POI_KIT` - Evacuation Queue Terminal POI Kit: Evacuation proof is strongest when it is a queue, a door, a clock and a failed route.
- `P390_ATLAS_SERVICE_BASIN_POI_KIT` - Atlas Service Basin POI Kit: The Atlas service basin is a final-depth room that looks like maintenance and worship only because the same function survived both.
