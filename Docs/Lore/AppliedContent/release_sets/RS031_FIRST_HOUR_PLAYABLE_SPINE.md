# RS031_FIRST_HOUR_PLAYABLE_SPINE

Status: production-facing draft, pending native localization pass.
Runtime contract: authoring source only; runtime must consume baked static data/string-pool rows.

Purpose: locks first-hour playable beats from contract approach through drop damage, first safe module, first lie and first Atlas repair trace.

## Packets

- `P151_BLACK_KEEL_CONTRACT_APPROACH` - Black Keel Contract Approach: Black Keel Contract Approach defines the first playable pressure: contract before catastrophe.
- `P152_DROP_CAPSULE_DAMAGE_SEQUENCE` - Drop Capsule Damage Sequence: Drop Capsule Damage Sequence makes stranding visible and repairable.
- `P153_SHALLOW_ANNEX_P63_PUMP_ROOM` - Shallow Annex P-63 Pump Room: Shallow Annex P-63 Pump Room is the first-hour survival tutorial without turning into a tutorial room.
- `P154_FIRST_SANITIZED_ACCIDENT_PACKET` - First Sanitized Accident Packet: First Sanitized Accident Packet defines the game's evidence-before-exposition rule.
- `P155_FIRST_ATLAS_REPAIR_TRACE` - First Atlas Repair Trace: First Atlas Repair Trace introduces biomechanical horror before the player reaches real darkness.
