# HECTON-8 Geology Resource Fieldguide

Status: production-facing AppliedLore source.
Runtime rule: source/export only; runtime consumes baked static data and string-pool offsets.

Convert HECTON-8 geology and resource logic into usable fieldguide packets for scanner, codex, site articles and future table handoff.

## Packets

- `P351_DROWNED_CRUST_STRATA_GUIDE` - Drowned Crust Strata Guide: Procedural geology varies local routes while preserving fixed strata and pressure rules.
- `P352_BRINE_CANYON_DENSITY_LADDER_GUIDE` - Brine Canyon Density Ladder Guide: Depth progression is a density and pressure ladder, not a generic level gate.
- `P353_VENT_FORGE_FIELD_PROCESS_GUIDE` - Vent Forge Field Process Guide: Resource identity follows process history, so procedural variation can stay scientifically legible.
- `P354_BLUE_DEBT_PRESSURE_HISTORY_GUIDE` - Blue Debt Pressure History Guide: Blue debt is valuable pressure-stable substrate for extreme computation and energy isolation, not magic ore.
- `P355_PRESSURE_GLASS_AND_SEALANT_GUIDE` - Pressure Glass and Sealant Guide: Atlas repair growth follows existing fracture, mineral and pressure-memory routes rather than mystical intent.
