# Carrier Contract Ownership Surfaces

Status: production-facing AppliedLore source.
Runtime rule: source/export only; runtime consumes baked static data and string-pool offsets.

Lock Black Keel as a claim-pool salvage carrier with masked beneficiary pressure, limited autonomy, orbital recovery windows and player lien start copy.

## Packets

- `P321_BLACK_KEEL_CLAIM_POOL_CHARTER` - Black Keel Claim-Pool Charter: Black Keel is a rented claim-pool recovery asset, not a personal ship or loyal companion.
- `P322_MASKED_DEEP_REACH_BENEFICIARY_CLAUSE` - Masked Deep Reach Beneficiary Clause: Deep Reach does not own the player openly, but it holds priority hooks through proxy contract layers.
- `P323_ORBITAL_RECOVERY_WINDOW_PROTOCOL` - Orbital Recovery Window Protocol: Escape requires weather, Aegir magnetic windows, carrier geometry and a repaired ascent route.
- `P324_SALVAGE_CARRIER_AUTONOMY_LIMITS` - Salvage Carrier Autonomy Limits: Black Keel can process claims and recovery, but it cannot improvise a full rescue under HECTON-8 pressure.
- `P325_PLAYER_LIEN_CONTRACT_START_CARD` - Player Lien Contract Start Card: The player starts as an ex-Deep-Reach professional under salvage debt, not as a tourist or chosen hero.
