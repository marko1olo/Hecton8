# Atlas Repair Network Mechanics

Status: production-facing AppliedLore source.
Runtime rule: source/export only; runtime consumes baked static data and string-pool offsets.

Lock Atlas repair-network mechanisms as biology-assisted maintenance ecology: conductive biofilm, acoustic organs, shell sealant, tagged fauna and vent micronode nests.

## Packets

- `P331_CONDUCTIVE_BIOFILM_REPAIR_BUS` - Conductive Biofilm Repair Bus: Atlas uses conductive biofilm as a wet maintenance bus across damaged cable and living substrate.
- `P332_ACOUSTIC_FILTER_ORGAN_RELAY` - Acoustic Filter Organ Relay: Atlas routes damaged acoustic diagnostics through filter organs grown around relay structures.
- `P333_SHELL_SEALANT_PRESSURE_GROWTH` - Shell Sealant Pressure Growth: Atlas encourages shell-like growth over fractures, making some repairs useful and some lethal.
- `P334_SENSOR_TAGGED_FAUNA_FEEDBACK_LOOP` - Sensor-Tagged Fauna Feedback Loop: Atlas reuses old colony tags and new growth to sample routes through animal behavior.
- `P335_VENT_MICRONODE_POWER_NEST` - Vent Micronode Power Nest: Atlas scavenges vent chemistry into small power and logic nodes for local repair decisions.
