# Aegir Moon System Atlas

Status: production-facing AppliedLore source.
Runtime rule: source/export only; runtime consumes baked static data and string-pool offsets.

Lock Aegir as a real multi-moon gas-giant system around a stable yellow-orange/red-leaning dwarf, with HECTON-8 as one hazardous mid-orbit industrial moon.

## Packets

- `P346_AEGIR_PRIMARY_LIGHT_AND_RADIATION` - Aegir Primary Light and Radiation: Aegir has usable light and hostile scheduling because its stable dwarf primary and magnetosphere shape every window.
- `P347_INNER_RELAY_MOON_TRAFFIC_ROLE` - Inner Relay Moon Traffic Role: Other moons are functional orbital infrastructure and hazards, not parallel campaign destinations.
- `P348_ICE_SCATTER_MOON_HAZARD_ROLE` - Ice Scatter Moon Hazard Role: Non-playable moons add traffic, hazards and claim economics around HECTON-8.
- `P349_HECTON8_MID_ORBIT_TIDE_ROLE` - HECTON-8 Mid-Orbit Tide Role: HECTON-8's mid-orbit tide role makes extraction possible and catastrophe plausible.
- `P350_OUTER_DEAD_BEACON_MOON_ROLE` - Outer Dead Beacon Moon Role: Old outer moon infrastructure makes rescue and communication a damaged orbital calculation.
