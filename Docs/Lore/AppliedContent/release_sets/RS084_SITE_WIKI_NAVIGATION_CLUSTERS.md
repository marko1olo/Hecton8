# Site Wiki Navigation Clusters

Status: production-facing AppliedLore source.
Runtime rule: source/export only; runtime consumes baked static data and string-pool offsets.

Add navigation clusters for public wiki/site and in-game codex grouping so the content base can be published without becoming an unordered packet dump.

## Packets

- `P416_SITE_WIKI_START_HERE_CLUSTER` - Site Wiki Start Here Cluster: The public start-here cluster frames HECTON-8 as salvage contract, professional guilt and hard constraints without spoiling final receivers.
- `P417_SITE_WIKI_SYSTEM_AND_SHIPS_CLUSTER` - Site Wiki System And Ships Cluster: The system/ships cluster groups no-FTL, Aegir route, carrier custody and drop-capsule constraints into one readable navigation lane.
- `P418_SITE_WIKI_COLONY_AND_WORKERS_CLUSTER` - Site Wiki Colony And Workers Cluster: The colony/workers cluster makes people legible through jobs and evidence, not relatives of the protagonist.
- `P419_SITE_WIKI_RESOURCES_AND_ECOLOGY_CLUSTER` - Site Wiki Resources And Ecology Cluster: The resource/ecology cluster connects geology, blue debt, native life and Atlas repair misuse as process chains.
- `P420_SITE_WIKI_ENDINGS_SPOILER_CLUSTER` - Site Wiki Endings Spoiler Cluster: The endings cluster must be spoiler-gated and organized by receiver/custody consequences, not good/bad moral labels.
