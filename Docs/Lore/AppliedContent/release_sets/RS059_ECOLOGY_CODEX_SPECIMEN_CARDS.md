# Ecology Codex Specimen Cards

Status: production-facing AppliedLore source.
Runtime rule: source/export only; runtime consumes baked static data and string-pool offsets.

Lock concrete scanner/codex cards for native ecology and Atlas-touched repair organisms.

## Packets

- `P291_PHOTIC_MAT_CODEX_CARD` - Photic Mat Codex Card: Photic mats make oxygen, color and food, but they also reveal how quickly pressure ecology turns route safety into a local condition.
- `P292_GLASS_GRAZER_CODEX_CARD` - Glass Grazer Codex Card: Glass grazers are not threats; their sudden silence, schooling direction and bite marks teach predator telegraph and route risk.
- `P293_LANTERN_DRIFT_CODEX_CARD` - Lantern Drift Codex Card: Lantern drifts can mark oxygen and food, but storm charge and industrial residue make them false beacons.
- `P294_BRINE_VANE_CODEX_CARD` - Brine Vane Codex Card: Brine vanes grow where density shear is stable; reading them lets the player infer survivable canyon steps.
- `P295_SENSOR_TAGGED_FAUNA_CODEX_CARD` - Sensor Tagged Fauna Codex Card: Atlas-tagged fauna are still animals, but old sensor tags, biofilm and route impulses make them maintenance carriers.
