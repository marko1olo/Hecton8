# RS002 - Deepening Descent Release Set

Status: production-facing draft.
Purpose: second bundled content set for midgame/deep descent, covering route salvage, brine/thermal traversal, evacuation truth, Atlas bottom, and final payload structure.

## Included Content

- P006 Dead Claim Cache.
- P007 Brine Stair.
- P008 Evacuation Hold.
- P009 Bottom Factory.
- P010 Payload Window.

## Player-Facing Arc

1. The player finds evidence of other Marauders and learns HECTON-8 has a shadow salvage history.
2. The moon's geology becomes traversal: brine, heat, ballast, pressure chemistry.
3. The abyss reveals that the colony was not simply lost; people were held, routed, delayed, and misclassified.
4. The Atlas bottom zone proves the final place is not a base, but the fused result of Deep Reach, Atlas, colony, and ocean.
5. Endings become physical payload decisions: what leaves HECTON-8, what burns, what stays buried.

## Deliverables In This Set

- Structured multilingual packet bundle.
- In-game wiki articles in EN/RU.
- External site articles in EN/RU.
- Image/art briefs.
- Release manifest.

## Runtime Boundary

This is authoring/export content. The game consumes baked IDs, localized string pools, flags, offsets, and packet tables. Runtime must not parse these markdown files.
