Status: production-facing draft.
Purpose: third bundled content set for the broader hard-sci-fi world: human domains, relay infrastructure, nearlight ships, Aegir route windows, and Black Keel ledger logic.

## Player-Facing Arc

1. The player sees that HECTON-8 belongs to a larger human world, but that world is slow and far away.
2. Tool marks, route codes, and safety standards explain human domains through objects instead of lectures.
3. No-FTL ships become economic infrastructure, not personal freedom.
4. Aegir orbital geometry becomes gameplay pressure: windows, tides, storms, signal quality, and ascent timing.
5. Black Keel is framed as claim-pool machinery with hidden Deep Reach priority hooks, not a warm rescue ship.

This is authoring/export content. Runtime should consume baked packet IDs, localized string pool offsets, unlock flags, route-window IDs, and asset references. Runtime must not parse these markdown files.
