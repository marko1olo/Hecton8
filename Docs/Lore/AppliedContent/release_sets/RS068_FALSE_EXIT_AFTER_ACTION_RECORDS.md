# False Exit After-Action Records

Status: production-facing AppliedLore source.
Runtime rule: source/export only; runtime consumes baked static data and string-pool offsets.

Lock false and partial exits as real records with material, lien, quarantine, coordinate-capture and public-ledger consequences.

## Packets

- `P336_MATERIAL_EXIT_RECEIPT_AUDIT` - Material Exit Receipt Audit: Material success can be true while story truth fails.
- `P337_PARTIAL_RETURN_LIEN_EXTENSION` - Partial Return Lien Extension: Partial exit can return to the same seed with knowledge pressure and deeper debt, not power inheritance.
- `P338_QUARANTINE_HOLD_INTERROGATION_RECORD` - Quarantine Hold Interrogation Record: A biological rescue can still be a custody failure.
- `P339_CORPORATE_COORDINATE_CAPTURE_RECORD` - Corporate Coordinate Capture Record: Selling coordinates can restore Deep Reach access even when the player survives.
- `P340_PUBLIC_LEDGER_AFTERSHOCK_RECORD` - Public Ledger Aftershock Record: Publishing truth prevents clean erasure but removes player control over consequences.
