# RS028_REPLAY_CONTRACT_DOSSIER_RULES

Status: production-facing draft, pending native localization pass.
Runtime contract: authoring source only; runtime must consume baked static data/string-pool rows.

Purpose: locks replay persistence as knowledge, rumor families, riskier contract seeds, four false-ending families and starting claim variants without power carryover.

## Packets

- `P136_DOSSIER_RUMOR_UNLOCKS` - Dossier Rumor Unlocks: Dossier Rumor Unlocks define replay memory as narrative intelligence instead of roguelite strength.
- `P137_RISKIER_CONTRACT_SEEDS` - Riskier Contract Seeds: Riskier Contract Seeds make replayability economic and procedural: the contract changes the ocean's demands.
- `P138_FALSE_ENDING_COUNT_LADDER` - False Ending Count Ladder: False Ending Count Ladder controls scope: many exits, few clear families, and deep Atlas endings as the campaign's gravity center.
- `P139_STARTING_CLAIM_VARIANTS` - Starting Claim Variants: Starting Claim Variants let HECTON-8 replay with different economic hooks while preserving one strong protagonist.
- `P140_DOSSIER_KNOWLEDGE_NOT_POWER` - Dossier Knowledge Not Power: Dossier Knowledge Not Power is the replayability rule that keeps HECTON-8 long-form and dangerous.
