# RS087_PDA_CODEX_PRESENTATION_RULES

Status: production-facing draft pending native localization.
Runtime contract: runtime reads baked DataMonolith/string-pool records, not these JSON/Markdown files.

- `P431_PDA_EVIDENCE_TIER_LABEL_RULE` - PDA Evidence Tier Label Rule: PDA labels must describe proof/custody state without moralizing endings.
- `P432_SCANNER_STAGE_COPY_ESCALATION_RULE` - Scanner Stage Copy Escalation Rule: Scanner copy escalates by evidence stage, not by arbitrary horror tone.
- `P433_TERMINAL_OPERATOR_SURFACE_RULE` - Terminal Operator Surface Rule: Terminals should expose systems and people through operational language.
- `P434_DOSSIER_ENDING_RECORD_LAYOUT_RULE` - Dossier Ending Record Layout Rule: Ending records are custody/consequence layouts, not moral verdict screens.
- `P435_LOCALIZED_OVERFLOW_PRESENTATION_RULE` - Localized Overflow Presentation Rule: Localization may change layout but not packet identity, units or evidence authority.
