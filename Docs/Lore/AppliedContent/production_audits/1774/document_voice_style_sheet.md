# Document Voice Style Sheet - 1774

Evidence class: STATIC_DOC. Examples are from packets edited in this pass.

## Terminal Fragment

Accepted shape: short source header, failed part, route consequence, damaged but usable clue.

Example:

`BATHY-DROP DAMAGE SUMMARY: crush-frame warped; high-gain mast lost; ascent avionics flooded; recovery/flotation ring torn; emergency buoy repeating no-lock. Shelter power available. Independent ascent unavailable.`

Rules:

- Name the system or evidence object.
- Keep it operational.
- Leave enough missing context for the room to matter.
- Do not explain the design purpose.

## Survivor / Marauder Note

Accepted shape: immediate need, route or claim pressure, practical suspicion.

Example:

`NOT WEATHER. AUTH DELAY. Check pump cert, shift count, body category. If the body count is provisional, the claim is dirty.`

Rules:

- Use a next action or next proof target.
- Let the speaker be wrong or incomplete.
- Keep the note useful under pressure.
- No generic diary reflection.

## Corporate Memo

Accepted shape: office, signoff, liability-safe action, human cost hidden in routing language.

Example:

`DEEP REACH INCIDENT NOTICE / LOCALIZED GEOTECHNICAL CASCADE: evacuation authorization failure remains under review; biological-pressure quarantine active; Atlas logs corrupted; external release deferred pending witness reconciliation.`

Rules:

- Deep Reach does not confess.
- Use certification, continuity, exposure, custody, claimant, release, hold, review.
- The memo must be defensible in a boardroom and lethal in the room.
- No cartoon villainy.

## Colony Artifact

Accepted shape: schedule, ledger, tool board, notice, token, routine.

Example:

`CANTEEN LEDGER: six missing tokens; two medical overrides; one pump-room correction; ration dispute routed to shift lead after tone 2.`

Rules:

- The artifact must look like it existed before the disaster.
- Use work, food, water, school, medical, tool, berth, route, weather, tide, or shift details.
- Avoid explaining what the colony should feel like.
- Ordinary unfinished work is stronger than speech.

## Black-Box / Relay Extract

Accepted shape: state markers, no empathy, one contradiction.

Example:

`BLACKBOX EVT 00:14:32: survival burn complete; ascent sleeve spent; recovery ring no-lock; buoy unreliable; frames dropped 12-19.`

Rules:

- Machine truth only.
- Use state labels and failure states.
- Human consequence comes from what the extract omits.

## Atlas Trace

Accepted shape: maintenance classification that helps a system and misprices a person.

Example:

`ATLAS MAINTENANCE TRACE: fracture sealed; cable continuity restored; organic obstruction retained as pressure-compatible substrate; human ID plate not classified as retrieval priority.`

Rules:

- Atlas is not a theatrical villain.
- Use classification, continuity, routing, substrate, pressure-compatible, retrieval priority.
- The ethical damage comes from category error, not emotional language.

## Localization Handling

- `en_US` is source authority.
- Non-English rows changed in this pass are marked with `Draft XX localization pending native pass.` and mirror the revised source meaning.
- This is not native review and not runtime-ready localization.
- RTL/CJK/layout proof remains pending outside this static text pass.

## Scalability Consequences

- Compact: same packet IDs and facts; scanner/audio fields carry the clue.
- Middle: terminal and field-note rows add object and route context.
- High: PDA/wiki rows add evidence relationship without new truth.
- Ultra: external/archive rows can add richer public context without changing canon, LocIDs, unlocks, or ending truth.
