# Audio / Black-Box Style Sheet - 1775

Evidence class: STATIC_DOC.

## Accepted Patterns

| Family | Accepted pattern | Rejected pattern |
|---|---|---|
| Distress | One urgent operation, one object, one route or body fact. | Perfect last words, theme speech, generic panic. |
| Corporate call | Clean prerequisite language, pricing/custody/coordinate gates, defensible omission. | Villain confession, cartoon threat, full liability chain too early. |
| Black box | Timestamp, system ID, confidence, dropped frames, hardware state, contradiction. | Poetic lore, human emotion, unexplained static. |
| Atlas fragment | Maintenance telemetry, category collapse, repair words, serviceability contradiction. | God voice, emotional villain line, magical ocean agency. |
| Survivor / worker whisper | Job title, task, fatigue, route cue, small wrong assumption. | Family melodrama, omniscient summary, prophecy. |
| Field-team chatter | Tool order, pressure state, gauge doubt, named route or part. | Tutorial wording, designer instruction, trailer tagline. |

## Source Rules

- Black Keel speaks in accounting, mass, orbit and conditional windows.
- Deep Reach speaks in safety language that routes to cost, custody or coordinates.
- Workers speak from task pressure, not lore awareness.
- Atlas speaks as a damaged maintenance system, not a person.
- Black boxes do not explain; they expose event state.
- Relay/custody fragments can contradict themselves formally: accepted extraction, denied release.

## Interruption Rules

- Interruption must carry information: lag, dropped frames, packet loss, alarm priority, confidence loss, route blackout, custody hold.
- Decorative `static` is rejected.
- Redaction can hide a name or receiver, not the player-useful alarm.

## Subtitle Rules

- Split source label, event state, and clue into separate beats.
- Keep one breath per beat when possible.
- Preserve numbers and custody terms exactly until native localization rewrites them.
- `ar_SA` and `he_IL` need RTL numeric/Latin-ID QA.
- CJK and Germanic rows need line-break and expansion proof.

## GlobalQualityWeight Consequences

- Low: one clean source line plus critical subtitle beats; no optional archive layer.
- Middle: source line plus terminal reconstruction.
- High: richer interruption/damage layer and source metadata.
- Ultra: optional dossier/archive contradiction, never a different canon truth.
