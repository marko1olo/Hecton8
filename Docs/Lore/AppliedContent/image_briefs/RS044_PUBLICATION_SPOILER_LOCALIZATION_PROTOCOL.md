# Publication Spoiler Localization Protocol Image Briefs

Status: art-direction source for site/wiki/codex cards.

Do not render as decorative generic sci-fi. Every image must expose a route, tool, ledger, pressure state or evidence object.

## P216_PUBLIC_SITE_ARTICLE_TIER_RULES - Public Site Article Tier Rules

- Primary evidence objects: poi.public_article_tier_card, poi.site_spoiler_gate, poi.pr_copy_lock.
- Composition: close industrial evidence, readable label/stamp/tool wear, pressure damage, no clean showroom sci-fi.
- Low tier: static card / scan still.
- Middle tier: diegetic light state, wet glass, shallow parallax and stable text crop.
- High/Ultra: animated condensation, route overlay, instrument noise and subtle physical response without changing lore truth.
