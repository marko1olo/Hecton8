# RS010 Image Brief - Pressure Machinery / Return Route

Status: art-facing brief for future screenshot/key-image production.

Goal: every image should show a machine, the pressure consequence, and a route decision.

Frames:
- Pump room: player-facing valve panel, dirty intake grate, waterline, return corridor pressure warning.
- Hatch seal: warped wheel, gasket ledger screen, stains showing which side stayed wet.
- Cable splice: wet junction box, clean-but-wrong Atlas repair geometry, old human cable tags.
- Sonar route: beacon ping graph, blocked mapped corridor, route-home line bending around new obstruction.
- Tool custody: salvage cutter dock, sample trace, claim-token reader, black-box style receipt UI.

Rules:
- No hero ocean vista.
- No clean sci-fi hallway.
- No UI-only explanation.
- The route back must look physically worse after the useful action.
