# RS009 - Colony Layout / Worker Evidence

Status: production-facing art brief.

Purpose: visual references for the drowned worker colony layer.

Packets:
- P041_WORKER_LOCKER_ROW: flooded locker corridor, cheap paint, tagged tools, meal tabs, Barnard scratch marks. Human texture first, no horror pose.
- P042_PRESSURE_BUNK_ROUTINE: stacked pressure bunks, condensation drains, oxygen ration cards, clean green checklist lights in a dead room.
- P043_SHIFT_BOARD_ROUTE_HOLDS: shift board or tram dispatch wall with route hold language, queue states, not panic.
- P044_MEDICAL_LOCK_DELAY: sealed medical airlock with sterile stock visible behind pressure glass and red authorization denial.
- P045_BLACK_BOX_NAME_STACK: compact rugged archive stack, name strips, pressure-state telemetry, payload case for ending broadcast.

Visual constraints:
- The colony must feel worked in, not theatrical.
- Avoid corpse-focus. Horror comes from functioning procedures and missing people.
- Use ordinary objects as evidence: lockers, bunks, boards, doors, labels, tool marks.
- Keep Deep Reach language procedural and deniable.
