# Петля зворотного зв'язку сенсорно-міченої фауни

Сенсорно-мічена фауна не є керованими солдатами. Ця різниця важлива. Програми тегування Deep Reach починалися як звичайна польова наука й логістика: відстежити міграцію, стійкість до тиску, зараження й щільність маршрутів. Через роки теги вже не чисте обладнання. Мушля обростає їх, рубцева тканина зміщує, мінеральні ковпаки змінюють сигнал.

Atlas усе ще читає повернення. Поранена травоїдна тварина, що переходить затоплений місток, може виглядати як зйомка тиску. Хижак зі старим тегом може зробити коридор схожим на зайнятий інфраструктурним ризиком. Тварина лишається собою, але система навколо трактує рух як дані. Тому зустрічі з фауною мають друге лезо: поведінка виживання може бути також ремонтним зворотним зв'язком.
