# Збірка ланцюга втечі

Збірка ланцюга втечі - інженерний хребет кампанії. HECTON-8 не дає чистого витягнення на поверхню після першого ремонту; відхід стає набором фізичних, юридичних і доказових компонентів, розкиданих затопленою інфраструктурою. Це дає довгому спуску практичну й моральну причину: вихід треба зібрати з частин тієї самої колонії, якій відмовили в чесному виході.
