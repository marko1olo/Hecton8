# Вентиляційне мікровузлове силове гніздо

Вентиляційні мікровузлові силові гнізда — повільне серцебиття глибокої ремонтної мережі. Біля джерел океан дає теплові градієнти, мінеральний потік, вібрацію тиску й хімічний дисбаланс. Deep Reach використовувала ці градієнти для приладів і аварійного заряду. Atlas зберіг звичку після відмови чистої мережі.

Мікровузол не робить Atlas всевидющим. Ця межа важлива. Він може поштовхнути імпульс у близьку плівку, затвердити шар герметика, крапельно зарядити гніздо дронів або зберегти локальний запис рішення в пошкодженому субстраті. Тисячі таких вузлів роблять безодню організованою, але не безпечною. На дні гравець не б'ється з богом. Він рухається містом малих ремонтів, які забули, для чого були люди.
