# Досьє графа зв'язків доказів

## Що доводить запис

Шар зв'язків створено для втомлених розслідувачів і наляканих збирачів, а не для суддів. Він кладе на один стіл записи зі спільним вихідним об'єктом, маршрутною пластиною, фразою претензії, хешем свідка, родиною підпису, слідом травми, станом редагування або видимим наслідком. Під тиском стають видимими закономірності. Так само легко виникає хибна певність.

Збіг хешу не доводить правду свідка. Збіг підпису не доводить відновлення джерела. Спільний стан редагування може означати тільки, що один службовець різав два файли одним шаблоном. Шар корисний, бо показує, куди спрямувати увагу: зберігання пакета, вихідний об'єкт, мова претензії, хеш свідка, маршрутний наслідок, причина редагування і порядок підписів. Він стає небезпечним, коли лінію читають як вирок.

## Як це читати

ЛЕГЕНДА ГРАФА
Зелене: збіг вихідного об'єкта або маршрутної пластини.
Бурштинове: збіг фрази претензії або родини підпису.
Червоне: збіг хешу свідка, сліду травми або наслідку придушення.
Сіре: лише спільний стан редагування.
Кожне ребро звіряти з ланцюгом зберігання. Гарний граф усе ще може бути брехнею із рівними лініями.

## Польова примітка

Не дозволяй чистому графу думати за тебе. Лінії дешеві. Підпис і стан редагування - місця, де брехня стає достатньо дешевою для відправки.
