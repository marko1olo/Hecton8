# Картка кодексу: фауна із сенсорною міткою

Фауна із сенсорними мітками показує Atlas у найпроцедурнішому вигляді. Жах не в контролі розуму; жах у тому, що старе моніторингове залізо стало історією тіла, а пошкоджена maintenance logic прийняла це тіло за частину карти.

## Scanner

Фауна із сенсорною міткою. Старий біометалевий tag Deep Reach у шрамі, панцирі чи кільці росту. Слабке ехо маршруту Atlas; намір тварини не підтверджено.

## Terminal

ЗРАЗОК / ФАУНА ІЗ СЕНСОРНОЮ МІТКОЮ / роль: живий носій telemetry, застарілий survey landmark, забруднювач repair-route / безпечне читання: старий імпульс tag, ріст рубцевої тканини, рух без команди / відмова: трактувати поведінку як послух, вирізати tag із живого тіла, довіряти occupancy echo / примітка маршруту: tag може повідомити кімнату, через яку пройшла тварина, але не причину проходу.

## Audio

Вона не підкоряється Atlas. Вона несе старе питання, яке Atlas досі ставить.

## Field Note

Мітка — шрам, не повідець. Вона може видати тебе, поставити не туди або розбудити те, що тварини навіть не бачило.
