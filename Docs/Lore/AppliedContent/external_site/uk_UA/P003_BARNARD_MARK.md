# Мітка Barnard

Barnard Yards — не шляхетна батьківщина. Це робочий шрам: розбір кораблів, орендовані різаки, притискні хомути, інструмент третього власника й люди, які точно знають ціну поганого контракту. Перший штамп Barnard на HECTON-8 має здаватися майже замалим для лору. Це не промова. Це мітка на ключі, неправильний сплав на петлі шафки, ремонтна звичка, яку Deep Reach ніколи б не прописала. Для гравця ця деталь змінює контракт. HECTON-8 вже не просто мертвий корпоративний claim під чужою водою. Хтось із тієї самої верфової культури дістався сюди раніше, працював тут, потрапив до тих самих книг і лишив доказ досить малий, щоб його стерли, якщо Marauder не помітить.
