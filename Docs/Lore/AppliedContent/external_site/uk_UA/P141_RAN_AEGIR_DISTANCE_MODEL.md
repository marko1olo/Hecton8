# Модель відстані Ran-Aegir

Модель відстані Ran-Aegir є тихим фундаментом тиску HECTON-8. Aegir лежить у жорстокій середній зоні: досить близько, щоб корпорації виправдали маршрутні пластини, seed-обладнання, фрахтові застави, віддалених нотаріусів і постійну видобувну колонію; досить далеко, щоб ніхто не зміг терміново надіслати милосердя, коли відмовляють гермодвері.

Саме ця різниця важлива. Повідомлення, юридичні претензії, графіки перевізників, рятувальні кораблі й людські тіла не мають одного годинника. Попередження вже може летіти, поки корабель, що мав відповісти, ще замкнений паливом, вікном, масою і згодою власника. Deep Reach навчилася користуватися цією щілиною. Колонія жила всередині неї.
