# Утримана евакуація

Evacuation Hold перетворює катастрофу HECTON-8 з природної аварії на ланцюг рішень. Абісальні архіви показують систему, що класифікувала людей швидше, ніж могла їх урятувати.

## Scanner

Аварійна транзитна брама. Механізм заблоковано під час відмови тиску.

## Terminal

EVAC ROUTE: відкладено. SUBSTRATE ROUTE: захищено. MEDICAL ROUTE: очікує авторизації. ATLAS ROUTE: конфлікт безперервності.
