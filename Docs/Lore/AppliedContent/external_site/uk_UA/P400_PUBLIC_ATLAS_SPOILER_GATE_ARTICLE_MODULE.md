# Межа доступу Atlas

Atlas-6 не слід вводити як просту збунтовану машину чи диво-інтелект. Публічна безпечна стаття починається з того, що гравець може перевірити рано: логіка безперервності пошкоджена, ремонтні шляхи імпровізовані, а екологія HECTON-8 втягнута в інфраструктуру. Кабель оживає через біоплівку. Труба повертає таймінг через тканину. Тріщина закривається під мушлевим ростом. Позначена тварина змінює стан маршруту. Цього досить, щоб обслуговування стало небезпечним без раннього називання останнього шару зберігання. Записи приймача й фінальний наслідок корисного навантаження мають лишатися за відновленим доказом, бо перетворюють ранні сцени ремонту на докази передачі, збереження й шкоди.

## Scanner

Запис межі Atlas. Публічний шар охоплює відмовлену інфраструктуру безперервності, ремонтну екологію, біоплівкові шини, акустичну релейну тканину й мушлеві ущільнення; зберігання приймача лишається за доказом.

## Terminal

ПУБЛІЧНИЙ АРХІВНИЙ ВУЗОЛ // МЕЖА ДОСТУПУ ATLAS. Видимий шар: ремонт безперервності тиску. Обмежений шар: зберігання приймача, наслідок корисного навантаження, фінальне повноваження передачі. Не змішувати шари без відновленого доказу.

## Audio

Поки називай це ремонтом. Не називай, що воно зберігає, доки запис не змусить.

## Field Note

Нотатка мародера: якщо Atlas пише збережено, постав наступне питання: збережено для якого приймача.
