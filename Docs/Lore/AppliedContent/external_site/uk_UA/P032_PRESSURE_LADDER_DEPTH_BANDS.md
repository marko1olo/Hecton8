# Сходи тиску

Сходи тиску описують доступ до глибин HECTON-8 як сервісний ланцюг, а не умовний замок: кожен пояс відкривається лише тоді, коли ущільнення, клас костюма, живлення, кисень, ізоляція, сигнал і план повернення проходять перевірку разом.

## Scanner

ЗЧИТУВАННЯ ГЛИБИННОГО ШЛЮЗУ // Пояс: сервісний спуск 250-1200 м. Запас ущільнення 11%. Пластина костюма приймає Grade C лише після фіксації батарейного блока B2. Зворотний ping слабшає нижче третього хомута. Не відкривати нижній шлюз самою сміливістю.

## Terminal

ТАБЛО ДОСТУПУ ЗА ГЛИБИНОЮ
0-250 м: світловий шельф / коротка робота з пошкодженим спорядженням дозволена
250-1200 м: сервісний шельф / потрібне ущільнення костюма Grade C, зафіксована батарея, ping троса
1200-2800 м: каньйон розсолу / потрібна ізоляційна обмотка й налаштування плавучості
2800-4300 м: абісальне машинне поле / потрібен захищений сигнал і дисципліна корпусу
4300-5600 м: басейн Atlas / план повернення має витримати втрату тиску й шум шини
Відмова: наступний пояс замкнений, доки не відремонтовано найслабший показник

## Audio

Досить сперечатися з дверима. Запас ущільнення червоний, а зворотний ping уже запізнюється.

## Field Note

Шлюзу байдуже, навіщо тобі маршрут. Він читає ущільнення, живлення, кисень, ізоляцію, сигнал, а потім дає зелений або закриває задум.
