# Ланцюг збереження пакета

Повідомлення з HECTON-8 важить лише разом із маршрутом, пломбою, отримувачем і станом пошкоджень. Ланцюг збереження проводить факт крізь затримку Aegir, тиск претендентів і фізичне вилучення, не роблячи його звичайним вантажем.

## Scanner

ПЛОМБА ПАКЕТА // Смуга witness hash пошкоджена, але читається. Зберегти до різу. Доказ без пломби стане матеріалом претензії.

## Terminal

НОТАРІЙ KEELMARK // До передачі зберегти пломбу, witness hash, маршрутний штамп і тег роз'єму. Матеріал без штампа може піти як претензійна втрата.

## Audio

Ретранслятор Black Keel: вантаж це маса. Доказ це збереження. Принеси обидва, інакше вікно виставить рахунок за різницю.

## Field Note

Спершу пломба, потім різ. Чистий зразок зі зламаним тегом належить тому, хто тримає реєстр.
