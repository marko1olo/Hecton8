# Вікно корисного вантажу

Payload Window задає структуру фіналів HECTON-8. Останнє питання не тільки в тому, у що вірить гравець, а в тому, що він здатен винести з океану.

## Scanner

Імпровізований пакет підйому. Він може вийти з океану, якщо збігнуться маса, погода й геометрія carrier.

## Terminal

PAYLOAD SLOT: обмежений. WINDOW: відкрите. ROUTE: оспорюється. CLAIM VALUE: змінна. EVIDENCE STATE: недостатній для чистої суперечки.

## Audio

Вікно відкрите. Воно не лишиться відкритим для всього.

## Field Note
