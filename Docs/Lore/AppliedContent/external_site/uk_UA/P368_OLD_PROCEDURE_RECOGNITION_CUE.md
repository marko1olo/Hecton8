# Сигнал упізнавання старої процедури

Сигнал упізнавання старої процедури тримає мотив персонажа на документі, який оператор уміє читати. Форма навмисно звичайна: route-safe certification, declared occupants, бирки насосної, поле ручної перевірки, печатка Continuity Office.

Поломка в розбіжності. Прийнятий підрахунок каже, що маршрут закрито. Бирки кажуть, що люди ще були прив'язані до кімнати. Офісна печатка каже, що другої перевірки не буде. HECTON-8 використовує це процедурне протиріччя як доказ: не драматичне зізнання, а форму, яка ламає людину, бо вона розуміє кожне поле.
