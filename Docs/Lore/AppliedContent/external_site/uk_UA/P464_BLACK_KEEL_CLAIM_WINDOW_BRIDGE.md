# Вікно претензії Black Keel

Black Keel може почути сигнал раніше, ніж підніме тіло. В Aegir відповідь носія це платна смуга крізь геометрію реле, погоду, карантин, прийом вантажу і повернення маси. Контакт це факт маршруту. Порятунок це завершений ланцюг.

## Scanner

ВІКНО ПРЕТЕНЗІЇ // ретранслятор Aegir показує лише вікно прийому. Для повернення потрібні підйомний пакет, карантинне узгодження і ліміт tonne-window.

## Terminal

ПОВІДОМЛЕННЯ KEELMARK // сигнал оператора отримано. Пріоритет повернення не вирішено. Прийом сигналу чи пакета доказів не гарантує повернення оператора.

## Audio

Ретранслятор Black Keel: сигнал оператора оцінено. Вікно повернення очікує. Не плутай прийом із підйомом.

## Field Note

Якщо Black Keel відповідає, рахуй рахунок, не порятунок. Прийнятий пакет це лише місце в черзі, доки маса, пломба, карантин і погода не зійдуться.
