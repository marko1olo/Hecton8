# Журнал ремонтних латок напірного скафандра

Ідеальний напірний скафандр належить буклету. HECTON-8 не буклет. Важливі скафандри залатані, стерті на колінах і манжетах, просолені біля швів і чинені будь-якою смугою для ще одного спуску.

Добра латка несе соціальну інформацію. Завод - рівно. Нагляд - правильна стрічка без часу. Робітник - чужа нитка й знання тіла. Медицина - швидко й страшно. Чорний Кіль - спершу ідентифікатори.

Латки належать шафкам, медвідсікам, затопленим роздягальням і кинутим верстакам. Вони роблять колонію особистою без промови над кожним тілом.
