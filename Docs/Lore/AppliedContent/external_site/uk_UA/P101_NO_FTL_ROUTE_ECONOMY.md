# Економіка маршрутів без FTL

Економіка маршрутів без FTL - правило, яке робить HECTON-8 чесним. Людський простір може дістатися Aegir у 2190 році, але кожен прибуток складається зі стартових вікон, маси захисту, пального, гальмівних систем, custody packets і років оплаченого терпіння. Закон може випереджати кораблі, бо рухається даними. Борг може випереджати порятунок, бо його оцінили до аварії. Гравця покинула не відсутність дива, а економіка, яка ніколи дива не обіцяла.
