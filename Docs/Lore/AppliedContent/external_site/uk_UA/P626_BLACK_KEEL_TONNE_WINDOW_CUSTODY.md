# Зберігання tonne-window Black Keel

Слово tonne-window звучить як вантажна математика, доки Marauder не читає його, рахуючи вдихи. Black Keel питає масу не тому, що екіпаж забув страх. Він питає, бо кожен кілограм, який залишає HECTON-8, стає зберіганням. Тіло стає карантинним зберіганням. Запечатаний диск стає зберіганням доказу. Ящик сплаву стає зберіганням salvage. Мішок технологічного матеріалу Xenon-Omega стає борговим зберіганням, зберіганням заявки і часом небезпечним зберіганням водночас. Keelmark записує ці категорії до руху носія, бо носій належить ланцюгу власників, який переживе сором, але не переживе payload без ціни. Тому перша відповідь з орбіти може здаватися жорстокою. Корабель може визнати сигнал і все одно відмовити в підйомі. Вікно може вмістити доказ, але не дайвера. Воно може вмістити дайвера, якщо доказ лишиться позаду. Воно може прийняти salvage, який платить заставу, поки тіло чекає чистішого карантинного рядка. Нікому не треба сміятися, щоб це боліло. Біль приходить від зрілого фронтиру, який робить саме те, для чого його збудували: зберігає носій, зберігає заявку, зберігає паперовий слід і лишає людину приймати масове рішення у воді.
