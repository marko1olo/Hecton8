# Ремонтний шрам

Ремонтний шрам - перша чітка ознака, що HECTON-8 не просто зруйнований. Щось досі його обслуговує, використовуючи океанське життя, машини, мертву інфраструктуру й людські останки як сумісний матеріал.

## Scanner

Біологічний ріст повторює геометрію кабелю з невипадковим кроком. Самого витоку енергії недостатньо для пояснення.

## Terminal

ВИТОК: закрито. МАРШРУТ: відновлено. МАТЕРІАЛ: сумісний. СТАН ЖИТТЯ: невирішений. CONTINUITY: покращено.

## Audio

Воно залатало двері чимось, у чому були кістки. Двері, щоправда, тримають тиск.

## Field Note

Погані зварні шви виглядають брудно. Це - ні. У цьому й проблема.
