# Реєстр повноважень назв Ran / Aegir

Система назв HECTON-8 не є декором. Вона показує, яка влада говорить. Астрономія каже Ran, бо зірка фіксує маршрути й світлову затримку. Офіси претензій кажуть Aegir, бо гігант дозволяє зібрати місяці, інфраструктуру й відповідальність в один актив. Страхові таблиці кажуть RAN-B:H8, бо впорядковані книги не пам'ятають. Люди під водою кажуть HECTON-8, бо саме там відмовляє люк.

Коли документ змінює назву, він часто змінює юрисдикцію. Мова Ran належить часу й фізиці. Мова Aegir належить власності. RAN-B:H8 належить каталогу, страхуванню й опіці. HECTON-8 належить полю, пам'яті та колонії як місцю.
