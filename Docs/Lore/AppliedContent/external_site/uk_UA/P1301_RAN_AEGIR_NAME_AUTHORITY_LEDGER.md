# Реєстр повноважень назв Ran / Aegir

Система назв HECTON-8 - тихе світобудування із зубами. У місяця чотири назви не для барви. Кожна назва належить іншій владі й іншій моральній відстані до одного й того самого потонулого місця.

            Ran - мова астрономії: зірка, якір маршруту, світлова затримка, таймінг носія. Aegir - мова претензії: гігант як батьківське тіло, публічне скорочення і корпоративна парасоля. RAN-B:H8 - мова страхування: сортований запис місяця, який можна передати й оскаржувати, не зберігаючи голос колонії. HECTON-8 - прожита мова: двері, кімнати, могили й сигнали тиску.

            Коли гравець засвоює цю граматику, документи змінюють форму. Корпоративне повідомлення з Aegir може від'їхати так далеко, що провал місяця виглядає обслуговуванням системи. Квитанція RAN-B:H8 готує ціну опіки. Польова нотатка HECTON-8 зберігає свідчення до того, як каталог його відмиє.
