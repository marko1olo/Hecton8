# Журнал ремонтної обмотки кабельної оболонки

Добра кабельна обмотка корисно негарна. У ній шари паніки, навички й поганого світла. Працівник обмотував лінію не через схему, а тому що на іншому кінці щось ще мало значення: насос, двері, датчик.

Обмотка читається через тиск і поводження. Сіль у шві стрічки означає старий ремонт. Сіль зовні чистого хомута означає пізніший хомут. Волокно під мілкою потертістю означає новий рух. Сплющені смуги показують навантаження.

Ремонтований кабель може бути здобиччю, маршрутом, електричним попередженням, доказом пізньої роботи або єдиною чесною стрілкою в коридорі мертвих знаків.
