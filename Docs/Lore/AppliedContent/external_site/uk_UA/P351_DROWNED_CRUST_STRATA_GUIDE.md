# Польовий довідник затоплених пластів кори

Польовий довідник затоплених пластів кори робить дно HECTON-8 збудованим і зламаним водночас: terrain, salvage routes і мінеральні зразки походять з однієї шаруватої історії тиску.

## Scanner
