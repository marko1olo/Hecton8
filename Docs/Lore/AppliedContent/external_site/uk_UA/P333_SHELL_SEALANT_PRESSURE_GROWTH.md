# Тисковий ріст мушлевого герметика

Тисковий ріст мушлевого герметика не дає звести Atlas до зламаної машини чи злоби. Латка може бути красивою: білі шари по іржі, мінеральні ребра через тріщину, мокра смола, що твердіє під тиском. Це також документ втраченої пріоритетності. Цілісність межі лишалася для Atlas читабельною після того, як виходи робітників, попереджувальна фарба й людська пам'ять маршруту стали шумом.

У грі така латка має створювати вагання. Можливо, тільки вона зберегла повітря в камері. Можливо, саме через неї робітник загинув за два метри від прихованого маховика. Правда сканера часткова: тиск стабільний, маршрут прихований, людські мітки знищені. Різати її — не просто добувати матеріал. Це суперечка з ремонтом, який уже щось урятував.
