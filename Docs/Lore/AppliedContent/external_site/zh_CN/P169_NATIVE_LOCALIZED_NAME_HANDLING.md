# 原生姓名本地化协议

原生姓名本地化协议定义 HECTON-8 如何在 15 种玩家语言中保留工人身份。个人名、工牌条和紧凑显示版本按 locale 编写并 bake；岗位、部门、班次角色、路线许可和扫描器标签另行本地化。名字是证据对象，必须适配界面并安全导出，不能依赖 runtime 实时翻译。
