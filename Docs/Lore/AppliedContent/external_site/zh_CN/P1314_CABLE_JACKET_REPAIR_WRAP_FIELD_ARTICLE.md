# 电缆外皮修补缠带野外条目

电缆外皮修补缠带是 HECTON-8 上强力的小尺度证据表面。材料普通，压力不普通：防水橡胶、灰色胶带、外露纤维、盐缝、夹具印和潮湿刮痕都能被阅读。

玩法上，一段缠带可以把玩家引向旁通、氧气线路、继电器、狭窄通道或危险。物理痕迹最重要：重叠下的盐、被磨亮的夹具印、舱口附近变化的缠绕间距、空走廊里不该出现的新胶带。

缠带也把人类维护和 Atlas 修复生态分开。活体层可以后来出现；胶带记录了最初的人类妥协。
