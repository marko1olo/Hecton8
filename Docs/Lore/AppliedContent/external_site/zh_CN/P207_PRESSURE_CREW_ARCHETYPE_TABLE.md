# 压力班组原型表

压力班组原型把 HECTON-8 的工人演员表变成可读的劳动史。殖民地首先不是由传记解释，而是由工作解释。Pump、Seal、Relay、Brine Map、Vent Forge、Triage、Pressure Botany 和 Payload Witness 给每个名字功能、在海洋经济中的位置，以及作为证据出现的理由。这样，世界观通过物件和航线浮现，而不是靠脱离场景的说明。

## Scanner

班组先是动词，之后才是背景：抽水、密封、中继、测绘、锻造、分诊、栽培、见证。

## Terminal

CREW FAMILIES: Pump、Seal、Relay、Brine Map、Vent Forge、Triage、Pressure Botany 和 Payload Witness。每个工人身份在个人细节之前先绑定到一个班组家族。这样证据会继续连接到机器、航线、压力故障、食物文化、打捞法和最终 payload 链。
