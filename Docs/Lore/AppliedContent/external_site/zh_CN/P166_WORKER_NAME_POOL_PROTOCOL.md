# 工人姓名池记录

工人姓名池记录定义了 HECTON-8 如何把 seed 化证据变成连续的人类痕迹。每个身份由预制姓名、域来源带、压力劳动岗位、工牌碎片、路线许可和班次标记组成。目标不是随机风味，而是可读责任：谁能打开舱门，谁维护泵机，谁被拒绝医疗离岗，后来的 Marauder 又在扰动谁的痕迹。

该系统保留个人身份，同时允许物品位置和证据组合变化。这带来没有矛盾的重玩。工人可以通过储物柜、工作板、路线卡或名单出现，但原则不变：房间可以 seed，人不能因此变成程序化耗材。

## Scanner
