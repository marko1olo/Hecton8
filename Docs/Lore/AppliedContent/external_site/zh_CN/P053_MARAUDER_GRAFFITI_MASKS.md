# 掠夺者涂鸦伪装

HECTON-8的掠夺者不是没有面孔的袭击派系。他们是工人、债务跑腿、被遗弃的承包商和打捞队，学会在墙上写字，因为每个干净频道都可能被监看或计费。他们的涂鸦故意难看：足够快，可以在压力下画完；足够清楚，可以透过冷凝水读出；也足够含糊，可以被看成恐慌或破坏。黑环不是装饰，它表示载体可能听见你。断箭不是画得差，它表示自上次安全通过后，走廊已经变了。
