# 部分撤离：同一seed返回

部分撤离保护长线战役，避免虚假的闭合。Black Keel可以在有限窗口内拉起操作者，修补潜服，记录取回的包，并把暂停包装成福利。下方世界不会翻成更干净的版本。

当玩家返回时，同一个seed仍在那里。盐阶还是同一个陷阱，中继还是同一个坏角度，同一份证据仍然危险。这个结局给出没有赦免的缓解：肺里有空气，合同里有更多债务，发现过的东西没有被抹掉。
