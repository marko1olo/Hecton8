# 部分撤离：同seed返回

部分撤离是长线生存故事的压力阀。承包者赢得pickup窗口，缝合伤口，修补装备，听见少有的、不是从坏掉潜服里过滤出来的空气声。那份缓解是真实的，所以返回才痛。

Black Keel把暂停记为福利和lien维护。同一个world seed仍在，同一批证据未解决，同一片海带着所有已发现路线等待。部分撤离不是系统的怜悯，而是对一个仍被期待下潜的资产进行保养。
