# 生物金属传感标签

生物金属传感标签不是普通收集品。它们出现于一个修复系统不再关心载体到底是机器、电缆生长物还是动物的时候。标签是一片薄薄的生物金属鳞，会长进组织，吸取一点电流，记录运动，并通过水体重复位置置信。掠夺者可以用它调校脉冲器、延长扫描距离，或证明Atlas接触某条路线时，那条路线仍是活的。问题就在这种有用性。冷拔标签，它会成为证据。热拔标签，网络可能注意到丢失的载体，用假回波回答，或把修复逻辑引向受伤动物、被切断的海带，或手里拿着标签的潜水者。这种材料要求玩家把战利品当成案卷处理：有用、肮脏，而且仍在汇报。
