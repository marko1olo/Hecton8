# 工人联络公告

工人联络公告是一份小型社会文件，边缘很硬。它列出铺位排、路线负责人、医锁见证人、工具库联系人和中继窗口。在压力逻辑显露前，它像普通管理表；一旦看懂就知道，站外联系人可以哀悼、争吵、记住，却不能比水更快赶到舱门。

所以 HECTON-8 的紧急联系人定义为：在站内、受过训练、能被提示音叫到，并且有该工人路线许可。这个定义严厉，却不是无情。一个错过的返回可能变成进水通道时，关照只能长成这种样子。

公告也把日常证据连成共同体网络。一个工件里的泵钥匙，另一个账本里的水量更正，第三处工具签名：每个标记都把疲惫的工人接到另一个工人身上。结果不是煽情，而是可信的压力定居点，责任本身成了亲密关系。
