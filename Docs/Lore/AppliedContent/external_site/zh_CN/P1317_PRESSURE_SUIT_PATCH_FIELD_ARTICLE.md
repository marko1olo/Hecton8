# 压力服补片现场条目

压力服修补片是小而密集的证据表面。深色技术织物、缝带、针脚、盐和磨损显示一件压力服是被维护、借用、判废，还是被推去完成最后一次返程。

读取方式是物理的。缝合边缘下的盐意味着潮湿压力循环。发亮月牙标记与梯子、舱口或线缆的反复接触。跨过关节的补片比平面布料上的补片更糟。没有压力测试标签，打捞品就可能变成危险。

补片让人类的求生痕迹保持可见，而不是变成完美科幻自愈。
