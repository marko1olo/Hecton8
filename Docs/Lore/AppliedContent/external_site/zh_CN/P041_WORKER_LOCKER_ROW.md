# 工人储物柜排

工人储物柜排是人性纹理包：廉价储物、船员姓名、Barnard印记，以及从职业任务到个人牵连的第一座桥。

## Scanner

这些柜子不是布景。姓名、餐票和Barnard工具印让沉没殖民地变回工作场所。

## Terminal

储物柜审计：个人封条在压力破裂后失效。多枚标签带Barnard工场印和未结班次预支。
