# 弹丸航道尾迹账本

弹丸航道不是道路。它们是基础设施在飞船抵达多年前作出的承诺。发射阵列、仓站或航线站把反应弹丸流抛向预测轨迹；货船接住这条流，把它喂给聚变脉冲，在护盾后航行，巡航多年，然后依赖一套在船抵达 Aegir 前可能已经换过主人的制动架构。这套机器分层建起航线：先是 needleprobe 探针，再是 seed 机器，之后是重货物、冬眠合同、系统航母和 Black Keel 这样的本地驳运船。它也解释了当下的残酷。信息能在有用质量服从它之前穿过航线。救援请求可以是新的，但飞船、推进剂、制动槽、隔离床位和幸存者座位可能属于事故发生前就买好的时间表。到 2190 年，驱动板读起来不像冒险，更像法律疤痕组织。Marauder 扫描一条蚀坑尾迹账本，就能看出谁有钱把金属扔过十光年，又打算让谁为停下它付账。
