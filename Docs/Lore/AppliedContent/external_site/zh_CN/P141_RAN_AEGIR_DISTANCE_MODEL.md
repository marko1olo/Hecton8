# Ran-Aegir距离模型

Ran-Aegir距离模型是HECTON-8压力的安静基础。Aegir处在残酷的中间距离：近到公司可以证明航线板、seed硬件、货运留置权、远程公证和永久采掘殖民的合理性；远到压力门失效时，没有人能临时送来仁慈。

这个差别才是重点。消息、法律索赔、承运时间表、救援船和人的身体不按同一个时钟移动。警告可以已经上路，而该回应它的船仍被燃料、窗口、质量和所有者批准锁住。Deep Reach学会了使用这道缝。殖民地就活在这道缝里。
