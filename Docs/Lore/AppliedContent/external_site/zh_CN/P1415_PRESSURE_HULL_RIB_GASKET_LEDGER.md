# 压力壳肋条与密封圈账本

HECTON-8的压力壳不好看，因为它们诚实。它们不是为了像飞船，而是为了让工作房间不要变成海。每一条材料都有职责：外板分散载荷，肋条承受载荷，密封圈阻止水迁移，锁扣侧告诉你人在压力下原本打算从哪里打开。

最好的读壳从污渍开始。盐在低缝下生长。黑绿色生物膜沿着慢漏扩散。螺栓旁的锈不如螺栓排是否仍直重要。直排表示模块整体受难；错位表示框架被撕开。被挤出的密封材料说明浸水前曾经受压。空槽里干净的金属说明后期拆解或有意开启。

这让环境信息变成玩法。玩家可以选择锁扣侧进入，避开仍在承载的肋条，切开已经孤立的外板，或保留密封痕迹作为官方时间线被破坏的证据。海没有给殖民地增加谜语，它只是剥掉涂装、标志和借口，留下肋条、盐和弯曲的螺栓。
