# 带传感器标签的动物群

带传感器标签的动物群防止 HECTON-8 的生物机械层滑向简单的腐化故事。这些生物并不是被魔法变成无人机。它们是比监测硬件活得更久的动物和群体。标签变成窝、疤、生长环、矿物水泡或假眼，因为生态系统做了生态系统会做的事：围绕损伤继续生长。

于是每一个信号幽影都有历史。Marauder 可能从一只贝壳啃食者体内听到微弱的 Deep Reach 标识，也可能看见一枚生物金属眼节点在无视命令的身体上闪烁。旧公司仍在血肉里留下文书痕迹，但血肉并不服从。Atlas 可以利用信号，却不能拥有动物。这让恐怖更悲伤也更强：工业控制试图标记生命，生命活了下来，而标记仍向已经听不懂的系统报告。
