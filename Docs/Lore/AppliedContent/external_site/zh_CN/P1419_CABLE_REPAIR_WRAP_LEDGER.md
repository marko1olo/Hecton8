# 电缆外护套维修缠绕账本

好的电缆包扎有一种有用的丑。里面有恐慌、技术和糟糕照明的层次。工人包住一条线，不是因为它在图纸上显得重要，而是因为另一端还有东西重要：不许死掉的泵、必须再循环一次的门、没人愿意大声说出的传感器警告。

HECTON-8的电缆缠绕通过压力和处理痕迹来读。胶带缝内的盐说明维修足够老，已经吸入海水。干净夹具外的盐说明夹具更晚。浅擦痕下露出的纤维说明近期移动。深压扁的带状痕说明工具或支架曾在负载下固定电缆。

维修电缆可以是战利品，也可以是路线标记、危险警告、后期运行证据，或死标牌走廊里唯一诚实的箭头。读缠绕的玩家找到的不只是铜，而是意图。
