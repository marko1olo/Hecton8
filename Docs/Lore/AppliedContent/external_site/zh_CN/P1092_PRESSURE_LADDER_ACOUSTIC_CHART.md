# 压力阶梯声学图

HECTON-8是垂直建成的。海洋是一架压力和化学阶梯：透光陆棚、电缆礁、盐水峡谷、机器场、Atlas盆地。每个层带都会改变玩家能看见、听见、相信和修理的东西。所以下潜保持物理性。更深路线意味着更苛刻的密封、更差的回程时机、更怪的浮力，以及从损坏仪器里抵达的证据。

无线电很早失败，因为矿物海洋吞噬电磁信号。声音仍有用，但水柱会重塑它。高密度盐水能困住脉冲并把它横向带走。喷口热流能撕开它。电缆礁能反弹信号，让走廊看起来开放。这张图可怕是因为它实用：声呐回波不是事实，直到压力、线张力、运动和第二次 ping 一起同意。
