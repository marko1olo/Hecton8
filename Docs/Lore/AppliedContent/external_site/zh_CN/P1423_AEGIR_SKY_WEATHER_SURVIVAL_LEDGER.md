# Aegir天空天气生存账册

HECTON-8把天空用作生存系统。Aegir足够巨大，能让地表充满戏剧性，但关键并不是大小。关键是天空会改变玩家面对的真实。平静的地平线可能让上行链路更清晰，也可能提高辐射。风暴可能保护血肉，却把carrier埋进静电。月亮穿行可能把潮汐模型从玩家计划使用的门口拉走。

这让虚构保持物理性。救援不是被模糊的剧情墙挡住。挡住它的是天气、电荷、中继几何、监管路由、质量分配，以及轨道上的carrier不能在每个被困者想要时都花掉一次升力机会这一事实。Black Keel可能在一个窗口接收证据，却仍拒绝身体回收直到之后的窗口。这个差别就是游戏。

玩家应该像读氧气一样读Aegir。天空会告诉你何时传输、何时躲避、何时相信水流、何时怀疑清晰信号，以及何时升空计划只是一个等待几何条件的承诺。
