# 潮湿隔热毯热记忆账

旧殖民地不只在舱门和船壳上失败。它也在那些本该让压力变得可忍受的地方失败：背板、绗缝隔热层、维修壁龛，以及发射前没人拍照的米色织物。

好的隔热层讲的是人的尺度。深色下缝记录呼吸和冷凝。针脚槽里的盐记录干燥周期。被压扁的绗缝口袋记录压力，也记录靠在墙上的身体。露出暗色内层的小裂口可能是工具勾伤、紧急进入，或有人切开垫层找隐藏线缆。

所以隔热层连接机器史和工人史。它属于空气袋、紧急避难处、爬行空隙、仍在嗡鸣的死面板。若织物湿在错误一侧，房间的故事已经翻面。
