# 证据关系图档案

## 记录证明了什么

关系叠层不是给法官用的，而是给疲惫调查员和受惊拾荒者用的。只要记录共享来源物体、路线牌、索赔短语、证人哈希、说明族、伤痕、修订状态或可见后果，它就把它们放到同一张桌上。这样能在压力下看见模式，也很容易制造虚假的确定性。

哈希匹配不能证明证言真实。说明匹配不能证明来源已经找回。相同的修订状态也许只是同一名文员用同一模板删改。叠层有用，是因为它告诉玩家把注意力花在哪里: 数据包保管、来源物体、索赔措辞、证人哈希、路线后果、修订理由和说明顺序。一旦把线当成裁决，它就危险了。

## 如何阅读

档案图例
绿色边: 来源物体或路线牌匹配。
琥珀边: 索赔短语或说明族匹配。
红色边: 证人哈希、伤痕或压制后果匹配。
灰色边: 仅共享修订状态。
每条边都必须核对保管链。漂亮的图仍可能是画成直线的谎言。

## 现场备注

别让干净的图替你思考。线很便宜。说明和修订状态，才是谎言变得便宜到能发货的地方。
