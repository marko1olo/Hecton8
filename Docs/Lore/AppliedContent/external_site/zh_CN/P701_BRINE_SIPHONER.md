# 卤水吸食者

在HECTON-8工业陆架作业的打捞队报告了一种短体渗透压摄食种，它停在密度界面上，用一对虹吸管抽水，而不是游过那一层。群落集中在人造界面上，尤其是裂开的冷却管路和隔着失效泵仍有流量的取水格栅。

现场把这种动物当作测量仪器：沿格栅的种群密度跟随后面破口的大小。44区的Deep Reach记录把该物种列为无合同的检漏服务，并以校准漂移为由关闭了对应的传感器更换项。
