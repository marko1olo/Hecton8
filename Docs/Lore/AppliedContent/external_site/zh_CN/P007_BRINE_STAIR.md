# 盐水阶梯

盐水阶梯是HECTON-8不再只是简单下潜、而变成水造机器的地方。高密度盐水不会与上方层次干净混合。它沿海底形成架层、帘幕和缓慢河流，在最糟的时刻弯折声呐并改变浮力。这种危险给玩家一种新的识读能力。更强的船壳有帮助，但读懂水更重要：哪里热量上抬，哪里盐分下沉，哪条边界可以像道路一样骑行，哪里一次粗心的压载变化会把艇钉在看不见的天花板下。它的 lore 价值同样重要。盐水阶梯保存殖民地试图丢失的东西。它们留住旧路线标记、压力匣、死无人机、化学痕迹，有时还有几十年未混合层里的尸体。每向下一阶，都可能同时成为导航、考古和控诉。
