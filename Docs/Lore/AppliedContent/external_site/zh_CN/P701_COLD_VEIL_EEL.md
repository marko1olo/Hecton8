# 冷幕鳗

在HECTON-8加压基地机械区1,900米深度作业的队伍报告，有一种片状形态的冷水鳗停在洗涤器排放羽流中。在灯光距离上，该物种常被误认为撕裂的阻尼毯；可靠的区分点是边缘行为——自由的毯子顺流而动，而这种动物把一条边缘对着水流保持刚直。

接触造成的伤害是热性的，不是机械性的，报告中包括服装快速失热与密封件变硬。44区的Deep Reach记录把该物种列为非计划的温度仪表，并把一个内生标签记录为正在上报；该舱段的周期自2147年起在无人员的情况下维持。
