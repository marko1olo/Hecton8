# Deep Reach净化包转录

## 干净语言，肮脏延迟

Deep Reach包危险，是因为它听起来像帮助。它说安全。它承认事件。它使用正确的灾难名词：压力、隔离、坐标、exposure、recovery。然后它删除真正重要的动词。谁延迟疏散？谁给hold定价？殖民地崩坏时，谁让Atlas weighting继续生效？

被净化的语言不需要否认海洋。否认太容易被推翻。这个包通过接受物理灾难，并把责任重排成pending review来运作。坐标排在第一，因为公司在承诺任何身体之前，想先拿到claim空间的custody。隔离费用紧随其后，因为活着的工人和受污染的证据会在同一个desk下变成liabilities。

对玩家来说，这份转录应该制造愤怒，但不破坏可信度。Deep Reach不是从轨道大喊的卡通反派。它是一家公司，清楚知道哪些字段必须从一条未来可能成为证据的信息里消失。
