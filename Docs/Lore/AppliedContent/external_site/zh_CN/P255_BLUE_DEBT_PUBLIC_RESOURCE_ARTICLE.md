# Blue Debt公开资源文章

Blue debt 不是魔法矿石。它是边疆俚语，指含 Xenon-Omega 的压力基质：富盐卤水矿囊、clathrate layers、pressure glass 污染、biofilm-bound lattice，以及在普通设备无法承受条件下幸存的受损 containment material。它的价值来自压力下的历史。一个样本可能保存计算痕迹、containment 行为、sensor memory，或只有 HECTON-8 能制造的化学状态。

debt 这个词很重要。Blue debt 有价值，是因为别人已经用基础设施、劳动、时间和风险为它的形成付过代价。看起来干净的一块可能同时携带 quarantine exposure、Deep Reach 托管、Black Keel 质量罚项和证据价值。拿走它从来不只是采矿，而是与航路账本争论。

公开资源文本应让材料诱人，但不能简单。玩家应想扫描它、收容它、出售它、证明它，有时还要留下它。最好的 blue debt 物体不是发光奖励，而是一份压力记录：有用到值得冒险携带，不稳定到需要尊重，有记录到所有权会伤人。
