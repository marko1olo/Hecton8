# Barnard Yards 打捞出身

## 记录证明了什么

Barnard Yards 用租来的切割器、压力夹、债务标签和死亡索赔流程把操作员训练成有用的人。Black Keel 把这项技能变成可计费项目。

Barnard Yards 解释了操作员为什么知道 HECTON-8 的第一维修顺序：排水、隔离、按等级补丁、只切服务金属、保留证据，然后移动。这种能力不是自由。同一套船坞逻辑会把工具、训练和死亡索赔变成 Black Keel 可以定价的债务。

BARNARD YARDS 租赁柜台 // 发放：感应切割器、夹具套装、封印计、见证套。留置说明：工具丢失、污染、未认证切割或 payload 见证失败，可把合同工作转成可回收债务。切割前排水。升举前定级。出售前打标签。

## 玩家该怎样读它

Barnard 教你安静切割，也教你大声读债。切割器标签是一条带序列号的绳索。 把它当成处理证据的规则，不要当成救援已经出发的承诺。
