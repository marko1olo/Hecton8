# 渗漏、锈蚀与生物膜时间账本

好的渗漏痕一开始并不戏剧化。它看起来像脏东西。正因为如此，它属于HECTON-8。殖民地没有把真相留在干净铭牌上，而是留在水停留的地方、螺栓出汗的地方、密封件呼吸的地方、工人没有时间再擦拭的地方。

有用的问题不是污迹是什么颜色，而是哪一层在上面。盐下的锈说明老湿缝。盐上的油说明后期机器泄漏。油上的盐说明水后来才来。油漆上的生物膜说明表面长期潮湿并得到供养。脏痕中的干净线可能是后期擦拭、标签被移除或工具拖过。

在玩法里，渗漏时间线可以同时承担多件事：让路线可读，警告弱密封，说明房间在官方关闭后仍运转，或标记一个值得保存而不是切碎的证物。
