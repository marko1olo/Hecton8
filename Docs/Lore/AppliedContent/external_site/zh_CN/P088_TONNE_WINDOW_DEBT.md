# 吨窗债务

吨窗是carrier容量的一片切口,以质量、burn时机、隔离体积和法律优先级衡量。对操作员来说它像债务,因为HECTON-8上每件有用物体都进入同一本ledger,和发现它的身体并列。封存箱可能很轻,却在法律上很重。样本架可能质量不大,却需要清洁体积。人类撤出看似显然,直到压载、氧气储备和payload custody已经花掉可用窗口。HECTON-8的经济变成物理,而不是抽象。玩家不是被虚假的道德计惩罚。玩家被困在一台用燃料、质量、污染和文件给生存定价的机器里。
