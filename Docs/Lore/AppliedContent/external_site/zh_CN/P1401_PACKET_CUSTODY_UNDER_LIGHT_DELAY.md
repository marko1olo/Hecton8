# 光延迟下的包托管

HECTON-8不是Marauder找到发光文件后真相就会获胜的地方。这颗卫星离核心法律太远，离Deep Reach所有权太近，又太依赖承运队列。文件可以真实，但如果唯一副本留在索赔方托管内，它仍然无用。

证据路径是机械的。首先，来源必须带有能与现场核对的时钟或压力状态。其次，数据包需要稳定哈希和重复见证：另一个终端、徽牌托盘、Black Keel扫描、工人封印，或一个能说明文件来自那个房间而不是法律剧场的实物。第三，载荷需要在索赔方路径之外托管。Black Keel可以移动它，但Black Keel也是合同机器。Keelmark队列可以保存一个数据包，同时让它远离公共后果。

这就是无FTL距离变得私人的地方。光比身体更便宜地运送索赔、威胁和公证收据。Marauder必须让真相穿过同一台缓慢机器：本地中继、承运托管、Luyten收据、公共接收方。这不华丽。它决定死去的工人会成为证据，还是成为可回收质量。

HECTON-8最好的证据同时是物理的、也是程序性的。被水损坏的账本重要，因为页面仍留着压力污痕。路线印章重要，因为它把一个人系在一扇门上。哈希重要，因为它证明海洋交出数据包后内容没有变化。接收方重要，因为Deep Reach能在自己的办公室里承受羞耻，却很难承受离开索赔链的已验证数据包。
