# 传感标记动物反馈环

带传感标记的动物不是傀儡。它是野生生命，壳层和疤痕组织下仍有公司仪器在应答。这足够让Atlas把移动误认为环境更新，也足够让潜水员的路线改变，而动物本身毫不知情。

## Scanner

左侧体表壳层下有旧Deep Reach标记。运动数据包仍在ping维护网。

## Terminal

FAUNA TAG LOOP / DR-2147-MIG：压力、运动和污染数据包被接收为环境遥测。不解析动物意图。路线警报可能跟随迁移路径。

## Audio

它不是在猎你。它的标签仍可能打开错误的门。

## Field Note

如果带标记动物穿过中继场，先等一等再相信警报。动物可能已经走了；路线状态还在追它。
