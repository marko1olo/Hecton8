# 传感标记动物反馈环

传感标记动物不是受控士兵。这个区别很重要。Deep Reach的标记项目最初只是普通野外科学和物流：追踪迁徙、耐压、污染暴露和路线密度。多年以后，标签已不再是干净设备。壳层包住它们，疤痕组织把它们拉偏，矿物帽改变它们的信号。

Atlas仍然读取回传。受伤的食草动物穿过淹没栈桥时，可能看起来像一次压力测绘。带着旧标签的捕食者，会让走廊像被基础设施风险占据。动物仍是它自己，但周围系统把移动当作数据。野生遭遇因此有第二层锋刃：求生行为也可能是维修反馈。
