# 碰撞裂月

HECTON-8不是为了传奇效果而被捕获的流浪天体。它在Aegir自己的碎屑带中聚合，冷却成分层海洋月球，随后遭遇一次斜向撞击，地壳被扭曲，世界却没有被抹去。撞击抬升陆架，沉降盆地，打开长长的断层梯，炽热化学仍在盐水中流动。潮汐共振在轨道锁定后继续维持这些伤口。因此海洋拥有可读的疤痕：盐卤峡谷、喷口熔炉、压力玻璃脉、裸露脊线，以及通往古老海底的稀有窗口。
