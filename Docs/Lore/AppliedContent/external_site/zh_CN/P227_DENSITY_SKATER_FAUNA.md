# 密度滑行者动物群

密度滑行者动物群把 HECTON-8 最奇特的硬科幻想法之一变成玩家无需讲座也能理解的遭遇：水里可以藏着表面。在盐水峡谷中，盐度、温度和压力堆叠成密度台地。小型动物利用这些台地，就像地球水黾利用表面张力，只是这个表面埋在海洋内部。效果应该诡异但公平。滑行者穿过看似空旷的间隙；声纳显示波纹；潜水服 trim 摇晃；玩家意识到那里有边界。写法和摆放都应拒绝奇幻悬浮。滑行者不是因为世界忘了物理才漂浮。它活着，是因为物理足够具体。它的路径可能通向撕裂的 brine vane、低盐口袋、温热盐水台阶或伏击路线。它也可能误导：能托住轻小动物的东西，也许会让满载的 Marauder 掉进黑色层状水。设计价值不在生物本身，而在它教给玩家的事。峡谷不是开放空间。它是堆叠水体组成的机器，每一个在其上行走的小身体都在用运动画地图。

## Scanner
