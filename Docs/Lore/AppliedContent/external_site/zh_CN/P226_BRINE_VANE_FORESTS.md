# 盐水叶片林

盐水叶片林是 HECTON-8 不再让水表现得像空白空间的地方。在峡谷里，水变成建筑：密度层像墙一样叠起，声纳围绕不可见台地弯折，粗心下潜会在深度计显得戏剧化之前，就把潜水服压到预期浮力以下。盐水叶片让这套数学可见。它们不是地球植物，也不是会说话的外星礁。它们是盐-矿物膜，生长在化学梯度持续供养它们的地方；足够平坦，看起来像植物，足够物理，值得相信。活膜片说：不要从这里穿过。撕裂边缘说：最近有东西穿过。卷曲尖端说：边界正在减弱。苍白肋条说：膜在脱落材料，可能可用于盐水化学、密封剂砂粒或密度传感器校准。好的峡谷设计应该让玩家靠这些迹象导航，而不是靠箭头：沿完整墙体漂移，找到撕裂入口，观察声纳扭曲，感受潜水服 trim 改变，并明白海洋不是出于恶意挡路。它是在服从压力。这就是为什么盐水叶片林的美比光照大陆架更冷。它不欢迎你。它可以被阅读。

## Scanner

盐水叶片林 // 盐-矿物膜沿密度剪切生长。它们显示水在哪里变厚成墙，也显示声纳会在哪里弯折。

## Terminal

峡谷基线：完整叶片膜标记坚硬密度边界。撕裂边缘和卷曲尖端表示剪切窗口、低盐口袋或近期通行。避开不透明层状水；它会致盲声纳，并把潜水服拖到预期浮力以下。

## Audio

## Field Note

它们不是树。它们是压力的叶子：以化学梯度为食的膜，只在最近有路线硬挤过去的地方撕裂。
