# 海底工厂

海底工厂应该像所有早期线索在物理上汇合的时刻。Blue debt不再只是样本。修复疤痕不再是孤立补丁。盐水阶梯不再只是路线。撤离记录不再只是文书。在海底，所有这些系统喂养着一个仍在工作的身体。它是工厂，因为它处理材料。它是船，因为路线和压力皮肤仍在移动载荷。它是神殿，因为殖民地的旧分类被维护仪式取代，而没有任何人类能安全解释这些仪式。关键在于这个地方没有死。它很忙。它保持门密封，生长膜，回收残骸，保存连续性，并使用海洋送来的一切。对玩家来说，最终下潜不再只是寻找最后一个房间，而是进入一台已经决定人、工具、路线和原料之间差异可以省略的机器。
