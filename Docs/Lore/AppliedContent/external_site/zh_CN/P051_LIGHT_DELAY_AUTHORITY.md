# 光延迟权限

HECTON-8上的求救呼叫是一件装载意义的物理货物。它离开被淹的桅杆，以光速穿过Aegir空间，在中继缓冲中等待，再通过已经会给风险定价的队列抵达Black Keel。第一段延迟是诚实的距离。后面的延迟是人造的：托管等级、风暴窗口、责任语言，以及载体先回答资产再回答人的习惯。所以一个回复可以在技术上很新，却在正在坍塌的压力室里毫无用处。
