# 路线许可戳重叠

路线许可戳有用，正因为它们不戏剧化。它们只是行政残留：某个工人获准通过舱门，某类工作被分配，返程被期待。在沉没殖民地里，这种小痕迹可能比任何官方解释活得更久。

窄读数落在一个接触点：路线戳墨、盐、舱门漆刮痕和packet notary遮盖相遇的位置。如果戳墨在遮盖下，却在暴露盐层上，载体在暴露后经过处理台，然后才被遮盖。这不会揭开隐藏句子。它揭开的是保管链谎言。

Deep Reach受益于把授权和时间顺序混在一起。法律遮盖可以被授权，同时仍然是后来加的。路线戳可以有效，同时指向证据处理而不是房间入口。重叠把这两个事实分开，留下材料顺序，而不是道德演讲。

转录损伤带和packet notary遮盖边缘出现之后，载体不再像一段完整故事。它变成经过手、水、盐、油漆和办公流程叠压过的物体。
