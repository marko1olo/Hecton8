# 盐水密度航路账本

Brine Stairs 介于航路和陷阱之间。远看像建筑：台地、浅色边缘、白色层阶叠入黑暗。近看却是流动的化学。重盐水像第二片海灌在裂缝里，边界会发亮，盐皮会起皱，表面能用石头般自信的回声欺骗 sonar。

所以旧航路板不写“从这里下降”。它写习惯：侧向 ping，两次配平，看温降，看缆线刮痕，等边界扬起的泥尘拒绝混合。好的穿越点不是图上的线，而是在海水撒谎之后仍会重复的行为。

几艘撤离舱被报失于并不存在的海床坐标。最后 ping 来自第三道密度帘下方：驾驶员看见白色台地，向下修正，然后把最后压载余量花在比舱体更重的水里。Deep Reach 写成导航错误，航路板留下了缆线伤痕。

在玩法上，同一规则变成选择。玩家能借盐水层遮音、冷却切割器、回收保存的标签，或不暴露灯光穿过峡谷。坏角度 ping、陈旧压载、破损密封和恐慌下降会把航路变成坑。HECTON-8 有时不需要怪物，只需要海看起来很平。
