# 浅水捕食者阴影规则

浅水捕食者阴影规则是 lore 与遭遇规则，不是物种档案。它的任务是保护光照大陆架的基调：美丽、可读、活着，同时仍能杀死你。捕食者通过见证者抵达。玻璃啃食者留下食物并消失。灯漂 bloom 继续发光，却失去柔软的颗粒 chatter。壳夹礁在缆线上收紧，仿佛整条路线吸了一口气。只有这之后，阴影才穿过光。这一顺序很重要，因为它让海洋显得系统化，而不是戏剧化。玩家不是被凭空出现的怪物惩罚；玩家是被一组本可以学会阅读的迹象压迫。好的实现应叠加音频、视觉和生态提示，让警告能跨越不同显示、语言和无障碍需求：消失的滴答、被切断的 bloom 噪声、宽阔轮廓、错位尾迹、动作失相的路线动物。直接攻击是最不有趣的部分。更强的时刻，是维修目标仍然够得着，水仍然美得惊人，而每一个活体仪器都在说这条路线已经变得昂贵。

## Scanner

浅水捕食者阴影 // 啃食者滴答消失、bloom 噪声撕裂、宽阔移动阴影，就是第一次接触。路线压力先于战斗接触。

## Terminal

接触规则：捕食者证据应先改变路线选择，再强制伤害。按不在场、沉默、轮廓和尾迹分阶段；只有玩家忽视或误读至少两个提示后，才进入直接攻击。

## Audio

当那些小嘴停止滴答时，停止移动。

## Field Note

不要先给捕食者一张脸。让大陆架先变得不对：食物还在，水更亮，小生命离开，然后阴影横过任务。
