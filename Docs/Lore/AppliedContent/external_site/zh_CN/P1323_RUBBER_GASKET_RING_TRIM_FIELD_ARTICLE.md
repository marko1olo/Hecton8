# 橡胶压力舱门密封环

橡胶密封环小到容易被当作细节，这正是它们在 HECTON-8 中有效的原因。毁坏的基地可以失去标志、涂装和整洁建筑，但垫圈仍会说明什么曾经压住什么。它显示舱门咬合的位置，海水爬入的位置，工人过度拧紧夹具的位置，以及后来的打捞者撬开一扇可能仍在工作的门的位置。

关键是压缩记忆。承压橡胶不会像普通装饰那样失效。它会变平、膨胀、撕裂、粉化、被抛光，并根据时间和载荷在不同位置留住盐。光滑的内唇可能说明反复合法启闭。参差外侧咬痕可能说明恐慌进入。沟槽深处的盐意味着长期渗漏。只有表面的盐意味着近期暴露。这些不是氛围痕迹，而是路线事实。

在游戏中，密封环应该让玩家在舱门和窗前放慢速度。黑色环可以是修理材料，可以警告干燥气袋仍然存在，可以提示有人在公开时间线之后打开了模块，也可能是阻止管道插座变成水柱的唯一东西。盲目拿走它是廉价生存。先读懂它，才是 HECTON-8 的生存方式。
