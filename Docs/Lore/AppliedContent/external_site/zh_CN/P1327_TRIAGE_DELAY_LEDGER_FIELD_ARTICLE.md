# 延迟分诊账册

HECTON-8 的医疗舱并不是在灯灭时才失败。它更早就在整齐的行列中失败了。

延迟分诊账册乍看像是仁慈的东西。里面有伤情等级、氧债、稳定备注、转移窗口和见证字段。紧凑的文字让人信任，因为它看起来实用。在压力下，实用确实重要。舱门呻吟、泵线敲击甲板时，医护人员不能写长篇报告。他们需要标记、代码和快速决定。

丑陋的部分从代码服务管理层开始。被压碎的肋骨变成 amber hold。需要撤离的人变成等待路线清理的稳定状态。没电的担架电池变成设备状态未解决。锁住的走廊变成无移动权限，而不是没人来接。每个短语都保持系统干净，同时房间变得更糟。

所以实体医疗舱很重要。账册可以靠省略说谎。床带、氧气架、地面划痕、舱门印章、湿掉的压力胶带和见证哈希会逼它回答。病人真的稳定了吗，还是同一只氧气瓶被重新分配了三次？路线是在受伤前关闭，还是因为伤情会破坏数字才关闭？后来的手是否在水线之上重写了那一行？Marauder 的标记是否还原了账册想变成类别的名字？

对玩家来说，这些账册让伤害可以被阅读，而不是变成廉价煽情。HECTON-8 最强的地方，是证据既有程序性又有私人重量。账册说明系统有一套遗弃人的语言。房间说明谁为这种语言付了代价。
