# Marauder打捞法现场文章

Marauder这个词应该卡在喉咙里。它不是权力幻想标签。它是边疆法律系统发明的一种头衔：系统需要有人去触碰毁坏资产，却不想承认那资产曾经是充满人的工作场所。

            HECTON-8用Marauder让玩家行动保持道德重量。你掠夺，因为氧气、债务和工具让掠夺成为必要。你也记录，因为你偷走的物体可能是唯一能穿过水、压力和公司清洗幸存的证据。好的Marauder并不干净。好的Marauder知道拆空房间和保留房间所证明之事的区别。

            现场文化从这个矛盾中生长。墙面标记、被划掉的标签、工人姓名、压力箭头和难看的速记，在官方法律下面形成第二层法律。它粗鲁，因为礼貌语言已经失败。它迅速，因为隔舱开始呼吸时没人有时间读索赔手册。
