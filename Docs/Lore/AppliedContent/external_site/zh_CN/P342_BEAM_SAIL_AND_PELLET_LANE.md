# 光束帆与颗粒航道

HECTON-8里的高速船不是装着奇迹发动机的小彗星。它们是包着船壳的账单。光束帆从阵列获得功率，而那些阵列在船进入航道很久以前就已经被建造、维护、投保并瞄准。颗粒流以残酷的时序纪律把反应质量扔进路径；太稀，载具会饿死，太密，就会变成霰弹图案。船仍然携带聚变级、护盾冰、散热器、泵，以及决定何时消耗它们的授权，但昂贵的半台发动机在船壳之外。

这种设计扩大了人类空间，却没有把空间变小。Aegir之所以可达，是因为更老的域为加速走廊、公证员、接收站和制动储备付过钱。困在HECTON-8上的身体不能把求救信号变成那条走廊。必须有人拥有捕获窗口，分配热余量，接受检疫监管，并承担把一次快速救援航次变成快速残骸的风险。Black Keel能在这种经济里活下来，因为它购买窗口并出售证据；玩家能活下来，是因为明白距离并不是空白。它已经被排期、抵押，并被别人预先占有。
