# 光束帆与颗粒航道

HECTON-8里的高速船不是装着奇迹引擎的小彗星。它们更像套着船壳的账单。光束帆从阵列取能，而那些阵列在船进入航道很久以前就已经被建造、维护、投保和校准。弹丸流以残酷的时序纪律把反应质量抛进路径：太稀，载具会“挨饿”；太密，它就变成一串霰弹。船仍然携带聚变级、护盾冰、散热器、泵，以及决定何时消耗它们的权限，但引擎昂贵的一半在船体之外。

这种设计把人类空间拉宽了，却没有让它变小。Aegir可达，是因为更老的域已经为加速走廊、公证站、接收站和制动储备付过账。困在HECTON-8上的身体不能把一条求救信息变成那条走廊。必须有人拥有捕获窗口，分配热余量，接受检疫托管，并承担把一次高速salvage航次变成高速碎片的风险。Black Keel能在这种经济里存在，是因为它购买窗口，出售证明。水下的生存从一个认识开始：距离不是空白。它被排程、被抵押，也早已被占用。
