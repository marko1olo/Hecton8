# 焊缝与铆钉列账本

压力壳被设计来隐藏恐慌。面板平滑，紧固件等距，检查标记小而官僚。焊缝打破了这种语言。它局部、丑陋、灼热、具体。它指出系统停止维护、开始被人恳求撑住的位置。

从旧到新读。工厂铆钉成列，是因为海水碰到墙之前载荷已经算好。现场焊道鼓起，是因为人在糟糕通道、糟糕能见度、糟糕时间里下手。铆钉头下的锈说明湿空气穿过接缝。焊道下的盐说明泄漏曾干过又回来。撕裂维修板旁边的螺栓法兰说明船员试图留下未来入口，后来压力变大，他们放弃了这种体面。

最有价值的接缝通常不是最大的，而是打断干净图案的那一道。服务面板上一道难看的焊疤，可能指向封死舱室、遇难者空气袋、隔离机器，或者后来的回收队用更好工具和更少怜悯切开的路线。
