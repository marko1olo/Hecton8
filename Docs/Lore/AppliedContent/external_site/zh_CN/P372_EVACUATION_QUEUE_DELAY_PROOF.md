# 疏散队列延迟记录

被淹的房间仍能保存时间。回收的队列时钟显示残酷顺序：警报、审查、延迟、密封等级超限、进水。Deep Reach的公开措辞把它压缩成突发结构失效中的不完整疏散。房间不同意。它的队列记录在救援路径仍有物理意义的时刻之后，继续保留空白见证字段和待定隔离审查。这并不是说所有人都能被救下。它更准确也更糟：授权一直等到可救人数缩小。玩家找到这条记录时，救援不再像承诺，而像权限系统。
