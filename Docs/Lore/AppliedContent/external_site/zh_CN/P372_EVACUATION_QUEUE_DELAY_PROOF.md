# 疏散队列延迟记录

尸体消失之后，疏散日志很容易被写得温和。Deep Reach 在公开语言里可以说路线未完成、被中断或已退化。回收的队列时钟没有那么柔软。它记录了压力警报进入有人区后，一扇门仍在响应行政状态。
