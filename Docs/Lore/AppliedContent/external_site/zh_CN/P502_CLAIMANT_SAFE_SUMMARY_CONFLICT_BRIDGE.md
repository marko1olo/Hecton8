# 索赔安全摘要冲突

## 记录证明了什么

索赔安全摘要不是缩短后的真相。它是索赔路线中被授权的删节。它可以删除工人姓名、模糊坐标、把伤情细节换成赔付类别、把已扣押改成排队中，或者只列出允许回复公共邮件的办公室。有些删除是在保护仍然活着的班组、医疗隐私或尚未结束的回收路线。另一些删除是在保护 Deep Reach 避开保管问题。摘要和原始物件之间的冲突本身就是证据，因为被删掉的部分也有所有者、时间标记和受益方。

把摘要放在迫使它出现的物件旁边读：标签套、录音带、样本袋、压力门日志、潜服环或托盘照片。保持缺失字段列表可见。问清楚删掉了什么，对应哪个法律风险标记，谁请求删节，以及物件是否能在不编造姓名或坐标的情况下恢复上下文。如果原始物件证明的内容比摘要更多，就保留这个缺口。不要用一句干净的话把它填平。

## 如何阅读

索赔安全摘要冲突
摘要获准公开处理。原始物件没有。
不要凭猜测恢复姓名、坐标或伤情细节。
下一项证据：缺失列表、请求方、法律风险标记、物件路线、保管时间。
行动：在缺失内容有所有者之前，保持摘要和原始物件相连。

## 现场备注

摘要可以保护工人，也可以保护办公桌。物件路线会说明是哪一个。
