# 索赔安全摘要冲突

## 它证明了什么

索赔安全摘要不是中立短版，而是受保护的改写。它可能删除姓名、模糊坐标、把伤情换成类别、软化路线动词，或把接收办公室换成允许公开答复的办公室。这些编辑可能保护人，也可能被Deep Reach用来埋掉筹码。摘要与原始物体的冲突不是设定错误，而是证据: 什么被删除，谁受益，哪个物体能恢复语境。

## 如何阅读

索赔安全摘要冲突
摘要文本适合公开处理。原始物体未必安全。
不要靠猜测恢复受保护姓名或坐标。
保留省略清单、路线证据和索赔风险标记。

## 现场备注

摘要说安全时，先问对谁安全。保留省略清单。
