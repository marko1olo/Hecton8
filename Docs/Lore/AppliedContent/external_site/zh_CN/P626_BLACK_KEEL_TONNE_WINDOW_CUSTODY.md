# Black Keel tonne-window托管

tonne-window这个词听起来像货运数学，直到Marauder一边数呼吸一边读它。Black Keel询问质量，不是因为船员忘记恐惧。它询问，是因为每一公斤离开HECTON-8的东西都会变成托管。身体变成检疫托管。封存驱动器变成证据托管。一箱合金变成salvage托管。一袋Xenon-Omega工艺材料会同时变成债务托管、索赔托管，有时还会变成危险托管。Keelmark在承运船移动前写下这些类别，因为承运船属于一条所有者链，那条链可以承受丢脸，却承受不了未定价payload。所以来自轨道的第一次回答会显得残酷。船可以承认一个信号，仍然拒绝升运。窗口可能装得下证据，却装不下潜水员。它可能装得下潜水员，如果证据被留下。它可能接受能偿付留置权的salvage，而身体等待更干净的检疫行。没人需要发笑，这件事也会疼。痛感来自一个成熟边疆正在做它被建造来做的事：保全承运船，保全索赔，保全纸面轨迹，把人在水里留下来做质量决定。

## Scanner

托管线 // 已接受的tonne-window质量可以是salvage、证据、身体或债务物。听见的数据包不会分配升运优先级；它分配责任。

## Terminal

KEELMARK质量回执 // 窗口给槽位托管权，不给人慈悲。超质量payload会滚入下一趟，除非索赔价值、检疫类别和承运几何同时放行。

## Audio

Black Keel债务音频：我能载证据、金属或你。账本会问哪一个能让船保持偿付。

## Field Note

当承运船说已接受质量，它不是在说已接受的人。账本要求你选择前，把证据绑到潜水服上。
