# 公开索引剧透上限

## 记录证明了什么

公开索引的目的，是让档案可用而不烧掉路线。标题可以命名证据族: 保管路线、证据类别、修订状态、索赔语言、扫描门。这足以让玩家知道自己在追哪种证明，以及为什么另一个数据包重要。

索引不能揭示载荷由谁接收、最终路线落在哪里、载荷状态如何、Atlas会如何处理、它压向哪个结局分支，或会产生什么法律结果。这些意义属于被挣来的证明路径。如果标题暴露接收者线，索引就不再是档案，而是剧透机器。正确的公开承诺很简单: 这只货架存在，最后一页被遮住。

## 如何阅读

公开索引上限印记
显示: 类别标题、保管路线、证据类别、修订状态、扫描门、下一证明目标。
隐藏: 接收链、最终坐标、载荷状态、Atlas后果、结局分支、法律结果。
规则: 显示货架，遮住最后一页。公开索引可以告诉玩家存在什么类型的证据，不能告诉证据在路线终点会做什么。

## 现场备注

类别名比身体走得更远。读货架，但别假装货架就是最后一页。如果最后一页免费，说明有人已经把路线卖了。
