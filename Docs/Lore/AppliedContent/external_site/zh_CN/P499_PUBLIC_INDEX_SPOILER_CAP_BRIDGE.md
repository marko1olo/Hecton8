# 公共索引删节规则

## 记录证明了什么

公共索引行是访问控制记录，不是摘要。它可以显示案卷族、保管线路、证据类型、删节标记、扫描器门槛，以及打开数据包所需的下一个物证。这样足以引导搜索，同时不暴露接收方。

被遮蔽的字段比标题更重要。接收链、最终坐标、载荷状态、Atlas响应、结局压力和法律结果，都应留在删节封印后面，直到路线真正取得它们。如果索引过早打印接收地址，它不是在说明案件；它是在把路线泄给所有盯着镜像的人。

## 如何阅读

公共索引删节戳记
显示: 标题、案卷族、保管线路、证据类型、删节标记、扫描器门槛、下一个物证。
隐藏: 接收链、最终坐标、载荷状态、Atlas响应、结局压力、法律结果。
失败: 保管阈值前显示接收地址。
行动: 保持路线字段封印，直到数据包哈希与物证匹配。

## 现场备注

用索引选择下一个物证。可见类别不是保管、判决，也不是目的地。
