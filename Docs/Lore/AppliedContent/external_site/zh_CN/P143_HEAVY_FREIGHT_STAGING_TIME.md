# 重型货运筹备时间

重型货运筹备是星际物流无需武器就变成暴力的地方。栖居环、反应堆壳、切割爬行机、压力肋或食物储备都太贵，不能被当成随口承诺。它们还没到Aegir，就已经积累了保险人、留置权、承运商、检查员和备用条款。
