# 回收合规诱饵合同种子

回收合规诱饵是合同板上最脏的干净合同之一。案卷披着公共服务的面孔：回收进水的医疗柜，带回死亡潜服的识别件，移除危险机器核心，在腐败或压力损伤毁掉记录前送回封存货物。列出的报酬足够高，在艰难的一周里像是一点仁慈。

陷阱藏在接收链里。回收合规印章可以经过中立打捞办公室、殖民地保险方或灾后清理台面，但最后的读取方常常属于 Deep Reach，或属于向他们出售优先访问权的代理。操作者拿到物资回收的钱，同时被悄悄绑上坐标证明、舱门状态条和保管记录。拒绝交接并不会消除风险。它会把路线标成扣留敏感，让后续安全接收方更没有耐心。

这些合同会奏效，因为绝望会让漂亮文件看起来像庇护。缺少过滤器、电池板或压力胶带的队伍看到一笔干净报酬，往往在读完坐标条款前就接下案卷。等第一只封存箱上船时，合同板已经知道这支队伍还能抵达哪里，也知道废弃区还有什么没来得及埋掉。
