# 储物柜证据变体

HECTON-8 把储物柜当作证据表面，而不是怀旧盒子。一个工人的储物柜可以有压力胶带、磨损密封圈碎片、工具间代币、餐食额度条、路线粉笔、班次贴纸、medlock 拒绝单，以及后来 Marauder 的修正纸条。没有任何单件物品必须解释整场灾难；它们合在一起，让沉没殖民地先像一个有习惯的工作场所，然后才像废墟。

关键是克制。储物柜不该命令玩家悲伤。它应该展示人在手湿、空气有限时做了什么：堵漏、借密封圈、标路、保存被拒的医疗单、留下一次餐食额度，或把工具脏着放回去，因为下一班本该完成工作。这样的细节让程序化房间保有人味，而不用给每个死者做一段独立影片。

回收选择很重要。代币、纸条和小工具有资源价值，但它们的排列有意义。好的 Marauder 会先记录整组物件，再取走。粗心的人只会把一个人变成散件。
