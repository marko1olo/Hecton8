# 索赔窗口救援延迟账本

来自轨道的第一条回复，是HECTON-8最残酷的硬科学之一。Black Keel可以早在取回承包人之前就承认他。无线数据包几乎不带质量就能穿过本地窗口。人不行。这两个事实之间的差，就是游戏的打捞经济所在。

索赔窗口不是救援承诺。它是一个会计槽，允许质量、责任和权力移动。Keelmark Mutual可以保留频道，Aegir Reclamation Pool可以承认保管，Deep Reach可以在回收包有安全上升路径之前就争夺载荷。压力级密封、上升装药、制导时机和检疫握手不是风味设定。它们决定载体接收的是身体、样本、文件，还是无物。

这种延迟让HECTON-8显得被遗弃，却没有让文明消失。文明以文书、信号和价格存在。它能听见。它能威胁。它能给幸存者标价。但没有硬件和接收方，它无法把关切变成向上的运动。

对玩家来说，这本账本改变了逃离的意义。目标不只是呼救。帮助已经用系统唯一信任的语言回答了。玩家必须让返还在物理上可行，并在法律上变得难以拒绝。
