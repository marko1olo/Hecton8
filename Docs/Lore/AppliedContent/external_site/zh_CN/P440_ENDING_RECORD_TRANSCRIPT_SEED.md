# 结局记录转录

## 写成Custody的结束

HECTON-8的结局不该给玩家干净的赦免。记录会说receiver、payload hash、债务状态和生存状态，因为机构记这些字段比记人更牢。这种冷是有用的。它让每个outcome可比较，却不把真相变成奖杯。

未解决字段最重要。Suppression flag unknown. Truth custody unresolved. Atlas continuity unclear. Public ledger status pending. 这些空缺让结局诚实：有东西离开了海洋，但拥有不等于正义，活下来也不等于修复。

转录格式也保护replay。玩家可以带着知识回来，但下一次run不应继承力量。它继承的是怀疑、品味和恐惧。记录是收据，不是宽恕。
