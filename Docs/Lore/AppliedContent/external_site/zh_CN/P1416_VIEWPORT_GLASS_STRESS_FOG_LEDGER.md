# 观察窗应力雾账本

观察窗是淹没殖民地里最残酷的物件之一。它被建造出来，是为了让海可见，却不让海成为房间的一部分。殖民地失败后，它仍在完成一半工作。你能看穿它，但这不等于安全。

HECTON-8的观察窗读取从边缘开始。玻璃中心会骗人，因为人清洁它，摄像头盯着它，玩家也自然相信自己能看见的东西。边缘没有那么爱面子。乳白弧线表示层间在压力下弯曲。密封圈下的盐雾表示水迁移到了不该去的地方。夹层里的冷凝说明干燥侧在坍塌前长期吸入湿气。

好的读取会改变行为。玩家可以识别干燥口袋，选择低应力切线，保留玻璃作为缓慢失效的证据，或避开已经变成压力弹簧的房间。这里的玻璃不是单纯资源，而是见证物。
