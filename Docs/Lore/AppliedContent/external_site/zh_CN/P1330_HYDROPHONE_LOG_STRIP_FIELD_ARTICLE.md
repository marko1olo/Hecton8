# 水听器日志带

水听器带是HECTON-8最有用的证据物之一，因为它让声音变成物理。

        它是一条穿过旧房间记录器的窄陶瓷纤维带。记录器听的是压力舱，不是某个人。它捕捉泵节奏、舱口撞击、缆线断裂、工具敲击、船壳受力，以及穿过水和金属后被抹开的声音形状。带能幸存，是因为它简单。它不需要活着的网络、干净终端或配合的公司档案。它只需要压力、墨和运动。

        对玩家来说，带应当像法证物一样被读取。音频可以诡异，但证据在错位里：授权前的门撞击、声称停机后的泵音、所有记录器同时变平的缺失秒、无人签署的路线印章旁边出现的声音形状。这不是独白。是房间在反驳自己的文件。

        HECTON-8需要这种语气：通过工作表面找回人的存在。带不会命令玩家该感受什么。它让玩家听到一个地方在上面的人决定纸张比里面的人更重要之后，仍然试图完成自己的工作。
