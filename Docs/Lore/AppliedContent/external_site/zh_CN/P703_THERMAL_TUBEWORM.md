# 热泉管虫

HECTON-8的热泉场勘测报告了密集的成管群落，它们仅限于大约4,000至5,500米之间的活动喷出流。群落会在可测流量变化前数秒一起缩回，作业队把这一行为当作热脉冲预警使用。

记录在案的危险是仪器。喷口化学会干扰低成本电化学氧电池，在条件恶化的同时把溶解氧与服装储备的显示值推高，而这个误差平滑得不会表现为故障。44区的Deep Reach样品批次记录了从群落基部回收内生节点，并把宿主列为不需要。
