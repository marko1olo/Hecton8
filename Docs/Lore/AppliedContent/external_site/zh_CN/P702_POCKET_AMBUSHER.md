# 洞口伏击者

Aegir的打捞队描述了一种重体伏击摄食种，它占据淹没工业结构中的切割开口，而不是天然空腔。报告的打击距离超过可见体长，因此用目视估算安全间距并不可靠。

HECTON-8上的现场做法是读开口周围的淤泥圈，而不是试图看清那只动物。44区的Deep Reach记录把该物种列为附带的出入管制资产，这个类别描述了一条被封闭的走廊，却没有描述走廊为什么封闭。
