# 潜服储备差值不匹配

在Aegir，房间支持和潜服储备本该一起移动。房间供气，潜服缓冲损耗，压缩机写下交接，路线板等待返程标记。当这些数字分裂时，殖民地的纸面地图就不再匹配身体路径。
