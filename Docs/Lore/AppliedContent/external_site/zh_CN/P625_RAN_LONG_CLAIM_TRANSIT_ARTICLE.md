# Ran长期索赔航渡

每张Aegir航路图都以安慰和羞辱开头。安慰是HECTON-8并不在人类之外。到2190年，Sol、Centauri、Barnard、Tau Ceti、Luyten和Aegir索赔办公室共享了足够的时钟、法律模板和数据包基础设施，可以在恒星之间移动人、质量和责任。羞辱是尺度。地图背后没有超光速救援开关。数据包以光、中继和耐心纠错穿过空隙。人作为货物穿过：热量、氧气、文件、推进剂和风险。Ran Long Claim让Aegir看起来很近，因为最早的公开图是给会计画的。它们衡量索赔连续性，不衡量人的等待。回收承运船还离beam-lane交接有数月时，航路就可能已经认证。尸袋离开卫星前，法院就可能受理死亡争议。维修无人机可以继续给本地工单盖章，因为下一份权限数据包还没爬完梯子。Black Keel就在这个系统里。它是索赔艇也是salvage承运船，有债务柜、托管封印、备用人手和一只塞满坏窗口的时钟。它回答你，因为回答时间便宜。只有当质量、法律暴露和承运几何对齐时，它才移动。这种差别是Aegir salvage的第一堂硬课。边疆成熟到足以拥有你、给你开账单、把你归档。它还不密集到能迅速救你。对HECTON-8上的Marauder来说，Ran Long Claim与其说是回家的路，不如说是证明家也有队列，而队列已经知道你的吨位。
