# 透光生物膜基线

透光生物膜基线把HECTON-8的美丽变成实际规则。生物膜不是布景，而是让早期陆架可读的活仪表：颜色代表氧气交换，边缘硬度代表压力化学，气泡节律代表水流运动，声学质感代表隐藏接缝。因此最早的亮岩既应该吸引人，也应该让人警惕。被困的Marauder可以从膜边取得纤维、密封膏前体或应急氧气读数，但每一刀都会改变这个水囊。最安全的采集点是远离金属、舱口接缝和旧Deep Reach管线的松散边缘。最糟糕的采集点是漂亮中心，因为那通常是最努力工作的部分。好的摆放不需要讲课：健康膜在干净石头上发亮；受压膜在压力漏点周围长出白色盐边；中毒膜过于平滑，在工具下声音不对。浅层陆架保持明亮，是因为生命在那里工作。它保持紧张，是因为玩家一次贪心刮取就能毁掉这种工作。

## Scanner

透光生物膜 // 覆在浅层岩石上的矿物供养活膜。明亮条带给水增氧；盐化硬边标出受压化学和隐藏接缝漏点。

## Terminal

生态基线：记录氧气皮层、矿物流、声学阻尼和盐边压力。只采松散边缘。在接缝或密封设备附近撕开生物膜，会让氧气囊塌成污染。

## Field Note

不要先刮最亮的地方。先读边缘、气泡和声音；它先是仪表，才是资源。
