# 深渊机器场修复门

深渊机器场把恐惧变成程序。导电膜、声学器官和服务盆地不是装饰。它们是操作员必须在压力、断电和受污染所有权表中路由的组件。

这一阶段成立，是因为每次修复都有用，并且在法律上肮脏。活桥可以恢复一扇门。同一座桥也能让门变成生物类别，让修复成为 Atlas 事件，并让索赔分类更难。向前的路由那些让文书更糟的东西构成。
