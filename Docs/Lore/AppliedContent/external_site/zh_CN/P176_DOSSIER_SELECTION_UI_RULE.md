# 档案索赔登记

DR-902 把档案选择变成索赔记录。它保留知识、传闻和法律压力，同时把生存装备和世界事实留在文件外。

## Scanner

DR-902 索赔登记。激活档案显示传闻族、结局记录、留置压力、托管条款、轨道/天气条款和证据顺序提示。不继承装备。
