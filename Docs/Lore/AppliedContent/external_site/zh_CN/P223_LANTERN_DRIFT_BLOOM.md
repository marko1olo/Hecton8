# 灯漂 bloom

灯漂 bloom 是 HECTON-8 用来说明“明亮不等于安全”的方式。bloom 不是装饰性的雾层。它是一块由活细胞、水流、振动和食欲组成的移动仪表板。在安静水体中，它比手电更会描出浅层大陆架：涡流边缘发亮，缆线环像破碎光晕一样显现，pressure glass 碎片投出细蓝切口，安全水道甚至会像星河。陷阱在于，同一片光也会记录扰动。启动切割器、让泵咳一下、过度 ping 声纳，或在恐慌中踢动推进器，bloom 就会把你的位置向外传开。啃食者的滴答声变稀。滤食者转向。更大的东西可能在 UI 来得及命名前沿着发光尾迹追过来。这篇条目的作用，是防止 HECTON-8 的美变成墙纸。好的遭遇设计应该让玩家想要光、使用光，然后害怕光暴露了自己。bloom 走廊可以是穿过礁体最清晰的路，同时也是修理吵闹阀门最糟的地方。它应该与玻璃啃食者和捕食者阴影并列，因为三者都教同一条规则：海洋可以被阅读，而海洋也在阅读你。
