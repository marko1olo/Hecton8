# 盐与矿物沉积记忆账

殖民地曾努力保持表面清洁，因为清洁看起来像控制。盐拒绝这个谎言。擦掉后它会回来，从垫圈边缘爬出，聚在螺丝口袋里，在水停留足够久的地方画出苍白边界。

矿物沉积有语法。下接缝上的盐花说明迁移。向下的钙质指痕说明排水。螺栓周围的环说明金属在压力下呼吸。新油下的粉末说明水先到。只在一侧破裂的盐壳说明面板弯曲，而不一定是被踢坏。

打捞队会很快学会尊重这种证据。盐会指出哪条走廊先淹、哪扇舱门不能信、哪个洞穴口袋藏着盐水，以及哪份“单次破裂”报告其实掩盖了一场压力、金属与疏忽之间的长谈。
