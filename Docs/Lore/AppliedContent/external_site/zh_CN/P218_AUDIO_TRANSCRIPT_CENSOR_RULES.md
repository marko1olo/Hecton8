# 音频转写损伤带

HECTON-8的语音日志不是有声音就算完整。转写必须展示自己的伤口。

损伤带让这些伤口变得诚实。它可以标记静噪、丢包、法律删改、压力失真、说话者分离失败、机器翻译失败或后期编辑。没有这一层，每段破损录音都会变成虚假的清晰或虚假的神秘。有了它，玩家能看出哪些是世界丢失的，哪些是有人选择删除的。

规则严格，因为游戏依靠证据。损伤可以隐藏姓名、编号和剧透货物。它可以制造怀疑。它可以让路线在玩家看到舱门之前就显得危险。但剩余转写仍然必须携带行动：不要打开气闸，从服务梯返回，手动计氧，忽略绿色状态灯，保留官方行可见。

对于本地化和无障碍，损伤带是内容的一部分，不是事后注释。翻译后的转写必须保留说话者职责、时间压力和可读警告。删改只有在玩家仍能行动时才是气氛。否则它只是一个假装成设定的坏界面。
