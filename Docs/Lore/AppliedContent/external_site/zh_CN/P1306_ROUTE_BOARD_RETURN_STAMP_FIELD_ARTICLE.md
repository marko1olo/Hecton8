# 路线板与返回戳现场文章

路线板是 lore 与玩法之间很强的桥，因为它让普通工作变得可读。舱门板上有四个名字、两个工具标签、一个糟糕的潮汐窗口，以及一个从未落下的返回戳，玩家就不需要关于殖民地人手的讲课。这个物件同时讲出时间、工作、危险和责任。

好的板面证据应该有手摸过的感觉。油笔应当划过旧盐。戳印应当歪几毫米，因为用它的手疲惫、潮湿或害怕。名字应当被移动，而不是被擦掉。这些细节让殖民地保持人性，不必给每具尸体编一个家庭支线。工人是在压力下工作的专业人员，不是装饰性的受害者。

在设计上，路线板支撑可重复内容。同一套板面语言可以指向补给、危险、锁住的舱门、丢失的工具、音频碎片或程序化房间变体。在故事上，它暴露 Deep Reach 把人的缺席转换为受管理状态的习惯。当玩家意识到殖民地在死亡前并没有停止工作，而是继续把死亡归档为工作时，HECTON-8 会更可怕。
