# 有光层石灰岩碎屑台地

有光层台地位于光仍有权威的深度。这里的海不够黑，不能把一切藏起；也不够温柔，不会原谅粗心的脚步。石灰岩板由古老生物钙、贝壳砂和矿物胶结形成。上方碎屑是一份混合记录：自然破裂、殖民开采、风暴冲击、车辆痕迹，以及把裂缝变成庇护的小型生物。

有用的读取总是局部的。缝中的砂说明水仍在整理底面。台阶上的苍白粉尘说明新破裂。孔隙中的橄榄色说明受保护的稳定。干净圆形擦痕可能是工具脚、锚板或旧采石夹具。如果玩家只看见亮度，它像安全教学区。如果玩家阅读表面，它就是第一张诚实地图。
