# 淹没地壳层指南

HECTON-8的地壳不像未触碰过的海床。殖民地切开它、加热它、密封它、用压力玻璃给它加载，然后把它丢给海洋。工资停了以后，海还继续工作。同一面墙上可能同时有服务钻孔的工具痕、冰塌留下的浅色台阶、渗流造成的绿黑矿物带，以及Atlas后来找到路径的发丝状接缝。

对salvage队伍来说，地层就是导航。平整表面可能敲起来是空的。漂亮的矿物边缘可能是服务峡谷唯一还在承重的部分。好的路线阅读意味着取走样本，却不教会墙壁如何坍塌。这就是淹没地壳在现场如此重要的原因：海床不是背景。它是档案、道路，有时也是陷阱。
