# HECTON-8公开入门

HECTON-8 不是以死废墟的姿态登场。它首先是一个值得跨越星际距离的地方：明亮的透光陆棚、坚硬的蓝色海水、耐压殖民地骨架，以及能透过活海看见旧机器的清浅水域。第一个承诺是美。第一个威胁是，这种美已经被定价。

可玩前提从承受合同压力的 Marauder 开始，不是游客、天选继承人或家族复仇者。你下降，是因为债务、blacklist 风险和 Aegir salvage 法让这份工作既可能又危险。Drop 出错。海洋不在乎合同是否公平。最初几小时是实际生存：庇护、泵、密封、氧气、工具和信号。故事通过仍有主人的物体进入。

这就是 HECTON-8 的公开面貌：带有工业记忆的海洋生存。Deep Reach 在这里建造压力路线和工人栖居地。Black Keel 能从轨道回应，却不能抹去距离、天气和托管法律。这颗月球足够美，足以让损失有重量；也足够有记录，足以让每个回收标记成为证据。
