# Aegir卫星阶梯

Aegir卫星阶梯让可游玩的月球成为运动系统的一部分。其他卫星塑造潮汐、carrier等待、relay阴影和离开的代价。

## Scanner

卫星序列：Cinder、Hook、Glass、Switch、Drywell、Brinehook、Rake、HECTON-8、Pale、Longmark、Grave、Farline。

## Terminal
