# Aegir 回收窗口几何

Aegir 的回收首先是时间表，其次才是救援。Black Keel 可以在狭窄中继通行中听到数据包，却仍然拒绝回收身体，因为航线尚未通过航母相位、风暴顶限、Kestrel 中继阴影、隔离状态、上升包封签和已接受 tonne-window 质量。HECTON-8 让这种延迟变成物理事实。海洋把降落硬件压在深压之下，天空用天气和带电噪声打断直线视距，而航母把每一公斤都记入索赔账本。来自轨道的第一次回应因此不是仁慈。它只是证明机器的一部分在几分钟内对齐。活下去意味着在下一个窗口关闭前，让机器的其余部分也同意。

## Scanner

窗口时钟 // Black Keel 本轮可接收数据包。人员回收仍需上升硬件、隔离握手、Kestrel 中继阴影放行，以及已接受的 tonne-window 质量行。

## Terminal

KEELMARK 回收通知 // 信号已收不等于批准升运。请求回收前，必须对齐航母相位、风暴顶限、中继阴影、隔离许可、上升包状态和已接受载荷质量。

## Audio

Black Keel 中继：数据包已接收。身体不在本窗口内。保持上升包封存，保持证据带标签，不要为一个数字浪费空气庆祝。

## Field Note

航母回应了也别把空气花在庆祝上。回应是几何加账目。窗口、封签、载荷和身体进入同一条线时，救援才开始。
