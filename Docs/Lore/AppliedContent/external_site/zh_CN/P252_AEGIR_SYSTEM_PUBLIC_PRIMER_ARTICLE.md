# Aegir系统公开入门

Aegir 重要，是因为它让天空变得实际。HECTON-8 周围的系统不是装饰性星图，而是由卫星、窗口、辐射天气、中继阴影、冰散射危险和 carrier 转移几何组成的机器。消息可以在狭窄信号窗口离开，而身体仍无法回收。样本可能很有价值，却错过检疫时机。Black Keel 可以在系统内存在，却不是惊恐潜水员想要的那种头顶救援。

这就是 HECTON-8 保持硬科幻而不变成作业的方式。玩家不需要轨道力学讲座也能感到 Aegir。信号通过而 lift 不通过时，风暴噪声污染中继时，月影把安全 uplink 变成死 slot 时，潮汐窗口决定峡谷路线是否可生存时，他们就感到了。

Aegir 也让边疆不是空的。其他卫星承担中继角色、冷索赔、死信标、交通伤痕和检疫压力。HECTON-8 是可玩的危机，不是整个系统。更大的月梯让救援昂贵、salvage 合法、证据延迟，也让每个返回窗口都像是挣来的。
