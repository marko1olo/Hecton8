# Keelmark 吨窗口

## 记录证明了什么

Keelmark 一开始把操作员当成质量问题：在氧气、福利、样本保管和证据载荷调整前，基础值是 4.8 tonne-window 等价。

tonne-window 是 Black Keel 在一次轨道机会里可能升举的可回收质量，前提是燃料、风暴、隔离、保险和优先级都已定价。Keelmark Mutual 先把玩家变成可读的质量，然后才把他看成人。每个保住的样本、证据包、氧气债和福利条款都会移动数字。

KEELMARK MUTUAL 窗口账本 // 基础留置：4.8 tonne-window 等价。调整可包括氧气风险、福利附录、样本保管、证据载荷、隔离扣留和 carrier 升举分配。这个账本给回收定价，不承诺救援。

## 玩家该怎样读它

不要只把 4.8 读成钱。它是你下一次机会的重量。 把它当成处理证据的规则，不要当成救援已经出发的承诺。
