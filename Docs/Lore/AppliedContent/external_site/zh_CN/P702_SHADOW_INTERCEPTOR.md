# 暗影拦截者

Aegir的深水转移作业队报告了一种捕食者，它不是从后面跟踪，而是向潜水员的推算位置合拢，并在接触前的几秒内停止返回声呐接触。

HECTON-8目前的现场做法把开阔横渡中的接触丢失本身当作警告，并要求更换目的地而不是提高速度。2147年Deep Reach一起涉及三名人员的转移损失记录中，损失原因写为路线选择。
