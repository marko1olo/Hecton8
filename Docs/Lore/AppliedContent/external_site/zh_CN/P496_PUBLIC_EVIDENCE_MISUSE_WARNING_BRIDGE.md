# 公开证据滥用警告

## 记录证明了什么

公开账本不是救援信号，而是一套定价机制。当Tau Ceti数据包带着修订头、说明链、证人哈希和Luyten公证标记进入公开镜像时，Deep Reach就不能廉价地假装那个房间不存在。Aegir的壳办公室也不能不处理每一处随附矛盾，就出售干净时间线。

危险在于，同一个数据包也会变成目录。中介用姓名和身体痕迹给赏金定价。保险方用时间戳拖延付款。索赔办公室会赶在援助者之前找到家属。清理队按说明顺序判断哪名证人还能被恐吓、收买或抹掉。公开改变的是筹码，不会自动保护记录里的人。

## 如何阅读

公开传输警告 TL-2190-AEGIR-77
必需附件: 修订头、说明链、证人哈希、Luyten公证标记、原始路线牌。
效果: 否认变得昂贵。
副作用: 赏金中介、保险方、索赔清理队和市场席位拿到同一张地图。
不要为了省带宽去掉说明。没有说明的图像，只是挂着受害者的传闻。

## 现场备注

账本漂亮，但不是盾。把说明和血迹、时间、路线牌、身体标记放在一起。为了方便携带而拆开证据，也会让它更方便出售。
