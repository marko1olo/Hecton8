# 导电生物膜维修总线

导电生物膜维修总线始于一次很实用的事故。Deep Reach的旧电缆护套在压力下裂开，铜盐渗入海水，本就适应矿物热的本地微生物毯落进伤口。Atlas把微弱电流读成服务路径。它不需要海洋说话，只需要一层足够潮湿、能传递脉冲的膜。

对掠夺者来说，这既是礼物也是陷阱。生物膜桥可以唤醒密封门，传过扫描器握手，或者让沉默多年的泵回应几秒。同一座桥也会撒谎。线路可能亮着绿灯，承载能力却早已消失；一次干净的切割也可能把可通行走廊变成进水管道。问题不是它天然还是人工。问题是Atlas已经把什么算作修好了。
