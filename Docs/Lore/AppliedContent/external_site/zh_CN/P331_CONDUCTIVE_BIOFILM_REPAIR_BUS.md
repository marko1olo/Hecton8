# 导电生物膜维修总线

被导电生物膜包住的电缆既有用也不安全。生长物减缓腐蚀，传过弱ping，并给Atlas一条廉价维修路径。它也会把断裂导体藏过只检查导通的系统。

## Scanner

绿黑色薄膜桥接了裂开的电缆护套。低电流从湿润生长物回流；导通读数不可靠。

## Terminal

ATLAS维护痕迹 / LINE K-44：铜线外露、盐性生长、低热泄漏。生物膜桥减缓腐蚀并返回虚假导通脉冲。不得通过此线转接泵控制。

## Audio

信标音穿过黏膜。电也穿过。别把它叫维修。

## Field Note

如果死面板通过绿色薄膜醒来，把路线标成临时。工具碰护套前先断电。
