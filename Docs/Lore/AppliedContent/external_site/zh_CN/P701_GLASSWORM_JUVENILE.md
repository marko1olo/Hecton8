# 玻璃虫，幼体

HECTON-8的打捞报告描述了一种群体性成管幼体，它把微量级导通基材直接积附在殖民地结构的裂缝上，生长密度跟随穿过裂缝的流量。管口方向一致朝向流入端，因此渗漏轴线可以从群落外侧读出。

这类生长掩盖压力泄漏，而不是消除它。作业队报告在看起来没有活性的群落处发生了手套和密封件破损，以及切开受载片区时管子依次破裂。44区的Deep Reach记录把该生物归为有机结构密封材，把对应的压力偏差记为已缓解，并且没有该物种成体的参照记录。
