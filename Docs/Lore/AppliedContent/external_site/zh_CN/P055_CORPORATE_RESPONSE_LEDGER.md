# 公司响应账本

公司响应账本不是反派演讲。它更冷。它是机器可读的承诺，表示Black Keel会响应，但只在合同认可的顺序内响应。资产托管第一。责任封印第二。船体审计、样本路线、付款路线，然后如果队列仍允许，才是操作员回收。玩家可以把这些账本当作线索、钥匙和杠杆，因为系统可预测。而这种可预测性就是控诉：HECTON-8不是被一个坏决定抛弃的，而是被一套在人员降为低优先级货物时仍继续运转的响应栈抛弃的。
