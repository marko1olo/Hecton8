# 索赔程序语言审计

## 记录携带了什么

Deep Reach的文书可以不删除记录，却把记录埋掉。它保留舱室、标签、时间戳和尸体数量，然后替换旁边的名词。在Tau镜像缓存中，进水时间03:18后仍标记为占用的泵房B，被归档为释放窗口偏差。从控制侧上锁的分诊门2，被归档为隔离复核。防护服环在打捞质量中、工人标签R-17却缺失，被归档为Keelmark暴露。归还托盘上四个工具包挂钩为空，被归档为部分货物资格。

从地面向上读记录：舱室、闩锁、标签、时钟、归还物数量。索赔程序语言只有能钉在物理证迹上时才是证据。如果文件保留类别却丢掉工人，办公室已经把路线清洗过一次。
