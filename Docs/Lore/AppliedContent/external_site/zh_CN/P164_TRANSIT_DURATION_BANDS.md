# 运输持续时间带

## 不同的时钟

同一条航路不代表同一段时间。probe packet 可以早早出发，燃烧光年，在任何 crew 看见海水前几十年成为 claim。heavy freight 需要 staged launches、braking rights、pellet lanes、radiators，以及接受损失曲线的保险。human crew 需要这一切，还需要 life support、liability language 和支付 return mass 的理由。

HECTON-8 正是用这些错开的时钟困住玩家。distress hash 可以有效却无用。货运机会可以开启，而救援仍然关闭。公共后果可能在多年之外，却仍值得保护。恐怖不在于航路坏了。恐怖在于航路对除求救身体之外的一切都正常工作。
