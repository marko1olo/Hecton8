# 颗粒尾迹制动账本

HECTON-8之所以孤立，是因为旅行有重量。Aegir航线始于颗粒束侦察器：从Luyten Junction推出的小型自主探测器，被预期以有用的方式死去。它们携带地图、恒星定位和法律见证数据包。损失一台探测器只是成本行。损失一艘殖民船就是一代债务。

Atlas货运时代移动的是真实质量。运载船带着工厂核心、冷冻舱、钻探系统、航线接收器、封存合同，以及足够便宜而愿意签字的人越过航线。它的聚变电力堆用多年建立速度。那套架构里没有奇迹。每次修正都烧掉库存。每块护盾板都是赌注。每一公斤到达时都带着一个绑到账本上的名字。

制动账本是残酷的一页。近光运载船必须重新变慢，才能交付任何东西。磁帆以不可能的跨度展开，拉拽带电粒子。颗粒航道咬住帆缘。最后的通道把大气、风暴包层和气态巨行星重力当作刹车。余量错了，飞船就活在无用之处。余量切得太薄，航线收到的是羽流，不是货物。

所以HECTON-8里的救援可以在不破坏物理的前提下显得丑陋。Sol可能在决定过期后才回应。Deep Reach可以比移动船体更快继承债务。Black Keel可以坐在本地轨道上出售回收窗口，因为它已经是Aegir机器的一部分。幸存者并不在文明之外。他处在文明抵达的顺序里：文书、信号，然后才是质量。
