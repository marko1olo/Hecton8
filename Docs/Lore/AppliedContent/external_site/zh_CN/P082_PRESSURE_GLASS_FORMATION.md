# 压力玻璃形成

压力玻璃是Marauder所说blue debt和Deep Reach的Xenon-Omega语言背后的技术名称。它在压力、惰性气体囊、卤水、矿物、热和改造生物相遇处形成。

压力玻璃形成把Xenon-Omega变成硬科幻材料生态，而不是魔法矿石。它连接Atlas、封存和计算。 这不是矿石。它是会记住生成地点的过程。
