# 压力玻璃形成

压力玻璃是掠夺者蓝债和Deep Reach的Xenon-Omega语言背后的现场名称。只有在惰性气体囊、矿物缺陷、热盐水、改造生物和暴烈压力历史长期共处，足以把晶格锁进记忆时，它才会形成。
