# payload 公共总账接收协议

公共总账通道是最不私人、也最不服从的接收方。它拒绝坐标出售、直接回收索赔和干净付款收据。它接收的是没有路线地图的事故包：attestation hashes、责任链、Atlas 权重摘要和接收方时间戳。

延迟很重要。包不会召来即时救援或即时审判。它会沿着一条缓慢通道移动，这条通道被设计成能承受禁令、接收方争端和保管压力。接收后，携带者无法拉回它。失去控制，就是让证据更难被购买的代价。
