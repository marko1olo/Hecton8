# 支持负载结转例外

carry-forward 听起来无害，直到它被放在金属旁边读。它是给丑陋转移起的整齐词：把无法在这里解决的负载拿走，移到下一笔账，让路线活到另一个桌面接手问题。

在 HECTON-8 上，这个词坐在 maintenance 和 claims 之间。本地生命维持可以失效，房间仍可能保持在服务保管下。工人可以缺席，路线仍可能保持激活。潜服可以是空的，例外条仍能让支持级别保持开放。

材料细节很重要。在服务舱里被拿过的条，不会像后来录入的行那样老化。油脂会断。墨会洇。盐会标出折边。迟来的 carry-forward 勾往往干净地跨过它本该共同经历的损伤。那个小小干净标记，就是行政开始跑赢机器的位置。

这份记录应在压缩机交接回填之后阅读。泵和继电器显示空气是否移动。结转例外显示谁在负载不再可呼吸后仍把它保持为有用状态。
