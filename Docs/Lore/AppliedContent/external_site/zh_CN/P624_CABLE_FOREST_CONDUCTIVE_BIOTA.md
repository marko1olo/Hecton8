# 电缆森林导电生物群

在电缆森林里，HECTON-8不再把生物和基础设施分开。死去的中继主干、撕裂的绝缘层、渗出的盐水，以及耐心的殖民藻类，为本地生命提供了富含铜、陶瓷尘和电流记忆的脚手架。电缆海带最初像污迹一样进入，随后变成丝线，最后成为湿润的编织导体。静电灌丛学会在维护脉冲通过线路时僵硬起来。灯草生长在泄漏附近，用闪光回应压力波，而不是语言；但那节奏足以让疲惫的潜水者回头再看一眼。对掠夺者来说，这种生态是一张带牙的资源图。接地切割可以得到导电纤维、灯草酶和一点有用电荷。粗心切割会把安静的主干变成投诉：假的维护脉冲、旧撤离音、湿组织里重复的通道碎片，还有赶来维修一条已不只属于金属的线路的无人机。这片森林并不邪恶，也不是奇迹。它是这颗卫星在使用殖民地留下的东西，而被遗弃的殖民地会根据先醒来的协议，把生命误读成损坏或修理。

## Scanner
