# 岸掠鱼

Aegir的陆架作业队报告，HECTON-8上有一种快速的表层觅食种，停留在上层八米内，沿风力聚集的涌浪拉成一条不断的线觅食。这条线在表层氧气下降的水域周围断开，因此它的断口在远距离上就能读出。

现场做法是读断开处而不是读鱼群，并把线上的断口当作不可呼吸的水，而不是开阔水。44区的Deep Reach记录把该物种列为表层状态指示物，并注明它所替代的陆架浮标服务已于2146年暂停。
