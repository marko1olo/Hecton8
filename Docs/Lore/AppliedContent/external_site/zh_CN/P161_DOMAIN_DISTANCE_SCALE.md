# 域距尺度

## 作为压力的距离

Marauder 使用的域图不是为了惊叹而画，而是为了计费而画。Sol、Centauri、Barnard、Tau Ceti、Luyten 和 Ran/Aegir 被写成航路带，因为它们触碰洪水月球中工人的方式正是如此：认证、宪章话术、打捞劳工、公共证据、数据包 custody，以及边境的肮脏执行。

Sol Core 在物理上很远，却仍然危险。它可以拥有碰不到的资产，承保永远闻不到的损失，并在与 claim 相连的人耗尽 scrubber time 时接受该 claim。Centauri 重要，是因为早期 extrasolar 合法性给新的滥用披上旧词。Barnard 重要，是因为玩家来自一种把死亡 claim 当工作而非传说的文化。

Tau Ceti 和 Luyten 是地图中段的冷硬部分。Tau Ceti 能让证据响到足以伤害公司，但必须等光和 custody 允许证据抵达。Luyten 能让数据包保持诚实，却不关心发送者是否还活着。Ran/Aegir 是这套系统的远端：法律、货物和证据都能在场，救援却依旧贵到不现实。

这让 HECTON-8 不靠魔法也足够坚硬。玩家不是因为人类太小而被抛弃。玩家被抛弃，是因为人类空间以错误的方式太大。所有权比怜悯更快穿过黑暗。一份盖章的权利可以先于会呼吸的 crew 到达 Aegir，并在抵达后开始计息。
