# 玛拉·文恩潮汐模型

玛拉·文恩写的不是预言。她写的是带误差棒、疏散余量和糟糕时间点的模型。在Aegir春季几何下，cryosphere shear可能超过可用升运能力。殖民地行动不需要完美确定性。它需要有人把曲线尾部当成人，而不是成本。

Deep Reach保留了模型，却削弱了反应。警告变成monitor，疏散余量变成未来预算问题，后来的公开记录称洪水不可读。玩家应当从文件形状里感到谎言：潮汐是自然的，但灾难经过编辑。
