# 壳夹礁

壳夹礁是 HECTON-8 明亮生态和后期机械恐怖之间的视觉桥梁。重点不是海洋憎恨人类硬件。重点更糟，也更有用：海洋已经学会围绕它生长。夹壳会在水流、矿物渗流和振动让硬边变得有利可图的地方定居，因此缆线外套、逃生舱接缝和玄武岩边唇都能变成同一种栖息地。这让浅层大陆架有了触感，而不只是装饰。玩家应该看见披着生命的螺栓、变成礁肋的缆线路径、被白色夹壳结壳的 pressure glass 接缝，并理解不是所有生长都是污染。有些生长正在承重。这个想法提前为 Atlas 修复逻辑付款，不需要魔法。Atlas 后来滥用了礁体已经证明的习性：本地生物可以把人类机械当成结构。好的放置应该让采集成为决策，而不是按键。死去的边缘提供壳砂、密封膏质感和早期材料信心。礁体活着的核心可能正在固定路线标记，或封住泄漏。盲目移除它，海洋不会讲道理惩罚玩家；缆线开始移动，接缝开始渗水，啃食者群退走，路线改变。

## Scanner

壳夹礁 // 本地夹壳会抓住岩石、缆线外套、逃生舱外板和 pressure glass 接缝。礁体已经把机械当成基质。

## Terminal

礁体基线：磨损缆线外套、温热接缝金属、带矿物渗流的 pressure glass 边缘会提高附着。只采集死去的外层壳。切割服务线附近的活夹壳可能打开渗漏，或吸引修复动物群注意。

## Audio

## Field Note

不要撬下第一个够得到的夹壳。活体集群可能正在固定缆线、封住发丝般的渗漏，或标记路线锚点。
