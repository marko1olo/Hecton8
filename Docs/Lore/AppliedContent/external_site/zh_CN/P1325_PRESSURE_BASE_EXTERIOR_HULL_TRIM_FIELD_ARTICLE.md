# 压力基地外部船壳饰条

压力基地外部被设计成从远处看起来平静。这既是谎言的一部分，也是工程的一部分。平滑浅色面板让模块在脏水中仍可辨认。深色肋显示外壳预期受力的位置。密封槽标出一间房承诺不淹没下一间房的位置。小型下沉唇标出工人在戴着手套、疲惫并对手册愤怒时仍能用工具触及的地方。

有用的信息在这些特征的顺序里。无视面板缝的肋是结构件。在舱口处停止的饰条说的是维修语言。密封槽下的盐意味着缓慢呼吸。涂漆板下的盐意味着更大的水迁移路径。螺钉列旁的锈说明紧固件曾带水。下沉唇内部的干净油漆说明它是在周围外皮已经老化后才被打开的。

对玩家来说，外部饰条是一件导航仪器。它能指出安全切线、假安全面板、隐藏干燥口袋、后期维修，以及Deep Reach标为已封闭却未证明空置的房间。它也能暴露意图。螺栓间距整齐的补丁饰条说明维护人员预计会回来。焊在维修唇上的条带说明访问不再被允许。疲惫模块上一条完美的新替换带说明官方故事碰过这面墙。

把饰条当成视觉噪声是错误。在HECTON-8，边缘往往比中央更诚实。干净平整的面板也许只会说公司想让人看见什么。围绕它的带子会说基地真正需要什么才能活下来。
