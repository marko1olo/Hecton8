# Deep Reach压力陶瓷

Deep Reach压力陶瓷解释了殖民地为何能够运转，也解释了它的遗骸为何仍然致命。Deep Reach并不是靠无能建起海底工业的。公司学会把本地黏土、硫化物助熔剂和喷口炉热强化成陶瓷零件，使其能承受普通金属无法忍受的压力。夹环维持居住舱接缝。密封座让泵保持诚实。切割器触点在卤水中传热而不会软成废料。上升摇架隔热在发射硬件本应把自己烤坏的时刻买下关键的几分钟。这种能力是恐怖的一部分，不是矛盾。玩家拆取压力陶瓷时，手里拿着证据：Deep Reach足够了解这个世界，能让人活下去；随后它选择了让遗弃变得有利可图的程序与责任结构。材料记得这两件事。它在逃生配方中珍贵，在残骸中危险。热冲击会造成碎片开花：安静的白色裂纹沿环面张开成刀刃花瓣。错误释压能把完美密封座变成霰弹。这个资源应展示工业真相，而不是泛泛的反派质感。殖民地依赖它，因为它确实有效。玩家也会因为同一个理由依赖它。
