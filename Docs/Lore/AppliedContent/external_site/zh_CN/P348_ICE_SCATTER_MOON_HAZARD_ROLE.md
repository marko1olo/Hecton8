# Claw 冰散射危险角色

Claw 让系统显得被工作磨损。它不是纯净冰卫星，而是一片明亮场，里面有碎片、claim 标记和曾经有主人的物件。风暴后，航道会显示新材料、新雷达回波，以及能杀死廉价船员的传闻。危险只是普通物理：轨道速度的冰不会询问船壳载的是证据、食物还是尸体。 所以 Claw 的获利传闻总和航行成本一起出现。先被计算的往往不是找到的东西，而是抵达前被削掉的前装甲。
