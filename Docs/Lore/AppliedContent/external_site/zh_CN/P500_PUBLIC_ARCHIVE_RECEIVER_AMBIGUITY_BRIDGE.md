# 公共档案接收方冲突

## 记录证明了什么

这些包里的接收方不是一个人。它是每次交接时被复制的一项字段。一份 HECTON-8 档案包可以同时带有 Deep Reach Claims 的原始地址带、Atlas 中继戳、浅水附属区的隔离扣押、Keelmark 索赔台编号，以及公共档案登记行。任何一个字段单独拿出来，都不能证明是谁持有过证据、是谁改动过证据，或是谁付钱让它变得可见。在公共镜像里，干净的接收方往往只是被允许回复邮件的办公室，不一定是包实际经过的地点。

把接收方冲突当作路线问题来读。核对封印顺序、哈希时间、套袋上的水线、托盘上的工具痕，以及上传发生时哪个办公室还有供电。如果地址带指向一个办公室，中继回执指向另一个办公室，不要在物理保管痕迹打断顺序之前就判定它是伪造。也不要因为公共字段看起来整齐就替任何人洗清责任。有用的证据在办公室名称和处理痕迹之间。

## 如何阅读

公共档案接收方冲突
不要合并接收方字段。
地址带 = 预定目的地。
中继回执 = 运输经过。
隔离扣押 = 控制。
索赔台 = 付款与法律回应。
档案登记行 = 发布所有方。
行动：在物理保管顺序与包哈希吻合之前，继续封存最终接收方。

## 现场备注

先看湿痕，不要先看信头。办公室可以给包改名；它们移不走托盘上的锈线。
