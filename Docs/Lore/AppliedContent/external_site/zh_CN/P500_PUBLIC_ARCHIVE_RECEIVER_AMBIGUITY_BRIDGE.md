# 公开档案接收方歧义

## 它证明了什么

一个HECTON-8数据包上出现两个接收方标签，并不自动证明文件伪造。公开档案把接收问题拆成几条线: 原始地址带、首次中继节点、隔离办公室、索赔台和法律归档处。这些线可以互相矛盾，而且不一定无害。危险在于把最干净的标签当成真正的标签。Deep Reach文书常把公开接收方写得很窄，同时让有用的保管路线走向别处。Atlas回收碎片也可能反过来: 中继收据看似所有权，其实只证明经过。

## 如何阅读

公开档案接收方歧义
不要把地址、中继、隔离、索赔、归档字段合并成一个所有者。
公开摘要可能只写允许公开答复的办公室。保管路线可能显示实际持有数据包的办公室。
最终接收方需等路线证据。

## 现场备注

接收字段很礼貌。保管痕迹是物理的。标签在微笑而路线在流血时，跟路线走。
