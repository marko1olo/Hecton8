# 伊利亚·瓦尔内克的潮汐余量

“伊利亚·瓦尔内克的潮汐余量”是HECTON-8最早让玩家清楚读到Deep Reach责任机制的文章之一。它避开了廉价的企业邪恶版本。瓦尔内克不需要按下洪水按钮。他签署的是一种风险解释。

2147年，大潮模型按平均值仍然通过。危险的词就是“平均”。平均行为让生产排期继续存在，而极端叠加仍留在工人暴露之内：Aegir潮汐窗口、冰架回弹、耐压路线交通、Atlas补偿不确定性。一条路线可以在统计上可接受，却对遇上曲线尾部的人致命。

对玩家来说，这份证据把灾难从事故改写为决策链。瓦尔内克的备忘录不是供词。它是一份让责任可读的文件：不确定性被知晓、被打折、被向下转嫁。恐怖是官僚式的，但并不干瘪。余量被做得太小，小到工人会死在里面。
