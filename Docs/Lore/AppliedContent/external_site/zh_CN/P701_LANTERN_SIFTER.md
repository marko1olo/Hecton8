# 灯笼滤食者

HECTON-8电缆礁的报告描述了一种群体性生物发光滤食种，它会把入射声呐重新辐射出去。作业队一致记录到一次脉冲产生两个回波，第二个延迟约0.2秒，偏离真方位，且幅度高于距离所能预期的水平。

解剖报告指出每只个体鳃篮内有一颗高密度矿物包体，其特征更接近微量级导通基材，而不是生物矿化。44区的Deep Reach记录把该物种列为培育声学中继器的库存项，并以单元自行替换为由不记录维护间隔。
