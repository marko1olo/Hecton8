# 氙营养修复生态野外指南

Xenon-Omega常被描述成Deep Reach来偷的东西。这是真的，但说得太小了。在HECTON-8，蓝色物质属于一条由喷口供养的链：热量、硫化盐、压力缺陷、真菌爆发、牧食者、导电生物膜和受损Atlas例程都触碰同一批表面。

这让生态成为可游玩的证据。蓝色矿脉可能标记价值、毒性、电流泄漏、捕食者通行或旧修复路径。带标签动物可能在狩猎、啃食，或者把陈旧传感器数据带进维护循环。玩家不需要自然和机器之间的干净边界。真正有用的问题是：这个过程现在在做什么，如果样本活下来，谁会获利。
