# 近光速驱动堆剖面图

HECTON-8里的近光速船不是一支装着不可能发动机的干净银箭。可见的船体只是航路最后被维护的部件，而那条航路在船员醒来多年以前就已铺设。Barnard Yards的训练牌按照工人真正付费的顺序画出驱动堆：束帆推送、弹丸捕获、聚变电喉管、阴影护盾、散热肋、磁帆卷筒、气动制动蒙皮和接收方托管。

每一级都有不同的所有者，也有不同的失效方式。束阵列可以在没人支付抵达费用前出售离港。弹丸航道可以喂给加速燃烧，却在捕获公差漂移时让货运窗口破产。护盾能通过变薄熬过航程。散热器能让所有人活着，但代价是把每一公斤额外质量都变成问题。磁帆和气动制动账户决定这艘船能否在不烧掉油箱里利润的情况下停下。

这就是人类边疆能保持辽阔而残酷，同时不打破物理的原因。光运送索赔、求救包和法律威胁，成本远低于运送身体。Deep Reach可以在移动船体前继承权利。Black Keel可以停在Aegir星系里，仍像合同终端一样行事，因为它属于本地接收堆，而不属于下方被困的工人。

这张剖面图有用，因为它让玩家把救援读成一台机器。布满蚀坑的散热肋、关闭的制动账册或托管计量器都不是背景细节。它们回答一个简单问题：谁付钱让这份质量停在这里，谁没有？
