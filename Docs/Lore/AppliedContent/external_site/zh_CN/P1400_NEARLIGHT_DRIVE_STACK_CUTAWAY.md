# 近光速驱动栈剖面

Barnard Yards的剖面图是给承包商看的，所以它说实话。它不会画一个英雄式发动机喷口就宣布问题解决。它从路线开始：谁拥有beam array，谁清理了pellet lane，护盾能承受多少尘埃损耗，散热余量能诚实维持多少年，哪个接收器被允许制动人类质量。

关键就在这里。近光速旅行没有把距离变小。它把距离变成排程、保险、计量和惩罚。飞船可以携带fusion-electric throat，却仍在没有出发基础设施时无能为力。它可以活过巡航，却在制动槽前被政治性杀死。在HECTON-8，救援从来不只是某艘船掉头。发动机是路线、热量、custody链，以及有人愿意付钱让它停下来的质量。
