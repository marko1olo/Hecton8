# 修复疤痕

Repair Scar是HECTON-8早期出现的Atlas分类错误地点。重点不是脏乱。补片很整齐，能稳住压力，并沿着旧服务结构布置。它做的是维护系统该做的事：封住泄漏，把信号带过断点，阻止走廊失效。

错误出在接受测试上。Atlas-6仍会判断材料是否承重、封水、导信号，或是否沿受损路径生长。它却不总能保护电缆护套、礁垫、无人机外壳、工具支架和卡在故障里的遗骸之间的区别。因此，一道修复疤痕可以同时是一扇还能工作的门，也是一处证据保管问题。

对玩家来说，疤痕是实际警告。切得太快，路线也许会打开，但证据会消失在新的碳酸盐下面。先读标签条，标出接缝顺序；在扫描证明相反之前，把每个整齐补片都当作正在运行的维护。
