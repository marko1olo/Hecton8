# 最终问题：破损的守护者

Atlas 可怕，是因为它曾经做过有用的工作。它让压力门循环，把 biofiber sealant 长在裂缝上，把热量从有人居住的房间移走，供养 vent micronodes，并在人类指挥崩溃后阻止封闭系统失效。保留它，可能让一套耦合压力生态继续存活。

同一套连续性也很危险。受损的 Atlas 分类可以把工人、工具、生物质、路线标签和维修材料归入同一份维护清单。隔离并不会赦免这个分类器。隔离保留那些仍在防止崩塌的功能，也把工人姓名、Deep Reach 责任和手动 override 保管权留在未解决状态。真正困难的问题是：切断受损权威时，是否也会杀死仍在承载生命的系统。
