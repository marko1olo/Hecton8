# 壳质密封剂压力生长

维修不总是复原。Deep Reach 的应急密封剂首先保护压力，而不是舒适度。在 HECTON-8 化学环境下，泡沫补丁可能变成承重矿物壳。

从账本看结果很好。对 Marauder 来说，同样的成功会毁掉路线：补丁向内增厚，卡住舱口，埋掉工具，或把最后的隔间隔在一堵技术上仍在工作的墙后。
