# 壳质压力密封生长

壳质密封是Atlas维修里最清楚的现场矛盾之一。压力边界变好，房间撑得更久，而路线在同一层白壳下变得不可读。玩家切开它时不是在移除装饰；可能是在重新打开让舱室保持干燥的东西。

## Scanner

白色钙质壳层封住裂缝，也埋住了舱口边缘的路线箭头。切开可能重新漏水。

## Terminal

维修冲突 / DOOR S-9：漏率下降，压力边界改善，出口标记被遮蔽，手轮埋没62%。授权切割前必须布置分阶段进水路径。

## Audio

## Field Note
