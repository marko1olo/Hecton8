# 声学滤器官中继

在无线电失效的深度下，声音是主要仪器。电缆礁会扭曲声音：破壳会响，金属毯会散射，风暴脉冲会模糊距离，活组织可能夹在声源与回波之间。

所以声呐不是干净真相。中继可能显示一扇门，也可能喂给掠食者、重复旧警告，或让同一条走廊出现两次。
