# 声学过滤器官中继

声学过滤器官中继由压力、习性和误用构成。Deep Reach把金属中继喉管铺进殖民地，因为无线电在HECTON-8水下很快死亡。本地过滤生物发现这些喉管很好用：稳定水流、矿物砂、泵振动、受保护表面。多年后，褶皱组织长在旧硬件本来就塑造声音的地方。

Atlas把这场意外变成基础设施。活体挡板能吞掉泵噪声，同时让窄带ping音通过。它也会让回声偏移一点，让一张地图在错误的舱壁另一侧看起来真实。当走廊用组织塑造出的声音回应时，玩家得到的是信息，不是安全。风暴脉冲、动物移动或濒死褶皱，都可能在没有警告的情况下移动路线。
