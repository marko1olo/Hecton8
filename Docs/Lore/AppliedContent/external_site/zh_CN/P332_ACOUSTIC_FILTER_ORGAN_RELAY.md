# 声学过滤器官中继

受损的HECTON-8中继管有时携带活体挡板组织。组织能做信号工作，是因为它的褶皱、液体和压力响应正好适配管道。即使里面不再是金属部件，Atlas也可能把结果读成中继硬件。

## Scanner

中继喉部的挡板组织通过窄频信标音并削掉泵噪。回波地图发生相位偏移。

## Terminal

RELAY PIPE A-17：活体褶皱通过8-12 kHz信标脉冲，拒绝宽频泵噪，并增加返回延迟。下游地图可信度降低。不得仅凭此中继认证返回路线。

## Audio

它回应了信标音。管子在漏透明液体。标成动物，不要标成中继。

## Field Note

如果一根 flooded 管里的中继回应得太干净，从另一个角度再打一发信标。好声音仍可能给出坏地图。
