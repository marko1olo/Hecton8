# 旧程序识别提示

旧程序识别提示把人物动机落在操作员会读的文件上。表单故意普通：route-safe certification、declared occupants、泵房标签、人工复核字段、Continuity Office封印。

损坏存在于不匹配里。被接受的计数说路线已关闭。标签说仍有人和房间相连。办公室封印说不会允许第二次检查。HECTON-8把这种程序矛盾当作证据：不是戏剧化供认，而是一张因为操作者理解每个字段而毁掉人的表。
