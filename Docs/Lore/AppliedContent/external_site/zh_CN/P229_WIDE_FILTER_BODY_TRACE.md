# 宽幅滤食体痕迹

宽幅滤食体痕迹展示了 HECTON-8 如何处理巨型动物，而不把它变成舞台化的首领登场。宽幅滤食体是移动的生态：深渊中的活天气锋，啃食浮游云，清出可视通道，扭曲声呐，并短暂显露废弃殖民地设备的几何形状。玩家应当通过导航规则的改变感到尺度，而不是因为镜头停下来欣赏怪物。

在身体下方，声音失去硬边。边缘附近，回声会折叠。它身后，海水变得不自然地干净，旧轨道、管道肋骨或维护塔会出现在原本空白的地图上。这种有用性就是陷阱。显露路线的同一条尾流，也可能把负重的 Marauder 拉进开放深水，那里没有墙、没有底，也没有可靠的返程线。动物依旧无动于衷。它不是邪恶的，不是驯服的，也不是在等待玩家。它是海洋在证明：生存知识也包括耐心。等待它经过，读取浮游空隙，标记废墟，在淤泥落回前离开。
