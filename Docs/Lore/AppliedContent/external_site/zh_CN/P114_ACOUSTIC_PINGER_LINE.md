# 声学信标线

声学pinger line不是救援信标。它是能被听见的纪律。玩家在浑浊、brine shimmer或恐惧让路线陌生之前固定return sound。工具教会玩家：导航是一种习惯，不是map screen。

后续系统可以从这颗种子生长：relay timing、carrier handshake、路径仍存在的声学证明。第一版故意很小。它拯救玩家免于自信。
