# 储物柜道具变体矩阵

储物柜道具变体矩阵定义 HECTON-8 如何把个人储物变成可读证据。储物柜不是传记垃圾箱，而是紧凑的世界物件，连接工人、工作、航线权限、损坏和后来的篡改。玩家因此能通过仍属于房间的物件阅读殖民地生活。

## Scanner

储物柜应显示工作、航线权限，以及某人试图擦除的东西。纪念物只有在工作可读之后才允许存在。

## Terminal
