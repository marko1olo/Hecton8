# 压力服维修补丁账

崭新的压力服属于宣传册。HECTON-8不是宣传册。真正重要的压力服有补丁，膝盖和袖口被磨毛，缝线周围有盐，用任何能再撑一次下潜的布条修过。

好补丁带着社会信息。工厂维修很均匀。主管维修用正确胶带，但没有时间。工人维修用错线，却知道身体在哪里弯。医疗维修快而丑。黑龙骨维修会先剥掉识别信息。脏压力服上的干净补丁可能说明穿戴者对某个有库存权限的人很重要。

所以补丁应该出现在柜子、医疗舱、淹没更衣室和废弃工作台上。它们让殖民地变得私人，而不需要每具尸体都开口说话。补丁说：有人在这里，有人知道风险，有人决定工作仍要继续。
