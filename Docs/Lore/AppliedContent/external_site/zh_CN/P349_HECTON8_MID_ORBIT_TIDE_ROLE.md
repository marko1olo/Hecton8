# HECTON-8中轨潮汐角色

HECTON-8位于Aegir月梯里有利可图的中段。这个轨道给Deep Reach一片海：它能冷却机器，隐藏资产，喂养压力工业，并推动足够的化学循环来证明索赔成立。它也给殖民地一层永不停下的天花板。潮汐压载服务峡谷，弯折沉没地壳，毁掉干净日程，并决定上升质量何时能离开。

被困的潜水者并不只是深在水下。身体位于一片持续改变合同的天空之下。好的救援窗口从来不是怜悯加推力；它是潮汐相位、载体接受、风暴噪声、托管措辞、燃料热余量，以及那个难听的问题：如果胶囊被污染、迟到，或装满证据抵达，到底由谁付款。
