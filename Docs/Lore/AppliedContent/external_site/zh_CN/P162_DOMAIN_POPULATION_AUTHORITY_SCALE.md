# 人口与权力尺度

## 人数不是权力

域表有意保持人口模糊。精确 census 可以日后调整，但压力关系已经锁定：Sol 掌握旧金融和认证，Centauri 掌握合法性语言，Barnard 掌握 salvage 文化，Tau Ceti 掌握公共证据压力，Luyten 掌握数据包 custody，Aegir 掌握让这一切变成机器的肮脏地点。

HECTON-8 的玩家不应把域名当作百科琐事。Sol Core 是财产和保险连续性的印章。它能让死亡海洋在法律上仍然活跃。Centauri Compact 是功能性扩张的记忆，因此 Deep Reach 能借它的宪章语气，让自己看起来没那么腐烂。Barnard Yards 解释了主角为何懂夹具、切割器、压力工具和坏工作，而不需要英雄神话。

Tau Ceti 有价值，因为它能让证据在公共层面产生后果。这不代表它能在潮汐改变前救出潜水员。Luyten Junction 更冷：即使没有道德权威，它也能保存 custody、hash chains 与 packet notary records。Aegir 是肮脏的 claim node，本地 shells、Black Keel windows 与 Deep Reach priority hooks 会把远方权力变成即时危险。

所以一个小 desk 可能比一颗星球重要。统治 HECTON-8 的不是最多的人口，而是谁能让 claim 熬过距离，并向触碰它的幸存者收费。
