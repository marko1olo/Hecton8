# 努尔·哈尔丹的撤离证书

“努尔·哈尔丹的撤离证书”是一篇关于合规作为致命物体的Deep Reach证据文章。哈尔丹不是大喊大叫的反派。她是让撤离在法律上可辩护的法律顾问签名，而物理路线正在失败。

她的保留由可信的要求构成：压力-生物隔离、承运方监管、外部路线复核、下游港口接收、责任链。没有一个词荒谬。这正是重点。系统可以在自己的框架内正确，同时通过等待杀人。

这篇文章让玩家有办法阅读旧殖民地的门和路线板。锁住的撤离路径不只是坏掉的机器。它可能是一项仍在等待复核的法律决定。HECTON-8的黑色气质来自这种延迟：如果证书能说足够久的“还不行”，就没有人需要说“让他们死”。
