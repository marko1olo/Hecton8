# 黏土粉砂浊流坡野外条目

黏土粉砂浊流坡让 HECTON-8 的低能见度有原因，而不是任意紧张。水不会因为场景需要悬念而变浑；它变浑是因为玩家、机器、滑塌或旧坍塌把细黏土重新扬入水中。

这个表面有三种职责。它是危险：推进和坏落脚会让路线失明。它是证据：新伤、压缩波纹和拖痕说明玩家到达前发生了什么。它也是导航：同样的标记可能指向埋藏设施，或警告薄弱陆架。
