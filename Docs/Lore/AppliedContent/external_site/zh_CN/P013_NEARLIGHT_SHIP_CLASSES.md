# 近光速船级

HECTON-8 的近光速船不是包在船壳里的奇迹发动机。它是航路经济可见的末端。光束阵列在车辆出发前就消耗能量。Pellet lanes 用残酷的时序供给反应质量。fusion-electric 喉管、护盾冰、散热器和冷冻系统防止载荷变成明亮错误。magsails、气动制动皮和接收窗口决定船能否停止。

这就是船级表对玩家有用的原因。needleprobe 解释 Aegir 为什么先被知道，后才安全。seed ship 解释机器为什么早于稳定社区。Atlas 解释殖民地为何一开始就背负债务和维护妥协。system tender 解释 Black Keel 的限制：它能处理 Aegir 索赔，不能改写星际距离。
