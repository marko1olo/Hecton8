# 高托管样本合同种子

高托管样本从更好的价格和更糟的箱子开始。合同板把某些样本标为receiver-certified：blue debt砂粒、组织铁薄片、封存盐水、滤包，以及仍带有航路上下文的生长残料。每件东西在可付款前都需要容器、质量检查、封签状态和custody标签。
