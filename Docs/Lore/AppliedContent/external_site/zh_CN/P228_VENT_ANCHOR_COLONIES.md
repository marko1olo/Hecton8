# 热口锚群落

热口锚群落回答了一个资源叙事问题：被困的 Marauder 为什么要下得更深，而不是只向上修修补补？因为能承受 HECTON-8 压力的部件，诞生在海洋最敌对的地方。热口锚像活夹具一样围绕热液出口生长，把硫化物、热循环矿物和陶瓷前体困在肋状台地里。它们以扎实方式把生态和制作连接起来。群落不是战利品节点。它是有脉搏的危险工业过程。小型动物躲在较冷肋条里。Brine vanes 会从热羽流旁卷开。密度滑行者也许会穿过温热台阶，但不会越过白色喉口。好的遭遇应让玩家在同一物体中看见维修路线和死亡区域。锚说：是的，你需要的材料存在；不，你不能安全拿走。这也让 Deep Reach 的能力变得可信。公司不是凭空发明有用的压力化学。它学会采集并标准化海洋已经运行的过程，然后围绕被派去从沸水中切样的人建立 liability paperwork。
