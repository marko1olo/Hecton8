# 接收端制动债务账册

HECTON-8的太空设定成立，是因为文明有能力但仍受约束。剧情背后没有隐藏的FTL救援，也不是原始孤立。人类可以通过near-light routes推动质量，但每一公斤都穿过某人拥有的基础设施。

制动债务账册让这一点变得可见。它记录谁拥有减速路径，谁吸收热量，谁接受隔离，谁接收货物，以及停止损坏船、站、货物或身体时谁付款。信号可以便宜，因为它不要求接收端捕获一个人。证据能先于救援移动，因为证据不会呼吸。

对玩家来说，这把距离变成压力，而不是资料。问题不是文明是否存在。它存在。问题是玩家能否把自己的身体、证据、样本和债务塞进一条已经忙着搬运公司更早关心之物的航路。
