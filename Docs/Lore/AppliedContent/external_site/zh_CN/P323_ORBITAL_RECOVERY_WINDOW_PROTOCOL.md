# 轨道回收窗口协议

轨道回收窗口协议把 HECTON-8 的逃离循环落在本地天文学和系统工程上。玩家不是因为剧情需要而被困，而是因为 Aegir 的风暴剪切、磁干扰、受损上升链和法律接收端状态只会在狭窄窗口里对齐。救援不是要按的按钮，而是要建出的路线。

## Scanner

Black Keel 近到能听见你，却受限到不能随叫随接。Aegir 只会打开狭窄的回收窗口。

## Terminal

回收窗口 / Black Keel 接收器仅在低 storm-top shear、Aegir 磁噪降低、guidance core 已验证、quarantine handshake 匹配且 receiver custody state 合法时接受 rated ascent object。窗口漂移会使手动 launch 失效。

## Audio

船近到足够重要，又远到不能迅速救你。

## Field Note

用于路线计时器、carrier UI 和假出口解释：风暴剪切、磁噪、上升几何、隔离 handshake。
