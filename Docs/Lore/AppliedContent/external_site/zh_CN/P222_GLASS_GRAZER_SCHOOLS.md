# 玻璃啃食者群

玻璃啃食者群是 HECTON-8 给玩家上的第一堂动物行为仪器课。它们不是宠物、不是战利品袋，也不是无害装饰。它们是小型透明壳质取食者，会把矿物膜刮成明亮水道，让浅层大陆架变得可读。活着的群体会告诉 Marauder：pressure glass 在哪里生长，哪条接缝过热，哪股水流刚刚转向，以及捕食者最近没有经过哪里。真正重要的时刻往往是不在场：膜还在，小小的壳嘴停止滴答，一条干净路线突然显得不对劲。这种沉默直接连到浅水捕食者语法；危险先以消失的动物群、断裂的 bloom 噪声和横过美丽礁面的阴影抵达。好的放置应该让玩家用身体学会：游向苍白刮线，听壳声变尖，注意温热密封剂周围的空区，然后在声纳明白原因前看见群体折身散开。玻璃啃食者让 HECTON-8 显得活着，因为它们有用、脆弱、诚实。它们不解释海洋。它们暴露海洋刚刚做过的事。

## Scanner

玻璃啃食者群 // 透明壳质取食者会从 pressure glass 和光照席毯边缘刮下矿物膜。它们的滴答声打开明亮的路线刮痕；突然的沉默就是捕食者数据。

## Terminal

基础动物群：非敌对啃食者集群。追踪 pressure glass 膜、新鲜矿物 bloom、水流扰动和捕食者驱离。活跃取食后的消失是路线警告，不是空刷点。

## Audio

## Field Note

不要追着群体走。读它们暴露出的东西：新鲜膜层、旧刮痕、对温热密封剂的避让，以及它们拒绝穿过的空白水道。
