# 资源与生态

第一个错误，是把 HECTON-8 的资源叫作原料。下面有用的东西几乎都不是未被触碰地到来。Drowned Crust 的碎片带着压力史。blue debt 矿脉保留着热、盐水和采集方法的记忆。一片壳板在 Marauder 装箱之前，可能同时是礁体护甲、失败的密封物、Atlas 生长出的电缆皮层和法庭证据。

所以资源页面必须和生态页面放在一起。旧殖民地开采的不是死地板。Deep Reach 切入盐水阶梯、喷口供养的矿物台地、淤泥里的机器和早已学会月球节律的活过滤系统。灾难之后，Atlas 把自己的修复模型推给任何能堵漏或传递信号的东西。生物膜成了导体。根毯成了垫圈。带标签的动物成了移动反馈。

动物不是长着鳍的 loot 箱。它们读取振动、热、光衰、血液化学、盐迹和被搅动的泥。食草者只按旧习性行动，就可能暴露安全刮取区。捕食者的影子能说明哪条走廊带着错误的声学脉冲。带标签的动物可以在同一次经过中成为修复路线、证人和危险。

blue debt 让道德计算更脏。最好的样本可能暗淡、密封又难看，因为它保住了能证明形成地点的压力状态。明亮碎片如果被喷口洗掉记忆，可能一文不值。取走任意一种，都可能改变水流、唤醒猎手、损坏 Atlas 补丁，或抹掉比付款更重要的工人时代事故痕迹。

有用的问题从来不只是能收割什么。它还要问，在人手进入链条之前，海洋正用这种物质做什么。当地质、生命、机器和 custody 被当成一个会记住伤害的系统来读，HECTON-8 才变得可读。
