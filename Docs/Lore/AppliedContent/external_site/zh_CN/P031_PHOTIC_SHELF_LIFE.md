# 透光陆架生命

透光陆架生命是 HECTON-8 上层水域的生态基线。表层带仍接收光、热变化和天空节律，所以在更深处出现 Atlas 修复逻辑前，原生生命会留下可读的路线证据：氧气膜、glass-grazer 通道、pressureweed 弯折，以及残骸周围的路线藻。陆架说明 Deep Reach 为什么想要这颗月亮，但不会把它说成无害区域。每个有用线索都有失效路径。能换来一口气的氧气膜可能遮住污染；标出回流的藻道可能在风暴淤泥或捕食者压力下偏移。

## Scanner

透光陆架扫描 // 玄武岩边缘有氧气膜。新鲜 glass-grazer 通道切开绿色生长。Pressureweed 在浪涌前向西弯折。路线藻标出回到庇护线的水流。风险：浅水捕食者经过、风暴淤泥、回程线松动。

## Terminal

陆架基线调查
深度：0-250 m
样本A：氧气膜 / 矿物供养 / 可呼吸囊低容量
样本B：glass-grazer 通道 / 新鲜切痕 / 捕食者驱散未知
样本C：pressureweed 弯折 / 浪涌前向西
样本D：路线藻 / 水流回到庇护线
对比：电缆根膜、修复疤组织、压力闸生物膜
