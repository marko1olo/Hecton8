# 透光陆架生命

透光陆架生命是HECTON-8开场的生态基线。它不是安全水族箱，也不是等待恐怖降临的死海。上方0-250米仍能接收光、热变化和天空节律，所以原生生命用颜色写出第一套路线语言：石上的氧气膜、在藻中切出道路的透明啃食者、在浪涌前倾斜的pressureweed，以及在残骸周围描出水流的路线藻。这种美丽很重要。它让玩家理解Deep Reach为何想要这颗月亮，也理解一个被困的Marauder为何可能为了读懂它而战，而不只是洗劫它。陆架同时教会本设定的核心规则：可读不等于无害。明亮的生物膜可以维持可呼吸水体，也可能遮住受污染的接缝。玻璃啃食者群可以标出安全通道，也可能因为更大的东西经过而消失。Pressureweed可能预警天气、捕食者挤压，或下方基础设施传来的压力脉冲。它应作为玩家的第一处诚实对照点：在电缆礁、修复疤、Atlas把生命变成维护逻辑之前，月亮先展示它自己会做什么。
