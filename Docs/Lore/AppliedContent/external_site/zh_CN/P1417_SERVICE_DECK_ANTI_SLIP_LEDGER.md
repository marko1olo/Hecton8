# 湿滑防滑服务甲板账本

HECTON-8里最可信的地板并不干净。干净的地板会撒谎。被淹的服务甲板应该显示设计与使用的差异：计划中的防滑网格、实用的黄色线、人类反复转身的弧线，以及海水用盐和锈写下的慢修订。

防滑板通过接触讲时间。凸脊顶部被靴子和箱子磨亮。槽里因为油、冷却液或卤水变暗。安全漆最先从真正重要的路线消失。锈只在手、脚、车和水不再打扰的地方生长。

到了现场，这些痕迹就是选择：相信磨损线、避开发亮的湿槽、保存一处后期擦痕作为证据，或沿黄色漆进入Deep Reach从未放进公开地图的维护空间。
