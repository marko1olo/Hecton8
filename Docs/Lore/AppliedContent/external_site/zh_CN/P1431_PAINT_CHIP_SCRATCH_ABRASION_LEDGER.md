# 漆面剥落、划痕与磨损账本

殖民地仍通过海水没能抹去的痕迹说话。油漆是这份记录里很小的声音。它比压力肋便宜，比密封圈脆弱，也比破舱门更容易被忽略。正因如此，它有用。Deep Reach用颜色让水雾和应急灯里的维修动作可读：白色是压力外皮，深色底漆在硬面下，石墨色用于导轨和接触区，橙色标出工人在切割、解锁或循环系统前应该看的地方。

Great Tide之后，这些颜色不再是说明，而成了时间线。填满盐的缺口是旧的。带干净黑边的缺口是后来的。划痕上覆着浅色矿物粉，说明这个痕迹在房间潮湿呼吸时已经存在。矿物粉上出现划痕，说明工具在那次呼吸停止后才通过。锁扣周围的弧线保存着反复开启的路径。面板唇边附近的短平行擦痕，显示工具箱或切割器脚座不断打滑。宽而抛亮的边缘，说明有重物在压力或水流中摩擦，而不是模块在干仓库里静置。

这一层重要，是因为HECTON-8有太多官方表面已经不值得信任。终端会断电。标签会脱落。企业报告能把数周的工作、失败和被放弃的修理压成一句干净的事故描述。油漆不能解释全部罪行，但它能把一只手放回时间里。它能显示面板在所谓撤离窗口之后被打开，锁扣在进水后仍被使用，后来的打捞切过工人的修理痕迹，或某个房间是从地图遗忘的一侧进入的。

最好的读取会把油漆与其他材料证人交叉检查。渗漏锈和生物膜给出潮湿时间线。焊缝和铆钉排列给出修理顺序。打捞切面给出工具方向和意图。油漆给出接触。它记录手伸向哪里、工具咬在哪里、哪一个动作被重复到颜色消失。它在成为废料前就有价值。带着正确缺色的板件可以是掩护、入口、赔付材料或证据。第一步做错，四者都会变成无名废铁。
