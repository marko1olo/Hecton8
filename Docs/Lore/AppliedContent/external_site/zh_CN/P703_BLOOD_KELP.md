# 血藻

HECTON-8的深水勘测记录了一种红色色素的固着大型植物，在大约1,400至2,600米的硬质基底上形成一片片独立群丛。这种色素吸收了标准工作灯所配的蓝绿波段，因此群丛对灯锥几乎不返回任何信号，只有在接触距离上才能分辨，而琥珀色应急滤镜能把它清晰地呈现出来。

接触会在整片群丛上触发发光器放电，持续时间约为九十秒。打捞队把由此产生的光当作自身位置的暴露，而不是照明帮助。44区的Deep Reach采收记录把这种生长列为照明原料，并在四起已登记的缠绕事件旁保留非危险、植被的分类。
