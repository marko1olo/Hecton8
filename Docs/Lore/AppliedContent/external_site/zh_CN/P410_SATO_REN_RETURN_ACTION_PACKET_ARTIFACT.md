# 佐藤-任 Return Action Packet

## 以 Claim 顺序说出的救援

佐藤-任 packet 是现在时的压力。玩家已经从旧 memo 和 ledger 学到 Deep Reach 做过什么后，它才抵达，并证明公司不只是档案里的尸体。Deep Reach 仍在说话。它只是按系统理解的顺序说话：coordinates、access state、sample custody、silence acknowledgement、extraction language。

顺序就是威胁。救援服务会问你哪里受伤。recovery desk 会问你携带什么，谁能 certify，Atlas 是否还能打开 route，以及你是否接受 silence 作为移动条件。佐藤-任不需要在 HECTON-8 上空放一艘战舰。packet 本身就是 leverage，因为消息稀少、质量昂贵，而玩家被 debt-bound。

late game 应该因此变得道德上狭窄。同一份文件，根据玩家已知内容，可以像帮助、repossession 或勒索。它把旧的溺亡官僚体系连到 Marauder 面前的活选择：卖出坐标、保存 proof、sever Atlas、公开 ledger，或继续穿过一片连 rescue 都有 claim number 的海。
