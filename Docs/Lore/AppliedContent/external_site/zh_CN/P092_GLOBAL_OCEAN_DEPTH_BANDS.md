# 全球海洋深度带

HECTON-8不是一个只有数字变深的平面海洋。它是一座垂直国家，边界由压力写成。0到250米，透光打捞陆架仍有光、藻类、软残骸，也给新手错误留出余地。250到1200米，工业陆架和电缆礁开始出现：断裂锚缆、管架、中继器残骨和旧公司航道。1200到2800米，盐卤阶梯弯折声呐，隐藏热量，让压载成为昂贵选择。2800到4300米，维修变成与机器场谈判。4300到5600米，Atlas把压力变成权力。
