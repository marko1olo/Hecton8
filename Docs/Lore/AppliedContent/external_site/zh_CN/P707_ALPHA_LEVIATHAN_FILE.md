# 阿尔法利维坦：合并档案

在Aegir沉没结构上作业的打捞队之间流传着一份不完整的Deep Reach文件，归档代号为ALPHA LEVIATHAN。文件里列出二十二次事件，其中九次带着这个代号本身：写明的合并依据是这九次产生了船体应力申报，而损失表格只允许填一行原因。其余十三次作为已记录的方位保留，没有就它们提出索赔。

除此之外，流传的各份副本一致的地方主要是它们缺了什么：形态、质量与展长、声学载波的上限在每一份里都不予披露，被引用的附录一份也没有随件。

经过删除之后留下的是仪器的表现，不是观察。没有声呐接触的船体应力报警、记录了方位却没有距离、在任何可见来源之前出现的水流扰动，以及比这些更早出现的小动物噪声持续下降。生存者陈述全文留档，并受缺氧和氮麻醉影响，这也是文件中给出的不将其计入的理由。Deep Reach把该代号作为通行提示管理，相关损失归档为压力偏差。
