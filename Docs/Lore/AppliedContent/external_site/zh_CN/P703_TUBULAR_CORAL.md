# 管状珊瑚

HECTON-8上的Aegir打捞队报告了一种群体性成管生物，它沿工业板材的裂缝定殖，而不是铺在完好表面上，把自2147年起无人照管的结构裂缝填满并压力封住。已有房间在仅靠这种生长的情况下承住数兆帕被回收。

同样的生长覆盖了用于结构认证的钢印面板识别。44区的Deep Reach维修记录以外部踏勘结掉这类房间，这种方法能确定房间是完好的，却不能确定它是哪个房间。现场做法是把任何横跨焊缝的管迹都当作承载件。
