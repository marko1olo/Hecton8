# 现场系统专员记录

现场系统专员记录给HECTON-8的核心操作员一段有用的过去，但不把这段过去洗得太干净。他们不是指挥人员，也不是灾难的秘密设计者。他们曾在那些本应让疏散路线、泵、密封件和中继室保持诚实的系统旁工作。

这很重要，因为废弃殖民地里充满程序，而不只有残骸。route-safe印章、clamp等级或maintenance措辞，有时比戏剧化录音更能定罪。操作员知道这些记录在人受到保护时该是什么样，也知道公司想让保护变成文书时它们会是什么样。

被撤销的访问权让历史更锋利。旧徽章不再给予控制，但仍留下识别失败方言的能力。HECTON-8把这种职业记忆变成动机：不是造成灾难的罪，而是在读懂可避免房间如何被归档后产生的责任。
