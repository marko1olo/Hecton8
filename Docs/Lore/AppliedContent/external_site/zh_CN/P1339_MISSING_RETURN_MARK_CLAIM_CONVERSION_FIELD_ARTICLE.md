# 缺失返程标记与索赔转换

返程标记很小，却决定一条路线允许表达什么。关闭路线可以审计。开放路线可以被延迟、转移、计费、重新接到设备上，或作为未解决质量处理。在HECTON-8，这种模糊很重要：许多房间停止换气之后，工人仍在表里显示为移动中。

证据位于路线戳和后来的claim desk例外之间。如果氧气停止、潜服标签仍在舱内、返程栏仍为空，那不是普通漏填。这是保留的开口。身体证据移向别处时，工人仍可被留在合同状态里。

Deep Reach不需要戏剧性供述。一个台面可以按规则做事，同时选择最便宜的字段：路线开放、回收待定、设备质量未决、打捞权保留。每个字段都很窄，叠在一起就让死亡路线无法成为已关闭损失。

返程栏要同路线戳重叠、packet notary遮盖边缘、转录损伤带一起读。这些物件不靠情绪指控。它们叠出顺序：房间暴露、路线处理、关闭缺失、claim desk转换。
