# 漂泥者

HECTON-8的打捞报告描述了一种宽体底栖摄食种，它啃食陆架沉积物并留下持久的犁沟。作业队用犁沟的形状判断局部水流：开阔沉积物上是直线，水下取水口抽水处是曲线。

接触会引发浓重的沉积物浑浊，灯光和声呐同时失效，现场规程要求收窄光束并按方位航行直到脱离。Deep Reach的记录把该物种归入沉积物管理，并把该深度段的取水格栅检查记为视为现行。
