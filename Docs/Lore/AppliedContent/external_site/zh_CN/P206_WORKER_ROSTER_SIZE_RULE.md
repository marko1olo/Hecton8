# 工人名册规模规则

工人名册规模规则是可读殖民地证据的人口契约。它给 HECTON-8 72个工人身份：24个用于反复叙事证据的锚点，48个用于重玩变化的 seed-role 身份。玩家应该逐渐认出名字，因为世界会把名字和工作一起重复：储物柜、工具、航线章、维修命令、最后音频标签。殖民地感觉比演员表更大，但证据仍然足够作者化，值得记住。

## Scanner

七十二个名字不是氛围文本。它是殖民地的记忆预算：足够多，让这里像曾经有人工作；又足够少，让储物柜、维修标签和最后班次指回同一个人。

## Terminal

ROSTER RULE: 运行名册包含72个工人身份。24个是锚点姓名，可在储物柜、账簿、损坏工具、通行许可章和音频碎片中反复出现。48个是用于重玩变化的 seed-role 姓名。生成姓名可以移动证据顺序；它不能变成一次性填充物。

## Audio

当房间能证明那份工作时，名字才成为证据。

## Field Note

如果一个名字之后不能带着工作再次出现，就从名册里删掉它。
