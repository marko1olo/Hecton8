# 返还权利检疫握手账本

在HECTON-8里，幸存者到达海面或载体甲板并不意味着返还完成。游戏把回收当作保管问题：谁接收身体，什么东西随身体而来，哪个机构要对幸存者携带的证据负责。

检疫法律握手就是这个决定背后的机制。它结合医疗许可、压力硬件认证、索赔所有权、接收方授权和载荷保管。检疫一词故意比感染更宽。潜服可以一次带回生物、毒性化学、黑匣子记录、公开证词和债务索赔。系统无法决定哪个问题最重要，直到有人签字。

这个签字是政治性的。公司接收方能快速行动，把幸存者消失进合法保管。公共账本接收方能让证据更难被抹除，却让受害者和坐标更容易被追猎。中立检疫滞留能让人活着，同时暂停能让他们自由发声的每项权利。HECTON-8的救援恐惧不在于无人回应，而在于每个回应都会把玩家定义为资产、风险、证人或污染物。

这条路线给玩家的实用读法很直接。不要只建上升硬件。要建立对接收方的筹码。保存数据包保管链，选择什么变成公开内容，并理解逃离的最后一扇门不是机械门。它是决定什么抵达的那张桌子。
