# 打捞切割断面账

在HECTON-8，最诚实的门常常不是设计出来的。坍塌后被切开的面板不再有公司承诺，只剩热色、撕裂绝热层、密封碎片，以及那些需要墙后之物的人留下的急迫几何。

读边缘要从外向内。涂漆外皮给方向。深色芯材显示船壳承力部分。陶瓷粉尘说明热走得多散。橡胶像牙一样撕裂，说明切割后又用了机械力。线缆端头说明意图：整齐为隔离，压碎为恐慌，剥皮为盗取，封帽则说明有人以为自己会回来。

好的断面能装下一整段失踪场景。它能说明有人在淹水后打开墙、绕过密封舱门、取走证据、救出被困工人，或给后来拾荒者做路。边缘不记得名字，但记得工具。
