# 贵气卤水囊

贵气卤水囊定义了HECTON-8蓝色经济的硬科幻根基。真正有价值的不是发光石头，也不是魔法同位素，而是一段密封的压力历史：贵气困在矿物卤水中，又被锁进笼合物痕迹、微裂缝和缺陷晶格里。只有完整回收的样本才有意义。粗心船员听见水囊嘶嘶放气，会以为自己找到了钱。通常他只是把钱变成了天气。因此野外抽取需要压力钟、缓慢热隔离和证据记录，之后才谈得上炼厂索赔。气体比例重要，但它如何形成同样重要。不能证明压力曲线的样本，即使氙计数看起来很高，也只是低级原料。这个资源教会玩家：Xenon-Omega是工艺结果，不是可收集矿物。Deep Reach发现的不是奇迹宝石，而是哪些密封历史能被压榨成债务材料。Atlas后来用受损优先级给这些历史分类。水囊本身比两者都更古老、更怪异：一枚仍努力不变成天气的地质气泡。
