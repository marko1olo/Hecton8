# 生物金属资源栈

资源栈让HECTON-8不至于坍缩成一种魔法材料。蓝债很重要，但这颗月球还支付硫化金属、盐类、惰性气体、陶瓷、催化剂、生物纤维、光蛋白、打捞硬件和Atlas改变的生物金属。暴力之所以合理，是因为价值分布在许多地方：切割、标记、隐藏、返回和撒谎都有太多小理由。

生物金属资源栈把HECTON-8定义为完整压力经济；Xenon-Omega是战略顶点，而不是唯一值得阅读的东西。 如果每个样本都说Xenon-Omega，世界就会变平。也要数清那些让人死去的小理由。
