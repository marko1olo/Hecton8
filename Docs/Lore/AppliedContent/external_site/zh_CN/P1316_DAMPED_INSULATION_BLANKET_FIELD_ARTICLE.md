# 潮湿隔热毯现场条目

潮湿隔热毯位于 HECTON-8 承压内饰可见金属背后。灰米色绗缝织物是工程层，不是居家舒适层。它降低振动，保护背板，并在墙体出现可见泄漏前记录湿气。

在玩法中，这一层可以引向仍工作的设备、隐藏水路、腐蚀线缆槽或糟糕的进水后维修。深色缝线显示湿干循环。下垂方格显示滞留水。缝线处盐尘显示冷凝路径。

这种材料让旧殖民内饰拥有人工维护史，而不是单纯墙面贴图。
