# 路线许可戳

这座淹没的殖民地不是靠演讲移动人。它靠戳记移动人。

在HECTON-8，路线许可可以是班次板上的印刷方格、舱门旁刮花的金属片、潜服芯片更新、车板上的油笔授权，或工具柜托盘里的压印。它很小，因为压力作业讨厌不能承受手套、水和疲劳的文书。它很有力，因为它把工人的名字变成许可：去这里，修这个，见证那个，从这条路线回来。

Great Tide之后，这些小许可比许多日志更硬。日志可以被概括。戳记很顽固。空白返程格证明移动没有结束。分诊条目旁的拒绝路线证明伤害通过程序流动。应该守泵房的人身上有BRINE戳，证明风险被转移。腐蚀舱门上的干净迟到贴纸证明房间状态改变后，记录又被碰过。

路线戳也会撒谎。Deep Reach可以事后补写、划掉，或让一条死路线在法律上保持有效，因为承认关闭就等于计算尸体。物理房间会检验戳记。门闩磨损是否符合授权使用？水线是否切过墨迹？潜服芯片是否一致？旁边是否有Marauder修正，警告官方类别错误？

对玩家来说，路线戳让殖民地可读，而不必让每个工人独白。它们同时是程序性的、苦涩的、人性的。沿着它们走，沉没站点就不再只是迷宫，而是一个在安全已经失败后仍继续分配任务的工作场所。
