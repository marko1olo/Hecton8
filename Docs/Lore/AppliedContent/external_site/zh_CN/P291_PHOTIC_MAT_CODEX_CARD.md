# 透光垫层图鉴卡

透光垫层是HECTON-8最早教给玩家的可读生态之一。它们照亮浅水，喂养小型grazers并稳定矿物膜，但也标记压力化学和脆弱接缝。海洋看起来诱人，是因为活体表面正在工作。

## Scanner

透光垫层。覆盖在矿物皮肤上的产氧生物膜片。明亮、有用、承压脆弱。不要从封住的裂缝上剥离。

## Terminal

样本 / 透光垫层
作用: 浅水产氧表面、grazer食物、矿物膜稳定器
安全采样: 小于手掌宽度的松散边缘
拒绝: 封缝片、带气泡的垫层、新鲜grazer咬痕区
路线备注: 撕裂垫层可能释放困住的气体，把清澈浅架变成hazard。
