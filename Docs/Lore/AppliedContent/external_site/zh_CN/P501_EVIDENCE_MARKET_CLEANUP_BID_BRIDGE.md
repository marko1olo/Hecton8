# 证据清理竞价

## 记录证明了什么

清理竞价不是判决。它是一份针对证据路线的购买指令。请求可能要求中介擦干标签、规范名称、把碎片移进打捞批次、延迟公开、把工人姓名转换成赔付类别，或把原始物件埋在一份对索赔方安全的摘要后面。它重要，是因为钱在记录改变之前出现。付款方可能有罪，可能害怕，可能粗心，也可能只是在买时间；竞价本身证明的是证据痕迹受到压力，不证明碎片的真假。

按顺序阅读这份竞价。原始标签、竞价来源、托管扣押、处理人账户、清理后标签、保管转移和物件路线必须放在一起。如果清理后标签出现在付款之前，可能只是普通档案处理。如果付款先于改名出现，就是有人买下了路线变更。把原始标签保留在清理后标签旁边，否则档案本身就成了清理的一部分。

## 如何阅读

证据清理竞价
不要把付款当作判决。
付款早于改名 = 购买路线变更。
改名早于付款 = 可能是档案处理。
下一项证据：托管扣押、处理人账户、保管转移、旧标签、清理后标签、物件路线。
行动：在物件路线解决前，保留两个标签。

## 现场备注

永远不要只归档干净标签。旧标签和付款时间才是证据。
