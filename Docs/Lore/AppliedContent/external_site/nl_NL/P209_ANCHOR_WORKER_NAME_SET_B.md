# Ankerarbeidersnamenset B

Ankerarbeidersnamenset B is de diepere terugkerende arbeiderslaag voor HECTON-8. Deze namen moeten de horror niet verzachten; ze moeten het systeem leesbaarder maken. Tegen de tijd dat de speler Set B ziet, hebben drukstoringen, routeholds en triagevertragingen al een patroon. De herhaalde namen verbinden dat patroon met mensen en daarna met de verantwoordelijkheid van Deep Reach.

## Scanner

Diepere namen moeten aankomen nadat de speler het schadepatroon al kent. Ze kosten meer omdat het water de misdaad is gaan bewijzen.

## Terminal

ANCHOR SET B: herhaling in pekelkloof en abyssale machinevelden. Bind deze namen aan witness hashes, routeholds, triage-uitzonderingen, Atlas-reparatietegenspraken en sporen van salvageschuld. Set B is waar arbeidersbewijs ophoudt lokale tragedie te zijn en een bedrijfsoorzaak wordt.
