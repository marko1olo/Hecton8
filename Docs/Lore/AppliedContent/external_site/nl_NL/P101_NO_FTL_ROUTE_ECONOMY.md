# Route-economie zonder FTL

De route-economie zonder FTL houdt HECTON-8 eerlijk. Menselijke ruimte kan Aegir in 2190 bereiken, maar elke aankomst bestaat uit lanceervensters, schildmassa, brandstof, remsystemen, bewaarpakketten en jaren betaalde geduld. De setting wordt groot zonder handig te worden. Wet haalt schepen in omdat zij als data reist. Schuld haalt redding in omdat zij vóór de noodsituatie is geprijsd. De speler is niet verlaten door een ontbrekend wonder; hij is verlaten door een economie die nooit wonderen beloofde.
