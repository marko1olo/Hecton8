# Beste route: residu zichtbaar houden

Het sterkste HECTON-8-einde mag de wereld niet repareren tot een beloningsscherm. Het moet de operator concreet werk laten doen: Black Keel-bewaring verlaten, een record publiceren, Deep Reach een terugweg ontzeggen, een levend bekken onder quarantaine bewaren, arbeidersnamen naar buiten dragen of een Atlas proof hash verzegelen waar hij niet als vracht geprijsd kan worden.

Het record moet ook open velden houden. Een betaalde uitgang kan arbeidersnamen weglaten. Publieke vrijgave kan receivers maken die het dossier als wapen gebruiken. Severance kan beschadigde autoriteit stoppen en reparatieleven verwonden. Bewaren kan drukecologie beschermen en de oude sorteerder actief houden. Een goed eindrecord toont wat gered is, de receiver, het schuldeffect, de Atlas-staat en de schade die nog door het systeem beweegt.
