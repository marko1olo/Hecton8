# Logboek voor kabelmantel-reparatiewikkel

Goede kabelreparatie is nuttig lelijk. Ze heeft lagen paniek, vaardigheid en slecht licht. Een werker wikkelde de lijn niet omdat het schema belangrijk leek, maar omdat het andere uiteinde nog telde: pomp, deur, sensor.

De wikkel leest via druk en behandeling. Zout in tapenaad betekent oude reparatie. Zout buiten schone klem betekent latere klem. Vezel onder oppervlakkige slijtage betekent nieuwe beweging. Platte banden tonen belasting.

Gerepareerde kabel kan buit zijn, route, elektrische waarschuwing, bewijs van late werking of de enige eerlijke pijl in een gang van dode borden.
