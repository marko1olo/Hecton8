# Barnard-merk

Barnard Yards is geen nobele geboorteplaats. Het is een werklitteken: scheepssloop, gehuurde cutters, drukklemmen, gereedschap uit derde hand en mensen die precies weten wat een slecht contract kan kosten. De eerste Barnard-stempel op HECTON-8 moet bijna te klein voelen voor lore. Geen toespraak. Een merk op een sleutel, de verkeerde legering op een lockerschanier, een reparatiegewoonte die Deep Reach nooit zou voorschrijven. Voor de speler verandert dat detail het contract. HECTON-8 is niet langer alleen een dode bedrijfsclaim onder vreemd water. Iemand uit dezelfde werfcultuur bereikte deze plek eerder, werkte hier, belandde in dezelfde registers en liet bewijs achter dat klein genoeg is om gewist te worden tenzij een Marauder het opmerkt.
