# Kluisbewijsvarianten

HECTON-8 gebruikt kluisjes als bewijsoppervlakken, niet als nostalgiedozen. Een werkerskluis kan druktape, pakkingfragmenten, gereedschapstokens, maaltijdkredieten, routekrijt, shiftstickers, medlock-weigeringen en latere Marauder-correcties bevatten. Geen enkel object hoeft de ramp alleen uit te leggen. Samen tonen ze dat de verdronken kolonie eerst een werkplek met gewoonten was.

De kracht ligt in terughoudendheid. Een kluis hoeft de speler niet verdrietig te maken. Ze moet tonen wat iemand deed met natte handen en beperkte lucht: een lek dichten, een pakking lenen, een route markeren, een medische weigering bewaren, een maaltijd sparen of een vies gereedschap achterlaten omdat de volgende shift het werk zou afmaken. Zo krijgen procedurele kamers menselijke textuur zonder aparte scene voor elke dode.

Salvage is een keuze. Kleine objecten hebben waarde, maar hun ordening heeft betekenis. Een goede Marauder legt de set vast voordat die hem meeneemt. Een slordige maakt van een persoon losse onderdelen.
