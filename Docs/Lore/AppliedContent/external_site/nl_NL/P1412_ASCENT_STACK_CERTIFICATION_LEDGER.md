# Certificeringslogboek voor de ascent stack

HECTON-8 maakt ontsnapping fysiek voordat het ontsnapping hoopvol maakt. De ascent stack is het hardwarebewijs dat een overlevende omhoog kan bewegen zonder puin te worden. Hij combineert drukzegelringen, een opstijglading, een geleidingsping, thermische schokmarge en ontvangertag tot één lelijk certificaat.

Dat certificaat telt omdat de oceaan geen achtergrond is. Een drukfout kan een capsule bij de eerste burn opensnijden. Een ongemeten lading kan een lichaam voorbij het venster gooien of onder de drager verspreiden. Een ontbrekende ping maakt herstel tot een zoekraster dat niemand wil financieren. Een ontbrekende receiver tag maakt het teruggekeerde lichaam tot een bewaringsprobleem in plaats van redding.

De stack werkt ook als goede gamelore omdat elk onderdeel speelbaar is. Een zegelring kan in een verwoest luik liggen. Een burn-cartridge kan uit salvage mass komen. Een geleidingswieg kan uit relayhardware worden herbouwd. Een shock strip kan bewijzen dat de mof kou, brine en drukcycli overleefde. De speler verzamelt geen abstracte tokens. Hij laat de claim-window-desk zonder excuses komen te zitten.

Wanneer de ascent stack gecertificeerd is, wordt Black Keel niet vriendelijk. De drager verliest alleen één reden om massa te weigeren. Dat is de toon van HECTON-8: de weg omhoog wordt niet uit sympathie gegeven, maar omdat drukwaardig bewijs voor een vijandig systeem beprijsbaar is geworden.
