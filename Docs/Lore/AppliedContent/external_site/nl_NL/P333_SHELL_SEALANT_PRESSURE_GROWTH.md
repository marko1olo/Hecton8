# Drukgroei van schelpafdichting

Reparatie is niet altijd herstel. Deep Reach-noodafdichtingen moesten eerst druk redden. Onder HECTON-8-chemie kan schuim een dragende minerale schelp worden.

Voor het grootboek is dat uitstekend. Voor een Marauder kan hetzelfde succes een route ruïneren: de patch groeit naar binnen, klemt een luik, begraaft gereedschap of isoleert het laatste compartiment achter een muur die technisch werkt.
