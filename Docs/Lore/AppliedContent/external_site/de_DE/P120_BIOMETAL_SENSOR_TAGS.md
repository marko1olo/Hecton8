# Biometall-Sensormarken

Biometall-Sensormarken sind keine generischen Sammelstücke. Sie entstehen, wenn einem Reparatursystem egal wird, ob ein Träger Maschine, Kabelbewuchs oder Tier ist. Die Marke ist eine dünne biometallische Schuppe, die in Gewebe wächst, etwas Strom trinkt, Bewegung speichert und Positionsvertrauen durch Wasser wiederholt. Ein Marauder kann damit einen Pinger abstimmen, Scannerreichweite erweitern oder beweisen, dass eine Route lebte, als Atlas sie berührte. Diese Nützlichkeit ist das Problem. Zieh eine Marke kalt und sie wird Beweis. Zieh sie heiß und das Netz bemerkt vielleicht den fehlenden Träger, antwortet mit falschen Rückgaben oder schickt Reparaturlogik zum verwundeten Tier, zum geschnittenen Kelp oder zum Taucher, der die Marke hält. Das Material verlangt, Beute wie eine Akte zu behandeln: nützlich, schmutzig und noch immer meldend.

## Scanner

BIOMETALL-SENSORMARKEN // Dünne Metallschuppen, in Fische, Kabelkelp und Reparaturgewebe gewachsen. Verbessern Pinger-Abstimmung; heiß geerntet kann Atlas den fehlenden Träger hören.

## Terminal

RESSOURCENKLASSE: Atlas-verändert / beweissensibel. Nutzung: Pinger-Fokus, Scanner-Gitter, Routenvertrauen, Beweispakete. Kalte Ernte empfohlen. Risiken: Aufmerksamkeitsanstieg, falsche Trägerrückgaben, verletzte Fauna.

## Audio

Der Fisch ist keine Drohne. Die Marke meldet trotzdem weiter.

## Field Note

Wenn sie unter dem Messer blinkt, zeichne auf, bevor du schneidest.
