# Feldartikel: Druckanzug-Flicken

Druckanzug-Flicken sind kleine, dichte Beweisflaechen. Dunkles technisches Gewebe, Nahtband, Stiche, Salzschrammen und Abrieb zeigen, ob ein Anzug gewartet, geliehen, verworfen oder fuer eine letzte Rueckkehr benutzt wurde.

Die Lesart ist physisch. Salz unter einer Kante bedeutet feuchte Druckzyklen. Ein glaenzender Halbmond markiert wiederholten Kontakt mit Leitern, Luken oder Kabeln. Ein Flicken ueber einem Gelenk ist riskanter als einer auf flachem Stoff. Fehlt das Drucktest-Tag, kann Beute zur Gefahr werden.

Der Flicken macht menschliches Ueberleben sichtbar, nicht perfekte Sci-Fi-Heilung.
