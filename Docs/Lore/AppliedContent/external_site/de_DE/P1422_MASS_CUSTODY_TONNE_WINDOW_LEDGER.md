# Massen-Custody-Tonnenfenster-Protokoll

HECTON-8 verwandelt Gnade in Lastberechnung, weil diese Welt keine magische Rettung hat. Black Keel kann eine claim hören, ein packet akzeptieren und trotzdem Körperbergung verweigern, bis das nächste Hubfenster die richtige Masse unter richtiger custody tragen kann.

Grausam ist nicht, dass die Rechnung falsch wäre. Grausam ist, dass die Rechnung zuerst sprechen darf. Ein Überlebender wird Körpermasse. Sauerstoff wird Welfare-Schuld. Eine Probe wird versiegelte custody. Eine Blackbox wird Beweis-payload. Quarantäne wird Volumen. Receiver rights werden liability. Der carrier entscheidet nicht, ob diese Dinge wichtig sind. Er entscheidet, welche zusammen bewegt werden können.

So bleibt der Lore spielbar. Beweis erhalten, Kontamination abwerfen, Hardware zertifizieren, Sauerstoff ausgeben, Probe behalten, öffentlichen hash zeigen oder genug Körpermarge schützen: Jede Wahl drückt auf das Protokoll. Der Spieler sammelt keine Abstraktionen. Er kämpft darum, was als bergbar gezählt wird.
