# Feldartikel zu Routentafel und Rückkehrstempel

Routentafeln sind eine der stärksten Brücken zwischen Lore und Spiel, weil sie gewöhnliche Arbeit lesbar machen. Der Spieler braucht keinen Vortrag über Koloniepersonal, wenn eine Lukentafel vier Namen, zwei Werkzeugmarken, ein schlechtes Tidefenster und einen Rückkehrstempel zeigt, der nie gesetzt wurde. Das Objekt erzählt Zeit, Arbeit, Gefahr und Schuld zugleich.

Gute Tafeln müssen benutzt wirken. Fettstift soll älteres Salz kreuzen. Ein Stempel darf ein paar Millimeter schief sitzen, weil die Hand müde, nass oder verängstigt war. Ein Name wird verschoben statt radiert. Solche Details halten die Kolonie menschlich, ohne jedem Toten eine Familienhandlung anzuhängen. Die Arbeiter waren Profis unter Druck, keine dekorativen Opfer.

Für das Design tragen Routentafeln wiederholbare Inhalte. Dieselbe Tafelsprache kann auf Cache, Gefahr, gesperrte Luke, fehlendes Werkzeug, Audiofragment oder prozedurale Raumvariante zeigen. Für die Story zeigt sie Deep Reachs Gewohnheit, menschliche Abwesenheit in verwalteten Status zu verwandeln. HECTON-8 wird unheimlicher, sobald der Spieler begreift: Die Kolonie hörte nicht auf zu arbeiten, bevor sie starb. Sie meldete den Tod weiter als Arbeit.
