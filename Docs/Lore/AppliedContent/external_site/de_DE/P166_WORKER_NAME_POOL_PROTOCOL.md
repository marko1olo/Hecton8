# Arbeiternamen-Register

Das Arbeiternamen-Register definiert, wie HECTON-8 gesiedete Beweise in menschliche Kontinuität verwandelt. Jede Identität entsteht aus geschriebenem Namen, Herkunftsband, Druckarbeitsrolle, Abzeichenfragment, Routenerlaubnis und Schichtmarke. Ziel ist keine Zufallsfarbe, sondern lesbare Verantwortung: wer eine Luke öffnen durfte, wer eine Pumpe wartete, wem medizinische Freigabe verweigert wurde und wessen Spur ein später Marauder stört.

Das System bewahrt persönliche Identität und erlaubt zugleich wechselnde Objektplätze und Beweispaarungen. So entsteht Replay ohne Widerspruch. Ein Arbeiter kann durch Spind, Aufgabenbrett, Routenkarte oder Manifest erscheinen; der Grundsatz bleibt: Menschen werden nicht prozedural verbrauchbar, nur weil ein Raum seedbar ist.

## Scanner

NAMENSSTREIFEN // Herkunftsband, Routengenehmigung, Schichtrolle und beschädigtes Abzeichen gehören zu derselben Person. Erst den Namen lesen, dann den Spind ausschlachten.

## Terminal

NAMENSPOOL-PROTOKOLL // Arbeiteridentitäten bestehen aus stabilem Personennamen, Herkunftsband, Druckberuf, Schichtbuchstaben, Abzeichenfragment und Routenerlaubnis. Das System darf Reihenfolge und Paarungen pro Seed variieren, Menschen aber nie zu Loot-Etiketten machen. Personennamen werden pro Locale geschrieben; Rolle, Route und Zugang tragen die Mechanik.

## Field Note

Namen sind keine Stimmung. Ein Name zeigt, wer in einem nassen Raum sein durfte, als die Station zu lügen begann.
