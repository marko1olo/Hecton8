# Feldführer für xenonische Nahrungs- und Reparaturökologie

Xenon-Omega wird oft als das beschrieben, was Deep Reach stehlen wollte. Das stimmt, ist aber zu eng. Auf HECTON-8 gehört das blaue Material zu einer ventgespeisten Kette: Hitze, Sulfidsalze, Druckdefekte, Pilzblüte, Weider, leitfähiger Biofilm und beschädigte Atlas-Routinen berühren dieselben Oberflächen.

So wird Ökologie spielbarer Beweis. Eine blaue Ader kann Wert, Gift, Stromleck, Räuberverkehr oder alten Reparaturpfad markieren. Ein markiertes Tier kann jagen, weiden oder veraltete Sensordaten durch eine Wartungsschleife tragen. Der Spieler braucht keine saubere Grenze zwischen Natur und Maschine. Die nützliche Frage lautet, was der Prozess jetzt tut und wer profitiert, wenn die Probe überlebt.
