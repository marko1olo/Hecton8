# Paketverwahrung

Eine Nachricht von HECTON-8 zählt nur, wenn Route, Siegel, Empfänger und Schadenszustand mit ihr überleben. Paketverwahrung trägt einen Fakt durch Aegir-Verzug, Anspruchsdruck und Bergung, ohne ihn zu Wegwerffracht zu machen.

## Scanner

PAKETSIEGEL // Zeugenhash-Streifen beschädigt, aber lesbar. Vor dem Bergungsschnitt sichern. Ungesiegelte Beweise werden Anspruchsmaterial.

## Terminal

KEELMARK PAKETNOTAR // Siegelplatte, Zeugenhash, Routenstempel und Steckertag vor Transfer sichern. Ungestempeltes Material kann als Anspruchsverlust laufen.
