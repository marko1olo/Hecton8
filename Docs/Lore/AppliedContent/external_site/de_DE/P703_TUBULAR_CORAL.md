# Röhrenkoralle

Aegir-Bergungsmannschaften auf HECTON-8 melden einen koloniebildenden, röhrenbildenden Organismus, der sich entlang von Rissen in Industrieplatte ansiedelt und nicht über intakter Fläche, wobei er Risse in seit 2147 unbetreuter Struktur füllt und druckdicht verschließt. Es wurden Räume geborgen, die mehrere Megapascal allein durch den Wuchs halten.

Derselbe Wuchs überdeckt die eingestanzte Panelkennung, die für die Strukturzertifizierung verwendet wird. Deep-Reach-Reparaturnachweise aus Sektor 44 schließen solche Räume über Außenbegehung ab, ein Verfahren, das feststellt, dass ein Raum intakt ist, ohne festzustellen, welcher Raum es ist. Feldpraxis ist, jede Bahn, die eine Schweißnaht kreuzt, als tragend zu behandeln.
