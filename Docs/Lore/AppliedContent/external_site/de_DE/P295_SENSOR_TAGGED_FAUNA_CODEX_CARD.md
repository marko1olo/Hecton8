# Kodexkarte: sensorgetaggte Fauna

Sensorgetaggte Fauna zeigt Atlas in seiner prozeduralsten Form. Der Horror ist keine Gedankenkontrolle, sondern alte Überwachungshardware als Körpergeschichte, die beschädigte Wartungslogik wieder als Teil der Karte behandelt.

## Scanner

Sensorgetaggte Fauna. Alter Deep-Reach-Biometalltag in Narbe, Schale oder Wachstumsring. Schwaches Atlas-Routenecho; Tierabsicht nicht bestätigt.

Es gehorcht Atlas nicht. Es trägt eine alte Frage, die Atlas noch immer stellt.

## Field Note

Der Tag ist eine Narbe, keine Leine. Er kann dich melden, falsch platzieren oder etwas wecken, das das Tier nie gesehen hat.
