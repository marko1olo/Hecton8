# Audiofragment-Tags

HECTON-8 sollte Stimme nie als Abkürzung um Beweise herum benutzen. Ein gutes Audiofragment ist ein beschädigtes Objekt, das zufällig spricht.

Der Tag zählt so sehr wie die Stimme. Er sagt, woher der Ton kam, wer ihn erfasste, welches Gerät ihn trug und welcher Schaden das Transkript veränderte. Hydrophonstreifen, Anzugspulen, Blackbox-Scherben und Terminalcaches sprechen verschieden. Ein Hydrophon fängt Raumdruck und Maschinenrhythmus. Ein Anzugrecorder fängt Atem, Handschläge und unterdrückte Panik. Ein Terminalcache fängt, was jemand bewahren wollte. Eine Blackbox fängt, was das System nicht vergessen durfte.

So bleibt Stimme menschlich, ohne manipulativ zu werden. Die Kolonie sollte nicht voller perfekter Sterbereden sein. Sie sollte Fragmente von Arbeit enthalten: halte die Pumpe, zähle den Sauerstoff, öffne die Schleuse nicht, wiederhole die Route, lass die offizielle Zeile sichtbar. Wenn diese Fragmente an Objekte gebunden sind, hört der Spieler Menschen, ohne gesagt zu bekommen, was er fühlen soll.

Für Autorinnen und Designer gilt: kein Objekt, keine Stimme. Das Transkript muss Schaden, Verwahrung und Quelle tragen. Audio kann ein Objekt vertiefen, ein Etikett widersprechen oder eine Route menschlich machen. Es darf das Objekt nie ersetzen.
