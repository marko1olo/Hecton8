# Kapsel-Blackbox-Audio 01

Kapsel-Blackbox-Audio 01 ist das erste ehrliche technische Artefakt von HECTON-8. Es rahmt Überleben als Schuld: Die Landung wurde durch den Verbrauch von Rückkehrhardware erkauft. Der Datensatz gibt Spielern einen geerdeten Grund für die Ozeanfalle, bevor das Konzernmysterium erscheint.

## Scanner

Die erste Blackbox sagt nicht, dass du abgestürzt bist. Sie sagt, dass die Kapsel überlebte, indem sie die Hardware verbrauchte, die sie wieder hochbringen sollte.
