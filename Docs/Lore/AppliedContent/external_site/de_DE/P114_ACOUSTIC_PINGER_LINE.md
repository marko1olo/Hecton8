# Akustische Pingerleine

Die akustische Pingerleine ist kein Rettungsfeuer. Sie ist hörbar gemachte Disziplin. Der Spieler verankert einen return sound, bevor Trübung, brine shimmer oder Angst die Route fremd machen. Das Werkzeug lehrt, dass Navigation Gewohnheit ist und kein map screen.

Spätere Systeme können aus diesem Samen wachsen: relay timing, carrier handshake, akustischer Beweis, dass ein Weg noch existiert. Die erste Version bleibt absichtlich klein. Sie rettet den Spieler vor Selbstvertrauen.
