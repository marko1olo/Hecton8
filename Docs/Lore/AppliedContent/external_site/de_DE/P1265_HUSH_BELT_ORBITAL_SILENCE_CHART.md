# Orbitale Schweigekarte des Hush Belt

HECTON-8 ist nah genug, damit der Orbit zählt, und unzugänglich genug, damit Rettung scheitert. Black Keel kann über Kopf vorbeiziehen, während der Marauder darunter keinen brauchbaren Kanal hat. Hush Belt ist der Name für diesen Widerspruch: Aegirs Magnetwetter, Kestrel-Bedeckung, leitfähige Ozeanchemie und Deep-Reach-Relaisverwahrung.

Funk stirbt zuerst. Laser brauchen freie Sicht durch Sturm, Eisfahnen und Blendung. Akustische Telemetrie überlebt, aber sie ist langsam, schmal und besitzt einen Eigentümer. Jedes nützliche Paket steigt über Boje, Puffer und Quittung. Das Ergebnis ist grausamer Realismus: Stille bedeutet nicht, dass niemand da ist. Sie bedeutet, dass das System genau wie entworfen arbeitet.
