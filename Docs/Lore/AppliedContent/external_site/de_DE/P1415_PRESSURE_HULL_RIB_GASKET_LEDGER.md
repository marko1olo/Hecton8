# Protokoll für Druckrippen und Dichtungen

Druckhüllen auf HECTON-8 sind hässlich, weil sie ehrlich sind. Sie sollten nicht wie Raumschiffe aussehen, sondern verhindern, dass ein Arbeitsraum zum Ozean wird. Platte, Rippe, Dichtung und Verriegelungsseite haben je eine klare Aufgabe.

Die beste Lesung beginnt bei Flecken. Salz wächst unter tiefen Nähten. Schwarzgrüner Biofilm folgt langsamen Lecks. Rost an einzelnen Bolzen zählt weniger als die Linie der ganzen Reihe. Gerade heißt: Das Modul blieb als Körper zusammen. Versetzt heißt: Der Rahmen riss. Herausgepresste Dichtung erzählt von Kompression vor der Flutung.

Im Spiel wird daraus Entscheidung. Der Spieler kann den Einstieg wählen, tragende Rippen meiden, isolierte Platten schneiden oder eine Dichtungsspur als Beweis sichern. Ein einziges Material wird Beute, Schutz, Gefahr und Akte zugleich.
