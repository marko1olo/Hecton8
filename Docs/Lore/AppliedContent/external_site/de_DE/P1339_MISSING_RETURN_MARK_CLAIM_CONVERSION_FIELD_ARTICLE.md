# Fehlende Rückkehrmarke und Anspruchsumwandlung

Rückkehrmarken sind klein, aber sie entscheiden, was eine Route bedeuten darf. Eine geschlossene Route kann auditiert werden. Eine offene Route kann verzögert, übertragen, berechnet, wieder an Ausrüstung gebunden oder als ungeklärte Masse behandelt werden. Auf HECTON-8 zählt diese Mehrdeutigkeit: Arbeiter blieben als unterwegs gelistet, nachdem ihre Räume keine Luft mehr bewegten.

Die Evidenz liegt zwischen Routenstempel und später Claim-Desk-Ausnahme. Sauerstoff gestoppt, Anzugtag in der Bucht, Rückkehrfeld leer: Das ist keine Lücke der Schreibkraft. Das ist eine gehaltene Öffnung. Der Arbeiter bleibt im Vertragszustand, während Körperbeweis woanders hingeht.

Deep Reach braucht keine theatralische Beichte. Ein Pult kann Regeln folgen und das billigere Feld wählen: Route offen, Bergung ausstehend, Ausrüstungsmasse ungeklärt, Salvage-Recht gehalten. Jedes Feld wirkt eng. Zusammen verhindern sie, dass eine tote Route ein geschlossener Verlust wird.

Die Marke gehört neben Routenstempel-Überlagerung, packet-notary-Maskenkante und Transkriptschadensband. Die Objekte stapeln Sequenz: Raumexposition, Routenhandling, fehlender Abschluss, Claim-Desk-Umwandlung.
