# Nachtrag der Kompressoruebergabe

Der Kompressor ist ein schlechter Ort fuer eine saubere Luege. Er hat zu viele kleine Ausfaelle: ein Relais mitten im Klick, ein halb verschmutztes Zaehlerzeichen, eine Ventillippe mit Salz nur auf Raumseite, ein Ablaufbecher, der Sole faengt, bevor der Desk etwas weiss.

Darum zaehlen Uebergabezeilen. Im Deep-Reach-Verfahren konnte eine Raumlast aus lokaler Lebenserhaltung in ein groesseres Konto uebergeben werden. Die Zeile war nuetzlich. Sie sagte Route, Maintenance und Claim Desk, wohin die Luftkosten gingen. Sie bot auch einen Platz, an dem weitergeschrieben werden konnte, nachdem der Raum die Arbeit eingestellt hatte.

Nachtrag braucht keine grosse Faelschung. Eine spaete Zeile reicht, die den Bruch glaettet: compressor accepted, handoff pending, support load carried, route still active. Neben dem Pumpenzaehler gelesen verlieren diese Phrasen ihren Trost. Die Maschine stoppte in Teilen. Die Zeile kam als sauberer Block.

Dieser Eintrag nennt keinen letzten Desk-Besitzer. Er laesst eine weitere harte Fuge: Pumpe, Relais, Ventil, Buch. Bricht diese Fuge vor dem claim hold, wurde die aktive Route von Papier getragen, nicht von Druck.
