# Feldartikel zur abyssalen Knollenebene

Abyssale Knollenebenen lassen Ressourcen in HECTON-8 geologisch statt dekorativ wirken. Eine Manganknolle ist kein leuchtendes Sammelobjekt. Sie ist ein langsames Archiv: ein kleiner Körper mineralischen Wachstums um einen Kern, gebaut von Chemie in Wasser, das lange genug stabil blieb, um sich selbst aufzuschreiben. Wenn der Spieler eine Ebene findet, sollte sie reich und widerwillig zugleich wirken.

Das passt zum Ton. Das Spiel handelt von einem Plünderer allein im tiefen Ozean, nicht von einem Bergmann, der eine Liste leert. Eine Knolle kann genommen werden, aber der Schlick erzählt mehr. Strömungslinien, Staubschatten, leere Ernteringe, Kriechspuren und verfärbte Krusten beschreiben, was vor dem Spieler geschah. Ein vorsichtiger Spieler nimmt Ressource, Route und Beweis mit. Ein grober Spieler nimmt eine Kiste Brocken und eine blinde weiße Wolke.

Für die Welt zeigt die Knollenebene auch, warum Deep Reach moralisch scheiterte, bevor es mechanisch scheiterte. Die Firma sah einen geduldigen Meeresboden und übersetzte ihn in billigen Abbau. Sie bepreiste jede Knolle und rabattierte den Schaden am Sedimentprotokoll, an der Akustikkarte und an den Arbeitern im weiße Sichtnull.
