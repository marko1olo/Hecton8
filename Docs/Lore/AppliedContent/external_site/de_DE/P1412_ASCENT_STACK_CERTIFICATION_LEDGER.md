# Ascent-Stack-Zertifizierungsledger

HECTON-8 macht Flucht physisch, bevor es sie hoffnungsvoll macht. Der Ascent Stack ist der Hardwarebeweis, dass ein Überlebender nach oben gehen kann, ohne Trümmer zu werden. Er kombiniert Druckdichtungsringe, Aufstiegsladung, Führungs-Ping, thermische Schockmarge und Empfängertag zu einem hässlichen Zertifikat.

Dieses Zertifikat zählt, weil der Ozean kein Hintergrund ist. Ein Druckfehler kann eine Kapsel im ersten Burn aufschneiden. Eine ungemessene Ladung kann einen Körper am Fenster vorbeischleudern oder unter dem Träger zerstreuen. Ein fehlender Ping macht Bergung zu einem Suchgitter, das niemand finanzieren will. Ein fehlender Empfängertag macht den zurückgekehrten Körper zu einem Verwahrungsproblem statt zu Rettung.

Der Stack funktioniert auch als gute Spiellore, weil jeder Teil spielbar ist. Ein Siegelring kann in einer zerstörten Luke liegen. Eine Burn-Kartusche kann aus salvage mass entstehen. Eine Führungswiege kann aus Relay-Hardware rekonstruiert werden. Ein Shock Strip kann beweisen, dass die Hülse Kälte, Brine und Druckzyklen überstand. Der Spieler sammelt keine abstrakten Marken. Er lässt dem claim-window-Desk die Ausreden ausgehen.

Wenn der Ascent Stack zertifiziert ist, wird Black Keel nicht freundlich. Der Träger verliert nur einen Grund, Masse zu verweigern. Das ist der Ton von HECTON-8: Der Weg nach oben wird nicht aus Mitgefühl gewährt, sondern weil druckbewertete Beweise für ein feindliches System bepreisbar geworden sind.
