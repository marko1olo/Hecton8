# Akustische Druckleiterkarte

HECTON-8 ist vertikal gebaut. Der Ozean ist eine Leiter aus Druck und Chemie: photischer Schelf, Kabelriff, Solecanyon, Maschinenfeld und Atlas-Becken. Jede Zone verändert, was der Spieler sehen, hören, glauben und reparieren kann. So bleibt Abstieg physisch. Eine tiefere Route bedeutet härtere Dichtungen, schlechteres Rücktiming, fremderen Auftrieb und Beweise aus beschädigten Instrumenten.

Funk fällt früh aus, weil der mineralische Ozean elektromagnetische Signale frisst. Schall bleibt nützlich, doch die Wassersäule formt ihn um. Dichte Sole kann einen Puls fangen und seitlich tragen. Venthitze kann ihn zerreißen. Kabelriffe können ein Signal zurückwerfen, bis ein Korridor offen aussieht. Die Karte ist beängstigend, weil sie praktisch ist: Eine Sonarrückgabe ist keine Wahrheit, bis Druck, Leinenspannung, Bewegung und ein zweiter Ping übereinstimmen.
