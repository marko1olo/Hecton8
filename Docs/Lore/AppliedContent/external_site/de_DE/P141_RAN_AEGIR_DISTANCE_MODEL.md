# Ran-Aegir-Distanzmodell

Das Ran-Aegir-Distanzmodell ist das stille Fundament von HECTON-8s Druck. Aegir liegt in einer grausamen Mittelzone: nah genug, um Routenplatten, Seed-Hardware, Frachtpfandrechte, Fernnotare und eine dauerhafte Förderkolonie zu rechtfertigen; fern genug, dass niemand Barmherzigkeit improvisiert, wenn eine Drucktür versagt.

Dieser Unterschied zählt. Nachrichten, Rechtsansprüche, Trägerpläne, Rettungsschiffe und menschliche Körper laufen nicht auf derselben Uhr. Eine Warnung kann unterwegs sein, während das Schiff, das antworten sollte, noch in Treibstoff, Fenster, Masse und Eigentümerfreigabe steckt. Deep Reach lernte, diese Lücke zu nutzen. Die Kolonie lebte darin.
