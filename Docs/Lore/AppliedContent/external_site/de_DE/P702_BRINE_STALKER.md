# Salzlaugenjäger

Berichte aus den Salzlaugenschluchten von Aegir beschreiben einen Verfolgungsräuber, der an Dichtegrenzen Position hält, wo akustische Echos sich aufspalten und verdoppeln. Mannschaften melden ein einzelnes Tier, das auf derselben Anzeige in zwei Tiefen erscheint, wobei sich das schärfere Echo als falsch erweist.

Feldpraxis auf HECTON-8 ist, sich dem Tier beim ersten Vorbeizug zuzuwenden statt zu beschleunigen. Deep-Reach-Unterlagen aus Sektor 44 vermerken, dass die Patrouille der Art einen außer Betrieb genommenen Evakuierungskorridor überschneidet, und stufen Salzlaugenkontakt als Geräteverschleiß ein.
