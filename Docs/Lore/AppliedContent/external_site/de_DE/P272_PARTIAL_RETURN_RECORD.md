# Datensatz zur Teilrückkehr

Dieser Datensatz markiert eine Atempause der Kampagne, keinen Reset. Er zählt, wenn die Route Extraktionshardware und ein lebendes Carrier-Fenster hat, aber nicht genug Verwahrungsabschluss, um Abholung in Freiheit zu verwandeln.

## Scanner

DATENSATZ ZUR TEILRÜCKKEHR // Black-Keel-Abholung akzeptiert. Rückkehr in denselben Seed unter erweitertem Pfand erlaubt; Scan-Speicher und offene Beweispakete bleiben.

## Terminal

ENDDATENSATZ / TEILRÜCKKEHR
Abholung: temporäre Black-Keel-Extraktion.
Zweck: Anzugreparatur, Luftfüllung, Dekon, Registerabgleich.
Verwahrungsstand: Pfand erweitert; Quarantänefrist angehängt.
Rückkehrbefugnis: derselbe Seed, derselbe Ozean, Routenwarnungen behalten.
Persistente Daten: Scan-Speicher, offene Beweispakete, ungelöste Nutzlast.
Bekannter Verlust: Erleichterung wird berechnet, bevor sie Freiheit wird.
