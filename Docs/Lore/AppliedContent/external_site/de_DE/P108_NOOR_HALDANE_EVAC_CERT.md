# Noor Haldane: Evakuierungszertifikat

Noor Haldane: Evakuierungszertifikat ist ein Deep-Reach-Beweisartikel über Compliance als tödliches Objekt. Haldane ist keine schreiende Schurkin. Sie ist die Beratungssignatur, die Evakuierung rechtlich verteidigbar hält, während die physische Route versagt.

Ihre Sperre besteht aus plausiblen Anforderungen: Druck-Bio-Quarantäne, Trägerverwahrung, externe Routenprüfung, nachgelagerte Hafenannahme, Haftungskette. Keines dieser Wörter ist absurd. Das ist der Punkt. Das System kann im eigenen Rahmen recht haben und trotzdem durch Warten töten.

Der Artikel gibt Spielern eine Möglichkeit, alte Kolonietüren und Routentafeln zu lesen. Ein verriegelter Evakuierungspfad ist nicht nur eine kaputte Maschine. Er kann eine rechtliche Entscheidung sein, die noch auf Prüfung wartet. HECTON-8s Noir entsteht aus dieser Verzögerung: Niemand muss sagen, dass sie sterben sollen, wenn das Zertifikat lange genug 'noch nicht' sagen kann.
