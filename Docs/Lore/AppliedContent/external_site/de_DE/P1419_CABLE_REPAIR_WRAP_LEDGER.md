# Protokoll für Kabelmantel-Reparaturwickel

Gute Kabelreparatur ist nützlich hässlich. Sie besteht aus Panik, Können und schlechtem Licht. Eine Leitung wurde nicht gewickelt, weil sie im Plan wichtig aussah, sondern weil am anderen Ende noch etwas zählte: Pumpe, Tür, Sensor.

Der Wickel liest sich durch Druck und Handhabung. Salz in der Bandnaht bedeutet alte Reparatur. Salz außerhalb einer sauberen Klemme bedeutet spätere Klemme. Faser unter flachem Abrieb bedeutet neue Bewegung. Plattgedrückte Bänder zeigen Last.

Reparierte Kabel sind Beute, Route, Stromwarnung, Beweis später Aktivität oder einziger ehrlicher Pfeil in einem Korridor toter Beschilderung.
