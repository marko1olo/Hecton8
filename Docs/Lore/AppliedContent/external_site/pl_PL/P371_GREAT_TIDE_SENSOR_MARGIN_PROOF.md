# Ślad marginesu Wielkiego Pływu

Pierwszy użyteczny dowód przeciw Deep Reach nie jest przyznaniem się. To margines czujnika, który nagrywał dalej po zatopieniu korytarza. Liczby nie czynią katastrofy sztuczną: obciążenie hydrostatyczne, ścinanie pływowe i awaria infrastruktury naprawdę pokonały HECTON-8. Dlatego dowód ma wagę. Kłamstwo zaczyna się między surowym śladem a publicznym raportem. Surowy ślad oznacza naruszenie marginesu ostrzegawczego przed zamknięciem zatwierdzonego okna trasy. Raport zostawia cascade geotechniczną i usuwa notę accepted-tail-risk. Gracz widzi właściwy kształt winy: fizyka uderzyła kolonię, a potem ludzie z władzą uznali, że ostrzeżenie jest tańsze niż zatrzymanie.
