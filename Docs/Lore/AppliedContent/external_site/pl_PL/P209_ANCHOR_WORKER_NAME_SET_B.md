# Zestaw kotwiczących nazwisk pracowników B

Zestaw kotwiczących nazwisk pracowników B to głębsza powracająca warstwa pracowników HECTON-8. Te nazwiska nie mają łagodzić horroru; mają uczynić system czytelniejszym. Gdy gracz widzi Set B, awarie ciśnienia, blokady tras i opóźnienia triażu mają już wzór. Powtarzane nazwiska łączą ten wzór z ludźmi, a potem z odpowiedzialnością Deep Reach.

## Scanner

Głębsze nazwiska powinny przychodzić, gdy gracz zna już wzór uszkodzeń. Kosztują więcej, bo woda zaczęła już dowodzić zbrodni.

## Terminal

ANCHOR SET B: powracanie w kanionie solanki i abisalnych polach maszyn. Wiąż te nazwiska z witness hashes, blokadami tras, wyjątkami triażu, sprzecznościami napraw Atlas i śladami długu za odzysk. Set B to miejsce, gdzie dowód pracownika przestaje być lokalną tragedią i staje się przyczyną korporacyjną.

## Audio

Głębokie nazwisko kosztuje więcej, bo woda już dowiodła, co się stało.
