# Podpisy Quarantine Review Gate

Warstwa podpisów kwarantanny czyni winę Deep Reach proceduralną. Great Tide stworzył realne ryzyko skażenia i ciśnienia; kłamstwem było użycie tego ryzyka do zatrzymania ludzi i zapisów w lokalnym depozycie, gdy przegląd zewnętrzny pozostawał w tyle. Publiczne raporty nazwały to kwarantanną biologiczno-ciśnieniową i awarią autoryzacji. Odzyskane karty gate dodają twardszy fakt: ekstrakcję wstrzymano językiem certyfikatu nawet tam, gdzie sprzęt trasy jeszcze nie zawiódł.

## Scanner

Odzyskano kartę przeglądu: extraction state HELD, pole BIO/PRESSURE-UNCERTAIN, brak certyfikatu zewnętrznego. Zwolnienie trasy blokuje gate code.
