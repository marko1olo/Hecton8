# Rejestr Władzy Nazw Ran / Aegir

System nazw HECTON-8 nie jest ozdobą. Pokazuje, która władza mówi. Astronomia mówi Ran, bo gwiazda ustala trasy i opóźnienie światła. Biura roszczeń mówią Aegir, bo olbrzym pozwala spiąć księżyce, infrastrukturę i odpowiedzialność. Tabele ubezpieczeń mówią RAN-B:H8, bo uporządkowane księgi nie pamiętają. Ludzie pod wodą mówią HECTON-8, bo tam zawodzi właz.

Gdy dokument zmienia nazwę, często zmienia jurysdykcję. Język Ran należy do czasu i fizyki. Język Aegir należy do własności. RAN-B:H8 należy do katalogu, ubezpieczenia i pieczy. HECTON-8 należy do terenu, pamięci i kolonii jako miejsca.
