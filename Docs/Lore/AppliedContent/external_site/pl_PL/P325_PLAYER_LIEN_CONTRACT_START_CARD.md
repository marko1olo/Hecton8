# Karta startowa kontraktu z lien gracza

Protagonista HECTON-8 to były profesjonalista Deep Reach, który został salvage operatorem. To pochodzenie utrzymuje historię dorosłą i praktyczną: gracz przychodzi po pracę, nie po przeznaczenie. Emocjonalny zwrot zostaje zarobiony przez dowody, kontrakty i rozpoznany dostęp, dzięki czemu tajemnica staje się osobista bez redukowania jej do rodzinnej zemsty.

## Scanner

Karta startowa nie czyni cię wybraną ofiarą. Czyni cię byłym profesjonalistą Deep Reach z lien, kluczem i powodem, by okłamywać samego siebie.

## Terminal

START KONTRAKTU / operator: niezależny salvage contractor / dawny dostęp: Deep Reach field key, nieaktywny, ale rozpoznany / lien: aktywny / deklarowany motyw: claim value / presja ukryta: prior exposure, znajomość trasy, beneficiary conflict.

## Audio

## Field Note

Bez lost-relative hook. Motyw zaczyna się jako praca: salvage value, dawny field access, zawodowa ekspozycja, maskowana presja osobista.
