# Dossier grafu relacji dowodow

## Co dowodzi zapis

Nakladka relacji powstala dla zmeczonych sledczych i przestraszonych zbieraczy, nie dla sedziow. Klada na jednym stole zapisy, ktore dziela obiekt zrodlowy, plyte trasy, fraze roszczenia, hash swiadka, rodzine podpisu, znak obrazenia, stan redakcji albo widoczny skutek. Wzory staja sie widoczne pod presja. Falszywa pewnosc tez.

Zgodny hash nie dowodzi prawdy swiadka. Zgodny podpis nie dowodzi odzyskania zrodla. Wspolny stan redakcji moze znaczyc tylko, ze ten sam urzednik ucial dwa pliki tym samym szablonem. Narzedzie jest uzyteczne, bo wskazuje, gdzie poswiecic uwage: opieka nad pakietem, obiekt zrodlowy, jezyk roszczen, hash swiadka, skutek trasy, powod redakcji i kolejnosc podpisow. Staje sie grozne, gdy linia udaje wyrok.

## Jak to czytać

LEGENDA GRAFU
Zielony: zgodny obiekt zrodlowy lub plyta trasy.
Bursztynowy: zgodna fraza roszczenia lub rodzina podpisu.
Czerwony: zgodny hash swiadka, znak obrazenia lub skutek tlumienia.
Szary: tylko wspolny stan redakcji.
Kazda krawedz wymaga sprawdzenia z lancuchem opieki. Ladny graf nadal moze byc klamstwem z prostymi liniami.

## Notatka terenowa

Nie pozwol czystemu grafowi myslec za ciebie. Linie sa tanie. Podpis i stan redakcji to miejsce, gdzie klamstwo tanieje na tyle, by je wyslac.
