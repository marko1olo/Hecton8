# HECTON-8 i pływy orbity środkowej

HECTON-8 siedzi w zyskownym środku. Orbita daje Deep Reach ocean, który chłodzi maszyny, chowa aktywa, karmi przemysł ciśnieniowy i porusza dość chemii, by uzasadnić claim.
