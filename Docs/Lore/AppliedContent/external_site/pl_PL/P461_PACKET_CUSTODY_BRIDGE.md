# Kustodia pakietu

Wiadomość z HECTON-8 ma znaczenie tylko wtedy, gdy przetrwa z nią trasa, pieczęć, odbiorca i stan uszkodzeń. Kustodia przenosi fakt przez opóźnienie Aegir, nacisk roszczeń i fizyczny odzysk, nie zmieniając go w zwykły ładunek.

## Scanner

PIECZĘĆ PAKIETU // Pasek hash świadka uszkodzony, ale czytelny. Zachować przed cięciem. Dowód bez pieczęci staje się materiałem roszczenia.

## Terminal

NOTARIUSZ KEELMARK // Przed transferem zachować płytę pieczęci, hash świadka, stempel trasy i tag złącza. Materiał bez stempla może zostać stratą roszczeniową.

## Audio

## Field Note

Najpierw pieczęć, potem cięcie. Czysta próbka ze złamanym tagiem należy do tego, kto trzyma rejestr.
