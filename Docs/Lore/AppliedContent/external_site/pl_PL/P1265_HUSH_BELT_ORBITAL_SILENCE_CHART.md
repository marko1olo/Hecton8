# Mapa ciszy orbitalnej Pasa Wyciszenia

HECTON-8 jest dość blisko, by orbita miała znaczenie, i dość niedostępny, by ratunek zawodził. Black Keel może przejść nad głową, a Marauder na dole nadal nie ma użytecznego kanału. Pas Wyciszenia nazywa tę sprzeczność: pogoda magnetyczna Aegira, zakrycie przez Kestrel, przewodząca chemia oceanu i nadzór przekaźników Deep Reach.

Najpierw umiera radio. Lasery potrzebują czystej linii przez burzę, lód pióropuszy i blask. Telemetria akustyczna przeżywa, ale jest wolna, wąska i czyjaś. Każdy użyteczny pakiet idzie przez boję, bufor i pokwitowanie. Wynik jest okrutnie realistyczny: cisza nie znaczy, że nikogo tam nie ma. Znaczy, że system działa dokładnie tak, jak go zaprojektowano.
