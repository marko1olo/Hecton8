# Najlepsza trasa: widoczny osad

Najmocniejszy finał HECTON-8 nie powinien naprawiać świata do ekranu nagrody. Powinien pozwolić operatorowi wykonać konkretną pracę: opuścić depozyt Black Keel, opublikować zapis, odmówić Deep Reach drogi powrotnej, zachować żywy basen w kwarantannie, wynieść nazwiska pracowników albo zapieczętować Atlas proof hash tam, gdzie nie da się go wycenić jak ładunku.

Zapis musi też zostawić otwarte pola. Płatne wyjście może pominąć nazwiska pracowników. Publiczna publikacja może stworzyć odbiorców uzbrojonych w plik. Odcięcie może zatrzymać uszkodzoną władzę i zranić życie naprawcze. Zachowanie może chronić ekologię ciśnienia i utrzymać stary sorter przy pracy. Dobry zapis finałowy pokazuje uratowaną rzecz, odbiorcę, efekt długu, stan Atlasa i szkodę, która nadal porusza się przez system.
