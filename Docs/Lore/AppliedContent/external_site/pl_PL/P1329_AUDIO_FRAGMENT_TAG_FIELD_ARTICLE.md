# Tagi fragmentów audio

HECTON-8 nie powinien używać głosu jako skrótu wokół dowodów. Dobry fragment audio to uszkodzony obiekt, który przypadkiem mówi.

Tag jest równie ważny jak głos. Mówi, skąd pochodził dźwięk, kto go uchwycił, jakie urządzenie go niosło i jakie uszkodzenie zmieniło transkrypt. Paski hydrofonu, szpule skafandrów, odłamki black-box i cache terminali mówią inaczej. Hydrofon łapie ciśnienie pokoju i rytm maszyn. Rekorder skafandra łapie oddech, uderzenia rękawic i tłumioną panikę. Cache terminala łapie to, co ktoś chciał zachować. Black-box łapie to, czego system nie mógł zapomnieć.

Dzięki temu głos pozostaje ludzki bez manipulacji. Kolonia nie powinna być pełna idealnych mów śmierci. Powinna mieć fragmenty pracy: trzymaj pompę, licz tlen, nie otwieraj śluzy, powtórz trasę, zostaw oficjalną linię widoczną. Gdy te fragmenty są przypięte do przedmiotów, gracz słyszy ludzi bez rozkazu, co czuć.

Reguła dla autorów jest prosta: bez obiektu nie ma głosu. Transkrypt musi nosić uszkodzenie, custody i źródło. Audio może pogłębić obiekt, zaprzeczyć etykiecie albo uczłowieczyć trasę. Nigdy nie może zastąpić obiektu.
