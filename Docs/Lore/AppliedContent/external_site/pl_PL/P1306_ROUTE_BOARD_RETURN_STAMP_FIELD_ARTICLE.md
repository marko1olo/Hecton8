# Artykuł terenowy o tablicy trasy i stemplu powrotu

Tablice trasy są mocnym mostem między lore i grą, bo czynią zwykłą pracę czytelną. Gracz nie potrzebuje wykładu o personelu kolonii, jeśli tablica włazu pokazuje cztery nazwiska, dwa znaczniki narzędzi, jedno złe okno pływu i stempel powrotu, którego nigdy nie wbito. Obiekt mówi czas, pracę, zagrożenie i winę naraz.

Dobra tablica dowodowa powinna czuć dotyk. Tłusty ołówek przecina starą sól. Stempel siedzi kilka milimetrów krzywo, bo ręka była zmęczona, mokra albo przestraszona. Nazwisko zostaje przesunięte, nie wymazane. Takie szczegóły utrzymują kolonię ludzką bez rodzinnego wątku przy każdym trupie. Robotnicy byli profesjonalistami pod ciśnieniem, nie dekoracyjnymi ofiarami.

Projektowo tablice wspierają treść powtarzalną. Ten sam język może wskazać skrytkę, zagrożenie, zamknięty właz, brakujące narzędzie, fragment audio albo wariant proceduralnego pokoju. Fabularnie obnaża nawyk Deep Reach: zmieniać ludzką nieobecność w zarządzany status. HECTON-8 jest straszniejsze, gdy gracz rozumie, że kolonia nie przestała pracować przed śmiercią. Nadal księgowała śmierć jako pracę.
