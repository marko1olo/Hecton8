# Artikel Lapangan Tambalan Pakaian Tekanan

Tambalan pakaian tekanan adalah permukaan bukti kecil. Kain teknis gelap, pita jahitan, tusuk, garam, dan abrasi menunjukkan apakah pakaian dirawat, dipinjam, dikutuk, atau dipaksa untuk satu perjalanan pulang lagi.

Pembacaannya fisik. Garam di bawah tepi jahitan berarti siklus tekanan basah. Bulan sabit mengilap menandai gesekan berulang dengan tangga, palka, atau kabel. Tambalan di sendi lebih buruk daripada di kain datar. Tanpa tag uji tekanan, salvage bisa menjadi bahaya.

Tambalan menjaga bertahan hidup manusia tetap terlihat.
