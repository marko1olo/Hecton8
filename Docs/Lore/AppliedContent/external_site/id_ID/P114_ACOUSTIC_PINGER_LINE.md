# Jalur Pinger Akustik

Acoustic pinger line bukan suar penyelamat. Ia disiplin yang dibuat terdengar. Pemain menambatkan return sound sebelum kekeruhan, brine shimmer, atau takut membuat rute terasa asing. Alat ini mengajarkan bahwa navigasi adalah kebiasaan, bukan map screen.

Sistem berikutnya bisa tumbuh dari benih ini: relay timing, carrier handshake, bukti akustik bahwa jalan masih ada. Versi pertama sengaja kecil. Ia menyelamatkan pemain dari rasa percaya diri.
