# Catatan Rib dan Segel Lambung Tekanan

Lambung tekanan HECTON-8 buruk rupa karena jujur. Tugasnya bukan tampak seperti kapal angkasa, tetapi menjaga ruang kerja agar tidak menjadi laut. Pelat menyebar beban, rib menahannya, segel menghentikan air, dan sisi pengunci menunjukkan niat manusia saat membuka.

Pembacaan terbaik dimulai dari noda. Garam tumbuh di bawah sambungan rendah. Biofilm hitam hijau mengikuti kebocoran lambat. Karat pada satu baut kurang penting daripada kelurusan seluruh baris. Baris lurus berarti modul tetap utuh; baris bertangga berarti rangka robek.

Dalam permainan, ini menjadi keputusan: masuk dari sisi pengunci, hindari rib penahan beban, potong pelat yang sudah terisolasi, atau simpan jejak segel sebagai bukti. Laut tidak menambahkan simbol; ia menghapus kenyamanan dan menyisakan rib, garam, dan baut bengkok.
