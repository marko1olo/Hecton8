# Paparan Jatuh

Paparan Jatuh adalah ruang pertama pemain dan tempat perkara pertama. Sebuah kapsul turun setengah terkubur di rumput garam dan keramik hangat, terlalu rusak untuk pergi dan terlalu berguna untuk ditinggalkan. Rangka yang selamat memberi pemain perlindungan, salvage, target pemindai, dan jalur ke Black Keel yang terdengar prosedural sebelum terdengar manusiawi. Nada itu penting. Carrier tidak menjawab seperti teman. Ia menginventarisasi kegagalan: paket naik hilang, uplink retak, operator hidup, wewenang pemulihan belum selesai. Lokasi pembuka mengajarkan HECTON-8 tanpa ceramah. Keindahan itu nyata: bioluminesensi dangkal, warna karang, cahaya badai di bawah Aegir. Kekerasan industrinya juga nyata: bagian bercap, bekas benturan, bahasa klaim, rantai penyelamatan yang sudah menghitung biaya. Pertanyaan pertama praktis: tetap hidup. Pertanyaan kedua tiba di reruntuhan yang sama: siapa yang mendapat untung jika kamu berhasil?
