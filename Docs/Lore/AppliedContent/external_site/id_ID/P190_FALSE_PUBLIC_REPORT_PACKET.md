# Paket Laporan Publik Palsu

Paket Laporan Publik Palsu menyatakan versi publik Deep Reach tentang hilangnya koloni dan penghilangan yang membuatnya palsu. Ini bukan propaganda yang menyangkal bencana; ini propaganda yang menyunting bencana menjadi kecelakaan tanpa tangan yang bertanggung jawab. Artikel ini penting karena memungkinkan HECTON-8 mempertahankan bencana hard-sci-fi sekaligus membuktikan cerita penutup. Fisika samudra menjelaskan mengapa koloni rentan. Memo yang hilang menjelaskan mengapa kerentanan menjadi ditinggalkan.
