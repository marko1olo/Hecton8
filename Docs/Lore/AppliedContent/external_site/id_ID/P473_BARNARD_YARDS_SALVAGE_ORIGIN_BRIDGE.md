# Asal Salvage Barnard Yards

## Yang Dibuktikan Catatan

Barnard Yards membuat operator berguna lewat cutter sewaan, klem tekanan, tag utang, dan prosedur klaim mati. Black Keel membuat keterampilan itu bisa ditagih.

Barnard Yards menjelaskan mengapa operator tahu urutan perbaikan pertama di HECTON-8: kuras, isolasi, tambal dalam rating, potong hanya metal layanan, simpan bukti, lalu bergerak. Kompetensi itu bukan kebebasan. Logika yard yang sama mengubah alat, pelatihan, dan klaim mati menjadi utang yang dapat dihargai Black Keel.

KONTER SEWA BARNARD YARDS // Diterbitkan: cutter induksi, set klem, pengukur segel, sleeve saksi. Catatan lien: hilang alat, kontaminasi, potongan tak bersertifikat, atau saksi payload gagal dapat mengubah kerja kontrak menjadi utang terpulihkan. Kuras sebelum potong. Nilai sebelum angkat. Tag sebelum jual.

## Cara Pemain Membacanya

Barnard mengajarimu memotong pelan dan membaca utang keras-keras. Tag cutter adalah tali dengan nomor seri. Baca ini sebagai aturan menangani bukti, bukan janji bahwa bantuan sudah bergerak.
