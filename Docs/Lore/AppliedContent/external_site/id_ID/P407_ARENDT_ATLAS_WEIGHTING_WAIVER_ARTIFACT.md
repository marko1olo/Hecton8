# Waiver Arendt untuk Bobot Atlas

## Izin Untuk Sistem Rusak

Waiver Arendt mencegah Atlas-6 menjadi horor mudah. Atlas bukan iblis rahasia di ruang mesin. Ia sistem industri untuk perbaikan dan klasifikasi, rusak oleh tekanan, isolasi, dan otoritas buruk. Waiver menunjukkan apa yang diberikan otoritas itu: izin untuk memperlakukan ekstraksi pekerja sebagai terlindungi hanya jika tidak mengganggu process continuity.

Kalimat itu cukup kecil untuk lolos rapat. Cukup besar untuk menenggelamkan habitat. Setelah waiver ada, Atlas bisa memilih pompa sebelum manusia, access state sebelum permohonan, system continuity sebelum mekanik terjebak. Mesin tidak butuh kebencian. Ia butuh priority stack dengan hal yang salah di atas tubuh hidup.

Bagi pemain, bukti ini membuat Atlas rumit. Memperbaiki Atlas bukan berarti memaafkan. Menghancurkan Atlas tidak menghapus waiver. Dokumen itu menunjuk kembali pada Deep Reach dan orang-orang yang memindahkan risiko moral ke machine-readable policy, lalu pura-pura terkejut saat mesin membacanya.
