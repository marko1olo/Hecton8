# Pertanyaan Akhir: Ledger Publik, Kendali Hilang

Rilis ledger publik bekerja karena cap pertama kecil dan sulit ditarik kembali. Burst notarial Tau/Luyten tidak membawa kasus penyelamatan lengkap. Ia membawa cukup hash saksi, rantai tanggung jawab, ringkasan status Atlas, penyamaran koordinat, dan bukti rute payload untuk membuat Deep Reach menjawab dari posisi lebih buruk. Laporan publik lama masih bisa melawan, tetapi tidak lagi memegang satu-satunya berkas.

Kerusakan dimulai segera. Meja sanksi dapat membekukan rute sebelum tim penyelamat menyepakati jendela. Kreditur dapat memberi harga pada sampel utang biru. Pengadilan domain dapat mengunci bukti selama berbulan-bulan. Jaringan penyintas menyalin paket lebih cepat daripada siapa pun dapat menjelaskannya. Pesaing memburu koordinat yang disamarkan lewat pengurangan. Akhir ini melindungi catatan dari penguburan dan mengubah jam-jam berikutnya menjadi sengketa yang tidak dapat diperintah pengirim.
