# Mulai di Sini: HECTON-8

Klaster navigasi pertama harus masuk lewat arsip, bukan ringkasan promosi. Black Keel mencatat HECTON-8 sebagai recoverable ocean claim. Deep Reach menyebut kehilangan itu storm-and-collapse event. Ruangan lama menjawab lain: pump boards, quarantine doors, maintenance routes, dan jejak perbaikan Atlas menunjukkan koloni tidak hilang dalam satu momen.
