# Inventory Stack Tuning Rule

Inventory Stack Tuning Rule defines future stack-size logic for HECTON-8 resources.

## Scanner

Inventory stacks must express physical containment and cargo debt, not arbitrary UI convenience.

## Terminal

STACK RULE: stack by containment vessel, pressure class, contamination stage, carrier lien mass, certification state and sample quality. Generic loot stacks are rejected for critical resources.

If it can break your claim, it should not stack like scrap.
