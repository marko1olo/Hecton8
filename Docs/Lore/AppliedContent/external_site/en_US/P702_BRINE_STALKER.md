# Brine Stalker

Reports from the Aegir brine canyons describe a pursuit predator that holds position along density interfaces, where acoustic returns split and duplicate. Crews report a single animal appearing at two depths on the same display, with the sharper return proving false.

HECTON-8 field practice is to face the animal on its first pass rather than accelerate. Deep Reach records from Sector 44 note the species' patrol overlapping a decommissioned evacuation corridor, and classify brine contact as equipment degradation.
