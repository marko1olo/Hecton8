# Six Returns, No Range

Active sonar sets of the Mark 9 generation apply an upper limit on target extent when computing range. A return exceeding that limit fails the range solution, and the set publishes a bearing with an empty range field rather than declaring a fault.

Recovered sensor tickets from HECTON-8 record series of six or more clean returns held on bearing with no range, filed as a sensor parameter exception with no action taken and the parameter left unchanged. Salvage practice treats an empty range field as size information and calls for shutting down the active set.
