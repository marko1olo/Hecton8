# Masked Deep Reach Beneficiary Clause

Deep Reach appears on HECTON-8 hire sheets as an unnamed beneficial interest rather than a named party. Schedule 3 designates a proxy loss desk, permits onward assignment without notice, and ties recovery channel priority and coordinate release to the beneficiary of record.

## Scanner

Deep Reach is not printed on the hire sheet. It appears where the money, receiver priority and coordinate access converge.

## Terminal

BENEFICIARY TRACE / visible hirer: proxy loss desk / masked beneficiary: Deep Reach-linked shell / liability: insulated / coordinate access: preserved / priority recovery channel: opens before contractor distress lane.

## Audio

If the name is missing but the channel opens first, the owner is still in the room.
