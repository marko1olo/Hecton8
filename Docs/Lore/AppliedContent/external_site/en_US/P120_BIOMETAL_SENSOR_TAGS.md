# Biometal Sensor Tags

Biometal Sensor Tags are not generic collectibles. They are what happens when a repair system stops caring whether a carrier is machine, cable growth or animal. The tag is a thin biometal scale that grows into tissue, drinks a little current, records motion and repeats location confidence through water. A Marauder can use one to tune a pinger, extend scanner range or prove that a route was alive when Atlas touched it. That usefulness is the problem. Pull a tag cold and it becomes evidence. Pull it hot and the network may notice the missing carrier, answer with false returns or send repair logic toward the wounded animal, the cut kelp or the diver holding the tag. The material asks the player to treat loot like a case file: useful, dirty and still reporting.
