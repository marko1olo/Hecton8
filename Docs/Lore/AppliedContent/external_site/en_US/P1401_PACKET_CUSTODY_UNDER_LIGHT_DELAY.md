# Packet Custody Under Light Delay

HECTON-8 is not a setting where truth wins because a Marauder recovers a glowing file. The moon is too far from core law, too close to Deep Reach ownership, and too dependent on carrier queues for that. A document can be true and still be useless if the only surviving copy sits inside the claimant's custody.

The evidence route is mechanical. First, the source has to carry a clock or pressure-state that can be checked against the site. Second, the packet needs a stable hash and a duplicate witness: another terminal, a badge tray, a Black Keel scan, a worker seal, or a physical object that says the file came from that room and not from a legal theater. Third, the payload needs custody outside the claimant's path. Black Keel can move it, but Black Keel is also a contract machine. A Keelmark queue can preserve a packet and still keep it away from public consequence.

This is where the no-FTL setting becomes personal. Light can move claims, threats and notary receipts cheaper than bodies. Deep Reach can send a return-action demand before any civic authority can send rescue. The Marauder has to build a path for truth through the same slow machinery: local relay, carrier custody, Luyten receipt, public receiver. It is not glamorous. It is the difference between a dead worker becoming evidence and a dead worker becoming recoverable mass.

The best HECTON-8 evidence is therefore physical and procedural at the same time. A water-damaged ledger matters because the page still holds a pressure stain. A route stamp matters because it ties a person to a door. A hash matters because it proves the packet did not change after the ocean gave it up. A receiver matters because Deep Reach can survive shame inside its own office, but not a verified packet that leaves the claim.
