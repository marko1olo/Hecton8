# Guide de terrain de l'écologie xénon trophique et réparatrice

Xenon-Omega est souvent décrit comme ce que Deep Reach est venue voler. C'est vrai, mais trop étroit. Sur HECTON-8, la matière bleue appartient à une chaîne nourrie par les cheminées : chaleur, sels sulfurés, défauts de pression, prolifération fongique, brouteurs, biofilm conducteur et routines Atlas endommagées touchent les mêmes surfaces.

L'écologie devient ainsi une preuve jouable. Une veine bleue peut signaler valeur, poison, fuite de courant, passage de prédateur ou ancien chemin de réparation. Un animal marqué peut chasser, brouter ou porter de vieilles données de capteur dans une boucle de maintenance. Le joueur n'a pas besoin d'une frontière nette entre nature et machine. La question utile est ce que le processus fait maintenant, et qui profite si l'échantillon survit.
