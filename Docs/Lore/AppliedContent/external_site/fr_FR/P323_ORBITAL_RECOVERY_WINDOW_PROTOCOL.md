# Protocole de fenêtre de récupération orbitale

Le Protocole de fenêtre de récupération orbitale ancre la boucle d'évasion de HECTON-8 dans l'astronomie locale et l'ingénierie système. Le joueur n'est pas bloqué parce que l'histoire l'exige. Il est bloqué parce que le cisaillement d'Aegir, les interférences magnétiques, la chaîne d'ascension endommagée et l'état légal du receveur ne s'alignent que dans de brèves fenêtres. Le sauvetage devient une route à construire, pas un bouton à presser.
