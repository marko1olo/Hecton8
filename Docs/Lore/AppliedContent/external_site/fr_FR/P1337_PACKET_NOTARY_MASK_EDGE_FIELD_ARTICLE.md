# Bord de masque packet notary

HECTON-8 utilise les marques packet notary pour garder les dossiers endommagés exploitables sans tout révéler d'un coup. Un masque notary peut être légitime. Il peut cacher un nom, une coordonnée de route, un numéro de payload ou une entrée de table en quarantaine. Le problème n'est pas la ligne cachée. Le problème commence quand cette ligne ne partage plus la couche du support abîmé.

Le bord du masque porte la réponse. Si le pigment noir est sous le sel et partage le même lit de rayure que le support, le masque a pu voyager avec la source. Si le pigment passe sur le sel, franchit une rayure ou coupe un route stamp tout en laissant les dommages mécaniques lisibles, le document a été manipulé après le dommage du support. La rédaction devient une action tardive avec un propriétaire.

Cette preuve se lit avec les bandes endommagées de transcription, les bandes hydrophones et les cassettes de baie d'enregistrement. La bande dit ce que le texte lisible reconnaît comme manquant. La bande hydrophone dit ce que la salle a enregistré par l'eau et le métal. Les dents de cassette disent comment le support a bougé. Le bord du masque notary dit qui a essayé de rendre le dossier publié plus propre que l'objet.

En copie publique, la marque peut s'appeler omission légale. Sur le terrain, un Marauder lit d'abord le bord. Du sel sous le pigment et du pigment sur le sel ne racontent pas la même séquence; une seule peut appartenir à la salle.
