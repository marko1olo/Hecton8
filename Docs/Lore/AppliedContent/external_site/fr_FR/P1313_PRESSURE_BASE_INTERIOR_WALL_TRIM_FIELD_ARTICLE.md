# Article de terrain sur garniture murale intérieure de base pressurisée

La garniture murale intérieure est l'un des meilleurs endroits pour rendre HECTON-8 humain sans l'adoucir. Ce n'est pas un décor : c'est une architecture de pression rendue supportable, avec céramique, graphite, caoutchouc, lèvres de service, usure ambre et lignes d'eau.

En jeu, les marques rendent les couloirs lisibles. Une tache basse peut indiquer une ancienne hauteur d'inondation. Une lèvre polie peut mener à un bypass ou une cache. Un panneau bombé avertit d'une pression derrière lui. Un rectangle propre sur mur sale peut être suspect.

Pour l'histoire, les murs contredisent les schémas propres de Deep Reach. Ils gardent les bricolages, les réparations tardives, les lieux d'attente et les retours après date officielle. La colonie a été utilisée, maintenue, masquée puis noyée.
