# Registre de brouillard et contrainte de hublot

Un hublot est l'un des objets les plus cruels d'une colonie noyée. Il a été conçu pour rendre l'océan visible sans le laisser devenir présent. Après l'échec, il continue la moitié de ce travail : on voit à travers, mais cela ne le rend pas sûr.

La lecture commence au bord. Le centre ment parce qu'on l'a nettoyé, surveillé, utilisé par les caméras. Le bord est moins vaniteux. Les arcs laiteux montrent des couches fléchies sous pression. Le brouillard salin sous le joint montre une eau entrée sans invitation. La condensation dans le laminé montre que le côté sec a respiré humide longtemps avant l'effondrement.

Bien lire change le comportement. Identifier une poche sèche, choisir une ligne de coupe moins tendue, préserver la vitre comme preuve de défaillance lente, éviter une salle devenue ressort de pression. Ici le verre n'est pas seulement ressource : il est témoin.
