# Registre du mât relais tordu par l'orage

Le mât relais est l'une des logiques les plus nettes de HECTON-8. Il donne au joueur quelque chose à réparer, une direction visible vers le ciel et un résultat cruel : meilleur contact sans sauvetage garanti. Ce résultat n'est pas un tour. C'est la différence centrale entre être entendu et être récupérable.

Dans la fiction, le mât est une infrastructure locale. Il connaît l'azimut Aegir, les anciens timings relais, le bruit météo et la confiance packet. Il ne possède pas les priorités carrier, les récepteurs de quarantaine, la custody law ni la masse de levage. La réparation peut rendre un message moins cassé, mais elle ne peut pas forcer Black Keel à dépenser une opportunité d'ascension.

C'est pourquoi le premier choix de packet compte. Une fenêtre faible transforme chaque ligne en cargaison : preuve, corps, échantillon, dette, coordonnées, excuse. Le mât est l'outil qui permet au joueur d'envoyer quelque chose dans le système. L'horreur est que le système peut répondre clairement.
