# Carte de route des lunes d'Aegir

La carte des lunes d'Aegir doit se lire comme un tableau d'opérations. Chaque label peut changer âge de signal, abri radiatif, risque de transfert, météo de descente, géométrie de récupération ou calendrier légal de garde. HECTON-8 se trouve dans cette échelle mouvante : les corps internes perturbent le contact étroit, les lunes de glace fragmentent les routes optiques, les bandes d'occultation créent des fenêtres muettes et de vieilles balises gardent des marques de propriété après disparition des équipages. Le matériel public peut montrer le système sans promettre de lunes jouables. La promesse utile est plus précise : quand le joueur lève les yeux depuis l'eau, le ciel peut expliquer pourquoi le relais a trébuché, pourquoi un transporteur a refusé la masse de descente ou pourquoi une réclamation valide a attendu dans le noir.

## Scanner

Enregistrement de carte système. Les labels lunaires fixent âge relais, charge de marée, abri radiatif, diffusion de glace, bandes d'occultation, balises mortes et géométrie de récupération.
