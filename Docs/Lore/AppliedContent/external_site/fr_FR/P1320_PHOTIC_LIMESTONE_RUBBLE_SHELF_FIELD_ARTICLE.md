# Plateau photique de gravats calcaires

Les plateaux photiques se trouvent là où la lumière a encore autorité. À cette profondeur, l'océan n'est pas assez noir pour tout cacher ni assez doux pour pardonner les pas négligents. Les plaques calcaires viennent d'ancien calcium biogène, de grit de coquille et de ciment minéral. Les gravats portent un relevé mêlé : cassures naturelles, extraction coloniale, poussée de tempête, passage de machines et travail patient des petits organismes.

La lecture utile reste locale. Du grit dans une jointure dit que l'eau trie encore le sol. Une poussière pâle sur une marche dit une fracture récente. De l'olive dans les pores dit une stabilité protégée. Une trace circulaire propre peut être pied d'outil, plaque d'ancrage ou ancienne pince de carrière. Si le joueur ne voit que la lumière, le plateau ment. S'il lit la surface, il devient la première carte honnête.
