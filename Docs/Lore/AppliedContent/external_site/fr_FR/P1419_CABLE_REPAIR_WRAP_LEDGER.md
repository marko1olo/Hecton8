# Registre des gaines de câble réparées

Une bonne réparation de câble est laide d'une façon utile. Elle porte panique, compétence et mauvaise lumière. Un ouvrier ne l'a pas faite pour suivre un schéma, mais parce que l'autre bout comptait encore : une pompe, une porte, un capteur.

La gaine réparée se lit par pression et manipulation. Le sel dans la bande indique une réparation ancienne. Le sel autour d'un collier propre indique un collier plus tardif. La fibre sous une éraflure montre un mouvement récent. Une bande écrasée montre un câble tenu sous charge.

Ce câble peut être butin, mais aussi marqueur de route, danger électrique, preuve d'opération tardive ou seule flèche honnête d'un couloir de panneaux morts.
