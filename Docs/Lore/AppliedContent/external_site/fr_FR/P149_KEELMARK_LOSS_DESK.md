# Bureau des pertes Keelmark

Le Bureau des pertes Keelmark n'est pas la main qui noie un couloir. C'est la main qui décide comment ce couloir entre dans les livres. Voilà pourquoi il compte. Un assureur peut faire ressembler un meurtre à la météo si les catégories sont prêtes assez tôt.

Les tables Keelmark enseignent à Deep Reach le langage qui survivra à l'enquête. L'équipement se déprécie. L'habitat est atteint. Le travail est suspendu. Les témoins deviennent exposés, compromis ou irrécupérables. Les noms sont plus lourds, donc le bureau les évite jusqu'à contrainte.
