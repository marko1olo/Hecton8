# Enregistrement de paiement matériel

Cet enregistrement de paiement vaut pour ses champs de reçu : ce que le destinataire a acheté, ce qui manque, quelles coordonnées ont été acceptées, quel échantillon est parti, comment le gage change, quels noms manquent et quel retour Deep Reach obtient.

## Scanner

ENREGISTREMENT DE PAIEMENT MATÉRIEL // Keelmark/Recovery Compliance a accepté coordonnées de bassin et échantillon de dette bleue. Gage opérateur réduit ; preuves ouvrières hors garde notariale.

## Terminal

ENREGISTREMENT DE FIN / PAIEMENT MATÉRIEL
Destinataire : Keelmark/Recovery Compliance.
Accepté : coordonnées du bassin Atlas, échantillon de dette bleue, hash de garde du transporteur.
Non joint : paquet témoin notarié, registre des noms ouvriers, audit de masse de sauvetage.
Effet sur le gage : réduit ou soldé selon table contractuelle.
Effet Deep Reach : chemin de retour plus propre vers HECTON-8.
Perte connue : une preuve peut être chiffrée sans être entendue.
