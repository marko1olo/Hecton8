# Commencer ici : HECTON-8

Le premier cluster de navigation doit entrer par les archives, pas par un résumé promotionnel. Black Keel classe HECTON-8 comme recoverable ocean claim. Deep Reach décrit la perte comme storm-and-collapse event. Les anciennes salles répondent autrement : pump boards, quarantine doors, maintenance routes et traces de réparation Atlas montrent que la colonie n'a pas disparu en un seul instant. Cette entrée rassemble les questions de base : qui est le Maraudeur, pourquoi la dette compte, pourquoi l'aide n'arrive pas immédiatement, ce que cache la langue officielle et pourquoi les premières preuves se trouvent dans le travail de pression plutôt que dans un destin héroïque.
