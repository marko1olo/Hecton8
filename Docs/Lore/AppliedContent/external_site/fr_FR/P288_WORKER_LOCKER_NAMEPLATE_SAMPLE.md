# Échantillon de plaque de casier ouvrier

L'Échantillon de plaque de casier ouvrier transforme un seul casier en dossier humain compact. Ren Okoye survit par accès de route, certification d'outil, jeton repas et cicatrice d'effacement. L'objet montre le style de preuve central de HECTON-8 : l'identité préservée par le travail quand la mémoire de paie échoue.

## Scanner

La plaque de Ren Okoye garde le nom parce que la ligne de paie était plus facile à effacer que le travail.

## Terminal

LOCKER CROSSCHECK / OKOYE, REN / ROUTE B: VALID / CLAMP CERT: ACTIVE / MEAL TOKEN: PRESENT / PAYROLL STATUS: OVERWRITTEN BY LOSS DESK / ERASURE INCOMPLETE.

## Audio

Nom conservé. Ligne de paie effacée. Travail encore attaché.

## Field Note

REN OKOYE / Clamp Route B / cutter cert active / jeton repas sous ruban. Bande paie poncée ; marque de taille de gant encore visible.
