# 벤트 앵커 군체

벤트 앵커 군체는 자원에 관한 서사 문제의 답이다. 좌초한 Marauder 는 왜 위로만 수리하지 않고 더 깊이 내려가야 하는가? HECTON-8 의 압력을 견디는 부품은 바다가 가장 적대적인 곳에서 태어나기 때문이다. 벤트 앵커는 열수 출구 주위에서 살아 있는 클램프처럼 자라며, 황화물, 열 순환 광물, 세라믹 전구체를 늑골형 선반에 가둔다. 생태와 제작을 근거 있게 연결한다. 군체는 보물 노드가 아니다. 맥박을 가진 위험한 산업 공정이다. 작은 동물상은 더 차가운 늑골에 숨어 있다. Brine vanes 는 뜨거운 플룸에서 말려 물러난다. 밀도 스케이터는 따뜻한 계단을 건널 수 있지만 흰 목구멍은 결코 건너지 않는다. 좋은 조우는 플레이어가 같은 물체에서 수리 경로와 죽음의 구역을 보게 해야 한다. 앵커는 말한다. 필요한 재료는 존재한다. 하지만 안전하게 가져갈 수는 없다. 여기서 Deep Reach 의 역량도 설득력을 얻는다. 기업은 유용한 압력 화학을 무에서 발명하지 않았다. 바다가 이미 돌리던 공정을 수확하고 표준화하는 법을 배웠고, 끓는 물에서 샘플을 자르러 보낸 사람들 주변에 liability paperwork 를 구축했다.
