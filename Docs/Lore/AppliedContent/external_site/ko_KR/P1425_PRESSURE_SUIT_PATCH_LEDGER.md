# 압력복 수리 패치 장부

완벽한 압력복은 브로슈어의 물건이다. HECTON-8은 브로슈어가 아니다. 중요한 수트는 패치가 붙고, 무릎과 소매가 닳고, 이음 주위가 짜며, 한 번 더 내려갈 만큼 버티는 천으로 수리되어 있다.

좋은 패치는 사회 정보를 담는다. 공장은 균일하다. 감독자는 맞는 테이프를 쓰지만 시간이 없다. 노동자는 틀린 실을 쓰고 몸이 굽는 곳을 안다. 의료 수리는 빠르고 못생겼다. 블랙 킬은 식별자를 먼저 벗긴다.

패치는 사물함, 의무실, 잠긴 탈의실, 버려진 작업대에 속한다. 모든 시신에게 연설을 시키지 않고도 식민지를 개인적으로 만든다.
