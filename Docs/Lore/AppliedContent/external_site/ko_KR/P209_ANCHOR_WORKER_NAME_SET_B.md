# 앵커 작업자 이름 세트 B

앵커 작업자 이름 세트 B는 HECTON-8의 더 깊은 반복 작업자 층이다. 이 이름들은 공포를 누그러뜨리기보다 시스템을 더 읽기 쉽게 만들어야 한다. 플레이어가 Set B를 볼 때쯤이면 압력 실패, 항로 보류, triage 지연에는 이미 패턴이 있다. 반복되는 이름은 그 패턴을 사람에게, 그리고 Deep Reach의 책임으로 연결한다.

## Scanner

더 깊은 이름은 플레이어가 손상 패턴을 이미 이해한 뒤에 도착해야 한다. 물이 범죄를 증명하기 시작했기 때문에 더 무겁다.

## Terminal

ANCHOR SET B: 염수 협곡과 심연 기계장 반복. 이 이름들은 witness hashes, 항로 보류, triage 예외, Atlas 수리 모순, salvage 부채 흔적에 묶어야 한다. Set B는 작업자 증거가 지역 비극을 멈추고 기업 원인이 되는 지점이다.
