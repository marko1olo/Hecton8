# payload 좌표 판매 수신 프로토콜

이 프로토콜은 단순한 전리품 판매가 아니다. 도달권의 이전이다. Deep Reach에는 HECTON-8을 두고 다툴 문서가 이미 충분하다. 부족한 것은 손상된 분지를 통과해 돌아갈 신뢰할 길이다. payload는 좌표, 신뢰, 증거 보관, salvage 등급을 묶어 그 길을 제공한다.
