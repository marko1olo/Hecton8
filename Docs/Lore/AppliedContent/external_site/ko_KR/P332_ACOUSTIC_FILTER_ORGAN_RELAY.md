# 음향 필터 기관 중계기

무전이 죽는 깊이 아래에서 소리는 주 계기다. 케이블 암초는 그것을 복잡하게 만든다. 깨진 하우징은 울리고, 금속 매트는 산란시키며, 폭풍 펄스는 거리를 흐리고, 살아 있는 조직은 발신과 반환 사이에 낀다.

그래서 소나는 깨끗한 진실이 아니다. 중계기는 문을 드러낼 수도, 포식자를 먹일 수도, 낡은 경고를 반복할 수도, 같은 복도를 두 번 보이게 할 수도 있다.
