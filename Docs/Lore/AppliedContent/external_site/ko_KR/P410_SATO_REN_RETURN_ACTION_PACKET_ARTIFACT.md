# 사토-렌 Return Action Packet

## Claim 순서로 말해지는 구조

사토-렌 packet은 현재형 압력이다. 플레이어가 오래된 memo와 ledger에서 Deep Reach가 무엇을 했는지 배운 뒤 도착하며, 회사가 아카이브 속 시체만이 아님을 증명한다. Deep Reach는 아직 말한다. 다만 시스템이 이해하는 순서로 말한다. coordinates, access state, sample custody, silence acknowledgement, extraction language.

그 순서가 위협이다. 구조 서비스는 어디를 다쳤는지 묻는다. recovery desk는 무엇을 운반하는지, 누가 certify할 수 있는지, Atlas가 아직 route를 열 수 있는지, 이동 조건으로 silence를 받아들이는지 묻는다. 사토-렌에게 HECTON-8 위의 군함은 필요 없다. packet 자체가 leverage다. 메시지는 드물고 질량은 비싸며 플레이어는 debt-bound이기 때문이다.

여기서 late game은 도덕적으로 좁아져야 한다. 같은 문서도 플레이어가 아는 것에 따라 도움, repossession, 협박처럼 보인다. 그것은 오래된 익사한 관료제와 Marauder 앞의 살아 있는 선택을 연결한다. 좌표를 팔 것인가, proof를 지킬 것인가, Atlas를 sever할 것인가, ledger를 공개할 것인가, 아니면 rescue에도 claim number가 붙는 바다를 계속 지나갈 것인가.
