# 대조석 여유율 흔적

Deep Reach에 대한 첫 유효 증거는 자백이 아니다. 복도가 잠긴 뒤에도 기록한 센서 여유율이다. 숫자는 재난을 인공으로 만들지 않는다. 정수압, 조석 전단, 실패한 인프라가 실제로 HECTON-8을 압도했다. 그래서 증거가 중요하다. 거짓은 원시 흔적과 공개 보고서 사이에서 시작된다. 원시 흔적은 승인된 경로 창이 닫히기 전 경고 여유율 파손을 표시한다. 공개 보고서는 지질공학 cascade를 남기고 accepted-tail-risk 메모를 삭제한다. 플레이어는 거기서 죄의 정확한 형태를 본다. 물리가 식민지를 쳤고, 권한을 가진 사람들이 경고보다 정지를 비싸게 계산했다.

## Scanner

회수된 조석 센서. 최대 전단은 식민지 설계치를 넘었지만, 경고 여유율 파손은 공개 cascade 시각보다 먼저 기록됐다.
