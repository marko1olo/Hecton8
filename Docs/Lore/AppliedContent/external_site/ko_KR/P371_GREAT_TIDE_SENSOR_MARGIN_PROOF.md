# 대조 마진 흔적

쓸모 있는 재난 기록은 장식을 거부하는 데서 시작한다. P-63 조석 배열은 바다를 고발하지 않는다. 전단 스파이크, 압력 마진 붕괴, 그리고 복도보다 오래 전력을 버틴 brine-buffer 메모리에 남은 체크섬을 기록한다.

그래서 이 흔적이 중요하다. Deep Reach는 대조를 가리키며 실제 사건을 말할 수 있었고, 행동의 근거가 되는 줄은 숨길 수 있었다. 마진이 정지 하한 아래로 떨어졌을 때 식민지에는 아직 항로 결정이 남아 있었다. 공개 보고서는 캐스케이드를 남기고 상업 예외를 제거해, 지연된 정지 명령을 날씨로 바꾸었다.
