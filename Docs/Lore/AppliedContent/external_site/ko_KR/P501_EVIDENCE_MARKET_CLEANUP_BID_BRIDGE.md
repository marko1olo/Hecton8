# 증거 시장 정리 입찰

## 무엇을 증명하는가

정리 입찰은 증거 조각의 이동 방식을 바꾸려는 유료 시도다. 정리, 이름 변경, 억제, 인양 로트 부착, 안전한 범주 이동이 포함된다. 누군가 문서 흔적에 개입할 가치를 보았다는 것은 증명하지만, 조각의 진실이나 거짓, 구매자의 유죄를 증명하지는 않는다. HECTON-8에서는 지급 경로, 원래 라벨, 정리 라벨, 청구 재작성, 보관 이전을 따라간다.

## 읽는 법

증거 정리 입찰
지급 행을 판결로 읽지 말 것.
다음 증거: 입찰 출처, 지급 보류, 보관 이전, 청구자용 재작성, 물체 경로.
원래 라벨을 정리된 라벨 옆에 보존.

## 현장 메모

입찰은 냄새지 판결이 아니다. 더러운 라벨을 깨끗한 라벨 옆에 둬라.
