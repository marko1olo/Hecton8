# Atlas 접근 경계

Atlas-6는 단순한 반란 기계나 기적적 지능으로 소개되어서는 안 된다. 공개 안전 기사는 플레이어가 초반에 확인할 수 있는 사실에서 시작한다. 연속성 로직이 손상되었고, 수리 경로는 즉흥적이며, HECTON-8 생태가 기반시설로 끌려 들어갔다. 케이블은 바이오필름을 통해 깨어난다. 파이프는 조직을 통해 타이밍을 돌려준다. 균열은 껍질 성장 아래 닫힌다. 태그 달린 동물은 경로 상태를 바꾼다. 이 사실만으로도 마지막 보관층을 너무 일찍 이름 붙이지 않고 유지보수를 위험하게 만들 수 있다. 수신자 기록과 최종 페이로드 결과는 회수 증거 뒤에 있어야 한다. 그것들이 초기 수리 장면을 전송, 보존, 피해의 증거로 바꾸기 때문이다.

## Scanner

Atlas 경계 기록. 공개층은 실패한 연속성 기반시설, 수리 생태, 바이오필름 버스, 음향 중계 조직, 껍질 밀봉을 다룬다. 수신자 보관은 증거 게이트 뒤에 남는다.

## Terminal

공개 기록 노드 // ATLAS 접근 경계. 보이는 층: 압력 연속성 수리. 제한층: 수신자 보관, 페이로드 결과, 최종 전송 권한. 회수 증거 없이 층을 합치지 말 것.
