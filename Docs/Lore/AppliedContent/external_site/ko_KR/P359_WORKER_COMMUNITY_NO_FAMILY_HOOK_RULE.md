# 작업 연락처 공지

작업 연락처 공지는 단단한 가장자리를 가진 작은 사회 문서다. 침상 열, 경로 책임자, 의료락 증인, 공구실 연락처, 중계 창을 나열한다. 압력의 논리가 보이기 전에는 행정처럼 보인다. 그러나 외부 연락처는 슬퍼하고 다투고 기억할 수 있어도 물보다 먼저 해치에 도착할 수 없다.

그래서 HECTON-8에서 긴급 연락처란 스테이션 안에 있고, 훈련되었고, 톤으로 호출 가능하며, 작업자의 경로에 들어갈 수 있는 사람이다. 정의는 엄격하지만 무정하지 않다. 놓친 귀환이 침수 경로가 될 수 있는 곳에서 돌봄은 그런 형태를 띤다.

게시판은 일상 증거를 공동체의 그물로도 묶는다. 한 유물의 펌프 키, 다른 장부의 물 수정, 세 번째의 공구 서명. 각 표식은 지친 작업자를 다른 작업자에게 붙인다. 이것은 멜로드라마가 아니라 책임이 친밀함의 형태가 된 그럴듯한 압력 정착지다.
