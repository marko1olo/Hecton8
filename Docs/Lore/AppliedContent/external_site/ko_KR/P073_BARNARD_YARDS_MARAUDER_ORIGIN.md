# 바너드 야드 마로더 기원

바너드 야드 마로더 기원은 HECTON-8의 빚 묶인 salvage 계급을 규정한다. 마로더는 죽은 청구를 미스터리 관광이 아니라 계산이 나쁜 일로 다루는 노동 문화에서 온다.

## Scanner

바너드 공구 각인. 선박 해체 문화. 깔끔한 구조 조항을 의심하는 법을 가르치는 곳.

## Terminal

BARNARD YARDS SERVICE MARK: 비상 클램프 승인. Salvage 인증은 버려진 압력 거주구, 죽은 carrier compartment, 방치된 claim hull에 유효.
