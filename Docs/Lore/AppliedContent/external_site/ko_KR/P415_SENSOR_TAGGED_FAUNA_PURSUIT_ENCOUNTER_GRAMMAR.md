# 조우 문법: 센서 표식 생물의 추격

센서 표식 추격은 Atlas를 악당의 명령이 아니라 손상된 해석으로 보여준다. 해롭지 않거나 겁먹은 동물도 위험해질 수 있다. 오래된 기반 시설이 아직 그 흉터를 원격 측정으로 취급하기 때문이다.

## Scanner

센서 표식 생물 추격. 오래된 바이오메탈 표식이 수리 네트워크의 메아리를 돌려보낸다. 동물의 움직임은 국소적이지만, 네트워크의 해석은 그렇지 않다.

## Terminal

조우 문법 / 센서 표식 추격 / 역할: 손상된 유지보수 피드백, 은신처 오염 위험, 악당 없는 압박 / 안전한 해석: 표식 맥박이 움직임보다 늦고, 동물은 고통을 피하며, Atlas 경로 메아리는 마지막으로 알려진 길을 따른다 / 거부: 정신 지배 구도, 깔끔한 적대 AI 행동, 표식 동물을 기지 은신처로 유도 / 경로 메모: 각도, 침묵, 차폐로 메아리를 끊어라. 네트워크에 집의 위치를 가르치지 마라.
