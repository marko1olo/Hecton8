# 릴레이 스파인

HECTON-8에는 ansible도, 마법 같은 비상 채널도, 바다 위로 실시간 말하는 핵심 세계 법원도 없다. 인간권은 예정된 빔, 패킷 보관, 증인 해시, 로컬 버퍼, 영수증 사슬로 이어진다. 사실을 보존하는 데는 강한 기계다. 지금 공기가 필요한 사람을 구하는 데는 형편없다.
