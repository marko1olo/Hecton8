# Atlas-6 공개 수리망

## 기록이 증명하는 것

Atlas-6는 서비스 우선순위, 비상 경로, 정비 대기열, 압력 수리 통로를 뜻할 때만 공개 기록에 남길 수 있다. 이것은 분지의 최종 진실이 아니다.

공개 Atlas-6 언어는 산업 경로 용어다. 수리 우선순위, 비상 안내, 연속성 기록, 제작기 일정을 표시한다. 태그를 따라가되 물리적 수리와 대조하라. 침수선, 압력 칼라, 작업자 동선, Black Keel 보관 상태, 이후 블랙박스 조각이 중요하다.

ATLAS 연속성 사무소 // 공개 내보내기는 서비스 라벨, 경로 표식, 압력 등급, 손상 상태, 수리 우선순위를 보존할 수 있다. 분지 분석, Xenon-Omega 공정 제어, 미해결 수신 권한은 붙이지 말 것.

## 플레이어가 읽어야 할 것

공개 이름은 답이 아니라 지도다. Atlas-6 태그를 따라간 뒤 그 수리가 무엇을 지켰고 누가 기다렸는지 묻는다. 이것은 증거 처리 규칙이지, 구조가 이미 움직인다는 약속이 아니다.
