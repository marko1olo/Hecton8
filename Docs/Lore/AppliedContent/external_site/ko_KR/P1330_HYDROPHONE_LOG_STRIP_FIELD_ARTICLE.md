# 하이드로폰 로그 스트립

하이드로폰 스트립은 소리를 물리적으로 만들기 때문에 HECTON-8에서 가장 유용한 증거 물체 중 하나다.

        오래된 방 녹음기를 지나가는 좁은 세라믹 섬유 테이프다. 녹음기는 사람이 아니라 압력실을 들었다. 펌프 박자, 해치 충격, 케이블 끊김, 공구 타격, 선체 장력, 물과 금속을 지난 번진 목소리를 잡았다. 스트립은 단순해서 살아남았다. 살아 있는 네트워크, 깨끗한 단말기, 협조적인 회사 기록 보관소가 필요 없었다. 압력, 잉크, 움직임만 필요했다.

        플레이어에게 스트립은 법의학 물체처럼 읽혀야 한다. 오디오는 섬뜩해도 되지만 증거는 불일치에 있다. 승인 전 문 충격, 신고된 정지 뒤 펌프음, 다른 녹음기도 동시에 평평해지는 사라진 1초, 살아 있는 오퍼레이터가 서명하지 않은 경로 스탬프 옆 목소리 모양. 이것은 독백이 아니다. 방이 자기 서류에 반박하는 것이다.

        HECTON-8에 필요한 톤은 이것이다. 작업 표면을 통해 회수되는 인간의 흔적. 스트립은 플레이어에게 무엇을 느끼라고 말하지 않는다. 위쪽 사람들이 안의 사람보다 서류를 더 중요하게 여긴 뒤에도 계속 일하려던 장소를 들려준다.
