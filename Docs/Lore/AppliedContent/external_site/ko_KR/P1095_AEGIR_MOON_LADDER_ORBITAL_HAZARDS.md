# Aegir 달 사다리

Aegir 달 사다리는 구조가 바다만 이기면 된다는 플레이어의 본능을 먼저 고친다. HECTON-8 위에는 빈 하늘이 아니라 바쁜 거대 행성권이 있다. Ran은 빛을 주고, Aegir는 중력, 방사선, 잔해 날씨, 전이 시각을 주며, 달들은 물 위의 공간을 움직이는 자물쇠로 만든다.

각 단은 서로 다른 확실성을 깬다. Skarn은 정상 전자장비를 간헐적으로 만든다. Vela는 광학과 carrier 링크를 흩뜨린다. Claw는 기계가 아직 따르는 낡은 항로 논리를 보존한다. Lumen은 패킷 통과를 증명하지만 공정한 취급은 증명하지 않는다. Thorne은 격리 의심을 운반한다. Anvil은 salvage 장비에 화물법을 남긴다. Kestrel은 잘못된 자리에 서기만 해도 창을 압축한다. HECTON은 물, 압력, 폭풍 플룸을 준다. Mute는 죽은 항로도 서류 위에서 살 수 있음을 증명한다.

따라서 Black Keel은 영웅적인 모선이 아니다. 이 기하 안의 claim-tender다. 몸을 들어 올리려면 신호 보관, 깨끗한 payload hash, 격리 핸드셰이크, 유도 신뢰도, 보험이 받아들이는 톤수 창이 필요하다. 밝은 하늘은 쓸모없을 수 있다. 참된 신호도 너무 늦게 올 수 있다. 사다리는 고립을 물리적, 법적, 천문학적으로 동시에 만든다.
