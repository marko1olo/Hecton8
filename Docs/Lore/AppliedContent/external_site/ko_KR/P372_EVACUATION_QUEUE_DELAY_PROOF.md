# 대피 대기열 지연 기록

시신이 사라진 뒤 대피 로그는 쉽게 부드러워진다. 공개 언어에서 Deep Reach는 경로가 미완료, 중단, 저하되었다고 말할 수 있다. 회수된 대기열 시계는 덜 휘어진다. 압력 경보가 점유 구역으로 들어간 뒤에도 게이트가 행정 상태에 반응했음을 기록한다.

중요한 점은 모두를 구할 수 있었다는 보장이 아니다. 기록은 그런 약속을 하지 않는다. 회사에 아직 제어 경로가 있었고 그것을 기다림에 사용했다는 사실을 보여 준다. 수동 확인은 비어 있었다. 격리 위원회는 대기 중이었다. 해제 승인 전에 실 등급이 한계를 넘었다. 지연이 기반 시설이 되었다.
