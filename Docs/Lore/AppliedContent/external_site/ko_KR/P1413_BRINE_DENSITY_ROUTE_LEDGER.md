# 염수 밀도 경로 장부

Brine Stairs 는 경로와 함정 사이에 있다. 멀리서는 밝은 턱과 흰 단이 어둠 속으로 쌓인 구조물처럼 보인다. 가까이서는 움직이는 화학이다. 무거운 염수가 균열 속 두 번째 바다처럼 보통 물 아래에 놓인다. 경계는 빛나고, 때로 돌처럼 자신 있게 sonar 에 답한다.

그래서 옛 경로판은 '여기서 내려가라'고 쓰지 않는다. 측면 ping, 두 번의 트림, 온도, 케이블 상처, 섞이지 않는 실트. 좋은 횡단점은 선이 아니라, 바다가 거짓말한 뒤에도 반복되는 행동이다.

몇몇 대피 포드는 존재하지 않는 바닥 좌표에서 사라졌다. 마지막 ping 은 세 번째 밀도 커튼 아래에서 왔다. Deep Reach 는 항법 오류로 처리했다. 경로판은 케이블 상처를 남겼다.

게임에서는 같은 규칙이 행동이 된다. 소음을 숨기고, cutter 를 식히고, 보존된 태그를 회수하고, 빛 없이 협곡을 건넌다. 나쁜 ping 각도, 오래된 밸러스트, 손상된 씰, 공황 하강은 경로를 구덩이로 바꾼다.
