# 물적 지급 기록

이 지급 기록에서 중요한 것은 영수증 필드다. 수령자가 무엇을 샀는지, 무엇이 빠졌는지, 어떤 좌표가 수락됐는지, 어떤 샘플이 나갔는지, 유치권이 어떻게 바뀌었는지, 어떤 이름이 없는지, Deep Reach가 어떤 복귀 경로를 얻었는지다.

## Scanner

물적 지급 기록 // Keelmark/Recovery Compliance가 분지 좌표와 블루-부채 샘플을 수락. 작업자 증거는 공증 보관 밖에 남고 운용자 유치권은 감액됨.

## Terminal

엔딩 기록 / 물적 지급
수령자: Keelmark/Recovery Compliance.
수락: Atlas 분지 좌표, 블루-부채 샘플, 운반체 보관 해시.
미첨부: 공증 증인 패킷, 작업자 이름 장부, 구조 질량 감사.
유치권 효과: 계약표에 따라 감액 또는 종료.
Deep Reach 효과: HECTON-8로 돌아가는 더 깨끗한 경로.
확인된 손실: 증거는 들리지 않은 채 가격이 매겨질 수 있다.
