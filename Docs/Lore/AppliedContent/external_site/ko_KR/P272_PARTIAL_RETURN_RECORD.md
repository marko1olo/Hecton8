# 부분 귀환 기록

이 기록은 캠페인의 숨 돌림이지 초기화가 아니다. 경로에 추출 장비와 살아 있는 운반체 창이 있지만, 회수를 자유로 바꿀 만큼의 보관 종료가 없을 때 쓰인다.
