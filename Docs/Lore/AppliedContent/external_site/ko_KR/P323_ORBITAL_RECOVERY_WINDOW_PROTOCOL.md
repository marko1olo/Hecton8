# 궤도 회수 창 프로토콜

궤도 회수 창 프로토콜은 HECTON-8의 탈출 루프를 지역 천문학과 시스템 공학에 접지한다. 플레이어가 이야기가 원해서 좌초된 것이 아니다. Aegir의 폭풍 전단, 자기 간섭, 손상된 상승 사슬, 법적 receiver state가 좁은 창에서만 맞기 때문에 좌초된다. 구조는 누를 버튼이 아니라 만들어야 할 경로가 된다.
