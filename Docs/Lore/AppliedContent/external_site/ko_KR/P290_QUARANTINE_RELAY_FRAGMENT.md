# 검역 릴레이 파편

검역 릴레이 파편은 HECTON-8 생존의 쓰라린 경계를 정의한다. 이 배경은 수압에서 도망치는 것만이 아니라, 홍수 뒤에도 살아남은 기록, 구금 사슬, 소유권 청구에서 도망치는 이야기다. 파편은 엔딩에 더 단단한 형태를 준다. 누군가는 바다에서 회수될 수 있지만 여전히 자유롭지 않을 수 있다.

## Scanner

같은 릴레이 패킷이 추출을 승인하고 석방을 거부한다. 바다는 몸을 놓아주지만 식민지는 사람을 놓아주지 않는다.

## Terminal

릴레이 보류 QRF-17 / 추출: 승인 / 석방: 거부 / 사유: 샘플 보관 미해결, 공기 검토 만료, 청구자 분쟁 활성, 증인 상태 임시.

## Audio

릴레이 보류. 추출 승인. 석방 거부. 물 밖으로 나왔지만 구금 밖은 아니다.

## Field Note

도장 두 개: 신체 회수, 인원 보류. 공기 검토는 구조 영수증보다 오래되었다. 청구자 분쟁은 아직 열려 있다.
