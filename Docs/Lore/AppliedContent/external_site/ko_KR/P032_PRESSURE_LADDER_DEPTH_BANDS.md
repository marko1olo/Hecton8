# 압력 사다리

압력 사다리는 HECTON-8의 심도 접근을 임의 레벨 게이트가 아닌 서비스 사슬로 정의한다. 각 구간은 압력 씰, 슈트 등급, 전력, 산소, 절연, 신호, 귀환 계획이 함께 통과할 때만 열린다.

## Scanner

심도 게이트 판독 // 구간: 250-1200 m 서비스 하강. 씰 여유 11%. 슈트 플레이트는 배터리 팩 B2가 잠긴 뒤에만 Grade C를 승인. 세 번째 클램프 아래에서 귀환 ping 약화. 용기로 하부 락을 열지 말 것.

## Terminal

심도 접근 보드
0-250 m: 유광 선반 / 손상 장비로 단시간 작업 허용
250-1200 m: 서비스 선반 / Grade C 슈트 씰, 잠긴 배터리, 테더 ping 필요
1200-2800 m: 브라인 협곡 / 절연 랩과 부력 트림 필요
2800-4300 m: 심연 기계장 / 강화 신호와 선체 규율 필요
4300-5600 m: Atlas 분지 / 귀환 계획은 압력 손실과 버스 노이즈를 견뎌야 함
실패: 가장 약한 판독을 수리할 때까지 다음 구간 잠김

## Audio

문하고 다투지 마. 씰 여유는 빨간색이고, 네 귀환 ping은 이미 늦었다.

## Field Note

게이트는 네가 왜 그 경로가 필요한지 신경 쓰지 않는다. 씰, 전력, 산소, 절연, 신호를 읽고 녹색을 주거나 계획을 죽인다.
