# Barnard 표식

Barnard Yards는 고귀한 출신지가 아니다. 선박 해체, 빌린 절단기, 압력 클램프, 세 번째 주인을 거친 도구, 나쁜 계약의 비용을 정확히 아는 사람들의 작업 흉터다.
