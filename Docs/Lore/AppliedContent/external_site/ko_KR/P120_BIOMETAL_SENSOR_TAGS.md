# 바이오메탈 센서 태그

바이오메탈 센서 태그는 평범한 수집품이 아니다. 수리 시스템이 운반체가 기계인지, 케이블 성장인지, 동물인지 신경 쓰지 않게 되었을 때 생기는 물건이다. 태그는 조직에 파고드는 얇은 바이오메탈 비늘로, 약간의 전류를 마시고, 움직임을 기록하고, 물속으로 위치 신뢰도를 반복한다. Marauder는 그것으로 핑거를 조율하고, 스캐너 범위를 늘리고, Atlas가 닿았을 때 경로가 살아 있었다는 사실을 증명할 수 있다. 그 유용성이 문제다. 차갑게 뽑으면 증거가 된다. 뜨겁게 뽑으면 네트워크가 사라진 운반체를 알아차리고, 가짜 반환으로 응답하거나, 다친 동물, 잘린 켈프, 태그를 든 잠수부에게 수리 논리를 보낼 수 있다. 이 재료는 전리품을 사건 파일처럼 다루게 한다. 유용하고, 더럽고, 아직도 보고 중이다.

## Scanner

바이오메탈 센서 태그 // 물고기, 케이블 켈프, 수리 조직에 자란 얇은 금속 비늘. 핑거 조율을 향상한다. 뜨거운 채취는 Atlas가 사라진 운반체를 듣게 할 수 있다.

## Terminal

자원 등급: Atlas 변형 / 증거 민감. 용도: 핑거 초점, 스캐너 격자, 경로 신뢰도, 증거 패킷. 냉각 채취 권장. 위험: 주의 상승, 가짜 운반체 반환, 손상된 동물상.

## Audio
