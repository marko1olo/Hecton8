# 음향 핑거 라인

음향 pinger line은 구조 신호기가 아니다. 들을 수 있게 된 규율이다. 플레이어는 탁도, brine shimmer, 두려움이 경로를 낯설게 만들기 전에 return sound를 고정한다. 이 도구는 항법이 map screen이 아니라 습관임을 가르친다.

나중 시스템은 이 씨앗에서 자랄 수 있다. relay timing, carrier handshake, 경로가 아직 존재한다는 음향 증거. 첫 버전은 의도적으로 작다. 플레이어를 자신감으로부터 구한다.
