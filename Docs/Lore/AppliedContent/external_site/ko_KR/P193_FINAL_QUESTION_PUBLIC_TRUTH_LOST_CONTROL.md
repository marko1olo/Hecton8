# 최종 질문: 공개 장부, 잃어버린 통제

공개 장부 공개가 작동하는 이유는 첫 도장이 작고 회수하기 어렵기 때문이다. Tau/Luyten 공증 버스트는 완전한 구조 사건을 운반하지 않는다. 증인 해시, 책임 사슬, Atlas 상태 요약, 좌표 가림, 페이로드 경로 증명을 충분히 운반해 Deep Reach가 더 나쁜 위치에서 답하게 한다. 오래된 공개 보고서는 여전히 반격할 수 있지만 더 이상 유일한 파일을 소유하지 않는다.

피해는 즉시 시작된다. 구조팀이 창을 합의하기 전에 제재 데스크가 경로를 동결할 수 있다. 채권자는 블루-부채 샘플에 가격을 매길 수 있다. 도메인 법원은 증거를 몇 달 동안 잠글 수 있다. 생존자 네트워크는 누군가 설명하기보다 더 빨리 패킷을 복사한다. 경쟁자는 가려진 좌표를 빼기로 추적한다. 이 결말은 기록을 매장에서 보호하고, 다음 몇 시간을 송신자가 명령할 수 없는 분쟁으로 바꾼다.
