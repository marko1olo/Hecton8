# 책임 메모 조각 사슬

책임 메모 조각 사슬은 HECTON-8의 증거를 설명이 아니라 재구성으로 정의한다. 이 글은 플레이어가 조각, 타임스탬프, 손상된 행정실에 관심을 가져야 하는 이유를 준다. Deep Reach는 하나의 자백을 남기지 않았다. 서로 맞지 않는 자기방어를 남겼다. 각 조각은 그럴듯할 만큼 작고, 중요할 만큼 추하다. 함께 보면 회사가 공개적으로는 조석 물리를 탓하면서 내부적으로는 위험, 대피, Atlas 연속성, 보험 전환, 화물 보관을 통해 책임을 이동시킨 방법이 드러난다.

## Scanner

책임 메모는 조각으로 살아남았다. 각 사무실이 자신을 보호하는 문단만 보관했기 때문이다.

## Terminal

FRAGMENT CHAIN: 위험 여유 표 / 대피 해제 메모 / Atlas 연속성 오버라이드 / Keelmark 손실 전환 / 회수 보관 요청. 공개 요약을 받아들이기 전에 경로 시간, 방 손상, 작업자 이름을 교차 확인할 것.

## Audio

그들은 진실을 금고에 숨기지 않았다. 조각으로 파일했다.

## Field Note

찢어진 메모는 솔직할 생각이 없던 부분에서 솔직해진다.
