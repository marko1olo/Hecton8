# Seed Ship 제동 구조

가속은 낭만을 얻고, 제동은 청구서를 얻는다. Aegir로 향한 Seed ship은 쓸모 있을 만큼의 생존 질량을 가지고 도착해야 했다. 그래서 모든 차폐층, 얼음 예비, 자기 세일, 펠릿 포획, 핵융합 연소는 거주지가 물에 닿기 전부터 식민화의 일부였다. 첫 인프라는 마을이 아니었다. 멈추기 위해 자기 일부를 이미 쓴 차량이 삽입한 기계였다. 그래서 HECTON-8은 세워진 곳보다 상속된 곳처럼 느껴진다. 노동자들은 안전 논쟁 수년 전에 잠긴 제동 타협, 오래된 자동화, 화물 우선순위 속으로 들어갔다.
