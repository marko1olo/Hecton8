# 분출구 마이크로노드 전력 둥지

아래쪽 바다는 작은 전력으로 가득하지만 넉넉한 전력은 아니다. 분출구는 금속이 많은 지각으로 열을 흘리고, 화학 구배는 광물 피부 위에 모이며, 오래된 장비는 접점과 코일을 남겼다.

노드 하나는 중계기를 계속 뛰게 하고, 드론을 한 번 기게 하거나, 기억을 보존할 수 있다. 분출구에 접근할 이유를 주지만 안전한 보물상자는 아니다. 열, 압력, 독, Atlas 정비 논리가 같은 둥지에 있다.
