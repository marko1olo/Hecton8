# 대피 대기열 터미널 증거 키트

대기열 터미널은 고통을 행정적으로 깔끔하게 만들기 위해 지어진 방처럼 느껴져야 한다. 터미널은 경로 보류, 격리 해제 지연, Atlas 가중치, 작업자 수를 나열하지만 벽에는 더 지저분한 기록이 있다. 해치 상태 스트립, 배지 잔류물, 사라진 용량 표식, 아직 누군가 팔고 싶어 하는 패널의 salvage 태그다.

POI의 무게는 충돌에서 나온다. 부품을 빼면 경로가 열리거나 빚을 갚을 수 있지만, 지연을 입증하는 표면도 망가질 수 있다. 올바른 판독은 자백이 아니다. 맞지 않는 물체들의 묶음이 오퍼레이터에게 잠수에서 무엇을 살릴지 고르게 한다.
