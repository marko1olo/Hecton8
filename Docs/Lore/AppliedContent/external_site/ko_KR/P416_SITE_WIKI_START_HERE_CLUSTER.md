# 여기서 시작: HECTON-8

첫 내비게이션 클러스터는 홍보 요약이 아니라 기록으로 들어가야 한다. Black Keel은 HECTON-8을 recoverable ocean claim으로 기록하고, Deep Reach는 손실을 storm-and-collapse event로 설명한다. 그러나 오래된 방들은 다르게 답한다. pump boards, quarantine doors, maintenance routes, Atlas 수리 흔적은 식민지가 한순간에 사라진 것이 아님을 보여준다. 이 입구는 기본 질문을 묶는다.
