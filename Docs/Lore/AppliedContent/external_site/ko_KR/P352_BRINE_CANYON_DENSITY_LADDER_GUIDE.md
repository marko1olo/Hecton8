# 염수 협곡 밀도 사다리 가이드

염수 협곡은 램프 가장자리가 휘고, 게이지가 망설이고, 떨어뜨린 도구가 멈추면 안 되는 곳에서 멈출 때까지 빈 물처럼 보인다. HECTON-8의 조밀한 층은 깊이를 건축으로 바꾼다. 담수, 염분 부하, 차가운 seep 잔류물, 점토 실트, 화학 막이 보이지 않는 바닥으로 쌓여 광물 조각 구름을 떠받치거나 드론 신호를 통째로 삼킬 수 있다.

협곡은 이익보다 먼저 생존을 가르친다. 베인 그림자를 따라가라. 진흙 선을 봐라. 염수 안에서는 조용한 계기를 밖에서보다 덜 믿어라. 자원 주머니는 밀도가 유용 물질의 낙하를 늦추는 곳에 모이지만, 같은 주머니는 정체 가스, 죽은 센서, 값싼 선체를 벌할 만큼 날카로운 압력 변화를 숨긴다. 내려간다는 것은 단지 더 깊어진다는 뜻이 아니다. 유체들 사이의 합의를 건너는 일이다.
