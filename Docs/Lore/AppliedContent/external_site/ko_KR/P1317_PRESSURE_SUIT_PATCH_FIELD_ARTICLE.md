# 압력복 패치 현장 문서

압력복 수리 패치는 작지만 밀도 높은 증거 표면이다. 어두운 기술 직물, 봉합 테이프, 바느질, 소금, 마모는 수트가 정비품인지, 빌린 물건인지, 폐기품인지, 마지막 귀환을 위해 밀어붙인 물건인지 보여 준다.

읽기는 물리적이다. 봉합 가장자리 밑의 소금은 젖은 압력 사이클을 뜻한다. 빛나는 초승달은 사다리, 해치, 케이블과의 반복 접촉이다. 관절 위 패치는 평면 패치보다 나쁘다. 압력 시험 태그가 없으면 salvage가 위험이 된다.

패치는 인간의 생존을 보이게 둔다.
