# 펌프실 밸브 핸드셰이크

HECTON-8의 펌프실은 단순한 배수구가 아니다. 국소 밸브, 핸드휠, 지친 체크 밸브는 바닥이 마른 뒤 물이 어디로 갔는지 묻게 한다. 작동하는 펌프는 문을 열고, 통로를 깨우고, 소나에 소음을 넣고, 귀환 경로를 다음 문제로 바꿀 수 있다.

## Scanner

국소 섬프 펌프가 핸드휠 입력을 수락했다. 흡입 바스켓은 캡슐 폼으로 오염되었고, 배출 펄스가 귀환 통로 B에 부하를 건다.

## Terminal

P-63 섬프 제어 / 국소 핸드셰이크: 핸드휠 권한 수락. 원격 오버라이드 거부. 흡입 흐름 저속 복구. RETURN CORRIDOR B에서 배출 압력 상승. 하류 해치 확인 후에만 재시동.

## Audio

밸브가 물었다. 출구가 두드린다. 아직 안전하다고 부르지 마라.

## Field Note

마른 펌프실도 돌아가는 길을 잠기게 할 수 있다. 밸브를 벗기기 전에 배출 라인의 수격음을 들어라.
