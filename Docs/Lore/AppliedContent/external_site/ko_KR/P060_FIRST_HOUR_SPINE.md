# 첫 시간의 등뼈

첫 시간의 등뼈는 HECTON-8의 개막 리듬을 정의한다. 손에 잡히는 공학 과제와 시각적 경이가 먼저 오고, 그 과제들은 기업의 거짓말과 생물학으로 들어간 유지보수 생태에 연결된다. 바다는 이야기를 숨기지 않는다. 압력, 소금, 절차 속에 증거를 보존한다.
