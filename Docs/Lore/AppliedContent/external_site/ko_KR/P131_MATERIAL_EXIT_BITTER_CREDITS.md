# 물자 탈출: 쓴 크레딧

물자 탈출은 만화적인 악이 아니라 차갑게 합법적인 느낌이어야 한다. 계약자는 일을 했고, 압력 물질을 회수했으며, Black Keel 회계에 충분한 custody를 보존했고, lien을 실제로 줄였다. 상업 시스템에는 이것을 실패라 부를 이유가 없으므로 함선은 경보를 울리지 않는다.
