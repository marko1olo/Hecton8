# 부분 귀환 유치권 연장

HECTON-8의 리플레이 구조는 부분 탈출을 리셋이 아니라 기록으로 다룬다. 실패한 탈출도 무엇을 알게 되었는지, 누구에게 빚졌는지, 다음 어떤 창이 열리는지를 바꾸며 캠페인을 전진시킬 수 있다.

## Scanner

연장 유치권 아래 귀환 승인. 지식 플래그는 유지되며 장비 인벤토리는 격리되고 회수된다.

## Terminal

PARTIAL RETURN 명령: 연장 유치권, 수정된 폭풍 창, 보존된 지식 dossier 아래 같은 seed 재진입 허가. 물리 인벤토리는 보관 격리로 초기화. 도구는 증거 검토 종료 전까지 carrier 재산으로 남는다.

## Audio

루트는 네가 증명한 것을 기억한다. 바다는 나머지를 가져간다.

## Field Note

재진입 기록: 같은 seed 귀환은 상속 장비가 아니라 지식, 채무 압박, 폭풍 변화, 보관 리셋을 운반한다.
