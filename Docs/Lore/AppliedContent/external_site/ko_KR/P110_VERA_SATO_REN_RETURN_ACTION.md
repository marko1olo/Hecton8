# 베라 사토-렌 반환 조치

베라 사토-렌 반환 조치는 Deep Reach의 오래된 재난과 플레이어의 현재 캠페인을 잇는 다리다. 그녀는 2190년 회수 준수 사무소를 대표하며, Deep Reach가 방 안에 서 있지 않아도 힘을 행사할 수 있음을 보여준다. 그것은 반환 조치 패킷을 보낸다.

패킷은 좌표, XO 증거, Atlas 접근 상태, 보관 창 안의 계약자 침묵을 요구한다. 그 형태가 중요하다. 위협은 연설이 아니다. 위협은 타이밍이다. payload가 회수 가능하면 Deep Reach는 구조, 법적 보호, 운송체 접근을 제안할 수 있다. 증거 위험이 커지면 같은 시스템은 플레이어를 책임 대상으로 만들 수 있다.

이 글은 세력을 지상에 묶어 둔다. Deep Reach가 위험한 이유는 여전히 절차적이고, 지급 능력이 있고, 인내심이 있기 때문이다. 그것은 구조보다 회수, 진실보다 보관을 원한다. 사토-렌은 그 기계의 사람 모양 날이다.
