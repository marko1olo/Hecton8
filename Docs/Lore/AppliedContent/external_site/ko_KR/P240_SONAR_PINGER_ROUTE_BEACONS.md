# 소나 Pinger 경로 비콘

소나 pinger 경로 비콘은 HECTON-8다운 물건이다. 싸고, 물리적이고, 음향적이며, 도덕적으로 무겁다. 플레이어를 돌아오게 하지만 바다에도 존재를 알린다.

## Scanner

pinger 부표는 귀환 기하를 표시하고 거짓 반향을 드러내며 구조 신호와 원치 않는 생명을 함께 끌어들인다.

## Terminal

PINGER RULE: return line first, sample tag second, distress packet third. Never trust one echo.

## Audio

한 번의 ping은 약속이다. 두 번의 ping은 청구서다.

## Field Note

pinger는 첫 정직한 도구다. 거리, 빚, 사라진 경로, 생물 위험을 소리로 말한다.
