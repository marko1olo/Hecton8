# 렌 오코예, 염수 지도 제작자

렌 오코예는 이동에 인간의 출처를 준다. 플레이어가 구슬, 핀, 지워진 선, 경로 표식으로 된 수작업 체계를 찾으면 HECTON-8의 염수 협곡은 단순한 위험을 넘어선다. 물이 움직였을 때 합법 경로도 죽일 수 있음을 알던 사람의 흔적이다.

## Scanner

기록: 렌 오코예. 밀도 구슬, 슬레이트 절흔, 핀줄 자국이 하룻밤 사이 움직인 경로를 설명한다.

## Terminal

염수 지도 책상 / OKOYE, REN: 밀도 역전 뒤 안전한 흐름이 동쪽으로 3.2m 이동. 허가판은 아직 어제의 회랑을 표시한다. 다음 측심 전까지 작업자 경로 표식이 관리 경로보다 우선한다.

## Audio

오코예는 그림을 간직하려 하지 않는 물속에 길을 그렸다.

## Field Note

오코예는 염수 경로 공개, 밀도층 내비게이션, 허가판 모순에 사용한다. 그의 증거는 플레이어가 오래된 지도를 의심할 구체적 이유를 줘야 한다.
