# Deep Reach의 기원 사슬

기원 사슬은 Deep Reach를 하나의 사악한 사무실로 만들지 않는다. 그것은 여러 법적 피부를 쓴 항로 경제이며, 각 관할권에서는 현지처럼 보이고 충돌 지점에서는 부재한 것처럼 보인다. HECTON-8은 이 역사를 통해 기업 권력을 오래되고, 지루하고, 치명적으로 느끼게 한다. 악당처럼 들리지 않고도 식민지를 죽일 수 있는 기계로.
