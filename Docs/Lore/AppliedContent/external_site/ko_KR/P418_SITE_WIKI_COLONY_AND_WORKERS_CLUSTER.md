# 식민지와 노동자

식민지와 노동자 클러스터는 HECTON-8이 빈 방의 지도가 되는 것을 막는다. Deep Reach의 공식판은 사람들을 손실 범주로 밀어 넣지만, 살아남은 기록은 일을 통해 그들을 붙잡는다. pump chief는 pressure board에, relay operator는 witness trays에, brine crew는 소금 루트와 ration ledgers에, triage technician은 repair tags에, forge shift는 숨길 시간이 없던 rejects에 남는다. 이것은 주인공의 가족 훅이 아니다. 노동 증거다. Marauder는 왜 문이 열린 채였는지, 왜 펌프가 늦게 재시동되었는지, 작은 name tag가 깨끗한 loss summary보다 강할 수 있는 이유를 읽는다.
