# Ran/Aegir 거리 대역

Aegir 시스템은 도달 가능하지만 가혹한 no-FTL 대역에 있다. 산업에는 충분히 가깝고, abandonment가 의미를 갖기엔 충분히 멀다.

## Scanner

공개 대역: Ran/Aegir는 Sol에서 온 10광년급 no-FTL 항로다.

## Terminal

EPHEMERIS BAND: 천체 상수가 테이블에서 고정될 때까지 공개 문장에는 10광년급을 사용한다. 이 항로에는 FTL rescue가 없다.

## Audio

10광년은 지도에서는 가깝고 계약에서는 잔혹하다.
