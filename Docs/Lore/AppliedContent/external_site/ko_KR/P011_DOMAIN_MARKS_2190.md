# 도메인 표식 2190

2190년에는 망가진 물건 하나가 여러 법적 부모를 가질 수 있다. HECTON-8의 압력 걸쇠 하나는 Sol 인증, Barnard 수리, Luyten 보관, Centauri 정당화, Aegir 청구 껍데기를 동시에 품을 수 있다. 표식은 식민지를 안전하게 만들지 않는다. 문서화된 곳으로 만든다.

그 차이가 게임의 음색이다. HECTON-8은 문명 밖이 아니다. 문명의 차가운 면 아래 있다. 브래킷에 이름을 붙이고, 몸에 가격을 매기고, 패킷을 보존하면서도 구조 질량을 제때 움직이지 못하는 면이다.
