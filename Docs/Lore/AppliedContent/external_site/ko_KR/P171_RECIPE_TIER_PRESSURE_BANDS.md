# 레시피 단계 압력대

레시피 단계 압력대는 HECTON-8이 일반적인 생존 제작을 피하는 방식을 정의한다. 재료는 추상 비용이 아니다. 경로 이력, 인증, 법적 결과를 지닌 압력 등급 증거다. 같은 구조가 레시피, 스캐너 경고, UI 단계 라벨, 로어 문서를 동시에 지탱하며 게임플레이와 픽션의 언어를 갈라놓지 않는다.

## Scanner

HECTON-8의 레시피는 장보기 목록이 아니라 깊이에 대한 주장이다. 부품은 주장한 압력대를 살아남아야 부품으로 인정된다.

## Terminal

레시피 압력대 / T0 생존 패치: 얕은 salvage, 손 봉합, 보관 없음 / T1 등급 수리: 선반 산업 부품, 펌프실 인증 / T2 압력 하드웨어: 염수 세척, 분출공 경화, 음향 증명 / T3 상승 또는 Atlas 작업: 심연 출처, 법적 수신자, 격리 영수증.

## Audio

레시피는 볼트가 달린 깊이 허가서다.

## Field Note

레시피 단계는 압력 등급, 경로 비용, 보관 위험과 맞아야 한다. 잘못된 압력대의 싼 볼트는 싸지 않다. 미래의 누수다.
