# 항로 허가 도장 세트

항로 허가 도장 세트는 HECTON-8의 접근 소품을 정의한다. 도장은 작업자 신원을 물리적 경계에 연결한다. 문, 차량, 슈트, 리프트, 항로 게시판. 각 도장은 나중에 장부나 오디오 조각과 모순될 수 있으므로, 접근 권한은 압력 아래의 전기가 되고 식민지의 마지막 이동을 읽는 핵심 방식이 된다.
