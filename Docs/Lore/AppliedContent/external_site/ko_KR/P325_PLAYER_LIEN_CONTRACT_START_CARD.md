# 플레이어 Lien 계약 시작 카드

HECTON-8의 주인공은 Deep Reach의 전 전문가에서 salvage operator가 된 사람이다. 이 출신은 이야기를 성숙하고 실용적으로 유지한다. 플레이어는 운명이 아니라 일을 위해 온다. 감정적 전환은 증거, 계약, 기억된 접근을 통해 획득되며, 미스터리를 가족 복수로 줄이지 않고도 개인적인 것으로 만든다.

## Scanner

시작 카드는 당신을 선택받은 피해자로 만들지 않는다. Lien, 열쇠, 자신에게 거짓말할 이유를 가진 전 Deep Reach 전문가로 만든다.

## Terminal

계약 시작 / operator: 독립 salvage contractor / 이전 접근: Deep Reach field key, 비활성이나 인식됨 / lien: 활성 / 선언 동기: claim value / 미선언 압력: prior exposure, 경로 친숙도, beneficiary conflict.

## Audio

당신은 일을 하러 왔다. 파일은 당신이 그것을 기억하기 전에 당신을 기억했다.

## Field Note

Lost-relative hook 없음. 동기는 일로 시작한다: salvage value, 오래된 field access, 전문적 노출, 가려진 개인 압력.
