# 누수, 녹, 생물막 연대 장부

좋은 누수 얼룩은 처음에는 극적이지 않다. 그냥 더러움처럼 보인다. 그래서 HECTON-8에 맞는다. 진실은 깨끗한 명판이 아니라 물이 머물고, 볼트가 땀 흘리고, 밀봉이 숨 쉬던 곳에 남았다.

쓸모 있는 질문은 색이 아니다. 어느 층이 위에 있는가다. 소금 아래 녹은 오래된 젖은 이음이다. 소금 아래 기름은 늦은 기계 누수다. 도색 위 생물막은 오래 젖고 먹이를 받은 표면이다. 더러운 줄 속 깨끗한 도색은 늦은 닦음이나 끌린 도구일 수 있다.

게임에서 이 연대기는 길을 읽고, 약한 밀봉을 경고하고, 공식 정지 뒤에도 방이 작동했다는 증거가 되며, 잘라 버리지 말아야 할 증거물을 표시한다.
