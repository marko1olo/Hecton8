# payload 공개 원장 수신 프로토콜

공개 원장 레인은 가장 사적이지 않고 가장 순종적이지 않은 수신자다. 좌표 판매, 직접 회수 청구, 깨끗한 지급 영수증을 거부한다. 수락하는 것은 경로 지도가 제거된 사고 패킷이다. attestation hashes, 책임 체인, Atlas 가중치 digest, 수신자 타임스탬프로 구성된다.

지연은 중요하다. 패킷은 즉각 구조나 즉각 판결을 부르지 않는다. 금지 명령, 수신자 분쟁, 보관 압력을 견디도록 만들어진 느린 레인을 지나간다. 수락되면 운반자는 되돌릴 수 없다. 그 통제 상실이 증거를 사기 어렵게 만드는 대가다.
