# Mute 외부 죽은 beacon 역할

Mute는 오래된 인프라가 사라지지 않고 조용해지는 곳이다. 죽은 beacon망은 아직 route solver를 구부린다. 거기에 의존한 모든 legacy 표를 지울 여유가 누구에게도 없기 때문이다. 때로 유령 데이터는 쓸 만한 relay 창을 예측한다. 때로 그것은 carrier 데스크가 메시지를 붙잡을 구실이 된다. HECTON-8 주변의 침묵은 순수한 부재인 경우가 드물다. 그 모호함은 통신 고장으로 끝나지 않는다. 보험, 계약, 구조 창이 침묵을 서로 다른 언어로 이용한다.
