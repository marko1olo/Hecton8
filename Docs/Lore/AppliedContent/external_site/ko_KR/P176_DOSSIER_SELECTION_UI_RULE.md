# 도시어 청구 등록부

DR-902은 도시어 선택을 청구 기록으로 만든다. 지식, 소문, 법적 압박은 보존하지만 생존 장비와 세계 사실은 파일 밖에 둔다.

## Scanner

DR-902 청구 등록부. 활성 도시어는 소문 계열, 엔딩 기록, 유치권 압박, 보관 조건, 궤도/기상 조항, 증거 순서 힌트를 드러낸다. 장비 상속 없음.
