# 가려진 Deep Reach 수익자 조항

가려진 Deep Reach 수익자 조항은 HECTON-8 음모의 현대적 형태를 정의한다. Deep Reach는 전능한 꼭두각시 조종자가 아니다. 회수 우선순위, 보험 경로, shell custody에 숨은 beneficiary다. 그 결과는 평범하기 때문에 더 무섭다. 결코 지급을 멈추지 않은 재난 주변의 이빨 달린 서류다.

## Scanner

Deep Reach는 고용표에 인쇄되어 있지 않다. 돈, 수신자 우선순위, 좌표 접근이 만나는 곳에 나타난다.

## Terminal

수익자 추적 / 표시 고용자: proxy loss desk / 가려진 수익자: Deep Reach-linked shell / 책임: 격리 / coordinate access: 보존 / priority recovery channel: contractor distress lane보다 먼저 열림.

## Audio
