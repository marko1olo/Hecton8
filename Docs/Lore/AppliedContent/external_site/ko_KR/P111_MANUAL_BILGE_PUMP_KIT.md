# 수동 빌지 펌프 키트

수동 빌지 펌프는 극적인 척을 거부하기 때문에 첫 생존 동사다. powered panel도, 영웅적 인터페이스도, 방이 안전하다는 약속도 없다. 플레이어는 막힌 흡입구를 치우고, 손잡이가 맞서는 것을 느끼며, 물에는 정직한 출구가 필요하다는 사실을 배운다.

이 작은 도구가 HECTON-8의 톤을 정한다. 수리는 손, 압력, 결과에서 시작한다. 펌프가 되받아치면 방이 대답하는 것이다. 배출구가 틀리면 생존은 위험을 다른 곳으로 옮길 뿐이다.
