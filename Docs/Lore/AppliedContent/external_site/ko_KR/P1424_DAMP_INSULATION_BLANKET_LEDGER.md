# 젖은 단열 담요 열 기억 장부

오래된 식민지는 문과 선체에서만 실패하지 않았다. 압력을 견딜 수 있게 만들어야 했던 곳에서 실패했다. 뒤판, 열 랩, 서비스 홈, 출항 전 아무도 찍지 않은 베이지색 천이다.

좋은 단열재는 인간 크기의 진실을 말한다. 어두운 아래 이음은 숨과 결로다. 바느질 홈의 소금은 건조 주기다. 납작한 퀼트는 압력과 벽에 기대어 있던 몸이다. 작은 어두운 찢김은 도구, 비상 접근, 숨은 케이블 찾기일 수 있다.

그래서 단열재는 기계의 이야기와 노동자의 이야기를 잇는다. 공기 주머니, 비상 쉼터, 기어가는 통로, 아직 윙윙거리는 죽은 패널 옆에 속한다.
