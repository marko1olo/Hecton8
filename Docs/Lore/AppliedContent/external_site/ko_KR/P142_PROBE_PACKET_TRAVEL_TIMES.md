# 탐사 패킷 이동 시간

탐사 패킷 이동 시간은 이 세계에서 가장 덜 극적이면서 가장 해로운 힘 중 하나다. 초기 Ran-Aegir 패킷은 거짓이 아니었다. 실제 분광값, 질량 추정, 얼음 화학, 릴레이 기하, 얕은 물의 희망을 운반했다. 다만 사람들이 그것을 허가증으로 다룰 때 이미 낡아 있었다.

그래서 식민지의 실패는 더 날카롭다. HECTON-8은 순수한 환상 위에 세워지지 않았다. 항로는 견뎠지만 시간은 견디지 못한 데이터 위에 세워졌다. 새로운 판독값이 첫 약속을 반박했을 때, 오래된 약속에는 이미 부채, 계약, 장비, 인간의 계획이 붙어 있었다.
