# 유리 그레이저 코덱스 카드

유리 그레이저는 HECTON-8의 생태를 생존 언어로 바꾼다. 먹이 활동은 막과 매트 성장에 밝은 경로 흉터를 만들지만, 때로는 움직임보다 정지가 더 중요하다. 해롭지 않은 동물이 계기보다 먼저 플레이어에게 경고할 수 있다.

## Scanner

유리 그레이저 무리. 적대적이지 않은 껍질 먹이꾼이 광물막을 긁어 먹는다. 일정한 딸깍임은 작업 가능한 물, 갑작스러운 침묵은 더 큰 것이 공터를 바꿨다는 뜻이다.

## Terminal

표본 / 유리 그레이저 무리 / 역할: 얕은 막 긁개, 해류 증인, 포식자 이동 단서 / 안전 판독: 먹이 가장자리, 새 옅은 긁힘 길, 안정된 껍질 딸깍임 / 거부: 먹이가 남은 빈 구역, 단단히 얼어붙은 무리, pinger 후 돌아오지 않는 딸깍임 / 경로 메모: 먹이 활동 뒤의 부재는 위험 데이터다.

## Audio

작은 입들이 딸깍임을 멈췄고 먹이가 그대로라면, 다음으로 기다리는 것이 되지 마라.

## Field Note

먹는 무리: 길을 읽어라. 얼어붙은 무리: 물을 읽어라. 먹이가 남은 빈 길: 떠나라.
