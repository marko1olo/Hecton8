# 마렉 이바라 손실 전환

마렉 이바라 손실 전환은 식민지의 두 번째 실종을 다룬다. 첫 번째는 물리적이었다. 압력문, 침수된 경로, 회수되지 않은 시신. 두 번째는 행정적이었다. 노동자가 미해결 적재 등급이 되었다.

이바라의 표는 기술적 보험 언어를 무기로 사용한다. 압력 상태, 오염 상태, 급여 상태, 보관 증거가 사람이 청구가 될지, 지연이 될지, 무기한 열린 범주가 될지를 결정한다. 잔혹함은 연설이 아니다. 열린 상태가 더 싸기 때문에 열려 있는 표다.

이 글은 증거 루프를 뒷받침한다. 이름, 태그, 침상 기록은 중요하다. 그것들이 시스템이 죽은 노동자를 미해결 화물로 취급하는 것을 멈추게 할 수 있기 때문이다.
