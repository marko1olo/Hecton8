# 귀환 벡터 창

귀환 벡터 창은 HECTON-8 추출을 즉시 구조가 아니라 궤도 절차로 설명한다. Black Keel은 좁은 Aegir 창을 통해 신호를 받을 수 있지만, 회수는 폭풍 틈, 하전 입자 정온, 중계 무결성, 재건된 상승 하드웨어에 달려 있다. 이 packet은 carrier와의 첫 접촉과 뒤의 부분 출구 기록을 잇는다. 응답은 경로가 존재할 수 있음을 증명하지만, 준비 완료를 증명하지 않는다.

## Scanner

귀환 벡터 판독 // Aegir 폭풍 틈으로 Black Keel ping 수신. carrier 거리: 고전이 궤도. 구름 전하 아래 중계선 오염. 유도 코어, 열 차폐, 귀환 핸드셰이크가 모두 녹색이 될 때까지 캡슐 상승 거부.
