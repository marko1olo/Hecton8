# 청구 언어 감사

## 기록이 증명하는 것

청구 언어는 식민지에서 가장 조용한 무기 중 하나다. 펌프실, 닫힌 분류실 문, 정비 격자 뒤에 남은 노동자 질량을 부정할 필요가 없다. 권한 있는 사람이 파일을 읽기 전에 이름만 바꾸면 된다. 대기열은 방출 시간 편차가 된다. 잠긴 문은 격리 검토문이 된다. 돌아오지 않은 몸은 지급 노출이 된다. 손상된 인양 반환은 부분 적격이 된다.

감사는 플레이어가 절차 언어를 행동으로 읽게 하려고 존재한다. 변환된 모든 문구는 사람, 방, 도구, 경로 시계, 압력 사건으로 되돌려 읽어야 한다. Deep Reach는 증인을 보존하면서도 선반 라벨을 바꿔 증언을 묻을 수 있다. 범주는 살아남고 몸이 사라졌다면, 증거는 이미 한 번 세탁된 것이다.
