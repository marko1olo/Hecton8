# 작업자 이름 풀 기록

작업자 이름 풀 기록은 HECTON-8이 seed 기반 증거를 인간적 연속성으로 바꾸는 방식을 정의한다. 각 신원은 작성된 이름, 도메인 출신 대역, 압력 노동 역할, 배지 조각, 경로 허가, 교대 표식으로 만들어진다. 목표는 무작위 분위기가 아니라 읽을 수 있는 책임이다. 누가 해치를 열 수 있었는지, 누가 펌프를 정비했는지, 누가 의료 해제를 거부당했는지, 뒤늦은 Marauder가 누구의 흔적을 건드리는지 보여 준다.

시스템은 개인 신원을 지키면서 물건 위치와 증거 조합을 바꿀 수 있게 한다. 이는 모순 없는 replay를 위한 것이다. 작업자는 사물함, 작업판, 경로 카드, 명단을 통해 나타날 수 있지만 원칙은 같다. 방이 seed 가능하다고 해서 사람이 절차적 소모품이 되지는 않는다.

## Scanner

이름 띠 // 출신 대역, 경로 허가, 교대 역할, 긁힌 배지 조각이 한 작업자를 가리킨다. 사물함을 salvage로 만들기 전에 이름을 읽어라.

## Terminal

이름 풀 프로토콜 // 작업자 신원은 안정된 개인명, 도메인 출신 대역, 압력 직무, 교대 문자, 배지 조각, 경로 허가로 구성된다. 시스템은 seed마다 순서와 짝을 바꿀 수 있지만, 사람을 무작위 전리품 라벨로 바꾸면 안 된다. 개인명은 locale별로 작성하고, 역할과 경로와 접근 어휘가 기계적 의미를 맡는다.

## Audio

이름은 식민지가 처음으로 부품처럼 뜯어내려 한 물건이었다.

## Field Note

이름은 장식이 아니다. 정거장이 거짓말을 시작했을 때 누가 젖은 구역에 들어갈 허가를 받았는지 알려 주는 증거다.
