# 질량 custody 톤-윈도 장부

HECTON-8은 자비를 하중 계산으로 바꾼다. 마법 같은 구조가 없는 세계이기 때문이다. Black Keel은 claim을 듣고 packet을 받아도, 다음 리프트 창이 올바른 custody 아래 올바른 질량을 들 수 있을 때까지 몸 회수를 거부할 수 있다.

잔혹함은 수학이 가짜라서가 아니다. 수학이 첫 언어가 되도록 허락받았기 때문이다. 생존자는 몸 질량이 된다. 산소는 welfare 부채가 된다. 샘플은 봉인 custody가 된다. 블랙박스는 증거 payload가 된다. 격리는 부피가 된다. receiver rights는 liability가 된다. carrier는 그것들이 중요한지 결정하지 않는다. 무엇이 함께 움직일 수 있는지 결정한다.

그래서 lore는 플레이 가능하다. 증거 보존, 오염 폐기, 하드웨어 인증, 산소 소비, 샘플 보관, 공개 hash 노출, 탈출할 몸 여유 보호가 모두 장부를 민다. 플레이어는 추상물을 줍지 않는다. 무엇이 recoverable로 계산될지 싸운다.
