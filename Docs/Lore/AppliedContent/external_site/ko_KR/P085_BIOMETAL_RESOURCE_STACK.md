# 바이오메탈 자원 스택

자원 스택은 HECTON-8이 하나의 마법 물질로 무너지는 것을 막는다. 푸른 빚은 중요하지만 달은 황화 금속, 염류, 귀가스, 세라믹, 촉매, 바이오섬유, 광단백질, salvage 하드웨어, Atlas가 바꾼 바이오메탈로도 값을 치른다. 가치는 흩어져 있기 때문에 폭력이 말이 된다. 자르고, 표시하고, 숨기고, 돌아오고, 거짓말할 작은 이유가 많다.

바이오메탈 자원 스택은 HECTON-8을 완전한 압력 경제로 잡는다. Xenon-Omega는 읽을 가치가 있는 유일한 것이 아니라 전략적 정점이다. 모든 샘플이 Xenon-Omega라고 말하면 세계는 납작해진다. 사람들이 죽은 더 작은 이유들도 세어라.
