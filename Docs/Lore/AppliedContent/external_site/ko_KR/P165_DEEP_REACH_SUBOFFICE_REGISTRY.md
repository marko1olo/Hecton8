# Deep Reach 하위 사무실 등록

## 작은 사무실, 큰 결과

Deep Reach는 음모처럼 들리지 않고 행정처럼 들리기 시작할 때 더 무섭다. 이 등록은 모든 사무실 이름이 진짜처럼 지루하기 때문에 유용하다. Contract Continuity Desk는 노동자가 죽기를 바라는 obligations를 살려 둔다. Packet Notary Interface는 메시지가 증거인지 소음인지 결정한다. Quarantine Hold Desk는 지연을 의학적 책임처럼 보이게 한다. Asset Silence Board는 증인을 exposure로 바꾼다. Return Action Queue는 body를 payload, orbit, public risk와 비교해 가격을 매긴다.

어떤 desk도 플레이어를 미워할 필요가 없다. 물이 오르기 전에 쓰인 priority stack 안에서 일을 하면 충분하다. 그래서 HECTON-8의 증거는 도장, routing fragments, 작은 모순으로 쌓여야 한다. 범죄는 연극적인 악 뒤에 숨지 않는다. 플레이어가 줄 세우기 전까지 defensible해 보이는 양식들에 퍼져 있다.
