# Ran / Aegir 명칭 권한 장부

HECTON-8의 명명 체계는 장식이 아니다. 어떤 권력이 말하는지 알려준다. 천문학은 별이 항로와 빛 지연을 고정하므로 Ran이라고 한다. 청구 사무실은 거대 행성이 위성, 인프라, 책임을 묶게 해주므로 Aegir라고 한다. 보험 표는 정렬된 장부가 기억을 갖지 않으므로 RAN-B:H8이라고 한다. 물 아래 사람들은 해치가 망가지는 곳이기 때문에 HECTON-8이라고 한다.

문서가 이름을 바꾸면 관할도 바뀌는 경우가 많다. Ran 언어는 시간과 물리에 속한다. Aegir 언어는 소유에 속한다. RAN-B:H8은 카탈로그, 보험, 보관에 속한다. HECTON-8은 현장 사용, 기억, 장소로서의 식민지에 속한다.
