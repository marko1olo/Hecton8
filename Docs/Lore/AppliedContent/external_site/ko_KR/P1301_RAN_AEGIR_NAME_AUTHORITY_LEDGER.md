# Ran / Aegir 명칭 권한 장부

HECTON-8의 명명 체계는 조용하지만 날카로운 세계관이다. 위성에 네 이름이 있는 것은 장식이 아니다. 각 이름은 다른 권한과 같은 익사한 장소에 대한 다른 도덕적 거리에 속한다.

            Ran은 천문 언어다. 별, 항로 기준, 빛 지연, 운반 시각. Aegir는 청구 언어다. 모체로서의 거인, 공용 약칭, 기업 우산. RAN-B:H8은 보험 언어다. 식민지의 목소리를 붙이지 않고 정렬, 이전, 소송할 수 있는 위성 기록. HECTON-8은 살아 겪은 언어다. 문, 방, 무덤, 압력 경보.

            플레이어가 이 문법을 배우면 문서가 달라 보인다. Aegir를 쓰는 회사 공지는 위성 실패를 시스템 정비처럼 보이게 멀리 잡을 수 있다. RAN-B:H8 영수증은 보관 가격을 준비한다. HECTON-8 현장 메모는 카탈로그가 씻어내기 전에 증언을 보존한다.
