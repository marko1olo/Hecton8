# FTL 없는 경로 지연

HECTON-8에는 즉시 구조 채널이 없다. Aegir로 향하는 인간 교통은 선행 탐사체 차트, 빔 레인 기반시설, 펠릿 융합 화물, 제동 시스템, 운반자 창구, 법적 보관 인계로 이루어진다. 긴급함은 질량을 없애지 않는다. 배는 적재물을 가격 책정하고, 청구를 받아들이고, 네 기록을 보관할 수 있지만 물속으로 유용한 물건 하나를 내릴 하강 배정이 없을 수 있다. 그래서 게임은 통신을 구조가 아니라 증거로 다룬다. 답변은 누군가 비상을 들었다는 증거다. 밀봉을 때우거나, 배시드롭을 움직이거나, 나쁜 궤도 창구를 줄이지 않는다.
