# 도구 인증 보드

공구 인증판은 말보다 표시를 더 믿은 문화를 기록한다. 커터 헤드 재인덱스. 실런트 카트리지 계량. 압력 장갑 이중 서명. 펌프 키 지연. 하강 키트 보류. 거의 맞는 공구가 조용히 사람을 죽일 수 있는 곳에서는 무뚝뚝한 절차가 사람을 살렸기에, 각 줄도 무뚝뚝하다.

판이 의식처럼 보이는 것은 위험한 노동이 같은 동작을 반복해 두려움이 갈 곳을 만들기 때문이다. 재고, 확인하고, 서명하고, 돌려주고, 다시 확인한다. 두 번째 서명은 장식이 아니었다. 신뢰에 책임을 붙였다. 장갑이 압력 아래 실패하면, 판의 표시는 누가 봤고, 누가 서둘렀고, 누가 그래도 아래로 보내려 했는지를 말한다.

이것은 신비 없는 노동자의 믿음이다. 식민지는 커터 위에서 기도하지 않았다. 다른 지친 사람이 날, 실, 무게, 키 반환을 보게 했다. 모든 공구가 경로에 닿기 전 누군가 다른 이름을 지녔기 때문에 생존은 공동의 일이 되었다.
