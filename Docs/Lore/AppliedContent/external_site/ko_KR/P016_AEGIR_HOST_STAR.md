# Aegir 주성

## Scanner

## Terminal

RAN/AEGIR 천체력: K왜성 주성, 안정적 광구 출력, 지연된 성간 패킷급, FTL 구조 벡터 없음. 질량이 도착하기 전까지 도움은 지역 자원으로 취급.
