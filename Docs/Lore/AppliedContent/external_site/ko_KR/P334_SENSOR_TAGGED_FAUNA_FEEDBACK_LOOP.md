# 센서 태그 부착 동물 피드백 루프

HECTON-8의 첫 조사는 깨끗한 위성만으로 이루어지지 않았다. 식민지는 동물에 태그를 달고 해류계를 뿌렸으며, 살아 있는 경로가 물기둥을 따라 지도를 만들게 했다.

Atlas는 낡은 채널을 너무 믿는다. 이동은 염도 사건처럼 보이고, 다친 포식자는 막힌 통로처럼 보일 수 있다. 동물은 여전히 야생이지만 시스템은 그것을 잘못 듣는다.
