# Black Keel 청구 창

Black Keel은 몸을 들어 올리기 전에 신호를 들을 수 있다. Aegir에서 캐리어 응답은 릴레이 기하, 날씨, 격리 심사, 탑재물 수락, 질량 회수를 지나는 유료 레인이다. 접촉은 경로 사실이다. 구조는 완성된 사슬이다.

## Scanner

청구 창 // Aegir 릴레이는 수신 창만 예측한다. 회수에는 상승 패키지, 격리 핸드셰이크, tonne-window 배정이 필요하다.

## Terminal

KEELMARK 보관 통지 // 운용자 신호 수신. 회수 우선순위 미해결. 신호나 증거 패킷 수신은 운용자 회수를 보장하지 않는다.

## Audio

Black Keel 중계: 운용자 신호 가격 책정. 회수 창 보류. 수신을 인양으로 착각하지 마라.

## Field Note

Black Keel이 답하면 구조가 아니라 청구서를 세어라. 받은 패킷은 질량, 봉인, 격리, 날씨가 맞을 때까지 줄의 자리일 뿐이다.
