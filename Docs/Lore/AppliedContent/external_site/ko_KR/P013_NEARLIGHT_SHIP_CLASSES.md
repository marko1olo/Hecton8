# 근광속 선박 등급

HECTON-8의 근광속 선박은 선체에 싸인 기적 엔진이 아니다. 항로 경제의 보이는 끝이다. 빔 배열은 출발 전부터 전력을 쓴다. 펠릿 레인은 잔혹한 타이밍으로 반응 질량을 먹인다. fusion-electric throat, 방패 얼음, 라디에이터, 냉동계는 탑재물이 밝은 실수가 되지 않게 막는다. magsail, aerobrake skin, receiver 창이 배가 멈출 수 있는지를 결정한다.

그래서 등급표가 플레이어에게 유용하다. Needleprobe는 Aegir가 안전해지기 전에 알려진 이유다. Seed ship은 공동체보다 기계가 먼저 온 이유다. Atlas는 식민지의 부채와 정비 타협을 설명한다. System tender는 Black Keel의 한계를 설명한다. Aegir 청구를 처리할 수는 있지만 성간 거리를 다시 쓰지는 못한다.
