# 인간 승무원 교대 수송

인간 승무원 교대 수송은 항로가 천문학을 멈추고 노동 통제가 되는 지점이다. HECTON-8의 사람은 단순한 승객이 아니다. 침상 부피, 산소 부하, 방사선 노출, 정신의학적 위험, 임금 담보, 의료 파일, 보관 범주, 가능한 증인이다. 모든 귀환 창은 공포보다 먼저 그 값들을 정렬한다.
