# 자연 황화염 적층

자연 황화염 적층은 HECTON-8의 물에 잠긴 지질을 설명하는 기본 자원 문서다. 이것은 Atlas 오염도, Deep Reach 폐기물도, Xenon-Omega의 시작도 아니다. 더 오래된 층이다. 황화염, 금속 이온, 염수 껍질이 압력과 열과 시간으로 만들어졌다. 현장에서는 빛나는 부채 물질 옆에서 수수해 보이지만, 첫 수리를 가능하게 하는 것은 바로 이것이다. 적층 하나가 산화된 접점을 씻어 내고, 비상 전지 화학을 먹이고, 세라믹의 녹는점을 낮추거나, 깨끗한 장갑을 1분도 안 되어 산성 문제로 바꿀 수 있다. HECTON-8의 유용함은 이렇게 느껴져야 한다. 실용적이고, 위험하고, 무심하다. Deep Reach가 달의 금속에 대한 식욕을 발명한 것이 아니다. 회사는 그것을 청구서로 바꾸는 법을 배웠을 뿐이다. 좋은 자원 배치는 더 큰 공포가 오기 전에 이 사실을 가르쳐야 한다. 벽은 이미 반응한다. 염수는 이미 압력을 기억한다. 인양은 어떤 세계의 조각이 숨을 돕고, 어떤 조각이 생명을 지탱하는 장비를 갉아먹을지 구분하는 데서 시작된다.

## Scanner

자연 황화염 // 분출구가 세운 결정과 검은 염수 껍질. Deep Reach보다 오래되었다. 젖으면 전도하고, 데워지면 부식하며, 무엇이든 파랗게 변하기 전부터 쓸모가 있었다.

## Terminal

자원 분류: 자연 지질. 용도: 도체 세척, 비상 전지 화학, 세라믹 플럭스, 부식 촉매. 따뜻한 흡기와 격리할 것. 먼지는 슈트 금속 위에서 산성 막으로 피어난다.
