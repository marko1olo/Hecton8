# 격리 보류: 탁한 공기

격리 보류는 가장 조용한 거짓 탈출이다. 방 안에 악당이 필요 없다. 양식은 생존 회수라고 말하고, 공기 계량기는 배급 활성이라고 말하며, 다음 문은 오염 검토, claimant 이의, 보험 손실 검토 뒤에만 열린다.

결과는 방어 가능하기 때문에 잔혹하다. 아무도 증인을 죽이지 않았다. 아무도 샘플을 파괴하지 않았다. 시스템은 모든 진술을 시체들이 기다릴 수 있었던 시간보다 더 오래 기다리게 할 뿐이다. 플레이어는 바다에서 살아남아 절차로 만든 밀폐 복도로 들어간다.
