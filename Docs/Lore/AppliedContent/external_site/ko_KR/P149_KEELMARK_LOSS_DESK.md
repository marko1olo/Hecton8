# Keelmark 손실 데스크

Keelmark 손실 데스크는 복도를 침수시키는 손이 아니다. 침수된 복도가 장부에 어떻게 들어갈지 정하는 손이다. 그래서 중요하다. 범주가 충분히 일찍 준비되면 보험자는 살인을 날씨처럼 보이게 할 수 있다.

Keelmark의 표는 Deep Reach에게 조사에서 살아남을 언어를 가르친다. 장비는 감가상각된다. 거주지는 손상된다. 노동은 중지된다. 증인은 노출, 훼손, 회수 불가가 된다. 이름은 더 무겁기 때문에 데스크는 강요될 때까지 피한다.
