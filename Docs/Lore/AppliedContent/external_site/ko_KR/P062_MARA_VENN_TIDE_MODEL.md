# 마라 벤 조석 모델

마라 벤은 예언을 쓰지 않았다. 오차 막대, 대피 여유, 나쁜 타이밍을 가진 모델을 썼다. Aegir 봄철 기하에서 cryosphere shear는 사용 가능한 상승 수송 능력을 앞지를 수 있었다. 식민지가 행동하는 데 완벽한 확실성은 필요하지 않았다. 곡선의 꼬리를 비용이 아니라 사람으로 대하는 누군가가 필요했다.

Deep Reach는 모델을 보존하고 대응을 약하게 만들었다. 경고는 monitor가 되었고, 대피 여유는 미래 예산 문제가 되었으며, 이후 공개 기록은 홍수를 읽을 수 없었다고 불렀다. 플레이어는 문서 형태에서 거짓말을 느껴야 한다. 조석은 자연적이었지만 재난은 편집되었다.
