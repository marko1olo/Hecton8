# Regra de Redação do Índice Público

## O que o registro prova

Uma linha de índice público é um registro de controle de acesso, não um resumo. Ela pode mostrar família de dossiê, faixa de custódia, tipo de prova, marca de redação, portão de scanner e o próximo objeto necessário para abrir o pacote. Isso basta para orientar a busca sem expor o receptor.

Os campos mascarados importam mais que o título. Cadeia de receptores, coordenadas finais, estado da carga, resposta do Atlas, pressão de final e resultado jurídico ficam atrás do selo de redação até a rota merecê-los. Se o índice imprime um endereço de receptor cedo demais, ele não informa o caso; ele vaza a rota para qualquer um olhando o espelho.

## Como ler

SELO DE REDAÇÃO DO ÍNDICE PÚBLICO
Mostrar: título, família de dossiê, faixa de custódia, tipo de prova, marca de redação, portão de scanner, próximo objeto de prova.
Mascarar: cadeia de receptores, coordenadas finais, estado da carga, resposta do Atlas, pressão de final, resultado jurídico.
Falha: endereço de receptor visível antes do limite de custódia.
Ação: manter campos de rota selados até hash do pacote e prova de objeto coincidirem.

## Nota de campo

Use o índice para escolher o próximo objeto de prova. Uma categoria visível não é custódia, veredito nem destino.
