# Regras de Marcas de Correção Marauder

As Regras de Marcas de Correção Marauder explicam como HECTON-8 permite que salvagers posteriores toquem evidência antiga sem quebrar cânone. Marcas de correção adicionam uma camada viva sobre papelada corporativa: preservar um nome, contestar uma categoria, avisar uma rota, precificar uma amostra, esconder uma testemunha ou marcar dívida. Elas fazem a evidência de replay parecer manuseada por outros trabalhadores de reivindicação, mantendo cada alteração manuscrita funcional.

## Scanner

Uma marca de correção pode resgatar um nome, contaminar uma reivindicação ou avisar o próximo mergulhador que a categoria oficial mente.

## Terminal

CORRECTION RULE: marcas Marauder devem mudar interpretação de evidência, risco de rota ou pressão de pagamento. Marcas válidas preservam nome de trabalhador, contestam categoria de seguro, avisam rota, precificam amostra, escondem testemunha ou marcam dívida. Grafite vazio quebra a cadeia de evidência.
