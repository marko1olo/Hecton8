# Reivindicação inicial do Marauder

HECTON-8 começa com um contrato familiar o bastante para ser perigoso. A Black Keel dá a um Marauder preso por dívida acesso a uma rota de recuperação sobre P-63, não uma promessa de resgate. O registro usa vocabulário da Deep Reach porque o personagem do jogador trabalhou dentro dele: sistemas de campo, infraestrutura de evacuação, procedimento de pressão, formulários de rota, prova admissível. Esse passado muda a primeira hora. Um painel ruim não é cenário. Uma etiqueta corrigida não é detalhe de cor. Uma frase polida de responsabilidade pode ser comparada a um amassado, relógio, estado de porta ou marca de desaparecido. A descida começa como salvage pago e vira reconhecimento profissional: o papel conhece a sala, e a sala prova que o papel foi limpo.
