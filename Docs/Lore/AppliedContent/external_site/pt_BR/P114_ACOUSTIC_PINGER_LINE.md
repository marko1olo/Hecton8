# Linha de pinger acústico

A linha de pinger acústico não é um beacon de resgate. É disciplina tornada audível. O jogador ancora um return sound antes que turbidez, brine shimmer ou medo tornem a rota estranha. A ferramenta ensina que navegação é hábito, não map screen.

Sistemas posteriores podem crescer dessa semente: relay timing, carrier handshake, prova acústica de que um caminho ainda existe. A primeira versão fica pequena de propósito. Ela salva o jogador da confiança.
