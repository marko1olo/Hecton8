# Marca Barnard

Barnard Yards não é berço nobre. É uma cicatriz de trabalho: desmonte de naves, cortadores alugados, grampos de pressão, ferramentas de terceiro dono e gente que sabe exatamente quanto um contrato ruim pode custar. O primeiro selo Barnard em HECTON-8 deve parecer quase pequeno demais para lore. Não é discurso. É uma marca numa chave, a liga errada numa dobradiça de armário, um hábito de reparo que a Deep Reach nunca especificaria. Para o jogador, esse detalhe muda o contrato. HECTON-8 deixa de ser só uma reivindicação corporativa morta sob água alienígena. Alguém da mesma cultura de estaleiro chegou antes, trabalhou aqui, foi empurrado para os mesmos livros e deixou uma prova pequena o bastante para ser apagada se um Marauder não notar.
