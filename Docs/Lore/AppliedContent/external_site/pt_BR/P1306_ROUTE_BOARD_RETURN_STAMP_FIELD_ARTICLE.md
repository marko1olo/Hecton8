# Artigo de campo sobre quadro de rota e carimbo de retorno

Quadros de rota são uma ponte forte entre lore e jogo porque tornam o trabalho comum legível. O jogador não precisa de uma aula sobre equipe de colônia se um quadro de escotilha mostra quatro nomes, duas etiquetas de ferramenta, uma janela de maré ruim e um carimbo de retorno que nunca chegou. O objeto fala tempo, trabalho, perigo e culpa de uma vez.

A melhor evidência de quadro deve parecer manuseada. Lápis graxo cruza sal antigo. Um carimbo fica alguns milímetros torto porque a mão estava cansada, molhada ou com medo. Um nome é movido em vez de apagado. Esses detalhes mantêm a colônia humana sem inventar uma trama familiar para cada corpo. Os trabalhadores eram profissionais sob pressão, não vítimas decorativas.

Para design, quadros de rota sustentam conteúdo repetível. A mesma linguagem pode apontar para cache, perigo, escotilha trancada, ferramenta perdida, fragmento de áudio ou variante procedural de sala. Para a história, expõe o hábito da Deep Reach de converter ausência humana em status gerenciado. HECTON-8 fica mais assustadora quando o jogador percebe que a colônia não parou de trabalhar antes de morrer. Ela continuou arquivando morte como trabalho.
