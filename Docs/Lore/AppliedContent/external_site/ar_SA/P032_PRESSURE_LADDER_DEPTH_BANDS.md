# سلم الضغط

سلم الضغط يعرّف الوصول إلى أعماق HECTON-8 كسلسلة خدمة لا كبوابة مستوى اعتباطية: لا يفتح كل نطاق إلا عندما تجتاز أختام الضغط ودرجة البدلة والطاقة والأكسجين والعزل والإشارة وخطة العودة الفحص معا.

## Scanner

قراءة بوابة العمق // النطاق: نزول خدمة 250-1200 م. هامش الختم 11%. لوحة البدلة تقبل Grade C فقط بعد تثبيت حزمة البطارية B2. ping العودة ضعيف تحت المشبك الثالث. لا تفتح القفل السفلي بالشجاعة.

1200-2800 م: وادي المحلول الملحي / غلاف عزل وضبط طفو مطلوبان
2800-4300 م: حقل آلات سحيق / إشارة مقواة وانضباط بدن مطلوبان

## Audio
