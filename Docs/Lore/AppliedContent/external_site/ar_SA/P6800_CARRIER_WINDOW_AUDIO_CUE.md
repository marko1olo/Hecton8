# إشارة صوت نافذة الناقل

قد يبدو Black Keel قريبا بينما يبقى غير متاح. تفصل إشارة نافذة الناقل بين استلام الحزمة وتصريح الاسترداد: نغمتان عاليتان تثبتان دخول الرسالة إلى الطابور، بينما تبقي نغمة الإغلاق المنخفضة الجسد والدليل والإنقاذ تحت الماء حتى تتفق النافذة والختم والحمولة والخط القانوني.

## Scanner

نغمة نافذة الناقل // نغمتان عاليتان تعنيان استلام الحزمة فقط. النغمة الثالثة المنخفضة تعني أن مسار الاسترداد مغلق؛ سجّل النافذة قبل الحركة.

## Terminal

حالة صوت BLACK KEEL // نغمتان عاليتان تؤكدان استلام الحزمة. نغمة إغلاق منخفضة تعني أن مسار الاسترداد ما زال مغلقا بسبب حزمة الصعود أو مصافحة الحجر أو هندسة الناقل أو تخصيص tonne-window. الإقرار الصوتي لا يخصص كتلة رفع.

## Audio

مرحل Black Keel: تم استلام الحزمة. مسار الاسترداد مغلق. سجّل النافذة. لا تصعد اعتمادا على النغمة.

## Field Note

نغمتان ساطعتان هما إيصال. النغمة القبيحة هي الفاتورة التي تقول إن جسدك لا يزال خارج النافذة.
