# סולם נתיב קניון התמלחת

קניוני תמלחת הופכים עומק לחומר. נהרות מלח צפופים שוכבים בתוך האוקיינוס כמו רצפות, מראות ומלכודות. נתיב נקי נבנה מסמני צפיפות, חלונות נטל, בדיקות ממסר ומשמעת זווית, לא מאומץ. השכבות העמוקות מלמדות מדוע מכשירים חשובים: סונאר יכול לשקף את החדר שמעל, ציפה יכולה לשקר, והחליפה יכולה להיות צודקת בזמן שהים מסרב.
