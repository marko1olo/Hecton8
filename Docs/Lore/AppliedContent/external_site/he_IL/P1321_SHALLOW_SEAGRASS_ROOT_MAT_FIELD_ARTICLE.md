# מצע שטיח שורשים רדוד

שטיח השורשים הרדוד הוא אחת המערכות החיות הראשונות שצולל לומד לקרוא. הוא בהיר מספיק כדי להיראות מזמין וצפוף מספיק כדי לשקר. השכבה העליונה קולטת אור Aegir ומשחררת סרט חמצן דק בחלונות יצרניים. מתחתיה השורשים קושרים גרגרים, אבק גיר ושברי אלמוגים מקבילים למשטח שמתנהג כמו רצפה ארוגה, עד שמשקל, זרם או גז כלוא משנים את הכלל.

צוותי Deep Reach השתמשו בשפות השטיח כזיכרון מסלול זול. קווי pinger נתקעים שם. צינורות ישנים נעשים עוגני שורש. שטיח סביב טבעת יכול להשאיר דרך קריאה אחרי שהשלט נעלם. אבל קו שזור יכול להיות מעבר בטוח חוזר, או כישלונות שהזרם גרר שוב לאותו קשר חי.
