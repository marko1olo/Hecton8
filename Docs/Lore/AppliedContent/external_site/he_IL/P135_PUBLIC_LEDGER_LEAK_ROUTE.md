# דליפה לרשם ציבורי

דליפה לרשם ציבורי אינה פנטזיית חושף שחיתות מושלמת. זו חבילה פגומה שיוצאת לפני custody מלא, עם מספיק ראיה כדי להפוך הכחשה ליקרה ועם מספיק הקשר חסר כדי להפוך כל קורא למסוכן. Tau Ceti עשויה להפוך את הרשומה לציבורית הרבה אחרי שתוכל להציל מישהו במים.

העיכוב הוא הנקודה. Deep Reach מאבדת את הכיסוי הנקי ביותר, אבל גם העד מאבד בעלות. אותה רשומה יכולה להפוך לתביעה, מנוף, מתמטיקת ביטוח, תעמולת דומיין או חוזה חדש. הנתיב הזה מקשה לקבור את האמת ומקשה להחזיק בה.
