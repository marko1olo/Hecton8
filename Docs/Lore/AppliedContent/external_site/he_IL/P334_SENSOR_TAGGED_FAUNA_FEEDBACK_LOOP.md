# לולאת משוב של חיות מתויגות חיישנים

חיות מתויגות חיישנים אינן חיילים נשלטים. ההבחנה הזאת חשובה. תוכניות התיוג של Deep Reach התחילו כמדע שטח ולוגיסטיקה רגילים: מעקב אחרי נדידה, סבילות לחץ, חשיפה לזיהום וצפיפות נתיבים. שנים אחר כך, התגים כבר אינם ציוד נקי. קליפה גדלה סביבם, רקמת צלקת מושכת אותם מהציר, וכיפות מינרליות משנות את האות.

Atlas עדיין קורא את החזרה. אוכל עשב פצוע שחוצה גשר מוצף יכול להיראות כמו סקר לחץ. טורף עם תג ישן יכול לגרום למסדרון להיראות תפוס בסיכון תשתית. בעל החיים נשאר עצמו, אבל המערכת סביבו מתייחסת לתנועה כנתונים. כך מפגשי חיות מקבלים קצה שני: התנהגות הישרדות יכולה להיות גם משוב תחזוקה.
