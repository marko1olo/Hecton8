# יומן טלאי תיקון חליפת לחץ

חליפת לחץ מושלמת שייכת לחוברת. HECTON-8 אינה חוברת. החליפות החשובות מטולאות, שחוקות בברכיים ובשרוולים, מלוחות סביב התפרים ומתוקנות בכל רצועה שיכלה להחזיק עוד ירידה.

טלאי טוב נושא מידע חברתי. מפעל: אחיד. מפקח: סרט נכון בלי זמן. עובד: חוט שגוי והבנה של הגוף. רפואה: מהר ומכוער. הקיל השחור: מזהים מוסרים קודם.

טלאים שייכים לארוניות, מרפאות, חדרי החלפה מוצפים ושולחנות עבודה נטושים. הם הופכים את המושבה לאישית בלי שכל גוף ינאם.
