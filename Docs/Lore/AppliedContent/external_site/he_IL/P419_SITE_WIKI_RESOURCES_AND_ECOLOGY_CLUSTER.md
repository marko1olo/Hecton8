# משאבים ואקולוגיה

הטעות הראשונה היא לקרוא למשאבי HECTON-8 חומרי גלם. למטה כמעט שום דבר שימושי אינו מגיע בלי עקבות. שבר מ-Drowned Crust נושא היסטוריית לחץ. עורק blue debt שומר זיכרון של חום, תמלחת ושיטת חילוץ. לוח שריון יכול להיות מגן שונית, איטום כושל, עור כבל ש-Atlas הצמיח וראיה משפטית עוד לפני ש-Marauder מכניס אותו לארגז.

לכן דפי המשאבים יושבים ליד דפי האקולוגיה. המושבה הישנה לא כריתה רצפה מתה. Deep Reach חתכה לתוך סולמות תמלחת, מדפי מינרלים שניזונו מפתחים, מכונות טבועות בבוץ ומערכות סינון חיות שכבר הכירו את קצב הירח. אחרי האסון Atlas דחף את מודל התיקון שלו לכל דבר שיכול לסגור דליפה או לשאת אות. ביופילם הפך למוליך. שטיח שורשים הפך לאטם. פאונה מתויגת הפכה למשוב נע.

החיות אינן קופסאות loot עם סנפירים. הן קוראות רטט, חום, ירידת אור, כימיית דם, עקבות מלח ובוץ שהופרע. אוכל עשב יכול לחשוף אזורי גירוד בטוחים פשוט דרך פעולתו הרגילה. צל טורף יכול להראות איזה מסדרון נושא פעימה אקוסטית שגויה. חיה מתויגת יכולה להיות נתיב תיקון, עד וסכנה באותו מעבר.

Blue debt מלכלך את החשבון המוסרי. הדגימה הטובה ביותר יכולה להיות עמומה, אטומה ומכוערת מפני ששמרה את מצב הלחץ שמוכיח איפה נוצרה. שבר מבריק יכול להיות חסר ערך אם הפתח שטף ממנו את הזיכרון. לקיחת אחד מהם יכולה לשנות זרימה, להעיר צייד, לפגוע בטלאי Atlas או למחוק עקבת תאונה מתקופת העובדים שהייתה חשובה יותר מהתשלום.

השאלה המועילה אינה רק מה אפשר לקצור. היא שואלת מה האוקיינוס עשה עם החומר הזה לפני שיד אנושית נכנסה לשרשרת. HECTON-8 נעשה קריא כאשר גאולוגיה, חיים, מכונות ו-custody נקראים כמערכת אחת שזוכרת נזק.
