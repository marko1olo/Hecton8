# סימני תחום 2190

בשנת 2190 לחפץ שבור אחד יכולים להיות כמה הורים משפטיים. ב-HECTON-8 מנעול לחץ יכול להיות מאושר ב-Sol, מתוקן ב-Barnard, שמור ב-Luyten, מוצדק ב-Centauri ומוחרם תחת מעטפת Aegir. הסימנים לא הופכים את המושבה לבטוחה. הם הופכים אותה למתועדת.
