# ערכת ראיות לחצר ממסרי שונית הכבלים

חצר הממסרים הופכת גועל למשמעת כלים. מעטפות כבל נבקעו, בידוד התקלף, וסרט שירות Atlas חצה שקעים שלא נועדו לחלוק משטח. חיתוך נקי יכול להרוס את הנתיב היחיד שעוד נושא אות.
