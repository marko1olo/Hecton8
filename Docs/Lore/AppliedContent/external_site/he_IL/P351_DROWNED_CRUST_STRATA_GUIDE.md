# מדריך שכבות הקרום הטבוע

הקרום של HECTON-8 אינו מתנהג כמו קרקעית ים שלא נגעה בה יד. המושבה חתכה אותו, חיממה אותו, אטמה אותו, העמיסה עליו זכוכית לחץ ואז נטשה אותו לאוקיינוס שהמשיך לעבוד לאחר שהשכר נעצר. קיר אחד יכול לשאת סימני כלי מקידוח שירות, מדף חיוור מקריסת קרח, רצועה מינרלית ירוקה-שחורה מזרימת seep ותפר דקיק שבו Atlas מצאה אחר כך דרך.
