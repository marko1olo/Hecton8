# מפעל הקרקעית

מפעל הקרקעית אינו אולם כס אחרון. זהו מפעל ההחזרה התחתון שבו ראיות מוקדמות הופכות לחומרה: שאריות blue debt בתפרי קיר, נתיבי brine מתחת ללוחות סיפון, ריתוכי תיקון תחת פחמת חדשה ותגי פינוי שעדיין לכודים ליד דלתות אטומות.

Deep Reach בנתה את הצומת התחתון כדי לשמור על רציפות תביעה ושירות בזמן עיכוב ארוך. Atlas-6 המשיך לנתב סביב קטגוריות שכשלו מפני שהמשאבות, הכבלים ומגשי הדגימה עדיין ענו. התוצאה היא מפעל עובד. brine זז. חום חוזר. אות חוצה שרוולי כבל מטולאים. אורגניזמים מסננים נאספים במארזים שהיו פעם קופסאות שירות נקיות. אטמים שגדלו בלחץ מחזיקים לוחות סגורים אחרי שהאטמים המקוריים כשלו.

זה מה שהופך את האתר למסוכן באופן מעשי. הוא מתקן סביב כל מה שנשאר במסלול. הוא יכול לשמר נתיב בזמן שהוא קובר את התג שמסביר מי היה בתוכו. קרא את מגירת התגים לפני שאתה חותך תפר בהיר; המפעל עלול לאטום את הדליפה מהר יותר מכפי שתספיק לשחזר את השם.
