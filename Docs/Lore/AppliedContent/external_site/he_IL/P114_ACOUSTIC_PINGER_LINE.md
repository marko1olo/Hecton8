# קו פינגר אקוסטי

קו ה-pinger האקוסטי אינו משואת חילוץ. הוא משמעת שנעשתה נשמעת. השחקן מעגן return sound לפני שעכירות, brine shimmer או פחד הופכים את המסלול לזר. הכלי מלמד שניווט הוא הרגל, לא map screen.
