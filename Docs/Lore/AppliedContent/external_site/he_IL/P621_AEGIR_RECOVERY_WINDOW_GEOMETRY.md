# גאומטריית חלון החילוץ של Aegir

חילוץ ב-Aegir הוא לוח זמנים לפני שהוא הצלה. Black Keel יכול לשמוע חבילה דרך מעבר ממסר צר ועדיין לסרב לגוף, משום שהנתיב לא ניקה מופע נשא, תקרת סערה, צל ממסר Kestrel, מצב הסגר, חותם חבילת עלייה ומסת tonne-window מאושרת. HECTON-8 הופך את העיכוב הזה לפיזי. האוקיינוס מחזיק את חומרת הירידה תחת לחץ, השמיים שוברים קו ראייה במזג אוויר וברעש טעון, והנשא מתייחס לכל קילוגרם כחלק מספר התביעות. לכן התשובה הראשונה מהמסלול אינה רחמים. היא הוכחה שחלק אחד של המכונה הסתדר לכמה דקות. הישרדות פירושה לגרום לשאר המכונה להסכים לפני שהחלון הבא נסגר.
