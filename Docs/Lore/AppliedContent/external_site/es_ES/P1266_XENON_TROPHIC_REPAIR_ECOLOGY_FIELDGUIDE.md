# Guía de campo de ecología trófica y reparadora de xenón

Xenon-Omega suele describirse como lo que Deep Reach vino a robar. Es cierto, pero demasiado estrecho. En HECTON-8, el material azul pertenece a una cadena alimentada por respiraderos: calor, sales sulfurosas, defectos de presión, floración fúngica, pastadores, biofilm conductor y rutinas dañadas de Atlas tocan las mismas superficies.

Eso vuelve la ecología una prueba jugable. Una veta azul puede señalar valor, veneno, fuga de corriente, tráfico de depredadores o una antigua ruta de reparación. Un animal etiquetado puede estar cazando, pastando o llevando datos viejos de sensores dentro de un ciclo de mantenimiento. El jugador no necesita una frontera limpia entre naturaleza y máquina. La pregunta útil es qué hace ahora el proceso y quién gana si la muestra sobrevive.
