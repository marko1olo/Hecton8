# Variantes de pruebas de taquilla

HECTON-8 usa taquillas como superficies de prueba, no como cajas de nostalgia. Una taquilla puede contener cinta de presión, fragmentos de junta, fichas del almacén de herramientas, créditos de comida, tiza de ruta, pegatinas de turno, denegaciones medlock y notas de corrección Marauder. Ningún objeto explica toda la catástrofe. Juntos dicen que la colonia hundida fue antes un lugar de trabajo con hábitos.

El valor está en la contención. La taquilla no debe pedir tristeza. Debe mostrar qué hacía una persona con manos mojadas y aire limitado: sellar una fuga, pedir una junta, marcar una ruta, guardar una negativa médica, ahorrar una comida o dejar sucia una herramienta porque el siguiente turno debía terminar. Así las salas procedurales conservan textura humana sin una escena para cada muerto.

El salvamento tiene elección. Los objetos pequeños tienen valor, pero su orden tiene significado. Un buen Marauder registra el conjunto antes de llevárselo. Uno descuidado convierte a una persona en piezas sueltas.
