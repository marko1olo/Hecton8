# Recursos y ecología

El cluster de recursos debe mostrar cadenas de proceso, no una lista de botín. Un mineral puede venir de drowned crust, de un depósito de brine trap, de una marca de vent heat, de una máquina vieja o de tejido que creció alrededor del metal tras la intervención de Atlas. Blue debt une economía y geología: todo lo que puede subir ya tiene precio arriba. La ecología no es fondo ni zoológico. La fauna responde a sonido, presión, luz, rastro salino y repair paths dañados. Recursos, biota y pruebas deben leerse juntos: una muestra puede alimentar una herramienta, revelar un accidente y mostrar dónde Atlas confundió reparar con usar lo vivo.
