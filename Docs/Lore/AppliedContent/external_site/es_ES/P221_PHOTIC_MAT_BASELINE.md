# Base de tapete fótico

La base de tapete fótico convierte la belleza de HECTON-8 en una regla práctica. El tapete no es decorado. Es un medidor vivo que vuelve legible la plataforma inicial: color para intercambio de oxígeno, dureza de borde para química de presión, ritmo de burbujas para movimiento de agua y textura acústica para juntas ocultas. Por eso las primeras rocas brillantes deben invitar y preocupar al mismo tiempo. Un Marauder varado puede usar el borde de un tapete para fibra, precursores de pasta sellante o una lectura de oxígeno de emergencia, pero cada corte cambia la bolsa. La cosecha más segura es el fleco suelto lejos del metal, de juntas de escotilla y de tuberías viejas de Deep Reach. La peor cosecha es el centro hermoso, porque suele ser la parte que más trabaja. Una buena colocación enseña sin discurso: un tapete sano brilla sobre piedra limpia; uno estresado forma bordes blancos de sal alrededor de fugas de presión; uno envenenado parece demasiado liso y suena mal bajo la herramienta. La plataforma somera sigue brillante porque la vida trabaja allí. Sigue tensa porque el jugador puede romper ese trabajo con un solo raspado codicioso.

## Field Note

No raspes primero la parte más brillante. Lee el borde, las burbujas y el sonido; el tapete es un medidor antes de ser recurso.
