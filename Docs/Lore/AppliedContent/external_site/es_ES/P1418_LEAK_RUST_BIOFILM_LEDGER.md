# Registro cronológico de fuga, óxido y biofilm

Una buena mancha de fuga no parece dramática. Parece suciedad. Por eso pertenece a HECTON-8. La verdad no quedó en placas limpias, sino donde el agua se demoró, los pernos sudaron, las juntas respiraron y los trabajadores dejaron de tener tiempo para limpiar.

La pregunta útil no es el color, sino qué capa está arriba. Óxido bajo sal: vieja costura húmeda. Sal bajo aceite: fuga mecánica posterior. Biofilm sobre pintura: superficie húmeda y alimentada. Pintura limpia dentro de una raya sucia: limpieza tardía, etiqueta retirada o herramienta arrastrada.

En juego, la cronología de fuga hace legible un camino, avisa de una junta débil, prueba que una sala funcionó tras el apagado oficial o marca un objeto que conviene conservar.
