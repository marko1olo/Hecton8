# Filtración al registro público

La filtración al registro público no es una fantasía perfecta de denunciante. Es un paquete dañado que sale antes de la custody completa, con pruebas suficientes para hacer cara la negación y suficiente contexto ausente para volver peligroso a cada lector. Tau Ceti puede hacer público el registro mucho después de poder salvar a alguien en el agua.

Ese retraso es el punto. Deep Reach pierde el encubrimiento más limpio, pero el testigo también pierde la propiedad. El mismo registro puede volverse acusación, palanca, matemática de seguros, propaganda de dominio o nuevo contrato. Esta ruta hace que la verdad sea más difícil de enterrar y más difícil de poseer.
