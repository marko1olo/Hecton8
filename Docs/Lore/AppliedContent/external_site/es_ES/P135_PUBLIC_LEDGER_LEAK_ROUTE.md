# Fuga al registro público

La fuga al registro público no es una fantasía perfecta de denunciante. Es un paquete que sale por una ventana relay estrecha con un witness hash, custody suficiente para ser difícil de negar y demasiadas piezas ausentes para ser seguro. Tau Ceti puede hacer público el registro mucho después de poder salvar a alguien en el agua.

Ese retraso es el punto. Deep Reach ya no puede borrar simplemente el claim, pero el jugador tampoco puede decidir quién lo usa después. Aseguradoras, rivales, tribunales cívicos, pools Marauder y oficinas corporativas leerán la misma herida de forma distinta. Este final hace que la verdad sea más difícil de enterrar y más difícil de poseer.
