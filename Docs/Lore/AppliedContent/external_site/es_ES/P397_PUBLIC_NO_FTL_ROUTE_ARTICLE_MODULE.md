# Demora de ruta sin FTL

HECTON-8 no tiene canal de rescate instantáneo. El tráfico humano hacia Aegir se construye con cartas de sondas precursoras, infraestructura de carriles de haz, carga de fusión de pellets, sistemas de frenado, ventanas de portador y traspasos legales de custodia. La urgencia no cancela la masa. Una nave puede tasar una carga, aceptar una reclamación y conservar tu registro sin tener asignación de descenso para mover un objeto útil al agua. Por eso el juego trata la comunicación como evidencia, no como rescate. Una respuesta prueba que alguien oyó la emergencia. No parchea un sello, no mueve un batisalto ni acorta una mala ventana orbital.

## Scanner
