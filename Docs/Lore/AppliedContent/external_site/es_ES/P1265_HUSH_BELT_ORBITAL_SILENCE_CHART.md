# Carta del silencio orbital del Cinturón Mudo

HECTON-8 está lo bastante cerca para que la órbita importe y lo bastante inaccesible para que el rescate falle. Black Keel puede pasar por encima mientras el saqueador de abajo sigue sin canal útil. El Cinturón Mudo nombra esa contradicción: clima magnético de Aegir, ocultación de Kestrel, química oceánica conductora y custodia de relés de Deep Reach.

La radio muere primero. Los láseres necesitan una línea limpia a través de tormenta, hielo de pluma y resplandor. La telemetría acústica sobrevive, pero es lenta, estrecha y tiene dueño. Cada paquete útil sube por boya, búfer y recibo. El resultado es un realismo cruel: el silencio no significa que no haya nadie. Significa que el sistema funciona exactamente como fue diseñado.
