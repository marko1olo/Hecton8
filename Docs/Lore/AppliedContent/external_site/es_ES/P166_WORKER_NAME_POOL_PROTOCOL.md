# Registro de nombres de trabajadores

El Registro de nombres de trabajadores define cómo HECTON-8 convierte evidencia seed en continuidad humana. Cada identidad combina nombre autorado, franja de origen, rol laboral de presión, fragmento de placa, permiso de ruta y marca de turno. El objetivo no es color aleatorio, sino responsabilidad legible: quién podía abrir una escotilla, quién mantenía una bomba, a quién se negó salida médica y qué rastro va a perturbar un Marauder posterior.

El sistema conserva la identidad personal mientras permite variar ubicación de objetos y parejas de evidencia. Esto sostiene la rejugabilidad sin contradicción. Un trabajador puede aparecer mediante casillero, tablero de tareas, tarjeta de ruta o manifiesto, pero el principio se mantiene: las personas no son desechables por el hecho de que la sala sea seedable.

## Scanner

TIRA DE NOMBRE // Franja de origen, permiso de ruta, rol de turno y cicatriz de placa coinciden en un trabajador. Lee el nombre antes de convertir el casillero en salvamento.

## Terminal

PROTOCOLO DE NOMBRES // Las identidades se forman con nombre personal estable, franja de origen, oficio de presión, letra de turno, fragmento de placa y permiso de ruta. El sistema puede variar orden y parejas por seed, pero no convertir personas en etiquetas de botín. Los nombres personales se autoran por idioma; rol, ruta y acceso llevan el significado mecánico.

## Field Note

Los nombres no son adorno. Un nombre dice quién tenía permiso para estar en una sala húmeda cuando la estación empezó a mentir.
