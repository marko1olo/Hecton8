# Custodia del paquete

Un mensaje de HECTON-8 solo importa si sobreviven su ruta, sello, receptor y estado de daño. La custodia del paquete permite que un hecho cruce el retraso de Aegir, las reclamaciones y la extracción física sin volverse carga desechable.

## Scanner
