# Plataforma fótica de escombro calizo

Las plataformas fóticas existen donde la luz aún manda. A esta profundidad el océano no es tan oscuro como para esconderlo todo ni tan amable como para perdonar pasos torpes. Las placas calizas nacen de calcio biogénico antiguo, arenilla de concha y cemento mineral. El escombro encima mezcla roturas naturales, extracción colonial, oleaje de tormenta, tráfico de máquinas y organismos pequeños que vuelven refugio cada grieta.

La lectura útil es local. Arenilla en una junta significa que el agua sigue ordenando el suelo. Polvo pálido en un borde significa fractura reciente. Mancha oliva en poros significa estabilidad. Una marca circular limpia puede ser pie de herramienta, placa de anclaje o mordaza de cantera. Si solo ves brillo, parece una zona segura. Si lees la superficie, es el primer mapa honesto.
