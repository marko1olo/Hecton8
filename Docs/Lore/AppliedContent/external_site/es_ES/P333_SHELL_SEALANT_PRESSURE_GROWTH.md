# Crecimiento de sellante de concha por presión

Reparar no siempre es restaurar. Los sellantes de emergencia de Deep Reach salvaban presión antes que comodidad. Con la química de HECTON-8, una espuma puede volverse concha mineral portante.

Para el libro contable es excelente. Para un saqueador puede arruinar la ruta: el parche engorda hacia dentro, atasca una escotilla, entierra herramientas o aísla el último compartimento detrás de una pared que funciona.
