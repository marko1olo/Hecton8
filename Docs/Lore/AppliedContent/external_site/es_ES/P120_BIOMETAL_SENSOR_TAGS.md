# Etiquetas sensoras de biometal

Las etiquetas sensoras de biometal no son coleccionables genéricos. Son lo que ocurre cuando un sistema de reparación deja de importar si el portador es máquina, crecimiento de cable o animal. La etiqueta es una fina escama biomética que crece dentro del tejido, bebe un poco de corriente, registra movimiento y repite confianza de ubicación por el agua. Un Marauder puede usar una para ajustar un pinger, ampliar alcance de escáner o demostrar que una ruta estaba viva cuando Atlas la tocó. Esa utilidad es el problema. Arranca una etiqueta fría y se vuelve prueba. Arráncala caliente y la red puede notar al portador perdido, responder con falsos retornos o mandar lógica de reparación hacia el animal herido, el kelp cortado o el buzo que sostiene la etiqueta. El material obliga a tratar el botín como un expediente: útil, sucio y todavía informando.

## Scanner

ETIQUETAS SENSORAS DE BIOMETAL // Escamas metálicas finas crecidas en peces, kelp de cable y tejido de reparación. Mejoran el ajuste del pinger; si se extraen calientes, Atlas puede oír al portador perdido.

## Terminal

CLASE DE RECURSO: alterado por Atlas / sensible como prueba. Usos: foco de pinger, retícula de escáner, confianza de ruta, paquetes de prueba. Se recomienda extracción fría. Riesgos: subida de atención, falsos retornos de portador, fauna dañada.

## Audio

El pez no es un dron. La etiqueta informa de todos modos.

## Field Note

Si parpadea bajo el cuchillo, registra antes de cortar.
