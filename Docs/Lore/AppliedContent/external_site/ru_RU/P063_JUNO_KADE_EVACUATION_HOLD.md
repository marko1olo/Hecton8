# Эвакуационное удержание Джуно Кейд

Джуно Кейд стоит между паникой и процедурой. Ее журнал показывает не колонию, слишком глупую для побега. Он показывает очередь, маршала, маршрутные панели, попытки manual override и ворота, которые ждут разрешения, пока вода движется быстрее review.

У удержания несколько имен: карантин, сертификация, ранг payload, claim seal. Каждое имя по отдельности звучит разумно. Вместе они образуют запертую дверь с людьми не с той стороны. Кейд важна потому, что сохраняет человеческую форму эвакуации. Игрок находит не абстрактную халатность. Игрок находит рабочий выход, который стал непригодным из-за разрешенной задержки.
