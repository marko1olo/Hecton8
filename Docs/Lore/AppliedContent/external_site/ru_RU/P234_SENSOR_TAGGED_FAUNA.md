# Фауна с сенсорными метками

Фауна с сенсорными метками удерживает биомеханический слой HECTON-8 приземленным. Старые biometal monitoring tags становятся раковинными гнездами, шрамами и призраками сигнала, давая существам промышленную историю без превращения их в простых марионеток.

## Scanner

Biometal tags сидят в кольцах роста, шрамах и раковинных гнездах; часть животных теперь носит monitoring hardware Deep Reach как историю тела.

## Terminal
