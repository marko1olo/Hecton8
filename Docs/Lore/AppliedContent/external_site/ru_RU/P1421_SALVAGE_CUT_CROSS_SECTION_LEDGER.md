# Журнал среза спасательной резки

В HECTON-8 самая честная дверь часто та, которую никто не проектировал. Панель, вскрытая после обрушения, уже не несет корпоративного обещания. В ней остались цвет перегрева, рваная изоляция, куски прокладки и нетерпеливая геометрия людей, которым было нужно что-то за стеной.

Кромку читают снаружи внутрь. Окрашенная кожа дает ориентацию. Темное ядро показывает несущую часть корпуса. Керамическая пыль говорит, насколько гуляло тепло. Резина, разорванная зубьями, значит механическое усилие после резака. Кабельные концы показывают намерение: ровный срез для изоляции, смятый для паники, зачищенный для кражи, заглушенный для экипажа, который собирался вернуться.

Хороший срез может держать целую пропавшую сцену. Он показывает, что стену вскрыли после затопления, обходили запертый люк, вынимали доказательство, спасали зажатого рабочего или готовили проход для поздних добытчиков. Кромка не помнит имен, но помнит инструменты.
