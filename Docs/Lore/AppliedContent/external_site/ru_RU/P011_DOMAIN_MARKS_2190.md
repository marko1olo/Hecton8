# Метки доменов 2190

К 2190 году один сломанный предмет может иметь сразу нескольких юридических родителей. На HECTON-8 замок давления может быть сертифицирован Sol, отремонтирован Barnard, проведен через хранение Luyten, оправдан языком Centauri и изъят оболочкой Aegir. Метки не делают колонию безопасной. Они делают ее задокументированной.

Эта разница держит тон игры. HECTON-8 не за пределами цивилизации. Она под ее холодной стороной: той, что умеет назвать кронштейн, оценить тело, сохранить пакет и все равно не сдвинуть спасательную массу вовремя.
