# Окно возвратного вектора

Окно возвратного вектора описывает эвакуацию с HECTON-8 как орбитальную процедуру, а не мгновенное спасение. Black Keel может принять сигнал через узкие окна Aegir, но подбор зависит от разрывов шторма, спадов заряженных частиц, целостности реле и восстановленного подъемного железа. Этот пакет связывает первый контакт с carrier и более поздние записи частичного выхода: ответ доказывает, что маршрут может существовать, а не что он готов.

## Scanner

СЧИТЫВАНИЕ ВОЗВРАТНОГО ВЕКТОРА // Пинг Black Keel принят через штормовой разрыв Aegir. Дальность carrier: высокая переходная траектория. Релейная линия шумит ниже облачного заряда. Подъем капсулы отклонен, пока ядро наведения, теплозащита и возвратное рукопожатие не дадут зеленый.
