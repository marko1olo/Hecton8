# Цветение фонарного дрейфа

Цветение фонарного дрейфа объясняет, почему HECTON-8 может быть ярким и при этом давящим. Биолюминесцентный планктон делает воду читаемой, но также скрывает угрозы и разносит шум инструментов через пищевую сеть.

## Scanner
