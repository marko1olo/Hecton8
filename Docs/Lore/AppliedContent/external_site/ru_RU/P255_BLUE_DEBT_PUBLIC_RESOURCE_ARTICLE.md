# Публичная статья о ресурсе Blue Debt

Blue debt — не магическая руда. Это frontier-сленг для Xenon-Omega-bearing pressure substrate: соленые минеральные карманы, clathrate layers, загрязнение pressure glass, biofilm-bound lattice и поврежденный containment material, переживший условия, где обычная техника не живет. Его ценность приходит из истории под давлением. Образец может хранить следы вычислений, поведение containment, sensor memory или химические состояния, которые могла создать только HECTON-8.

Слово debt важно. Blue debt ценен потому, что кто-то уже заплатил за его образование инфраструктурой, трудом, временем и риском. Чистый на вид кусок может одновременно нести quarantine exposure, хранение Deep Reach, штраф массы Black Keel и доказательную ценность. Взять его — не просто добыть. Это спор с маршрутным реестром.

Публичный текст ресурса должен делать материал желанным, но не простым. Игрок должен хотеть сканировать его, удерживать, продавать, доказывать и иногда оставлять. Лучший объект blue debt — не светящийся приз. Это запись давления: достаточно полезная, чтобы рискнуть переноской, достаточно нестабильная, чтобы требовать уважения, и достаточно задокументированная, чтобы право собственности могло ранить.
