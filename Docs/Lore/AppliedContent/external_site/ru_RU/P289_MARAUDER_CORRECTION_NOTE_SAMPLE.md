# Пример Marauder correction note

Marauder notes позволяют миру спорить с официальными записями. Они сохраняют сомнение, не ответы.

## Scanner

Correction note зачеркивает accident и пишет weighted delay.

## Terminal

MARAUDER NOTE: official cause rejected; physical contradiction required before claim filing.

## Audio

Кто-то уже почувствовал гниль в бумагах.

## Field Note

Пример prop copy: NOT WEATHER. AUTH DELAY. CHECK PUMP CERT, SHIFT COUNT, BODY CATEGORY.
