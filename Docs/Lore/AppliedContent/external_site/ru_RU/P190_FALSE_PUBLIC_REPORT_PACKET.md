# Пакет ложного публичного отчета

Пакет ложного публичного отчета формулирует публичную версию Deep Reach о потере колонии и пропуски, которые делают ее ложной. Это не пропаганда, отрицающая катастрофу; это пропаганда, редактирующая катастрофу в несчастный случай без ответственных рук. Статья важна потому, что позволяет HECTON-8 сохранить жесткую научно-фантастическую катастрофу и одновременно доказать легенду прикрытия. Физика океана объясняет, почему колония была уязвима.
