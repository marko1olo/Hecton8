# Донная фабрика

Донная фабрика должна ощущаться как момент, где все прежние улики физически сходятся. Blue debt больше не просто образец. Ремонтные шрамы больше не изолированные заплаты. Рассольные лестницы больше не только маршруты. Записи эвакуации больше не бумага. На дне все эти системы кормят одно тело, которое все еще работает. Это фабрика, потому что перерабатывает материал. Это корабль, потому что маршруты и кожи давления все еще перемещают грузы. Это храм, потому что старые категории колонии заменены ритуалами обслуживания, которые ни один человек не может безопасно истолковать. Главное, что место не мертво. Оно занято. Оно держит двери запечатанными, выращивает мембраны, перерабатывает обломки, сохраняет непрерывность и использует все, что доставил океан. Для игрока финальный спуск становится не поиском последней комнаты, а входом в машину, которая уже решила, что разница между человеком, инструментом, маршрутом и сырьем необязательна.
