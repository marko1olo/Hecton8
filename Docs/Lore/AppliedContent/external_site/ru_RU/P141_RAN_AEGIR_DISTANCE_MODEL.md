# Модель расстояния Ran-Aegir

Модель расстояния Ran-Aegir лежит под давлением HECTON-8 как тихий фундамент. Aegir находится в жестокой средней зоне: достаточно близко, чтобы корпорации оправдали маршрутные пластины, seed-оборудование, грузовые залоги, удаленных нотариусов и постоянную добывающую колонию; достаточно далеко, чтобы никто не мог срочно проявить милосердие, когда срывает гермодверь.

Именно это различие важно. Сообщения, юридические претензии, графики перевозчиков, спасательные суда и человеческие тела живут на разных часах. Предупреждение уже летит, пока корабль, который должен ответить, все еще заперт в топливе, стартовом окне, массе и разрешении собственника. Deep Reach научилась пользоваться этим зазором. Колония жила внутри него.
