# Железный коралл

Спасательные реестры HECTON-8 описывают минерализующий колониальный рост, который закрепляется только на железосодержащей и сплавной подложке, поэтому стоящая кора — надёжный поверхностный признак закопанной конструкции. Цвет коры используют в поле для оценки того, что лежит ниже, включая синеватое изменение, связанное со следовым содержанием Xenon-Omega.

На учёте две практические издержки. Скелет истирает швы перчаток костюма, давая отказы, которые проходят статическую проверку герметичности, а аналитические партии Deep Reach зачитывают поднятую кору по массе брутто против тоннажа поднимающей стороны, не разделяя кору и подложку. Записи по Сектору 44 также закрывают осмотры швов с пометкой «заросло».
