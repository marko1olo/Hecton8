# Жизнь светового шельфа

Жизнь светового шельфа задает верхнюю экологическую базу HECTON-8. Поверхностный пояс все еще получает свет, тепловые смены и ритм неба, поэтому местная жизнь оставляет читаемые маршрутные признаки до появления ремонтной логики Atlas глубже: кислородные маты, дорожки glass-grazer, изгиб pressureweed и маршрутные водоросли вокруг обломков. Шельф объясняет, почему Deep Reach хотела эту луну, не делая его безвредной зоной. У каждого полезного признака есть путь отказа. Мат, который может дать вдох, может скрывать загрязнение; водорослевая дорожка, ведущая к обратному течению, может сместиться под штормовым илом или давлением хищника.

## Scanner

СКАН СВЕТОВОГО ШЕЛЬФА // Кислородный мат на базальтовой кромке. Свежая дорожка glass-grazer прорезает зеленый рост. Pressureweed согнут к западу до прихода волны. Маршрутные водоросли отмечают течение к линии укрытия. Риски: проход мелководного хищника, штормовой ил, слабый возвратный линь.

## Terminal

БАЗОВАЯ СЪЕМКА ШЕЛЬФА

Образец B: дорожка glass-grazer / свежий срез / разбег хищником не исключен
Образец C: изгиб pressureweed / западный наклон до волны
Образец D: маршрутные водоросли / течение возвращает к линии укрытия
Сравнить с: кабельным корневым матом, тканью ремонтного шрама, биопленкой глубинного шлюза

## Field Note

Яркая вода сначала полезна, а уже потом безопасна. Проверь цвет мата, дорожки grazers, изгиб weed и натяжение линя, прежде чем доверять ей.
