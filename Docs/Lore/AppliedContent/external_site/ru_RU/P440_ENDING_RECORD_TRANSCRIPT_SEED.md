# Транскрипт финальной записи

## Закрытие, Записанное Как Custody

Финалы HECTON-8 не должны давать игроку чистое оправдание. Запись называет receiver, payload hash, состояние долга и состояние выживания, потому что институты помнят эти поля лучше, чем людей. Эта холодность полезна. Она делает каждый исход сравнимым, не превращая правду в трофей.

Самые важные поля остаются нерешенными. Suppression flag unknown. Truth custody unresolved. Atlas continuity unclear. Public ledger status pending. Эти разрывы держат финал честным: что-то вышло из океана, но владение не равно справедливости, а выживание не равно ремонту.

Формат транскрипта защищает replay. Игрок может вернуться со знанием, но следующий заход не должен наследовать силу. Он наследует подозрение, вкус и страх. Запись - квитанция, не прощение.
