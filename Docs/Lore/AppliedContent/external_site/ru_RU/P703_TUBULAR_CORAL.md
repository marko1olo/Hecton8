# Трубчатый коралл

Спасательные команды Aegir на HECTON-8 сообщают о колониальном трубчатом организме, который закрепляется по трещинам в промышленной обшивке, а не по целой поверхности, заполняя и запирая под давлением трещины в конструкциях, оставленных без присмотра с 2147 года. Есть помещения, поднятые с давлением в несколько мегапаскалей, которое держит только рост.

Тот же рост покрывает выштампованную идентификацию панели, по которой выполняется сертификация конструкций. Ремонтные записи Deep Reach по Сектору 44 закрывают такие помещения по наружному обследованию — метод, который устанавливает, что помещение целое, не устанавливая, какое это помещение. На практике любую дорожку, пересекающую сварной шов, считают несущей.
