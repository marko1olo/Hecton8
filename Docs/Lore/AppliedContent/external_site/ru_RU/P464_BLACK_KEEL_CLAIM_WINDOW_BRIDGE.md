# Окно претензии Black Keel

Black Keel может услышать сигнал раньше, чем поднимет тело. В Aegir ответ носителя это платная полоса через геометрию реле, погоду, карантин, прием груза и возврат массы. Контакт это факт маршрута. Спасение это завершенная цепь.

## Scanner

ОКНО ПРЕТЕНЗИИ // ретранслятор Aegir показывает только окно приема. Для возврата нужны подъемный пакет, карантинное согласование и лимит tonne-window.

## Terminal

УВЕДОМЛЕНИЕ KEELMARK // сигнал оператора получен. Приоритет возврата не решен. Прием сигнала или пакета доказательств не гарантирует возврат оператора.

## Audio

Ретранслятор Black Keel: сигнал оператора оценен. Окно возврата ожидает. Не путай прием с подъемом.

## Field Note

Если Black Keel отвечает, считай счет, а не спасение. Принятый пакет это только место в очереди, пока масса, пломба, карантин и погода не совпадут.
