# Запись материальной выплаты

Эта запись выплаты важна полями квитанции: что купил получатель, чего нет в приложении, какие координаты приняты, какой образец ушел, как изменился залог, какие имена отсутствуют и какой обратный путь получила Deep Reach.

Получатель: Keelmark/Recovery Compliance.

Эффект для Deep Reach: более чистый обратный путь к HECTON-8.
Известная потеря: доказательство можно оценить в деньгах и не выслушать.
