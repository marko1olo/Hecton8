# Маршрутная лестница рассольного каньона

Рассольные каньоны превращают глубину в вещество. Плотные соляные реки лежат внутри океана как полы, зеркала и ловушки. Чистый маршрут строится из маркеров плотности, окон балласта, проверок ретрансляторов и дисциплины угла, а не из храбрости. Нижние слои объясняют цену приборов: сонар может отразить помещение сверху, плавучесть может солгать, и скафандр может быть прав, пока море с ним не согласно.

Маршрутная лестница рассольного каньона показывает спуск на HECTON-8 как химическую географию: выживаемость маршрута решают плотность, течение, минеральные стены и звук. Через каньон не плывут. С его слоями договариваются, потому что они тяжелее скафандра.
