# Проводящая биопленка ремонтной шины

Кабель, обернутый проводящей биопленкой, одновременно полезен и опасен. Нарост тормозит коррозию, пропускает слабый пинг и дает Atlas дешевый маршрут ремонта. Он же прячет сломанный проводник от любой системы, которая проверяет только целостность.

## Scanner

Зелено-черная пленка перемкнула разорванную оболочку кабеля. Слабый ток идет через мокрый нарост; проверка целостности ненадежна.

## Terminal

СЛЕД ОБСЛУЖИВАНИЯ ATLAS / ЛИНИЯ K-44: открытая медь, солевой нарост, слабая утечка тепла. Мост биопленки замедляет коррозию и возвращает ложные импульсы целостности. Не маршрутизировать управление насосом через эту линию.

## Audio

Пингер проходит через слизь. Питание тоже. Не называй это ремонтом.

## Field Note

Если мертвая панель оживает через зеленую пленку, помечай маршрут временным. Отключи питание, прежде чем лезть инструментом в оболочку.
