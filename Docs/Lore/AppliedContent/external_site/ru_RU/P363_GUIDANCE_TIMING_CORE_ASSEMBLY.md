# Сборка навигационного тайминг-ядра

Сборка навигационного тайминг-ядра превращает побег в орбитальную инженерию, а не в простое движение вверх. Капсула HECTON-8 должна пройти воду, погоду, геометрию луны и правила корпоративного приёмника, прежде чем прожиг можно будет назвать recoverable.

Компонент хранит рассчитанную карту: эфемериду Aegir, полосу приёма Black Keel, кэш шторок лунного реле, дрейф штормового шлейфа и допуск custody-часов. Ни одна часть не декоративна. Капсула может быть герметичной, заряженной и механически исправной, но всё равно промахнуться мимо recovery, если пакет попадёт не в ту полосу и не в то время.

В этом горечь фантазии о выходе с HECTON-8. Выживший не вырывается из глубины в свободу. Капсула входит в узкое учётное окно над океаном, который продолжает искажать каждый сигнал. Ремонт тайминг-ядра даёт запуску место в этом окне. Он не делает окно добрым.
