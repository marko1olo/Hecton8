# Метка Barnard

Barnard Yards — не благородная родина. Это рабочий шрам: разборка кораблей, арендованные резаки, нажимные хомуты, инструмент третьего владельца и люди, которые точно знают цену плохому контракту. Первый штамп Barnard на HECTON-8 должен казаться почти слишком маленьким для лора. Это не речь. Это метка на ключе, неправильный сплав на петле шкафчика, ремонтная привычка, которую Deep Reach никогда бы не прописала. Для игрока эта деталь меняет контракт. HECTON-8 уже не просто мёртвый корпоративный claim под чужой водой. Кто-то из той же верфевой культуры добрался сюда раньше, работал здесь, попал в те же книги и оставил доказательство достаточно малое, чтобы его стёрли, если Marauder не заметит.
