# Фауна плотностных скользунов

Фауна плотностных скользунов показывает hard-sci-fi логику существ HECTON-8. Они не ломают физику; они используют brine interfaces, слои давления и слепые зоны сонара как среду и охотничьи маршруты.

## Scanner

Скользуны идут по brine interface как по твердой поверхности, оставляя рябь там, где сонар ожидает открытую воду.

## Terminal
