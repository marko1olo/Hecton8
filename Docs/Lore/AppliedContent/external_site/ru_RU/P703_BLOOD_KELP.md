# Кровавая ламинария

Глубоководная съёмка на HECTON-8 фиксирует прикреплённую макрофлору с красным пигментом, образующую отдельные кусты на твёрдом основании примерно между 1400 и 2600 м. Пигмент поглощает синезелёную полосу, под которую взвешены штатные рабочие лампы, поэтому куст почти ничего не возвращает конусу лампы и проявляется только на дистанции контакта, тогда как янтарные аварийные фильтры показывают его отчётливо.

Контакт вызывает разряд фотофоров по всему кусту, который держится порядка девяноста секунд. Спасательные команды считают полученный свет раскрытием своей позиции, а не подспорьем. Записи заготовки Deep Reach по Сектору 44 числят рост как сырьё для освещения и сохраняют классификацию «не опасно, растительность» рядом с четырьмя зафиксированными случаями запутывания.
