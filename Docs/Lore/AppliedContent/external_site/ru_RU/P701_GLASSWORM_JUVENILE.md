# Стеклянный червь, ювенильная особь

Отчёты по спасательным работам HECTON-8 описывают колониальную трубчатую ювенильную форму, которая наращивает проводящую подложку следового класса прямо на трещинах конструкций колонии, причём густота роста следует за скоростью потока через трещину. Устья трубок ориентированы согласованно навстречу притоку, что позволяет прочитать ось течи снаружи обрастания.

Такой рост скрывает утечки давления, а не устраняет их. Команды сообщают о повреждениях перчаток и уплотнений у обрастаний, выглядевших мёртвыми, и о последовательном разрушении трубок при срезе несущего участка. Записи Deep Reach по Сектору 44 относят организм к органическим герметикам конструкций, отмечают соответствующее отклонение по давлению как скомпенсированное и не содержат описания взрослой формы вида.
