# Экология обслуживания

Atlas не нашел дружелюбный океан. Он нашел жизнь, способную нести нагрузку. Проводящая биопленка могла на несколько часов замкнуть слабую цепь. Раковинный рост мог удержать трещину до следующего скачка давления. Фильтрующая колония могла повторить акустический импульс дальше, чем утонувший ретранслятор. Меченая фауна могла вернуть sensor packets после отказа металлических drones.

Поэтому ремонтная сеть одновременно соблазнительна и мерзка. Игрок может срезать живой материал ради salvage или оставить его, потому что он держит давление. Стена может быть инфраструктурой, средой обитания и уликой сразу. Экология обслуживания доказывает первой: HECTON-8 не магический. Он хуже магии, потому что за каждым чудом стоит рабочий наряд.
