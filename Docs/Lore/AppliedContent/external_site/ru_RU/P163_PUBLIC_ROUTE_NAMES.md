# Публичные Названия Маршрутов

## Имена, Которые Выставляют Счет

Публичные маршруты HECTON-8 не обязаны быть красивыми. Они обязаны переживать invoices, печати, insurance tables и salvage-споры. Название маршрута - та часть карты, которая все еще важна, когда картинка исчезла и остался только контракт.

Sol-Centauri Charter Spine - приличная линия. Она несет старую легитимность, compatibility language и формулировки, которые Deep Reach любит цитировать, когда хочет сделать frontier project цивилизованным на вид. Barnard Breaker Run грубее и честнее: shipbreaking, pressure hardware, debt crews, stripped hulls и практическая культура, делающая Marauders возможными.

Luyten Packet Ladder - не общество в романтическом смысле. Это custody infrastructure. Она объясняет, почему сообщение может стать доказательством, почему доказательство может задержаться и почему честный пакет не равен помощи. Tau Public Ledger Lane - место, где доказательство становится публичным давлением после того, как свет проделал свою медленную работу.

Ran Long Claim ближе всего к HECTON-8. Это не highway. Это claim path через дистанцию, закон, braking rights и freight cost. Когда игрок видит его на плите, правильная реакция - не восторг. Правильная реакция - расчет: чей это маршрут, что через него двигали и почему человеческое тело не попало в return manifest?
