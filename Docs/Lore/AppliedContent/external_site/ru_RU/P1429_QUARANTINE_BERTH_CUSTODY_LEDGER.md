# Журнал карантинной койки и custody

HECTON-8 остается правдоподобно одинокой, потому что подтверждение отделено от спасения. Цивилизация вокруг Aegir не невежественна и не бессильна. Она может принять доказательный пакет, оценить образец, ответить на distress hash и все равно не перевезти живое тело, потому что тело - другой класс обязательства.

Журнал карантинной койки делает эту разницу физической. Он называет комнату, медицинского владельца, hold загрязнения, ответственность приемника, lift exception и тормозной запас, без которых выживший не становится грузом, который маршрут обязан поймать. Без этих полей сообщение может быть честным и все равно бесполезным для эвакуации.

Это не должно делать мир тупым. Он должен ощущаться промышленным. На HECTON-8 спасение - не синяя лампа, прилетевшая потому, что сюжету нужна милость. Это дорогой перенос из океана, claim-law и корпоративных доказательств в воздух, которым владеет кто-то другой. Игрок может использовать эту правду: пакеты создают давление, но заполненные custody-поля создают рычаг.
