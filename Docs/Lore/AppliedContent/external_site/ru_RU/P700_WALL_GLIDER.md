# Стенной ползун

Сообщения с шельфовых спасательных работ HECTON-8 описывают вид, который держится на поверхности и передвигается исключительно по изготовленным материалам — обшивке корпуса, кабелепроводам и кабельным трассам — и не переходит через трещины в том, за что держится. Команды читают протяжённость его следов как признак целой обшивки.

Животное оставляет по маршруту проводящий налёт, который несёт слабый ток там, где конструкция ещё под напряжением. Поскольку налёт электрически перекрывает волосяные трещины, автоматическая проверка целостности даёт исправный результат на обшивке, которая механически разрушается. Записи Deep Reach по Annex P-63 принимают полученный охват в замену планового мониторинга конструкции и сообщают об отсутствии отклонений по давлению на обследованном следе, не описывая остаток.
