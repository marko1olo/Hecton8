# Финальный вопрос: отсечение, милость, кража

Отсечение должно ощущаться как работа инструментом, а не как моральная кнопка. Разрез проходит через двери давления, живую проводящую пленку, буферы записей рабочих, маршруты помеченной фауны, vent micronodes, импульсы shell sealant и пути груза. Каждый пакет доказательств, принесенный в финальную комнату, меняет того, кто потом сможет назвать этот поступок.

Если Atlas действует как тюремщик, отсечение может выпустить запертые записи из логики, которая продолжала их хоронить. Если Atlas держит бассейн вместе, тот же разрез может превратить ремонтные маршруты в мертвое оборудование. Если ремонтный слой стал формой местной жизни, отсечение ранит не только машину. Если Deep Reach еще может пройти по рельсу непрерывности, разрез закрывает им дорогу назад. Финал работает, когда запись сначала показывает физический ущерб, а спор о ярлыке оставляет праву получателей.
