# Маршрутные сонарные пингеры

Маршрутные сонарные пингеры являются характерным объектом HECTON-8: дешевым, физическим, акустическим и морально нагруженным. Они помогают игроку картировать, возвращаться, метить улики и договариваться о спасении, одновременно объявляя океану о присутствии.

## Scanner

Pinger float отмечает геометрию возврата, вскрывает false echoes и может притянуть и помощь, и нежелательную жизнь.

## Terminal

PINGER RULE: return line first, sample tag second, distress packet third. Never trust one echo.

## Audio

Один пинг - обещание. Два пинга - счет.

## Field Note

Pinger - первый честный инструмент: он говорит о дистанции, долге, потере маршрута и риске существ через звук.
