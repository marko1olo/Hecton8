# Колонии вент-якорей

Колонии вент-якорей объясняют, почему глубокое исследование механически необходимо. Они превращают термальные выходы в ресурсные двигатели, биологические укрытия и угрозы давления, давая игроку причину двигаться вниз, а не просто чиниться вверх.

## Scanner

Колониальные ребра цепляются за thermal vents, ловят сульфиды и питают материалы для глубинного ремонта.

## Terminal

RESOURCE NOTE: vent anchor colonies повышают вероятность sealant и pressure-ceramic. Тепловое воздействие остается смертельным.

## Audio

## Field Note
