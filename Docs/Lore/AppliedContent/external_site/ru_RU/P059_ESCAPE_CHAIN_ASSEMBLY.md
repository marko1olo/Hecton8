# Сборка цепи побега

Сборка цепи побега — инженерный хребет кампании. HECTON-8 не даёт чистого извлечения на поверхность после первого ремонта; уход становится набором физических, юридических и доказательных компонентов, разбросанных по утонувшей инфраструктуре. Это даёт долгому спуску практическую и моральную причину: игрок не просто покидает океан, а собирает маршрут, который доказывает, почему у колонии никогда не было честного выхода.

## Scanner

Для выхода нужны шесть твёрдых доказательств: релейная связь, уплотнение, наведение, заряд подъёма, юридическое рукопожатие и груз, который носитель не сможет проигнорировать.

## Terminal

ПАКЕТ ПОДЪЁМА: акустический релейный хребет отсутствует. Рейтинг зажимного кольца недостаточен. Ядро наведения отсутствует. Люлька заряда пуста. Карантинное рукопожатие не решено. Доказательный груз необязателен, но меняет власть над возвратом.

## Audio

Ты не ремонтируешь капсулу. Ты строишь первый честный выход, которого у колонии никогда не было.

## Field Note

Маршрут вверх строится из деталей, которые никогда не предназначались для самостоятельного ухода рабочих.
