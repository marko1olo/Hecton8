# Леса соляных лопастей

Леса соляных лопастей задают экологию каньонов HECTON-8. Эти мембранные ростки отмечают границы плотности, маршрутные угрозы и химическую экономику, из-за которой глубокий океан луны ощущается созданным давлением.

## Scanner

Плоские brine vanes растут вдоль границ плотности и показывают, где вода становится стеной.

## Terminal

CANYON NOTE: держись рваных краев vane для дыхательных карманов; избегай мутной слоистой воды.

## Audio

У каньона есть листья, потому что у него есть градиенты давления.

## Field Note

Леса лопастей не являются растениями в земном смысле. Это соляно-минеральные мембраны, питающиеся химическими градиентами.
