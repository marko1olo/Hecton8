# Частичный выход: возврат в тот же seed

Частичный выход - клапан давления для длинной истории выживания. Подрядчик зарабатывает окно pickup, получает зашитые раны, подлатанное снаряжение и редкий звук воздуха не через умирающий костюм. Облегчение настоящее, поэтому возврат и болит.

Black Keel записывает паузу как welfare и обслуживание lien. Тот же world seed остается активен, те же улики не решены, тот же океан ждет со всеми открытыми маршрутами. Частичный выход - не милость системы. Это обслуживание актива, от которого все еще ждут спуска.
