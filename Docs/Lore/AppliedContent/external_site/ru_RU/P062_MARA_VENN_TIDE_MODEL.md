# Приливная модель Мары Венн

Мара Венн писала не пророчество. Она писала модель с доверительными границами, эвакуационными запасами и плохим таймингом. При весенней геометрии Aegir сдвиг криосферы мог обогнать доступную подъемную емкость. Колонии не нужна была идеальная уверенность. Ей нужен был кто-то, кто увидит в хвосте кривой людей, а не расход.

Deep Reach сохранил модель и ослабил реакцию. Предупреждение стало monitor, эвакуационный запас стал будущей бюджетной проблемой, а публичный отчет позже назвал паводок нечитаемым. Игрок должен чувствовать ложь по форме документа: прилив был естественным, но катастрофу отредактировали.
