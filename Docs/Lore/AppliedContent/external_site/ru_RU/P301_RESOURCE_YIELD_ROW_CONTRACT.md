# Строка приемки ресурсного выхода

Сальважные реестры вокруг HECTON-8 не оценивают минералы по одному названию. Запись выхода требует класс образца, диапазон давления, маршрут хранения, состояние истощения, стадию загрязнения и хеш пакета, прежде чем заявленная стоимость станет доверенной. Образец без истории давления остается неоплаченной массой.

## Scanner

Строка образца неполная: история давления, класс хранения, истощение, загрязнение и хеш пакета не сходятся.

## Terminal

СХЕМА ПРИЕМКИ ВЫХОДА / Aegir Reclamation Pool: не выставлять стоимость без класса ресурса, диапазона давления, класса хранения, кривой редкости, поведения истощения, стадии загрязнения и хеша свидетеля пакета. Камень в мешке считается массой, пока маршрут давления не доказан.

## Audio

Black Keel: удержание образца принято после маршрута давления и хеша хранения. До этого он летит балластом.

## Field Note

Если в строке нет диапазона давления, не спорь о цене. Клади в мертвую массу, держи контейнер запечатанным и заставь брокера платить после очистки хранения.
