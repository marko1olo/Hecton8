# Лучший маршрут: видимый остаток

Самый сильный финал HECTON-8 не должен чинить мир до экрана награды. Он должен дать оператору сделать конкретную работу: выйти из хранения Black Keel, опубликовать запись, закрыть Deep Reach дорогу назад, сохранить живой бассейн под карантином, вынести имена рабочих или запечатать Atlas proof hash там, где его нельзя оценить как груз.

Запись должна оставить и открытые поля. Оплаченный выход может пропустить имена рабочих. Публичная публикация может создать получателей, которые используют файл как оружие. Отсечение может остановить поврежденную власть и ранить ремонтную жизнь. Сохранение может защитить напорную экологию и оставить старый сортировщик активным. Хорошая финальная запись показывает спасенную вещь, получателя, эффект долга, состояние Atlas и ущерб, который все еще движется по системе.
