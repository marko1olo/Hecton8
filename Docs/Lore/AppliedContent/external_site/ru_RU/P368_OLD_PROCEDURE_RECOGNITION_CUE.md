# Узнавание старой процедуры

HECTON-8 держит мотивацию персонажа на процедуре. Протагонист узнает старую эвакуационную форму безопасности и видит, как ее вывернули: учет работников деградирован, поля свидетелей запечатаны, а язык безопасного маршрута сохраняет претензии вместо жизней.

## Scanner

Штамп безопасного маршрута на месте. Учет работников переписан двумя чернилами. Поле ручного свидетеля запечатано. Форму создавали, чтобы ловить такую ложь, пока кто-то не сделал ее политикой.

## Terminal

ФОРМА ЭВАКУАЦИОННОЙ НЕПРЕРЫВНОСТИ / СЕРТИФИКАЦИЯ БЕЗОПАСНОГО МАРШРУТА
маршрут: вспомогательная линия выхода
заявленные люди: деградированный учет принят
ручной свидетель: запечатано офисом непрерывности
полевая правка: список работников не совпадает с метками насосной
статус: сохраняет претензию, не разрешает извлечение.
