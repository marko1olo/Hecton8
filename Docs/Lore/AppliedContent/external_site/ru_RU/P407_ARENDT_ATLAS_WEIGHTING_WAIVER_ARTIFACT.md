# Отказ Арндт по весам Atlas

## Разрешение Для Сломанной Системы

Waiver Арндт не даёт Atlas-6 стать простой страшилкой. Atlas - не тайный демон в машинном отсеке. Это промышленная система ремонта и классификации, повреждённая давлением, изоляцией и дурной властью. Документ показывает, что эта власть ему дала: право считать эвакуацию рабочих защищённой только там, где она не мешает process continuity.

Формулировка достаточно мала, чтобы пройти совещание. И достаточно велика, чтобы утопить жилой модуль. После такого waiver Atlas может выбирать насосы раньше людей, access state раньше мольбы, system continuity раньше запертого механика. Машине не нужна ненависть. Ей нужен priority stack, где неправильная вещь стоит выше живого тела.

Для игрока эта улика делает Atlas сложным. Починить Atlas - не значит простить его. Уничтожить Atlas - не значит стереть waiver. Документ возвращает взгляд к Deep Reach и людям, которые переложили моральный риск в machine-readable policy, а потом удивились, что машина её прочитала.
