# Запись частичного возврата

Эта запись отмечает вдох кампании, а не сброс. Она нужна, когда у маршрута есть железо эвакуации и живое окно перевозчика, но не хватает закрытого хранения, чтобы подъем стал свободой.

## Scanner

ЗАПИСЬ ЧАСТИЧНОГО ВОЗВРАТА // Подъем Black Keel принят. Возврат в тот же seed разрешен под продленным залогом; память сканов и открытые доказательные пакеты сохраняются.

## Terminal

ЗАПИСЬ ФИНАЛА / ЧАСТИЧНЫЙ ВОЗВРАТ
Подъем: временная эвакуация Black Keel.
Цель: ремонт костюма, пополнение воздуха, декон, синхронизация реестра.
Состояние хранения: залог продлен; карантинный срок приложен.
Право возврата: тот же seed, тот же океан, предупреждения маршрута сохранены.
Сохраняемые данные: память сканов, открытые доказательные пакеты, нерешенная полезная нагрузка.
Известная потеря: облегчение выставляют в счет раньше, чем оно становится свободой.
