# Илия Варнек: приливный допуск

Статья «Илия Варнек: приливный допуск» — один из первых ясных взглядов HECTON-8 на то, как устроена ответственность Deep Reach. Здесь нет простой версии корпоративного зла. Варнеку не нужно нажимать кнопку потопа. Он подписывает трактовку риска.

В 2147 году модель Великого прилива все еще проходила по среднему значению. Опасное слово — «среднему». Среднее поведение сохраняло производственный график, пока экстремальный стек оставался внутри рабочей экспозиции: приливные окна Aegir, отдача ледового шельфа, трафик маршрутов давления и неопределенность компенсации Atlas. Маршрут может быть статистически приемлемым и смертельным для тех, кто встретит хвост кривой.

Для игрока это доказательство превращает катастрофу из несчастного случая в цепочку решений. Мемо Варнека — не признание. Это документ, который делает вину читаемой: неопределенность была известна, уценена и передана вниз. Ужас бюрократический, но не сухой. Допуск сделали таким малым, что рабочие могли умереть внутри него.
