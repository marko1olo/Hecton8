# ベントフォージ現地工程ガイド

ベントフォージは海底の宝箱ではない。熱い湧出流、塩水の密度、砕けた鉱物供給、そして急ぎを許さない圧力からできた遅い反応炉だ。有用な物質はしばしば、自然沈殿物と失敗した工業バッチの中間にある。鉱物の喉で育つセラミック粒、裂け目に焼き付くシーラント前駆体、正しい順序で冷えたときだけ安定する電荷膜だ。

だから現地処理そのものが資源の一部になる。新しいロットを冷水に引き上げれば殻は割れる。熱を早く逃がしすぎれば、清潔な試料は粉になる。待ちすぎれば、ベントは欲しかった層の上に別の化学を書き込む。サルベージ班がベントフォージを重視するのは、HECTON-8を惑星自身が働き続ける場所に感じさせるからだ。海は素材を隠しているだけではない。まだ製造している。
