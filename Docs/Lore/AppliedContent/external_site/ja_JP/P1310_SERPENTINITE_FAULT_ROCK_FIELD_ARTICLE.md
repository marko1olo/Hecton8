# 蛇紋岩断層岩の野外記事

蛇紋岩は HECTON-8 の洞窟地質を交換可能な背景ではなく具体的なものにする。ただの緑の岩ではない。水、熱、圧力に変えられた深部超苦鉄質物質で、鉱物が変わり、古い剪断帯の面が滑らかになったものだ。

蛇紋岩の壁は道と脅威を同時に約束すべきだ。淡い脈帯はよい支点になり得る。光る緑面は古い滑り面かもしれない。アルカリ性湧水は近くの生命を変え、隠れた水の動きを示す。

Deep Reach はこれらの断層を、すでに壊れていたから使った。古い弱さを許可と取り違えたのが問題だった。
