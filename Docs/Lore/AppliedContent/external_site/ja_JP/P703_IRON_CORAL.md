# 鉄サンゴ

HECTON-8のサルベージ台帳は、鉄質および合金の基材にのみ定着する鉱化性の群体生長を記述している。そのため立っている外殻は、埋没した構造を示す信頼できる表面指標になる。現場では外殻の色で下にあるものを推定し、微量のXenon-Omega含有に伴う青い変色も判断材料に含める。

実務上の負担が二点記録されている。骨格はスーツのグローブ縫い目を削り、静的な気密確認を通ってしまう不具合を生じる。またDeep Reachの分析ロットは、回収された外殻を基材と分離せずに総質量で回収側のトン数に計上する。セクター44の記録は、被覆と記載された継ぎ目点検も終了扱いにしている。
