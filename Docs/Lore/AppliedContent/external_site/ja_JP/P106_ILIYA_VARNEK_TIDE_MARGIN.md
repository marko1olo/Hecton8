# イリヤ・ヴァルネクの潮汐マージン

「イリヤ・ヴァルネクの潮汐マージン」は、HECTON-8におけるDeep Reachの責任を最初にはっきり読ませる記事の一つである。安易な企業悪の形にはしない。ヴァルネクは洪水ボタンを押す必要がない。彼はリスクの解釈に署名する。

2147年、グレート・タイドのモデルはまだ平均では合格していた。危険なのはその言葉だ。平均的な挙動は生産スケジュールを生かし続け、その一方で極端なスタックは作業員曝露の中に残った。Aegirの潮汐窓、氷棚の反動、圧力ルートの交通、Atlas補償の不確実性。ルートは統計上許容できても、曲線の裾野に出会う人間には致命的になり得る。

プレイヤーにとって、この証拠は災害を事故ではなく意思決定の連鎖に変える。ヴァルネクのメモは自白ではない。だが責任を読める文書だ。不確実性は知られ、割り引かれ、下へ渡された。恐怖は官僚的だが乾いてはいない。マージンは、人がその内側で死ねるほど小さくされた。
