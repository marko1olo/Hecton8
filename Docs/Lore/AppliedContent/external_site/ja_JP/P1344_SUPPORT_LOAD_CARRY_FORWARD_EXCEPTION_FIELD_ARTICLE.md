# 支援負荷繰り越し例外

carry-forwardは、金属の隣で読むまで無害に聞こえる。解決できない負荷をここから取り、次の勘定へ動かし、別の机が問題を所有するまでルートを生かす。醜い転送に付いた整った言葉だ。

HECTON-8では、その言葉はmaintenanceとclaimsの間に座っていた。ローカル生命維持が失敗しても、部屋は保守管理下に残ることがある。作業者が不在でも、ルートはアクティブのままになることがある。スーツが空でも、例外ストリップは支援クラスを開いたままにできる。

物の細部が重要になる。サービスベイで扱われたストリップは、後で入力された行とは老い方が違う。グリースは途切れる。インクはにじむ。塩は折り目を印す。遅いcarry-forward刻みは、同じ傷を共有しているはずの場所にきれいに乗りがちだ。その小さな清潔な印が、管理が機械を追い越し始める場所だ。

この記録はコンプレッサー引き渡し後追いの後で読む。ポンプとリレーは空気が動いたかを示す。繰り越し例外は、失敗した負荷が呼吸不能になった後、誰がそれを有用に保ったかを示す。
