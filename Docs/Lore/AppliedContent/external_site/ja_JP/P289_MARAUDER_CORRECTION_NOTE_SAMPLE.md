# 略奪者の訂正メモ標本

略奪者のメモは、公式システムと争いながら全知の解説にはならない、HECTON-8らしい証拠面である。この標本は時刻、証明、誤った区分、承認遅延という実務的な印で疑いを保つ。事件を解決して渡すのではない。保守記録として提出された嘘の読み方を教える。

## Scanner

事故報告書に油性鉛筆で入った訂正。原因は天候でも恐慌でもない。遺体数を抱えた承認遅延だ。
