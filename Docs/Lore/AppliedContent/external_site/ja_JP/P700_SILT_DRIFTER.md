# 泥漂い

HECTON-8のサルベージ報告は、シェルフの堆積物を食んで持続的な掘り跡を残す幅広の底生種を記述している。作業班は掘り跡の形を局所的な流れの指標として使う。開けた堆積物の上では直線、水没した取水口へ水が引かれている場所では曲線になる。

接触は重い堆積物の濁りを起こし、ランプもソナーも無効になる。現場手順では光束を落とし、濁りを抜けるまで方位航行を行う。Deep Reachの記録はこの種を堆積物管理に分類し、該当深度帯の取水格子点検を現行とみなして記載している。
