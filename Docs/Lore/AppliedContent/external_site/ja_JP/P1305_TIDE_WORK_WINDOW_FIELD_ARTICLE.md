# 潮汐作業窓フィールド記事

潮汐窓は、HECTON-8 におけるハード SF とゲームプレイをつなぐ最も明確な橋の一つだ。軌道、海洋質量、嵐のノイズ、産業圧力システムは背景の図鑑に留まらない。プレイヤーがいつ動けるか、何を聞けるか、どの契約が危険になるか、そして古い記録がなぜ海を敵対的なシフト管理者のように語るかを形作る。

窓は決して自然だけのものではない。静水はハッチ荷重を軽くするが、ポンプ低下は同じ経路を壊す。中継影はキャリアを黙らせるが、修理された脊柱を通じて音響ピンガーはまだ働く。嵐は視界を閉じ、否認を開く。Deep Reach はその複雑さの中に判断を隠すことを覚えた。

プレイヤーに必要なのは抽象的な天文学の暗記ではない。潮汐痕、経路板、ピンガーの拍子、塩水角度、新しいテープ、修正された帰還印、契約リスクカードを読むことだ。
