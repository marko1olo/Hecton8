# ブラインベーン林

ブラインベーン林は、HECTON-8 が水を空間の空白として扱うのをやめる場所である。峡谷では水が建築になる。密度層は壁のように積み重なり、ソナーは見えない棚の周囲で曲がり、不注意な下降は深度計が劇的に鳴る前にスーツを予想浮力の下へ置く。ブラインベーンはその数学を見えるものにする。地球の植物でも、話す異星の礁でもない。化学勾配が供給を続ける場所で成長する塩鉱物膜であり、植物のように見えるほど平たく、信じられるほど物理的だ。生きたベーンシートは、ここを横切るなと言う。裂けた縁は、何かが最近横切ったと言う。巻いた先端は境界が弱っていると言う。淡いリブは、膜が素材を落としており、ブライン化学、シーラント粒、密度センサー較正に使えるかもしれないと言う。よい峡谷設計では、プレイヤーは矢印ではなくこれらの印で航行する。無傷の壁に沿って漂い、裂けた口を見つけ、ソナーの歪みを見て、スーツのトリム変化を感じ、海が意地悪で道を塞いでいるのではないと理解する。海は圧力に従っている。だからブラインベーン林は、フォティックシェルフより冷たい美しさを持つ。歓迎はしない。読めるのだ。
