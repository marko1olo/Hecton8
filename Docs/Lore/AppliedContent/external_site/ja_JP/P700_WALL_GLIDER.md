# 壁滑り

HECTON-8のシェルフ・サルベージからの報告は、船体板、配管、ケーブル路を含む加工面の上だけを移動し、付着している素材の亀裂を越えない付着性の摂食種を記述している。作業班はその跡の範囲を、板が健全であることの指標として読む。

この動物は経路に沿って導電性の付着物を残し、下の構造がまだ通電している区間ではその付着物に微弱電流が流れる。付着物が髪筋の亀裂を電気的に橋渡しするため、自動導通試験は機械的に破断しつつある板を健全と判定する。ANNEX P-63に関するDeep Reachの記録は、これによる調査範囲を予定された構造監視の代替として受理し、調査済みの跡に圧力偏差がないと報告する一方、未調査の残りについては記述していない。
