# 圧力スーツ補修パッチ台帳

完璧な圧力スーツはパンフレットのものだ。HECTON-8はパンフレットではない。意味を持つスーツは、膝と袖口が擦れ、縫い目に塩が集まり、もう一度だけ潜るための布で補修されている。

良いパッチは社会情報を持つ。工場修理は均一だ。監督者の修理は正しいテープを使うが時間がない。作業者の修理は違う糸を使い、体が曲がる場所を知っている。医療修理は速く醜い。ブラックキール修理は識別子を先に剥がす。汚れたスーツ上のきれいなパッチは、着用者が在庫権限を持つ誰かにとって重要だったことを示す。

だからパッチはロッカー、医療区画、沈んだ更衣室、放棄された作業台に置くべきだ。すべての死体に演説をさせず、植民地を個人的にする。パッチは語る。誰かがここにいた。危険を知っていた。それでも仕事は続くと決めた。
