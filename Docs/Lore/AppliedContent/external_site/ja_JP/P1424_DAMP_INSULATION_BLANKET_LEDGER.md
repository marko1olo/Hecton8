# 湿った断熱ブランケット熱記憶台帳

古い植民地は扉と船体だけで壊れたのではない。圧力を耐えられる生活に変えるはずの場所で壊れた。裏板、キルト状の熱ラップ、サービスくぼみ、出発前に誰も写真を撮らなかったベージュの布だ。

良い断熱材は人間サイズの真実を話す。下側の暗い縫い目は息と結露を示す。縫製溝の塩は乾燥周期を示す。潰れたキルトは圧力と、壁にもたれた体を示す。暗い内層を見せる小さな裂け目は、工具、緊急アクセス、隠れたケーブル探しの跡かもしれない。

だから断熱材は機械の物語と作業者の物語をつなぐ。空気ポケット、緊急避難所、 crawlspace、まだ唸る死んだパネルのそばに置くべき素材だ。布が逆側で濡れているなら、部屋の話はもう反転している。
