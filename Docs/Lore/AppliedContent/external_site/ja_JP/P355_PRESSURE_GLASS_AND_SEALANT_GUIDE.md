# 圧力ガラスとシーラントガイド

圧力ガラスは実用的な植民地材料として始まった。覗き窓に使えるほど透明で、圧力扉に耐えるほど強く、サービス継ぎ目へ流し込めるほど安かった。水中の歳月がその役割を変えた。潮汐が板に応力を書き込んだ。鉱物が縁を曇らせた。バイオフィルムが亀裂を覚えた。Atlas化学が到着したとき、植民地を通る道を発明する必要はなかった。割れたガラスがすでに描いていた。

だからレンズの在庫は価値と危険を同時に持つ。シールの死んだ側から切れば、ガラスはサルベージになる。生きている縁を削れば、修復ネットワークはより清潔な道を得る。HECTON-8のシーラントはただの接着剤ではない。どの故障を閉じるか、どれを地図に残すか、そしてどれがまだ間違った身体を修復しようとするものへの扉になるかを決めるものだ。
