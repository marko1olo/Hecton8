# レコーダーカセット歯の摩耗

レコーダーカセット歯の摩耗は、HECTON-8の音声証拠に物理的な保管経路を与える。

        手掛かりは意図的に派手ではない。回収された声でも、不気味な欠けた秒でもない。圧力室が失敗する間、レコーダーを通ったカセットの縁だ。各歯は機械接点である。ベイの爪が触れ、ストリップが逆らって引き、汚れが入り、乱暴な扱いが、どんな清掃済み音声ファイルにも説明できない痕を残す。

        だから歯はプレイヤーに価値を持つ。塩が手跡の下にあれば、部屋が浸水した後にストリップが抜かれたと証明できる。歯間が地元の爪痕に合わなければ、別のレコーダーからコピーされたと示せる。欠けた秒を劇的な編集ではなく本当の詰まりとして示せる。物理カセットが、航路スタンプの前に部屋が開いたと言えば、磨き込まれた公式クリップは急に弱くなる。

        使い方は単純だ。プレイヤーに、きれいすぎる証拠を疑わせる。歯の列は小さく、汚く、具体的だ。説明の山ではなく、物に注意を払うことを報いる。良いカセット縁は、プレイヤーを近づけ、コロニーが記録の発言内容を決める前に誰がそれに触れたのかを尋ねさせる。
