# 琥珀色非常灯レンズ

非常灯に琥珀色が選ばれたのは見た目のためではない。霧に強いからだ。赤は汚れた水で早く失われ、白は浮遊粒子をすべて雑音に変える。琥珀色は結露、塩霧、古い傷だらけの視界窓を通しても輪郭を保つ。この実用的な選択が、沈んだ廊下に残る最良の証人の一つを作った。

カバーは単なる色付き樹脂ではない。硬い外皮、柔らかい拡散層、湿った空気をソケットから遠ざけるガスケット付きの唇を持つリブ付き拡散レンズだ。シールがゆっくり死ぬと、鉱物は均一には広がらない。塩はまず溝に集まり、次に下唇へ、さらにクランプ傷の周りへ進む。きれいな割れは衝撃を示す。縁の乳白色の弧は圧力循環を示す。ガスケット下の茶緑の汚れは、ランプが部屋と一緒に呼吸していたことを示す。

プレイヤーにとって、このレンズは経路証拠である。澄んだ琥珀色の線は、まだ生きている電力経路を示すかもしれない。曇った線は、結露で失敗した古い避難経路を示すかもしれない。汚れた廊下の中で一つだけ清潔なランプは怪しい。誰かが警告を見えるようにしたか、記録を変えようとした。リブを横切る傷は、警報中に拭かれた痕であることが多い。

回収者の失敗は単純だ。素材目当てでレンズを割り、時間の記録を失う。重要なのは光ったかどうかではない。いつ信頼されなくなったかだ。HECTON-8では、死んだ琥珀色カバーが最後に開いた扉、最後の通電ノード、そして廊下がまだ点滅している間に去った人物を示すことがある。
