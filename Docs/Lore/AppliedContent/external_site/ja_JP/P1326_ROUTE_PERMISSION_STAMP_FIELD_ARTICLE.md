# 経路許可スタンプ

沈んだコロニーは演説で人を動かさなかった。スタンプで動かした。

HECTON-8 での経路許可は、勤務板の印刷枠、ハッチ横の傷ついた金属タブ、スーツチップの更新、カート板のグリースペン許可、工具棚トレイの押印として現れた。小さいのは、圧力下の仕事が手袋、水、疲労に耐えない書類を嫌うからだ。強いのは、作業者名を許可に変えるからだ。ここへ行け、これを直せ、それを証言し、この経路で戻れ。

Great Tide 後、その小さな許可は多くのログより固い証拠になった。ログは要約できる。スタンプはしぶとい。空白の帰還欄は未完の移動を示す。トリアージ記録の隣の拒否経路は、傷害が手続きを通って進んだことを示す。ポンプ室に残るはずの人に BRINE スタンプがあるなら、リスクが押しつけられた証拠だ。腐食したハッチ上の清潔な後貼りステッカーは、部屋の状態が変わった後で記録が触られた証拠だ。

経路スタンプも嘘をつく。Deep Reach は後から埋め、取り消し、死んだ経路を法的に有効なままにできた。閉鎖を認めれば遺体を数えることになるからだ。物理的な部屋がスタンプを試す。ラッチ摩耗は許可された使用と合うか。水位線はインクを切っているか。スーツチップは同意するか。Marauder の訂正印は公式カテゴリの誤りを警告しているか。

プレイヤーにとって、経路スタンプは全員に独白を与えずにコロニーを読めるようにする。手続きで、苦く、人間的だ。たどれば沈んだ施設は迷路ではなくなる。安全が破綻した後も任務を割り当て続けた職場になる。
