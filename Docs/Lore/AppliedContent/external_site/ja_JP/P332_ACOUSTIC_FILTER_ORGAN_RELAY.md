# 音響フィルター器官リレー

音響フィルター器官リレーは、圧力と習性と誤用から作られる。HECTON-8の水中では無線がすぐ死ぬため、Deep Reachは金属製リレー喉部をコロニー中に通した。現地の濾過生物はそれを便利な場所として使った。一定の流れ、鉱物の砂、ポンプ振動、守られた表面があったからだ。古い機械が音を整えていた場所に、何年もかけてひだ状の組織が育った。

Atlasはその偶然をインフラに変える。生きた隔壁はポンプ騒音を飲み込み、細いピンガー音だけを通せる。同時に、戻りをわずかにずらし、隔壁の向こうから見た地図を真実らしく見せる。組織に形作られた声で廊下が答えたとき、プレイヤーが得たのは情報であって安全ではない。嵐のパルス、動物の移動、死にかけのひだが、警告なく経路を動かすことがある。
