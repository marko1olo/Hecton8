# 音響フィルター器官リレー

電波の届かない深度では音が主な計器になる。ケーブル礁はそれを複雑にする。割れた筐体は鳴り、金属マットは散乱し、嵐のパルスは距離をぼかし、生きた組織が発信源と戻りの間に座る。

そのためソナーは清潔な真実ではない。リレーは扉を示すことも、捕食者へ餌を渡すことも、古い警告を繰り返すことも、同じ廊下を二重に見せることもある。
