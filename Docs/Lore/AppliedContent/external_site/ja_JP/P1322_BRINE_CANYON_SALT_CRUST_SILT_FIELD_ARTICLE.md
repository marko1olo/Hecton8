# ブライン渓谷の塩殻シルト

ブライン渓谷の塩殻シルトは、清潔な白い表面を疑うことを教える床だ。HECTON-8の浅場には、淡い石、貝殻の砂、安全な鉱物殻がいくらでもある。これはそれではない。渓谷では高密度のブラインが粘土の盆地や割れた棚を這い、化学、温度、遅い流れが一致した場所に脆い皮膜を残す。写真では床に見え、実際には罠として働く。

この素材が有効なのは、読めるからだ。塩は無作為には積もらない。弱い流路に沿って脈を作り、密度層の縁で厚くなり、下のシルトが呼吸した場所で柔らかい薄片に割れる。足、ケーブル、クローラー、落下したパネルが表面を傷つけた場所には青灰色の粘土が見える。割れ目の緑黒い染みは、古いブライン、低酸素、鉱物細菌を示す。傷のない明るい板は、プレイヤーを安心させるものではなく不安にさせるものだ。

Deep Reachはこうした場所を安定帰還棚と呼びたがった。動くほど生きている、と認めるより安定のほうが安く聞こえるからだ。整備板の表現は丁寧だった。足場信頼度低下、密度遅延、中程度腐食。作業員の言葉は短い。白い皮、悪い泥、ケーブル喰い。間違った場所を工具ケーブルが引きずられると、きれいな溝を切って殻の下へ沈み、塩の化学で被覆を柔らかくして戻ってくることがあった。

ゲーム上では、塩殻シルトは基質であり記憶面でもある。サルベージを隠し、タグを保存し、避難そりの最後の擦り跡を保ち、地図印刷後にブラインのカーテンが動いたことを示す。重い荷、悪いアンカー、シャベルのように使うカッターを罰することもできる。正しい相互作用は講義ではない。プレイヤーは淡い蓋を見て、傷を読み、縁を試し、HECTON-8には床を危険にするための怪物が不要だと理解する。
