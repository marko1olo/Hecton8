# ブラインベーン標本カード

ブラインベーンは、HECTON-8の中深度の水を物理的に感じさせる。峡谷が空の青い体積ではなく密度で作られていることを示す。膜は警告標識、素材源、偽床の縁を同時に持ち得る。

## Scanner

ブラインベーン膜。密度せん断に固定された塩鉱物膜。完全な縁は壁、裂けた口は通路。ベーン縁のない黒い水は偽床リスク。

## Terminal

標本 / ブラインベーン / 役割: 密度壁マーカー、sonar屈曲警告、脱落リブ素材源 / 安全な読み: 完全な膜、下流側の裂け口、丸まったshear-window先端 / 拒否: 生きた経路膜を切る、開いた発光を横切る、偽床反射を信用する / 経路注記: 採るのは脱落リブ。地図を開いたままにしている膜ではない。

## Audio

ベーンは上を指していない。海が横へ曲がる場所を示している。

## Field Note

完全な膜: 壁。裂けた口: 可能な経路。脱落リブ: 標本。生きた膜が道を保持しているなら残せ。
