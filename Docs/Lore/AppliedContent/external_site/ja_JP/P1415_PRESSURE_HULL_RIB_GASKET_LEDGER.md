# 耐圧リブとガスケット台帳

HECTON-8の耐圧外殻は醜い。だから信用できる。宇宙船らしく見せるためではなく、作業室を海にしないために作られた。外板は荷重を広げ、リブはそれを受け、ガスケットは水の移動を止め、ラッチ側は人間が緊急時に開ける位置を残す。

読むべき最初の文字は汚れだ。塩は低い継ぎ目に育つ。黒緑の生膜は遅い漏れを追う。ボルトの錆より、列が直線を保ったかどうかが重要になる。直線ならモジュールは一体として耐えた。段差があればフレームは裂けた。押し出されたガスケットは浸水前の圧縮を示し、きれいな金属の空溝は後日の開放を示す。

ひとつの外殻は、戦利品、避難場所、危険物、証拠を同時に持つ。読む者は入口を選び、荷重を残すリブを避け、切るべき板を探し、公式記録と違う開閉の痕跡を保存できる。
