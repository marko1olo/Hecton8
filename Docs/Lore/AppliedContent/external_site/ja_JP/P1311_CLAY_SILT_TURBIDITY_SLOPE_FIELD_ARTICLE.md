# 粘土シルト濁流斜面の野外記事

粘土シルト濁流斜面は、HECTON-8 の低視界を恣意的ではなく原因のあるものにする。水が濁るのは緊張感のためではない。プレイヤー、機械、滑り、古い崩壊が細かな粘土を再び浮かせたからだ。

この表面には三つの役割がある。危険として、推進と悪い足場は経路を見えなくする。証拠として、新しい傷、圧縮リップル、引きずり跡は到着前の出来事を示す。航法として、同じ印は埋もれた設備や弱い棚を知らせる。

設定面では、斜面は Deep Reach の書類文化に合う。失敗した経路は自然濁りと記録できる。自然な滑りは作業者のせいにできる。滑らかな場所は地質、清掃、または隠された道かもしれない。
