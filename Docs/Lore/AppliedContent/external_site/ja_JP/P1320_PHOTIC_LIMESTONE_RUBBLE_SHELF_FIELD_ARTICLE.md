# 有光層石灰岩瓦礫棚

有光層の棚は、光がまだ権威を持つ深さにある。この深度の海は、すべてを隠すほど暗くなく、雑な足取りを許すほど優しくもない。石灰岩板は古い生物由来カルシウム、貝殻砂、鉱物セメントからできる。その上の瓦礫は、自然破断、植民地採取、嵐、機械の通行、小さな生物の働きが混ざった記録だ。

読むべきものは足元にある。継ぎ目の砂は、水がまだ床を選別していることを示す。棚の淡い粉は新しい破断を示す。孔のオリーブ色は保護された安定を示す。きれいな円形の擦れは工具の足、アンカー板、古い採石クランプかもしれない。明るさだけを見るなら安全な導入に見える。表面を読むなら、最初の正直な地図になる。
