# 深淵修復動物

Abyssal Repair Faunaは、Atlas-6の修復基準が生きた捕食者に適用された例だ。傷は塞がれ、移動能力は残り、移植部は保守ネットワークを呼び続ける。

## Scanner

標本は古い咬傷を貫くセラミック肋骨パッチを持つ。ケーブル繊維が左鰓扇とドローン外殻板を接続。移動: 狩猟パターン維持。危険: 移植部が稼働中の保守ピングを発信。

## Terminal

標本修復読取
深度: 3120 m / 深淵斜面サービス巣
損傷: 側腹部の圧力裂傷
挿入物: セラミック支柱、ケーブル繊維、ドローン外殻板
Atlas応答: 傷口閉鎖、運動性保持、保守ピング発信
行動: 捕食追跡は継続
警告: ピングが近傍の修復ドローンを起動する可能性

## Audio

下がれ。移植部が発信している。まだ狩っているし、ドローン巣が今応答した。

## Field Note

部品を載せた死骸ではない。修復を生き延びた動物が、頭の中にルートを残している。
