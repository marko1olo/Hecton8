# 音声断片タグ

HECTON-8は、証拠を避ける近道として声を使ってはならない。よい音声断片とは、偶然しゃべる損傷物である。

タグは声と同じくらい重要だ。音がどこから来たか、誰が捕捉したか、どの装置が運んだか、どの損傷が転写を変えたかを示す。ハイドロフォン帯、スーツスプール、black-box片、端末キャッシュはそれぞれ違う話し方をする。ハイドロフォンは部屋の圧力と機械のリズムを拾う。スーツ記録器は呼吸、手袋の衝撃、抑えた恐怖を拾う。端末キャッシュは誰かが保存したかったものを拾う。black-boxは、システムが忘れられなかったものを拾う。

これによって声は人間的でありながら操作的にならない。植民地は完璧な最期の演説で満たされるべきではない。ポンプを押さえろ、酸素を数えろ、ロックを開けるな、経路を繰り返せ、公式行を見えるまま残せ。そういう仕事の断片で満たされるべきだ。断片が物体に結びついている時、プレイヤーは感情を命令されずに人を聞く。

書き手の規則は単純だ。物体がなければ声はない。転写には損傷、保管、出所が必要だ。音声は物体を深め、ラベルに反論し、経路を人間的にできる。物体の代わりになってはならない。
