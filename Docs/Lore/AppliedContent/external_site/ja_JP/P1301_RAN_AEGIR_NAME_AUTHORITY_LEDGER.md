# Ran / Aegir名称権限台帳

HECTON-8の名称体系は静かだが鋭いワールドビルドだ。月に四つの名があるのは飾りではない。それぞれの名は異なる権限と、同じ沈んだ場所への異なる道徳的距離を持つ。

            Ranは天文学の言語だ。恒星、ルート基準、光遅延、キャリア時刻。Aegirは請求の言語だ。親天体としての巨星、公共略称、企業の傘。RAN-B:H8は保険の言語だ。植民地の声を残さず並べ、移し、訴えられる月記録。HECTON-8は生きられた言語だ。扉、部屋、墓、圧力警報。

            プレイヤーがこの文法を覚えると、文書の形が変わる。Aegirを使う企業通知は、月の失敗をシステム保守に見せるまで視点を引くことがある。RAN-B:H8の受領は保管価格を準備する。HECTON-8の現場メモは、カタログが洗う前に証言を守る。
