# Ran / Aegir名称権限台帳

HECTON-8の命名体系は小ネタではない。誰が話しているかを示す道具だ。天文学は、星がルートと光遅延を固定するのでRanと言う。請求オフィスは、巨大惑星が月とインフラと責任を束ねられるのでAegirと言う。保険表は、整理された台帳が記憶を持たないのでRAN-B:H8と言う。水の下の人々は、ハッチが壊れる場所だからHECTON-8と言う。

文書が名前を変える時、管轄も変わっていることが多い。Ran語は時間と物理に属する。Aegir語は所有に属する。RAN-B:H8はカタログ、保険、保管に属する。HECTON-8は現場使用、記憶、場所としての植民地に属する。
