# レコーダーラッチガラスの破断

HECTON-8の証拠は、声を運んだ物を見てその声を疑える時に最も強い。レコーダーラッチガラスはそのための物体だ。劇的に見えるには小さすぎ、無視するには物理的すぎる。

        それは圧力室レコーダーベイのラッチ上にある。稼働中のコロニーでは整備の便利部品だった。浸水後は真実の表面になる。亀裂方向、欠けの深さ、鉱物の曇り、擦り傷の順番が、ベイが衝撃の間も封じられていたのか、閉じ込められた作業員が開けたのか、よりきれいな手と都合の良い話を持つ誰かが後で触れたのかを示す。

        ガラスは音声と競争しない。音声を律する。回収されたボイスログは無傷に聞こえるかもしれないが、ガラスは誰がベイを開けたか、どちら側が力を受けたか、カセットはすでに座っていたか、公式回収の前に亀裂内で塩が育ったかを問う。汚れたガラスにきれいなファイルは怪しい。正直なガラスに汚れた音は、もう少し信じられる。

        HECTON-8が保つべき調子はこれだ。魔法のブラックボックスも、全知の録音も、コロニーを解くロアの投げ出しもいらない。カバーの欠片、カセット歯、顔料車、航路スタンプがプレイヤーを立ち止まらせ、物理的な証人を比べさせ、一行の音を信じる権利を得させる。
