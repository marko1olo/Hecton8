# 公開索引の伏せ字規則

## 記録が証明すること

公開索引の一行は要約ではなく、アクセス制御の記録だ。表示してよいのは、記録ファミリー、保管レーン、証拠種別、伏せ字フラグ、スキャナーゲート、パケットを開くために必要な次の物証。受取人を露出させずに捜索を進めるにはそれで足りる。

伏せられた欄のほうが題名より重要だ。受取人連鎖、最終座標、積載物の状態、Atlasの応答、エンディングへの圧力、法的結果は、経路がそこまで到達するまで伏せ字シールの後ろに残す。索引が受取人住所を早く印字したら、それは事件の説明ではない。ミラーを見ている全員への経路漏えいだ。

## 読み方

公開索引伏せ字スタンプ
表示: 題名、記録ファミリー、保管レーン、証拠種別、伏せ字フラグ、スキャナーゲート、次の物証。
非表示: 受取人連鎖、最終座標、積載物状態、Atlas応答、エンディング圧、法的結果。
失敗: 保管しきい値前に受取人住所が見える。
処置: パケットハッシュと物証が一致するまで経路欄を封印。
