# 公開索引スポイラー制限

## 記録が証明すること

公開索引は、ルートを燃やさずにアーカイブを使えるようにするためのものだ。タイトルは証拠ファミリーを名指ししてよい。保管ルート、証拠クラス、編集状態、請求者言語、スキャナーゲート。プレイヤーが追っている証拠の種類と、隣のパケットが重要な理由を理解するには十分だ。

索引は、誰が積載物を受け取るか、最終ルートがどこへ着くか、積載物の状態、Atlasが何をするか、どのエンディング分岐へ圧力をかけるか、法的結果を明かしてはならない。それらの意味は、獲得された証拠経路に属する。タイトルが受取人線を明かすなら、索引はアーカイブではなくスポイラー機械になる。公開の約束は単純だ。この棚は存在する。最後のページは隠されている。

## 読み方

公開索引制限スタンプ
表示: カテゴリ名、保管ルート、証拠クラス、編集状態、スキャナーゲート、次の証拠目標。
保持: 受取人連鎖、最終座標、積載状態、Atlas結果、エンディング分岐、法的結果。
規則: 棚を見せ、最後のページを隠す。公開索引は証拠の種類を示してよいが、ルートの終点で何をするかは示さない。

## 現場メモ

カテゴリ名は身体より遠くまで旅する。棚を読め。ただし棚を最後のページだと思うな。最後のページが無料なら、誰かがもうルートを売った。
