# 大潮マージン痕跡

有用な災害記録は、飾らないことから始まる。P-63潮汐アレイは海を告発しない。せん断スパイク、圧力マージンの崩落、そして通路より長く電力を保ったbrine-bufferメモリに残ったチェックサムを記録している。

だからこの痕跡は重要だ。Deep Reachは大潮を指して実在の出来事を名指しできた。その上で、行動を要求する行を隠せた。マージンが停止床を下回った時点で、コロニーにはまだ航路判断が残っていた。公開報告はカスケードを残し、商業例外を消し、遅れた停止命令を天候に変えた。
