# Marauder修正マーク

Marauderが信頼されるのは高潔だからではない。信頼されるとしても、それはclaimがどう嘘をつくかに気づく仕事で既に報酬を受けているからだ。

HECTON-8では、彼らの修正は公式システムが清潔にしたがった場所に残っている。シフトボードの横、隔離印の下、圧力寝台の縁、パケットのフッター、工具箱の内側、作業員タグの近く。マークが短いのは、水中で長いメモが失敗するからだ。物理的なのは、きれいな要約が簡単に移動しすぎるからだ。

修正マークの役目は一つ。物体に議論を続けさせることだ。これは全ての真実だとは言わない。その文に部屋を終わらせるなと言う。公式行は見えるまま残る。誰が体、経路、費用を改名したかを証明できるからだ。修正は横に残る。次の潜水者には数分ではなく数秒しかないかもしれない。

この文化は実用的で疑い深く、無垢ではない。よいMarauderは半分消えた名前を戻せる。悪いMarauderはclaimを支払いへ誘導できる。疲れた者は役に立つが曲がっていて、なお間違ったメモを残すことがある。その緊張が重要だ。HECTON-8はMarauderを純粋な救助者にも純粋な盗人にもしてはならない。彼らは証拠作業の汚れた縁である。

プレイヤーにとって修正は受け継いだ疑念だ。習慣を教える。公式文を読み、物体を読み、マークを読み、その後で部屋との接触に耐える部分を決める。
