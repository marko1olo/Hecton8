# 資源と生態

最初の間違いは、HECTON-8 の資源を raw と呼ぶことだ。下では有用なものほど手つかずでは来ない。Drowned Crust の破片は圧力履歴を抱える。blue debt の脈は熱、塩水、採取方法の記憶を残す。殻の板は、Marauder が箱に入れる前から、リーフの装甲、失敗したシール材、Atlas が育てたケーブル皮膜、法的証拠であり得る。

だから資源ページは生態ページの隣に置かれる。古いコロニーは死んだ床を採掘していたわけではない。Deep Reach は塩水ラダー、ベント由来の鉱物棚、泥に埋もれた機械、月の律動をすでに覚えた生きた濾過系を切り開いた。破局後、Atlas は漏れを閉じるもの、信号を運ぶものすべてへ修理モデルを押し込んだ。バイオフィルムは導体になり、根のマットはガスケットになり、タグ付き動物は動くフィードバックになった。

動物はひれの付いた loot 箱ではない。振動、熱、光の落ち方、血液化学、塩の跡、乱された泥を読む。草食体はいつもの行動だけで安全な削り取り場所を露出させる。捕食者の影は、どの通路が間違った音響パルスを運ぶかを示す。タグ付き動物は、一度の通過で修理ルート、証人、危険になり得る。

blue debt は道徳計算をさらに汚す。最良の標本は鈍く、密封され、不格好かもしれない。形成場所を証明する圧力状態を保っているからだ。明るい破片は、ベントに記憶を洗われていれば無価値になる。どちらを採っても、流れを変え、狩るものを起こし、Atlas のパッチを傷つけ、支払いより大事な労働時代の事故痕を消すことがある。

有用な問いは、何を採取できるかだけではない。人間の手が鎖へ入る前に、海がその物質で何をしていたかだ。地質、生命、機械、custody を、害を記憶する一つの系として扱う時、HECTON-8 は読めるようになる。
