# 作業連絡先掲示

作業連絡先掲示は小さな社会文書だが、鋭い縁を持つ。寝台列、ルート主任、医療ロック証人、工具庫連絡員、中継窓が並ぶ。圧力の論理が見えるまでは単なる管理に見える。外世界の連絡先は悲しみ、怒り、記憶できるが、水より早くハッチへは届かない。

だから HECTON-8 の緊急連絡先は、ステーション内、訓練済み、トーンで到達可能、作業者のルートに入れる者を意味する。厳しい定義だが、愛の欠如ではない。帰還の欠落が浸水路になる場所で、世話はそういう形を取る。

掲示は日常の証拠を共同体の網に変える。別の資料にあるポンプキー、水台帳の訂正、工具署名。それぞれの印が疲れた作業者を別の作業者へ結びつける。結果は芝居ではなく、責任が親密さの形になった圧力居住地である。
