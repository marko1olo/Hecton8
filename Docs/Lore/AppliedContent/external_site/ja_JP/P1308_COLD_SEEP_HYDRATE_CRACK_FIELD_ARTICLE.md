# 冷湧水メタンハイドレート裂け目の野外記事

ハイドレート裂け目は、HECTON-8 の資源を物理契約のように感じさせる。メタンハイドレートは魔法の氷でも光る収集品でもない。深さ、温度、化学が一時的に一致したため、水がメタンを抱えている状態だ。プレイヤーは利用できるが、利用は安定条件そのものを脅かす。

安全な縁には静かな泡、落ち着いた粉、粘土に消える皮膜がある。悪い筋はスキャナー下で叩き、新しい孔を持ち、生きたバイオフィルムを引っ張り、古い採掘擦りのそばにいる。それは飾りではなく指示だ。

Deep Reach は筋を原料として値付けし、道、作業者、堆積記録、次の潜水者の視界を割り引いただけでよかった。破れた裂け目は火ではなく盲目で急ぎを罰する。
