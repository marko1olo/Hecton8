# フィールドシステム専門員記録

フィールドシステム専門員記録は、HECTON-8の中心オペレーターに有用な過去を与えるが、その過去をきれいにしすぎない。彼らは指揮スタッフではなく、災害の秘密設計者でもない。避難ルート、ポンプ、シール、リレー室を正直に保つはずだったシステムの近くで働いていた。

だから放棄されたコロニーには残骸だけでなく手順がある。route-safe印、clamp等級、maintenance文句は、劇的な録音より強く告発することがある。オペレーターは、人が守られるときの記録の形と、企業が保護を紙に変えたいときの形を知っている。

剥奪されたアクセスがその歴史を鋭くする。古いバッジはもう制御を与えないが、失敗の方言を識別する力は残す。HECTON-8はその職業記憶を動機に変える。災害を起こした罪ではなく、防げた部屋がどう処理されたか読んだ後の責任だ。
