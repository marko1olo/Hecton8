# 経路許可スタンプの重なり

経路許可スタンプが有用なのは、劇的ではないからだ。作業者がハッチを通され、作業系統が割り当てられ、帰還が期待されたという事務残渣にすぎない。だが沈んだコロニーでは、その小さな痕跡が公式説明より長く残る。

狭い読み取り点は、経路スタンプのインク、塩、ハッチ塗装の削れ、packet notaryの黒塗りが交わる場所にある。スタンプのインクが黒塗りの下、曝露塩の上にあるなら、媒体は曝露後の処理デスクを通ってから黒塗りされた。隠された文を読む記事ではない。保管経路の嘘を読む記事だ。

Deep Reachには承認と時系列を混ぜる利点がある。法的なマスクは承認済みでも遅いことがある。経路スタンプは有効でも、部屋への入室ではなく証拠処理を示すことがある。重なりはその二つを引き離す。

転写損傷帯とpacket notaryマスク縁が先に見つかると、媒体は完成した物語ではなくなる。手、水、塩、塗装、事務手順を通った物体として読める。
