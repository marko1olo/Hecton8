# 有光棚の生命

有光棚の生命は、HECTON-8の開幕に置かれる生態学的な基準線である。安全な水族館ではなく、恐怖が来るのを待つ死んだ海でもない。上層0-250メートルにはまだ光、熱の変化、空のリズムが届く。そのため天然の生命は、色で最初のルート言語を書く。石を覆う酸素マット、藻を切って道を作る透明なグレイザー、うねりの前に傾くpressureweed、残骸の周りに流れを描くルート藻。その美しさには意味がある。Deep Reachがなぜこの月を欲したのか、そして取り残されたMarauderがなぜ略奪だけでなく読解のために戦うのかを、プレイヤーに理解させる。棚は同時に、この設定の中核規則を教える。読めることは安全を意味しない。明るいマットは呼吸可能な水を保ち、汚染された継ぎ目を隠すことがある。グラス・グレイザーの群れは安全な道を示すことも、より大きな何かが通ったせいで消えることもある。Pressureweedは天候、捕食者の変位、下のインフラから来る圧力パルスを警告する。ケーブル礁の前、修復痕の前、Atlasが生命を保守ロジックへ変え始める前に、月は自分だけで何をしていたかを見せる。
