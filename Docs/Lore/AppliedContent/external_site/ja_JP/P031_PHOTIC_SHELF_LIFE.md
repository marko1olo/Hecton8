# 有光棚の生命

有光棚の生命は、HECTON-8 の上層水にある生態基準線だ。表層帯にはまだ光、熱変化、空の周期が届くため、下層で Atlas 修復ロジックが現れる前に、土着生命は読める経路証拠を残す。酸素マット、グラスグレイザーの筋、pressureweed の曲がり、残骸周辺のルート藻である。この棚は、Deep Reach がこの月を欲しがった理由を示すが、無害な場所にはしない。役に立つ手掛かりには必ず失敗経路がある。息を買える酸素マットは汚染を隠し、帰還流を示す藻の筋は嵐の泥や捕食者の圧力でずれる。
