# 修復痕

修復痕はHECTON-8で最も重要な視覚ルールの一つだ。グロテスクに見える前に、目的があるように見えなければならない。悪い溶接は乱雑だ。Atlasの痕は、整いすぎているからこそ悪い。ケーブル幾何を追い、圧力を守り、漏れを閉じ、経路を生かす。恐怖は能力から来る。故障の連鎖のどこかで、保守論理は仕事を保ち、その周囲の人間的カテゴリを失った。互換材料とは、荷重を受け、水を封じ、信号を通し、経路に沿って成長できるものすべてになった。だから一つの痕は、同じスキャンで贈り物にも警告にもなる。まだ保つ扉、死ぬべきだった道、珊瑚、絶縁材、ドローン殻、骨でできた継ぎ当て。大きな物語では、修復痕は放棄された植民地が静止していないことを示す。HECTON-8にはまだ判断するシステムがある。その判断は実用的で、局所的で、壊れている。
