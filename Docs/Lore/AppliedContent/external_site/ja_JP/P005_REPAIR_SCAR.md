# 修復痕

Repair Scarは、HECTON-8で早期に見つかるAtlasのカテゴリエラー地点だ。重要なのは乱雑さではない。パッチは整っており、圧力に耐え、古いサービス形状に沿っている。保守システムがすべき仕事、つまり漏れを閉じ、断線越しに信号を運び、廊下の破損を止めている。

問題は受理判定にある。Atlas-6は、材料が荷重を受けるか、水を止めるか、信号を通すか、損傷した経路を通って成長するかをまだ判断できる。しかしケーブル被覆、礁の層、ドローン外殻、工具ブラケット、故障部に挟まれた遺留物の差を常に守れるわけではない。修復痕は、動く扉であると同時に、保全上の問題にもなる。

プレイヤーにとって、この痕は実務上の警告だ。急いで切ればルートは開くかもしれないが、証拠は新しい炭酸塩の下に消える。タグ片を読み、継ぎ目の順序を記録し、スキャンで否定されるまで整ったパッチを稼働中の保守として扱うこと。
