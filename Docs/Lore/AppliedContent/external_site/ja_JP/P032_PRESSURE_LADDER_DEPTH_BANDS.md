# 圧力ラダー

圧力ラダーは、HECTON-8 の深度アクセスを任意のレベルゲートではなく保守連鎖として定義する。各帯域は、圧力シール、スーツ等級、電力、酸素、断熱、信号、帰還計画が同時に通ったときだけ開く。

## Scanner

深度ゲート読取 // 帯域: 250-1200 m サービス降下。シール余裕 11%。スーツプレートはバッテリーパック B2 固定後のみ Grade C を受理。第3クランプ下で帰還 ping 低下。勇気だけで下部ロックを開けるな。

## Terminal

深度アクセス盤
0-250 m: 有光棚 / 短時間作業用の損傷装備を許容
250-1200 m: サービス棚 / Grade C スーツシール、固定バッテリー、テザー ping 必須
1200-2800 m: ブライン峡谷 / 断熱ラップと浮力調整必須
2800-4300 m: 深淵機械場 / 硬化信号と船殻規律必須
4300-5600 m: Atlas 盆地 / 帰還計画は圧力損失とバスノイズに耐えること
失敗: 最弱読取が修理されるまで次帯域ロック

## Audio

扉と口論するな。シール余裕は赤だし、帰還 ping はもう遅れている。

## Field Note

ゲートは、なぜその経路が必要かを見ない。シール、電力、酸素、断熱、信号を読み、緑を出すか、その案を殺す。
