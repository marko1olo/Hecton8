# 導電性バイオフィルム修理バス

導電性バイオフィルムに巻かれたケーブルは、役に立つと同時に危険だ。成長部は腐食を遅らせ、弱いピングを通し、Atlasに安い修理経路を与える。その同じ膜が、導通だけを見るシステムから断線を隠す。

## Scanner

緑黒の膜が裂けたケーブルジャケットを橋渡ししている。低電流は湿った成長部を戻る。導通値は信用できない。

## Terminal

ATLAS保守痕跡 / LINE K-44：露出銅、塩性成長、低い熱漏れ。バイオフィルム橋が腐食を遅らせ、偽の導通パルスを返す。この線にポンプ制御を通すな。

## Audio

ピングは粘膜を通る。電力も通る。それを修理と呼ぶな。

## Field Note

死んだパネルが緑の膜で起きたら、そのルートは仮扱いにしろ。ジャケットへ工具を入れる前に電源を落とせ。
