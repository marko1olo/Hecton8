# 導電性バイオフィルム修理バス

導電性バイオフィルム修理バスは、実用的な事故から始まる。古いDeep Reach製ケーブル外皮が圧力で裂け、銅塩が海水へにじみ、鉱物熱に適応していた現地の微生物マットがその傷口に定着する。Atlasは弱い電流を保守経路として読む。海が話す必要はない。濡れた膜が一つのパルスを運べれば足りる。

マローダーにとって、それは贈り物であり罠でもある。バイオフィルムの橋は密閉扉を起こし、スキャナーの握手を通し、何年も沈黙していたポンプを一瞬だけ返事させる。同じ橋は嘘もつく。負荷能力が死んでいても線は緑に光り、きれいな切断が生存可能な通路を浸水路に変える。問題は自然か人工かではない。Atlasが何を修理済みとして数えたかだ。
