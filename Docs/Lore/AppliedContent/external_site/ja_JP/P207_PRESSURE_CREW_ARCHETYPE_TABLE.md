# 圧力クルー原型表

圧力クルー原型は、HECTON-8 の作業員キャストを読める労働史に変える。コロニーはまず伝記で説明されるのではなく、仕事で説明される。Pump、Seal、Relay、Brine Map、Vent Forge、Triage、Pressure Botany、Payload Witness は、すべての名前に機能、海洋経済での場所、証拠として現れる理由を与える。これにより、ロアは切り離された説明ではなく、物体とルートを通じて表面化する。

## Scanner

クルーは背景設定である前に動詞だ。汲む、封じる、中継する、測る、鍛える、選別する、育てる、証言する。

## Terminal
