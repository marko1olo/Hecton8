# 塩分・鉱物沈着記憶台帳

植民地は表面をきれいに保とうとした。きれいなら制御されているように見えるからだ。塩はその嘘を拒んだ。拭き取っても戻り、ガスケットの唇から出て、ねじのくぼみに集まり、水が記録になるまで留まった境界を淡く描いた。

鉱物沈着には文法がある。下側の継ぎ目に沿う花は移動を示す。下向きの石灰指は排水を示す。ボルト周囲の輪は金属が圧力で呼吸した印だ。新しい油の下に粉があれば、水が先にいた。片側だけ割れた殻は蹴られたのでなく、パネルがたわんだ証拠かもしれない。

回収班はこういう証拠を尊重する。塩は最初に沈む廊下、信用できないハッチ、濃塩水を隠す洞窟ポケット、そして公式報告の「単一破口」が実は圧力と金属と放置の長い会話だったことを示す。
