# 溶接シームとリベット列台帳

圧力殻は恐慌を隠すよう設計されている。パネルは滑らかで、固定具は等間隔、検査印は小さく官僚的だ。溶接シームはその言語を壊す。局所的で、醜く、熱く、具体的だ。そこは保守が終わり、持ちこたえてくれと頼み始めた場所だ。

古いものから新しいものへ読め。工場リベットは、海が壁に触れる前に荷重が計算されていたから列をなす。現場ビードは、悪い足場、悪い視界、悪い時間の中で人の手が置いたから膨れる。リベット頭下の錆は湿った空気の移動を示す。溶接下の塩は乾いて戻った漏れを示す。裂けた補修板の横のボルトフランジは、未来のアクセスを残そうとした後、圧力が大きくなってその礼儀を捨てたことを示す。

最も価値あるシームは最大のものではない。清潔なパターンを遮るものだ。整備パネルを横切る一本の醜いビードが、封じた区画、犠牲者の空間、隔離された機械、あるいは後の回収者が同じ恐怖をよりよい工具と少ない慈悲で切った経路を示す。
