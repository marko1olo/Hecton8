# ビームセイル探査機時代

ビームセイル探査機時代は、Aegir史の静かな始まりである。小さなペイロードは遠方アレイの出力に乗り、最初に渡り、議論には古すぎても販売には十分なパケットを返した。探査機はAegirを安全にしなかった。重力井戸、放射帯、海洋シグネチャ、リレー視線、そして十分な無関心があれば利益化できる航路を読めるようにしただけだ。読めることと安全であることの差に、Deep Reachが入り込む。
