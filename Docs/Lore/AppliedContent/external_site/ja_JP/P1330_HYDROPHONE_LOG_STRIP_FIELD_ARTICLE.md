# ハイドロフォン・ログストリップ

ハイドロフォン・ストリップは、音を物理化するため、HECTON-8で最も有用な証拠物の一つだ。

        古い室内レコーダーを通る細いセラミック繊維テープである。レコーダーは人ではなく圧力室を聞いていた。ポンプ律動、ハッチ衝撃、ケーブル断線、工具の打撃、船殻応力、水と金属越しに滲んだ声を拾った。ストリップが生き残ったのは単純だったからだ。生きたネットワークも、きれいな端末も、協力的な企業アーカイブもいらない。必要なのは圧力、インク、動きだけだった。

        プレイヤーにとってストリップは鑑識物として読めるべきだ。音は不気味でよいが、証拠は不一致にある。承認前の扉衝撃、停止申告後のポンプ音、他のレコーダーも平坦になる欠落秒、生存オペレーターが署名していない経路スタンプ横の声の形。これは独白ではない。部屋が書類に反論している。

        HECTON-8に必要なのはこの調子だ。作業面から回収される人間の気配。ストリップはプレイヤーに何を感じるか命じない。上が中の人間より書類を重んじた後も、まだ仕事を続けようとしていた場所を聞かせる。
