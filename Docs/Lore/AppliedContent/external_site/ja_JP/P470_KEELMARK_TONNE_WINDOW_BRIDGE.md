# Keelmark トン窓

## 記録が証明するもの

Keelmark は作業者をまず質量問題として扱う。酸素、福祉、試料保管、証拠ペイロード調整の前に 4.8 tonne-window 相当として始まる。

tonne-window は、燃料、嵐、隔離、保険、優先度の値付け後に Black Keel が一度の軌道機会で上げられる回収質量だ。Keelmark Mutual はプレイヤーを人間として見る前に、質量として読めるようにする。保存した試料、証拠パケット、酸素債務、福祉条項が数字を動かす。

KEELMARK MUTUAL 窓台帳 // 基本リエン: 4.8 tonne-window 相当。調整対象は酸素リスク、福祉追補、試料保管、証拠ペイロード、隔離保留、carrier 揚収割当。これは回収を値付けする台帳であり、救助の約束ではない。

## プレイヤーが読むべきこと

4.8 を金だけとして読むな。それは次の機会の重さだ。 これは証拠を扱うための規則であり、救助がもう動いているという約束ではない。
