# スタック上限データ境界

HECTON-8 のインベントリ圧は、封じ込め、認証、汚染質量から来る。ゲームは単純なスタックを見せられるが、lore はなぜそのスタックが安全で、なぜ壊れ、なぜ海がアイコンを気にしないかを語る。

## Scanner

スタック行はアイコンの山を拒否する: 容器分類、圧力等級、汚染、質量が数を決める。

## Terminal
