# 物資回収出口: 苦いクレジット

物資回収出口は、漫画的な悪ではなく冷たい合法性として感じられるべきだ。請負者は仕事を行い、圧力素材を回収し、Black Keelの会計に足るcustodyを保ち、lienを実際に減らした。商業システムにはこれを失敗と呼ぶ理由がないので、船は警報を鳴らさない。
