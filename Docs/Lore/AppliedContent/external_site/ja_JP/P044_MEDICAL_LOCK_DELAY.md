# 医療ロック遅延

医療ロック遅延は証拠パケットだ。物資も手順もあったが、認可ロジックが医療を壁にした。

## Scanner

医療ロックには滅菌在庫が残るが、扉は検疫と責任フラグで閉じた。

## Terminal

医療ロック状態: 酸素、鎮静剤、圧迫包帯あり。汚染審査と資産保全認可待ちで入室拒否。

## Audio

助けられる部屋は許可を待った。

## Field Note

物資は生き残った。アクセスは死んだ。
