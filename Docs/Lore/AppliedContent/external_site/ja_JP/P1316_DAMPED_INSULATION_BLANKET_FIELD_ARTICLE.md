# 湿った断熱ブランケット・フィールド記事

湿った断熱ブランケットは、HECTON-8 の耐圧内装の金属裏にある。灰ベージュのキルト状布は家庭的な快適さではなく、振動を抑え、背面板を守り、壁が漏れを見せる前に湿気を記録する技術層だ。

ゲーム内では、これが通電機器、隠れた水路、腐食したケーブルトレイ、悪い水没後修理を示す。暗い縫い目は湿乾サイクル、垂れた区画は保持水、塩粉は結露路を示す。

この素材は古い内装に人間の保守履歴を与える。
