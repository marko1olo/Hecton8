# Aegir Sky Window Machine

Aegir の空は背景ではない。海の上で動く機械であり、明るい隙間の一つ一つに値段が付く。月たちは上層大気に relay shadow を切り込み、ガス巨星は荷電した天候を回線へ投げ、海は下から潮汐荷重、音響散乱、圧力遅延で返答する。生存者は見上げて星を見る。Black Keel は見下ろして、待つ理由の表を見る。

## 空は時計である

最初の誤りは、晴れた空を許可として読むことだ。Aegir 周辺では、晴れは露出を意味しうる。carrier へのきれいな線は、より厳しい radiation count、より熱い ascent skin、悪化した quarantine margin、claim pool を監視する者にとって鋭すぎる署名を同時に意味する。嵐は水中の危険であり、空の遮蔽でもある。雲は packet を殺し、身体を救うことがある。

だから古い route plate は空を天井ではなく時計として扱った。Skarn、Vela、Claw、Lumen、Thorne、Anvil、Kestrel、HECTON-8、Mute が重要なのは、名前が美しいからではない。その動きが relay に囁く時刻を、潮に引く時刻を、ascent sleeve に熱くなる時刻を、Black Keel に tonne-window が嘘なしに質量を受け入れられる時刻を教えるからだ。

## 月影

Kestrel の影が最も残酷なのは、それが不在のように見えるからだ。何も爆発しない。神が空を黒くするわけでもない。さっきまで通じていた線が、壊れた receipt、繰り返す checksum、底を噛み取られた carrier tone を返し始める。terminal は relay loss と呼ぶ。古い技師は scheduled blindness と呼んだ。

月影は packet の切迫を気にしない。自分の速度で route geometry を進む。proof が影の悪い縁を通って送られれば、壊れた断片、遅れた receipt、あるいは recovery authority のない清潔な packet として届くかもしれない。船は真実の一部を聞いた。空は身体を許可しなかった。

## 汚れた窓

Aegir window が一つの「はい」になることはほとんどない。それは部分的な「はい」の積み重ねだ。signal yes、tide no、storm maybe、quarantine pending、mass denied、carrier phase late。同じ空が scanner ping を支え、terminal upload を塞ぎ、ascent request を自殺に変える理由はそこにある。矛盾ではない。別々の門を持つ機械なのだ。

役に立つ計器は地味だ。radiation strip は端から褐色になる。tide card は避難所の bulkhead より先に震える。relay mast は発話より前に confidence を失う。安い window clock は Kestrel が線に近づくとつまずく。Marauder が軌道力学を解く必要はない。空が沈黙によって嘘をつく時、世界がそれを見せる必要がある。

## 海が上を見る

深く潜るほど、空の論理は音と圧力になる。Marauder は通過を壊した conjunction を一度も見ないかもしれないが、pump room はそれを遅れた relay tone として聞く。船体は tide load として感じる。scanner は carrier channel の周囲で潰れる confidence band として見る。海は天文学を作業へ翻訳する。

だから水面は単に降下の上にあるものではない。shallow relay board、浸水した antenna hinge、moon-shadow strip、storm ceiling note は同じ機械の部品だ。空が route を動かし、route が risk を動かし、risk が次の清潔な線を proof、body、salvage のどれへ渡すか決める。

## 機械を読む

正しい習慣は、信頼を伴わない忍耐だ。sky window を読む。ただし崇拝しない。明るい裂け目は packet opportunity、radiation hazard、tide warning、悪い ascent への餌のどれでもありうる。moon tag を記録し、storm ceiling と照合し、proof sealed を保ち、mass line が同意するまで待つ。HECTON-8 では、空は開いて見えるから人を救うのではない。機械のすべての門が争うのをやめた時だけ救う。
