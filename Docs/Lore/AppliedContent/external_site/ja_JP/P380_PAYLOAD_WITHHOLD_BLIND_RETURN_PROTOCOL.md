# payload blind return保持プロトコル

blind returnは拒否のルートだ。payloadをすべての正式受領者から外し、盆地ベクトルをローカルに残す。Deep Reachはアクセスマップを受け取らない。公開台帳はインシデントパケットを受け取らない。検疫はescrow割当を受け取らない。Atlasは切断鍵を受け取らない。

拒否には牙と代価がある。捕食者をもう一間隔だけ盆地から遠ざけられるかもしれないが、証拠は脆い人間の脆い容器に残る。債務は開いたまま。保管は非公式のまま。パケットが浸水するか、運搬者が通路で死ねば、誰も抑圧しなくても連鎖は消える。
