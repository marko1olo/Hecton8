# 請求枠救助遅延台帳

軌道からの最初の返答は、HECTON-8で最も冷酷なハードSFの一部だ。Black Keelは請負人を認めることができるが、回収できるとは限らない。無線パケットはほとんど質量なしでローカル窓を越える。人間はそうはいかない。その差に、このゲームのサルベージ経済がある。

請求枠は救助の約束ではない。質量、責任、権限が移動を許される会計上の枠だ。Keelmark Mutualはチャンネルを保持できる。Aegir Reclamation Poolは保管を認められる。Deep Reachは、回収パッケージに安全な上昇手段ができる前からペイロードを争える。圧力対応シール、上昇チャージ、誘導タイミング、隔離ハンドシェイクは飾りではない。キャリアが身体を受け入れるのか、試料を受け入れるのか、ファイルを受け入れるのか、それとも何も受け入れないのかを決める。

この遅れによって、HECTON-8は文明が消えたわけではないのに見捨てられたように感じられる。文明は書類、信号、価格として存在している。聞くことはできる。脅すこともできる。生存者に数字を付けることもできる。だがハードウェアと受領者なしには、懸念を上向きの運動へ変えられない。

プレイヤーにとって、この台帳は脱出の意味を変える。目的は単に助けを呼ぶことではない。助けは、システムが信じる唯一の言語ですでに返答している。プレイヤーは帰還を物理的に可能にし、拒否するには法的に不都合なものにしなければならない。
