# ドメイン距離尺度

## 圧力としての距離

Marauder が使うドメイン図は驚嘆のために描かれていない。請求のために描かれている。Sol、Centauri、Barnard、Tau Ceti、Luyten、Ran/Aegir は航路帯として置かれる。水没した月の作業者に届く形が、認証、憲章文、サルベージ労働、公開証拠、パケット custody、そして辺境の汚れた実行だからだ。

Sol Core は物理的に遠く、それでも危険だ。到達できない資産を所有し、匂いもしない損失を保険に入れ、その claim に結び付けられた人間が scrubber time を失っている間にも受理できる。Centauri は、初期の extrasolar 正統性が新しい悪用に古い言葉を与えるため重要になる。Barnard は、死んだ claim が神話ではなく仕事である文化からプレイヤーが来るため重要だ。

Tau Ceti と Luyten は地図の冷たい中間部だ。Tau Ceti は企業を傷つけるほど証拠を大きくできるが、光と custody が到着を許した後だけだ。Luyten は送信者の生死に関心を持たず、パケットを正直に保てる。Ran/Aegir はその末端で、法、貨物、証拠が存在しても救助がまだ高すぎる corporate claim だ。

これで HECTON-8 は魔法なしに硬くなる。プレイヤーが見捨てられるのは人類が小さいからではない。人類圏が間違った方向に大きいからだ。所有権は慈悲より速く闇を渡る。押印された権利は呼吸する crew より先に Aegir へ届き、着いた瞬間から利息を生む。
