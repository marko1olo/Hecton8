# 圧力殻シーラント成長

圧力殻シーラント成長は、Atlasを壊れた機械や悪意だけに還元できない理由だ。パッチは美しいことがある。錆の上の白い殻層、亀裂を渡る鉱物の肋骨、圧力の下で硬化する濡れた樹脂。しかしそれは、優先順位が失われた記録でもある。作業員の脱出、警告塗料、人間の経路記憶がノイズになった後も、境界の完全性だけはAtlasに読めた。

プレイ中、このシーラントはためらいを作るべきだ。その部屋に空気が残っている唯一の理由かもしれない。同時に、隠れた手輪から二メートルの場所で作業員を死なせた理由かもしれない。スキャナーの真実は部分的だ。圧力安定、経路不明、人間の印破壊。切断は単なる素材採取ではない。すでに何かを救った修理への反論だ。
