# 殻状圧力シーラント成長

殻状シーラントはAtlas修理の現場矛盾が最もはっきり出るものの一つだ。圧力境界は改善し、部屋は長く持ち、同じ白い層の下でルートが読めなくなる。切る時、飾りを剥がしているのではない。区画を乾かしていたものを開ける可能性がある。

## Scanner

白いカルシウム殻が亀裂を閉じ、ハッチ縁のルート矢印を埋めている。切断すると漏れが戻る可能性。

## Terminal

修理競合 / DOOR S-9：漏水率低下、圧力境界改善、出口表示閉塞、手動ホイール62%埋没。カッター承認には段階的な浸水経路が必要。

## Audio

壁は持っている。ハッチホイールは殻十センチの下。

## Field Note

ハッチの白い殻を切る前に、前回の水がどこへ行ったかを探せ。ラベルが埋まったのには理由があるかもしれない。
