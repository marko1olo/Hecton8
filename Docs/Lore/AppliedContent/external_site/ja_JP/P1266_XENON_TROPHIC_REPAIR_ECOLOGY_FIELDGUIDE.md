# キセノン栄養修復生態フィールドガイド

Xenon-OmegaはDeep Reachが盗みに来たものとして語られがちだ。それは正しいが、狭すぎる。HECTON-8では青い物質は噴出口に養われる連鎖の一部だ。熱、硫化塩、圧力欠陥、菌類ブルーム、草食群、導電性バイオフィルム、損傷したAtlas手順が同じ表面に触れる。

だから生態はプレイ可能な証拠になる。青い脈は価値、毒、電流漏れ、捕食者の通路、古い修復経路を示すことがある。タグ付き動物は狩っているのか、食べているのか、保守ループに古いセンサーデータを運んでいるのかもしれない。自然と機械のきれいな境界は不要だ。重要なのは、そのプロセスが今何をしていて、標本が残れば誰が得をするかだ。
