# Sol Core 遠隔請求権限

Sol Core は作業者の声を聞くには遠すぎるが、法では名前を債務の下に置けるほど近い。その印章は距離、shell 所有、保険審査、裁判遅延を越えて請求を残す。残酷さは構造だ。契約経路は救助経路より先に動く。
