# 近光速ドライブスタック断面図

HECTON-8の近光速船は、不可能な単一エンジンを積んだ銀の矢ではない。見えている船体は、乗員が目覚める何年も前に敷かれた航路の、最後に整備される部品だ。Barnard Yardsの訓練プレートは、作業員が実際に支払う順番でスタックを描く。ビーム帆の押し、ペレット捕獲、核融合電気スロート、影シールド、放熱リブ、磁気帆スプール、空力制動スキン、受領側の保管権だ。

各段には別の所有者と別の壊れ方がある。ビームアレイは、誰も到着費を払う前に出発を売れる。ペレット航路は燃焼を支えながら、捕獲許容差がずれれば貨物窓を破産させる。シールドは薄くなることで航海を生き延びる。放熱器は、余分な一キログラムをすべて問いに変えることで全員を生かす。磁気帆と空力制動の口座が、船がタンク内の利益を燃やさず止まれるかを決める。

こうして人類の辺境は、物理を破らず広く残酷なままでいる。光は、請求権、遭難パケット、法的脅しを、肉体よりはるかに安く運ぶ。Deep Reachは船体を動かす前に権利を相続できる。Black KeelがAegir星系にいても契約端末のように振る舞うのは、下にいる閉じ込められた作業員ではなく、現地の受領スタックに属しているからだ。

この断面図が役に立つのは、救助を機械として読ませるからだ。穴の空いた放熱リブ、閉じた制動台帳、保管メーターは背景の飾りではない。それは単純な問いへの答えの一部だ。この質量をここで止めるために誰が支払い、誰が支払わなかったのか。
