# Nearlight駆動スタック断面

Barnard Yardsの断面図は請負業者向けなので正直だ。英雄的なエンジンベルを描いて問題解決とは言わない。まず経路から始める。誰がbeam arrayを所有するか、誰がpellet laneを開けたか、シールドがどれだけ塵の損失に耐えるか、放熱余裕が何年正直でいられるか、どの受信機が人間の質量を制動する権利を持つか。

重要なのはそこだ。近光速航行は距離を小さくしなかった。距離を予定化し、保険化し、計量化し、罰則化した。船はfusion-electric throatを積んでいても、出発インフラなしでは無力だ。巡航を生き延びても、制動スロットで政治的に死ぬことがある。HECTON-8で救助が単に船の反転を意味しないのはそのためだ。エンジンとは経路、熱、custody連鎖、そして誰かが停止費用を払う質量である。
