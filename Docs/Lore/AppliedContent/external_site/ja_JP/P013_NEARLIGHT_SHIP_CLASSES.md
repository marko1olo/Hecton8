# 近光速船級

HECTON-8の近光速船は、船体に包まれた奇跡のエンジンではない。航路経済の見える端だ。ビームアレイは出発前に電力を使う。ペレットレーンは残酷なタイミングで反応質量を供給する。fusion-electric喉、シールド氷、放熱器、冷凍系はペイロードを明るい失敗にしないためにある。magsail、エアロブレーキ皮、受信窓が、船の停止許可を決める。

船級表がプレイヤーに役立つのはそのためだ。needleprobeはAegirが安全になる前に知られていた理由を示す。seed shipは共同体より先に機械が到着した理由を示す。Atlasは植民地の債務と保守妥協を示す。tenderはBlack Keelの限界を示す。Aegirの請求を処理できても、星間距離は書き換えられない。
