# 青い負債

青い負債があるから、HECTON-8のサルベージは安全に見える前に儲かりそうに見える。この物質は礁に眠る宝石ではない。産業圧力システムの残りかすだ。Xenon-Omega基質、失敗した封じ込め媒体、計算スラグ、そして海が押し続けたために安定していた封印スクラップ。間違って引き上げればサンプルは状態を変える。間違って売れば書類の痕跡があなたの身分を変える。その二重の危険が名前の意味だ。青い負債は生存者に素早く支払うが、各コンテナは未来の費用を運ぶ。除染、carrierの留置権、Black Keelの保管規則、Deep Reachの請求語彙、そしてサンプルが証拠でもある可能性。広いロアでは、この資源はHECTON-8が単に放棄されたわけではないという最初の手がかりの一つだ。価値あるシステムが圧力下でまだ動いており、触ろうとするのは追い詰められたオペレーターだけだった。
