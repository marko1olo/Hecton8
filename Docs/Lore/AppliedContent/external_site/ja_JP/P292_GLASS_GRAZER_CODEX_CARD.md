# グラスグレイザー標本カード

グラスグレイザーはHECTON-8の生態をサバイバル言語に変える。摂食は膜とマット成長に明るい経路痕を刻むが、しばしば静止のほうが動きより重要だ。無害な動物が計器より先にプレイヤーへ警告する。
