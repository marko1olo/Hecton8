# 工具認証ボード

工具認証板は、言葉より印を信じた文化を記録している。カッターヘッド再指数化。シーラントカートリッジ計量。圧力手袋二重署名。ポンプキー遅延。下降キット保留。ほとんど正しい工具が静かに人を殺せる場所では、無骨な手順が命を保った。

板が儀式めいて見えるのは、危険な労働が同じ動きを繰り返し、恐怖の置き場を作るからだ。量る、確認する、署名する、返す、再確認する。二つ目の署名は飾りではない。信頼に責任を与えた。手袋が圧力下で失敗すれば、板の印は誰が見たか、誰が急がせたか、誰がそれでも下へ送ろうとしたかを示す。

これは神秘ではない労働者の信仰だ。植民地はカッターに祈らなかった。別の疲れた人間に刃、シール、重量、鍵の返却を見させた。すべての工具がルートに触れる前に誰か別の名を背負ったため、生存は共同のものになった。
