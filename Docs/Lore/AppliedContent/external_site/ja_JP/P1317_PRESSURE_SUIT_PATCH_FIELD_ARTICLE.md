# 耐圧スーツパッチ・フィールド記事

耐圧スーツ修理パッチは、小さく密度の高い証拠表面である。暗色の技術布、シームテープ、縫い目、塩擦れ、摩耗は、スーツが整備品か借用品か廃棄品か、最後の帰還のために押し出された物かを示す。

読み方は物理的だ。縫い縁の下の塩は湿った圧力サイクルを示す。光る三日月は梯子、ハッチ、ケーブルとの反復接触を示す。関節を横切るパッチは平面上のパッチより悪い。圧力試験タグがなければ、戦利品は危険に変わる。

パッチは人間の生存を見えるままにする。
