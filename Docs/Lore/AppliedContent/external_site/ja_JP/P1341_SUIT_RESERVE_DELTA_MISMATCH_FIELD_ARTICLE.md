# スーツ予備差分の不一致

手首カウンターは見栄えの悪い小さな記録だ。告白でも最後の言葉でもない。ただ作業員の手元で圧力が落ちていく。それが酸素台帳の隣に置く理由だ。ルートがまだ開いていたかどうかを気にしない。

Aegirでは、部屋の支援とスーツ予備は一緒に動くはずだった。部屋が空気を送り、スーツが損失を吸収し、コンプレッサーが引き渡しを書き、ルート盤が帰還印を待つ。数字が割れると、コロニーの紙の地図は体の経路と一致しなくなる。

Deep Reachはその隙間を使えた。未解決の予備を持つスーツは回収可能装備として残せる。開いたルートの作業員は請求可能でいられる。claim holdはその両方にかかり、有利な所有権の言葉が固まるまで清算を遅らせる。

予備差分は死を解かない。呼吸が在庫になった机を指す。酸素台帳停止、欠けた帰還印、ルート許可スタンプの重なりと合わせて読んでから、作業員有効状態を信じるべきだ。
