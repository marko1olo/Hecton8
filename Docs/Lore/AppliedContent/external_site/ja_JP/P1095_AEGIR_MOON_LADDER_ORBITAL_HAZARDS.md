# Aegirの月梯子

Aegirの月梯子は、救助が海だけに勝てばよいという直感を最初に壊す。HECTON-8の上にあるのは空いた空ではなく、混雑した巨星圏である。Ranは光を与え、Aegirは重力、放射線、デブリ天候、移送時刻を与え、月たちは水面上の空間を動く錠前に変える。

各段の名前は、別々の確実性を破壊する。Skarnは正常な電子機器を断続的にする。Velaは光学とcarrierリンクを散乱させる。Clawは機械がまだ従う古い航路論理を残す。Lumenはパケットの通過を証明しても公正な扱いを証明しない。Thorneは隔離の疑いを運ぶ。Anvilはsalvageハードに貨物法を残す。Kestrelは間違った場所に立つだけで窓を圧縮する。HECTONは水、圧力、嵐プルームを与える。Muteは死んだ航路が紙の上で生きることを示す。

だからBlack Keelは英雄的な母船ではない。これはその幾何の中のclaim-tenderである。身体を引き上げるには、信号保管、清浄なpayload hash、隔離ハンドシェイク、誘導信頼度、保険が認めるトン窓が必要だ。明るい空は役に立たないことがある。真の信号も遅すぎれば無力だ。月梯子は孤立を物理、法、天文の三つで同時に成立させる。
