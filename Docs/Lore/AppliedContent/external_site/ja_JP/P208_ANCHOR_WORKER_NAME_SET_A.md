# アンカー作業員名セットA

アンカー作業員名セットAは、HECTON-8 の序盤で繰り返されるコロニー名を定義する。この8人は雑学ではなく記憶の取っ手だ。プレイヤーはまず物と労働を通じて彼らに出会い、その後、同じ名前が保守記録、許可、損傷報告、音声断片を横断することを見る。Set A は、説明でゲームを止めずに最初の数時間を人間的に保つ。

## Scanner

序盤の名前は演説ではなく仕事を通じて戻るべきだ。浅いルートは反復で記憶を教える。

## Terminal

ANCHOR SET A: 浅層と工業棚での反復。各名は、一つの工具、一つのルート許可、一つの壊れた作業物、一つの後の矛盾へ結びつくべきだ。これらの名前は、コロニーがサルベージ品になる前に職場だったというプレイヤー最初の証拠になる。

## Audio

工具が理由を語るまで、その名前を悼むな。
