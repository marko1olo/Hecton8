# ブラックアウト窓の信号崩壊

HECTON-8 の沈黙は、天文学、損傷したインフラ、企業自動化の混合物だ。Aegir の影、沈んだリレー、キャリアのタイミング、法務キューが通信を天候に変える。プレイヤーはそれを見越し、恐れ、修理し、時には利用する。

## Scanner

通信窓が崩れかけている: 濡れたリレー脊柱、Aegir の影、古いキャリア幾何、法務キューは再試行中。

## Audio
