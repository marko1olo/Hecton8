# 帰還権限と隔離ハンドシェイク台帳

HECTON-8での帰還は、生存者が海面やキャリア甲板へ届いた時点では完了しない。ゲームは回収を保管の問題として扱う。誰が身体を受け取り、何がそれに続き、生存者が運ぶ証拠にどの機関が責任を負うのか。

隔離法務ハンドシェイクはその決定の仕組みだ。医療許可、圧力ハードウェア認証、請求所有権、受領者権限、ペイロード保管を組み合わせる。隔離という言葉は感染より広い。スーツは生物、毒性化学、ブラックボックス記録、公的証言、債務請求を同時に持ち上げることがある。誰かが署名するまで、システムはどの問題が最重要かを決められない。

その署名は政治的だ。企業受領者は素早く動き、生存者を合法的保管の中へ消せる。public ledger受領者は証拠を消しにくくするが、犠牲者と座標を狩られやすくする。中立隔離保留は人を生かしながら、自由に話す権利を停止する。HECTON-8の救助の恐怖は、誰も答えないことではない。すべての答えがプレイヤーを資産、リスク、証人、汚染物のどれかとして定義することだ。

このルートの実用的な読み方は明確だ。上昇装置だけを作るな。受領者に対するレバレッジを作れ。パケット保管を守り、何を公開するかを選び、脱出の最後の扉は機械ではないと理解しろ。それは、何が到着したのかを決める机だ。
