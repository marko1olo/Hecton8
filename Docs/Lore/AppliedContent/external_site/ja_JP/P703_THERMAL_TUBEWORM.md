# 熱水チューブワーム

HECTON-8の熱水域調査は、およそ4,000から5,500 mの活動中の噴出流に限られた密な管形成群体を報告している。群体は測定可能な流れの変化の数秒前に一斉に引っ込み、作業班はこの挙動を熱パルスの警告として使う。

記録された危険は計測機器である。噴出口の化学が低価格の電気化学式酸素セルに干渉し、条件が悪化する一方で溶存酸素とスーツ予備の表示値を上昇させる。この誤差は滑らかで、故障として現れない。セクター44のDeep Reach試料ロットは、群体基部から埋没ノードを回収した記録を残し、宿主は不要と記載している。
