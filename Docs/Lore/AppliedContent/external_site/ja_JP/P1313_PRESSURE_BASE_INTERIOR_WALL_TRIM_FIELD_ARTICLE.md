# 圧力基地内壁トリムの野外記事

内壁トリムは、HECTON-8 を人間的にしながら甘くしないための良い場所だ。これは装飾ではない。セラミック、グラファイト、ゴム、サービス縁、琥珀色の摩耗、結露汚れ、水線で、耐圧建築を耐えられる場所にしたものだ。

プレイでは、廊下が読める表面になる。下の染みは以前の浸水高を示す。磨かれたサービス縁はバイパスやキャッシュを示す。膨らんだパネルは背後の圧力を警告する。汚れた壁のきれいな長方形は、壊れたパネルより怪しい。

物語では、壁は Deep Reach の清潔な図面を複雑にする。応急処置、遅い修理、人が待った場所、公式時系列後の帰還を記憶する。コロニーは使われ、維持され、隠され、その後沈んだ。
