# 人員ローテーション輸送

人員ローテーション輸送は、航路が天文学ではなく労働管理になる場所である。HECTON-8の人間は単なる乗客ではない。寝台体積、酸素負荷、放射線曝露、精神リスク、賃金担保、医療ファイル、管理区分、可能な証人である。帰還窓は恐怖より先にそれらの値を分類する。

悲劇は、その制度が完全な偽物ではなかったことだ。Aegirを離れた人はいた。圧力の傷、貯金、公開用に編集された話を持って帰った人もいた。その歴史が後の約束を信じられるものにした。植民地が壊れ始めた時、Deep Reachは帰還を否定する必要がなかった。遅らせ、分類し直し、値を付け、もう一周期を求めればよかった。
