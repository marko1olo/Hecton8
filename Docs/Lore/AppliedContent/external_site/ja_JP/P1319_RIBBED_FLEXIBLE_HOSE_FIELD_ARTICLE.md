# リブ付き柔軟ホース

柔軟ホースは、加圧基地をただの記念碑にしない地味な部品だ。硬い配管が通れない場所を横切る。動くハッチ、整備引き出し、スーツラック、ポンプ架台、仮設の回収リグ、最後の混乱で作られた機械室バイパス。リブは飾りではない。折れずに曲がり、濡れた手袋に握りを与え、残留物をゆっくり記録する。

読み取りは方向から始まる。リブの頂点は乾いた塩と摩耗を集める。谷は水、油、シルトを抱える。頂点がきれいで谷が暗いホースは、部屋と一緒に呼吸した可能性が高い。片側だけ磨かれていれば、引きずられたか流れに擦られた。平たい輪はクランプ位置を示す。古い塩の上のクランプは遅い修理、クランプ縁の上の塩は古い設置を示す。

ホースは背景ではない。酸素ホースを切れば部屋は敵になる。冷却バイパスは、死んだ廊下で一台だけ温かい機械を説明する。工具テザーは、逆方向に切った人物へ続く。両端を読み、リブを読み、それから切れ。
