# HECTON-8中軌道潮汐役

HECTON-8は利益の出る中間に座る。軌道はDeep Reachに、機械を冷やし、資産を隠し、圧力産業を養い、claimを正当化する化学を動かす海を与える。同時にコロニーには止まらない天井を与える。潮汐はサービス峡谷に荷重をかけ、沈水地殻を曲げ、きれいな予定を壊し、上昇質量がいつ出られるかを決める。 その軌道のせいで、プレイヤーの潜水は海底だけでなく、頭上の時刻表と法律にも縛られる。
