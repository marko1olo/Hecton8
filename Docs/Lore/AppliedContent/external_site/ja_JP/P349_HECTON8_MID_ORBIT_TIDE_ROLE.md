# HECTON-8中軌道潮汐役割

HECTON-8はAegirの梯子の利益が出る中間にある。その軌道はDeep Reachに、機械を冷やし、資産を隠し、圧力産業を養い、請求を正当化するだけの化学を動かす海を与えた。同時に植民地には、決して止まらない天井を与えた。潮汐はサービス峡谷に荷重をかけ、沈んだ地殻を曲げ、清潔な予定を壊し、上昇質量がいつ離れられるかを決める。

取り残された潜水者は、単に水深が深い場所にいるのではない。その身体は、契約を変え続ける空の下にある。良い救助窓とは、慈悲に推力を足したものではない。潮汐位相、キャリア受諾、嵐のノイズ、保管文言、燃料の熱余裕、そしてカプセルが汚染され、遅れ、証拠を満載して到着した場合に誰が払うのかという不快な問いでできている。
