# 管状サンゴ

HECTON-8のAegirサルベージ班は、健全な面ではなく産業用板の亀裂に沿って定着し、2147年以降手が入っていない構造の亀裂を埋めて圧力封止する群体性の管形成生物を報告している。生長のみで数メガパスカルを保持した状態で回収された室もある。

同じ生長が、構造認証に用いる打刻パネル識別を覆う。セクター44のDeep Reach修理記録はそうした室を外部踏査で完了扱いにしている。これは室が健全であることは確定するが、それがどの室であるかは確定しない方法である。現場では溶接継ぎ目を横切る筋はすべて耐荷重として扱う。
