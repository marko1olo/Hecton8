# 経路板と帰還スタンプのフィールド記事

経路板は、普通の仕事を読める形にするため、 lore と gameplay の強い橋になる。ハッチ横の板に四つの名前、二つの工具タグ、悪い潮汐窓、押されなかった帰還スタンプがあれば、プレイヤーに人員説明の講義はいらない。その物体だけで時間、仕事、危険、責任が同時に伝わる。

よい板の証拠は、人が触った感じを持つべきだ。グリースペンは古い塩を横切る。スタンプは数ミリずれる。押した手が疲れ、濡れ、恐れていたからだ。名前は消されるのではなく移される。そうした細部が、全ての遺体に家族ドラマを足さずにコロニーを人間的に保つ。労働者は圧力下の専門家であり、装飾的な犠牲者ではない。

設計面では、経路板は反復コンテンツを支える。同じ板の言語がキャッシュ、危険、ロックされたハッチ、失われた工具、音声断片、手続き生成の部屋差分を示せる。物語面では、Deep Reach が人間の不在を管理ステータスへ変える癖を露出する。コロニーは死ぬ前に仕事を止めなかった。死を仕事として記録し続けたのだとプレイヤーが気づく時、HECTON-8 はさらに怖くなる。
