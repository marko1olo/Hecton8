# Aegir系公開入門

AegirはHECTON-8を取り巻く恒星系であり、あらゆる実務面で重要だ。月の梯子は潮汐と接近窓を形作る。中継幾何は、救助質量より先に証拠を運ばせる。運搬船の軌道はBlack Keelを存在させるが、即座に役立つものにはしない。奇跡のドライブも、ansible救助も、清潔な緊急ボタンもない。公開版Aegirは、残酷でいられるほど到達可能に感じるべきだ。接続され、予定され、値付けされ、それでも下に閉じ込められた人々には遅すぎる。
