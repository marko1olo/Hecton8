# 深海団塊平原フィールド記事

深海団塊平原は、HECTON-8 の資源を装飾ではなく地質として感じさせる。マンガン団塊は光る収集物ではない。小さな核の周りに鉱物が育った遅い記録であり、十分長く安定した水が自分を書き残したものだ。プレイヤーが平原を見つけた時、その場は豊かで、同時に簡単には渡さない感じが必要だ。

これはトーンに関わる。ゲームは深海で一人の 略奪者 を扱うのであって、チェックリストを片づける鉱夫ではない。団塊は取れる。しかし周囲のシルトはもっと大きな話をする。流線、粉の影、空の採取輪、クローラー痕、染みた殻が、プレイヤー到着前の出来事を語る。慎重なプレイヤーは資源、経路、証拠を持ち帰る。雑なプレイヤーは塊の箱と白い盲目の雲を持ち帰る。

世界設定として、団塊平原は Deep Reach が機械的に失敗する前に倫理的に失敗したことも示す。会社は忍耐強い海底を見て、安い採取に翻訳した。塊ごとに値段をつけ、堆積記録、音響地図、白濁の中で働く作業員への損害を割り引いた。
