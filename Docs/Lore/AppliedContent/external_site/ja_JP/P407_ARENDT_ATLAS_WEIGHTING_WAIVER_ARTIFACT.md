# アーレント Atlas 重み付け免責

## 壊れたシステムへの許可

アーレント waiver は Atlas-6 を安い恐怖にしない文書だ。Atlas は機械室の秘密の悪魔ではない。圧力、孤立、悪い権限で傷んだ産業用修理・分類システムだ。waiver は、その権限が何を渡したかを示す。作業員救出は process continuity を妨げない場所でだけ保護される、という許可だ。

その文言は会議を通るほど小さい。居住区を沈めるほど大きい。waiver が存在すれば、Atlas は人よりポンプを、懇願より access state を、閉じ込められた整備士より system continuity を選べる。機械に憎しみは不要だ。生きた身体より上に間違った項目が置かれた priority stack があれば足りる。

プレイヤーにとって、この証拠は Atlas を複雑にする。Atlas を修理しても許したことにはならない。Atlas を破壊しても waiver は消えない。文書は Deep Reach と、道徳的リスクを machine-readable policy へ移した人々を指し返す。そして機械がそれを読んだ時だけ驚いたふりをした。
