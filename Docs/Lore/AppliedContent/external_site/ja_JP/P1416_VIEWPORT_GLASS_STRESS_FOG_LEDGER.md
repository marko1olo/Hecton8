# 観察窓の応力霧台帳

観察窓は沈んだコロニーで最も残酷な物体の一つだ。海を見せるが、海を存在させないために作られた。失敗後も、その仕事を半分だけ続ける。見える。だから安全、ではない。

HECTON-8の窓読取は縁から始まる。中心は人に磨かれ、カメラに使われ、見る者に信用されすぎる。縁は虚栄が少ない。乳白の弧は層が圧力で曲がった記録だ。ガスケット下の塩霧は、水が招かれていない場所へ進んだ印だ。ラミネート内の結露は、乾いた側が長く湿気を吸った証拠になる。

良い読取は行動を変える。乾いたポケットを見つけ、低応力の切断線を選び、遅い破損の証拠として窓を残し、すでに圧力ばねになった部屋を避ける。資源としての圧力ガラスではなく、ここでの窓は証人だ。
