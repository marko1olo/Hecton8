# Aegir空模様サバイバル台帳

HECTON-8は空をサバイバルシステムとして使う。Aegirは地表に迫力を与えるほど巨大だが、重要なのは大きさではない。重要なのは、空がプレイヤーにとっての真実を変えることだ。穏やかな地平線はアップリンクを鋭くし、放射線を上げる。嵐は肉体を守り、carrierを雑音に沈める。月の通過は、プレイヤーが使うつもりだった扉から潮汐モデルを外す。

これによりフィクションは物理的であり続ける。救助は曖昧な筋書きの壁で止められているのではない。天候、電荷、リレー幾何、custody経路、質量配分、そして軌道上のcarrierが遭難者の望むたびに揚力機会を使えないという事実に止められている。Black Keelは一つの窓で証拠を受け取り、それでも身体回収は後の窓まで拒むことがある。その差がゲームだ。

プレイヤーは酸素計を読むようにAegirを読むべきだ。空は、いつ送信し、いつ避難し、いつ流れを信じ、いつ澄んだ信号を疑い、いつ上昇計画が幾何を待つ約束にすぎないかを教える。
