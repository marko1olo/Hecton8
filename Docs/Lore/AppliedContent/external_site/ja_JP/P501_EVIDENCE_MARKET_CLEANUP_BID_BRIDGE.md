# 証拠市場クリーンアップ入札

## 証明すること

クリーンアップ入札は、証拠片の移動方法を変えるための有償の試みだ。清掃、改名、抑圧、サルベージロットへの添付、安全な分類への移動が含まれる。誰かが紙の痕跡に介入する価値を見たことは証明するが、断片の真偽や買い手の有罪は証明しない。HECTON-8では、支払い経路、元ラベル、清掃後ラベル、請求者書換、保管移転を追う。

## 読み方

証拠クリーンアップ入札
支払い行を評決として読むな。
次の証拠: 入札元、支払い保留、保管移転、請求者向け書換、物体経路。
清掃前ラベルを清掃後ラベルの横に残す。

## 現場メモ

入札は匂いであって判決ではない。汚れたラベルをきれいなラベルの横に置け。
