# 墜落棚

墜落棚はプレイヤーの最初の部屋であり、最初の犯罪現場でもある。降下カプセルは塩草と温かいセラミックに半ば埋まり、去るには壊れすぎ、捨てるには役に立ちすぎる。生き残ったフレームは、避難場所、サルベージ、スキャナー対象、そしてBlack Keelへの線を与える。その声は人間的に聞こえる前に、まず手続きの声として聞こえる。そこが重要だ。carrierは友人のようには答えない。失敗を棚卸しする。上昇パッケージ喪失、アップリンク破断、オペレーター生存、回収権限未解決。開始地点は講義なしでHECTON-8を教える。美しさは本物だ。浅瀬の生物発光、礁の色、Aegirの下の嵐光。産業の暴力も本物だ。刻印された部品、衝突痕、請求の言葉、すでに費用を数える救助連鎖。最初の問いは実務的だ。生き残れ。二つ目の問いは同じ残骸の中で届く。あなたが生き残ると、誰が得をするのか。
