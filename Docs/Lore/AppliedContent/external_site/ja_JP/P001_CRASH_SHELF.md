# 墜落棚

HECTON-8は水際から始まる。壊れた降下カプセル、明るい異星の浅瀬、そしてきれいには応答しない遠いキャリア。最初の謎は海底の生物ではなく、救助の鎖が最初から敵意を帯びている理由だ。

## Scanner

降下カプセルの残骸。耐圧フレームは無事だが、上昇パッケージは破壊されている。生き延びる場所にはなるが、帰る船にはならない。

## Terminal

上昇パッケージ: 消失。通信コア: 亀裂検出。キャリア接触: 遅延。

## Audio

Black Keelのハンドシェイクを受信。パケット完全性は回収しきい値未満。繰り返す、しきい値未達。

## Field Note

殻がまだ圧を保っているなら、全部はぎ取るな。粗末な避難所は、きれいな在庫より価値がある。
