# 嵐曲がりリレーマスト台帳

リレーマストはHECTON-8の世界論理の中でもっとも明快な部品の一つだ。プレイヤーに直す物、空への見える方向、そして残酷な結果を与える。接触は良くなるが救助は保証されない。その結果はトリックではない。聞かれることと回収可能であることの差だ。

設定上、マストは局地インフラである。Aegir方位、古いリレータイミング、天候ノイズ、packet信頼度を知っている。carrier優先度、隔離受信者、custody law、lift質量は所有しない。修理はメッセージを壊れにくくするが、Black Keelにascent機会を使わせることはできない。

だから最初のpacket選択が重い。弱い窓ではすべての行が貨物になる。証拠、身体、試料、債務、座標、謝罪。マストはプレイヤーが何かをシステムへ送る道具だ。恐ろしいのは、そのシステムがはっきり返事をするかもしれないことだ。
