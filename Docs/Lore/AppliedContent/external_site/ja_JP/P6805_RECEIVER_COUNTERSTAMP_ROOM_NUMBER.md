# receiver counterstamp の部屋番号

receiver counterstamp room number は、blank quarantine berth を空白でなくす最初の印だ。room code、receiver strip、medical owner seal、timestamp、body custody class。小さく見えるが、HECTON-8 では巨大な意味を持つ。海の上の誰かが、もう「その扉に owner はいない」と言えなくなるからだ。

それで扉が優しくなるわけではない。room number は取っ手であって赦免ではない。Black Keel は body line を名指しの場所へ向けられるようになるが、同時に lift 後に body を所有する者、suit 内の evidence を管理する者、testimony を遅らせる者、pressure transition が失敗した時に請求される者も決まる。

## 空白から所有へ

blank berth receipt は、route が Marauder を聞いたが receiver room を名指しできないことを示す。counterstamp はその状態を変える。欄に部屋を書き込み、その部屋を public quarantine、corporate recovery、medical custody、claim-pool emergency hold、またはきれいなラベルと汚い clauses を持つ mixed receiver に結び付ける。

stamp は一行ずつ読む必要がある。`Room named` は `body accepted` ではない。`Body accepted` は `testimony protected` ではない。`Medical owner present` は `Deep Reach excluded` ではない。route は、疲れた手が信じるほど mercy に近く聞こえる言葉を好む。

## Sample の部屋、Body の部屋

最も普通の罠は sample room だ。receiver は sealed canister、pressure glass、suit residue、proof core のために quarantine room を stamp し、生きた body を別の legal class に残せる。console では同じ carrier pass、同じ receiver name、違う custody rule の二行が並ぶ。

この差は重要だ。sample は箱詰めされ、遅延され、archive される。生きた body は話す。生きた body は memory、debt、contamination、injury、proof を同じ皮膚に持つ。counterstamp が sample custody だけを名指しするなら、berth field が空に見えなくても body line はまだ露出している。

## 良い Stamp も鋭い

役に立つ counterstamp は room、medical owner、body custody class、receiver liability line を名指しする。Black Keel が扉と owner を指せるため、lift allocation を可能にするはずだ。同時に拒否を高価にする。route がその後 body を無視すれば、拒否は次の ledger に見える。

しかし stamp はまだ鋭い。public ledger receiver は proof を消しにくくして守るが、coordinates を露出させることがある。neutral quarantine room は body を生かしつつ speech を停止する。corporate receiver は最速で動き、chain の外側が行の背後の顔を見る前に survivor を lawful custody に変える。

## Counterstamp を読む

room number は comfort ではなく evidence として読む。timestamp を body ledger と blank berth receipt と比べる。room class が `body`、`sample`、`witness`、`mixed exposure` のどれかを見る。owner strip を見る。lift allocation switch が変わった理由が、room が body を受け入れたからなのか、proof core が body を引きずれるほど価値を持ったからなのかを確認する。

counterstamp は progress だ。最もきれいな遅延を壊すからだ。だが危険でもある。emptiness を ownership に置き換えるからだ。Aegir 空間で最初の room number は、Marauder が救われたかを答えない。もっと厳しい問いに答える。誰が扉を閉じる権利を得るのか。
