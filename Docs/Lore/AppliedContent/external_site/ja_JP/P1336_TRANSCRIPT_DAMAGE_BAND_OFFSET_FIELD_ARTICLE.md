# 転写損傷帯のずれ

HECTON-8では、音声ログはまず物体であり、その次に言葉になる。転写損傷帯はその規則を守る道具だ。元の音声が失われた、隠された、または引用できないほど壊れた箇所を示す。カセット、ハイドロフォン帯、notary印と合うなら警告で済む。物から離れているなら、処理の跡になる。

ずれが重要なのは、転写は物理媒体より早く直せるからだ。回収卓はノイズをならし、字幕位置を動かし、名前を隠し、公式に見える版を出せる。レコーダーの機械はそこまで従順ではない。傷、送り飛び、塩のにじみ、クロックラダーの刻みは順番を保つ。黒い帯が遅れて現れる時、文書の保管と機械の保管が分かれた点が見える。

この項目はレコーダーベイ証拠列の一部だ。音声断片タグは声の所属主張を示す。ハイドロフォン帯は部屋が金属と水越しに聞いたものを示す。カセット歯とインク車は媒体の動きを示す。転写損傷帯のずれは、読める言葉がまだその媒体のものかを問う。大きな秘密ではない。請求先のある時刻ずれだ。

公開資料では、Deep Reachはこれを字幕の劣化部分と呼べる。エギルで帯を手にしたMarauderなら、もっと硬い言い方をする。転写は損傷の後で清掃され、清掃版は自分を古く見せようとしている。
