# 遅延トリアージ台帳

HECTON-8 の医療区画は、照明が消えた瞬間にだけ壊れたのではない。もっと前に、整った行の中で壊れていた。

遅延トリアージ台帳は一見すると人道的に見える。負傷区分、酸素負債、安定化メモ、搬送窓、証人欄がある。短い記録は実用的に見えるため信頼される。圧力下では実用性が必要だった。ハッチがうなり、ポンプ管が甲板を叩く中で、医療員は長い報告を書けない。印、コード、素早い判断が必要だった。

醜い部分は、そのコードが管理側に便利になった時に始まる。砕けた肋骨は amber hold になる。避難が必要な人は経路確認待ちで安定化になる。空の担架バッテリーは装備状態未解決になる。閉ざされた通路は誰も迎えに来なかったではなく移動権限なしになる。各語句は、部屋が悪化する間もシステムを清潔に保った。

だから物理的な医療室が重要になる。台帳は省略で嘘をつける。拘束帯、酸素ラック、床の傷、ハッチ印、濡れた圧力テープ、証人ハッシュが問いを返させる。本当に患者は安定していたのか。同じボンベが三回割り当て直されたのか。経路は負傷前に閉じたのか、それとも負傷が数字を悪くしたから閉じたのか。遅い手が水位跡の上で行を書き直したのか。Marauder の印は、台帳がカテゴリに変えた名前を戻したのか。

プレイヤーにとって、この台帳は安い悲劇ではなく証拠として損害を読む方法である。HECTON-8 は、証拠が手続き的であり同時に個人的である時に強い。台帳は、見捨てるための言語がシステムにあったことを示す。部屋は、その言語の代金を払った人を示す。
