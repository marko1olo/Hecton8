# センサータグ付き動物相

センサータグ付き動物相は、HECTON-8 の生体機械層を単純な汚染フィクションにしない。生物は魔法でドローンに変えられたわけではない。監視装置より長く生き延びた動物や群体である。タグは窪み、傷、成長輪、鉱物の水ぶくれ、偽の眼になった。生態系はいつものことをした。傷の周囲で成長したのだ。

そのため、すべての信号ゴーストに履歴がある。Marauder は殻を食む生物の中から弱い Deep Reach 識別子を聞くかもしれないし、命令を無視する体の上でバイオメタルの眼が瞬くのを見るかもしれない。古い企業は肉の中にまだ書類仕事を残しているが、肉は従わない。Atlas は信号を利用できても、動物を所有できない。だから恐怖はより悲しく、強い。産業的支配は生命に印を付けようとし、生命は生き残り、その印は今も、何を聞いているか理解しないシステムへ報告している。
