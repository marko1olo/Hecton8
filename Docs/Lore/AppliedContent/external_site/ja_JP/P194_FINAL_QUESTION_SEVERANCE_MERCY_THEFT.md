# 最終問い: 切断、慈悲、盗み

切断は抽象ではなく、触れるほど怖い行為であるべきだ。プレイヤーは善悪と書かれた赤いボタンを押していない。圧力扉、生きた導電膜、古い作業員記録、動物の経路、payloadの道を通る連続性を切っている。最終室までに集めた証拠パケットの一つ一つが、その切断の意味を変える。

Atlasが主に看守なら、切断は慈悲だ。盆地を支える唯一のものなら、破壊工作だ。新しい海洋機械生命なら、殺害だ。Deep Reachの所有物なら、盗みだ。正しい設計は、どれか一つをプレイヤーに代わって選ばない。部屋にいるどの証人も、この行為を正直に単純化できない理由を理解させることだ。
