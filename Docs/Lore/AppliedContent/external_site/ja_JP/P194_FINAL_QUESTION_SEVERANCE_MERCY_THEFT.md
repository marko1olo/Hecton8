# 最終問い：切断、慈悲、窃盗

切断は道具で行う作業として感じられるべきで、道徳ボタンではない。切断は圧力扉、生きた導電膜、作業員記録バッファ、タグ付き動物経路、vent micronodes、shell sealantパルス、ペイロード経路を横切る。最終室に持ち込まれた証拠パケットごとに、後からその行為を名付けられる主体が変わる。

Atlasが看守として働いているなら、切断は埋め続けられた記録をそのロジックから解放できる。Atlasが盆地を支えているなら、同じ切断は修復経路を死んだハードウェアに変える。修復層が地域の生命形態になっているなら、切断は機械以上のものを傷つける。Deep Reachがまだ連続性レールに乗れるなら、切断は戻り道を閉ざせる。この終わり方は、記録がまず物理的損傷を示し、ラベル争いを受信者法に任せるときに機能する。
