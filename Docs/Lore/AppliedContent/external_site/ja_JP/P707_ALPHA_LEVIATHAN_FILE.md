# アルファ・リヴァイアサン：統合ファイル

Aegirの沈没構造で作業するサルベージ班の間では、ALPHA LEVIATHANの呼称で整理されたDeep Reachの不完全な文書が回っている。文書には二十二件の事象が挙げられ、そのうち九件が呼称そのものを負っている。統合の根拠として記載されているのは、この九件が船体応力の届出につながったこと、そして損失報告の書式が原因欄を一行しか認めないことである。残る十三件は、請求が立てられなかった記録上の方位として扱われている。

回っている写しがそれ以外で一致しているのは、主にそこに無いものだ。形態、質量および全幅、音響搬送波の上限はどの写しでも非開示で、参照されている付録はどれにも付いていない。

削除を経て残るのは観察ではなく機器の挙動である。ソナー接触のない船体応力警報、距離のない方位記録、見える原因より先に現れる流れの乱れ、そしてそれらより前から続く小動物の音の低下。生存者供述は全文が保持されており、低酸素症と窒素酔いによって汚染されている。これが、供述を判断材料に入れなかった理由として記載されている。Deep Reachはこの呼称を通航注意として管理し、関連する損失は圧力変動として計上している。
