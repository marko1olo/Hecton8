# グラスグレイザーの群れ

グラスグレイザーの群れは、動物行動を計器として読む HECTON-8 最初の授業である。グレイザーはペットでも、戦利品の袋でも、無害な飾りでもない。彼らは小さな透明の殻を持つ採餌生物で、鉱物膜を明るいレーンへ削ることで浅い棚を読めるものにする。生きた群れは Marauder に、pressure glass がどこで育ち、どの継ぎ目が熱すぎ、どの流れがいま曲がり、捕食者が最近通っていない場所はどこかを知らせる。重要なのは多くの場合、不在である。膜は残り、小さな殻の口は刻むのをやめ、清潔な経路が急に間違ったものに感じられる。その沈黙は浅瀬の捕食者文法に直結する。危険はまず、消えたファウナ、途切れたブルーム音、美しい礁を横切る影として来る。よい配置なら、プレイヤーは身体で学ぶ。淡い削痕へ泳ぎ、殻に当たる刻み音が鋭くなるのを聞き、温かいシーラント周りの空白を見つけ、ソナーが理由を知る前に群れが折れて退くのを見る。グラスグレイザーが HECTON-8 を生きているように感じさせるのは、彼らが有用で、脆く、正直だからだ。彼らは海を説明しない。海がいま何をしたかを露出させる。

## Scanner

グラスグレイザー群 // 透明な殻を持つ採餌生物が pressure glass とフォティックマットの縁から鉱物膜を削る。殻の刻む音は明るい経路痕を開き、急な沈黙は捕食者のデータになる。

## Terminal

基礎ファウナ: 非敵対性のグレイザー集団。pressure glass 膜、新しい鉱物ブルーム、流れの乱れ、捕食者による退避を追跡する。活発な採餌後の不在は経路警告であり、空の出現地点ではない。

## Audio

殻を叩くあの刻み音が聞こえるか。食事であり、地図であり、同じ音の警告だ。

## Field Note

群れを追うな。群れが露出させるものを読め。新しい膜、古い削痕、温かいシーラントの回避、そして彼らが渡ろうとしない空白のレーン。
