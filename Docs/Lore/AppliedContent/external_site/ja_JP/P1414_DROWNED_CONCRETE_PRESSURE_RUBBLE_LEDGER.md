# 沈没圧力コンクリート台帳

沈没コンクリートは死んだ建物の文法だ。白い塊は岩に見えるが、直線、ガスケット跡、錆影、骨材の帯が人間の設計を残している。

最初の問いは採取できるかではなく、何を押さえていたか。下の汚れ、割れ方、ケーブル傷、ボルト粉は、乾いた側と浸水した側を教える。

Deep Reach は事故名を変えられても、悪い打設の老い方は変えられない。プレイヤーは建設を証拠として読む。
