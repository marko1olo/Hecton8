# ブライン階段

ブライン階段は、HECTON-8が単純な下降であることをやめ、水でできた機械になる場所だ。濃いブラインは上の層ときれいには混ざらない。海底に棚、カーテン、遅い川として横たわり、ソナーを曲げ、最悪の瞬間に浮力を変える。その危険がプレイヤーに新しい読解力を与える。強い船殻は助けになるが、水を読むことのほうが重要だ。どこで熱が持ち上げ、どこで塩が落とし、どの境界を道のように乗れるか、どの不注意なバラスト変更が艇を見えない天井の下に縫い止めるか。ロア上の価値も大きい。ブライン階段は、植民地が失おうとしたものを保存する。古い経路標識、圧力カスケット、死んだドローン、化学痕跡、ときには何十年も混ざらなかった層の中の遺体を保つ。下への一段一段が、同時に航法、考古学、告発になる。
