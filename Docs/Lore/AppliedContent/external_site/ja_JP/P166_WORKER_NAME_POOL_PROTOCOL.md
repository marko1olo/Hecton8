# 作業員名簿記録

作業員名簿記録は、HECTON-8 が seed された証拠を人間の継続性へ変える方法を定義する。各身元は、作成済みの名前、ドメイン由来帯、圧力労働の役割、バッジ片、経路許可、シフト印から組み立てられる。目的はランダムな雰囲気づくりではない。誰がハッチを開けられたのか、誰がポンプを整備したのか、誰が医療解放を拒否されたのか、後の Marauder が誰の痕跡を乱すのかを読める責任にすることだ。

この仕組みは個人性を保ちながら、物品配置と証拠の組み合わせを変えられる。矛盾のないリプレイのためである。作業員はロッカー、作業板、経路カード、マニフェストから現れるが、原則は同じだ。部屋が seed 可能でも、人間は手続き的な消耗品ではない。

## Scanner

NAME STRIP // 出身帯、経路許可、シフト役割、傷ついたバッジ片が同じ作業員を指している。ロッカーをサルベージに変える前に名前を読むこと。

## Terminal

NAME POOL PROTOCOL // 作業員の身元は、固定された個人名、ドメイン由来帯、圧力下の職務名、シフト記号、バッジ片、経路許可から構成される。seed ごとに順序や組み合わせは変えられるが、人をランダムな戦利品ラベルにしてはならない。個人名はロケールごとに作成し、役割、経路、アクセス語彙が機械的意味を持つ。

## Audio

名前は、コロニーが最初に部品取りしようとした物だった。

## Field Note

名前は飾りではない。ステーションが嘘をつき始めた時、誰がその湿った区画に入る許可を持っていたかを示す証拠だ。
