# ドメイン刻印 2190

2190年には、壊れた一つの物体が複数の法的親を持つ。HECTON-8では、圧力ラッチがSol認証、Barnard修理、Luyten保管、Centauri正当化、Aegir請求殻による差し押さえを同時に背負うことがある。刻印はコロニーを安全にしない。記録された場所にする。

その差がゲームの調子を決める。HECTON-8は文明の外ではない。文明の冷たい側の下にある。ブラケットに名を付け、身体に価格を付け、パケットを保存し、それでも救助質量を間に合わせられない側だ。
