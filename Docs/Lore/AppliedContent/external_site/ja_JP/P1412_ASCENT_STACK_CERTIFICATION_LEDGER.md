# 上昇スタック認証台帳

HECTON-8では、脱出は希望になる前に物理になる。上昇スタックは、生存者が破片にならず上へ動けることを示すハードウェア証明だ。圧力シールリング、上昇チャージ、誘導ping、熱衝撃余裕、受領者タグを一つの醜い証明書にまとめる。

その証明書が重要なのは、海が背景ではないからだ。圧力欠陥は最初の燃焼でカプセルを切り裂く。未計測のチャージは身体を窓の外へ投げるか、キャリアの下で散らす。pingがなければ回収は誰も資金を出したくない捜索格子になる。receiver tagがなければ、戻った身体は救助ではなく保管問題になる。

このスタックはゲームのロアとしても強い。すべての部品が遊べるからだ。シールリングは壊れたハッチで見つかる。燃焼カートリッジはsalvage massから作れる。誘導クレードルはrelayハードから再建できる。shock stripは、スリーブが冷却、塩水、圧力サイクルに耐えたことを示す。プレイヤーは抽象トークンを集めているのではない。claim-window deskから拒否理由を奪っている。

上昇スタックが認証されても、Black Keelが優しくなるわけではない。キャリアが質量を拒む理由を一つ失うだけだ。それがHECTON-8の調子だ。上への道は同情で与えられない。敵対的なシステムが価格を付けられるほど、圧力対応証拠が揃ったから開く。
