# 回収コンプライアンス餌契約シード

回収コンプライアンス餌は、掲示板で最も汚れた清潔な契約の一つだ。案件は公共奉仕の顔をしている。浸水した医療ロッカーを回収し、死亡スーツの識別子を取り戻し、危険な機械コアを除去し、腐敗や圧力損傷で記録が崩れる前に密封貨物を返す。表示報酬は、苦しい週には慈悲に見えるほど高い。

罠は受領者チェーンにある。回収コンプライアンスの印章は、中立サルベージ事務所、植民地保険会社、災害清掃デスクを経由できる。しかし最後の読み手は Deep Reach か、同社へ優先アクセスを売る代理であることが多い。オペレーターは物資回収の報酬を受け取り、同時に座標証明、ハッチ状態記録、保管メモへ静かに縛られる。引き渡し拒否で危険は消えない。経路は差し止め警戒対象として記録され、後の安全な受領者は忍耐を失いやすくなる。

この契約が機能するのは、追い詰められた時ほど整った書類が避難所に見えるからだ。フィルター、バッテリープレート、圧力テープが足りないクルーは、きれいな報酬を見て座標条項を読む前に案件を受ける。最初の密封箱が船内に入った時点で、掲示板はそのクルーがまだ届く場所と、放棄区域がまだ埋めきれていないものを知っている。
