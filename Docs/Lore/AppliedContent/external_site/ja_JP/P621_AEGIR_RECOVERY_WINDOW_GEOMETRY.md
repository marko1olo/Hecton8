# Aegir回収ウィンドウの幾何

Aegirの回収は、救助である前に予定表である。Black Keelは狭いリレー通過でパケットを聞けても、母船位相、嵐の天井、Kestrelリレー影、検疫状態、上昇パッケージ封印、承認済みtonne-window質量がそろわなければ身体を拒む。HECTON-8ではその遅延が物理になる。海は降下装備を圧力下に縛り、空は天候と荷電ノイズで直線視界を壊し、母船はあらゆるキログラムを請求台帳の一部として扱う。だから軌道からの最初の返答は慈悲ではない。機械の一部が数分だけそろった証拠である。生き延びるには、次のウィンドウが閉じる前に残りの機械も同意させる必要がある。

## Scanner

ウィンドウ時計 // この通過でBlack Keelはパケットを受信できる。身体回収にはまだ上昇装備、検疫ハンドシェイク、Kestrelリレー影の解除、承認済みtonne-window質量行が要る。

## Terminal

KEELMARK回収通知 // 信号受信はリフト承認ではない。回収要求の前に、母船位相、嵐の天井、リレー影、検疫許可、上昇パッケージ状態、承認済みペイロード質量を合わせること。

## Audio

Black Keel中継: パケット受信。身体はこのウィンドウに入らない。上昇パッケージを封印したまま、証拠タグを維持し、数字ひとつで空気を使って喜ぶな。

## Field Note

母船が応答しても、空気を祝いに使うな。返答は幾何と会計だ。救助は、ウィンドウ、封印、ペイロード、身体が同じ線に入った時に始まる。
