# 加圧コロニーの勤務日フィールド記事

HECTON-8 のコロニー生活は、温かい辺境ノスタルジーではない。居住地は、人間の普通の習慣を加圧運用に変えることで生き延びた。眠ること、食べること、修理すること、経路を記録すること、工具を渡すことは別々の分類ではない。同じ空気、同じ扉、同じポンプ、同じ疲れた身体に結びついていた。

そのためゲームは日常空間を証拠として扱う。寝台列は企業メモよりも人員圧迫を説明できる。サービス用の食事場は、人々がどれほど長く呼び出し状態に置かれたかを示せる。経路ボードは、清潔な予定表と、壊れかけの区画へ誰が入らされたのかという汚れた現実の差を暴く。プレイヤーは説明板ではなく、個人生活が常に仕事に綴じられていたことを見てコロニーを学ぶ。

この調子が重要だ。HECTON-8 は夢の都市を築く高潔な入植者の話ではなく、悲劇の小道具になる無名労働者の話でもない。有能な人々が、有能さを忍耐時間へ変換する制度の中で暮らし、その余白が壊れる話だ。
