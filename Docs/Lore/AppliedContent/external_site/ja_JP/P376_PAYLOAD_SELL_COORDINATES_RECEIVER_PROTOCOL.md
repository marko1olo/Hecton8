# payload座標売却受領プロトコル

このプロトコルは単なる戦利品売却ではない。到達権の移転だ。Deep ReachにはHECTON-8を争う紙は十分にある。足りないのは損傷した盆地を抜けて戻る信頼できる道だ。payloadは座標、信頼、証拠保管、salvageクラスを束ねてその道を渡す。
