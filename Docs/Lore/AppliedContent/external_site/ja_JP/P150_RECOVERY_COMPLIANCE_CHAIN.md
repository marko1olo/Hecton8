# Recovery Complianceチェーン

Recovery Complianceという語は終盤を冷たくする。秩序立って聞こえるのは、本当に秩序立っているからだ。請負者には許可、証拠には管理、サルベージには権原、航路保険には記録、公開オフィスには自白しない文言が必要になる。

恐ろしいのは、チェーンが生きた人間を含んでも救助にならないことだ。生存者は証人素材、圧力服は返還質量、告白はデータペイロードとして扱われる。チェーンは人を外へ出しながら、その人を下に置いたオフィスに仕え続ける。
