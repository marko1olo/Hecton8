# 浅瀬の根マット基質

浅瀬の根マットは、新しい潜水者が最初に読む生きたシステムの一つだ。歓迎するほど明るく、嘘をつくほど密だ。上層はAegirの光を受け、生産窓では薄い酸素膜を放つ。下では根が貝殻砂、石灰粉、サンゴ類似片を結び、編まれた床のような表面を作る。重量、流れ、閉じ込められたガスが規則を変えるまでは。

Deep Reachの作業員はマットの端を安い経路記憶として使った。ピンガー線はそこに引っかかる。古い管は根の錨になる。輪の周りに育ったマットは標識が消えた後も道を読ませる。しかし編み込まれた線は、繰り返された安全な通行か、同じ生きた結び目へ流された失敗かもしれない。
