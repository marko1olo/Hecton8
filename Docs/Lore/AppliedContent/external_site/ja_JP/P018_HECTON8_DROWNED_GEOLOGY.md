# 沈んだ地質

沈んだ地質は、任意の門ではなく地形、塩水、熱、圧力で再プレイ性を作る。

## Scanner

棚、峡谷、塩水階段、噴出口。月はレベルゲートではなく地形で降下を教える。

## Terminal

深度予測: 棚崩落、峡谷流路、塩水密度幕、熱プルーム、深淵シルト。

## Audio

スーツに勝たせる前に岩を読め。

## Field Note

最も安全な道は通路ではなく読解だ。
