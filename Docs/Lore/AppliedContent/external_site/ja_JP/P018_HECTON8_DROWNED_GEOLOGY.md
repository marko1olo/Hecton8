# 水没地質

水没地質は安全経路を期限付きにする。嵐、シルト漂流、塩水移動、サルベージ損傷が昨日の道を罠に変える。

## Scanner

層状棚、峡谷漏斗、塩水階段、噴出口痕、シルト露出を検出。地形は背景ではなく圧力経路だ。

## Terminal

深度予測: 棚崩落、サービス峡谷の集中流、塩水密度カーテン、熱プルーム、深海シルト露出。嵐の増水またはサルベージ切断後、経路信頼度は低下。

## Audio

スーツに勝たせる前に岩を読め。

## Field Note

最も安全な道は通路ではなく読み取りだ。
