# packet notaryマスクの縁

HECTON-8では、packet notaryの印は損傷記録を使えるままにしつつ、すべてを一度に明かさないためにある。notaryマスクは正当な場合がある。名前、ルート座標、payloadシリアル、隔離表の行を隠すことがある。問題は行が隠されることではない。隠された行が損傷物と同じ層に属さなくなった時が問題だ。

その答えはマスクの縁に残る。黒塗り顔料が塩の下にあり、媒体と同じ傷底を共有するなら、マスクはソースと一緒に移動した可能性がある。顔料が塩の上に乗り、傷をまたぎ、対応する機械損傷を読めるままroute stampだけを切るなら、媒体が傷ついた後で文書が扱われた。黒塗りは所有者のいる遅い操作になる。

この証拠は転写損傷帯、ハイドロフォンログ帯、レコーダーベイのカセットと並べて読む。損傷帯は読める文章が何を欠落と認めるかを示す。ログ帯は部屋が水と金属越しに録ったものを示す。カセット歯は媒体の動きを示す。notaryマスクの縁は、公開記録を物よりきれいに見せようとした相手を示す。

公開文では、合法的な省略と呼べる。現場ではMarauderが縁を先に読む。顔料の下の塩と、塩の上の顔料は同じ順序ではない。部屋に属せる順序は一つだけだ。
