# ロッカー証拠バリエーション

HECTON-8ではロッカーは郷愁の箱ではなく証拠面だ。圧力テープ、摩耗したガスケット片、工具庫トークン、食事クレジット、経路チョーク、勤務ステッカー、medlock却下票、後日のMarauder修正メモが入る。単独の物が事故全体を説明する必要はない。組み合わさることで、沈んだコロニーが廃墟になる前に習慣を持つ職場だったと分かる。

重要なのは抑制だ。ロッカーは悲しめと命令しない。限られた空気と濡れた手で何をしたかを示す。漏れを塞ぐ、ガスケットを借りる、経路を記す、医療拒否票を隠す、食事クレジットを残す、次の班が終えるはずの工具を汚れたまま置く。これで手続き生成の部屋にも人間の質感が残る。

回収には意味がある。小物は資源になるが、配置は証言になる。よいMarauderは取る前に記録する。雑な者は人間を部品の山に変える。
