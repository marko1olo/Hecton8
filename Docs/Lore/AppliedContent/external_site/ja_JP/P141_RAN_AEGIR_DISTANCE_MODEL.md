# Ran-Aegir距離モデル

Ran-Aegir距離モデルは、HECTON-8の圧力の静かな土台である。Aegirは残酷な中間距離にある。航路プレート、seed機材、貨物担保、遠隔公証人、恒久的な採掘植民地を企業が正当化できるほど近い。しかし圧力扉が壊れた瞬間に、誰かが即席の慈悲を送れるほど近くはない。

重要なのはその差だ。メッセージ、法的請求、輸送予定、救助船、人間の身体は同じ時計を持たない。警告は進むが、答えるべき船は燃料、窓、質量、所有者承認に閉じ込められている。Deep Reachはその隙間の使い方を学んだ。植民地はその隙間の中で暮らした。
