# ケーブルジャケット補修巻き現地記事

ケーブルジャケット補修巻きは、HECTON-8で強い小規模証拠面になる。材料は普通だが圧力は普通ではない。防水ゴム、灰色テープ、露出繊維、塩の継ぎ目、クランプ痕、濡れた傷が読む対象になる。

ゲームでは、一つの巻き帯が迂回、酸素経路、リレー、狭い通路、危険へ導く。重ね口の塩、磨かれたクランプ痕、ハッチ近くの巻き間隔変化、無人のはずの廊下の新しいテープが手がかりだ。

この巻きは人間の保守とAtlas修復生態を分ける。生きた膜は後から来る。テープは最初の妥協を記録している。
