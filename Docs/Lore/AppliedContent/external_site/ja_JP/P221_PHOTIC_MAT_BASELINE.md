# 有光マット基準

有光マット基準は、HECTON-8の美しさを実用的な規則へ変える。マットは背景ではない。初期シェルフを読めるようにする生きた計器だ。色は酸素交換、縁の硬さは圧力化学、泡のリズムは水の動き、音響の手触りは隠れた継ぎ目を示す。だから最初の明るい岩は、魅力的であると同時に疑わしく感じるべきだ。取り残されたMarauderは、マットの縁から繊維、シール材前駆体、非常用酸素読みを得られる。しかし切るたびにポケットは変わる。最も安全なのは、金属、ハッチ継ぎ目、古いDeep Reach配管から離れた浮いた縁を採ることだ。最悪なのは美しい中心を削ること。そこがたいてい一番働いているからだ。良い配置は説明なしで教える。健康なマットは清潔な石に光る。ストレスを受けたマットは圧力漏れの周りに白い塩縁を作る。毒されたマットは滑らかすぎ、工具の下で音が間違っている。浅いシェルフが明るいのは生命が働いているからだ。緊張しているのは、欲張った一削りでその働きを壊せるからだ。
