# ハッシュベルト軌道沈黙図

HECTON-8は軌道が意味を持つほど近く、救助が失敗するほど遠い。Black Keelが頭上を通過しても、下のマローダーには使える通信路がない。ハッシュベルトはその矛盾に付いた名前だ。Aegirの磁気天候、Kestrelの掩蔽、導電性の海洋化学、Deep Reachのリレー保管権が重なる。

最初に死ぬのは無線だ。レーザーには嵐、噴出氷、眩光を抜ける清潔な見通し線が要る。音響テレメトリは生き残るが、遅く、細く、所有されている。有用なパケットはすべてブイ、バッファ、受領を通って上がる。残るのは冷たい現実だ。沈黙は誰もいないという意味ではない。システムが設計通りに動いているという意味だ。
