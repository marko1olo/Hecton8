# サルベージ切断断面フィールド記事

サルベージ切断断面は、耐圧パネルや漂着した外板、古いコロニー壁を工具で開いたあとに残る縁である。失われた部品より、露出した層の方が多くを語る。

ゲーム内では、この縁が進入口を示し、まだ生きている系統を警告し、遅い人間の帰還を証明する。塩の上の焼け跡は浸水後の切断を示す。白く崩れた断熱材は壁内の水を示す。きれいに断たれたケーブルは急ぎか意図的な遮断を示す。

Marauder は切断を読む。同じ縁に危険、経路、所有の証拠が並んでいるからだ。
