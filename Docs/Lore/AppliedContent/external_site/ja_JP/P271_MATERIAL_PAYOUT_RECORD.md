# 物資支払い記録

この支払い記録で読むべきものは受領書の欄だ。受領者が買ったもの、欠けているもの、受理された座標、出た試料、変わった先取特権、欠けた名前、Deep Reachが得た戻り道である。

## Scanner

物資支払い記録 // Keelmark/Recovery Complianceが盆地座標とブルーデット試料を受理。作業者証拠は公証保管外に残り、オペレーター先取特権は減額。

## Terminal

エンディング記録 / 物資支払い
受領者: Keelmark/Recovery Compliance。
受理: Atlas盆地座標、ブルーデット試料、輸送体保管ハッシュ。
未添付: 公証済み証人パケット、作業者名簿、救助質量監査。
先取特権への効果: 契約表により減額または閉鎖。
Deep Reachへの効果: HECTON-8への戻り道がよりきれいになる。
既知の損失: 証拠は聞かれないまま値付けされる。

## Audio

台帳は墓の地図に支払った。部屋は開けていない。

## Field Note

受領書が消すのは先取特権の欄であって、部屋ではない。保管に入らなかった名前は、支払い後も欠けたままだ。
