# コンプレッサー引き渡しの後追い記入

コンプレッサーは、きれいな嘘を隠すには不向きな場所だ。小さな故障が多すぎる。途中で止まったリレー、半分だけ汚れたカウンター数字、部屋側だけに塩を抱いた弁の縁、机が異常を知る前に塩水を受けたドレンカップ。

だから引き渡し行は重要になる。Deep Reachの手順では、部屋の支援負荷をローカル生命維持から広い勘定へ渡すことができた。その行は役に立った。route、maintenance、claim deskに、空気の費用がどこへ行ったかを知らせた。同時に、部屋が仕事をやめた後も書き続ける場所になった。

後追い記入に大きな偽造は要らない。切れ目を滑らかにする遅い一行だけで足りる。compressor accepted、handoff pending、support load carried、route still active。ポンプカウンターの隣で読むと、その語句は安心を失う。機械はばらばらに止まった。行だけが一つのきれいな塊で来た。

この記事は最後の机の所有者を名指ししない。プレイヤーにもう一つの硬い継ぎ目を渡す。ポンプ、リレー、弁、台帳。その継ぎ目がclaim holdより先に壊れていれば、開いたルートを運んだのは圧力ではなく書類だ。
