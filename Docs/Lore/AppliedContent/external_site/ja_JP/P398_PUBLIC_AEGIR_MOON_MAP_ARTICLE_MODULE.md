# Aegir衛星経路図

Aegir衛星図は運用板として読むべきだ。各ラベルは信号年齢、放射線避難、転送リスク、降下天候、回収幾何、法的保管時刻を変え得る。HECTON-8はその動くラダーの内側にある。内側の天体は狭帯域通信を乱し、氷衛星は光経路を破片化し、掩蔽帯は無音窓を作り、古いビーコンは乗員消失後も所有印を保持する。公開資料はプレイ可能な衛星を約束せずに星系を示せる。役に立つ約束はもっと狭く強い。水から見上げた時、空は中継がつまずいた理由、キャリアが降下質量を拒んだ理由、有効な請求が暗闇で待った理由を説明できる。

## Scanner

星系図記録。衛星ラベルは中継年齢、潮汐負荷、放射線遮蔽、氷散乱、掩蔽帯、死んだビーコン、回収幾何を設定する。
