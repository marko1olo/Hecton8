# 最終問い: 公開台帳、失われた制御

公開台帳の解放が効くのは、最初のスタンプが小さく、取り消しにくいからだ。Tau/Luyten公証バーストは完全な救助案件を運ばない。証人ハッシュ、責任連鎖、Atlas状態要約、座標墨消し、ペイロード経路証明を十分に運び、Deep Reachに悪い位置から回答させる。古い公開報告はまだ反撃できるが、唯一のファイルをもう所有していない。
