# Aegir リレー窓

## 記録が証明するもの

リレー窓は救助ではない。天候、月影、磁気ノイズ、carrier 配置、リレー待ち列、隔離、質量割当が汚く重なった一瞬だ。

Aegir はパケットだけを上げ、作業者を水中に残せる。リレー窓は天候、磁気、待ち列、Black Keel carrier 位置、法的許可の一時的な幾何だ。メッセージが HECTON-8 を出られる証拠にはなるが、同じ穴から身体が上がれる証拠にはならない。

AEGIR リレー通知 // 連絡は救助より先に通ることがある。パケット経路、時刻印、アンテナ状態、嵐プルーム値、carrier レーン、保管封印を保存せよ。窓の受理は酸素、揚収質量、作業者回収を割り当てない。

受信 ping は救助船ではない。窓を記録し、経路を残し、切断を続ける。 これは証拠を扱うための規則であり、救助がもう動いているという約束ではない。
