# 岸すくい

Aegirのシェルフ班は、HECTON-8で上層八メートルに留まり、風で寄せられたうねりに沿って切れ目のない線を作って採餌する高速の表層採餌種を報告している。この線は表層酸素が低下した水を避けて途切れるため、切れ目が離れた位置からでも読める。

現場では群れではなく途切れを読み、線の切れ目は開けた水ではなく呼吸できない水として扱う。セクター44のDeep Reach記録はこの種を表層状態指示体に分類し、これが代替したシェルフ・ブイ業務が2146年に停止されたことを記載している。
