# ガラス虫、幼体

HECTON-8のサルベージ報告は、コロニー構造の亀裂に微量級の導通基材を直接積層する群体性の管形成幼体を記述している。成長密度は亀裂を通る流量に追従する。管の口は一貫して流入方向を向いており、群落の外側から漏れの軸を読み取ることができる。

この種の成長は圧力漏れを取り除くのではなく覆い隠す。作業班は、活性がないように見えた群落でグローブとシールの損傷が起きたこと、荷を受けている区画を切った際に管が順に破れたことを報告している。セクター44のDeep Reach記録はこの生物を有機の構造シール材に分類し、対応する圧力偏差を緩和済と記載し、成体についての参照は残していない。
