# 質量保管トン窓台帳

HECTON-8は慈悲を荷重計算に変える。魔法の救助がない世界だからだ。Black Keelはclaimを聞き、packetを受け取り、それでも次の揚収窓が正しいcustodyで正しい質量を運べるまで身体回収を拒む。

残酷なのは計算が偽物だからではない。計算が第一言語として許されていることだ。生存者は身体質量になる。酸素は福祉債務になる。試料は封印custodyになる。ブラックボックスは証拠payloadになる。隔離は体積になる。receiver rightsはliabilityになる。carrierはそれらが大事かどうかを決めない。一緒に動かせるかを決める。

これでloreは遊べるまま残る。証拠を守る、汚染を捨てる、ハードウェアを認証する、酸素を使う、試料を残す、公開hashを出す、脱出できる身体余白を守る。どれも台帳を押す。プレイヤーは抽象物を拾っていない。何が回収可能として数えられるかを争っている。
