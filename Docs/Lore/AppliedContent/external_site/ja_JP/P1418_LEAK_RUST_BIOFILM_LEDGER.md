# 漏水・錆・生膜の時系列台帳

良い漏水痕は最初から劇的ではない。ただの汚れに見える。だからHECTON-8に合う。真実はきれいな標識ではなく、水が残り、ボルトが汗をかき、封止が呼吸し、作業者が拭く時間を失った場所に残る。

大事なのは色ではなく、どの層が上にあるかだ。塩の下の錆は古い濡れた継ぎ目を示す。塩の上の油は後日の機械漏れだ。塗装上の生膜は表面が長く湿り、栄養を受けた証拠になる。汚れの中のきれいな筋は、遅い拭き取り、剥がされたラベル、または工具の跡かもしれない。

この素材は経路、危険な封止、公式停止後に動いた部屋、保存すべき証拠を同時に持てる。海は一度で正直に来たのではない。壁はそれを知っている。
