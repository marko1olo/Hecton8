# 静かな軌道の受領台帳

Black KeelはHECTON-8上空で待つ母船ではない。Aegir系の請求テンダーであり、軌道を保ち、回収を値付けし、マニフェストを検証し、Aegir Reclamation Poolの損失を抑える装置だ。上層海の下では通常の無線は役に立たない。水は塩、金属、産業粉塵を含み、データは低周波の音響パルスとして少しずつ押し出される。

この制約がHECTON-8の孤立を作る。SolからFTL返答は来ない。浸水モジュールからプレイヤーを導くansibleの声もない。局地軌道でさえ嵐、月の幾何、Kestrelの中継影に切られる。Black Keelは台帳上の保管義務でパケットを確認し、上昇質量、隔離状態、ペイロード価値が契約に合うまで抽出を止めることがある。

## Scanner

音響受領 // パケットを312 bpsで受理。船殻質量、酸素リース、請求ハッシュ、サルベージ検査値を受信。抽出ベクトルなし。

## Terminal

BLACK KEEL軌道受領 BKH8-RC-2190-0041 // アップリンク種別: 音響。送信者: 債務拘束契約者。内容: マニフェスト予告、圧力テレメトリ、スーツ残存推定。状態: 受領、エスクロー済み、未回収。Kestrel影窓は11時間40分後に閉鎖。回収には認証済み上昇質量、隔離ハンドシェイク、支払い対象請求物が必要。

## Audio

受領記録。マニフェスト確認。抽出ベクトル保留。質量、シール証明、より清浄な検査値を送れ。

## Field Note

受領は救助ではない。Keelがパケットに請求できるという意味だ。帰り道を請求できるまで息を残せ。
