# 提灯ふるい

HECTON-8のケーブル礁からの報告は、入射したソナーを再放射する群体性の生物発光ろ過摂食種を記述している。作業班は一発の音に対して二つの反射を一貫して記録しており、二つ目はおよそ0.2秒遅れ、真方位からずれ、距離から予測される値より振幅が大きい。

解剖報告は、各個体の鰓かごに高密度の鉱物異物が一つあり、生物由来の鉱化ではなく微量級の導通基材に一致すると記載している。セクター44のDeep Reach記録はこの種を育成音響中継器の在庫項目として扱い、個体が自己交換するという理由で整備間隔を記載していない。
