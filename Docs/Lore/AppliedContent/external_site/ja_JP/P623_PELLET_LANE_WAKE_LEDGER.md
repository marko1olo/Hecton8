# ペレットレーン航跡台帳

ペレットレーンは道路ではない。船が到着する何年も前にインフラが交わす約束である。発射アレイ、デポ、航路ステーションが予測経路に反応ペレットの流れを投げる。貨物船はその流れを捕まえ、核融合パルスに食わせ、遮蔽の後ろを走り、何年も巡航し、Aegirに着く前に所有者が変わっているかもしれない制動設備に頼る。その機械は層ごとに航路を作った。最初にneedleprobe、次にseed機械、その後に重貨物、スリーパー契約、システムキャリア、Black Keelのような現地テンダーだ。同じ仕組みが現在の残酷さも説明する。メッセージは、有用な質量がそれに従うより早く航路を渡れる。救助要請は新しくても、船、推進材、制動枠、検疫寝台、生存者席は事故が起こる前に買われた予定表に属している。2190年には、ドライブプレートは冒険よりも法的な瘢痕組織として読まれる。マローダーは孔食した航跡台帳を一枚スキャンするだけで、十光年へ金属を投げる金を誰が持ち、その停止費用を誰に払わせるつもりだったかを読める。
