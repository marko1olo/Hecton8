# 塩水峡谷ルート梯子

塩水峡谷は深度進行を物理にする。高密度層、鉱物壁、熱漏れ、音響歪みが、深い移動には良い計器と圧力規律が必要だと教える。

塩水峡谷ルート梯子はHECTON-8の中核探索構造だ。廊下ではなく、密度、流れ、音が進行を作る化学地形である。 峡谷を泳いで抜けるのではない。スーツより重い層と交渉する。
