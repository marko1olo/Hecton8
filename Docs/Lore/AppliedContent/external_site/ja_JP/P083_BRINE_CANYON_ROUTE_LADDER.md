# 塩水峡谷ルート梯子

塩水峡谷は深度を物質に変える。濃い塩の川が床、鏡、罠のように海中に横たわる。安全な経路は勇気ではなく、密度マーカー、バラスト窓、中継確認、角度の規律で作られる。深層は計器の重要さを教える。ソナーは上の空間を反射し、浮力は嘘をつき、スーツが正しくても海が反対することがある。

塩水峡谷ルート梯子は、HECTON-8の降下を化学地理として描く。密度、流れ、鉱物壁、音が生存可能な道を決める。 峡谷を泳ぎ抜けるのではない。スーツより重い層と交渉する。
