# 圧力室レコーダーベイ

圧力室レコーダーベイは、HECTON-8で音を雰囲気から証拠へ変える場所だ。

        滑らかなblack-boxでも、都合よく置かれたホラー用レコーダーでもない。古いコロニーの壁付け受け台である。セラミックカセットスロット、ハイドロフォン受音盤、インク車、ラッチガラス、整備封印、時刻ラダー、そして清潔すぎる音声ファイルを疑わせるだけの塩を含んだ金属。悪いシールが端末の確認待ちより先に一勤務を殺すような部屋のために作られた。

        だからこのベイは重要だ。プレイヤーに物理的な真実の源を渡す。回収された音は美しくも、怖くも、ほとんど読めなくもなるが、それが部屋のものかどうかを決めるのはベイだ。カセット歯はストリップの引き抜き方向と同じ向きに摩耗しているか。インク車はエアロック衝撃の前に乾いたのか、後に乾いたのか。割れたカバーはtranscriptの損傷帯と合うか。封印は外から破られたのか、それとも閉じ込められた作業員が震える手で開けたのか。

        うまく使えば、この物体は講義ではなく観察でロアを届ける。プレイヤーは理解する前にベイを見つける。後で、車輪の引きずり、欠けた秒、新しい傷が古い塩を横切る場所、二度開けられたベイ、そんな音を出したはずのない部屋に移されたカセットを読むようになる。機械に限界があるから物語は強くなる。コロニー全体を説明することはできない。ただ一つの部屋が報告書ほど嘘をつかなかったと証明できるだけだ。
