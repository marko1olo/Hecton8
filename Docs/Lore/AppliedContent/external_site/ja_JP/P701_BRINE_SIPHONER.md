# 塩水吸い

HECTON-8の工業シェルフで作業するサルベージ班は、密度境界に定位し、層を泳ぐのではなく一対のサイフォンで水を引く短躯の浸透圧摂食種を報告している。コロニーは人工の境界に集中し、とくに裂けた冷却配管と、故障したポンプを通してなお流れのある取水格子に多い。

現場ではこの動物を測定器として扱う。格子沿いの個体密度は、その背後の破口の大きさに追従する。セクター44のDeep Reach記録はこの種を契約外の漏水検知業務に分類し、対応するセンサー交換項目を校正ドリフトとして終了させている。
