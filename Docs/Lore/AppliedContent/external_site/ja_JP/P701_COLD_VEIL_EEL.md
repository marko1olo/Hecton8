# 冷幕ウナギ

HECTON-8の加圧基地機械区、深度1,900メートルで作業する班は、スクラバー排出のプルーム内に定位する板状形態の冷水性ウナギを報告している。この種はランプの距離では裂けた制振マットと誤認されることが多く、確実な識別点は縁の挙動である。自由なマットは流れに従うが、この動物は片縁を流れに対して固定する。

接触による損傷は機械的ではなく熱的で、スーツの急速な熱損失とシールの硬化が報告されている。セクター44のDeep Reach記録はこの種を計画外の温度計測器として扱い、埋め込まれたタグを送信中として記録している。当該ベイの周期は2147年以降、人員なしで維持されている。
