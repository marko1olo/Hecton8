# 天然硫化塩スタック

天然硫化塩スタックは、HECTON-8の沈んだ地質を読むための基礎資源記事である。これはAtlas汚染でも、Deep Reachの廃棄物でも、Xenon-Omegaの始まりでもない。もっと古い層だ。硫化塩、金属イオン、塩水クラストが、圧力、熱、時間によって組み上げられている。現場では発光する負債素材ほど派手ではないが、最初の修理を成立させるのはこの地味な物質だ。スタックは酸化した接点を洗い、非常用セル化学を動かし、セラミックの融点を下げる。その一方で、清潔な手袋を一分もかからず酸の問題に変える。だからこの資源の有用さは、HECTON-8らしい。実用的で、危険で、無関心だ。Deep Reachは月の金属への食欲を発明したのではない。請求書に変える方法を覚えただけだ。良い配置は、大きな恐怖が来る前にそれをプレイヤーへ教える。壁はすでに反応性を持つ。塩水はすでに圧力を覚えている。サルベージは、呼吸を助ける世界の欠片と、命を守る装備を食い破る欠片を見分けることから始まる。
