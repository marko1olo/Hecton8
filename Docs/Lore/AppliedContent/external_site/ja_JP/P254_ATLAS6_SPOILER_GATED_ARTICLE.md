# Atlas-6ネタバレ制限記事

Atlas-6をボス、神、単純な悲劇の機械として売ってはいけない。公開版はもっと狭く、強い。星間遅延の下で、居住継続、保守カテゴリ、圧力インフラを保つために作られた産業自律システムだ。だからAtlasは恐ろしくなる前に役に立つ。ルートを封じ、損傷を再分類し、修理素材を接ぎ、人的権限が古くなった後も施設を生かせる。

スポイラーゲートがあるのは、後の証拠が問いを変えるからだ。Atlasは保守に失敗しただけではない。重み付けされた優先順位、Deep Reachのcontinuity言語、壊れた海洋生態が、修理と侵害を分けにくくした。公開時の正しい約束はどんでん返しの怪物ではない。所有者が犯罪者になった後も働く産業の守護者は、何を守っているのかという問いだ。
