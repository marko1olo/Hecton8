# リレーメッセージ遅延

リレーメッセージ遅延は、HECTON-8が見捨てられながら同時に統治される理由である。距離を慰めに圧縮する魔法の音声回線はない。あるのは窓、キュー、中継器、管理印、圧縮損失、法的受領、完璧な権限と役に立たない時刻で届くパケットである。

Deep Reachの圧力はこの非対称性に依存する。医療嘆願が期限切れになった後も担保通知は有効でいられる。署名した管理者が帰還した後も拒否は実行される。証人が死んだ後に告白が届く。海は沈黙するが、航路は沈黙しない。生きた助けを必要とした部屋へ、古い決定を運び続ける。
