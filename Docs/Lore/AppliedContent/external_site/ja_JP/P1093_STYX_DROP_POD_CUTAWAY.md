# Styx降下ポッド断面

> **出典:** *Black Keel*降下作戦マニュアル、付録D-44「契約作業員Bathy-Drop配送」。
> **話者:** 降下管制官 Marek Ibarra、復元訓練記録。
> **査読注:** 公開可能な断面解説。本稿はポッド構造のみを扱い、非公開のclaim-window鍵、上昇チャージ署名、保険償却しきい値は含まない。

## 1. シャトルではない

Styxポッドはシャトルでも救命艇でもエレベーターでも救助カプセルでもない。これは使い捨てのBathy-Drop殻であり、Class-IVスーツを着た作業員一人を*Black Keel*からHECTON-8上の合法作業地点まで、保険会社が認める最小質量で運ぶために作られている。

古いマニュアルでは「契約作業員用大気・海洋配送ユニット」と呼ばれる。Marauderたちは棺、釘、落下殻、最初の悪い契約と呼ぶ。どちらも正しい。ポッドは狭い耐圧円筒で、アブレータ、バラスト、音響機器、衝撃フォーム、天候との議論に負ける程度の誘導電子機器に包まれている。操縦席はない。窓もない。作業員はClass-IVスーツのクレードルに固定され、人体なら海に触れる前に死ぬ旅程をポッドが処理する。

Deep ReachはStyxを快適さのために設計していない。原型は、Aegirの嵐帯を通して自律採掘ヘッドを撃ち込むためのドリル投下バスだった。コロニー喪失後、救助よりもclaim回収が安くなると、そのドリルバスは生体貨物用に再認証された。認証書には「安全」とは書かれなかった。「契約パラメータ内で生存可能」と書かれた。

Keelmarkの保険数理表は、天候、ポッド年齢、スーツシール、作業員バイオメトリクスがすべて緑域にある場合、88.4パーセントの生存配送率を示す。同じ表は失敗したdropを乗客死亡ではなく配送損失として分類する。これがStyxの最初の教えだ。HECTON-8では、圧力より先に言葉が殺す。

## 2. 降下プロファイル

発射は静かに始まる。ポッドは*Black Keel*の回転クレードルに固定されている。最終確認は人間が読むより速く流れる。スーツロック、脊椎フォーム、ヘルメット供給、スクラバー予備、バラスト弁、uplinkマスト、音響pinger、claim hash、衝撃時計。管制官は準備ができたかを尋ねない。契約がもう答えている。

そしてクレードルが投げる。

ポッドは磁気補助のデオービット軌道でcarrierを離れ、鈍い端を前にして進む。最初の重い抗力を作業員が感じる前に、アブレータは熱を持つ。HECTON-8上層大気は清潔な青い殻ではない。嵐の霞、帯電した塵、ヨウ素茶色の雲、そしてAegirの磁気天候に向けて海が押し上げる静電気だ。Styxはそこを明るい傷のように通過する。アブレータは層ごとに沸き飛ぶ。耐圧フレームが鳴る。緩んだネジはすべて鐘になる。

この段階の誘導は意図的に愚鈍だ。ポッドは優雅な経路を飛ばない。優雅さには燃料と可動部品が要る。ポッドは回廊を受け入れ、乱流を焼き抜け、衝突楕円が保険対象の棚から外れる時だけ修正し、その他の苦痛はすべて作業員の問題として処理する。豪華な降下なら人間を守る。Styx降下はclaimを守る。

水面衝突は第二の発射である。HECTON-8の表面は濃く、冷たく、動いている。ポッドは終端速度で衝突し、鼻部の犠牲衝撃スカートを展開する。スカートが壊れ、アブレータが割れ、フォームクレードルがスーツの周囲で潰れ、ポッドが跳ねる前にバラスト系が浸水する。きれいな衝突なら、作業員は脳震とうを起こし、生きて、沈んでいく。悪い衝突なら、耐圧円筒は横を向き、uplinkマストはせん断され、物語は警報で始まる。

水面下の最初の数分は、機械がもっとも正直な時間だ。ポッドは嘘をつくにはうるさすぎる。冷却する殻がフレーム内で刻む。バラスト弁が咳をする。水が外殻を叩く。pingerは*Black Keel*への遅い音響呼び出しを開始する。作業員あり、殻降下中、claim開放。

## 3. 搭載されるもの

完全なStyxには、衝突後に重要になる五つの系統がある。

耐圧フレームは有用な部分だ。リブ付きチタンカーバイド円筒であり、ポッドが乗り物でなくなった後も、人間一人分の空気だまりを保持できる。フレームが生き残れば、墜落地点は避難所、工具ロッカー、メッセージ端末、証拠物になる。

アブレータは罪の部分だ。新しいポッドは清潔な耐熱層を持つ。再使用ポッドは補修樹脂、不揃いのタイル、焦げた履歴を持つ。Marauderはその痕を読む。整備は書類ほど上手に嘘をつけないからだ。アブレータの不均等な損耗は、計画回廊外の嵐剪断を通った可能性を示す。マスト周囲の樹脂は、過去の回収失敗を示すことが多い。

音響スタックは社会的な部分だ。HECTON-8の水中では無線が早く死ぬ。ポッドは低周波パルス、ライン張力、圧縮パケットで話す。uplinkマストが無事なら、窓が合った時に*Black Keel*と短い状態を交換できる。マストが割れていれば、すべてのメッセージは遅れ、欠け、あるいは怪しいほどきれいに届く。

生存バスは残酷な部分だ。ランプを点け、スーツクレードルを温め、手工具を少し充電し、スクラバーをパージし、小型端末を生かすことはできる。基地は動かせない。ダイバーを家まで牽引できない。破壊された上昇パッケージを奇跡に変えられない。

回収インターフェースは最も誤解される部分だ。契約者向けコピーでは時にascent packageと呼ばれる。寛大すぎる呼び方だ。実体はウインチ機器、ブイライン、緊急チャージアダプタ、carrier側認証のためのキー付きスリーブである。無事で、軌道が同意すれば、何かが海を離れる助けにはなる。船のエンジンではない。許可、幾何、そして正しいフックを受け入れるかもしれない金属の喉だ。

## 4. なぜ殻は部屋になるのか

HECTON-8最初のプレイ可能な部屋は、約束をほとんど果たした機械のように感じられるべきだ。ポッドは作業員を下ろした。圧力を保った。考えるだけの空気を残した。そして高価な部分が壊れた。

その故障が重要なのは、生存を物理的にするからだ。プレイヤーは記憶喪失、運命、施錠された扉で閉じ込められているのではない。具体的な連鎖が壊れたから閉じ込められている。耐熱タイル予備消費、relayマストせん断、ascent sleeve損傷、コンプレッサ浸水、誘導バス破断、claim handshake回収しきい値未満。各故障は読める物体になれる。各物体は任務、疑い、後の嘘になれる。

ポッドは抽象的なlootに分解されるべきではない。損傷した証人としての方が価値が高い。焦げ模様は大気が何をしたかを語る。バラスト砂はどの棚が落下を受け止めたかを語る。潰れたフォームは衝突の強さを語る。端末はcarrierがまだ何を欲しがるかを語る。壊れた上昇ハードは、海がすでに何を奪ったかを語る。

良いHECTON-8 loreは、罠を上から説明しない。プレイヤーに罠へ触れさせ、自分で結論を出させる。

## 5. 故障の言葉

Styxの故障は、マニュアルの言葉ではめったに劇的に見えない。マニュアルは小さな語句を好む。

**Gimbal lock** は衝突ベクトルが悪化し、ポッドが厳しい角度で水面を叩いたという意味だ。作業員は生きるかもしれない。マストはおそらく生きない。

**Relay mast shear** は、ポッドが音響ノイズをまだ受け取れるが、嵐の水と磁気干渉を通して清潔なuplinkを押し出せないという意味だ。これが、プレイヤーが声を得ても助けを得ない仕組みである。

**Compressor flood** は、シールが安定する前に圧力均衡系が海を飲んだという意味だ。避難所は生き、上昇連鎖は死ぬことがある。

**Heat-tile reserve local only** は、ポッドが水に到達するため最後の信頼できるアブレータ余裕を使ったという意味だ。ダイバーを守ることはできるが、二度目の大気通過は生き残れない。

**Recovery ring no-lock** は、*Black Keel*が何かの到着を見ているが、何を回収できるか認証できないという意味だ。ここで契約言語は恐怖になる。人間は生きていてもrecoverable assetではないことがある。

## 6. なぜ使い続けるのか

Styxが存在するのは、より良い方法がすべて高すぎるからだ。

有人救助シャトルには燃料、操縦士、冗長圧力系、整備時間、危険手当、そして死んだclaimで生きた乗員を危険にさらす法的命令が要る。深海対応droneは回収対象の人間より高価であり、HECTON-8の鉱物水は高度な回路を短時間で破壊する。完全な上昇機には打ち上げ質量、安定天候、明瞭な軌道幾何、そしてDeep Reachが管理下に置きたいハードウェアが必要になる。

Styxに必要なのは、使い捨ての殻一つ、必死の契約者一人、契約署名一つ、そして作業地点へ作業員を届けたと言えるcarrier一隻だけだ。

だからMarauderは乗り続ける。ポッドが安全だと信じているからではない。借金から借金取り消しの可能性へ向かう最安の道だからだ。彼らを置き去りにする同じ機械が、ledgerを変えられる距離まで彼らを運ぶ。

## 7. プレイヤー向け利用

ウェブサイトでは、Styx記事は底の真実を明かさずHECTON-8の前提を売れる。プレイヤーが孤独なのは、距離、水、契約、安い機械がすべて同意しているからだ。

ゲーム内wikiでは、項目は段階的に解放されるべきだ。最初は「降下ポッド損傷、避難所有用、上昇不能」。後に回収インターフェース、claim hash、せん断されたマスト、ascent sleeve、保険しきい値が加わる。最終的な意味は、救助と所有が別の操作だと理解できるだけのシステムをプレイヤーが修理してから来るべきだ。

環境テキストでは、ポッドは文字の機械である。シリアルプレート、警告ラベル、アブレータの傷、バラスト砂、冷たい端末行、古い整備スタンプを持てる。どれも説明文のように聞こえる必要はない。生き残った物体のように聞こえるべきだ。

Styxは冒険の始まりではない。再突入でまだ温かい、悪い取引の領収書だ。すでに何を保持するか決めている海へ沈んでいく。
