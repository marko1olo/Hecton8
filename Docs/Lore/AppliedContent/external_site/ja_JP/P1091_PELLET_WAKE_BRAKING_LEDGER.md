# ペレット航跡制動台帳

HECTON-8はプレイヤーを孤立させるための魔法の壁を必要としない。距離だけで十分だ。Aegir経路はペレットビーム探査機で開かれた。Luyten Junctionの巨大ビーム施設に押された小型自律偵察機である。探査機は撃ち出し、失い、損失処理できる。植民船はそうはいかない。

Atlas級貨物船は別物だ。工場、冷凍区画、掘削システム、封印された債務契約、それに安く署名した人間を運ぶ。核融合電気パルス機関は何年もかけて速度を作る。到着前には、その速度を失わなければならない。磁気帆は帯電粒子を相手に途方もない幅で展開する。最後の通過は大気、嵐外層、ガス巨星の縁を削る。制動台帳の小さな誤差が、貨物と乗員と請求権を消す。

だからHECTON-8の救助は、物理を破らずに冷酷に感じられる。Solは決定期限の後にパケットを受け取る。Deep Reachは船体を動かすより速く負債を所有できる。Black KeelはAegir現地軌道で回収窓に値を付けられるが、それは現地サルベージ機械であり、故郷からの約束ではない。文明はまず書類として、次に信号として、ずっと後に質量として届く。
