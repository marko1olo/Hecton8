# 鉄モロコ

HECTON-8のシェルフ調査は、体表に鉄質微粒子を持つ小型の群れ採餌種を記録している。体格に対して異常に強い音響反射と走査反射を生じる。作業班は群れの形状を環境値として使うと報告している。圧縮された水平の帯は局所的な酸素の濃集を示し、既知の鉱脈上に帯が無いことは濃集が失われたことを示す。

同じ反射は近距離で計器を飽和させ、群れの背後の構造を隠す。セクター44のDeep Reach記録はこの種を付随的な微量分析法として分類し、再調査を行わずに群れ密度の数値を請求トン数へ繰り越している。
