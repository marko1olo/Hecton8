# Black Keel接触

Black Keelは軌道へ戻る唯一の線だ。死んではいないが、忠実でもない。断片的な通信は空を生存システムに変える。各通信窓は救助要請、嘘、サンプル報告、証拠のどれかを運ぶ。

## Scanner
