# サルベージ切断断面台帳

HECTON-8で最も正直な扉は、設計されなかった扉であることが多い。崩壊後に切られたパネルには、企業の約束は残らない。残るのは熱色、裂けた断熱、ガスケット断片、壁の向こうを必要とした人間の急いだ幾何だ。

縁は外から内へ読む。塗装皮膜が向きを与える。暗い芯が支持部を示す。セラミック粉は熱の迷いを示す。歯のように裂けたゴムは、カッター後の機械力を示す。ケーブル端は意図を示す。隔離、焦り、盗み、帰還予定。

良い断面は消えた一場面を抱える。浸水後に壁を開けた、封鎖ハッチを迂回した、証拠を抜いた、閉じ込められた作業者を救った、後の略奪者の通路を作った。縁は名前を覚えないが、工具を覚える。
