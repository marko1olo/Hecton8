# 隔離保持: よどんだ空気

隔離保持は最も静かな偽の出口だ。脅しも、見える警備員も、劇的な裏切りもいらない。システムは請負者を生きて回収し、証人を封じ、空気を計り、次の一歩をすぐ終わらない審査に結びつければいい。

その残酷さは一行ずつ弁護できる。サンプルは破壊されていない。証人は処刑されていない。真実が嘘だとも言われていない。手続きはただ、すべての呼吸を条件付きにし、すべての文を死者を救えなくなるまで待たせる。
