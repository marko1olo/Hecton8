# 隔離保留：よどんだ空気

隔離保留は最も静かな偽退出である。部屋に悪役はいらない。書式は生存回収と示し、空気カウンターは配給作動中と示し、次の扉は汚染審査、claimant異議、保険損失審査の後でしか開かない。
