# バイオメタル・センサータグ

バイオメタル・センサータグは一般的な収集品ではない。修理システムが、担体が機械なのか、ケーブル成長なのか、動物なのかを気にしなくなった結果である。タグは薄いバイオメタルの鱗で、組織に生え込み、わずかな電流を吸い、動きを記録し、水中へ位置信頼度を繰り返す。Marauderはそれを使ってピンガーを調整し、スキャナー範囲を伸ばし、Atlasが触れたとき経路が生きていたことを証明できる。その有用性が問題だ。冷たく抜けば証拠になる。熱いまま抜けば、ネットワークは失われた担体に気づき、偽の戻り信号で答え、負傷した動物、切られたケルプ、タグを持つ潜水者へ修理論理を向けるかもしれない。この素材は、戦利品を事件ファイルとして扱わせる。有用で、汚れていて、まだ報告している。

## Scanner
