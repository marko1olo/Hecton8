# 塩水密度ルート台帳

Brine Stairs はルートであり罠でもある。遠くから見ると棚と白い縁が建築物のように積まれている。近づくとそれは化学の動きだ。重い塩水が割れ目の中に第二の海として溜まり、境界は光り、皮はしわを寄せ、sonar には石のように自信満々の返事をする。

だから古いルート板は「ここで降りろ」とは書かない。横から ping。二度トリム。温度低下を見る。ケーブル傷を見る。境界から上がるシルトが混ざらない場所を待つ。よい横断点は地図の線ではなく、海が一度嘘をついた後でも繰り返す挙動だ。

行方不明の避難ポッドのいくつかは、存在しない床の座標から報告された。最後の ping は第三密度カーテンの下だった。Deep Reach は navigation error と処理したが、ルート板は cable scar を残した。

ゲーム内では同じ規則が行動になる。層を利用して音を隠す、cutter を冷やす、保存されたタグを回収する、光を晒さず峡谷を渡る。悪い ping 角、古いバラスト、傷んだ seal、焦った降下はルートを穴に変える。
