# Ran Long Claim航路通過

Aegirの航路図は、どれも慰めと侮辱から始まる。慰めは、HECTON-8が人類の外側ではないことだ。2190年には、Sol、Centauri、Barnard、Tau Ceti、Luyten、そしてAegir請求事務所が、星々のあいだで人、質量、責任を動かすだけの時計、法的ひな形、パケット基盤を共有している。侮辱はその尺度だ。地図の裏に超光速救助スイッチはない。パケットは光、中継、辛抱強い誤り訂正として隙間を越える。人間は貨物として越える。熱、酸素、書類、推進剤、リスクとして。Ran Long ClaimがAegirを近く見せたのは、最初の公開図が会計係のために描かれたからだ。そこでは請求権の連続性を測っていた。人の待ち時間ではない。回収キャリアがbeam-lane引き渡しまでまだ何か月もあるのに、航路だけは認証され得た。遺体袋が月を出る前に、裁判所は死亡紛争を受理し得た。次の権限パケットがまだ梯子を這っているあいだ、保守ドローンは現地作業命令に判を押し続け得た。Black Keelはその制度の内側にいる。請求権テンダーであり、債務ロッカー、保管封印、予備の手、悪い窓だらけの時計を持つサルベージキャリアだ。応答は安いから答える。質量、法的露出、キャリア幾何がそろった時だけ動く。この違いがAegirサルベージの最初の硬い授業になる。辺境は、君を所有し、請求し、記録する程度には成熟している。だがすばやく救うほど密ではない。HECTON-8のMarauderにとって、Ran Long Claimは帰路というより、帰る場所にも列があり、その列がすでに君のトン数を知っている証拠だ。
