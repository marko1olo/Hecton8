# Ran Long Claim航行

Ran Long Claimは実務上の矛盾の公開名だ。人類文明はAegirへ到達できる。probe、段階貨物、packet custody、claim tenderを送れる。だが stranded Marauderが頼めばすぐ吊り上げられるという意味ではない。

航路は層でできている。情報は軽く法的に有用だから、パケットが先に動く。燃料デポ、receiver予備、検疫slotは遅い。重貨物はさらに遅く、制動費、payload所有、回収リスクの契約に包まれる。

プレートは誰も聞いていないとは言わない。聞くことが救助で一番安いと言う。Black Keelはdistress hashを受け、仮tonne-windowを予約し、それでも質量、検疫、claimant優先が争う間プレイヤーを水中に残せる。
