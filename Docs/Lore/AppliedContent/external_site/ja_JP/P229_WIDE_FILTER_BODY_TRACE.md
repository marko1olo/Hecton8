# 広域濾過体の痕跡

広域濾過体の痕跡は、HECTON-8 が巨大生物を演出されたボス登場にせず扱う方法である。広域濾過体は動く生態系だ。深淵の中の生きた気象前線であり、プランクトン雲を食み、視界の通路を開き、ソナーを歪め、放棄されたコロニー機材の形を一時的に露出させる。プレイヤーが尺度を感じるのは、カメラが怪物を見せるために止まるからではなく、航行の規則そのものが変わるからでなければならない。

体の下では音の硬い輪郭が失われる。縁ではエコーが折り重なる。背後では海が不自然なほど澄み、空白だった地図に古いレール、配管の肋骨、整備塔が現れる。その有用性こそ罠だ。ルートを露出させる同じ航跡が、荷を背負った Marauder を壁も床も確かな帰還ラインもない開けた深海へ引き込む。生物は無関心なままだ。悪でもなく、飼いならされてもおらず、プレイヤーを待ってもいない。通過を待ち、プランクトンの隙間を読み、遺構を記録し、シルトが戻る前に離れる。生存知識には忍耐も含まれると、海が証明している。
