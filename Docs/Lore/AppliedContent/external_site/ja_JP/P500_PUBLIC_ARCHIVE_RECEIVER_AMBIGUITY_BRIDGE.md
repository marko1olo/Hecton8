# 公開アーカイブの受取人競合

## 記録が示すこと

この種のパケットでいう受取人は、一人の人物ではない。各引き渡しで写し直されるフィールドだ。HECTON-8のアーカイブパケット一つに、Deep Reach Claims宛ての元住所帯、Atlasの中継スタンプ、浅層付属区の検疫保留、Keelmark請求デスク番号、公開アーカイブの登録行が同時に載ることがある。そのどれか一つだけでは、誰が証拠を保持したか、誰が改変したか、誰が可視化に金を払ったかは証明できない。公開ミラーで整った受取人名は、郵便に返答を許された事務所であることが多い。パケットが物理的に通った場所とは限らない。

受取人の競合は経路の問題として読む。封印の順序、ハッシュ時刻、スリーブの水線、トレイの工具痕、アップロード時にまだ電力を持っていた事務所を確認する。住所帯が一つの事務所を示し、中継受領票が別の事務所を示しても、物理的な保管痕が順序を破るまでは偽造と決めない。公開フィールドがきれいだからといって誰かを潔白にもしない。有用な証拠は、事務所名と取り扱いが残した痕の間にある。

## 読み方

公開アーカイブ受取人競合
受取人フィールドを一つにまとめるな。
住所帯 = 想定宛先。
中継受領票 = 通過。
検疫保留 = 管制。
請求デスク = 支払いと法務応答。
アーカイブ登録行 = 公開所有者。
処置: 物理的な保管順序がパケットハッシュと一致するまで最終受取人を伏せる。

## フィールドノート

便箋ではなく濡れた痕から始める。事務所はパケット名を変えられる。トレイの錆線は動かせない。
