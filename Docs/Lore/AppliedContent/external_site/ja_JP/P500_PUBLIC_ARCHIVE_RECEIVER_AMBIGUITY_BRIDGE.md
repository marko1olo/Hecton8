# 公開アーカイブ受信者曖昧性

## 証明すること

一つのHECTON-8パケットに二つの受信者名があっても、それだけで偽造とは限らない。公開アーカイブでは、元の宛名帯、最初の中継ノード、隔離オフィス、請求者デスク、法務アーカイブを別の証拠レーンとして扱う。レーンは食い違い得るし、その食い違いは無害とは限らない。最もきれいなラベルを真実と読むのが危険だ。Deep Reachは公開向け受信者を狭く保ち、有用な保管経路を別へ動かすことがある。Atlas由来の断片では逆に、中継受領が所有に見えても単なる通過証明でしかない場合がある。

## 読み方

公開アーカイブ受信者曖昧性
宛名、中継、隔離、請求者、保管欄を一人の所有者へ潰すな。
公開要約は返答を許された部署を示すだけかもしれない。保管経路は実際にパケットを保持した部署を示す。
最終受信者は経路証拠まで保留。

## 現場メモ

受信者欄は礼儀正しい。保管痕は物理だ。ラベルが笑い、経路が血を流すなら、経路を追え。
