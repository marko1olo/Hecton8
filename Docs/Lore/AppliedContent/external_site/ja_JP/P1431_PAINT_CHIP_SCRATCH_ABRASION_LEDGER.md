# 塗装剥離・擦傷・摩耗台帳

海が消しきれなかったものを通じて、コロニーはまだ話している。塗装はその記録の小さな声だ。耐圧リブより安く、ガスケットより弱く、壊れたハッチより見落としやすい。だから役に立つ。Deep Reachは水の霞と非常灯の中でも作業が読めるように塗った。白は耐圧外皮、暗い下地は硬い面の下、黒鉛色はレールと接触域、橙色は作業者が切断やラッチ解除やシステム操作の前に見るべき場所だった。

Great Tideの後、その色は指示ではなく時系列になった。塩が詰まった剥離は古い。清潔な黒い縁の剥離は後のものだ。傷の上に淡い鉱物粉があれば、その傷は部屋が湿気を吸っていた時期より前にあった。鉱物粉の上に傷があれば、その呼吸が止まった後に工具が通った。ラッチ周りの弧は反復アクセスを保存する。パネル縁近くの短い平行擦れは工具箱やカッターの足が滑った場所を示す。広く磨かれた縁は、乾いた倉庫ではなく圧力や流れの中で重いものが擦れた痕だ。

この層が重要なのは、HECTON-8にはもう信用できない公式表面が多いからだ。端末は死ぬ。ラベルは剥がれる。企業報告は何週間もの作業、失敗、放棄された修理を一文の事故に圧縮する。塗装だけで全容は語れないが、手を時間の中に置ける。退避窓の後でパネルが開いたこと、浸水後もラッチが使われたこと、後のサルベージが作業者の修理痕を横切ったこと、地図が忘れた側から部屋に入ったことを示せる。

塗装は他の物証と合わせて読むと強い。漏れの錆と生物膜は湿った時系列を与える。溶接シームとリベット列は修理順を与える。サルベージ切断面は工具方向と意図を与える。塗装は接触を与える。手が伸びた場所、工具が食い込んだ場所、同じ動作が色を消すまで繰り返された場所だ。だから回収資材になる前に価値がある。正しい欠損色を持つ板は遮蔽、入口、支払い資材、証拠のどれにもなり得る。最初の誤った動きで、その全てが名もないスクラップになる。
