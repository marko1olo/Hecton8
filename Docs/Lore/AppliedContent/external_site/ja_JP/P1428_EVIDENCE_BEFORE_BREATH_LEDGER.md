# 呼吸より先に届く証拠台帳

HECTON-8で最も強い孤立は無線沈黙ではない。返答があり、それでもほとんど何も変わらない状態だ。distress hash、sample certificate、claim packetは、コンパクトで冗長で法的に有用だから動ける。船室容量、隔離、医療リスク、receiver heat marginを求めない。

この違いが設定を硬く保つ。プレイヤーは聞かれても救われないことがある。データは身体より先に価値を持つ。Black Keelと航路経済は不在ではない。慈悲より前に貨物、責任、所有のために作られた優先順位として存在している。

wikiとサイトでは、Evidence Before Breathを単純な規則として扱う。証拠は救助を追い越せる。ドラマは、証拠だけなら喜んで運んだ航路へ、生きた人間を押し戻すところから始まる。
