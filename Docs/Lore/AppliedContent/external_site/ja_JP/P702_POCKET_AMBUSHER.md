# 穴待ち

Aegirのサルベージ班は、自然の空洞ではなく、冠水した産業構造の切り抜き開口を占有する重躯の待ち伏せ摂食種を記述している。報告されている打撃距離は可視体長を超えるため、安全距離を目視で見積もることは信頼できない。

HECTON-8の現場手順では、動物を見ようとするのではなく開口周りのシルトの襟を読む。セクター44のDeep Reach記録はこの種を付随的な入退管理資産に分類している。この区分は閉鎖された通路を記述するが、通路が閉鎖された理由は記述しない。
