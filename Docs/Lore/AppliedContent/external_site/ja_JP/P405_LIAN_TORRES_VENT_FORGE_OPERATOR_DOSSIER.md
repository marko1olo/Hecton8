# リアン・トレス、ベント鍛造オペレーター

リアン・トレスはHECTON-8の産業を奇跡の素材ではなく職人仕事に結びつける。ベント鍛造の証拠は、圧力ガラス、シールリング、セラミックライナーが最初から戦利品だったわけではないことを示す。それらは加工され、拒否され、再ラベルされ、水中で誰かが信じられる程度まで安全にされた。

## Scanner
