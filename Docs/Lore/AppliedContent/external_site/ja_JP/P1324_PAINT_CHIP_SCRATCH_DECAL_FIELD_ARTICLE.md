# 塗装剥がれと傷の証拠

塗装は、沈んだ基地に残る数少ない正直な公開言語だ。会社は作業を整理するために表面を塗った。圧力外皮にはオフホワイト、硬い被膜の下には黒鉛プライマー、整備動作には橙、手や工具がストレス下でも正しい縁を見つけられる場所には小さな安全線。海が入るとその秩序は崩れるが、消えはしない。記録になる。

塗装剥がれは時間の断面だ。上の色は、その表面が何であるべきだったかを言う。プライマーは傷の深さを言う。剥がれの内側の塩は、部屋が湿った空気を呼吸している間、傷が開いたままだったことを示す。表面だけの塩は、剥がれが漏れより新しいことを示す。藻、ガスケット汚れ、古い鉱物粉の上を横切る傷は遅い。そうした層の下の傷は古い。大きさより方向が有用なことが多い。ラッチの弧、箱の縦擦れ、クローラーの横引き、Marauderが刃で継ぎ目を試した小さな鉤傷。

だから傷はアート制作だけでなくロアに属する。プレイヤーは表面の振る舞いから歴史を解ける。汚れた廊下の清潔な取っ手は怪しい。死んだスイッチの下の新しい橙色片は、停電後に誰かが試したことを示すかもしれない。閉じたハッチの横の磨かれた縁は列を示す。すべての傷が公式出口から離れているパネルは、避難マップが嘘をついた証拠になり得る。

Deep Reachは報告書を書き換えられた。だが損傷した縁すべてを同じ方向に老化させることはできなかった。良いプレイヤーは完璧な塗装を疑い、傷ついた塗装を注意深く読む。壁は鑑賞を求めていない。指示が役に立たなくなったとき、手がどこへ向かったかを示している。
