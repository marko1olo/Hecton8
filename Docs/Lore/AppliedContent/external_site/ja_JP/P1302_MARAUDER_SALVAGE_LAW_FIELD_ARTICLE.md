# Marauderサルベージ法フィールド記事

Marauderという語は喉に引っかかるべきだ。力の幻想のラベルではない。辺境法が、壊れた資産に誰かを触れさせたいが、その資産が人で満ちた職場だったとは認めたくない時に作る肩書きだ。

            HECTON-8はMarauderによってプレイヤーの行動を道徳的に重くする。酸素、借金、道具のため略奪は必要になる。同時に記録もする。盗む物が、水圧と企業清掃を生き残る唯一の証拠かもしれないからだ。良いMarauderは清くない。部屋を剥ぐことと、部屋が証明するものを守ることの違いを知っている。

            現場文化はその矛盾から生まれる。壁印、消されたラベル、労働者名、圧力矢印、醜い速記は、公式法の下に第二の法を作る。礼儀正しい言葉はもう失敗したから粗い。隔壁が呼吸している時に請求マニュアルを読む者はいないから速い。
