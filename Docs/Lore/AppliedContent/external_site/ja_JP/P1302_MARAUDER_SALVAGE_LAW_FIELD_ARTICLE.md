# Marauderサルベージ法フィールド記事

Marauderという語は不快であるべきだ。ロマンチックなクラス名でも清潔な職名でもない。HECTON-8では、法が助けとしてより書類として速く移動する時にMarauderが生まれる。請求システムは、死んだ資産や係争資産に入り、価値を回収し、汚染財産に触れ、個人リスクを受け、ほかの事務所が管理されていたと装えるだけの記録を残す人間を必要とする。

そのためプレイヤーは最初から道徳的に露出している。あなたは植民地を救う騎士ではない。古いDeep Reach手順を手にした専門スカベンジャーで、頭上には債務窓があり、下には帳簿がすでに分類へ押しつぶそうとした人々の海がある。恐怖は略奪することではない。略奪こそがシステムにまだ認識される唯一の行動かもしれないことだ。

Marauderの現場言語はその圧力から育った。黒い輪は、次の潜水者に公式所有者が嘘をついていると伝えるなら落書きではない。押印された死因への線は、失われたポンプ証明を示すなら感傷ではない。ルート印の横の作業員名は、磨かれた記念碑より法的な力を持つことがある。
