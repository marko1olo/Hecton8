# 保存隔離記録

この隔離記録で重要なのは、保留されたもの、保護されたもの、後で壊れ得るものの列挙だ。ペイロード保管、座標ブラインド、部分公開受領書、Atlas損傷、生態保留、作業者名、責任、ブラインド後続請求である。
