# 濡れた滑り止め作業床台帳

HECTON-8で信じられる床はきれいではない。きれいな床は嘘だ。沈んだ作業床は設計と使用の差を見せる。計算された滑り止め、実用の黄線、人間が何度も曲がった弧、塩と錆による海の修正。

滑り止め板は接触で時間を語る。山の上は靴と箱で白く磨かれる。溝は油や冷却液で暗くなる。安全塗装は重要な経路から先に消える。錆はもう誰も触れない場所に育つ。

現場では、それらの跡が選択になる。摩耗線を信じるか、光る溝を避けるか、遅い足跡を証拠として残すか、Deep Reachが隠した保守区画へ黄線を追うかを選べる。
