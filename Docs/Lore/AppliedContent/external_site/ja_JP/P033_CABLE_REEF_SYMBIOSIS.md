# ケーブル礁共生

Cable Reef SymbiosisはHECTON-8中層の警告だ。生命は放棄されたサービス線を動かし続ける一方で、後にAtlas修復論理を引き寄せる絶縁不良を隠すことがある。

## Scanner

ケーブル根マットがP63電力幹線を3つのクランプリングでつかんでいる。信号は緑のスリーブ下をまだ通過。下縁に絶縁不良あり。危険: ドローンと摂食生物の往来が活電流を追跡。
