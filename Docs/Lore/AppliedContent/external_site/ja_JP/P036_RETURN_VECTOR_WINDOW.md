# 帰還ベクトル窓

帰還ベクトル窓は、HECTON-8 からの回収を即時救助ではなく軌道手順として説明する。Black Keel は狭い Aegir 窓を通して信号を受け取れるが、回収は嵐の切れ目、荷電粒子の静穏、中継の完全性、再建された上昇装備に依存する。この packet はキャリアとの初回接触と後の部分回収記録をつなぐ。応答は経路が成立し得る証拠であり、準備完了の証拠ではない。

## Scanner

帰還ベクトル読取 // Black Keel ping を Aegir 嵐間隙で受信。キャリア距離: 高位遷移トラック。中継線は雲電荷下で汚い。誘導コア、熱シールド、帰還ハンドシェイクが全て緑になるまでカプセル上昇拒否。

## Terminal

中継: 空側ラインノイズ / シェルターマストは一度だけ反復可
上昇装備: 誘導コア欠落、熱シールド未認証、バッテリー予備低
処置: carrier ping を回収扱いにする前に上昇連鎖を再建
