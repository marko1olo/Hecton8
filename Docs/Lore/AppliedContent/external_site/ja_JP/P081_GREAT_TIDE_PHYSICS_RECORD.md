# Great Tide物理記録

Great Tide物理記録は惨事を正直なままにする。HECTON-8は最初から危険だった。Aegirの春季配置が海を引き、氷圏が棚を重くし、嵐の重なりが日程余裕を消し、植民地の熱が封じた排水を逆流させた。Deep Reachの罪はその後にある。上昇予備を未来の費用に回し、Atlasの連続性を守り、人間の体を優先度の低い質量として扱った。
