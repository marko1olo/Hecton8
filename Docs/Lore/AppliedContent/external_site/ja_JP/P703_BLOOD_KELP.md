# 血ケルプ

HECTON-8の深海調査は、およそ1,400から2,600 mの硬質基盤に個別の群落を作る赤色色素の固着性大型植物を記録している。この色素は標準的な作業ランプが合わせている青緑帯を吸収するため、群落はランプの光円錐にほとんど反射を返さず、接触距離でしか分解できない。一方で琥珀色の非常用フィルターでは明瞭に写る。

接触は群落全体で発光器の放電を起こし、九十秒程度持続する。サルベージ班はその光を助けではなく自分の位置の開示として扱う。セクター44のDeep Reach採取記録はこの生長を照明用原料として記載し、記録された四件の絡まり事案と並べて非危険・植生の分類を維持している。
