# 貴ガス塩水ポケット

貴ガス塩水ポケットは、HECTON-8の青い経済にある硬い科学的根を定義する。価値あるものは光る岩でも魔法の同位体でもない。密封された圧力履歴だ。貴ガスが鉱物塩水に捕まり、クラスレート痕、微小亀裂、欠陥格子の中に固定されている。試料が無傷で回収された時だけ、その構造は意味を持つ。不注意なクルーはポケットの hiss を聞いて金を見つけたと思う。たいていは金を天候に変えただけだ。そのため現場抽出には圧力ベル、遅い熱遮蔽、精製請求の前の証拠記録が必要になる。ガス比は重要だが、その比がどう生まれたかも同じだけ重要だ。圧力曲線を証明できない試料は、キセノン量が豊かに見えても低品位原料である。この資源は、Xenon-Omegaが拾える鉱物ではなく工程の結果であることをプレイヤーへ教える。Deep Reachが奇跡の宝石を見つけたのではない。密封された履歴のどれを負債素材へ絞れるかを学んだのだ。Atlasは後に損傷した優先順位でそれらを分類した。ポケット自体はそのどちらより古く奇妙で、まだ天候にならずに耐えている地質の泡である。
