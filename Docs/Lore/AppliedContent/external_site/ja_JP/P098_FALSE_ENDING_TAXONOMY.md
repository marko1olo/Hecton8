# 偽エンディング分類

偽エンディング分類は、ゲームのリプレイ構造を説明する。出口は物理的に本物で、利益を生み、それでも道徳的には未完であり得る。ドシエは試行をまたいで知識を残すが、圧力、債務、公的真実が、その結末をただの脱出にするか本当の清算にするかを決める。

## Scanner

結末ボード。成立するほど本物で、傷つくほど間違った出口がある。

## Terminal

結末系統: 物資報酬、部分脱出と同一シード帰還、企業拘束、隔離保留、公開台帳の放出、Atlas盆地解決。結果記録ではペイロード、証拠、債務状態を分けて保持すること。

## Audio

## Field Note

偽エンディングは手品ではない。真実を欠いた有効な取引だ。
