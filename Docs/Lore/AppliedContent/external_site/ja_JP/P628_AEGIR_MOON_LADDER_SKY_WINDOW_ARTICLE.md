# Aegir月梯子の空ウィンドウ

Aegirの月は暦の飾りではない。Skarn、Vela、Claw、Lumen、Thorne、Anvil、Kestrel、HECTON-8、Muteは交通線、中継影、潮汐時刻、blackout危険、transfer費用を示す。プレイヤーは空を正確な天文学ではなく経路圧力として読む。

空を使うために正確な軌道定数は要らない。天候の向こうにある月は悪い中継路を意味し得る。明るい窓は一つの清潔なパケットを意味し得る。会合は驚異ではなく潮汐荷重を意味し得る。ラダーは空を読めるものにするが、講義にはしない。
