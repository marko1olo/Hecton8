# 植民地と労働者

植民地と労働者のラインは、HECTON-8を名のない部屋だらけの美しい廃墟にしないためにある。Deep Reachは災害をstorm、collapse、failed autonomy、Atlas rescue、lost dataとして記録した。その言葉は責任を圧縮するから便利だった。残ったworker recordsは逆のことをする。名前を決定に結び付けたままにする。

pump chiefは、リセットされるべき時に戻らなかったpressure boardを通して見える。relay handは、線が盲目になる前に抜かれたwitness tagsのtrayに残る。brine crewはroute stamps、ration ledgers、塩で焼けた手袋に形を残す。triage technicianは、誰に他人のための酸素を使う許可が出たかを示すrepair tagに現れる。vent-forge operatorは、loss reportがきれいなら隠されるはずだったrejected partsの中で生き残る。

だからこのworker clusterは安いfamily hookを拒む。HECTON-8は植民地を人間的にするために、主人公の秘密の親、失われた兄弟、感傷的な写真を必要としない。pump cardに名前があったために扉が開いたままだった時、shift swapが廊下で死ぬ人物を変えた時、署名がquarantine delayをsafetyからliabilityへ動かした時、人は読めるようになる。

Marauderは人間をpressure evidenceとして読む。よいdossierはまず実用的な問いに答えるべきだ。この労働者は何を所有し、何を遅らせ、何を修理し、何を拒み、何を偽り、何を守ったのか。答えが明確になれば、感情は頼まなくても来る。

海が入る前、植民地は空ではなかった。そこには日課、恨み、能力、shortcut、恐怖、職業上の誇りがあった。残った記録は追悼プレートではない。まだ働く文書であり、その一部はいまも告発できる。
