# 略奪者のグラフィティ・マスク

HECTON-8の略奪者は顔のない襲撃勢力ではない。彼らは労働者、借金の運び手、置き去りの請負人、サルベージ班であり、清潔な通信が監視や課金の対象になるため壁に書くことを覚えた。彼らの落書きは意図的に醜い。緊張下で素早く描け、結露越しに読め、パニックや破壊行為に見えるだけの曖昧さがある。黒い輪は飾りではない。キャリアが聞いているかもしれないという意味だ。折れた矢印は下手な絵ではない。最後の安全通過から廊下が変わったという意味だ。
