# Claw氷散乱危険役

Clawは星系を使い古された場所に見せる。清い氷月ではなく、破片、claim旗、かつて所有者がいた物体でできた明るい場だ。嵐の後、レーンは新しい物質、新鮮なレーダー反射、安いクルーを殺す噂を見せる。危険は普通の物理だ。軌道速度の氷は、船殻が証拠、食料、身体のどれを運んでいるかを気にしない。 そのためClawの儲け話は常に航行費と一緒に来る。見つかる物より、そこへ行くために削れる装甲が先に請求される。
