# システム・キャリア牽引スタック

Black Keelは、責められるほど近く、触れられないほど遠く感じられるべきだ。英雄的救助譚の船ではない。キャリア船体、タグ船バース、貨物ラック、保管ソフト、カプセル展開レール、眠らない台帳から組まれた、賃借の産業スタックだ。

だから役に立つ。サンプルを受け取り、パケットに返答し、軌道を保ち、カプセルを展開し、狭い窓へ機材を押し込める。同時に残酷でもある。すべての有用な機能が、所有権、タイミング、検疫文言、熱余裕、負債に結び付いている。身体は、実在し、そこにいて、耳を傾けながら、構造上シェルターになることを拒む機械の下で取り残される。
