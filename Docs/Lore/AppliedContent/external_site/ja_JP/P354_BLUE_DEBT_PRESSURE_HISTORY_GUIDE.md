# ブルーデット圧力履歴ガイド

ブルーデットは宝石ではなく、魔法の鉱石でもない。Xenon-Omegaを含む圧力安定基質の現場名だ。海が正しい順番で押し潰し、加熱し、冷却し、電気的な傷を入れたあとで初めて価値を持つ鉱物構造である。明るい試料が無価値なこともある。鈍い密封塊が、圧力履歴が清潔で信号ドリフトが静かなら、一か月分の酸素を払うこともある。

だからブルーデットの発見は即座に法的な物になる。Atlasはドリフトを欲しがる。Deep Reachは請求履歴を欲しがる。Salvage crewは、ドローンを起こすほど大きく歌わない容器を欲しがる。この資源が危険なのは、地質、計算、保管、債務の交差点にあるからだ。HECTON-8がただ沈んだ植民地ではなかったことを証明している。圧力が数字を書き込んだ、埋もれた帳簿だった。
