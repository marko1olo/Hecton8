# ケーブル外装補修巻き台帳

良いケーブル補修は、役に立つ形で醜い。そこには焦り、技術、悪い照明が重なっている。作業者は図面で重要に見えたから巻いたのではない。向こう側にまだ意味があったから巻いたのだ。死なせたくないポンプ、もう一度だけ動かす扉、声に出したくない警告を送るセンサー。

補修巻きは圧力と扱いで読める。テープ継ぎ目の内側の塩は古い修理を示す。きれいなクランプの外側の塩は、クランプが後から来たことを示す。浅い擦れ下の繊維は最近の移動だ。深い平帯は工具やブラケットが荷重を持った印になる。

補修ケーブルは資源だけでなく、経路、危険、遅い稼働の証拠になる。銅を見つけるだけではない。意図を見つける。
