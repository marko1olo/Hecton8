# 欠落した帰還印と請求変換

帰還印は小さいが、経路が何を意味できるかを決める。閉じた経路は監査できる。開いた経路は遅延、移送、請求、装備への再接続、未解決質量として扱える。HECTON-8ではその曖昧さが効く。空気が止まった後も、多くの作業者が移動中として表に残った。

証拠は経路スタンプと後のclaim desk例外の間にある。酸素が止まり、スーツタグがベイに残り、帰還欄が空なら、それはただの記入漏れではない。開口を保持した状態だ。身体の証拠が別の場所へ動く間、作業者を契約状態に閉じ込められる。

Deep Reachに悪役の演説は不要だ。デスクは規則通りに動きながら、安い欄を選べる。経路未閉鎖。回収保留。装備質量未解決。サルベージ権保持。欄はどれも狭い。積むと、死んだ経路が閉じた損失にならない。

この印は経路スタンプ重なり、packet notaryマスク縁、転写損傷帯と並べて読む。物は気分で責めない。室内曝露、経路処理、欠落した閉鎖、claim desk変換という順序を積む。
