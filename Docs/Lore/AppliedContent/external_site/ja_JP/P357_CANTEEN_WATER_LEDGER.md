# 食堂水台帳

食堂水台帳は、飲める水を工具保管と同じ厳しさで数えた植民地の、膨れた食堂スレートだ。六つの不足トークン、二つの医療例外、ポンプ室の訂正だけで部屋は生きて見える。英雄的でも整然でもない。圧力系がすでに崩れはじめているのに、まだカップについて争っている。

HECTON-8 の水は、ただの水ではなかった。フィルター、シフト主任、医療例外、ポンプキー、食堂の信頼を通っていた。不足トークンは忘却、盗難、病気、汚染、あるいはもう一シフトだけ局所故障を Deep Reach 書類から隠す監督の判断かもしれない。

グリースペンシルの余白を消してはいけない。部屋が人間になるのはそこだ。友人をかばい、症状を隠し、配給順を争い、酸っぱくなった一つのフィルターを次の下降トーンまで全体パニックにしないようにする手が見える。
