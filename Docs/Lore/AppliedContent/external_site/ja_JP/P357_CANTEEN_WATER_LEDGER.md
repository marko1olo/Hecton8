# 食堂水台帳

食堂水台帳は HECTON-8 の最も単純な人間的遺物の一つだ。食事室の板に飲用水、トークン返却、ポンプアクセス、医療例外が記録されている。災害を説明するものではない。災害が物語になる直前のコロニーを見せるものだ。

価値は質感と証拠にある。六つの消えたトークンは些細に聞こえるが、圧力コロニーで水が何だったかを知ると変わる。飲用水はフィルター、シフト会計、医療 override、ポンプ室 custody を通る。消えたカップは疲れた作業員かもしれない。病気の班、汚染ライン、配給命令の迂回、Deep Reach 報告から局所故障を隠す主任かもしれない。

狙いはメロドラマではない。台帳はコロニーを労働として読ませる。人々は戻り、争い、記録を直し、工具を借り、仲間を守り、海がシステムに入り始めても部屋を正常に保とうとした。HECTON-8 では、そんな普通の痕跡が証拠になる。
