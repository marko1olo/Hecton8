# フォティックマット標本カード

フォティックマットは、HECTON-8で最初に学ぶ読み取れる生態の一つだ。浅場を明るくし、小型grazersを養い、鉱物膜を安定させるが、同時に圧力化学と脆いシームを示す。海が誘って見えるのは、生きた表面が働いているからだ。

## Scanner
