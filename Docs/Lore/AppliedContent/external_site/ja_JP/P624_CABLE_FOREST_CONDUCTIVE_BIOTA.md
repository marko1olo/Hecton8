# ケーブルの森の導電性生物相

ケーブルの森では、HECTON-8は生物とインフラを分けるのをやめる。死んだ中継幹線、裂けた絶縁材、染み出すブライン、辛抱強い植民地藻類が、銅とセラミック粉と電流の記憶に富んだ足場を現地の生命へ与えた。ケーブルケルプは最初は染みとして入り、次に糸となり、最後には濡れた編み導体になった。静電の藪は、保守パルスが線を通ると硬くなることを覚えた。ランタングラスは漏れの近くに育ち、言葉ではなく圧力波に光で答えるが、そのリズムは疲れた潜水者を二度見させる程度には近い。Marauderにとって、この生態は歯のある資源地図だ。接地した切断なら導電繊維、ランタン酵素、小さな有用電荷を得られる。雑に切れば、静かな幹線が苦情になる。偽の保守ピング、古い避難音、濡れた組織を通じて繰り返される経路断片、そしてもはや金属だけではない線を直しに来るドローン。森は邪悪でも奇跡でもない。月が植民地の残したものを使っており、放棄された植民地が、どのプロトコルが先に目覚めるかによって生命を損傷とも修理とも読み違えている。

## Scanner

導電ケルプ // 死んだ中継ケーブルに編み込まれた生きた束。弱い電荷を蓄え、偽のピングを返し、接地してから切ればきれいな電流を渡す。

## Terminal

ケーブルの森の生態 // 静電の藪、ランタングラス、ケーブルケルプが裂けた絶縁材に住み着く。濡れた組織は通電線として扱うこと。振動を読み、損傷した経路を橋渡しし、修理ドローンにはインフラとして記録される場合がある。
