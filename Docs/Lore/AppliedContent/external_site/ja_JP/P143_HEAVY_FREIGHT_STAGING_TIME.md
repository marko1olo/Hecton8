# 重貨物ステージング時間

重貨物ステージングは、恒星間物流が武器なしに暴力になる場所である。居住リング、炉殻、切断クローラー、圧力リブ、食料備蓄は、気軽な約束として扱うには高すぎる。Aegirに届く前から、保険者、担保、輸送者、検査官、代替条項が積み上がる。
