# 空白の quarantine berth receipt

空白の quarantine berth receipt は、返答がないという意味ではない。Black Keel が生きた body を聞き取り、body line に価格を付け、custody query を開き、それでも body を受け入れる部屋を名指しできない時に出せる返答だ。フォームで最も暴力的なのは、印ではなく空の欄である。

tonne-window body ledger の後、次の機械はもっと冷たい質問をする。carrier が body を捕まえたら、その body はどこへ行くのか。body は単なる mass ではない。pressure exposure、suit residue、oxygen debt、legal testimony、Xenon-Omega contamination の可能性、そして誰かが書面で受け入れなければならない liability owner である。その owner が quarantine berth を名指ししなければ、Black Keel は receipt を印刷できても rescue は印刷できない。

## 番号のない扉

quarantine berth はベッドではない。排水、medical-owner authority、custody cameras、pressure transition、sample separation、evidence lockboxes、そして扉が誤って開いた時に誰が支払うかを示す route note を備えた密閉室だ。その部屋は body、suit、residue、そして一緒に上がってくる truth に耐えなければならない。

だから berth number は重要だ。名指しされた berth は body line を目的地にする。空白の berth は body を、全員が認められて誰も受け入れていない cargo のままにする。route は沈黙していない。沈黙より悪い。route は Marauder を読み取り可能にし、 mercy が部屋になる前に止まった。

## 空白の作られ方

receipt は、Black Keel または Keelmark Mutual が return-rights handshake に receiver custody を要求した後に生成される。packet は受理される。body line は alive。tonne-window は価格化される。contamination class が暫定的に付く。そして receiver column が null を返す。berth id なし、medical owner なし、custody door なし、release officer なし。

Deep Reach はその空白に殺害命令を書く必要がない。古い clauses だけで空白を合法に見せられる。external review pending、pressure quarantine not certified、proof priority unresolved、route-notary mismatch、receiver braking debt unpaid。どの clause も遅延に聞こえる。まとめると、扉は番号を持たないままになる。

## 世界が見せるもの

receipt は物理的であるべきだ。quarantine slot printer に詰まった感熱紙の巻き。まだ alive と読む body line の上に押された赤い `NULL BERTH` スタンプ。packet accepted と lift blocked を同じ呼吸で示すコンソール。高い確認チャイムの後に鳴る Black Keel の低音。部屋欄が空のまま次の carrier pass へ進む berth timer。

これらの物は、演説なしに規則を教える。助けは存在する。route は起きている。system は body を見ている。できない、またはしたくないことは、その body を誰か別の責任にすることだ。

## 誤読で壊れるもの

空白の berth を missing data として扱うと、route の鋭さが消える。空白は壊れたラベルではない。失敗した receiver handshake の可視状態だ。proof なしの拒否として扱えば、Deep Reach は望んでいたきれいな否認を得る。既定で rescue pending と読むなら、Black Keel は契約より柔らかくなる。

receipt は custody trap として読む。duplicate receipts は新しい機会ではなく同じ blocked state を指す。timestamp が body ledger より古い stale receipt は危険だ。berth がなくても新しい packet hash を持つ receipt は、route が Marauder をまだ帰還者ではなく recoverable mass として扱っている証拠になる。

## 欄を埋めさせる方法

前進に必要なのは希望ではなく leverage だ。blank receipt を body ledger、receiver braking debt、quarantine berth custody、return-rights handshake と合わせる。矛盾する stamps を探す。samples 用に予約された部屋だが bodies 用ではない部屋。proof を archive するが medical door を開かない public receiver。coordinates は受け取るが testimony は受け取らない corporate receiver。

埋まった berth field は議論を変える。carrier には捕まえる部屋があり、receiver には請求先があり、custody owner には晒される責任があり、save、reload、scene shift、次の packet pass の後にも繰り返せる一行がある。rescue は空白が防御不能になった時に始まる。それまで Marauder は闇に失われていない。Marauder は、誰も署名したくない扉の前で待っている。
