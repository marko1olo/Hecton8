# Kestrelリレー影図

HECTON-8では、空は背景ではない。KestrelがAegirレーンを通過すると、Black Keelがパケット、母船タイミング、回収計算に必要とする同じ幾何へリレー影が落ちる。信号はランプのように滑らかに暗くならない。櫛に割れる。明るい縁、ノイズの溝、古い戻り、そして誰かが聞いた証拠になる程度のチェックサムはあるが、リフト承認に必要な連続性はない短いバーストだ。下の海は問題を悪化させる。水は電力を食い、嵐は表面タイミングを曲げ、Aegirの荷電環境は清浄な空を移動する法的かつ物理的危険に変える。アップリンク失敗は見捨てられた証拠ではない。あなたを運べる唯一の空を、月が横切っているだけかもしれない。

## Scanner

リレー影 // KestrelがAegirレーンを横切っている。アップリンク品質は滑らかに落ちず、歯のように欠ける。荷電した縁が開くまでバーストパケットを保持。

## Terminal

AEGIRリレー予報 // Kestrel掩蔽とAegir磁気ノイズが影の櫛を作る。低帯域音響リレーは上昇データをキューに入れられるが、検証は清浄な母船エッジを待つ。

## Audio

## Field Note
