# 圧力階梯音響図

HECTON-8は垂直に作られている。海は圧力と化学の階段だ。有光棚、ケーブル礁、塩水峡谷、機械原、Atlas Basin。各帯は、プレイヤーが何を見て、聞いて、信じ、修理できるかを変える。だから下降は物理的であり続ける。より深い経路は、より厳しいシール、悪い帰還タイミング、奇妙な浮力、壊れた計器から届く証拠を意味する。

鉱物の海が電磁信号を食うため、無線は早く失敗する。音は使えるが、水柱が音を作り替える。濃い塩水はパルスを捕まえて横へ運ぶ。熱水孔の熱はそれを裂く。ケーブル礁は信号を跳ね返し、通路が開いているように見せる。怖いのは実用的だからだ。ソナー反射は、圧力、線の張力、動き、二度目のピングが一致するまで真実ではない。
