# Deep Reach圧力セラミック

Deep Reach圧力セラミックは、なぜコロニーが機能できたのか、そしてなぜその残骸が今も致命的なのかを説明する。Deep Reachは無能で海底産業を築いたわけではない。現地粘土、硫化物フラックス、噴出炉の熱を増幅し、通常の金属が耐えられない圧力で生き残るセラミック部品を作った。クランプリングは居住区の継ぎ目を支えた。シール座はポンプを正直に保った。カッター接点は塩水中で熱を運び、柔らかい屑にならなかった。上昇クレードル断熱は、発射部品が自分を焼くはずの瞬間に、重要な数分を買った。その有能さは恐怖と矛盾しない。恐怖の一部だ。圧力セラミックを回収するプレイヤーは、Deep Reachが人々を生かせるほどこの世界を理解していた証拠を扱っている。その上で、放棄を利益にする手続きと責任の形を選んだ証拠でもある。素材は両方を記憶している。脱出レシピでは貴重で、残骸では危険だ。熱衝撃は破片開花を起こす。静かな白い亀裂が、リング面に刃の花弁として開く。誤った減圧は完璧なシール座を榴散片にする。これは汎用の悪役素材ではなく、産業の真実として使う資源である。コロニーが依存したのは、これが機能したからだ。プレイヤーも同じ理由で依存する。
