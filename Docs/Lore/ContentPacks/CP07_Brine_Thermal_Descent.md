# CP07 - Brine And Thermal Descent

Status: source draft.
Packet Family: geology traversal / heat / pressure chemistry.
Canon Owner: HECTON8_Field_Atlas Z06/Z07, HECTON8_Resource_Gameplay_Catalog.

## Player Experience

The moon itself becomes a machine the player must learn.

Brine layers behave like false floors and hidden roads. Thermal fields provide power and rare materials, but punish sloppy routing. This is where exploration should feel technical without becoming a lecture.

## Core Objects

Brine Curtain:
Density boundary. It hides routes, bodies, predators, and preserved hardware.

Ballast Station:
Old infrastructure used to tune descent/ascent through layered water.

Vent Chimney:
Heat source, mineral source, hazard, and visual landmark.

Thermal Tap:
Deep Reach hardware built into natural heat.
