# CP10 - Final Payload And False Exit

Status: source draft.
Packet Family: endings / false exits / payload choice.
Canon Owner: Final_Payloads_Gameplay_Map, False_Ending_Families.
Runtime Layer: Narrative.
Primary Surfaces: carrier transcript, ending dossier, PDA, website archive.

## Player Experience

The player should be able to leave wrong.

A material exit can be real. A coward exit can be human. A Deep Reach capture can look like success. A containment ending can cost more than a victory screen wants to admit.

## Core Objects

Ascent Package:
Built or recovered hardware for leaving ocean/atmosphere.

Payload Slot:
Limited physical/cargo/data capacity. Forces choice.

Evidence Stack:
Names, manifests, directives, process proof, carrier logs.

Sample Casket:
Blue debt, living sample, substrate, or Atlas-compatible material.

Carrier Receipt:
Cold summary of what left and what was ignored.

## Text Drafts

Title:
Payload Window.

Scanner Short - Ascent Package:
Improvised ascent package. It can leave the ocean if mass, weather, and carrier geometry agree.

Scanner Short - Payload Slot:
Limited payload capacity. Every kilogram is an argument.

Marauder Field Note:
Getting out is a route. Getting out clean is a myth.

Carrier Transcript - Material Exit:
Payload accepted. Claim value updated. Evidence state insufficient for external dispute.

Carrier Transcript - Evidence Exit:
Cargo value reduced. Legal exposure packet detected. Routing conflict opened.

Carrier Transcript - Capture Route:
Recovery accepted. Medical quarantine and contract debrief authorized by priority handler.

PDA Codex Body:
The final payload defines the ending more than the launch. HECTON-8 can return money, proof, names, living material, Atlas signal, Deep Reach process knowledge, or silence. The carrier does not treat those choices equally.

Audio Beat:
Window is open. It will not stay open for everything.

## Gameplay Use

- False material ending.
- Partial exit and return.
- Evidence/Names/Containment endings.
- Deep Reach capture risk.
- Replayability through different payload combinations.
