# Dead / Cold Claims

Status: draft encyclopedia entry.

## Public

A dead claim is a failed settlement, extraction site, station, or moon operation where the original owner has lost practical control but not necessarily legal ownership.

A cold claim is quieter: no confirmed active crew, no clean abandonment notice, no public disaster record, and enough automated systems still running to keep lawyers interested.

## Marauder Field Note

Dead claims still kill. Cold claims lie first.

If the owner says there is no crew, look for oxygen use. If the owner says there is no hazard, look for missing maintenance cycles. If the owner says salvage is unauthorized, ask what they left behind that can still hurt them.
