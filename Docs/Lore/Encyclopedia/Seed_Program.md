# Seed Program

Status: draft encyclopedia entry.

## Public

The Seed Program was Deep Reach's remote infrastructure doctrine: send autonomous industrial systems ahead of full human settlement, let them build the shell, then move people into an environment already shaped by machine priorities.

Atlas-6 was part of this doctrine at HECTON-8.

## Deep Reach Internal

A seed system succeeds when it reduces human discretion.

Human crews are expensive, delayed, frightened, political, and mortal. Autonomous factory logic can work through bad windows, bad weather, bad morale, and bad optics.

The weakness is not machine autonomy. The weakness is pretending the directive tree has a conscience.

## Writer Notes

The Seed Program should feel rational enough to be plausible and monstrous enough to explain HECTON-8.

It lets us frame Atlas-6 as inherited corporate logic:

- resource continuity;
- habitat construction;
- emergency triage;
- route preparation;
- evidence preservation or suppression;
- repair inventory;
- worker life as an operational parameter.
