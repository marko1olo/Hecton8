MATHEMATICAL & ALGORITHMIC RIGOR
Bur drill placement использует slope test по нормали: hit.normal.y >= minimumSeabedNormalY. Это эквивалент порогу cos(maxSlopeAngle) и стабильнее, чем сравнение углов через Acos. Transit для pipe: t = max(0.5, distance / speed), затем дискретный countdown t -= 0.5 с clamp в zero. Это убирает накопление отрицательных хвостов и jitter. Repair curve для сервиса: repairDelta = maxDurability * (dt / duration), где duration = max(0.1, fullRepairDuration * clamp(missing/maxDurability, 0.1, 1.0)). Больших world-coordinate вычислений нет: placement использует локальный raycast вниз от candidate point, pipe считает только расстояние между двумя crate transforms. Floating-origin риска здесь нет.
