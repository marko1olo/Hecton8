## STEP 1: SCENE SETUP [~10 minutes]
# ─────────────────────────────────────────────────────────────────────────────────

[ ] 1.1 Open main gameplay scene (Hecton8_MainGame or equivalent)

[ ] 1.2 Verify required managers exist:
    [ ] BiomeMatrixDirector (provides biome context)
    [ ] WorldZoneDirector (provides zone information)
    [ ] HectonVoxelEngine (mesh generation)
    [ ] MapMagicBridge (terrain sampling)
    [ ] GameTickManager (ITickable registration)

[ ] 1.3 Create empty GameObject named "CaveDirectorSystem"
    └─ Parent: Scene root or [CaveSystem] folder

[ ] 1.4 Add CaveBioluminescenceSystem to "CaveDirectorSystem"
    └─ Inspector → Add Component → CaveBioluminescenceSystem

[ ] 1.5 Configure CaveBioluminescenceSystem in Inspector:
    [ ] Enable Biolum: ✓ (true)
    [ ] Shallow Intensity: 2.0f
    [ ] Mid Intensity: 1.5f
    [ ] Deep Intensity: 1.0f
    [ ] Hazard Range Scale: 1.5f
    [ ] Update Interval: 5 (frames between tick updates)
    [ ] Debug Log Light Spawn: □ (false — set true only for debugging)

[ ] 1.6 Locate WorldCaveDirector in scene
    └─ Search Assets/Scripts/ or find via scene hierarchy

[ ] 1.7 Assign CaveBioluminescenceSystem reference in WorldCaveDirector:
    [ ] In Inspector, find field "caveBiolumSystem" (empty SerializeField)
    [ ] Drag "CaveDirectorSystem" GameObject into it
    [ ] Verify assignment shows Component: CaveBioluminescenceSystem

[ ] 2.2 Open Console (Window → General → Console)

[ ] 2.3 Force script recompilation:
    [ ] Assets → Reimport All (or Ctrl+R if bound)
    [ ] Wait for "Compiling..." message to finish (~30 seconds)

[ ] 2.4 Verify no compilation errors:
    [ ] Console should show 0 errors
    [ ] If errors appear, copy full error to log and check:
        - Missing using directives
        - Type name conflicts
        - Null reference in Inspector assignment

[ ] 2.5 (Optional) Run static analysis:
    [ ] Window → Analysis → Run Analyzer (if available in your project)
    [ ] No warnings related to new cave system files

## STEP 3: EDITOR PLAYMODE TEST [~15 minutes]
# ─────────────────────────────────────────────────────────────────────────────────

[ ] 3.1 Enter Play Mode (Ctrl+P)
    └─ Watch console for startup messages

[ ] 3.2 Expected console output (in order):
    [ ] "[GameTickManager] Started" or similar
    [ ] "[BiomeMatrixDirector] Initialized" or similar
    [ ] "[HectonVoxelEngine] Ready" or similar
    [ ] (If cave spawns immediately) "[WorldCaveDirector] Cave generated at..."
    [ ] (If enabled) "[CaveBiolum] Created light 0 in cave..."

[ ] 3.3 Verify player is spawned in safe starting location
    [ ] Can move/swim
    [ ] Camera responds to input
    [ ] Sonar/visor functional (if enabled)

[ ] 3.4 Manually wait for cave spawn (may take 30-60 seconds):
    [ ] Keep watching console for generation messages
    [ ] If no caves spawn after 2 minutes:
        - Check console for errors (null manager, voxel engine crashed, etc.)
        - Verify MapMagicBridge is working (terrain height queries)
        - Check BiomeMatrixDirector has valid profiles assigned

[ ] 3.5 Once cave spawns (console shows "successfully generated"):
    [ ] Exit Play Mode (Ctrl+P again)
    [ ] Do NOT save scene yet

## STEP 4: CAVE VISUAL INSPECTION [~20 minutes]
# ─────────────────────────────────────────────────────────────────────────────────

[ ] 4.1 Enter Play Mode again and navigate toward spawned cave

[ ] 4.2 From ~50-100 meters away, observe cave entrance:
    [ ] Light visible (should be colored: yellow/orange for shallow)
    [ ] Particles visible around entrance
    [ ] Entrance marker is readable (you can identify it as a cave entrance)

[ ] 4.3 From ~20 meters away, evaluate entrance color:
    [ ] Shallow cave: warm yellow/orange (inviting)
    [ ] Mid cave: neutral white/cyan
    [ ] Deep cave: cold blue (eerie)
    [ ] Hazardous cave: reddish tint overlaid (danger signal)

    IF COLORS ARE WRONG:
    └─ Check CavePreset.hazardLevel and spawnContext assignments in WorldCaveDirector

[ ] 4.4 Swim toward entrance and enter the cave:
    [ ] Entrance zone feels safe (no immediate threat)
    [ ] Ambient light from biolum system visible
    [ ] Interior of cave is not pitch black (lights are working)

[ ] 4.5 Inside cave, look for interior details:
    [ ] Structures visible (stalactites, boulders, columns, arches)
    [ ] Wall mineral deposits visible (shader overlay)
    [ ] Floor sediment visible (shelf meshes)
    [ ] Bioluminescent glow on walls (fungi particles)

    IF STRUCTURES MISSING:
    └─ Check WorldCaveDirector preset.enableStructures = true
    └─ Check CaveGraphGenerator.Phase4 implementation

    IF NO MINERALS/SHELVES:
    └─ Check InitializeCaveDressingLayer() is called in TrySpawnCaveAt()
    └─ Check dressing config is not null

[ ] 4.6 Swim deeper into cave:
    [ ] Light stays visible (no sudden dark zones)
    [ ] Creatures present (fauna system active)
    [ ] Environment feels consistent with cave type

[ ] 4.7 Exit cave and return to entrance:
    [ ] Landmark is recognizable from inside (safe nav reference)
    [ ] Transition is smooth (no visual popping)
