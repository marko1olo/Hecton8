======================================================================
0. HARD FINDINGS
======================================================================

F1. LIVE RUNTIME SAFE-DEPTH PROGRESSION IS UNDERCUT BY OXYGEN MATH.
Live hull upgrades stack to SafeDepth 4900m and Integrity 150, but live oxygen
drain scales with raw pressureFactor = max(1, pressure * 0.5). Result: fully
stacked suit still dies to oxygen at 4000m in 1.45s. That is not player fault.
That is formula fault.

F2. LIVE PRESSURE MATH IS CONSISTENT. LIVE OXYGEN MATH IS NOT.
Pressure death curve respects suit safe depth. Oxygen curve does not. This
breaks intended deep EVA progression and forces Micro Sub access too early.

F3. LIVE THERMAL MODEL IS GOOD ENOUGH TO CARRY ABYSSAL FEAR ONCE O2 IS FLATTENED.
At 4000m, the live abyssal cold model creates a strong battery-to-integrity
death chain. That already gives the required "short deep EVA" feeling.

F4. LIVE POWER GRID HAS NO THERMAL GENERATOR OWNER.
Current Turbine exists and outputs static +18W. Thermal Generator does not
exist as a live buildable owner. Thermal-generator counts below are PROPOSED
design normalization, not current runtime fact.

F5. LIVE ECONOMY HAS 45 MATERIAL LINES, NOT 50.
The requested 50-line matrix is closed by using 45 live material/component/
processed lines plus 5 live craft outputs that are core economy gates.

F6. LIVE UI LIE THRESHOLDS ALREADY EXIST.
Soft corruption starts at hull stress 0.70. Hard madness override becomes
eligible at 0.90. The project already has the right late-stress language.

1.1 LIVE RUNTIME SURVIVAL CURVES

pressure(d) = 1 + 0.1d

oxygenDrainLive =
    OxygenConsumptionRate
  * max(1, pressure(d) * 0.5)
  * transportOxygenScale
  * difficultyOxygenScale

For d > 10m and base suit values:
OxygenConsumptionRate = 0.5
oxygenTTD_live(d, O2cap) = O2cap / (0.5 * (0.5 + 0.05d))

For base cap O2cap = 100:
oxygenTTD_live(d) = 4000 / (d + 10)

pressureDpsLive =
    PressureDamageRate
  * (1 + (d - SafeDepth) * PressureScalePerMeter)
  * transportPressureScale

Base suit values:
PressureDamageRate = 2
SafeDepth = 50
PressureScalePerMeter = 0.02

For base suit at d > 50:
pressureTTD_live(d) = 2500 / d

passiveEnergyDrainLive = 0.8 * (1 + 0.005 * carryWeightKg)

thermalDrainLive =
    coldExcessC
  * TempEnergyScale
  * transportThermalScale
  * AbyssalHeatingMultiplier
  * deepColdPocketMultiplier

At 4000m in baseline water:
baseTemp = 20C
abyssalPenalty = 42C
envTemp = -22C
starterSuit coldExcess = 17C
T4 shell coldExcess = 12C
AbyssalHeatingMultiplier = 10
hazardGrace = 3s

warningWindow_oxygen = 0.35 * oxygenTTD
criticalWindow_oxygen = 0.15 * oxygenTTD
warningWindow_energy = remaining25pctEnergy / totalDrainAfterGrace

safeDepthPrewarning =
20m margin warning
6m margin critical

At nominal descent 2.0 m/s:
pressure prewarning window = 10.0s
pressure critical window   = 3.0s

1.2 TARGET BALANCE CURVES

TARGET RULE:
Pressure should attack hull.
Thermal should attack power reserve.
Oxygen should accelerate through stress, not through raw absolute pressure.

Recommended target oxygen curve:
oxygenDrainTarget = BaseOxygenDrain * (1 + 0.5 * stress01)

stress01 =
    0.60 * overpressure01
  + 0.20 * thermalStress01
  + 0.10 * pollutionStress01
  + 0.10 * panicStress01

Clamp stress01 to [0, 1].
This matches ABYSS_SURVIVAL_LOGIC intent: O2 multiplier envelope is 1.0x..1.5x.

Recommended overpressure carrier:
overpressure01 = clamp((depth - effectiveSafeDepth) / max(150, effectiveSafeDepth * 0.35), 0, 1)

Result:
- Within rated depth, O2 remains a planning timer, not a fake instant-death timer.
- Beyond rated depth, pressure stress ramps into the same HUD corruption stack.

Recommended suit cost curve:
SuitERU(Tier) = 15 + 7T + 2T^2

Recommended transport cost curve:
TransportERU(ClassTier) = 10 + 7C + 5C^2

Recommended horror-preservation curve:
RiskCost(depthTier)   = 1 + 0.80D + 0.35D^2
RewardValue(depthTier)= 1 + 0.55D + 0.20D^2

Interpretation:
At D >= 2, RiskCost grows faster than RewardValue.
Power-up never deletes horror. It only makes deeper commitment possible.

Oxygen:
- First warning threshold = 35%
- Critical threshold = 15%
- In any stable loadout, player needs 18s minimum from first truthful oxygen warning to irreversible kill.
- 25s to 35s is the preferred deep-route reserve.

Battery:
- First warning threshold = 25%
- Deep EVA should hit battery warning first, not O2 warning.
- Deep EVA preferred window from first battery warning to thermal death: 45s to 60s.

Pressure:
- Pre-breach warning = safe-depth margin <= 20m
- Critical margin = 6m
- Nominal descent doctrine at 2.0 m/s gives 10s warning, 3s critical.

Temperature:
- No thermal warning should fire at 0m or 1000m in neutral water.
- At 4000m, first cold-state alarm should be immediate after the 3s hazard grace.
- On-foot T4 EVA should be survivable for one short repair or one short extraction, not for route wandering.

3.6 EXTRACTION DOCTRINE BY BIOME

Littoral Karst:
- Route fuel biome.
- Player should leave with wire, glass, plates, and one utility craft.
- Do not hide tier-gate rares here.

Fossil Reef:
- Sustain biome.
- O2 aids, med gels, seals, and repair sustain live here.
- Risk comes from pockets and line-of-sight traps, not pure scarcity.

Granite Escarpment:
- Infrastructure biome.
- The player should feel heavier after each run.
- This is where structures, brackets, and grid hardware become credible.

Chemosynthetic Brine:
- Power chemistry biome.
- Item count is lower than Littoral, but value density is higher.
- The biome must punish greed with heat, haze, and route corruption.

Rift Void:
- Jackpot biome.
- One successful run should pay a breakthrough, not a pantry refill.
- Retreat with one rare objective is success. Empty greed-runs are expected.

The suit should not become stronger in every axis.

6.4 HARD RULE FOR FAIRNESS

Mission-critical lies are only allowed when one of the following is true:
- safe pocket is reachable inside 20s to 30s
- beaconed return line already exists
- the player owns a truth-restoring tool state: Analyzer, Scanner, or sheltered base link

If none of those are true, do not push mission-critical UI into 0.90+.
That becomes math cruelty, not horror.
