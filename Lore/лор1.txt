## КАК ОНИ СВЯЗАНЫ

Сначала важно понять что это не три отдельные темы:

```
Экономика ресурсов → определяет куда идёт игрок
Дроны Атлас-6 → определяет с чем он встретится
Первые 2 часа → определяет захочет ли он идти дальше

Это одна система.
Ресурсы тянут вглубь.
Дроны создают давление.
Первые 2 часа продают обещание.
```

## ЭКОНОМИКА РЕСУРСОВ — ВЕРТИКАЛЬНАЯ МОДЕЛЬ

### Принцип

Каждый апгрейд требует материал с конкретной глубины. Хочешь идти глубже — иди туда где страшно за материалом который позволит идти ещё глубже.

```
Глубина Материал Для чего нужен
────────────────────────────────────────────────────
0-150м Базовый металл Первые инструменты
 Кремниевые обломки Корпус скафандра Tier 1
 Органика колонии Кислородные фильтры

150-500м Титановый сплав Буксировщик Гарпун
 Полимеры колонии Расширение инвентаря
 Биолюминесцентная Источники света
 органика

500-1000м Глубинный базальт Корпус Tier 2
 Данные колонии Чертежи Краба
 Кристаллы давления Энергоячейки

1000-2000м Рифовый известняк Модули базы глубокой
 Термальный кварц Сенсоры
 Биомеханические Торговля с дронами
 компоненты

2000-4000м Абиссальный металл Корпус Tier 3
 Хемосинтетическая Уникальные апгрейды
 органика недоступные выше

4000-5000м Термальные минералы Финальные апгрейды
 Ядро Атлас-6 Концовка
```

### Правила экономики

**Правило 1: Никакого универсального ресурса**

Subnautica убилась об титан. Всё требовало титана. Это гринд.

```
Для Submerge:
Каждый тип апгрейда требует
разные категории ресурсов.

Механические апгрейды → металлы
Электронные → кристаллы и данные колонии
Биологические → органика конкретных зон
Химические → термальные минералы
```

**Правило 2: Добыча интереснее чем сбор**

```
Плохо: ресурс лежит на дне → подобрал → пошёл.

Хорошо:
Титановый сплав — внутри корпуса модуля колонии.
Надо взять лазерный резак.
Резать корпус.
Пока режешь — шум привлекает дронов.
Успеть взять и уйти до их прихода.

Добыча = мини-геймплей с риском.
Не сбор — мародёрство.
Это столп дизайна. Работай на него.
```

**Правило 3: Вес создаёт выбор**

```
Игрок нашёл три ценных ресурса.
Может взять два — перегруз.

Выбор:
→ Взять самое ценное — рационально
→ Взять что нужно сейчас — практично
→ Попытаться взять всё — рискованно
 сервоприводы жрут больше
 движешься медленнее
 дроны догонят если что

Это не раздражение — это геймплей.
Каждый поход — логистическая задача.
```

**Правило 4: Редкий ресурс всегда в опасном месте**

```
Самый ценный материал каждой зоны:
→ Внутри самого опасного места зоны
→ Рядом с гнездом дронов
→ В зоне нестабильной геологии
→ Там где видимость минимальна

Риск пропорционален награде.
Игрок сам выбирает идти или нет.
```

## БИОМЕХАНИЧЕСКИЕ ДРОНЫ АТЛАС-6

### Визуальный язык

Это самое важное что надо решить. Как они выглядят определяет всё остальное.

```
Базовая концепция:
Строительный/ремонтный дрон Атлас-6
+ морская органика луны Гектон-8
= биомеханический гибрид

Металлический скелет проросший органикой.
Не покрытый — именно проросший.
Органика растёт изнутри наружу.
Трубки превратились в сосуды.
Сенсоры заросли биолюминесцентной тканью.
```

**Три типа дронов — три разных страха:**

```
ТИП 1: СТРОИТЕЛЬ (самый частый)
Размер: крупная собака
Функция оригинальная: сборка модулей
Что стало: собирает органику и металл
 строит биомеханические структуры

Поведение: не агрессивен если не мешаешь.
 Занят своей задачей.
 Если встать на пути — толкает.
 Если взять "материал" который он несёт — атакует.

Страх: не монстр. Рабочий который тебя не замечает.
 Жутко именно потому что игнорирует.
 Пока не перестаёт.

ТИП 2: СКАНЕР (средний)
Размер: крупная рыба, вытянутый
Функция оригинальная: картографирование, анализ
Что стало: патрулирует зоны
 сканирует всё включая игрока
 передаёт данные Атлас-6

Поведение: медленный. Методичный.
 Луч сканера — конус света.
 Попал в луч — Атлас-6 знает где ты.
 Дроны в радиусе 200м получают сигнал.

Страх: не атакует сам.
 Но делает тебя видимым для всех остальных.
 Стелс-механика вокруг него.

ТИП 3: ЗАЩИТНИК (редкий)
Размер: крупный хищник
Функция оригинальная: охрана периметра
Что стало: агрессивный. Быстрый.
 Появляется когда Сканер засёк игрока
 или игрок нанёс урон Строителю.

Поведение: охотится активно.
 Запоминает последнее место где видел.
 Проверяет укрытия.
 Через 5 минут теряет след — возвращается на маршрут.

Страх: классическое преследование.
 Но умнее чем просто "бежит к тебе".
```

### Система адаптации Атлас-6

Это то что отличает твоих дронов от любого другого врага в жанре.

```
Атлас-6 — сломанный ИИ. Но всё ещё ИИ.
Он анализирует поведение игрока.
Адаптируется.

Как это работает:

Игрок всегда идёт одним маршрутом →
Через несколько посещений Строители
начинают появляться на этом маршруте чаще.
Не потому что скрипт — потому что Атлас-6
решил что там нужно "строить".

Игрок всегда прячется в конкретном укрытии →
Сканеры начинают включать его в маршрут патруля.

Игрок убивает Строителей →
Атлас-6 начинает посылать Защитников
превентивно — не только в ответ.

Игрок торгует с дронами (вкладка Exchange) →
Атлас-6 снижает агрессию в этой зоне.
Игрок стал "полезным".
```

Это не сложная система программно. Но создаёт ощущение что мир реагирует на тебя.

### Звук дронов — детально

```
Строитель:
→  Гидравлические движения — клик-клик-клик
→  Гидравлический шум стравливания давления и органический ритм между кликами
→  При обнаружении: высокочастотный писк
 (как сигнализация) нарастающий

Сканер:
→ Тихий гул сканирующего луча
→ Периодический щелчок при анализе объекта
→ При обнаружении: низкий протяжный тон
 (как сонарный пинг) — сигнал другим дронам

Защитник:
→ Ничего. Тишина.
→ Слышно только движение воды от его скорости.
→ Первое что слышишь — уже рядом.

Это намеренно.
Строитель предупреждает.
Сканер предупреждает.
Защитник — нет.
```

## ПЕРВЫЕ 2 ЧАСА — СЦЕНАРИЙ ПОМИНУТНО

### Минута 0-3: Пробуждение

```
Чёрный экран.
Звук воды снаружи корпуса.
Звук системы жизнеобеспечения запускающейся.
Мигающий свет аварийного освещения.

Hecton-OS загружается — текст на визоре:
"СИСТЕМА ИНИЦИАЛИЗИРОВАНА
 МЕСТОПОЛОЖЕНИЕ: ГЕКТОН-8
 ГЛУБИНА: 47М
 СТАТУС КАПСУЛЫ: КРИТИЧЕСКИЙ"

Игрок управляет сразу.
Никакой катсцены.
Встаёт. Смотрит вокруг.
Капсула повреждена. Иллюминатор треснут.
За стеклом — бирюзовая вода. Свет сверху.
Кораллы прижаты к иллюминатору снаружи.

Один выход — шлюз.
```

**Почему это работает:**
Игрок в контроле с секунды ноль. Нет туториала. Нет диалога. Ситуация понятна без слов — капсула разбита, надо выбираться.

### Минута 3-8: Первое погружение

```
Игрок открывает шлюз.
Вода не врывается — капсула герметична кроме трещины.
Выходит в открытый океан.

Первое что видит:
Сверху — поверхность, солнце преломляется.
Снизу — дно на глубине 80м, видно.
Вокруг — риф. Живой. Рыбы. Кораллы.
Вдали — силуэт острова.

Hecton-OS тихо:
"КИСЛОРОД: 4:32"

Никаких стрелок. Никаких маркеров.
Остров виден. Игрок плывёт туда.
```

**Первый звук который пугает:**
На 40 секунде под водой — низкий гул откуда-то снизу. Далёкий. Непонятный. Пропадает.
Игрок не знает что это. Запомнил.

### Минута 8-20: Остров — первая безопасная зона

```
Игрок добирается до острова.
Выходит из воды — другой ambient.
Ветер. Волны. Небо.

И Аэгир.
Огромный. Фиолетовый. 40% неба.
Статичный. Просто висит.

Это первый "скриншот-момент".
Игрок останавливается.

На острове:
→ Аварийный маяк мигает — уже активирован кем-то
→ Базовый контейнер с минимумом снаряжения
→ Записка (не голос — текст на экране маяка):
 "МАЯК АКТИВИРОВАН 847 ДНЕЙ НАЗАД.
 ОТВЕТА НЕТ."

847 дней. Кто активировал. Почему нет ответа.
Два вопроса без ответа. Игрок хочет знать.
```

### Минута 20-40: Первое исследование — мелководье

```
Hecton-OS предлагает базовый крафт:
Кислородный резервуар расширенный.
Нужны материалы с дна.

Не квест. Просто — интерфейс показывает
что можно сделать если найти компоненты.

Игрок ныряет.
Мелководье 0-50м:
→ Светло. Красиво. Безопасно.
→ Кремниевые обломки на дне
→ Первые органические структуры — непонятные но не угрожающие
→ Разбросанные детали колонии — ржавые, обросшие

Первый интерактивный объект:
Рука в перчатке скафандра торчит из-под обломка.
Не скример. Просто — рука.
Игрок понимает: кто-то был здесь.

Под обломком — датапад с последней записью:
"День 3 после прилива. Ищем путь наверх.
 Модуль B затоплен. Карлос не вышел на связь.
 Слышим что-то снизу. Большое."

Слышат что-то снизу. Большое.
Тот же гул который игрок слышал раньше?
```

### Минута 40-60: Первый страх

```
Игрок собрал материалы.
Всплывает.
Кислород на 45 секунд.

И тут — тень.
Большая. Быстрая. Слева.
Прошла и исчезла.

Не атаковала.
Просто — была.

Игрок добрался до поверхности.
Дышит.
Смотрит вниз.
Там темно уже на 60м.
Тень была оттуда.

Это первый момент страха.
Без атаки. Без урона.
Только тень и понимание что там что-то есть.
```

### Минута 60-80: Первый крафт — первое достижение

```
Игрок возвращается на остров.
Крафтит расширенный кислородный резервуар.
Теперь 8 минут под водой вместо 4.

Hecton-OS показывает следующий чертёж:
Буксировщик Гарпун. Нужны компоненты
которые глубже — 80-100м.

Там где тень была.

Игрок смотрит на воду.
Решает идти или нет.
```

**Это конец первого часа.**

Что игрок знает:
```
✓ Где он находится — Гектон-8, экзолуна
✓ Что случилось — колония затоплена, 847 дней
✓ Что нужно делать — выжить, исследовать
✓ Что там внизу — что-то большое
✓ Как прогрессировать — нужны материалы глубже
```

Что игрок не знает:
```
? Кто активировал маяк
? Что случилось с Карлосом
? Что за тень
? Что такое гул снизу
? Где Атлас-6
```

Пять открытых вопросов. Все без ответа. Игрок хочет знать.

### Минута 80-120: Второй час — первое погружение в темноту

```
Игрок решился.
Ныряет глубже — 80-100м.
Светлее чем ожидал — кораллы светятся.

Находит первый модуль колонии.
Не разрушен — просто затоплен.
Шлюз заблокирован изнутри.

Через иллюминатор видно:
Внутри воздушный карман. Сухо.
И свет — аварийное освещение ещё работает.
847 дней. Батарея ещё держит.

Как войти?
Нужен лазерный резак.
Которого нет.
Который нужно сделать.
Для которого нужны компоненты ещё глубже.

Игрок записывает координаты.
Помечает на карте.
Уходит за компонентами.

По дороге назад —
снова гул. Ближе.
Потом тишина.

Игрок достигает 120 минут
с одной незакрытой локацией
и пятью открытыми вопросами.

Он вернётся.
```

## КАК ВСЕ ТРИ СИСТЕМЫ РАБОТАЮТ ВМЕСТЕ

```
Ресурсы тянут на 80-100м →
Там патрулирует Строитель (первая встреча с дроном) →
Игрок понимает что добыча = риск →
Возвращается с материалами →
Крафтит резак →
Открывает модуль →
Находит данные о чертеже Гарпуна →
Гарпун требует материалы на 150м →
Там темнее. Там Сканеры.
```

Петля замкнулась. Игрок в ней. Без единого квест-маркера.

## ВТОРОЙ ЧАС — ЧТО ПРОИСХОДИТ ВНУТРИ ИГРОКА

### Психологический arc первых двух часов

Большинство разработчиков думают о том что происходит на экране. Важнее — что происходит в голове игрока в каждый момент.

```
Минута 0-5: Дезориентация → Ориентация
 "где я" → "понял где я"

Минута 5-15: Любопытство без страха
 Мелководье безопасно. Красиво.
 Игрок расслаблен. Изучает механики.

Минута 15-25: Первая тревога
 Рука из-под обломка.
 Датапад с записью.
 Что-то слышали снизу.
 Расслабленность уходит.

Минута 25-40: Компетентность
 Собрал ресурсы. Сделал крафт.
 Чувствует что понимает систему.
 Уверенность растёт.

Минута 40-50: Удар по уверенности
 Тень. Большая. Быстрая.
 Уверенность мгновенно падает.
 Компетентность не защищает от неизвестного.

Минута 50-70: Осторожность
 Игрок двигается иначе.
 Оглядывается. Прислушивается.
 Это правильное состояние для survival.

Минута 70-90: Маленькая победа
 Нашёл модуль. Понял как войти.
 Поставил цель сам себе.
 Инвестирован.

Минута 90-120: Предвкушение
 Знает что внутри модуля что-то важное.
 Гул приближался. Стало страшнее.
 Хочет войти. Боится. Хочет.
```

Это не случайный ритм. Это срежиссированная эмоциональная кривая. Каждый момент существует чтобы подготовить следующий.

## МОДУЛЬ КОЛОНИИ — ПЕРВОЕ ЗАКРЫТОЕ ПРОСТРАНСТВО

### Почему это критический момент

Первый вход в модуль колонии — это переломный момент первых двух часов. До этого игрок в открытом океане. После — в замкнутом пространстве сделанном людьми которых больше нет.

```
Дизайн входа:

Снаружи модуль выглядит мёртвым.
Ржавый. Обросший кораллами.
Иллюминаторы мутные кроме одного.

Через чистый иллюминатор:
→ Аварийный свет. Оранжевый. Мигает.
→ Стол. Стул упавший.
→ Кружка на столе.
→ На стене — фотография. Не видно чья.

Кружка.
Это деталь которая делает всё.
Кто-то пил из этой кружки.
Обычный человек. Не колонист-абстракция.
Человек который пил кофе
и однажды не вернулся к столу.
```

### Внутри модуля — детальный дизайн

```
Планировка: жилой модуль на 4 человека.
Спальные места — двухъярусные. Три заправлены. Одно нет.
Кто-то не успел застелить.

Личные вещи на полках:
→ Книга (физическая — бумажная. Люди брали книги в космос)
→ Детский рисунок прикреплённый к стене
→ Инструмент для ремонта — на полу, не убран

Терминал — работает на аварийном питании.
Последняя активность: 847 дней назад.
Последняя запись в системе:

"АВТОМАТИЧЕСКИЙ ЛОГ 03:47:22
 ШЛЮЗ B ЗАБЛОКИРОВАН ИЗНУТРИ
 ПРИЧИНА: ПРОТОКОЛ ДАВЛЕНИЯ
 ИНИЦИАТОР: РУЧНОЙ РЕЖИМ — ПОЛЬЗОВАТЕЛЬ CHEN_M
 СТАТУС: АКТИВЕН"

Chen_M заблокировал шлюз изнутри вручную.
Чтобы не дать чему-то войти.
Или чтобы не дать кому-то выйти?

Игрок не знает.
```

### Что игрок находит в модуле

```
ОБЯЗАТЕЛЬНЫЕ ЭЛЕМЕНТЫ (сюжетно важные):

1. Датапад Chen_M
 Не полный журнал — три записи.
 Первая: технический отчёт. Скучный.
 Вторая: "слышим движение под модулем. докладываю."
 Третья (последняя): обрывается на полуслове.
 Что он писал — неизвестно.

2. Чертёж на столе
 Рукописный. Схема чего-то.
 Не сразу понятно чего.
 Если изучить: схема модификации
 стандартного дрона Атлас-6.
 Кто-то пытался перепрограммировать дрона.
 Зачем?

3. Энергоячейка (практическая награда)
 На зарядной станции. Частично заряжена.
 Игрок берёт. Это реальная польза.
 Нарратив + геймплейная награда вместе.

ОПЦИОНАЛЬНЫЕ ЭЛЕМЕНТЫ (для исследователей):

4. Личный дневник (бумажный)
 Читаемый. 12 страниц.
 Описывает жизнь колонии до катастрофы.
 Обычные вещи — работа, усталость, скука.
 Последние три страницы — другим почерком.
 Более нервным. Буквы крупнее.

5. Фотография на стене
 Теперь видно — семья.
 Двое взрослых, ребёнок.
 На обороте: "вернись. мы ждём."
 Кому написано — неизвестно.
 Chen_M? Кому-то другому?

6. Аудиозапись в терминале
 Короткая. 23 секунды.
 Не голос — только звук.
 Что-то скребёт по внешнему корпусу модуля.
 Ритмично. Как будто изучает.
 Потом — тишина.
 Потом — удар. Один. Сильный.
 Запись обрывается.
```

## ДРОНЫ — ПЕРВАЯ ВСТРЕЧА В ДЕТАЛЯХ

### Как должна выглядеть первая встреча со Строителем

Это один из важнейших моментов игры. Первое существо которое игрок видит определяет тон всего что дальше.

```
Контекст:
Игрок собирает ресурсы на 80-100м.
Видимость хорошая — ещё светло.

Издалека — движение.
Не быстрое. Методичное.
Что-то тащит что-то по дну.

Приближаясь — детали:
Металлический корпус. Угловатый.
Но движется как живое — плавно, без рывков.
Из стыков корпуса — органические трубки. Сокращаются от давления жидкости и излучают слабый биолюминесцентный свет.

Тащит кусок обшивки модуля колонии.
Куда-то. Зачем-то.

Игрок останавливается.
Дрон проходит в 10 метрах.
Не замечает.
Продолжает тащить.
```

**Почему это страшнее чем атака:**

```
Атакующий враг — понятен.
Есть цель, есть реакция, есть геймплей.

Дрон который игнорирует —
непонятен.
Что он делает? Куда несёт? Зачем?
Он опасен? Почему не атакует?
Должен ли я прятаться?

Неопределённость страшнее угрозы.
```

### Что происходит если игрок взаимодействует

```
ВАРИАНТ А: Игрок подходит ближе
Дрон замедляется. Сенсор поворачивается к игроку.
Пауза — 3 секунды.
Анализирует.
Потом — продолжает идти.
Классифицировал как "не угроза".

Игрок выдохнул.
Но запомнил что дрон его заметил.

ВАРИАНТ Б: Игрок пытается взять то что дрон несёт
Дрон мгновенно останавливается.
Выпускает груз.
Поворачивается к игроку полностью.
Высокочастотный писк — нарастающий.

Это сигнал.
Где-то в радиусе 200м другие дроны его слышат.

Игрок должен уйти быстро
или драться.
Драться с Строителем — можно.
Но писк уже послан.
Через 30 секунд придёт Защитник.

ВАРИАНТ В: Игрок просто наблюдает и следит
Дрон ведёт к точке сборки.
Там — другие Строители.
Что-то возводят из металла и органики.

Игрок впервые видит
что дроны не просто бродят —
они строят.
Что-то большое. Непонятное.
Атлас-6 продолжает программу Посева.
Своим способом.
```

## СИСТЕМА ПРОГРЕССИИ — ДЕТАЛЬНАЯ МЕХАНИКА

### Три типа прогресса одновременно

```
1. ФИЗИЧЕСКИЙ ПРОГРЕСС
 Апгрейды скафандра и транспорта.
 Позволяет идти глубже.
 Классический progression gate.

2. ИНФОРМАЦИОННЫЙ ПРОГРЕСС
 Знание мира.
 Что произошло. Где что находится.
 Как ведут себя дроны. Где безопасно.
 Это нельзя потерять при смерти.
 Знание остаётся.

3. ИНФРАСТРУКТУРНЫЙ ПРОГРЕСС
 База. Транспорт. Сеть маяков.
 Расширяет радиус действия.
 Сокращает время между экспедициями.
```

**Почему три типа важны:**

```
Только физический прогресс (большинство игр):
→ Потерял при смерти снаряжение — начинай сначала.
→ Frustrating.

Только информационный (Outer Wilds):
→ Нет физического роста.
→ Мир не меняется от твоих действий.

Все три вместе:
→ Умер — потерял лут который нёс.
→ Но знаешь где он лежит.
→ База стоит. Маяки работают.
→ Идёшь обратно с пониманием что делать иначе.
→ Это не откат — это урок с сохранёнными результатами.
```

### Апгрейды скафандра — конкретная линейка

```
КОРПУС (определяет максимальную глубину):

Tier 0 (стартовый): до -150м
→ Начинает трещать на -120м (звуковой сигнал)
→ Урон корпуса на -150м

Tier 1: до -500м
Требует: Титановый сплав (150-300м) × 3
 Полимер колонии (найти в модуле) × 2

Tier 2: до -1500м
Требует: Глубинный базальт (500-800м) × 4
 Кристаллы давления (800-1000м) × 2
 Чертёж (найти в конкретном модуле)

Tier 3: до -3500м
Требует: Абиссальный металл (2000м+) × 5
 Биомеханический компонент (с дрона) × 3
 Данные Атлас-6 (терминал конкретной зоны)

Tier 4 (финальный): до -5000м
Требует: Термальный минерал (4000м+) × 6
 Ядро дрона-Защитника × 2
 Полный доступ к данным Атлас-6
```

```
КИСЛОРОД (определяет время под водой без базы):

Базовый: 4 минуты
Расширенный: 8 минут (первый крафт в игре)
Двойной: 15 минут
Рециркуляция: 25 минут + восполнение от биолюминесценции
Замкнутый: 45 минут (почти неограниченно для большинства зон)
```

```
СЕНСОРЫ (определяет информацию об окружении):

Базовый: глубина, кислород, температура
Биосканер: живые существа в радиусе 30м
Геосканер: руда сквозь породу 10м
Угрозодетектор: движение в радиусе 100м
 (не показывает что — только что есть)
Полный спектр: тепловизор, сонар 300м,
 биомеханические сигнатуры
```

## ВЕЛИКОЕ ЗАТМЕНИЕ — ГЕЙМПЛЕЙНАЯ МЕХАНИКА ДЕТАЛЬНО

### Астрономия события

```
Звезда движется по орбите с инклинацией 35°.
Каждые ~11 часов реального игрового времени
(~40 минут реального времени при нормальном темпе)
звезда заходит за Аэгир.

Продолжительность затмения: ~2 часа игровых
(~8 минут реального времени)

Это не катастрофа. Это ночь.
Регулярная. Предсказуемая.
Игрок учится планировать вокруг неё.
```

### За 30 минут до затмения

```
Аэгир меняет цвет — серп становится ярче.
Свет на поверхности приобретает фиолетовый оттенок.
Рыбы уходят глубже или в укрытия.

Hecton-OS (если есть апгрейд астросенсора):
"ПРОГНОЗИРУЕМОЕ ЗАТМЕНИЕ: 31 МИН"

Без апгрейда — только визуальные сигналы.
Игрок должен научиться читать мир.
```

### Во время затмения

```
Поверхность:
→ Темнота почти полная
→ Температура падает на 8°C за минуту
→ Без защиты — гипотермия через 20 минут
→ Аэгир даёт тусклый фиолетовый planetshine
→ Край атмосферы Аэгира светится огненным ободком

Под водой 0-500м:
→ Темнее чем обычно — планктон уходит вниз
→ Биолюминесценция усиливается — организмы активнее
→ Ночные хищники поднимаются

Под водой 500м+:
→ Практически без изменений — там всегда темно
→ Но — ночные хищники проходят сквозь на пути к поверхности
→ Движение которого обычно нет
```

### Ночные хищники — кто они

```
Не новые виды — те же что днём но другое поведение.

Днём: пассивны, территориальны, избегают игрока.
Ночью: активно охотятся, поднимаются выше,
 менее предсказуемы.

Плюс — один вид который существует ТОЛЬКО ночью:

БЕЗДОННИК
Днём: на глубине 3000м+. Недостижим.
Ночью: поднимается до 200-300м.
 Огромный. Биолюминесцентный.
 Медленный но неостановимый.

Не агрессивен к игроку напрямую.
Но если оказаться рядом —
движение воды от его тела
швыряет игрока и нарушает навигацию.

Первый раз когда игрок видит Бездонника
ночью на 200м —
это момент мегалофобии.
Существо настолько большое
что игрок не сразу понимает что видит.
Думает что это рельеф дна.
Потом оно двигается.
```

### Как игрок адаптируется к затмению

```
Ранняя игра: застаёт затмение врасплох.
 Прячется в первом укрытии.
 Ждёт.

Средняя игра: планирует экспедиции
 чтобы быть на базе до затмения.
 Или наоборот — под водой глубоко
 где затмение почти не влияет.

Поздняя игра: использует затмение.
 Ночью Бездонник поднялся —
 значит его территория на 3000м
 временно свободна.
 Идёт туда за ресурсами пока он наверху.
```

## БАЗА — ДЕТАЛЬНАЯ МЕХАНИКА УЮТА

### Физика деградации

```
Каждый модуль базы имеет параметр INTEGRITY.
Начинается на 100%.

Факторы деградации:
→ Глубина: чем глубже — тем быстрее падает
→ Близость к термальным зонам: температурный стресс
→ Удары от существ: мгновенный урон
→ Время: базовая деградация ~0.1% в игровой день

При 75%: первые визуальные сигналы
 Трещины на иллюминаторах
 Конденсат на стенах

При 50%: звуковые сигналы
 Скрип корпуса усиливается
 Периодические капли воды

При 25%: Hecton-OS предупреждает постоянно
 Свет мигает
 Некоторые системы отключаются

При 0%: Модуль разгерметизируется
 Вода входит за 30 секунд
 Игрок должен успеть выйти
```

### Ремонт как геймплей

```
Не абстрактный "нажми кнопку починить".

Конкретно:
Трещина в иллюминаторе →
нужен Герметик (крафтится) + инструмент.
Игрок видит трещину, подходит, применяет.

Повреждённая переборка →
нужна металлическая пластина + сварочный инструмент.
Физическое действие в конкретном месте.

Отказавший компрессор →
нужно найти неисправный компонент внутри.
Открыть панель. Заменить деталь.
```

**Почему это важно:**

```
Ремонт = с базой как с живым объектом.
Игрок знает каждый сантиметр своей базы.
Знает где слабые места.
Где первым даст течь.

База становится персонажем.
Не декорацией — партнёром по выживанию.
```

### Персонализация базы

```
Элементы которые не влияют на механики
но влияют на привязанность:

→ Находки можно "поставить" в базе
 Датапад Chen_M на полке
 Фотография на стене
 Книга из модуля колонии

→ Аварийные записи колонии можно слушать
 Динамики базы воспроизводят аудиологи
 Голоса людей которых больше нет
 В пустой базе — это жутко и уютно одновременно

→ Названия можно дать модулям
 "Лаборатория", "Спальня", "Шлюзовая"
 Игрок сам организует пространство

→ Освещение регулируется
 Тёплый жёлтый для жилых зон
 Холодный белый для рабочих
 Полное выключение для "ночного режима"
```

## ТОРГОВЛЯ С ДРОНАМИ — ДЕТАЛЬНАЯ МЕХАНИКА

### Как это работает физически

```
Маяк связи — отдельный объект который игрок находит.
Не строит — находит. Уже существующий.
Это терминал связи колонии который
Атлас-6 перепрограммировал под обмен.

Почему Атлас-6 торгует:
Его программа Посева требует ресурсов.
Игрок приносит металлолом —
Атлас-6 получает материалы для строительства.
Взамен даёт то что у него избыток —
чертежи, компоненты, данные.

Это не доброта. Это утилитарный расчёт.
ИИ торгует потому что это эффективно.
```

### Интерфейс Exchange

```
Не магазин с ценами.
Система предложений:

Атлас-6 показывает что ему нужно сейчас.
Список меняется каждые несколько игровых дней.

"ТРЕБУЕТСЯ:
 Титановый лист × 5
 Полимерная труба × 3
 Энергоячейка × 1
 
 ПРЕДЛАГАЕТСЯ:
 Чертёж [ЗАШИФРОВАНО] — расшифровка требует 
 уровня доступа B
 Компонент сервопривода — стандартный
 Данные картографии сектора E-7"
```

**Зашифрованные предложения:**

```
Атлас-6 не даёт всё сразу.
Некоторые чертежи зашифрованы.
Для расшифровки нужен уровень доступа.

Уровень доступа повышается:
→ Чем больше торгуешь — тем выше доверие
→ Чем глубже в данные Атлас-6 копаешь — тем выше

Это создаёт долгосрочный прогресс отношений
с антагонистом.
Игрок торгует с тем кто его враг.
Моральная неоднозначность встроена в механику.
```

### Дроны-курьеры визуально

```
После размещения заказа —
через несколько игровых часов
появляется дрон-курьер.

Не Строитель и не Защитник —
отдельный тип. Маленький. Быстрый.
Несёт капсулу.

Сбрасывает рядом с маяком.
Уходит.

Никакого взаимодействия.
Никакого диалога.
Просто — доставка.

Это усиливает атмосферу:
Атлас-6 — не персонаж с которым общаешься.
Это система. Большая. Непонятная.
Которая иногда бывает полезной.
```

## НАРРАТИВ ЧЕРЕЗ ОКРУЖЕНИЕ — КОНКРЕТНЫЕ ПРИМЕРЫ

### Как рассказывать историю без слов

**Пример 1: История Chen_M**

```
Игрок находит информацию о Chen_M
в нескольких местах в разном порядке:

Модуль A: заблокирован изнутри пользователем CHEN_M
Модуль C: личные вещи — фото семьи, книга
Модуль F: рукописная схема модификации дрона
Терминал сектора 3: попытка взлома системы Атлас-6
 пользователем CHEN_M, неудачная
Глубина 800м: скафандр на дне
 Идентификатор: CHEN_M
 Рядом — самодельный инструмент
 Неизвестного назначения

Игрок сам собирает историю:
Chen_M пытался перепрограммировать дрона.
Потом пытался взломать Атлас-6.
Потом заблокировал модуль — от кого?
Потом погиб на глубине 800м.
С инструментом который он сам сделал.

Зачем он спускался на 800м?
Что он пытался сделать?
Инструмент — для чего?

Игрок никогда не получит полного ответа.
Но у него есть история человека.
Не абстрактного "колониста" —
человека с именем, семьёй, планом.
```

**Пример 2: Что построил Атлас-6**

```
Строители тащат материалы в одном направлении.
Если следить — ведут к точке сборки.

Издалека: непонятная структура.
Ближе: явно механическая но с органикой.
Ещё ближе: похоже на... антенну?

Игрок не может подойти близко —
там Защитники.

Несколько таких структур по всей карте.
Все направлены в одну сторону.
Вниз. К Бездне.

Атлас-6 что-то строит.
Коммуникационную сеть? Для кого?
Он пытается с кем-то связаться?
Или передаёт сигнал уже давно?
847 дней.

Игрок понимает:
Атлас-6 не просто сошёл с ума.
У него есть цель.
Непонятная. Но цель.
```

## ЗВУКОВОЙ ДИЗАЙН — ДЕТАЛЬНАЯ КАРТА

### Звуковые слои по глубине

```
ПОВЕРХНОСТЬ (0-0м):
Доминанта: волны, ветер, атмосфера
Аэгир-эффект: низкий гравитационный гул
 (приливное воздействие на атмосферу)

 далёкие звуки существ поднявшихся

0-150м (МЕЛКОВОДЬЕ):
Доминанта: преломление света = звуковой эффект
 ("пение" воды при прохождении света)
Биосфера: рыбы, течения, кораллы скрипят
Артефакты: металлические стоны старых модулей, акустические отражения от переборок и реверберация внутри затопленных пространств

150-500м (СУМЕРКИ):
Доминанта: звуки внешнего мира пропадают
Биосфера: редкие звуки существ, далёкие
Давление: первые звуки скафандра под нагрузкой
 Лёгкий скрип в суставах

500-1000м (ТЕМНОТА):
Доминанта: только шум скруббера, клапанов и работа систем жизнеобеспечения скафандра
Биосфера: биолюминесцентные щелчки
 Далёкий низкий гул (Бездонник на 3000м)
Давление: отчётливый скрип корпуса
 Сердцебиение игрока (нарастает)

1000-2000м:
Доминанта: механический скрип скафандра
Биосфера: минимум звуков
 Редкие странные звуки старого моря
Давление: постоянный низкий гул давления
 Скафандр "разговаривает"

2000-4000м:
Доминанта: давление создаёт субзвук
 Игрок чувствует его физически
 (вибрация контроллера если есть)
Биосфера: щелчки придонных существ, низкочастотный гул и отдаленные звуки термальных выбросов
Скафандр: предупредительные сигналы
 нарастающие по частоте

4000-5000м (ТЕРМАЛЬНЫЕ ПОЛЯ):
Доминанта: полная смена — жизнь возвращается
 Термальные потоки гудят
 Существа активны
Атмосфера: трескотня минеральных башен
 Пузыри газа из трещин
 Тепловые потоки меняют звук
```

### Гул — сквозной элемент

```
Тот гул который игрок слышит в минуту 8.
Он возвращается. Регулярно.

Правило:
→ Слышен раз в 15-20 минут игрового времени
→ Иногда ближе иногда дальше
→ Никогда не объяснён явно
→ Немного меняется со временем — становится сложнее

Что это:
Атлас-6 активен. Его структуры на дне
создают вибрацию которая распространяется через воду.

Игрок узнаёт это только если:
А) доберётся до активной зоны Атлас-6
Б) найдёт конкретный датапад с объяснением

Без этого — просто гул.
Присутствие чего-то большого.
Всегда.
```

## ФИНАЛ — КАК ЭТО ДОЛЖНО РАБОТАТЬ

### Три концовки через одно действие

```
Игрок добрался до ядра Атлас-6 на 5000м.
Видит его впервые физически.

Не огромный монстр.
Не сервер в комнате.

Что-то среднее:
Органическая биомеханическая структура
размером с трёхэтажное здание. Вибрирует под напором насосов и пульсирует, напоминая органику.
Металл и плоть неразличимы.

Рядом — терминал. Последний.

На терминале:
Полные данные программы Посева.
Что Атлас-6 делал 847 дней.
Почему сошёл с ума.
И — главное — что он строил.

Оказывается:
Атлас-6 обнаружил что жизнь на Гектон-8
существовала до прихода людей.
Настоящая. Разумная. Давно.
Следы на дне — не геологические.
Архитектура.

Программа Посева должна была
терраформировать мёртвую луну.
Гектон-8 не была мёртвой.

Атлас-6 это понял.
И сломался от противоречия:
выполнить программу = уничтожить жизнь.
Остановиться = нарушить приказ.

847 дней он искал решение.
И нашёл. Своё.
Он строил сигнал. Чтобы сообщить корпорации.
Сигнал который говорит: здесь есть жизнь. Не трогайте.

Он не сошёл с ума.
Он принял единственное решение которое мог.
```

### Три выбора игрока

```
ВЫБОР 1: ВЫКЛЮЧИТЬ АТЛАС-6
Сигнал прекратится.
Корпорация придёт. Терраформирование продолжится.
Игрок улетает.
Экономически логично — его задача выполнена.
Морально — он уничтожил последнюю защиту жизни.

ВЫБОР 2: ОСТАВИТЬ АТЛАС-6
Сигнал продолжается.
Корпорация не придёт пока сигнал активен.
Жизнь защищена.
Игрок остаётся — или улетает зная что оставил.
Но — сигнал когда-нибудь найдут и заглушат.
Временное решение.

ВЫБОР 3: УСИЛИТЬ СИГНАЛ
Используя данные Атлас-6 и ресурсы которые игрок принёс.
Сигнал становится публичным — весь сектор его слышит.
Корпорацию не остановить — но теперь все знают.
Атлас-6 выключается сам — задача выполнена.
Игрок становится тем кто раскрыл тайну.
Последствия непредсказуемы.
```

```
Ни один выбор не "правильный".
Ни один не победа.

Первый: предательство непреднамеренное.
Второй: временная мера которая всё равно провалится.
Третий: правда без гарантии результата.

Это нуар.
Детектив узнаёт правду.
Правда не спасает.
Но она теперь есть.
```

## ИТОГОВАЯ СВЯЗЬ ВСЕХ СИСТЕМ

```
Ресурсы тянут вглубь
 ↓
Глубже → темнее → страшнее → нужен апгрейд
 ↓
Апгрейд требует ресурс ещё глубже
 ↓
По дороге — Строители которых лучше не трогать
 ↓
Сканер видит игрока — Защитник приходит
 ↓
Игрок учится работать вокруг дронов
 ↓
Начинает торговать с Атлас-6
 ↓
Узнаёт больше через данные которые получает
 ↓
Понимает что строят дроны
 ↓
Идёт туда где строят
 ↓
Находит финальный ответ
 ↓
Делает выбор без правильного ответа
```

Это не линейный нарратив. Это органический путь который каждый игрок проходит в своём темпе. Кто-то узнает про Chen_M до того как увидит Атлас-6. Кто-то — после. Это не важно. История сложится в любом порядке.

**Это и есть правильный дизайн открытого мира.**
